# Unit A｜肿瘤是什么

<!-- kianos:kp id="path-u019-kp01" -->
## KP01｜肿瘤本质：致瘤因素撤除后为什么还能继续长

> **主提示：** 基因失控｜单克隆｜相对自主｜2能力↓↑｜对机体1关系

### Detailed Expansion

肿瘤是在致瘤因素作用下，细胞于基因水平失去正常调控后形成的单克隆异常增殖。基因改变一旦建立，致瘤因素不必持续存在，异常克隆仍可继续生长，体现**相对自主性**。

核心身份：

```text
分裂 / 增殖潜能↑
+ 分化成熟能力不同程度↓
→ 与机体正常结构和需求不协调
→ 对机体有害无利
```

“局部肿块”常见但不是定义；白血病等可不形成实体肿块。

**Routing**：CORE｜BOUNDARY｜MI-G

<!-- kianos:kp id="path-u019-kp02" -->
## KP02｜实质与间质：谁决定身份，谁塑造环境

> **主提示：** 实质3决定｜间质4成分｜间质3作用｜无间质×1｜检测3层

### Detailed Expansion

- **实质**＝肿瘤细胞：判断分化方向、完成组织学分类、主要决定生物学行为。
- **间质**＝成纤维/结缔组织、血管/内皮、淋巴细胞、巨噬细胞：营养支持、参与免疫、构成微环境并影响生长/分化/迁移。
- Study 特殊：绒癌无典型肿瘤间质。

检测按问题层级选择：

```text
染色体 → FISH
基因序列 / 融合基因 → 测序
蛋白表达 → 免疫组化 / Western
```

# Unit B｜分化、异型、分级与分期

<!-- kianos:kp id="path-u019-kp03" -->
## KP03｜异型性：肿瘤与来源正常组织哪里不一样

> **主提示：** 结构1轴｜细胞5看｜核4怪｜线粒体↓｜特殊核×1

### Detailed Expansion

异型性包括：

1. **组织结构异型性**：排列、极性、连接与空间结构异常。良性肿瘤常以结构异型性更突出，而细胞仍较成熟。
2. **细胞异型性**：大小形状多形；核大、多形、深染；核仁大且多；核/浆比增大；核分裂象多，可见病理性核分裂。
3. 讲义口径：肿瘤细胞线粒体减少，与瓦伯格效应接口相连。

（特殊：甲状腺乳头状癌核染色质少，可呈毛玻璃样核，不按“越深染越恶性”机械套用。）

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="path-u019-kp04" -->
## KP04｜分化—异型—恶性度：三者怎样同向或反向

> **主提示：** 分化↔异型↔恶性｜间变定义｜3意义｜急慢白血病接口

### Detailed Expansion

通常：

```text
分化越高 → 越接近来源组织 → 异型性越小 → 恶性度较低
分化越低 → 异型性越大 → 恶性度较高
```

**间变**指恶性肿瘤由未分化或极低分化细胞构成，异型显著、恶性度极高。

异型性服务三项判断：良恶性鉴别、分化程度判断、恶性肿瘤分级。白血病急慢性可用“分化停滞阶段”理解，但完整血液肿瘤后置。

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="path-u019-kp05" -->
## KP05｜分级 vs 分期：微观看坏不坏，宏观看占多大

> **主提示：** 分级看2｜分期看3｜TNM｜预后谁更强｜器官T轴可变

### Detailed Expansion

- **分级**：以分化、异型、核分裂等微观特征评价恶性度；常分Ⅰ高分化、Ⅱ中分化、Ⅲ低分化。
- **分期**：以原发灶范围、淋巴结和远处转移评价播散程度，常用TNM。

```text
T：原发灶大小 / 浸润深度 / 局部范围（按器官规则）
N：区域淋巴结
M：远处转移
```

分期对预后和治疗通常更直接。T不能跨器官机械理解：乳腺常看大小/侵犯，胃肠更重浸润深度。

**Routing**：CORE｜CONFUSABLE｜MI-G

# Unit C｜良性、恶性与交界性

<!-- kianos:kp id="path-u019-kp06" -->
## KP06｜良性 vs 恶性：用完整行为组合，不靠单一特征

> **主提示：** 分化｜核分裂｜边界/包膜｜生长｜坏死｜复发｜转移｜副肿瘤｜特殊×3

### Detailed Expansion

| 轴 | 良性一般规律 | 恶性一般规律 |
|---|---|---|
| 分化/异型 | 分化好、异型小 | 分化差、异型大 |
| 核分裂 | 少，无病理性 | 多，可病理性 |
| 边界 | 较清，常膨胀性 | 不清，常浸润性 |
| 生长 | 多较慢 | 多较快 |
| 出血坏死 | 少 | 常见 |
| 复发/转移 | 少复发、不转移 | 易复发、可转移 |
| 副肿瘤综合征 | 无 | 可有 |

不能只靠包膜或速度：子宫平滑肌瘤可无包膜；甲状腺滤泡癌可有包膜；大量淋巴细胞浸润的乳腺髓样癌边界可清楚。

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="path-u019-kp07" -->
## KP07｜交界性与低度恶性：浸润和转移不是同义词

> **主提示：** 定位1｜行为2｜复发/转移｜例4｜脉管瘤/基底癌

### Detailed Expansion

交界性肿瘤的组织形态和行为介于良恶性之间，常呈局部浸润、易复发，但多不远处转移。Study例：骨巨细胞瘤、带状瘤、侵袭性葡萄胎、卵巢浆液性乳头状囊腺瘤。

- 脉管瘤可浸润、易复发，但不转移；
- 皮肤基底细胞癌可浸润，转移很少。

所以：

```text
浸润性生长 ≠ 必然远处转移
转移能力才是恶性肿瘤最重要行为之一
```

**Routing**：CORE｜SPECIAL｜CONFUSABLE｜MI-G

# Unit D｜生长、血管与异质性

<!-- kianos:kp id="path-u019-kp08" -->
## KP08｜肿瘤怎样获得持续供血

> **主提示：** VEGF来源2｜内皮祖细胞｜干细胞转分化2｜血管拟态｜意义

### Detailed Expansion

肿瘤持续生长依赖供血。Source列出四条形成途径：

1. 肿瘤细胞和巨噬细胞分泌VEGF；
2. 吸引骨髓来源内皮祖细胞归巢并分化；
3. 肿瘤干细胞转分化为内皮细胞和周细胞；
4. 肿瘤细胞形成可与血管交通的管状结构，即血管拟态。

这也说明间质和微环境不是被动支架。

**Routing**：CORE｜SPECIAL｜MI-G

<!-- kianos:kp id="path-u019-kp09" -->
## KP09｜为什么恶性肿瘤长得快，化疗敏感却仍会复发

> **主提示：** 生长3因｜主因1｜化疗杀谁｜静止细胞结局｜倍增时间边界

### Detailed Expansion

生长速度由三项共同决定：倍增时间、生长分数、细胞生成与死亡比例。Source强调多数恶性肿瘤倍增时间未必明显短，**生长分数高**更关键。

```text
增殖细胞多 → 生长快 → 对化疗更敏感
静止细胞残留 → 化疗后重新进入周期 → 复发
```

因此“化疗敏感”与“预后差/易复发”并不矛盾。

**Routing**：CORE｜CONNECTION｜MI-G

<!-- kianos:kp id="path-u019-kp10" -->
## KP10｜异型性、异质性与演进：三个词不要混

> **主提示：** 异型=和谁比｜异质=和谁比｜演进3结果｜单克隆/亚克隆

### Detailed Expansion

- **异型性**：肿瘤与来源正常组织比较，强调形态结构差异。
- **异质性**：同一肿瘤内部不同亚群比较，强调生物学性质差异。
- **演进**：亚克隆选择使生长更快、浸润更强、转移更易。

单克隆起源并不意味着所有后代永久完全一致；后续突变形成亚克隆，仍可归于原始克隆谱系。

**Routing**：CORE｜CONFUSABLE｜MI-G

# Unit E｜浸润与转移

<!-- kianos:kp id="path-u019-kp11" -->
## KP11｜扩散、转移与原位癌：先把边界说清

> **主提示：** 扩散2部分｜转移定义3件｜原位边界｜入血≠转移

### Detailed Expansion

```text
扩散 = 局部浸润 / 直接蔓延 + 转移
```

转移必须满足：肿瘤细胞离开原发灶，经一定途径到达他处，并继续生长形成与原发灶同类型肿瘤。仅入血或进入淋巴而未建立新灶，不算完成转移。

**原位癌**未突破基底膜；一旦突破进入间质，才成为浸润癌。

**Routing**：CORE｜BOUNDARY｜MI-G

<!-- kianos:kp id="path-u019-kp12" -->
## KP12｜四条扩散路径：一般规律与高频例外

> **主提示：** 直接｜淋巴｜血道｜种植｜癌一般｜血道例外4｜乳腺特殊

### Detailed Expansion

- 直接蔓延：沿邻近组织扩展；
- 淋巴转移：多数癌最早最常见；
- 血道转移：肉瘤常见，癌多在晚期；
- 种植转移：体腔表面播散。

Source高频例外：绒癌、HCC、甲状腺滤泡癌、肺腺癌最早最常见血道转移。乳腺癌最早最常见仍是淋巴，但早期即可血行至骨。

**Routing**：CORE｜SPECIAL｜MI-G

<!-- kianos:kp id="path-u019-kp13" -->
## KP13｜血流和解剖决定转移落点

> **主提示：** 胃肠→肝｜骨肉瘤→肺｜甲乳省钱→骨｜Krukenberg 3件｜牛眼征

### Detailed Expansion

- 胃肠道癌晚期经门静脉血道转移至肝，可见牛眼征；
- 骨肉瘤经静脉—右心—肺循环，易转移至肺；
- 甲状腺、乳腺、肾、前列腺可经椎旁静脉至脊椎；
- Krukenberg瘤：胃肠道黏液癌，尤其胃印戒细胞癌，主要种植至双侧卵巢。

（易混：牛眼征是转移性肝癌征象，不是某一个原发肿瘤的专属。）

**Routing**：CORE｜RECOGNITION｜MI-G

<!-- kianos:kp id="path-u019-kp14" -->
## KP14｜浸润四步：先分开，再抓基膜、拆ECM、向前走

> **主提示：** CAM↓｜LN-R↑｜蛋白酶↑｜阿米巴迁移｜各对应哪步

### Detailed Expansion

```text
癌细胞彼此分离
→ CAM / E-钙黏蛋白减少

与基底膜黏附增强
→ 层粘连蛋白受体增加

降解ECM
→ 基质金属蛋白酶、胶原酶等增加

迁移
→ 类阿米巴运动进入间质 / 脉管
```

这是一条连续机制，不能拆成四个孤立名单。

**Routing**：CORE｜MI-G

<!-- kianos:kp id="path-u019-kp15" -->
## KP15｜促进扩散：高侵袭亚群、黏附转换和EMT

> **主提示：** 演进｜CD44↑｜nm23↓｜EMT 2失3得｜为何易血道

### Detailed Expansion

促进扩散的Source主轴：

- 演进形成高侵袭亚群；
- CD44高表达；
- 转移抑制基因nm23低表达；

**Routing**：CORE｜CONFUSABLE｜MI-G

# Unit F｜命名、来源与形态

<!-- kianos:kp id="path-u019-kp16" -->
## KP16｜“瘤”不等于良性：命名例外与非肿瘤

> **主提示：** 恶性瘤名单｜非真瘤4｜良性母细胞4｜脊索/脊膜｜粒层/卵泡膜

### Detailed Expansion

名称必须按Source名单记忆：绿色瘤、淋巴瘤、骨髓瘤、黑色素瘤、精原细胞瘤、脊索瘤、多数母细胞瘤等可为恶性。

动脉瘤、室壁瘤、黄色瘤、结核瘤不是由肿瘤性细胞增殖构成的真性肿瘤。肌母细胞瘤、脂肪母细胞瘤、软骨母细胞瘤、骨母细胞瘤为Source列出的良性例外。卵泡膜细胞瘤良性；粒层细胞瘤恶性倾向；脊膜瘤良性，脊索瘤恶性。

## KP22｜油门、刹车、保真与癌前连续谱

> **主提示：** 原癌5类｜抑癌7｜P53 3功能｜两击｜显/隐｜癌前→浸润4阶

### Detailed Expansion

### 1｜分子三层（Recall G5）

```text
原癌基因激活：油门卡住
→ 生长因子 / 受体 / 信号转导 / 转录因子 / 细胞周期

抑癌基因失活：刹车失灵
→ p53、RB、APC、BRCA、NF、WT、VHL等Source例

DNA修复失败：错误持续积累
```

p53承担：细胞周期阻滞、促进修复、损伤过重时诱导凋亡。遗传性抑癌基因综合征可用“两次打击”理解：先天一击使发病更早、多发，体细胞第二击完成失活。

### 2｜癌前连续谱

```text
长期损伤 / 遗传易感
→ 癌前病变
→ 异型增生 / 上皮内瘤变
→ 原位癌（未破基膜）
→ 浸润癌（突破基膜）
```

连续但非必然；癌前病变并不都已有异型增生。具体名单如黏膜白斑、慢性萎缩性胃炎/肠化、腺瘤和息肉病、炎症性肠病等进入器官应用。
