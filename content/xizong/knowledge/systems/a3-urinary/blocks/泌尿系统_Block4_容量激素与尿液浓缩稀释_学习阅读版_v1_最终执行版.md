# 0｜浓缩尿不是“肾把水吸走”这么简单

集合管要把水吸回来，必须同时满足三件事：

```text
外面够咸
髓质间质存在高渗梯度
        ×
通道能开
ADH使AQP2插入集合管顶端膜
        ×
梯度不被冲走
U形直小血管逆流交换维持高渗
```

缺任意一项，浓缩功能都会下降：

- 有 ADH、没有髓质梯度：水没有足够动力离开管腔；
- 有梯度、没有 AQP2：集合管对水不通；
- 梯度形成后被血流冲走：浓缩发动机失去外部环境。

本 Block 最终要形成两个双向模型：

```text
输入状态
渗透压 / 容量 / 灌注 / NaCl
→ 激素与肾端反应
→ 尿量 / 尿渗透压
```

以及：

```text
多尿 / 低比重尿
→ 是溶质拖水？
  还是ADH/AQP2失效？
  还是髓质梯度形成/维持失败？
```

## KP02｜交感 + AngⅡ：轻中度先保GFR，严重时“少滤 + 多吸收”

> **讲义定位 →** 生理 Lecture PDF P280；Recall K2交感总效应。  
> **主提示**：交感4路｜低浓AngⅡ出球｜高浓入球+系膜｜近端｜醛固酮/ADH｜尿量总效应。

强交感已在 K2建立，这里只调用肾端四路：

```text
入球α1收缩 → 肾小球毛细血管压↓、RPF↓
系膜收缩 → Kf↓
球旁β1 → 肾素↑
近端α1 → Na⁺和水重吸收↑
```

AngⅡ具有 Study 强调的浓度依赖：

```text
轻中度低灌注
→ 低浓度AngⅡ偏收缩出球
→ 肾小球毛细血管压得到维持
→ GFR相对保留
同时近端Na水重吸收↑

严重低灌注 / 大失血
→ 高浓度AngⅡ可明显收缩入球
+ 系膜收缩使Kf↓
+ 醛固酮、ADH↑
→ 少滤 + 多吸收
→ 尿量显著下降
```

（易混：AngⅡ不能被压成“永远使GFR升高”或“永远使GFR降低”；要看浓度、入/出球和整体灌注背景。）

## KP04｜醛固酮肾端：ENaC吸Na⁺，水跟随，K⁺被推出

# 4｜ADH与ANP：一个直接收水，一个主动卸载

## KP06｜ADH肾端全链：V2—cAMP—AQP2 + 内髓尿素

> **讲义定位 →** 生理 Lecture PDF P282。  
> **主提示**：ADH：合成/运输/储存｜V2-cAMP-AQP2链｜内髓尿素｜V1条件｜中枢/肾性断点

**压缩 Recall**：ADH = VP = AVP = 当前 Study 的垂体后叶素相关称谓；由下丘脑视上核为主、室旁核等合成，沿下丘脑—垂体束运输，在神经垂体储存释放。

### K4新增重点｜集合管肾端链

```text
ADH
→ 主细胞基底侧V2（GPCR）
→ G蛋白—AC—cAMP—PKA
→ 含AQP2囊泡插入顶端膜
→ 集合管水通透性↑
→ 水重吸收↑
→ 尿量↓、尿渗透压 / 尿比重↑
```

另有两条：

- 增加内髓集合管对尿素的通透性，帮助内髓高渗；
- 浓度明显升高时经 V1收缩血管，生理情况下首先体现抗利尿。

断点识别：

- 下丘脑—神经垂体系统受损 → 中枢性尿崩接口；
- V2 / AQP2效应异常 → 肾性尿崩接口。

## KP07｜ADH释放：先看晶体渗透压，再看有效循环量

> **讲义定位 →** 生理 Lecture PDF P283。  
> **主提示**：最重要1｜促释放7｜抑制4｜出汗链｜饮水链｜1 L清水峰值｜盐水为何不同。

- 最重要促进：血浆晶体渗透压↑；
- 也促进：血容量↓、动脉压↓、AngⅡ、应激、创伤、疼痛、恶心等；
- 抑制：乙醇、ANP、咖啡因、糖皮质激素等。

### 两个完整场景


# 5｜浓缩稀释的三大条件

<!-- kianos:kp id="urinary-b04-kp10" -->

## KP10｜三大条件：动力、通透性、维持器

> **讲义定位 →** 生理 Lecture PDF P284–286。  
> **主提示**：3条件｜各自结构｜谁建立/谁维持｜ADH管什么｜缺一会怎样。

尿浓缩需要：

```text
1. 肾髓质间质高渗梯度
   → 水重吸收的动力

2. ADH使集合管对水通透
   → AQP2提供通路

3. U形直小血管逆流交换
   → 维持梯度，避免溶质被洗走
```

统一理解：

```text
水流动
= 外部渗透驱动力
× 膜对水的通透性
```

（易混：NaCl和尿素负责高渗的**形成 / 建立**；直小血管负责**维持**；ADH主要决定集合管水与内髓尿素通透性。）

## KP11｜外髓 vs 内髓：外髓靠NaCl，内髓靠NaCl+尿素

> **讲义定位 →** 生理 Lecture PDF P284–285。  
> **主提示**：外髓 vs 内髓高渗来源｜主要溶质｜皮质→髓质梯度｜集合管水动力

按本节 Study：

- 外髓部高渗主要由 **NaCl**建立；
- 内髓部高渗由 **NaCl + 尿素**共同建立，Study取各约50%；
- 从皮质向内髓，间质渗透压逐渐升高；
- Study示意内髓最深处可达约血浆4倍、约1200 mOsm/L的接口。

因此：

- 外髓集合管水回收主要受 NaCl形成的高渗驱动；
- 内髓集合管还依赖尿素对高渗的贡献。

这些精确数值进入 MI-D；第一轮先掌握空间与溶质身份。

## KP12｜U形直小血管：逆流交换“只带走多余，尽量不洗掉梯度”

> **讲义定位 →** 生理 Lecture PDF P285。  
> **主提示**：降支水/溶质方向｜折返峰值｜升支方向｜维持什么｜流量过快/过慢两端风险。

### 逆流交换

```text
直小血管降支深入髓质
→ 周围间质更高渗
→ 溶质进入血管、水离开血管
→ 血浆渗透压逐步升高

折返后沿升支返回皮质
→ 血液比同层间质更高渗
→ 溶质回到间质、水进入血管
→ NaCl / 尿素在U形结构中被返还
```

结果：

> 直小血管带走重吸收的水和多余溶质，同时尽量保留髓质 NaCl / 尿素梯度。

### 血流量的两端

- 过快：溶质被“洗出”，梯度下降；
- 明显过低：供氧不足，小管主动转运受损，也会削弱浓缩。

（易混：不是“血流越慢越好”；Study强调正常较低、较慢有利，但过低会造成缺氧损伤。）

## KP13｜尿素再循环：A2入管，A1/A3出管，UT-B帮直小血管交换

> **讲义定位 →** 生理 Lecture PDF P285–287。  
> **主提示**：3段通透性｜UT-A2｜UT-A1/A3｜UT-B｜循环路线｜作用｜vs 生化尿素循环。

```text
内髓间质尿素高
→ 经降支细段UT-A2中等通透进入小管液
→ 升支、远曲、皮质/外髓集合管对尿素低通透
→ 水被回收，管液尿素逐渐浓缩
→ 到内髓集合管
→ ADH促进UT-A1 / UT-A3高通透
→ 尿素回到内髓间质
→ 再经UT-A2进入降支细段
```

直小血管 UT-B 参与尿素逆流交换。

作用：

- 让尿素在内髓聚集；
- 与 NaCl共同建立内髓高渗；
- 增强水回收和浓缩能力。

（易混：这是**肾脏的尿素再循环**；生化“尿素循环”是肝脏鸟氨酸循环，任务是氨解毒。）

## KP14｜AQP地图：AQP1负责固定通水，AQP2负责激素可调通水

> **讲义定位 →** 生理 Lecture PDF P286。  
> **主提示**：AQP1三处｜AQP2位置/膜侧｜ADH是否调AQP1｜AQP3/4层级｜尿崩断点。

| 水通道 | Study位置 | 调节特征 |
|---|---|---|
| AQP1 | 近端小管、髓袢降支细段、直小血管等 | 构成较固定的高水通透性 |
| AQP2 | 集合管主细胞顶端膜 / 胞质囊泡 | 受ADH—V2调节，是终尿可变性的关键 |
| AQP3 / AQP4 | 集合管基底侧接口 | Study列作了解，进入MI-D |

中枢性或肾性尿崩最终都可表现为 AQP2效应不足：

```text
集合管水通透性↓
→ 低渗小管液不能被浓缩
→ 大量低渗尿
```

# 6｜滤过液沿小管的渗透压电影

## KP15｜降支细段：出水、不出NaCl，管液一路变浓

> **讲义定位 →** 生理 Lecture PDF P286–287。  
> **主提示**：水/NaCl/尿素通透性｜AQP｜小管液方向｜折返处｜为什么UT-A2只中度通透？

```text
近端等渗小管液进入降支细段
→ 对水高通透（AQP1）
→ 对NaCl相对不通透
→ 髓质高渗把水拉出
→ UT-A2允许尿素中度进入管腔
→ 小管液渗透压逐渐↑
→ 髓袢折返处最高
```

Study强调 UT-A2“中等通透”有利于浓缩；若尿素过度进入管腔，会减小水外流的渗透差，也会削弱后续升支 NaCl被动外流。

## KP16｜升支细段→粗段→远曲：不出水，只出NaCl，管液一路变稀

> **讲义定位 →** 生理 Lecture PDF P286–288。  
> **主提示**：升细被动｜升粗NKCC2主动｜远曲NCC｜共同水通透性｜稀释强度｜进入集合管状态。

### 升支细段

```text
对水不通透
+ 管液NaCl浓度高
→ NaCl顺浓度被动进入内髓间质
→ 开始稀释
```

### 升支粗段

```text
对水不通透
+ NKCC2主动重吸收NaCl
→ 外髓间质高渗↑
→ 管液显著稀释
```

它是逆流倍增最重要的起始动力。

### 远曲小管

```text
对水不通透
+ NCC继续回收NaCl
→ 管液继续稀释
```

> 进入集合管的小管液按本节 Study 一定是低渗的；终尿最终是否仍低渗，由集合管和 ADH决定。

<!-- kianos:kp id="urinary-b04-kp17" -->

## KP17｜集合管：终尿的最终调节阀

> **讲义定位 →** 生理 Lecture PDF P287。  
> **主提示**：进入时状态｜ENaC｜ADH高/低两链｜皮质外髓尿素｜内髓尿素｜终尿3种可能。

集合管同时处理：

- ENaC介导 Na⁺回收；
- ADH调节 AQP2水通透性；
- 内髓部在 ADH作用下增加尿素通透性。

### ADH低

```text
AQP2少
→ 水通透性低
→ 低渗小管液保持稀
→ 大量低渗尿
```

### ADH高

```text
AQP2多
→ 集合管沿髓质高渗环境回收水
→ 管液逐步浓缩
→ 内髓尿素再循环增强
→ 少量高渗尿
```

因此集合管是调节终尿浓缩和稀释的关键部位，终尿可呈低渗、等渗或高渗。

## KP18｜浓缩功能下降：先定位三层故障

> **讲义定位 →** 生理 Lecture PDF P288。  
> **主提示**：梯度形成4类｜梯度维持2端｜水通透性2断点｜每类例子｜夜尿/低比重接口。

### A. 髓质高渗形成失败

- 袢利尿剂抑制 NKCC2；
- 营养不良 / 蛋白摄入少 → 尿素生成少；
- 髓质纤维化、萎缩等破坏髓袢；
- 小儿髓袢较短 → 逆流倍增效率低。

### B. 高渗维持失败

- 直小血管血流过快 → 溶质洗出；
- 肾血流明显过低 → 缺氧，小管转运障碍。

### C. 集合管水通透性失败

- 中枢性尿崩：ADH合成 / 释放不足；
- 肾性尿崩：V2 / AQP2效应不足。

共同结果：

```text
浓缩能力↓
→ 尿量↑
→ 尿渗透压 / 尿比重↓
→ 夜尿、多尿接口
```

完整慢性肾盂肾炎、CKD和尿崩症诊疗后置相应 Block。

## KP19｜水利尿 vs 渗透性利尿：一个缺ADH，一个管腔溶质多

> **讲义回看 →** P283、P277；Recall K3。  
> **主提示**：第一断点｜管腔溶质｜ADH｜尿渗方向｜典型例子｜补液/内分泌模型边界。

| 轴 | 水利尿 | 渗透性利尿 |
|---|---|---|
| 第一断点 | ADH↓ / 集合管水通透性↓ | 小管液中不易回收溶质↑ |
| 水重吸收 | 集合管末端明显减少 | 多段因渗透压而减少 |
| 尿渗透压 | 明显低 | 由溶质负荷决定，不等于单纯低渗 |
| 典型例子 | 大量饮清水、尿崩接口 | 高血糖尿糖、甘露醇、SGLT2抑制 |

识别算法：

```text
多尿
→ 先问尿是否很稀
→ 再问管腔是否有大量溶质
→ 再定位ADH / AQP2、髓质梯度或近端重吸收
```

（边界：完整糖尿病、HHS、DI、SIADH诊疗不在本 Block展开。）
