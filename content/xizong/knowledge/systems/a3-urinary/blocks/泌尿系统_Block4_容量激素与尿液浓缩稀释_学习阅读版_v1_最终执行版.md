# 0｜浓缩尿需要同时具备动力、通路和梯度维持

同一股管液经过近端等渗回收、降支出水和升支/远曲拿盐后，到集合管时已被稀释。它还能不能重新变浓，取决于集合管外有没有高渗梯度，以及膜上有没有可用的水通路。NaCl 与尿素参与建立梯度，U 形直小血管通过逆流交换尽量防止溶质被洗出，ADH/AQP2 调水通透性；三者是共同条件。

灌注、致密斑 NaCl、有效循环量、心房牵拉和晶体渗透压经各自入口影响交感、RAAS、醛固酮、ADH 与 ANP 的不同效应。它们可并行工作，盐水排出又回过头改变这些输入。轻重低灌注是条件分支，水利尿和渗透性利尿是不同故障入口，不能将它们排成同一条必经时间线。

# 1｜总 Framework

<!-- kianos:framework id="urinary-b04-framework-main" -->

**管液前进与盐水分离同时建立空间梯度。** 降支细段对水通透，升支细/粗段和远曲稀释段拿盐而不透水；NKCC2 的局部盐转运与持续滤过、管液流动反复配合，把差异积成皮质到乳头的纵向高渗。外髓以 NaCl 为主，内髓由 NaCl 与尿素共同参与，进入集合管的管液在课程模型中已低渗。

**相邻血流和尿素循环维持可用环境。** 内髓尿素经降细 UT-A2 入管，低尿素通透的后续段保留它，集合管回水可使尿素浓缩，再经内髓 UT-A1/A3 返回间质。直小血管下降时得溶质失水，上升时返溶质得水，带走回收水并尽量保留梯度；血流过快洗出，过低缺氧也损害浓缩。

**激素回作用于不同变量。** ADH 经基底侧 V2—cAMP/PKA 使顶端 AQP2 增加，并增内髓尿素通透；醛固酮经核受体调 Na/K 转运，水随行另需通路与梯度；交感/RAAS 调血管、滤过和近端回收；ANP 在牵拉输入下从增滤过、减回收和抑保容量激素三路卸载。盐水处理改变容量和张力，再反馈到原输入。

**终尿是共同条件的结果，也是反向定位证据。** 梯度形成失败、维持失败或水门效应不足均可使浓缩差；管内难回收溶质增加也能多尿。读尿渗/比重、管内溶质和容量情境后，才能回到相应环节；完整 DI/SIADH、原醛及水钠治疗仍归既有后续 owner。

# 1A｜同一模型上的自然节点〔完整 Prompt〕

## 管液先出水变浓，再出盐变稀

近端等渗液进入降支细段，AQP1 使水易通过，NaCl 相对难通过；越深入高渗髓质，水越被吸向间质，管液到袢折返处最浓。降细 UT-A2 对尿素中等通透，既参与再循环，也保留水外流和后续盐外流所需的浓度条件。
〈降支细段：出水、不出NaCl，管液一路变浓〔水/NaCl/尿素3通透轴｜AQP1｜管液渗透压/折返峰｜UT-A2通透程度/逻辑〕〉

折返后升支细段不透水，管液高浓度 NaCl 可被动进入内髓间质；升支粗段同样不透水，用 NKCC2 回收盐，是逆流倍增的重要起始动力。远曲稀释段以 NCC 继续回盐不回水，进入集合管时课程模型中已低渗。持续滤过补入新管液并推动前进，让局部水盐分离反复发生，才把横向差异积成纵向梯度。
〈升支细段→粗段→远曲：不出水，只出NaCl，管液一路变稀〔升细/升粗/远曲｜转运体与主动/被动｜共同水通透性｜稀释强度｜进入集合管状态。〕〉

## 管外的高渗靠盐与尿素建立，靠相邻血流维持

外髓高渗主要来自 NaCl，内髓还需要尿素贡献。皮质向乳头的间质渗透压逐步升高，提供集合管回水的外部驱动力；课程比例与最高渗透压是带条件的精确数值，完整去向保留在 Core/MI-D。
〈外髓 vs 内髓：外髓靠NaCl，内髓靠NaCl+尿素〔外髓 vs 内髓高渗来源｜主要溶质｜皮质→髓质梯度｜集合管水动力〕〉

内髓间质尿素经降细 UT-A2 进入管液，随管液流过对尿素低通透的升支、远曲和皮质/外髓集合管。升支与远曲不回水；在允许回水的集合管段，水被拿走使尿素相对浓缩。到内髓集合管，ADH 增强 UT-A1/A3 通透，尿素再回间质，部分又进入降细；直小血管 UT-B 参与尿素交换。这是肾内再循环，肝脏鸟氨酸循环则负责氨解毒。
〈尿素再循环：A2入管，A1/A3出管，UT-B帮直小血管交换〔3段通透性｜UT-A2｜UT-A1/A3｜UT-B｜循环路线｜作用｜vs 生化尿素循环。〕〉

直小血管降支深入更高渗间质时得溶质、失水，折返上行时又返还溶质、接收水。U 形交换让回收的水和多余溶质离开髓质，同时尽量保留 NaCl/尿素。流量过快可洗出梯度，明显过低又可因缺氧损害主动转运；维持梯度不是把血流降到越低越好。
〈U形直小血管：逆流交换“只带走多余，尽量不洗掉梯度”〔直小血管降/升支水盐方向｜折返峰值｜梯度维持｜流量两端风险〕〉

因此，尿浓缩同时需要外部高渗动力、可通水的膜以及未被破坏的梯度维持。任一项不足都能减弱回水；直小血管不是另一个制造 NaCl 梯度的 NKCC2。
〈三大条件：动力、通透性、维持器〔浓缩3条件/结构｜建立vs维持｜ADH通透性｜缺项故障〕〉

## ADH 改膜通透性，必须与外部梯度合用

AQP1 在近端、降细和直小血管等构成较固定水通路；集合管主细胞的 AQP2 位于顶端膜/胞质囊泡，可按激素改变，基底侧 AQP3/4 是另一侧的水通路接口。只有两侧通路与管外驱动力共同成立，水才容易跨过上皮回血。
〈AQP地图：AQP1负责固定通水，AQP2负责激素可调通水〔AQP1三处/调节｜AQP2位置/膜侧｜AQP3/4｜尿崩断点〕〉

调用已学的下丘脑合成—神经垂体储放路径，ADH/AVP 到肾端结合主细胞基底侧 V2，经 G 蛋白—AC—cAMP—PKA 促 AQP2 囊泡插入顶端膜，增加水通透性；它还增内髓尿素通透，帮助维持回水环境。高浓度 V1 血管作用与生理抗利尿效应分开。垂体后叶素是制剂/提取物称谓，不能与纯 AVP 分子等同。
〈ADH肾端全链：V2—cAMP—AQP2 + 内髓尿素〔ADH：合成/运输/储存｜肾端受体—信号—效应链｜内髓尿素｜V1条件｜中枢/肾性断点〕〉

晶体渗透压升高是重要 ADH 输入，有效循环量/动脉压下降、恶心等也可经非渗透途径促释放。净失水较多的出汗且摄水不足，可同时高渗和低容量；胃肠丢失的渗透状态则取决于丢失与补入成分。稀释功能完整时饮大量清水使渗透压下降、ADH 减少，出现水利尿；不能只由呕吐腹泻就断定高渗。
〈ADH释放：先看晶体渗透压，再看有效循环量〔渗透/容量双入口｜促抑因素｜出汗/胃肠丢失｜清水vs盐水〕〉

进入集合管的低渗液仍可经 ENaC 回 Na，但水是另一条通路：ADH 低、AQP2 少时，管液可保持稀并排出较多低渗尿；ADH 高且梯度可用时，水沿途被回收，尿素循环加强，可形成少量浓尿。最终尿液可低、等或高渗，既不由入口低渗锁死，也不由 ADH 单项保证。
〈集合管：终尿的最终调节阀〔进入时状态｜ENaC｜ADH高/低两链｜皮质外髓尿素｜内髓尿素｜终尿3种可能。〕〉

## 灌注与盐递送调 RAAS，醛固酮再作用于末端 Na/K

入球灌注压下降、球旁 β₁驱动增强、致密斑 NaCl 减少，是肾素的三条稳定输入；反方向信号减弱释放驱动。致密斑高 NaCl 一面增强入球 TGF 收缩、一面抑肾素，低 NaCl 一面减弱入球收缩信号、一面促肾素。AngⅡ形成后又负反馈抑制入口；长期低盐是否低灌注仍要看实际容量与 NaCl 递送，NO 等低频名单保留各自 Source 条件。
〈肾素释放：先抓三大稳定输入，再处理 Source-specific 调节因子〔肾素3输入/双向｜NaCl→TGF与肾素2出口｜AngⅡ短反馈｜低频调节的条件边界〕〉

轻中度低灌注时，较低浓度 AngⅡ偏收缩出球，支持毛细血管压力与 GFR，同时促近端回收；严重低灌注时，强交感/高 AngⅡ可收缩入球、系膜，减少 RPF、滤过压力与 Kf，保容量回收又增强，形成少滤多吸收。两种是不同强度条件下的净效应；局部反馈恢复 GFR 也不等于终尿必增。
〈交感 + AngⅡ：轻中度先保GFR，严重时“少滤 + 多吸收”〔交感4路｜AngⅡ低/高浓度靶点对照｜近端｜醛固酮/ADH｜尿量总效应。〕〉

AngⅡ和血 K⁺升高可促进醛固酮。醛固酮进入主细胞，经核受体/转录作用增加 ENaC 与 Na⁺-K⁺泵等，促进 Na 回收和 K 分泌；水是否随行取决于相应段的通透性和梯度。保留盐水能回补容量、灌注并改变原有肾素输入；ADH 另调水门，两种作用可以并行。
〈醛固酮肾端：ENaC吸Na⁺、排K⁺与水随行条件〔醛固酮：来源/刺激｜靶点/受体｜Na⁺/水/K⁺方向｜允许作用｜ACTH边界〕〉

原醛从醛固酮自主增多起步，Liddle 从 ENaC 遗传性过度激活起步，都可保 Na 扩容、低 K、高血压并压低肾素；前者醛固酮高，后者因反馈而低。观察双激素方向可帮助分辨入口，药物靶点分别对应 MR 和 ENaC，完整原醛筛查/定位/治疗仍留内分泌。
〈原醛 vs Liddle：表型相似，激素方向与靶点相反〔共同表型2｜第一故障｜肾素/醛固酮双轴｜肾上腺｜药物靶点〕〉

## 容量牵拉又能触发卸载，各激素不是固定接力

心房壁牵拉促 ANP，肾端入球与系膜舒张支持滤过，同时 cGMP 抑小管 Na 回收，并抑肾素、醛固酮与 ADH，形成利钠利尿的卸载方向。容量下降后牵拉输入随之改变；完整刺激名单、血管/重构效应及 BNP 的心衰用途沿原 Core 和循环 B2 回看。
〈ANP肾端：提高滤过、减少回收、关闭保容量系统〔牵拉入口/刺激名单｜肾小球→滤过｜小管cGMP｜抑制3激素｜血管/重构〕〉

交感偏快速调血管、肾素与近端回收，RAAS 调灌注/保盐，ADH 直接调水门，ANP 按牵拉卸载。反应速度不同却可同时启动。比较 ADH、醛固酮和 ANP 时，应固定输入、分子性质、肾端靶点和第一被调变量，再看终尿与药物效应；托伐普坦切水门，MR 拮抗切保 Na/排 K，不能只凭“都影响容量”互换。
〈四个系统的最小分工：交感抢救、RAAS保压保盐、ADH保水、ANP卸载〔4系统｜输入/肾端/终尿｜快慢接力〕〉
〈ADH vs 醛固酮 vs ANP：三个变量轴不要混〔三激素6轴：输入/性质/靶点/机制/结果/药物｜Na-K-水方向〕〉

## 多尿与低比重是回看这套条件的证据

NKCC2 被抑、尿素不足或髓质/袢结构损伤可使梯度形成不足；血流洗出或缺氧可使梯度维持/转运失败；中枢 ADH 不足或肾端 V2/AQP2 效应不足可使水门失败。它们均可降低浓缩能力，出现夜尿、多尿或低比重线索；完整 CKD、肾盂肾炎与尿崩疾病诊疗后置。
〈浓缩功能下降：先定位三层故障〔梯度形成4类｜梯度维持2端｜水通透性2断点｜每类例子｜夜尿/低比重接口。〕〉

观察多尿时，同时问尿是否很稀、管内是否存在大量难回收溶质。水利尿主要是末端水通透性降低；渗透性利尿是管内溶质增加，其尿渗取决于负荷，不保证低渗。用这些证据回到水门、髓质梯度或近端处理，B5 再将容量、张力与电解质放进临床病例；这里保留完整补液/DI/SIADH 诊疗的原边界。
〈水利尿 vs 渗透性利尿：末端通水受限，或管腔溶质增多〔第一断点｜管腔溶质｜ADH｜尿渗方向｜典型例子｜补液/内分泌模型边界。〕〉

**Residual 边界**：可由自然节点组织并值得主动恢复的知识留在完整 Prompt；仍需独立精确提取的部分沿既有 Memory / Precision 去向复习。数字、名单或配对不因形式自动外移，Prompt 已覆盖也不自动撤销既有精记；本次不改变既有准入。

## KP01｜四个系统的最小分工：交感抢救、RAAS保压保盐、ADH保水、ANP卸载

> **讲义定位 →** 生理 Lecture PDF P280–284；Recall 循环B2。  
> **主提示**：4系统｜输入/肾端/终尿｜快慢接力

| 系统 | 主要读取 | 肾端第一作用 | 终尿方向 |
|---|---|---|---|
| 肾交感 | 急性低压、失血、应激 | 肾血管收缩、肾素↑、近端Na水重吸收↑ | 尿量↓ |
| RAAS / AngⅡ | 灌注↓、致密斑NaCl↓、β1 | 调入/出球、近端Na水、促醛固酮/ADH | 保压、保Na水 |
| ADH / VP | 晶体渗透压↑最重要；容量/压力↓ | V2—AQP2，直接增加集合管水通透性 | 水重吸收↑、尿浓缩 |
| ANP | 心房壁牵拉 / 容量过多 | GFR↑、小管Na水重吸收↓、抑制RAAS/ADH | 利钠、利尿 |

> **醛固酮主要调Na⁺与容量，ADH主要直接调水与晶体渗透压；两者都能增加容量，但不是同一入口。**

时间接力回看循环B2：神经血管反应通常最快；AngⅡ直接血管效应与ADH水通透反应可较快出现；醛固酮转录效应和改变全身盐水总量较慢。各系统可同时启动，不是等交感结束才轮到体液；不硬设每一类固定分钟数。

## KP03｜肾素释放：先抓三大稳定输入，再处理 Source-specific 调节因子

> **讲义定位 →** 生理 Lecture PDF P280。  
> **主提示**：肾素3输入/双向｜NaCl→TGF与肾素2出口｜AngⅡ短反馈｜低频调节的条件边界

### 1｜第一轮 Core：三条稳定输入

```text
入球灌注压↓
→ 球旁颗粒细胞牵张 / 肾内压力信号↓
→ 肾素↑

交感β1↑
→ 球旁颗粒细胞
→ 肾素↑

致密斑NaCl↓
→ JGA信号
→ 肾素↑
```

原题中的长期低盐饮食也需归位：课程按“水随Na⁺”将其串为容量 / 灌注↓→肾素↑。实际应按容量、肾灌注及致密斑NaCl递送判断，不能把低盐饮食无条件等同于低血压或低灌注。

### 2｜致密斑轴必须与 K1 KP12 的双向 TGF 对齐

```text
致密斑NaCl↑
→ ATP / 腺苷等TGF信号增强
→ 入球收缩、单肾单位GFR↓
同时
→ 肾素释放受抑

致密斑NaCl↓
→ 入球TGF收缩信号减弱
同时
→ PGE₂等JGA信号促进肾素释放
```

泌尿K1 KP12已经完成“NaCl → 入球张力 / GFR”的快速反馈；本 KP 只把同一个传感器接到**肾素释放**这一内分泌出口。

### 3｜AngⅡ负反馈：下游不能无限把自己的入口越推越高

```text
肾素↑ → RAAS↑ → AngⅡ↑
                  ↓
             反过来抑制肾素
```

这是 RAAS 的重要短反馈。与此同时 AngⅡ本身还会调入/出球张力、近端 Na⁺回收、醛固酮和 ADH；这些是**下游效应**，不要和“什么促进肾素释放”混成一张名单。

### 4｜NO 与历史促 / 抑名单：降到 Source-specific Precision

历史 Study 还列举儿茶酚胺、缓激肽、PG、小剂量多巴胺、NO、ANP、ET、大剂量 VP 等促 / 抑方向。这里不删除这些考试来源信息，但改变它们的学习地位：

- 儿茶酚胺的稳定主干已经由 **β1 → 肾素↑**承接；
- PGE₂等可参与低 NaCl 条件下的肾素促进；
- **NO 在 JGA / macula densa 中具有情境依赖、常见允许 / 促进作用，不编码成无条件“NO → 肾素↓”箭头**；
- 多巴胺、缓激肽、ET、VP、ANP等完整课程促/抑名单已在K1 KP10第3段列明；本题直接Recall该处，不再另造一份，也不把其中条件相关方向提升为无条件因果链。

> 第一轮掌握“三输入 + AngⅡ负反馈”就能正确运行 RAAS；上下文敏感的低频名单不应成为进入后续浓缩—稀释主线的门槛。

## KP07｜ADH释放：先看晶体渗透压，再看有效循环量

## KP11｜外髓 vs 内髓：外髓靠NaCl，内髓靠NaCl+尿素

> **讲义定位 →** 生理 Lecture PDF P284–285。

## KP12｜U形直小血管：逆流交换“只带走多余，尽量不洗掉梯度”

> **讲义定位 →** 生理 Lecture PDF P285。  
> **主提示**：直小血管降/升支水盐方向｜折返峰值｜梯度维持｜流量两端风险

### 逆流交换

```text
直小血管降支深入髓质
→ 周围间质更高渗
→ 溶质进入血管、水离开血管
→ 血浆渗透压逐步升高

折返后沿升支返回皮质
→ 血液比同层间质更高渗
→ 溶质回到间质、水进入血管
→ NaCl / 尿素在U形结构中被返还
```

结果：

> 直小血管带走重吸收的水和多余溶质，同时尽量保留髓质 NaCl / 尿素梯度。

### 血流量的两端

- 过快：溶质被“洗出”，梯度下降；
- 明显过低：供氧不足，小管主动转运受损，也会削弱浓缩。

（易混：不是“血流越慢越好”；Study强调正常较低、较慢有利，但过低会造成缺氧损伤。）

## KP13｜尿素再循环：A2入管，A1/A3出管，UT-B帮直小血管交换

> **讲义定位 →** 生理 Lecture PDF P285–287。  
> **主提示**：3段通透性｜UT-A2｜UT-A1/A3｜UT-B｜循环路线｜作用｜vs 生化尿素循环。

```text
内髓间质尿素高
→ 经降支细段UT-A2中等通透进入小管液
→ 升支、远曲、皮质/外髓集合管对尿素低通透
→ 水被回收，管液尿素逐渐浓缩
→ 到内髓集合管
→ ADH促进UT-A1 / UT-A3高通透
→ 尿素回到内髓间质
→ 再经UT-A2进入降支细段
```

直小血管 UT-B 参与尿素逆流交换。

作用：

- 让尿素在内髓聚集；
- 与 NaCl共同建立内髓高渗；
- 增强水回收和浓缩能力。

（易混：这是**肾脏的尿素再循环**；生化“尿素循环”是肝脏鸟氨酸循环，任务是氨解毒。）

```text
集合管水通透性↓
→ 低渗小管液不能被浓缩
→ 大量低渗尿
```

# 6｜滤过液沿小管的渗透压电影

<!-- kianos:kp id="urinary-b04-kp15" -->

## KP15｜降支细段：出水、不出NaCl，管液一路变浓

> **讲义定位 →** 生理 Lecture PDF P286–287。  
> **主提示**：水/NaCl/尿素3通透轴｜AQP1｜管液渗透压/折返峰｜UT-A2通透程度/逻辑

```text
近端等渗小管液进入降支细段
→ 对水高通透（AQP1）
→ 对NaCl相对不通透
→ 髓质高渗把水拉出
→ UT-A2允许尿素中度进入管腔
→ 小管液渗透压逐渐↑
→ 髓袢折返处最高
```

Study强调 UT-A2“中等通透”有利于浓缩；若尿素过度进入管腔，会减小水外流的渗透差，也会削弱后续升支 NaCl被动外流。

---

<!-- kianos:kp id="urinary-b04-kp16" -->

## KP16｜升支细段→粗段→远曲：不出水，只出NaCl，管液一路变稀

> **讲义定位 →** 生理 Lecture PDF P286–288。  
> **主提示**：升细/升粗/远曲｜转运体与主动/被动｜共同水通透性｜稀释强度｜进入集合管状态。

### 升支细段

```text
对水不通透
+ 管液NaCl浓度高
→ NaCl顺浓度被动进入内髓间质
→ 开始稀释
```

### 升支粗段

```text
对水不通透
+ NKCC2主动重吸收NaCl
→ 外髓间质高渗↑
→ 管液显著稀释
```

它是逆流倍增最重要的起始动力。持续肾小球滤过则不断补入并推动小管液沿髓袢至集合管流动，使分段水盐分离过程反复进行，促进皮质向肾乳头的纵向渗透梯度建立；“持续流动”的作用不能在列完各段转运后漏掉（原题浓缩过程第8题）。

### 远曲小管

```text
对水不通透
+ NCC继续回收NaCl
→ 管液继续稀释
```

> 进入集合管的小管液按本节 Study 一定是低渗的；终尿最终是否仍低渗，由集合管和 ADH决定。

<!-- kianos:kp id="urinary-b04-kp17" -->

## KP17｜集合管：终尿的最终调节阀

> **讲义定位 →** 生理 Lecture PDF P287。  
> **主提示**：进入时状态｜ENaC｜ADH高/低两链｜皮质外髓尿素｜内髓尿素｜终尿3种可能。

集合管同时处理：

- ENaC介导 Na⁺回收；
- ADH调节 AQP2水通透性；
- 内髓部在 ADH作用下增加尿素通透性。

### ADH低

```text
AQP2少
→ 水通透性低
→ 低渗小管液保持稀
→ 大量低渗尿
```

### ADH高

```text
AQP2多
→ 集合管沿髓质高渗环境回收水
→ 管液逐步浓缩
→ 内髓尿素再循环增强
→ 少量高渗尿
```

因此集合管是调节终尿浓缩和稀释的关键部位，终尿可呈低渗、等渗或高渗。

<!-- kianos:kp id="urinary-b04-kp18" -->

## KP18｜浓缩功能下降：先定位三层故障

> **讲义定位 →** 生理 Lecture PDF P288。  
> **主提示**：梯度形成4类｜梯度维持2端｜水通透性2断点｜每类例子｜夜尿/低比重接口。

### A. 髓质高渗形成失败

- 袢利尿剂抑制 NKCC2；
- 营养不良 / 蛋白摄入少 → 尿素生成少；
- 髓质纤维化、萎缩等破坏髓袢；
- 小儿髓袢较短 → 逆流倍增效率低。

### B. 高渗维持失败

- 直小血管血流过快 → 溶质洗出；
- 肾血流明显过低 → 缺氧，小管转运障碍。

### C. 集合管水通透性失败

- 中枢性尿崩：ADH合成 / 释放不足；
- 肾性尿崩：V2 / AQP2效应不足。

共同结果：

```text
浓缩能力↓
→ 尿量↑
→ 尿渗透压 / 尿比重↓
→ 夜尿、多尿接口
```

完整慢性肾盂肾炎、CKD和尿崩症诊疗后置相应 Block。

<!-- kianos:kp id="urinary-b04-kp19" -->

## KP19｜水利尿 vs 渗透性利尿：末端通水受限，或管腔溶质增多

> **讲义回看 →** P283、P277；Recall K3。  
> **主提示**：第一断点｜管腔溶质｜ADH｜尿渗方向｜典型例子｜补液/内分泌模型边界。

| 轴 | 水利尿 | 渗透性利尿 |
|---|---|---|
| 第一断点 | ADH↓ / 集合管水通透性↓ | 小管液中不易回收溶质↑ |
| 水重吸收 | 集合管末端明显减少 | 多段因渗透压而减少 |
| 尿渗透压 | 明显低 | 由溶质负荷决定，不等于单纯低渗 |
| 典型例子 | 大量饮清水、尿崩接口 | 高血糖尿糖、甘露醇、SGLT2抑制 |

识别算法：

```text
多尿
→ 先问尿是否很稀
→ 再问管腔是否有大量溶质
→ 再定位ADH / AQP2、髓质梯度或近端重吸收
```

（边界：完整糖尿病、HHS、DI、SIADH诊疗不在本 Block展开。）
