# Block 3｜分段小管转运与利尿剂
## 学习阅读版 v1｜最终执行版

> **中心问题**：原尿沿近端小管、髓袢、远曲小管和集合管前进时，每一段到底拿回什么、分泌什么；利尿剂切断哪个转运环节后，为什么会改变尿量、Na⁺、K⁺和酸碱？

# 0｜为什么必须先建立“分段处理器”

肾小球做的是批量滤过；真正决定终尿成分的，是滤过液沿小管行进时发生的分段处理：

```text
肾小球滤出原尿
→ 近端小管：大批量、等渗、低选择成本地回收
→ 髓袢：把水和NaCl处理拆开，为髓质梯度做准备
→ 远曲小管：继续稀释并精细调NaCl
→ 集合管：按激素状态最后决定Na⁺、K⁺、H⁺与水
→ 终尿
```

药物并不是凭空“把尿催出来”。每一类利尿剂都在某一段切断一个真实转运环节：

```text
转运被阻断
→ 管腔内溶质留下
→ 水重吸收减少 / 下游流量改变
→ Na⁺、K⁺、H⁺与浓缩能力出现连锁变化
```

本 Block 的目标不是背一张药表，而是做到：

> **看到转运体，就能定位小管段；看到药物，就能反推被切断的转运；看到电解质方向，就能回到该段的生理。**

## 一条完整电影

```text
滤过液进入近端小管
→ Na⁺-K⁺泵建立细胞内低Na⁺
→ 各类顶端共转运 / 交换把Na⁺及营养物带入细胞
→ 溶质离开管腔后水跟随
→ 近端完成大批量等渗回收
→ 髓袢和远曲把NaCl与水的处理拆开
→ 集合管以ENaC、ROMK、H⁺泵完成末端精调
→ 利尿剂在不同节点留下Na⁺或其他溶质
→ 下游流量、电位和激素作用随之改变
→ 形成特定的尿量、电解质和酸碱指纹
```

# 3｜小管方向与球管平衡

<!-- kianos:kp id="urinary-b03-kp01" -->

## KP01｜四个方向 + 两张膜：先把箭头画对

> **讲义定位 →** 生理 Lecture PDF P275。  
> **主提示**：4方向｜顶端 vs 基底侧｜研究重吸收/分泌时看哪张膜｜原尿180 L/d→水回收率？

### 1｜四个方向

```text
滤过
血浆 → 肾小囊 / 小管液

重吸收
小管液 → 小管上皮 → 组织间液 → 管周毛细血管

分泌
管周毛细血管 / 小管上皮 → 小管液

排泄
最终随终尿离开机体
```

总关系继续沿用 K1：

```text
排泄量
= 滤过量 - 重吸收量 + 分泌量
```

### 2｜两张膜

| 膜 | 朝向 | 当前意义 |
|---|---|---|
| 顶端膜 / 管腔膜 | 小管液 | 决定物质进出小管腔，是分析重吸收与分泌的关键门 |
| 基底侧膜 | 组织间液 / 毛细血管侧 | Na⁺-K⁺泵等维持细胞内梯度，把物质送回组织液 |

Study 的组织关系是：小管上皮细胞属于实质；细胞外的支撑区域是间质，里面的液体称组织间液。

### 3｜为什么终尿远少于原尿

按本节 Study：

- 双肾原尿约 **180 L/d**；
- 小管对水的重吸收率约 **99%**；
- 终尿因此只保留原尿中的少部分水和需要排出的溶质。

（易混：浓缩与稀释描述的是**小管液 / 终尿相对于血浆的渗透状态**，不是把肾组织本身“浓缩”。）

## KP02｜球管平衡：滤得多，近端就按比例多吸

> **讲义定位 →** 生理 Lecture PDF P276。  
> **主提示**：67%｜维持2项｜机制2变量｜GFR↑完整链｜vs 管球反馈3轴｜何时被打破？

### 1｜定义与目标

近端小管对 Na⁺和水的重吸收，通常维持在 GFR 的 **65%–70%，Study常取67%**：

```text
GFR↑ → 近端重吸收Na水↑
GFR↓ → 近端重吸收Na水↓
```

它主要维持：

- 尿量相对稳定；
- 尿 Na⁺排出相对稳定。

### 2｜为什么 GFR↑会促进近端重吸收

```text
GFR↑
→ 出球后管周毛细血管中的蛋白相对浓缩
→ 管周毛细血管血浆胶体渗透压↑
同时管周毛细血管静水压↓
→ 组织液更容易回到管周毛细血管
→ 近端小管Na⁺和水重吸收↑
```

### 3｜球管平衡 vs 管球反馈

| 比较轴 | 球管平衡 | 管球反馈 |
|---|---|---|
| 读取位置 | 近端小管—管周毛细血管环境 | 远端致密斑 NaCl |
| 调整对象 | 近端 Na⁺和水重吸收 | 入/出球张力、肾素与 GFR |
| 核心目的 | 稳定尿量与尿Na⁺ | 稳定 RBF / GFR |

（易混：两者名称相反，调节位置和目标也不同。）

### 4｜何时可被打破

渗透性利尿时，即使 GFR 可不变：

```text
管腔溶质↑
→ 水重吸收↓
→ 近端重吸收比例下降
→ 尿量和尿Na⁺排出↑
```

# 4｜近端小管：大批量等渗回收

<!-- kianos:kp id="urinary-b03-kp03" -->

## KP03｜近端小管的底层发动机：钠泵把所有转运串起来

> **讲义定位 →** 生理 Lecture PDF P276–277。  
> **主提示**：动力根源1｜顶端3类入口｜基底侧出口｜水2途径｜为什么等渗？

### 1｜动力根源

基底侧 Na⁺-K⁺泵持续把 Na⁺泵出细胞，维持细胞内低 Na⁺。这为顶端膜多类继发性主动转运提供势能：

- Na⁺—葡萄糖 / 氨基酸同向转运；
- Na⁺—H⁺交换；
- 其他 Na⁺耦联转运。

### 2｜水为什么跟着回来

Na⁺、Cl⁻、HCO₃⁻、葡萄糖、氨基酸等被回收后：

```text
小管液溶质减少
→ 形成渗透压差
→ 水经AQP1跨细胞
  + 经细胞旁通路
→ 同步重吸收
```

因此近端小管重吸收的特点是：

> **大批量、近似等渗、水盐同步。**

（边界：等渗重吸收不表示“所有溶质按完全相同比例回收”；它说明水和总有效溶质总体同步离开小管液。）

## KP04｜近端前半 vs 后半：跨细胞先走，Cl⁻再拉着Na⁺走细胞旁

> **讲义定位 →** 生理 Lecture PDF P277。  
> **主提示**：前/后比例｜主途径各1｜Cl⁻为什么滞后｜后半2个被动梯度｜AQP1。

按本节 Study，在近端小管内部：

- 前半段承担约 **2/3** 的 Na⁺和水重吸收，以**跨细胞途径**为主；
- 后半段承担约 **1/3**，以**细胞旁途径**为主。

### 后半段为何转向细胞旁

```text
前半段其他溶质优先被重吸收
→ Cl⁻相对滞留、管腔Cl⁻浓度升高
→ Cl⁻顺浓度差经细胞旁被动回收
→ 形成电位差
→ Na⁺再顺电位差经细胞旁回收
→ 水跟随
```

（易混：Cl⁻主要依靠**浓度差**；Na⁺在后半段主要依靠 Cl⁻形成的**电位差**。）

## KP05｜葡萄糖 / 氨基酸：近端正常时接近100%回收

> **讲义定位 →** 生理 Lecture PDF P277。  
> **主提示**：重吸收率｜顶端2个SGLT分工｜基底侧GLUT｜转运性质｜清除率指纹。

按本节 Study：

- 葡萄糖、氨基酸正常情况下约 **100%** 在近端小管回收；
- 顶端膜通过 Na⁺—葡萄糖 / 氨基酸同向的**继发性主动转运**进入细胞；
- 葡萄糖中，SGLT2承担约90%，SGLT1承担剩余部分；
- 细胞内葡萄糖再经基底侧 GLUT2 易化扩散进入组织液。

正常状态：

```text
滤过葡萄糖
→ 近端全部回收
→ 终尿几乎无葡萄糖
→ 葡萄糖清除率≈0
```

（易混：SGLT位于顶端膜并依赖 Na⁺梯度；GLUT2位于基底侧，走易化扩散。）

## KP06｜肾糖阈与Tm：尿糖是“滤得太多”还是“吸得太差”

> **讲义定位 →** 生理 Lecture PDF P277。  
> **主提示**：阈值定义｜约多少｜反映哪2过程｜Tm边界｜尿糖2路径。

### 1｜肾糖阈

肾糖阈是：

> **尿中刚开始出现葡萄糖时的最低血糖浓度。**

按本节 Study 约为 **180 mg/dL**。它反映：

```text
肾小球滤过负荷
vs
近端小管最大重吸收能力
```

### 2｜两条尿糖路径

#### A. 滤得太多

```text
糖尿病血糖↑
→ 滤过葡萄糖负荷↑
→ 超过近端重吸收上限
→ 尿糖
```

此时近端小管重吸收功能可仍正常，只是达到极限。

#### B. 吸得太差

```text
化疗药等肾毒性
→ 近端小管重吸收障碍
→ 即使血糖 / 滤过量不高
→ 仍可尿糖
```

（易混：尿糖不等于一定高血糖；必须先分“滤过负荷过大”与“近端处理失败”。）

## KP07｜SGLT2 抑制：主动把葡萄糖和Na⁺留在管腔

## KP08｜渗透性利尿：不是先把GFR做大，而是让水留在管腔

> **讲义定位 →** 生理 Lecture PDF P277、P279。  
> **主提示**：机制链｜破坏什么｜尿量/尿Na方向｜例子4｜vs 水利尿。

```text
小管液中不易被回收的溶质↑
→ 管腔渗透压↑
→ 水重吸收↓
→ 尿量↑
→ 尿Na⁺排出可↑
→ 球管平衡被打破
```

本节例子：

- 血糖超过肾糖阈的糖尿病；
- 甘露醇；
- SGLT2 抑制剂；
- Study列举的高渗葡萄糖场景。

（易混：渗透性利尿的首要断点是**管腔溶质**；水利尿的首要断点是 **ADH下降 / 集合管水通透性下降**，完整比较在 K4。）

## KP09｜HCO₃⁻重吸收：不是整颗直接穿膜，而是先变成CO₂

> **讲义定位 →** 生理 Lecture PDF P276–278。  
> **主提示**：约80%｜Na-H交换｜管腔CA链｜CO₂回细胞｜基底侧回血｜为何快于Cl⁻？

近端小管回收约 **80%** 的滤过 HCO₃⁻。Study主链：

```text
Na⁺-H⁺交换把H⁺分泌入管腔
→ H⁺ + HCO₃⁻ → H₂CO₃
→ 顶端碳酸酐酶CA催化
→ CO₂ + H₂O
→ CO₂快速扩散入细胞
→ 细胞内CA再生成H₂CO₃
→ 解离为H⁺ + HCO₃⁻
→ H⁺循环回管腔
→ HCO₃⁻经基底侧回到组织液 / 血液
```

因此：

> **HCO₃⁻是以 CO₂ 形式跨顶端进入细胞；CO₂扩散快，所以其回收先于Cl⁻。**

（易混：这里循环利用的 H⁺主要帮助回收滤过的 HCO₃⁻；“净排酸”还要看可滴定酸和 NH₄⁺等载体。）

## KP10｜H⁺与氨：近端“交换”，集合管“扩散并捕获”

> **讲义定位 →** 生理 Lecture PDF P276–278。  
> **主提示**：泌H⁺2方式/主者｜近端NH4⁺方式｜集合管NH3方式｜每排1个NH4⁺对应什么｜慢性酸中毒怎样变？

### 1｜H⁺分泌

近端小管：

- 主要：Na⁺—H⁺交换；
- 少量：H⁺-ATPase 主动分泌。

### 2｜氨系统

近端小管：

```text
NH₄⁺可替代H⁺
→ 经Na⁺-NH₄⁺交换进入小管液
```

集合管：

```text
膜对NH₃通透、对NH₄⁺相对低
→ NH₃扩散入管腔
→ 与H⁺结合成NH₄⁺
→ 被“捕获”并随尿排出
```

本节 Study 强调：

- 生理情况下约半数分泌 H⁺可由 NH₃缓冲；
- 慢性酸中毒促进谷氨酰胺代谢，使 NH₃ / NH₄⁺生成与排泄增加；
- 每排出一个 NH₄⁺，可对应新增 / 保留一个 HCO₃⁻进入血液的接口。

（边界：肾脏通过氨系统**排酸保碱**；肝脏通过鸟氨酸循环“解毒氨”，两者任务不同。）

# 5｜集合管：末端Na⁺—K⁺—H⁺精调

<!-- kianos:kp id="urinary-b03-kp11" -->

## KP11｜主细胞 vs 闰细胞：一个管Na/K，一个管H/K

> **讲义定位 →** 生理 Lecture PDF P278。  
> **主提示**：2细胞｜主细胞分泌什么｜闰细胞分泌/重吸收什么｜H泵2个｜终尿K主要来源。

| 细胞 | 主要转运方向 | 当前角色 |
|---|---|---|
| 集合管主细胞 | Na⁺重吸收；K⁺分泌 | 终尿K⁺的重要来源；醛固酮 / ENaC作用场 |
| 集合管闰细胞 | H⁺分泌；K⁺重吸收 | 通过H⁺-ATPase与H⁺-K⁺-ATPase参与排酸保钾 |

Study定位：

- K⁺主要在近端小管重吸收；
- K⁺末端可在集合管主细胞分泌；
- H⁺主要分泌部位强调近端小管，集合管闰细胞完成末端酸化。

（易混：不能只背“集合管排钾”；主细胞排K⁺，闰细胞可回收K⁺，两者方向不同。）

---

<!-- kianos:kp id="urinary-b03-kp12" -->

## KP12｜主细胞电路：ENaC吸Na⁺，管腔变负，ROMK排K⁺

> **讲义定位 →** 生理 Lecture PDF P278。  
> **主提示**：基底侧泵｜顶端ENaC｜管腔电位｜K⁺2个驱动力｜Cl⁻/水方向｜为何“保Na就排K”？

```text
基底侧Na⁺-K⁺泵
→ 细胞内Na⁺低、K⁺高

顶端ENaC
→ Na⁺由管腔进入细胞
→ 管腔相对负电

ROMK等K⁺通道
→ K⁺顺浓度差
  + 顺管腔负电位
→ 分泌入小管液
```

同时：

- Cl⁻可顺电位差经细胞旁回收；
- 水可随 NaCl 回收，但最终水通透性还受 ADH / AQP2控制，见 K4。

一句话：

> **只要末端Na⁺经ENaC被吸收，就会同时为K⁺分泌提供电化学驱动力。**

<!-- kianos:kp id="urinary-b03-kp13" -->

## KP13｜K⁺分泌四个控制柄：肾功能、醛固酮、流量、H⁺竞争

> **讲义定位 →** 生理 Lecture PDF P279。  
> **主提示**：4控制柄｜各自方向｜排钾利尿剂为何低K｜保钾2机制｜肾衰为何高K。

### 1｜肾功能

```text
有效肾单位 / 集合管分泌能力↓
→ K⁺排出↓
→ 高钾接口
```

### 2｜醛固酮

```text
ENaC与Na⁺-K⁺泵表达↑
→ Na⁺重吸收↑
→ K⁺分泌↑
```

完整激素调节在 K4。

### 3｜小管液流量

```text
下游流量↑
→ 已分泌K⁺被迅速带走
→ 管腔K⁺保持低
→ 浓度差维持
→ K⁺继续分泌
```

因此多数排钾利尿剂可因下游流量增加而促K⁺丢失。

### 4｜H⁺竞争

H⁺分泌与K⁺分泌存在竞争性关系，见下一 KP。

### 5｜两类保钾利尿剂

- 螺内酯、依普利酮：拮抗醛固酮受体；
- 阿米洛利、氨苯蝶啶：直接抑制 ENaC。

共同结果：Na⁺重吸收↓、K⁺分泌↓，因此有高钾风险。

<!-- kianos:kp id="urinary-b03-kp14" -->

## KP14｜K⁺—H⁺四格：先找“谁是原因”，再判尿液方向

> **讲义定位 →** 生理 Lecture PDF P279。  
> **主提示**：酸/碱为因2格｜高/低K为因2格｜正常尿方向｜反常尿2格｜库存血特殊｜低Mg。

### A. 酸碱是原因

| 原发改变 | 肾端方向 | 血K⁺ | 尿液 |
|---|---|---|---|
| 代谢性酸中毒 | 泌H⁺↑、泌K⁺↓ | 高钾 | 酸性尿 |
| 代谢性碱中毒 | 泌H⁺↓、泌K⁺↑ | 低钾 | 碱性尿 |

### B. K⁺异常是原因

| 原发改变 | 肾端方向 | 酸碱 | 尿液 |
|---|---|---|---|
| 高钾血症 | 泌K⁺↑、泌H⁺↓ | 代谢性酸中毒 | **反常性碱性尿** |
| 低钾血症 | 泌K⁺↓、泌H⁺↑ / 回收K⁺ | 代谢性碱中毒 | **反常性酸性尿** |

> 先确定因果入口，不能看到“高钾+酸中毒”就机械推出尿一定酸。

### 两个 Study 特殊

1. 大量输入库存血：红细胞破坏释放 K⁺，同时枸橼酸钠在肝脏转为 NaHCO₃，可形成**高钾 + 碱中毒**；
2. 低钾补充后仍不改善：考虑低 Mg²⁺，Study用“Mg²⁺不能封住ROMK，K⁺继续外流”的模型解释。

完整高 / 低钾临床处置在 K5。

## KP16｜甘露醇：靠“留在管腔的溶质”利尿

> **讲义回看 →** 生理 Lecture PDF P293。  
> **主提示**：甘露醇：作用部位｜滤过/重吸收性质｜渗透性利尿链｜与糖尿/SGLT2同轴｜电解质接口

## KP18｜袢 vs 噻嗪：NKCC2切在梯度发动机，NCC切在远曲精调

## KP19｜保钾与V2拮抗：一个减少Na⁺入口，一个直接减少水入口

> **讲义回看 →** 生理 Lecture PDF P295–296。  
> **主提示**：MR拮抗2药｜ENaC抑制2药｜共同K风险｜Liddle选谁｜V2拮抗对Na/K/水的第一作用。

### A. 醛固酮受体拮抗剂

- 螺内酯；
- 依普利酮。

```text
阻断醛固酮核受体作用
→ ENaC / Na⁺-K⁺泵相关表达↓
→ Na⁺重吸收↓
→ K⁺分泌↓
→ 保钾
```

### B. ENaC 抑制剂

- 阿米洛利；
- 氨苯蝶啶。

```text
直接抑制ENaC
→ 管腔负电位减弱
→ K⁺分泌驱动力↓
→ 保钾
```

原醛可用醛固酮受体拮抗剂；Liddle 综合征中醛固酮已低，核心靶点是异常 ENaC，因此选阿米洛利 / 氨苯蝶啶接口。

### C. V2拮抗剂

托伐普坦阻断 V2—AQP2 水回收轴，首要结果是**减少水重吸收**，不是通过 ENaC 直接改变 Na⁺ / K⁺交换。完整机制和低钠接口在 K4。
