# Block 7｜AKI、CKD与透析
## 学习阅读版 v1｜最终执行版

> **中心问题**：肾功能突然下降和长期下降如何区分；AKI 的第一故障究竟在灌注、肾实质还是尿路出口；CKD 为什么会同时出现贫血、骨病、水电酸碱紊乱和心血管并发症；什么时候必须从保守处理升级到肾脏替代治疗？

>

# 0｜这个 Block 到底解决什么

K1–K6 已经把肾脏正常运行拆成：

```text
灌注
→ 滤过
→ 分段重吸收 / 分泌
→ 浓缩 / 稀释
→ 水、电解质、酸碱
→ 尿液证据与总 / 分肾功能
```

K7 反过来问：

```text
如果肾功能下降
→ 是血没到肾？
→ 是肾小管 / 间质等肾实质坏了？
→ 还是尿排不出去、压力顶回来？

如果是急性的
→ 当前处于起始、维持还是恢复？
→ 哪些电解质 / 容量问题会先致命？

如果是慢性的
→ 哪些毒素和内分泌功能长期累积失衡？
→ 为什么出现贫血、出血、骨病、心衰和神经症状？

如果保守处理已经不够
→ 哪些临床问题要求升级肾脏替代治疗？
```

因此本 Block 的核心不是背两张“肾衰表”，而是建立：

> **时间轴 × 第一故障层 × 全身后果 × 升级治疗门槛。**

# 1A｜同一模型上的自然节点〔完整 Prompt〕

## 用时间与第一故障层解释功能下降

肾功能突然恶化先按AKI判断，肾结构/功能异常持续≥3个月则进入CKD判断；CKD可以尚无GFR降低，也可叠加AKI。病史、肌酐趋势和长期并发症与肾大小共同支持时间判断，小肾或正常大小均不能单轴定案。AKI/CKD是时间与损伤背景，不是先后相接的必经阶段。
〈AKI vs CKD：先判时间，再找第一故障层〔急慢2证据轴｜AKI三层｜CKD长期4输出｜肾小不可机械化｜特殊不缩小×4。〕〉
〈急慢性鉴别：小肾支持CKD，但4种慢病可以不小〔检查2类｜小肾方向｜4个不缩小｜长期并发症3｜不能单轴判定。〕〉

灌注不足降低滤过驱动力；肾实质病变可损伤小管、间质、肾小球或血管；足以影响总功能的梗阻抬高上游压力。三路可汇到GFR下降，但保Na/浓缩能力不一定同变。持续低灌注可进展为缺血性小管损伤，不能把所有肾性AKI都当ATN。
〈AKI三分：血没来、肾坏了、尿出不去〔3型｜第一变量｜代表病因｜压力落点｜可逆方向｜肾后串K12。〕〉

肾前性且小管尚能工作时，保Na/保水使尿更浓；ATN的小管损伤使回收与浓缩变差，可出现稀尿、尿Na增加和颗粒管型。尿指标受药物、CKD和病因干扰，八项典型对照须带条件使用。
〈肾前 vs 缺血性 ATN：会不会“拼命保Na和浓缩水”〔8指标｜浓缩2｜Na2｜Cr/BUN2｜FENa/RFI｜沉渣｜本质1句。〕〉

## 排泄不足与小管恢复分别决定当前危险

GFR下降减少排出负荷；小管损伤还可同时改变重吸收、分泌和浓缩。这些并行入口造成水、电解质、酸和代谢产物失衡，并非GFR下降后才必然发生小管损伤。严重排泄不足可出现高K、酸中毒、容量超负荷，少尿型更需警惕；讲义的“三高三低两中毒”是典型组合，不能要求每例全部具备。
〈起始→进展/维持：少尿期“3高3低2中毒”〔起始1｜少尿/无尿2阈｜3高3低2中毒｜主要死因2｜纠酸特殊×1。〕〉

若小管损伤的病因解除并有恢复能力，滤过可先改善而小管回收/浓缩仍滞后，出现多尿与水盐丢失；低K、低容量和感染风险须继续观察。肾前性纠正灌注或解除梗阻有自己的恢复路径，未必经过ATN的三期；多尿也不证明滤过已正常，恢复不保证完全。
〈多尿 / 恢复期：GFR先回来，小管后回来〔滤过vs小管恢复先后｜多尿机制｜危险2项｜少尿期对照〕〉

## 观察确认功能变化，寻找可逆病因

Scr的绝对/相对变化与尿量时窗确认AKI，三条件任一成立即可；Cr非稳态时不能把常规估算当瞬时真实GFR。稳定条件下菊粉、Ccr和核素分别提供测量接口，左右结果须按方法加总；只有怀疑肾实质病因且现有评估不能明确时，才考虑活检。测量、病因评估和救急处置可以并行，不能等走完检查目录才处理危险。
〈AKI三条诊断标准：48h、7d、6h〔Scr绝对/相对｜尿量｜3阈值/时窗｜初查vs最准确。〕〉
〈GFR三种测法 + 肾图加总 + 肾性病因不明才活检〔GFR定义｜3测法｜最准/常用｜肾图注意1｜活检条件2。〕〉

## 慢性肾单位损失，清除和内分泌后果并行

CKD进展使排泄能力不足，代谢物、水盐和酸可蓄积；EPO不足使红系生成减少，活性VitD不足则接入钙磷调节。毒素影响消化、神经和血小板功能；容量/血压、贫血和代谢因素从不同入口增加心血管负担。贫血不是先发生出血的必经原因，骨病也不是神经症状后的下一阶段。
〈CKD毒素三层：小分子、中分子、大分子〔小分子7｜中分子1｜大分子5｜各代表后果｜与K6小蛋白易混1。〕〉
〈CKD系统表现：消化最先，心衰最致命〔最先1｜主要死因1｜循环4线｜神经4线｜“清除失败+内分泌失败”。〕〉
〈肾性贫血与出血：EPO少；血小板数量可正常但功能差〔贫血vs出血2机制｜治疗4类｜Hb阈值3人群｜贫血4级｜血液接口〕〉

## CKD-MBD：磷排出与维生素D活化分叉，再接不同骨病

肾排磷能力下降可造成磷潴留；肾VitD活化减少使钙三醇不足、肠钙吸收下降。这些入口与低钙等信号共同推动继发PTH升高；高磷不能写成钙三醇减少的直接结果，早期也不要求血磷已经升高。持续PTH过高促进骨重塑/吸收，可形成高转化骨病。
〈高转化性骨病：钙三醇↓ → 低钙 → PTH长期升高〔机制链｜课程最常见｜PTH效应｜表现4｜原发vs继发〕〉

另一条件分支是长期钙/钙三醇负荷或高钙透析液过度抑制PTH，使骨更新低下，形成骨再生不良；钙三醇不足或铝毒性等可损害矿化，形成骨软化。低更新与矿化障碍不是同一变量，也不是高PTH骨病的必经下一期，混合病变仍归原Source。
〈低转化性骨病：骨再生不良 vs 骨软化〔低转化骨病2型｜触发｜PTH/矿化｜骨软化2部位〕〉

## 评估慢性程度，并通过干预反馈减负

确立CKD后按GFR分G期，G1/G2仍须肾损伤证据；分期读取严重程度，不等同Cr旧四档或自动透析开关。减少持续高血压/肾小球内压和蛋白尿可保护残余肾单位：ACEI/ARB减少RAAS支持、降低出球阻力和肾小球内压，同时须监测容量、BP、K与肾功能变化。低灌注/高钾等会改变处置，不能单用绝对Scr停药。
〈CKD分期：GFR 是正式主轴；血Cr四档是旧阶段辅助口径〔G分期｜G3细分｜GFR阈值｜Cr四档｜透析边界〕〉
〈ACEI / ARB：先学为什么护肾，再把旧禁忌数字降为 Source Precision〔护肾2作用/出球轴｜启动监测4组｜可逆因素/减停门槛｜旧Scr与BP数值边界〕〉

水Na、磷、营养和肾毒药物从输入端改变排泄负担，补液须看当前容量、丢失和输出；课程公式与药物名单保留原来源条件。监测结果反馈调整措施，而不是所有CKD病人沿目录依次接受同一方案。
〈水、Na、P、蛋白与药物：输入端也要减负〔水2公式｜P结合剂2｜限蛋白/脂/肾毒药｜保热量。〕〉

## 维持不了内环境时升级KRT，并观察各自并发症

AKI或CKD若出现难治高K、严重酸中毒、容量超负荷或尿毒症器官损害等，结合状态进入KRT评估，不能只等Cr/BUN达到某个数。IHD、CRRT、PD按稳定性、清除速度、通路和资源选择，严重AKI本身不构成禁PD的绝对条件。
〈KRT指征：先看难治的内环境 / 容量 / 尿毒症器官损害，再看Source数字〔难治内环境3类｜尿毒症器官｜综合评估｜Source数字边界〕〉
〈三类KRT modality：IHD、CRRT、PD；按患者与场景选，不做“严重AKI禁PD”绝对规则〔KRT3法｜选择5轴｜效率/稳定性｜AKI-PD边界｜CRRT历史名词〕〉

KRT缓解排泄负担，也产生不同风险入口：内瘘低阻力可增加心输出负担，快速清除尿素可产生脑血渗透差，长期β₂-MG蓄积可接淀粉样变，钙/PTH管理可接低转化骨病；这些并发症相互独立，不是一次透析必经的顺序。
〈透析并发症：先记5个有独立机制的，再把长表放MI-D〔核心5｜各自机制｜初次透析特殊1｜β2-MG｜长表MI-D。〕〉

病例决策把时间背景、第一故障层、当前致命变量和可逆原因合起来，决定是否能保守维持或需要KRT；救急与解除病因并行，并随输出/功能变化重新评估。
〈K7最终病例算法：时间→位置→致命变量→可逆原因→KRT〔5步｜急慢｜肾前/性/后｜高K/水/酸｜可逆病因｜KRT临床门槛〕〉

**Residual 边界**：先保留模型与自然节点的完整 Prompt，再独立判断精确恢复的困难；分类、比较或名单不能仅因形式被移出 Prompt。已审 Prepared Memory / Precision 即使与 Prompt 重叠，仍保留原有答案、条件、身份与历史，不因本次模型校准撤销准入。

## KP01｜AKI vs CKD：先判时间，再找第一故障层

> **讲义定位 →** 内科 Lecture P151–153。  
> **主提示**：急慢2证据轴｜AKI三层｜CKD长期4输出｜肾小不可机械化｜特殊不缩小×4。

面对 Cr / GFR异常，第一步不是直接背病名，而是先分：

```text
突然下降
→ AKI
→ 再分肾前 / 肾性 / 肾后

肾结构或功能异常持续≥3个月并有健康影响
→ CKD（GFR可以仍正常；不等同已进入慢性肾衰）
→ 看长期毒素与内分泌失败造成的系统表现
```

CKD进一步进展可损害四类输出：代谢废物排泄、容量/血压调节、电解质/酸碱稳态、EPO与活性维生素D等内分泌功能。

慢性支持证据中，Study强调：

- B超、肾图等可辅助急慢性鉴别；
- **双肾明显缩小**支持 CKD；
- 但不能机械写成“CKD一定小肾”。

（特殊×4：多囊肾、双肾多发囊肿、糖尿病肾病、肾淀粉样变性，慢性时双肾常不缩小。）

## KP02｜AKI三分：血没来、肾坏了、尿出不去

> **讲义定位 →** 内科 Lecture P151；Recall K1/K2。  
> **主提示**：3型｜第一变量｜代表病因｜压力落点｜可逆方向｜肾后串K12。

### A｜肾前性｜最常见

```text
大失血 / 液体丢失过多 / 肝硬化 / 心衰 / 机械通气等
→ 有效循环血量或肾灌注↓
→ 肾小球毛细血管压↓
→ GFR↓
```

关键：**第一故障在肾脏之前的灌注。**早期肾实质仍有保Na、浓缩尿的能力。

### B｜肾性 / 肾实质性

Study代表：

- 急性肾小管坏死 ATN；
- 间质性肾炎等。

机制入口：

- 肾缺血；
- 肾毒物：氨基糖苷、鱼胆、蘑菇、Hb、肌红蛋白、轻链蛋白等；
- 原尿外漏；
- 肾小管阻塞。

关键：**肾组织本身已经损伤**。上述缺血/肾毒物、原尿外漏和小管阻塞主要描述ATN入口，不是所有肾性AKI共有的机制；肾小球、血管和间质病变也可造成肾性AKI，保Na/浓缩能力随受累部位而异。

### C｜肾后性

```text
结石 / BPH / 盆腔肿瘤 / 神经源性膀胱尿潴留等
→ 尿路梗阻
→ 肾小囊囊内压↑
→ 有效滤过压↓
→ GFR↓
```

明显总肾功能下降常涉及双侧梗阻、孤立功能肾受阻或对侧肾功能已受损；单侧结石可伤患肾，但另一肾正常时血肌酐未必升高，不能把任何单侧梗阻都直接等同整体肾衰。

//串联：这里只建立“压力顶回滤过器”的机制。结石、BPH、肾积水、尿潴留和解除梗阻优先级在 K12 完整学习。

## KP03｜肾前 vs 缺血性 ATN：会不会“拼命保Na和浓缩水”

> **讲义定位 →** 内科 Lecture P151 原表。  
> **主提示**：8指标｜浓缩2｜Na2｜Cr/BUN2｜FENa/RFI｜沉渣｜本质1句。

肾前性 AKI 的肾小管仍在工作，因此会尽量保水、保Na；缺血性 ATN 的小管已损伤，保存能力下降。

| 指标 | 肾前性 AKI | 缺血性 ATN |
|---|---:|---:|
| 尿比重 | >1.018 | <1.012 |
| 尿渗透压 | >500 | <250 mOsm/kg·H₂O |
| 尿Na⁺ | <10 mmol/L | >20 mmol/L |
| 尿Cr / 血Cr | >40 | <20 |
| BUN / Cr（两者均以mg/dL表示） | >20 | 讲义<10–15；不是混用SI单位的原始数值比 |
| FENa | <1% | >1% |
| 肾衰指数 RFI | <1 | >1 |
| 尿沉渣 | 透明管型 | 棕色颗粒管型 |

本表是典型未受干扰情境。利尿剂、CKD、脓毒症、色素性肾损伤等可使FENa/尿钠失去简单区分力；FENa低不保证只是肾前，高不保证ATN，须结合病史、容量评估及尿沉渣。

一条机制：

```text
肾前性
肾实质尚可
→ 小管保Na、保水、浓缩尿

ATN
小管上皮损伤
→ Na和水重吸收差
→ 尿稀、尿Na高、颗粒管型
```

（易混：透明管型并不等于“肾脏有实质损伤”；Study提醒正常人也可出现透明管型。）

# 4｜AKI时间轴：同一种疾病，危险会换挡

<!-- kianos:kp id="urinary-b07-kp04" -->

## KP04｜起始→进展/维持：少尿期“3高3低2中毒”

> **讲义定位 →** 内科 Lecture P151；Recall K5。  
> **主提示**：起始1｜少尿/无尿2阈｜3高3低2中毒｜主要死因2｜纠酸特殊×1。

### 起始期

- 原Study：尚无明显肾实质损伤。
- Current边界：这是讲义阶段的概括；缺血/毒性小管损伤在起始阶段即可发生，不能据此排除实质损伤，也不把ATN分期推广为所有AKI的必经过程。

### 少尿 / 进展 / 维持期

尿量：

- <400 mL/d：少尿；
- <100 mL/d：无尿；
- 部分 AKI 可 ≥400 mL/d，为非少尿型，Study认为一般病情较轻。

核心紊乱：

```text
3高：K+ / Mg2+ / P ↑
3低：Ca2+ / Na+ / Cl- ↓
2中毒：水中毒 + 代谢性酸中毒
```

这是讲义对少尿期常见组合的记忆表，不是AKI诊断必须同时满足的八项：电解质实际方向还受病因、输入、丢失和治疗影响，非少尿型也不能仅凭尿量判定无危险。

机制主轴：

```text
肾排泄失败
→ K/Mg/P/H+/水排出↓
→ 高K、高Mg、高P、酸中毒、水中毒

肾小管1α-羟化酶功能↓
→ 钙三醇↓
→ 低Ca

水潴留造成稀释
→ 低Na、低Cl
```

**主要死因：高钾血症、水中毒。**

（特殊：酸中毒环境中游离 Ca²⁺比例相对较高，低钙时未必马上抽搐；纠正酸中毒后游离 Ca²⁺下降，反而可能出现手足抽搐。只保留 Study 机制，不扩展额外酸碱公式。）

<!-- kianos:kp id="urinary-b07-kp05" -->

## KP05｜多尿 / 恢复期：GFR先回来，小管后回来

> **讲义定位 →** 内科 Lecture P152。  
> **主提示**：滤过vs小管恢复先后｜多尿机制｜危险2项｜少尿期对照

恢复期不是“尿一多就安全”。本段描述可恢复的小管损伤常见过程，不要求所有AKI都先少尿再多尿，也不保证每例完全恢复。

```text
肾皮质滤过功能先恢复
→ 滤过可先改善；GFR未必已正常

但再生中的肾小管上皮仍幼稚
→ 重吸收水、浓缩功能恢复较慢
→ 多尿
```

因此危险从：

```text
少尿期：高K + 水中毒
```

切换成：

```text
多尿期：低K + 感染
```

这就是 AKI 时间轴最需要主动回忆的“危险换挡”。

# 5｜AKI怎么被确认：Scr、尿量和GFR各回答什么

<!-- kianos:kp id="urinary-b07-kp06" -->

## KP06｜AKI三条诊断标准：48h、7d、6h

> **讲义定位 →** 内科 Lecture P152。  
> **主提示**：Scr绝对/相对｜尿量｜3阈值/时窗｜初查vs最准确。

Study给出三条标准：

1. **48 h内** Scr升高 ≥0.3 mg/dL（≥26.5 μmol/L）；
2. **7 d内** Scr较基础值升高 ≥50%；
3. 尿量 <0.5 mL/(kg·h)，持续 ≥6 h。

临床入口与“最准确”要分开：

- Scr / BUN容易获得，实际可先查；
- 讲义称GFR“最准确”，应区别真实滤过能力与由血肌酐估算的eGFR；急性非稳态时常规eGFR公式可能滞后失真，不能替代上述动态Scr/尿量诊断标准。

（易混：不要把“先查得方便”与“理论上更准确”混成一个问题。）

# 7｜CKD-MBD：一个“活性VitD少—PTH高”的长期骨代谢后果

<!-- kianos:kp id="urinary-b07-kp11" -->

## KP11｜高转化性骨病：钙三醇↓ → 低钙 → PTH长期升高

> **讲义定位 →** 内科 Lecture P153；Recall K1肾脏1α-羟化酶。  
> **主提示**：机制链｜课程最常见｜PTH效应｜表现4｜原发vs继发

Study原链为“肾衰→钙三醇↓→低钙→PTH过高”；以下把同一CKD背景下的排磷与VitD活化分为并行入口，不把高磷归因于钙三醇下降：

```text
肾衰
├─ 1α-羟化酶 / 钙三醇生成↓ → 肠钙吸收↓ → 可低钙
└─ 排磷能力↓ → 磷潴留（血磷可随阶段变化）

活性VitD不足、低钙与磷负荷等共同促进继发PTH↑
→ 持续过高PTH促进骨重塑/吸收
→ 高转化性骨病
```

讲义将高转化性列作最常见肾性骨病；实际比例受CKD阶段和治疗影响，不强推所有人群。这里的继发性PTH升高是低钙/高磷/活性维生素D不足等反馈驱动，与甲状旁腺自身自主病变的原发性亢进区别，不类比成“原醛”。持续高PTH促进骨重塑和骨吸收，表现：

- 骨质疏松；
- 易骨折；
- 骨骼囊样缺损；
- 纤维囊性骨炎。

//串联：完整 PTH—VitD—Ca/P 调节轴仍归后续内分泌；K7只掌握 CKD 为什么触发这条轴。

# 8｜急慢性鉴别与CKD分期

## KP13｜急慢性鉴别：小肾支持CKD，但4种慢病可以不小

> **讲义定位 →** 内科 Lecture P153。  
> **主提示**：检查2类｜小肾方向｜4个不缩小｜长期并发症3｜不能单轴判定。

支持 CKD：

- B超、肾图等发现双肾明显缩小；
- 长期贫血、CKD-MBD、长期水电酸碱问题等慢性后果也支持时间较长。

# 9｜保住残余肾单位：RAAS阻断、血压与输入端减负

## KP15｜ACEI / ARB：先学为什么护肾，再把旧禁忌数字降为 Source Precision

> **讲义定位 →** 内科 Lecture P153。  
> **主提示**：护肾2作用/出球轴｜启动监测4组｜可逆因素/减停门槛｜旧Scr与BP数值边界

### 1｜稳定机制 Core

```text
高血压 / 肾小球内压 + 蛋白尿
→ ACEI / ARB 阻断RAAS

→ 肾小球内压下降

```

### 2｜Current 安全边界：看变化和临床状态，不用一个绝对Scr切断

启动或加量后要监测：

- Scr / eGFR 变化；
- K⁺；
- 血压与容量状态；
- 合并 NSAID、利尿剂、脱水、肾动脉狭窄等可逆因素。

KDIGO 2024有两个不同表述，不能把百分比当成同一量：Practice Point 3.6.4用启动/加量后4周内Scr升高>30%作为重新评估继续治疗的条件；图21用eGFR下降≥30%触发查找其他原因。通常在启动/加量后2–4周复查血压、Scr与K⁺，先查低容量、药物、肾动脉狭窄等可逆因素。症状性低血压或治疗后仍无法控制的高钾可考虑减量/停药。**eGFR<30 mL/min/1.73m²本身不是自动停ACEI/ARB的理由。**

### 3｜Study-specific Precision｜考试旧口径

原 Lecture列：

- Scr >265 μmol/L；
- K⁺ >5.5 mmol/L；
- 双肾动脉狭窄；
- 妊娠；
- 低血压。

其中双肾动脉狭窄、妊娠、低血压 / 高钾风险仍是重要临床边界；**`Scr >265` 仅作为本讲义旧考试数字保留，不再作为 Current 通用绝对禁忌。**

### 4｜BP目标也分两层

原 Lecture 的考试数字：

- UACR ≥30 mg/g：<130/80 mmHg；
- UACR <30 mg/g：<140/90 mmHg。

保留到 MI-D / Source Precision。Current KDIGO BP 指南对非透析成人 CKD 的主建议已转为：在标准化诊室测压且能耐受时，目标 SBP <120 mmHg，并强调个体化。B7 第一轮不需要重学完整高血压指南，只需知道**旧两档不是永恒临床真理**。

# 10｜KRT：什么时候不能再只看Cr

## KP17｜KRT指征：先看难治的内环境 / 容量 / 尿毒症器官损害，再看Source数字

> **讲义定位 →** 内科 Lecture P154；Recall K5高K / 酸中毒。  
> **主提示**：难治内环境3类｜尿毒症器官｜综合评估｜Source数字边界

### 1｜第一轮 Current Core

当肾脏已经无法安全维持内环境，尤其出现以下**难以通过保守治疗控制**的情况，要进入 KRT / 透析决策：

- 高钾或其他危及生命的电解质紊乱；
- 严重代谢性酸中毒；
- 容量超负荷 / 肺水肿，利尿和其他措施不能控制；
- 尿毒症心包炎、脑病、癫痫等器官表现；
- 结合症状、体征、生活质量、GFR和实验室异常的综合临床恶化。

> **不能把“Cr 到某个数字”当成单轴自动透析开关。**

### 2｜Study-specific Precision

原 Lecture 的高频考试数字：

```text
K+ >6.5 mmol/L 或严重心律失常
pH <7.2
Cr >442 或 707 μmol/L
BUN >21.4 mmol/L
严重尿毒症：心包炎 / 脑病 / 癫痫
利尿无效的严重肺水肿
```

这些数字用于识别本 Study / 真题口径；其中 Cr/BUN **不能提升为现代普适 KRT 指征**。KDIGO 2024 CKD 强调综合评估，KRT 开始常但并非必然发生在 GFR 5–10 mL/min/1.73m²范围。

## KP18｜三类KRT modality：IHD、CRRT、PD；按患者与场景选，不做“严重AKI禁PD”绝对规则

> **讲义定位 →** 内科 Lecture P154。  
> **主提示**：KRT3法｜选择5轴｜效率/稳定性｜AKI-PD边界｜CRRT历史名词

三类基础 modality：

1. **间歇性血液透析 IHD / IRRT**；
2. **连续肾脏替代治疗 CRRT**；
3. **腹膜透析 PD**。

选择要结合：

- 血流动力学稳定性；
- 需要多快清除溶质 / 脱水；
- 腹腔条件与禁忌；
- 血管通路；
- 当地设备、团队经验和资源。

CRRT 的优势之一是更缓慢、连续的溶质与容量调整，常用于血流动力学不稳者；IHD 清除快、效率高；**急性 PD 也是 AKI 可用的 KRT modality，并非因为“严重”二字就自动排除。**

### Study旧口径边界

原 Lecture 写“严重 AKI 不宜腹膜透析，效率低且易腹膜炎”。这个结论保留为 Source-specific / historical exam note，不作为 Current 一般临床规则。ISPD 有专门的 AKI-PD 指南，KDIGO 也将 PD 列为 AKI 的 RRT modality；具体选择取决于患者和资源。

### CRRT名词 Precision

Study列：

- 连续性静—静脉血液滤过；
- 连续性动—静脉血液滤过。

后者属于历史技术命名，进入 MI-D；第一轮核心是**连续、缓慢、血流动力学更平稳的体外 KRT**。

## KP19｜透析并发症：先记5个有独立机制的，再把长表放MI-D

> **讲义定位 →** 内科 Lecture P154 原正文 + 原表。  
> **主提示**：核心5｜各自机制｜初次透析特殊1｜β2-MG｜长表MI-D。

### 核心5个

1. **高排量心衰**：动静脉内瘘建立低阻力通路；
2. **动脉粥样硬化/心血管风险**：与原有CKD、高血压、炎症、脂代谢及矿物骨异常等共同有关；讲义列透析湍流/内皮损伤，不能把全部风险单归透析本身；
3. **骨再生不良**：透析液钙 / 钙三醇过多 → PTH相对偏低接口；
4. **透析失衡综合征**：血中尿素下降快于脑内，短时渗透梯度可使水进入脑组织、发生脑水肿；多见首次或强烈快速透析，表现恶心、呕吐、头痛等，并非只有初次才会发生；
5. **透析相关性淀粉样变骨病**：β₂-微球蛋白相关。

### //MI-D｜原页并发症表还列

- 低血压；
- 血栓；
- 空气栓塞；
- 痛性肌痉挛；
- 透析器首次使用综合征；
- 发热；
- 心律失常；
- 低血糖；
- 出血与急性溶血；
- 蛋白质—能量营养不良；
- 血小板减少症。

讲义“透析禁忌脂溶性中毒”应改为效能判断：高脂溶性常伴大分布容积而不易清除，但这不是统一的透析禁忌；还须看蛋白结合、分子量、血中比例、毒物及其他透析指征。完整中毒血液净化归后续模块。

## KP20｜K7最终病例算法：时间→位置→致命变量→可逆原因→KRT

> **主提示**：5步｜急慢｜肾前/性/后｜高K/水/酸｜可逆病因｜KRT临床门槛

```text
1. 急性还是慢性？
   Scr变化速度 / 肾大小 / 长期贫血骨病等

2. AKI第一故障在哪里？
   灌注不足 / 肾实质 / 尿路梗阻

3. 当前最危险的不是“Cr高”本身，而是什么？
   难治高K / 容量超负荷 / 严重酸中毒 / 尿毒症器官损害

4. 是否有可逆原因必须先处理？
   低容量、缺血/肾毒物、感染、梗阻等

5. 保守治疗还能安全维持内环境吗？
   若不能 → 结合症状、体征、GFR、实验室与患者状态进入KRT
```

病例中如果只会说“AKI / CKD”，但不能回答**第一故障层和当前致命变量**，就还没有完成 K7。
