# Block 6｜尿液证据与肾功能诊断语言
## 学习阅读版 v1｜最终执行版

> **中心问题**：尿中出现蛋白、红细胞、白细胞或管型时，各自说明哪一层结构出了问题；血肌酐 / BUN和分肾功能检查分别回答“总功能”还是“哪侧肾”；尿三杯怎样把出血定位到尿路空间？
>
> **文件性质**：泌尿系统第六个 canonical Block，也是从正常生理进入疾病分支的共同诊断入口。K7 AKI / CKD、K8 UTI、K9–K11肾小球病、K12–K14泌尿外科都要先调用本 Block。
>
> **Primary Study**：内科 Lecture P143–144《泌尿系统总论》；外科 Lecture 书页 P106“分肾功能 + 尿三杯”。
>
> **Primary Outline**：内科 U060 14题；外科 U026 中“分肾功能”与“尿三杯”2题，共 **16题**。外科“分肾功能”是对同一知识身份的跨科强化，不制造第二个 Primary。
>
> **第一轮流程**：Framework → 内科 / 外科 Lecture连续学习与原图 → Framework Reconstruction → KP Active Recall → Outline低压力扫漏 → TTSX Lecture-attached Questions。
>
> **边界**：本 Block只建立证据—位置—功能语言，不提前展开 AKI / CKD分期、UTI治疗、肾小球病 LM / IF / EM、结石 / 肿瘤 / 外伤完整诊疗。当前 Study 口径如有跨章节不完全一致，原样保留并标明边界，不用模型常识静默改写。

# 0｜尿液是一份“从肾单位到尿道”的系统日志

面对异常尿检，不能先猜疾病名。先问异常证据从哪一层产生：

```text
滤过屏障漏
→ 白蛋白 / 大分子蛋白 / 变形RBC / RBC管型

近端小管回收失败
→ 小分子蛋白、葡萄糖等回收障碍

血中小分子负荷过高
→ 溢出性蛋白尿

肾小管 / 集合管内有细胞与蛋白凝固
→ 管型

尿路下游出血或炎症
→ RBC / WBC可出现，但通常不形成肾内管型

单侧肾功能或上尿路通畅问题
→ 分肾功能影像

出血发生在尿流的哪个时间段
→ 尿三杯定位
```

固定顺序：

> **先判断证据身份 → 再定位结构 → 再判断总肾功能 / 单侧功能 → 最后进入疾病模型。**

```text
   证据 → 位置 → 功能 → 病因分支
   [KP16]
```

## 一条总电影

```text
肾小球滤过
→ 近端小管回收小分子蛋白
→ 远端小管 / 集合管形成管型的空间
→ 终尿进入肾盂、输尿管、膀胱、尿道

任何一层损伤
→ 在尿液中留下不同证据
→ 再结合Cr / BUN和分肾功能
→ 判断是肾小球、小管间质、上尿路还是下尿路
→ 进入K7–K14相应疾病分支
```

# 3｜证据地图与蛋白尿

<!-- kianos:kp id="urinary-b06-kp01" -->

## KP01｜五类证据先定位：漏、吸不回、负荷过大、肾内凝固、尿路出血

> **讲义定位 →** 内科 Lecture P143–144；外科 P106。  
> **主提示**：5证据机制｜各自第一结构｜总功能vs分肾｜先定位后命名。

```text
肾小球屏障漏
→ 肾小球性蛋白尿 / 变形RBC / RBC管型

近端小管重吸收失败
→ 肾小管性蛋白尿

血中小分子蛋白负荷过高
→ 溢出性蛋白尿

远端小管 / 集合管内蛋白+细胞凝固
→ 管型

尿路局部炎症、结石、肿瘤、外伤
→ 血尿 / 脓尿，可无管型
```

同时区分：

- Cr / BUN：总肾功能；
- 肾图、CTU、IVU / IVP：分肾功能与上尿路接口；
- 尿三杯：出血时间—空间定位。

<!-- kianos:kp id="urinary-b06-kp02" -->

## KP02｜蛋白尿定义 + 两类生理性 + 微量蛋白尿

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：定量/定性/外观3｜生理2型及触发｜微量范围｜提示疾病｜一过性边界。

蛋白尿的 Study 定义：

- 尿蛋白定量 > **0.15 g/d**；
- 定性阳性；
- 尿液可见较多、持续泡沫。

### 生理性蛋白尿｜一过性

- 功能性：运动、发热时出现；
- 体位性：直立时出现。

### 微量蛋白尿

- **30–300 mg/d**；
- Study主要提示糖尿病肾病早期。

（易混：普通蛋白尿阈值单位是 g/d；微量蛋白尿单位是 mg/d。）

---

<!-- kianos:kp id="urinary-b06-kp03" -->

## KP03｜肾小球性蛋白尿：选择性只漏白蛋白，非选择性提示屏障更重

> **讲义定位 →** 内科 Lecture P143；Recall K2滤过屏障。  
> **主提示**：2型｜主要蛋白｜大分子3｜谁更重｜机械/电荷接口｜量级边界。

| 类型 | 终尿主要蛋白 | 屏障损伤程度 |
|---|---|---|
| 选择性肾小球性蛋白尿 | 白蛋白为主 | 相对较轻，Study联系电荷屏障接口 |
| 非选择性肾小球性蛋白尿 | 白蛋白 + 免疫球蛋白 + C3等 | 更严重，较大蛋白也可通过 |

统一机制：

```text
滤过屏障选择性下降
→ 原本受大小 / 电荷限制的蛋白进入原尿
→ 超过小管回收能力
→ 尿蛋白增多
```

Study将肾小球性蛋白尿量级概括为常可 >2 g/d接口；完整肾炎 / 肾病综合征分支在K9–K11。

---

<!-- kianos:kp id="urinary-b06-kp04" -->

## KP04｜肾小管性蛋白尿：小蛋白能滤，但近端吸不回来

> **讲义定位 →** 内科 Lecture P143；Recall K3近端。  
> **主提示**：机制｜量级｜小蛋白5｜第一故障层｜vs 肾小球性。

正常情况下，一些小分子蛋白可经过滤过膜，再由近端小管回收。

```text
近端小管重吸收障碍
→ 小分子蛋白回收失败
→ 肾小管性蛋白尿
```

Study列举五类：

- VitA结合蛋白；
- 溶菌酶；
- 核糖核酸酶；
- 轻链蛋白；
- β₂-微球蛋白。

量级：多 <2 g/d。

（易混：这里的第一故障在小管，不是滤过屏障大量漏大蛋白。）

---

<!-- kianos:kp id="urinary-b06-kp05" -->

## KP05｜溢出性蛋白尿：小管正常，但血中小蛋白太多

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：机制链｜肾小管功能｜3疾病—3蛋白｜vs 肾小管性｜清除负荷边界。

```text
血中某种小分子蛋白大量增加
→ 经肾小球滤过负荷↑
→ 超过正常近端小管重吸收上限
→ 溢出性蛋白尿
```

三组对应：

| 场景 | 尿中蛋白 |
|---|---|
| 血管内溶血 | 血红蛋白 |
| 横纹肌溶解 / 挤压综合征 | 肌红蛋白 |
| 多发性骨髓瘤 | Bence-Jones / 凝溶蛋白 / 游离轻链 |

| 比较轴 | 肾小管性 | 溢出性 |
|---|---|---|
| 血中小蛋白负荷 | 通常不必升高 | 明显升高 |
| 小管本身 | 回收障碍 | 初始可正常，只是超载 |

---

<!-- kianos:kp id="urinary-b06-kp06" -->

## KP06｜分泌性、组织性 + 肾衰大分子毒素：三个名单不要串

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：分泌性1｜组织性1｜肾衰毒素5｜与小管小蛋白差哪1项｜T-H来源边界。

### 分泌性蛋白尿

- 尿中 IgA增多。

### 组织性蛋白尿

- 尿中小分子 Tamm-Horsfall（T-H）糖蛋白增多接口。

### 肾衰竭“大分子毒素”｜Study名单

- 核糖核酸酶；
- 溶菌酶；
- β₂-微球蛋白；
- VitA结合蛋白；
- 氨甲酰化蛋白。

（易混：与肾小管性蛋白尿五种小蛋白相比，肾衰毒素名单**没有轻链蛋白，增加氨甲酰化蛋白**。二者参考分类不同，不能因重叠就视为同一知识。）

# 4｜血尿：先确认来源，再看管型

<!-- kianos:kp id="urinary-b06-kp07" -->

## KP07｜肉眼血尿、镜下血尿与脓尿：三组阈值

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：肉眼1mL/L+外观｜镜下RBC两阈｜脓尿WBC两阈｜常见病因4｜单位别混。

### 肉眼血尿

- >1 mL血 / 1 L尿；
- 典型洗肉水样。

### 镜下血尿

- 尿沉渣 RBC >3个 / HP；
- 或12 h尿 RBC >5×10⁵。

### 脓尿

- 尿沉渣 WBC >5个 / HP；
- 或12 h尿 WBC >10⁶。

血尿常见于泌尿系统炎症、结石、肿瘤、外伤等。

（易混：血尿和脓尿是尿中细胞数量概念；红 / 白细胞管型还要求这些细胞在肾小管内与蛋白凝固。）

---

<!-- kianos:kp id="urinary-b06-kp08" -->

## KP08｜肾小球源性血尿：变形RBC + 小容积曲线 + RBC管型 / 蛋白

> **讲义定位 →** 内科 Lecture P144；Recall K2滤过膜。  
> **主提示**：首选检查｜RBC形态｜容积分布2点｜伴随证据2｜机制链｜非对称原因。

判断肾小球源性血尿，Study首选：**相差显微镜**。

证据层：

```text
大量变形RBC
+ 尿RBC非对称容积分布曲线
+ 曲线峰值小于静脉RBC容积
+ 可伴RBC管型
+ 可伴大量蛋白尿
```

机制：

```text
RBC通过受损但仍狭窄的滤过屏障
→ 受挤压、形态多样、体积偏小
→ 进入肾小管后可与蛋白凝固成RBC管型
```

（边界：大量蛋白尿增加肾小球来源概率；没有大量蛋白尿不能单独排除。）

---

<!-- kianos:kp id="urinary-b06-kp09" -->

## KP09｜严重屏障破裂的特殊：肾小球源性RBC也可形态正常

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：肾小球源性RBC为何也可正常形态｜特殊病变机制｜判定不能只看什么｜例子边界

Study特殊：急进性 / 新月体性肾炎时，滤过屏障破坏可很严重、裂隙较大：

```text
RBC通过时未被明显挤压
→ 可出现形态正常的肾小球源性血尿
```

因此：

> **“RBC不变形”不能在所有情境下绝对排除肾小球来源。**

本节 Study列举肾小球源性血尿例子时包括肾小球肾炎、肾病综合征、肾盂肾炎、肾结核。该名单按当前 Study 保留；后续 K8–K13会在各疾病模型中重新用感染部位、管型、影像和病理进行定位，本 Block不静默重写名单。

# 5｜WBC与管型：细胞出现 ≠ 管型形成

<!-- kianos:kp id="urinary-b06-kp10" -->

## KP10｜脓尿 vs 白细胞管型：一个说明尿中有WBC，一个提示肾内形成圆柱

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：脓尿定义｜WBC管型形成位置｜疾病2类｜下尿路为何无管型｜“不等于”边界。

```text
脓尿
= 尿中WBC数量增多

白细胞管型
= WBC在远端小管 / 集合管内
  与蛋白等凝固成圆柱
```

Study关联：

- 白细胞管型：肾盂肾炎、肾脏免疫反应；
- 膀胱 / 下尿路炎症可有脓尿，但细胞没有在肾小管内凝固，因此可无白细胞管型。

> 白细胞管型不等于脓尿；脓尿也不保证一定有白细胞管型。

---

<!-- kianos:kp id="urinary-b06-kp11" -->

## KP11｜五类管型地图：红、白、蜡、上皮、脂肪

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：形成位置/材料｜5管型—疾病｜谁预后差｜谁指向小管坏死｜谁指向肾病综合征。

管型由蛋白质、细胞和细胞碎片等在**远端肾小管、集合管**中凝固，形成圆柱形蛋白聚体。

| 管型 | Study提示 |
|---|---|
| 红细胞管型 | 肾小球源性血尿 |
| 白细胞管型 | 肾盂肾炎、肾脏免疫反应 |
| 蜡样管型 | 肾单位长期阻塞、肾衰竭、严重小管病变；预后差 |
| 上皮细胞管型 | 肾小管坏死 |
| 脂肪管型 | 肾小管上皮脂肪变性等；肾病综合征接口 |

这些是证据身份，不等于已完成病因诊断。

<!-- kianos:kp id="urinary-b06-kp12" -->

## KP12｜RBC / WBC 与管型的两条边界

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：血尿≠RBC管型｜脓尿≠WBC管型｜形成所需2条件｜上/下尿路定位价值｜可否反推绝对病因？

### 边界1

```text
尿中有RBC
≠
一定有RBC管型
```

RBC必须进入肾小管，并在蛋白基质中凝固，才形成管型。

### 边界2

```text
尿中有WBC
≠
一定有WBC管型
```

下尿路炎症可直接把WBC加入尿液，但没有经历肾小管内凝固。

定位价值：

- 细胞本身：可来自肾或尿路多个层级；
- 细胞管型：更支持肾实质 / 肾小管内形成。

（边界：管型提供位置证据，但仍需结合蛋白、Cr、培养、影像和病理。）

# 6｜总肾功能、分肾功能与尿三杯

<!-- kianos:kp id="urinary-b06-kp13" -->

## KP13｜总肾功能与尿量：Cr / BUN看总体，尿量是动态输出

> **讲义定位 →** 内科 Lecture P144；Recall K1/K4。  
> **主提示**：总功能2项｜能否分左右｜尿量3类信号｜尿比重/渗透压归哪层｜K7后续。

按本节 Study：

- 血肌酐 Cr；
- 血尿素氮 BUN；

主要反映**总肾功能**，不能告诉你哪一侧肾功能差。

尿量与尿渗透压是动态输出：

- 少尿 / 无尿：灌注、GFR、肾实质或梗阻接口；
- 多尿：渗透性利尿、水利尿或浓缩失败接口；
- 夜尿 / 低比重尿：浓缩功能下降接口。

这些阈值已在K1 / K4进入MI-D；AKI / CKD完整定义与分期在K7。

<!-- kianos:kp id="urinary-b06-kp14" -->

## KP14｜分肾功能三检查：肾图、CTU、IVP / IVU

> **讲义定位 →** 内科 Lecture P144；外科 P106。  
> **主提示**：3检查｜肾图回答4项｜CTU｜IVP/IVU｜MRU能否｜逆行造影能否｜总vs分肾。

Study列三项：

1. **放射性核素肾显像 / 肾图**：可检测肾血流、解剖与功能（含分泌功能），并判断上尿路有无梗阻；
2. **CT尿路造影 CTU**；
3. **静脉肾盂 / 尿路造影 IVP / IVU**。

Study明确：

- MRU不作为当前题纲的分肾功能检查；
- 逆行性肾盂 / 尿路造影不用于评价分肾功能。

（易混：逆行造影可显示解剖通路，但不代表能反映肾脏的滤过 / 分泌功能。）

### 当前来源边界

## KP16｜最终病例算法：证据 → 位置 → 功能 → 病因分支

> **主提示**：8步｜蛋白类型｜RBC形态｜管型｜WBC｜Cr/BUN｜分肾｜尿三杯｜进入哪4分支。

```text
1. 尿中最突出的证据是什么？
   蛋白 / RBC / WBC / 管型 / 尿量

2. 蛋白尿属于哪条机制？
   肾小球漏 / 小管吸不回 / 溢出 / 分泌-组织

3. 血尿是否肾小球源性？
   变形RBC / 容积分布 / RBC管型 / 大量蛋白

4. 是否存在肾内管型？
   红 / 白 / 蜡 / 上皮 / 脂肪

5. Cr / BUN是否异常？
   总肾功能是否下降

6. 是否需要分肾功能与上尿路通畅判断？
   肾图 / CTU / IVP-IVU

7. 出血位于尿流哪个时段？
   初始 / 终末 / 全程

8. 进入哪条疾病分支？
   AKI-CKD / 感染 / 肾小球免疫 / 梗阻-肿瘤-外伤
```

> 当前 Block的出口不是给出最终病名，而是把后续搜索空间压缩到正确结构层。
