# 1A｜同一模型上的自然节点〔完整 Prompt〕


## 共同起点：同一滤过器会同时“漏”和“滤不过”，但疾病时间与损伤入口不同

肾小球屏障受损使红细胞/蛋白进入尿液；毛细血管内增生、坏死或后期硬化减少有效滤过面积，使 GFR 下降、排钠水不足、血压/水肿改变。面对这些共享表现，先并行记录**前驱感染到发病的时间、肾功能下降速度、补体状态与病理/免疫证据**，再区分四条可能路径，不能从“血尿”直接串成急性→急进→IgA→慢性四个必经阶段。

## 感染后免疫反应的经典急性分支：屏障漏与增生性低滤过并行

若前驱链球菌等感染与肾炎发病相隔典型 1–3 周，抗原-抗体反应在肾小球产生炎症，**不是细菌沿尿路进入肾小球**。病理可见毛细血管内内皮与系膜细胞增生，免疫荧光呈颗粒状，电子显微镜经典上皮下驼峰状沉积，肉眼可出现大红肾/蚤咬肾。它解释感染后性肾炎的经典三重命名，但不把所有“急性肾炎综合征”都等同特定病原。
〈前驱感染：为什么要等1–3周〔病原1｜感染部位3｜时间｜ASO意义｜感染程度≠病情〕〉
〈急性肾炎三个别名〔临床/病理/病因3身份｜病理同义名｜增生2细胞〕〉
〈急性肾炎病理四联〔大体2｜LM2细胞｜EM位置+形状｜IF形态〕〉

屏障异常带来血尿/轻重不同的蛋白尿；毛细血管腔狭窄使滤过下降，伴少尿、水钠潴留、高血压及水肿。补体参与炎症而**消耗 C3，血中 C3 可短暂下降**，典型感染后病程好转则恢复；持续低补体、肾功能继续恶化或表现不典型时须重新寻因。血 Cr 和贫血是观察严重程度/演变速度的证据，不是将两种综合征硬拆开的绝对截点。
〈急性肾炎为什么同时“漏”和“滤不过”〔屏障→血尿/蛋白｜增生→GFR｜临床4表现｜Cr/贫血比较〕〉
〈C3：一过性下降，8周内恢复〔C3消耗机制｜恢复时程/意义｜持续低2类对照〕〉

大多数典型病例按炎症消退与容量/血压变化进行支持和对症处理，抗菌针对尚存的感染，并非用抗菌药治疗已发生的全部免疫损伤。肾功能持续恶化、肾病范围蛋白丢失或不能按典型病程改善，构成重新评估、考虑肾活检的分支；急性容量超负荷可同时出现肺水肿/左心衰，高血压严重时发生脑病，必须及时处理，不等待完成一张诊断表。
〈急性肾炎肾活检3指征〔活检3情境｜肾功能趋势｜肾病综合征｜不改善时程〕〉
〈急性肾炎治疗：自限性 + 对症〔治疗性质｜降压顺序2｜抗生素条件｜激素/免疫抑制适用边界〕〉
〈急性重症出口：左心衰与高血压脑病〔容量→血压/前负荷｜肺水肿vs脑病｜急症药接口｜循环/神经〕〉

## 快速恶化来自严重毛细血管损伤：新月体是后果证据，不是病原名称

若肾功能在短期内进行性下降，应尽快考虑急进性肾炎综合征。严重肾小球袢损伤使 GBM 破裂、纤维蛋白和炎症细胞进入 Bowman 囊，壁层上皮细胞等增殖形成新月体；新月体压迫肾小球丛并加速失滤。**临床“急进”是速度判断，组织“新月体”是形态证据**，可高度相关但不是定义上互相替代，严重度和出现比例也可变化。
〈急进性肾炎三个别名〔临床速度｜毛细血管外/新月体2形态名｜病变细胞｜Cr/贫血〕〉
〈新月体形成链〔GBM断裂｜纤维素｜2类细胞｜细胞→纤维｜压迫2结果〕〉
〈“急进性综合征”与“新月体”不是绝对同义〔临床速度｜病理形态｜综合征/新月体对应边界｜经典低概率方向〕〉

这条快速坏死性病变可能有三种**并行免疫来源**：针对 GBM 的抗体沿基底膜结合，IF 经典线状，肺出血提示可能的肺肾综合征；免疫复合物沉积激活效应系统，IF 多呈颗粒；免疫沉积极少的 pauci-immune 病变常与 ANCA 相关，但 **ANCA 阴性不能单独否定这个病理模式**。LM 均可出现新月体，最终靠 IF/EM、血清学和病因背景区分；课程“Ⅰ型最差、Ⅱ型最常见”保留其特定比较范围，不推广为所有年代和人群的无条件排名。
〈Ⅰ型 RPGN：抗GBM、线状、预后最差〔抗体｜原位｜IF｜EM｜继发肺肾｜治疗强化〕〉
〈Ⅱ型 RPGN：免疫复合物、颗粒、最常见〔原位/循环｜IF｜EM｜C3｜继发3〕〉
〈Ⅲ型 RPGN：pauci-immune，常与 ANCA 相关〔pauci-immune定义｜ANCA价值/定义边界｜沉积2证据｜系统血管炎接口〕〉
〈RPGN三型总轴〔RPGN3型：机制/IF/EM｜常见度/预后｜C3｜ANCA定义边界〕〉

因功能可快速不可逆丧失，紧急评估病因、肾活检风险和当前危险变量应同步推进。糖皮质激素/其他免疫抑制、特定抗体病的血浆置换以及需要时的 KRT 是**按病因、损伤程度和临床状态分支**的治疗任务，不是对所有新月体患者同一套固定配方；考试原药物/剂量配对保留原 Core 与 Source。
〈RPGN强化治疗配对〔置换/甲冲配型｜肺出血｜共同2药｜透析/移植〕〉

## IgA 分支：黏膜时序可提示，但身份主要依赖系膜 IgA 证据

在感染前后紧贴发生的肉眼血尿（课程常见相隔 1–3 天），可提示 IgA 肾病而非典型感染后肾炎的迟发间隔；黏膜免疫异常相关的 IgA 优势/共优势沉积主要位于系膜。**IF 的系膜 IgA 才是病理身份锚点**，LM 常见系膜增生却不是唯一、永久的形态，EM 与临床范围亦可变。血清 IgA 升高既不必然发生，也不与严重程度简单一一对应。
〈IgA身份：临床入口 + IF身份锚点，不锁死单一LM〔常见性2｜人群/感染时程｜系膜IgA身份｜LM可变/EM位置〕〉
〈血IgA升高不是严重度尺；确证回系膜IgA〔升高比例方向｜严重度相关？｜黏膜接口｜确诊证据〕〉

同一 IgA 肾病可表现为反复血尿、无症状尿异常、蛋白增多乃至快速进展；管理应随蛋白尿、血压、肾功能趋势和活检风险形态改变，先保留支持/危险控制，再考虑具体治疗条件，而非见到 IgA 就走同一药物表。对照紫癜/IgA 血管炎时需要全身皮肤/关节/胃肠证据；对照感染后肾炎需连同病程、补体与病理读数，**不靠“感染过”三个字直接判定病种**。
〈IgA五种临床表型与治疗分流〔IgA临床5表型｜蛋白/高压强化分支｜各处理｜靶向新药接口〕〉
〈急性GN vs IgA vs 紫癜肾炎〔感染时间3｜沉积IgG/IgA｜C3｜皮肤特征〕〉

## 慢性进展：不同原发损伤可汇成肾小球硬化与肾单位丢失

各种肾小球损伤若长期迁延，可逐步形成小球硬化、间质纤维化及小血管改变，使有效肾单位减少，逐渐出现尿异常、容量/血压紊乱和慢性功能下降；这是**不同病因的共同结局**，并非某一急性肾炎没有治疗就必然转成慢性。B 超早期未必缩小，双肾相对对称缩小更多是晚期支持线索，也须保留原来的肾大小例外。
〈慢性肾炎身份：各种肾小球病的终末路径〔3别名｜来源｜进展快慢2代表｜时间门槛〕〉
〈慢性肾炎病理与B超〔肾小球2改变｜炎细胞2｜血管1｜固缩肾｜B超早晚〕〉

剩余肾单位承受钠水负荷和 RAAS 等机制，高血压又增加肾小球压力，形成进一步损伤的反馈；舒血管物质变化只是其中一层，不能以“先高血压还是先尿异常”的单独一句话取代病例鉴别。控制 BP/蛋白尿和可逆损伤有助延缓进展，ACEI/ARB 的肾小球内压机制与监测边界沿 B7 现有 owner，课程旧 Scr/限盐限蛋白数字仍归 Source Precision，不另建第二套治疗真相。
〈慢性肾炎高血压：容量 + RAAS + 舒血管物质减少〔3机制｜ANP方向｜血压先后｜尿证据〕〉
〈慢性肾炎治疗目标：Current Core 与 Study Precision 分层〔目标2/非目标｜ACEI-ARB机制/监测｜旧阈值边界｜营养5限+肾毒药｜热量〕〉

与原发性高血压肾损害、慢性肾盂肾炎比较时，联系尿蛋白/血尿先后、长期 BP、双侧形态、是否以小管间质及瘢痕为主等多项证据，不能把双肾大小、年龄或一次尿白细胞单轴当绝对判断。
〈慢性肾炎 vs 原发性高血压 vs 慢性肾盂肾炎〔先后顺序｜年龄｜肾损害层级｜肾大小对称性｜靶器官〕〉

最终陌生病例：先确定是否有急性危险（Cr 速度、K/容量/血压、器官损害），平行收集感染时间、C3、尿沉渣、血清学和肾形态；再根据需要使用 LM/IF/EM 定位损伤模式与免疫来源，回到病因特异处置及当前危险干预，随后复查临床/功能反应。这是**诊断与干预的可反馈流程，不是四种肾炎的自然先后顺序**。
〈肾炎分支病例算法〔感染时程｜Cr趋势/C3｜LM-IF-EM｜肾形态｜按病因治疗〕〉

B10 既有“急性肾炎 P195 任务／P197 急进性形态资产”不一致仍为原 MedicalVisual/Source HOLD；不能通过此文字模型冒称原图已匹配或已接触。

**Residual 边界**：损伤机制、时间/速度/病理双轴、疾病分支和危险反馈归模型与完整原 Prompt；阈值/时间、药物剂量与低频配对继续由原 Core/Precision/Source/MedicalVisual 承接；P195/P197 视觉定位 HOLD 不解除。

# 3｜急性肾炎

<!-- kianos:kp id="urinary-b10-kp01" -->
## KP01｜急性肾炎三个别名

> **主提示：临床/病理/病因3身份｜病理同义名｜增生2细胞**

### 快速核对

- 急性肾小球肾炎：临床身份；
- 急性弥漫性增生性肾炎 / 毛细血管内增生性肾炎：病理身份；
- 感染后性肾炎：病因时间身份。

LM主轴：内皮细胞和系膜细胞增生。本段用感染后肾炎作为课程典型模型，不能把所有“急性肾炎综合征”都直接命名为链球菌感染后肾炎；综合征还可见于其他病因。

<!-- kianos:kp id="urinary-b10-kp02" -->
## KP02｜前驱感染：为什么要等1–3周

> **主提示：病原1｜感染部位3｜时间｜ASO意义｜感染程度≠病情**

### 快速核对

当前 Study重点是 β-溶血性链球菌等感染：

```text
上呼吸道 / 消化道 / 皮肤感染
→ 约1–3周形成免疫反应
→ 急性肾炎综合征
```

原题跨章节串联：课程1–3周前驱感染还见于病毒性心肌炎、急性非特异性心包炎、亚急性甲状腺炎及肾炎识别题；IgA肾病强调1–3天。时间线只作线索，不能单独确诊。

ASO升高提示近期溶血性链球菌感染；感染程度与肾炎轻重不完全相关，因为肾损伤主体是免疫反应，不是细菌直接侵入肾小球。

<!-- kianos:kp id="urinary-b10-kp03" -->
## KP03｜急性肾炎病理四联

> **主提示：大体2｜LM2细胞｜EM位置+形状｜IF形态**

### 快速核对

```text
大体：大红肾、蚤咬肾
LM：内皮细胞 + 系膜细胞增生
EM：上皮下驼峰状电子致密物
IF：颗粒状荧光
```

这是“临床急性肾炎综合征”与“病理毛细血管内增生性肾炎”对齐的典型模型。

<!-- kianos:kp id="urinary-b10-kp04" -->
## KP04｜急性肾炎为什么同时“漏”和“滤不过”

> **主提示：屏障→血尿/蛋白｜增生→GFR｜临床4表现｜Cr/贫血比较**

### 快速核对

```text
滤过屏障损伤
→ 血尿、蛋白尿、管型

内皮 / 系膜增生
→ 毛细血管袢狭窄、有效滤过面积下降
→ GFR下降
→ 少尿、水钠潴留、水肿、高血压
```

课程识别：血Cr多＜200 μmol/L，贫血多无或轻度，用于与急进性肾炎比较；这不是排除急性肾炎重症或定义RPGN的硬阈值，诊断还看变化速度、临床和病理。

## KP06｜急性肾炎肾活检3指征

1. 少尿超过1周、尿量进行性减少或Cr持续升高；
2. 伴肾病综合征；
3. 病程超过8周无好转趋势。

## KP07｜急性肾炎治疗：自限性 + 对症

> **主提示：治疗性质｜降压顺序2｜抗生素条件｜激素/免疫抑制适用边界**

### 快速核对

- 以对症治疗为主；
- 容量依赖性高血压先利尿消肿；再按情况用ACEI/ARB或CCB。明显AKI、高钾或低容量时要特别评估ACEI/ARB风险，利尿也不能替代严重少尿/肺水肿时的肾脏替代治疗评估；

- 典型自限性感染后GN不常规用糖皮质激素和免疫抑制剂；非典型、快速恶化者需重新明确病因，不能把所有急性肾炎综合征一概套用同一禁用结论；
- 反复扁桃体炎可在病情稳定后处理病灶。

# 4｜急进性肾炎

<!-- kianos:kp id="urinary-b10-kp09" -->
## KP09｜急进性肾炎三个别名

> **主提示：临床速度｜毛细血管外/新月体2形态名｜病变细胞｜Cr/贫血**

### 快速核对

- 快速进行性肾炎：临床强调肾功能快速恶化；
- 毛细血管外增生性肾炎：LM强调病变在毛细血管袢外；

## KP10｜新月体形成链

## KP12｜Ⅱ型 RPGN：免疫复合物、颗粒、最常见

> **主提示：原位/循环｜IF｜EM｜C3｜继发3**

### 快速核对

- 原位或循环免疫复合物；
- IF颗粒状；
- EM有电子致密物；
- C3可持续下降；

<!-- kianos:kp id="urinary-b10-kp13" -->
## KP13｜Ⅲ型 RPGN：pauci-immune，常与 ANCA 相关

> **主提示：pauci-immune定义｜ANCA价值/定义边界｜沉积2证据｜系统血管炎接口**

### 快速核对

III 型的**形态 / 免疫模式身份**是 pauci-immune crescentic GN：

```text
IF：免疫球蛋白 / 补体沉积极少或几乎没有
EM：无典型电子致密物
→ pauci-immune
```

它**常与 ANCA 相关小血管炎相连**，因此 306 看到：

```text
ANCA阳性
+ pauci-immune
+ 新月体 / 快速肾功能恶化
```

要高度匹配 III 型。但 **ANCA 阴性的 pauci-immune GN 也存在**，所以“ANCA阳性”是高价值病因证据，不是 pauci-immune 定义本身的必要条件。

当前 Study 接口继续保留：

- MPA：常见 p-ANCA 方向；
- Wegener / GPA：常见 c-ANCA 方向。

本型可有发热、消瘦、关节痛等系统性血管炎表现；这些是病因线索而非每位患者必备。完整血管炎疾病谱、抗原特异性和治疗后置免疫系统。

# 5｜IgA肾病

<!-- kianos:kp id="urinary-b10-kp17" -->
## KP17｜IgA身份：临床入口 + IF身份锚点，不锁死单一LM

> **主提示：常见性2｜人群/感染时程｜系膜IgA身份｜LM可变/EM位置**

### 快速核对

当前 Study 高价值入口：

- 我国最常见的肾小球疾病；
- 肾小球源性血尿最常见原因；
- 青少年多见；
- 上呼吸道感染后 **1–3天** 出现明显血尿；
- 课程临床表现以单纯血尿为主要入口，也可有蛋白尿、高血压、肾病综合征或肾功能不全。

最稳定的病理身份锚点不是某一个固定 LM，而是：

> **IF：系膜区 IgA 优势或共优势沉积。**

课程所问**最常见LM模式**是系膜增生（系膜细胞 / 基质增生）；但IgA肾病形态可从接近轻微改变，到系膜增生、节段硬化，重症时也可出现新月体等变化。EM 常见系膜 / 旁系膜电子致密物方向。

因此可以背：

```text
IgA肾病常见系膜增生
```

不能写成：

```text
IgA肾病 = 一个固定的“系膜增生性肾小球肾炎”LM病型
```

<!-- kianos:kp id="urinary-b10-kp18" -->
## KP18｜血IgA升高不是严重度尺；确证回系膜IgA

> **主提示：升高比例方向｜严重度相关？｜黏膜接口｜确诊证据**

### 快速核对

讲义约30%–50%患者血IgA升高，但与病情严重程度不完全相关。IgA参与黏膜免疫，呼吸道等黏膜感染可与数天内血尿发作相连；该关联不能单靠总IgA升高证明肾脏致病机制。关键仍是临床表型与肾活检 IF 中的**系膜区 IgA 优势 / 共优势沉积**；LM形态用于描述损伤模式，不单独承担 IgA 身份定义。

<!-- kianos:kp id="urinary-b10-kp19" -->
## KP19｜IgA五种临床表型与治疗分流

> **主提示：IgA临床5表型｜蛋白/高压强化分支｜各处理｜靶向新药接口**

### 快速核对

当前 Study分流：

1. 单纯血尿：对症、定期复查；
2. 感染后反复肉眼血尿：控制感染，慢性扁桃体炎可处理病灶；
3. 蛋白尿和/或高血压：课程ACEI/ARB，尿蛋白目标＜0.5 g/d，逐渐调整至可耐受剂量；
4. 难控蛋白尿 / 高血压：激素接口；
5. 肾病综合征：糖皮质激素为主；
6. 肾衰竭：按肾功能状态处理；
7. 靶向释放布地奈德为当前 Lecture 的新药接口。

以上保留课程五种临床表型（第4项是蛋白尿/高血压分支的强化，第7项是药物补充）。必须同时带条件：高血压难控本身不是自动加激素的指征；反复肉眼血尿也不等于每次都有需抗生素的细菌感染。

KDIGO 2025校准：伴肾病综合征仍须看活检，若IgA沉积合并MCD样足细胞病按MCD治疗；系膜增生性IgAN则按IgAN进展风险处理，不能把所有IgAN肾病综合征直接等同激素敏感。免疫/靶向治疗应结合持续蛋白尿、eGFR、病理与治疗风险，不用一条“难控血压”取代决策；本段不展开整套新药方案。

## KP23｜慢性肾炎高血压：容量 + RAAS + 舒血管物质减少

> **主提示：3机制｜ANP方向｜血压先后｜尿证据**

### 快速核对

1. GFR下降 → 水钠潴留 → 容量依赖；
2. 肾缺血 → 交感与RAAS激活 → 肾素依赖；
3. 肾实质受损 → PG、缓激肽等舒血管物质减少；
4. 讲义列ANP下降，但“与RAAS作用拮抗”不能推出血中浓度一定反向变化；容量扩张可刺激ANP，亦可能有作用抵抗，应与K4/A1容量调节一致。

鉴别先后：课程典型慢性肾炎是先肾病后高血压，血尿/蛋白尿较突出；原发性高血压常先高血压后肾损，小管浓缩障碍可较早。隐匿起病时先后并非总能确定，须结合既往尿检、血压及靶器官证据。

## KP24｜慢性肾炎治疗目标：Current Core 与 Study Precision 分层

> **主提示：目标2/非目标｜ACEI-ARB机制/监测｜旧阈值边界｜营养5限+肾毒药｜热量**

### 快速核对

目标：

```text
延缓肾功能恶化
+ 防止心脑血管并发症
≠ 消灭所有肾炎综合征表现
```

稳定 Current Core：

- 利尿消肿；肾功能下降时按容量和肾功能状态选择利尿策略；
- ACEI/ARB 通过降压、降低肾小球内压和减少蛋白尿保护残余肾单位；
- 启用 / 加量后关注血压、肌酐 / eGFR 与 K⁺变化；明显恶化先找低容量、NSAID、肾动脉狭窄等可逆原因；症状性低血压或难以控制的高钾等才进入减量 / 停药决策；
- 限钠、水、磷、蛋白、脂及肾毒性药物等当前 Source 支持的减负方向；
- 保证热量；
- 不把“消灭血尿/蛋白尿”当最终治疗目标。

### //MI-D｜Study Precision

课程印刷P166的精度：收缩压＜120 mmHg、尿蛋白＜1 g/d；氢氯噻嗪在GFR＜30 mL/(min·1.73 m²)时转呋塞米的教学选择；血Cr＞265 μmol/L不用ACEI/ARB的旧写法。最后一个固定Cr门槛不作为现代通用禁忌，监测与停药条件回K7 KP15，不能误指循环系统B7。

原图确写“限钠＜5 g/d”，不把它静默改成限盐；与KDIGO 2024的钠＜2 g/d（约食盐＜5 g/d）存在单位/目标差异，作为Source冲突保留。

收缩压＜120的现代CKD应用须结合标准化诊室测量和耐受，并非拿任意一次家庭/随意诊室读数强行降到该数。限水、蛋白、磷等须按容量、病期、营养及化验调整，不是所有慢性肾炎统一严格限制。课程“不推荐积极用激素＋环磷酰胺”用于慢性硬化/进展性模型，不排除明确活动性免疫病因的针对治疗。

## KP25｜慢性肾炎 vs 原发性高血压 vs 慢性肾盂肾炎

> **主提示：先后顺序｜年龄｜肾损害层级｜肾大小对称性｜靶器官**

### 快速核对

| 轴 | 慢性肾炎 | 原发性高血压肾损害 | 慢性肾盂肾炎 |

## KP26｜肾炎分支病例算法

> **主提示：感染时程｜Cr趋势/C3｜LM-IF-EM｜肾形态｜按病因治疗**

### 快速核对

```text
1. 是否有血尿突出
2. 前驱感染是1–3周还是1–3天
3. Cr是一过性轻度、快速恶化，还是长期进展
4. C3是一过性恢复、持续低，还是多正常
5. IF：线状 / 颗粒 / pauci-immune / 系膜IgA
6. EM：驼峰 / 有无沉积 / 系膜或旁系膜沉积

8. 肾脏：增大、大白，还是后期对称缩小
9. 治疗：
   急性对症
   急进按具体免疫/病因强化
   IgA按表型与风险
   慢性延缓进展
```
