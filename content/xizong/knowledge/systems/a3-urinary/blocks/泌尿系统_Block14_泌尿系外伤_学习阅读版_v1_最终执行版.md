# 0｜这个 Block 到底解决什么

泌尿外伤最容易被背成四张表：

- 前尿道；
- 后尿道；
- 膀胱；
- 肾。

真正统一它们的是一个空间问题：

> **哪里裂了，血和尿就先进入哪里的邻近间隙。**

再加一个优先级问题：

> **患者是否已经因大出血和休克失去稳定性？**

所以病例顺序必须是：

```text
受伤机制
→ 可疑部位
→ 尿道口滴血 / 血尿 / 腹膜刺激征 / 肿块
→ 血和尿外渗到哪里
→ 是否可以安全置管
→ 选择造影或CT
→ 是否需要引流 / 修补 / 探查
→ 同时处理休克
```

四个空间入口：

```text
会阴骑跨伤
→ 前尿道球部
→ 尿生殖膈以下外渗

骨盆骨折
→ 后尿道膜部
→ 尿生殖膈以上、膀胱周围 / 耻骨后外渗

膀胱前壁破裂
→ 腹膜外
→ 膀胱周围 / 耻骨后

膀胱顶部 / 后壁破裂
→ 腹膜内
→ 尿进入腹腔、出现全腹腹膜刺激征

腰腹部损伤
→ 肾挫伤 / 裂伤 / 肾蒂伤
→ 血尿、肿块、休克强度并不总成比例
```

# 1｜总 Framework

<!-- kianos:framework id="urinary-b14-framework-main" -->

```text
① 先看生命危险
   大出血 / 休克？
   有 → 抗休克同时准备探查
   [KP01]
        ↓
② 看受伤机制
   会阴骑跨 → 前尿道球部
   骨盆骨折 → 后尿道膜部
   下腹 / 膀胱充盈受伤 → 膀胱
   腰腹部钝伤 → 肾
   [KP02]
        ↓
③ 若有尿道口滴血 / 排尿困难
   不盲目导尿
   → 逆行尿道造影金标准
   [KP03]
        ↓
④ 尿道损伤按尿生殖膈分层
   前尿道：膈下、会阴阴囊阴茎下腹壁
   后尿道：膈上、膀胱周围耻骨后
   [KP04–KP06]
        ↓
⑤ 膀胱破裂按腹膜内外分层
   腹膜外：前壁 / 局部下腹体征
   腹膜内：顶部后壁 / 全腹腹膜刺激征
   [KP07–KP09]
        ↓
⑥ 肾外伤看结构严重度
   挫伤最轻
   裂伤可肿块、大量全程血尿、休克
   肾蒂伤最重，休克快、功能丧失
   [KP10–KP12]
        ↓
⑦ 血尿不能判断轻重
   肾蒂伤可重而血尿少
   → 影像与血流动力学优先
   [KP13]
        ↓
⑧ 最终病例算法
   机制→空间→造影/CT→引流/探查→抗休克
   [KP14]
```

## 一条总电影

```text
会阴骑跨伤
→ 尿道球部受损
→ 尿道滴血、排尿困难
→ 尿液和血肿向会阴、阴囊、阴茎、下腹壁扩散
→ 逆行尿道造影定位

骨盆骨折
→ 尿道膜部 / 后尿道受损
→ 尿道滴血、排尿困难
→ 尿外渗进入尿生殖膈以上、膀胱周围和耻骨后
→ 直肠指检可见肿痛、前列腺尖端浮动感
→ 不能盲目导尿

膀胱破裂
→ 腹膜外或腹膜内
→ 外渗空间决定局部下腹体征还是全腹腹膜刺激征
→ 决定下腹正中切口或剖腹探查

肾外伤
→ 挫伤、裂伤或肾蒂伤
→ 血尿强度不与损伤程度平行
→ CT定位
→ 大出血 / 休克时边抗休克边手术探查
```

# 3｜先判是否存在需要立即处理的大出血与休克

<!-- kianos:kp id="urinary-b14-kp01" -->

## KP01｜泌尿外伤第一优先级：稳定性先于精细分型

> **讲义定位 →** 外科 P111。  
> **主提示**：第一问1｜大出血/休克处理2并行｜不能等什么｜血尿轻重陷阱。

面对泌尿外伤，先问：

> 是否存在大出血和休克？

当前 Study 明确：

```text
大出血、休克
→ 手术探查
+ 同时抗休克
```

这不是先后排队，而是并行：不能为了把损伤部位完全分清，延误生命支持与止血。

（易混：血尿少不代表安全，肾蒂损伤可迅速休克而血尿不突出。）

---

<!-- kianos:kp id="urinary-b14-kp02" -->

## KP02｜受伤机制先定位：前骑球、后骨膜、腰腹看肾

> **主提示**：4机制｜4部位｜各1首发线索｜机制比单一血尿更先行。

| 受伤机制 | 首先定位 |
|---|---|
| 会阴部骑跨伤 | 前尿道，常伤尿道球部 |
| 骨盆骨折 | 后尿道，常伤尿道膜部 |
| 下腹部 / 膀胱区域外伤 | 膀胱破裂接口 |
| 腰腹部外伤 | 肾外伤 |

病例不能只抓“血尿”：

- 尿道口滴血 + 排尿困难更支持尿道损伤；
- 全腹腹膜刺激征把位置拉向腹膜内膀胱破裂；
- 腰腹部痛、血尿或肿块把位置拉向肾。

# 4｜尿道外伤：尿道口滴血时先停下导尿动作

<!-- kianos:kp id="urinary-b14-kp03" -->

## KP03｜尿道外伤警报：尿道滴血 → 禁忌盲目导尿 → 逆行尿道造影

> **主提示**：警报2｜不能做1｜金标准1｜造影读什么｜完全断裂线索。

男性尿道外伤最多见。

若出现：

- 尿道口滴血；
- 排尿困难；
- 会阴骑跨伤或骨盆骨折背景；

应高度怀疑尿道损伤。

当前 Study：

> **金标准是逆行尿道造影。**

原则：

```text
可疑尿道损伤
→ 不盲目插导尿管
→ 先逆行尿道造影
→ 看造影剂在哪里外漏
```

“哪里漏，哪里有裂伤”；若造影剂不能进入后尿道，提示尿道完全断裂接口。

# 5｜膀胱破裂：腹膜内外决定尿向哪里流

<!-- kianos:kp id="urinary-b14-kp07" -->

## KP07｜膀胱外伤先分腹膜外与腹膜内

> **主提示**：2型｜壁部位｜外渗空间｜腹膜征｜切口/探查｜为什么空间决定症状。

共同逻辑：

```text
膀胱壁破裂
→ 尿液进入邻近空间
→ 空间决定症状、体征和手术入口
```

两类：

- 腹膜外型膀胱破裂；
- 腹膜内型膀胱破裂。

接下来依次比较：破裂壁、尿外渗、腹膜刺激征、手术路径。

---

<!-- kianos:kp id="urinary-b14-kp08" -->

## KP08｜腹膜外型膀胱破裂：前壁、膀胱周围 / 耻骨后、局部下腹体征

> **主提示**：壁1｜外渗2｜体征4｜DRE｜手术切口1。

当前 Study：

- 常见破裂位置：膀胱前壁；
- 尿外渗 / 血肿：膀胱周围、耻骨后间隙；
- 体征：下腹疼痛、压痛、肌紧张；直肠指检可肿痛；
- 手术：下腹正中切口。

其空间特点是尿液主要留在腹膜外间隙，因此以局部下腹和耻骨后表现为主。

---

<!-- kianos:kp id="urinary-b14-kp09" -->

## KP09｜腹膜内型膀胱破裂：顶部 / 后壁、尿入腹腔、全腹腹膜刺激征

> **主提示**：壁2｜外渗1｜体征2｜移动性浊音｜手术1｜与腹膜外对照。

当前 Study：

- 常见破裂位置：膀胱顶部、后壁；
- 尿液进入腹腔；
- 可出现全腹腹膜刺激征；
- 可有移动性浊音；
- 处理：剖腹探查。

对照：

| 腹膜外 | 腹膜内 |
|---|---|
| 前壁 | 顶部 / 后壁 |
| 膀胱周围、耻骨后 | 腹腔 |
| 局部下腹体征 | 全腹腹膜刺激征 |
| 下腹正中切口 | 剖腹探查 |

# 6｜肾外伤：血尿不等于严重度尺子

<!-- kianos:kp id="urinary-b14-kp10" -->

## KP10｜肾外伤入口：腰腹痛 + 血尿；影像首选CT

> **主提示**：症状2｜检查1｜血尿是否必有｜肿块提示哪型｜何时先稳定性。

当前 Study 典型入口：

- 腰腹部疼痛；
- 血尿。

影像学首选：**CT**。

但血尿可为肉眼、镜下，甚至不明显；不能因“没有大量血尿”排除重伤。

腰腹部肿块更支持肾全层裂伤等较重结构损伤，而不是单纯挫伤。

---

<!-- kianos:kp id="urinary-b14-kp11" -->

## KP11｜肾挫伤：最轻，可有或无血尿

> **主提示**：肾挫伤：严重度｜血尿可有哪些情况｜肿块？｜与裂伤对照

肾挫伤是当前 Study 三型中最轻。

Lecture-attached Questions 支持：

- 可有肉眼血尿；
- 可有镜下血尿；
- 也可无血尿。

与肾裂伤对照：单纯挫伤通常不以腰腹部肿块作为典型识别物。

---

<!-- kianos:kp id="urinary-b14-kp12" -->

## KP12｜肾裂伤与肾蒂伤：肿块 / 大量血尿 vs 迅速休克 / 功能丧失

> **主提示**：3型排序｜裂伤4表现｜肾蒂2最重｜血尿悖论｜处理门槛。

当前 Study 三型：

1. 肾挫伤：最轻；
2. 肾裂伤；
3. 肾蒂损伤：最重。

肾全层裂伤可见：

- 腰腹部肿块；
- 大量全程肉眼血尿；
- 腹膜刺激征；
- 休克。

肾蒂损伤：

- 可迅速出现休克；
- 肾功能丧失。

（易混：肾蒂损伤最重，但若血管 / 输尿管通路严重破坏，血尿未必最突出。）

---

<!-- kianos:kp id="urinary-b14-kp13" -->

## KP13｜血尿—严重度脱钩：轻伤可血尿，重伤可血尿少

> **主提示**：不相关1结论｜轻重各1反例｜为什么不能据血尿排除｜下一证据2。

当前 Study 反复强调：

> 血尿与病变程度不一定相关。

因此：

```text
血尿明显
≠ 一定最重

血尿不明显
≠ 可以排除肾蒂损伤或严重出血
```

下一步证据：

- 血流动力学是否稳定；
- CT所见结构与血管损伤。

这条原则也适用于 K12 的结石：血尿不能单独反推梗阻或损伤严重度。

# 7｜最终定位与处理算法

<!-- kianos:kp id="urinary-b14-kp14" -->

## KP14｜泌尿外伤7步：机制—滴血—空间—稳定性—造影/CT—处理

> **主提示**：7步｜尿道禁忌1｜检查2｜膀胱2型｜肾3型｜休克并行。

```text
1. 受伤机制是什么？
   骑跨 / 骨盆骨折 / 下腹 / 腰腹

2. 是否有尿道口滴血和排尿困难？
   有 → 不盲目导尿

3. 怀疑尿道损伤时做什么？
   逆行尿道造影

4. 血和尿外渗到哪里？
   会阴阴囊阴茎下腹壁 → 前尿道
   膀胱周围 / 耻骨后 → 后尿道或腹膜外膀胱
   腹腔 + 全腹腹膜刺激征 → 腹膜内膀胱

5. 腰腹痛 / 血尿 / 肿块时做什么？
   CT定位肾损伤

6. 肾损伤属于哪一层？
   挫伤 / 裂伤 / 肾蒂伤

7. 是否大出血或休克？
   是 → 抗休克 + 手术探查并行
```

```text
   → 腹腔、全腹腹膜刺激征

肾
挫伤 → 裂伤 → 肾蒂伤
最轻                最重
```

再写一句优先级：

> **尿道滴血先造影不盲插；大出血休克边复苏边探查；血尿不能判断轻重。**

# 9｜Memory Routing

## 9.1 MI-G｜第一轮必须即时掌握

- 会阴骑跨伤 → 前尿道球部；骨盆骨折 → 后尿道膜部；
- 尿道滴血 / 可疑尿道伤时不盲目导尿；逆行尿道造影金标准；
- 前尿道尿外渗：会阴、阴囊、阴茎、下腹壁；
- 后尿道尿外渗：膀胱周围、耻骨后；DRE前列腺尖端浮动感；
- 腹膜外膀胱破裂：前壁、膀胱周围 / 耻骨后、局部下腹体征；
- 腹膜内膀胱破裂：顶部 / 后壁、尿入腹腔、全腹腹膜刺激征；
- 肾外伤首选 CT；
- 肾挫伤最轻，肾蒂伤最重；
- 肾全层裂伤：肿块、大量全程肉眼血尿、腹膜刺激征、休克；
- 血尿与损伤程度不相关；
- 大出血 / 休克：手术探查 + 抗休克并行。

## 9.2 MI-D｜进入 MarginNote 3

- 尿生殖膈以上 / 以下的精确空间；
- 前尿道外渗四个区域；
- 直肠指检肿痛与前列腺尖端浮动感；
- 膀胱前壁、顶部、后壁与腹膜关系；
- 下腹正中切口 vs 剖腹探查；
- 肾挫伤可有 / 无血尿的选项口径；
- 尿道完全断裂的造影线索；
