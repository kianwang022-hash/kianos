## 学习阅读版 v1｜最终执行版

# 0｜为什么泌尿系统从这里开始

肾脏不是一根“把废物排出去”的管道，而是一套高流量、分层处理、可测量并能主动调节全身稳态的系统：

```text
血液高流量进入肾脏
→ 肾小球先大量滤出小分子
→ 肾小管与集合管把需要的物质拿回去
→ 将某些物质额外分泌进管腔
→ 形成终尿并排出
```

同时，肾脏还通过肾素、EPO、1α-羟化酶等，把循环容量、红细胞生成和钙磷代谢连接起来。

本 Block 要先建立四套共同语言：

```text
空间地图
肾皮质 / 髓质 → 肾单位 → 血管 → 尿路

方向语言
滤过 / 重吸收 / 分泌 / 排泄

测量语言
GFR / RPF / RBF / FF / 清除率

控制语言
交感 / 体液 / 肌源性 / 管球反馈
```

只要这四套语言稳定，后面遇到“某物质为什么出现在尿中”“为什么 GFR 下降”“为什么肾衰会贫血和低钙”“为什么双肾动脉狭窄不能轻易用 ACEI/ARB”，都能从同一张图推出来。

# 2｜肾脏的任务与空间地图

<!-- kianos:kp id="urinary-b01-kp01" -->

## KP01｜肾脏总任务：高流量“洗血”，再分层形成终尿

> **讲义定位 →** 生理 Lecture PDF P257｜泌尿概述。  
> **主提示**：皮/髓｜尿生成3步｜肾单位边界｜尿路5段｜高流量为何

### 1｜肾脏为什么要有约 1200 mL/min 的高血流

按本节 Study，肾脏是供血最丰富的器官之一，肾血流量约 **1200 mL/min**，远超过肾脏自身代谢需要。核心目的不是给肾脏“供能”，而是让大量血浆反复经过肾单位：

```text
排出代谢终产物
+ 排出进入机体的异物
+ 排出过剩物质
+ 调节水、电解质与酸碱
```

大部分血流供应肾皮质，因为肾小体主要位于皮质，滤过首先发生在这里。

### 2｜皮质、髓质与尿路

| 区域 | Study 主体结构 | 当前角色 |
|---|---|---|
| 肾皮质 | 肾小体（肾小球 + 肾小囊）及部分肾小管 | 高血流、滤过入口 |
| 肾髓质 | 肾锥体，以肾小管和集合管为主 | 浓缩 / 稀释的空间基础 |
| 肾乳头 | 肾锥体尖端 | 集合管开口，尿进入肾小盏 |

尿液大方向：

```text
集合管
→ 肾乳头
→ 肾小盏
→ 肾大盏
→ 肾盂
→ 输尿管
→ 膀胱
→ 尿道
```

肾盏、肾盂和输尿管壁含平滑肌，其收缩推动尿液向膀胱移动。

### 3｜尿生成三过程

```text
肾小球滤过
血浆小分子 → 肾小囊，形成原尿 / 超滤液
        ↓
肾小管和集合管重吸收
小管液 → 血液
        ↓
肾小管和集合管分泌
血液 / 小管上皮细胞 → 小管液
        ↓
终尿排泄
终尿 → 体外
```

（易混：**滤过**是血浆到原尿；**清除**是把某物质从血浆最终弄到终尿；二者不是同一个方向终点。）

### 4｜肾单位与集合管

```text
肾单位
= 肾小体 + 与之相连的肾小管

肾小体
= 肾小球 + 肾小囊

肾小管
= 近曲小管 + 髓袢 + 远曲小管
```

集合管与远曲小管相接，和肾单位共同完成尿生成，但**集合管不属于肾单位**。

（特殊：肾脏不能再生新的肾单位；Study 提示 40 岁后功能性肾单位数量可逐渐减少，正常情况下剩余肾单位仍足以维持功能。）

# 3｜肾脏内分泌与球旁器

<!-- kianos:kp id="urinary-b01-kp02" -->

## KP02｜肾脏内分泌：肾素、EPO、活化 VitD 与局部血流介质

> **讲义定位 →** 生理 Lecture PDF P258｜肾的内分泌功能。  
> **主提示**：3内分泌｜来源+作用｜VitD 3站｜肾衰2后果｜局部介质2

### 1｜肾素：把低灌注接到 RAAS

```text
球旁细胞 / 近球细胞 / 颗粒细胞
→ 合成、储存、释放肾素
→ 激活 RAAS
```

肾素完整的人设已在循环 B2 建立；本 Block 重点是它的**肾脏来源与球旁器位置**。后续 B4 再完成 RAAS 对小管、Na⁺、水和终尿的肾端作用。

### 2｜EPO：把肾脏氧合状态接到红细胞生成

按 Study：

```text
肾皮质肾小管周围的间质细胞
如成纤维细胞样细胞
→ 合成促红细胞生成素 EPO
→ 促进红细胞生成
```

双肾严重破坏时 EPO 缺乏，形成肾性贫血接口。

（易混：EPO 不是由肾小球或球旁细胞产生；本节强调的是**肾皮质肾小管周围间质细胞**。）

### 3｜1α-羟化酶：把 VitD 变成活性形式

Study 链条：

```text
皮肤胆固醇相关前体
+ 紫外线
→ VitD3
→ 肝脏生成 25(OH)VitD3
→ 肾小管上皮细胞的 1α-羟化酶
→ 1,25(OH)₂VitD3
= 活化VitD / 钙三醇 / 骨化三醇
```

按本节 Study，钙三醇具有升钙、升磷作用。因此：

```text
肾衰
→ 1α-羟化酶与钙三醇生成下降
→ 低钙接口
→ 后续 CKD-MBD / 肾性骨病
```

完整 PTH—VitD—钙磷轴后置内分泌；泌尿系统保留肾脏在其中的关键转换位置。

### 4｜其他内分泌 / 局部调节

本节还列出：

- 前列腺素；
- 激肽释放酶；
- 肾脏对胃泌素、PTH等的灭活接口。

其中前列腺素和激肽系统在本 Block 后面的肾血流调节中再次调用。

## KP03｜球旁器：把灌注和小管 NaCl 变化变成肾素与 GFR 调节

> **讲义定位 →** 生理 Lecture PDF P258｜球旁器。  
> **主提示**：3组成｜位置/功能｜系膜内外｜致密斑读什么｜皮质偏向

### 1｜三组成

| 结构 | Study 位置 / 身份 | 核心作用 |
|---|---|---|
| 球旁细胞 / 颗粒细胞 | 入球小动脉壁特殊分化的平滑肌细胞 | 合成、储存、释放肾素 |
| 致密斑 | 穿过入、出球小动脉间的远曲小管起始部 | 感受小管液 NaCl 变化，参与管球反馈 |
| 球外系膜细胞 | 入球、出球和致密斑之间 | 吞噬、收缩，传递局部信息接口 |

### 2｜球内 vs 球外系膜细胞

```text
球内系膜细胞
位于肾小球毛细血管袢之间
→ 与滤过面积 / 滤过功能相关

球外系膜细胞
位于球旁器三角区
→ 吞噬、收缩和信息传递接口
```

完整球内系膜细胞—Kf—GFR 机制后置 B2。

### 3｜为什么球旁器偏皮质肾单位

按本节 Study，球旁器主要分布在皮质肾单位，因为皮质肾单位含肾素较多，近髓肾单位几乎不含肾素。

### 4｜致密斑的角色

```text
远曲小管起始部NaCl变化
→ 致密斑感受
→ 信息传给球旁细胞 / 球外系膜细胞
→ 调节肾素与肾小球血流动力学
→ 管球反馈
```

（易混：致密斑读的是**流到远曲小管的 NaCl 信号**，不是直接测全身血钠浓度。）

# 4｜肾单位与两类肾单位分工

<!-- kianos:kp id="urinary-b01-kp04" -->

## KP04｜从血管到小管：滤过、重吸收、分泌和排泄的方向

> **讲义定位 →** 生理 Lecture PDF P258–259｜尿生成和排出的基本功能单位。  
> **主提示**：肾单位顺序｜近/远定义｜血管串联｜4过程方向

### 1｜小管结构顺序

```text
肾小囊
→ 近曲小管
→ 髓袢降支粗段
→ 髓袢降支细段
→ 髓袢升支细段
→ 髓袢升支粗段
→ 远曲小管
→ 集合管
```

按 Study：

```text
近端小管
= 近曲小管 + 髓袢降支粗段

远端小管
= 髓袢升支粗段 + 远曲小管
```

### 2｜血管顺序

```text
肾动脉分支
→ 入球小动脉
→ 肾小球毛细血管
→ 出球小动脉
→ 管周毛细血管 / 直小血管
→ 肾静脉系统
```

肾小球毛细血管负责滤过；出球小动脉之后形成的管周毛细血管 / 直小血管接收重吸收回来的物质，并为分泌提供血液侧来源。

### 3｜四个方向必须分清

| 过程 | 方向 | 终点 |
|---|---|---|
| 滤过 | 肾小球毛细血管 → 肾小囊 | 原尿 |
| 重吸收 | 小管液 → 小管上皮 → 管周血液 | 回到体内 |
| 分泌 | 管周血液 / 小管上皮 → 小管液 | 加入尿液 |
| 排泄 | 终尿 → 体外 | 真正离开机体 |

> 判断一个物质尿中排出多少，不能只看“滤过了多少”，还要看后续重吸收与分泌。

### 4｜一个最小物质量关系

```text
排泄量
= 滤过量
− 重吸收量
+ 分泌量
```

本节 Study 主要用清除率的相对大小来判断这三种小管处理方向；分段转运细节后置 B3。

## KP05｜皮质肾单位 vs 近髓肾单位：滤过效率与浓缩能力的结构分工

> **讲义定位 →** 生理 Lecture PDF P259｜两类肾单位。  
> **主提示**：皮质 vs 近髓：7轴｜直小血管归谁

| 比较轴 | 皮质肾单位 | 近髓肾单位 |
|---|---|---|
| 肾小体位置 | 外皮质层 / 皮质外 2/3 | 靠近髓质的内皮质层 |
| 数量 | 多 | 少 |
| 肾小球 | 较小 | 较大 |
| 髓袢 | 短，不入髓质或只到外髓 | 长，可深入内髓，部分达乳头 |
| 入 / 出球口径 | 入球明显大于出球，Study约 2:1 | 两者口径无明显差异 |
| 出球后血管 | 以管周毛细血管网为主 | 管周毛细血管 + U形直小血管 |
| 主要优势 | 高肾小球压利于滤过；管周高胶渗压利于重吸收 | 直小血管与长髓袢维持髓质高渗、支持浓缩稀释 |

### 1｜为什么皮质肾单位利于滤过与重吸收

```text
入球口径 > 出球口径
→ 肾小球毛细血管压较高
→ 利于滤过

水被滤出、蛋白多被保留
→ 出球后管周毛细血管胶体渗透压较高
→ 利于重吸收
```

### 2｜为什么近髓肾单位是浓缩能力的结构基础

```text
长髓袢深入髓质
+ U形直小血管与髓袢并行
→ 有利于维持髓质间质高渗
→ 为尿浓缩 / 稀释提供空间基础
```

完整逆流倍增、逆流交换与尿素循环后置 B4。

（易混：肾小球无论属于哪类肾单位，都位于皮质；“近髓”是靠近髓质，不是肾小球位于髓质。）

# 5｜肾清除率：把方向变成可测量的数值

<!-- kianos:kp id="urinary-b01-kp06" -->

## KP06｜清除率概念：不是“清掉百分之几”，而是等效清空多少毫升血浆

> **讲义定位 →** 生理 Lecture PDF P260｜肾清除率。  
> **主提示**：定义｜单位｜为何是等效值｜滤过 vs 清除终点

### 1｜概念

肾清除率表示：

> 双肾每分钟把某物质排到终尿中的量，相当于把多少毫升血浆中的该物质完全清除。

所以清除率单位通常是：

```text
mL/min
```

它是一个**等效血浆容积**，不是比例。

### 2｜为什么是推算值

真实肾脏并不是把某一小管血浆“完全抽干”，而是从持续流动的大量血浆中排出一定量物质。清除率把尿中排出的量反算为：

```text
这些排出量
相当于来自多少mL血浆中的该物质
```

### 3｜滤过 vs 清除

```text
滤过
血浆 → 原尿

清除
血浆中的物质最终 → 终尿
```

同一物质若滤过后又被重吸收，清除量会小于滤过量；若又被分泌，清除量会大于滤过量。

## KP07｜清除率指纹：菊粉、肌酐、PAH、葡萄糖和“不滤过物”

> **讲义定位 →** 生理 Lecture PDF P260–261｜常考物质的清除率。  
> **主提示**：C=0/GFR/RPF/>/<｜菊粉 vs 肌酐｜PAH边界｜葡萄糖例外

### 1｜两种“清除率为 0”必须分开

#### A. 根本不进入原尿

血细胞和多数血浆蛋白不能被肾小球滤过，也不存在小管重吸收 / 分泌这一过程：

```text
不滤过
→ 不进入小管液
→ 尿中没有
→ 清除率为0
```

#### B. 滤过后被全部重吸收

在未超过重吸收能力时，葡萄糖可滤过，但被近端小管全部重吸收：

```text
滤过
→ 完全重吸收
→ 终尿中为0
→ 清除率为0
```

（易混：两者最终都可 C=0，但一个是“从未进入原尿”，另一个是“进入后又全部拿回”。）

### 2｜菊粉：最准确测 GFR

```text
可自由滤过
不重吸收
不分泌
→ 排泄量 = 滤过量
→ C菊粉 = GFR
```

### 3｜内生肌酐：更常用，但近似 GFR

按 Study：内生肌酐来自体内组织代谢，操作方便，数值上可大致评估 GFR；但小管可有少量分泌 / 重吸收接口，因此不如菊粉准确。

测定前需要避免肉类摄入和剧烈运动对肌酐生成的影响。

```text
菊粉：更准确
内生肌酐：更常用
```

### 4｜PAH / 碘锐特：近似有效肾血浆流量

理想模型：

```text
可滤过
+ 小管强烈分泌
+ 不重吸收
→ 流经肾单位的PAH几乎全部进入终尿
→ 肾静脉浓度接近0
→ CPAH ≈ 有效肾血浆流量 ERPF
```

Study 同时说明：实际肾脏并非所有血浆都流经有清除能力的肾单位，提取率可按约 90% 修正，因此 PAH 清除率代表的是**有效**肾血浆流量，实际 RPF 还需按提取率校正。

### 5｜用 C 与 GFR 判断净处理方向

```text
C = GFR
→ 无净重吸收、无净分泌

C > GFR
→ 一定存在净分泌
（可以同时有重吸收，但分泌量更大）

C < GFR
→ 一定存在净重吸收
（可以同时有分泌，但重吸收量更大）
```

### 6｜Study 对葡萄糖“最大重吸收率”的口径

按本节 Study，葡萄糖被作为近端小管最大重吸收能力的代表；在血糖未超过重吸收能力时可被全部重吸收，清除率为 0。真正的葡萄糖阈、Tm 和糖尿机制后置 B3。

## KP08｜四个计算：清除率、RPF、RBF 与 FF

> **讲义定位 →** 生理 Lecture PDF P261｜清除率相关计算。  
> **主提示**：4公式｜PAH修正｜RPF→RBF｜FF｜尿量3阈值

### 1｜清除率公式

```text
Cx = Ux × V / Px
```

- `Ux`：尿中某物质浓度；
- `V`：每分钟尿量；
- `Px`：血浆中该物质浓度。

感性推导：

```text
清除率 × 血浆浓度
= 每分钟终尿量 × 尿中浓度
```

口诀可以保留为 Study 的“尿尿除血清”，但理解必须回到**量 = 浓度 × 容积**。

### 2｜有效 RPF 与实际 RPF

```text
ERPF ≈ CPAH
```

若 PAH 提取率为 90%：

```text
RPF = CPAH / 0.90
```

### 3｜RBF 与 HCT

血细胞比容 HCT 是血细胞占全血体积的比例，因此：

```text
血浆比例 = 1 − HCT

RBF = RPF / (1 − HCT)
```

（易混：RPF 是血浆流量；RBF 是全血流量，必须把血细胞部分补回来。）

### 4｜滤过分数 FF

```text
FF = GFR / RPF
```

它表示流经肾脏的血浆中，有多大比例经肾小球形成原尿。按 Study 例题约为 19%。

本节还保留：

- 肾小球肾炎：FF 下降；
- 心衰：FF 升高。

完整病理解释分别后置肾小球疾病与心衰 / 心肾接口。

### 5｜尿量门槛

按 Study：

```text
每天约35g代谢终产物
溶解度约7g/100mL
→ 每天尿量不应少于约500mL
```

- 24 小时尿量 `<400 mL`：少尿；
- 24 小时尿量 `<100 mL`：无尿。

这些数值进入 MI-D，但少尿 / 无尿身份是后续 AKI 的高频入口。

## KP09｜自由水清除率：肾小管是在保纯水，还是排纯水

> **讲义定位 →** 生理 Lecture PDF P261｜无溶质水清除率。  
> **主提示**：CH₂O意义｜高/低渗尿正负｜浓缩差时方向

### 1｜它测的不是溶质清除，而是“纯水”方向

按本节 Study，自由水清除率 `CH₂O` 反映小管保留水的能力。

### 2｜高渗尿

```text
尿液高渗
→ 肾小管 / 集合管重吸收了较多水
→ 纯水被保留在体内
→ CH₂O 为负值
```

### 3｜低渗尿

```text
尿液低渗
→ 较多纯水留在小管并被排出
→ CH₂O 为正值
```

若小管浓缩功能减退，保水能力下降，更多自由水被清除：

```text
CH₂O 正值增大
```

完整浓缩 / 稀释机制、髓质高渗与 ADH 后置 B4；本处只建立测量语言。

# 6｜肾血流的全身调节与自身调节

## KP10｜肾血流的神经与体液调节：先分“血管方向”和“肾素方向”

> **讲义定位 →** 生理 Lecture PDF P262｜肾血流量调节。  
> **主提示**：交感2出口｜缩/舒血管组｜肾素↑/↓｜NSAID链｜腺苷肾/冠

### 1｜交感的两个出口

```text
交感 → 肾血管 α₁受体
→ 肾血管收缩、肾血流下降

交感 → 球旁细胞 β₁受体
→ 肾素释放增加
→ RAAS激活
```

（易混：同一个 NA / Adr 可以同时通过 α₁ 收缩肾血管、通过 β₁ 增加肾素。不要把两个作用轴合成一个结论。）

### 2｜肾血管舒缩表

| 肾血管方向 | Study 物质 |
|---|---|
| 收缩 | NA、Adr、AngⅡ、大剂量 VP、ET、腺苷 |
| 舒张 | NO、ANP、缓激肽、PGE₂、PGI₂、小剂量多巴胺 |

（特殊：腺苷在冠脉是舒张物质，在肾血管按本节 Study 为收缩物质，服务于血流重新分配。）

### 3｜肾素方向不能从血管方向机械反推

按 Study：

```text
肾素↑
NA / Adr（β₁）
缓激肽
PGE₂ / PGI₂
小剂量多巴胺

肾素↓
AngⅡ
大剂量VP
ET
NO
ANP
```

注意：

- 缓激肽、PG、小剂量多巴胺既舒张肾血管，又使肾素↑；
- NO、ANP也舒张肾血管，但使肾素↓；
- 所以“舒张肾血管”不能推出统一的肾素方向。

### 4｜NSAID为什么可使肾血流下降

```text
NSAID
→ 抑制前列腺素合成
→ 失去PGE₂ / PGI₂的肾血管舒张保护
→ 肾血流下降
→ 可出现肾衰接口
```

完整药物性 AKI 后置 B7。

## KP11｜肌源性自身调节：灌注压升高时，入球动脉主动收缩

> **讲义定位 →** 生理 Lecture PDF P262｜自身调节。  
> **主提示**：自身调节范围｜肌源链｜越界｜稳定2指标

### 1｜Study 的压力范围

本节主口径：

```text
肾动脉灌注压 / MAP 约 70–180 mmHg
→ RBF 与 GFR 相对稳定
```

Study 同时提示不同教材 / 版本也可见 `80–180` 或 `80–160 mmHg`。这些精确边界属于 MI-D；主机制是“存在一个自身调节平台”。

### 2｜肌源性链

```text
入球动脉灌注压↑
→ 管壁牵张↑
→ 平滑肌机械门控Ca²⁺通道开放
→ Ca²⁺内流
→ 入球小动脉收缩
→ 管径↓、阻力↑
→ RBF不随灌注压等比例上升
→ GFR相对稳定
```

若灌注压下降，则入球动脉舒张，方向相反。

### 3｜为什么超出平台后不再稳定

```text
MAP > 上限
→ 入球动脉已接近收缩极限
→ 继续升压会使RBF / GFR上升

MAP < 下限
→ 入球动脉已接近舒张极限
→ 继续降压会使RBF / GFR下降
```

（易混：自身调节不是让 RBF / GFR 在任何血压下恒定，而是只在有限压力窗口内缓冲。）

## KP12｜管球反馈：致密斑用 NaCl 把单肾单位 GFR 拉回合适范围

> **讲义定位 →** 生理 Lecture PDF P262–263｜管球反馈与肾动脉狭窄。  
> **讲义回看 →** KP03 球旁器。  
> **主提示**：致密斑读什么｜NaCl高/低两条链｜入球张力｜GFR方向｜低NaCl何时接肾素

### 1｜先分清两个相连但不等价的动作

```text
快速 TGF 执行端
致密斑 NaCl
→ 入球小动脉张力
→ 单肾单位肾血流 / GFR

低 NaCl 的额外 handoff
致密斑 / JGA
→ 肾素
→ RAAS
```

所以管球反馈不能被压缩成“致密斑 → 肾素 → AngⅡ → GFR”；**入球小动脉的局部负反馈本身就是核心执行端。**

### 2｜远端 NaCl 增多：把过高滤过负荷往回压

```text
到达致密斑的 NaCl ↑
→ TGF 收缩信号增强
→ 入球小动脉收缩 / 阻力↑
→ 单肾单位肾血流与 GFR ↓
→ 肾素释放受抑
```

这条链负责把“滤得太多、送到远端太多”的状态往正常方向拉回。

### 3｜远端 NaCl 减少：放松入球，并接入肾素 / RAAS

```text
肾灌注↓
或近端 Na⁺耦联重吸收↑
→ 到达致密斑的 NaCl ↓
→ 入球侧 TGF 收缩信号减弱
→ 入球相对舒张
→ 支持恢复单肾单位肾血流 / GFR
同时
→ 球旁器肾素释放↑
→ AngⅡ等进入较慢的保灌注 / 保容量调节
```

按本节 Study 的 AngⅡ浓度边界：

```text
AngⅡ浓度较低
→ 主要收缩出球小动脉
→ 维持肾小球毛细血管压与GFR

AngⅡ浓度很高（如大失血）
→ 入球小动脉也明显收缩 / Study强调主要收缩入球
→ RBF与GFR进一步下降
→ 血流重新分配给心脑
→ 肾前性AKI接口
```

### 4｜双肾动脉狭窄与 ACEI / ARB：低灌注 handoff 的临床应用

```text
双肾动脉狭窄
→ 入球前灌注下降
→ 肾小球毛细血管压下降
→ GFR下降
→ RAAS激活
→ AngⅡ选择性收缩出球小动脉
→ 尽量维持肾小球内压和GFR
```

若使用 ACEI / ARB：

```text
AngⅡ效应被阻断
→ 出球小动脉舒张
→ 肾小球毛细血管压进一步下降
→ GFR显著下降
→ 可诱发肾衰
```

所以按本节 Study，双肾动脉狭窄不宜使用 ACEI / ARB。

（易混：ACEI / ARB 的关键肾小球效应是**舒张出球小动脉**，不是简单“扩血管所以肾血流一定更好”。）

### 5｜管球反馈 vs 球管平衡

```text
管球反馈 TGF
远端致密斑读 NaCl
→ 反向调入球张力 / GFR

球管平衡
近端重吸收随滤过负荷按比例变化
→ 稳定近端 Na⁺和水回收
```

第一轮必须掌握的是双向 NaCl 传感 → 入球张力 / GFR，以及低 NaCl → 肾素这一 handoff；ATP、腺苷、PGE₂、NO 等完整旁分泌细节不在这里展开。

# 7｜排尿反射：先完成正常初见，后续疾病只调用

<!-- kianos:kp id="urinary-b01-kp14" -->

## KP14｜正常排尿反射：脊髓可完成，但受高级中枢控制

> **讲义定位 →** 生理 Lecture PDF P263｜排尿反射。  
> **主提示**：刺激｜感受-传入-中枢-传出-效应｜括约肌2｜正反馈｜儿童｜数字

### 1｜反射层级

排尿反射是一种脊髓反射，基本中枢位于骶髓；正常情况下又受脑干与大脑皮层高级中枢控制，可以有意识地抑制或加强排尿。

### 2｜触发与主链

Study 强调排尿反射的主要触发因素是膀胱内压升高：

```text
膀胱充盈
→ 膀胱壁牵张感受器兴奋
→ 冲动沿盆神经传入
→ 骶髓初级排尿中枢
+ 上行至脑干 / 大脑皮层产生尿意
→ 冲动沿盆神经传出
→ 逼尿肌收缩
→ 尿道内括约肌舒张
→ 尿进入后尿道
→ 后尿道刺激进一步加强排尿中枢
→ 外括约肌开放
→ 膀胱排空
```

尿液刺激后尿道后再次加强排尿中枢，形成正反馈，直到膀胱排空。

### 3｜Study 数字

- 膀胱一般可在较低压力下容纳尿液，Study写膀胱内压常保持在约 `10 cmH₂O`以下；
- 内压约 `35 cmH₂O`时逼尿肌出现节律性收缩、尿意明显，但仍可控制；
- 内压约 `70 cmH₂O`以上出现明显痛感，迫使排尿；
- 尿量约 `400–500 mL`或以上可明显刺激牵张感受器。

这些精确数字属于 MI-D；主线是“充盈—牵张—骶髓—正反馈排空”。

### 4｜儿童为何排尿频繁

```text
儿童大脑高级中枢发育不完善
→ 对骶髓排尿中枢的抑制控制较弱
→ 排尿反射更容易释放
→ 排尿较频繁
```

## KP15｜排尿神经损伤：传入、传出、骶髓和高位脊髓四层定位

> **讲义定位 →** 生理 Lecture PDF P264｜排尿反射损伤。  
> **主提示**：4损伤层｜急性/恢复｜无张力→尿潴留→充溢性

### 1｜传入神经受损

```text
膀胱充盈信号不能有效传入
→ 膀胱充盈时不能正常引起反射性张力增加
→ 无张力膀胱
→ 膀胱过度充盈
→ 充溢性尿失禁
```

### 2｜传出神经或骶髓受损

```text
排尿反射弧的效应通路 / 基本中枢受损
→ 逼尿肌不能正常收缩
→ 尿潴留
```

### 3｜高位脊髓受损

基本骶髓反射弧没有被直接破坏，但突然失去高级中枢控制。

#### 脊休克期间

```text
排尿反射暂时消失
→ 尿潴留
→ 膀胱过度充盈时可出现溢流 / 充溢性尿失禁
```

Study 正文同时写“尿潴留”，并提示教材可表述为溢流性尿失禁；两者是同一急性期链条的不同表现层。

#### 脊休克之后

```text
骶髓排尿反射恢复
但失去高级中枢控制
→ 一有充盈就反射性排尿
→ 尿失禁
```

（易混：高位脊髓损伤后期不是反射弧消失，而是**反射恢复但脱离高级控制**。）

完整尿失禁类型、神经源性膀胱、BPH和梗阻后置 B12。

# 8｜四张 Discrimination Map

## 8.1 滤过、重吸收、分泌、清除

```text
滤过：血浆 → 原尿
重吸收：小管液 → 血液
分泌：血液 / 小管细胞 → 小管液
排泄：终尿 → 体外
清除率：尿中排出的量等效来自多少mL血浆
```

## 8.2 GFR、RPF、RBF、FF

```text
GFR
每分钟双肾生成多少原尿

RPF
每分钟流经肾脏的血浆量

RBF
每分钟流经肾脏的全血量

FF
GFR / RPF
= 血浆中被滤过的比例
```

## 8.3 皮质 vs 近髓肾单位

```text
皮质肾单位
数量多、髓袢短、入球>出球
→ 滤过与重吸收主力

近髓肾单位
数量少、髓袢长、直小血管
→ 维持髓质高渗与浓缩基础
```

## 8.4 排尿障碍定位

```text
传入坏
→ 感受不到充盈
→ 无张力膀胱 / 充溢性尿失禁

传出或骶髓坏
→ 逼尿肌不能有效收缩
→ 尿潴留

高位脊髓急性期
→ 脊休克、反射暂消失
→ 尿潴留 / 溢流

高位脊髓恢复后
→ 骶髓反射恢复但无高级控制
→ 反射性尿失禁
```

# 9｜Memory Routing

## 9.1 Mechanism Spine｜第一轮必须闭卷恢复

```text
高肾血流
→ 肾小球滤过
→ 小管 / 集合管重吸收与分泌
→ 终尿

不同小管处理
→ 不同清除率
→ 反推GFR、RPF、RBF与小管方向

远端NaCl高/低
→ 致密斑
→ 入球张力反向调节GFR
低NaCl额外接入肾素 / RAAS
→ RBF / GFR相对稳定或失代偿
```

## 9.2 MI-G｜会阻断 B2–B14，必须即时掌握

1. 肾单位 = 肾小体 + 肾小管；不含集合管；
2. 滤过、重吸收、分泌、排泄四个方向；
3. 入球—肾小球—出球—管周 / 直小血管顺序；
4. 皮质与近髓肾单位分工；
5. 球旁器三组成；
6. 肾素、EPO、1α-羟化酶的来源与接口；
7. 清除率不是比例；
8. 菊粉 = 准确 GFR，肌酐 = 常用近似 GFR，PAH ≈ ERPF；
9. `C>GFR` 净分泌，`C<GFR` 净重吸收；
10. `FF=GFR/RPF`，`RBF=RPF/(1-HCT)`；
11. 交感 α₁收缩肾血管、β₁促肾素；
12. 肌源性自身调节；
13. TGF：远端 NaCl↑ → 入球收缩/GFR↓；远端 NaCl↓ → 入球收缩信号减弱并促进肾素；
14. 低浓度 AngⅡ偏出球、高浓度可收缩入球；
15. 双肾动脉狭窄依赖出球收缩维持 GFR；
16. 排尿反射基本中枢在骶髓并受高级控制。

## 9.3 MI-D｜归位后进入 MarginNote 3

- 肾血流量约 1200 mL/min；
- 皮质 / 近髓肾单位全部比例与尺寸；
- 尿量 500 / 400 / 100 mL；
- PAH 90%提取率计算；
- FF约19%；
- 自由水清除率全部变式；
- 肾血管活性物质完整名单；
- 肾素↑ / ↓完整名单；
- 自身调节 70–180、80–180、80–160 mmHg不同口径；
- 排尿反射 10 / 35 / 70 cmH₂O及400–500 mL；
- 低频内分泌灭活与药物细节。
