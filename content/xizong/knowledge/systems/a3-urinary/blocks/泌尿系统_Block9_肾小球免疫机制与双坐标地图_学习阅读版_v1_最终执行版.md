# K9｜肾小球免疫机制与“双坐标”地图
## 先用临床综合征判断患者正在怎样坏，再用 LM / IF / EM 判断肾小球究竟在哪里坏

> **中心问题**：肾小球病为什么不能只背“肾炎 / 肾病”；怎样同时使用“临床综合征坐标”和“病理证据坐标”，把免疫机制、沉积位置、尿液表现与后续疾病分支接在一起？
>
> **Primary Study**：`内科学讲义_AI阅读版.md` P157–160。当前 Project 没有独立肾脏病理 Lecture，因此内科这一连续范围同时承担肾小球疾病的临床与病理联合真相层。
>
> **Primary Outline**：内科 U065 全部 18 题；U066 中高脂血症与隐匿性肾炎 3 题；U069 病例总入口 2 题；U070“间断水肿”1题，共 **24 / 24**。
>
> **边界**：K9只建立共同坐标和证据语言。急性、急进、IgA与慢性肾炎完整模型进入 K10；肾病综合征及 MCD、膜性、MsPGN、MPGN、FSGS进入 K11；SLE、ANCA血管炎和过敏性紫癜的全身模型后置免疫系统。

## 两套坐标不能互相替代

```text
临床综合征坐标
= 患者当前以什么方式失控

病理类型坐标
= 肾小球哪一层、哪种细胞或结构发生了什么改变
```

同一病理类型可呈不同临床综合征；同一临床综合征也可由不同病理类型造成。

1. 原发 / 继发 / 遗传三类；
2. 肾穿刺活检是明确病理类型的金标准；

6. 系膜、内皮下、上皮下、致密层四个沉积位置；

# 3｜KP Active Recall

<!-- kianos:kp id="urinary-b09-kp01" -->
## KP01｜三类病因身份：原发、继发、遗传

> **主提示：3类｜各定义｜代表1｜男性方向｜起点边界**

### 快速核对

- **原发性**：起始于肾小球，或当前病因不清；Study提示男性多见；
- **继发性**：全身性疾病导致肾小球损害，如糖尿病肾病、狼疮性肾炎、显微镜下多血管炎；
- **遗传性**：如 Alport 综合征。

这套分类回答“病从哪里来”，不回答当前患者呈肾炎还是肾病，也不直接等同某一 LM / IF / EM。

---

<!-- kianos:kp id="urinary-b09-kp02" -->
## KP02｜肾穿刺活检：为什么它是金标准

> **主提示：金标准1｜回答3层｜什么时候不靠症状｜风险边界**

### 快速核对

肾穿刺活检能够直接提供：

```text
LM
+ IF
+ EM
→ 明确病理类型、损伤空间和免疫模式
```

症状、尿检和肾功能只能证明“肾小球正在漏或滤不过”；不能稳定区分所有病理类型。

（边界：首选检查可以有很多；“明确病理类型的金标准”是肾穿刺活检。）

---

<!-- kianos:kp id="urinary-b09-kp03" -->
## KP03｜真正损伤肾小球的不是“免疫复合物本身”

> **主提示：复合物→补体/WBC｜损伤对象｜尿2类｜GFR链**

### 快速核对

```text
抗原—抗体复合物形成或沉积
→ 激活补体和白细胞
→ 炎症效应在清除复合物时损伤肾小球固有结构
→ 屏障受损：血尿、蛋白尿
→ 毛细血管袢狭窄 / 闭塞：GFR下降
```

这里的核心不是“有沉积就自动损伤”，而是沉积触发的效应系统造成组织伤害。

---

<!-- kianos:kp id="urinary-b09-kp04" -->
## KP04｜细胞免疫的特殊入口：MCD

> **主提示：特殊1｜T还是B｜有无复合物｜屏障哪层｜后续K11**

### 快速核对

当前 Study 将微小病变性肾病作为特殊：

```text
T细胞相关细胞免疫
→ 不形成典型抗原抗体复合物
→ IF无特异沉积
→ EM见足突融合
→ 主要进入选择性蛋白尿 / 肾病综合征
```

完整 MCD 模型在 K11。

---

<!-- kianos:kp id="urinary-b09-kp05" -->
## KP05｜原位 vs 循环免疫复合物：差别在“在哪里形成”

> **主提示：形成地2｜固有抗原｜血中形成｜为何易沉积｜代表各2**

### 快速核对

```text
原位免疫复合物
抗体进入肾小球
→ 与肾小球固有抗原在原位结合

循环免疫复合物
先在血液循环中形成
→ 随血流进入肾小球并沉积
```

当前 Study 用肾小球高压、高流量解释循环复合物为何容易沉积。

代表入口：

- 原位：抗足突膜方向的膜性肾病；抗GBM方向的Ⅰ型急进性肾炎；
- 循环：急性肾炎、Ⅱ型急进性肾炎、Ⅰ型MPGN等。

---

<!-- kianos:kp id="urinary-b09-kp06" -->
## KP06｜三条急进性免疫入口：抗GBM、免疫复合物、ANCA

> **主提示：I/II/III｜抗体/复合物｜IF3形态｜EM有无｜完整分支→K10**

### 快速核对

| 入口 | 核心证据 | IF | EM沉积 |
|---|---|---|---|
| 抗GBM | 抗GBM抗体 | 线状 | 当前Study：无典型电子致密物 |
| 免疫复合物 | 原位或循环复合物 | 颗粒状 | 有 |
| ANCA相关 | 免疫反应缺乏 / pauci-immune | 阴性或极弱 | 无 |

完整Ⅰ、Ⅱ、Ⅲ型与治疗进入 K10。

---

<!-- kianos:kp id="urinary-b09-kp07" -->
## KP07｜四个沉积位置：先在空间上放对

> **主提示：系膜｜内皮下｜上皮下｜致密层｜相邻结构**

### 快速核对

- **系膜区**：毛细血管袢之间，未被GBM完整包围；
- **内皮下**：毛细血管内皮与GBM之间；
- **上皮下**：GBM与肾小囊脏层足细胞之间；
- **致密层**：GBM自身结构内。

空间位置会影响炎症细胞接近程度、病理形态和临床表现，但本 Block不从外部知识扩写沉积位置的完整现代分类。

---

<!-- kianos:kp id="urinary-b09-kp08" -->
## KP08｜LM / IF / EM：三种检查各回答一个层级

> **主提示：LM看4｜IF看2｜EM看3｜不能互相替代**

### 快速核对

```text
LM
→ 细胞增生、基质、基膜、硬化、新月体、大体结构

IF
→ 免疫球蛋白 / 补体是否沉积，以及线状、颗粒或阴性

EM
→ 电子致密物位置、足突融合、GBM超微结构
```

不能用“光镜基本正常”推断电镜也正常；MCD正是典型反例。

---

<!-- kianos:kp id="urinary-b09-kp09" -->
## KP09｜IF三大识别方向

> **主提示：线1｜颗粒多数｜无2｜（易混：无荧光≠无病变）**

### 快速核对

- **线状**：Ⅰ型急进性肾炎 / 抗GBM方向；
- **颗粒状**：多数免疫复合物性肾小球病；
- **无荧光或极弱**：MCD、Ⅲ型急进性肾炎方向。

无荧光不等于肾小球没有病变，而是当前方法下没有典型免疫沉积。

---

<!-- kianos:kp id="urinary-b09-kp10" -->
## KP10｜五类临床综合征：只选这五个

> **主提示：急性｜急进｜慢性｜隐匿｜肾病｜病理名不能混入**

### 快速核对

当前 Study 的临床分型：

1. 急性肾小球肾炎；
2. 急进性肾小球肾炎；
3. 慢性肾小球肾炎；
4. 无症状性血尿和/或蛋白尿；
5. 肾病综合征。

“毛细血管内增生性肾炎”“膜性肾病”等属于病理类型或疾病身份，不能直接塞进临床分型答案。

---

<!-- kianos:kp id="urinary-b09-kp11" -->
## KP11｜急性肾炎综合征：血尿必备且突出

> **主提示：4表现｜必备1｜水肿起点｜高血压机制｜肾功能接口**

### 快速核对

```text
血尿：必备且突出
蛋白尿：轻中度为主，也可更重
水肿：多从眼睑、颜面开始
高血压：GFR下降后的水钠潴留，容量依赖
```

可伴少尿、Cr / BUN升高及贫血。完整急性、急进疾病分支在 K10。

---

<!-- kianos:kp id="urinary-b09-kp12" -->
## KP12｜慢性肾炎综合征：同一四联迁延超过3个月

> **主提示：时间1｜四联｜多尿夜尿链｜后期功能｜完整模型→K10**

### 快速核对

```text
血尿 + 蛋白尿 + 水肿 + 高血压
持续 / 迁延 >3个月
→ 慢性肾炎综合征
```

部分肾小球损害后，残存肾单位高负荷过滤，小管来不及充分重吸收水，可出现多尿、夜尿、低比重尿；后期再进入尿量下降、Cr / BUN升高和贫血。

---

<!-- kianos:kp id="urinary-b09-kp13" -->
## KP13｜肾病综合征：两项必备 + 两项常见

> **主提示：4联｜必备2｜3.5/30｜水肿主轴｜高脂2机制｜完整模型→K11**

### 快速核对

1. 大量蛋白尿：`>3.5 g/d`；
2. 低蛋白血症：白蛋白 `<30 g/L`；
3. 明显水肿；
4. 高脂血症。

前两项是当前 Study 的必备条件。完整并发症、治疗和病理类型进入 K11。

---

<!-- kianos:kp id="urinary-b09-kp14" -->
## KP14｜肾炎性 vs 肾病性水肿：一个“憋住”，一个“锁不住”

> **主提示：主机制2｜起始部位｜RAAS方向｜血容量方向｜间断水肿2病**

### 快速核对

| 轴 | 肾炎性水肿 | 肾病性水肿 |
|---|---|---|
| 主机制 | GFR下降，水钠潴留 | 大量蛋白丢失，胶体渗透压下降 |
| 起始 | 多从眼睑颜面 | 可从下肢，也可见眼睑颜面 |
| 有效循环量 | 容量增加方向 | 下降方向 |
| RAAS | 当前Study：抑制方向 | 激活方向 |

“间断水肿”可进入慢性肾炎或肾病综合征候选，不能只凭水肿部位锁定疾病。

---

<!-- kianos:kp id="urinary-b09-kp15" -->
## KP15｜无症状性血尿和/或蛋白尿：三无 + 一种或两种尿异常

> **主提示：三无｜尿异常3组合｜治疗2不做｜随访**

### 快速核对

```text
无水肿
+ 无高血压
+ 无肾功能损害
+ 仅肾小球源性血尿
  或仅蛋白尿
  或血尿+蛋白尿
→ 无症状性血尿和/或蛋白尿
```

当前 Study：定期随访，不用糖皮质激素和免疫抑制剂。

（易混：无症状细菌尿有真性细菌尿，属于K8；隐匿性肾炎是肾小球源性尿异常。）

---

<!-- kianos:kp id="urinary-b09-kp16" -->
## KP16｜“炎”与系膜区：当前 Study 的病例识别语言

> **主提示：系膜参与｜炎细胞/增生｜基膜损伤｜血尿方向｜边界**

### 快速核对

当前 Lecture 用“病变累及系膜区、细胞与基质增生、较多炎症成分参与”帮助解释为何名字中带“炎”的疾病常伴血尿。

这是 Study 的识别语言，不应被机械扩成：

```text
所有带“炎”都一定血尿
所有不带“炎”都一定无血尿
```

膜性肾病等仍可有镜下血尿；临床与病理必须回双坐标。

---

<!-- kianos:kp id="urinary-b09-kp17" -->
## KP17｜局灶 / 弥漫，节段 / 球性：病变范围有两层

> **主提示：局灶/弥漫看哪一层｜节段/球性看哪一层｜分类阈值？｜FSGS接口**

### 快速核对

- 局灶：受累肾小球 `<50%`；相对弥漫；
- 节段：单个肾小球内受累毛细血管袢 `<50%`；相对球性。

这两个词描述不同层级。FSGS完整病理与肾病综合征模型在 K11。

---

<!-- kianos:kp id="urinary-b09-kp18" -->
## KP18｜双坐标病例算法：先临床，后病理，再回病因

> **主提示：症候5选1｜尿证据｜肾功能｜LM/IF/EM｜病因3类｜分支K10/11**

### 快速核对

```text
1. 先判临床综合征
   急性 / 急进 / 慢性 / 隐匿 / 肾病

2. 读尿液与功能
   血尿、蛋白尿、管型、尿量、Cr、BUN

3. 需要时做肾穿刺
   LM / IF / EM

4. 再判免疫与位置
   线状 / 颗粒 / 无荧光
   系膜 / 内皮下 / 上皮下 / 致密层 / 足细胞

5. 最后判病因身份
   原发 / 继发 / 遗传
```

接下来：

- 肾炎分支 → K10；
- 肾病综合征分支 → K11。
