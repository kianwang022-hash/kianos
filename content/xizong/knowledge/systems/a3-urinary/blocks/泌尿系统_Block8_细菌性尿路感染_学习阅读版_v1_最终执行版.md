# Block 8｜细菌性尿路感染
## 学习阅读版 v1｜最终执行版

> **中心问题**：细菌怎样从尿道 / 膀胱向上进入肾盂和肾间质；同样出现尿频、尿急、尿痛和脓尿时，怎样判断感染仍局限于膀胱，还是已经进入肾实质；哪些结构或功能异常会把普通尿感变成复杂性尿感；慢性肾盂肾炎为什么首先表现为小管浓缩与分泌功能下降？

# 0｜这个 Block 到底解决什么

尿路感染最容易学成一串：

> “尿频尿急尿痛 → 培养 → 抗生素”。

但真正的判断轴只有两步：

```text
第一步｜感染在哪里？
下尿路：膀胱 / 尿道
上尿路：肾盂 + 肾间质

第二步｜为什么容易上去、为什么容易反复？
正常尿流能冲走细菌
结构 / 功能异常、反流、结石、导尿等
→ 尿液不畅 / 屏障受损 / 逆行机会↑
→ 复杂性尿感
```

然后证据才有意义：

```text
尿频尿急尿痛
→ 说明下尿路刺激

发热 + 肾区叩痛
→ 支持肾实质受累

WBC管型 / NAG↑ / β2-MG↑
→ 进一步把位置拉向肾小管 / 间质

慢性反复感染
→ 小管先坏
→ 浓缩、分泌先下降
→ 后期才可能影响GFR
```

所以本 Block 的核心不是“背菌名”，而是：

> **感染途径 → 位置 → 证据 → 复杂化条件 → 疗程与复发 → 慢性小管损害。**

## 一条总电影

```text
尿道口 / 膀胱定植细菌
→ 多数沿尿路逆行上行
→ 先形成下尿路感染
→ 若尿路反流、梗阻、器械或宿主条件增加风险
→ 细菌更易上达肾盂 / 肾间质
→ 发热、肾区叩痛、WBC管型等提示肾实质受累
→ 先留标本，再立即抗感染
→ 疗程按膀胱炎 / 肾盂肾炎 / 复发升级
→ 反复超过半年
→ 慢性化脓性炎 + 纤维化
→ 肾不对称缩小、肾盂肾盏变形
→ 小管浓缩与分泌功能持续下降
→ 晚期才进入肾小球功能损害
```

# 4｜什么叫复杂性尿感

<!-- kianos:kp id="urinary-b08-kp04" -->

## KP04｜复杂性尿感：感染 + 尿路结构/功能异常或宿主高风险

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：培养阈1｜结构/功能例7｜男性特殊｜复杂为什么危险｜串K12。

当前 Study 写法：

```text
清洁中段尿细菌培养 ≥10万/mL
+ 泌尿系统结构或功能异常 / 易感染基础病
→ 复杂性尿感
```

Study列举：

- 尿路畸形；
- 结石；
- 肿瘤；
- 前列腺肥大；
- 妊娠；
- 膀胱输尿管反流；
- 神经源性膀胱，如糖尿病或截瘫；
- 以及其他易发感染的基础疾病。

Lecture题旁还强调：**男性尿路感染基本应优先按复杂性尿感理解。**

一条逻辑：

```text
尿流不畅 / 反流 / 结构异常 / 器械或宿主风险
→ 细菌更难被冲走
→ 更易上行、复发、形成肾盂肾炎和尿源性脓毒症
```

//串联：K12会完整学习结石、BPH、梗阻、残余尿和肾积水；当前只保留“为什么让感染复杂化”的接口。

# 5｜无症状细菌尿：有菌不等于人人都治

<!-- kianos:kp id="urinary-b08-kp05" -->

## KP05｜无症状细菌尿：无症状 + 两次同菌；只治疗Study指定两类

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：定义3件｜不治疗6类｜治疗2类｜为什么妊娠/手术例外。

### 定义

```text
无临床症状
+ 有真性细菌尿
+ 两次尿菌培养为同一菌种
→ 无症状细菌尿 / 隐匿性尿感
```

### 当前 Study：不需治疗

- 绝经前非妊娠女性；
- 老年人；
- 儿童；
- 糖尿病患者；
- 脊髓损伤者；
- 留置导尿管者。

### 当前 Study：需短程疗法

1. 妊娠；
2. 即将接受可能损伤黏膜的泌尿系统外科手术。

Study对妊娠的解释：

```text
妊娠相关输尿管受压 / 反流风险↑
→ 含菌尿液更容易向上
→ 肾盂肾炎风险↑
```

手术前处理的逻辑：避免带菌尿液在黏膜损伤后造成感染扩散。

> **边界**：以上只代表当前 Lecture 的考试口径，不根据外部最新指南静默修改特殊人群清单。

# 6｜“有感染”怎样被证明

<!-- kianos:kp id="urinary-b08-kp06" -->

## KP06｜亚硝酸盐 + 脓尿：一个筛菌，一个看炎症

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：亚硝酸盐针对谁｜特异/敏感｜成立条件2｜脓尿阈｜血尿/蛋白可否出现。

### 亚硝酸盐还原试验

- 用于筛查；
- G⁻菌阳性；
- **特异性高、敏感性差**。

Study题旁解释其需要：

- 尿中有足够硝酸盐；
- 尿液在膀胱内停留足够时间。

### 尿沉渣

尿感几乎都有：

- 脓尿：WBC >5/HP。

可伴：

- 血尿：RBC >3/HP；
- 蛋白尿：>0.15 g/d。

（易混：脓尿说明尿路炎症明显，但**不能单靠脓尿区分膀胱炎和肾盂肾炎**。）

---

<!-- kianos:kp id="urinary-b08-kp07" -->

## KP07｜真性细菌尿：把“污染”与“真正尿路细菌”分开

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：3种证据｜中段培养阈｜涂片阈｜膀胱穿刺｜vs 单纯脓尿。

Study列三种真性细菌尿证据：

1. 清洁中段尿细菌培养 ≥10万/mL；
2. 清洁中段尿沉渣涂片细菌 >1个/HP；
3. 膀胱穿刺尿细菌培养阳性。

关键不是把三个数字孤立背，而是理解：

> 这些证据在减少“外阴 / 尿道口污染”对判断的干扰。

（易混：尿中 WBC多是炎症证据；真性细菌尿是“细菌确实存在于尿路”的证据。）

# 7｜怎样判断已经进入肾实质

<!-- kianos:kp id="urinary-b08-kp08" -->

## KP08｜肾盂肾炎证据：血里有反应、小管有痕迹

> **讲义定位 →** 内科 Lecture P146；Recall K6管型。  
> **主提示**：血2｜尿管型1｜小管标志2｜培养取样2｜浓缩1｜为什么能定位肾。

Study列更支持肾盂肾炎的证据：

### 全身 / 血液

- 血WBC、CRP↑；
- 血液细菌培养阳性。

### 肾小管 / 尿液

- WBC管型；
- 尿 NAG↑；
- 尿 β₂-MG↑；
- 尿比重、尿渗透压↓。

### 排除膀胱干扰的培养

- 输尿管导尿尿培养阳性；
- 膀胱冲洗后尿培养阳性。

定位逻辑：

```text
WBC管型形成于远端小管 / 集合管
NAG、β2-MG提示小管受累
浓缩功能下降也是小管损伤结果
→ 证据越靠“小管”，越支持感染不只停在膀胱
```

<!-- kianos:kp id="urinary-b08-kp09" -->

## KP09｜急性膀胱炎 vs 急性肾盂肾炎：局部刺激 vs 全身 + 肾区

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：6轴｜刺激征｜全身｜肾区｜菌/脓尿｜WBC管型｜谁可有可无。

| 轴 | 急性膀胱炎 | 急性肾盂肾炎 |
|---|---|---|
| 尿频 / 尿急 / 尿痛 | 有 | 可有可无 |
| T>38、血WBC↑等全身症状 | 无 | 有 |
| 肾区叩痛 | 无 | 有 |
| 真性细菌尿 | 有 | 有 |
| 明显脓尿 | 有 | 有 |
| WBC管型 | 无 | 有 |

为什么肾盂肾炎反而“尿频尿急尿痛可有可无”？

> 感染已经在肾脏，但如果炎症没有明显波及膀胱，下尿路刺激症可以不突出。

因此病例看到“无尿频尿急尿痛”不能机械排除肾盂肾炎；反过来，看到尿频尿急尿痛也不能直接等于膀胱炎，必须继续看**全身症状、肾区叩痛和WBC管型**。

# 8｜治疗第一步：先留标本，但不要等结果才治疗

<!-- kianos:kp id="urinary-b08-kp10" -->

## KP10｜先留尿标本 → 立即经验治疗 → 药敏 / 72h无效再调整

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：先后顺序3步｜为什么先留｜为什么不等｜何时换药。

当前 Study 的操作顺序：

```text
先留取尿细菌检查标本
→ 立即开始经验性抗感染
→ 药敏结果回来后调整
或用药 >72h无效时调整
```

两个目的同时满足：

- **先留标本**：避免抗菌药让培养结果失真；
- **立即治疗**：不能为了等药敏而放任感染继续上行或播散。

# 9｜疗程不是一个数字：看位置、宿主和复发

<!-- kianos:kp id="urinary-b08-kp11" -->

## KP11｜急性膀胱炎：3日 → 7日 → 2周

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：3日谁｜7日5类｜2周触发1｜位置仍在下尿路。

当前 Study：

### 3日短程

- 年轻、未孕女性。

### 7日

- 免疫力低下；
- 糖尿病；
- 老年；
- 妊娠；
- 男性。

### 延长到2周

- 停抗生素7天后复查尿菌培养仍阳性。

这条线的本质是：

> 同样是膀胱炎，宿主风险和细菌是否真正清除会改变疗程。

---

<!-- kianos:kp id="urinary-b08-kp12" -->

## KP12｜急性肾盂肾炎：2周；复发6周；频繁发作可6个月抑菌

> **讲义定位 →** 内科 Lecture P146 + U062。  
> **主提示**：基础疗程｜复发病原关系｜6周边界｜半年内次数｜6月方案｜再感染vs复发。

当前 Study：

- 急性肾盂肾炎：**2周**；
- 复发、病原体与上次完全相同：**6周**；
- 半年内发作 ≥2次：**6个月低剂量抑菌**。

### 复发 vs 再感染｜Outline考试边界

U062要求掌握：

- **停药6周内**再次发生，且为同一菌株：支持复发；
- **停药6周后**，或病原体不同：支持再感染。

这两个概念不要混成“只看时间”或“只看菌种”，考试中要把**时间 + 菌株身份**一起看。

## KP13｜常用抗菌药 + 膀胱炎一线 + 2个特殊禁区

> **讲义定位 →** 内科 Lecture P146。

### 常用类别

# 11｜慢性肾盂肾炎：长期问题首先落在小管

<!-- kianos:kp id="urinary-b08-kp14" -->

## KP14｜慢性肾盂肾炎：>6个月 + 不对称瘢痕肾 + 小管功能持续损害

> **讲义定位 →** 内科 Lecture P147。  
> **主提示**：慢性阈1｜病史可有无｜IVU金标准｜结构3｜小管2功能｜晚期肾小球4证据。

### 慢性定义与病史

- 病程 >6个月；
- 肾区可有叩痛；
- 反复尿菌培养阳性；
- **可有也可没有**明确急性肾盂肾炎病史、尿路刺激症和全身症状。

（特殊：一般炎症常以3个月讨论急慢性；本 Lecture 对肾盂肾炎采用**6个月**边界。）

### 金标准｜IVP / IVU

Study：

- 单侧或双侧**不对称缩小**；
- 肾盂、肾盏变形；
- 缩窄。

这和高血压颗粒性固缩肾的**双肾对称缩小**是高价值易混轴。

### 为什么小管先坏

持续小管功能损害：

1. **浓缩功能下降**：夜尿多、尿比重↓、尿渗透压↓；
2. **分泌功能下降**：肾小管性酸中毒、PSP↓。

晚期才可明显进入肾小球功能损害：

- GFR / Ccr↓；
- Cr、BUN↑；
- 水肿；
- 高血压。

> 这是 K8 与 K7 的关键串联：慢性肾盂肾炎最初是**小管—间质病**，不是一开始就按原发性肾小球病思路理解。

## KP15｜慢性病理身份：化脓性炎 → 纤维化 → “肾小管甲状腺化”

> **讲义定位 →** 内科 Lecture P147题旁与理顺。  
> **主提示**：急/慢炎细胞｜都属哪类炎｜纤维化结果｜甲状腺化3件｜vs肾小球病。

当前 Lecture 补充的病理连续性：

```text
反复细菌感染
→ 化脓性炎
→ 慢性期纤维化
→ 胶原纤维收缩
→ 肾盂肾盏缩窄变形 + 肾实质瘢痕
```

炎细胞：

- 急性：中性粒细胞为主；
- 慢性：淋巴细胞、浆细胞为主；
- 急 / 慢性肾盂肾炎都属于化脓性炎的疾病谱。

### 肾小管“甲状腺化”

慢性期可见：

- 部分肾小管萎缩；
- 部分代偿性扩张；
- 扩张管腔内均质红染胶样管型；
- 形似甲状腺滤泡。

**Routing**：SPECIAL + RECOGNITION + MI-D。

（边界：当前 Project没有独立肾病理 Lecture；本内容只保留内科 Lecture 明确给出的慢性肾盂肾炎形态，不凭一般病理学再扩写一套。）

# 12｜尿道综合征：有刺激征，不等于有普通细菌尿感

<!-- kianos:kp id="urinary-b08-kp16" -->

## KP16｜尿道综合征：刺激征 + 无全身症状 + 无真性细菌尿

> **讲义定位 →** 内科 Lecture P147。  
> **主提示**：3个否/有｜2分类｜脓尿方向｜支原体衣原体边界｜vs膀胱炎。

Study定义：

```text
尿道刺激征
+ 无全身症状
+ 无真性细菌尿
→ 尿道综合征
```

再分：

- 非感染性尿道综合征：**无脓尿**；
- 感染性尿道综合征：支原体 / 衣原体等，**可有脓尿**。

高价值易混：

- 急性膀胱炎：真性细菌尿 + 明显脓尿；
- 尿道综合征：没有普通细菌性真性细菌尿；感染性亚型仍可有脓尿。

完整支原体 / 衣原体与 STI 模型后置感染系统。

<!-- kianos:kp id="urinary-b08-kp17" -->

## KP17｜K8最终病例算法：刺激征→全身→肾区→肾实质证据→复杂化条件

> **主提示**：5步｜膀胱vs肾｜真性菌尿｜复杂化｜慢性小管｜肾结核边界。

```text
1. 有没有尿频、尿急、尿痛？
   有 → 尿路刺激，但不能直接定位膀胱

2. 有没有T>38 / 血WBC↑ / 肾区叩痛？
   有 → 向急性肾盂肾炎倾斜

3. 有没有WBC管型 / NAG↑ / β2-MG↑ / 小管浓缩下降？
   有 → 更支持肾实质受累

4. 有没有结构/功能异常？
   结石、肿瘤、BPH、妊娠、VUR、神经源膀胱、导尿等
   → 复杂性尿感风险↑

5. 是否反复>6个月？
   是 → 看不对称瘢痕肾、IVU变形、小管功能持续损害
```

最后再问：

> 如果是持续膀胱刺激症但普通细菌培养逻辑解释不了，是否要把肾结核留给 K13？

当前只保留这个边界，不提前展开结核。

# 13｜急性肾盂肾炎并发症与尿源性脓毒症

急性肾盂肾炎并不是“发热 + 尿频”的轻型上尿路感染而已，Lecture明确给出三个并发症群：

### 1｜肾乳头坏死

线索：

- 体温再度升高；
- 腰痛剧烈；
- 绞痛：脱落坏死组织堵塞输尿管；
- 血尿。

可伴：

- 败血症；
- 感染性休克；
- AKI。

### 2｜局部化脓并发症

- 肾盂积脓；
- 肾周围脓肿。

### 3｜尿源性脓毒症

Study危险因素：

- **尿路梗阻最常见**；
- 高龄；
- 糖尿病；
- 免疫抑制剂；
- 留置导尿管；
- 泌尿外科手术。

这段是 K8→K12 / 感染系统的重要桥梁：

```text
感染 + 梗阻
→ 不是简单“再加一种抗生素”
→ 尿路源控制与解除梗阻的重要性上升
```

但完整梗阻处理、源控制和脓毒症复苏分别后置 K12 与血液—免疫—感染系统。
