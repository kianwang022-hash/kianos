## 学习阅读版 v1｜最终执行版

# 0｜这个 Block 到底解决什么

尿路感染最容易学成一串：

> “尿频尿急尿痛 → 培养 → 抗生素”。

但真正的判断轴只有两步：

```text
第一步｜感染在哪里？
下尿路：膀胱 / 尿道
上尿路：肾盂 + 肾间质

第二步｜为什么容易上去、为什么容易反复？
正常尿流能冲走细菌
结构 / 功能异常、反流、结石、导尿等
→ 尿液不畅 / 屏障受损 / 逆行机会↑
→ 更难清除、更易上行和复发
```

然后证据才有意义：

```text
尿频尿急尿痛
→ 说明下尿路刺激

发热 + 肾区叩痛
→ 支持肾实质受累

WBC管型 / NAG↑ / β2-MG↑
→ 支持位置向肾小管 / 间质移动
但没有WBC管型也不能单独排除肾盂肾炎

慢性反复感染
→ 小管先坏
→ 浓缩、分泌先下降
→ 后期才可能影响GFR
```

所以本 Block 的核心不是“背菌名”，而是：

> **感染途径 → 位置 → 证据 → 复杂化条件 → 疗程与复发 → 慢性小管损害。**

## 一条总电影

```text
尿道口 / 膀胱定植细菌
→ 多数沿尿路逆行上行
→ 先形成下尿路感染
→ 若尿路反流、梗阻、器械或宿主条件增加风险
→ 细菌更易上达肾盂 / 肾间质
→ 发热、肾区叩痛 + 肾实质支持证据提高上尿路感染概率
→ 先留标本，再立即抗感染
→ 疗程按感染位置、宿主与复发模式调整
→ 长期反复
→ 慢性化脓性炎 + 纤维化
→ 肾不对称瘢痕、肾盂肾盏变形
→ 小管浓缩与分泌功能持续下降
→ 晚期才进入肾小球功能损害
```

# 4｜什么让尿感变复杂

<!-- kianos:kp id="urinary-b08-kp04" -->

## KP04｜复杂化核心：尿流 / 结构 / 反流 / 器械 / 宿主风险；男性归类是Study口径

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：结构/功能例7｜男性Study分类｜为什么危险｜10^5是否定义复杂性的本质｜串K12。

真正的机制核心：

```text
尿流不畅 / 反流 / 结构异常 / 器械 / 宿主高风险
→ 细菌更难被冲走
→ 更易持续、上行、复发和形成系统性感染
```

Study列举：

- 尿路畸形；
- 结石；
- 肿瘤；
- 前列腺肥大；
- 妊娠；
- 膀胱输尿管反流；
- 神经源性膀胱，如糖尿病或截瘫；
- 以及其他易发感染的基础疾病。

### Study-specific 分类

历史 Lecture 把“清洁中段尿培养≥10⁵/mL + 结构/功能异常”写成复杂性尿感，并强调男性尿路感染基本按复杂性理解。306 识别题可保留这个口径。

但 Current Core 不把：

- `10^5` 当成“复杂性”的机制定义；
- “男性”当成现代所有 UTI 分类体系里永久固定的唯一归类。

第一轮真正要掌握的是**为什么这些情境使感染更难清除 / 更危险**。

//串联：K12会完整学习结石、BPH、梗阻、残余尿和肾积水；当前只保留“为什么让感染复杂化”的接口。

# 5｜无症状细菌尿：有菌不等于人人都治

<!-- kianos:kp id="urinary-b08-kp05" -->

## KP05｜无症状细菌尿：先确认“无症状 + 持续菌尿”，再问是否属于高收益治疗人群

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：无症状｜10^5经典阈值｜女性2次/男性1次｜治疗2类｜不治疗常见组。

### 1｜Current定义边界

无症状细菌尿（ASB）的核心是：

```text
没有尿路感染症状
+ 规范留取的尿培养达到ASB菌落计数标准
→ ASB
```

经典清洁中段尿阈值仍是 **≥10⁵ CFU/mL**。

为确认持续菌尿：

- 女性：通常要求 **2份连续清洁中段尿**检出同一菌种 / 相符菌量；
- 男性：**1份**合格清洁中段尿即可满足培养定义。

所以历史 Study 的“无症状 + 两次同菌”只适合女性确认逻辑，不能投影成男女通用规则。

### 2｜治疗对象｜主方向保留

高价值主轴：

1. **妊娠**；
2. **即将接受会造成泌尿道黏膜创伤的内镜 / 泌尿操作**。

常见不获益组一般不做常规筛查 / 治疗，包括健康非妊娠女性、很多老年人、糖尿病患者、长期导尿者、脊髓损伤者等。

Study 对妊娠的解释仍可用于理解：妊娠相关尿流 / 反流改变增加上行肾盂肾炎风险。

> 第一轮不背整份现代人群指南；只掌握“有菌 ≠ 必须治，只有预期治疗收益明确的人群才治”的原则。

# 6｜“有感染”怎样被证明

<!-- kianos:kp id="urinary-b08-kp06" -->

## KP06｜亚硝酸盐 + 脓尿：一个筛菌，一个看炎症

> **讲义定位 →** 内科 Lecture P145。  
> **主提示**：亚硝酸盐针对谁｜特异/敏感｜成立条件2｜脓尿阈｜血尿/蛋白可否出现。

### 亚硝酸盐还原试验

- 用于筛查；
- 对能还原硝酸盐的常见 G⁻菌更有帮助；
- **特异性较高、敏感性有限**。

Study题旁解释其需要：

- 尿中有足够硝酸盐；
- 尿液在膀胱内停留足够时间。

### 尿沉渣

常见细菌性尿感通常有脓尿：

- WBC >5/HP（Study阈值）。

可伴：

- 血尿：RBC >3/HP；
- 蛋白尿：>0.15 g/d。

（易混：脓尿说明尿路炎症明显，但**不能单靠脓尿区分膀胱炎和肾盂肾炎**。）

---

<!-- kianos:kp id="urinary-b08-kp07" -->

## KP07｜真性细菌尿：10⁵是经典清洁中段尿锚点，不是所有有症状UTI的万能门槛

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：Study三证据｜10^5适用场景｜有症状可否更低｜穿刺阳性｜vs单纯脓尿。

Study列三种“真性细菌尿”考试证据：

1. 清洁中段尿细菌培养 ≥10⁵ CFU/mL；
2. 清洁中段尿沉渣涂片细菌 >1个/HP；
3. 膀胱穿刺尿细菌培养阳性。

第一轮要区分两件事：

```text
经典10^5
= 清洁中段尿 / ASB / 旧Study常用的高特异性菌量锚点

有症状患者
= 较低菌落计数也可能具有临床意义
```

因此 `10^5` 进入 306 Source Precision，**不能写成“不到10^5就绝不是真UTI”**。导尿、穿刺和不同症状情境也有自己的解释阈值。

（易混：尿中 WBC多是炎症证据；培养菌量是微生物学证据，两者不能互相替代。）

# 7｜怎样判断已经进入肾实质

<!-- kianos:kp id="urinary-b08-kp08" -->

## KP08｜肾盂肾炎证据：全身反应 + 肾区 + 小管 / 肾实质支持证据

> **讲义定位 →** 内科 Lecture P146；Recall K6管型。  
> **主提示**：临床2轴｜WBC管型定位价值｜小管标志2｜培养取样2｜浓缩1｜是否每例都有管型。

### 临床定位先行

- 发热、全身炎症反应；
- 腰 / 肾区疼痛或肋脊角叩击痛 / 压痛。

### 支持肾实质 / 小管受累的证据

- WBC管型；
- 尿 NAG↑；
- 尿 β₂-MG↑；
- 尿比重、尿渗透压↓；
- 血液细菌培养阳性可支持系统播散 / 菌血症。

### Study列的定位性培养接口

- 输尿管导尿尿培养阳性；
- 膀胱冲洗后尿培养阳性。

定位逻辑：

```text
WBC管型形成于肾小管
NAG / β2-MG提示小管受累
浓缩功能下降也支持小管-间质损伤
→ 这些证据把位置拉向肾实质
```

但：

> **WBC管型是高价值支持证据，不是每例急性肾盂肾炎都必须出现的“必要条件”。**

没有 WBC管型时，仍要综合发热、肾区体征、尿检、培养和复杂化因素判断。

<!-- kianos:kp id="urinary-b08-kp09" -->

## KP09｜急性膀胱炎 vs 急性肾盂肾炎：局部刺激 vs 全身 + 肾区

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：6轴｜刺激征｜全身｜肾区｜菌/脓尿｜WBC管型支持不必需｜谁可有可无。

| 轴 | 急性膀胱炎 | 急性肾盂肾炎 |
|---|---|---|
| 尿频 / 尿急 / 尿痛 | 常有 | 可有可无 |
| T>38、血WBC↑等全身症状 | 通常无 | 常有 |
| 肾区 / CVA叩痛 | 无 | 支持 |
| 真性细菌尿 | 可有 | 可有 |
| 明显脓尿 | 常见 | 常见 |
| WBC管型 | 不支持下尿路单独来源 | **出现时支持肾实质受累，但并非必需** |

为什么肾盂肾炎反而“尿频尿急尿痛可有可无”？

> 感染已经在肾脏，但如果炎症没有明显波及膀胱，下尿路刺激症可以不突出。

因此病例看到“无尿频尿急尿痛”不能机械排除肾盂肾炎；反过来，看到尿频尿急尿痛也不能直接等于膀胱炎，必须继续看**全身症状、肾区体征和肾实质支持证据**。

# 8｜治疗第一步：先留标本，但不要等结果才治疗

<!-- kianos:kp id="urinary-b08-kp10" -->

## KP10｜先留尿标本 → 立即经验治疗 → 药敏 / 临床无效再调整

> **讲义定位 →** 内科 Lecture P146。  
> **主提示**：先后顺序3步｜为什么先留｜为什么不等｜Study 72h边界。

当前 Study 的操作顺序：

```text
先留取尿细菌检查标本
→ 立即开始经验性抗感染
→ 药敏结果回来后调整
或Study写用药 >72h无效时调整
```

两个目的同时满足：

- **先留标本**：避免抗菌药让培养结果失真；
- **立即治疗**：对需要抗菌治疗的感染，不能为了等药敏而放任感染继续上行或播散。

`72h` 是当前 Study 的复评 Precision；Current 临床还要根据病情严重度、培养结果和是否存在梗阻 / 脓肿等源控制问题动态判断。

# 11｜慢性肾盂肾炎：长期问题首先落在小管

## KP14｜慢性肾盂肾炎：反复上尿路感染 → 瘢痕 / 不对称 → 小管功能持续损害

> **讲义定位 →** 内科 Lecture P147。  
> **主提示**：主机制｜Study>6mo｜Study IVU｜结构3｜小管2功能｜晚期肾小球4证据。

### Current机制 Core

```text
反复 / 长期肾盂-肾间质感染与炎症
→ 瘢痕与纤维化
→ 肾脏可不对称缩小
```

最先体现：

- GFR / Ccr↓；
- Cr、BUN↑；
- 水肿；
- 高血压。

> 这是 K8 与 K7 的关键串联：慢性肾盂肾炎首先是**小管—间质病**，不是一开始就按原发性肾小球病思路理解。

### Source-specific Precision

历史 Lecture 采用：

- 病程 **>6个月**作为慢性边界；
- **IVP / IVU“金标准”**；
- 影像见单 / 双侧不对称缩小、肾盂肾盏变形、缩窄。

这些保留为 306 Study 识别口径。Current 不把“>6个月”或“IVU金标准”升级成现代所有临床情境的永久定义 / 检查金标准；现代影像路径会随场景与技术变化，B8 第一轮只需掌握**瘢痕 / 不对称 / 集合系统变形 + 小管功能先坏**。

# 12｜尿道综合征：有刺激征，不等于有普通细菌尿感

## KP16｜尿道综合征：刺激征 + 无全身症状 + 无普通真性细菌尿

> **讲义定位 →** 内科 Lecture P147。  
> **主提示**：3个否/有｜2分类｜脓尿方向｜支原体衣原体边界｜vs膀胱炎。

Study定义：

```text
尿道刺激征
+ 无全身症状
+ 无普通细菌性真性细菌尿
→ 尿道综合征
```

再分：

- 非感染性尿道综合征：**无脓尿**；
- 感染性尿道综合征：支原体 / 衣原体等，**可有脓尿**。

高价值易混：

- 急性膀胱炎：细菌性尿感证据 + 明显脓尿；
- 尿道综合征：没有普通细菌性真性细菌尿；感染性亚型仍可有脓尿。

完整支原体 / 衣原体与 STI 模型后置感染系统。

## KP17｜K8最终病例算法：刺激征→全身→肾区→肾实质证据→复杂化条件

> **主提示**：5步｜膀胱vs肾｜菌尿情境｜复杂化｜慢性小管｜肾结核边界。

```text
1. 有没有尿频、尿急、尿痛？
   有 → 尿路刺激，但不能直接定位膀胱

2. 有没有发热 / 血炎症反应 / 肾区或CVA痛？
   有 → 向急性肾盂肾炎倾斜

3. 有没有WBC管型 / NAG↑ / β2-MG↑ / 小管浓缩下降？
   有 → 支持肾实质受累；无WBC管型不单独排除

4. 有没有结构/功能异常？
   结石、肿瘤、BPH、妊娠、VUR、神经源膀胱、导尿等
   → 持续 / 上行 / 复发 / 系统性感染风险↑

5. 是否长期反复并出现瘢痕 / 不对称 / 集合系统变形？
   是 → 看小管浓缩 / 分泌功能持续损害
```

最后再问：

> 如果持续膀胱刺激症但普通细菌培养逻辑解释不了，是否要把肾结核留给 K13？

当前只保留这个边界，不提前展开结核。

# 13｜急性肾盂肾炎并发症与尿源性脓毒症

急性肾盂肾炎并不是“发热 + 尿频”的轻型上尿路感染而已，Lecture明确给出三个并发症群：

### 1｜肾乳头坏死

线索：

- 体温再度升高；
- 腰痛剧烈；
- 绞痛：脱落坏死组织堵塞输尿管；
- 血尿。

可伴：

- 败血症；
- 感染性休克；
- AKI。

### 2｜局部化脓并发症

- 肾盂积脓；
- 肾周围脓肿。

### 3｜尿源性脓毒症

Study危险因素：

- **尿路梗阻最常见**；
- 高龄；
- 糖尿病；
- 免疫抑制剂；
- 留置导尿管；
- 泌尿外科手术。

这段是 K8→K12 / 感染系统的重要桥梁：

```text
感染 + 梗阻
→ 不是简单“再加一种抗生素”
→ 尿路源控制与解除梗阻的重要性上升
```

但完整梗阻处理、源控制和脓毒症复苏分别后置 K12 与血液—免疫—感染系统。
