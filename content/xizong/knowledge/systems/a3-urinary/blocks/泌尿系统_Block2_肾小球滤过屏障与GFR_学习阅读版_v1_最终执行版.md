# Block 2｜肾小球滤过屏障与 GFR
## 学习阅读版 v1｜最终执行版

> **中心问题**：肾小球怎样决定“哪些东西能进入原尿、每分钟能滤出多少”；机械屏障、电荷屏障、有效滤过压、肾血浆流量和 Kf 分别从哪一层改变滤过？
>
> **文件性质**：泌尿系统第二个完整 canonical Block。它把 Block 1 的肾血流、清除率、入球—肾小球—出球地图，推进为真正的滤过器模型；后续蛋白尿、血尿、AKI、肾小球病和尿路梗阻都要调用本 Block。
>
> **Study 主范围**：生理 Lecture PDF P267–274《肾小球滤过》。
>
> **Outline Primary**：生理 U025《8.2 肾小球滤过》，共 23 题。
>
> **使用方法**：先看总 Framework；进入每个 KP 后，只看“主提示”闭卷恢复。滤过屏障、有效滤过压、滤过平衡点、肾血浆流量曲线和系膜细胞必须回原讲义图核对。
>
> **边界**：本 Block 完整学习正常滤过屏障与 GFR 决定因素；蛋白尿、血尿只保留机制接口，完整尿液诊断后置 B6；免疫性肾小球病的 LM / IF / EM 和临床综合征后置 B9–B11；小管分段处理与利尿剂后置 B3。

# 0｜为什么 Block 1 后立即学滤过器

Block 1 已经告诉你：

```text
血液
→ 入球小动脉
→ 肾小球毛细血管
→ 出球小动脉
→ 管周毛细血管 / 直小血管
```

并建立：

```text
GFR
RPF
RBF
FF
清除率
```

但这些只是“地图与测量语言”。Block 2 要进一步回答两类完全不同的问题：

```text
问题A｜滤过内容
血细胞、白蛋白、葡萄糖、Na⁺为什么命运不同？

问题B｜滤过数量
为什么同一个肾小球有时GFR升高，有时下降，甚至无尿？
```

这两个问题不能混为一谈：

> **GFR 是原尿体积的量；滤过屏障选择性决定原尿里有什么。**

因此：

```text
蛋白尿
不等于“原尿整体滤得更多”
而更可能是“筛网选择性失效”

少尿 / GFR下降
不等于滤过屏障一定漏蛋白
而可能是灌注、压力、面积或通路受阻
```

本 Block 的最小运行模型：

```text
滤过内容
= 三层滤过膜 + 机械屏障 + 电荷屏障

滤过数量
= 有效滤过压 + 肾血浆流量 + Kf
```

# 2｜滤过屏障：决定“漏什么”

<!-- kianos:kp id="urinary-b02-kp01" -->

## KP01｜滤过膜三层：内皮、基膜、足细胞裂隙膜

> **讲义定位 →** 生理 Lecture PDF P267｜滤过膜。  
> **主提示**：3层顺序｜孔/裂隙｜机械最强｜血细胞/蛋白为何不过

### 1｜从血管腔到肾小囊的三层顺序

```text
肾小球毛细血管内皮细胞
→ 毛细血管基膜
→ 肾小囊脏层上皮细胞 / 足细胞裂隙膜
→ 肾小囊腔
```

| 层次 | Study 结构 | 当前角色 |
|---|---|---|
| 内层 | 有窗孔的毛细血管内皮 | 水与小分子可通过；血细胞被挡在血管内 |
| 中层 | 毛细血管基膜 | 网孔最小；按本节 Study，机械屏障功能最强 |
| 外层 | 足细胞足突与裂隙膜 | 最后一道选择屏障；含裂孔素 nephrin |

### 2｜机械屏障主要按“大小”选择

```text
分子 / 颗粒越大
→ 越难通过三层滤过膜
```

所以正常情况下：

- 血细胞不能滤过；
- 多数血浆蛋白不能滤过；
- 水、离子、葡萄糖、尿素等小分子可进入原尿。

（易混：**基膜机械屏障最强**是本节 Outline 的直接口径；足细胞裂隙膜仍是重要的最后一道屏障，不能理解成“足细胞不重要”。）

### 3｜从结构损伤反推尿液

```text
滤过膜结构完整
→ 血细胞与多数蛋白留在血液

滤过膜严重结构损伤
→ 大分子甚至血细胞漏出接口
```

完整蛋白尿 / 血尿定位后置 B6；当前只建立“筛网损伤可改变尿液成分”的入口。

<!-- kianos:kp id="urinary-b02-kp02" -->

## KP02｜机械屏障 + 电荷屏障：白蛋白为什么尤其难滤过

> **讲义定位 →** 生理 Lecture PDF P267｜机械屏障、电荷屏障与等电点。  
> **主提示**：2屏障｜白蛋白电荷｜pH vs pI 3关系｜双重受限｜裂孔素

### 1｜电荷屏障带负电

按本节 Study，滤过膜各层含带负电荷的蛋白质，形成负电荷屏障。

```text
同性相斥
→ 带负电的大分子更难通过
```

对白蛋白尤其重要：

- 白蛋白是血浆中含量最多的蛋白；
- 白蛋白分子本身较大，受机械屏障；
- 白蛋白在生理 pH 下带负电，又受负电荷屏障排斥。

> **白蛋白同时受机械和电荷双重限制。**

### 2｜等电点 pI 的完整判断

```text
pH < pI
→ 环境相对酸
→ 蛋白质带正电

pH = pI
→ 蛋白质呈电中性

pH > pI
→ 环境相对碱
→ 蛋白质带负电
```

白蛋白 pI 接近 5.0，生理 pH 约 7.35–7.45：

```text
pH > pI
→ 白蛋白带负电
→ 被滤过膜负电荷排斥
```

（易混：电荷屏障主要解释**带电大分子**的选择性，不要因为 Cl⁻带负电就推断它不能滤过；无机离子体积极小，仍可自由滤过。）

### 3｜裂孔素 nephrin 与蛋白尿

按本节 Study：

```text
足细胞 / 裂隙膜受损
→ 裂孔素减少
→ 滤过屏障选择性减弱
→ 白蛋白漏入原尿
→ 蛋白尿接口
```

（按本节 Study 口径：裂孔素减少被放入电荷屏障受损与蛋白尿的解释链；本文件保留该表述，不用外部知识静默改写。）

### 4｜一个关键鉴别

```text
GFR增加
= 原尿体积增加

蛋白尿
= 原尿成分异常，屏障选择性丢失
```

两者可以同时发生，也可以彼此独立。

# 3｜原尿与 GFR：决定“滤多少”

<!-- kianos:kp id="urinary-b02-kp03" -->

## KP03｜原尿与 GFR：双肾每分钟生成多少超滤液

> **讲义定位 →** 生理 Lecture PDF P268｜肾小球滤过概念。  
> **主提示**：原尿 vs 血浆｜超滤｜GFR单/双肾｜正常值｜体表面积4指标

### 1｜原尿是什么

```text
血液流经肾小球毛细血管
→ 除血细胞和多数血浆蛋白外
→ 其余可滤过血浆成分进入肾小囊
→ 形成原尿 / 超滤液
```

原尿与血浆的主要差别：

> **原尿缺少不能被正常滤过的血细胞和多数血浆蛋白。**

按 Study，“超滤”可由血浆 Na⁺和原尿 Na⁺浓度接近来理解：小分子并未被筛网普遍阻挡。

### 2｜GFR 的定义

```text
GFR
= 单位时间双肾生成的原尿量
```

按本节 Study：

```text
约125 mL/min
≈ 180 L/day
```

（易混：GFR 说的是**双肾**；心输出量说的是**一侧心室**每分钟输出。）

### 3｜与体表面积相关的四个指标

本节 Outline 要求归位：

```text
GFR
心指数 CI
比顺应性
基础代谢率 BMR
```

这一组属于 MI-D；第一轮重点是知道它们都用于减少个体体型差异对比较的影响。

### 4｜GFR 与清除率的接口

Block 1 已学：

```text
菊粉清除率 = GFR
内生肌酐清除率 ≈ GFR
```

当前继续追问的是：

> **GFR 本身为什么变化？**

答案不在清除率公式，而在后面的压力、流量、面积与通透性。

# 4｜有效滤过压与滤过平衡点

<!-- kianos:kp id="urinary-b02-kp04" -->

## KP04｜有效滤过压：一个动力对抗两个主要阻力

> **讲义定位 →** 生理 Lecture PDF P268｜有效滤过压。  
> **主提示**：Starling 4压｜囊胶渗≈?｜简化式｜直接动力｜入球端数值

### 1｜完整公式

```text
有效滤过压
=（肾小球毛细血管静水压 + 肾小囊胶体渗透压）
−（肾小囊囊内压 + 肾小球毛细血管血浆胶体渗透压）
```

正常情况下，多数蛋白不能滤入肾小囊：

```text
肾小囊胶体渗透压 ≈ 0
```

所以简化为：

```text
有效滤过压
= 肾小球毛细血管血压
− 肾小囊囊内压
− 肾小球毛细血管血浆胶体渗透压
```

### 2｜三股力量的角色

| 力量 | 方向 | 角色 |
|---|---|---|
| 肾小球毛细血管血压 | 向囊腔 | **原尿生成的直接动力** |
| 肾小囊囊内压 | 向毛细血管 | 尿路 / 囊腔侧阻力 |
| 血浆胶体渗透压 | 向毛细血管 | 血浆蛋白“拉水回去”的阻力 |

（易混：全身平均动脉压和肾动脉压是上游条件；真正直接推动液体跨过滤过膜的是**肾小球毛细血管压**。）

### 3｜正常数值作为 MI-D

按本节 Study 入球端示例：

```text
毛细血管压约45 mmHg
血浆胶体渗透压约25 mmHg
囊内压约10 mmHg

有效滤过压
= 45 − 25 − 10
= 10 mmHg
```

这些数值需要制卡，但不应先于公式逻辑。

<!-- kianos:kp id="urinary-b02-kp05" -->

## KP05｜滤过平衡点：为什么越靠近出球端越难继续滤

> **讲义定位 →** 生理 Lecture PDF P268–269｜滤过平衡点与有效滤过面积。  
> **主提示**：沿毛细血管3压｜净滤压方向｜平衡点｜有效面积｜前后移→GFR

### 1｜沿毛细血管前进时发生什么

按本节 Study：

- 肾小球毛细血管口径较大，毛细血管压从入球端到出球端下降不多；
- 肾小囊囊内压大致稳定；
- 水和小分子不断被滤出，但蛋白大多留在血浆；
- 血浆蛋白被逐渐浓缩，血浆胶体渗透压不断升高。

所以：

```text
从入球端 → 出球端
血浆胶体渗透压↑
→ 滤过阻力↑
→ 有效滤过压逐渐↓
```

### 2｜滤过平衡点

```text
有效滤过压降至0
→ 动力与阻力相等
→ 滤过停止
→ 达到滤过平衡点
```

有效滤过压不会继续变成负值去“反向滤过”；达到 0 后，该段不再继续形成原尿。

### 3｜有效滤过面积

```text
入球小动脉端
→ 滤过平衡点
```

之间的毛细血管面积，称为本节所说的有效滤过面积。

### 4｜平衡点移动

```text
有效滤过压下降得更快
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

```text
有效滤过压下降得更慢
→ 平衡点向出球端移动
→ 有效滤过面积↑
→ GFR↑
```

> 后面的“肾血浆流量”本质上就是通过改变蛋白浓缩速度，移动这个平衡点。

# 5｜GFR 的三层决定模型

<!-- kianos:kp id="urinary-b02-kp06" -->

## KP06｜GFR 三大决定层：压力、流量、Kf

> **讲义定位 →** 生理 Lecture PDF P269–271｜肾小球滤过影响因素。  
> **主提示**：GFR 3层｜各改什么｜压力≠全部｜量 vs 选择性

### 1｜本节三层模型

```text
第一层｜有效滤过压
决定某一位置还有没有向外滤的净驱动力

第二层｜肾血浆流量 RPF
决定血浆蛋白被浓缩得有多快
→ 改变滤过平衡点与有效面积

第三层｜滤过系数 Kf
= 有效通透系数 × 有效滤过面积
→ 决定筛网能以多大规模完成滤过
```

可以压缩为：

```text
GFR
取决于净滤过驱动力
× 可参与滤过的面积 / 通透能力
并受RPF对平衡点的影响
```

### 2｜为什么“屏障漏蛋白”与“GFR下降”可以同时出现

同一个病变可以从不同轴改变结果：

```text
屏障选择性破坏
→ 蛋白漏出

内皮 / 系膜增生、毛细血管腔闭塞
→ Kf / 有效面积下降
→ GFR下降
```

因此肾小球病不能只用一句“通透性增高”概括。

### 3｜一个病例先问哪一层

```text
原尿量减少？
→ 压力 / RPF / Kf

尿中出现蛋白或血细胞？
→ 屏障选择性

两者同时存在？
→ 可能是同一结构病变同时影响多个轴
```

# 6｜肾小球毛细血管压与入、出球小动脉

<!-- kianos:kp id="urinary-b02-kp07" -->

## KP07｜入球管“进水”，出球管“卡出口”：怎样改变 GFR

> **讲义回看 →** Block 1 KP11–KP12；生理 Lecture PDF P269｜入 / 出球小动脉与 AngⅡ。  
> **主提示**：入球收/舒｜出球适度收/舒｜双肾A狭窄｜ACEI/ARB｜极度收缩边界

### 1｜入球小动脉

```text
入球收缩
→ 入肾小球血流↓
→ 肾小球毛细血管压↓
→ 有效滤过压↓
→ GFR↓
```

```text
入球舒张
→ 入肾小球血流↑
→ 肾小球毛细血管压倾向↑
→ GFR倾向↑
```

剧烈运动、应急、强交感和缓进型高血压的入球小动脉器质性狭窄，都可从这条链切入。

### 2｜出球小动脉

按本节 Study：

```text
出球适度收缩
→ 出口阻力↑
→ 肾小球毛细血管压↑
→ GFR轻度↑或被维持
→ RPF下降时FF倾向↑
```

```text
出球舒张
→ 肾小球内压力释放
→ 肾小球毛细血管压↓
→ GFR↓
```

### 3｜双肾动脉狭窄

```text
双肾动脉狭窄
→ 入球前灌注不足
→ 肾小球内压与GFR下降
→ RAAS激活
→ AngⅡ偏向收缩出球小动脉
→ 勉强维持肾小球内压和GFR
```

若使用 ACEI / ARB：

```text
阻断AngⅡ
→ 出球小动脉舒张
→ 肾小球内压进一步下降
→ GFR显著下降
→ 肾衰接口
```

### 4｜当前方向矩阵的来源边界

当前 Study 明确支持：

- 入球收缩 → GFR↓；
- 出球适度收缩 → GFR轻度↑ / 维持；
- 出球舒张 → GFR↓；
- 高浓度 AngⅡ / 强烈交感时入球也收缩 → RBF、GFR进一步↓。

本文件不凭一般知识补造所有“纯入 / 出球操作”下的完整定量 RBF / FF 表；第一轮先掌握以上稳定方向。

# 7｜两种主要滤过阻力

<!-- kianos:kp id="urinary-b02-kp08" -->

## KP08｜肾小囊囊内压：尿路堵住，压力会反向传回滤过器

> **讲义定位 →** 生理 Lecture PDF P269｜囊内压。  
> **主提示**：囊内压：阻/动？｜梗阻3例｜肾后性GFR链｜新月体接口

### 1｜囊内压是滤过阻力

```text
有效滤过压
= 毛细血管压
− 囊内压
− 血浆胶体渗透压
```

所以：

```text
囊内压↑
→ 有效滤过压↓
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 2｜典型原因

- 肾盂 / 输尿管结石；
- 肿瘤压迫；
- 蛋白管型阻塞；
- 其他尿流梗阻。

这是后续 B12“尿路出口阻力 → 上游压力 → 肾积水 → 肾后性 AKI”的生理底座。

### 3｜新月体接口

按本节 Study，新月体性肾炎可由肾小囊壁层上皮细胞增生占据囊腔，形成“囊内空间 / 压力与滤过受限”的接口。完整 RPGN 后置 B10。

（易混：输尿管结石导致尿量下降，本节首先从**囊内压升高**定位；不要优先套用 ADH 或小管重吸收。）

---

<!-- kianos:kp id="urinary-b02-kp09" -->

## KP09｜血浆胶体渗透压：蛋白越少，局部滤过阻力越小

> **讲义定位 →** 生理 Lecture PDF P269｜血浆胶体渗透压。  
> **主提示**：Alb↓→3变量｜大量输液｜肝病：局部 vs 整体

### 1｜局部公式方向

```text
血浆白蛋白↓
→ 血浆胶体渗透压↓
→ 滤过阻力↓
→ 有效滤过压↑
→ GFR↑
```

本节列出的局部因素：

- 大量输液造成稀释；
- 肝功能受损使白蛋白合成减少；
- 肾小球毛细血管通透性增大使蛋白从尿中丢失。

### 2｜大量输液

```text
血浆被稀释
→ 胶体渗透压下降
→ 有效滤过压增加
```

同时大量输液还可使 RPF 增加，进一步把平衡点推向出球端；完整双通路见 KP12。

### 3｜肝功能受损的双层答案

#### 生理局部公式

```text
白蛋白合成↓
→ 血浆胶渗压↓
→ 有效滤过压↑
→ GFR↑
```

#### 临床肝硬化整体

```text
低蛋白血症
→ 水进入组织 / 腹腔
→ 有效循环血量↓
→ 肾灌注与毛细血管压↓
→ GFR↓
→ 肝肾综合征接口
```

（易混：题目如果只问公式中“血浆胶体渗透压降低”，方向是 GFR↑；若给出肝硬化、腹水、有效循环血量下降的完整临床场景，整体方向可转为 GFR↓。）

# 8｜肾血浆流量与 Kf

<!-- kianos:kp id="urinary-b02-kp10" -->

## KP10｜肾血浆流量：不一定改变起始压力，却能移动滤过平衡点

> **讲义定位 →** 生理 Lecture PDF P270｜肾血浆流量。  
> **主提示**：RPF↑/↓｜蛋白浓缩｜平衡点/面积/GFR｜为何非起始压

### 1｜RPF 增加

```text
每分钟进入肾小球的血浆更多
→ 同样滤出一部分水后，蛋白被浓缩得较慢
→ 血浆胶体渗透压上升速度减慢
→ 有效滤过压下降得更慢
→ 平衡点向出球端移动
→ 有效滤过面积↑
→ GFR↑
```

### 2｜RPF 减少

```text
进入肾小球的血浆较少
→ 蛋白浓缩得更快
→ 胶体渗透压上升更快
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 3｜作用轴边界

按本节 Study：

> **肾血浆流量主要通过改变血浆胶渗压上升速度、滤过平衡点和有效滤过面积影响 GFR，而不是简单等同于改变起始有效滤过压。**

现实场景可同时改变多个轴，例如大失血既降低毛细血管压，也降低 RPF。

<!-- kianos:kp id="urinary-b02-kp11" -->

## KP11｜Kf 与球内系膜细胞：筛网面积和通透能力可以主动改变

> **讲义定位 →** 生理 Lecture PDF P271｜滤过系数、系膜细胞与肾小球肾炎。  
> **主提示**：Kf定义｜系膜收缩→2项｜收缩介质｜肾炎GFR｜通透性陷阱

### 1｜Kf

```text
Kf
= 滤过膜有效通透系数
× 有效滤过面积
```

因此 Kf 下降可来自：

- 能参与滤过的毛细血管面积减少；
- 滤过膜有效通透能力下降；
- 毛细血管腔变窄或闭塞。

### 2｜球内系膜细胞

```text
系膜细胞收缩
→ 毛细血管袢被牵拉
→ 有效滤过面积↓
+ Study强调孔隙 / 有效通透性下降
→ Kf↓
→ GFR↓
```

按本节 Study，可收缩系膜细胞的物质包括：

- 交感 / 儿茶酚胺；
- AngⅡ；
- 大剂量 VP；
- ET；
- 腺苷；
- TXA₂等缩血管物质。

（易混：这些物质既可能改变肾血管张力，也可能直接改变系膜细胞与 Kf；两个作用轴要分别看。）

### 3｜肾小球肾炎

按本节 Study：

```text
内皮细胞 / 系膜细胞增生
→ 肾小球毛细血管腔变窄、闭塞
→ 有效面积与Kf下降
→ GFR下降
→ 水钠潴留
→ 肾炎性水肿、容量依赖型高血压接口
```

（易混：肾小球肾炎可出现屏障通透性异常和蛋白 / 血细胞漏出，但分析 **GFR方向** 时，本节要求从增生、管腔变窄和 Kf下降切入，不能只说“炎症使通透性增高，所以GFR升高”。）

# 9｜两个综合场景与交感总效应

<!-- kianos:kp id="urinary-b02-kp12" -->

## KP12｜大量输液 vs 大失血：同一套滤过模型的正反电影

> **讲义回看 →** 生理 Lecture PDF P269–270。  
> **主提示**：输液 vs 失血｜4变量｜直接压力 vs 流量

### A｜大量输液

```text
大量输液
├─ 血浆被稀释
│  → 血浆胶体渗透压↓
│  → 有效滤过压↑
│
└─ RPF↑
   → 蛋白浓缩速度减慢
   → 平衡点向出球端移动
   → 有效滤过面积↑

两条路共同
→ GFR↑
```

### B｜大失血

```text
大失血
├─ 有效循环血量 / 肾灌注↓
│  → 肾小球毛细血管压↓
│  → 有效滤过压↓
│
└─ RPF↓
   → 蛋白浓缩速度加快
   → 平衡点向入球端移动
   → 有效滤过面积↓

两条路共同
→ GFR↓
```

随后强烈交感还会通过系膜收缩、RAAS / ADH与小管重吸收继续减少尿量，见 KP13。

### C｜一眼分清“压力通路”和“流量通路”

| 通路 | 直接改变 | 主要后果 |
|---|---|---|
| 压力通路 | 毛细血管压、囊内压、血浆胶渗压 | 改变有效滤过压 |
| 流量通路 | RPF | 改变蛋白浓缩速度、平衡点和有效面积 |

<!-- kianos:kp id="urinary-b02-kp13" -->

## KP13｜肾交感强烈兴奋：四条路同时把尿量压低

> **讲义定位 →** 生理 Lecture PDF P272｜肾交感神经兴奋小结图。  
> **主提示**：交感强刺激4路｜入球2通路｜系膜｜RAAS/ADH｜近端α₁｜尿量

按讲义第 272 页总图，强烈肾交感兴奋如大失血时，至少从四层减少尿量：

### 1｜降低肾小球毛细血管压

```text
交感 → 入球小动脉收缩
→ 肾小球毛细血管压↓
→ 有效滤过压↓
→ GFR↓
```

### 2｜降低肾血浆流量

```text
入球收缩
→ RPF↓
→ 滤过平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 3｜收缩球内系膜细胞

```text
交感 / 缩血管介质
→ 系膜收缩
→ Kf↓
→ GFR↓
```

### 4｜增加小管 Na⁺、水重吸收

```text
交感 → 肾素↑
→ 醛固酮↑、ADH↑
→ 保Na⁺、保水

交感 → 近端小管α₁受体
→ Na⁺、水重吸收↑
```

最终：

```text
GFR下降
+ 小管重吸收增加
→ 尿量显著下降
```

> 这解释为什么“大失血尿少”不能只用一个 ADH 结论回答；它是滤过、流量、Kf和重吸收同时变化。

# 10｜最终 Discrimination 与病例算法

<!-- kianos:kp id="urinary-b02-kp14" -->

## KP14｜先判“筛网漏”还是“滤得少”，再找第一故障层

> **讲义回看 →** 全 Block；Block 1 肾血流、RAAS、NSAID与 ACEI / ARB 接口。  
> **主提示**：筛网漏 vs 滤得少｜5故障层｜6场景定位

## 1｜两大入口

### A. 尿液成分异常

```text
蛋白尿 / 血尿
→ 先问滤过屏障选择性是否受损
→ 机械屏障、电荷屏障、足细胞 / 裂隙膜
```

### B. 原尿量下降

```text
GFR↓ / 少尿
→ 先问：
毛细血管压？
囊内压？
血浆胶渗压？
RPF？
Kf？
```

## 2｜五类典型场景

| 场景 | 第一故障层 | 主链 |
|---|---|---|
| 蛋白尿 | 屏障选择性 | nephrin / 机械或电荷屏障受损 → 蛋白漏出 |
| 大失血 / 休克 | 灌注 + RPF + 交感 | 毛细血管压↓、RPF↓、Kf↓、重吸收↑ |
| 尿路结石 / 肿瘤压迫 | 囊内压 | 上游压力↑ → 有效滤过压↓ → GFR↓ |
| 肾小球肾炎 | Kf + 屏障 | 增生 / 腔闭塞使Kf↓；同时可有成分漏出 |
| 双肾动脉狭窄 | 入球前灌注 | 依赖AngⅡ收缩出球维持GFR |

## 3｜两类药物接口

### NSAID

```text
NSAID
→ 抑制PGE₂ / PGI₂
→ 丢失入球小动脉舒张保护
→ 肾血流与GFR下降接口
```

尤其在失血、心衰等低有效循环血量状态更危险。完整药物性 AKI 后置 B7。

### ACEI / ARB

```text
阻断AngⅡ
→ 出球小动脉舒张
→ 肾小球内压↓
→ GFR↓
```

双肾动脉狭窄时尤其可能诱发肾衰。

## 4｜早期糖尿病的 Study 边界

本节真题页同时保留两层提示：

- 早期糖尿病肾病可出现高滤过接口；
- 普通糖尿病早期多尿首先从“滤过葡萄糖增多 → 小管液溶质高 → 渗透性利尿”切入，不能把尿多机械等同于 GFR 增高。

因此第一轮只记：

> **糖尿病多尿主要是小管渗透性利尿模型；若题干明确指向早期糖尿病肾病，再考虑高滤过。**

## 5｜六步病例算法

```text
第一步：问题是尿成分异常，还是GFR / 尿量异常？
        ↓
第二步：若成分异常，先定位机械 / 电荷 / 足细胞屏障
        ↓
第三步：若GFR异常，写出有效滤过压公式
        ↓
第四步：再检查RPF与滤过平衡点
        ↓
第五步：再检查Kf与系膜 / 毛细血管面积
        ↓
第六步：最后把交感、RAAS、药物和尿路梗阻放回对应层
```

# 12｜Memory Routing

## 12.1 Mechanism Spine

```text
三层滤过膜
→ 机械 / 电荷选择
→ 有效滤过压推动
→ 血浆蛋白逐渐浓缩
```

7. 滤过平衡点与有效滤过面积；
8. GFR 三层因素：有效滤过压、RPF、Kf；
9. 入球收缩、出球适度收缩、出球舒张的核心方向；
10. 囊内压升高导致肾后性 GFR下降；
11. RPF通过蛋白浓缩速度移动平衡点；
12. 系膜收缩 / 增生使Kf下降；
13. 大量输液与大失血的正反电影；
14. 强交感减少尿量的四条路径；
15. “筛网漏”与“滤得少”两类问题的区分。

- 与体表面积相关的四个指标；

- 低频等电点变式；

# 17｜B2 → B3 交接

B2 只决定：

```text
什么进入原尿
+ 每分钟生成多少原尿
```

B3 接下来要决定：

```text
原尿进入近端小管后
→ 哪些物质被拿回
→ 哪些被额外分泌
→ 各段使用什么转运体
→ 利尿剂卡在哪一段
→ 最终怎样改变Na⁺、水、K⁺与酸碱
```

## B2 给 B3 的稳定输入

```text
原尿 ≠ 终尿
GFR ≈ 125 mL/min
每天原尿约180 L
滤过量 = GFR × 血浆浓度
排泄量 = 滤过量 − 重吸收量 + 分泌量
```
