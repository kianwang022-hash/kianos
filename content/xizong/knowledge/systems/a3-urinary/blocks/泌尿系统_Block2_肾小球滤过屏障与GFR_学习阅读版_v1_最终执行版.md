# 0｜为什么 Block 1 后立即学滤过器

血液流过肾小球时，一部分水和可滤过溶质从毛细血管腔跨过滤过屏障进入肾小囊。同一界面同时决定两件事：屏障限制决定“哪些成分能通过”，净压力、血浆流动及可用滤过能力决定“每分钟通过多少液体”。GFR 测量体积，蛋白或血细胞进入尿液提示成分限制可能受损；两条观察轴可以同向改变，也可以在同一病变中出现漏蛋白增加而 GFR 下降。

下面沿血管腔—滤过壁—囊腔定位各变量，再把入/出球阻力、血浆蛋白、尿路回压、系膜与交感作用挂回实际位置。滤过后的液体还要经小管处理，终尿少不能直接等同于筛网漏或只由 GFR 决定。

# 1｜总 Framework

<!-- kianos:framework id="urinary-b02-framework-main" -->

**在同一屏障上分别读成分与体积。** 毛细血管内皮、基膜、足细胞裂隙膜共同限制血细胞及大部分蛋白进入囊腔。大小/结构与经典电荷选择性解释成分，nephrin 归裂隙膜结构轴。滤过的血浆超滤液每分钟总量为双肾 GFR，测量 GFR 与观察蛋白漏出各有用途。

**四种压力共同决定当处滤过驱动力。** 肾小球毛细血管液压与囊内胶体渗透压促滤过，囊内液压与血浆胶体渗透压反向；正常蛋白限制使囊内胶体压可近似忽略。沿程滤水而保留蛋白，使血浆胶体压升高、净滤过压下降。只有在管内降至零的课程情境中，才有可讨论位置前后移动的滤过平衡点。

**血流与结构分别修饰这份驱动力。** RPF 改变沿程蛋白浓缩速度；Kf 由滤水通透系数和可用面积决定。入/出球阻力改毛细血管压力与流量，梗阻抬高囊压，低白蛋白降低胶体阻力，系膜收缩/结构损伤降低 Kf。功能滤过范围随平衡点变化，不等于 RPF 改变了解剖膜面积。

**多因素扰动要并列算效应。** 强交感可同时降低毛细血管压、RPF、Kf 并增加小管回收；失血和输液的课程情境也会同时改压力、流量及蛋白浓度。血压、尿成分、GFR 与终尿量是证据，NSAID/ACEI/ARB 等作用回到相应血管变量，完整病因诊疗仍各归后续 Block。

# 1A｜同一模型上的自然节点〔完整 Prompt〕

## 跨过三层屏障时，成分限制与滤出体积同时存在

从血管腔向肾小囊腔依次跨过有窗孔的内皮、基膜和足细胞裂隙膜。血细胞被限制在血管侧，大部分蛋白难以通过，水与许多小分子可以滤出。屏障受损可让蛋白或血细胞出现异常通路；尿液证据的完整定位接 B6。
〈滤过膜三层：内皮、基膜、足细胞裂隙膜〔滤过膜3层/孔隙｜机械屏障强弱｜细胞/蛋白限制｜结构损伤接口〕〉

白蛋白受大小/结构和课程经典负电荷模型的共同限制；小分子即使带负电也不能照搬白蛋白的行为。蛋白在特定 pH 下的净电荷需与其等电点比较。nephrin 属于足细胞裂隙膜结构与信号，不能替代负电荷屏障分子；结构选择性失效与滤水能力下降可以同时发生。
〈大小选择性 + 经典电荷选择性：白蛋白为什么正常很难进入原尿〔大小/经典电荷2选择｜白蛋白双限制｜pH-pI 3态｜nephrin结构轴｜量vs成分〕〉

正常原尿是蛋白很少的血浆超滤液；正常血浆本身已不含血细胞。双肾每分钟生成原尿的体积是 GFR，可用合适标志物清除率测量。体表面积校正与课程正常量留原 Core；肺比顺应性按肺容积/FRC 校正的区别也保留，不能把不同分母混为一个指标。
〈原尿与 GFR：双肾每分钟生成多少超滤液〔原尿 vs 血浆｜超滤｜GFR单/双肾｜正常值｜体表面积4指标〕〉

## 液体是否继续滤出，取决于四项压力的合力

完整净滤过压为“毛细血管液压 + 囊内胶体渗透压 − 囊内液压 − 血浆胶体渗透压”。正常屏障限制蛋白时，囊内胶体压近似为零，才可压缩为一个主要动力对抗两个阻力。直接推动跨壁滤过的是肾小球毛细血管液压，上游动脉压还要经入/出球阻力和自身调节才传到这里。
〈有效滤过压：一个动力对抗两个主要阻力〔Starling4压｜囊胶渗近似/条件｜完整→简化式｜直接动力｜入球端3值〕〉

沿毛细血管滤水而大部分蛋白仍留血侧，蛋白相对浓缩、血浆胶体压逐步升高；毛细血管液压和囊压较稳定的课程模型中，净滤过压因此沿程下降。**若在到达出球前降至零**，该位置称滤过平衡点，上游仍工作的长度可随它移动。没有达到零时，仍可讨论沿程压力，却不能强行安放一个平衡点。
〈滤过平衡点：为什么越靠近出球端越难继续滤〔沿毛细血管3压｜净滤压方向｜平衡点｜有效面积｜前后移→GFR〕〉

RPF 较大时，滤出水对沿程血浆蛋白浓缩的影响较缓，净滤过压可维持更长；RPF 减小时相反。在存在平衡点的课程情境中，才将这个变化描述为平衡点后移/前移及功能范围改变。它没有把肾小球膜的解剖面积变大，也不是直接抬高入口的净滤过压。
〈肾血浆流量：不一定改变起始压力，却能移动滤过平衡点〔RPF双向｜蛋白浓缩速度｜平衡点/面积/GFR｜起始压力轴区别〕〉

## 流量之外，还要有可工作的滤过膜

GFR 要合看净滤过压、RPF 对沿程压力的影响和 Kf。Kf 是水力通透系数与可用滤过面积的乘积，描述滤过壁自身的能力；不能把同一“功能范围”再算成第二次结构面积增加。
〈GFR 三大决定层：压力、流量、Kf〔GFR3层/作用轴｜压力≠全部｜量vs选择性〕〉

球内系膜收缩可减少可用滤过面积，增生、毛细血管腔狭窄或阻塞也可使 Kf 下降。肾小球病变于是可能一面破坏成分选择性而漏蛋白，一面减少有效滤水能力而使 GFR 下降，后者再接水钠潴留、容量和血压变化。这是一个病变的并行后果。
〈Kf 与球内系膜细胞：筛网面积和通透能力可以主动改变〔Kf定义｜系膜收缩→2项｜收缩介质｜肾炎GFR｜通透性陷阱〕〉

## 血管入口、出口与尿路回压各改不同位置

入球收缩可同时减少 RPF、降低肾小球毛细血管液压和 GFR，舒张时方向相反。适度出球收缩可在 RPF 减少时支持毛细血管压力，使 GFR 相对保留或略增；出球舒张撤去支持，可使 GFR 下降。高浓度 AngⅡ或强交感还可能明显收缩入球，不能只用“卡住出口”预测所有强度下的净结果。双肾动脉狭窄时 ACEI/ARB 撤去 AngⅡ出球支持，是这条条件链的应用。
〈入球管“进水”，出球管“卡出口”：怎样改变 GFR〔入球收/舒｜出球适度收/舒｜双肾A狭窄｜ACEI/ARB｜极度收缩边界〕〉

结石、肿瘤或管型等阻断下游通路，可使压力向上游传回、囊内液压升高，抵消滤过动力而降低 GFR；这里是回压轴，完整梗阻及新月体病变诊断仍到原 owner。
〈肾小囊囊内压：尿路堵住，压力会反向传回滤过器〔囊内压阻力轴｜梗阻3例｜反向压力→GFR｜新月体接口〕〉

血浆白蛋白减少则降低胶体渗透阻力，**其他条件相同时**使净滤过压和 GFR 有上升倾向。肝病等整个人体情境同时可有有效循环量/肾灌注下降，净结果可以相反；不能从低白蛋白和腹水直接诊断肝肾综合征。
〈血浆胶体渗透压：蛋白越少，局部滤过阻力越小〔Alb↓→3变量｜大量输液｜肝病：局部 vs 整体〕〉

## 病例和处置同时改变多个变量，最后回到证据核对

课程大量输液情境可同时稀释血浆蛋白、增加 RPF，分别减少胶体阻力并减缓沿程蛋白浓缩，因而使滤过增加；大失血则降低灌注压力与 RPF，使滤过减少。它们是条件化的生理扰动，并非所有患者都适用的固定补液处方；若谈平衡点移动，仍须满足前面的平衡条件。
〈大量输液 vs 大失血：同一套滤过模型的正反电影〔输液vs失血｜压力/流量2通路｜胶渗/净滤压/平衡点/面积｜GFR汇合〕〉

强交感可并行产生四条肾端效应：入球收缩降低毛细血管压，RPF 减少改变沿程压力，系膜收缩降低 Kf，近端回收及保容量激素作用增加回收。前三者影响滤出量，后一条还影响滤后处理，共同可使终尿量减少。神经和激素不用等待前一条完成才启动。
〈肾交感强烈兴奋：四条路同时把尿量压低〔交感强刺激4路｜入球2通路｜系膜｜RAAS/ADH｜近端α₁｜尿量〕〉

读病例时，先把尿成分异常与滤过体积下降分别放回屏障、压力/灌注、Kf 和回压，允许同时有多个故障。NSAID 可撤去前列腺素对入球的保护，ACEI/ARB 可减少出球支持；糖尿病多尿首先检查管内溶质，早期高滤过另有其条件。用灌注、药物、尿成分及滤过测量互相核对；小管处理与完整肾病病因分别接 B3、B6–B10。
〈先判“筛网漏”还是“滤得少”，再找第一故障层〔筛网漏vs滤得少｜GFR5因素｜临床5场景｜药物2接口｜糖尿病2语境｜定位6步〕〉

**Residual 边界**：章节主链、分类、比较、诊断/处理方向归模型 / Prompt；数值、阈值、公式、低频名单与精确配对才进入 MI-D / Precision。

# 2｜滤过屏障：决定“漏什么”

<!-- kianos:kp id="urinary-b02-kp01" -->

## KP01｜滤过膜三层：内皮、基膜、足细胞裂隙膜

> **讲义定位 →** 生理 Lecture PDF P267｜滤过膜。  
> **主提示**：滤过膜3层/孔隙｜机械屏障强弱｜细胞/蛋白限制｜结构损伤接口

### 1｜从血管腔到肾小囊的三层顺序

```text
肾小球毛细血管内皮细胞
→ 毛细血管基膜
→ 肾小囊脏层上皮细胞 / 足细胞裂隙膜
→ 肾小囊腔
```

| 层次 | Study 结构 | 当前角色 |
|---|---|---|
| 内层 | 有窗孔的毛细血管内皮 | 水与小分子可通过；血细胞被挡在血管内 |
| 中层 | 毛细血管基膜 | 网孔最小；按本节 Study，机械屏障功能最强 |
| 外层 | 足细胞足突与裂隙膜 | 最后一道选择屏障；含裂孔素 nephrin |

### 2｜机械屏障主要按“大小”选择

```text
分子 / 颗粒越大
→ 越难通过三层滤过膜
```

所以正常情况下：

- 血细胞不能滤过；
- 多数血浆蛋白不能滤过；
- 水、离子、葡萄糖、尿素等小分子可进入原尿。

（易混：**基膜机械屏障最强**是本节 Outline 的直接口径；足细胞裂隙膜仍是重要的最后一道屏障，不能理解成“足细胞不重要”。）

### 3｜从结构损伤反推尿液

```text
滤过膜结构完整
→ 血细胞与多数蛋白留在血液

滤过膜严重结构损伤
→ 大分子甚至血细胞漏出接口
```

完整蛋白尿 / 血尿定位后置 B6；当前只建立“筛网损伤可改变尿液成分”的入口。

## KP02｜大小选择性 + 经典电荷选择性：白蛋白为什么正常很难进入原尿

> **讲义定位 →** 生理 Lecture PDF P267｜机械屏障、电荷屏障与等电点。  
> **主提示**：大小/经典电荷2选择｜白蛋白双限制｜pH-pI 3态｜nephrin结构轴｜量vs成分

### 1｜先固定三层结构与大小选择性

正常肾小球滤过屏障由：

```text
有窗内皮
→ 肾小球基底膜
→ 足细胞裂隙膜
```

共同形成。血细胞和大分子受到结构 / 大小选择性的强限制；因此“屏障选择性”不是某一层单独完成的。

### 2｜306 仍需掌握经典电荷选择性模型

按本节 Study，滤过屏障存在负电荷选择性：

```text
同性相斥
→ 带负电的大分子更难通过
```

对白蛋白尤其重要：

- 白蛋白分子较大，先受大小 / 结构限制；
- 白蛋白在生理 pH 下带负电，按经典考试模型又受负电荷选择性限制。

> **考试第一轮保留“白蛋白同时受大小与经典电荷因素限制”这一判断。**

### 3｜等电点 pI 的完整判断

```text
pH < pI
→ 环境相对酸
→ 蛋白质带正电

pH = pI
→ 蛋白质呈电中性

pH > pI
→ 环境相对碱
→ 蛋白质带负电
```

白蛋白 pI 接近 5.0，生理 pH 约 7.35–7.45：

```text
pH > pI
→ 白蛋白带负电
→ 按经典电荷选择性模型更难滤过
```

（易混：电荷选择性主要用于理解带电**大分子**的滤过差异；不要因为 Cl⁻带负电就推断它不能滤过，小离子体积极小，仍可自由滤过。）

### 4｜nephrin 放回正确的结构轴

```text
足细胞 / 裂隙膜受损
→ nephrin / 裂隙膜结构与信号完整性受损
→ 蛋白限制能力下降
→ 蛋白尿接口
```

**nephrin 是足细胞裂隙膜的核心结构 / 信号蛋白，属于裂隙膜结构与通透选择性轴；不要把 nephrin 减少本身写成“负电荷屏障丢失”的分子机制。**

现代研究对“电荷选择性究竟由哪些结构贡献、贡献多大”的解释比经典教材模型复杂；306 第一轮不展开这场争议，只保留考试所需的经典大小 / 电荷判断，同时把 nephrin 的结构角色放对位置。

### 5｜一个关键鉴别

```text
GFR增加
= 原尿体积增加

蛋白尿
= 原尿成分异常，滤过选择性丢失
```

两者可以同时发生，也可以彼此独立。

# 3｜原尿与 GFR：决定“滤多少”

<!-- kianos:kp id="urinary-b02-kp03" -->

## KP03｜原尿与 GFR：双肾每分钟生成多少超滤液

> **讲义定位 →** 生理 Lecture PDF P268｜肾小球滤过概念。  
> **主提示**：原尿 vs 血浆｜超滤｜GFR单/双肾｜正常值｜体表面积4指标

### 1｜原尿是什么

```text
血液流经肾小球毛细血管
→ 除血细胞和多数血浆蛋白外
→ 其余可滤过血浆成分进入肾小囊
→ 形成原尿 / 超滤液
```

原尿与血浆的主要差别：

> **与血浆相比，原尿中大多数血浆蛋白显著减少；血浆本身已不含血细胞，不能把缺少血细胞列为原尿相对血浆的差别。**

按 Study，“超滤”可由血浆 Na⁺和原尿 Na⁺浓度接近来理解：小分子并未被筛网普遍阻挡。

### 2｜GFR 的定义

```text
GFR
= 单位时间双肾生成的原尿量
```

按本节 Study：

```text
约125 mL/min
≈ 180 L/day
```

（易混：GFR 说的是**双肾**；心输出量说的是**一侧心室**每分钟输出。）

### 3｜讲义四指标：校正基准不能混同

本节 Outline 要求归位：

```text
GFR
心指数 CI
比顺应性
基础代谢率 BMR
```

讲义将这四项并列，但比顺应性是肺顺应性按肺容积（通常FRC）归一，不是除体表面积；心指数按体表面积，GFR可按1.73 m²标准化，基础代谢率也有按体表面积表达的课程口径。记住各自分母，不能硬凑“四个都按BSA”。

### 4｜GFR 与清除率的接口

Block 1 已学：

```text
菊粉清除率 = GFR
内生肌酐清除率 ≈ GFR
```

当前继续追问的是：

> **GFR 本身为什么变化？**

答案不在清除率公式，而在后面的压力、流量、面积与通透性。

# 4｜有效滤过压与滤过平衡点

<!-- kianos:kp id="urinary-b02-kp04" -->

## KP04｜有效滤过压：一个动力对抗两个主要阻力

> **讲义定位 →** 生理 Lecture PDF P268｜有效滤过压。  
> **主提示**：Starling4压｜囊胶渗近似/条件｜完整→简化式｜直接动力｜入球端3值

### 1｜完整公式

```text
有效滤过压
=（肾小球毛细血管静水压 + 肾小囊胶体渗透压）
−（肾小囊囊内压 + 肾小球毛细血管血浆胶体渗透压）
```

正常情况下，多数蛋白不能滤入肾小囊：

```text
肾小囊胶体渗透压 ≈ 0
```

所以简化为：

```text
有效滤过压
= 肾小球毛细血管血压
− 肾小囊囊内压
− 肾小球毛细血管血浆胶体渗透压
```

### 2｜三股力量的角色

| 力量 | 方向 | 角色 |
|---|---|---|
| 肾小球毛细血管血压 | 向囊腔 | **原尿生成的直接动力** |
| 肾小囊囊内压 | 向毛细血管 | 尿路 / 囊腔侧阻力 |
| 血浆胶体渗透压 | 向毛细血管 | 血浆蛋白“拉水回去”的阻力 |

（易混：全身平均动脉压和肾动脉压是上游条件；真正直接推动液体跨过滤过膜的是**肾小球毛细血管压**。）

### 3｜正常数值作为 MI-D

按本节 Study 入球端示例：

```text
毛细血管压约45 mmHg
血浆胶体渗透压约25 mmHg
囊内压约10 mmHg

有效滤过压
= 45 − 25 − 10
= 10 mmHg
```

这些数值需要制卡，但不应先于公式逻辑。

<!-- kianos:kp id="urinary-b02-kp05" -->

## KP05｜滤过平衡点：为什么越靠近出球端越难继续滤

> **讲义定位 →** 生理 Lecture PDF P268–269｜滤过平衡点与有效滤过面积。  
> **主提示**：沿毛细血管3压｜净滤压方向｜平衡点｜有效面积｜前后移→GFR

### 1｜沿毛细血管前进时发生什么

按本节 Study：

- 肾小球毛细血管口径较大，毛细血管压从入球端到出球端下降不多；
- 肾小囊囊内压大致稳定；
- 水和小分子不断被滤出，但蛋白大多留在血浆；
- 血浆蛋白被逐渐浓缩，血浆胶体渗透压不断升高。

所以：

```text
从入球端 → 出球端
血浆胶体渗透压↑
→ 滤过阻力↑
→ 有效滤过压逐渐↓
```

### 2｜滤过平衡点

```text
有效滤过压降至0
→ 动力与阻力相等
→ 滤过停止
→ 达到滤过平衡点
```

这是达到滤过平衡时的课程模型，不应断言每个正常人肾小球都必在出球前达到平衡；未达到时，末端仍可有正的净滤过压。讲义“不可能负值”也不宜脱离模型作为所有病理条件的普遍定律。

### 3｜有效滤过面积

```text
入球小动脉端
→ 滤过平衡点
```

之间的参与滤过面积称为本节模型的有效滤过面积；若平衡点未在毛细血管内出现，则不能按一段不存在的末端截断。这个功能性区域变化不等于滤过系数Kf中的解剖面积和通透性必然同步改变。

### 4｜平衡点移动

```text
有效滤过压下降得更快
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

```text
有效滤过压下降得更慢
→ 平衡点向出球端移动
→ 有效滤过面积↑
→ GFR↑
```

> 肾血浆流量可改变蛋白浓缩及沿程净滤过压；只有达到平衡的模型才用平衡点前后移动解释，不能把所有GFR变化都归为平衡点移动。

# 5｜GFR 的三层决定模型

<!-- kianos:kp id="urinary-b02-kp06" -->

## KP06｜GFR 三大决定层：压力、流量、Kf

> **讲义定位 →** 生理 Lecture PDF P269–271｜肾小球滤过影响因素。  
> **主提示**：GFR3层/作用轴｜压力≠全部｜量vs选择性

### 1｜本节三层模型

```text
第一层｜有效滤过压
决定某一位置还有没有向外滤的净驱动力

第二层｜肾血浆流量 RPF
决定沿毛细血管的血浆蛋白浓缩及胶渗压分布
→ 在达到滤过平衡的模型中，可表现为平衡点/功能性滤过区域移动

第三层｜滤过系数 Kf
= 水力通透系数 × 可用滤过膜面积
→ 决定筛网的水力滤过能力；不与RPF改变造成的功能性截断自动等同
```

可以压缩为：

```text
GFR
取决于净滤过驱动力
× 可参与滤过的面积 / 通透能力
并受RPF对沿程蛋白浓缩和净滤过压的影响
```

### 2｜为什么“屏障漏蛋白”与“GFR下降”可以同时出现

同一个病变可以从不同轴改变结果：

```text
屏障选择性破坏
→ 蛋白漏出

内皮 / 系膜增生、毛细血管腔闭塞
→ Kf / 有效面积下降
→ GFR下降
```

因此肾小球病不能只用一句“通透性增高”概括。

### 3｜一个病例先问哪一层

```text
原尿量减少？
→ 压力 / RPF / Kf

尿中出现蛋白或血细胞？
→ 屏障选择性

两者同时存在？
→ 可能是同一结构病变同时影响多个轴
```

# 6｜肾小球毛细血管压与入、出球小动脉

<!-- kianos:kp id="urinary-b02-kp07" -->

## KP07｜入球管“进水”，出球管“卡出口”：怎样改变 GFR

> **讲义回看 →** Block 1 KP11–KP12；生理 Lecture PDF P269｜入 / 出球小动脉与 AngⅡ。  
> **主提示**：入球收/舒｜出球适度收/舒｜双肾A狭窄｜ACEI/ARB｜极度收缩边界

### 1｜入球小动脉

```text
入球收缩
→ 入肾小球血流↓
→ 肾小球毛细血管压↓
→ 有效滤过压↓
→ GFR↓
```

```text
入球舒张
→ 入肾小球血流↑
→ 肾小球毛细血管压倾向↑
→ GFR倾向↑
```

剧烈运动、应急、强交感和缓进型高血压的入球小动脉器质性狭窄，都可从这条链切入。

### 2｜出球小动脉

按本节 Study：

```text
出球适度收缩
→ 出口阻力↑
→ 肾小球毛细血管压↑
→ GFR轻度↑或被维持
→ RPF下降时FF倾向↑
```

```text
出球舒张
→ 肾小球内压力释放
→ 肾小球毛细血管压↓
→ GFR↓
```

### 3｜双肾动脉狭窄

```text
双肾动脉狭窄
→ 入球前灌注不足
→ 肾小球内压与GFR下降
→ RAAS激活
→ AngⅡ偏向收缩出球小动脉
→ 勉强维持肾小球内压和GFR
```

若使用 ACEI / ARB：

```text
阻断AngⅡ
→ 出球小动脉舒张
→ 肾小球内压进一步下降
→ GFR显著下降
→ 肾衰接口
```

### 4｜当前方向矩阵的来源边界

当前 Study 明确支持：

- 入球收缩 → GFR↓；
- 出球适度收缩 → GFR轻度↑ / 维持；
- 出球舒张 → GFR↓；
- 高浓度 AngⅡ / 强烈交感时入球也收缩 → RBF、GFR进一步↓。

本文件不凭一般知识补造所有“纯入 / 出球操作”下的完整定量 RBF / FF 表；第一轮先掌握以上稳定方向。

# 7｜两种主要滤过阻力

<!-- kianos:kp id="urinary-b02-kp08" -->

## KP08｜肾小囊囊内压：尿路堵住，压力会反向传回滤过器

> **讲义定位 →** 生理 Lecture PDF P269｜囊内压。  
> **主提示**：囊内压阻力轴｜梗阻3例｜反向压力→GFR｜新月体接口

以下涉及“平衡点/功能性面积”的箭头沿用KP05的达到滤过平衡模型；不表示所有人均有血管内平衡点，也不表示解剖面积/Kf随RPF必然改变。

### 1｜囊内压是滤过阻力

```text
有效滤过压
= 毛细血管压
− 囊内压
− 血浆胶体渗透压
```

所以：

```text
囊内压↑
→ 有效滤过压↓
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 2｜典型原因

- 肾盂 / 输尿管结石；
- 肿瘤压迫；
- 蛋白管型阻塞；
- 其他尿流梗阻。

这是后续 B12“尿路出口阻力 → 上游压力 → 肾积水 → 肾后性 AKI”的生理底座。

### 3｜新月体接口

按本节 Study，新月体性肾炎可由肾小囊壁层上皮细胞增生占据囊腔，形成“囊内空间 / 压力与滤过受限”的接口。完整 RPGN 后置 B10。

（易混：输尿管结石导致尿量下降，本节首先从**囊内压升高**定位；不要优先套用 ADH 或小管重吸收。）

<!-- kianos:kp id="urinary-b02-kp09" -->

## KP09｜血浆胶体渗透压：蛋白越少，局部滤过阻力越小

> **讲义定位 →** 生理 Lecture PDF P269｜血浆胶体渗透压。  
> **主提示**：Alb↓→3变量｜大量输液｜肝病：局部 vs 整体

### 1｜局部公式方向

```text
血浆白蛋白↓
→ 血浆胶体渗透压↓
→ 滤过阻力↓
→ 有效滤过压↑
→ GFR↑
```

本节列出的局部因素：

- 大量输液造成稀释；
- 肝功能受损使白蛋白合成减少；
- 肾小球毛细血管通透性增大使蛋白从尿中丢失。

### 2｜大量输液

```text
血浆被稀释
→ 胶体渗透压下降
→ 有效滤过压增加
```

同时大量输液还可使 RPF 增加，进一步把平衡点推向出球端；完整双通路见 KP12。

### 3｜肝功能受损的双层答案

#### 生理局部公式

```text
白蛋白合成↓
→ 血浆胶渗压↓
→ 有效滤过压↑
→ GFR↑
```

#### 临床肝硬化整体

```text
低蛋白血症
→ 水进入组织 / 腹腔
→ 有效循环血量↓
→ 肾灌注与毛细血管压↓
→ GFR↓
→ 肝肾综合征接口
```

（易混：题目只问降低血浆胶体渗透压的单因素效应、其他条件固定时，GFR倾向升高；临床肝硬化合并有效循环不足时整体可下降。此图只是课程的局部与整体对照，不能单凭低白蛋白、腹水和Cr升高就确诊肝肾综合征，仍需病因与排除性评估。）

# 8｜肾血浆流量与 Kf

<!-- kianos:kp id="urinary-b02-kp10" -->

## KP10｜肾血浆流量：不一定改变起始压力，却能移动滤过平衡点

> **讲义定位 →** 生理 Lecture PDF P270｜肾血浆流量。  
> **主提示**：RPF双向｜蛋白浓缩速度｜平衡点/面积/GFR｜起始压力轴区别

以下两条链按其他决定因素受控、且毛细血管内达到滤过平衡的课程模型理解；若未达到平衡，不应虚构血管内的平衡点或面积截断。

### 1｜RPF 增加

```text
每分钟进入肾小球的血浆更多
→ 同样滤出一部分水后，蛋白被浓缩得较慢
→ 血浆胶体渗透压上升速度减慢
→ 有效滤过压下降得更慢
→ 平衡点向出球端移动
→ 有效滤过面积↑
→ GFR↑
```

### 2｜RPF 减少

```text
进入肾小球的血浆较少
→ 蛋白浓缩得更快
→ 胶体渗透压上升更快
→ 平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 3｜作用轴边界

按本节 Study：

> **RPF影响沿程蛋白浓缩和胶渗压，从而影响GFR；在达到滤过平衡的模型中还可表现为平衡点与功能性滤过区域移动，不能据此断言解剖面积/Kf同步变化，也不能把RPF简单等同于起始有效滤过压。**

现实场景可同时改变多个轴，例如大失血既降低毛细血管压，也降低 RPF。

## KP11｜Kf 与球内系膜细胞：筛网面积和通透能力可以主动改变

> **讲义定位 →** 生理 Lecture PDF P271｜滤过系数、系膜细胞与肾小球肾炎。  
> **主提示**：Kf定义｜系膜收缩→2项｜收缩介质｜肾炎GFR｜通透性陷阱

### 1｜Kf

```text
Kf
= 滤过膜有效通透系数
× 有效滤过面积
```

因此 Kf 下降可来自：

- 能参与滤过的毛细血管面积减少；
- 滤过膜有效通透能力下降；
- 毛细血管腔变窄或闭塞。

### 2｜球内系膜细胞

```text
系膜细胞收缩
→ 毛细血管袢被牵拉
→ 有效滤过面积↓
+ Study强调孔隙 / 有效通透性下降
→ Kf↓
→ GFR↓
```

按本节 Study，可收缩系膜细胞的物质包括：

- 交感 / 儿茶酚胺；
- AngⅡ；
- 大剂量 VP；
- ET；
- 腺苷；
- TXA₂等缩血管物质。

（易混：这些物质既可能改变肾血管张力，也可能直接改变系膜细胞与 Kf；两个作用轴要分别看。）

### 3｜肾小球肾炎

按本节 Study：

```text
内皮细胞 / 系膜细胞增生
→ 肾小球毛细血管腔变窄、闭塞
→ 有效面积与Kf下降
→ GFR下降
→ 水钠潴留
→ 肾炎性水肿、容量依赖型高血压接口
```

（易混：肾小球肾炎可出现屏障通透性异常和蛋白 / 血细胞漏出，但分析 **GFR方向** 时，本节要求从增生、管腔变窄和 Kf下降切入，不能只说“炎症使通透性增高，所以GFR升高”。）

# 9｜两个综合场景与交感总效应

<!-- kianos:kp id="urinary-b02-kp12" -->

## KP12｜大量输液 vs 大失血：同一套滤过模型的正反电影

> **讲义回看 →** 生理 Lecture PDF P269–270。  
> **主提示**：输液vs失血｜压力/流量2通路｜胶渗/净滤压/平衡点/面积｜GFR汇合

以下涉及“平衡点/功能性面积”的箭头沿用KP05的达到滤过平衡模型；不表示所有人均有血管内平衡点，也不表示解剖面积/Kf随RPF必然改变。

### A｜大量输液

```text
大量输液
├─ 血浆被稀释
│  → 血浆胶体渗透压↓
│  → 有效滤过压↑
│
└─ RPF↑
   → 蛋白浓缩速度减慢
   → 平衡点向出球端移动
   → 有效滤过面积↑

两条路共同
→ GFR↑
```

### B｜大失血

```text
大失血
├─ 有效循环血量 / 肾灌注↓
│  → 肾小球毛细血管压↓
│  → 有效滤过压↓
│
└─ RPF↓
   → 蛋白浓缩速度加快
   → 平衡点向入球端移动
   → 有效滤过面积↓

两条路共同
→ GFR↓
```

随后强烈交感还会通过系膜收缩、RAAS / ADH与小管重吸收继续减少尿量，见 KP13。

### C｜一眼分清“压力通路”和“流量通路”

| 通路 | 直接改变 | 主要后果 |
|---|---|---|
| 压力通路 | 毛细血管压、囊内压、血浆胶渗压 | 改变有效滤过压 |
| 流量通路 | RPF | 改变蛋白浓缩速度、平衡点和有效面积 |

## KP13｜肾交感强烈兴奋：四条路同时把尿量压低

> **讲义定位 →** 生理 Lecture PDF P272｜肾交感神经兴奋小结图。  
> **主提示**：交感强刺激4路｜入球2通路｜系膜｜RAAS/ADH｜近端α₁｜尿量

以下涉及“平衡点/功能性面积”的箭头沿用KP05的达到滤过平衡模型；不表示所有人均有血管内平衡点，也不表示解剖面积/Kf随RPF必然改变。

按讲义第 272 页总图，强烈肾交感兴奋如大失血时，至少从四层减少尿量：

### 1｜降低肾小球毛细血管压

```text
交感 → 入球小动脉收缩
→ 肾小球毛细血管压↓
→ 有效滤过压↓
→ GFR↓
```

### 2｜降低肾血浆流量

```text
入球收缩
→ RPF↓
→ 滤过平衡点向入球端移动
→ 有效滤过面积↓
→ GFR↓
```

### 3｜收缩球内系膜细胞

```text
交感 / 缩血管介质
→ 系膜收缩
→ Kf↓
→ GFR↓
```

### 4｜增加小管 Na⁺、水重吸收

```text
交感 → 肾素↑
→ 醛固酮↑、ADH↑
→ 保Na⁺、保水

交感 → 近端小管α₁受体
→ Na⁺、水重吸收↑
```

最终：

```text
GFR下降
+ 小管重吸收增加
→ 尿量显著下降
```

> 这解释为什么“大失血尿少”不能只用一个 ADH 结论回答；它是滤过、流量、Kf和重吸收同时变化。

## KP14｜先判“筛网漏”还是“滤得少”，再找第一故障层

> **讲义回看 →** 全 Block；Block 1 肾血流、RAAS、NSAID与 ACEI / ARB 接口。  
> **主提示**：筛网漏vs滤得少｜GFR5因素｜临床5场景｜药物2接口｜糖尿病2语境｜定位6步

### 1｜两大入口

#### A. 尿液成分异常

```text
蛋白尿 / 血尿
→ 先问滤过屏障选择性是否受损
→ 大小 / 结构、经典电荷、足细胞 / 裂隙膜
```

#### B. 原尿量下降

```text
GFR↓ / 少尿
→ 先问：
毛细血管压？
囊内压？
血浆胶渗压？
RPF？
Kf？
```

### 2｜五类典型场景

| 场景 | 第一故障层 | 主链 |
|---|---|---|
| 蛋白尿 | 屏障选择性 | 大小 / 结构、经典电荷或足细胞 / 裂隙膜异常 → 蛋白限制下降 |
| 大失血 / 休克 | 灌注 + RPF + 交感 | 毛细血管压↓、RPF↓、Kf↓、重吸收↑ |
| 尿路结石 / 肿瘤压迫 | 囊内压 | 上游压力↑ → 有效滤过压↓ → GFR↓ |
| 肾小球肾炎 | Kf + 屏障 | 增生 / 腔闭塞使Kf↓；同时可有成分漏出 |
| 双肾动脉狭窄 | 入球前灌注 | 依赖AngⅡ收缩出球维持GFR |

### 3｜两类药物接口

#### NSAID

```text
NSAID
→ 抑制PGE₂ / PGI₂
→ 丢失入球小动脉舒张保护
→ 肾血流与GFR下降接口
```

尤其在失血、心衰等低有效循环血量状态更危险。完整药物性 AKI 后置 B7。

#### ACEI / ARB

```text
阻断AngⅡ
→ 出球小动脉舒张
→ 肾小球内压↓
→ GFR↓
```

双肾动脉狭窄时尤其可能诱发肾衰。

### 4｜早期糖尿病的 Study 边界

本节真题页同时保留两层提示：

- 早期糖尿病肾病可出现高滤过接口；
- 普通糖尿病早期多尿首先从“滤过葡萄糖增多 → 小管液溶质高 → 渗透性利尿”切入，不能把尿多机械等同于 GFR 增高。

因此第一轮只记：

> **糖尿病多尿主要是小管渗透性利尿模型；若题干明确指向早期糖尿病肾病，再考虑高滤过。**

### 5｜六步病例算法

```text
第一步：问题是尿成分异常，还是GFR / 尿量异常？
        ↓
第二步：若成分异常，先定位大小 / 结构、经典电荷或足细胞 / 裂隙膜
        ↓
第三步：若GFR异常，写出有效滤过压公式
        ↓
第四步：再检查RPF与滤过平衡点
        ↓
第五步：再检查Kf与系膜 / 毛细血管面积
        ↓
第六步：最后把交感、RAAS、药物和尿路梗阻放回对应层
```

# 11｜四张 Discrimination Map

## 11.1 滤过量 vs 滤过内容

| 问题 | 主要变量 | 典型结果 |
|---|---|---|
| 滤多少 | 有效滤过压、RPF、Kf | GFR增减 |
| 漏什么 | 大小 / 结构、经典电荷、足细胞 / 裂隙膜 | 蛋白尿、血尿接口 |

## 11.2 三个主要压力

| 变量↑ | 有效滤过压 | GFR |
|---|---:|---:|
| 肾小球毛细血管压 | ↑ | ↑ |
| 肾小囊囊内压 | ↓ | ↓ |
| 血浆胶体渗透压 | ↓ | ↓ |

## 11.3 平衡点方向

在毛细血管内确已达到净滤过压为零的课程模型中，平衡点向入球端移可缩小仍在滤过的功能范围，向出球端移可扩大这份范围，分别对应 GFR 减少/增加的方向。这个比较继承其他条件及沿程压力模型；未达平衡时不强行安放平衡点，功能范围也不能冒充解剖滤过膜面积/Kf。

## 11.4 肾前 / 肾后 / 肾实质入口

| 类型 | B2 当前定位 |
|---|---|
| 肾前 | 灌注、毛细血管压、RPF下降 |
| 肾后 | 囊内压升高 |
| 肾实质 / 肾小球 | 屏障选择性、Kf、毛细血管腔与系膜异常 |

# 12｜Memory Routing

## 12.1 Mechanism Spine

血管腔与囊腔之间的三层屏障限制成分；四项 Starling 力合成净驱动力，RPF 改变沿程蛋白浓缩，Kf 表示可用滤水通透性/面积。滤水而保留蛋白使沿程胶体压升、净滤过压降；只有达到零时才讨论平衡点和功能范围，不能把这份范围变化当作解剖 Kf 改变。

入/出球阻力、囊内回压、白蛋白与系膜/毛细血管病变分别改这些变量。强交感和容量扰动可同时改变多项，终尿还受小管回收影响。把 GFR/尿成分作为证据，分别反推滤出体积与成分限制，再核对病因和药物作用。

## 12.2 MI-G｜必须即时掌握

1. 滤过膜三层；
2. 基膜机械屏障最强（Study 口径）；
3. 经典负电荷选择性重点限制白蛋白；
4. nephrin 属于足细胞裂隙膜的结构 / 通透选择性轴，不等于“负电荷屏障分子”；
5. `pH<pI 正、pH=pI 中性、pH>pI 负`；
6. GFR 是双肾每分钟原尿量；
7. 有效滤过压简化公式；
8. 滤过平衡点与有效滤过面积；
9. GFR 三层因素：有效滤过压、RPF、Kf；
10. 入球收缩、出球适度收缩、出球舒张的核心方向；
11. 囊内压升高导致肾后性 GFR下降；
12. RPF改变沿程蛋白浓缩与净滤过压；在达到滤过平衡的课程模型中再判断平衡点移动；
13. 系膜收缩 / 增生使Kf下降；
14. 大量输液与大失血的正反电影；
15. 强交感减少尿量的四条路径；
16. “筛网漏”与“滤得少”两类问题的区分。

## 12.3 MI-D｜进入 MarginNote 3

- GFR 125 mL/min、180 L/day；
- 入球端 45 / 25 / 10 mmHg 与有效滤过压 10 mmHg；
- GFR、心指数、基础代谢率的体表面积口径与肺比顺应性按肺容积/FRC校正的区别；
- 所有缩血管 / 系膜收缩物质名单；
- 70–180 mmHg 自身调节范围与 40–50 mmHg 无尿接口；
- 所有真题年份；
- 低频等电点变式；
- 早期糖尿病 / 糖尿病肾病措辞边界；
- 肝功能受损局部公式与肝硬化整体临床的双口径。

# 17｜B2 → B3 交接

B2 在血管腔—滤过壁—囊腔上分别解释原尿成分与每分钟体积，B3 接着追同一股滤液沿近端、髓袢、远曲和集合管前进。各段在两侧膜之间回收或分泌，利尿剂则作用于当段靶点，改变下游溶质、流量、电位与终尿。

## B2 给 B3 的稳定输入

原尿并非终尿。对可自由滤过的溶质，滤过负荷由 GFR 与相应血浆浓度共同决定；最终排泄量等于滤过量减去重吸收量，再加分泌量。课程 GFR 与日滤液量保留原 Core，变化量要带相同单位和条件。小管可以因负荷变化而适应，也可以因转运损伤而改变终尿，不能只从 GFR 单项推出所有终尿结果。

## 进入 B3 前的 8 个交接问题

1. 为什么每天约180 L原尿最终只有少量终尿？
2. 哪些小分子进入原尿后必须被小管大量拿回？
3. 蛋白尿主要属于滤过屏障问题，还是小管转运问题？
4. GFR增加时，小管负荷为什么会同步增加？
5. 为什么葡萄糖可自由滤过，却正常不出现在终尿？
6. 为什么利尿剂必须按小管分段学习？
7. 为什么肾小球滤过下降可少尿，而小管重吸收增加也可少尿？
8. `滤过量—重吸收量—分泌量—排泄量` 四者怎样连成一个物质量公式？

> **Block 2 的最终目标**：面对任何“蛋白尿、少尿、GFR变化、药物或梗阻”题，先判断是筛网选择性、压力、流量、Kf还是小管后处理，而不是只背一个方向结论。
