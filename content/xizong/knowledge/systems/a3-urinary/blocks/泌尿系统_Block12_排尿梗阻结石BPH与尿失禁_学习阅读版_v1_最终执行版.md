# Block 12｜排尿、梗阻、结石、BPH与尿失禁
## 学习阅读版 v1｜最终执行版

> **中心问题**：尿液从肾盂到尿道的通路在哪一层受阻；出口阻力、逼尿肌与括约肌控制怎样共同决定排尿症状、残余尿和尿失禁；梗阻、结石与感染怎样互相促进并最终损害肾功能？
>
> **文件性质**：泌尿系统第十二个 canonical Block，也是医学肾脏分支进入泌尿外科“尿路出口模型”的入口。K1 已完整建立正常排尿反射，K6 已建立尿液证据与分肾功能，K7 已建立肾后性 AKI，K8 已建立感染与梗阻接口；本 Block 不重复这些 Primary，而是把它们应用到 BPH、尿潴留、结石、梗阻与四类尿失禁。

> **第一轮流程**：Framework → 外科 Lecture连续学习 + 生理既学模型回调 + 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete。

# 0｜这个 Block 到底解决什么

K1 已经回答“正常膀胱怎样排空”，K12 要回答的是：

```text
尿已经形成
→ 能否从肾盏、肾盂、输尿管顺利下行
→ 膀胱能否低压储尿
→ 逼尿肌能否有效收缩
→ 内外括约肌能否在正确时相开放
→ 尿道出口是否被前列腺、结石或狭窄阻挡
```

任何一层失败，都可进入同一条后果链：

```text
出口阻力↑ / 逼尿肌收缩异常 / 括约肌控制异常
→ 排尿不畅或错误时相漏尿
→ 残余尿↑、膀胱过度充盈或高压
→ 感染、结石、假性憩室
→ 上游压力传递、肾积水
→ 囊内压↑、GFR↓
→ 肾后性肾功能不全
```

因此，本 Block 的核心不是分别背“BPH、结石、尿失禁”，而是建立：

> **尿流通路 × 出口阻力 × 膀胱动力 × 上游压力 × 处理优先级。**

```text

   排尿困难 / 绞痛 / 漏尿
   → 定位 → 判断高危 → 选择检查 → 决定先减压还是根治
   [KP17]
```

## 一条总电影

```text
前列腺移行带增生、尿道狭窄或结石
→ 出口阻力增加
→ 早期膀胱代偿性活动增强，出现尿频、尿急
→ 继续进展后排尿等待、尿线变细、进行性排尿困难
→ 残余尿增加、膀胱过度充盈
→ 急性或慢性尿潴留
→ 急迫性尿失禁可转为充溢性尿失禁
→ 尿液滞留促感染、结石和假性憩室
→ 压力向输尿管和肾盂传递
→ 肾积水、GFR下降、肾后性肾功能不全
```

同时：

```text
结石在输尿管内移动或刺激平滑肌
→ 阵发性绞痛
→ 黏膜摩擦可血尿
→ 完全梗阻时可很严重却不一定有血尿
→ 感染合并梗阻时，单纯抗感染不够
→ 必须把解除梗阻 / 尿路引流提到优先位置
```

# 3｜排尿与梗阻共同底座

<!-- kianos:kp id="urinary-b12-kp01" -->

## KP01｜正常排尿控制：K1 既学模型在疾病中的最小调用

> **讲义回看 →** 生理 P263–264；K1 KP14–KP15。  
> **主提示**：正常排尿4层控制｜逼尿肌/内外括约肌方向｜正反馈｜损伤可落哪层

正常排尿的最小链：

```text
膀胱充盈、内压升高
→ 膀胱壁牵张感受器
→ 盆神经传入
→ 骶髓排尿中枢
+ 脑干 / 大脑皮层高级控制
→ 盆神经传出
→ 逼尿肌收缩
→ 尿道内括约肌舒张
→ 后尿道刺激进一步加强排尿反射
→ 外括约肌开放
→ 膀胱排空
```

当前只需把既学控制层放回疾病：

- **逼尿肌收缩不足**：排不净，残余尿增多，可进入充溢性尿失禁；
- **出口阻力增高**：即使逼尿肌收缩，也需对抗更大阻力；
- **逼尿肌不稳定收缩**：出现尿急、急迫性尿失禁；
- **膀胱颈 / 尿道括约肌破坏**：可形成持续性尿失禁；
- **盆底支持下降或外括约肌受损**：腹压升高时出现压力性尿失禁。

（边界：K1 的容量 / 压力数字属于 MI-D，本 Block 不再重新背一遍。）

## KP02｜尿路梗阻：出口阻力如何一路顶回 GFR

> **讲义回看 →** K2 有效滤过压；K7 肾后性 AKI；外科 P108–109。  
> **主提示**：阻力2源｜残尿链｜上游压力链｜GFR方向｜高危3情形。

梗阻可以来自：

```text
通路内堵塞
结石 / 肿瘤 / 血块

通路壁或周围压迫
前列腺增生 / 狭窄 / 肿块

膀胱动力失败
逼尿肌收缩无力，功能上无法克服出口阻力
```

后果分两层：

```text
下游排空失败
→ 残余尿↑
→ 膀胱过度充盈 / 假性憩室
→ 感染与结石风险↑

上游压力传递
→ 输尿管、肾盂扩张
→ 肾积水
→ 肾小囊内压↑
→ 有效滤过压↓
→ GFR↓
→ 肾后性AKI / CKD
```

第一轮必须立即识别的高危情形：

1. **双侧梗阻或孤立肾梗阻**；
2. **梗阻伴感染 / 尿源性脓毒症风险**；
3. **肾功能已明显下降、无尿或持续少尿**。

这些情形的共同处理逻辑是：

> **先恢复尿流 / 引流减压，再谈最终取石或根治。**

# 4｜BPH：从移行带增生到膀胱失代偿

<!-- kianos:kp id="urinary-b12-kp03" -->

## KP03｜BPH 身份：老龄 + 功能睾丸 + 移行带

> **讲义定位 →** 外科 P108。  
> **主提示**：发病2条件｜好发带区｜DHT链｜与前列腺癌2差异｜出口阻力。

Study 的 BPH 最小身份：

- 发病因素：**老龄 + 有功能的睾丸**；
- 好发部位：**移行带**；
- 前列腺癌好发于**外周带**，两者并非同一病变的连续阶段；
- 睾酮经 **5α还原酶**形成活性更强的双氢睾酮，构成药物靶点接口。

```text
移行带增生
→ 围绕尿道的前列腺组织增多
→ 尿道出口阻力↑
→ 逼尿肌必须更用力才能排尿
→ 由代偿走向失代偿
```

（易混：BPH 与前列腺癌均多见于老年男性，也都受雄激素接口影响，但好发带区、触诊和完整疾病模型不同；前列腺癌在 K13 完整学习。）

<!-- kianos:kp id="urinary-b12-kp04" -->

## KP04｜BPH 症状进展：尿频最早，进行性排尿困难最典型

> **讲义定位 →** 外科 P108。  
> **主提示**：最早1｜最典型1｜储尿3｜排尿4｜加重2｜急迫→充溢。

按当前 Study：

- **尿频最早**；
- **进行性排尿困难最典型**；
- 劳累、饮酒等可加重。

可按“储尿—排尿—失代偿”理解：

```text
早期出口阻力↑
→ 膀胱反复增强收缩、变得不稳定
→ 尿频、尿急
→ 可出现急迫性尿失禁

梗阻继续
→ 排尿等待、尿线细弱、排尿不能成线
→ 进行性排尿困难
→ 残余尿不断增加

失代偿
→ 尿潴留、膀胱过度充盈
→ 尿液滴沥外溢
→ 充溢性尿失禁
```

饮酒加重接口按 Study 保留两层：前列腺充血使梗阻加重，乙醇抑制 ADH 又增加尿量，使本已受阻的出口负担上升。

## KP05｜BPH 检查：306 识别入口与 Current 评估层分开

> **讲义定位 →** 外科 P108。  
> **主提示**：DRE｜B超｜触诊1征｜BPHvs癌带区｜“首选”情境边界。

当前 Study 的考试口径：

- **首选检查：直肠指检 DRE**；
- 典型触诊：前列腺增大，**中间沟变浅或消失**；
- **影像学首选：B 超**。

这些用于 306 识别继续保留，但不要把“首选”理解成所有 LUTS/BPO 情境中唯一的完整评估路径。Current learner 只需分清：

```text
DRE
→ 触诊大小/质地/硬结等床旁信息

超声
→ 前列腺体积、残余尿、上尿路/膀胱等结构信息

症状严重度、尿流、残余尿、肾功能等
→ 决定是否存在真实梗阻及其后果
```

判断时不要把“前列腺增大”直接等同于 BPH：

```text
BPH
→ 移行带
→ 中间沟变浅 / 消失
→ 进行性排尿困难主导

前列腺癌
→ 外周带
→ 可触及硬结
→ PSA / MRI / 穿刺等完整肿瘤模型在K13
```

## KP06｜BPH 药物：放松出口 + 减少 DHT；CCB禁用仅作Source Precision

> **讲义定位 →** 外科 P108。  
> **主提示**：2类药｜代表各1｜作用层｜联合方案｜旧禁用项边界。

Study 给出的两条稳定药物路线：

| 药物类别 | 代表 | 当前作用理解 |
|---|---|---|
| α受体阻断剂 | 特拉唑嗪 | 放松尿道出口相关平滑肌，降低动态阻力 |
| 5α还原酶抑制剂 | 非那雄胺 | 减少睾酮转为双氢睾酮，作用于增生基础 |

传统联合方案：

> **α受体拮抗剂 + 5α还原酶抑制剂。**

### //MI-D｜Source-specific exam Precision

Lecture 另写“**禁用 CCB**”，理由是膀胱逼尿肌收缩依赖 Ca²⁺。该句作为历史题源识别保留，但**不作为 Current BPH/LUTS 的一般正式禁忌**。第一轮不要为了这一条低频旧口径建立第二套药理模型。

## KP07｜BPH 手术与急性尿潴留：先把尿放出来，术式阈值再进Precision

> **讲义定位 →** 外科 P108。  
> **主提示**：观察｜2药｜3术式｜80mL Source阈值｜急性潴留第一步｜手术指征入口。

当前 Study 的治疗层级：

```text
症状轻 / 风险低
→ 观察随访

需要药物
→ α受体阻断剂 ± 5α还原酶抑制剂

需要手术
→ TURP / TUIP / EEP 等
```

- 并发**急性尿潴留**：首先导尿，先解除膀胱过度充盈；
- 手术指征型线索包括反复尿潴留、反复泌尿系感染、继发膀胱结石、上尿路/肾功能受累等；
- PSA 轻度升高本身不构成 Study 所列手术指征。

### //MI-D｜Source-specific procedure Precision

- Lecture 把 **EEP ≥80 mL** 作为高价值术式阈值；
- 现代术式选择还受前列腺体积、设备、术者经验、并存疾病与患者偏好等影响，因此这个数字不作为“过线只能做某一种术式”的 Current 开关。

第一轮只要稳定：

> **先解除潴留 / 保护肾功能，再依据症状、体积和并发症决定长期治疗。**

## KP08｜BPH 并发症：一个残余尿可以拖出十种后果

> **讲义定位 →** 外科 P108。  
> **主提示**：残尿链｜3尿路后果｜2失禁｜肾后损害｜腹压2后果｜癌变边界。

Study 并发症：

- 尿潴留；
- 急迫性尿失禁；
- 充溢性尿失禁；
- 膀胱结石；
- 感染；
- 肾后性肾功能不全；
- 膀胱假性憩室；
- 无痛性血尿；
- 腹外疝；
- 痔疮。

把它们挂回两条链：

```text
残余尿 / 尿流停滞
→ 感染、膀胱结石、假性憩室
→ 向上梗阻、肾功能不全

长期排尿用力、腹压增加
→ 腹外疝、痔疮
```

（易混：BPH 可出现无痛性血尿，但遇到无痛全程肉眼血尿时，仍应首先保留泌尿恶性肿瘤分支；BPH 本身不等于癌前病变。）

## KP09｜四类结石：形态、颜色与 X 线显影

> **讲义定位 →** 外科 P108。  
> **主提示**：4成分｜最常见｜硬/脆｜粗/滑｜形状颜色｜显影2+2｜酸化特殊×1。

| 成分 | Study形态 | 颜色 | X线 | 处理记忆接口 |
|---|---|---|---|---|
| 草酸钙 | 硬、粗糙、桑葚样 | 棕褐色 | 高密度 | 最常见 |
| 磷酸钙 | 易碎、粗糙、鹿角样 | 灰白等 | 高密度 | 酸化尿液 + 抗感染 |
| 尿酸盐 | 硬、光滑、颗粒状 | 红色 | 不显影 | 一般碱化尿液逻辑 |
| 胱氨酸 | 硬、光滑、蜡样 | 淡黄至黄棕 | 不显影 | 低频精确记忆 |

规律：

```text
含钙较多
→ 多粗糙、X线显影

含钙少或不含钙
→ 多光滑、X线不显影
```

（特殊：当前 Study 强调一般结石处理偏碱化尿液，但磷酸盐结石为酸化尿液 + 抗感染。具体代谢性结石治疗不在本 Block扩写。）

## KP10｜尿路结石 vs 胆系结石：不要只见“石头”就套同一模型

> **讲义定位 →** 外科 P109。  
> **主提示**：地区｜钙代谢｜成分｜X线｜治疗目标｜共同绞痛机制。

| 比较轴 | 尿路结石 | 胆系结石 |
|---|---|---|
| 地区 | 南方多见 | 西北多见 |
| 与钙代谢 | 有关 | 无关 |
| 主要成分 | 草酸钙、磷酸钙等 | 胆固醇等 |
| X线 | 含钙石多显影；尿酸盐/胱氨酸不显影 | 纯胆固醇常不显影；混合性常显影；胆色素部分显影 |
| 治疗方向 | 碎石、取石、解除梗阻 | 胆囊结石多切胆囊；胆管结石取石等 |

共同点：胆系结石、输尿管结石及机械性肠梗阻都可出现**阵发性绞痛**，Study 将其理解为平滑肌为克服阻塞而阵发性痉挛。

## KP11｜结石位置决定疼痛和排尿表现

> **讲义定位 →** 外科 P109。  
> **主提示**：肾/输尿管/膀胱3位置｜疼痛3型｜膀胱2特征｜血尿边界｜完全堵死特殊。

- **肾结石**：肾区、肋脊角疼痛；
- **输尿管结石**：阵发性绞痛；
- **膀胱结石**：排尿突然中断，改变体位后又可排尿，并可有膀胱刺激征。

```text
结石移动 / 摩擦
→ 疼痛 + 血尿

结石卡住
→ 平滑肌阵发性收缩
→ 绞痛

完全梗阻
→ 病情可很重
→ 但因石头不再摩擦或尿流中断，未必出现明显血尿
```

因此：

> **血尿程度与结石 / 损伤严重度不一定平行。**

## KP12｜结石检查与并发症：检查层级和“最严重”都要看情境

### Study 检查口径

```text
→ 再用CT进一步显示结石
```

## KP13｜结石处理优先级：先保肾、先通路、先危险侧

> **讲义定位 →** 外科 P109。  
> **主提示**：肾功极差｜感染梗阻｜双肾｜双输尿管｜肾+输尿管｜总原则。

稳定 Current Core：

```text
感染性梗阻 / 脓毒症风险
或无尿 / 肾功能明显受威胁
→ 先建立引流、解除梗阻
→ 抗感染 / 稳定患者
→ 再处理结石本身
```

当前 Study 的考试顺序继续保留：

- **肾功能极差**：先造瘘 / 引流；
- **双侧肾结石**：先处理容易取出的一侧；
- **双侧输尿管结石**：可双侧输尿管镜碎石取石；否则先处理梗阻严重的一侧；
- **一侧肾结石 + 一侧输尿管结石**：先处理输尿管结石。

Study 记忆语：**“先输后肾，先易后难”**，但不能脱离“哪侧更危险、是否感染/无尿、肾功能怎样”机械套用。

## KP14｜结石尺寸—部位—术式矩阵：完整保留为306 Precision

> **讲义定位 →** 外科 P109。  
> **主提示**：Source矩阵｜稳定决策轴｜>2cm肾结石PCNL锚点｜不能单变量选术式。

### //MI-D｜当前 Study 矩阵

| 位置 | <0.6 cm | 0.6–2 cm | >2 cm |
|---|---|---|---|
| 肾结石 | 药物 + 饮水 | ESWL | PCNL |
| 输尿管上段 | 药物 + 饮水 | ESWL | 腹腔镜输尿管切开取石 |
| 输尿管中下段 | 药物 + 饮水 | 输尿管镜碎石取石 | 腹腔镜输尿管切开取石 |

特殊：

- 肾盂结石合并肾盂输尿管连接处梗阻：Study 为肾盂切开取石，同时解除梗阻；
- 中下段输尿管结石受肠道气体影响，Study 因此把 0.6–2 cm 的主术式放在输尿管镜。

### Current Core｜不要把三列变成唯一算法

稳定选择逻辑：

```text
先看是否急需减压
→ 再看位置 + 大小
→ 再看成分/硬度/CT密度、解剖和患者因素
→ 选择SWL / URS-RIRS / PCNL等
```

高价值稳定锚点：

- **肾结石 >2 cm：PCNL 是一线强锚点**；
- SWL 成功率会受结石大小、位置、硬度及患者条件影响；
- 现代内镜技术显著压缩了开放/腹腔镜取石的常规适用面。

因此上表**必须背用于 306，但不能在 Current 病例中只凭一个尺寸格子自动下术式。**

## KP15｜膀胱与尿道结石：Source 操作表保留，先理解“不能制造新梗阻”

> **讲义定位 →** 外科 P109。  
> **主提示**：膀胱/尿道结石Source操作｜前尿道 vs 后尿道｜为何少切尿道｜Precision边界。

当前 Study：

- 膀胱结石尤其 **<2 cm**：膀胱镜碎石取石；
- 膀胱结石 **>2 cm**，或伴尿路感染：耻骨上膀胱切开取石；
- 后尿道结石：推入膀胱，按膀胱结石处理；
- 前尿道结石：石蜡润滑后挤出尿道口；
- 尽量不作尿道切开取石，因为切开后瘢痕可造成尿道狭窄。

这些作为 306 Source 操作 Precision 保留；现代实际方案还受结石位置、可内镜处理性、感染与设备等因素影响。第一轮稳定原则是：

> **取出结石的同时，不能制造新的出口损伤 / 狭窄；高危梗阻先减压。**

# 6｜四类尿失禁：漏尿时相就是定位线索

<!-- kianos:kp id="urinary-b12-kp16" -->

## KP16｜持续、充溢、急迫、压力性尿失禁四轴比较

> **讲义定位 →** 外科 P112；生理排尿反射 Recall。  
> **主提示**：4型｜漏尿时相｜膀胱状态｜控制失败层｜代表病因｜BPH前后期。

| 类型 | 排尿表现 | 第一故障层 | Study常见病因 |
|---|---|---|---|
| 持续性 / 真性 | 任何时间、体位持续不自主流尿 | 膀胱颈 / 尿道括约肌完整性丧失 | 外伤、手术、先天疾病 |
| 充溢性 / 假性 | 不连续滴沥，夜间多；膀胱过度充盈 | 排不净，残余尿累积；膀胱内压超过尿道阻力 | BPH、肿瘤、尿道狭窄、神经性逼尿肌无力 |
| 急迫性 | 严重尿频、尿急，膀胱先于意识排尿 | 逼尿肌不稳定收缩 | 膀胱炎、神经源性膀胱、重度出口梗阻 |
| 压力性 | 平时控制正常；咳嗽、起立等腹压增高时少量漏尿 | 盆底支持 / 外括约肌抵抗不足 | 多产、绝经后，前列腺术后外括约肌损伤 |

BPH 的时相：

```text
早期膀胱不稳定
→ 急迫性尿失禁

晚期残余尿持续增加、膀胱过度充盈
→ 充溢性尿失禁
```

（易混：充溢性不是膀胱“太会收缩”，而是长期排不净后压力越积越高，尿液被动滴沥；压力性漏尿时，平时排尿控制可正常。）

## KP17｜最终病例算法：排尿困难、绞痛和漏尿怎样分流

> **主提示**：入口3类｜定位4层｜危险3问｜检查层级｜先减压vs根治｜进入K13/K14边界。

```text
1. 主诉是哪类？
   进行性排尿困难 / 阵发性绞痛 / 漏尿 / 无尿

2. 定位在哪里？
   前列腺-膀胱出口 / 输尿管 / 膀胱 / 尿道 / 神经控制

3. 是否有高危变量？
   双侧或孤立肾梗阻？
   感染合并梗阻？
   Cr升高、无尿或肾功能极差？

4. 检查回答什么层级？
   BPH：DRE / 超声用于触诊、体积、残余尿和结构评估
   结石：超声与无增强CT按情境用于积水/位置/大小/密度评估

5. 先处理什么？
   高危梗阻：先引流减压
   稳定结石：按位置 + 大小 + 成分/密度 + 解剖/患者条件选择方案
   急性尿潴留：先导尿

6. 漏尿是哪一型？
   持续 / 充溢 / 急迫 / 压力

7. 是否需要转入其它 Block？
   无痛全程肉眼血尿 / 硬结 → K13
   外伤后滴血、不能排尿 → K14
```
