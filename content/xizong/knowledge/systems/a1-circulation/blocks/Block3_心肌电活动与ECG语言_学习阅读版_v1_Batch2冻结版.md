# Block 3｜心肌电活动与 ECG 语言
## 从单细胞动作电位，到传导、体表 ECG 与机械收缩｜学习阅读版 v1 · Batch 2 冻结版

> **中心问题**：某一种心肌细胞为什么以特定方式产生动作电位；该动作电位怎样决定起搏、传导、兴奋、不应期与收缩；全心电活动怎样投影成 ECG；细胞电活动又怎样经 Ca²⁺耦联触发机械泵血？

# 先把四个层级分开

B3 最重要的不是先背离子通道，而是永远不要把下面四层混成一个东西：

```text
单个心肌细胞动作电位
    ├─ 局部电流激活邻旁细胞 → 传导系统／心肌传播 → 全心电活动时序
    │                                                   ↓ 体表观察
    │                                                  ECG
    └─ 细胞Ca²⁺耦联 → 横桥产力 → 相应充盈／负荷下的压力、射血、脉搏

ECG记录全心电活动；机械输出依靠电—机械耦联及负荷，两者是不同结果层。
```

因此：

```text
动作电位 ≠ ECG
ECG ≠ 机械射血
有电活动 ≠ 一定有有效脉搏
```

> **ECG 边界**：B3 只建立 `P = 心房除极 / QRS = 心室除极 / ST-T = 心室复极相关` 这座翻译桥。PR、QT、导联轴、异常节律识别和临床判图归 B10；不要在这里提前学成一门临床 ECG 课。

# 一部电影先走完

先看心脏怎样组织一次有顺序的搏动。它需要有细胞主动发令，也需要把这道兴奋传给负责收缩的细胞。窦房结能自己逐渐走到下一次兴奋的起点，因此可以带节奏；兴奋传到心房，再在房室结稍作延迟，让房、室活动有先后，随后经希—浦系统迅速分发，让心室协调工作。

接到兴奋的心室肌还要把电变化变成力量。钙进入细胞并触发更多钙释放，带动横桥产力；钙随后回收、排出，心肌才能舒张，再为下一搏接血。在这一过程中，细胞也有一段不能再次正常兴奋的时间，避免收缩不断叠加而失去舒张机会。心电图则从体表观察全心的电活动，它能提供线索，却不能单凭一条电信号保证心脏已经有效泵出了血。

有了这个过程，再看下面的电流名称：它们分别解释“谁能自己发令、怎样传开、怎样产力、何时能再兴奋”。先知道每个开关在做什么，再沿同一模型逐步填入名称和条件。

```text
窦房结P细胞4期自动去极化 → 达到ICa-L阈值 → 慢0期发令
→ 兴奋传遍心房 → 房室结慢传导／房室延搁 → 希—浦高速分发
→ 心室肌近乎同步除极：0期INa快速内流 → 1期初复极 → 2期平台
    ├─ ICa-L外Ca²⁺触发SR放Ca²⁺ → 横桥 → 收缩／相应条件下射血
    │   → Ca²⁺回收与排出 → 舒张／再充盈
    └─ 内流减弱、K⁺复极电流占优 → 3期复极 → 通道恢复、准备再兴奋

泵与交换体持续维持离子稳态；长ERP与收缩重叠，保留舒张机会。
全心电活动叠加另投影成ECG，不必先“经过ECG”才产生机械力。
```

全心大量细胞的除极与复极最后投影成：

```text
P波 → QRS波群 → ST段 / T波
```

```text
细胞类型先定位：0期快／慢反应 × 4期工作／自律

    ├─ 平台Ca²⁺ → CICR／横桥 → 力 → 压力／射血 → 回收Ca²⁺／舒张
```

# ① 先判细胞类型与层级

## KP01｜心肌细胞的两条分类轴

> **讲义定位 →** P138。  
> **主提示**：分类2轴｜代表3组合｜0期电流→速/幅→传导｜自律≠传导快

### 快反应 vs 慢反应：看 0 期

| 类型 | 代表细胞 | 0期主要电流 | 0期特点 | 传导 |
|---|---|---|---|---|
| 快反应 | 心房肌、心室肌、浦肯野 | 快钠通道 `INa` | 速度快、幅度大 | 快 |
| 慢反应 | 窦房结、房室结 | `ICa-L` | 速度慢、幅度小 | 慢 |

```text
0期内向电流越快 / 越大
→ 与邻近未兴奋细胞的电位差越快 / 越强
→ 局部电流越强
→ 传导越快
```

### 工作 vs 自律：看 4 期

| 类型 | 代表细胞 | 4期 | 主要任务 |
|---|---|---|---|
| 工作细胞 | 心房肌、心室肌 | 稳定静息，无自动去极化 | 收缩 |
| 自律细胞 | 窦房结、房室结、浦肯野 | 自动去极化 | 起搏 / 传导 |

常用三组合：

```text
快反应工作：心房肌、心室肌
快反应自律：浦肯野
慢反应自律：窦房结、房室结
```

（易混：自律性高不等于传导快。窦房结自律性最高；浦肯野传导最快；房室结传导最慢。）

## KP02｜动作电位、传导、ECG、机械活动不能互相替代

> **讲义定位 →** P140、P145；**讲义回看 →** B1。  
> **主提示**：活动4层｜P/QRS/ST-T映射｜电→力→脉搏｜有电≠有效射血

```text
单细胞AP：某一个细胞膜电位随时间变化
传导：一个细胞产生的局部电流让邻旁细胞达到阈值
ECG：全心电活动在体表的综合投影
机械活动：Ca²⁺与横桥产生力，形成压力和射血
```

当前 Study 明确：

```text
P波 = 心房除极
QRS波群 = 心室除极
ST段、T波 = 心室复极相关
```

其中 ST 段与心室肌平台期 / 缓慢复极接口相连。

```text
电兴奋
→ 兴奋—收缩耦联
→ 胞质Ca²⁺↑
→ 横桥活动
→ 心肌收缩
→ 压力与射血
→ 动脉脉搏
```

```text
→ 快钠通道INa开放
→ Na⁺快速内流
→ 快速去极化
```

### 1期｜快速复极化初期

```text
INa失活
→ Ito瞬时外向电流
→ K⁺短暂外流
```

### 2期｜平台期

```text
内向：ICa-L为主 + INa,late + Na-Ca交换
外向：IK
且去极化状态下IK1通透性低
→ 内外电流相对平衡
→ 平台维持
```

平台期是心室肌 AP 特别长、并连接兴奋与收缩的关键。

### 3期｜复极

```text
ICa-L逐渐失活
+ IK增强
+ 复极时IK1外向电导恢复，参与终末复极
→ 净外向电流使膜电位回落
→ 接近K⁺平衡电位时驱动力变小，不能把外流画成一直增加
→ 复极完成
```

### 4期｜恢复离子稳态

工作细胞无自动去极化，但 Na⁺-K⁺泵、Ca²⁺泵、Na-Ca交换持续把离子重新归位。

**APD**：从 0 期开始到 3 期复极完成；不等于 ERP。

## KP04｜IK1：静息、平台和3期终末都离不开它

> **讲义定位 →** P139。  
> **主提示**：内向整流｜电导vs电流｜3角色｜复极反馈｜阻断剂

按 Study 感性理解：

```text
膜去极化
→ IK1电导↓ → K⁺外流↓
→ 不妨碍去极化 / 帮助平台

膜由去极化状态复极
→ IK1外向电导恢复，外向电流可促进复极
→ 但电流还取决于K⁺驱动力，不是越负外流就必然越多
```

三个角色：

```text
静息：维持较负静息电位
平台：去极化时通透性低，减少K⁺外流
3期末：IK1参与快速复极，并使膜电位趋近K⁺平衡电位
```

课程的复极促进链可记为“复极 → 整流阻挡减弱 → IK1外向电流参与 → 更复极”。它有电位范围；I_K约由电导与(Vm−E_K)共同决定，接近E_K时驱动力减小，不能无限外推。

Study 使用钡作为 IK1 阻断剂。IK1 与延迟整流 `IK` 不是同一电流。

## KP05｜平台期、APD与改变动作电位时程的切入点

> **讲义定位 →** P139–140、P143。  
> **主提示**：平台内外流｜Ca触发｜IK早晚｜APD｜药物方向/条件

平台本质：

```text
缓慢持久的内向电流
≈
较弱但逐渐增强的外向K⁺电流
```

- 内向：ICa-L为主，另有 INa,late、Na-Ca交换；
- 外向：IK；平台时 IK1 通透性较低。

Ca²⁺内流绝对量可不大，但负责触发 SR 释放 Ca²⁺，因此意义巨大。

```text
平台早期：IK主要抗衡ICa-L
平台晚期：IK增强并推动复极
```

当前 Study：APD 中复极阶段占比大，因此主要反映 K⁺通道 / 复极速度。

**缩短 APD**：维拉帕米阻 ICa-L、ACh、利多卡因抑 INa,late；高钙常使平台/ST缩短；课程从膜表面电荷/晚Na切入，但不能据此排除Ca²⁺依赖性L型通道失活等机制，净APD还受其他电流与实验条件影响。

**延长APD的典型路径**：Ⅲ类如胺碘酮/E-4031抑K⁺复极电流，ⅠA奎尼丁也有延长方向；长QT可来自INa,late↑或IK↓。

**ⅠC普罗帕酮另列**：核心是强抑Na⁺电流、减慢传导；APD效应随组织、频率及浓度变化。课程把它列为延长方向，但犬浦肯野纤维原始实验可见APD缩短，不能以ⅠC身份推出必然延长APD。

完整抗心律失常药理归 B10。

# ③ 自律细胞：为什么窦房结能自动发令

## KP06｜窦房结P细胞：没有稳定静息，也没有平台期

> **讲义定位 →** P140–141。  
> **主提示**：最大复极电位｜0/3/4期机制｜1/2期特征｜慢0期｜自动4期

窦房结 P 细胞是慢反应自律细胞：

- 无稳定静息电位，用“最大复极电位”描述，Study约 `-65 mV`；
- 4期自动去极化；
- 0期主要 ICa-L；
- 无明显1、2期平台；
- 3期主要 IK。

```text
0期依赖慢Ca²⁺通道
→ 开放 / 内流较慢
→ 0期速度与幅度小
→ 传导慢
```

自律性最高看的是**4期自动去极化最快**，不是0期最快。

## KP07｜窦房结4期：外向电流减弱 + 内向电流增强

> **讲义定位 →** P141。  
> **主提示**：4期电流4路｜Study主导｜激活位置/阻断剂｜阈值→0期

```text
外向K⁺电流逐渐减少
+
内向Na⁺ / Ca²⁺相关电流逐渐增加
→ 4期自动去极化
```

- **IK逐渐减少**：当前 Study 主导机制；约 -50mV后衰减 → K⁺外流减少。
- **If**：复极 / 超极化方向激活；约 -60mV开始，需更深超极化才大量激活。窦房结最大复极电位不够负，所以参与但非 Study 主导；铯、伊伐布雷定抑制。
- **ICa-T**：4期后段约 -50mV加入，加速到 ICa-L 阈值。
- **Na-Ca交换**：参与内向电流。
- 达约 -40mV → ICa-L大量开放 → 新0期。

（易混：If不是快钠通道 INa。If在自律细胞4期；INa在快反应细胞0期。）

# ④ 兴奋性与不应期：什么时候还能再产生动作电位

## KP09｜ERP、相对不应期与超常期

> **讲义定位 →** P142。  
> **主提示**：时期3：膜电位/兴奋性/刺激/机械｜ERP覆盖范围→防强直

**ERP**：当前 Study 从 0期开始到3期复极约 -60mV，包括绝对不应期和局部反应期；兴奋性为0或极低，不能产生正常传播 AP，约覆盖整个收缩期和舒张早期。

**相对不应期**：约 -60→-80mV；部分Na通道恢复，兴奋性低于正常，需要阈上刺激；新AP幅度小、0期慢、传导慢、时程 / 不应期短。

**超常期**：约 -80→-90mV；多数Na通道恢复且膜电位相对接近阈值，兴奋性可高于正常，阈下刺激也可能触发。

“超常”指刺激阈强度降低；按本Study P148的期前刺激比较，相对不应期与超常期诱发的新AP时程都可较短，不能由较易触发推出波形和传导已完全恢复正常。

```text
长ERP覆盖收缩期
→ 第二个兴奋不能叠加
→ 心肌不能完全强直
→ 必须保留舒张 / 充盈
```

---

## KP10｜期前兴奋、早搏与代偿间歇

> **讲义定位 →** P142–143。  
> **主提示**：期前兴奋时机｜ERP｜窦房重置｜完全/不全/间位

越过 ERP 进入相对不应期 / 超常期后，如果下一窦性冲动前异位点给出足够刺激，可提前兴奋 → 期前收缩 / 早搏。

期前兴奋本身又产生 ERP：

```text
下一次窦性冲动
若落入该ERP
→ 冲动作废
→ 无新心室收缩
→ 较长舒张间歇
```

早搏后的间歇还取决于窦房结是否被提前重置，不能只看“下一窦性冲动是否撞进ERP”：

- 房早常逆传重置窦房结 → 下一窦性发放时点改变，常为不完全代偿间歇；
- 室早若未重置窦房结 → 原窦性节律可继续，常见完全代偿间歇；
- 间位室早可插在两个窦性搏动之间，没有通常的代偿间歇。

这些是常见模式，不是按异位起源作无例外裁定；完整ECG判读归B10。

## KP11｜APD与ERP：一个看复极，一个看再次去极化能力

> **讲义定位 →** P143。  
> **主提示**：APDvsERP：时间/功能｜ⅠAvsⅠB：各自方向/程度｜ERP/APD

```text
APD：0期开始 → 3期复极完成
→ 主要反映复极速度 / K⁺通道状态

ERP：快钠通道失活到逐渐恢复
→ 反映再次完成有效去极化的能力
```

ⅠA奎尼丁：INa↓ → ERP延长明显，APD也轻度延长 → `ERP/APD↑`。

ⅠB利多卡因：更突出抑制 INa,late → APD缩短明显；ERP也缩短但少于APD → `ERP/APD↑`。

两者都使快速冲动更容易落入相对较长的有效不应状态。完整药理归 B10。

## KP12｜兴奋性三个决定因素：通道状态、膜—阈距离、过度去极化

> **讲义定位 →** P143–144。  
> **主提示**：兴奋性定义｜门控/膜阈距离｜高低K×轻重4格｜Ca抗高K作用层｜细胞类型条件

兴奋性：受刺激后产生 AP 的能力，Study 用阈强度衡量。

```text
Na⁺ / Ca²⁺通道完全失活 → 兴奋性0
膜与阈距离远 → 兴奋性↓
距离适度变近 → 兴奋性↑
持续去极化、距离“过近” → 通道失活 / 去极化阻滞 → 兴奋性↓
```

| 情况 | Study方向 | 切入点 |
|---|---|---|
| 轻度低K⁺ | ↑ | K⁺电导 / 通透性改变 |
| 严重低K⁺ | ↓ | 严重失衡可致骤停 |
| 轻度高K⁺ | ↑ | 膜去极化、靠近阈值 |
| 严重高K⁺ | ↓ | 持续去极化 → 通道失活 |

严重高钾使用葡萄糖酸钙的 Study 解释：Ca²⁺膜屏障作用 → Na⁺通透性下降 / 阈值上移 → 重新拉开膜—阈距离 → 拮抗心脏毒性。

Ca²⁺对窦房结、房室结、工作细胞影响不同，必须先判细胞类型。

# ⑤ 传导与起搏：兴奋怎样分发到全心

## KP13｜传导性的三类决定因素

> **讲义定位 →** P144–145。  
> **主提示**：传导因素3类｜0期速/幅→局部电流｜邻旁兴奋性｜结构3项

最主要：已兴奋细胞0期速度和幅度。

```text
0期越快 → 局部电流形成越快
0期幅度越大 → 电位差越大 → 局部电流越强 → 传导越快
```

0期受通道电导 / 通透性 + 电化学驱动力影响：快反应看Na⁺，慢反应看Ca²⁺。

邻旁细胞：膜—阈距离近 → 易激活 → 传导快；持续去极化使Na通道失活 → 传导障碍。

结构：细胞直径大→内阻小；闰盘 / 缝隙连接多→低阻；分化程度高→传导功能完善。

## KP14｜心肌传导速度差异：部位、机制与功能

## KP15｜自律性层级、抢先占领与超速驱动阻抑

> **讲义定位 →** P145–146。  
> **主提示**：3层级｜抢先vs超速｜逸搏vs主动异位｜停驱风险

```text
窦房结自律性最高
> 房室结
> 浦肯野最低
```

衡量自律性主要看自动兴奋频率。

**抢先占领**：潜在起搏点4期未达阈值，窦房结冲动已先到 → 被重置 → 表现窦律。

**超速驱动阻抑**：潜在起搏点长期被高于自身固有频率的冲动驱动；外来高频突然停止后不能立刻恢复，需静止期。因此高频驱动突然终止后，下位节律恢复可能延迟。这里用于解释停驱风险；是否以及如何调整人工起搏取决于起搏依赖、装置和监护情境，不能由本条推出自行调低或停用起搏器。

```text
异位点自律性主动超过窦房结
→ 主动异位：早搏 / 自主性心动过速接口

窦房结过慢或下传受阻
→ 下位点被迫接管
→ 被动异位：逸搏 / 逸搏心律接口
```

## KP16｜自律性决定因素 + Ca²⁺对不同细胞方向不同

> **讲义定位 →** P146。  
> **主提示**：4期斜率｜最大复极—阈值距离｜Ca²⁺↑：窦房结vs浦肯野

```text
或内向Na⁺ / Ca²⁺增加
```

最大复极电位到阈值距离越近，自律性越高；越远越低。

# ⑥ 电信号怎样变成机械力

## KP17｜心肌收缩四个特征：CICR、功能合胞体、长ERP和长度—张力

# ⑦ 自主神经 / 药物怎样修改电生理

## KP19｜儿茶酚胺：β1—cAMP—PKA把起搏、传导、收缩与舒张一起加速

> **讲义定位 →** P149–150；**讲义回看 →** B2。  
> **主提示**：β₁→cAMP｜2信号路｜4效应｜受磷蛋白｜左右交感

```text
NA / Adr → β1 → G蛋白—AC → cAMP↑
    ├─ 直接调节If通道 → 有利于起搏去极化
    └─ 激活PKA → 通道/调节蛋白磷酸化
```

四类效应：

- **收缩性↑**：工作细胞平台 ICa-L↑ → Ca²⁺内流 / CICR↑。
- **舒张速度↑**：受磷蛋白磷酸化 → SR Ca²⁺泵回收加快。
- **传导性↑**：慢反应细胞0期 ICa-L↑ → 0期速度 / 幅度↑。
- **心率 / 自律性↑**：窦房结4期 ICa-T、If等内向电流↑ → 斜率↑。

本标题展开起搏、传导、收缩与舒张四项作用；讲义P150及B2所说的“四正效应”则按兴奋性、传导性、自律性、收缩性计数，其中正性兴奋指相应细胞条件下较易由刺激触发AP，舒张加快另列。

课程主线突出ICa-L、ICa-T与If，但不能据此回答“儿茶酚胺与IK绝无关系”；人心室实验显示β刺激可调节延迟整流K⁺电流、尤其IKs的作用。按 Study：右交感更偏窦房结 / HR；左交感更偏房室交界和心室肌 / 传导与收缩。

## KP20｜ACh与迷走：室上结构为主的四负效应

> **讲义定位 →** P149–150；**讲义回看 →** B2。  
> **主提示**：M信号｜电流4类｜心房/窦房结/房室结｜左右迷走/心室弱支配

ACh作用于心脏M受体，抑制ICa-L、ICa-T、If并激活IK-ACh；以下按靶细胞分开。

- **兴奋性↓**：在本节心房／窦房结等受作用的室上细胞中，IK-ACh增强可使膜电位更负、膜—阈距离增大，较难由刺激触发AP；这与自律细胞4期自动去极化变慢是两个判断。
- **心房收缩性↓**：抑平台 ICa-L + 激活 IK-ACh → 平台缩短、Ca²⁺内流↓。
- **房室传导↓**：抑房室结0期 ICa-L。
- **窦房结自律性 / HR↓**：抑4期 ICa-T、If + 激活 IK-ACh → 4期斜率↓且最大复极电位更负、离阈值更远。

**分布**：右迷走更偏窦房结；左迷走更偏房室交界；对心室肌支配少，因此负性收缩效应以心房更突出。

ACh不是一句“膜超极化”即可概括；必须先看细胞位置和电流。

## KP21｜E-4031 vs ACh + 最终电生理算法

> **讲义定位 →** P150–152。  
> **主提示**：E-4031vsACh：复极/If/其他电流｜自律性｜判题5步

按当前 Study：

```text
E-4031抑制窦房结IK
→ 最大复极不够负
→ If激活不足
→ 4期自动去极化受影响
→ 自律性↓
```

ACh：促进 IK-ACh，使最大复极更负，同时抑 If / ICa-T。两者都可使自律性↓，但路径不同。

E-4031这一链是课程窦房结比较情境；反应还受细胞区域、大小和实验条件影响，不把它外推为所有K⁺电流阻断的统一心率结果。

最终遇到任何题：

```text
1. 哪种细胞？
   快 / 慢反应；工作 / 自律
2. 哪一期？
   0 / 1 / 2 / 3 / 4
3. 哪个电流？
   INa / INa,late / Ito / ICa-L / ICa-T / IK / IK1 / If / IK-ACh...
4. 问哪种性质？
   兴奋 / 传导 / 自律 / 收缩 / APD / ERP
5. 落到哪一层？
   单细胞AP / 全心传导 / ECG / 机械泵血
```

不能从“某离子↑”直接跳到“心率↑ / 传导↑ / 收缩↑”。
