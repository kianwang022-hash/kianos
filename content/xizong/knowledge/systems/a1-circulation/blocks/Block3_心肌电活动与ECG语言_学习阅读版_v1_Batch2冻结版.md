# Block 3｜心肌电活动与 ECG 语言
## 从单细胞动作电位，到传导、体表 ECG 与机械收缩｜学习阅读版 v1 · Batch 2 冻结版

> **中心问题**：某一种心肌细胞为什么以特定方式产生动作电位；该动作电位怎样决定起搏、传导、兴奋、不应期与收缩；全心电活动又怎样投影成 ECG，并最终触发机械泵血？

# 先把四个层级分开

B3 最重要的不是先背离子通道，而是永远不要把下面四层混成一个东西：

```text
单个心肌细胞动作电位
        ↓
兴奋在传导系统和心肌中的传播
        ↓
全心电活动投影到体表 ECG
        ↓
Ca²⁺介导的机械收缩 → 压力 / 射血 / 脉搏
```

因此：

```text
动作电位 ≠ ECG
ECG ≠ 机械射血
有电活动 ≠ 一定有有效脉搏
```

> **ECG 边界**：B3 只建立 `P = 心房除极 / QRS = 心室除极 / ST-T = 心室复极相关` 这座翻译桥。PR、QT、导联轴、异常节律识别和临床判图归 B10；不要在这里提前学成一门临床 ECG 课。

# 一部电影先走完

```text
窦房结P细胞4期自动去极化
→ 达到ICa-L阈值
→ Ca²⁺内流形成慢反应0期
→ 兴奋传遍心房
→ 房室结慢传导，留下心室充盈时间
→ 希—浦系统高速分发
→ 心室肌近乎同步除极
→ 心室肌0期INa快速内流
→ 2期ICa-L与K⁺外流形成平台
→ Ca²⁺触发肌浆网释放Ca²⁺，启动收缩
→ K⁺外流完成复极
→ 离子泵 / 交换体恢复稳态
→ 准备下一次心跳
```

全心大量细胞的除极与复极最后投影成：

```text
P波 → QRS波群 → ST段 / T波
```

```text
① 先判细胞类型，再判层级
```

# ① 先判细胞类型与层级

## KP01｜两条分类轴：0期区分快慢，4期区分工作与自律

> **讲义定位 →** P138。  
> **主提示**：快 / 慢反应看哪一期；工作 / 自律看哪一期；代表细胞；0期主电流、速度、幅度与传导。

### 快反应 vs 慢反应：看 0 期

| 类型 | 代表细胞 | 0期主要电流 | 0期特点 | 传导 |
|---|---|---|---|---|
| 快反应 | 心房肌、心室肌、浦肯野 | 快钠通道 `INa` | 速度快、幅度大 | 快 |
| 慢反应 | 窦房结、房室结 | `ICa-L` | 速度慢、幅度小 | 慢 |

```text
0期内向电流越快 / 越大
→ 与邻近未兴奋细胞的电位差越快 / 越强
→ 局部电流越强
→ 传导越快
```

### 工作 vs 自律：看 4 期

| 类型 | 代表细胞 | 4期 | 主要任务 |
|---|---|---|---|
| 工作细胞 | 心房肌、心室肌 | 稳定静息，无自动去极化 | 收缩 |
| 自律细胞 | 窦房结、房室结、浦肯野 | 自动去极化 | 起搏 / 传导 |

常用三组合：

```text
快反应工作：心房肌、心室肌
快反应自律：浦肯野
慢反应自律：窦房结、房室结
```

（易混：自律性高不等于传导快。窦房结自律性最高；浦肯野传导最快；房室结传导最慢。）

## KP02｜动作电位、传导、ECG、机械活动不能互相替代

> **讲义定位 →** P140、P145；**讲义回看 →** B1。  
> **主提示**：四层各是什么；当前 Study 对 P / QRS / ST-T 的映射；为什么有电不等于有有效射血。

```text
单细胞AP：某一个细胞膜电位随时间变化
传导：一个细胞产生的局部电流让邻旁细胞达到阈值
ECG：全心电活动在体表的综合投影
机械活动：Ca²⁺与横桥产生力，形成压力和射血
```

当前 Study 明确：

```text
P波 = 心房除极
QRS波群 = 心室除极
ST段、T波 = 心室复极相关
```

其中 ST 段与心室肌平台期 / 缓慢复极接口相连。

```text
电兴奋
→ 兴奋—收缩耦联
→ 胞质Ca²⁺↑
→ 横桥活动
→ 心肌收缩
→ 压力与射血
→ 动脉脉搏
```

//串联：B12 用“有电活动但无有效脉搏”再次验证这条边界。

# ② 心室肌动作电位：把0–4期学成连续电影

## KP03｜心室肌0–4期完整图

> **讲义定位 →** P139–140。  
> **主提示**：静息电位；0、1、2、3、4期主电流；APD；哪一期最特殊。

### 静息

当前 Study 约 `-90 mV`：

```text
IK1介导K⁺外流（主要）
+ 少量Na⁺内流
+ Na⁺-K⁺泵生电作用
```

### 0期｜快速去极化

```text
达到阈值（Study约-70mV）
→ 快钠通道INa开放
→ Na⁺快速内流
→ 快速去极化
```

### 1期｜快速复极化初期

```text
INa失活
→ Ito瞬时外向电流
→ K⁺短暂外流
```

### 2期｜平台期

```text
内向：ICa-L为主 + INa,late + Na-Ca交换
外向：IK
且去极化状态下IK1通透性低
→ 内外电流相对平衡
→ 平台维持
```

平台期是心室肌 AP 特别长、并连接兴奋与收缩的关键。

### 3期｜复极

```text
ICa-L逐渐失活
+ IK增强
+ 复极越深，IK1通透性越高
→ K⁺外流进一步增加
→ 复极完成
```

### 4期｜恢复离子稳态

工作细胞无自动去极化，但 Na⁺-K⁺泵、Ca²⁺泵、Na-Ca交换持续把离子重新归位。

**APD**：从 0 期开始到 3 期复极完成；不等于 ERP。

## KP04｜IK1：静息、平台和3期终末都离不开它

> **讲义定位 →** P139。  
> **主提示**：内向整流；去极化 / 复极时通透性；静息、平台、3期三个角色；3期正反馈；阻断剂。

按 Study 感性理解：

```text
膜去极化
→ IK1电导↓ → K⁺外流↓
→ 不妨碍去极化 / 帮助平台

膜复极、更负
→ IK1电导↑ → K⁺外流↑
→ 促进复极
```

三个角色：

```text
静息：维持较负静息电位
平台：去极化时通透性低，减少K⁺外流
3期末：复极越深 → IK1越开放 → K⁺外流越多
```

于是形成 3 期终末正反馈：复极 → IK1↑ → K⁺外流↑ → 更复极。

Study 使用钡作为 IK1 阻断剂。IK1 与延迟整流 `IK` 不是同一电流。

---

## KP05｜平台期、APD与改变动作电位时程的切入点

> **讲义定位 →** P139–140、P143。  
> **主提示**：平台内外电流；Ca²⁺触发意义；IK早晚期；APD主要反映什么；缩短 / 延长APD的Study方向。

平台本质：

```text
缓慢持久的内向电流
≈
较弱但逐渐增强的外向K⁺电流
```

- 内向：ICa-L为主，另有 INa,late、Na-Ca交换；
- 外向：IK；平台时 IK1 通透性较低。

Ca²⁺内流绝对量可不大，但负责触发 SR 释放 Ca²⁺，因此意义巨大。

```text
平台早期：IK主要抗衡ICa-L
平台晚期：IK增强并推动复极
```

当前 Study：APD 中复极阶段占比大，因此主要反映 K⁺通道 / 复极速度。

**缩短 APD**：维拉帕米阻 ICa-L、ACh、利多卡因抑 INa,late；高钙按当前 Study 以膜屏障 / 平台-ST缩短路径组织。

**延长 APD**：Ⅲ类如胺碘酮 / E-4031抑 K⁺复极电流；ⅠA奎尼丁、ⅠC普罗帕酮按 Study 有延长方向；长 QT 可来自 INa,late↑ 或 IK↓。

完整抗心律失常药理归 B10。

# ③ 自律细胞：为什么窦房结能自动发令

## KP06｜窦房结P细胞：没有稳定静息，也没有平台期

> **讲义定位 →** P140–141。  
> **主提示**：最大复极电位；0、3、4期；为什么没有1、2期；0期为何慢；4期为何自动去极化。

窦房结 P 细胞是慢反应自律细胞：

- 无稳定静息电位，用“最大复极电位”描述，Study约 `-65 mV`；
- 4期自动去极化；
- 0期主要 ICa-L；
- 无明显1、2期平台；
- 3期主要 IK。

```text
0期依赖慢Ca²⁺通道
→ 开放 / 内流较慢
→ 0期速度与幅度小
→ 传导慢
```

自律性最高看的是**4期自动去极化最快**，不是0期最快。

---

## KP07｜窦房结4期：外向电流减弱 + 内向电流增强

> **讲义定位 →** P141。  
> **主提示**：IK、If、ICa-T、Na-Ca交换如何加入；谁是Study主导；达到阈值后谁形成0期。

```text
外向K⁺电流逐渐减少
+
内向Na⁺ / Ca²⁺相关电流逐渐增加
→ 4期自动去极化
```

- **IK逐渐减少**：当前 Study 主导机制；约 -50mV后衰减 → K⁺外流减少。
- **If**：复极 / 超极化方向激活；约 -60mV开始，需更深超极化才大量激活。窦房结最大复极电位不够负，所以参与但非 Study 主导；铯、伊伐布雷定抑制。
- **ICa-T**：4期后段约 -50mV加入，加速到 ICa-L 阈值。
- **Na-Ca交换**：参与内向电流。
- 达约 -40mV → ICa-L大量开放 → 新0期。

（易混：If不是快钠通道 INa。If在自律细胞4期；INa在快反应细胞0期。）

# ④ 兴奋性与不应期：什么时候还能再产生动作电位

## KP09｜ERP、相对不应期与超常期

> **讲义定位 →** P142。  
> **主提示**：三个时期对应膜电位、兴奋性、刺激要求、机械时相；ERP为何覆盖收缩期和舒张早期。

**ERP**：当前 Study 从 0期开始到3期复极约 -60mV，包括绝对不应期和局部反应期；兴奋性为0或极低，不能产生正常传播 AP，约覆盖整个收缩期和舒张早期。

**相对不应期**：约 -60→-80mV；部分Na通道恢复，兴奋性低于正常，需要阈上刺激；新AP幅度小、0期慢、传导慢、时程 / 不应期短。

**超常期**：约 -80→-90mV；多数Na通道恢复且膜电位相对接近阈值，兴奋性可高于正常，阈下刺激也可能触发。

```text
长ERP覆盖收缩期
→ 第二个兴奋不能叠加
→ 心肌不能完全强直
→ 必须保留舒张 / 充盈
```

## KP10｜期前兴奋、早搏与代偿间歇

> **讲义定位 →** P142–143。  
> **主提示**：何时可发生期前兴奋；为什么不是每次早搏都必有代偿间歇。

越过 ERP 进入相对不应期 / 超常期后，如果下一窦性冲动前异位点给出足够刺激，可提前兴奋 → 期前收缩 / 早搏。

期前兴奋本身又产生 ERP：

```text
下一次窦性冲动
若落入该ERP
→ 冲动作废
→ 无新心室收缩
→ 较长舒张间歇
```

所以早搏后不一定总有代偿间歇；关键是下一窦性冲动是否撞进 ERP。

## KP11｜APD与ERP：一个看复极，一个看再次去极化能力

> **讲义定位 →** P143。  
> **主提示**：APD与ERP各反映什么；ⅠA与ⅠB怎样改变二者。

```text
APD：0期开始 → 3期复极完成
→ 主要反映复极速度 / K⁺通道状态

ERP：快钠通道失活到逐渐恢复
→ 反映再次完成有效去极化的能力
```

ⅠA奎尼丁：INa↓ → ERP延长明显，APD也轻度延长 → `ERP/APD↑`。

ⅠB利多卡因：更突出抑制 INa,late → APD缩短明显；ERP也缩短但少于APD → `ERP/APD↑`。

两者都使快速冲动更容易落入相对较长的有效不应状态。完整药理归 B10。

## KP12｜兴奋性三个决定因素：通道状态、膜—阈距离、过度去极化

> **讲义定位 →** P143–144。  
> **主提示**：兴奋性定义；通道失活；膜—阈距离；轻重高低钾；葡萄糖酸钙拮抗高钾。

兴奋性：受刺激后产生 AP 的能力，Study 用阈强度衡量。

```text
Na⁺ / Ca²⁺通道完全失活 → 兴奋性0
膜与阈距离远 → 兴奋性↓
距离适度变近 → 兴奋性↑
持续去极化、距离“过近” → 通道失活 / 去极化阻滞 → 兴奋性↓
```

| 情况 | Study方向 | 切入点 |
|---|---|---|
| 轻度低K⁺ | ↑ | K⁺电导 / 通透性改变 |
| 严重低K⁺ | ↓ | 严重失衡可致骤停 |
| 轻度高K⁺ | ↑ | 膜去极化、靠近阈值 |
| 严重高K⁺ | ↓ | 持续去极化 → 通道失活 |

严重高钾使用葡萄糖酸钙的 Study 解释：Ca²⁺膜屏障作用 → Na⁺通透性下降 / 阈值上移 → 重新拉开膜—阈距离 → 拮抗心脏毒性。

Ca²⁺对窦房结、房室结、工作细胞影响不同，必须先判细胞类型。

# ⑤ 传导与起搏：兴奋怎样分发到全心

## KP13｜传导性的三类决定因素

> **讲义定位 →** P144–145。  
> **主提示**：0期速度 / 幅度；邻旁兴奋性；细胞直径、闰盘、分化。

最主要：已兴奋细胞0期速度和幅度。

```text
0期越快 → 局部电流形成越快
0期幅度越大 → 电位差越大 → 局部电流越强 → 传导越快
```

0期受通道电导 / 通透性 + 电化学驱动力影响：快反应看Na⁺，慢反应看Ca²⁺。

邻旁细胞：膜—阈距离近 → 易激活 → 传导快；持续去极化使Na通道失活 → 传导障碍。

结构：细胞直径大→内阻小；闰盘 / 缝隙连接多→低阻；分化程度高→传导功能完善。

## KP14｜浦肯野最快、房室结最慢：速度差本身就是功能

> **讲义定位 →** P145。  
> **主提示**：谁最快 / 最慢；为什么；Ⅰ类药和维拉帕米怎样按细胞类型减慢传导。

```text
浦肯野：快反应 + INa陡峭高幅0期 + 结构适合快速传导
→ 全心最快
→ 心室近乎同步激活
```

```text
房室结：慢反应 + 0期ICa-L
→ 0期慢 / 幅度小
→ 全心最慢
→ 房室延搁，为心室充盈留时间
```

Ⅰ类药阻 INa → 快反应细胞0期速度 / 幅度↓ → 传导↓。

维拉帕米阻 ICa-L → 房室结0期↓ → 传导↓，可打断房室结折返接口。完整室上速归 B10。

## KP15｜自律性层级、抢先占领与超速驱动阻抑

> **讲义定位 →** P145–146。  
> **主提示**：固有频率层级；窦房结为何正常起搏；抢先占领；超速驱动阻抑；逸搏 vs 主动异位；人工起搏不能骤停。

```text
窦房结自律性最高
> 房室结
> 浦肯野最低
```

衡量自律性主要看自动兴奋频率。

**抢先占领**：潜在起搏点4期未达阈值，窦房结冲动已先到 → 被重置 → 表现窦律。

**超速驱动阻抑**：潜在起搏点长期被高于自身固有频率的冲动驱动；外来高频突然停止后不能立刻恢复，需静止期。因此人工起搏若中断不宜骤停，应逐渐降低频率。

```text
异位点自律性主动超过窦房结
→ 主动异位：早搏 / 自主性心动过速接口

窦房结过慢或下传受阻
→ 下位点被迫接管
→ 被动异位：逸搏 / 逸搏心律接口
```

## KP16｜自律性决定因素 + Ca²⁺对不同细胞方向不同

> **讲义定位 →** P146。  
> **主提示**：4期斜率；最大复极电位—阈值距离；Ca²⁺对窦房结与浦肯野为何不同。

```text
4期外向K⁺减少更快
或内向Na⁺ / Ca²⁺增加
→ 4期斜率↑ → 更快到阈值 → 自律性↑
```

最大复极电位到阈值距离越近，自律性越高；越远越低。

按 Study：

- **窦房结**：胞外Ca²⁺↑ → ICa-L驱动力↑（0期 / 传导↑）+ ICa-T↑（4期 / 自律↑）。
- **浦肯野**：胞外Ca²⁺↑ → Ca²⁺膜屏障影响Na⁺内流 → 0期INa与4期If相关效应受抑 → 传导 / 自律 / 兴奋性下降方向。

不能从“Ca²⁺↑”直接推出所有心肌细胞同向变化。

# ⑥ 电信号怎样变成机械力

## KP17｜心肌收缩四个特征：CICR、功能合胞体、长ERP和长度—张力

> **讲义定位 →** P147–148。  
> **主提示**：为何依赖细胞外Ca²⁺；CICR；全或无同步；为何无空间总和 / 完全强直；长度—张力；收缩性因素。

```text
平台期ICa-L开放
→ 少量细胞外Ca²⁺进入
→ 激活SR RyR
→ Ca²⁺触发Ca²⁺释放 CICR
→ 胞质Ca²⁺↑
→ 肌钙蛋白 / 横桥活动
→ 收缩
```

心肌 SR 不如骨骼肌发达，对细胞外Ca²⁺触发更依赖；CCB可抑制心肌收缩。

闰盘 / 缝隙连接使心房和心室分别成为功能合胞体 → 近乎同步“全或无”收缩；收缩强度仍可由每个细胞Ca²⁺ / 横桥改变，并不是每搏固定。

```text
平台期长 → ERP覆盖收缩期
→ 无时间总和 / 完全强直
→ 保留舒张与充盈
```

生理范围内心肌长度—张力曲线无明显降支，与伸展性小 / 连接蛋白限制有关。

收缩性主要看活化横桥数目（Ca²⁺）与横桥ATP酶活性等。

## KP18｜心肌与骨骼肌：相同横纹结构，不同电—机械规则

> **讲义定位 →** P147–148。  
> **主提示**：神经、受体、AP、耦联、Ca²⁺源、CCB、空间 / 时间总和、长度—张力。

| 维度 | 骨骼肌 | 心室肌 |

| 神经 | 运动神经ACh | 自主神经调节 |
| 受体 | N2 | β1、M等 |

# ⑦ 自主神经 / 药物怎样修改电生理

## KP19｜儿茶酚胺：β1—cAMP—PKA把起搏、传导、收缩与舒张一起加速

> **讲义定位 →** P149–150；**讲义回看 →** B2。  
> **主提示**：β1信号；工作细胞平台Ca²⁺；慢反应0期；窦房结4期；受磷蛋白；左右交感。

```text
NA / Adr → β1 → G蛋白—AC
→ cAMP↑ → PKA → 通道 / 蛋白磷酸化
```

四类效应：

- **收缩性↑**：工作细胞平台 ICa-L↑ → Ca²⁺内流 / CICR↑。
- **舒张速度↑**：受磷蛋白磷酸化 → SR Ca²⁺泵回收加快。
- **传导性↑**：慢反应细胞0期 ICa-L↑ → 0期速度 / 幅度↑。
- **心率 / 自律性↑**：窦房结4期 ICa-T、If等内向电流↑ → 斜率↑。

不是简单“通过 IK”。按 Study：右交感更偏窦房结 / HR；左交感更偏房室交界和心室肌 / 传导与收缩。

## KP20｜ACh与迷走：室上结构为主的四负效应

> **讲义定位 →** P149–150；**讲义回看 →** B2。  
> **主提示**：M受体；ICa-L、ICa-T、If、IK-ACh；心房、窦房结、房室结分别怎样；迷走分布。

- **心房收缩性↓**：抑平台 ICa-L + 激活 IK-ACh → 平台缩短、Ca²⁺内流↓。
- **房室传导↓**：抑房室结0期 ICa-L。
- **窦房结自律性 / HR↓**：抑4期 ICa-T、If + 激活 IK-ACh → 4期斜率↓且最大复极电位更负、离阈值更远。
- **分布**：右迷走更偏窦房结；左迷走更偏房室交界；对心室肌支配少，因此负性收缩效应以心房更突出。

ACh不是一句“膜超极化”即可概括；必须先看细胞位置和电流。

## KP21｜E-4031 vs ACh + 最终电生理算法

> **讲义定位 →** P150–152。  
> **主提示**：E-4031怎样从IK影响最大复极电位与If；ACh另一切入点；陌生题先判五层。

按当前 Study：

```text
E-4031抑制窦房结IK
→ 最大复极不够负
→ If激活不足
→ 4期自动去极化受影响
→ 自律性↓
```

ACh：促进 IK-ACh，使最大复极更负，同时抑 If / ICa-T。两者都可使自律性↓，但路径不同。

最终遇到任何题：

```text
1. 哪种细胞？
   快 / 慢反应；工作 / 自律
2. 哪一期？
   0 / 1 / 2 / 3 / 4
3. 哪个电流？
   INa / INa,late / Ito / ICa-L / ICa-T / IK / IK1 / If / IK-ACh...
4. 问哪种性质？
   兴奋 / 传导 / 自律 / 收缩 / APD / ERP
5. 落到哪一层？
   单细胞AP / 全心传导 / ECG / 机械泵血
```

不能从“某离子↑”直接跳到“心率↑ / 传导↑ / 收缩↑”。
