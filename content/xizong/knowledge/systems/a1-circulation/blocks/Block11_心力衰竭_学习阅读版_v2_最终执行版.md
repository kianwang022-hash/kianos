# Block 11｜心力衰竭 · 学习阅读版 v2｜最终执行版
## 多种上游疾病为什么汇合成同一个综合征

> **中心问题**：心脏收缩或充盈异常怎样同时造成前向低灌注与后向淤血，并通过神经体液代偿形成恶性循环；又怎样根据表型、病因与诱因、湿冷状态和证据选择治疗目标？

# 先建立脑内模型：心衰不是“心脏停了”

心衰是各种原因导致心脏结构和 / 或功能异常，使心脏出现收缩和 / 或充盈功能障碍，在静息或运动时出现：

```text
心排血量不足
或
必须靠更高心腔充盈压才能维持输出
```

所以不要先从 EF 分类开始。先抓住共同电影：

```text
泵不出去 / 充不进去
→ 有效 SV、CO下降，或充盈压被迫升高
        ↓
前向：组织和肾灌注不足
后向：上游心房、静脉与毛细血管压力升高
        ↓
交感↑、RAAS↑、醛固酮↑、ADH↑
→ HR / 收缩性↑、血管收缩、水钠潴留
        ↓
短期：保压、保灌注、提高回心
长期：耗氧↑、后负荷↑、充盈压↑、淤血↑、肥大 / 纤维化 / 重构
        ↓
泵与充盈进一步恶化
```

这条链直接解释两个看似矛盾的现象：

```text
前向低灌注 + 后向淤血可以同时存在

全身总水量很多
≠ 有效循环量 / 器官灌注足够
```

因此患者可以**全身水肿，却仍让肾脏读到“有效循环量不足”并继续保钠保水**。

再把淤血方向放回串联泵：

```text
左心问题
→ 左房 / 肺静脉压力↑
→ 肺淤血

右心问题
→ 右房 / 体静脉压力↑
→ 体静脉淤血
```

> 后面的 HFrEF / HFpEF、左 / 右心衰、干湿冷暖和所有治疗，都是在这张图上定位，不是另一套知识。

# ① 分型、分期与严重度：这是给共同机制贴标签，不是学习起点

<!-- kianos:kp id="circulation-b11-kp01" -->

## KP01｜按 LVEF 分型：EF回答射血比例，不等于完整泵功能

> **讲义定位 →** 内科 P355。  
> **主提示**：四种 EF 分型；HFrEF vs HFpEF 的核心；为何 HFpEF 仍可心衰。

| 类型 | LVEF | 当前 Study 身份 |
|---|---:|---|
| HFrEF | ≤40% | 射血分数降低；传统“收缩性心衰”主体 |
| HFmrEF | 41%–49% | 射血分数轻度降低 |
| HFpEF | ≥50% | 射血分数保留；通常有充盈压升高 / 舒张功能受损，既往常称“舒张性心衰” |
| HFimpEF | 既往≤40%，治疗后＞40% | 射血分数改善型 |

```text
HFrEF
→ 收缩性下降突出
→ ESV↑、EF↓

HFpEF
→ 常见顺应性下降 / 主动舒张异常
→ 心室不易充盈、充盈压↑
→ EF可保留但患者仍可明显淤血、呼吸困难
```

> **边界**：HFpEF 不能机械等同于“只有舒张异常”。当前 Study 自身也提示 HFrEF 常合并舒张功能不全，而 HFpEF 也可存在一定程度的收缩功能异常；EF 是分型轴，不是全部机械功能。

（易混：EF是 `SV/EDV`；EF正常不等于舒张功能、充盈压、CO储备均正常。）

<!-- kianos:kp id="circulation-b11-kp02" -->

## KP02｜A–D 分期：描述疾病进展，治疗只能延缓，不轻易逆转阶段

> **主提示**：A、B、C、D；心功能不全与有症状心衰边界。

| 分期 | 状态 |
|---|---|
| A | 只有高危因素，如高血压、冠心病危险因素；无结构异常、无症状 |
| B | 前心衰：已有结构改变、充盈压 / 标志物异常，但无症状 |
| C | 症状性心衰：既往或目前有症状 / 体征 |
| D | 晚期心衰：优化治疗后仍明显症状、反复住院，可有心源性恶病质 |

无症状性收缩功能减退时：

```text
收缩性↓
→ ESV↑
→ EDV↑
→ Frank–Starling暂时维持SV
→ 但EF已下降，神经体液系统已激活
```

因此 LVEF 比单次 SV 更敏感地暴露早期射血功能减退。

<!-- kianos:kp id="circulation-b11-kp03" -->

## KP03｜NYHA、Killip 与 6 分钟步行分别回答什么

> **主提示**：NYHAⅡ–Ⅳ；急性心梗为什么用Killip；6MWT轻中重。

### NYHA

- Ⅰ：日常活动不受限；
- Ⅱ：休息无症状，一般活动出现症状；
- Ⅲ：活动明显受限，较轻活动即出现症状，夜间憋醒坐起后缓解接口；
- Ⅳ：静息也有症状，不能平卧 / 任何活动均加重。

（易混：端坐呼吸不能机械等同于NYHAⅣ；Study 强调“夜间躺下后坐起可缓解”可在Ⅲ级，而持续半卧、完全躺不下更接近Ⅳ级。）

### Killip

急性心肌梗死并发心衰采用：

```text
I 无心衰
II 肺啰音＜50%肺野等
III 肺水肿 / 啰音＞50%
IV 心源性休克
```

陈旧性心梗导致慢性心衰仍按 NYHA。

### 6分钟步行

按 Study：

```text
＜150m 重度
150–450m 中度
＞450m 轻度
```

# ② 病因与诱因

<!-- kianos:kp id="circulation-b11-kp04" -->

## KP04｜病因两大类：“泵本体坏了”或“长期负荷不对”

> **讲义定位 →** P356。  
> **主提示**：原发 / 继发心肌损害；压力负荷、容量负荷、前负荷不足。

### 心肌损害

- 原发：缺血（冠心病最主要）、炎症 / 免疫（心肌炎、扩心病接口）、遗传（HCM、DCM等）；
- 继发：糖尿病、甲亢 / 甲减、浸润、心脏毒性药物等。

### 负荷异常

```text
后负荷 / 压力负荷过重
→ 高血压、主动脉瓣狭窄、肺动脉高压、肺动脉瓣狭窄

前负荷 / 容量负荷过重
→ 瓣膜关闭不全、动脉导管未闭、间隔缺损、高排量状态

充盈入口受限 / 前负荷不足接口
→ 二尖瓣狭窄等“左室没血可充”
```

压力负荷常先向心性肥厚；容量负荷常先扩张 / 离心性重构。超过代偿后均可进入心衰。

<!-- kianos:kp id="circulation-b11-kp05" -->

## KP05｜诱因：本来能勉强维持的系统被一次额外负担推入失代偿

> **主提示**：最常见诱因；房颤、容量、劳累、治疗不当；病因 vs 诱因。

常见诱因：

- 呼吸道感染最常见；
- 心律失常，尤其房颤；
- 输液过多过快、血容量增加；
- 过度劳累、情绪激动、妊娠后期 / 分娩；
- 不恰当停药；
- 原有心脏病突然加重。

```text
病因
放在原本健康心脏上也足以造成长期结构 / 功能损害

诱因
使已有心脏病的代偿平衡突然被打破
```

急性心梗若直接造成心衰，是病因；既往心梗后长期稳定，后来因其他事件失代偿，旧心梗可作为基础病因，而感染 / 房颤等是当前诱因。

# ③ 共同机制再压缩：把开篇模型变成可闭卷推导链

<!-- kianos:kp id="circulation-b11-kp06" -->

## KP06｜心衰共同电影

> **讲义回看 →** B1、B2、当前 Study。  
> **主提示**：泵 / 充盈异常→低灌注 / 淤血→交感 / RAAS / ADH→重构→恶性循环。

```text
泵 / 充盈异常
→ 有效SV和CO下降，或必须靠更高充盈压维持输出
→ 前向低灌注 + 后向淤血
→ 交感 / RAAS / 醛固酮 / ADH激活
→ 短期保压保容量
→ 长期耗氧、后负荷、充盈压与重构进一步上升
→ 泵与充盈继续恶化
```

ANP / BNP 是室壁牵张后的反向卸货信号，是代偿 / 标志物，不是心衰病因。

# ④ 左、右、全心衰

<!-- kianos:kp id="circulation-b11-kp07" -->

## KP07｜左心衰：必须关注肺

> **讲义定位 →** P357。  
> **主提示**：呼吸困难顺序、咳痰 / 咯血、急性肺水肿、心脏体征、发绀。

### 肺淤血表现

- 咳嗽、白色泡沫痰、双肺湿啰音；
- 劳力性呼吸困难：最早但缺乏特异性；
- 夜间阵发性呼吸困难、端坐呼吸：更有特点；
- 急性肺水肿 / 心源性哮喘：粉红色泡沫痰、明显呼吸困难、湿啰音或干湿共存。

夜间 / 仰卧加重的 Study 链：

```text
回心血量↑
+ 膈肌上移、肺活量↓
+ 迷走张力↑、支气管收缩
+ 熟睡时呼吸中枢敏感性↓
→ 呼吸困难加重
```

咯血：痰中带血与肺毛细血管淤血相关；大咯血可与压力经侧支传至支气管静脉并破裂相关。

### 心脏体征

- 心尖向左下移；
- 相对性二尖瓣关闭不全 → 心尖部收缩期杂音；
- S1减弱；
- S3奔马律；
- 交替脉。

### 心源性哮喘 vs 支气管哮喘

| 维度 | 心源性哮喘 | 严重支气管哮喘 |
|---|---|---|
| 呼吸困难 | 混合性、常端坐 | 呼气性为主 |
| 痰 | 可粉红泡沫痰 | 一般无 |
| 啰音 | 湿啰音或干湿共存 | 干啰音，严重可沉默肺 |
| X线 | 左心扩大、肺淤血 / 蝴蝶征 | 可无明显异常或透亮度↑ |

<!-- kianos:kp id="circulation-b11-kp08" -->

## KP08｜右心衰：必须关注体静脉

> **讲义定位 →** P357。  
> **主提示**：最有价值体征、消化道、肝、颈静脉、水肿、胸腹水、心脏体征。

```text
右心射血能力下降
→ 肺循环血流下降
→ 右房 / 体静脉压力升高
→ 体循环淤血
```

主要表现：

- 颈静脉怒张；
- **肝颈静脉回流征阳性：诊断右心衰最有价值体征**；
- 肝大、压痛，长期可心源性肝硬化；
- 胃肠淤血：腹胀、食欲下降、恶心等；
- 双下肢对称性、凹陷性、低垂部位水肿；
- 胸水、腹水，多为漏出液；
- 心尖多向左移，胸骨左缘4–5肋间收缩期杂音、奔马律；当前 Study 另保留严重右心衰可见奇脉 / 吸停脉的精确接口。

（易混：单侧不对称肢体肿痛先考虑DVT；甲减黏液性水肿多为非凹陷性。奇脉不是右心衰的第一定位征，只作为当前 Study 的低权重精确点保留。）

<!-- kianos:kp id="circulation-b11-kp09" -->

## KP09｜左心衰发展到右心衰后，肺淤血为什么可减轻

> **主提示**：串联泵；全心衰时“肺里进的血少了”。

```text
原先左心衰
→ 左房和肺静脉压力↑
→ 肺淤血

随后右心也衰
→ 右室向肺循环射血↓
→ 肺循环输入减少
→ 肺淤血症状可相对减轻
```

这不代表病情好转，而是前向输出进一步下降、体静脉淤血加重。

# ⑤ 辅助检查与证据职责

<!-- kianos:kp id="circulation-b11-kp10" -->

## KP10｜血流动力学：Swan-Ganz 是 Study 金标准

> **讲义定位 →** P358。  
> **主提示**：PAWP / PCWP、CVP、CO、CI方向；HFpEF侵入性确诊接口。

左心衰常见：

```text
PAWP / PCWP ↑
CVP 可↑（尤其全心衰）
CO ↓
CI ≤2.2 接口
```

Study 常用参考：PAWP / PCWP 正常＜12mmHg，左心衰可≥18mmHg；CVP正常约5–10cmH₂O；CO正常约＞5L/min；CI正常约＞2.5。

无创不能确诊 HFpEF 的劳力性呼吸困难者，可用静息 / 负荷 PCWP 或 LVEDP 辅助确认，精确阈值进入 MI-D。

<!-- kianos:kp id="circulation-b11-kp11" -->

## KP11｜影像：超声首选，MRI看容积 / 室壁运动，X线看肺淤血

> **主提示**：各检查职责。

- 超声心动图：心衰首选影像；看LVEF、心腔、瓣膜、室壁和舒张功能；
- 心脏MRI：评价心室容积和室壁运动的 Study 金标准；
- X线：
  - 上肺纹理增多、肺门增大；
  - Kerley B线：慢性间质性肺水肿；
  - 肺门蝴蝶征：急性肺泡性肺水肿。

（易混：LVEF确认“比例”，超声 / MRI还要看心腔、室壁和瓣膜；X线主要看心影和肺淤血。）

<!-- kianos:kp id="circulation-b11-kp12" -->

## KP12｜BNP / NT-proBNP 与心肺运动试验

> **主提示**：来源、诊断排除、严重度 / 预后、局限；CPET作用。

### BNP

- 主要来源于心室；
- 室壁张力 / 牵张增加时释放；
- 增高程度与心衰严重度正相关，可评估预后；
- 正常值有助排除急性 / 慢性心衰；
- Study 提醒约20% HFpEF患者可有正常脑钠肽。

具体急慢性排除阈值进入 MI-D。

### 心肺运动试验

用于症状和静息检查不完全匹配者评估运动能力、治疗和预后；最大耗氧量、无氧阈等反映功能损害，精确分层进入 MI-D。

# ⑥ 急性心衰：先看淤血与低灌注

<!-- kianos:kp id="circulation-b11-kp13" -->

## KP13｜急性心衰四象限：先判断“湿不湿、冷不冷”

> **讲义定位 →** P359–360。  
> **主提示**：湿/冷分别看什么｜四象限｜最常见｜最严重

| 类型 | 淤血 | 低灌注 | 感性身份 |
|---|---|---|---|
| 干暖 | 无 | 无 | 相对稳定 |
| 干冷 | 无 | 有 | 低输出、可能容量不足 / 泵弱 |
| 湿暖 | 有 | 无 | 最常见，淤血突出但灌注尚可 |
| 湿冷 | 有 | 有 | 最严重，淤血 + 低灌注 |

```text
湿：颈静脉、肺啰音、水肿、充盈压↑
冷：低血压、少尿、意识差、皮肤冷、器官灌注不足
```

<!-- kianos:kp id="circulation-b11-kp14" -->

## KP14｜急性处理的四个目标

> **主提示**：氧合、充盈压、血压、灌注；为什么不能见肺水肿就一律利尿 / 扩管。

```text
1. 改善氧合与呼吸困难
2. 降低过高充盈压和淤血
3. 维持足够血压
4. 恢复组织灌注并处理诱因
```

- 湿暖：利尿、静脉扩张 / 降前负荷等；
- 干冷：评估是否容量不足，必要时补液试验或正性肌力；
- 湿冷且SBP＜90：先正性肌力 / 血管收缩维持灌注，低灌注纠正后再利尿；
- 高血压急症伴急性肺水肿：硝普钠等扩张动静脉可降前后负荷；
- 低血压 / 休克、HCM、AS、急性右室梗死等禁忌 / 慎用扩血管。

> **核心边界**：急性心衰“减负荷”成立的前提是仍有足够灌注；已休克时继续扩血管可加重低灌注。

<!-- kianos:kp id="circulation-b11-kp15" -->

## KP15｜急性药物与非药物按功能归类

> **主提示**：利尿、扩管、正性肌力、血管收缩；机械 / 呼吸支持接口。

| 目标 | Study代表 |
|---|---|
| 利尿降容量 | 袢利尿剂等 |
| 静脉 / 动脉扩张 | 硝酸酯、硝普钠、奈西立肽等按血压选择 |
| 正性肌力 | 多巴酚丁胺、多巴胺、米力农、左西孟旦、毛花苷丙等按场景 |
| 血管收缩保灌注 | 去甲肾上腺素等 |
| 其他 | 吸氧 / 通气、处理ACS / 节律 / 感染、机械循环支持接口 |

β受体激动剂、PDE抑制剂等增加心肌耗氧，低灌注纠正后应尽早停用；不是慢性抗重构药。

# ⑦ 慢性 HFrEF 治疗

<!-- kianos:kp id="circulation-b11-kp16" -->

## KP16｜治疗目标分三层：改善结局、改善症状、处理诱因 / 合并症

> **主提示**：哪些是抗重构，哪些主要控容量 / 症状。

```text
改善长期结局
→ 抑制交感 / RAAS / 醛固酮、SGLT2、sGC、CRT / ICD等

改善症状
→ 利尿、适当扩血管、特定正性肌力 / 控率

处理诱因和上游病因
→ 缺血、瓣膜、房颤、感染、高血压、贫血、甲状腺等
```

（易混：利尿很重要，但主要改善淤血和症状；不能把“症状改善”自动等同于“降低死亡率”。）

<!-- kianos:kp id="circulation-b11-kp17" -->

## KP17｜Study“降低死亡率五朵金花”与共同逻辑

> **讲义定位 →** P360–361。  
> **主提示**：五类及其机制角色；禁忌数字进入MI-D。

按本节 Study：

1. ACEI / ARB / ARNI；
2. β受体拮抗剂；
3. MRA；
4. SGLT2抑制剂；
5. sGC刺激剂。

共同逻辑：

```text
阻断长期交感 / RAAS / 醛固酮
+ 减少水钠和压力负担
+ 抑制肥厚、纤维化和重构
→ 延缓疾病进展、改善预后
```

<!-- kianos:kp id="circulation-b11-kp18" -->

## KP18｜ACEI / ARB / ARNI、MRA、SGLT2i、sGC

> **主提示**：作用链和主要限制。

- ACEI / ARB / ARNI：降低AngⅡ / AT₁效应，减少血管收缩、醛固酮、重构；ARNI同时增强利钠肽等；
- MRA：阻断醛固酮保钠排钾和重构，为保钾利尿 / 抗重构；
- SGLT2i：近端小管排糖排钠、减轻容量负担并有心肾保护接口；
- sGC刺激剂：增强NO–sGC–cGMP方向，扩血管 / 抗重构接口。

高钾、肾功能、低血压、双侧肾动脉狭窄、妊娠等具体禁忌与阈值进入 MI-D，保留 Study 口径。

<!-- kianos:kp id="circulation-b11-kp19" -->

## KP19｜β受体拮抗剂：慢性稳定期抗重构，不是急性休克时强行压心率

> **主提示**：适应证、常用药、何时不用、急性失代偿是否停。

常用 Study 代表：美托洛尔缓释、比索洛尔、卡维地洛等。

```text
长期交感激活
→ 心率 / 耗氧↑、β受体脱敏、重构、心律失常风险↑

β阻断
→ 慢性稳定期降低交感毒性
→ 延缓进展、减少猝死
```

通常不用 / 慎用：

- 心源性休克、明显低灌注；
- 严重缓慢节律、SSS、二度Ⅱ型 / 三度AVB；
- 支气管哮喘、变异型心绞痛、雷诺等 Study 接口；
- 急性失代偿期若无休克，原已长期服用者常继续，避免反跳；具体调整按Study。

<!-- kianos:kp id="circulation-b11-kp20" -->

## KP20｜利尿剂：改善液体潴留症状的基石

> **主提示**：什么时候用；袢、噻嗪、保钾、V2拮抗剂角色；过量风险。

只要存在明显体液潴留，利尿剂可改善淤血。剂量不足 → 淤血持续；剂量过大 → 容量不足、低血压、肾功能恶化。

- 袢利尿剂：强效，GFR低时仍常用；低钾、耳毒性接口；
- 噻嗪：中效，GFR明显下降时作用受限；低钾、高尿酸等接口；
- 保钾：MRA或ENaC抑制剂，常与排钾利尿剂合用；
- V2拮抗剂：减少水重吸收，低钠 / 利尿抵抗接口。

<!-- kianos:kp id="circulation-b11-kp21" -->

## KP21｜伊伐布雷定、强心苷、血管扩张剂、CRT 与 ICD

> **讲义定位 →** P362。  
> **主提示**：谁减窦性心率、谁强心兼抑房室结、谁改善同步、谁防猝死。

### 伊伐布雷定

选择性抑制窦房结 If；用于窦性心律、HR仍快、β受体拮抗剂基础上仍符合条件的慢性HFrEF。房颤和急性心衰不用，精确阈值进入 MI-D。

### 强心苷

```text
抑制Na⁺-K⁺泵
→ 胞内Na⁺↑
→ Na⁺-Ca²⁺交换反向
→ 胞内Ca²⁺↑
→ 正性肌力
```

同时抑制房室结、增强迷走。适合收缩性心衰合并快房颤 / 房扑或AVNRT等特定场景；预激、SSS、二度Ⅱ / 三度AVB、急性MI早期、重症心肌炎早期、HCM / AS、二狭窦性心律、电复律等Study禁忌进入MI-D。

### 血管扩张剂

用于不耐受ACEI / ARB或合并心绞痛 / 高血压等特定场景；SBP＜90、HCM、AS、急性右室MI等不用 / 慎用。

### CRT

改善房室、室间 / 室内收缩不同步，提高有效输出。Study 典型：优化药物后仍有症状、窦性心律、完全性LBBB、QRS延长、LVEF≤35%、NYHAⅡ–Ⅳ等。

### ICD

预防 / 终止室颤、持续性室速所致猝死。它不直接改善机械同步；CRT与ICD可组合，但任务不同。

# ⑧ HFpEF：以充盈压 / 舒张障碍为核心，但不等同于“只有舒张异常”

<!-- kianos:kp id="circulation-b11-kp22" -->

## KP22｜HFpEF：泵不一定弱，但“泵硬、充不进去、压力高”

> **主提示**：基础病、核心障碍、PV环 / 压力、超声指标。

常见背景：高血压导致左室肥厚、HCM、限制性心肌病、老龄等。

```text
顺应性下降
或
主动舒张耗能 / Ca²⁺回收异常
→ 心室舒张不充分
→ 同一容积需要更高舒张压
→ 左房 / 肺静脉压力↑
→ 呼吸困难、肺淤血
```

PV环感性：舒张期压力—容积关系上移 / 左移，EDV可不大，LVEF可保留。超声看 E/e′、E/A 等舒张功能证据，具体阈值进入 MI-D。

<!-- kianos:kp id="circulation-b11-kp23" -->

## KP23｜HFpEF 治疗：控制上游病因、延长充盈、适量减淤血，避免盲目强心

> **主提示**：β阻断、ACEI / ARB / ARNI、CCB、利尿、为何禁强心苷。

- 控制高血压、缺血、房颤和心动过速；
- β受体拮抗剂降低HR、延长舒张，HCM尤其适用；
- ACEI / ARB / ARNI用于高血压、肥厚等背景；
- 非二氢吡啶CCB可改善舒张 / 控率接口；
- 利尿减淤血但避免过量导致前负荷和充盈不足；
- 强心苷等正性肌力药不能改善顺应性，反而可能增加耗氧 / 梗阻，因此一般不用。

（易混：HFrEF和HFpEF都可淤血、都可用适量利尿；但“长期结局药”和“盲目强心”的适用边界不同。）

# ⑨ 最终病例算法

## KP24｜心衰六问

> **主提示**：分型、方向、时程、湿冷、病因诱因、治疗目标。

```text
1. 共同故障是什么：输出不足、充盈压升高，还是二者都有？
2. 主要是左、右还是全心衰？
3. HFrEF、HFmrEF、HFpEF还是HFimpEF？
4. 急性还是慢性；病因和当前诱因是什么？
5. 当前湿不湿、冷不冷？哪一层证据最能校准？
6. 当前目标是什么：氧合、利尿、扩管、强心、抗重构、控节律、器械或处理病因？
```

## 三个反事实

### EF正常但呼吸困难、左房压高

```text
不排除心衰
→ 考虑HFpEF / 舒张障碍
```

### 水肿明显但肾仍保钠保水

```text
总水量多
≠ 有效前向灌注足
→ 肾读取的是灌注 / 有效循环量
```

### 左心衰肺淤血后来减轻但全身水肿加重

```text
右心进一步衰竭
→ 肺循环输入减少
→ 肺淤血相对减轻
→ 体静脉淤血加重
```
