# Block 2｜循环调节与容量控制 · 学习阅读版 v4
## 为什么短期救命，长期却可能伤心

> **中心问题**：体位、运动、失血或容量变化时，感受器、神经、儿茶酚胺、RAAS、ADH、利钠肽和局部介质怎样按时间接力，既保住重要器官灌注，又解释长期激活为何会反噬？

# 先看一遍整套调节系统

B1 已经给出被调变量：

```text
CO = HR × SV
MAP ≈ CO × TPR
SV受前负荷、后负荷、收缩性影响
静脉容量与CVP影响回心
微动脉影响TPR和器官血流
```

B2 只回答：**这些变量偏离时，谁发现、谁下命令、谁执行、谁负责长期容量，局部组织又怎样修正全身命令。**

最典型的急性失血电影：

```text
失血
→ 血容量↓、回心↓、SV / CO / MAP↓
        ↓
秒级：窦弓等感受器
→ 交感↑、迷走↓
→ 强心 + 夹微动脉 + 挤静脉
        ↓
分钟级：儿茶酚胺、AngⅡ等放大
        ↓
小时级：醛固酮、ADH、口渴
→ 保Na⁺、保水
        ↓
天级：肾—体液系统重建ECF / 血容量
        ↓
局部代谢 / 内皮持续修正器官血流
```

这套系统没有固定的“好 / 坏”：

```text
急性低灌注
→ 保压、保容量、保心脑

长期持续激活
→ 耗氧↑、后负荷↑、水钠潴留、充盈压↑、纤维化 / 重构
→ 反而推动高血压和心衰恶化
```

# ① 感知：谁先发现循环变量偏了

## KP01｜急性失血后，循环调节怎样按时间接力

> **讲义回看 →** P153–161、P280–284；并调用 Block 1 的 P/Q/R/V。  
> **主提示**：共同目标；秒—分钟—小时—天分别由谁接力；失血后从血容量下降一直推到神经、RAAS、ADH、醛固酮和ANP方向；每一层主要救哪个变量。

循环调节真正要保的不是某一个血压数字，而是：

```text
重要器官灌注
+ 有效循环血量
+ 足够组织氧供
```

MAP 是实现灌注的重要手段，但不是唯一目标。

| 时间层 | 主系统 | 主要改变 | 角色 |
|---|---|---|---|
| 秒级 | 压力感受性反射、自主神经 | HR、收缩性、微动脉、静脉 | 先把压力托住 |
| 分钟级 | 儿茶酚胺、AngⅡ、较高浓度VP等 | 强心、夹管、强化交感 | 放大应急命令 |
| 小时级 | 醛固酮、ADH、口渴 | Na⁺、水、尿量 | 把容量慢慢补回来 |
| 天级 | 肾—体液控制 | ECF、血容量、排Na⁺排水 | 决定长期工作点 |

完整失血链：

```text
失血
→ 循环血量↓、平均充盈压↓
→ 静脉回心↓、CVP↓、EDV↓
→ SV↓、CO↓、MAP↓
```

第一批神经抢救：

```text
颈动脉窦 / 主动脉弓牵张↓
→ 交感↑、迷走↓
→ HR↑、收缩性↑
→ 微动脉收缩：TPR↑
→ 静脉收缩：静脉容量↓、回心↑
→ MAP与心脑灌注暂时改善
```

严重低灌注时：

```text
外周化学感受性反射 + 脑缺血反应
→ 交感缩血管紧张显著↑
→ 皮肤、骨骼肌和多数内脏血管收缩
→ 血流重新分配给心、脑
```

体液与容量接力：

```text
肾灌注压↓ + 致密斑NaCl↓ + 肾交感β1↑
→ 肾素↑ → AngⅡ↑
→ 微动脉 / 静脉收缩 + 交感强化 + 口渴
→ 醛固酮↑、ADH↑
→ 保Na⁺、保水、尿量↓
→ ECF / 血容量逐步回升
```

容量不足时，ANP / BNP 方向总体下降或其卸货作用被压制。

每个效应器调不同变量：

```text
心脏：HR、收缩性 → CO
微动脉：TPR + 器官血流分配
静脉：容量池 → 回心 / 前负荷
肾脏：Na⁺和水 → ECF / 血容量
```

（易混：某机制“升压”不等于它只作用血管；同一升压结果可来自 CO、TPR、静脉回心或血容量。）

## KP02｜压力感受器与窦弓反射：血压的快速双向缓冲器

> **讲义定位 →** P153–154。  
> **主提示**：感受器位置与直接刺激；传入神经；血压高 / 低时完整反射链；夹闭颈总动脉；6个特点；调定点、敏感性和高血压重调定；为什么不负责长期血压。

- **颈动脉窦、主动脉弓**血管外膜下感觉末梢；直接感受**血管壁机械牵张程度**。
- 同一压力水平下，颈动脉窦通常更敏感。

```text
颈动脉窦 → 窦神经 → 舌咽神经 → 延髓
主动脉弓 → 迷走神经干 → 延髓
```

血压升高：

```text
管壁牵张↑ → 传入放电↑
→ 交感↓、迷走↑
→ HR↓、收缩性↓
→ 微动脉舒张、静脉舒张
→ CO↓、TPR↓、回心↓
→ 血压回落
```

血压降低方向相反，所以“降压反射”实际是**双向负反馈**。

夹闭颈总动脉：

```text
颈动脉窦局部压力 / 牵张↓
→ 传入放电↓
→ 交感↑、迷走↓
→ 动脉压↑
```

特点：快速、短暂、持续工作、双向负反馈、调定点附近最敏感、可重调定。高血压时调定点右移 / 升高，调定点处斜率下降，敏感性低于正常。

长期压力持续改变时会重调定，因此长期血压工作点主要依赖：

> **肾—体液系统对细胞外液量和血容量的控制。**

//串联：按摩颈动脉窦可增强反射、增加迷走活动，Study 将其作为室上性心动过速短接口；完整诊疗后置 B10。

## KP03｜外周化学感受性反射、脑缺血反应与库欣反应

> **讲义定位 →** P154–155。  
> **主提示**：颈动脉体 / 主动脉体各偏什么；主要刺激；平时为何不参与血压调节；血压约低到什么程度才明显；如何重分配血流；脑缺血反应与库欣反应。

- **颈动脉体**更偏呼吸；**主动脉体**更偏循环；主要读取 PaO₂↓、PaCO₂↑、H⁺↑。
- 首先使呼吸加深、加快。
- 按 Study，当动脉压下降到约 **80 mmHg以下**，感受器局部低灌注后才明显参与循环调节。

```text
严重低氧 / 酸中毒 / 血压过低
→ 外周化学感受器兴奋
→ 交感缩血管中枢↑
→ 骨骼肌和多数内脏血管收缩
→ TPR↑、血压↑
```

心、脑血管无明显收缩或轻度舒张，优先保心脑。这不是日常双向缓压，而是危急状态偏单向升压。

脑缺血反应：

```text
急性大出血 / 动脉压极低 / 颅内压过高
→ 脑血流显著减少
→ 交感缩血管紧张显著↑
→ 外周血管强烈收缩
→ 动脉压↑
```

库欣反应：

```text
颅内压↑ → 脑血管受压、脑血流↓
→ 脑缺血反应 → 动脉压↑
→ 以更高灌注压对抗颅内压
```

完整颅压与神经定位后置神经系统。

## KP04｜心肺容量感受性反射与心交感传入反射

> **讲义定位 →** P155–156。  
> **主提示**：两类反射感受器在哪里；前者为何又叫低压力 / 容量 / 牵张感受器；容量↑时神经和激素怎样变；后者的机械 / 化学刺激、急性意义与慢性正反馈。

### A｜心肺容量感受性反射

感受器位于心房、心室、肺循环大血管。

| 称谓 | 为什么 |
|---|---|
| 容量感受器 | 反映循环充盈度 / 血容量 |
| 牵张感受器 | 直接感受局部壁牵张 |
| 低压力感受器 | 位于循环低压力部分 |

```text
血容量 / 回心↑
→ 心肺壁牵张↑
→ 交感↓、迷走↑
+ ANP↑、ADH↓、醛固酮↓
→ 排Na⁺排水↑，心泵和血管紧张度下降
→ 容量和血压回落
```

主任务是调循环血量和 ECF，不是快速修正某一搏 SBP。

### B｜心交感传入反射

感受器：心室壁交感传入末梢。刺激包括心室扩张以及腺苷、缓激肽、PG、H₂O₂等缺血相关物质。

```text
心肌缺血 / 心室扩张
→ 心交感传入冲动↑
→ 交感活动↑
→ 动脉压↑
```

急性可维持压力，但长期可：

```text
交感↑ → HR↑、收缩性↑、耗氧↑
→ 缺血进一步加重
→ 心交感传入进一步增强
```

四类反射总表：

| 反射 | 主要感受器 | 典型刺激 | 主要输出 | 核心任务 |
|---|---|---|---|---|
| 压力感受性 | 颈动脉窦、主动脉弓 | 动脉壁牵张变化 | 交感 / 迷走双向 | 缓冲快速血压波动 |
| 外周化学感受性 | 颈动脉体、主动脉体 | 低O₂、高CO₂、高H⁺ | 呼吸↑；危急时交感升压 | 保心脑 |
| 心肺容量感受性 | 心房、心室、肺循环大血管 | 容量 / 回心与牵张↑ | 交感↓、ANP↑、ADH/醛固酮↓ | 降容量 |
| 心交感传入 | 心室壁 | 扩张、缺血代谢物 | 交感↑、血压↑ | 缺血时维压，也可恶化 |

# ② 神经快速执行：命令怎样落到心脏、血管和肾

## KP05｜自主神经总输出：把“交感 / 迷走”翻译成 B1 变量

> **主提示**：交感兴奋对心率、收缩性、微动脉、静脉、球旁细胞五个出口分别怎样；迷走主要作用哪里；右 / 左迷走特殊；最终怎样改变 CO、TPR、回心和 MAP。

| 效应器 | 主要受体 / 方式 | 直接结果 | B1变量 |
|---|---|---|---|
| 窦房结 / 传导 | β₁ | 心率、自律性、传导性↑ | HR↑ |
| 心房 / 心室肌 | β₁ | 收缩性↑ | ESV↓、SV↑、CO↑ |
| 微动脉 | α₁为主 | 收缩 | TPR↑；多数器官血流↓ |
| 静脉容量池 | α₁为主 | 收缩、容量↓ | 回心↑、前负荷倾向↑ |
| 肾球旁细胞 | β₁ | 肾素↑ | 启动RAAS |

> **交感既能强泵、夹动脉、挤静脉，也能叫肾素。**

迷走主要分布室上组织：右侧更偏窦房结 → HR↓；左侧更偏房室交界 → 传导↓；对心房肌可有影响；对心室肌支配弱，Study 真题口径中不会造成心室肌收缩力明显下降。

```text
交感↑
├─ HR / 收缩性↑ → CO↑
├─ 微动脉收缩 → TPR↑
├─ 静脉收缩 → 回心 / 前负荷↑ → SV↑
└─ 肾素↑ → 长期保压保容量
→ MAP倾向↑
```

```text
迷走↑ → HR↓、房室传导↓ → CO倾向↓ → MAP倾向↓
```

（易混：受体效应、单条神经效应和整个反射最终效应不是一层，例如 NA 直接β₁可加速，但强烈升压触发窦弓反射后整体 HR 可下降。）

## KP06｜血管神经支配：四类纤维与轴突反射一次学全

> **主提示**：4类纤维×4轴｜微动脉 vs 前括约肌｜轴突反射为何“假”

### 1｜交感缩血管纤维

- NA / NE → α₁ → 收缩；
- 有紧张性，安静时持续放电；
- 几乎所有血管，多数血管只受其单一支配；
- 器官：皮肤最多、心脑最少；
- 血管：动脉多于静脉，微动脉最多；后微动脉 / 前括约肌较少；真毛细血管无平滑肌。

```text
微动脉 = 微循环总闸门，主要接受全身神经命令
毛细血管前括约肌 = 分闸门，更受局部代谢控制
```

### 2｜交感舒血管纤维

- ACh → M；骨骼肌血管；无紧张性；防御 / 情绪激动时参与。

```text
应急 → CO↑
→ 皮肤和内脏相对收缩
→ 骨骼肌血管因交感舒血管纤维等舒张
→ 血流转向运动器官
```

### 3｜副交感舒血管纤维

ACh → M；无紧张性；分布于唾液腺、胃肠外分泌腺、脑膜、外生殖器等少数器官，主要调局部血流。

（特殊：按 Study，迷走使心肌代谢下降、腺苷减少，冠脉最终收缩，因此不归入这里。）

### 4｜脊髓后根舒血管纤维 / 轴突反射

```text
皮肤伤害刺激
→ 感觉传入纤维局部分支释放CGRP
→ 微动脉舒张、红晕
```

没有中枢整合，称轴突反射 / 假反射。

| 纤维 | 递质→受体 | 血管效应 | 紧张性 | 主要分布 / 场景 |
|---|---|---|---|---|
| 交感缩血管 | NA→α₁ | 收缩 | 有 | 几乎所有血管；皮肤多、心脑少；微动脉最多 |
| 交感舒血管 | ACh→M | 舒张 | 无 | 骨骼肌血管；防御 / 情绪激动 |
| 副交感舒血管 | ACh→M | 舒张 | 无 | 唾液腺、胃肠外分泌腺、脑膜、外生殖器等 |
| 脊髓后根舒血管 | CGRP等 | 局部舒张 | 非日常张力 | 伤害刺激周围轴突反射 |

## KP07｜儿茶酚胺：把交感应急命令放大到全身

> **主提示**：髓质来源比例｜NA/Adr身份｜α₁/β₁/β₂｜NA vs Adr｜Adr剂量｜NA→HR？｜翻转｜嗜铬｜调节4轴

肾上腺髓质嗜铬细胞约释放 **80% Adr + 20% NA / NE**。NA 可作激素及交感递质；Adr 外周主要体现为激素。

| 受体 | 感性角色 | 核心效应 |
|---|---|---|
| α₁ | 夹管 | 血管收缩 → TPR↑ |
| β₁ | 强心 + 叫肾素 | 心脏“四正效应”；球旁细胞肾素↑ |
| β₂ | 给特定血管开路 | 血管舒张 |

- NA：α₁ > β₁ > β₂，偏强烈升压；
- Adr：α₁ = β₁ = β₂；骨骼肌 / 肝等β₂较多血管，小剂量可舒张，大剂量α₁显现而收缩。

单用 NA 可使 HR 下降：

```text
NA强烈α₁ → TPR / BP↑
→ 窦弓反射 → 交感↓、迷走↑
→ 反射性HR↓
```

α₁阻断后的“肾上腺素作用翻转”：α₁效应被封闭 → Adr主要剩β₂舒张 → BP下降。

调节：交感节前 ACh→髓质N₁释放CA；ACTH / GC参与应激；CA入血解除自身合成酶抑制；低血糖使CA↑。

//串联：嗜铬细胞瘤、CCB只留机制接口，完整诊疗 / 药理后置。

# ③ 体液与肾容量：低灌注后怎样夹管、叫人、加水

## KP08｜肾素释放与 RAAS 主链：三个报警入口不能混

> **主提示**：来源3称｜释放3入口+感受器｜化学促/抑｜肾血管方向≠肾素方向｜RAAS主链至AngⅢ

肾素来自球旁细胞 = 近球细胞 = 颗粒细胞。

| 入口 | 直接感受器 / 通路 | 肾素方向 |
|---|---|---|
| 肾动脉灌注压↓ | 入球动脉牵张感受器 | ↑ |
| 小管液NaCl↓ | 远曲小管致密斑 | ↑ |
| 肾交感兴奋 | 球旁细胞β₁ | ↑ |

促进肾素：儿茶酚胺、缓激肽、PG、小剂量多巴胺。抑制：NO、ANP、ET、大剂量VP、AngⅡ负反馈。

> 肾血管舒缩方向不能直接反推肾素分泌方向。

```text
肝血管紧张素原
→ 肾素 → AngⅠ
→ ACE → AngⅡ → AngⅢ
```

主要受体 AT₁。

## KP09｜AngⅡ / AngⅢ：夹管、强化、释放、喝水和重构

> **主提示**：两个极值｜1233｜GC vs 醛固酮路径｜肾素反馈｜肾内浓度依赖｜近端+系膜

按 Study：AngⅡ为 RAS 中全身微动脉收缩 / 升压作用最强；AngⅢ直接促醛固酮作用最强。

AngⅡ：

- **1个重构**：心肌肥大 / 凋亡、成纤维与血管细胞增殖、ECM堆积 / 纤维化；
- **2个减弱**：压力反射敏感性↓；肾素负反馈↓；
- **2个收缩**：微动脉收缩→TPR↑；静脉收缩→容量↓、回心 / 前负荷↑；
- **3个加强**：加强CRH→ACTH→GC、口渴、交感中枢紧张；
- **3个释放**：醛固酮、ADH / VP、交感末梢NA。

（易混：GC 经 CRH/ACTH 间接；醛固酮由 AngⅡ直接促进。）

肾内浓度依赖：

| AngⅡ水平 / 作用处 | 主要结果 |
|---|---|
| 较低浓度，出球收缩 | 维持 / ↑肾小球毛细血管压与GFR |
| 高浓度，入球也收缩 | 肾小球毛细血管压↓、GFR↓ |
| 系膜细胞收缩 | Kf↓、GFR↓ |
| 近端小管等 | Na⁺、水重吸收↑ |

```text
低灌注 → AngⅡ
→ 夹动脉保压 + 夹静脉增回心
+ 强化交感 + 叫醛固酮 / ADH + 口渴
+ 肾小管保Na水
→ 急性维持灌注
→ 长期增加前后负荷与重构
```

## KP10｜醛固酮：留的是钠，水只是跟着钠走

> **主提示**：性质、来源；主要靶细胞；核受体机制；ENaC / Na⁺-K⁺泵；Na⁺ / 水 / K⁺方向；主要释放因素；允许作用；与ACTH / GC区别；原醛 vs Liddle短接口。

- 类固醇激素；来源肾上腺皮质球状带；主要靶点集合管主细胞，远曲小管亦有作用。

```text
醛固酮
→ 胞内核受体
→ ENaC、Na⁺-K⁺泵、ATP合酶等表达↑
→ Na⁺重吸收↑
→ 水随Na⁺重吸收↑
→ K⁺分泌↑
```

> **保钠、带水、排钾。** 水不是像 ADH 那样通过直接增加水通透性。

主要促进：血容量↓→RAAS→AngⅡ、血K⁺↑；Study另保留血Na⁺↓、ACTH等。还可提高平滑肌对缩血管物质敏感性。

> 醛固酮主体由 RAAS 驱动；GC主体由 ACTH 驱动。

| 疾病 | 上游故障 | 肾素 | 醛固酮 | 处理身份 |
|---|---|---:|---:|---|
| 原醛 | 球状带增生 / 肿瘤等 | ↓ | ↑ | MRA等 |
| Liddle | ENaC遗传性过度激活 | ↓ | ↓ | 阿米洛利 / 氨苯蝶啶 |

完整诊疗后置内分泌 / 泌尿。

## KP11｜ADH / VP / AVP：直接管水，关键是 V₂—AQP2

> **主提示**：4个称谓；性质；下丘脑核团、轴突运输与神经垂体储存；V₂完整链；尿素通道；V₁；释放↑ / ↓因素；最重要刺激；DI / SIADH接口。

ADH = 抗利尿激素 = VP = AVP 等垂体后叶素相关称谓；为肽类神经激素。

- 主要由下丘脑视上核、室旁核等大细胞神经元合成；
- 囊泡沿下丘脑—垂体束运输；
- 储存于神经垂体并释放；不是经垂体门脉运输，也不是神经垂体合成。

```text
ADH
→ 集合管主细胞基底侧V₂（GPCR）
→ G蛋白 → AC → cAMP↑ → PKA
→ AQP2囊泡插入顶端膜
→ 水通透性↑ → 水重吸收↑
→ 尿量↓、尿渗透压 / 比重↑
```

还增加内髓集合管对尿素通透性。V₁位于血管平滑肌，可缩血管：生理浓度主要 V₂抗利尿；浓度显著升高时 V₁升压参与危急反应。

**最重要刺激：血浆晶体渗透压↑。**

ADH↑：晶体渗透压↑、血容量↓、动脉压↓、AngⅡ、应激 / 创伤 / 疼痛 / 恶心等。ADH↓：乙醇、ANP、咖啡因、GC等。

```text
大量饮清水 → 渗透压↓ → ADH↓ → 水利尿
大量出汗 / 高热等 → 渗透压↑ → ADH↑ → 尿量↓、比重↑
```

中枢合成 / 释放异常 → 中枢性 DI；集合管 V₂ / 效应系统异常 → 肾性 DI；小细胞肺癌异位 ADH → SIADH接口。完整诊疗后置。

## KP12｜ANP / BNP：容量过多时，心脏主动“卸货”

> **主提示**：来源 / 刺激；对入球、系膜、Kf、GFR；对小管Na水；抑制哪些系统；血管与重构方向；BNP升高为什么是报警而不是病因。

- ANP：心房壁牵张时释放；
- BNP：主要由心室产生，心室壁张力增加时升高。

ANP刺激包括 CVP↑、血容量↑、心房牵张、头低足高 / 浸水，以及 Study 保留的 NE、ACh、ADH、K⁺↑等。

```text
ANP
├─ 入球等舒张
├─ 球内系膜舒张 → Kf↑ → GFR / 滤过分数↑
├─ cGMP抑制小管NaCl和水重吸收
├─ 抑制肾素、醛固酮、ADH
└─ 对抗RAAS、ET、NE
→ 利钠、利尿、降容量
```

还舒张血管、抑制成纤维 / 血管平滑肌增殖、抗重构；按当前 Study 还保留 HR、SV、BP下降等方向。

```text
压力 / 容量负荷 / 心肌缺血
→ 心室壁张力↑ → BNP↑
→ 试图利钠、利尿、扩管和抗重构
```

BNP是报警 / 代偿，不是心衰病因。完整心衰阈值后置 B11。

## KP13｜肾—体液长期调压：最终工作点由 ECF 量决定

> **主提示**：为什么窦弓只管短期；压力性利尿 / 利钠；Na水、ECF、血容量、回心、CO和MAP完整闭环；RAAS / ADH / ANP各调什么。

```text
动脉压持续↑
→ 肾排Na⁺、排水↑
→ ECF / 血容量↓
→ 平均充盈压↓、回心↓
→ EDV / SV / CO↓
→ MAP回落
```

反向：低压 / 低肾灌注 → RAAS / 醛固酮 / ADH / 口渴 → 增容量 → 回心 / CO / MAP回升。

| 系统 | 主要读取 | 直接被调变量 | 最终容量结果 |
|---|---|---|---|
| RAAS / AngⅡ | 肾灌注、NaCl、交感 | 血管、交感、醛固酮、ADH、口渴 | 保压 + 增容量 |
| 醛固酮 | AngⅡ、K⁺等 | Na⁺重吸收、K⁺分泌 | 保Na带水 |
| ADH | 晶体渗透压最重要；容量 / 压力参与 | 集合管水通透性 | 直接保水 |
| ANP / BNP | 心房 / 心室壁牵张 | GFR、Na水重吸收、RAAS / ADH | 排Na排水 |

# ④ 局部修正：血管自己的油门和刹车

## KP14｜内皮素 vs NO / PGI₂ / EDHF

> **主提示**：ET 4轴｜NO：刺激→第二信使→Ca²⁺｜PG家族方向｜EDHF链｜切应力双向｜共同抗板/抗重构

### ET

- 强而持久收缩多数血管，可参与长期血压；
- 正性肌力，但可被强冠脉收缩及刺激 AngⅡ / NA作用掩盖；
- 促进凋亡、分化、表型转化与重构；
- 切应力可促释放；Study将“最强缩血管物质”另给尾升压素。

### NO

刺激包括 ACh、雌激素、NA / NE、切应力、缓激肽、硝酸甘油接口。

```text
NO → sGC → cGMP↑ → PKG↑
→ 胞质Ca²⁺↓ → 血管舒张
```

并抗血小板黏附、抗平滑肌增殖、对抗RAAS、抗重构。

### PG / EDHF

- PGI₂：舒张、抗板、抗重构；PGE₂舒张；PGF₂α收缩。
- EDHF → Ca²⁺依赖K⁺通道开放 → K⁺外流 → 超极化 → 舒张。

| 因子 | 方向 | 关键机制 / 角色 | 其他高频作用 |
|---|---|---|---|
| ET | 收缩 | 强而持久，联动AngⅡ / NA | 正性肌力、重构 |
| NO | 舒张 | sGC–cGMP–PKG，Ca²⁺↓ | 抗板、抗增殖、抗重构 |
| PGI₂ | 舒张 | 花生四烯酸通路 | 抗板、抗重构 |
| EDHF | 舒张 | K⁺通道开放、超极化 | 小血管局部调节 |

## KP15｜缓激肽、ADM、CGRP及其他舒血管因子

> **主提示**：缓激肽B₁/B₂｜内皮3介质｜ADM 3轴｜CGRP定位+轴突反射｜其他舒血管因子｜ACEI/ARNI串联

- 缓激肽 B₁：炎症 / 疼痛接口；B₂作用内皮后使 NO、PGI₂、EDHF↑ → 舒张。不同效应轴不能互相否定。
- ADM 来源包括肾上腺髓质嗜铬细胞、血管平滑肌 / 内皮；血中主要来源按 Study 为内皮。主要旁分泌，持久舒张、利尿、抑制AngⅡ / 醛固酮、正性肌力 / 舒张冠脉。
- CGRP 按 Study 为目前最强舒血管物质，也是后根舒血管纤维 / 轴突反射重要递质。
- 阿片肽、CO、H₂S、IGF-1等低频身份进入 MI-D。

药物只看机制断点：ACEI使 AngⅡ↓且缓激肽降解↓；ARB阻断 AngⅡ效应而不增加缓激肽；ARNI = ARB + 脑啡肽酶抑制；sGC刺激剂强化 NO–sGC–cGMP。完整方案后置 B11 / 泌尿。

## KP16｜全身命令与局部需求怎样协调

> **主提示**：交感缩血管分布2梯度｜皮肤/内脏 vs 心脑｜骨骼肌防御反应｜微动脉 vs 前括约肌｜全身命令 vs 局部代谢

```text
交感缩血管纤维分布：皮肤最多，心和脑最少
血管层级：微动脉最多，后微动脉 / 前括约肌较少
真毛细血管无平滑肌
```

大失血：交感↑ → 皮肤、骨骼肌和多数内脏收缩 → TPR↑；心脑因交感支配少且局部代谢强而相对保留。

运动 / 防御：骨骼肌同时受交感缩血管、交感舒血管、Adr β₂和局部代谢；活动肌局部舒张可占优势。

- 微动脉：全身神经控制器官总流量 / TPR；
- 前括约肌：更受局部代谢；
- 真毛细血管：交换，无平滑肌。

> **全身神经命令决定资源总分配，局部代谢决定当前组织到底需要多少。**

# ⑤ 场景运行：把系统真正跑起来

## KP17｜体位、失血、容量过多与水状态变化

> **主提示**：突然站立、急性失血、等渗容量负荷、单纯饮水 / 脱水：第一变量、传感器、神经、RAAS / ADH / ANP、尿量和回心方向。

### 卧位突然站立

```text
下肢静脉淤积 → 中央血容量 / 回心↓
→ CVP、EDV、SV、CO、MAP↓
→ 窦弓牵张↓ → 交感↑、迷走↓
→ HR / 收缩性↑、微动脉 / 静脉收缩
→ 回心与MAP恢复
```

### 急性失血

神经链同 KP01，同时肾灌注↓ + 致密斑NaCl↓ + β₁交感↑ → RAAS↑ → AngⅡ、醛固酮、ADH、口渴 → 尿量↓、容量恢复；严重时化学感受 / 脑缺血反应保心脑。

### 等渗容量负荷

```text
ECF / 血容量↑ → 平均充盈压、回心、CVP↑
→ 心肺牵张↑ → 交感↓、迷走↑、ANP↑
→ 肾素 / 醛固酮 / ADH↓
→ 排Na排水↑
```

### 大量饮清水 vs 脱水

饮清水：晶体渗透压↓ → ADH↓ → 水利尿 → 尿量↑、比重↓。

脱水 / 高热 / 出汗：水丢失相对多 → 渗透压↑ → ADH↑ → 尿量↓、比重↑；若同时容量↓，压力 / 容量感受与 RAAS也启动。

| 场景 | 第一层问题 | 快速反应 | 容量 / 激素反应 | 尿量 |
|---|---|---|---|---:|
| 突然站立 | 中央回心↓ | 窦弓交感↑ | 持续时RAAS可参与 | 倾向↓ |
| 急性失血 | 总容量↓、MAP↓ | 窦弓 + 危急升压 | RAAS、醛固酮、ADH↑ | ↓ |
| 等渗容量负荷 | ECF / 回心↑ | 心肺容量反射 | ANP↑，RAAS / ADH↓ | ↑ |
| 单纯饮清水 | 渗透压↓ | 不主要靠窦弓 | ADH↓ | ↑ |
| 脱水 | 渗透压↑，可伴容量↓ | 视容量下降 | ADH↑，RAAS可↑ | ↓ |

## KP18｜急性救援、慢性反噬与药物作用层级

> **主提示**：急救5系统｜慢性代价4轴｜药物断点9类｜机制层 vs 临床方案边界

| 系统 | 急性低灌注时救什么 | 长期持续后的主要代价 |
