# Block 5｜高血压与动脉粥样硬化
## 长期压力与内皮损伤怎样建立慢性血管病底物｜学习阅读版 v2 · 最终执行版

> **中心问题**：慢性高压与慢性内皮损伤怎样分别造成阻力血管重构和中大动脉粥样斑块，并最终引出冠脉缺血、周围血管病和心力衰竭？

# 先看两条长期损伤轴

B1–B4 已经建立了正常血压、调节、内皮和止血。B5 只问一件新事：**如果压力异常和内皮损伤不是短暂事件，而是持续很多年，会留下什么结构性底物？**

```text
轴1｜长期高压
CO / TPR / 容量 / 大动脉顺应性异常
→ MAP长期升高
→ 阻力血管长期受压
→ 小动脉 / 细动脉重构
→ 心、脑、肾、视网膜靶器官损害
→ 左室长期后负荷↑
→ 肥厚、舒张障碍、缺血，最终可心衰

轴2｜慢性内皮损伤
高压 / 吸烟 / 糖脂异常等
→ LDL进入内膜并氧化
→ 单核细胞 / SMC形成泡沫细胞
→ 脂纹
→ SMC合成ECM形成纤维帽
→ 深部坏死形成脂质坏死核心
→ 稳定斑块：固定狭窄
或
→ 易损斑块：破裂 / 侵蚀 → 血栓事件
```

两条轴不是平行不相交：

```text
高血压
→ 增加内皮机械损伤
→ 促进AS进展
同时增加左室后负荷
```

> 第一次学习先建立“长期变量异常 → 结构重构 → 器官后果”。测量阈值、分级和药物都放在机制之后附着，不能让数字先于疾病模型。

# 总 Framework

```text
第一条轴｜高血压
① 长期变量异常
   CO / TPR / 容量 / 顺应性
   [KP01–KP03]
        ↓
② 长期结构重构与靶器官
   功能性痉挛 → 玻璃样变
   → 肾 / 脑 / 心 / 视网膜
   → 急进型纤维素样坏死 / 洋葱皮
   [KP07–KP12]
        ↓
③ 再用测量 / 风险 / 急症校准
   办公室血压 / ABPM / 分级 / 风险
   → 急症 vs 亚急症
   [KP04–KP06、KP13–KP15]
        ↓
④ 长期治疗
   生活方式 → 联合原则 → ABCD
   → 并存病 / 继发性高血压
   [KP16–KP20]

第二条轴｜动脉粥样硬化
⑤ 内皮损伤 → 泡沫细胞 → 脂纹
   [KP21–KP23]
        ↓
⑥ 纤维帽 + 坏死核心
   → 稳定 / 易损斑块
   [KP24–KP25]
        ↓
⑦ 器官分布与后续出口
   冠脉 / 主动脉 / 颈脑 / 肾 / 四肢 / 肠系膜
   [KP26]
```

# Part A｜高血压：先从长期变量异常开始

## KP01｜高血压先放回 P/Q/R/V：血压升高是共同结果，不是单一病因

> **讲义回看 →** B1 MAP、B2调节；**讲义定位 →** 内科P309–315、病理P39–41。  
> **主提示**：MAP形成；CO / TPR / 容量 / 顺应性；测量层、风险层、病因层。

```text
MAP ≈ CO × TPR
```

长期升压的上位路径：

- `CO↑`：HR、收缩性、回心量 / 容量增加；
- `TPR↑`：阻力血管持续收缩或结构性狭窄；
- `ECF / 血容量↑`：肾保钠保水；
- `大动脉顺应性↓`：弹性储器下降，尤其SBP / PP升高。

三个判断层：

```text
测量层：血压达到当前Study阈值了吗？
风险层：危险因素 / 靶器官 / 临床疾病有多少？
病因层：原发还是继发，主故障在哪个调节环？
```

不能因为 RAAS 能升压，就把所有高血压解释成单一路径。

---

## KP02｜原发性 vs 继发性：不是“有没有原因”，而是能否定位单一主病因

> **讲义定位 →** P309–315。  
> **主提示**：原发性高血压身份；继发性共同变量模型；哪些线索应优先寻找病因。

原发性高血压：多因素、长期调压网络整体偏移，通常不能定位一个唯一可逆主病因。

继发性高血压：存在可定位的基础疾病 / 结构异常，但其血压最终仍通过容量、CO、TPR、RAAS或大血管力学等共同变量升高。

提高继发性病因搜索优先级的线索包括：

- 年轻起病或突然恶化；
- 顽固 / 难治；
- 明显低钾、阵发症状；
- 腹部 / 血管杂音；
- 上下肢血压显著差；
- 肾功能、尿检或内分泌异常。

本 Block 只完整到当前 Study 的肾实质、肾血管与主动脉缩窄；原醛、嗜铬、库欣后置内分泌。

## KP03｜高血压心脏病：所有体征都能回到长期左室后负荷

> **讲义定位 →** P309；**讲义回看 →** B1心音 / 后负荷。  
> **主提示**：LVH、A2、S2逆分裂、S4、抬举样心尖、心界、功能性MR。

```text
长期高血压
→ 左室后负荷↑
→ 向心性肥厚
```

| 体征 | Study机制 |
|---|---|
| LVH / 心界向左下扩大 | 压力负荷；晚期可扩张 |
| A2亢进 | 主动脉压力高，关闭动力强 |
| S2反常 / 逆分裂 | 左室射血延迟，A2晚于P2 |
| S4 | 肥厚心室顺应性↓，房缩更用力 |
| 抬举样心尖 | 肥厚LV持续有力冲动 |
| 心尖收缩期吹风样杂音 | 腔 / 瓣环改变 → 相对性MR |

长期压力负荷先可表现舒张障碍 / HFpEF底物，晚期可扩张失代偿；完整心衰归 B11。

# Part B｜长期高压怎样变成器质性血管病

## KP07｜缓进型三步电影：功能紊乱 → 血管病变 → 器官病变

> **讲义定位 →** 病理P39–41。  
> **主提示**：早期是否器质性；细小动脉；后来如何重构和损害器官。

```text
功能紊乱期
全身细小动脉间歇性痉挛
→ TPR暂时↑、血压波动↑
→ 尚无器质性血管病变
        ↓
动脉病变期
长期高压 / 通透性异常
→ 血浆蛋白进入血管壁
+ SMC / ECM增多
→ 玻璃样变、管壁厚、管腔窄
        ↓
内脏病变期
→ 肾 / 脑 / 心 / 视网膜损害
```

---

## KP08｜玻璃样变：高压怎样把血浆蛋白和ECM压进细小动脉壁

> **讲义定位 →** 病理P39。  
> **主提示**：缓进型特征病变；机制；好发部位；与急进型纤维素样坏死区别。

> **细小动脉玻璃样变 / 玻璃样小动脉硬化** 是缓进型高血压特征病变。

```text
长期高压 + 内皮通透异常
→ 血浆蛋白渗入壁
+ SMC合成ECM
→ 均质嗜伊红玻璃样物沉积
→ 管壁厚、管腔窄
```

当前 Study 强调肾入球小动脉、视网膜、脾等。玻璃样变 ≠ 急进型纤维素样坏死。

---

## KP09｜高血压肾：双侧对称细颗粒固缩

> **讲义定位 →** 病理P39–40。  
> **主提示**：原发性颗粒性固缩肾；为什么细颗粒；与AS大瘢痕肾区别。

> **原发性颗粒性固缩肾**：双肾、对称、缩小、质硬、表面弥漫细颗粒。

```text
大量细小动脉弥漫狭窄
→ 许多小范围肾单位慢性缺血 / 萎缩 / 纤维化
→ 保存区与萎缩区细小不均
→ 细颗粒表面
```

肾动脉AS较大分支 / 开口狭窄 → 较大范围缺血 → 大瘢痕肾 / AS性固缩肾。

肾缺血又可激活RAAS，形成“高压伤肾—肾再升压”。

---

## KP10｜高血压脑：出血、软化、脑病是三条不同路径

> **讲义定位 →** 病理P40。  
> **主提示**：脑出血部位 / 血管；软化本质；脑病；Study最严重并发症 / 常见死因口径。

**脑出血**：当前 Study 视为高血压最严重并发症、缓进型常见死因；最常见基底节，尤其豆状核 / 内囊区域，与豆纹动脉等深穿支高压损伤和微动脉瘤破裂相关。

**脑软化**：

```text
小动脉血栓 / 闭塞
→ 局部缺血
→ 脑液化性坏死
→ 软化灶 → 胶质瘢痕接口
```

**高血压脑病**：以急性脑损害、脑水肿 / 神经症状为入口。三者不是同一病理过程。

---

## KP11｜高血压心与视网膜：同一高压在泵和微血管产生不同重构

> **讲义定位 →** 病理P40–41。  
> **主提示**：向心性→失代偿扩张；肥厚为何仍缺血；视网膜改变。

```text
长期左室后负荷↑
→ 向心性肥厚
→ 壁厚、腔正常 / 偏小
→ 顺应性↓、耗氧↑、毛细血管相对密度↓
→ 舒张障碍 / 缺血
→ 失代偿后扩张 / 离心性重构
```

视网膜：小动脉狭窄、硬化、交叉压迫；严重时出血、渗出、视盘水肿。眼底临床分级见 KP06。

---

## KP12｜急进 / 恶性高血压：坏死性细动脉炎 + 洋葱皮样增生

> **讲义定位 →** 病理P40–41；内科P310。  
> **主提示**：两大特征；肾；主要死亡结局；与缓进型区别。

```text
坏死性细动脉炎
→ 纤维素样坏死

增生性小动脉硬化
→ SMC / 基底膜同心层状增生
→ 洋葱皮样
```

当前 Study 强调肾细小动脉 / 入球小动脉，严重狭窄 → 肾急剧缺血 → 肾功能迅速恶化；Study主要死亡原因口径为肾衰 / 尿毒症。

| 维度 | 缓进型 | 急进型 |
|---|---|---|
| 病程 | 慢 | 急剧 |
| 特征 | 玻璃样小动脉硬化 | 纤维素样坏死 + 洋葱皮 |
| 主要风险 | 心脑肾长期损害 | 肾损害快速突出 |
| Study死因口径 | 脑出血 | 肾衰 / 尿毒症 |

# Part C｜机制之后再用测量、分级与风险校准

## KP04｜办公室血压与 ABPM 回答不同问题

> **讲义定位 →** P309。  
> **主提示**：测量准备 / 体位 / 双侧；ABPM正常均值和用途。

办公室：测前至少禁烟半小时；安静坐位；上臂与心脏同高；首次双侧，以后测高侧；非同日3次；疑直立性低血压时测卧 / 立位。

当前 Study ABPM：

| 指标 | 正常平均值 |
|---|---:|
| 24h | `<130/80` |
| 白天 | `<135/85` |
| 夜间 | `<120/70` |

用途：白大衣、隐蔽性、难治 / 顽固、短时变异、昼夜节律、疗效。办公室阈值 ≠ ABPM平均阈值。

---

## KP05｜诊断、分级与单纯收缩 / 舒张期高血压

> **讲义定位 →** P309。  
> **主提示**：当前Study分级；不同级别按高侧；单纯收缩 / 舒张；老年为何常见单纯收缩期。

| 类型 | SBP | DBP |
|---|---:|---:|
| 正常 | `<120` | 且 `<80` |
| 正常高值 | `120–139` | 和/或 `80–89` |
| 1级 | `140–159` | 和/或 `90–99` |
| 2级 | `160–179` | 和/或 `100–109` |
| 3级 | `≥180` | 和/或 `≥110` |
| 单纯收缩期 | `≥140` | 且 `<90` |
| 单纯舒张期 | `<140` | 且 `≥90` |

SBP / DBP不同级按较高级。老年单纯收缩期常与大动脉弹性下降 → 弹性储器作用↓ → SBP / PP↑相关。

---

## KP06｜危险分层：同一血压数字，器官风险可以完全不同

> **讲义定位 →** P310。  
> **主提示**：血压级别 + 危险因素 + 靶器官 + 临床疾病；眼底I–IV。

```text
血压级别
+ 其他危险因素
+ 靶器官损害 / CKD
+ 临床合并症
→ 低 / 中 / 高 / 很高危
```

危险因素 ≠ 靶器官损害 ≠ 已发生临床疾病。

眼底：I动脉变细 / 反光增强；II加交叉压迫；III加出血 / 棉絮状渗出；IV加视盘水肿。

---

## KP13｜高血压危象：急症 vs 亚急症看急性靶器官损害

> **讲义定位 →** P310。  
> **主提示**：危象入口；真正分界；高压绝对值与损害不成正比；脑病 / 恶性接口。

当前 Study危象常以 `>180/120 mmHg` 为入口，但：

```text
有急性进行性心 / 脑 / 肾等靶器官损害
→ 高血压急症

无急性靶器官损害
→ 高血压亚急症
```

血压绝对值与急性损害程度不成正比。脑损害 / 水肿突出 → 高血压脑病；Study另保留 DBP持续≥130且肾损害突出作为恶性 / 急进型临床入口。

---

## KP14｜急症降压：迅速，但不能把灌注一起打掉

> **讲义定位 →** P310。  
> **主提示**：为什么不能一步正常；当前Study 1h / 2–6h / 24–48h节奏。

长期高压使重要器官自身调节曲线右移：

```text
若突然降到正常人水平
→ 灌注压骤降
→ 心脑肾缺血
```

当前 Study：1h内MAP降幅≤25%；2–6h约降至160/100；24–48h逐步正常。若出现器官缺血，降幅更小。

---

## KP15｜急症药物：先看最危险的靶器官

> **讲义定位 →** P310。  
> **主提示**：Study总入口；为什么初期不猛利尿；ACS / 心衰、脑、妊娠 / 肾场景。

当前 Study：急症用静脉药，一般入口硝普钠；亚急症用口服快速起效药如 CCB，在24–48h降压。初期一般不首选呋塞米，除非急性心衰 / 明显容量负荷。

| 场景 | Study入口 | 机制 |
|---|---|---|
| 一般急症 | 硝普钠 | 动静脉扩张，以降后负荷突出 |
| ACS / 急性心衰 | 硝酸酯 | 扩静脉降前负荷 + 冠脉接口 |
| 急性脑血管 | 尼卡地平 | 扩血管 / 脑血流接口 |
| 妊娠 / 肾功能不全 | 拉贝洛尔 | α+β阻断接口 |
| 小动脉扩张 | 肼屈嗪 | 动脉侧 |

当前 Study口径保留，不用外部指南静默重排。

# Part D｜慢性治疗：围绕主导变量和器官风险

## KP16｜生活方式与慢性目标：治疗对象不是数字本身

> **讲义定位 →** P311。  
> **主提示**：当前Study目标值；限盐；生活方式底座。

当前 Study：一般 `<140/90`；合并糖尿病 / 肾病 / 心衰 / 冠心病 `<130/80`；老年单纯收缩期强调SBP安全达标；CKD特殊目标调用泌尿 Study。

生活方式：盐 `<6g/d`；补钾 / 叶酸接口；控重、戒烟、活动、改善糖脂代谢。

```text
限盐 → ECF / 容量负荷↓
控重 / 代谢 → 交感、胰岛素抵抗、内皮损伤与AS风险↓
```

所有风险层级都需要生活方式，不是“轻症专属”。

## KP17｜药物总原则与联合：同时打多个升压环节

> **讲义定位 →** P311–314。  
> **主提示**：个体化、小剂量、长效、联合、平稳、不骤停；优化组合；三药含利尿剂；SPC。

```text
单药打一个环节
→ 其他调压系统可代偿

不同机制联合
→ 同时降低容量 / CO / TPR / RAAS
→ 更易达标
```

当前 Study优化组合：`A+C / A+D / C+D / C+B`；三药联合强调含利尿剂；SPC改善依从性。

## KP18｜ABCD：先记作用层级，再记药名和禁忌

> **讲义定位 →** P314–315；**讲义回看 →** B2。  
> **主提示**：A/B/C/D各打哪层；适应与重要禁忌。

### A｜ACEI / ARB / ARNI

```text
ACEI：AngⅡ生成↓ + 缓激肽降解↓
ARB：AT1阻断
ARNI：ARB + 脑啡肽酶抑制
```

适用：糖尿病 / 蛋白尿、高血压、冠心病、慢性心衰 / DCM抗重构接口；Study痛风提示ARB。注意双侧肾动脉狭窄、妊娠、高钾、低血压 / 肾功能；ACEI干咳 / 血管性水肿；ACEI+ARB不合用。

### B｜β阻断

心脏β1 → HR / 收缩 / CO↓；球旁β1 → 肾素 / RAAS↓。适合交感 / 心率 / 肾素高、冠心病、快速节律、甲亢、HCM、稳定慢性心衰接口。哮喘、变异心绞痛、雷诺、病窦 / 严重AVB、急性失代偿等慎 / 禁；长期高剂量勿骤停。

### C｜CCB

二氢吡啶偏血管；非二氢吡啶兼负性频率 / 传导 / 肌力。降低TPR，适合老年 / 盐敏感、哮喘、变异、雷诺、冠心病、痛风接口。非DHP在HFrEF、病窦 / 严重AVB受限；BPH场景的Study特殊进入MI-D。

### D｜利尿剂

早期排Na水 → ECF / CO↓；后期血管平滑肌Na / Ca改变 → 舒张、TPR↓。容量依赖 / 老年盐敏感、心衰适用；GFR<30当前Study选袢。痛风避免噻嗪；急性右室MI避免强利尿；注意低K / 代谢。

## KP20｜三类继发性高血压：肾实质、肾血管、主动脉缩窄

# Part E｜动脉粥样硬化：内膜中的脂质—炎症—修复反应

## KP21｜危险因素与脂蛋白：先确定进入内膜的脂质负荷

> **讲义定位 →** 病理P42、内科P330；**讲义回看 →** 生化。  
> **主提示**：年龄 / 性别、吸烟、HTN、DM、血脂；LDL；继发高脂。

危险因素：中老年男性 / 绝经后女性、高脂、高血压、DM / 胰岛素抵抗、吸烟、甲减、代谢综合征等。

```text
TC / TG / LDL-C / VLDL / CM / apoB ↑ → 风险↑
HDL / apoA ↓ → 风险↑
```

当前 Study最强调 LDL-C，尤其 ox-LDL。继发高脂接口：DM / 高胰岛素、甲减、肾病综合征。

## KP22｜始动环节：内皮反复损伤后，脂质和白细胞才进入内膜

> **讲义定位 →** 病理P42–43；**讲义回看 →** B2、B4。  
> **主提示**：正常内皮；损伤→LDL / 黏附分子 / 单核；为什么AS是慢性炎症。

正常内皮是主动屏障：抗栓、舒缩、调黏附 / 迁移 / 增殖。

```text
高压 / 吸烟 / 糖脂异常
→ 内皮功能 / 屏障受损
→ LDL进入内膜并氧化
→ P-selectin、VCAM-1等黏附分子↑
→ 单核 / T细胞黏附、迁入
```

巨噬、T细胞、SMC、细胞因子和MMP持续参与，所以不是静态“脂肪堆积”。

始动环节＝内皮损伤；特征细胞＝泡沫细胞；最早肉眼病变＝脂纹，三个问题不能混。

## KP23｜泡沫细胞与脂纹：巨噬细胞和SMC都能吞脂

> **讲义定位 →** 病理P42–44。  
> **主提示**：两来源、受体、最早病变。

巨噬源：单核→巨噬 → 清道夫受体 / CD36 / Fc → 摄取ox-LDL → 泡沫细胞。

SMC源：中膜SMC在PDGF / FGF等作用下迁入内膜 / 增殖 → 当前Study LPL受体接口 → 吞脂 → 肌源性泡沫细胞。

大量泡沫细胞聚集 → **脂质点 / 脂纹**，肉眼黄色点状 / 条纹。

> 两类都能成为泡沫细胞，但形成纤维帽 / ECM的主力是SMC。

---

## KP24｜从脂纹到纤维帽与粥样坏死核心

> **讲义定位 →** 病理P44–45。  
> **主提示**：SMC / ECM；坏死核心；MMP与帽变薄。

```text
脂纹
+ SMC迁移 / 增殖
+ SMC合成胶原、蛋白多糖、弹性蛋白
→ 纤维帽 / 纤维斑块
```

```text
ox-LDL毒性
+ 泡沫 / 炎症细胞凋亡坏死
→ 脂质、细胞碎屑、胆固醇结晶等
→ 粥样坏死核心
```

炎症细胞释放MMP等降解胶原 → 帽变薄、机械强度下降、破裂风险↑。SMC既能形成泡沫细胞，也能合成保护性纤维帽，不是单向“促坏”。

## KP25｜稳定 vs 易损斑块：固定狭窄程度 ≠ 急性事件风险

> **讲义定位 →** 病理P45–46；**讲义跳转 →** B6接口。  
> **主提示**：皮厚馅少 / 皮薄馅多；继发改变；为什么狭窄不重也会ACS。

| 类型 | 结构 | 主后果 |
|---|---|---|
| 稳定 | 帽厚、核心小、炎症较少 | 固定狭窄 / 稳定缺血 |
| 易损 | 帽薄、核心大、炎症活跃 | 破裂 / 侵蚀 → 血栓 / ACS |

继发改变：斑块内出血、破裂 / 溃疡、血栓、胆固醇栓 / 血栓栓塞、梗死、营养不良性钙化、动脉瘤、狭窄。

```text
固定狭窄程度
→ 决定慢性血流储备

斑块稳定性
→ 决定突然血栓事件风险
```

狭窄不极重但高度易损也可引起 ACS。完整ACS归 B6。

## KP26｜AS器官地图：同一内膜病变落到不同管路

> **讲义定位 →** 病理P46–47。  
> **主提示**：大 / 中动脉；冠脉、主动脉、颈脑、肾、四肢、肠系膜后果。

主要累及体循环大型弹力动脉和中型肌性动脉；肺循环少见。

| 部位 | Study高频后果 |
|---|---|
| 冠脉 | 最严重；LAD最常见 → CHD / MI |
| 主动脉 | 后壁 / 分支开口，腹主动脉较重 → 动脉瘤 / 分支缺血 |
| 颈动脉 | 颈内动脉起始部 |
| 脑动脉 | MCA、基底、Willis等 → 缺血 / 软化 / 出血接口 |
| 肾动脉 | 开口 / 近端 → AS性固缩肾 / 大瘢痕肾 |
| 四肢 | 下肢多 → 缺血 / 坏疽，完整B9 |
| 肠系膜 | 肠缺血坏死接口 |
| 升主动脉 / 瓣膜 | 主动脉瓣硬化 / 狭窄接口 |

B5出口：长期高压→小动脉重构 + 心脏压力负荷；长期内皮损伤→中大动脉AS；两者相互促进 → 慢性固定狭窄或急性斑块事件。
