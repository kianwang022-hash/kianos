# Block 10｜心律失常 · 学习阅读版 v2｜最终执行版
## 先判断稳定性，再命名节律

> **中心问题**：面对异常节律，怎样先按有无脉搏和血流动力学稳定性决定是否必须立刻处理，再用快慢、QRS宽窄、规则性和房室关系定位机制、命名节律并选择药物、复律、除颤或起搏？

先把电活动接回一次真正的泵血：冲动从窦房结起，经心房、房室结和希浦系统到心室，频率、房室顺序与心室同步共同影响充盈和有效射血。冲动发得不对、在环路里反复跑，或该传下去时传不过去，都可能让机械输出受损。ECG能记录这些电事件，却不能替我们证明脑和其他器官已经得到血。

所以入口先看患者有没有有效脉搏、灌注是否稳定。稳定后再看快慢、QRS宽窄、规则性与P–QRS关系，把波形接回起源和传导路径；治疗再分别针对诱因、异常形成或环路、过慢或传导失败。房颤另有心房淤滞到栓塞的一支，控率或转复不能替代抗凝判断。危险状态按下方原算法优先处理，不等全部节律命名完。

先讲通这条“电活动→机械输出→灌注”的整块机制，再沿同一模型的自然节点填入正式标题〔完整 Prompt〕与Core，最后仍压回同一条线。药物、间期和条件的精记保留完整答案，波形辨认仍回原图。

# 先用这一条算法进入全文

心律失常不是一堆互不相干的 ECG 图形。进入任何节律题，顺序固定为：

```text
0. 有有效脉搏吗？血流动力学稳定吗？
   无脉搏 → 直接进入 B12 骤停路径，不等完整命名
   有脉但不稳定 → 先决定电治疗 / 起搏，不等把图认完
        ↓
1. 快还是慢？
        ↓
2. QRS 窄还是宽？
        ↓
3. RR 规则还是不规则？
        ↓
4. P 波存在吗？P 与 QRS 是什么关系？
        ↓
5. 再定位起源 / 机制
   窦性、房性、房室结、旁路、室性、传导阻滞
        ↓
6. 最后决定治疗目标
   去诱因 / 控率 / 转复 / 抗凝 / 消融 / 起搏 / ICD
```

> **最重要边界**：ECG 是节律证据，不是灌注证据；有规则电活动也不保证存在有效脉搏。B3 提供正常电生理语言，本 Block 只在算法需要时调用 ECG 纸面信息。

## 整篇只保留一条主线

```text
异常冲动形成 / 异常冲动传导
→ 心率、节律、房室顺序或心室同步异常
→ 舒张充盈、有效 SV、冠脉供需和脑灌注可能受损
→ 先判有无脉搏与稳定性
→ 再用快慢—宽窄—规则—房室关系定位
→ 最后命名并处理
```

# 总 Framework

<!-- kianos:framework id="circulation-b10-framework-main" -->

```text
医学因果：异常冲动形成 / 异常传导
→ 频率、房室顺序或心室同步异常
→ 充盈、有效SV、冠脉供需与脑灌注可能受损

临床入口先看人：有无有效脉搏 / 血流动力学是否稳定
├─ 无脉 → B12骤停路径；ECG有电活动不等于有灌注
├─ 有脉而快速节律致不稳 → 可同步者同步复律
│  持续多形VT不可可靠同步 → 立即非同步电击，即使仍有脉
├─ 严重缓慢不稳 → 判断可逆原因并进入起搏处理
└─ 稳定 → 快慢 / QRS宽窄 / RR规则 / P-QRS关系定位

机制分支与观察相互校准：
形成异常 → 窦性快慢 / 提前异位；上位过慢或下传受阻 → 下位逸搏
折返环路 + 单向阻滞 + 缓慢传导 → AVNRT / AVRT等持续快速节律
房扑 / 房颤 → 房室传导与有效房缩改变；房颤另有左房淤滞 / 栓塞支路
室性激动 / 复极异常 → 室早、室速等；再次回脉搏与稳定性门
传导受阻 → 延迟 / 漏传 / 房室脱节；房室分离还须比较房率与室率

治疗按靶点分流：去诱因，控制过快或异常机制，补偿过慢 / 传导失败
房颤抗凝独立于控率 / 转复；器械按起搏与终止致命VT / VF分别定位
处理效果回看机械输出 / 灌注，不把ECG命名或药物清单当作终点
```

# 同一模型上的自然节点〔完整 Prompt〕

以下消费原有“电活动影响机械输出，因此稳定性优先”的主线。医学因果、ECG观察和临床决策各保留自己的方向；自然节点展开完整 Prompt，不按节律病名顺排，精确数值和波形仍由正文 / Source承接。

```text
A1 循环｜B10 把电活动异常接回B1的充盈、搏出和灌注，正常电生理调用B3。
异常冲动形成 / 异常传导 → 频率、房室顺序或心室同步改变
→ 充盈、有效SV、冠脉供需和脑灌注可能受损；电活动不保证有效脉搏

① 因为危险落在机械输出，患者状态先决定处理时效
先判有效脉搏 / 稳定性，再用快慢、宽窄、规则和房室关系解释未知节律
〈ECG 四道门 + 稳定性门〔脉搏/稳定性｜快慢/QRS/RR/房室关系｜起源/机制｜治疗目标〕〉
├─ 无有效脉搏 → B12骤停路径；VF / pVT为可电击节律，同时需要CPR
├─ 有脉而快速节律导致低压 / 休克 / 缺血 / 肺水肿 / 意识障碍
│  可可靠同步者 → 同步电复律；持续多形VT → 立即非同步电击，即使仍有脉
│  同步R波用于避开易损期，不取代有无脉搏与稳定性判断
│  〈快速型：先看有无脉搏与稳定性，再决定同步复律或非同步除颤〔脉搏｜稳定性｜单形/多形｜同步机制｜VF/pVT路径〕〉
├─ 严重缓慢不稳 → 评估可逆原因并进入起搏判断
└─ 稳定 → 进入下面的电图定位；任何阶段恶化都返回这一门槛

② 观察层：ECG测量电事件，Holter把症状与电事件对应
P看心房除极，PR看房室传导，QRS看心室除极，ST / T / QT看复极相关信息
〈ECG 先回答“谁在除极、传了多久、心室如何复极”〔ECGvsHolter职责｜标尺2轴×大小格｜基本对象6｜正常/病因边界〕〉
窦房结 → 心房 → 房室结 → 希氏束 / 束支 / 浦肯野 → 心室快速同步除极
宽QRS可来自室性起源、束支阻滞、预激或差异传导，不能只凭宽度判室速
〈宽 QRS 的第一意义：心室没有按“寻常路”快速同步除极〔正常传导路｜宽QRS来源3组｜P/PR/QRS/RR各司其职〕〉
图像旁查：窦房出口问题改变整组P-QRS；束支问题改变QRS；房室增大各有图形
精确导联、时限与形态回原图，不能把心腔增大顺排成一种节律的下一阶段
〈窦房阻滞、束支阻滞与心腔增大〔窦房阻滞2型：PP/脱落｜RBBBvsLBBB｜房大2型P｜室大2侧〕〉

③ 用起源与路径解释观察结果；以下是并行机制，不是疾病进展次序

冲动形成：窦房结可过快、过慢或停发；异位冲动提前 / 快速主导 → 早搏 / 快速节律
上位起搏过慢或冲动下传受阻 → 下位被迫接管 → 逸搏 / 逸搏心律
〈异常冲动形成：窦性异常、被动异位、主动异位〔窦性5类｜主动vs被动异位｜早搏/逸搏→连续节律〕〉
窦性P仍在但RR变短 / 长 → 窦速 / 窦缓；暂时不发冲动 → 窦停
病窦可慢节律与房性快速节律交替，快速结束后长停顿 → 低灌注症状 / 起搏判断
〈窦速、窦缓、窦停与 SSS：先看 P 波是否仍为窦性，再看频率和长间歇〔窦速vs窦缓：P/RR｜窦停倍数关系｜SSS慢节律3类｜慢快交替｜症状→起搏〕〉

异常传导可造成阻滞，或在环路中重新激动已恢复的组织：
环路 + 单向阻滞 + 缓慢传导 → 冲动反复循环 → 持续快速节律
〈异常传导：阻滞、折返、旁路与生理性干扰〔传导异常3类｜折返条件3｜循环机制｜形成vs传导归类〕〉
环路的两种位置：
├─ AVNRT：房早遇快径仍不应 → 慢径下传 → 已恢复的快径逆传 → 结内折返
│  〈AVNRT：房室结快径与慢径形成内部折返〔快慢径：速度/ERP｜房早→折返环｜终止靶点｜药物/消融〕〉
└─ 顺向AVRT：房 → AV结 / 希浦 → 室 → 旁路逆传 → 房，QRS通常窄
   窦律预激则是旁路提前激动部分心室 → 短PR / δ波，与发作时环路分开
   合并预激房颤时，不能套普通房颤控率或规则顺向AVRT的AV结阻断路径
   〈预激综合征：旁路提前激动心室〔预激ECG｜顺向环路→QRS｜检查/根治｜房颤边界〕〉
上述折返可表现为窄而规则、突发突止的PSVT
稳定者迷走 / 腺苷等打断环路，反复可消融；不稳定回电治疗门
〈阵发性室上性心动过速：突发突止、窄 QRS、规则快速〔PSVT机制/起止｜ECG4轴｜频率｜稳定处理顺序｜不稳定入口〕〉

房性快速活动：
├─ 房扑的规则房活动形成F波；房室传导比固定或变化 → 室律规则或不规则
│  〈房扑：规则 F 波，心室规则性取决于房室传导比〔F波3特征｜心房率｜QRS｜房室比固定vs变化→室律〕〉
└─ 房颤的紊乱房活动 → 无有效房缩，典型ECG见f波与RR绝对不齐
   → S1强弱变化 / 脉搏短绌；充盈与CO影响随底物、室率和负荷而变
   〈房颤识别：三个不一致与两个主要后果〔ECG｜体征3联｜S4｜CO条件｜栓塞〕〉
   ├─ 房缩消失 + 过快 / 不规则室率 → 充盈和输出问题
   │  → 分别选择节律控制或控率；收缩性心衰保留用药条件
   │  〈房颤节律控制 vs 心室率控制〔节律控制3路｜控率首选/替代｜收缩性心衰条件｜控率适合情境｜抗凝独立〕〉
   └─ 左房 / 左心耳淤滞 → 附壁血栓 → 体循环栓塞
      → 独立评估抗凝；控率成功不等于可停抗凝
      转复前后仍有排栓 / 抗凝条件，危急不稳不能等待常规择期时间窗
      〈房颤抗凝：先区分瓣膜性 / 非瓣膜性，再评估栓塞风险〔抗凝分流｜评分8项/阈值｜NOAC｜封堵条件｜转复前后〕〉
   病程 / 策略旁查：阵发、持续与长期持续看时间，永久性包含共同治疗决定
   四类不是必然逐级恶化；同时追查心内外底物
   脉搏转为规则还须核对房室关系，不能据此判房颤治愈
   〈房颤分类与“孤立性房颤”〔4类：时长/转复｜心内外病因｜孤立性房颤〕〉

室性激动直接改变心室除极：
├─ 提前激动 → 室早；宽畸形QRS、P关系与暂停一起定位，形态还要连底物判断
│  〈室早：宽大畸形 QRS + 提前发生 + 完全代偿间歇〔ECG4轴｜联律/成对/多源｜间位｜R-on-T〕〉
├─ 连续快速室性激动 → 室速；房室分离、夺获与融合支持室性来源
│  → 立即回看脉搏、稳定性与单形 / 多形，决定药物或电击分流
│  〈室速：宽 QRS 快速节律，寻找房室分离、心室夺获和融合波〔ECG特征｜单形/多形｜脉搏/稳定性｜电击分流〕〉
└─ 长QT与相关诱因可形成TdP，补镁 / 纠因针对复发，不延误必要电击
   再灌注可见较慢、起止缓的AIVR，常观察并处理基础病，不能同套恶性室速处理
   〈尖端扭转型室速与加速性室性自主心律〔TdP：波形/QT/诱因/靶点｜AIVR：背景/起止/处理〕〉

传导受阻：
房室传导延迟 → PR长但每P仍下传；间歇漏传 → P后QRS脱落
完全阻滞 → 房与室各自活动，室由逸搏接管；并非每型都会顺次进展
二度Ⅱ型 / 高度 / 三度的非可逆、非生理性获得性阻滞，永久起搏评估不必等晕厥
〈房室传导阻滞：从 PR 延长到房室完全脱节〔AVB4型：PR/P-QRS/RR｜部位→逸搏QRS/速度｜风险/治疗〕〉
房室分离只是观察结果：三度AVB房率较快；VT室率较快；生理性干扰两者接近
〈房室分离：三度 AVB、室速与生理性干扰用“谁更快”区分〔房室分离3情境｜房率vs室率｜P-QRS关系〕〉

④ 干预回到机制与循环后果，各条路径保留自己的任务
寻找缺血 / 心衰 / 电解质 / 甲亢 / 药物 / 感染缺氧；低风险偶发可观察病因
无症状房颤仍要独立评估心室率与栓塞风险
〈第一原则：小场面不乱治，治疗病因优先〔观察条件｜诱因6组｜无症状房颤的独立风险〕〉
药物 / 消融作用于异常形成或传导环路；普通起搏器补偿过慢或传导失败
ICD预防 / 终止致命VT / VF；模式、药物与精确安全条件各回对应正文
〈抗心律失常药、起搏器与 ICD：先记角色，再把精确表格放入 MI-D〔药物Ⅰ–Ⅳ：靶点/作用/代表｜胺碘酮多通道/不良反应｜起搏4模式：起搏/感知/适用｜VVI同步风险｜ICD任务〕〉
处理后回看有效充盈、搏出和灌注；持续泵负担接B11，无脉 / 灌注崩溃接B12
```

**Prompt 与精记的分工**：模型节点及其完整 Prompt 负责结构化恢复；Core 在原位展开机制与条件。独立精确提取仍有难度的数字、配对、药物、例外或清单可在既有 Memory / Precision 再练一次，和 Prompt 重叠并不冲突，也不因出现在 Prompt 中自动撤销原有记忆身份。已有精记按本块 Memory Routing 核对完整答案；波形和空间关系保留 Source / MedicalVisual。

## KP01｜ECG 先回答“谁在除极、传了多久、心室如何复极”

> **讲义定位 →** 内科印刷 P363–364｜PDF P442–443。  
> **主提示**：ECGvsHolter职责｜标尺2轴×大小格｜基本对象6｜正常/病因边界

<details>
<summary>展开：ECG 先回答“谁在除极、传了多久、心室如何复极”</summary>

### 1｜检查角色

- **心电图**：用于诊断心律失常、心绞痛、心肌梗死；对心律失常的病因评价作用有限。
- **动态心电图 Holter**：用于判断心悸、胸痛、晕厥等症状是否与心律失常同步出现。

### 2｜纸面标尺

```text
横向（时间）：1小格 = 0.04 s；1大格 = 5小格 = 0.2 s
纵向（电压）：1小格 = 0.1 mV；1大格 = 5小格 = 0.5 mV
```

### 3｜六个基本对象

| 对象 | 当前 Study 含义 | 高频数字 / 边界 |
|---|---|---|
| P | 心房除极；前半右房、后半左房 | Ⅱ导联直立、aVR倒置；宽＜0.12s；肢导联高＜0.25mV、胸导联高＜0.20mV |
| PR | 心房除极开始至心室除极开始，反映房室传导 | 0.12–0.20s |
| QRS | 心室除极 | q＜0.04s且＜同导联1/4R；QRS＜0.11s；≥0.12s为宽大畸形接口 |
| ST | 心室缓慢复极，与平台期相关 | 高钙血症按本节 Study 可使ST缩短 |
| T | 心室快速复极 | 必须和ST整体判断 |
| QT | 心室除极开始至复极结束，约等于APD | 与心率成反比；延长可诱发早期后除极 / 尖端扭转 |

节律规则且采用本节标准纸速时，心室率 = 300 ÷ RR 间距所占大格数；不规则节律不能把任意一个 RR 算出的瞬时值当成总体心率。先辨窦性 P，再用间距比较快慢。

（易混：单个心室肌动作电位不等于整张体表 ECG；QRS 是电除极，不是机械射血。）

</details>
<!-- kianos:kp id="circulation-b10-kp02" -->

## KP02｜宽 QRS 的第一意义：心室没有按“寻常路”快速同步除极

> **主提示**：正常传导路｜宽QRS来源3组｜P/PR/QRS/RR各司其职

<details>
<summary>展开：宽 QRS 的第一意义：心室没有按“寻常路”快速同步除极</summary>

正常冲动：

```text
窦房结
→ 心房
→ 房室结
→ 希氏束
→ 左右束支
→ 浦肯野
→ 心室快速同步除极
```

宽大畸形 QRS 常提示：

- 室性心律失常；
- 完全性束支传导阻滞；
- 预激 / 旁路或室内差异性传导。

因此读 ECG 时分别问：

```text
P：心房在做什么？
PR：房到室如何传？
QRS：心室从哪里、以什么路径除极？
RR：心室节律规则吗、频率如何？
```

</details>

# ② 心律失常机制

<!-- kianos:kp id="circulation-b10-kp03" -->

## KP03｜异常冲动形成：窦性异常、被动异位、主动异位

> **讲义定位 →** 内科印刷 P365｜PDF P444。  
> **主提示**：窦性5类｜主动vs被动异位｜早搏/逸搏→连续节律

<details>
<summary>展开：异常冲动形成：窦性异常、被动异位、主动异位</summary>

### 窦性心律失常

- 窦性心动过速；
- 窦性心动过缓；
- 窦性心律不齐；
- 窦性停搏；
- 病态窦房结综合征。

### 异位心律

```text
被动性异位
窦房结过慢或下传受阻
→ 下位起搏点被迫接管
→ 逸搏 / 逸搏心律

主动性异位
异位冲动提前或快速主导节律
→ 早搏 / 心动过速 / 扑动 / 颤动
机制可为异常自律性、触发活动或折返；不全是自律性超过窦房结
```

按本节 Study，连续三个以上早搏可形成心动过速；连续多个逸搏形成逸搏心律。

### 房早与交界早：先找提前的P′来自哪里

- 房早：提前出现形态不同于窦性P的房性P′；经正常房室传导时后随通常正常的QRS，伴室内差异传导时可变宽；若提前的房性冲动遇房室结不应期，P′后也可无QRS，即房早未下传。窦房结被重置时常为不完全代偿间歇，包含该房早的PP间距小于两个基本PP周期。
- 交界早：提前的通常正常QRS，可伴Ⅱ、Ⅲ、aVF倒置的逆行P′；P′可在QRS前、后或与QRS重叠。课程列完全代偿间歇，具体暂停取决于逆行传导是否重置窦房结，不能只凭暂停长度定起源。该条件有[原始电生理病例记录](https://pmc.ncbi.nlm.nih.gov/articles/PMC5357858/)支持；原课程“完全”字样继续保留。

原题精确波形/间期回看：内科印刷P370–371/物理P449–450（房早P′R≥0.12s；交界早P′在QRS前时P′R<0.12s，在后时RP′<0.2s）。先区分主动提前与被动逸搏，再与KP14室早比较；治疗病因原则见KP20。

### 不应把所有室上快速节律都当折返

Source 的非阵发性房室交界性心动过速属于交界区自律性增加或触发活动，常见背景为强心苷中毒，也可见于下壁MI、心肌炎。它渐发渐止，课程心率约70–150次/分或更快，QRS通常正常；可有房室分离，合并文氏型阻滞时室律可不齐。治疗先找病因，疑强心苷中毒时走B11相应处理；不能直接套用PSVT的“固定折返环→消融”逻辑。这里保留识别与安全区别，不新增消融适应证或独立记忆卡。

</details>
<!-- kianos:kp id="circulation-b10-kp04" -->

## KP04｜异常传导：阻滞、折返、旁路与生理性干扰

> **主提示**：传导异常3类｜折返条件3｜循环机制｜形成vs传导归类

<details>
<summary>展开：异常传导：阻滞、折返、旁路与生理性干扰</summary>

### 三类

1. 传导阻滞：窦房、房内 / 房间、房室、室内 / 束支；
2. 折返与旁路异常传导；
3. 生理性传导异常：干扰、脱节、干扰性房室分离。

### 折返三个条件

```text
折返环路
+ 单向传导阻滞
+ 缓慢传导
→ 冲动可在环内反复循环
→ 持续快速节律
```

折返既可归为异常冲动形成，也可归为异常传导。

</details>

# ③ 窦性节律与病态窦房结

<!-- kianos:kp id="circulation-b10-kp05" -->

## KP05｜窦速、窦缓、窦停与 SSS：先看 P 波是否仍为窦性，再看频率和长间歇

> **讲义定位 →** 内科印刷 P366–367｜PDF P445–446。  
> **主提示**：窦速vs窦缓：P/RR｜窦停倍数关系｜SSS慢节律3类｜慢快交替｜症状→起搏

<details>
<summary>展开：窦速、窦缓、窦停与 SSS：先看 P 波是否仍为窦性，再看频率和长间歇</summary>

### 窦速 / 窦缓

二者仍为窦性 P 波：Ⅱ导联直立、aVR倒置。课程成人窦速为心率>100次/分、RR<3大格；窦缓为<60次/分、RR>5大格。窦性心律不齐仍有窦性P，课程以不同PP/RR差值>0.12s描述，常随呼吸变化；不能只因“不齐”就命名房颤。

窦速可见运动、情绪、发热、贫血、甲亢等；窦缓可见运动员、睡眠，也可见缺氧、甲减、颅内病变或负性频率药物作用。先分生理情境和可逆原因，频率异常不自动等于病窦。

### 窦性停搏

```text
窦房结暂时不发冲动
→ P波和随后QRS均缺失
→ 长PP / RR与基本PP / RR通常无固定倍数关系
```

### 病态窦房结综合征 SSS

按 Study 可见：

- 非药物所致持续明显窦缓（课程<50次/分）；
- 窦性停搏 / 窦房阻滞；
- 与房室阻滞并存；
- 慢节律后出现房速、房扑、房颤；
- 房性快速节律终止后再出现长停顿。

因此称为：

> **心动过缓—心动过速综合征。**

还可有运动后心率不能适当增加（变时功能不全）或房室交界逸搏。无心动过缓相关症状者可定期观察；有反复黑矇、晕厥和不可逆显著缓慢节律时，治疗主体进入起搏器，而不是继续用负性频率药压慢窦房结。慢—快交替时，单纯抗快速节律治疗可能加重停顿；合并房扑/房颤的栓塞风险仍需另行评估。

</details>

# ④ 预激、AVRT 与 AVNRT

<!-- kianos:kp id="circulation-b10-kp06" -->

## KP06｜预激综合征：旁路提前激动心室

> **讲义定位 →** 内科印刷 P368–369｜PDF P447–448。  
> **主提示**：预激ECG｜顺向环路→QRS｜检查/根治｜房颤边界

<details>
<summary>展开：预激综合征：旁路提前激动心室</summary>

典型 ECG：

```text
PR＜0.12s
QRS起始部粗钝形成δ波
QRS可增宽
ST-T继发性改变
```

核心：房室旁路绕开房室结生理延搁，提前激动部分心室。

顺向型AVRT：心房 → 房室结 → 希氏束/浦肯野 → 心室 → 旁路逆传回心房，构成折返。心室经正常传导系统下传激动，所以QRS通常窄；若合并室内差异性传导等也可增宽。它与窦律时旁路提前激动部分心室形成δ波，是不同观察场景。

逆向型AVRT则沿旁路前传、房室结逆传，心室除极不走正常希浦入口，QRS宽。顺向与逆向是环路方向之别，不能用“有预激”代替当前发作路径判断。

- 最佳辅助检查：心内电生理检查接口；
- 根治：射频导管消融旁路；
- 稳定、规则顺向AVRT按迷走刺激→腺苷→合适房室结抑制药处理；课程禁用强心苷，因其可缩短旁路不应期。若不稳定，回同步电复律入口；
- 预激伴房颤/房扑与规则顺向AVRT须分开：课程前者首选电复律，药物列伊布利特/普罗帕酮；禁用强心苷、维拉帕米、地尔硫卓、β阻断和胺碘酮。现行AF指南同样警示预激房颤避免房室结阻断药（还包括腺苷）；不稳定立即电复律。不能把规则顺向AVRT的腺苷路径套给宽QRS不规则的预激房颤。

</details>
<!-- kianos:kp id="circulation-b10-kp07" -->

## KP07｜AVNRT：房室结快径与慢径形成内部折返

> **主提示**：快慢径：速度/ERP｜房早→折返环｜终止靶点｜药物/消融

<details>
<summary>展开：AVNRT：房室结快径与慢径形成内部折返</summary>

```text
快径：传导快，不应期长
慢径：传导慢，不应期短

房早到来时快径仍在不应期
→ 冲动沿慢径下传
→ 快径恢复后逆传
→ 形成折返
```

治疗的核心不是“把全心脏变慢”，而是打断房室结折返环：

- 迷走刺激；
- 腺苷（Study 中药物首选接口）；
- β受体拮抗剂；
- 维拉帕米 / 地尔硫卓；
- 胺碘酮、强心苷等按具体场景；
- 反复发作可消融。

</details>
<!-- kianos:kp id="circulation-b10-kp08" -->

## KP08｜阵发性室上性心动过速：突发突止、窄 QRS、规则快速

> **讲义定位 →** 内科印刷 P370–372｜PDF P449–451。  
> **主提示**：PSVT机制/起止｜ECG4轴｜频率｜稳定处理顺序｜不稳定入口

<details>
<summary>展开：阵发性室上性心动过速：突发突止、窄 QRS、规则快速</summary>

典型：

- 突发、突止；
- RR 绝对规则；
- 心率保留两套来源口径：内科正文多150–200次/分、偶可>250；本节引用《诊断学》为160–250次/分。不能合成唯一精确诊断阈值，既有M21继续保留Source范围冲突；
- P 波常不易辨认或呈逆行；

治疗：

```text
稳定
→ 迷走刺激
→ 腺苷
→ 其他抑制房室结药物

血流动力学障碍
→ 同步电复律
```

</details>

# ⑤ 房扑与房颤

<!-- kianos:kp id="circulation-b10-kp09" -->

## KP09｜房扑：规则 F 波，心室规则性取决于房室传导比

> **讲义定位 →** 内科印刷 P373｜PDF P452。  
> **主提示**：F波3特征｜心房率｜QRS｜房室比固定vs变化→室律

<details>
<summary>展开：房扑：规则 F 波，心室规则性取决于房室传导比</summary>

```text
P波消失
→ 规则锯齿样F波
→ F波间无等电位线
```

心房率常约250–350次/分；QRS多正常，差异传导时可变宽。若房室传导比固定，心室节律可规则；传导比变化时可不规则。应从实际心房率除以传导比例得到心室率，例如心房率300次/分、2:1下传时约150次/分，不能把整个250–350范围一律当150。

</details>
<!-- kianos:kp id="circulation-b10-kp10" -->

## KP10｜房颤识别：三个不一致与两个主要后果

> **讲义定位 →** 内科印刷 P374–376｜PDF P453–455。  
> **主提示**：ECG｜体征3联｜S4｜CO条件｜栓塞

<details>
<summary>展开：房颤识别：三个不一致与两个主要后果</summary>

### ECG

- P 波消失；
- 出现细小、不规则f波，课程心房率350–600次/分，V1导联常较明显；
- RR 绝对不齐；
- QRS 多正常，室内差异性传导 / 预激可增宽。

### 三个不一致

```text
心律绝对不齐
S1强弱不等
脉搏短绌：脉率＜心率
```

### 两个主要后果

1. 心房有效收缩消失，加上室率过快或RR不规则，可损害充盈和输出；CO变化取决于原有心功能、室率与负荷。课程“至少下降25%”不能作为所有房颤患者的固定下限。无有效房缩，因此无S4，合并二尖瓣狭窄时原舒张晚期杂音增强部分也可消失；
2. 左房 / 左心耳血流淤滞 → 附壁血栓 → 体循环栓塞，常见脑栓塞。

原题“房颤心律变规则”须列三路：恢复窦律；转为固定传导比例房扑或其他规则异位节律；房颤合并完全房室阻滞，心室由规则逸搏接管（课程举强心苷中毒）。因此脉搏整齐不等于房颤已治好，仍要看P/f波与房室关系。

</details>
<!-- kianos:kp id="circulation-b10-kp11" -->

## KP11｜房颤分类与“孤立性房颤”

> **主提示**：4类：时长/转复｜心内外病因｜孤立性房颤

<details>
<summary>展开：房颤分类与“孤立性房颤”</summary>

先分时间轴与治疗策略轴：

| 类别 | 恢复要点 |
|---|---|
| 阵发性 | 发作在7天内终止；课程强调能自行终止 |
| 持续性 | 连续超过7天，往往需干预终止 |
| 长期持续/持久性 | 连续超过12个月，仍考虑节律控制 |
| 永久性 | 医患共同接受当前房颤，不再尝试恢复/维持窦律；属于治疗决策 |

旧课将永久性写为超过1年、不能转复或24小时内复发，这个描述不能当成“生物学上永远治不好”的定义。四类不必逐级必然演变。常见底物：

- 心脏疾病：二尖瓣狭窄等瓣膜病、心肌病、高血压性心脏改变；
- 心外疾病：甲亢；
- 无器质性心脏病、无高危因素者可称孤立性房颤，Study 真题可选择观察或消融等具体情境。

</details>
<!-- kianos:kp id="circulation-b10-kp12" -->

## KP12｜房颤抗凝：先区分瓣膜性 / 非瓣膜性，再评估栓塞风险

> **讲义定位 →** 内科印刷 P375–376｜PDF P454–455。  
> **主提示**：抗凝分流｜评分8项/阈值｜NOAC｜封堵条件｜转复前后

<details>
<summary>展开：房颤抗凝：先区分瓣膜性 / 非瓣膜性，再评估栓塞风险</summary>

- 合并机械瓣 / 中重度二尖瓣狭窄等瓣膜性场景，按 Study 采用长期华法林等方案，不用课程评分决定是否需要抗凝。Source 本表统一写INR 2.0–3.0，只能保留为该课程表口径，不能作为所有机械瓣的共同目标；机械瓣须按瓣位、瓣型及栓塞危险因素确认靶值。该限定有[ACC/AHA瓣膜指南官方摘要](https://www.acc.org/latest-in-cardiology/ten-points-to-remember/2020/12/16/22/01/2020-acc-aha-vhd-gl-pt-3-gl-vhd)依据，本块不增列另一套机械瓣数值表；
- 其余按课程CHA₂DS₂-VASc评估：心衰1、高血压1、年龄≥75岁2、糖尿病1、既往卒中/TIA/栓塞2、血管病1、年龄65–74岁1、女性1分；两个年龄档互斥，不重复加分。
- 课程阈值：男0/女1通常不因房颤常规抗凝；男1/女2权衡；男≥2/女≥3推荐。符合条件时优先直接口服抗凝药（NOAC/DOAC），仍需核对肾功能及出血风险；
- 左心耳封堵需在卒中风险、长期抗凝禁忌/高出血风险等条件下评估；抗凝后仍有事件应先核查依从性、剂量及其他病因，不能仅凭一次事件或高出血评分自动做封堵。

课程药物配对：达比加群抑制凝血酶，利伐沙班抑制Xa；不需常规凝血指标监测，不等于不评估肾功能、出血和依从性。Source 另列严重出血时“华法林—维生素K”“达比加群—依达赛珠单抗”，这是原题药物配对，不是完整严重出血急救方案。肝素/抗凝血酶、华法林/VitK因子、枸橼酸/Ca²⁺等共同抗凝机制回B4；ACS、库存血、肺栓塞、肾病综合征的用药不在本块另建治疗表。

转复前后：

```text
房颤持续＞48h或时间不明
→ 先有效抗凝至少3周，或走经食管超声排栓的提前转复路径
→ 转复前建立治疗性抗凝，排栓不等于不用抗凝
→ 转复后通常至少4周，是否长期继续再按栓塞风险
```

危急不稳定者不能因等待常规抗凝而延误电复律，抗凝按禁忌及急救条件尽快衔接。

版本分清：上面的评分和>48 h沿用课程；2024 ESC改用不含性别的CHA₂DS₂-VA，并采用>24 h的择期转复安全门槛。不能把两版分值与时间拼成一套新规则，也不能把短于48 h理解成必然安全、必然无需抗凝。

</details>

## KP13｜房颤节律控制 vs 心室率控制

> **主提示**：节律控制3路｜控率首选/替代｜收缩性心衰条件｜控率适合情境｜抗凝独立

<details>
<summary>展开：房颤节律控制 vs 心室率控制</summary>

### 节律控制

- 药物转复：普罗帕酮、胺碘酮等按器质性心脏病和禁忌选择；
- 电复律：不稳定时首选；
- 导管消融：根治 / 长期节律控制的重要手段。

### 心室率控制

- β受体拮抗剂为常用首选；
- 非二氢吡啶 CCB 有负性肌力作用，收缩性心衰禁用；
- 收缩性心衰合并快房颤可用 β受体拮抗剂、强心苷或胺碘酮等按场景；
- 老年、房颤持续时间长、左房明显扩大或难以维持窦律者更常采用控率策略。

课程控率目标：无症状且LV收缩功能正常，静息室率<110次/分；症状明显或心动过速性心肌病，静息<80、运动时<110次/分。达到目标后用Holter检查过缓或停搏；具体目标须结合症状、心功能与耐受，不能把所有人压到同一心率。

（易混：控率不是恢复窦律；抗凝也不能因为心室率控制好而自动停用。）

</details>

## KP14｜室早：宽大畸形 QRS + 提前发生 + 完全代偿间歇

> **讲义定位 →** 内科印刷 P377–378｜PDF P456–457。  
> **主提示**：ECG4轴｜联律/成对/多源｜间位｜R-on-T

<details>
<summary>展开：室早：宽大畸形 QRS + 提前发生 + 完全代偿间歇</summary>

典型：

- 提前出现宽大畸形 QRS；
- QRS 前无相关 P 波；
- ST-T 与 QRS 主波方向相反，为继发性改变；
- 常有完全性代偿间歇。



| 形态 | 怎样读出结构 |
|---|---|
| 二联律 | 1个正常搏动后接1个室早，反复出现 |
| 三联律 | 2个正常搏动后接1个室早，反复出现 |
| 成对 | 连续2个室早 |
| 多源/多形 | 关注不同起源或同一导联不同QRS形态；单凭形态不能包办起源定位 |
| 间位 | 插入两个窦性搏动之间，后无通常代偿间歇 |
| R-on-T | 室早QRS落在前一搏T波上，涉及易损期风险 |

课程危险形态包括：频发（>5次/分）、成对、多源/多形、短阵室速、R-on-T/落于易损期等。按“数量与连续性—形态—落点”分组恢复，但这些是课程危险线索，不替代器质性心脏病、缺血、电解质和症状的整体风险判断。偶发、无症状且无器质性心脏病者通常先观察和处理病因。

</details>

## KP15｜室速：宽 QRS 快速节律，寻找房室分离、心室夺获和融合波

> **讲义定位 →** 内科印刷 P378–379｜PDF P457–458。  
> **主提示**：ECG特征｜单形/多形｜脉搏/稳定性｜电击分流

<details>
<summary>展开：室速：宽 QRS 快速节律，寻找房室分离、心室夺获和融合波</summary>

典型室速：

- 连续≥3个室性搏动；
- 宽大畸形 QRS；
- 心室率常约100–250次/分；
- 房室分离；
- 可见心室夺获和室性融合波。

治疗先看有无脉搏，再结合形态与稳定性；以下有脉分支指可可靠同步的单形性室速：

```text
有脉且稳定
→ 按器质性心脏病与药物禁忌选择胺碘酮等

有脉、单形且血流动力学不稳定
→ 同步电复律

无脉性室速
→ B12：按可电击骤停节律处理，进入非同步除颤 / CPR
```

持续多形性室速是重要例外：QRS逐搏变化，不能可靠同步，应立即非同步电击；不能等到无脉才除颤。尖端扭转的复发处理还要看基础QT和诱因，见KP16。

</details>

## KP16｜尖端扭转型室速与加速性室性自主心律

> **主提示**：TdP：波形/QT/诱因/靶点｜AIVR：背景/起止/处理

<details>
<summary>展开：尖端扭转型室速与加速性室性自主心律</summary>

### 尖端扭转型室速

- 属多形性室速；
- QRS 振幅和轴围绕基线扭转；
- 常伴QT延长；课程还列明显U波、发作心室率多200–250次/分；
- 与低钾、低镁、奎尼丁 / 胺碘酮等药物或先天性长 QT 接口相关；
- Study强调补镁治疗，先天性长QT可用β受体拮抗剂接口；纠正诱因与防复发不能延误持续多形VT所需的非同步电击。

### 加速性室性自主心律

- 属较慢的室性心动过速；
- 常见于心肌梗死再灌注；
- 起止较缓，常无需专门治疗，重点在观察和处理基础病；
- 课程本页列连续3–10个室性QRS，旁注约60–110次/分，较室性逸搏20–40次/分快。它们是本页描述，不把短阵搏数当作所有AIVR的定义上限。

</details>

## KP17｜房室传导阻滞：从 PR 延长到房室完全脱节

> **讲义定位 →** 内科印刷 P379–382｜PDF P458–461。  
> **主提示**：AVB4型：PR/P-QRS/RR｜部位→逸搏QRS/速度｜风险/治疗

<details>
<summary>展开：房室传导阻滞：从 PR 延长到房室完全脱节</summary>

| 类型 | ECG核心 | 风险 / 处理 |
|---|---|---|
| 一度 | 每个P后均有QRS；PR＞0.20s且恒定 | 多观察病因 |
| 二度Ⅰ型 | PR进行性延长，直至一个QRS脱落；RR进行性缩短 | 多为房室结，通常观察 |
| 二度Ⅱ型 | PR恒定，突然P后无QRS；长RR常为基本周期整倍数 | 高风险；非可逆/非生理性获得性阻滞，无论有无症状均应评估永久起搏 |
| 三度 | P和QRS各自规律但无固定关系，房率＞室率 | 严重缓慢型，起搏为主体 |

阻滞在房室结时，交界逸搏约40–60次/分，QRS可窄、节律相对稳定；阻滞在希浦系统时，室性逸搏常<40次/分（课程潜在室性起搏点约20–40次/分），QRS宽、节律更不稳定。

二度Ⅰ型的“PR越来越长而RR越来越短”并不矛盾：相邻RR = PP + 本次PR − 上次PR；在PP基本固定、PR每次增量递减时，RR逐渐缩短。含受阻P的长RR小于两个基本PP，课程常见3:2或5:4下传。高度阻滞指连续两个或以上P不能下传。

把电图接回听诊：一度AVB的S1可恒定减弱；二度Ⅰ型逐渐减弱后心搏脱落；二度Ⅱ型强度基本恒定而间歇脱落；三度因房室关系变化，S1强弱不定，偶呈大炮音。房颤和室早联律也可S1强弱不等，所以心音是旁证，不独立命名节律。

课程明确：二度Ⅱ型/三度AVB有显著缓慢或Adams–Stokes发作应及早起搏；不可逆者无论有无症状均植入永久起搏器。临床指南同样将非可逆/非生理性获得性MobitzⅡ、高度或三度AVB列为不依赖症状的永久起搏适应证，不能等晕厥后才处理。急性期仍先评估并纠正可逆原因。课程在无起搏条件时列短期桥接：房室结部位阻滞可用阿托品；异丙肾上腺素可作短期接口，但急性MI禁用。短期药物不等于解决不可逆高阶阻滞。

</details>

## KP19｜窦房阻滞、束支阻滞与心腔增大

> **讲义定位 →** 内科印刷 P383–385｜PDF P462–464。  
> **主提示**：窦房阻滞2型：PP/脱落｜RBBBvsLBBB｜房大2型P｜室大2侧

<details>
<summary>展开：窦房阻滞、束支阻滞与心腔增大</summary>

### 窦房阻滞

- 二度Ⅰ型：窦房传导时间逐渐延长，PP逐渐缩短后整组P-QRS脱落；Source精确比较为长PP小于两个短PP之和；
- 二度Ⅱ型：突然整组P-QRS脱落，长PP为基本PP整倍数。

常规体表ECG不能直接记录窦房结冲动，不能凭看不见的S–P间期直接测出一度窦房阻滞；三度窦房阻滞与窦性停搏也不能仅凭无P轻易分开。这里用整组P-QRS是否脱落与PP关系观察，不把它混作只有QRS脱落的AVB。

### 束支阻滞

- 已具束支阻滞形态时，课程以QRS≥0.12s分完全性，<0.12s分不完全性；单凭<0.12s不能诊断束支阻滞；
- 右束支阻滞：右胸导联兔耳 / rsR′等 Study 图形；
- 左束支阻滞：左侧导联宽大、切迹 R 波等，具体图形必须回原图。

### 心腔增大

- 右房大：高尖肺型P；
- 左房大：增宽双峰二尖瓣型P；
- 右室大：右胸导联R增高、电轴右偏、顺钟向转位接口；
- 左室大：左胸导联R增高、电轴左偏接口。

课程精确量：右房高尖P≥0.25mV；左房P>0.12s且双峰；右室RV1+SV5≥1.05mV，伴电轴右偏、顺钟向转位（V5的R/S≤1）；左室RV5+SV1写为≥4/3.5mV，伴电轴左偏、ST可压低。当前文字未标明4与3.5对应的人群条件，须回印刷P385/PDF464原图核定，暂不生成单一完整阈值答案。

束支延迟也影响机械时序：RBBB可使P2延后，形成通常分裂；LBBB可使A2延后，形成反常分裂。图形、电压和心音各是证据，不能替代病因与结构检查。

</details>

## KP20｜第一原则：小场面不乱治，治疗病因优先

> **讲义定位 →** 内科印刷 P386–387｜PDF P465–466。  
> **主提示**：观察条件｜诱因6组｜无症状房颤的独立风险

<details>
<summary>展开：第一原则：小场面不乱治，治疗病因优先</summary>

偶发、无症状、无器质性心脏病的房早，一度或二度Ⅰ型房室阻滞等常先观察、寻找病因。需要主动寻找：

- 缺血 / MI；
- 心衰；
- 电解质异常；
- 甲亢；
- 药物 / 强心苷；
- 感染、缺氧等。

房颤即使主观无心悸，仍需独立评估栓塞风险和心室率。

</details>

## KP21｜快速型：先看有无脉搏与稳定性，再决定同步复律或非同步除颤

> **主提示**：脉搏｜稳定性｜单形/多形｜同步机制｜VF/pVT路径

<details>
<summary>展开：快速型：先看有无脉搏与稳定性，再决定同步复律或非同步除颤</summary>

课程口诀需加上节律形态和能否可靠同步这层条件：

```text
有脉且稳定
→ 按节律与底物用药

有脉且可可靠同步的快速节律，导致低血压、休克、缺血、肺水肿或意识障碍
→ 同步直流电复律

无脉性室速 / 室颤
→ 已进入心脏骤停
→ 非同步除颤 + CPR，完整路径在 B12
```

同步的意义是把放电与可识别的 R 波同步，避免电击落在心室易损期；**R 波是同步机制的解释，不是高于“有无脉搏 / 稳定性”的总分流标准。** 室扑 / 室颤等无法可靠同步的节律使用非同步电击；无脉性室速则因“无有效脉搏”直接进入可电击骤停路径。

（易混：除颤不是“更强的同步复律”；先判断患者处于有脉快速型还是无脉骤停，再讨论同步方式。）

持续多形性室速即使仍有脉，也不能套用“有脉→同步”；应立即非同步电击。无脉性室速/室颤则同时进入CPR路径。

</details>

## KP22｜抗心律失常药、起搏器与 ICD：先记角色，再把精确表格放入 MI-D

> **讲义定位 →** 内科印刷 P386–388｜PDF P465–467。  
> **主提示**：药物Ⅰ–Ⅳ：靶点/作用/代表｜胺碘酮多通道/不良反应｜起搏4模式：起搏/感知/适用｜VVI同步风险｜ICD任务

<details>
<summary>展开：抗心律失常药、起搏器与 ICD：先记角色，再把精确表格放入 MI-D</summary>

### Vaughan Williams 角色

| 类别 | 主要作用（课程表） | 本页完整药名 |
|---|---|---|
| ⅠA | 阻断快Na⁺，减慢0期Vmax，延长APD | 奎尼丁、丙吡胺、普鲁卡因胺 |
| ⅠB | 阻断快Na⁺，对0期Vmax减慢较轻，缩短APD；ERP缩短少于APD缩短 | 利多卡因、苯妥英钠、美西律 |
| ⅠC | 阻断快Na⁺，显著减慢0期Vmax/传导，课程列轻微延长APD | 普罗帕酮、氟卡尼、恩卡尼 |

胺碘酮按Study属多通道阻滞。既有M29完整六项按器官分组：肺纤维化；甲减、T4型甲状腺毒症；光过敏；角膜色素沉着；尖端扭转型室速。课程“肺—甲甲—光—角—尖”只作提取帮助，不能取代这六项或患者具体监测。

把药名接回任务而非通用处方：课程利多卡因侧重急性MI/强心苷中毒所致室早室速；普罗帕酮条目须保留“无器质性心脏病”等条件；腺苷用于稳定PSVT终止，不能把它作普通房颤长期控率药。房颤控率回KP13，预激房颤/房扑回KP06的禁用分支，收缩性心衰的负性肌力与强心苷条件回B11。

### 起搏器

| 模式 | 起搏 | 感知 | 典型适合 |
|---|---|---|---|
| VVI | 心室 | 心室 | 多类缓慢节律；慢房颤合并房室阻滞接口 |
| AAI | 心房 | 心房 | SSS且房室传导正常 |
| VDD | 心室 | 心房+心室 | 窦房结正常、严重房室阻滞 |
| DDD | 心房+心室 | 心房+心室 | SSS合并严重房室阻滞，维持房室顺序 |

第三位字母回答“感知后怎样反应”：I为抑制，D为兼有触发与抑制。VVI感知自身室性信号后抑制相应脉冲；AAI感知自身房性信号后抑制；VDD/DDD可由房性信号按设定房室间期触发室性起搏，也可因感知到自身室性信号而抑制。

VVI可破坏房室同步，引起起搏器综合征；心功能差者需谨慎。持续/永久房颤时心房起搏和追踪无有效窦性房活动的目标，不能机械选AAI或让DDD追踪房颤；具体模式与模式切换需设备评估。

### 电复律课程限制的精确回看

内科印刷P387/物理P466原表列：已用强心苷、病窦、严重房室阻滞、严重低钾、心房明显扩大伴附壁血栓而未抗凝。这里保存原题五项以便定位；“已用强心苷”需结合B11 KP21的中毒与择期复律条件，不能机械阻断KP21危急状态下的电击。房颤复律的血栓/抗凝条件回KP12–13；缓慢阻滞回KP17–19。

### ICD
