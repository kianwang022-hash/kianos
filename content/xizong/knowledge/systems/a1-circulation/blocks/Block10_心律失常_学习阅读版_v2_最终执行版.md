# Block 10｜心律失常 · 学习阅读版 v2｜最终执行版
## 先判断稳定性，再命名节律

> **中心问题**：面对异常节律，怎样先按有无脉搏和血流动力学稳定性决定是否必须立刻处理，再用快慢、QRS宽窄、规则性和房室关系定位机制、命名节律并选择药物、复律、除颤或起搏？

# 先用这一条算法进入全文

心律失常不是一堆互不相干的 ECG 图形。进入任何节律题，顺序固定为：

```text
0. 有有效脉搏吗？血流动力学稳定吗？
   无脉搏 → 直接进入 B12 骤停路径，不等完整命名
   有脉但不稳定 → 先决定电治疗 / 起搏，不等把图认完
        ↓
1. 快还是慢？
        ↓
2. QRS 窄还是宽？
        ↓
3. RR 规则还是不规则？
        ↓
4. P 波存在吗？P 与 QRS 是什么关系？
        ↓
5. 再定位起源 / 机制
   窦性、房性、房室结、旁路、室性、传导阻滞
        ↓
6. 最后决定治疗目标
   去诱因 / 控率 / 转复 / 抗凝 / 消融 / 起搏 / ICD
```

> **最重要边界**：ECG 是节律证据，不是灌注证据；有规则电活动也不保证存在有效脉搏。B3 提供正常电生理语言，本 Block 只在算法需要时调用 ECG 纸面信息。

## 整篇只保留一条主线

```text
异常冲动形成 / 异常冲动传导
→ 心率、节律、房室顺序或心室同步异常
→ 舒张充盈、有效 SV、冠脉供需和脑灌注可能受损
→ 先判有无脉搏与稳定性
→ 再用快慢—宽窄—规则—房室关系定位
→ 最后命名并处理
```

# 总 Framework

<!-- kianos:framework id="circulation-b10-framework-main" -->

```text
① 最高优先级门槛
   有无脉搏 / 稳定性
   → 决定是否必须先处理
        ↓
② 四道定位门
   快慢 → 宽窄 → 规则性 → 房室关系
   [KP01–KP02、KP23]
        ↓
③ 解释机制
   冲动形成异常 / 传导异常
   → 折返、旁路、阻滞、异位起搏
   [KP03–KP04]
        ↓
④ 按起源认识常见节律
   窦性 / 旁路与室上折返 / 房扑房颤
   → 室性节律 / 传导阻滞
   [KP05–KP19]
        ↓
⑤ 治疗统一坐标
   观察与去诱因 / 药物
   → 同步复律 / 非同步除颤 / 起搏 / ICD
   [KP20–KP22]
        ↓
⑥ 闭卷重建
   用同一算法反推未知节律
   [KP23]
```

# ① 算法需要时调用：ECG 最小读取语言

<!-- kianos:kp id="circulation-b10-kp01" -->

## KP01｜ECG 先回答“谁在除极、传了多久、心室如何复极”

> **讲义定位 →** 内科 P367–368。  
> **主提示**：心电图与 Holter 各回答什么；小格 / 大格；P、PR、QRS、ST、T、QT 的含义；正常 ECG 与病因诊断的边界。

### 1｜检查角色

- **心电图**：用于诊断心律失常、心绞痛、心肌梗死；对心律失常的病因评价作用有限。
- **动态心电图 Holter**：用于判断心悸、胸痛、晕厥等症状是否与心律失常同步出现。

### 2｜纸面标尺

```text
1小格 = 0.04 s = 0.1 mV
1大格 = 5小格 = 0.2 s = 0.5 mV
```

### 3｜六个基本对象

| 对象 | 当前 Study 含义 | 高频数字 / 边界 |
|---|---|---|
| P | 心房除极；前半右房、后半左房 | Ⅱ导联直立、aVR倒置；宽＜0.12s；肢导联高＜0.25mV |
| PR | 心房除极开始至心室除极开始，反映房室传导 | 0.12–0.20s |
| QRS | 心室除极 | q＜0.04s且＜同导联1/4R；QRS＜0.11s；≥0.12s为宽大畸形接口 |
| ST | 心室缓慢复极，与平台期相关 | 高钙血症按本节 Study 可使ST缩短 |
| T | 心室快速复极 | 必须和ST整体判断 |
| QT | 心室除极开始至复极结束，约等于APD | 与心率成反比；延长可诱发早期后除极 / 尖端扭转 |

（易混：单个心室肌动作电位不等于整张体表 ECG；QRS 是电除极，不是机械射血。）

<!-- kianos:kp id="circulation-b10-kp02" -->

## KP02｜宽 QRS 的第一意义：心室没有按“寻常路”快速同步除极

> **主提示**：什么叫寻常路；宽 QRS 的三类常见来源；P 波、QRS、RR三者各自解决什么。

正常冲动：

```text
窦房结
→ 心房
→ 房室结
→ 希氏束
→ 左右束支
→ 浦肯野
→ 心室快速同步除极
```

宽大畸形 QRS 常提示：

- 室性心律失常；
- 完全性束支传导阻滞；
- 预激 / 旁路或室内差异性传导。

因此读 ECG 时分别问：

```text
P：心房在做什么？
PR：房到室如何传？
QRS：心室从哪里、以什么路径除极？
RR：心室节律规则吗、频率如何？
```

# ② 心律失常机制

<!-- kianos:kp id="circulation-b10-kp03" -->

## KP03｜异常冲动形成：窦性异常、被动异位、主动异位

> **讲义定位 →** P369。  
> **主提示**：窦性五类；被动 / 主动异位；早搏、逸搏、心动过速的关系。

### 窦性心律失常

- 窦性心动过速；
- 窦性心动过缓；
- 窦性心律不齐；
- 窦性停搏；
- 病态窦房结综合征。

### 异位心律

```text
被动性异位
窦房结过慢或下传受阻
→ 下位起搏点被迫接管
→ 逸搏 / 逸搏心律

主动性异位
异位点自律性主动超过窦房结
→ 早搏 / 心动过速 / 扑动 / 颤动
```

按本节 Study，连续三个以上早搏可形成心动过速；连续多个逸搏形成逸搏心律。

<!-- kianos:kp id="circulation-b10-kp04" -->

## KP04｜异常传导：阻滞、折返、旁路与生理性干扰

> **主提示**：三类传导异常；折返三个必备条件；为什么折返是快速型心律失常最常见机制。

### 三类

1. 传导阻滞：窦房、房内 / 房间、房室、室内 / 束支；
2. 折返与旁路异常传导；
3. 生理性传导异常：干扰、脱节、干扰性房室分离。

### 折返三个条件

```text
折返环路
+ 单向传导阻滞
+ 缓慢传导
→ 冲动可在环内反复循环
→ 持续快速节律
```

折返既可归为异常冲动形成，也可归为异常传导。

# ③ 窦性节律与病态窦房结

<!-- kianos:kp id="circulation-b10-kp05" -->

## KP05｜窦速、窦缓、窦停与 SSS：先看 P 波是否仍为窦性，再看频率和长间歇

> **讲义定位 →** P370–371。  
> **主提示**：窦速 / 窦缓的P波与RR；窦停长间歇；SSS三类慢节律、慢—快综合征和治疗方向。

### 窦速 / 窦缓

二者仍为窦性 P 波：Ⅱ导联直立、aVR倒置。区别主要是 RR 间距缩短或延长。

### 窦性停搏

```text
窦房结暂时不发冲动
→ P波和随后QRS均缺失
→ 长PP / RR与基本PP / RR通常无固定倍数关系
```

### 病态窦房结综合征 SSS

按 Study 可见：

- 持续明显窦缓；
- 窦性停搏 / 窦房阻滞；
- 与房室阻滞并存；
- 慢节律后出现房速、房扑、房颤；
- 房性快速节律终止后再出现长停顿。

因此称为：

> **心动过缓—心动过速综合征。**

有反复黑矇、晕厥和不可逆显著缓慢节律时，治疗主体进入起搏器，而不是继续用负性频率药压慢窦房结。

# ④ 预激、AVRT 与 AVNRT

<!-- kianos:kp id="circulation-b10-kp06" -->

## KP06｜预激综合征：旁路提前激动心室

> **讲义定位 →** P372–373。  
> **主提示**：典型 ECG；顺向型为何QRS可窄；最佳检查、根治与房颤时的危险边界。

典型 ECG：

```text
PR＜0.12s
QRS起始部粗钝形成δ波
QRS可增宽
ST-T继发性改变
```

核心：房室旁路绕开房室结生理延搁，提前激动部分心室。

- 最佳辅助检查：心内电生理检查接口；
- 根治：射频导管消融旁路；
- 伴房颤 / 房扑时，房室结抑制药可能使冲动更偏向旁路，必须按 Study 的禁用表处理；血流动力学障碍时优先电复律。

<!-- kianos:kp id="circulation-b10-kp07" -->

## KP07｜AVNRT：房室结快径与慢径形成内部折返

> **主提示**：快径 / 慢径特征；房早如何触发；为什么迷走、腺苷、非二氢吡啶 CCB等能终止。

```text
快径：传导快，不应期长
慢径：传导慢，不应期短

房早到来时快径仍在不应期
→ 冲动沿慢径下传
→ 快径恢复后逆传
→ 形成折返
```

治疗的核心不是“把全心脏变慢”，而是打断房室结折返环：

- 迷走刺激；
- 腺苷（Study 中药物首选接口）；
- β受体拮抗剂；
- 维拉帕米 / 地尔硫卓；
- 胺碘酮、强心苷等按具体场景；
- 反复发作可消融。

<!-- kianos:kp id="circulation-b10-kp08" -->

## KP08｜阵发性室上性心动过速：突发突止、窄 QRS、规则快速

> **讲义定位 →** P374–376。  
> **主提示**：发生机制、ECG、心率、P波、治疗顺序和不稳定时处理。

典型：

- 突发、突止；
- RR 绝对规则；
- 心率按 Study / 诊断学口径约 150–250 次/分；
- P 波常不易辨认或呈逆行；
- QRS 多窄且形态正常，室内差异性传导或逆向型 AVRT 可增宽。

治疗：

```text
稳定
→ 迷走刺激
→ 腺苷
→ 其他抑制房室结药物
→ 反复发作考虑消融

血流动力学障碍
→ 同步电复律
```

# ⑤ 房扑与房颤

<!-- kianos:kp id="circulation-b10-kp09" -->

## KP09｜房扑：规则 F 波，心室规则性取决于房室传导比

> **讲义定位 →** P377。  
> **主提示**：F波形态、心房率、QRS和心室节律。

```text
P波消失
→ 规则锯齿样F波
→ F波间无等电位线
```

心房率常约 250–350 次/分；QRS 多正常。若房室传导比固定，心室节律可规则；传导比变化时可不规则。

<!-- kianos:kp id="circulation-b10-kp10" -->

## KP10｜房颤识别：三个不一致与两个主要后果

> **讲义定位 →** P378–380。  
> **主提示**：ECG、听诊、脉搏、S4、CO和栓塞。

### ECG

- P 波消失；
- 出现细小、不规则 f 波；
- RR 绝对不齐；
- QRS 多正常，室内差异性传导 / 预激可增宽。

### 三个不一致

```text
心律绝对不齐
S1强弱不等
脉搏短绌：脉率＜心率
```

### 两个主要后果

1. 心房有效收缩消失 → 充盈下降，CO按 Study 至少可下降约25%；无有效房缩，因此无S4；
2. 左房 / 左心耳血流淤滞 → 附壁血栓 → 体循环栓塞，常见脑栓塞。

<!-- kianos:kp id="circulation-b10-kp11" -->

## KP11｜房颤分类与“孤立性房颤”

> **主提示**：阵发、持续、持久、永久的时间 / 可转复性；常见心脏 / 心外病因；孤立性房颤处理。

按 Study 依持续时间和能否维持窦律区分阵发性、持续性、长期持续 / 持久性和永久性房颤。常见底物：

- 心脏疾病：二尖瓣狭窄等瓣膜病、心肌病、高血压性心脏改变；
- 心外疾病：甲亢；
- 无器质性心脏病、无高危因素者可称孤立性房颤，Study 真题可选择观察或消融等具体情境。

<!-- kianos:kp id="circulation-b10-kp12" -->

## KP12｜房颤抗凝：先区分瓣膜性 / 非瓣膜性，再评估栓塞风险

> **讲义定位 →** P379–380。  
> **主提示**：瓣膜性房颤、CHA₂DS₂-VASc、NOAC、左心耳封堵和转复前后抗凝。

- 合并机械瓣 / 中重度二尖瓣狭窄等瓣膜性场景，按 Study 采用长期华法林等方案；
- 非瓣膜性房颤用 CHA₂DS₂-VASc 评估栓塞风险，符合条件时优先新型口服抗凝药；
- 不能长期抗凝或抗凝仍有事件者可考虑左心耳封堵接口。

转复前后：

```text
房颤持续＞48h或时间不明
→ 先抗凝约3周或经食管超声排除房内血栓
→ 再转复
→ 转复后继续抗凝约4周
```

危急不稳定者不能因等待常规抗凝而延误电复律，但按 Study 同步进行快速抗凝接口。

<!-- kianos:kp id="circulation-b10-kp13" -->

## KP13｜房颤节律控制 vs 心室率控制

> **主提示**：转复手段、控率首选 / 次选、收缩性心衰边界、何时更适合控率。

### 节律控制

- 药物转复：普罗帕酮、胺碘酮等按器质性心脏病和禁忌选择；
- 电复律：不稳定时首选；
- 导管消融：根治 / 长期节律控制的重要手段。

### 心室率控制

- β受体拮抗剂为常用首选；
- 非二氢吡啶 CCB 有负性肌力作用，收缩性心衰禁用；
- 收缩性心衰合并快房颤可用 β受体拮抗剂、强心苷或胺碘酮等按场景；
- 老年、房颤持续时间长、左房明显扩大或难以维持窦律者更常采用控率策略。

（易混：控率不是恢复窦律；抗凝也不能因为心室率控制好而自动停用。）

# ⑥ 室性节律

<!-- kianos:kp id="circulation-b10-kp14" -->

## KP14｜室早：宽大畸形 QRS + 提前发生 + 完全代偿间歇

> **讲义定位 →** P381–382。  
> **主提示**：QRS、P波、ST-T、代偿间歇；二联律、三联律、成对、多源、间位与R-on-T。

典型：

- 提前出现宽大畸形 QRS；
- QRS 前无相关 P 波；
- ST-T 与 QRS 主波方向相反，为继发性改变；
- 常有完全性代偿间歇。

高危形态包括：频发、成对、多源 / 多形、短阵室速、R-on-T 等。偶发、无症状且无器质性心脏病者通常先观察和处理病因。

<!-- kianos:kp id="circulation-b10-kp15" -->

## KP15｜室速：宽 QRS 快速节律，寻找房室分离、心室夺获和融合波

> **讲义定位 →** P382–383。  
> **主提示**：ECG特征、特殊类型、稳定性与治疗。

典型室速：

- 连续≥3个室性搏动；
- 宽大畸形 QRS；
- 心室率常约100–250次/分；
- 房室分离；
- 可见心室夺获和室性融合波。

治疗优先看稳定性：

```text
有脉且稳定
→ 按器质性心脏病与药物禁忌选择胺碘酮等

有脉但血流动力学不稳定
→ 同步电复律

无脉性室速
→ B12：按可电击骤停节律处理，进入非同步除颤 / CPR
```

<!-- kianos:kp id="circulation-b10-kp16" -->

## KP16｜尖端扭转型室速与加速性室性自主心律

> **主提示**：尖端扭转与QT延长、电解质 / 药物、硫酸镁；AIVR与再灌注。

### 尖端扭转型室速

- 属多形性室速；
- QRS 振幅和轴围绕基线扭转；
- 常伴 QT 延长；
- 与低钾、低镁、奎尼丁 / 胺碘酮等药物或先天性长 QT 接口相关；
- Study 强调补镁治疗，先天性长QT可用β受体拮抗剂接口。

### 加速性室性自主心律

- 属较慢的室性心动过速；
- 常见于心肌梗死再灌注；
- 起止较缓，常无需专门治疗，重点在观察和处理基础病。

# ⑦ 传导阻滞

<!-- kianos:kp id="circulation-b10-kp17" -->

## KP17｜房室传导阻滞：从 PR 延长到房室完全脱节

> **讲义定位 →** P383–386。  
> **主提示**：一度、二度Ⅰ、二度Ⅱ、三度的PR / P-QRS关系；阻滞部位、QRS和治疗层级。

| 类型 | ECG核心 | 风险 / 处理 |
|---|---|---|
| 一度 | 每个P后均有QRS；PR＞0.20s且恒定 | 多观察病因 |
| 二度Ⅰ型 | PR进行性延长，直至一个QRS脱落；RR进行性缩短 | 多为房室结，通常观察 |
| 二度Ⅱ型 | PR恒定，突然P后无QRS；长RR常为基本周期整倍数 | 高风险，症状 / 高度阻滞考虑起搏 |
| 三度 | P和QRS各自规律但无固定关系，房率＞室率 | 严重缓慢型，起搏为主体 |

阻滞在房室结时逸搏 QRS可窄、心室率相对较快；阻滞在希浦系统时 QRS宽、心室率更慢且不稳定。

<!-- kianos:kp id="circulation-b10-kp18" -->

## KP18｜房室分离：三度 AVB、室速与生理性干扰用“谁更快”区分

> **主提示**：P与QRS无关；房率 / 室率关系。

```text
三度AVB：房率 > 室率
室速：室率 > 房率
生理性干扰性房室分离：房率与室率相近，各自节律受干扰
```

<!-- kianos:kp id="circulation-b10-kp19" -->

## KP19｜窦房阻滞、束支阻滞与心腔增大

> **讲义定位 →** P387–389。  
> **主提示**：二度Ⅰ / Ⅱ型窦房阻滞；RBBB / LBBB；肺型P / 二尖瓣型P和左右室肥大。

### 窦房阻滞

- 二度Ⅰ型：PP逐渐改变后整组P-QRS脱落，长PP通常小于2倍基本PP；
- 二度Ⅱ型：突然整组P-QRS脱落，长PP为基本PP整倍数。

### 束支阻滞

- 完全性束支阻滞：QRS ≥0.12s；
- 右束支阻滞：右胸导联兔耳 / rsR′等 Study 图形；
- 左束支阻滞：左侧导联宽大、切迹 R 波等，具体图形必须回原图。

### 心腔增大

- 右房大：高尖肺型P；
- 左房大：增宽双峰二尖瓣型P；
- 右室大：右胸导联R增高、电轴右偏、顺钟向转位接口；
- 左室大：左胸导联R增高、电轴左偏接口。

# ⑧ 治疗统一坐标

<!-- kianos:kp id="circulation-b10-kp20" -->

## KP20｜第一原则：小场面不乱治，治疗病因优先

> **讲义定位 →** P390–391。  
> **主提示**：哪些常观察；为什么房颤虽可无症状仍需评估栓塞；病因和诱因。

偶发、无症状、无器质性心脏病的房早，一度或二度Ⅰ型房室阻滞等常先观察、寻找病因。需要主动寻找：

- 缺血 / MI；
- 心衰；
- 电解质异常；
- 甲亢；
- 药物 / 强心苷；
- 感染、缺氧等。

房颤即使主观无心悸，仍需独立评估栓塞风险和心室率。

<!-- kianos:kp id="circulation-b10-kp21" -->

## KP21｜快速型：先看有无脉搏与稳定性，再决定同步复律或非同步除颤

> **主提示**：有脉 / 无脉；稳定 / 不稳定；同步为什么需要识别 R 波；VF / pVT为何进入可电击骤停路径。

按本节 Study 的高频口诀：

```text
有脉且稳定
→ 按节律与底物用药

有脉但低血压、休克、缺血、肺水肿或意识障碍
→ 同步直流电复律

无脉性室速 / 室颤
→ 已进入心脏骤停
→ 非同步除颤 + CPR，完整路径在 B12
```

同步的意义是把放电与可识别的 R 波同步，避免电击落在心室易损期；**R 波是同步机制的解释，不是高于“有无脉搏 / 稳定性”的总分流标准。** 室扑 / 室颤等无法可靠同步的节律使用非同步电击；无脉性室速则因“无有效脉搏”直接进入可电击骤停路径。

（易混：除颤不是“更强的同步复律”；先判断患者处于有脉快速型还是无脉骤停，再讨论同步方式。）

<!-- kianos:kp id="circulation-b10-kp22" -->

## KP22｜抗心律失常药、起搏器与 ICD：先记角色，再把精确表格放入 MI-D

> **讲义定位 →** P390–392。  
> **主提示**：Ⅰ–Ⅳ类主要通道；胺碘酮；起搏器VVI/AAI/VDD/DDD；ICD。

### Vaughan Williams 角色

| 类别 | 主要作用 | 代表接口 |
|---|---|---|
| Ⅰ | 阻断快Na⁺通道，减慢快反应组织传导 | IA奎尼丁；IB利多卡因；IC普罗帕酮 |
| Ⅱ | β受体拮抗剂，降低自律性、传导和交感效应 | 美托洛尔等 |
| Ⅲ | 阻断K⁺复极电流，延长APD / ERP | 胺碘酮、伊布利特等 |
| Ⅳ | 非二氢吡啶CCB，抑制房室结慢Ca²⁺通道 | 维拉帕米、地尔硫卓 |

胺碘酮按 Study 属多通道阻滞，常用于器质性心脏病相关快速节律；肺纤维化、甲状腺异常、光敏、角膜沉积和尖端扭转等进入 MI-D。

### 起搏器

| 模式 | 起搏 | 感知 | 典型适合 |
|---|---|---|---|
| VVI | 心室 | 心室 | 多类缓慢节律；慢房颤合并房室阻滞接口 |
| AAI | 心房 | 心房 | SSS且房室传导正常 |
| VDD | 心室 | 心房+心室 | 窦房结正常、严重房室阻滞 |
| DDD | 心房+心室 | 心房+心室 | SSS合并严重房室阻滞，维持房室顺序 |

VVI 可破坏房室同步，引起起搏器综合征；心功能差者需谨慎。

### ICD

用于预防 / 终止致命性室速、室颤所致猝死；与普通起搏器的主体任务不同。

## KP23｜ECG 四道门 + 稳定性门

> **主提示**：面对任何心律失常，按固定顺序说出判断。

```text
0. 有脉搏吗？稳定吗？
   无脉搏 → B12
   不稳定 → 先电治疗 / 起搏，不等完整命名
        ↓
1. 快还是慢？
        ↓
2. QRS 窄还是宽？
        ↓
3. RR 规则还是不规则？
        ↓
4. P波存在吗？P与QRS是什么关系？
        ↓
5. 起源 / 机制是什么？
   窦性、房性、房室结、旁路、室性、阻滞
        ↓
6. 治疗目标是什么？
   去诱因 / 控率 / 转复 / 抗凝 / 消融 / 起搏 / ICD
```

## 四个典型应用

```text
窄 + 规则 + 突发突止
→ PSVT / 折返优先

窄 + 绝对不规则 + 无P
→ 房颤优先

宽 + 规则快速 + 房室分离
→ 室速优先

慢 + P/QRS脱节 + 房率>室率
→ 三度房室传导阻滞优先
```
