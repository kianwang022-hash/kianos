# Block 6｜冠心病与心肌梗死
## 从冠脉供需、固定狭窄到斑块事件、ACS与坏死修复｜学习阅读版 v1 · Batch 3 冻结版

> **中心问题**：心肌氧供—耗氧失衡与斑块稳定性变化怎样把固定狭窄、稳定型心绞痛、UA、NSTEMI、STEMI和心肌坏死串成连续谱，并用症状、ECG、肌钙蛋白、冠脉证据和治疗目标完成分层？

# 先看一部完整冠脉电影

B6 是 B1–B5 第一次真正汇合成疾病模型：

```text
B1 冠脉舒张期供血 / 耗氧变量
+
B5 稳定斑块 / 易损斑块
+
B4 血小板 / 凝血 / 血栓
+
B3 ECG 电活动语言
+
P0 坏死 → 炎症清除 → 肉芽组织 → 瘢痕
```

汇合以后只有两条上游路径：

```text
路径1｜固定狭窄
稳定斑块 → 冠脉储备下降
→ 静息够用、活动时供不应求
→ 可预测的可逆缺血
→ 稳定型心绞痛

路径2｜斑块事件
易损斑块破裂 / 侵蚀
→ 血小板 + 凝血 + 血栓
→ 冠脉血流突然下降
→ ACS
   ├─ 尚无坏死 → UA
   ├─ 已坏死、无典型持续ST抬高谱系 → NSTEMI
   └─ 持续严重闭塞 / 损伤谱系 → STEMI
```

持续缺血后：

```text
代谢 / 舒缩异常
→ 电活动改变
→ 不可逆凝固性坏死
→ cTn等标志物释放
→ 电 / 泵 / 结构并发症
→ 中性粒细胞 / 巨噬细胞清除
→ 肉芽组织
→ 瘢痕与重构
```

治疗永远对应链上某一层：

```text
抗板 / 抗凝 → 不让血栓继续扩大
降耗氧 → 缓解供需失衡
再灌注 → 尽快恢复通路，挽救尚未坏死心肌
二级预防 → 稳定斑块、控制危险因素和重构
```

# Part A｜供需预算 + 斑块身份

## KP01｜CCS vs ACS：先问当前是“稳定供血上限”还是“急性供血骤降”

> **讲义定位 →** P330–332。  
> **主提示**：Study分类：ACS4/CCS3｜深层区别｜状态转换

当前 Study：

```text
ACS
├─ UA
├─ NSTEMI
├─ STEMI
└─ 猝死

CCS
├─ 稳定型心绞痛
├─ 隐匿型 / 无症状性冠心病
└─ 缺血性心肌病
```

深层：

```text
CCS = 病变相对稳定，缺血阈值可预测
ACS = 斑块事件 / 血栓 / 痉挛使供血突然下降
```

CCS与ACS不是两种完全分离的病；稳定患者可因斑块破裂进入ACS。

---

## KP02｜心肌氧供—耗氧预算：HR升高为何双重不利

> **讲义定位 →** P332–333；**讲义回看 →** B1。  
> **主提示**：供氧公式/变量｜耗氧3核心｜HR双重作用｜贫血反例

耗氧核心：HR、收缩性、壁张力。当前 Study 还用 `收缩压 × HR × 射血时间` 做简化入口。

供氧：

```text
冠脉血流 × 动脉血氧含量
```

受主动脉舒张压 / 冠脉灌注压、舒张期、冠脉阻力、Hb / SaO₂、局部代谢舒张影响。

```text
HR↑
├─ 单位时间收缩次数↑ → 耗氧↑
└─ 舒张期缩短 → 左冠供血时间↓
```

严重贫血即使冠脉管腔无新阻塞，`CaO₂↓` 也可造成心肌供氧不足。

## KP03｜固定狭窄与斑块事件：不是“狭窄越来越重”的一条路

> **讲义定位 →** P330–331；**讲义回看 →** B5。  
> **主提示**：稳定vs易损｜储备/急性风险

```text
稳定斑块（帽厚、核心小）
→ 固定狭窄
→ 冠脉扩张储备↓
→ 活动时缺血
→ 稳定型心绞痛

易损斑块（帽薄、核心大、炎症活跃）
→ 破裂 / 侵蚀
→ 血小板 + 凝血 + 血栓
→ ACS
```

固定狭窄程度主要决定慢性储备上限；急性事件风险还取决于斑块稳定性。

## KP04｜抗心绞痛药先按被调变量理解

> **讲义定位 →** 内科印刷P332 / PDF物理403；**讲义回看 →** B1、B2。
> **主提示**：药物4类→前负荷/后负荷/HR/收缩性｜供需2端

按课程四个变量比较，箭头表示该页教学模型，不是每种制剂、剂量和患者的固定反应：

| 药物 / 代表 | 前负荷 | 后负荷 | HR | 收缩性 |
|---|---|---|---|---|
| 硝酸酯：硝酸甘油、硝酸异山梨酯 | ↓↓，主要作用 | ↓ | 该页未给固定箭头 | 该页未给固定箭头 |
| β阻断：美托洛尔、比索洛尔 | 该页未给固定箭头 | 该页未给固定箭头 | ↓ | ↓ |
| DHP-CCB：氨氯地平、硝苯地平 | ↓（课程表） | ↓↓ | 可反射性↑ | 可反射性↑ |
| 非DHP-CCB：维拉帕米、地尔硫䓬 | 原表空白，旁文称几乎无影响 | ↓ | ↓↓ | ↓↓ |

硝酸酯三条链：扩静脉为主→回心/前负荷↓→壁张力及射血时间↓→耗氧↓；扩动脉→后负荷↓→耗氧↓；扩冠脉/解除痉挛→改善供血。DHP主要扩动脉，不能把表中的前负荷箭头读成与硝酸酯同等强度的静脉作用；HR/收缩性上升是反射效应，非直接正性肌力作用，制剂起效速度也影响该反应。

β阻断的主要链是HR/收缩性↓→耗氧↓，HR↓→舒张期延长→有利于冠脉灌注。课程另有“代谢及腺苷↓＋冠脉β2阻断→非缺血区收缩→血流重分配”的解释；它有受体选择性和局部代谢条件，不能套给所有β1选择性药物，也不等于所有患者冠脉总流量必然增加。

非DHP对心脏负性频率、传导和肌力作用更突出。原页旁文将维拉帕米/地尔硫䓬误称为二氢吡啶类，按药物实际分类纠正；原表空白保留，不补造箭头。

> B1 KP30–32负责供需回看，完整药物比较在此。

# Part B｜固定狭窄：稳定缺血

## KP05｜“稳定”和“劳力”分别意味着什么

> **讲义定位 →** P334。  
> **主提示**：稳定5维｜劳力→需求链｜固定供血上限

```text
稳定
= 数月内发作频率、程度、持续、性质、诱因无明显变化

劳力
= 活动使HR / 收缩性 / 壁张力↑
→ 需求超过固定供血上限
```

所以稳定型心绞痛主要用“固定狭窄 + 需氧增加”建立可预测模式；这不是所有患者必有显著固定狭窄的定义。课程也保留冠脉无显著狭窄时的微血管、痉挛或代谢异常等原因，需与KP10衔接。

## KP06｜典型胸痛六要素

> **讲义定位 →** P334。  
> **主提示**：胸痛6轴｜稳定模式｜程度≠分类

- 劳力 / 情绪诱发；
- 压榨、压迫、紧缩 / 发闷，可有濒死感；
- 胸骨后，可向颈、左肩、左臂内侧等放射；
- 多数持续数分钟，Study通常不超过30min；
- 休息 / 舌下硝酸甘油易缓解；
- 稳定期模式可预测。

疼痛“很重”本身不能区分稳定型、UA、MI；还要看持续 / 变化、ECG、标志物。

## KP07｜缺血发作时的电—机械短暂异常

> **讲义定位 →** P334；**讲义回看 →** B1、B3。  
> **主提示**：发作交感链｜S3/S4/S2逆分裂/暂时MR→机制｜可逆vs结构损害

缺血 / 疼痛 → 交感↑ → HR / BP↑、出汗、末梢收缩与皮肤血流减少。原题另问“外周动脉压”，讲义在血压升高旁又写其下降；末梢血流减少不等于外周动脉压必然下降，不能用血管收缩直接推出该结论，已核对PDF物理404原图，确实如此书写，属于Source表述冲突而非OCR漏字；学习时保留“交感兴奋、末梢收缩、皮肤血流减少”的机制，不把外周动脉压下降当作必然结论。

心肌舒张受损 / 顺应性↓可出现S4；泵功能受损可出现S3；左室射血延迟可使A2延迟 → S2逆分裂；乳头肌短暂缺血可出现暂时性心尖收缩期杂音。

这些是功能性缺血表现，不等于已经乳头肌断裂 / 固定瓣膜病。

## KP08｜稳定期治疗两目标：症状改善 ≠ 预后改善

> **讲义定位 →** P334–337。  
> **主提示**：目标2｜症状药组｜事件预防组｜缓痛≠降死亡

改善症状：硝酸酯、β阻断、CCB；课程四个其他药物按机制定位：伊伐布雷定抑制窦房结If电流，雷诺嗪抑制晚期Na电流以减轻Ca超载，曲美他嗪改善心肌能量代谢/氧利用，尼可地尔开放K通道并扩张冠脉微血管。

课程β阻断治疗后静息HR目标写55–60或50–60次/分，须保留该范围差异并以耐受为前提；高血压合并稳定心绞痛课程首选β阻断、次选CCB。

改善预后 / 减事件：抗血小板、降脂、危险因素控制、适应证下ACEI / ARB、必要时血运重建。

硝酸酯能明显减胸痛，但不因此自动成为长期降死亡核心药。

## KP09｜抗板、降脂、PCI / CABG各改变哪一层

> **讲义定位 →** 内科印刷P334 / PDF物理405–406；**讲义回看 →** B4、B5。
> **主提示**：抗板靶点/代表｜LDL课程目标｜联合降脂｜PCI/CABG条件

三层作用：抗板减少血小板血栓，降脂减少脂质负荷并稳定斑块，PCI/CABG改善供血通路。

1. COX-1抑制剂：阿司匹林不可逆抑制，吲哚布芬可逆抑制。阿司匹林是课程抗板基石；不耐受时课程列吲哚布芬，也列P2Y12抑制剂作为阿司匹林有禁忌时的选择。活动性消化道出血不能只凭“不耐受”三个字自动换药继续抗板，须先评估出血与缺血风险。
2. 支架后通常增加P2Y12抑制剂构成双联；课程代表替格瑞洛、氯吡格雷。氯吡格雷须代谢活化，CYP2C19慢代谢者效应可能减弱。疗程依PCI场景和出血风险，不能统一套用UA疗程。
3. 降脂首选他汀；不足时可联合胆固醇吸收抑制剂依折麦布。课程LDL-C目标：稳定冠心病/ASCVD＜1.8 mmol/L，ACS＜1.4 mmol/L；串联糖尿病未合并ASCVD时＜2.6 mmol/L。最后一项不是所有健康人通用目标，这组数是该课程版本，临床按相应风险分层与指南目标。
4. 规范药物后仍有症状可评估血运重建；PCI包括球囊扩张/支架，支架内血栓和再狭窄影响疗效。课程CABG例子是“左主干合并2支以上病变、多支病变合并糖尿病、严重扭曲伴重度钙化”，并考虑解剖复杂性、手术耐受和意愿。该组合不是现代CABG全部必要条件：显著左主干病变本身也可构成改善生存的血运重建适应证，不能要求必须再累及2支。

本段已经给出原题所需药物与目标；MI-D仅作精度复核入口，不再用一个空指针代替答案。

## KP10｜微血管性心绞痛 vs 心脏神经官能症

> **讲义定位 →** P337。  
> **主提示**：症状｜负荷/造影｜硝酸反应局限｜排除路径

**微血管性 / X综合征**：心绞痛样症状；负荷试验可阳性；冠脉造影无明显大血管狭窄；当前Study归因微循环障碍；不要求大血管痉挛。

**神经官能症**：青壮年 / 更年期女性较多，可有焦虑背景；针刺样 / 部位变动；几秒或数小时；可伴叹息、心悸、头晕、失眠；常疲劳后出现；硝酸甘油无典型快速效应。

硝酸甘油反应是辅助线索：微血管性心绞痛对短效硝酸酯的反应可变，不能用“无效”单独证明神经官能症，也不能用“有效”单独确诊缺血。

造影正常不能自动等于功能性胸痛，仍需排致命器质性疾病；课程X综合征的“无大血管痉挛”不等于现代微血管性心绞痛绝无微血管痉挛。

# Part C｜斑块事件 / ACS：有没有坏死是关键门槛

## KP11｜UA：症状阈值下降，说明病理已经从固定狭窄变成动态事件

> **讲义定位 →** P337–339；**讲义回看 →** B5、B4。  
> **主提示**：斑块急变｜分型4种｜CCS 4级｜坏死边界

```text
易损斑块破裂 / 侵蚀
→ 胶原 / TF暴露
→ 血小板 + 凝血
→ 动态 / 非完全血栓
+ 微血管栓塞 / 痉挛
→ 冠脉血流突然下降
→ UA
```

课程四型：初发、静息、恶化、变异（变异的痉挛模型见KP12）。初发指首发症状1–2个月内，轻微活动即可诱发；静息型在休息时发作；恶化型须有原来相对稳定的劳力性心绞痛基础，随后频率、强度、持续时间或缓解难度恶化。

这里CCS分级指加拿大心血管病学会的心绞痛活动分级，别与慢性冠脉综合征缩写混淆：Ⅰ一般活动不受限；Ⅱ轻度受限，课程用步行>200m或登楼>1层诱发；Ⅲ明显受限，约200m以内或登楼1层诱发；Ⅳ轻微活动甚至休息即可发作。课程初发型程度至少Ⅲ级，恶化型较既往增加≥1级。

UA缺乏急性心肌坏死的证据。不能仅凭一次肌钙蛋白升高就转判NSTEMI：要结合动态变化、急性缺血证据及ECG；心肌炎等也可升高，发病早期单次阴性也不能排除梗死。

## KP12｜变异型心绞痛：核心是自发严重痉挛

> **讲义定位 →** P338–339。  
> **主提示**：痉挛链｜诱因/时机｜ECG动态≠坏死｜药物选择/β阻断边界

## KP13｜UA为什么需要更强抗栓和风险分层

> **讲义定位 →** P338–339。  
> **主提示**：治疗5层→目标｜危险征象→侵入优先级

```text
DAPT → 抑血小板栓扩大
抗凝 → 抑凝血酶 / 纤维蛋白放大
β阻断 / 硝酸酯 / CCB → 再平衡供需
高强度降脂 → 稳定斑块 / 长期预防
```

极高危线索决定紧急侵入优先级：血流动力学不稳定/休克、急性心衰、致命心律失常或心搏骤停、心梗机械并发症、反复间歇性ST抬高、药物治疗无效的反复胸痛。课程极高危者<2h行紧急PCI评估路径；危险分层是判断紧迫性，不能等到标志物“确认”后才识别循环不稳。原题要求的药物与条件如下：

- 双联抗板：阿司匹林＋P2Y12抑制剂（课程举替格瑞洛、氯吡格雷）；课程写“＞1年”。2025 ACC/AHA默认至少12个月的前提是无高出血风险；高出血风险、口服抗凝等情境需调整，不能一律超过一年。NSTE-ACS计划早期侵入且冠脉解剖未知时，也不能把双联目标直接等同术前一律先负荷P2Y12。
- GPⅡb/Ⅲa拮抗剂：课程列PCI术中追加替罗非班/阿昔单抗。临床需保留选择性补救条件，如无复流或血栓并发症，不能变成所有PCI固定加第三种抗板药。
- 抗凝：课程肝素为基础，高出血风险者举磺达肝癸钠，PCI术中举比伐卢定。磺达肝癸钠是抗凝血酶依赖的间接Xa抑制剂；比伐卢定直接抑制凝血酶。这不是三药层层叠加处方：选择取决于侵入时机、肾功能和出血风险。2023 ESC对未预计24 h内早期造影的NSTE-ACS可选磺达肝癸钠，之后做PCI须补普通肝素；不能以单用磺达肝癸钠承担PCI抗凝。
- β阻断：无禁忌时早期使用，课程少数高危者举静脉艾司洛尔；急性心衰、低输出、休克风险或严重缓慢传导障碍时不能照此套用。ACEI/ARB亦须有适应证及血压、肾功能、血钾允许，不能把课程“尽早ACEI/ARB/ARNI”理解成所有ACS立即三选一。
- 课程ACS的LDL-C目标＜1.4 mmol/L；稳定期课程目标与降脂药物见KP09。

## KP14｜UA vs NSTEMI：最关键边界是坏死标志物

> **讲义定位 →** P339；**讲义回看 →** P0。  
> **主提示**：UA vs NSTEMI｜ECG｜标志物动态｜缺血证据

```text
UA：缺血，但无可检测坏死 → 标志物不升高
NSTEMI：缺血已不可逆 → 坏死 → 标志物升高
```

原题把住院死亡率放在UA/NSTEMI对比中，但讲义印刷P336实际给出的死亡率比较是NSTEMI与STEMI，见KP15；不把该比较对象偷换成UA。

两者都可有ST压低 / T波改变。判别需将标志物的动态变化与急性缺血证据合看：升高提示心肌损伤，不能单独等同缺血性梗死；早期一次阴性不能直接定为UA。

## KP15｜NSTEMI vs STEMI：不是“小梗死”和“大梗死”

> **讲义定位 →** P339–340。  
> **主提示**：NSTEMIvsSTEMI：闭塞/损伤层次/ECG/标志物/再灌注｜血栓相对性

```text
NSTEMI
→ 多为不完全 / 动态阻塞
→ 心内膜下坏死为主
→ ST压低 / T倒置等
→ cTn↑
→ 不按STEMI路径溶栓

STEMI
→ 多为持续严重 / 完全闭塞
→ 透壁 / 全层损伤谱系
→ 典型持续ST抬高，可出现病理Q
→ cTn↑
→ 适应证内尽快再灌注
```

NSTEMI不能仅因“也有血栓”就沿用STEMI的全身溶栓路径：在该人群未证实同样获益，反而增加出血风险，应采用抗栓和风险分层下的侵入评估。课程白色血栓模型有助理解，但不是“所有NSTEMI完全没有纤维蛋白”的理由。

当前 Study还用血栓成分解释：NSTEMI偏血小板性白色成分；STEMI可有更多纤维蛋白 / RBC。它是相对组织方式，不是绝对二分。

课程印刷P336还比较：NSTEMI群体多支病变率较高、侧支较多；住院死亡率较STEMI低，但长期心血管事件率接近。这是课程群体比较，不用于断言单个NSTEMI较轻，也不能由ECG类型直接确定冠脉是否完全闭塞。

# Part D｜STEMI：症状 → 坏死 → 证据 → 修复

## KP16｜STEMI胸痛与非典型表现

> **讲义定位 →** P340。  
> **主提示**：胸痛5轴｜下后壁胃肠入口｜老年/DM非典型

## KP17｜坏死吸收反应 + 低血压的三条路径

> **讲义定位 →** P340。  
> **主提示**：吸收反应3项/时点｜低压3路径｜感染鉴别接口

疼痛后1–2d可有低热、中性粒↑、ESR↑，反映坏死组织被清除，不等于感染。

```text
大面积坏死 → CO↓ → 泵性低灌注
迷走 / 外周扩张 → SVR↓
出汗 / 容量不足 → CVP / PAWP可低
```

课程印刷P337把三条路径对应为：泵衰→IABP；周围扩张→去甲肾上腺素/多巴胺；容量不足→补液。必须保留治疗条件：泵衰首先紧急再灌注并按灌注/淤血支持，2023 ESC不推荐无机械并发症的心梗休克常规IABP，机械并发症可另行讨论短期支持；血管活性药和容量治疗须据血流动力学选择，不能所有低压都大量补液。低充盈压/明确容量不足可谨慎补液并复评，伴肺水肿或高充盈压时尤其避免盲目扩容，完整分流见B12。

所以“低血压”不能直接决定同一处理；先定位泵 / 阻力 / 容量。血压没有下降甚至升高也不能排除MI，基础高血压、交感反应及梗死范围都会影响表现。

## KP19｜心肌梗死病理时程：坏死 → 清除 → 肉芽 → 瘢痕

> **讲义定位 →** 病理P46；**Outline →** U003 AS Q11。  
> **主提示**：梗死类型/细胞改变｜修复4时点｜肉芽→瘢痕｜修复≠收缩恢复

新鲜梗死：苍白、贫血性梗死、凝固性坏死；核固缩 / 碎裂 / 溶解；胞质均质红染 / 收缩带；间质水肿 + 中性粒。

```text
约4d → 外围充血 / 出血带
1–2w → 坏死溶解，边缘肉芽组织长入
约3w → 肉芽机化，瘢痕形成
6–8w → 瘢痕愈合，陈旧MI
```

心肌不能有效再生，所以修复主要靠瘢痕；瘢痕不等于收缩功能恢复。

## KP20｜坏死标志物：谁最早、谁最特异、谁回落快

> **讲义定位 →** P344。  
> **主提示**：标志物3种｜升高/回落｜再梗死/再通｜损伤≠梗死

```text
肌红蛋白 → 最早升、最早回，敏感但特异低
cTn → 提示心肌损伤，诊断MI需再结合动态与缺血证据，持续较长
CK-MB → 较早升、较快回，可帮助再梗死 / 再通判断
```

课程传统检测时间比较：肌红蛋白2h内升高、1–2d恢复；cTn约3–4h后升高、持续1–2w；CK-MB约4h内升高、3–4d恢复，峰值提前至<14h是间接再通线索。检测方法与再灌注影响时间，高敏cTn不能机械套用旧检测的最早升高时点。

CK-MB因回落较快可辅助识别短期再梗死，但不能据此说持续升高期cTn完全无用；仍应看再次动态变化与缺血证据。

## KP23｜检查层级：每项检查证明不同东西

> **讲义定位 →** P343–345。  
> **主提示**：检查8项→证据层｜缺血/坏死/解剖/灌注/活力/机械｜负荷禁用情境

## KP25｜乳头肌功能不全 / 断裂：新发MR的两个层级

> **讲义定位 →** P340；**讲义回看 →** B7。  
> **主提示**：乳头肌功能不全vs断裂｜血供/部位｜急性MR→肺水肿/低输出

功能不全：乳头肌缺血 → 收缩协调↓ → MR / 心尖收缩期杂音，可随抗缺血改善。

断裂：Study强调后乳头肌血供相对单一 + 下壁MI → 急性重度MR → LA来不及扩张 → LA压骤升 → 急性肺水肿 / 低输出。

## KP26｜游离壁破裂 vs 室间隔破裂：血流去向决定后果

> **讲义定位 →** P341。  
> **主提示**：两处破裂的血流去向｜各自循环后果｜识别线索与危险

```text
游离壁破裂
→ 血入心包
→ 心包积血 / 压塞
→ 回心 / 充盈骤降
→ PEA / 猝死接口

课程多在起病1周内；压塞可出现Beck三联征：动脉压低、静脉压高、心音低弱。破裂是结构性急症，必须紧急外科评估；课程的心包引流接口不能解释为修复了心肌破口。

```

## KP27｜室壁瘤 vs Dressler：结构重构 vs 免疫炎症

> **讲义定位 →** P341。  
> **主提示**：室壁瘤：形成/超声/ECG｜Dressler：时程/机制｜早期心包炎对照

室壁瘤：瘢痕变薄、失去收缩 + 心腔压力 → 局部膨出 / 反常运动；可见ST持续抬高；超声见局部突出 / 矛盾运动。首选超声心动图评估；与扩张型心肌病相对照，前者以节段性异常/局部瘤样膨出为线索，后者以心腔扩张和弥漫性室壁运动减弱为典型模型。持续ST抬高支持室壁瘤线索，但不能单独确诊；扩心病也可有非特异性ST-T或病理Q波，不能以“有Q波”硬分。

Dressler：坏死抗原暴露 → 延迟免疫反应 → 数周至数月后心包炎 / 胸膜炎等。

心梗后2–3d早期心包摩擦音 ≠ Dressler。

## KP28｜Killip vs Forrester：临床严重度 vs 湿 / 冷双坐标

> **讲义定位 →** P341。  
> **主提示**：Killip 4级｜Forrester 2轴/4型｜阈值

Killip：I无明显HF；II左心衰，课程肺部啰音<50%肺野；III急性肺水肿，课程啰音>50%；IV心源性休克。原表未单列恰好50%的边界，不自行补造。

Forrester：PAWP看“湿”，CI看“冷”：

```text
I   干暖：PAWP＜18，CI＞2.2
II  湿暖：PAWP≥18，CI＞2.2
III 干冷：PAWP＜18，CI≤2.2
IV  湿冷：PAWP≥18，CI≤2.2
```

以上按本课程分界，PAWP单位mmHg，CI单位L/(min·m²)。Killip IV的本课量化线索为SBP＜90 mmHg、PAWP≥18 mmHg、CI≤2.2 L/(min·m²)；这组典型左心泵衰指标不能用来排除所有低充盈压或右心来源的休克。

同样低压可来自高充盈压泵衰或低充盈压容量不足，不能只看BP。

# Part F｜再灌注 + 抗栓 + 长期保护

## KP29｜再灌注：有无PCI条件，目标都是尽快救回尚可逆心肌

> **讲义定位 →** P341–343。  
> **主提示**：时间2轴｜PCI/溶栓条件｜可逆vs坏死

```text
持续闭塞
→ 可逆缺血逐渐变不可逆坏死
→ 时间越久，可挽救心肌越少
```

把两只时钟分开：

| 时间轴 | 条件与含义 |
|---|---|
| 症状开始→再灌注 | 越早越好；课程强调3–6 h及12 h内，不能理解成要等到3 h才处理 |
| 医疗系统内预计延迟 | 课程：有及时PCI条件首选直接PCI；无条件或预计直接PCI>2 h，且起病12 h内、符合适应证及无禁忌时考虑溶栓 |

120 min必须带起止点：2023 ESC按STEMI诊断→导丝通过梗死相关动脉；2025 AHA/ACC按首次医疗接触→器械启动（直接就诊目标≤90 min、转运≤120 min）。两种定义不混算。超过12 h也不能一律放弃再血管化，持续缺血、休克或恶性心律失常等需走紧急评估路径。

再通能救边缘尚可逆心肌，不等于已坏死心肌立即恢复收缩。

## KP30｜抗板、抗凝、溶栓、PCI、降耗氧分别作用哪一环

> **讲义定位 →** P341–343、P349–350；**讲义回看 →** B4。  
> **主提示**：干预6层→靶点/目标｜抗凝vs溶栓｜急性vs长期

```text
抗板 → 血小板栓
抗凝 → 凝血酶 / 纤维蛋白继续放大
溶栓 → 已形成纤维蛋白血栓
PCI → 机械恢复通路
β阻断 / 硝酸酯 / 镇痛 → 降耗氧 / 缓解缺血与交感
降脂 / ACEI / ARB等 → 斑块 / 重构长期风险
```

抗凝不能直接溶已有血栓；溶栓不是抗板。

原题“再灌注前用药”在课程印刷P338列β阻断、吗啡或哌替啶、硝酸酯；β阻断用来降低心率/耗氧并减少恶性节律风险。它们不能拖延再灌注，也不是人人固定联合：β阻断有急性心衰/休克、严重缓慢节律等限制，低压或右室梗死时硝酸酯可能进一步降低回心，镇痛药还须考虑呼吸、血压及与抗板药吸收的影响。抗板/抗凝依具体PCI或溶栓策略同步安排，KP13给出课程药物与适用条件。

## KP31｜溶栓禁忌 + 再通证据

> **讲义定位 →** P342。  
> **主提示**：溶栓禁忌5风险组｜夹层排除｜间接再通4类｜直接证据

禁忌按风险来源记：严重颅内病变/卒中、活动性出血、近期重大创伤/手术及不能压迫部位的大血管穿刺、未控制严重高压（课程＞180/110 mmHg）、未排除主动脉夹层。此处是课程风险分组，不是绝对/相对禁忌的完整临床清单；卒中类型和时间、复苏是否创伤性/延长等不能省略，不能把所有既往卒中或任何短暂成功CPR都判成终身绝对禁忌。

原题串联“高危肺栓塞是否考虑禁忌”：必须评估。原讲义“高危肺栓塞不考虑溶栓禁忌症”已在A2 R9 KP21显式纠正，濒死风险可改变权衡，但不能忽略活动性出血及导管/外科替代方案。

课程印刷P339 / PDF物理411的四类间接证据：CK-MB峰值提前至起病＜14 h；胸痛在溶栓后2 h内基本消失；2 h内出现再灌注性心律失常，如加速性室性自主心律；原抬高ST段在2 h内回降＞50%。CK-MB的14 h按梗死起病时间理解，不能与溶栓后2 h混算。

这些是间接线索，不能由胸痛缓解或出现一次室性节律单独确认通畅；冠脉造影提供直接证据。临床持续缺血、血流动力学或电不稳定需立即评估补救性PCI，不能为了凑齐课程2 h指标而等待。

## KP33｜主动脉夹层：错误进入溶栓路径可以致命

> **讲义定位 →** P342、P349。  
> **主提示**：MI vs UA｜夹层线索｜溶栓前鉴别

MI vs UA：结合标志物动态、ECG、缺血表现与发病时间；不能用“单次阳性＝MI、单次阴性＝UA”分流。课程印刷P339六轴：MI有坏死标志物升高及特征/动态ECG，疼痛可持续数小时甚至更久、往往不是短暂频繁发作，血压可下降，并可有低热/白细胞增多等坏死物吸收反应；UA更常反复发作且无坏死证据。时长、频率和血压均不是绝对排除条件，疼痛超过30 min应警惕MI但不能仅按时长确诊。

夹层警报：突发撕裂样胸痛向背；双上肢BP / 脉搏不对称；新发AR杂音；主动脉壁影像；冠口受累也可ST抬高。

> ST抬高不能跳过致命鉴别；夹层误溶栓可灾难性出血。
