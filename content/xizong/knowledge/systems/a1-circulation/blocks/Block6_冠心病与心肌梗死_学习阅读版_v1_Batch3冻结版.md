# Block 6｜冠心病与心肌梗死
## 从冠脉供需、固定狭窄到斑块事件、ACS与坏死修复｜学习阅读版 v1 · Batch 3 冻结版

> **中心问题**：心肌氧供—耗氧失衡与斑块稳定性变化怎样把固定狭窄、稳定型心绞痛、UA、NSTEMI、STEMI和心肌坏死串成连续谱，并用症状、ECG、肌钙蛋白、冠脉证据和治疗目标完成分层？

# 先看冠脉供需与心肌命运

B1 的冠脉供需、B5 的斑块、B4 的血栓、B3 的电信号和 P0 的坏死修复在这里汇合。**固定狭窄、急性斑块事件与痉挛是不同入口；是否已经坏死、ECG 属于哪一谱系和循环是否稳定，需要分别判断。**

# 总 Framework

```text
供氧 = 冠脉血流 × 动脉血氧含量
耗氧随HR / 收缩性 / 壁张力增加；HR快还缩短舒张供血时间

固定狭窄 → 储备不足 + 需求增加 ─┐
斑块事件 → 血小板 / 凝血 / 血栓 → 血流骤降 ─┤
冠脉痉挛 / 微血管障碍，或血氧含量下降 ──────┤
                                           ↓
                                      心肌供需失衡
                                           ↓
                                         缺血
    ├─ 可逆：短暂舒缩 / 电异常、可有症状；解除失衡可恢复
    └─ 持续严重：不可逆坏死
         ├─ 释放标志物（观察损伤，须结合动态与缺血证据）
         ├─ 电、泵、结构、血栓等并发症；有些可在缺血阶段出现
         └─ 炎症清除 → 肉芽 → 瘢痕 / 重构（不等于收缩恢复）

观察分流：症状 + 动态ECG + 标志物 + 冠脉 / 心肌证据
→ 稳定缺血 / UA / NSTEMI / STEMI，彼此不串作必经病程。
治疗回路：降需求 / 解痉回到供需；抗栓回到血栓形成；
          再灌注恢复通路、救尚可逆心肌；同时保护有效循环。
危险征象决定紧迫性，不等所有检查和并发症齐全后才处理。
```

# 同一模型上的自然节点〔完整 Prompt〕

先沿供需失衡看心肌命运，再在相应位置读症状、证据和故障后果；治疗始终回作用于原变量。疾病分类、检查顺序与药物清单不充当医学因果主线。

```text
心肌的氧收支
冠脉血流 × 动脉血氧含量 → 供氧
HR / 收缩性 / 壁张力 → 耗氧
HR↑同时增加耗氧、缩短舒张供血时间；贫血可从血氧含量端降低供氧
〈心肌氧供—耗氧预算：HR升高为何双重不利〔供氧公式/变量｜耗氧3核心｜HR双重作用｜贫血反例〕〉

供血上限与供血骤降，是不同的上游故障
〈固定狭窄与斑块事件：不是“狭窄越来越重”的一条路〔稳定vs易损｜储备/急性风险〕〉
├─ 固定狭窄 → 冠脉扩张储备↓
│    活动使需求增加 → 超过供血上限 → 可预测的可逆缺血
│    〈“稳定”和“劳力”分别意味着什么〔稳定5维｜劳力→需求链｜固定供血上限〕〉
│    ├─ 症状窗口：诱因、部位 / 放射、性质、时间、缓解及稳定模式
│    │    〈典型胸痛六要素〔胸痛6轴｜稳定模式｜程度≠分类〕〉
│    └─ 短暂舒缩 / 电异常、交感反应 → 心音改变或暂时性MR
│         〈缺血发作时的电—机械短暂异常〔发作交感链｜S3/S4/S2逆分裂/暂时MR→机制｜可逆vs结构损害〕〉
│    解除供需失衡可改善功能；不能把暂时MR当作乳头肌已断裂。
│
├─ 易损斑块破裂 / 侵蚀 → 血小板 + 凝血 + 血栓
│    → 血流突然下降 → 急性缺血，症状阈值可能下降
│    〈UA：缺血模式不稳定，先找动态供血事件并判断坏死边界〔斑块急变｜分型4种｜CCS 4级｜坏死边界〕〉
│    是否坏死仍要结合动态证据；不要求先经历稳定型心绞痛。
│
└─ 冠脉自发严重痉挛 → 静息 / 夜间血流暂降 → ST可暂抬高
     → 痉挛解除可恢复；电改变不自动证明坏死
     〈变异型心绞痛：核心是自发严重痉挛〔痉挛链｜诱因/时机｜ECG动态≠坏死｜药物选择/β阻断边界〕〉
大冠脉无显著狭窄仍可有微血管性缺血；胸痛还需与其他来源区分。
正常造影或硝酸酯单次反应，均不能独立完成鉴别。
〈微血管性心绞痛 vs 心脏神经官能症〔症状｜负荷/造影｜硝酸反应局限｜排除路径〕〉

供需干预直接回到上方变量
降前负荷 / 后负荷 / HR / 收缩性可降低需求；解痉可改善供血
〈抗心绞痛药先按被调变量理解〔药物4类→前负荷/后负荷/HR/收缩性｜供需2端〕〉
症状控制，与降低长期事件风险是两个治疗目标
〈稳定期治疗两目标：症状改善 ≠ 预后改善〔目标2｜症状药组｜事件预防组｜缓痛≠降死亡〕〉
抗板减少血小板血栓，降脂降低脂质风险，PCI / CABG改善供血通路
〈抗板、降脂、PCI / CABG各改变哪一层〔抗板靶点/代表｜LDL课程目标｜联合降脂｜PCI/CABG条件〕〉
药物亚类、血压 / 灌注与出血风险、解剖和适应证共同约束选择。

缺血的时间与强度，决定可逆还是坏死
短暂失衡解除 → 可恢复；持续严重缺血 → 不可逆心肌坏死
    ├─ 标志物释放 → 可观测心肌损伤
    │    〈坏死标志物：谁最早、谁最特异、谁回落快〔标志物3种｜升高/回落｜再梗死/再通｜损伤≠梗死〕〉
    └─ 炎症清除 → 肉芽组织 → 瘢痕 / 重构
         〈心肌梗死病理时程：坏死 → 清除 → 肉芽 → 瘢痕〔梗死类型/细胞改变｜修复4时点｜肉芽→瘢痕｜修复≠收缩恢复〕〉
标志物是证据，既不制造坏死，也不引发后续并发症；瘢痕不恢复收缩肌。

从症状与动态证据区分冠脉状态
相对稳定的缺血状态与急性供血事件可转换，分类保留课程范围
〈CCS vs ACS：先问当前是“稳定供血上限”还是“急性供血骤降”〔Study分类：ACS4/CCS3｜深层区别｜状态转换〕〉
急性缺血无坏死证据 → UA；符合缺血性梗死的损伤但无典型持续ST抬高 → NSTEMI
〈UA vs NSTEMI：最关键边界是坏死标志物〔UA vs NSTEMI｜ECG｜标志物动态｜缺血证据〕〉
典型持续ST抬高谱系 → 紧急再灌注评估；NSTEMI按风险走侵入评估
〈NSTEMI vs STEMI：不是“小梗死”和“大梗死”〔NSTEMIvsSTEMI：闭塞/损伤层次/ECG/标志物/再灌注｜血栓相对性〕〉
两种MI不是“小 / 大”分级；单次cTn阴性不排早期MI，阳性也不独立证明MI。
症状可持续胸痛，也可下后壁胃肠表现，老年 / 糖尿病可不典型
〈STEMI胸痛与非典型表现〔胸痛5轴｜下后壁胃肠入口｜老年/DM非典型〕〉
缺血 / 损伤 / 坏死 ← 动态T / ST / Q电表现；电投影不能代替组织切片
〈ECG三层：缺血、损伤、坏死〔T/ST/Q→3层｜STEMI动态4期｜电投影≠组织切片〕〉
受累心肌空间 ← 导联—心壁—冠脉定位；保留冠脉优势型和个体差异
〈导联—心壁—冠脉：用空间投影定位〔导联5组/广泛前壁｜LAD/LCX/RCA供区｜节律接口〕〉
冠脉解剖、灌注、活力、室壁运动 / 机械结构各由相应检查验证
〈检查层级：每项检查证明不同东西〔检查8项→证据层｜缺血/坏死/解剖/灌注/活力/机械｜负荷禁用情境〕〉
急性不稳定情境不通过运动负荷来“证明”缺血。

缺血 / 坏死损及什么部件，就沿什么故障分支追后果
〈并发症总地图〔并发症6层→代表｜从损伤部件定位〕〉
├─ 电：心室肌或传导供区受累 → VT / VF或缓慢传导等风险
│    〈梗死部位与节律接口：前壁偏室性，下壁偏缓慢传导〔LAD/RCA｜前壁vs下壁：供区/节律｜前壁AVB意义〕〉
│    有无脉搏 / 循环是否稳定 → 电治疗或相应节律接口
│    〈AMI节律并发症：先看有效循环，再调用B10 / B12〔脉搏/稳定性→快慢｜室性恶性节律｜偶发vs频发｜高阶AVB接口〕〉
│    完整节律归B10，骤停归B12；不在此裁决未定的药物先后。
│
├─ 泵：LV收缩骤降
│    ├─ LVEDP / LA / 肺静脉压↑ → 肺水肿
│    └─ SV↓ → 低灌注
│    〈AMI急性左心衰：肺水肿和低灌注要分开读取〔淤血vs低灌注｜血压/充盈｜利尿-扩管-循环支持｜KillipvsForrester〕〉
│    RV失效则RV前送↓ → 肺循环流量↓ → LV前负荷↓ → CO / BP↓
│    〈急性右室梗死：右室失效后，左心首先缺“前负荷”〔伴发部位｜CVP/PAWP/肺部｜RV→LV前负荷链｜容量/硝酸酯/利尿条件〕〉
│    右心可静脉压高而肺相对清；补充容量须看实际充盈与反应。
│    泵后果的观察：临床严重度，与充盈压 / CI两轴分别评估
│    〈Killip vs Forrester：临床严重度 vs 湿 / 冷双坐标〔Killip 4级｜Forrester 2轴/4型｜阈值〕〉
│
├─ 结构：乳头肌缺血可暂时失能；真正断裂造成急性重度MR
│    → LA压骤升 + 有效前向量↓ → 肺水肿 / 低输出
│    〈乳头肌功能不全 / 断裂：新发MR的两个层级〔乳头肌功能不全vs断裂｜血供/部位｜急性MR→肺水肿/低输出〕〉
│    游离壁破裂 → 血入心包 → 压塞 / 充盈受限 → PEA风险
│    室间隔破裂 → LV血入RV → 左向右分流 → 肺负荷 + 低输出
│    〈游离壁破裂 vs 室间隔破裂：血流去向决定后果〔两处破裂的血流去向｜各自循环后果｜识别线索与危险〕〉
│
├─ 血栓：附壁血栓脱落 → 栓塞
│
└─ 修复 / 炎症：瘢痕局部膨出 → 室壁瘤；延迟免疫反应 → Dressler
     〈室壁瘤 vs Dressler：结构重构 vs 免疫炎症〔室壁瘤：形成/超声/ECG｜Dressler：时程/机制｜早期心包炎对照〕〉
     有效收缩心肌减少 + 重构 → 泵血 / 充盈异常 → 心衰接口
     〈B6 → B11 Preview：MI怎样走向心衰，但不提前重学〔MI→重构→心衰｜LVEF分型｜A–D接口｜绝对vs相对灌注｜长期目标〕〉
     完整EF分型、分期与慢性心衰治疗由B11负责。

同一床旁表现，要反查不同原因
坏死清除可引起低热 / 炎症指标升高；不自动等于感染。
低血压可分别来自CO↓、外周阻力↓或容量不足；不由一个BP数值选同一处理。
〈坏死吸收反应 + 低血压的三条路径〔吸收反应3项/时点｜低压3路径｜感染鉴别接口〕〉
胸痛 / ST抬高还须考虑夹层等致命反例；冠口受累也可出现缺血电表现
〈主动脉夹层：错误进入溶栓路径可以致命〔MI vs UA｜夹层线索｜溶栓前鉴别〕〉

急性处置回路：在识别危险时同步启动，回作用于病因和有效循环
血流动力学不稳、严重心衰、恶性节律、机械危险或持续缺血
→ 决定侵入评估紧迫性；抗板 / 抗凝 / 供需干预分别抑制相应环节
〈UA为什么需要更强抗栓和风险分层〔治疗5层→目标｜危险征象→侵入优先级〕〉
再灌注恢复冠脉通路 → 缩短缺血 → 挽救尚可逆心肌
〈再灌注：有无PCI条件，目标都是尽快救回尚可逆心肌〔时间2轴｜PCI/溶栓条件｜可逆vs坏死〕〉
抗板、抗凝、溶栓、PCI、降耗氧和长期保护分别对应原链的不同靶点
〈抗板、抗凝、溶栓、PCI、降耗氧分别作用哪一环〔干预6层→靶点/目标｜抗凝vs溶栓｜急性vs长期〕〉
溶栓前评估适应证 / 出血风险 / 夹层；之后复查缺血和再通证据
〈溶栓禁忌 + 再通证据〔溶栓禁忌5风险组｜夹层排除｜间接再通4类｜直接证据〕〉
不把间接再通线索当造影证实，不等标志物或并发症凑齐才救治。

病例反推沿同一模型闭合
先看稳定性；症状、ECG、动态标志物与致命反例合看
→ 分类与通路决策，同时识别电 / 泵 / 结构故障
→ 干预后回查有效循环和残余缺血，长期再降低事件 / 重构风险
〈最终病例算法：从胸痛到处理优先级〔稳定性｜缺血模式｜ECG｜标志物｜反例｜再灌注｜并发症〕〉
```

# Part A｜供需预算 + 斑块身份

## KP01｜CCS vs ACS：先问当前是“稳定供血上限”还是“急性供血骤降”

> **讲义定位 →** 内科印刷P329 / PDF P400。  
> **主提示**：Study分类：ACS4/CCS3｜深层区别｜状态转换

当前 Study：

```text
ACS
├─ UA
├─ NSTEMI
├─ STEMI
└─ 猝死

CCS
├─ 稳定型心绞痛
├─ 隐匿型 / 无症状性冠心病
└─ 缺血性心肌病
```

深层：

```text
CCS = 病变相对稳定，缺血阈值可预测
ACS = 斑块事件 / 血栓 / 痉挛使供血突然下降
```

CCS与ACS不是两种完全分离的病；稳定患者可因斑块破裂进入ACS。

## KP02｜心肌氧供—耗氧预算：HR升高为何双重不利

> **讲义定位 →** 内科印刷P331–332 / PDF P402–403；**讲义回看 →** B1。  
> **主提示**：供氧公式/变量｜耗氧3核心｜HR双重作用｜贫血反例

耗氧核心：HR、收缩性、壁张力。当前 Study 还用 `收缩压 × HR × 射血时间` 做简化入口。

供氧：

```text
冠脉血流 × 动脉血氧含量
```

受主动脉舒张压 / 冠脉灌注压、舒张期、冠脉阻力、Hb / SaO₂、局部代谢舒张影响。

```text
HR↑
├─ 单位时间收缩次数↑ → 耗氧↑
└─ 舒张期缩短 → 左冠供血时间↓
```

严重贫血即使冠脉管腔无新阻塞，`CaO₂↓` 也可造成心肌供氧不足。

## KP03｜固定狭窄与斑块事件：不是“狭窄越来越重”的一条路

> **讲义定位 →** 内科印刷P330 / PDF P401；**讲义回看 →** B5。  
> **主提示**：稳定vs易损｜储备/急性风险

```text
稳定斑块（帽厚、核心小）
→ 固定狭窄
→ 冠脉扩张储备↓
→ 活动时缺血
→ 稳定型心绞痛

易损斑块（帽薄、核心大、炎症活跃）
→ 破裂 / 侵蚀
→ 血小板 + 凝血 + 血栓
→ ACS
```

固定狭窄程度主要决定慢性储备上限；急性事件风险还取决于斑块稳定性。

## KP04｜抗心绞痛药先按被调变量理解

> **主提示**：药物4类→前负荷/后负荷/HR/收缩性｜供需2端

# Part B｜固定狭窄：稳定缺血

## KP05｜“稳定”和“劳力”分别意味着什么

> **讲义定位 →** 内科印刷P333 / PDF P404。  
> **主提示**：稳定5维｜劳力→需求链｜固定供血上限

```text
稳定
= 数月内发作频率、程度、持续、性质、诱因无明显变化

劳力
= 活动使HR / 收缩性 / 壁张力↑
→ 需求超过固定供血上限
```

所以稳定型心绞痛主要用“固定狭窄 + 需氧增加”建立可预测模式；这不是所有患者必有显著固定狭窄的定义。课程也保留冠脉无显著狭窄时的微血管、痉挛或代谢异常等原因，需与KP10衔接。

## KP08｜稳定期治疗两目标：症状改善 ≠ 预后改善

> **讲义定位 →** 内科印刷P333–334 / PDF P404–406。  
> **主提示**：目标2｜症状药组｜事件预防组｜缓痛≠降死亡

改善症状：硝酸酯、β阻断、CCB；课程四个其他药物按机制定位：伊伐布雷定抑制窦房结If电流，雷诺嗪抑制晚期Na电流以减轻Ca超载，曲美他嗪改善心肌能量代谢/氧利用，尼可地尔开放K通道并扩张冠脉微血管。

## KP09｜抗板、降脂、PCI / CABG各改变哪一层

> **讲义定位 →** 内科印刷P334 / PDF物理405–406；**讲义回看 →** B4、B5。
> **主提示**：抗板靶点/代表｜LDL课程目标｜联合降脂｜PCI/CABG条件

三层作用：抗板减少血小板血栓，降脂减少脂质负荷并稳定斑块，PCI/CABG改善供血通路。

1. COX-1抑制剂：阿司匹林不可逆抑制，吲哚布芬可逆抑制。阿司匹林是课程抗板基石；不耐受时课程列吲哚布芬，也列P2Y12抑制剂作为阿司匹林有禁忌时的选择。活动性消化道出血不能只凭“不耐受”三个字自动换药继续抗板，须先评估出血与缺血风险。
2. 支架后通常增加P2Y12抑制剂构成双联；课程代表替格瑞洛、氯吡格雷。氯吡格雷须代谢活化，CYP2C19慢代谢者效应可能减弱。疗程依PCI场景和出血风险，不能统一套用UA疗程。
3. 降脂首选他汀；不足时可联合胆固醇吸收抑制剂依折麦布。课程LDL-C目标：稳定冠心病/ASCVD＜1.8 mmol/L，ACS＜1.4 mmol/L；串联糖尿病未合并ASCVD时＜2.6 mmol/L。最后一项不是所有健康人通用目标，这组数是该课程版本，临床按相应风险分层与指南目标。
4. 规范药物后仍有症状可评估血运重建；PCI包括球囊扩张/支架，支架内血栓和再狭窄影响疗效。课程CABG例子是“左主干合并2支以上病变、多支病变合并糖尿病、严重扭曲伴重度钙化”，并考虑解剖复杂性、手术耐受和意愿。该组合不是现代CABG全部必要条件：显著左主干病变本身也可构成改善生存的血运重建适应证，不能要求必须再累及2支。

稳定期课程药量回看（内科印刷P334 / PDF P405）：阿司匹林维持量75–100 mg；支架植入后按上文适应证加用P2Y12抑制剂时，原表列替格瑞洛维持量90 mg。原表未在这些行给完整用药频次，不能补成每日总量或完整处方；也不能据此让所有稳定期患者常规加用第二种抗板药。

首次负荷须结合起始抗板、急性或介入场景；UA/NSTEMI课程的三组“负荷量→维持量”配对完整放在KP13急性抗栓节点，不把其中吲哚布芬200 mg负荷套作稳定期常规。药物与目标仍归本节点，不新建KP或Memory准入。

## KP10｜微血管性心绞痛 vs 心脏神经官能症

> **讲义定位 →** 内科印刷P334 / PDF P405–406。  
> **主提示**：症状｜负荷/造影｜硝酸反应局限｜排除路径

**微血管性 / X综合征**：心绞痛样症状；负荷试验可阳性；冠脉造影无明显大血管狭窄；当前Study归因微循环障碍；不要求大血管痉挛。

**神经官能症**：青壮年 / 更年期女性较多，可有焦虑背景；针刺样 / 部位变动；几秒或数小时；可伴叹息、心悸、头晕、失眠；常疲劳后出现；硝酸甘油无典型快速效应。

硝酸甘油反应是辅助线索：微血管性心绞痛对短效硝酸酯的反应可变，不能用“无效”单独证明神经官能症，也不能用“有效”单独确诊缺血。

造影正常不能自动等于功能性胸痛，仍需排致命器质性疾病；课程X综合征的“无大血管痉挛”不等于现代微血管性心绞痛绝无微血管痉挛。

# Part C｜斑块事件 / ACS：有没有坏死是关键门槛

## KP11｜UA：缺血模式不稳定，先找动态供血事件并判断坏死边界

> **讲义定位 →** 内科印刷P334–336 / PDF P405–408；**讲义回看 →** B5、B4。  
> **主提示**：斑块急变｜分型4种｜CCS 4级｜坏死边界

```text
易损斑块破裂 / 侵蚀
→ 胶原 / TF暴露
→ 血小板 + 凝血
→ 动态 / 非完全血栓
+ 微血管栓塞 / 痉挛
→ 冠脉血流突然下降
→ 急性缺血
└─ 无急性缺血性坏死证据时归UA；若已有相应坏死证据，进入MI分流
```

课程四型：初发、静息、恶化、变异（变异的痉挛模型见KP12）。初发指首发症状1–2个月内，轻微活动即可诱发；静息型在休息时发作；恶化型须有原来相对稳定的劳力性心绞痛基础，随后频率、强度、持续时间或缓解难度恶化。

这里CCS分级指加拿大心血管病学会的心绞痛活动分级，别与慢性冠脉综合征缩写混淆：Ⅰ一般活动不受限；Ⅱ轻度受限，课程用步行>200m或登楼>1层诱发；Ⅲ明显受限，约200m以内或登楼1层诱发；Ⅳ轻微活动甚至休息即可发作。课程初发型程度至少Ⅲ级，恶化型较既往增加≥1级。

UA缺乏急性心肌坏死的证据。不能仅凭一次肌钙蛋白升高就转判NSTEMI：要结合动态变化、急性缺血证据及ECG；心肌炎等也可升高，发病早期单次阴性也不能排除梗死。

## KP13｜UA为什么需要更强抗栓和风险分层

> **讲义定位 →** 内科印刷P335–336 / PDF P407–408。  
> **主提示**：治疗5层→目标｜危险征象→侵入优先级

```text
DAPT → 抑血小板栓扩大
抗凝 → 抑凝血酶 / 纤维蛋白放大
β阻断 / 硝酸酯 / CCB → 再平衡供需
高强度降脂 → 稳定斑块 / 长期预防
```

极高危线索决定紧急侵入优先级：血流动力学不稳定/休克、急性心衰、致命心律失常或心搏骤停、心梗机械并发症、反复间歇性ST抬高、药物治疗无效的反复胸痛。课程极高危者<2h行紧急PCI评估路径；危险分层是判断紧迫性，不能等到标志物“确认”后才识别循环不稳。原题要求的药物与条件如下：

- 双联抗板：阿司匹林＋P2Y12抑制剂（课程举替格瑞洛、氯吡格雷）；课程写“＞1年”。2025 ACC/AHA默认至少12个月的前提是无高出血风险；高出血风险、口服抗凝等情境需调整，不能一律超过一年。NSTE-ACS计划早期侵入且冠脉解剖未知时，也不能把双联目标直接等同术前一律先负荷P2Y12。
- GPⅡb/Ⅲa拮抗剂：课程列PCI术中追加替罗非班/阿昔单抗。临床需保留选择性补救条件，如无复流或血栓并发症，不能变成所有PCI固定加第三种抗板药。
- 抗凝：课程肝素为基础，高出血风险者举磺达肝癸钠，PCI术中举比伐卢定。磺达肝癸钠是抗凝血酶依赖的间接Xa抑制剂；比伐卢定直接抑制凝血酶。这不是三药层层叠加处方：选择取决于侵入时机、肾功能和出血风险。2023 ESC对未预计24 h内早期造影的NSTE-ACS可选磺达肝癸钠，之后做PCI须补普通肝素；不能以单用磺达肝癸钠承担PCI抗凝。
- β阻断：无禁忌时早期使用，课程少数高危者举静脉艾司洛尔；急性心衰、低输出、休克风险或严重缓慢传导障碍时不能照此套用。ACEI/ARB亦须有适应证及血压、肾功能、血钾允许，不能把课程“尽早ACEI/ARB/ARNI”理解成所有ACS立即三选一。
- 课程ACS的LDL-C目标＜1.4 mmol/L；稳定期课程目标与降脂药物见KP09。

本节点的课程UA/NSTEMI药量精记（内科印刷P335 / PDF P407）：在急性抗板方案内按“负荷量 → 维持量”比较，阿司匹林150–300 → 75–100 mg，吲哚布芬200 → 100 mg，替格瑞洛180 → 90 mg。阿司匹林与吲哚布芬是同组COX-1抑制剂的课程替代选择，不是两药同时负荷；再按上文条件考虑P2Y12抑制剂。数值仅对应本页急性用药情境，不能反推所有稳定患者都需此负荷，亦不取消出血风险和侵入策略对选药 / 给药时机的限制。原表未写完整给药频次，不自行补成每日总量或完整处方。

## KP14｜UA vs NSTEMI：最关键边界是坏死标志物

> **讲义定位 →** 内科印刷P336 / PDF P408；**讲义回看 →** P0。  
> **主提示**：UA vs NSTEMI｜ECG｜标志物动态｜缺血证据

```text
UA：缺血，但无可检测坏死 → 标志物不升高
NSTEMI：缺血已不可逆 → 坏死 → 标志物升高
```

原题把住院死亡率放在UA/NSTEMI对比中，但讲义印刷P336实际给出的死亡率比较是NSTEMI与STEMI，见KP15；不把该比较对象偷换成UA。

## KP15｜NSTEMI vs STEMI：不是“小梗死”和“大梗死”

> **讲义定位 →** 内科印刷P336–337 / PDF P408–409。  
> **主提示**：NSTEMIvsSTEMI：闭塞/损伤层次/ECG/标志物/再灌注｜血栓相对性

```text
NSTEMI
→ 多为不完全 / 动态阻塞
→ 心内膜下坏死为主
→ ST压低 / T倒置等
→ cTn↑
→ 不按STEMI路径溶栓

STEMI
→ 多为持续严重 / 完全闭塞
→ 透壁 / 全层损伤谱系
→ 典型持续ST抬高，可出现病理Q
→ cTn↑
→ 适应证内尽快再灌注
```

NSTEMI不能仅因“也有血栓”就沿用STEMI的全身溶栓路径：在该人群未证实同样获益，反而增加出血风险，应采用抗栓和风险分层下的侵入评估。课程白色血栓模型有助理解，但不是“所有NSTEMI完全没有纤维蛋白”的理由。

当前 Study还用血栓成分解释：NSTEMI偏血小板性白色成分；STEMI可有更多纤维蛋白 / RBC。它是相对组织方式，不是绝对二分。

课程印刷P336还比较：NSTEMI群体多支病变率较高、侧支较多；住院死亡率较STEMI低，但长期心血管事件率接近。这是课程群体比较，不用于断言单个NSTEMI较轻，也不能由ECG类型直接确定冠脉是否完全闭塞。

## KP17｜坏死吸收反应 + 低血压的三条路径

> **讲义定位 →** 内科印刷P337–338 / PDF P409–410。  
> **主提示**：吸收反应3项/时点｜低压3路径｜感染鉴别接口

```text
迷走 / 外周扩张 → SVR↓
出汗 / 容量不足 → CVP / PAWP可低
```

课程印刷P337把三条路径对应为：泵衰→IABP；周围扩张→去甲肾上腺素/多巴胺；容量不足→补液。必须保留治疗条件：泵衰首先紧急再灌注并按灌注/淤血支持，2023 ESC不推荐无机械并发症的心梗休克常规IABP，机械并发症可另行讨论短期支持；血管活性药和容量治疗须据血流动力学选择，不能所有低压都大量补液。低充盈压/明确容量不足可谨慎补液并复评，伴肺水肿或高充盈压时尤其避免盲目扩容，完整分流见B12。

所以“低血压”不能直接决定同一处理；先定位泵 / 阻力 / 容量。血压没有下降甚至升高也不能排除MI，基础高血压、交感反应及梗死范围都会影响表现。

## KP27｜室壁瘤 vs Dressler：结构重构 vs 免疫炎症

> **讲义定位 →** 内科印刷P337–338 / PDF P409–410。  
> **主提示**：室壁瘤：形成/超声/ECG｜Dressler：时程/机制｜早期心包炎对照

室壁瘤：瘢痕变薄、失去收缩 + 心腔压力 → 局部膨出 / 反常运动；可见ST持续抬高；超声见局部突出 / 矛盾运动。首选超声心动图评估；与扩张型心肌病相对照，前者以节段性异常/局部瘤样膨出为线索，后者以心腔扩张和弥漫性室壁运动减弱为典型模型。持续ST抬高支持室壁瘤线索，但不能单独确诊；扩心病也可有非特异性ST-T或病理Q波，不能以“有Q波”硬分。

Dressler：坏死抗原暴露 → 延迟免疫反应 → 数周至数月后心包炎 / 胸膜炎等。

## KP28｜Killip vs Forrester：临床严重度 vs 湿 / 冷双坐标

> **讲义定位 →** 内科印刷P338–339 / PDF P410–411。  
> **主提示**：Killip 4级｜Forrester 2轴/4型｜阈值

Killip：I无明显HF；II左心衰，课程肺部啰音<50%肺野；III急性肺水肿，课程啰音>50%；IV心源性休克。原表未单列恰好50%的边界，不自行补造。

Forrester：PAWP看“湿”，CI看“冷”：

```text
I   干暖：PAWP＜18，CI＞2.2
II  湿暖：PAWP≥18，CI＞2.2
III 干冷：PAWP＜18，CI≤2.2
IV  湿冷：PAWP≥18，CI≤2.2
```

以上按本课程分界，PAWP单位mmHg，CI单位L/(min·m²)。Killip IV的本课量化线索为SBP＜90 mmHg、PAWP≥18 mmHg、CI≤2.2 L/(min·m²)；这组典型左心泵衰指标不能用来排除所有低充盈压或右心来源的休克。

同样低压可来自高充盈压泵衰或低充盈压容量不足，不能只看BP。

# Part F｜再灌注 + 抗栓 + 长期保护

## KP29｜再灌注：有无PCI条件，目标都是尽快救回尚可逆心肌

> **讲义定位 →** 内科印刷P338–340 / PDF P410–412。  
> **主提示**：时间2轴｜PCI/溶栓条件｜可逆vs坏死

```text
持续闭塞
→ 可逆缺血逐渐变不可逆坏死
→ 时间越久，可挽救心肌越少
```

把两只时钟分开：

| 时间轴 | 条件与含义 |
|---|---|
| 症状开始→再灌注 | 越早越好；课程强调3–6 h及12 h内，不能理解成要等到3 h才处理 |
| 医疗系统内预计延迟 | 课程：有及时PCI条件首选直接PCI；无条件或预计直接PCI>2 h，且起病12 h内、符合适应证及无禁忌时考虑溶栓 |

120 min必须带起止点：2023 ESC按STEMI诊断→导丝通过梗死相关动脉；2025 AHA/ACC按首次医疗接触→器械启动（直接就诊目标≤90 min、转运≤120 min）。两种定义不混算。超过12 h也不能一律放弃再血管化，持续缺血、休克或恶性心律失常等需走紧急评估路径。

再通能救边缘尚可逆心肌，不等于已坏死心肌立即恢复收缩。

## KP30｜抗板、抗凝、溶栓、PCI、降耗氧分别作用哪一环

> **讲义定位 →** 内科印刷P335–336、P338–340、P347 / PDF P407–408、P410–412、P419；**讲义回看 →** B4。  
> **主提示**：干预6层→靶点/目标｜抗凝vs溶栓｜急性vs长期

```text
抗板 → 血小板栓
抗凝 → 凝血酶 / 纤维蛋白继续放大
溶栓 → 已形成纤维蛋白血栓
PCI → 机械恢复通路
β阻断 / 硝酸酯 / 镇痛 → 降耗氧 / 缓解缺血与交感
降脂 / ACEI / ARB等 → 斑块 / 重构长期风险
```

抗凝不能直接溶已有血栓；溶栓不是抗板。

## KP31｜溶栓禁忌 + 再通证据

> **讲义定位 →** 内科印刷P339–340 / PDF P411–412。  
> **主提示**：溶栓禁忌5风险组｜夹层排除｜间接再通4类｜直接证据

禁忌按风险来源记：严重颅内病变/卒中、活动性出血、近期重大创伤/手术及不能压迫部位的大血管穿刺、未控制严重高压（课程＞180/110 mmHg）、未排除主动脉夹层。此处是课程风险分组，不是绝对/相对禁忌的完整临床清单；卒中类型和时间、复苏是否创伤性/延长等不能省略，不能把所有既往卒中或任何短暂成功CPR都判成终身绝对禁忌。

原题串联“高危肺栓塞是否考虑禁忌”：必须评估。原讲义“高危肺栓塞不考虑溶栓禁忌症”已在A2 R9 KP21显式纠正，濒死风险可改变权衡，但不能忽略活动性出血及导管/外科替代方案。

课程印刷P339 / PDF物理411的四类间接证据：CK-MB峰值提前至起病＜14 h；胸痛在溶栓后2 h内基本消失；2 h内出现再灌注性心律失常，如加速性室性自主心律；原抬高ST段在2 h内回降＞50%。CK-MB的14 h按梗死起病时间理解，不能与溶栓后2 h混算。

这些是间接线索，不能由胸痛缓解或出现一次室性节律单独确认通畅；冠脉造影提供直接证据。临床持续缺血、血流动力学或电不稳定需立即评估补救性PCI，不能为了凑齐课程2 h指标而等待。

## KP33｜主动脉夹层：错误进入溶栓路径可以致命

> **讲义定位 →** 内科印刷P339–340、P346 / PDF P411–412、P418。  
> **主提示**：MI vs UA｜夹层线索｜溶栓前鉴别

MI vs UA：结合标志物动态、ECG、缺血表现与发病时间；不能用“单次阳性＝MI、单次阴性＝UA”分流。课程印刷P339六轴：MI有坏死标志物升高及特征/动态ECG，疼痛可持续数小时甚至更久、往往不是短暂频繁发作，血压可下降，并可有低热/白细胞增多等坏死物吸收反应；UA更常反复发作且无坏死证据。时长、频率和血压均不是绝对排除条件，疼痛超过30 min应警惕MI但不能仅按时长确诊。

## KP34｜最终病例算法：从胸痛到处理优先级

> **主提示**：稳定性｜缺血模式｜ECG｜标志物｜反例｜再灌注｜并发症

```text
1. 先判稳定性
   休克 / 低氧 / 肺水肿 / 恶性节律 / 意识 / 新发机械杂音？
2. 胸痛是否缺血性？
3. 立即ECG
4. 同步留取 / 动态复查cTn等标志物；不为等待结果延误需立即启动的再灌注 / 循环支持
5. 同步辨别夹层 / PE / 心包炎等会改变路径的反例
6. 分类
   稳定型 → 症状控制 + 事件预防
```
