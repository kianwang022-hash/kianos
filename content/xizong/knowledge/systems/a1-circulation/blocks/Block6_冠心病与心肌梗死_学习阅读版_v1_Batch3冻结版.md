# Block 6｜冠心病与心肌梗死
## 从冠脉供需、固定狭窄到斑块事件、ACS与坏死修复｜学习阅读版 v1 · Batch 3 冻结版

> **中心问题**：心肌氧供—耗氧失衡与斑块稳定性变化怎样把固定狭窄、稳定型心绞痛、UA、NSTEMI、STEMI和心肌坏死串成连续谱，并用症状、ECG、肌钙蛋白、冠脉证据和治疗目标完成分层？

# 先看一部完整冠脉电影

B6 是 B1–B5 第一次真正汇合成疾病模型：

```text
B1 冠脉舒张期供血 / 耗氧变量
+
B5 稳定斑块 / 易损斑块
+
B4 血小板 / 凝血 / 血栓
+
B3 ECG 电活动语言
+
P0 坏死 → 炎症清除 → 肉芽组织 → 瘢痕
```

汇合以后只有两条上游路径：

```text
路径1｜固定狭窄
稳定斑块 → 冠脉储备下降
→ 静息够用、活动时供不应求
→ 可预测的可逆缺血
→ 稳定型心绞痛

路径2｜斑块事件
易损斑块破裂 / 侵蚀
→ 血小板 + 凝血 + 血栓
→ 冠脉血流突然下降
→ ACS
   ├─ 尚无坏死 → UA
   ├─ 已坏死、无典型持续ST抬高谱系 → NSTEMI
   └─ 持续严重闭塞 / 损伤谱系 → STEMI
```

持续缺血后：

```text
代谢 / 舒缩异常
→ 电活动改变
→ 不可逆凝固性坏死
→ cTn等标志物释放
→ 电 / 泵 / 结构并发症
→ 中性粒细胞 / 巨噬细胞清除
→ 肉芽组织
→ 瘢痕与重构
```

治疗永远对应链上某一层：

```text
抗板 / 抗凝 → 不让血栓继续扩大
降耗氧 → 缓解供需失衡
再灌注 → 尽快恢复通路，挽救尚未坏死心肌
二级预防 → 稳定斑块、控制危险因素和重构
```

# Part A｜供需预算 + 斑块身份

## KP01｜CCS vs ACS：先问当前是“稳定供血上限”还是“急性供血骤降”

> **讲义定位 →** P330–332。  
> **主提示**：CCS / ACS包含什么；二者深层区别；同一患者为何可转换。

当前 Study：

```text
ACS
├─ UA
├─ NSTEMI
├─ STEMI
└─ 猝死

CCS
├─ 稳定型心绞痛
├─ 隐匿型 / 无症状性冠心病
└─ 缺血性心肌病
```

深层：

```text
CCS = 病变相对稳定，缺血阈值可预测
ACS = 斑块事件 / 血栓 / 痉挛使供血突然下降
```

CCS与ACS不是两种完全分离的病；稳定患者可因斑块破裂进入ACS。

---

## KP02｜心肌氧供—耗氧预算：HR升高为何双重不利

> **讲义定位 →** P332–333；**讲义回看 →** B1。  
> **主提示**：供氧 / 耗氧；HR双重作用；贫血为何冠脉正常也可缺血。

耗氧核心：HR、收缩性、壁张力。当前 Study 还用 `收缩压 × HR × 射血时间` 做简化入口。

供氧：

```text
冠脉血流 × 动脉血氧含量
```

受主动脉舒张压 / 冠脉灌注压、舒张期、冠脉阻力、Hb / SaO₂、局部代谢舒张影响。

```text
HR↑
├─ 单位时间收缩次数↑ → 耗氧↑
└─ 舒张期缩短 → 左冠供血时间↓
```

严重贫血即使冠脉管腔无新阻塞，`CaO₂↓` 也可造成心肌供氧不足。

---

## KP03｜固定狭窄与斑块事件：不是“狭窄越来越重”的一条路

> **讲义定位 →** P330–331；**讲义回看 →** B5。  
> **主提示**：稳定 / 易损斑块；储备上限 vs 急性事件风险。

```text
稳定斑块（帽厚、核心小）
→ 固定狭窄
→ 冠脉扩张储备↓
→ 活动时缺血
→ 稳定型心绞痛

易损斑块（帽薄、核心大、炎症活跃）
→ 破裂 / 侵蚀
→ 血小板 + 凝血 + 血栓
→ ACS
```

固定狭窄程度主要决定慢性储备上限；急性事件风险还取决于斑块稳定性。

---

## KP04｜抗心绞痛药先按被调变量理解

> **讲义定位 →** P333；**讲义回看 →** B1、B2。  
> **主提示**：硝酸酯、β阻断、二氢吡啶 / 非二氢吡啶 CCB 对前负荷、后负荷、HR、收缩性的影响。

**硝酸酯**：扩静脉为主 → 回心 / 前负荷↓ → 心室半径 / 壁张力↓ → 耗氧↓；并有扩冠 / 抗痉挛 / 侧支接口。

**β阻断**：HR↓ + 收缩性↓ → 耗氧↓；HR↓ → 舒张期↑ → 供血时间↑。

**DHP-CCB**：外周 / 冠脉扩张 → 后负荷↓、痉挛缓解；可反射性HR↑。

**非DHP-CCB**：HR↓、传导↓、收缩性↓ + 一定扩血管。

> B1 的 KP30–32 只是供需验证；完整药物位置在这里。

# Part B｜固定狭窄：稳定缺血

## KP05｜“稳定”和“劳力”分别意味着什么

> **讲义定位 →** P334。  
> **主提示**：稳定指什么；劳力触发什么；需氧增加型缺血。

```text
稳定
= 数月内发作频率、程度、持续、性质、诱因无明显变化

劳力
= 活动使HR / 收缩性 / 壁张力↑
→ 需求超过固定供血上限
```

所以稳定型心绞痛主要是“固定狭窄 + 需氧增加”的可预测模式。

---

## KP06｜典型胸痛六要素

> **讲义定位 →** P334。  
> **主提示**：诱因、性质、部位 / 放射、持续、缓解、模式变化。

- 劳力 / 情绪诱发；
- 压榨、压迫、紧缩 / 发闷，可有濒死感；
- 胸骨后，可向颈、左肩、左臂内侧等放射；
- 多数持续数分钟，Study通常不超过30min；
- 休息 / 舌下硝酸甘油易缓解；
- 稳定期模式可预测。

疼痛“很重”本身不能区分稳定型、UA、MI；还要看持续 / 变化、ECG、标志物。

---

## KP07｜缺血发作时的电—机械短暂异常

> **讲义定位 →** P334；**讲义回看 →** B1、B3。  
> **主提示**：交感、S3 / S4、S2逆分裂、暂时性MR杂音。

缺血 / 疼痛 → 交感↑ → HR / BP↑、出汗、末梢收缩。

心肌舒张受损 / 顺应性↓可出现S4；泵功能受损可出现S3；左室射血延迟可使A2延迟 → S2逆分裂；乳头肌短暂缺血可出现暂时性心尖收缩期杂音。

这些是功能性缺血表现，不等于已经乳头肌断裂 / 固定瓣膜病。

---

## KP08｜稳定期治疗两目标：症状改善 ≠ 预后改善

> **讲义定位 →** P334–337。  
> **主提示**：哪些主要减发作，哪些减少事件。

改善症状：硝酸酯、β阻断、CCB，以及 Study 的伊伐布雷定、雷诺嗪、曲美他嗪、尼可地尔等接口。

改善预后 / 减事件：抗血小板、降脂、危险因素控制、适应证下ACEI / ARB、必要时血运重建。

硝酸酯能明显减胸痛，但不因此自动成为长期降死亡核心药。

---

## KP09｜抗板、降脂、PCI / CABG各改变哪一层

> **讲义定位 →** P335–337；**讲义回看 →** B4、B5。  
> **主提示**：血栓、斑块、管腔三层。

```text
抗板 → 减少斑块事件后的血小板血栓
降脂 → 降低脂质负荷并稳定斑块
PCI / CABG → 改善冠脉供血通路
```

支架后强化抗板，是因为支架 / 病变局部仍有血栓风险。具体剂量、LDL目标、CABG适应证进入MI-D。

---

## KP10｜微血管性心绞痛 vs 心脏神经官能症

> **讲义定位 →** P337。  
> **主提示**：造影正常时，两者仍不是一回事。

**微血管性 / X综合征**：心绞痛样症状；负荷试验可阳性；冠脉造影无明显大血管狭窄；当前Study归因微循环障碍；不要求大血管痉挛。

**神经官能症**：青壮年 / 更年期女性较多，可有焦虑背景；针刺样 / 部位变动；几秒或数小时；可伴叹息、心悸、头晕、失眠；常疲劳后出现；硝酸甘油无典型快速效应。

造影正常不能自动等于功能性胸痛，仍需排致命器质性疾病。

# Part C｜斑块事件 / ACS：有没有坏死是关键门槛

## KP11｜UA：症状阈值下降，说明病理已经从固定狭窄变成动态事件

> **讲义定位 →** P337–339；**讲义回看 →** B5、B4。  
> **主提示**：破裂 / 侵蚀、血栓、微栓、痉挛；初发 / 静息 / 恶化。

```text
易损斑块破裂 / 侵蚀
→ 胶原 / TF暴露
→ 血小板 + 凝血
→ 动态 / 非完全血栓
+ 微血管栓塞 / 痉挛
→ 冠脉血流突然下降
→ UA
```

初发、静息、恶化型共同点：发作不可预测、阈值下降。UA仍无可检测坏死；标志物一旦升高就跨入NSTEMI。

---

## KP12｜变异型心绞痛：核心是自发严重痉挛

> **讲义定位 →** P338–339。  
> **主提示**：静息 / 夜间、暂时ST抬高、CCB、β阻断边界。

```text
冠脉自发严重痉挛
→ 血流暂时显著下降
→ 静息 / 夜间发作
→ 发作时暂时ST抬高
→ 痉挛解除后可恢复
```

当前 Study：CCB首选解除痉挛；不宜单用β阻断。ST抬高是电表现，不自动等于坏死。

---

## KP13｜UA为什么需要更强抗栓和风险分层

> **讲义定位 →** P338–339。  
> **主提示**：DAPT、抗凝、抗缺血、降脂、早期侵入分别解决什么。

```text
DAPT → 抑血小板栓扩大
抗凝 → 抑凝血酶 / 纤维蛋白放大
β阻断 / 硝酸酯 / CCB → 再平衡供需
高强度降脂 → 稳定斑块 / 长期预防
```

风险分层回答：是否持续缺血、循环不稳、恶性节律等 → 是否需更紧急冠脉造影 / PCI。精确极高危标准 / PCI时限进入MI-D。

---

## KP14｜UA vs NSTEMI：最关键边界是坏死标志物

> **讲义定位 →** P339；**讲义回看 →** P0。  
> **主提示**：为什么ECG不能单独完成分类。

```text
UA：缺血，但无可检测坏死 → 标志物不升高
NSTEMI：缺血已不可逆 → 坏死 → 标志物升高
```

两者都可有ST压低 / T波改变；标志物决定有没有进入“梗死”。

---

## KP15｜NSTEMI vs STEMI：不是“小梗死”和“大梗死”

> **讲义定位 →** P339–340。  
> **主提示**：闭塞 / 损伤层次、ECG、标志物、溶栓边界。

```text
NSTEMI
→ 多为不完全 / 动态阻塞
→ 心内膜下坏死为主
→ ST压低 / T倒置等
→ cTn↑
→ 不按STEMI路径溶栓

STEMI
→ 多为持续严重 / 完全闭塞
→ 透壁 / 全层损伤谱系
→ 典型持续ST抬高，可出现病理Q
→ cTn↑
→ 适应证内尽快再灌注
```

当前 Study还用血栓成分解释：NSTEMI偏血小板性白色成分；STEMI可有更多纤维蛋白 / RBC。它是相对组织方式，不是绝对二分。

# Part D｜STEMI：症状 → 坏死 → 证据 → 修复

## KP16｜STEMI胸痛与非典型表现

> **讲义定位 →** P340。  
> **主提示**：诱因、时机、程度、持续、缓解；上腹痛 / 恶心。

典型：诱因常不明显，可清晨；压榨 / 濒死感；持续>30min常数小时；休息 / 硝酸甘油难缓解。

下 / 后壁可以上腹痛为入口；坏死刺激迷走可恶心、呕吐、腹胀。老年 / DM可无典型胸痛，需依ECG / 标志物。

---

## KP17｜坏死吸收反应 + 低血压的三条路径

> **讲义定位 →** P340。  
> **主提示**：低热 / 中性粒 / ESR；泵、阻力、容量三条低压路径。

疼痛后1–2d可有低热、中性粒↑、ESR↑，反映坏死组织被清除，不等于感染。

```text
大面积坏死 → CO↓ → 泵性低灌注
迷走 / 外周扩张 → SVR↓
出汗 / 容量不足 → CVP / PAWP可低
```

所以“低血压”不能直接决定同一处理；先定位泵 / 阻力 / 容量。

## KP18｜梗死部位与节律接口：前壁偏室性，下壁偏缓慢传导

> **讲义定位 →** P340；**讲义回看 →** B3。  
> **主提示**：LAD前壁 vs RCA下壁；前壁合并AVB为何更危险。

```text
前壁 / LAD
→ 大片心室肌缺血
→ 室早 / VT / VF风险

下壁 / RCA
→ 可累及SA / AV结供血
→ 窦缓 / AVB
```

前壁MI再出现AVB提示范围广 / 多支病变，高危。完整节律诊疗归B10。

---

## KP19｜心肌梗死病理时程：坏死 → 清除 → 肉芽 → 瘢痕

> **讲义定位 →** 病理P46；**Outline →** U003 AS Q11。  
> **主提示**：凝固性坏死；4d、1–2w、3w、6–8w。

新鲜梗死：苍白、贫血性梗死、凝固性坏死；核固缩 / 碎裂 / 溶解；胞质均质红染 / 收缩带；间质水肿 + 中性粒。

```text
约4d → 外围充血 / 出血带
1–2w → 坏死溶解，边缘肉芽组织长入
约3w → 肉芽机化，瘢痕形成
6–8w → 瘢痕愈合，陈旧MI
```

心肌不能有效再生，所以修复主要靠瘢痕；瘢痕不等于收缩功能恢复。

---

## KP20｜坏死标志物：谁最早、谁最特异、谁回落快

> **讲义定位 →** P344。  
> **主提示**：肌红蛋白、cTn、CK-MB角色。

```text
肌红蛋白 → 最早升、最早回，敏感但特异低
cTn → 心肌坏死诊断价值最高，持续较长
CK-MB → 较早升、较快回，可帮助再梗死 / 再通判断
```

精确时间进入MI-D。

---

## KP21｜ECG三层：缺血、损伤、坏死

> **讲义定位 →** P345–346；**讲义回看 →** B3。  
> **主提示**：T、ST、Q分别属于哪层；动态四期。

```text
缺血 → T波改变
损伤 → ST改变
  心内膜下 → ST压低
  透壁 / 全层 → ST抬高
坏死 → 病理Q波
```

STEMI动态：超急性高耸T → 急性ST抬高 / 可病理Q → 亚急性ST回落 / T倒置 → 慢性残留T / Q变化。

ECG是电投影，不是组织学切片，必须结合临床 / 标志物。

---

## KP22｜导联—心壁—冠脉：用空间投影定位

> **讲义定位 →** P346–348。  
> **主提示**：V1–V3、V3–V5、V5–V7 / I / aVL、II / III / aVF；LAD / LCX / RCA。

```text
V1–V3 → 前间壁 → LAD
V3–V5 → 前壁 → LAD
V5–V7 + I/aVL → 侧 / 高侧 → LCX或LAD分支接口
II/III/aVF → 下壁 → RCA
```

RCA常供应右心 / 下壁及SA / AV结，所以下壁梗死易有缓慢传导异常。冠脉优势型存在个体差异，考试按Study典型映射。

## KP23｜检查层级：每项检查证明不同东西

> **讲义定位 →** P343–345。  
> **主提示**：CTA、DSA、核素、PET、超声、负荷、Holter职责。

- 冠脉CTA：无创冠脉解剖 / 狭窄，当前Study首选无创确诊接口；
- 冠脉造影DSA：管腔 / 狭窄，当前Study金标准；
- 核素心肌显像：灌注；
- 核素心腔造影：心腔功能；
- PET：代谢 / 存活心肌；
- 超声：节段壁运动 + 乳头肌 / 室间隔 / 室壁瘤等机械并发症；
- 运动负荷ECG：诱发缺血，不用于不稳定者；
- Holter：动态ST-T / 无痛性缺血。

先问“要证明缺血、坏死、解剖、灌注、活力还是机械并发症”，不要背一张谁最好总表。

# Part E｜并发症：电、泵、结构、血栓、重构、炎症

## KP24｜并发症总地图

> **讲义定位 →** P340–341。  
> **主提示**：按故障层分类。

```text
电 → 室早 / VT / VF / AVB
泵 → 急性左衰 / 心源性休克
结构 → 乳头肌 / 室间隔 / 游离壁破裂
血栓 → 附壁血栓 / 栓塞
重构 → 室壁瘤 / 缺血性心肌病
炎症 / 免疫 → 早期心包炎 / Dressler
```

每一项都能从“坏的是电系统、工作心肌、结构部件还是修复后瘢痕”推出。

---

## KP25｜乳头肌功能不全 / 断裂：新发MR的两个层级

> **讲义定位 →** P340；**讲义回看 →** B7。  
> **主提示**：功能不全 vs 断裂；急性肺水肿。

功能不全：乳头肌缺血 → 收缩协调↓ → MR / 心尖收缩期杂音，可随抗缺血改善。

断裂：Study强调后乳头肌血供相对单一 + 下壁MI → 急性重度MR → LA来不及扩张 → LA压骤升 → 急性肺水肿 / 低输出。

新发杂音 + 急性肺水肿要优先找机械并发症。

---

## KP26｜游离壁破裂 vs 室间隔破裂：血流去向决定后果

> **讲义定位 →** P341。  
> **主提示**：心包 vs 右室；压塞 vs 左向右分流。

```text
游离壁破裂
→ 血入心包
→ 心包积血 / 压塞
→ 回心 / 充盈骤降
→ PEA / 猝死接口
```

```text
室间隔破裂
→ LV高压血流进入RV
→ 急性左向右分流
→ 胸骨左缘3–4肋间新发收缩期杂音
→ 肺流量负荷 + 低输出
```

---

## KP27｜室壁瘤 vs Dressler：结构重构 vs 免疫炎症

> **讲义定位 →** P341。  
> **主提示**：室壁瘤超声 / ECG；Dressler时间 / 机制。

室壁瘤：瘢痕变薄、失去收缩 + 心腔压力 → 局部膨出 / 反常运动；可见ST持续抬高；超声见局部突出 / 矛盾运动。

Dressler：坏死抗原暴露 → 延迟免疫反应 → 数周至数月后心包炎 / 胸膜炎等。

心梗后2–3d早期心包摩擦音 ≠ Dressler。

---

## KP28｜Killip vs Forrester：临床严重度 vs 湿 / 冷双坐标

> **讲义定位 →** P341。  
> **主提示**：Killip I–IV；Forrester PAWP × CI。

Killip：I无HF；II轻中度；III肺水肿；IV心源性休克。

Forrester：PAWP看“湿”，CI看“冷”：

```text
I  干暖
II 湿暖
III 干冷
IV 湿冷
```

同样低压可来自高充盈压泵衰或低充盈压容量不足，不能只看BP。

# Part F｜再灌注 + 抗栓 + 长期保护

## KP29｜再灌注：有无PCI条件，目标都是尽快救回尚可逆心肌

> **讲义定位 →** P341–343。  
> **主提示**：直接PCI / 溶栓；为什么越早越好；再通不能复活已坏死心肌。

```text
持续闭塞
→ 可逆缺血逐渐变不可逆坏死
→ 时间越久，可挽救心肌越少
```

有及时PCI条件 → 直接PCI；无法在要求时间完成且符合溶栓适应证 / 无禁忌 → 溶栓。精确3–6h、12h、PCI延迟阈值等进入MI-D。

再通能救边缘尚可逆心肌，不等于已坏死心肌立即恢复收缩。

---

## KP30｜抗板、抗凝、溶栓、PCI、降耗氧分别作用哪一环

> **讲义定位 →** P341–343、P349–350；**讲义回看 →** B4。  
> **主提示**：不要把所有药都叫“抗栓”。

```text
抗板 → 血小板栓
抗凝 → 凝血酶 / 纤维蛋白继续放大
溶栓 → 已形成纤维蛋白血栓
PCI → 机械恢复通路
β阻断 / 硝酸酯 / 镇痛 → 降耗氧 / 缓解缺血与交感
降脂 / ACEI / ARB等 → 斑块 / 重构长期风险
```

抗凝不能直接溶已有血栓；溶栓不是抗板。

---

## KP31｜溶栓禁忌 + 再通证据

> **讲义定位 →** P342。  
> **主提示**：出血风险大类；夹层；四类间接再通证据。

禁忌按风险来源记：严重颅内病变 / 卒中接口、活动性出血、近期重大创伤 / 手术、未控制严重高压、未排除主动脉夹层等。

间接再通：胸痛明显缓解、ST回落、再灌注性节律、CK-MB峰值提前。冠脉造影是直接证据层。

---

## KP32｜急性右室梗死：右室失效后，左心首先缺“前负荷”

> **讲义定位 →** P343。  
> **主提示**：下壁伴发、CVP / PAWP、肺清、补容量、硝酸酯 / 利尿禁忌。

```text
RV MI
→ RV输出↓
→ 肺循环流量↓
→ LV前负荷↓
→ CO / BP↓
```

常伴下 / 后壁MI；JVD、肺相对清、CVP↑，PAWP↓或正常。

治疗：维持 / 补充前负荷 + 再灌注 + 必要时支持RV。硝酸酯 / 强利尿等减少回心可进一步降压。

---

## KP33｜主动脉夹层：错误进入溶栓路径可以致命

> **讲义定位 →** P342、P349。  
> **主提示**：MI vs UA；夹层胸痛 / 血压脉搏 / AR线索；为何先排除。

MI vs UA：坏死标志物↑ → MI；不升高 → UA，再结合ECG / 持续时间分层。

夹层警报：突发撕裂样胸痛向背；双上肢BP / 脉搏不对称；新发AR杂音；主动脉壁影像；冠口受累也可ST抬高。

> ST抬高不能跳过致命鉴别；夹层误溶栓可灾难性出血。

## KP34｜最终病例算法：从胸痛到处理优先级

> **主提示**：稳定性 → 缺血模式 → ECG → 标志物 → 反例 → 再灌注 → 并发症。

```text
1. 先判稳定性
   休克 / 低氧 / 肺水肿 / 恶性节律 / 意识 / 新发机械杂音？
2. 胸痛是否缺血性？
3. 立即ECG
4. cTn等坏死标志物
5. 排除夹层 / PE / 心包炎等会改变路径的反例
6. 分类
   稳定型 → 症状控制 + 事件预防
   NSTE-ACS → DAPT + 抗凝 + 风险分层 / 侵入策略
   STEMI → 尽快再灌注
7. 主动找电 / 泵 / 结构并发症 + RV MI
8. 二级预防
```

## KP35｜AMI节律并发症：先看有效循环，再调用B10 / B12

> **讲义定位 →** P339–340；**完整模型 →** B10 / B12。  
> **主提示**：无脉 / 有脉；快慢；室性恶性节律；高阶AVB。

B6只保留立即改变处理的门槛：

```text
无脉VF / pVT
→ B12：CPR + 非同步除颤

有脉但血流动力学不稳定的快速型
→ B10：按节律选择同步复律等

偶发室早 + 无症状 / 无灌注影响
→ 可观察

频发室早 / VT
→ 抗室性节律药接口

缓慢型
→ 阿托品接口
→ 二度Ⅱ / 三度AVB：临时起搏接口
```

> **边界**：最高层是“有无脉搏 / 稳定性”，不是先用R波做总分流。完整同步 / 非同步原理由B10 / B12负责。

## KP36｜AMI急性左心衰：肺水肿和低灌注要分开读取

> **讲义定位 →** P338；**完整模型 →** B11 / B12。  
> **主提示**：湿 / 冷；利尿 / 扩管必须服从灌注。

```text
大面积LV坏死
→ 收缩性骤降
→ LVEDP / LA / 肺静脉压↑ → 肺水肿
同时SV↓ → 低灌注
```

可喘憋、端坐、粉红泡沫痰、湿啰音 + 低压 / 少尿 / 意识异常。

当前 Study方向：呋塞米减淤血；血压允许时硝酸酯 / 硝普钠降负荷；镇痛 / 降交感接口；同时评估再灌注 / 循环支持。

Killip看临床严重度；Forrester把湿与冷分开。低血压不能单独决定补液 / 利尿 / 扩管。
