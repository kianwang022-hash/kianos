# Block 12｜休克与心脏骤停 · 学习阅读版 v2｜最终执行版
## 当组织灌注快速失败时，先判有无脉搏，再找容量、泵、阻力分布或通路

> **中心问题**：休克与心脏骤停都以有效组织灌注崩溃为核心，但怎样先区分仍有前向输出的休克与无有效脉搏的骤停，再用 Failure Layer、灌注指标和血流动力学定位根本故障并决定处理优先级？

# 先用这一张图进入全文

任何“低血压、少尿、意识改变、皮肤异常或倒地无反应”的病例，第一步不是先背休克类型，也不是先精确读完 ECG：

```text
0. 有无有效脉搏？

无有效脉搏
→ 已进入心脏骤停
→ 立即 CAB / CPR
→ 再分可电击 VF / pVT
   与系统级不可电击 PEA / 心静止接口

有有效脉搏
→ 再问是否真的存在组织低灌注
→ 若有，进入休克分支
```

休克分支只需要先找四个 Failure Layer：

```text
容量不足
→ 管里真的少

泵失败
→ 血在，但打不出去

阻力 / 分布异常
→ 管床过度扩张或血流分配失败

通路阻塞
→ 血回不来或过不去

四条路最终都可
→ 器官灌注不足
→ 代谢失败
→ 微循环失代偿
```

所以两条边界必须先钉住：

> **休克不等于低血压；心脏骤停也不等于“心电图成直线”。**

- 休克早期可以靠交感、RAAS 等暂时维持血压，但肾、皮肤、胃肠灌注已经下降；
- 心脏骤停的核心是**无有效脉搏 / 无有效前向输出**，不是某一种特定 ECG 外观。

# 总 Framework

<!-- kianos:framework id="circulation-b12-framework-main" -->

```text
① 最高优先级门槛
   有无有效脉搏
   → 无脉进入骤停；有脉再判断低灌注
        ↓
② 休克先找第一故障层
   容量 / 泵 / 阻力分布 / 通路阻塞
   [KP01–KP02]
        ↓
③ 看微循环怎样由代偿走向崩溃
   缩 → 扩 → 凝 / DIC
   [KP03–KP04]
        ↓
④ 用灌注证据判断严重度
   神志 / 尿量 / 皮肤 / BP / 脉压
   + 休克指数 / 乳酸 / BE
   [KP05–KP07]
        ↓
⑤ 用血流动力学校准容量与泵
   PAWP / PCWP、CVP
   → CVP–BP四格 + 补液试验
   [KP08–KP09]
        ↓
⑥ 恢复灌注，同时处理第一故障层
   液体 / 血液 / 强心 / 血管活性
   / 解除阻塞 / 源控制
   [KP10–KP14]
        ↓
⑦ 无脉搏时进入复苏
   CAB → CPR
   → VF / pVT 可电击路径
   → PEA / 心静止仅作系统级接口
   [KP15–KP18]
        ↓
⑧ 最终反推
   脉搏 → 低灌注 → Failure Layer
   → P/Q/R/V → 证据 → 最危险变量
   [KP19]
```

# ① 休克的定义与四类 Failure Layer

<!-- kianos:kp id="circulation-b12-kp01" -->

## KP01｜休克的本质、特征与“血压正常仍可休克”

> **讲义定位 →** 外科 P223。  
> **主提示**：本质/Study特征｜氧供失败4路｜BP≠灌注｜监测7组

### 1｜本质与特征

按本节 Study：

- **本质**：有效循环血量下降，导致组织灌注和氧供不足；
- **特征**：炎症介质释放。

从 B1 / B2 语言翻译：

```text
组织氧供不足
可来自：
CO下降
或
器官血流分配异常
或
有效回心不足
或
血流通路被阻断
```

### 2｜为什么休克≠低血压

休克早期：

```text
交感 + RAAS
→ HR↑、收缩性↑、微动脉收缩
→ TPR↑
→ BP可暂时维持
```

但皮肤、肾、胃肠等灌注已经下降。因此：

> 血压正常不能排除隐匿性休克。

反过来，单纯低血压若没有器官低灌注，也不能机械等同于休克。

### 3｜真正需要跟踪的对象

- 意识；
- 尿量；
- 皮肤温度、颜色和毛细血管充盈；
- 脉压、脉率；
- 乳酸、BE；
- 必要时胃肠道 pH；
- CVP / PAWP等血流动力学证据。

---

<!-- kianos:kp id="circulation-b12-kp02" -->

## KP02｜四类休克：容量、泵、阻力分布、回流通路

> **主提示**：休克4类：首故障→变量→场景｜终末表现≠分型｜补液边界

| 类型 | 第一故障层 | 典型场景 | 最初变量方向 |
|---|---|---|---|
| 低容量性 | 有效循环容量不足 | 失血、体液大量丢失 | 回心↓、前负荷↓、SV / CO↓ |
| 心源性 | 泵不能形成前向流量 | 大面积MI、急性左心衰、严重心肌病 | CO↓；上游压力常↑ |
| 分布性 | 血管张力 / 血流分配异常 | 感染性、过敏性等 | TPR异常下降或微循环分流；有效容量相对不足 |
| 阻塞性 | 回心或前向通路被机械阻断 | PE、张力性气胸、心包压塞 | 回心 / 右室输出或左室充盈骤降 |

### 一个统一判断

```text
低容量：管里真的少
心源性：泵打不出去
分布性：管床过度扩张 / 分流，容量相对不够
阻塞性：血回不来或过不去
```

（易混：四类休克最终都可低血压、少尿、意识异常；分类依赖第一故障层，而不是只看终末表现。）

# ② 微循环：从“只出不进”到“只进不出”

<!-- kianos:kp id="circulation-b12-kp03" -->

## KP03｜休克微循环三期：缩、扩、凝

> **讲义定位 →** 外科 P223；**讲义回看 →** B1 正常微循环。  
> **主提示**：微循环占比｜3期：入口/出口→流量｜早期分配｜后期5后果｜衰竭出口

按本节 Study，微循环约占总循环量 **20%**。

### 1｜收缩期 / 代偿期 / 休克早期

```text
有效循环量↓
→ 交感—肾上腺髓质 + RAAS
→ 缩血管物质↑
→ 微动脉、后微动脉 / 毛细血管前括约肌收缩
→ A端入口关闭更敏感
→ V端尚未完全关闭
→ “只出不进”
```

目的：

> 把血从皮肤、胃肠、肾等微循环重新分配给心、脑。

### 2｜扩张期 / 抑制期

```text
持续灌注不足
→ H⁺、乳酸等代谢产物积聚
→ 后微动脉和cap前括约肌开放
→ 入口重新打开
但微静脉端对缩血管物质仍敏感、出口关闭
→ “只进不出”
```

后果：

- 血液淤积；
- 毛细血管压力升高；
- 液体外渗；
- 血液浓缩、黏稠；
- 回心量进一步下降。

### 3｜衰竭期

```text
淤滞 + 内皮损伤 + 酸中毒
→ 微血栓 / 透明血栓
→ DIC
→ 多器官灌注和屏障进一步崩溃
```

> “缩—扩—凝”不是三个孤立名词，而是一条自我强化的失代偿链。

<!-- kianos:kp id="circulation-b12-kp04" -->

## KP04｜DIC接口：凝得太多，最后反而出血

> **讲义定位 →** 外科 P223；**讲义回看 →** B4止血 / 抗凝 / 纤溶。  
> **主提示**：DIC形成链｜5项指标/单位｜抗凝条件｜凝血vs出血

### 1｜形成链

```text
微循环淤滞和内皮损伤
→ 凝血广泛激活
→ 毛细血管内纤维蛋白微血栓
→ 血小板和凝血因子大量消耗
→ 继发纤溶
→ 微血栓 + 出血同时存在
```

### 2｜按本节 Study 的提示指标

- 血小板 `<80×10⁹/L`；
- PT 延长 `>3 s`；
- 纤维蛋白原 `<1.5 g/L`；
- 3P试验；
- 血涂片破碎红细胞 `>2%`。

> 原页省略了血小板和纤维蛋白原单位，这里按常规检验单位补全；该组是课程提示，不是单独确诊DIC的完整标准。结合基础病、动态变化及相应评分，不能用一项异常直接确诊。

### 3｜治疗接口

课程写“早期/高凝期→肝素”。临床核心先处理病因；治疗性肝素需看血栓主导表现、出血风险等条件，不能仅凭“休克早期”自动抗凝。

完整 DIC 分期、替代治疗和现代临床路径归血液系统；本 Block 只掌握它是休克微循环衰竭的重要出口。

# ③ 严重度与灌注监测

<!-- kianos:kp id="circulation-b12-kp05" -->

## KP05｜休克早期、中度、重度：失血量—血压—脉搏—神志一起看

> **讲义定位 →** 外科 P224。  
> **主提示**：Study3度：失血/SBP/DBP/PP/脉搏/神志｜早期代偿链｜总论vs各论口径

### 1｜休克早期 / 代偿期 / 轻度

- 失血量 `<20%`，按 Study 约 `<800 mL`；
- SBP正常或稍升；
- DBP升高；
- 脉压缩小；
- 心率加快。

机制：

```text
微动脉收缩
→ TPR↑
→ DBP上升更突出
→ SBP暂时维持
→ 脉压缩小
```

### 2｜休克期 / 失代偿期

| 程度 | 失血量 | 脉搏 | SBP | 神志 |
|---|---:|---:|---:|---|
| 中度 | 20%–40% | 脉率增快，原页数字待核 | 90–70 mmHg | 尚清楚、表情淡漠 |
| 重度 | >40%，>1600 mL | 细速、微弱或难触，原页数字待核 | <70 mmHg | 意识模糊、昏迷 |

原PDF物理277页/印刷224页已看清：脉搏栏确实写“中度100–200、重度>200”，不是OCR误读。但不能把>200次/min作为重度失血性休克的必备门槛，明显低于此值也可严重休克。这里保留源文数值作为待勘误记录，不擅换成另一套分级数字，也不把疑点作为已核精度释放。

### 3｜重要边界

- 《各论》题目中的“休克”常默认已进入休克期，SBP `<90`；
- 但总论中必须保留早期可血压正常的机制。

<!-- kianos:kp id="circulation-b12-kp06" -->

## KP06｜休克指数：把心动过速和低血压压成一个方向指标

> **主提示**：指数公式｜Study3档｜方向机制｜严重度线索≠病因

```text
休克指数 = 脉率 / 收缩压
```

按 Study：

- `0.5`：无休克；
- `>1–1.5`：休克；
- `>2`：严重休克。

感性理解：

```text
脉率越快
+ SBP越低
→ 指数越大
→ 代偿越强、循环越不稳定
```

（易混：休克指数不能区分低容量、心源、分布或阻塞性休克；它只是辅助严重度线索。低指数不能独自排除休克，心率受药物、节律、年龄和代偿能力影响，不能将课程“0.5无休克”当作绝对排除规则。）

<!-- kianos:kp id="circulation-b12-kp07" -->

## KP07｜尿量、胃肠道pH、乳酸和BE：寻找被BP掩盖的低灌注

> **讲义定位 →** 外科 P224。  
> **主提示**：尿量2门槛｜尿比重→肾前/肾性｜隐匿灌注指标｜乳酸/BE4职责｜单项局限

### 1｜尿量

按本节 Study：

```text
尿量达到30 mL/h
→ 微循环改善、液体已补足接口
```

```text
尿量<25 mL/h + 尿比重升高
→ 肾仍能浓缩
→ 肾灌注不足 / 血容量不足
→ 肾前性接口
```

```text
BP正常但尿量仍少 + 尿比重低
→ 肾浓缩功能下降
→ 肾实质损伤 / ATN接口
```

> 肾脏恢复提示重要器官灌注改善，但不能只靠单一尿量判断全部循环状态。

### 2｜胃肠道 pH

按 Study：用于发现**隐匿性休克**。胃肠道是早期被牺牲的灌注床，局部酸化可早于明显低血压。

### 3｜乳酸与碱剩余 BE

用于评估：

- 组织缺氧；
- 无氧代谢；
- 酸中毒程度；
- 预后与复苏趋势。

按 Study：`BE<-2.3`为代酸接口，`>+2.3`为代碱接口；精确值进入 MI-D。

# ④ CVP、PAWP 与容量—泵鉴别

<!-- kianos:kp id="circulation-b12-kp08" -->

## KP08｜PAWP看左侧充盈，CVP看右侧回心与射血的平衡

> **讲义定位 →** 外科 P224–225；**讲义回看 →** B1 CVP。  
> **主提示**：PAWP左侧定位｜CVP解剖/正常值｜合力2端｜CVP高3原因｜非容量计

### 1｜PAWP / PCWP

按本节 Study：肺动脉 / 毛细血管楔压反映：

- 肺静脉；
- 左心房；
- 左心室功能 / 充盈状态接口。

左心衰：

```text
血液淤滞在肺静脉 / 左房上游
→ 楔压升高
```

### 2｜CVP

正常约 `5–10 cmH₂O`，代表：

- 右心房压力；
- 胸腔内大静脉压力。

CVP由两个方向共同决定：

```text
静脉回心量
vs
右心射血能力
```

所以：

- 容量少 → 回心少 → CVP低；
- 容量多 / 静脉过度收缩 → CVP可高；
- 右心泵不出去 / 回流受阻 → CVP也高。

> CVP不是“血容量计”，必须和BP、肺部、超声和临床场景共同解释。

---

<!-- kianos:kp id="circulation-b12-kp09" -->

## KP09｜CVP–BP四格与补液试验

> **讲义定位 →** 外科 P225。  
> **主提示**：CVP×BP四格｜各自处理｜补液试验门槛｜BP升 vs CVP升解释

| CVP | BP | 按本节 Study 推断 | 处理方向 |
|---|---|---|---|
| 低 | 低 | 血容量严重不足 | 充分补液 |
| 低 | 正常 | 血容量不足但BP暂被代偿 | 适当补液 |
| 高 | 正常 | 容量血管过度收缩 / 回心过多接口 | 扩静脉 |
| 高 | 低 | 心功能不全或相对容量过多 | 强心、纠酸等；不能盲目补液 |

### 补液试验

按 Study，在 `CVP正常 + BP低` 的不确定场景进行：

```text
补液后BP升高
→ 血容量不足更可能

补液后CVP明显升高而BP不改善
→ 心功能不全更可能
```

（易混：表格是考试决策工具，不代表脱离病因、肺部和超声即可机械处理真实患者。）

# ⑤ 恢复灌注，但不能忘记真正故障层

<!-- kianos:kp id="circulation-b12-kp10" -->

## KP10｜休克治疗总原则：恢复有效循环 + 同时处理病因

> **讲义定位 →** 外科 P223、P227。  
> **主提示**：容量支持/液体/血液｜4故障层→根本处理｜复苏目标5组

按本节 Study，休克治疗最关键 / 首选一般是补充血容量：

- 首选平衡盐等晶体液；
- 课程列人工胶体接口，但具体制剂和休克类型须分开，不能常规泛用；
- 必要时输血。

2026 SSC对脓毒症/感染性休克以晶体液为一线，反对淀粉类、建议不用明胶；所以“晶体后接人工胶体”不能成为所有休克通用顺序。

必须把补容量放回四类故障层：

```text
低容量
→ 恢复真实容量是核心

心源性
→ 适量维持充盈 + 改善泵功能 / 处理缺血或机械并发症

分布性
→ 恢复相对容量 + 血管活性支持 + 源控制

阻塞性
→ 维持灌注只是过渡，必须解除阻塞
```

### 最终目标

不是把一个血压数字“补正常”，而是改善：

- 意识；
- 尿量；
- 皮肤 / 毛细血管灌注；
- 乳酸、BE；
- CO与器官功能。

<!-- kianos:kp id="circulation-b12-kp11" -->

## KP11｜低容量 / 失血性休克：先恢复回心，再止住继续丢失

> **主提示**：首变量/回心链｜CVP变化时序｜Study液体次序/血液门槛｜复苏/止血

```text
失血 / 体液丢失
→ 平均充盈压↓
→ 静脉回心↓
→ EDV / SV / CO↓
→ MAP与器官灌注↓
```

按本节 Study：

- 等待配血期间首选平衡盐；
- “先晶后胶再输血”是课程记忆顺序，不是活动性大出血必须逐项走完的临床流程；
- 失血量增加时逐步加入浓缩红细胞 / 全血接口；
- Hb是否输血按 Study 的 `<70 / 70–100 / >100`范围进入 MI-D。

活动性大出血要把止血与血液/凝血复苏并行，不能等晶体或胶体输完、更不能等单次Hb降到阈值后才处理。急性失血早期Hb可暂不反映真实丢失量；血液制品选择结合出血、灌注和凝血状态。

真正闭环：

```text
补容量和血液
+ 同时控制出血源
→ 才能停止继续丢失
```

进行性血胸、肝脾损伤等必须边复苏边手术止血，不能把输液当作根治。

## KP12｜心源性休克：总容量未必少，问题是泵打不出去

> **主提示**：泵故障→前后向｜CVP/PAWP｜强心/再灌注/机械4场景｜左右心容量边界

```text
心肌收缩严重下降或机械并发症
→ 前向SV / CO↓
→ BP与器官灌注↓
同时
→ 血液在泵上游淤积
→ CVP和/或PAWP升高
```

按 Study 的短接口：

- 急性左心衰且SBP<90：正性肌力药接口；禁用硝普钠等强扩血管；
- AMI合并休克：再灌注是根本，IABP在当前 Study 中作为过渡接口；
- 急性二尖瓣关闭不全 / 乳头肌断裂等机械并发症：需紧急机械 / 外科处理；
- IE瓣叶穿孔、破裂或瘘导致心衰 / 休克：瓣膜手术接口。

（易混：右室MI可能需要谨慎补容量以维持前负荷；一般左心源性肺淤血却不能盲目补液。必须先定位哪一侧和哪一故障层。）

## KP13｜阻塞性休克：泵可能有力，但血回不来或过不去

> **主提示**：阻塞3处｜回流/右室后负荷/LV充盈｜血流动力学｜解除目标

### 1｜急性肺栓塞

```text
肺血管床骤然阻塞
→ RV后负荷骤增
→ RV输出下降
→ LV前负荷下降
→ 低血压 / 休克
```

Study短接口：高危PE溶栓 / 抗凝；完整分层后置呼吸系统。

### 2｜张力性气胸

```text
胸腔内压持续升高
→ 大静脉回流受压
→ 回心骤降
→ 阻塞性休克
```

根本处理：立即穿刺减压，随后完整胸外处理。

### 3｜心包压塞

```text
心包内压↑
→ 心腔舒张充盈受限
→ SV / CO↓
→ 低血压 + 静脉压升高
```

根本处理：心包穿刺接口。

> 阻塞性休克的关键不是“把泵推得更用力”，而是解除通路阻塞。

## KP14｜感染性休克：容量、血管分布、心肌和源控制同时出问题

> **讲义定位 →** 外科 P225。  
> **主提示**：感染源｜冷暖：CO/TPR/体征｜SIRS｜灌注+源控制｜药物条件

### 1｜常见源

按本节 Study：

- 继发性腹膜炎 / 空腔脏器穿孔；
- AOSC；
- 绞窄性肠梗阻；
- 泌尿系感染；
- 重症胰腺炎等。

### 2｜冷休克

按 Study 多见，常与G⁻杆菌 / 内毒素相连：

```text
低动力型：CO↓ + 外周阻力↑
```

表现：

- 神志异常；
- 皮肤苍白、发绀、湿冷；
- 毛细血管充盈时间延长；
- 脉搏细速；
- 脉压<30 mmHg；
- 尿量<25 mL/h。

### 3｜暖休克

课程把暖休克与部分G⁺菌早期相连；不能用“仅见”限定病原，G⁻感染也可有高排低阻表现。冷暖是血流动力学表型，受容量状态、心功能和病程等影响：

```text
高排低阻
+ 微循环短路开放
→ 皮肤温暖
但有效组织交换仍不足
```

后期仍可转为冷休克。

### 4｜SIRS方向

按 Study：

- 体温>38℃或<36℃；
- HR>90次/min；
- 呼吸>20次/min或PaCO₂<4.3 kPa；
- WBC>12×10⁹/L或<4×10⁹/L，或未成熟细胞>10%。

SIRS是炎症反应筛查线索，不等于感染或脓毒症的单独确诊。

精确数字进入 MI-D。

### 5｜治疗

必须同时：

```text
补充有效循环容量 / 维持灌注
+
处理感染灶 / 源控制
```

按本节 Study还包括：

- 外科引流；
- 有效抗生素；
- 纠正酸中毒；
- 血管活性药按循环表型选：当前成人脓毒性休克一般以去甲肾上腺素为首选升压药，多巴酚丁胺用于合适的心功能受损/持续低灌注场景，不能把它们看作同一种任务的任选药；
- 激素：课程“早期大剂量短时间GC”属于待纠正的旧口径。2026 SSC有条件建议成人脓毒性休克使用静脉糖皮质激素；SCCM明确反对高剂量短疗程方案（氢化可的松等效>400 mg/d且<3天）。

> 保留原课程来源以便识别差异，但不把旧式大剂量冲击作为通用治疗。具体剂量、升压组合和补液量需随动态灌注评估，不在本概念框架里替代临床方案。

## KP15｜无脉搏是B12的最高优先级门槛

## KP17｜初级心肺复苏：步骤与操作要点

> **讲义定位 →** 内科 P398–399。  
> **主提示**：CAB｜按压4要点｜气道条件｜通气3场景

按本节 Study：

```text
C｜Circulation：胸外按压
→ A｜Airway：开放气道
→ B｜Breathing：人工呼吸
```

### 胸外按压

- 部位：胸部中央的胸骨下半部；不把乳头连线或距剑突固定距离当成人人相同的定位替代；
- 深度：5–6 cm；
- 频率：100–120次/min；
- 按压与放松时间比：1:1；
- 尚未置入高级气道时，按压与通气比30:2；每组通气尽量减少按压中断。

### 气道与通气

- 无头颈创伤时，仰头抬颏开放气道；疑头颈创伤时，由受训者先用不后仰头部的托颌法，若仍不能开放，优先保证有效气道；
- 捏鼻；
- 不需深吸气；
- 每次用约1 s送气，以可见胸廓起伏为准，避免过快、过多通气；
- 已置入高级气道：连续按压，约每6 s通气1次（10次/min），不再机械套用30:2；
- 有脉但无正常呼吸的呼吸骤停，也可用10次/min救援通气；这与无脉骤停的按压路径分开。

课程P394把30:2、10次/min和“>1 s”并排列出；这里按实际场景补齐条件，不把两种通气节奏叠加。

这些精确数字必须进入 MI-D，但 CAB 顺序和高质量按压是 MI-G。

# ⑦ 最终统一算法

<!-- kianos:kp id="circulation-b12-kp19" -->

## KP19｜休克 / 骤停七步决策

> **主提示**：脉搏/灌注｜首故障｜P/Q/R/V｜淤血/灌注｜阶段｜证据｜危险/根本处理

```text
0. 有无有效脉搏？
   无 → CAB / CPR → 分可电击与系统级不可电击接口
   有 → 继续判断休克
        ↓
1. 是否真的存在组织低灌注？
   意识、尿量、皮肤、乳酸 / BE、毛细血管充盈
        ↓
2. 第一故障层是什么？
   容量 / 泵 / 阻力分布 / 回流通路
        ↓
3. P、Q、R、V怎样变化？
   BP、CO、TPR、回心、CVP、PAWP
        ↓
4. 上游与下游怎样？
   淤血 / 低灌注 / 二者并存
        ↓
5. 当前代偿还是失代偿？
   微循环缩 → 扩 → 凝
        ↓
6. 哪项证据最能校准？
   尿量、休克指数、CVP-BP、补液试验、超声、乳酸
        ↓
7. 最危险变量和根本处理是什么？
   补容量 / 改善泵 / 血管活性 / 解除阻塞 / 源控制 / CPR除颤
```

## 六个典型反向场景

### 低BP + CVP低

```text
低容量优先
→ 补液 / 血液 + 找丢失源
```

### 低BP + CVP高 + 肺湿

```text
心源性泵衰优先
→ 改善泵 / 再灌注 / 机械并发症处理
```

### 低BP + CVP高 + 肺相对清

```text
阻塞性或右心泵衰
→ PE / 压塞 / 右室MI等鉴别
```

### 感染 + 暖皮肤 + 低阻

```text
早期分布性休克
→ 容量 + 血管活性 + 源控制
```

### 规则电活动 + 无脉搏｜Guide-level Integration

```text
PEA
→ 系统层定位为不可电击分支
```

### 室颤 / 无脉室速

```text
立即 CPR + 非同步除颤
```
