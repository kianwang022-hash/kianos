# Block 9｜周围血管疾病
## 动脉看下游缺血，静脉看上游淤血｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：面对肢体疼痛、肿胀、颜色变化或血管迂曲，怎样先区分动脉供血不足与静脉回流障碍，再判断急慢性、血管层级以及肢体或肺栓塞危险，从而选择检查和处理？

# 先用一条分流算法进入全文

先让一股血走完肢体：从心脏进入动脉，经过组织微循环，再沿静脉回到右心。动脉这段受限，是后面的组织收不到足够血；静脉这段回不来，是前面的静脉压力积起来，水更容易进入组织而肿。冷白与肿胀因此有方向上的区别，但颜色、温度或脉搏都只能帮助定位，不能单独给疾病定名。

沿动脉看，通路可以只是短暂痉挛，也可以突然被栓子堵住，或慢慢狭窄。突然堵时侧支来不及；慢慢窄时则可能先在活动增加需求时不够用，再发展到静息也不足。沿静脉看，浅静脉瓣膜失效使血逆流，深静脉血栓既可挡住回流，还可脱落经右心到肺；严重回流障碍甚至会再损害动脉灌注。深静脉承担主要回流，所以处理浅静脉前要先确认深通路能用。

接下来沿“流入和回流在哪里受阻，急到什么程度，先保护什么”讲完整块，再把正式标题〔完整 Prompt〕与Core放回下面同一模型；检查和治疗都回扣这条血流方向。

```text
1. 动脉还是静脉？
   动脉 → 血送不到下游 → 缺血
   静脉 → 血回不到心脏 → 病变上游淤血
        ↓
2. 急性还是慢性？
   急性阻断 → 侧支来不及 → 突然、严重
   慢性狭窄 → 侧支逐渐建立 → 跛行→静息痛→坏死
        ↓
3. 静脉再问深 / 浅 / 交通支
   浅静脉逆流？
   深静脉阻塞？
   交通支瓣膜失效？
        ↓
4. 当前最危险是什么？
   急性肢体缺血 / 不可逆坏死？
   DVT脱落 → PE？
        ↓
5. 用超声 / 造影 / 特定试验定位
        ↓
6. 动脉恢复下游灌注；静脉恢复回流并控制血栓
```

最小感性模型：

```text
动脉病
→ 冷、白、痛、麻、无脉
→ 严重时坏死 / 坏疽

静脉病
→ 肿、暗红 / 青紫、热、曲张
→ 严重时DVT / PE接口
```

> 这是定位模型，不是绝对规则；真实病例仍需结合急慢性、深浅层级、脉搏、温度和影像。

# 总 Framework

```text
正常方向：心脏 → 肢体动脉 → 组织微循环 → 静脉 → 右心

动脉流入受限 → 病变下游供血不足
├─ 小动脉阵发痉挛 → 苍白 / 青紫 → 解除后反应性潮红（Raynaud）
├─ 左心栓子突然阻断动脉 → 侧支来不及 → 5P / 肢体缺血危险
└─ AS闭塞 / TAO等逐渐狭窄 → 活动供血储备下降
   → 跛行；继续加重可至静息痛 → 组织缺损 / 坏疽

静脉回流受限 → 病变上游静脉压↑
├─ 浅静脉瓣膜 / 静脉壁失效 → 逆流 / 曲张 → 慢性静脉高压表现
└─ 损伤 + 淤滞 + 高凝 → DVT → 深静脉阻塞 / 肿痛
   ├─ 严重回流障碍可再影响动脉灌注 → 股青肿 / 肢体危险
   └─ 血栓脱落 → 经右心到肺动脉 → PE风险（完整诊疗归呼吸）

结构前提：深静脉承担主要回流；正常交通支使血浅→深、向心
处理浅静脉前先确认深静脉通畅，避免切断替代回流

病例推理：动 / 静 → 急 / 慢 → 血管层级 → 肢体与PE危险
证据校准：超声 / 造影 / 针对性试验；各自回答所在通路与功能
处理目标：恢复动脉灌注，或改善静脉回流并控制血栓
```

# 同一模型上的自然节点〔完整 Prompt〕

以下保留原有动 / 静、急 / 慢和血管层级，沿实际流入与回流方向展开。各病变是同一路径上的不同故障，检查用于定位、处理用于恢复通路；隐藏标题 / Prompt 后血流与危险关系仍连续。

```text
A1 循环｜B9 沿同一肢体的供血与回流定位故障。
正常血流：心脏 → 肢体动脉 → 组织微循环 → 静脉 → 右心
流入受限使病变下游缺血；回流受限使病变上游淤血，体位与颜色只作线索
〈一张总坐标：动脉看“去不了”，静脉看“回不来”〔动vs静：首故障/颜色/温度/脉搏/主诉/体位6轴〕〉

① 动脉：送不到组织的血，先问通路是暂时痉挛、突然堵还是逐渐窄

小动脉阵发痉挛 → 缺血 / 苍白冷 → 缺氧 / 青紫痛
痉挛解除 → 反应性充血 / 潮红；大动脉搏动仍可正常
〈Raynaud：小动脉阵发痉挛，不是固定大血管堵塞〔人群/部位｜功能性痉挛｜颜色3期→机制｜脉搏/杂音〕〉
干预指向痉挛与继发背景；历史课程药物和现代校准各保留原适用范围
〈Raynaud治疗与继发性现象〔Study药物/靶点｜禁用机制｜继发病接口〕〉

左心病变形成栓子 → 脱落进入体循环 → 卡在肢体动脉 → 急性灌注中断
→ 痛、白、无脉、感觉异常、麻痹（5P）
〈急性动脉栓塞：最常见栓子来自左心〔栓子来源组｜脱落/动脉阻断｜急性机制｜5P〕〉
突然阻断、侧支来不及 → 缺血进展快 → 先判肢体可逆性并尽快恢复通路
取栓 / 溶栓只保留现有课程条件，不凭名称补全未定指征
〈急性动脉栓塞：先抢救肢体，不等慢性侧支〔肢体可逆性｜急阻断vs侧支｜Fogarty/取栓｜溶栓条件接口〕〉

AS中大动脉病变，或TAO中小动静脉炎性 / 血栓性病变
→ 虽病因与血管层级不同，均可形成逐渐加重的动脉缺血
〈AS闭塞 vs TAO：同为慢性缺血，患者和血管不同〔AS闭塞vsTAO：本质/血管/人群/背景/分布/特殊6轴｜共性｜治疗/保暖边界〕〉
静息尚够而活动需求增大 → 跛行；进一步供血不足 → 静息痛 → 组织缺损 / 坏疽
症状与组织状态定阶段，ABI校准灌注但不能独自包办分期
〈慢性动脉缺血四期：从麻冷到坏疽〔I–IV期｜IIa/IIb距离｜ABI及局限｜缺血进程〕〉
同一缺血进程也可用Rutherford细分；两套分级的距离界值不拼接
〈Rutherford：把跛行—静息痛—组织缺损再细分〔Rutherford 1–6级｜跛行/静息痛/组织缺损｜供血阶段〕〉

② 静脉：血回不到心脏，压力留在阻塞或逆流处的上游

深静脉承担主要回流；正常交通支使血由浅入深、向心流动
回流障碍 → 静脉压 / 毛细血管静水压↑ → 组织液↑ / 肿
去氧血淤积 → 暗红 / 青紫；浅静脉高压 → 扩张 / 曲张
〈静脉共同模型：压力堆在上游，所以肿、红、热、曲张〔回流/静脉压｜水肿/颜色/曲张｜体位/压迫｜深浅交通/瓣向〕〉
两条并行回流故障：
├─ 浅静脉瓣缺陷 + 壁软薄 / 压力↑ → 逆流 → 曲张 / 酸胀沉重
│  长期静脉高压 → 足靴区等皮肤改变
│  〈单纯性静脉曲张：浅静脉瓣膜和静脉壁怎样失效〔背景｜逆流机制3项｜早期vs晚期/部位〕〉
└─ 静脉损伤 + 制动 / 术后淤滞 + 高凝 → DVT
   血栓脱落时可经右心到肺动脉 → PE风险，完整诊疗归呼吸
   活动需有效抗凝、循环稳定并经评估；不自行按摩或剧烈活动
   〈DVT形成链：Virchow三要素在外科病例里怎样出现〔Virchow3要素｜活动前提｜PE风险/接口〕〉
   深静脉阻塞位置 → 不同痛肿范围；严重肿胀可压迫动脉 → 股青肿危险
   多数近端DVT以抗凝为基础，威胁肢体等选择性场景才评估溶栓 / 介入
   〈DVT三型：堵在哪里，就在哪里痛肿〔DVT3型：阻塞位置→痛肿范围｜股白vs股青：色/温/脉搏｜动脉受压〕〉

浅静脉处理的结构前提：深静脉若阻塞，浅静脉可能是替代回流
→ 再结扎 / 剥脱 / 硬化会使回流更差；必须先确认深静脉通畅
〈处理浅静脉前必须先确认深静脉能承担回流〔浅静脉处理3法｜深静脉通畅前提｜Perthes阳性→风险链〕〉

③ 观察与决策附在血管上，不是从一种疾病走向另一种疾病

超声校准血流、狭窄、血栓与反流；造影看解剖、阻塞与侧支
〈血管检查：超声多普勒与造影各是什么身份〔超声vs造影：Study地位/血流/解剖｜动静/急慢选择〕〉
旁查对应位置：Buerger问动脉供血，Trendelenburg问大隐瓣，Pratt问交通支瓣
Perthes问深静脉通畅，Homans只保留小腿DVT接口；操作与原图回Source
〈五个试验一张表：每个试验只问一件事〔试验5：名称→对应血管/功能｜Perthes处理边界｜操作回Source〕〉
动 / 静 → 急 / 慢 → 深浅与血管层级 → 肢体可救性 / PE危险 → 证据校准
→ 恢复动脉灌注，或改善静脉回流并控制血栓；危险门槛决定时效
〈最终病例算法：先保肢体，再避免静脉血栓推向肺〔动静/急慢｜深浅/交通支｜危险门槛｜检查｜处理目标/接口〕〉
```

## KP01｜一张总坐标：动脉看“去不了”，静脉看“回不来”

> **主提示**：动vs静：首故障/颜色/温度/脉搏/主诉/体位6轴

| 维度 | 动脉性疾病 | 静脉性疾病 |
|---|---|---|
| 首要故障 | 下游供血不足 | 上游回流障碍 |
| 颜色 | 苍白，晚期发黑 / 坏疽 | 暗红、青紫 |
| 温度 | 冷 | 可潮热 |
| 脉搏 | 减弱 / 消失 | 多保留 |
| 主诉 | 痛、麻、冷、跛行 | 肿、酸胀、沉重 |
| 体位 | 下垂可改善灌注 | 抬高促进回流 |

当前 Study 口诀“动低静高”只用来恢复方向。

## KP02｜Raynaud：小动脉阵发痉挛，不是固定大血管堵塞

> **主提示**：人群/部位｜功能性痉挛｜颜色3期→机制｜脉搏/杂音

当前 Study：青壮年女性多见；双手指常见；寒冷、情绪应激等可触发末梢小动脉阵发痉挛。

```text
痉挛 / 缺血 → 苍白、冷
缺氧 / 代谢物积聚 → 青紫、痛
痉挛解除 / 反应性充血 → 潮红、恢复
```

因为是小动脉功能性痉挛，动脉搏动可正常，通常无中大动脉杂音。

## KP03｜Raynaud治疗与继发性现象

> **主提示**：Study药物/靶点｜禁用机制｜继发病接口

当前外科Study列肾上腺素能末梢阻断剂如胍乙啶、利血平；禁用普萘洛尔，因阻断血管β₂可能加重痉挛。该历史课程入口不能理解为现代治疗的统一首选，亦不与B5的CCB应用矛盾：例如EULAR 2023更新对系统性硬化相关雷诺现象仍推荐二氢吡啶类CCB（通常口服硝苯地平）为一线。

Raynaud现象可见于系统性硬化、SLE、多发性骨髓瘤 / 冷球蛋白等；完整疾病归相应系统。

## KP04｜急性动脉栓塞：最常见栓子来自左心

> **主提示**：栓子来源组｜脱落/动脉阻断｜急性机制｜5P

常见来源：房颤、IE、冠心病 / MI、DCM等左心病变。

```text
左心栓子脱落
→ 进入体循环动脉
→ 卡在肢体动脉
→ 急性灌注中断
```

5P：Pain、Pallor、Pulselessness、Paresthesia、Paralysis。

## KP05｜急性动脉栓塞：先抢救肢体，不等慢性侧支

> **主提示**：肢体可逆性｜急阻断vs侧支｜Fogarty/取栓｜溶栓条件接口

当前 Study：急诊 Fogarty球囊取栓或切开取栓；不能耐受手术、远端小动脉栓塞等可进入溶栓接口。

```text
突然阻断
→ 侧支来不及建立
→ 缺血进展快
→ 先判断肢体是否仍可逆
→ 尽快恢复血流
```

术式 / 再灌注损伤细节归 MI-D / Study。

## KP06｜慢性动脉缺血四期：从麻冷到坏疽

> **主提示**：I–IV期｜IIa/IIb距离｜ABI及局限｜缺血进程

当前 Study：

```text
I期：麻木、寒冷，脉搏减弱，ABI<0.9
II期：间歇性跛行
III期：静息痛 / 夜间痛
IV期：溃疡 / 坏疽，ABI<0.4接口
```

课程精确分界：IIa跛行距离>200 m；IIb<200 m。原页未给等于200 m的归类，不擅加等号。

ABI是踝部与肱动脉收缩压之比：课程常用<0.9提示动脉缺血、<0.4提示重度缺血。分期主要看症状及组织缺损，不能仅凭ABI给所有患者定期；钙化可使ABI假性升高，此时需结合趾肱指数等。

机制：静息时尚能供血 → 运动时供不应求产生跛行 → 狭窄继续进展后静息也不够 → 静息痛 → 组织缺损 / 坏疽。

## KP07｜Rutherford：把跛行—静息痛—组织缺损再细分

> **主提示**：Rutherford 1–6级｜跛行/静息痛/组织缺损｜供血阶段

当前 Study：

```text
1级：轻度跛行，课程最大跛行距离>500 m
2级：中度跛行，课程300–500 m
3级：重度跛行，课程<300 m
4级：静息 / 夜间痛
5级：少量组织缺损 / 活动性溃疡
6级：大面积溃疡 / 坏疽
```

最重要不是距离本身，而是病程已从“运动时供血不足”进入“静息低灌注”，再进入组织死亡。

## KP08｜AS闭塞 vs TAO：同为慢性缺血，患者和血管不同

> **主提示**：AS闭塞vsTAO：本质/血管/人群/背景/分布/特殊6轴｜共性｜治疗/保暖边界

| 维度 | 动脉硬化闭塞症 | TAO / Buerger |
|---|---|---|
| 本质 | AS | 炎性 / 血栓性闭塞 |
| 血管 | 中大动脉 | 中小动静脉 |
| 人群 | >45岁男性常见 | 青壮年男性 |
| 背景 | 高脂、高压、DM、吸烟 | 吸烟突出 |
| 分布 | 广泛，可钙化 | 节段性 |
| 特殊 | 未完全闭塞时可有血管杂音；完全闭塞也可无杂音 | 游走性浅静脉炎 |

共同：痛、麻、白、冷、脉搏减弱 / 消失、慢性缺血分期。

治疗共同入口：戒烟 / 控危险因素、抗板 / 抗凝 / 扩管接口、PTA、旁路；患肢保暖但不直接加热。寒冷可使血管收缩而加重缺血；直接加热虽可扩管，却同时增加局部耗氧，有限供血未必跟得上。

## KP09｜静脉共同模型：压力堆在上游，所以肿、红、热、曲张

> **主提示**：回流/静脉压｜水肿/颜色/曲张｜体位/压迫｜深浅交通/瓣向

```text
静脉回流障碍
→ 静脉压↑
→ 毛细血管静水压↑
→ 组织液↑ → 肿
+ 去氧血淤积 → 暗红 / 青紫
+ 浅静脉压↑ → 迂曲扩张
```

抬高患肢、弹力袜 / 绷带是促进回流的入口。深静脉是主要回流通道；正常交通支瓣膜使血由浅入深、向心流动。

## KP10｜单纯性静脉曲张：浅静脉瓣膜和静脉壁怎样失效

> **主提示**：背景｜逆流机制3项｜早期vs晚期/部位

背景：久站 / 久坐、体力负荷、原发瓣膜 / 静脉壁问题。

```text
大隐静脉瓣膜缺陷
+ 静脉壁软薄
+ 浅静脉压↑
→ 静脉逆流
→ 浅静脉迂曲扩张
```

早期曲张 / 酸胀沉重；晚期足靴区 / 小腿远侧1/3色素沉着等静脉高压改变。

## KP11｜处理浅静脉前必须先确认深静脉能承担回流

> **主提示**：浅静脉处理3法｜深静脉通畅前提｜Perthes阳性→风险链

当前 Study：浅静脉结扎、剥脱、硬化剂等都以**深静脉通畅**为前提。

```text
深静脉阻塞
→ 浅静脉可能成为替代回流通路
→ 再结扎 / 剥脱 / 硬化浅静脉
→ 回流更差
```

因此 Perthes 阳性提示深静脉阻塞时，禁止上述处理。

## KP12｜DVT形成链：Virchow三要素在外科病例里怎样出现

> **讲义回看 →** B4。  
> **主提示**：Virchow3要素｜活动前提｜PE风险/接口

```text
静脉损伤
+ 长期制动 / 手术后血流缓慢
+ 创伤 / 肿瘤等高凝
→ DVT
```

课程“未形成则动、形成后别动”是过度简化。预防阶段活动可减少淤滞；确诊急性DVT后不能自行按摩或剧烈活动，但也不等于所有患者长期卧床。完成有效抗凝、循环稳定并经评估后，可按疼痛、水肿及PE风险安排早期活动。未抗凝、不稳定或严重症状者不能套用同一活动方案。最严重后果是肺栓塞，完整PE归呼吸。

## KP13｜DVT三型：堵在哪里，就在哪里痛肿

> **主提示**：DVT3型：阻塞位置→痛肿范围｜股白vs股青：色/温/脉搏｜动脉受压

当前 Study：

- 周围型：股静脉→大腿痛肿；小腿深静脉→小腿痛肿、Homans接口；
- 中央型：髂窝 / 股三角痛，全下肢肿；
- 混合型：多处痛 + 全下肢肿。

股白肿：苍白、皮温↑；股青肿：青紫、动脉搏动消失、皮温↓，提示严重肿胀已压迫动脉。

治疗课程强调经导管直接溶栓接口，但不应推出全部DVT常规溶栓。多数近端DVT以抗凝为基础；威胁肢体的股青肿，或经选择的低出血风险、症状明显髂股DVT，才评估溶栓/介入的获益与出血风险。不能用抗血小板药代替必要抗凝，完整PE风险分层仍归呼吸。

> **主提示**：超声vs造影：Study地位/血流/解剖｜动静/急慢选择

```text
超声多普勒
→ 首选、无创

```

具体选择仍要看动脉 / 静脉、急 / 慢。

## KP16｜最终病例算法：先保肢体，再避免静脉血栓推向肺

> **主提示**：动静/急慢｜深浅/交通支｜危险门槛｜检查｜处理目标/接口

```text
① 动脉还是静脉？
冷白无脉 → 动脉
肿红曲张 → 静脉

② 急性还是慢性？
突发5P → 急性动脉阻断
跛行→静息痛→坏疽 → 慢性动脉
长期曲张 / 色素 → 浅静脉
手术后单肢痛肿 → DVT

③ 定位层级
小动脉痉挛？
中大动脉闭塞？
浅静脉逆流？
深静脉阻塞？
交通支失效？

④ 判断危险
感觉 / 运动丧失、麻痹、无脉 → 不可逆缺血风险
全肢肿、股青肿 → 严重静脉阻塞 / 动脉受压
DVT → PE风险

⑤ 选检查
超声多普勒 → 必要时造影 / 特定试验

⑥ 治疗目标
动脉：尽快恢复下游灌注
静脉：促进回流、控制血栓、避免脱落
```

向后：急性肢体低灌注→B12；DVT→PE→呼吸；慢性AS→B5；房颤 / IE栓子来源→B7 / B10。
