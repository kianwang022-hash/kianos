# Block 9｜周围血管疾病
## 动脉看下游缺血，静脉看上游淤血｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：面对肢体疼痛、肿胀、颜色变化或血管迂曲，怎样先区分动脉供血不足与静脉回流障碍，再判断急慢性、血管层级以及肢体或肺栓塞危险，从而选择检查和处理？

# 先用一条分流算法进入全文

```text
1. 动脉还是静脉？
   动脉 → 血送不到下游 → 缺血
   静脉 → 血回不去上游 → 淤血
        ↓
2. 急性还是慢性？
   急性阻断 → 侧支来不及 → 突然、严重
   慢性狭窄 → 侧支逐渐建立 → 跛行→静息痛→坏死
        ↓
3. 静脉再问深 / 浅 / 交通支
   浅静脉逆流？
   深静脉阻塞？
   交通支瓣膜失效？
        ↓
4. 当前最危险是什么？
   急性肢体缺血 / 不可逆坏死？
   DVT脱落 → PE？
        ↓
5. 用超声 / 造影 / 特定试验定位
        ↓
6. 动脉恢复下游灌注；静脉恢复回流并控制血栓
```

最小感性模型：

```text
动脉病
→ 冷、白、痛、麻、无脉
→ 严重时坏死 / 坏疽

静脉病
→ 肿、暗红 / 青紫、热、曲张
→ 严重时DVT / PE接口
```

> 这是定位模型，不是绝对规则；真实病例仍需结合急慢性、深浅层级、脉搏、温度和影像。

## KP01｜一张总坐标：动脉看“去不了”，静脉看“回不来”

> **主提示**：颜色、温度、脉搏、疼痛、肿胀；体位逻辑。

| 维度 | 动脉性疾病 | 静脉性疾病 |
|---|---|---|
| 首要故障 | 下游供血不足 | 上游回流障碍 |
| 颜色 | 苍白，晚期发黑 / 坏疽 | 暗红、青紫 |
| 温度 | 冷 | 可潮热 |
| 脉搏 | 减弱 / 消失 | 多保留 |
| 主诉 | 痛、麻、冷、跛行 | 肿、酸胀、沉重 |
| 体位 | 下垂可改善灌注 | 抬高促进回流 |

当前 Study 口诀“动低静高”只用来恢复方向。

---

## KP02｜Raynaud：小动脉阵发痉挛，不是固定大血管堵塞

> **主提示**：人群、部位、三段颜色、脉搏和杂音。

当前 Study：青壮年女性多见；双手指常见；本质为小动脉阵发痉挛。

```text
痉挛 / 缺血 → 苍白、冷
缺氧 / 代谢物积聚 → 青紫、痛
痉挛解除 / 反应性充血 → 潮红、恢复
```

因为是小动脉功能性痉挛，动脉搏动可正常，通常无中大动脉杂音。

---

## KP03｜Raynaud治疗与继发性现象

> **主提示**：当前Study药物；禁用；继发疾病。

当前 Study：肾上腺素能末梢阻断剂如胍乙啶、利血平接口；禁用普萘洛尔，因阻断血管β₂可能加重痉挛。

Raynaud现象可见于系统性硬化、SLE、多发性骨髓瘤 / 冷球蛋白等；完整疾病归相应系统。

---

## KP04｜急性动脉栓塞：最常见栓子来自左心

> **主提示**：来源；为何突发；5P。

常见来源：房颤、IE、冠心病 / MI、DCM等左心病变。

```text
左心栓子脱落
→ 进入体循环动脉
→ 卡在肢体动脉
→ 急性灌注中断
```

5P：Pain、Pallor、Pulselessness、Paresthesia、Paralysis。

---

## KP05｜急性动脉栓塞：先抢救肢体，不等慢性侧支

> **主提示**：Fogarty、取栓 / 溶栓接口；可逆性。

当前 Study：急诊 Fogarty球囊取栓或切开取栓；不能耐受手术、远端小动脉栓塞等可进入溶栓接口。

```text
突然阻断
→ 侧支来不及建立
→ 缺血进展快
→ 先判断肢体是否仍可逆
→ 尽快恢复血流
```

术式 / 再灌注损伤细节归 MI-D / Study。

---

## KP06｜慢性动脉缺血四期：从麻冷到坏疽

> **主提示**：I–IV期；ABI；跛行、静息痛、坏疽。

当前 Study：

```text
I期：麻木、寒冷，脉搏减弱，ABI<0.9
II期：间歇性跛行
III期：静息痛 / 夜间痛
IV期：溃疡 / 坏疽，ABI<0.4接口
```

IIa / IIb 的 200m 等精确距离进入 MI-D。

机制：静息时尚能供血 → 运动时供不应求产生跛行 → 狭窄继续进展后静息也不够 → 静息痛 → 组织缺损 / 坏疽。

---

## KP07｜Rutherford：把跛行—静息痛—组织缺损再细分

> **主提示**：结构必须掌握，数字进入MI-D。

当前 Study：

```text
1–3级：轻 / 中 / 重度跛行
4级：静息 / 夜间痛
5级：少量组织缺损 / 活动性溃疡
6级：大面积溃疡 / 坏疽
```

最重要不是距离本身，而是病程已从“运动时供血不足”进入“静息低灌注”，再进入组织死亡。

---

## KP08｜AS闭塞 vs TAO：同为慢性缺血，患者和血管不同

> **主提示**：血管口径、人群、危险因素、分布、钙化、游走性浅静脉炎。

| 维度 | 动脉硬化闭塞症 | TAO / Buerger |
|---|---|---|
| 本质 | AS | 炎性 / 血栓性闭塞 |
| 血管 | 中大动脉 | 中小动静脉 |
| 人群 | >45岁男性常见 | 青壮年男性 |
| 背景 | 高脂、高压、DM、吸烟 | 吸烟突出 |
| 分布 | 广泛，可钙化 | 节段性 |
| 特殊 | 血管杂音接口 | 游走性浅静脉炎 |

共同：痛、麻、白、冷、脉搏减弱 / 消失、慢性缺血分期。

治疗共同入口：戒烟 / 控危险因素、抗板 / 抗凝 / 扩管接口、PTA、旁路；患肢保暖但不直接加热。

---

## KP09｜静脉共同模型：压力堆在上游，所以肿、红、热、曲张

> **主提示**：共同表现、体位治疗；深浅交通支为何重要。

```text
静脉回流障碍
→ 静脉压↑
→ 毛细血管静水压↑
→ 组织液↑ → 肿
+ 去氧血淤积 → 暗红 / 青紫
+ 浅静脉压↑ → 迂曲扩张
```

抬高患肢、弹力袜 / 绷带是促进回流的入口。深静脉是主要回流通道；正常交通支瓣膜使血由浅入深、向心流动。

---

## KP10｜单纯性静脉曲张：浅静脉瓣膜和静脉壁怎样失效

> **主提示**：危险背景、机制、早晚表现。

背景：久站 / 久坐、体力负荷、原发瓣膜 / 静脉壁问题。

```text
大隐静脉瓣膜缺陷
+ 静脉壁软薄
+ 浅静脉压↑
→ 静脉逆流
→ 浅静脉迂曲扩张
```

早期曲张 / 酸胀沉重；晚期足靴区 / 小腿远侧1/3色素沉着等静脉高压改变。

---

## KP11｜处理浅静脉前必须先确认深静脉能承担回流

> **主提示**：结扎 / 剥脱 / 硬化；为什么 Perthes阳性时禁止。

当前 Study：浅静脉结扎、剥脱、硬化剂等都以**深静脉通畅**为前提。

```text
深静脉阻塞
→ 浅静脉可能成为替代回流通路
→ 再结扎 / 剥脱 / 硬化浅静脉
→ 回流更差
```

因此 Perthes 阳性提示深静脉阻塞时，禁止上述处理。

---

## KP12｜DVT形成链：Virchow三要素在外科病例里怎样出现

> **讲义回看 →** B4。  
> **主提示**：静脉损伤、血流慢、高凝；典型场景；形成后为什么不能运动。

```text
静脉损伤
+ 长期制动 / 手术后血流缓慢
+ 创伤 / 肿瘤等高凝
→ DVT
```

当前 Study：血栓未形成时活动可防淤滞；血栓已形成后避免反复下肢运动，以免脱落。最严重后果是肺栓塞，完整PE归呼吸。

---

## KP13｜DVT三型：堵在哪里，就在哪里痛肿

> **主提示**：周围型、中央型、混合型；股白肿 / 股青肿。

当前 Study：

- 周围型：股静脉→大腿痛肿；小腿深静脉→小腿痛肿、Homans接口；
- 中央型：髂窝 / 股三角痛，全下肢肿；
- 混合型：多处痛 + 全下肢肿。

股白肿：苍白、皮温↑；股青肿：青紫、动脉搏动消失、皮温↓，提示严重肿胀已压迫动脉。

治疗当前Study强调经导管直接溶栓接口；完整抗凝 / 风险分层后置。

---

## KP14｜血管检查：超声多普勒与造影各是什么身份

> **主提示**：首选、金标准；血流 vs 解剖。

```text
超声多普勒
→ 首选、无创
→ 看血流、狭窄、血栓、瓣膜回流

血管造影
→ 当前Study金标准接口
→ 看解剖、阻塞位置、侧支
```

具体选择仍要看动脉 / 静脉、急 / 慢。

---

## KP15｜五个试验一张表：每个试验只问一件事

> **主提示**：Buerger、Trendelenburg、Pratt、Perthes、Homans。

| 试验 | 当前 Study 主要用途 |
|---|---|
| Buerger | 动脉供血不足：AS闭塞、TAO |
| Trendelenburg | 大隐静脉瓣膜功能不全 |
| Pratt | 交通静脉瓣膜功能不全 |
| Perthes | 深静脉阻塞 / 通畅性；阳性时不能处理浅静脉 |
| Homans | 小腿DVT接口 |

操作细节必须回 Study，不只背英文名。

## KP16｜最终病例算法：先保肢体，再避免静脉血栓推向肺

> **主提示**：六步分流；紧急门槛；后续接口。

```text
① 动脉还是静脉？
冷白无脉 → 动脉
肿红曲张 → 静脉

② 急性还是慢性？
突发5P → 急性动脉阻断
跛行→静息痛→坏疽 → 慢性动脉
长期曲张 / 色素 → 浅静脉
手术后单肢痛肿 → DVT

③ 定位层级
小动脉痉挛？
中大动脉闭塞？
浅静脉逆流？
深静脉阻塞？
交通支失效？

④ 判断危险
感觉 / 运动丧失、麻痹、无脉 → 不可逆缺血风险
全肢肿、股青肿 → 严重静脉阻塞 / 动脉受压
DVT → PE风险

⑤ 选检查
超声多普勒 → 必要时造影 / 特定试验

⑥ 治疗目标
动脉：尽快恢复下游灌注
静脉：促进回流、控制血栓、避免脱落
```

向后：急性肢体低灌注→B12；DVT→PE→呼吸；慢性AS→B5；房颤 / IE栓子来源→B7 / B10。
