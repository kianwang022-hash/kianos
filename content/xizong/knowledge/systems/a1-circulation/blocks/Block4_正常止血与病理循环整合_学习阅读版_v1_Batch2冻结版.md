# Block 4｜正常止血与病理循环整合
## 从快速封口，到纤维蛋白加固、限制范围和最后拆除｜学习阅读版 v1 · Batch 2 冻结版

> **中心问题**：血管破损后，血小板、凝血、抗凝和纤溶怎样既快速完成局部止血，又把反应限制在损伤处；同一套系统若在完整血管内错误启动，又怎样转成血栓、栓塞和梗死？

# 先看一条完整止血电影

正常止血同时满足两个相反要求：

```text
必须快
→ 几分钟内封住破口

又必须受限
→ 只能在损伤局部发生
→ 不能把整条血管甚至全身血液凝住
```

所以第一次学习不要先掉进凝血因子号码表。先抓四个功能阶段：

```text
① 血小板封口
   血管收缩
   → 黏附 / 活化 / 聚集
   → 初步血小板栓
        ↓
② 纤维蛋白加固
   凝血级联放大
   → 凝血酶
   → 纤维蛋白网
   → 凝血块回缩
        ↓
③ 抗凝限域
   正常内皮 + AT + PC/PS/TM + TFPI
   + 血流稀释 / 清除
   → 不让凝血向正常血管扩展
        ↓
④ 纤溶拆除
   t-PA / u-PA
   → 纤溶酶
   → 降解已完成使命的纤维蛋白
   → 再通 / 修复
```

若同一系统在错误地点、错误强度或错误持续时间启动：

```text
病理血栓
→ 脱落成为栓子
→ 栓塞
→ 若缺血严重且侧支不足
→ 梗死
```

# ① 先封口：血管 + 血小板

## KP01｜正常止血的双重目标与三个重叠过程

> **讲义定位 →** P99。  
> **主提示**：生理性止血定义；三个过程；一期 / 二期止血；为什么血小板居中心。

生理性止血：小血管受损后，出血在数分钟内自行停止的保护过程。

三个过程不是首尾严格分开的流水线，而是重叠、相互促进：

```text
血管收缩
+
血小板血栓形成
+
血液凝固形成凝血块
```

```text
一期止血
= 血管收缩 + 血小板栓
→ 快速、初步、相对松软

二期止血
= 凝血 → 纤维蛋白凝血块
→ 加固血小板栓
```

血小板居中心，因为它既识别损伤、封口和释放 ADP / TXA₂，又提供磷脂反应面并参与凝血块回缩。

---

## KP02｜先缩口，最后把网拉紧：血管收缩与凝血块回缩

> **讲义定位 →** P99；**讲义跳转 →** P92。  
> **主提示**：血管收缩三来源；血小板 / 内皮释放物；凝血块回缩；血清 vs 血浆。

血管收缩来源：

1. **神经**：损伤刺激引起反射性收缩；
2. **自身**：机械变形 → 平滑肌机械门控Ca²⁺通道 → Ca²⁺内流 → 肌源性收缩；
3. **体液**：血小板 TXA₂ / 5-HT、受损内皮 ET → 局部收缩。

二期止血后：

```text
纤维蛋白网形成
→ 血小板伪足 / GPIIb/IIIa连接纤维蛋白索
→ 血小板收缩蛋白收缩
→ 凝血块回缩
→ 挤出血清
→ 凝血块更致密
```

血清相较血浆，少了凝固过程中被消耗的凝血因子，尤其纤维蛋白原；同时可含血小板释放的 ADP、TXA₂等。

> 血小板负责“拉紧”，纤维蛋白负责“加固成网”，两者不是同一物质。

## KP03｜血小板五动作：黏附—聚集—释放—收缩—吸附

> **讲义跳转 →** P91–93；**讲义回看 →** P99。  
> **主提示**：五动作各解决什么；GPIb / vWF；GPIIb/IIIa / 纤维蛋白原；释放物；磷脂平台。

### 黏附｜找到破口

```text
内皮破损 → 胶原暴露
→ vWF桥接胶原与血小板
→ 血小板GPIb结合vWF
→ 黏附
```

Study 接口：巨大血小板综合征＝GPIb异常；vWD＝vWF缺乏。

### 聚集｜血小板彼此连起来

```text
血小板激活
→ GPIIb/IIIa高亲和化
→ Ca²⁺参与下结合纤维蛋白原
→ 纤维蛋白原桥接相邻血小板
→ 聚集
```

Study 接口：血小板无力症＝GPIIb/IIIa异常；纤维蛋白原缺乏也影响聚集。

### 释放｜局部放大

- 致密体：ADP、ATP、5-HT、Ca²⁺；
- α颗粒：PF4、β血小板球蛋白等；
- 临时合成：TXA₂。

```text
聚集 → ADP / TXA₂释放
→ 招募更多血小板
→ 释放—聚集正反馈
```

### 收缩｜把网拉紧

Ca²⁺、ATP参与血小板收缩蛋白作用 → 凝血块回缩。

### 吸附｜提供凝血平台

血小板表面磷脂酰丝氨酸等提供磷脂表面 → 吸附 / 浓缩凝血因子 → 将一期止血与凝血级联接起来。

## KP04｜第一 / 第二聚集时相与 TXA₂—PGI₂ / NO 平衡

> **讲义跳转 →** P92；**讲义定位 →** P103。  
> **主提示**：两相聚集；可逆 / 不可逆；TXA₂ vs PGI₂ / NO；抗板药短接口。

| 时相 | 速度 | 可逆性 | 主组织方式 |
|---|---|---|---|
| 第一聚集时相 | 快 | 可逆 | 低浓度外源致聚剂等 |
| 第二聚集时相 | 较慢 | 不可逆 | 内源ADP、TXA₂等放大 |

```text
血小板TXA₂ → 聚集↑、血管收缩
正常内皮PGI₂ / NO → 抗黏附 / 抗聚集、舒张血管
```

PGI₂通过 cAMP，NO通过 cGMP 抑制血小板。内皮损伤后，PGI₂ / NO下降 + 胶原 / vWF暴露 + ADP / TXA₂释放，平衡转向局部聚集。

药物短接口：

- 阿司匹林 / 吲哚布芬：COX-1→TXA₂↓；
- 氯吡格雷 / 替格瑞洛：ADP受体；
- 阿昔单抗 / 替罗非班：GPIIb/IIIa；
- 前列环素 / 双嘧达莫：cAMP接口；
- 利多格雷：TXA₂合成酶接口。

完整冠心病抗板路径归 B6。

# ② 纤维蛋白加固：先记结果，再挂因子号

## KP05｜凝血最小主链：1→1a→n1a

> **讲义定位 →** P100–101。  
> **主提示**：凝血本质；1、2、10是什么；凝血酶原酶复合物；外 / 内源性最终共同做什么。

```text
可溶性FⅠ纤维蛋白原
→ FⅠa纤维蛋白单体
→ nFⅠa不溶性多聚体
→ 交织成网
→ 凝血块
```

倒推：

```text
1 → 1a      靠凝血酶2a
1a → n1a    靠13a稳定交联
2 → 2a      靠凝血酶原酶复合物
             = 10a + 5a + Ca²⁺ + PL
10 → 10a    靠外源性或内源性途径
```

先把因子定位成：启动10 / 放大10 / 生成2a / 生成1a / 稳定纤维蛋白，再记号码。

## KP06｜外源性启动，内源性放大，最后在 FⅩ 汇合

> **讲义定位 →** P100–102。  
> **主提示**：起始因子、主链、速度、复合物；TF启动 / 内源放大；FⅫ、PK、HK特殊意义。

外源性：

```text
组织损伤 → TF / FⅢ暴露
→ FⅢ–FⅦa–Ca²⁺复合物
→ FⅩa
```

- FⅢ位于组织，不在正常循环血浆；
- 步骤少、快；
- 当前 Study 强调体内主要由 TF / 外源性途径启动。

内源性：

```text
胶原 / 带负电表面
→ FⅫa → FⅪa
→ FⅨa–FⅧa–Ca²⁺–PL
→ FⅩa
```

两条联系：FⅦa可激活FⅨ；FⅨa可促进FⅦ激活；最终都到FⅩ。

```text
TF先产生少量凝血酶
→ 凝血酶激活FⅤ / FⅧ / FⅪ和血小板
→ 内源性系统放大
→ 大量凝血酶 / 纤维蛋白
```

FⅫ、PK、HK 对体内最初启动并非必需，更突出接触系统 / 纤溶接口；体外循环大量接触负电表面时意义增大。

## KP07｜关键凝血因子按角色组织，不背无序号码表

> **讲义定位 →** P101–102。  
> **主提示**：启动、离子、辅因子、酶原、稳定；VitK组；消耗组；不稳定因子；无FⅥ。

| 因子 | Study角色 |
|---|---|
| FⅠ | 纤维蛋白原，最终底物 |
| FⅡ | 凝血酶原 → Ⅱa |
| FⅢ | TF，外源启动 |
| FⅣ | Ca²⁺，唯一离子型凝血因子 |
| FⅤ | 凝血酶原酶辅因子 |
| FⅦ | 外源性核心酶因子 |
| FⅧ | 内源性FⅩ酶辅因子 |
| FⅨ | 与FⅧa组成内源性FⅩ酶复合物 |
| FⅩ | 外 / 内源共同交汇 |
| FⅪ | 激活FⅨ |
| FⅫ | 接触因子，内源起始 / 纤溶接口 |
| FⅩⅢ | 稳定纤维蛋白交联 |
| PK / HK | 接触系统；HK为辅因子 |

- 没有 FⅥ；历史“FⅥ”相当于活化 FⅤ。
- 丝氨酸蛋白酶 / 酶原：Ⅱ、Ⅶ、Ⅸ、Ⅹ、Ⅺ、Ⅻ、PK等；
- 辅因子：HK、Ⅲ、Ⅳ、Ⅴ、Ⅷ等；
- 多数由肝合成；
- VitK依赖：`Ⅱ、Ⅶ、Ⅸ、Ⅹ`；
- 消耗：`Ⅰ、Ⅱ、Ⅴ、Ⅷ、ⅩⅢ`；
- FⅤ、FⅧ较不稳定，Study称FⅤ最不稳定；vWF保护FⅧ。

精确名单附着在前面的功能链上，而不是先背表。

## KP08｜凝血酶：把启动变成爆发的总放大器

> **讲义定位 →** P100–104。  
> **主提示**：主要作用；正反馈；FⅩⅢa为何不同；凝血酶接触正常内皮后为何可转为抗凝。

主要作用：

```text
FⅡa凝血酶
→ FⅠ纤维蛋白原 → FⅠa
```

还可激活 FⅤ、FⅧ、FⅪ、FⅩⅢ和血小板。当前 Study 把 FⅤ、FⅧ、FⅪ和血小板纳入正反馈：少量凝血酶 → 更多辅因子 / 血小板磷脂面 → 更多FⅩa / 凝血酶。

FⅩⅢa主要负责稳定交联纤维蛋白，不按同一方式回头增加凝血酶。

凝血酶离开损伤处，接触正常内皮 TM：

```text
凝血酶 + TM → 激活PC
→ 灭活FⅤa / FⅧa
→ 限制凝血扩展
```

所以凝血酶的角色受局部环境决定。

## KP09｜血友病、vWD、肝病与 VitK：从异常位置反推故障层

> **讲义定位 →** P101–102。  
> **主提示**：A/B/C缺什么；vWF两角色；肝病；VitK / 华法林；血制品接口。

```text
血友病A：FⅧ缺乏
血友病B：FⅨ缺乏
血友病C：FⅪ缺乏
```

Study解释 C 型常较轻：外源性FⅦa仍可直接激活FⅨ，部分绕过FⅪ。

vWF两角色：

```text
胶原—vWF—GPIb → 血小板黏附
vWF保护FⅧ → 维持FⅧ稳定
```

因此 vWD 同时影响一期止血与FⅧ稳定。

肝硬化：凝血因子合成减少是出血倾向的重要原因，可用冰冻血浆补因子接口。

```text
VitK参与Ⅱ、Ⅶ、Ⅸ、Ⅹ合成
华法林拮抗VitK
→ 抑制新凝血因子合成
```

已经合成好的因子不会立即消失；这与体外通过枸橼酸 / 草酸螯合 Ca²⁺完全不同。完整出血病诊疗归血液系统。

# ③ 抗凝限域：为什么不会把全身都凝住

## KP10｜抗凝血酶与肝素：直接抑制酶，肝素负责放大

> **讲义定位 →** P102。  
> **主提示**：AT靶点；肝素来源 / 机制；TFPI释放；体内为何更强；硫酸乙酰肝素。

AT 来源于肝 / 血管内皮接口，当前 Study 主要抑制：

```text
FⅡa、FⅨa、FⅩa、FⅪa、FⅫa、PK
并弱抑制FⅦa
```

肝素来自肥大细胞、嗜碱性粒细胞：

```text
肝素 → 增强AT活性
→ 间接抑制凝血
```

Study还保留肝素促进内皮结合 TFPI 释放。体内有完整内皮 / TFPI，因此当前 Study 解释肝素体内抗凝强于体外。

正常内皮表面的硫酸乙酰肝素也可增强 AT；它与肥大细胞 / 嗜碱细胞释放的肝素不是同一表述层级。

（易混：体内 / 体外抗凝 ≠ 内源 / 外源凝血途径。）

## KP11｜PC—PS—TM：把凝血酶从促凝开关切换成抗凝开关

> **讲义定位 →** P102–103。  
> **主提示**：PC / PS / TM；完整链；灭活哪两个因子；vWF与FⅧ；PC缺陷。

```text
PC：肝合成，VitK依赖
PS：APC辅因子
TM：正常内皮表达
```

```text
凝血酶离开损伤局部
→ 与TM结合
→ 激活PC → APC
→ APC + PS
→ 灭活FⅤa / FⅧa
→ 抑制凝血酶原酶和内源性FⅩ酶复合物
→ 凝血不向正常血管扩展
```

PC系统缺陷增加静脉血栓风险；完整诊疗后置。

## KP12｜TFPI、正常内皮、血流与清除：空间限制完整闭环

> **讲义定位 →** P102–104。  
> **主提示**：TFPI负反馈；内皮抗栓物质；流动 / 吸附 / 清除；卧床为何DVT。

TFPI：

```text
外源途径启动 → 产生FⅩa
→ TFPI先结合FⅩa
→ 再抑制FⅢ–FⅦa–Ca²⁺复合物
→ 负反馈减少新FⅩa
```

正常内皮：

- 光滑屏障，隔开胶原 / TF；
- Study归纳抗栓物质：AT、硫酸乙酰肝素、TFPI、TM、PGI₂ / NO、t-PA。

其他限制：

- 凝血酶被局部纤维蛋白吸附；
- 血流稀释并带走活化因子；
- 单核—巨噬系统清除凝血因子。

```text
长期卧床 → 静脉血流慢
→ 活化因子不易稀释 / 清除
→ 局部浓度↑
→ DVT风险↑
```

# ④ 纤溶拆除：止血栓完成使命后怎样退出

## KP13｜纤溶系统：激活物、纤溶酶与纤维蛋白选择性

> **讲义定位 →** P105。  
> **主提示**：定义；纤溶酶原来源；四类激活物；t-PA纤维蛋白选择性；u-PA；FⅫa / K。

```text
已形成的纤维蛋白
→ 纤溶酶降解
→ 止血栓逐步溶解
→ 血管保持 / 恢复通畅
```

纤溶酶原主要由肝产生，以无活性酶原存在。

激活物：

```text
t-PA
u-PA / 尿激酶
激肽释放酶 K
FⅫa
```

纤维蛋白存在时，t-PA与纤溶酶原共同结合纤维蛋白表面 → 激活效率明显升高 → 纤溶更集中于血栓。rt-PA / 阿替普酶利用此特点。

u-PA按 Study 主要由肾小管 / 集合管上皮产生，不需依赖纤维蛋白结合。FⅫa / K平时贡献较小，体外循环负电表面接触时可重要。

## KP14｜纤溶刹车、FDP、D-dimer与3P试验

> **讲义定位 →** P105–106。  
> **主提示**：抑制物；纤溶酶底物；FDP；D-dimer；3P；月经血；纤溶过强 / 过弱。

纤溶抑制物：

```text
α₂-AP
PAI-1：灭活t-PA / u-PA
TAFI：凝血酶激活的纤溶抑制物
```

纤溶酶最敏感底物是纤维蛋白和纤维蛋白原，也可降解部分凝血因子。

FDP：纤维蛋白 / 纤维蛋白原降解产生，可与纤维蛋白结合、阻碍进一步交联，有抗凝接口。

D-dimer：交联纤维蛋白被降解的敏感标志；完整PE算法归呼吸。

3P：FDP与纤维蛋白单体形成可溶复合物；鱼精蛋白使单体游离并聚合沉淀，阳性提示 FDP / 纤溶亢进接口。

```text
纤溶过强 → 止血栓过早溶解 → 再出血
纤溶过弱 → 血栓不易清除 / 再通 → 栓塞风险↑
```

Study另指出子宫含较多纤溶酶原激活物，月经血不易凝固。

# ⑤ 用实验室和药物定位止血层级

## KP15｜BT、PT、APTT、TT：不是四个同义“凝血时间”

> **讲义定位 →** P106。  
> **主提示**：各自测什么；一期 / 二期；PT / APTT覆盖；TT；D-dimer位置。

| 检查 | 主要反映 |
|---|---|
| BT 出血时间 | 小血管 + 血小板一期止血 |
| PT 凝血酶原时间 | 外源 + 共同：FⅦ、Ⅹ、Ⅴ、Ⅱ、Ⅰ |
| APTT 活化部分凝血活酶时间 | 内源 + 共同：Ⅻ、Ⅺ、Ⅸ、Ⅷ、Ⅹ、Ⅴ、Ⅱ、Ⅰ |
| TT 凝血酶时间 | FⅠ纤维蛋白原转变环节 |

BT主要受血小板 / 小血管影响。PT和APTT启动不同，但都走共同途径 `Ⅹ→Ⅴ→Ⅱ→Ⅰ`。D-dimer反映纤溶，不等同 PT / APTT / TT。

## KP16｜抗板、抗凝、溶栓：阻止的不是同一层

> **讲义定位 →** P107。  
> **主提示**：三类概念；Study代表；华法林 / 肝素 / 枸橼酸身份；溶栓直接靶点。

**抗血小板**：减少血小板活化 / 聚集。

| 药物 | 靶点 |
|---|---|
| 阿司匹林 / 吲哚布芬 | COX-1→TXA₂↓ |
| 氯吡格雷 / 替格瑞洛 | ADP受体 |
| 阿昔单抗 / 替罗非班 | GPIIb/IIIa |

**抗凝**：减少凝血酶 / 纤维蛋白生成，不直接溶解已有血栓。

- 肝素：增强 AT 为主，TFPI接口；
- 华法林：拮抗VitK，抑Ⅱ/Ⅶ/Ⅸ/Ⅹ新合成；
- 枸橼酸 / 草酸：体外螯合Ca²⁺。

**溶栓**：激活纤溶酶原，直接拆除已经形成的纤维蛋白；代表 t-PA / 阿替普酶、尿激酶。

```text
抗板：不让血小板栓继续形成 / 放大
抗凝：不让纤维蛋白继续生成
溶栓：拆除已形成纤维蛋白
```

# ⑥ 放回循环疾病和 P0 病理链

## KP17｜动脉 vs 静脉血栓：是“突出不同”，不是绝对二分

> **讲义定位 →** P106–107；**讲义回看 →** P0。  
> **主提示**：动脉高剪切为何血小板突出；静脉淤滞为何凝血 / 纤维蛋白突出；CHD / DVT / PE方向；STEMI / NSTEMI接口。

动脉：

```text
高流速 / 高剪切
→ 血小板黏附 / 聚集作用突出
→ 白色血栓成分偏血小板
→ 冠心病抗栓方向突出抗血小板
```

静脉：

```text
血流慢 / 淤滞
→ 活化凝血因子易积聚
→ 纤维蛋白网和RBC成分突出
→ DVT / PE方向突出抗凝
```

> **边界**：这是相对优势模型，不是“动脉只有血小板、静脉只有凝血”。两类血栓都可同时包含血小板、纤维蛋白和血细胞。

按当前 Study：STEMI在相应条件下可考虑溶栓；NSTEMI不按同一路径溶栓。完整 ACS 时间窗 / 禁忌归 B6。

其他接口：长期卧床→DVT；肝硬化→因子合成少；温盐水纱布＝压迫 + 粗糙表面 + 温度；大量库存血的低Ca / 低温 / 高K / 枸橼酸代碱接口归血液。

## KP18｜Virchow—血栓—栓子—栓塞—梗死—修复

> **讲义回看 →** P0 U017、U015。  
> **主提示**：正常止血 vs 病理血栓；Virchow；术语严格区分；栓塞为何不必然梗死；血栓结局。

```text
正常止血
= 损伤局部 + 有限时间 + 限制系统
→ 完成封口后拆除

病理血栓
= 完整血管 / 错误地点
+ 内皮损伤、血流异常或高凝
→ 凝血持续或过度
```

Virchow 三要素：内皮损伤、血流异常（淤滞 / 湍流）、高凝。

```text
血栓：活体心血管内形成的固体质块
栓子：进入血流、随血流运行的异常物质
栓塞：栓子阻塞血管的过程 / 结果
梗死：血流中断造成局灶缺血性坏死
```

栓塞不必然梗死，还取决于阻塞程度 / 时间、侧支、组织耐缺血和局部氧供。

血栓结局：溶解、机化、再通、钙化、脱落。若梗死：坏死 → 炎症清除 → 再生或纤维性修复。
