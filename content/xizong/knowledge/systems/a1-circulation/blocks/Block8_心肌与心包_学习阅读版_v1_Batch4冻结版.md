# Block 8｜心肌与心包
## 症状来自泵弱、泵硬、动态堵，还是包住泵的外壳｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：面对呼吸困难、水肿、胸痛、低输出或杂音，怎样先分清收缩性下降、顺应性下降、动态流出道梗阻还是心包外部限制，再用结构和功能证据定位病因与处理方向？

# 先用四个故障层定位

B8 不要先从 HCM / DCM / RCM / 心包炎四篇病名开始背。先问“泵哪里坏了”：

```text
泵弱｜收缩性↓
→ 挤不出去
→ ESV↑、EF↓
→ DCM等

泵硬｜顺应性↓ / 舒张异常
→ 装不进去
→ 充盈压↑
→ HCM、RCM等

动态堵｜LVOT随负荷 / 收缩状态改变
→ 腔越空、收缩越强，出口越堵
→ 梗阻性 HCM

外壳限制｜心包压力↑或心包纤维化
→ 从外面限制舒张
→ 心包积液 / 压塞 / 缩窄
```

> **HCM 不是“泵硬”和“动态堵”二选一。** 同一个 HCM 患者可以同时有 `顺应性下降 / 舒张充盈障碍 + SAM / LVOT 动态梗阻`。这两条链共同解释呼吸困难、胸痛、晕厥和杂音。

统一观察六个变量：

```text
心室大小
+ 壁厚
+ 室壁运动
+ EF
+ 充盈压 / 心房大小
+ 病变在心肌还是心包
```

# 总 Framework

```text
① 先定故障层
   泵弱 / 泵硬 / 动态堵 / 外壳限制
   [KP01–KP02]
        ↓
② HCM：硬 + 可动态堵
   非对称肥厚 → 舒张障碍
   + SAM / LVOT → 晕厥 / 猝死
   [KP03–KP08]
        ↓
③ DCM：大 + 弱
   收缩性↓ → 多腔扩大
   → HFrEF / 血栓 / 节律
   [KP09–KP14]
        ↓
④ RCM / 特殊心肌病
   心肌 / 心内膜硬 → 充盈受限
   → 与缩窄作“内衣 vs 外套”鉴别
   [KP15–KP18]
        ↓
⑤ 心肌炎
   炎症同时破坏电与泵
   [KP19–KP23]
        ↓
⑥ 心包
   炎症 → 积液 → 压塞
   或机化 → 缩窄
   [KP24–KP33]
        ↓
⑦ 最终定位
   心肌本体 vs 心包外壳
   → 证据 / 危险门槛
   [KP34]
```

# Part A｜共同坐标

## KP01｜第一问不是“什么病”，而是“哪里坏了”

> **主提示**：收缩性、顺应性、动态梗阻、外部压力 / 缩窄分别意味着什么。

```text
收缩性↓ → 排空失败 → DCM
顺应性↓ → 充盈失败 → HCM / RCM
动态LVOT梗阻 → SAM / 梗阻性HCM
心包内压↑ / 心包变硬 → 积液 / 压塞 / 缩窄
```

（易混：EF正常 / 升高不能排除严重舒张性心衰；心界不大也不能排除 RCM / 缩窄。）

---

## KP02｜六个观察量：大小、厚薄、运动、EF、充盈压、病变位置

> **主提示**：比较 DCM / HCM / RCM / 心包病先看什么。

| 观察量 | 解决的问题 |
|---|---|
| 心室大小 | 扩张、正常还是偏小 |
| 壁厚 | 薄、对称肥厚、非对称肥厚 |
| 室壁运动 | 弥漫减弱、节段减弱或正常 |
| EF | 收缩功能是否下降 |
| 充盈压 / 心房大小 | 舒张受限程度 |
| 病变位置 | 心肌 / 心内膜还是心包外壳 |

---

# Part B｜HCM：厚、硬，并且可能动态堵

## KP03｜HCM病理身份：遗传、非对称肥厚与排列紊乱

> **讲义定位 →** 病理 P49–50、内科 P294–295。  
> **主提示**：遗传方式、主要结构、室间隔、心房、主要功能障碍。

当前 Study：常显遗传；肌球蛋白等编码基因异常；心肌细胞排列紊乱 / 漩涡样；心室非对称肥厚，尤其室间隔；室间隔 / LV游离壁比值 >1.3接口；LV腔变小。心房不是原发肥厚，但可因高充盈压扩大。

> **首要机械身份**：顺应性下降 / 舒张功能障碍。若同时存在SAM / LVOT，则再叠加动态梗阻。

---

## KP04｜SAM 与动态梗阻：为什么收缩越强，出口反而越堵

> **主提示**：高速血流、局部低压、二尖瓣前叶前移、恶性循环。

```text
室间隔明显肥厚
→ LVOT变窄
→ 收缩期高速射流
→ 局部压强下降
→ 二尖瓣前叶向前移动 SAM
→ 与室间隔接触
→ LVOT进一步狭窄
+ 可出现MR
```

这是**动态**梗阻，不是主动脉瓣固定狭窄。

---

## KP05｜HCM症状：舒张失败 + 缺血 + 动态低输出

> **主提示**：呼吸困难、胸痛、运动低血压 / 晕厥、猝死。

```text
顺应性↓ → LVEDP↑ → LA压↑ → 肺静脉压↑ → 劳力性呼吸困难

肥厚耗氧↑ + 毛细血管相对不足
+ LVEDP高 / LVOT阻塞影响冠灌注
→ 胸痛

运动HR↑ → 舒张期↓、充盈↓
+ 动态梗阻↑
→ SV / CO↓ → 低血压 / 晕厥

排列紊乱 / 纤维化
→ 室性心律失常 → 猝死
```

---

## KP06｜HCM杂音反事实：回心少、收缩强，杂音更响

> **主提示**：什么增强 / 减弱；为什么与AS不同。

胸骨左缘3–4肋间收缩期喷射样；可伴MR杂音；通常不按AS方式向颈传。

增强：站立、Valsalva、硝酸酯、大量利尿等前负荷↓；强心等收缩性↑ → LV更空 / 射流更快 → 梗阻↑。

减弱：β阻断、非DHP-CCB、卧位 / 蹲位 → HR / 收缩力↓或回心↑ → 腔变大、梗阻↓。

---

## KP07｜HCM证据层：超声看结构 / 梗阻，CMR看组织与风险

> **主提示**：首选 / 金标准、非对称肥厚、SAM、LVOT、舒张、LGE。

当前 Study：超声首选和金标准接口；看非对称室间隔肥厚、比值、SAM、LVOT梗阻、LV腔小、LA扩大、E/A / E/e′。CMR看结构和延迟强化；广泛 LGE进入猝死风险接口。精确阈值归 MI-D。

---

## KP08｜HCM治疗：不能机械套“所有心衰都减负荷”

> **主提示**：首选、替代、禁用 / 慎用、结构治疗、猝死。

当前 Study：β阻断首选；非DHP-CCB替代；丙吡胺 / 西苯唑啉接口；玛伐凯泰接口。避免正性肌力、强扩血管、大量利尿、DHP-CCB等可能使腔更空 / 梗阻更重的措施。结构治疗有室间隔切除 / 酒精消融接口；猝死高危用 ICD。

高危：骤停 / 室速史、晕厥、早发家族史、明显壁厚、LVEF下降、广泛LGE等；数字归MI-D。

---

# Part C｜DCM：大、弱，有血但射不出

## KP09｜DCM病因与病理

> **讲义定位 →** 病理 P50、内科 P295–298。  
> **主提示**：遗传、病毒 / 免疫、酒精 / 药物；心腔、室壁、心内膜。

病因接口：遗传、病毒直接损伤 / 免疫、酒精、蒽环类等。

```text
LV最早最显著扩大
→ 后期多腔扩大
→ 室壁多变薄，也可正常 / 略厚
→ 心尖钝圆、心内膜增厚
→ 附壁血栓 / 纤维化
→ 心肌细胞变性、坏死、瘢痕
```

---

## KP10｜DCM机械电影：腔越大不等于泵越强

> **主提示**：收缩性、ESV、EF、扩张、相对MR/TR、室壁运动。

```text
心肌损害 → 收缩性↓
→ ESV↑、EF↓
→ 扩张尝试维持SV
→ 超出Frank–Starling有效范围
→ 室壁弥漫减弱
→ 多腔扩大
→ 瓣环撑大 → 相对MR / TR
```

冠心病多节段性室壁运动减弱；DCM典型为弥漫减弱。

---

## KP11｜DCM临床：先左衰，后来“呼吸好转”可能更重

> **主提示**：起病、心界、杂音、左衰→全心衰。

起病隐匿；心界常向两侧扩大；左心衰或全心衰；LV大→功能性MR，RV大→TR。

```text
左心衰 → 肺淤血 / 肺水肿
→ 肺循环压力↑ → RV负荷↑
→ 右心衰 / 全心衰
→ RV射入肺循环减少
→ 肺淤血症状可相对减轻
```

这不代表好转。

---

## KP12｜DCM证据：超声、ECG、核素、BNP各看什么

> **主提示**：首选 / 金标准、心腔 / 室壁、病理Q、BNP局限。

当前 Study超声首选 / 金标准接口：LV舒张末内径↑、LVEF≤40%、多腔扩大、弥漫室壁减弱、MR / TR。ECG可病理Q、ST-T和节律异常；核素可摄取异常；BNP可因牵张升高但不特异。

---

## KP13｜DCM治疗：不是“泵弱就只强心”

> **主提示**：总体归属、β阻断、快房颤接口。

总体同慢性心衰，完整方案归B11。β阻断为重要 / 首选接口；当前讲义用抗β1受体抗体持续激动 / 受体脱敏解释。合并快房颤可用强心苷抑AV结。

长期目标还要减少神经体液过度激活和重构。

---

## KP14｜DCM三类危险：心衰、血栓、心律失常 / 猝死

> **主提示**：附壁血栓、ICD接口、与HCM共同点。

```text
腔大 + 淤滞 + 心内膜改变 → 附壁血栓 → 栓塞
心肌损伤 / 纤维化 → 电不稳定 → 房颤 / 室性节律 → 猝死
收缩性↓ → HFrEF
```

ICD接口：骤停史、持续室速、LVEF / NYHA门槛、高危基因等；数字归MI-D。

---

# Part D｜RCM 与特殊心肌病

## KP15｜RCM：心室像穿了紧内衣

> **主提示**：病变位置、心室、心房、功能、病因、超声。

```text
心内膜 / 心内膜下心肌纤维化或浸润
→ 心室不易扩张
→ 舒张充盈受限
→ 充盈压↑
→ 双房显著扩大
→ 体 / 肺静脉淤血
```

病因接口：淀粉样变、贮积病、心内膜弹力纤维增生、高嗜酸、放射 / 蒽环等。心室腔不一定大；淀粉样可弥漫增厚 / 毛玻璃样接口。

---

## KP16｜RCM vs 缩窄：同是“装不进去”，一个内衣紧，一个外套紧

> **主提示**：共同点、病变位置、心界、奇脉 / 叩击音 / 室间隔。

共同：舒张充盈受限、高静脉压 / JVD、体循环回流障碍、心界不大或稍大。

| 维度 | RCM | 缩窄性心包炎 |
|---|---|---|
| 位置 | 心内膜 / 心肌，“内衣紧” | 心包增厚 / 钙化，“外套紧” |
| 心房 | 双房大突出 | 可扩大 |
| 室间隔 | 被心肌病限制 | 可有呼吸相关抖动 |
| 奇脉 | 当前Study组织为无 | 可有 |
| 特征 | 浸润 / 双房大 | 心包叩击音、负性心尖搏动等 |

> 这组鉴别保留为 B8 最后的定位锚，不需要扩写成第二套心衰课。

---

## KP17｜致心律失常性右室心肌病

> **主提示**：纤维脂肪替代、RV、功能 / 节律后果。

```text
RV心肌 → 脂肪 / 纤维脂肪替代
→ RV扩大
→ 收缩 / 传导底物异常
→ 右心衰 + 室性心律失常
```

完整节律归B10。

---

## KP18｜克山病与其它心肌病：先按结构身份归类

> **主提示**：缺硒、心腔 / 室壁 / 心形、像哪型。

克山病：缺硒；双侧心腔大、室壁薄、球形心、心尖较重，可水肿 / 空泡脂肪变 / 坏死 / 瘢痕；表型类似 DCM。可有相对房室瓣关闭不全、心衰、附壁血栓 / 栓塞、猝死。

---

# Part E｜心肌炎：炎症同时破坏电与泵

## KP19｜心肌炎病理分类

> **讲义定位 →** 病理 P51–53。  
> **主提示**：病毒、细菌、Fiedler、免疫；主要细胞 / 组织层。

病毒性：心肌细胞损伤 + 间质病变，以间质淋巴 / 单核浸润为主，可纤维化。细菌性：多发小脓肿，中性粒为主。Fiedler / 特发性巨细胞性可肉芽肿；免疫反应性亦可。当前Study肉芽肿性例子包括特发性巨细胞、免疫反应、风湿性心肌炎。

---

## KP20｜病毒性心肌炎入口：1–3周前驱感染 + 心率不相称

> **讲义定位 →** 内科 P297–298。  
> **主提示**：前驱、心悸 / 节律、左衰、严重表现。

```text
1–3周前感染
→ 心悸 / 心率与体温不相称 / 节律异常 / 胸痛
→ 左心功能不全：呼吸困难、湿啰音、S1低、奔马律、相对MR
→ 严重：休克、钟摆律、猝死
```

当前Study最常柯萨奇B，另有埃可、腺、流感等。

---

## KP21｜心肌炎证据：损伤标志物 ≠ 组织学证明

> **主提示**：活检、CMR、cTn / CK-MB、ECG、BNP。

当前Study：心内膜心肌活检金标准；CMR重要；cTn / CK-MB可升；ECG可ST-T、病理Q、节律异常；BNP因牵张升高，不足以区分心肌炎和DCM。

---

## KP22｜心肌炎 vs MI vs DCM vs 心包炎

> **主提示**：病程、前驱、室壁运动、摩擦音、坏死证据。

```text
心肌炎 → 前驱感染 + 急性弥漫损伤 / 节律 / 左衰
MI → 冠脉缺血背景 + 节段壁运动 + ACS ECG / 坏死证据
DCM → 慢性隐匿 + 多腔大 + 弥漫收缩弱
心包炎 → 体位 / 呼吸相关锐痛 + 摩擦音 + 弥漫ST
```

病理Q波并非 MI 独有。

---

## KP23｜心肌炎转归：炎症怎样走向纤维化、心衰与猝死

> **主提示**：损伤 / 坏死→纤维修复；泵 / 电后果。

```text
炎症 → 心肌损伤 / 坏死 → 纤维性修复
→ 心肌纤维化
→ 收缩性下降 / DCM表型
+ 传导 / 复极不均 → 心律失常
→ 可心衰、休克、猝死
```

---

# Part F｜心包：外壳从炎症走向积液、压塞或缩窄

## KP24｜心包正常作用与急性心包炎病因

> **讲义定位 →** 内科 P299–304。  
> **主提示**：脏 / 壁层、液体、作用、病因。

心包：脏层 + 壁层，少量浆膜液润滑；固定 / 保护 / 减摩擦并限制急性过度扩张。急性病因包括病毒最常见、细菌、尿毒症、结缔组织病、肿瘤、MI后等；无明确病因称特发 / 急性非特异性。

---

## KP25｜纤维蛋白性心包炎：胸痛和摩擦音来自同一摩擦

> **主提示**：摩擦音、体位 / 屏气；胸痛性质 / 放射。

摩擦音：最有价值体征；粗糙搔抓高频，可双 / 三相，与心搏一致，屏气仍有；坐位前倾、左3–4肋最明显。胸膜摩擦音随呼吸，屏气消失。

胸痛：胸骨后 / 心前区锐痛，可放射颈、肩臂、背 / 上腹；深呼吸、咳嗽、吞咽、体位变化加重；NSAIDs接口。

---

## KP26｜急性心包炎 ECG vs STEMI：弥漫 vs 冠脉分布

> **主提示**：ST方向、aVR / V1、积液低电压 / 电交替。

当前Study：心包炎除aVR / V1可压低外，多导联弥漫性ST弓背向下抬高；STEMI按冠脉 / 心壁分布，常弓背向上。积液可QRS低电压、电交替、窦速。

---

## KP27｜摩擦音消失不一定好转：积液把脏壁层分开

> **主提示**：纤维素期→积液期；症状重心。

```text
早期纤维素 → 胸痛 + 摩擦音
液体增多 → 脏壁层分开
→ 摩擦音 / 胸痛可减轻
→ 呼吸困难突出、心界向两侧扩大
```

---

## KP28｜心包积液何时成为压塞：量不是唯一变量

> **主提示**：速度、右心低压腔、CVP、SV / CO、BP。

```text
液体快速或足量增加
→ 心包内压↑
→ RA / RV舒张先受压
→ 回心梯度↓ → CVP↑
→ 心室充盈↓ → SV / CO↓
→ BP / PP↓ → 阻塞性休克
```

少量快速积血可比大量慢性积液更危险；心影大小不能单独判断严重度。

---

## KP29｜压塞体征：Beck、奇脉、Ewart、Kussmaul

> **主提示**：四个体征分别指向什么。

Beck：低动脉压 + 静脉压 / JVD高 + 心音遥远。

奇脉：吸气回右心↑，但心包限制使RV扩张挤向LV → LV充盈 / SV进一步↓ → 吸气脉搏显著弱 / 消失。

Ewart：大量积液压肺 → 左肩胛下浊音、语颤增强、异常支气管呼吸音。

Kussmaul征：吸气时JVD更明显，可见于缩窄等充盈受限；不等于代酸的Kussmaul呼吸。

---

## KP30｜积液证据与穿刺：诊断、病因、治疗是三个问题

> **主提示**：超声、X线、ECG、穿刺；主动脉夹层禁忌。

```text
超声 → 首选；液体 / 游泳心 / RA-RV塌陷 / 室间隔摆动
X线 → 烧瓶心 / 两侧大，肺野可清；少量可阴性
ECG → 低电压 / 电交替 / 窦速
心包穿刺 → 明确性质 / 病因，当前Study金标准；压塞时可减压
```

主动脉夹层可破入心包；穿刺降低压力可能促进继续出血，当前Study列绝对禁忌。

---

## KP31｜心包炎病因模式：发热、胸痛、摩擦、积液量、细胞一起看

> **主提示**：急非特、结核、肿瘤、化脓、心脏损伤后。

一般：摩擦 / 胸痛越明显时积液往往较少。

- 急非特：1–3周前驱，急，痛 / 摩擦明显，少量草黄 / 血性，淋巴细胞；
- 结核：缓、低热，干性摩擦或湿性积液多，血性，淋巴；
- 肿瘤：缓、无 / 低热，积液多、血性、摩擦少；
- 化脓：感染灶、高热、中性粒；
- 心脏损伤后：手术 / MI史，可发热胸痛，摩擦未必明显。

血性积液当前Study重点：结核、肿瘤、急非特。

## KP32｜心包积液 vs DCM：都可心界向两侧大

> **主提示**：心尖、肺、杂音、奇脉。

| 维度 | 心包积液 | DCM |
|---|---|---|
| 首故障 | 外部限制充盈 | 收缩性↓ |
| 心尖 | 不易触 / 在心界内侧；心界可随体位变 | 与扩大心界较一致 |
| 主诉 | 回流受阻突出 | 左衰 / 全心衰 |
| 肺 | 可较清 | 左衰时肺湿 |
| 奇脉 | 可有 | 通常无 |
| 杂音 | 可低级功能性 | 相对MR / TR常见 |

## KP33｜RCM vs 缩窄 vs 心包积液：内衣 / 外套 / 液体

> **主提示**：共同回流受阻；先看心界，再看病变位置。

共同：JVD、体循环回流障碍、舒张充盈受限。

```text
心界明显向两侧大 → 优先积液
心界不大 / 稍大 → RCM或缩窄
```

```text
RCM：心肌 / 心内膜硬 → 双房大，当前Study无奇脉
缩窄：心包纤维化 / 钙化 → 可奇脉 / 叩击音 / 负性心尖 / 室间隔抖动
积液：液体 → 烧瓶心 / 游泳心 / 低电压 / 电交替
```

# Part G｜最终定位

## KP34｜最终算法：先判泵弱、泵硬、动态堵，还是外壳限制

> **主提示**：面对“呼吸困难 + 心界 / 静脉压 / 杂音 / ECG”一步定位。

```text
1. 病程
   急性前驱感染？慢性隐匿？家族 / 青年运动猝死？结核 / 肿瘤 / 手术 / MI？

2. 看心室
   大 + 弥漫弱 + EF低 → DCM
   厚 + 非对称 + 舒张受限 ± SAM → HCM
   心室不大 + 双房大 + 充盈受限 → RCM
   急性炎症 / 损伤证据 → 心肌炎

3. 看外壳
   摩擦音 / 弥漫ST → 急性心包炎
   心影两侧大 + 液体 → 积液
   CVP↑ + BP↓ + 奇脉 / 塌陷 → 压塞
   心包增厚 / 钙化 + 叩击音 → 缩窄

4. 看证据
   超声：结构 / EF / 充盈 / 液体
   CMR：心肌病 / 心肌炎组织接口
   活检：心肌炎金标准
   X线 / ECG：辅助

5. 判危险
   室性节律 / 猝死
   急性左衰
   压塞 / 休克
```

向后：器质性 / 纤维化节律底物→B10；收缩 / 舒张心衰→B11；压塞 / 低输出 / 骤停→B12。

右室后负荷只保留接口：`PVR↑ → RV后负荷↑ → 慢性先肥厚后扩张；急性可直接扩张并减少LV充盈`。完整肺高压 / 肺心病 / PE归呼吸。
