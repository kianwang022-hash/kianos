# Block 8｜心肌与心包
## 症状来自泵弱、泵硬、动态堵，还是包住泵的外壳｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：面对呼吸困难、水肿、胸痛、低输出或杂音，怎样先分清收缩性下降、顺应性下降、动态流出道梗阻还是心包外部限制，再用结构和功能证据定位病因与处理方向？

# 先用四个故障层定位

先在脑中放一颗正在工作的心脏：舒张时接血，收缩时把血送出去。现在患者喘、水肿或输出不足，我们先看这两件事卡在哪里，再给疾病命名。

肌肉收缩无力，血就排不干净，收缩末剩得多，心腔可扩大；肌肉变硬，则要用更高压力才能充盈，压力又传向上游。它们都能造成症状，却分别是“挤不出去”和“装不进去”。心室的射血比例正常，不能替代这一步判断。

HCM把第三种故障带进来：心肌可以既厚又硬，瓣叶与流出道的动态关系还会让出口随负荷变窄，所以腔更空或收缩更强时，输出反而可能更差。再把视线移到心包：外壳里液体积得太快，或外壳纤维化变紧，也会从外面限制充盈；压塞时上游静脉压可高，而前向输出低。炎症、损伤和修复还会同时影响泵功能与电活动。

这就是全块的四故障层。先把这段机制讲清，再沿下面同一模型把正式标题〔完整 Prompt〕和对应Core填回自然位置；收束仍压回这四层。

```text
泵弱｜收缩性↓
→ 挤不出去
→ ESV↑、EF↓
→ DCM等

泵硬｜顺应性↓ / 舒张异常
→ 装不进去
→ 充盈压↑
→ HCM、RCM等

动态堵｜LVOT随负荷 / 收缩状态改变
→ 腔越空、收缩越强，出口越堵
→ 梗阻性 HCM

外壳限制｜心包压力↑或心包纤维化
→ 从外面限制舒张
→ 心包积液 / 压塞 / 缩窄
```

> **HCM 不是“泵硬”和“动态堵”二选一。** 同一个 HCM 患者可以同时有 `顺应性下降 / 舒张充盈障碍 + SAM / LVOT 动态梗阻`。这两条链共同解释呼吸困难、胸痛、晕厥和杂音。

统一观察六个变量：

```text
心室大小
+ 壁厚
+ 室壁运动
+ EF
+ 充盈压 / 心房大小
+ 病变在心肌还是心包
```

# Part B｜HCM：厚、硬，并且可能动态堵

## KP03｜HCM病理身份：遗传、非对称肥厚与排列紊乱

> **讲义定位 →** 病理 PDF P49–50（印刷P47–48）；内科印刷P293–294｜PDF P359–360。  
> **主提示**：遗传/蛋白｜排列/肥厚分布｜室间隔比值｜LVvs心房｜功能2轴

当前 Study：常显遗传；肌球蛋白等编码基因异常；心肌细胞排列紊乱 / 漩涡样；心室非对称肥厚，尤其室间隔；室间隔 / LV游离壁比值 >1.3接口；LV腔变小。心房不是原发肥厚，但可因高充盈压扩大。

> **首要机械身份**：顺应性下降 / 舒张功能障碍。若同时存在SAM / LVOT，则再叠加动态梗阻。

---

## KP04｜SAM 与动态梗阻：为什么收缩越强，出口反而越堵

> **主提示**：SAM结构｜几何/血流作用｜动态反馈｜MR

```text
室间隔肥厚 + 二尖瓣装置几何/位置改变
→ 瓣叶进入流出血流的作用范围
→ 血流拖曳/推动瓣叶向室间隔移动（SAM）
→ 瓣叶—室间隔接近或接触
→ LVOT进一步变窄、梗阻加重
+ 瓣叶对合受影响，可出现MR
```

这是**动态**梗阻，不是主动脉瓣固定狭窄。

课程以“高速→局部压低→吸引”解释；这不足以作为SAM的唯一启动机制。患者研究观察到SAM可在正常流速甚至射血前开始，瓣叶几何及血流拖曳需纳入；不因此否认局部压差的存在。

## KP05｜HCM症状：舒张失败 + 缺血 + 动态低输出

> **主提示**：症状4路：呼吸困难/胸痛/低压晕厥/猝死→机制

```text
顺应性↓ → LVEDP↑ → LA压↑ → 肺静脉压↑ → 劳力性呼吸困难

肥厚耗氧↑ + 毛细血管相对不足
+ LVEDP高 / LVOT阻塞影响冠灌注
→ 胸痛

运动HR↑ → 舒张期↓、充盈↓
+ 动态梗阻↑
→ SV / CO↓ → 低血压 / 晕厥

排列紊乱 / 纤维化
→ 室性心律失常 → 猝死
```

## KP06｜HCM杂音：负荷改变的反事实

> **主提示**：杂音部位/传导｜负荷2轴｜增强/减弱场景｜HCMvsAS

胸骨左缘3–4肋间收缩期喷射样；可伴MR杂音；通常不按AS方式向颈传。

增强：站立、Valsalva、硝酸酯、大量利尿等前负荷↓；强心等收缩性↑ → LV更空 / 射流更快 → 梗阻↑。

减弱：β阻断、非DHP-CCB、卧位 / 蹲位 → HR / 收缩力↓或回心↑ → 腔变大、梗阻↓。

## KP07｜HCM证据层：超声看结构 / 梗阻，CMR看组织与风险

> **主提示**：超声地位｜结构/比值/SAM/LVOT/舒张｜CMR-LGE风险

当前 Study：超声首选和金标准接口；看非对称室间隔肥厚、比值、SAM、LVOT梗阻、LV腔小、LA扩大、E/A / E/e′。CMR看结构和延迟强化；广泛 LGE进入猝死风险接口。精确阈值归 MI-D。

## KP08｜HCM治疗：不能机械套“所有心衰都减负荷”

> **主提示**：Study药物首选/替代/新增接口｜慎禁→梗阻变量｜结构治疗2路｜ICD风险轴

本段治疗针对有症状的梗阻性HCM：课程β阻断首选，现行指南强调非血管扩张性β阻断剂；非DHP-CCB为替代，丙吡胺 / 西苯唑啉为课程接口。玛伐凯泰是心肌肌球蛋白抑制剂，减少过多的肌动–肌球蛋白横桥与过度收缩；课程列LVEF<55%不适合，不能把它当作泵弱时的强心药。

避免正性肌力、强扩血管、大量利尿、DHP-CCB等可能使腔更空 / 梗阻更重的措施；有淤血时的小剂量谨慎利尿不等于一律禁用，也不能把梗阻性HCM的限制套给全部非梗阻患者。结构治疗有室间隔切除 / 酒精消融接口；猝死高危评估ICD。

课程猝死风险八项：心尖室壁瘤、晕厥、持续性VT伴血流动力学不稳或反复NSVT、早发猝死家族史、心脏骤停史、LVEF<50%、广泛LGE（≥15%左室质量）、最大左室壁厚≥30mm。原文持续室速旁写SVT易误读，室速应记VT，不能与室上速混淆；风险因素不等于每项单独触发同一个ICD指征。

# Part C｜DCM：大、弱，有血但射不出

## KP09｜DCM病因与病理

> **讲义定位 →** 病理 PDF P50（印刷P48）；内科印刷P294–297｜PDF P360–363。  
> **主提示**：病因4组｜扩大先后｜室壁/心尖/心内膜/血栓｜细胞损伤修复

病因接口：遗传、病毒直接损伤 / 免疫、酒精、药物毒性（如蒽环类、锂制剂）。这些不同上游汇入心肌损伤，不是依次发生的四步。

```text
时间 / 心腔：LV最早最显著扩大 → 后期可多腔扩大
同一损伤构型的并行所见：
├─ 室壁多变薄，也可正常 / 略厚；心尖钝圆
├─ 心内膜增厚，可有附壁血栓 / 纤维化
└─ 心肌细胞变性、坏死、瘢痕；残存细胞可代偿性肥大
```

DCM也可见肥大细胞；与HCM遗传性非对称肥厚/排列紊乱的来源和整体构型不同，不能用“见到肥大细胞”一项把两者对调。原图对照：病理原版印刷P48/物理P50。

```text
DCM：细胞损伤 → 扩张、泵弱 ± 残存细胞代偿肥大
```

## KP10｜DCM机械电影：腔越大不等于泵越强

> **主提示**：收缩性/ESV/EF/心腔｜弥漫vs节段｜瓣环/MR/TR

```text
心肌损害 → 收缩性↓
→ ESV↑、EF↓
→ 扩张尝试维持SV
→ 超出Frank–Starling有效范围
→ 室壁弥漫减弱
→ 多腔扩大
→ 瓣环撑大 → 相对MR / TR
```

冠心病多节段性室壁运动减弱；DCM典型为弥漫减弱。

## KP11｜DCM临床：先左衰，后来“呼吸好转”可能更重

> **主提示**：起病/心界/杂音｜左衰/右衰/全心衰｜肺症状变化判读

起病隐匿；心界常向两侧扩大；左心衰或全心衰；LV大→功能性MR，RV大→TR。

```text
左心衰 → 肺淤血 / 肺水肿
→ 肺循环压力↑ → RV负荷↑
→ 右心衰 / 全心衰
→ RV射入肺循环减少
→ 肺淤血症状可相对减轻
```

这不代表好转。

## KP12｜DCM证据：超声、ECG、核素、BNP各看什么

> **主提示**：超声地位/结构功能｜ECG病理Q/ST-T/节律｜核素｜BNP非特异

当前 Study超声首选 / 金标准接口：LV舒张末内径↑、多腔扩大、弥漫室壁减弱、MR / TR。讲义LVEF≤40%是在说明合并HFrEF，不能反推为全部DCM的唯一诊断门槛；诊断还要判断心室扩张、收缩障碍及能否由异常负荷/冠脉病充分解释。ECG可病理Q、ST-T和节律异常；核素可摄取异常；BNP可因牵张升高但不特异。

## KP13｜DCM治疗：不是“泵弱就只强心”

> **主提示**：治疗归属｜β阻断免疫接口｜快房颤接口｜长期重构目标

总体同慢性心衰，完整方案归B11。β阻断为重要 / 首选接口；当前讲义用抗β1受体抗体持续激动 / 受体脱敏解释。合并快房颤可用强心苷抑AV结。

长期目标还要减少神经体液过度激活和重构。

## KP14｜DCM三类危险：心衰、血栓、心律失常 / 猝死

> **主提示**：危险3路｜附壁血栓链｜电不稳定链｜ICD指征轴｜HCM共同点

```text
腔大 + 淤滞 + 心内膜改变 → 附壁血栓 → 栓塞
心肌损伤 / 纤维化 → 电不稳定 → 房颤 / 室性节律 → 猝死
收缩性↓ → HFrEF
```

原讲义将HCM与DCM的共同表现列为房颤等心律失常，并列猝死、附壁血栓脱落后的栓塞、病理Q波/ST段压低/T波倒置；超声心动图作首选与金标准课程接口。精确回看内科原版印刷P295/物理P361的“肥心病和扩心病均可”注意栏。HCM猝死的室性快速节律机制另回KP05；不补造共同室早或“最常见节律”排序。

ICD接口按原课程分组回看，不把它们当成一个无条件阈值：
- 已有严重事件：心脏骤停史；持续性室速伴或不伴晕厥史。
- 低EF与功能 / 预期生存组合：LVEF≤35%、NYHAⅡ–Ⅲ级、预期生存期≥1年。
- 遗传高危：课程列LMNA、EMD、TMEM43、DSP、RBM20、PLN、FLNC截短变异等；即使LVEF>35%仍可考虑ICD一级预防，尤其另有室速、明显LGE。

这是内科印刷P295｜PDF P361原有ICD精确接口，不新增独立Memory准入，也不代替B10完整器械指征或现行临床决策。

# Part E｜心肌炎：炎症同时破坏电与泵

## KP19｜心肌炎病理分类

> **讲义定位 →** 病理 PDF P51–53（印刷P49–51）。  
> **主提示**：心肌炎4组｜细胞/组织层｜损伤与修复｜肉芽肿课程归类

# Part F｜心包：外壳从炎症走向积液、压塞或缩窄

## KP24｜心包正常作用与急性心包炎病因

> **讲义定位 →** 内科印刷P298–303｜PDF P365–370。  
> **主提示**：心包2层/液体｜功能｜急性病因6组｜特发定义

心包：脏层 + 壁层，少量浆膜液润滑；固定 / 保护 / 减摩擦并限制急性过度扩张。急性病因包括病毒最常见、细菌、尿毒症、结缔组织病、肿瘤、MI后等；无明确病因称特发 / 急性非特异性。

## KP25｜纤维蛋白性心包炎：胸痛和摩擦音来自同一摩擦

> **主提示**：摩擦音：性质/时相/屏气/体位/部位｜胸痛：性质/放射/诱发｜vs胸膜摩擦

摩擦音：最有价值体征；粗糙搔抓高频，可双 / 三相，与心搏一致，屏气仍有；坐位前倾、左3–4肋最明显。胸膜摩擦音随呼吸，屏气消失。

胸痛：胸骨后 / 心前区锐痛，可放射颈、肩臂、背 / 上腹；深呼吸、咳嗽、吞咽、体位变化加重；NSAIDs接口。

## KP26｜急性心包炎 ECG vs STEMI：弥漫 vs 冠脉分布

> **主提示**：心包炎vsSTEMI：分布/形态｜aVR/V1｜积液3个ECG表现

当前Study：心包炎除aVR / V1可压低外，多导联弥漫性ST弓背向下抬高；STEMI按冠脉 / 心壁分布，常弓背向上。积液可QRS低电压、电交替、窦速。

## KP27｜摩擦音消失不一定好转：积液把脏壁层分开

> **主提示**：纤维素/积液｜脏壁关系｜痛/摩擦变化｜呼吸困难/心界｜转归判读

```text
早期纤维素 → 胸痛 + 摩擦音
液体增多 → 脏壁层分开
→ 摩擦音 / 胸痛可减轻
→ 呼吸困难突出、心界向两侧扩大
```

---

## KP28｜心包积液何时成为压塞：量不是唯一变量

> **主提示**：量/速度｜心包压｜受压先后｜CVP-SV-CO-BP-PP｜小量快vs大量慢

```text
液体快速或足量增加
→ 心包内压↑
→ RA / RV舒张先受压
→ 回心梯度↓ → CVP↑
→ 心室充盈↓ → SV / CO↓
→ BP / PP↓ → 阻塞性休克
```

少量快速积血可比大量慢性积液更危险；心影大小不能单独判断严重度。

## KP29｜压塞体征：Beck、奇脉、Ewart、Kussmaul

> **主提示**：Beck3联｜奇脉机制｜Ewart3征｜Kussmaul征vs呼吸

Beck：低动脉压 + 静脉压 / JVD高 + 心音遥远。

奇脉：吸气回右心↑，但心包限制使RV扩张挤向LV → LV充盈 / SV进一步↓ → 吸气脉搏显著弱 / 消失。

Ewart：大量积液压肺 → 左肩胛下浊音、语颤增强、异常支气管呼吸音。

Kussmaul征：吸气时颈静脉压不降或反升，可见于缩窄等充盈受限；不等于代酸的Kussmaul呼吸。课程把它列在积液/压塞体征串联中，但单纯压塞通常不呈典型Kussmaul征；合并该征应考虑缩窄成分等，不能与Beck三联征捆成压塞必备表现。

## KP31｜心包炎病因模式：发热、胸痛、摩擦、积液量、细胞一起看

> **主提示**：病因5型×起病/发热/痛摩擦/液量性质/细胞｜血性3重点

先把“摩擦是否明显”与“两层是否被液体分开”放在一起，再沿同一组轴比较病因。以下是内科印刷P300｜PDF P367原有矩阵；“未列”表示该表未提供，不能当作阴性结果。

| 病因 | 病史 / 起病 | 发热 | 胸痛 / 摩擦音 | 积液量 | 液体性质 / 细胞 |
|---|---|---|---|---|---|
| 急性非特异性 | 1–3周前驱感染；急 | 明显 | 两者明显 | 少量 | 草黄色或血性；淋巴细胞 |
| 结核性 | 可伴原发结核灶；缓 | 低热多见 | 干性两者明显；湿性胸痛常无、摩擦不明显 | 干性少量、湿性大量 | 血性；淋巴细胞 |
| 肿瘤性 | 转移性肿瘤多见；缓 | 无或低热 | 胸痛常无、摩擦不明显 | 大量 | 血性；淋巴细胞 |
| 化脓性 | 伴原发感染灶；急 | 高热多见 | 表中未列 | 表中未列 | 中性粒细胞；颜色表中未列 |
| 心脏损伤后综合征 | 手术 / MI史 | 常有 | 胸痛常有、摩擦不明显 | 表中未列 | 淋巴细胞；颜色表中未列 |

分组恢复：急非特与干性结核偏“少液、痛 / 摩擦明显”；湿性结核与肿瘤偏“多液、痛 / 摩擦不明显”；损伤后是“可痛而摩擦不明显”的例外。细胞另比较：化脓性以中性粒，其余本表列淋巴。血性三重点仍为结核、肿瘤、急非特，原助记“血淋淋”只帮助记住这三型的血性 / 淋巴组合，不能凭颜色独断病因。

# Part G｜最终定位

## KP34｜最终算法：先判泵弱、泵硬、动态堵，还是外壳限制

> **主提示**：病程｜心室vs心包｜证据4类｜危险3组｜后续接口

```text
1. 病程
   急性前驱感染？慢性隐匿？家族 / 青年运动猝死？结核 / 肿瘤 / 手术 / MI？

2. 看心室
   大 + 弥漫弱 + EF低 → DCM
   厚 + 非对称 + 舒张受限 ± SAM → HCM
   心室不大 + 双房大 + 充盈受限 → RCM
   急性炎症 / 损伤证据 → 心肌炎

3. 看外壳
   摩擦音 / 弥漫ST → 急性心包炎
   心影两侧大 + 液体 → 积液
   CVP↑ + BP↓ + 奇脉 / 塌陷 → 压塞
   心包增厚 / 钙化 + 叩击音 → 缩窄

4. 看证据
   超声：结构 / EF / 充盈 / 液体
   CMR：心肌病 / 心肌炎组织接口
   活检：心肌炎金标准
   X线 / ECG：辅助

5. 判危险
   室性节律 / 猝死
   急性左衰
   压塞 / 休克
```

向后：器质性 / 纤维化节律底物→B10；收缩 / 舒张心衰→B11；压塞 / 低输出 / 骤停→B12。

右室后负荷只保留接口：`PVR↑ → RV后负荷↑ → 慢性先肥厚后扩张；急性可直接扩张并减少LV充盈`。完整肺高压 / 肺心病 / PE归呼吸。
