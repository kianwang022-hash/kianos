# Block 7｜风湿、感染性心内膜炎与四瓣膜病
## 先学“四扇门”，再看风湿 / IE 怎样把门破坏｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：瓣膜狭窄或反流怎样通过异常血流改变心腔压力和容量负荷，进而形成杂音、心腔重构、淤血与低输出；风湿和感染性心内膜炎又怎样把瓣膜推向这些故障？

# 先建立瓣膜开闭与四种故障的统一模型

B1 提供心动周期、压差、前向输出与心腔顺应性，B4 提供血栓 / 栓塞。B7 把这些变量放到瓣膜：**先看哪一处、哪一时相发生异常血流，再推压力或容量负荷；风湿与 IE 从上游解释结构为什么损坏。** 本块 MS、MR、AS、AR 是二尖瓣和主动脉瓣的四种典型故障。

# 总 Framework

```text
结构上游（并行）
风湿：链球菌相关交叉免疫 → 反复炎症 / 修复 → 瓣叶、交界、腱索变形
IE：内膜损伤 + 菌血症 → 含菌赘生物 → 瓣膜破坏
    └─ 还可脱落栓塞、形成免疫复合物损害，不都经过瓣膜血流后果
其他瓣叶 / 瓣环 / 腱索 / 乳头肌 / LV几何或主动脉根部异常
                         ↓
                 开放受阻或关闭失败

MS：舒张LA→LV受阻
    ├─ LA压↑ → 肺静脉淤血 / 肺高压 → RV负荷↑
    └─ LV充盈↓ → LV正常 / 小，前向输出受限
MR：收缩LV→LA反流，下次舒张反流血又回LV
    → LA + LV容量负荷↑，有效前向SV↓
AS：收缩LV→Ao受阻 → LV压力负荷↑ → 向心肥厚
    → 顺应性↓ / 耗氧↑ / 冠灌注受限，可心绞痛、晕厥或心衰
AR：舒张Ao→LV反流
    ├─ 主动脉舒张压↓ → 冠灌注受限
    └─ LV容量负荷↑ → 慢性扩张 / 总SV可↑ → 脉压可增宽

时间约束：慢性反流可扩张代偿；急性重度MR / AR来不及适应，
          腔未明显扩大也可压力骤升、肺水肿 / 低输出。
观察：杂音看异常血流，超声看门 / 流 / 腔，培养看病原；各有证明边界。
治疗：干预淤血 / 低输出，同时按病因与结构条件修门、控制感染。
```

# 同一模型上的自然节点〔完整 Prompt〕

四种故障共用位置—时相—血流—负荷坐标，彼此不是病程的连续阶段。病因、血流后果、观察与治疗相互对应；隐藏知识标注后仍可沿同一模型推导。

```text
先把门放回心动周期
房室瓣舒张应开、收缩应关；半月瓣收缩应开、舒张应关
二尖瓣装置的瓣叶 / 瓣环 / 腱索 / 乳头肌 + LV几何，共同决定关闭
〈先定位故障部件：瓣膜病是“门”的问题〔二尖瓣装置4部件＋LV几何｜上游/下游｜入题4问｜杂音≠病名〕〉
瓣口在应开放时受阻 → 为保持同流量需更高跨瓣压差 → 上游承压
应关闭时仍漏血 → 逆向反流 → 接收腔 / 泵出腔容量负荷，前向量受损
〈狭窄 vs 关闭不全：压力负荷和容量负荷的共同模型〔狭窄vs反流｜压力/容量链｜MSvsAS上游腔｜MRvsAR受累腔〕〉
将位置与时相代入，可同时得到MS / MR / AS / AR四条分支
〈四瓣膜一张坐标〔四瓣膜：时相→方向→负荷→首要心腔〕〉

门为什么损坏：两种病因并行，另保留各结构自己的病因
├─ 风湿：链球菌相关交叉免疫 → 自身组织免疫损伤
│    〈风湿病：链球菌感染后的交叉免疫〔病原/抗原｜交叉免疫链｜风湿vsIE｜赘生物含菌性〕〉
│    组织演变：变质渗出 → Aschoff肉芽肿阶段 → 纤维化
│    〈Aschoff 小体三阶段〔Aschoff演变3期｜各期组织变化｜风湿细胞来源/形态｜肉芽肿vs机化〕〉
│    ├─ 心内膜 / 瓣膜反复炎症、机化 → 粘连 / 缩短 / 变形
│    │    → 开放受阻或反流；闭锁缘赘生物通常无菌、牢固
│    │    〈风湿性心内膜炎怎样形成慢性瓣膜病〔最常瓣膜｜赘生物：位置/形态/成分/含菌/脱落｜McCallum｜反复→瓣膜病〕〉
│    ├─ 心肌间质瘢痕可影响传导；心包渗出、机化可影响充盈
│    │    〈风湿性全心炎：心肌和心包〔心肌间质/Aschoff位置→传导｜心包渗出2型→结局｜缩窄链〕〉
│    └─ 关节 / 皮肤 / 小血管等心外表现提供免疫背景线索
│         〈风湿病心外身份〔风湿vsRA比较6轴｜皮肤2征性质｜动脉炎｜小舞蹈病〕〉
│
└─ IE：病原经血行或直接途径感染心内膜；毒力与原瓣膜底物影响病程
     〈IE定义、分类与病原身份〔IE定义｜自体vs人工瓣｜急vs亚急：毒力/底物｜右心背景〕〉
     异常射流损伤内膜 → 血小板 / 纤维蛋白底物
     + 菌血症 → 病原种植 → 含菌赘生物
     〈IE形成链：内膜损伤 + 菌血症〔内膜损伤＋菌血症→赘生物｜射流危险背景｜异常血流下游｜非典型入口〕〉
     强毒力病原也可侵正常瓣；急 / 亚急两类均可含菌
     〈急性 IE vs 亚急性 IE〔急性vs亚急性IE：病原/瓣膜/赘生物/破坏/栓塞/免疫6轴〕〉
         ├─ 瓣叶穿孔 / 腱索断裂等破坏 → 反流 → 下方压容后果
         ├─ 赘生物脱落 → 左心至体循环，右心至肺循环
         └─ 免疫复合物 → GN等多器官损害
     〈IE周围体征、栓塞与免疫损害〔Janeway/Osler/Roth：位置/痛性/形态｜左右栓塞｜肾梗死vsGN｜最常并发症〕〉
     发热观察菌血症，杂音变化观察门损坏，多器官表现观察后两路
     〈IE三大临床轴：发热、杂音、多系统损害〔临床3轴｜怀疑组合｜杂音变化｜全身体征〕〉
     病原 ← 规范血培养；赘生物 / 瓣周破坏 ← 超声 / TEE
     〈IE证据：血培养与超声各证明什么〔血培养vs超声：证明对象/Study地位｜采血时机｜TEE优势｜赘生物下游3处｜免疫学〕〉
     抗感染回作用于病原；严重反流心衰、未控感染或栓塞危险需外科评估
     〈IE治疗：抗感染与外科各解决什么〔抗感染原则6｜自体vs人工瓣疗程｜外科危险门槛〕〉
     控制病原不能替代修复已穿孔的瓣膜，单项检查也不独立证实全部IE。

在同一瓣膜病因位置比较赘生物：风湿、IE、Libman–Sacks
用含菌性、位置、形态、脱落与后果区分；不串成一种病的三个阶段
〈三类赘生物：风湿、IE、Libman–Sacks〔赘生物3类：含菌/位置/形态/脱落/后果〕〉

四条异常血流分支

MS｜二尖瓣舒张开放受阻
〈MS：左房压力↑，左室反而没变大〔LA/LV血流｜LV充盈/大小｜LA/肺/RV压力链〕〉
├─ LA压↑ / LA扩大 → 肺静脉 / 毛细血管压↑
│    → 呼吸困难 / 肺水肿；长期肺高压 → RV负荷↑ / 晚期右衰
│    LA扩大还可产生压迫；咯血按相应出血来源辨别
│    〈MS症状：肺静脉高压怎样造成呼吸困难 / 咯血 / 压迫〔呼吸困难进展｜咯血4型｜压迫2处｜二尖瓣面容〕〉
└─ LV充盈↓ → LV正常 / 偏小，有效输出受限
瓣口面积↓，同流量所需压差↑ → 用面积、跨瓣压差和肺压共同评估
〈MS严重度：瓣口面积、跨瓣压差和肺压是一组变量〔Study面积：正常＋3级｜同流量条件｜面积/压差/肺压联动〕〉
跨瓣血流 + 弹性 / 心律 → S1、开瓣音、舒张隆隆声的相应表现
〈MS听诊：S1、开瓣音、舒张中晚期隆隆样〔S1/开瓣音条件｜S2-OS间隔｜杂音特征/增强｜房颤变化｜Graham–Steell〕〉
超声确认门 / 压差 / 心腔 / 血栓；结构条件决定开放或置换路径
〈MS证据与治疗门槛〔超声/ECG/X线→证据｜急性肺水肿｜窦律vs房颤用药｜弹性/开瓣音→术式〕〉
减轻肺淤血与按心律控制充盈负担，不能替代解除有适应证的结构阻塞。

MR｜二尖瓣收缩关闭失败
瓣叶、瓣环、腱索、乳头肌或LV几何失配 → LV→LA反流
〈MR结构入口：门、门框、腱索、乳头肌、LV都可能坏〔故障结构→病因｜急性vs慢性｜反流方向〕〉
收缩：部分总SV返回LA → 当次有效前向SV↓
舒张：肺静脉来血 + 上一搏反流血进入LV → LA / LV容量负荷↑
〈MR容量负荷与急慢性差别〔反流/充盈时序｜LA/LV容量｜急慢性压容反应〕〉
    ├─ 慢性适应 → 两腔扩张 / 离心重构，之后可失代偿
    └─ 急性重度 → LA来不及扩张 → LA压骤升 → 肺水肿 / 低输出
反流射流 → 心尖全收缩期吹风声；方向决定传导，响度不等同反流量
〈MR听诊：杂音特征与传导〔时相与形态｜部位与传导｜前/后叶差异｜强度边界〕〉
超声验证装置病变、反流、两腔与功能
〈MR证据层：先看反流，再看两腔和功能〔超声5轴：装置/结构病变｜反流方向程度｜LA/LV大小｜收缩功能｜功能vs器质〕〉
可修复性 / 急性结构破坏 → 约束修复或置换；同时支持灌注、控制肺水肿
〈MR治疗与后续并发症〔修复vs置换｜急性重度的循环＋结构处理｜房颤/心衰/低输出出口〕〉

AS｜主动脉瓣收缩开放受阻
先天瓣叶、退行钙化或风湿 → 固定出口变窄
高剪切还可使vWF高分子多聚体减少，连接初级止血 / Heyde出血接口
〈AS病因与 Heyde 综合征〔病因3类｜Heyde：剪切→vWF→止血〕〉
固定出口 → LV–Ao压差 / LV后负荷↑ → 向心性肥厚
→ 顺应性↓、LVEDP↑；耗氧↑且冠灌注受限
〈AS压力负荷电影：向心性肥厚为什么最后失败〔固定出口→压差/后负荷｜肥厚→顺应性/耗氧/冠灌注｜失代偿〕〉
    ├─ 供需失衡 → 心绞痛，即使大冠脉正常也可发生
    ├─ 运动CO增量受限 + 外周舒张 → 脑灌注↓ / 晕厥
    └─ 失代偿 → 心衰；静息晕厥另需考虑节律
〈AS三联症：心绞痛、晕厥、心衰〔三联症→机制｜正常冠脉仍痛的供需链｜运动vs静息晕厥〕〉
跨瓣喷射 → 右2肋递增—递减声向颈传；低流量重度病变也可不响
〈AS听诊：杂音特征与心音〔时相与形态｜部位与传导｜A2变化｜峰值与病变程度〕〉
固定瓣口与HCM动态LVOT梗阻同轴比较；降低前负荷的效应不能机械互套
〈AS vs HCM：固定堵 vs 动态堵〔ASvsHCM比较5轴｜前负荷↓→固定/动态差异〕〉
药物不能解除固定瓣口；依据结构与适应证评估瓣膜干预
〈AS治疗：固定结构最终要处理“门”〔Study年龄/钙化/耐受→术式｜药物局限｜固定结构目标〕〉

AR｜主动脉瓣舒张关闭失败
瓣叶损坏，或主动脉根部扩大使门框失配 → Ao→LV反流
〈AR病因：瓣叶坏了，还是根部把门框撑大〔瓣叶vs根部病因｜急性4组入口｜急慢性时间维度〕〉
    ├─ 主动脉舒张压↓ → 冠灌注受限
    └─ LV同时接收前向来血和反流血 → LV容量负荷↑
         慢性扩张 / 总SV可↑、SBP可↑，与DBP下降共同增宽脉压
〈AR容量负荷与脉压：为什么DBP显著下降〔舒张反流→DBP/冠灌注｜LV容量→重构/总SV｜SBP-DBP-PP链〕〉
反流 → 舒张递减叹气声；脉压增宽 → 相应周围血管征
〈AR听诊与周围血管征〔AR主杂音：时相/音质/传导/体位｜心音｜周围征5→共同机制〕〉
严重反流影响二尖瓣开放 / 来血 → Austin–Flint相对MS表现
总SV增多通过主动脉瓣 → 可有相对AS杂音；均不自动等于新器质性狭窄
〈Austin–Flint 与相对性主狭〔Austin–Flint形成链｜功能vs器质MS对照｜相对AS形成链〕〉
急性重度AR：LV来不及适应 → LV舒张压骤升 + 前向输出↓ → 肺水肿 / 休克
→ 同时评估IE / 夹层等病因和结构处理，不等待慢性周围征齐全
〈AR治疗与急性警报〔慢性结构治疗｜急性AR：腔/压/输出链｜IE/夹层病因警报〕〉

反流共同的时间约束
慢性容量负荷有时间扩张代偿；急性MR主要骤升LA压、急性AR主要骤升LV舒张压
→ 心腔尚未明显扩大，也可严重肺水肿 / 低输出；大总SV不保证前向Q正常
〈急性 vs 慢性重度反流：症状与心腔大小可不匹配〔急性vs慢性反流：时间→顺应性/腔大小→压力/前向输出〕〉

声音与检查回到这四条血流，而非替代它们
异常血流 ← 听诊区、收缩 / 舒张时相、呼吸变化与声音性质
〈杂音总算法：部位 → 时期 → 器质 / 功能〔听诊区5｜房室/半月瓣×狭窄/反流→时相｜器质vs功能｜呼吸影响〕〉
超声看门 / 流 / 腔 / 功能；ECG看节律与肥厚，X线看心影 / 肺淤血
血培养看病原，TEE补充小赘生物及瓣周破坏证据
〈检查证据层：结构、节律、形态、病原分开看〔证据5项｜超声/ECG/X线/血培养/TEE｜各自证实范围〕〉
按同一组轴比较四条分支：时相、方向、负荷、心腔、淤血、输出、声音与后果
〈四瓣膜统一比较表〔四瓣膜×9轴：时相/血流/负荷/LV/上游/输出/主杂音/额外体征/并发症〕〉

病例反推沿同一模型闭合
感染背景 + 杂音时相 / 部位 → 反查异常血流、首个承压 / 容量腔
→ 用相应证据核实；急性反流、肺水肿 / 休克、栓塞或未控感染改变优先级
〈最终病例算法〔感染背景｜杂音时相/部位｜血流/负荷/心腔｜证据｜急性反流/栓塞/感染门槛〕〉
房颤 / 血栓接B10；重构 / 淤血接B11；急性低输出接B12。
HCM本体接B8，肺高压完整模型接呼吸；不在四条分支外重画第二套模型。
```

# Part A｜四扇门的共同语言

## KP01｜先定位故障部件：瓣膜病是“门”的问题

> **讲义回看 →** B1。  
> **主提示**：二尖瓣装置4部件＋LV几何｜上游/下游｜入题4问｜杂音≠病名

二尖瓣的瓣膜装置：瓣环 / 纤维环、瓣叶、腱索、乳头肌。二尖瓣功能还依赖 LV 几何结构；任一环异常都可反流。

进入任何瓣膜题：

1. 哪个瓣膜？
2. 当前时相正常应开还是应关？
3. 打不开还是关不严？
4. 异常血流首先冲向哪里？

> 杂音只是湍流证据，不等于病名；贫血、高排量也可有功能性杂音。

## KP02｜杂音总算法：部位 → 时期 → 器质 / 功能

> **主提示**：听诊区5｜房室/半月瓣×狭窄/反流→时相｜器质vs功能｜呼吸影响

```text
心尖部 → 二尖瓣
左2肋间 → 肺动脉瓣
右2肋间 → 主动脉瓣第一听诊区
左3–4肋间 → 主动脉瓣第二听诊区 / 室间隔
左4–5肋间 → 三尖瓣
```

时相推导：

```text
房室瓣：舒张期本应开 → 狭窄为舒张期杂音
        收缩期本应关 → 关闭不全为收缩期杂音

半月瓣：收缩期本应开 → 狭窄为收缩期杂音
        舒张期本应关 → 关闭不全为舒张期杂音
```

当前 Study：多数左心杂音呼气更清楚；右心杂音多吸气增强；器质性多较粗糙 / 可震颤，功能性多较柔和、较轻。

## KP03｜狭窄 vs 关闭不全：压力负荷和容量负荷的共同模型

> **主提示**：狭窄vs反流｜压力/容量链｜MSvsAS上游腔｜MRvsAR受累腔

狭窄：

```text
瓣口面积↓
→ 正向血流受阻
→ 跨瓣压差↑
→ 上游腔压力↑
→ 上游静脉淤血
→ 下游充盈 / 输出不足
```

AS 的阻塞前泵腔是 LV → LV压力负荷 / 向心性肥厚；MS 的阻塞前是 LA → LA压力↑ / 扩大，LV反而充盈不足。

关闭不全：

```text
瓣膜关闭失败 → 反流
→ 反流接收腔容量↑
+ 泵出腔每搏总负荷↑
→ 扩张 / 离心性重构
→ 有效前向SV↓
```

MR：LA+LV容量负荷；AR：LV容量负荷并使主动脉舒张压↓。

## KP04｜急性 vs 慢性重度反流：症状与心腔大小可不匹配

> **主提示**：急性vs慢性反流：时间→顺应性/腔大小→压力/前向输出

```text
急性重度反流
→ 心腔来不及扩大 / 提高顺应性
→ 少量额外容积即使腔压快速↑
→ 肺水肿 / 低输出突出
→ 心影未必明显扩大

慢性反流
→ 长期容量负荷
→ 心腔扩张 / 离心性重构
→ 暂时维持总SV
→ 最终失代偿
```

# Part B｜风湿病：病原相关，但本质是免疫性疾病

## KP05｜风湿病：链球菌感染后的交叉免疫

> **讲义定位 →** 病理 P35–38。  
> **主提示**：病原/抗原｜交叉免疫链｜风湿vsIE｜赘生物含菌性

```text
A组β溶血性链球菌感染
→ M蛋白与人体瓣膜等组织有交叉抗原性
→ 免疫系统误伤自身组织
→ 风湿病
```

与感染相关，但本质是免疫性疾病；不是病原在瓣膜繁殖；风湿性赘生物通常不含菌。

## KP06｜Aschoff 小体三阶段

> **主提示**：Aschoff演变3期｜各期组织变化｜风湿细胞来源/形态｜肉芽肿vs机化

```text
① 变质渗出
胶原黏液样变 + 纤维素样坏死 + 渗出

② 增生 / 肉芽肿
坏死灶周围 → 风湿细胞 + T细胞 + 浆细胞
→ Aschoff小体 / 风湿肉芽肿

③ 纤维化
风湿细胞向成纤维方向转变
→ 机化 → 小瘢痕
```

风湿细胞来自增生巨噬细胞；可见枭眼 / 毛虫样核、Aschoff巨细胞。Aschoff 属肉芽肿性炎；机化 / 瘢痕属于修复。

## KP07｜风湿性心内膜炎怎样形成慢性瓣膜病

> **主提示**：最常瓣膜｜赘生物：位置/形态/成分/含菌/脱落｜McCallum｜反复→瓣膜病

当前 Study：危害最严重为风湿性心内膜炎；最常二尖瓣，其次主动脉瓣。闭锁缘形成灰白、单行串珠、疣状赘生物；以血小板等构成、属白色血栓；不含菌、附着牢、不易脱落。

```text
反复炎症
→ 机化 / 纤维化
→ 瓣叶、交界、腱索粘连 / 缩短 / 变形
→ 狭窄 / 关闭不全
```

MR反流冲击 LA 后壁可形成 McCallum 斑。

## KP08｜风湿性全心炎：心肌和心包

> **主提示**：心肌间质/Aschoff位置→传导｜心包渗出2型→结局｜缩窄链

心肌：主要在间质结缔组织，Aschoff常位于小血管旁；机化后小瘢痕 / 间质纤维化，累及传导系统可阻滞。

心包：

```text
浆液渗出 → 心包积液
纤维素渗出 → 绒毛心
大量纤维素不能吸收
→ 机化 / 纤维化 / 粘连
→ 缩窄性心包炎
```

## KP09｜风湿病心外身份

> **主提示**：风湿vsRA比较6轴｜皮肤2征性质｜动脉炎｜小舞蹈病

| 维度 | 风湿 | RA |
|---|---|---|
| 炎症性质（课程归类） | 特殊增生性肉芽肿性炎 | 慢性非特异性增生性炎 |
| 主要关节 | 大关节 | 小关节 |
| 特点 | 游走、反复 | 慢性持续 |
| 渗出 | 浆液、易吸收 | 纤维素、不易吸收 |
| 畸形 | 通常不留 | 常见 |
| 当前Study变态反应口径 | Ⅱ型 | Ⅲ型 |

环形红斑为渗出性病变，没有Aschoff小体；皮下结节为增生性病变，可见Aschoff小体，提示相应增生阶段。Aschoff小体有诊断意义，但不是风湿病所有时期、所有皮肤表现都必有。风湿性小动脉炎可纤维素样坏死，后期纤维化 / 狭窄 / 血栓。锥体外系受累可小舞蹈病。

# Part C｜感染性心内膜炎：一块赘生物为什么造成全身病

## KP10｜IE定义、分类与病原身份

> **讲义定位 →** 病理 P34；内科 P305–308。  
> **主提示**：IE定义｜自体vs人工瓣｜急vs亚急：毒力/底物｜右心背景

IE：病原体经血行或直接途径感染心瓣膜 / 心内膜 / 邻近大血管内膜，常伴含菌赘生物、结构损伤及全身炎症 / 栓塞。

- 自体瓣：二尖瓣 / 主动脉瓣常见；
- 人工瓣：原讲义具体写“经导管人工瓣膜心内膜炎”常见肠球菌、葡萄球菌；不能省掉经导管这一条件后，推广成全部人工瓣感染的固定病原排序；
- 急性：强毒力如金葡，可侵正常瓣；
- 亚急性：弱毒力如草绿色链球菌，多侵病变瓣；
- 静脉药物相关可累及右心三尖瓣。

---

## KP11｜IE形成链：内膜损伤 + 菌血症

> **主提示**：内膜损伤＋菌血症→赘生物｜射流危险背景｜异常血流下游｜非典型入口

```text
高速 / 异常湍流
→ 心内膜损伤
→ 血小板 + 纤维蛋白
→ 无菌性赘生物
        +
菌血症
→ 病原种植
→ 感染性赘生物
```

关闭不全、VSD、PDA等高压差射流易损伤内膜；赘生物多位于异常血流下游。单纯狭窄、大VSD、ASD、心衰 / 房颤并非当前Study典型入口，理解仍抓“损伤 + 菌血症”。

---

## KP12｜急性 IE vs 亚急性 IE

> **主提示**：急性vs亚急性IE：病原/瓣膜/赘生物/破坏/栓塞/免疫6轴

| 维度 | 急性 IE | 亚急性 IE |
|---|---|---|
| 病原 | 金葡等强毒力 | 草绿链等弱毒力 |
| 瓣膜 | 正常也可 | 多在病变瓣 |
| 赘生物 | 大、松软、含菌 | 息肉 / 菜花样、脆、含菌 |
| 局部 | 穿孔 / 急性破坏 | 慢性变形更常见 |
| 栓塞 | 感染性 / 败血性梗死、脓肿 | 当前病理Study按无菌性梗死组织 |
| 免疫 | 相对少 | GN、Osler等较多 |

两者赘生物都可含菌。“亚急性→无菌性梗死”是本病理课程的对照口径，不能推出亚急性IE没有感染性栓塞或脓肿；临床仍须按具体病原和栓塞部位评估。

## KP13｜IE三大临床轴：发热、杂音、多系统损害

> **主提示**：临床3轴｜怀疑组合｜杂音变化｜全身体征

```text
持续菌血症 → 发热
瓣膜基础病 / 新破坏 → 新杂音或性质改变
赘生物 + 免疫复合物 → 多器官损害
```

器质性心脏病 + 发热、新 / 变杂音，或发热 + 杂音 + 贫血 / 脾大 / 肾损害 / 栓塞都应警惕。可有贫血、脾大、杵状指、细菌性动脉瘤、瘀点、甲下线状出血。

## KP14｜IE周围体征、栓塞与免疫损害

> **主提示**：Janeway/Osler/Roth：位置/痛性/形态｜左右栓塞｜肾梗死vsGN｜最常并发症

- Janeway：掌 / 跖无痛红斑；
- Osler：指 / 趾垫痛性结节；
- Roth：视网膜中心白色卵圆出血斑。

```text
左心赘生物 → 脑最常见，也可视网膜 / 冠脉 / 肾 / 脾 / 四肢
右心赘生物 → 肺循环
```

肾：免疫复合物GN → 蛋白尿 / 镜下血尿；肾动脉栓塞 / 梗死 → 腰痛 / 可肉眼血尿。

最常见并发症为心衰，常因瓣叶穿孔 / 腱索断裂导致急性重度反流。

## KP15｜IE证据：血培养与超声各证明什么

> **主提示**：血培养vs超声：证明对象/Study地位｜采血时机｜TEE优势｜赘生物下游3处｜免疫学

当前 Study：

```text
血培养
→ 首选 + 金标准
→ 持续性菌血症，不必等发热高峰
→ 识别病原 / 指导治疗

超声
→ 赘生物 / 瓣膜破坏 / 瓣周病变
→ TEE更敏感，尤其小赘生物 / 人工瓣 / 器械
```

血培养尽量在开始抗菌治疗前规范留取，不必等热峰。课程“首选/金标准”强调病原证据；临床IE诊断仍综合微生物、影像与临床标准，血培养阴性不排除IE，阳性也不独自证明心瓣膜感染。

典型赘生物下游：主动脉瓣心室侧、二尖瓣心房侧、VSD右室侧。免疫学可高丙球、RF、循环免疫复合物。

## KP16｜IE治疗：抗感染与外科各解决什么

> **主提示**：抗感染原则6｜自体vs人工瓣疗程｜外科危险门槛

课程抗感染原则：早期、足量 / 大剂量、静脉、杀菌、联合、长疗程；自体瓣多2–6周，人工瓣多6–8周。课程列红霉素、氯霉素、磺胺、四环素不作常规主体，并列氨基糖苷联合接口。

这些是课程概括，具体方案必须按病原、药敏、瓣膜类型与肾功能选择；“联合”不能理解为所有IE均常规加氨基糖苷，也不能把课程列表扩成所有特殊病原方案的绝对禁药表。

外科门槛：严重瓣膜破坏致心衰 / 肺水肿 / 休克；未控制瓣周感染 / 脓肿 / 瘘；真菌 / 多重耐药；巨大赘生物或规范治疗后仍栓塞 / 培养阳性。精确尺寸 / 时限归 MI-D。


## KP20｜MS严重度：瓣口面积、跨瓣压差和肺压是一组变量

> **主提示**：Study面积：正常＋3级｜同流量条件｜面积/压差/肺压联动

当前Study：正常4–6 cm²；轻度>2.5；中度1.6–2.5；重度<1.6。面积越小，同流量需要更高LA–LV压差 → LA压 / 肺静脉压 / 肺动脉压越高。

原题精确表回看：内科印刷P320/物理P390；课程轻/中/重平均跨瓣压差分别<5、5–9、>9 mmHg，肺动脉压分别<30、30–50、>50 mmHg。它们是本页课程分组，不能省去流量条件，或视为与所有现代指南同一分级。

---

## KP21｜MS听诊：S1、开瓣音、舒张中晚期隆隆样

> **主提示**：S1/开瓣音条件｜S2-OS间隔｜杂音特征/增强｜房颤变化｜Graham–Steell

- S1常拍击样增强；重钙化僵硬可减弱；
- 有弹性可开瓣音；S2–开瓣音越短提示LA压越高 / 越重；
- 心尖低调舒张期隆隆样、局限不传导；窦律时可有舒张晚期（收缩前）增强，不能把整个舒张期画成单向递增；左侧卧位 / 运动增强；
- 肺高压P2亢进；
- 房颤使S1强弱不等、无有效房缩产生的S4，房缩相关的舒张晚期增强可消失；不据此宣称房颤时绝无任何收缩前振动。

Graham–Steell：严重肺高压 → 相对肺动脉瓣关闭不全 → 左2肋舒张早期递减杂音。右室扩大还可致相对三尖瓣关闭不全，在胸骨左缘4–5肋间产生收缩期杂音。

---

## KP22｜MS症状：肺静脉高压怎样造成呼吸困难 / 咯血 / 压迫

> **主提示**：呼吸困难进展｜咯血4型｜压迫2处｜二尖瓣面容

最早最常见劳力性呼吸困难 → PND / 端坐 → 可急性肺水肿。平卧回心血量增加与膈肌抬高、夜间神经和呼吸调节改变可促发呼吸困难，完整机制回B11。

原题四种咯血按来源区分：痰中带血联系肺毛细血管淤血；胶冻状暗红痰在课程联系晚期右心血栓脱落导致肺栓塞/肺梗死；粉红泡沫痰联系急性肺水肿；大咯血联系LA压力骤升后的支气管静脉破裂，不能与支扩的支气管动脉出血混为一谈。

左喉返神经受心血管结构压迫→Ortner声嘶；LA扩大也可压食管。二尖瓣面容为双颧绀红。

## KP23｜MS证据与治疗门槛

> **主提示**：超声/ECG/X线→证据｜急性肺水肿｜窦律vs房颤用药｜弹性/开瓣音→术式

超声：首选 / 金标准，看瓣叶、瓣口面积 / 压差、LA / RV、血栓；ECG看二尖瓣型P / 房颤；X线看LA扩大和肺淤血。

当前Study：急性肺水肿硝酸酯 / 呋塞米；窦律不把强心苷作主要工具，伴房颤可用其抑AV结；瓣膜有弹性 / 有开瓣音可球囊成形，其他直视分离 / 置换按Study。精确适应证归MI-D。

## KP26｜MR听诊：杂音特征与传导

> **主提示**：时相与形态｜部位与传导｜前/后叶差异｜强度边界

心尖全收缩期一贯型吹风样；前叶损害常向左腋 / 左肩胛传导，后叶可向心底；海鸥鸣 / 乐音提示腱索断裂。杂音强度与LV收缩力相关，不与反流程度严格成正比；低输出时重反流也可能不响。

## KP27｜MR证据层：先看反流，再看两腔和功能

> **主提示**：超声5轴：装置/结构病变｜反流方向程度｜LA/LV大小｜收缩功能｜功能vs器质

超声看瓣叶 / 腱索 / 乳头肌、脱垂 / 穿孔 / 断裂、反流方向 / 程度、LA/LV大小、LV收缩功能及功能性 vs 器质性。

## KP28｜MR治疗与后续并发症

> **主提示**：修复vs置换｜急性重度的循环＋结构处理｜房颤/心衰/低输出出口

当前Study：部分脱垂适合修复；不能修复 / 严重结构损害可置换；急性乳头肌 / 腱索断裂或 IE 穿孔重度MR要同时控制肺水肿 / 灌注并处理结构问题。

LA扩大→房颤 / 血栓归B10；LV失代偿→B11；急性低输出→B12。

# Part G｜主动脉瓣狭窄 AS

## KP29｜AS病因与 Heyde 综合征

> **主提示**：病因3类｜Heyde：剪切→vWF→止血

病因：先天单 / 二叶；老年退行钙化；风湿（常伴反流 / 二尖瓣病）。

```text
严重AS → 高剪切
→ vWF高分子量多聚体减少
→ 高剪切条件下血小板黏附/初级止血受损
+ 胃肠道血管发育异常
→ 胃肠道出血
```

vWF也有保护Ⅷ的作用，但不能用“Ⅷ不稳定”包办Heyde机制；原始研究中Ⅷ活性可正常。

---

## KP30｜AS压力负荷电影：向心性肥厚为什么最后失败

> **主提示**：固定出口→压差/后负荷｜肥厚→顺应性/耗氧/冠灌注｜失代偿

```text
收缩期瓣口受阻
→ LV–Ao压差↑ / LV后负荷↑
→ 向心性肥厚
→ 顺应性↓、LVEDP↑、S4
→ 耗氧↑ + 毛细血管相对不足 + 左冠灌注压↓
→ 心绞痛
→ 最终扩张 / 心衰
```

## KP31｜AS听诊：杂音特征与心音

> **主提示**：时相与形态｜部位与传导｜A2变化｜峰值与病变程度

右2肋收缩期递增—递减喷射样，向颈传；持续越长 / 峰值越晚提示越重。严重钙化的老年患者杂音可在心尖更清；合并AR时跨瓣流量增多可使AS杂音增强，低流量重度AS却可不响，不能只凭响度判严重度。A2减弱 / 延迟，可S2逆分裂；LV肥厚→抬举样心尖、S4。

---

## KP32｜AS三联症：心绞痛、晕厥、心衰

> **主提示**：三联症→机制｜正常冠脉仍痛的供需链｜运动vs静息晕厥

心绞痛：肥厚耗氧↑ + 毛细血管相对少 + LVEDP↑压低冠灌注 + 前向根部流量受限。运动时固定出口使CO不能充分增加，而外周舒张→脑灌注↓→晕厥；休息晕厥可节律异常。呼吸困难 / 心衰为进展表现。

---

## KP33｜AS vs HCM：固定堵 vs 动态堵

> **主提示**：ASvsHCM比较5轴｜前负荷↓→固定/动态差异

| 维度 | AS | HCM |
|---|---|---|
| 梗阻 | 主动脉瓣固定 | LVOT / SAM动态 |
| 肥厚 | 向心 / 对称 | 非对称室间隔 |
| 杂音 | 右2肋、向颈 | 左3–4肋、不典型向颈 |
| 前负荷↓ | 固定瓣口主导 | 梗阻加重 |
| 治疗 | 重度结构病处理瓣膜 | β阻断 / 非DHP等减动态梗阻 |

---

## KP34｜AS治疗：固定结构最终要处理“门”

> **主提示**：Study年龄/钙化/耐受→术式｜药物局限｜固定结构目标

当前Study：儿童 / 青少年非钙化先天AS可直视分离；成人瓣膜置换；老龄重度且不能耐受外科者TAVR接口。药物只能处理症状 / 合并症，不能解除固定瓣口。

# Part H｜主动脉瓣关闭不全 AR

## KP35｜AR病因：瓣叶坏了，还是根部把门框撑大

> **主提示**：瓣叶vs根部病因｜急性4组入口｜急慢性时间维度

瓣膜：IE、风湿、先天、退行钙化、黏液样变 / 脱垂。根部：Marfan、梅毒性主动脉炎、高血压、炎性脊柱关节病、主动脉夹层等。急性可IE、创伤、夹层、人工瓣问题。

---

## KP36｜AR容量负荷与脉压：为什么DBP显著下降

> **主提示**：舒张反流→DBP/冠灌注｜LV容量→重构/总SV｜SBP-DBP-PP链

```text
舒张期Ao→LV反流
→ 主动脉舒张压↓↓ → 左冠灌注压↓

LV同时收肺静脉来血 + 反流血
→ LV容量负荷↑ → 慢性扩张 / 离心重构
→ 总SV可↑、SBP可↑
→ SBP↑ + DBP↓↓ → PP增宽
```

---

## KP37｜AR听诊与周围血管征

> **主提示**：AR主杂音：时相/音质/传导/体位｜心音｜周围征5→共同机制

左3–4肋舒张期高调递减叹气样，向心尖传；坐位前倾呼气末更清。S1 / A2可减弱，容量负荷可S3。

周围征：Duroziez双重音、Traube枪击音、毛细血管搏动、水冲脉、De Musset点头；共同来自脉压显著增宽。

---

## KP38｜Austin–Flint 与相对性主狭

> **主提示**：Austin–Flint形成链｜功能vs器质MS对照｜相对AS形成链

```text
严重AR反流血
→ 影响二尖瓣开放 + 与LA来血形成涡流
→ 相对性MS
→ 心尖低调舒张期隆隆样 Austin–Flint
```

通常较柔和、无心尖震颤；LV大 / 心尖抬举、S1常减弱，房颤不如器质MS常见。

AR总搏出量↑ → 正常主动脉瓣收缩通过量↑ → 可有相对性AS收缩中期杂音。

## KP39｜AR治疗与急性警报

> **主提示**：慢性结构治疗｜急性AR：腔/压/输出链｜IE/夹层病因警报

主要结构治疗为瓣膜置换。急性重度AR因LV来不及扩张，LV舒张压骤升、前向输出↓ → 快速肺水肿 / 休克；若IE / 夹层需同时处理病因和结构灾难。
