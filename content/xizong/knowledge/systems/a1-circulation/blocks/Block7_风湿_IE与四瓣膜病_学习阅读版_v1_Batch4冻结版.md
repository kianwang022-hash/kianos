# Block 7｜风湿、感染性心内膜炎与四瓣膜病
## 先学“四扇门”，再看风湿 / IE 怎样把门破坏｜学习阅读版 v1 · Batch 4 冻结版

> **中心问题**：瓣膜狭窄或反流怎样通过异常血流改变心腔压力和容量负荷，进而形成杂音、心腔重构、淤血与低输出；风湿和感染性心内膜炎又怎样把瓣膜推向这些故障？

# 先建立四扇门的统一模型

瓣膜病不要从四篇病名开始背。先固定这条推导链：

```text
哪扇门？
→ 正常在当前时相应该开还是关？
→ 打不开（狭窄）还是关不严（反流）？
→ 异常血流从哪里到哪里？
→ 压力负荷还是容量负荷？
→ 首先改变哪个心腔？
→ 上游哪里淤血、下游哪里低输出？
→ 最后才解释杂音、心音、脉搏、超声和治疗
```

两类故障只有两个原型：

```text
门打不开｜狭窄
→ 正向血流受阻
→ 上游压力↑
→ 下游充盈 / 输出↓

门关不严｜关闭不全 / 反流
→ 血液逆向返回
→ 反流接收腔 + 泵出腔容量负荷↑
→ 有效前向SV↓
```

四瓣膜直接放回一张坐标：

| 疾病 | 异常时相 / 方向 | 首要负荷 | 主要心腔 |
|---|---|---|---|
| MS | 舒张期 LA→LV 受阻 | LA压力负荷 | LA扩大；LV正常 / 小 |
| MR | 收缩期 LV→LA 反流 | LA+LV容量负荷 | LA、LV扩张 |
| AS | 收缩期 LV→Ao 受阻 | LV压力负荷 | LV向心性肥厚 |
| AR | 舒张期 Ao→LV 反流 | LV容量负荷 | LV扩张 / 离心性重构 |

> **急慢性边界**：急性重度 MR / AR 可以肺水肿、低输出很重，却因为心腔来不及扩张而“心影并不大”；慢性反流则通过扩张 / 离心性重构暂时代偿。

风湿和 IE 只是回答“门为什么坏”：

```text
风湿
链球菌相关交叉免疫
→ 反复炎症 / 机化 / 纤维化
→ 慢性瓣膜粘连、变形

IE
心内膜损伤 + 菌血症
→ 含菌赘生物
→ 瓣膜破坏 + 栓塞 + 免疫损害
```

# 总 Framework

```text
① 四扇门共同语言
   门的位置 → 时相 → 狭窄 / 反流
   → 压力 / 容量负荷 → 急 / 慢
   [KP01–KP04]
        ↓
② 上游病因
   风湿：交叉免疫 → Aschoff → 慢性瓣膜病

   [KP05–KP17]
        ↓
③ 四瓣膜统一推导
   一张坐标先定位
   [KP18]
        ↓
④ MS / MR
   LA→LV受阻
   vs LV→LA反流
   [KP19–KP28]

⑤ AS / AR

⑥ 最终比较与病例反推

   [KP40–KP42]
```

# Part A｜四扇门的共同语言

## KP01｜先定位故障部件：瓣膜病是“门”的问题

> **讲义回看 →** B1。  
> **主提示**：瓣膜结构；上游 / 下游；进入任何题先问哪四个问题。

瓣膜结构：瓣环 / 纤维环、瓣叶、腱索、乳头肌。二尖瓣功能还依赖 LV 几何结构；任一环异常都可反流。

进入任何瓣膜题：

1. 哪个瓣膜？
2. 当前时相正常应开还是应关？
3. 打不开还是关不严？
4. 异常血流首先冲向哪里？

> 杂音只是湍流证据，不等于病名；贫血、高排量也可有功能性杂音。

---

## KP02｜杂音总算法：部位 → 时期 → 器质 / 功能

> **主提示**：五听诊区；收缩 / 舒张期如何反推；呼吸影响。

```text
心尖部 → 二尖瓣
左2肋间 → 肺动脉瓣
右2肋间 → 主动脉瓣第一听诊区
左3–4肋间 → 主动脉瓣第二听诊区 / 室间隔
左4–5肋间 → 三尖瓣
```

时相推导：

```text
房室瓣：舒张期本应开 → 狭窄为舒张期杂音
        收缩期本应关 → 关闭不全为收缩期杂音

半月瓣：收缩期本应开 → 狭窄为收缩期杂音
        舒张期本应关 → 关闭不全为舒张期杂音
```

当前 Study：多数左心杂音呼气更清楚；右心杂音多吸气增强；器质性多较粗糙 / 可震颤，功能性多较柔和、较轻。

---

## KP03｜狭窄 vs 关闭不全：压力负荷和容量负荷的共同模型

> **主提示**：狭窄为何偏压力；反流为何偏容量；MS为什么不能机械套“心室肥厚”。

狭窄：

```text
瓣口面积↓
→ 正向血流受阻
→ 跨瓣压差↑
→ 上游腔压力↑
→ 上游静脉淤血
→ 下游充盈 / 输出不足
```

AS 的阻塞前泵腔是 LV → LV压力负荷 / 向心性肥厚；MS 的阻塞前是 LA → LA压力↑ / 扩大，LV反而充盈不足。

关闭不全：

```text
瓣膜关闭失败 → 反流
→ 反流接收腔容量↑
+ 泵出腔每搏总负荷↑
→ 扩张 / 离心性重构
→ 有效前向SV↓
```

MR：LA+LV容量负荷；AR：LV容量负荷并使主动脉舒张压↓。

---

## KP04｜急性 vs 慢性重度反流：症状与心腔大小可不匹配

> **主提示**：急性 MR / AR 为什么重却未必大；慢性为什么能扩张代偿。

```text
急性重度反流
→ 心腔来不及扩大 / 提高顺应性
→ 少量额外容积即使腔压快速↑
→ 肺水肿 / 低输出突出
→ 心影未必明显扩大

慢性反流
→ 长期容量负荷
→ 心腔扩张 / 离心性重构
→ 暂时维持总SV
→ 最终失代偿
```

# Part B｜风湿病：病原相关，但本质是免疫性疾病

## KP05｜风湿病：链球菌感染后的交叉免疫

> **讲义定位 →** 病理 P35–38。  
> **主提示**：A组β溶血链球菌、M蛋白、为什么不是 IE。

```text
A组β溶血性链球菌感染
→ M蛋白与人体瓣膜等组织有交叉抗原性
→ 免疫系统误伤自身组织
→ 风湿病
```

与感染相关，但本质是免疫性疾病；不是病原在瓣膜繁殖；风湿性赘生物通常不含菌。

---

## KP06｜Aschoff 小体三阶段

> **主提示**：变质渗出、增生 / 肉芽肿、纤维化；风湿细胞来源与形态。

```text
① 变质渗出
胶原黏液样变 + 纤维素样坏死 + 渗出

② 增生 / 肉芽肿
坏死灶周围 → 风湿细胞 + T细胞 + 浆细胞
→ Aschoff小体 / 风湿肉芽肿

③ 纤维化
风湿细胞向成纤维方向转变
→ 机化 → 小瘢痕
```

风湿细胞来自增生巨噬细胞；可见枭眼 / 毛虫样核、Aschoff巨细胞。Aschoff 属肉芽肿性炎；机化 / 瘢痕属于修复。

---

## KP07｜风湿性心内膜炎怎样形成慢性瓣膜病

> **主提示**：最常瓣膜；赘生物形态 / 成分 / 脱落；McCallum；反复结局。

当前 Study：危害最严重为风湿性心内膜炎；最常二尖瓣。闭锁缘形成灰白、单行串珠、疣状赘生物；以血小板等构成、属白色血栓；不含菌、附着牢、不易脱落。

```text
反复炎症
→ 机化 / 纤维化
→ 瓣叶、交界、腱索粘连 / 缩短 / 变形
→ 狭窄 / 关闭不全
```

MR反流冲击 LA 后壁可形成 McCallum 斑。

---

## KP08｜风湿性全心炎：心肌和心包

> **主提示**：心肌间质；Aschoff位置；浆液 / 纤维素心包炎；缩窄入口。

心肌：主要在间质结缔组织，Aschoff常位于小血管旁；机化后小瘢痕 / 间质纤维化，累及传导系统可阻滞。

心包：

```text
浆液渗出 → 心包积液
纤维素渗出 → 绒毛心
大量纤维素不能吸收
→ 机化 / 纤维化 / 粘连
→ 缩窄性心包炎
```

---

## KP09｜风湿病心外身份

> **主提示**：风湿 vs RA；环形红斑 / 皮下结节；动脉炎；小舞蹈病。

| 维度 | 风湿 | RA |
|---|---|---|
| 主要关节 | 大关节 | 小关节 |
| 特点 | 游走、反复 | 慢性持续 |
| 渗出 | 浆液、易吸收 | 纤维素、不易吸收 |
| 畸形 | 通常不留 | 常见 |
| 当前Study变态反应口径 | Ⅱ型 | Ⅲ型 |

环形红斑为渗出性病变；皮下结节为增生性病变。风湿性小动脉炎可纤维素样坏死，后期纤维化 / 狭窄 / 血栓。锥体外系受累可小舞蹈病。

# Part C｜感染性心内膜炎：一块赘生物为什么造成全身病

## KP10｜IE定义、分类与病原身份

> **讲义定位 →** 病理 P34；内科 P305–308。  
> **主提示**：自体 / 人工瓣；急 / 亚急；金葡 / 草绿；右心特殊。

IE：病原体经血行或直接途径感染心瓣膜 / 心内膜 / 邻近大血管内膜，常伴含菌赘生物、结构损伤及全身炎症 / 栓塞。

- 自体瓣：二尖瓣 / 主动脉瓣常见；
- 人工瓣：当前Study强调肠球菌、葡萄球菌；
- 急性：强毒力如金葡，可侵正常瓣；
- 亚急性：弱毒力如草绿色链球菌，多侵病变瓣；
- 静脉药物相关可累及右心三尖瓣。

---

## KP11｜IE形成链：内膜损伤 + 菌血症

> **主提示**：无菌赘生物；关闭不全 / VSD / PDA为什么危险；异常血流下游。

```text
高速 / 异常湍流
→ 心内膜损伤
→ 血小板 + 纤维蛋白
→ 无菌性赘生物
        +
菌血症
→ 病原种植
→ 感染性赘生物
```

关闭不全、VSD、PDA等高压差射流易损伤内膜；赘生物多位于异常血流下游。单纯狭窄、大VSD、ASD、心衰 / 房颤并非当前Study典型入口，理解仍抓“损伤 + 菌血症”。

---

## KP12｜急性 IE vs 亚急性 IE

> **主提示**：毒力、基础瓣膜、赘生物、破坏、栓塞、免疫现象。

| 维度 | 急性 IE | 亚急性 IE |
|---|---|---|
| 病原 | 金葡等强毒力 | 草绿链等弱毒力 |
| 瓣膜 | 正常也可 | 多在病变瓣 |
| 赘生物 | 大、松软、含菌 | 息肉 / 菜花样、脆、含菌 |
| 局部 | 穿孔 / 急性破坏 | 慢性变形更常见 |
| 栓塞 | 感染性 / 败血性梗死、脓肿 | 当前病理Study按无菌性梗死组织 |
| 免疫 | 相对少 | GN、Osler等较多 |

两者赘生物都可含菌。

---

## KP13｜IE三大临床轴：发热、杂音、多系统损害

> **主提示**：最常症状；何时怀疑；杂音；贫血 / 脾大 / 杵状指。

```text
持续菌血症 → 发热
瓣膜基础病 / 新破坏 → 新杂音或性质改变
赘生物 + 免疫复合物 → 多器官损害
```

器质性心脏病 + 发热、新 / 变杂音，或发热 + 杂音 + 贫血 / 脾大 / 肾损害 / 栓塞都应警惕。可有贫血、脾大、杵状指、细菌性动脉瘤、瘀点、甲下线状出血。

---

## KP14｜IE周围体征、栓塞与免疫损害

> **主提示**：Janeway / Osler / Roth；左右心栓塞方向；肾梗死 vs GN；最常并发症。

- Janeway：掌 / 跖无痛红斑；
- Osler：指 / 趾垫痛性结节；
- Roth：视网膜中心白色卵圆出血斑。

```text
左心赘生物 → 脑最常见，也可视网膜 / 冠脉 / 肾 / 脾 / 四肢
右心赘生物 → 肺循环
```

肾：免疫复合物GN → 蛋白尿 / 镜下血尿；肾动脉栓塞 / 梗死 → 腰痛 / 可肉眼血尿。

最常见并发症为心衰，常因瓣叶穿孔 / 腱索断裂导致急性重度反流。

---

## KP15｜IE证据：血培养与超声各证明什么

> **主提示**：首选 / 金标准；TEE；赘生物位置；免疫学接口。

当前 Study：

```text
血培养
→ 首选 + 金标准
→ 持续性菌血症，不必等发热高峰
→ 识别病原 / 指导治疗

超声
→ 赘生物 / 瓣膜破坏 / 瓣周病变
→ TEE更敏感，尤其小赘生物 / 人工瓣 / 器械
```

典型赘生物下游：主动脉瓣心室侧、二尖瓣心房侧、VSD右室侧。免疫学可高丙球、RF、循环免疫复合物。

---

## KP16｜IE治疗：抗感染与外科各解决什么

> **主提示**：抗感染原则；疗程；外科危险门槛。

抗感染：早期、足量 / 大剂量、静脉、杀菌、联合、长疗程。当前Study：自体瓣多2–6周，人工瓣多6–8周；抑菌剂通常不作为主体，可联合氨基糖苷接口。

外科门槛：严重瓣膜破坏致心衰 / 肺水肿 / 休克；未控制瓣周感染 / 脓肿 / 瘘；真菌 / 多重耐药；巨大赘生物或规范治疗后仍栓塞 / 培养阳性。精确尺寸 / 时限归 MI-D。

---

## KP17｜三类赘生物：风湿、IE、Libman–Sacks

> **主提示**：含菌、位置 / 形态、脱落与后果。

| 类型 | 含菌 | 位置 / 形态 | 主要后果 |
|---|---|---|---|
| 风湿 | 否 | 闭锁缘、灰白疣状串珠 | 牢固，反复机化→瓣膜变形 |
| IE | 是 | 异常血流下游，大、脆、松软 | 易脱落、栓塞 / 感染性梗死、破坏瓣膜 |
| Libman–Sacks | 否 | 当前Study强调二尖瓣心室侧 | 白色疣状 |

# Part E｜二尖瓣狭窄 MS

## KP19｜MS：左房压力↑，左室反而没变大

> **主提示**：为什么LV正常 / 小；肺淤血→肺高压→右衰。

```text
二尖瓣舒张开放受阻
→ LA→LV充盈↓
→ LV前负荷↓，LV正常 / 小
→ LA压↑、LA扩大
→ 肺静脉 / 毛细血管压↑
→ 肺水肿 / 肺高压
→ RV负荷↑、晚期右衰
```

---

## KP20｜MS严重度：瓣口面积、跨瓣压差和肺压是一组变量

> **主提示**：当前Study面积口径；为什么越小压差越高。

当前Study：正常4–6 cm²；轻度>2.5；中度1.6–2.5；重度<1.6。面积越小，同流量需要更高LA–LV压差 → LA压 / 肺静脉压 / 肺动脉压越高。精确压差归MI-D。

---

## KP21｜MS听诊：S1、开瓣音、舒张中晚期隆隆样

> **主提示**：S1；开瓣音；杂音；房颤变化。

- S1常拍击样增强；重钙化僵硬可减弱；
- 有弹性可开瓣音；S2–开瓣音越短提示LA压越高 / 越重；
- 心尖舒张中晚期低调隆隆、递增、局限不传导；左侧卧位 / 运动增强；
- 肺高压P2亢进；
- 房颤使S1强弱不等、无S4、舒张晚期递增成分可消失。

Graham–Steell：严重肺高压 → 相对肺动脉瓣关闭不全 → 左2肋舒张早期递减杂音。

---

## KP22｜MS症状：肺静脉高压怎样造成呼吸困难 / 咯血 / 压迫

> **主提示**：最早；夜间 / 端坐；肺水肿；咯血；Ortner。

最早最常见劳力性呼吸困难 → PND / 端坐 → 可急性肺水肿。咯血可痰中带血、胶冻暗红痰、粉红泡沫痰、大咯血。LA扩大可压左喉返神经→Ortner声嘶，也可压食管；可见二尖瓣面容。

---

## KP23｜MS证据与治疗门槛

> **主提示**：超声 / ECG / X线；急性肺水肿；开瓣音与术式逻辑。

超声：首选 / 金标准，看瓣叶、瓣口面积 / 压差、LA / RV、血栓；ECG看二尖瓣型P / 房颤；X线看LA扩大和肺淤血。

当前Study：急性肺水肿硝酸酯 / 呋塞米；窦律不把强心苷作主要工具，伴房颤可用其抑AV结；瓣膜有弹性 / 有开瓣音可球囊成形，其他直视分离 / 置换按Study。精确适应证归MI-D。

# Part F｜二尖瓣关闭不全 MR

## KP24｜MR结构入口：门、门框、腱索、乳头肌、LV都可能坏

> **主提示**：常见病因；急 / 慢。

风湿、黏液样变 / 脱垂、DCM瓣环扩大、缺血性乳头肌功能不全、MI乳头肌断裂、IE穿孔 / 腱索断裂等均可使收缩期二尖瓣不能完全关闭 → LV→LA反流。

---

## KP25｜MR容量负荷与急慢性差别

> **主提示**：谁容量↑；急性为何腔不大；慢性为何扩张。

```text
收缩：一部分LV血返LA → 有效前向SV↓
舒张：肺静脉正常来血 + 反流血 → LV前负荷↑
```

慢性 → LA/LV容量负荷、LV离心扩张；急性 → LA/LV来不及扩张、LA压骤升 → 肺水肿 / 低输出重。

---

## KP26｜MR听诊：全收缩期一贯型

> **主提示**：部位、传导、前 / 后叶；强度边界。

心尖全收缩期一贯型吹风样；前叶损害常向左腋 / 左肩胛传导，后叶可向心底；海鸥鸣 / 乐音提示腱索断裂。杂音强度与LV收缩力相关，不与反流程度严格成正比；低输出时重反流也可能不响。

---

## KP27｜MR证据层：先看反流，再看两腔和功能

> **主提示**：超声解决什么。

超声看瓣叶 / 腱索 / 乳头肌、脱垂 / 穿孔 / 断裂、反流方向 / 程度、LA/LV大小、LV收缩功能及功能性 vs 器质性。

---

## KP28｜MR治疗与后续并发症

> **主提示**：修复 vs 置换；急性重度；向后路由。

当前Study：部分脱垂适合修复；不能修复 / 严重结构损害可置换；急性乳头肌 / 腱索断裂或 IE 穿孔重度MR要同时控制肺水肿 / 灌注并处理结构问题。

LA扩大→房颤 / 血栓归B10；LV失代偿→B11；急性低输出→B12。

---

# Part G｜主动脉瓣狭窄 AS

## KP29｜AS病因与 Heyde 综合征

> **主提示**：先天 / 退行 / 风湿；Heyde剪切力—vWF链。

病因：先天单 / 二叶；老年退行钙化；风湿（常伴反流 / 二尖瓣病）。

```text
严重AS → 高速射流 / 剪切
→ vWF受损 → Ⅷ稳定性受影响
+ GI血管发育异常
→ 隐匿GI出血
```

---

## KP30｜AS压力负荷电影：向心性肥厚为什么最后失败

> **主提示**：LV→Ao受阻；肥厚、顺应性、耗氧、冠脉、失代偿。

```text
收缩期瓣口受阻
→ LV–Ao压差↑ / LV后负荷↑
→ 向心性肥厚
→ 顺应性↓、LVEDP↑、S4
→ 耗氧↑ + 毛细血管相对不足 + 左冠灌注压↓
→ 心绞痛
→ 最终扩张 / 心衰
```

---

## KP31｜AS听诊：收缩期喷射递增—递减

> **主提示**：部位、传导、A2、峰值。

右2肋收缩期递增—递减喷射样，向颈传；持续越长 / 峰值越晚提示越重。A2减弱 / 延迟，可S2逆分裂；LV肥厚→抬举样心尖、S4。

---

## KP32｜AS三联症：心绞痛、晕厥、心衰

> **主提示**：为什么冠脉正常也痛；运动晕厥；休息晕厥。

心绞痛：肥厚耗氧↑ + 毛细血管相对少 + LVEDP↑压低冠灌注 + 前向根部流量受限。运动时固定出口使CO不能充分增加，而外周舒张→脑灌注↓→晕厥；休息晕厥可节律异常。呼吸困难 / 心衰为进展表现。

---

## KP33｜AS vs HCM：固定堵 vs 动态堵

> **主提示**：部位、肥厚、前负荷改变、药物方向。

| 维度 | AS | HCM |
|---|---|---|
| 梗阻 | 主动脉瓣固定 | LVOT / SAM动态 |
| 肥厚 | 向心 / 对称 | 非对称室间隔 |
| 杂音 | 右2肋、向颈 | 左3–4肋、不典型向颈 |
| 前负荷↓ | 固定瓣口主导 | 梗阻加重 |
| 治疗 | 重度结构病处理瓣膜 | β阻断 / 非DHP等减动态梗阻 |

---

## KP34｜AS治疗：固定结构最终要处理“门”

> **主提示**：儿童 / 成人 / 老龄；为什么药不能解除固定瓣口。

当前Study：儿童 / 青少年非钙化先天AS可直视分离；成人瓣膜置换；老龄重度且不能耐受外科者TAVR接口。药物只能处理症状 / 合并症，不能解除固定瓣口。

---

# Part H｜主动脉瓣关闭不全 AR

## KP35｜AR病因：瓣叶坏了，还是根部把门框撑大

> **主提示**：瓣膜本身 vs 主动脉根部；急 / 慢。

瓣膜：IE、风湿、先天、退行钙化、黏液样变 / 脱垂。根部：Marfan、梅毒性主动脉炎、高血压、炎性脊柱关节病、主动脉夹层等。急性可IE、创伤、夹层、人工瓣问题。

---

## KP36｜AR容量负荷与脉压：为什么DBP显著下降

> **主提示**：舒张反流；LV容量；冠灌注；SBP / DBP / PP。

```text
舒张期Ao→LV反流
→ 主动脉舒张压↓↓ → 左冠灌注压↓

LV同时收肺静脉来血 + 反流血
→ LV容量负荷↑ → 慢性扩张 / 离心重构
→ 总SV可↑、SBP可↑
→ SBP↑ + DBP↓↓ → PP增宽
```

---

## KP37｜AR听诊与周围血管征

> **主提示**：主杂音；心音；周围征。

左3–4肋舒张期高调递减叹气样，向心尖传；坐位前倾呼气末更清。S1 / A2可减弱，容量负荷可S3。

周围征：Duroziez双重音、Traube枪击音、毛细血管搏动、水冲脉、De Musset点头；共同来自脉压显著增宽。

---

## KP38｜Austin–Flint 与相对性主狭

> **主提示**：为什么AR可出现功能性MS样杂音；与器质MS区别；相对AS。

```text
严重AR反流血
→ 影响二尖瓣开放 + 与LA来血形成涡流
→ 相对性MS
→ 心尖低调舒张期隆隆样 Austin–Flint
```

通常较柔和、无心尖震颤；LV大 / 心尖抬举、S1常减弱，房颤不如器质MS常见。

AR总搏出量↑ → 正常主动脉瓣收缩通过量↑ → 可有相对性AS收缩中期杂音。

---

## KP39｜AR治疗与急性警报

> **主提示**：慢性结构治疗；急性为什么危险；IE / 夹层。

主要结构治疗为瓣膜置换。急性重度AR因LV来不及扩张，LV舒张压骤升、前向输出↓ → 快速肺水肿 / 休克；若IE / 夹层需同时处理病因和结构灾难。

---

## KP42｜最终病例算法

> **主提示**：杂音 / 发热 / 心衰病例如何顺序定位。

```text
1. 发热 / 菌血症背景？
2. 听诊区在哪里？
3. 收缩还是舒张？
4. 狭窄还是反流？
5. 画异常血流箭头
6. 压力还是容量负荷？首先哪个腔？
7. 上游淤血 / 下游低输出 / 房颤 / 血栓 / 缺血 / 心衰？

```
