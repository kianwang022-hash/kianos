# O16｜骨肿瘤
## 不从一个影像征猜病名：先判侵袭性，再把年龄、骨内位置、基质/骨膜反应、病理和治疗双向对应
> **中心问题**：面对骨性肿块或骨破坏，怎样依次用年龄、骨内位置、影像与基质和病变范围缩小候选，再用活检确认并决定处理方向？
>

> **FIRST PASS 固定流程**  
> `Framework → 对应外科 Lecture / 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> 本文件不是第二份肿瘤学或外科 Lecture。完整深度学习仍由 `外科学讲义_AI阅读版.md`、原 PDF 视觉层和前序肿瘤 Gate 承担；本文件负责骨肿瘤的年龄—部位—影像—病理—治疗映射、主动提取与 Coverage Routing。

# 1｜Framework｜五步缩小候选，再用活检确认

面对骨痛、肿块或病理性骨折，不先问“是不是骨肉瘤”，而按：

```text
Step 1 侵袭性
慢/快｜边界清/不清｜膨胀/浸润｜夜痛｜软组织肿块｜骨膜反应

Step 2 年龄
儿童｜青少年｜20–40岁｜中老年

Step 3 骨内位置
骨端｜干骺端｜骨干｜骨盆｜脊柱/骶尾｜手足短骨｜颅骨

Step 4 影像与基质
成骨/溶骨｜骨膜反应｜软骨钙化｜囊性/磨玻璃｜椎间隙

Step 5 证据与范围
活检确认｜胸部/全身转移评估｜MRI看脊髓/软组织
```

统一电影：

```text
异常克隆或发育异常
→ 形成特定肿瘤基质 / 破骨或成骨反应
→ 改变骨皮质、髓腔和骨膜
→ 产生疼痛、肿块、病理骨折或神经压迫
→ 影像缩小候选
→ 活检确认
→ 按生物学行为与范围治疗
```

## KP01｜良恶性入口：速度、边界、疼痛、皮质、骨膜、硬化、病折、扩散八轴
> **主提示：8轴｜良性特殊痛1｜恶性最显著症状1｜骨膜反应边界**

### Detailed Expansion

当前 Study 的总坐标：

| 轴 | 良性 | 恶性 |
|---|---|---|
| 生长 | 慢 | 快 |
| 边界 | 较清 | 不清 |
| 骨破坏 | 膨胀/外生 | 浸润性 |
| 血管怒张/皮温 | 少 | 多 |
| 疼痛 | 少；骨样骨瘤特殊明显 | 多，常夜间痛 |
| 骨皮质 | 膨胀变薄 | 被侵犯 |
| 骨膜反应 | 少 | 多 |
| 周围硬化 | 多 | 少 |
| 病理性骨折 | 少 | 多 |
| 扩散 | 无 | 以血道为主 |

重要边界：骨膜反应反映生长速度/骨膜刺激，不是恶性肿瘤专属；急性骨髓炎也可出现骨膜增生。

**Routing**：CORE + DISCRIMINATION_TREE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o16-kp02" -->
## KP02｜证据层：影像只能缩小候选，确诊金标准仍是活检
> **主提示：金标准1｜影像3任务｜病理1任务｜活检前后边界｜不要凭单征**

### Detailed Expansion

当前 Source：

- 骨肿瘤确诊金标准：**活检**；
- X线/CT/MRI用于识别位置、基质、侵袭范围和软组织/神经受累；
- ECT用于寻找代谢活跃的骨病灶，但特异性低；
- CT可用于引导活检。

正确顺序：

```text
年龄+部位+影像建立有限候选
→ 评估转移与手术范围
→ 活检确认病理身份
```

**Routing**：CORE + EVIDENCE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o16-kp03" -->
## KP03｜骨转移入口：乳腺最常见；ECT敏感但不特异，脊髓受累看MRI，最终仍需影像/活检闭环
> **主提示：原发5｜最常见1｜ECT优缺2｜脊髓1｜CT引导1｜椎旁静脉接口**

### Detailed Expansion

当前 Study 列出易骨转移的原发癌：

- 乳腺癌（最常见）；
- 前列腺癌；
- 甲状腺癌；
- 肺癌；
- 肾癌。

路径：

```text
怀疑骨转移
→ 放射性核素骨扫描/ECT（敏感高、特异低）
→ 其他影像
→ 脊髓受累用MRI
→ 必要时CT引导活检
```

不同原发肿瘤的完整诊疗仍归各器官系统。

**Routing**：CORE + CONNECTION + EVIDENCE + MI-G

<!-- kianos:kp id="orthopedics-o16-kp04" -->
## KP04｜化验方向：溶骨看血钙，成骨看ALP；前列腺成骨转移酸/碱性磷酸酶都可升
> **主提示：溶骨1｜成骨1｜骨肉瘤1｜前列腺2酶｜只是支持证据**

### Detailed Expansion

当前 Source：

- 溶骨性病变：血钙升高；
- 成骨性病变：碱性磷酸酶 ALP 升高；
- 骨肉瘤可有 ALP 升高；
- 前列腺癌成骨性骨转移：酸性磷酸酶与碱性磷酸酶均可升高。

这些只能支持“破骨/成骨活动方向”，不能取代影像和活检。

**Routing**：CORE + EVIDENCE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o16-kp05" -->
## KP05｜骨软骨瘤：青少年干骺端外生骨性突起，皮质连续、髓腔相通，骨骺闭合后多停长
> **主提示：年龄1｜部位1｜X线3｜查体vs片1｜自然史1｜治疗2**

### Detailed Expansion

当前 Study：

- 青少年；
- 长骨干骺端；
- 外生性杵/疣状骨性突起；
- 与正常骨皮质连续；
- 髓腔相通；
- 可见钙化；
- 软骨帽在X线上不显影，故查体肿块可比X线显示大；
- 骨骺线闭合后多停止生长。

多无需治疗；必要时从肿瘤基底四周部分正常骨组织开始切除。

**Routing**：CORE + RECOGNITION + VISUAL_ONLY + MI-G

<!-- kianos:kp id="orthopedics-o16-kp06" -->
## KP06｜骨软骨瘤恶变报警：闭合后再长、明显痛、软组织包块、破坏和不规则钙化
> **主提示：5报警｜为什么“再长”关键｜云雾/不规则钙化｜活检入口**

### Detailed Expansion

恶变提示：

- 明显疼痛；
- 软组织包块；
- 肿瘤再度生长；
- 骨质破坏；
- 云雾影、不规则钙化。

成年/骨骺闭合后再次生长尤其违背其正常自然史，应升级影像和病理评估。

**Routing**：SPECIAL + DANGER_GATE + MI-G

<!-- kianos:kp id="orthopedics-o16-kp07" -->
## KP07｜骨巨细胞瘤身份：20–40岁骨端、偏心膨胀肥皂泡、无骨膜反应，属于交界性行为
> **主提示：年龄1｜部位1｜X线4｜体征2｜细胞2｜性质1**

### Detailed Expansion

当前 Study：

- 20–40岁；
- 长骨骨端；
- 偏心性、膨胀性、肥皂泡样破坏；
- 无骨膜反应；
- 局部包块可有乒乓球样感、压痛；
- 单核基质细胞 + 多核巨细胞；
- 生物学行为不确定/交界性。

不能因“无骨膜反应”就简单归为普通良性瘤。

**Routing**：CORE + CONFUSABLE + VISUAL_ONLY + MI-G

<!-- kianos:kp id="orthopedics-o16-kp08" -->
## KP08｜骨巨细胞瘤治疗：早局切灭活植骨，晚根治切除；难治地舒单抗，脊柱放疗有肉瘤变风险
> **主提示：早3步｜晚1术｜脊柱困难｜放疗风险1｜单抗1｜化疗冲突**

### Detailed Expansion

当前 Source：

- 分期较早：局部切除 + 灭活 + 植骨；
- 分期较晚：根治性切除；
- 难治性：地舒单抗；
- 脊柱手术困难时可出现放疗/化疗表述，但放疗易肉瘤变；
- 同段另写化疗无效。

因此化疗角色登记 O16-SC01，不静默统一。

**Routing**：CORE + DECISION + SOURCE_CONFLICT + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o16-kp09" -->
## KP09｜骨肉瘤：青少年膝周干骺端、瘤骨/ALP、Codman三角和日光射线，手术夹在化疗之间
> **主提示：年龄1｜部位2｜成骨2｜骨膜2征｜治疗3段｜肺转移2步**

### Detailed Expansion

当前 Study：

- 最常见原发性恶性骨肿瘤；
- 青少年；
- 长骨干骺端，典型股骨下端/胫骨上端；
- 形成瘤骨，ALP升高；
- Codman三角；
- 日光射线样骨膜反应；
- 治疗：化疗 → 根治性手术 → 化疗；
- 易肺转移，术前胸部影像；可根治的肺转移灶可同时手术切除。

**Routing**：CORE + RECOGNITION + VISUAL_ONLY + DANGER_GATE + MI-G

<!-- kianos:kp id="orthopedics-o16-kp10" -->
## KP10｜尤文肉瘤：儿童骨干/骨盆/肩胛、葱皮样骨膜反应，低热WBC/ESR升高易像骨髓炎
> **主提示：别名1｜年龄1｜部位3｜骨膜1｜全身3｜治疗3｜最敏1**

### Detailed Expansion

当前 Study：

- 尤文肉瘤 / Ewing瘤 / 圆形细胞肉瘤；
- 儿童；
- 长骨骨干、骨盆、肩胛骨；
- 葱皮/板层/同心圆样骨膜反应；
- 可低热、WBC和ESR升高；
- 需与骨髓炎鉴别；
- 对放疗极敏感；
- 治疗为放疗 + 化疗 + 手术。

区分O13：骨髓炎更符合急性高热、深压痛和直接感染证据；尤文需年龄—骨干部位—侵袭影像—病理闭环。

**Routing**：CORE + CONFUSABLE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o16-kp11" -->
## KP11｜软骨源与骨瘤：手足短骨软骨瘤、骨盆软骨肉瘤、颅骨表面骨瘤；钙化提示软骨基质
> **主提示：软骨瘤部位｜软骨肉瘤部位｜钙化1｜治疗共同1｜放化敏感性｜骨瘤部位**

### Detailed Expansion

当前 Study：

- 软骨瘤：手足短管状骨；
- 软骨肉瘤：骨盆；
- 软骨来源肿瘤可有斑点状钙化；
- 软骨肉瘤对放疗、化疗不敏感，治疗以手术为主；
- 骨瘤：颅骨骨面隆起，手术。

年龄、部位和基质钙化共同缩小候选，不能只凭“有钙化”确定名称。

**Routing**：CORE + RECOGNITION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o16-kp12" -->
## KP12｜淋巴瘤与脊索瘤：融冰征对颅底/骶尾、气泡样细胞与黏液基质
> **主提示：淋巴瘤人群/征/治疗3｜脊索部位2｜症状1｜恶性特殊1｜细胞2**

### Detailed Expansion

当前 Study：

**淋巴瘤：**

- 中老年多见；
- 融冰征；
- 化疗 + 放疗，手术为辅。

**脊索瘤：**

- 颅底、骶尾椎；
- 可出现二便障碍；
- 恶性但可无骨膜反应；
- 气泡样细胞、黏液基质；
- 手术。

“无骨膜反应”不等于良性；脊索瘤是明确反例。

**Routing**：CORE + SPECIAL + RECOGNITION + MI-G/MI-D

<!-- kianos:kp id="orthopedics-o16-kp13" -->
## KP13｜骨样骨瘤：良性却夜痛明显，阿司匹林可缓解；小瘤巢周围反应性硬化
> **主提示：良性特殊痛｜时间1｜药反应1｜部位1｜X线2｜治疗2**

### Detailed Expansion

当前 Study：

- 成骨性良性肿瘤；
- 明显夜间痛；
- 阿司匹林可缓解；
- 好发下肢长骨；
- 低密度小瘤巢；
- 周围硬化反应骨；
- 手术 + NSAIDs。

它是“良性肿瘤多无痛”的重要特殊。

**Routing**：SPECIAL + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o16-kp14" -->
## KP14｜单纯性骨囊肿：儿童干骺端圆形清楚透亮灶，可观察/刮除植骨；<14岁可囊腔甲泼尼龙
> **主提示：人群1｜部位1｜X线3｜处理2｜年龄特殊1｜病折接口**

### Detailed Expansion

当前 Study：

- 儿童青少年；
- 长骨干骺端；
- 类圆形、边界清楚透亮灶；
- 可观察；
- 或刮除 + 植骨；
- <14岁可向囊腔注入甲泼尼龙。

骨皮质变薄时需识别病理性骨折风险；具体适应证按当前 Study，不外推个体治疗。

**Routing**：CORE + RECOGNITION + BOUNDARY + MI-G/MI-D

<!-- kianos:kp id="orthopedics-o16-kp15" -->
## KP15｜动脉瘤性骨囊肿：骨性间隔把囊腔分成蜂窝/泡沫，刮除植骨但要预估大出血
> **主提示：人群1｜部位1｜X线3｜手术1｜危险1｜脊柱放疗2风险**

### Detailed Expansion

当前 Study：

- 青少年；
- 长骨干骺端；
- 骨性间隔；
- 蜂窝或泡沫状囊腔；
- 刮除 + 植骨；
- 术前充分估计大量出血；
- 脊柱手术困难可出现放疗选择，但儿童有骨骺破坏和恶变风险。

与单纯骨囊肿相比，气球样膨胀、骨性间隔和出血风险更突出。

**Routing**：CORE + CONFUSABLE + DANGER_GATE + MI-G/MI-D

<!-- kianos:kp id="orthopedics-o16-kp16" -->
## KP16｜骨纤维发育不良：磨砂玻璃，股骨近端可成牧羊杖；刮除植骨，畸形可截骨
> **主提示：影像1｜部位1｜畸形1｜治疗2｜肿瘤样边界**

### Detailed Expansion

当前 Study：

- 磨砂玻璃样改变；
- 股骨近端受累可形成牧羊人手杖样畸形；
- 刮除 + 植骨；
- 明显畸形可截骨矫形。

它是肿瘤样/发育异常坐标，不能因骨变形就自动归恶性肿瘤。
