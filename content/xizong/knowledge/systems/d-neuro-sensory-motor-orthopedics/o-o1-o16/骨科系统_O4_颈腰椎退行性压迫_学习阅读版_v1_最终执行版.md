# 0｜统一模型：先问“压到谁”，不要先问“颈还是腰”

```text
椎间盘退变 / 突出
+ 椎体骨质增生
+ 韧带钙化或肥厚
+ 椎管/椎间孔空间变小
        ↓
神经根受压 → 局限放射痛、皮节/肌节/反射组合
脊髓受压   → 范围广、长束征、硬瘫、病理征、二便
马尾受压   → 鞍区/括约肌 + 下肢LMN模式
        ↓
影像确认压迫对象
→ 保守还是手术由类型、进展和红旗决定
```

> 同一个患者可以同时存在根和髓受压；此时必须分别描述局限根性体征与平面以下长束体征。

# 2｜椎间盘、神经根与疼痛

<!-- kianos:kp id="orthopedics-o04-kp01" -->

## KP01｜椎间盘三结构、钩椎关节与突出方向

> **讲义定位 →** 外科 Lecture PDF P194，书页 P158。  
> **主提示**：椎间盘3｜C1/2无｜C3–7钩｜易向侧后。

椎间盘由：

1. 软骨终板；
2. 髓核；
3. 纤维环。

颈椎 C1、C2 之间无椎间盘；C3–C7 有钩椎/Luschka 关节。椎间盘易向**侧后方**突出，因此常进入神经根和椎管相关空间。

（易混：颈椎病不只等于椎间盘突出；骨赘、韧带钙化等也可共同造成根或髓压迫。）

---

<!-- kianos:kp id="orthopedics-o04-kp02" -->

## KP02｜“m–n 椎间盘压 n 根”：先把椎间盘与神经根关系固定

> **讲义定位 →** 外科 Lecture PDF P194、P201。  
> **主提示**：m–n→n｜C5–6→C6｜L4–5→L5｜为何？

当前 Study 的定位规则：

```text
第 m–n 椎间盘突出
→ 通常压迫第 n 神经根
```

例：

- C5–C6 椎间盘 → C6 神经根；
- L4–L5 椎间盘 → L5 神经根；
- L5–S1 椎间盘 → S1 神经根。

应用时仍需由感觉、关键动作和反射验证，不能只看影像上的突出节段。

---

<!-- kianos:kp id="orthopedics-o04-kp03" -->

## KP03｜椎间盘突出致根性痛的三条机制

> **讲义定位 →** 外科 Lecture PDF P194；Outline SUR-U039。  
> **主提示**：根痛3｜机械｜化学｜自身免疫。

1. 机械性压迫；
2. 破裂椎间盘组织产生化学性刺激；
3. 髓核暴露后触发自身免疫性炎症。

因此根性痛不只是“压得越重越痛”。咳嗽、用力时椎管压力变化可加重放射痛；炎症和缺血也参与症状。

（易混：纤维环内层受髓核刺激可造成局部腰痛，但坐骨神经痛重点是神经根的机械/化学/免疫刺激。）

---

<!-- kianos:kp id="orthopedics-o04-kp04" -->

## KP04｜X线、CT、MRI：从骨性退变到根髓压迫

> **讲义定位 →** 外科 Lecture PDF P195，书页 P159。  
> **主提示**：X看5｜CT+盘｜MRI+根髓｜最值？

| 检查 | 当前 Study 可回答 |
|---|---|
| X线 | 生理曲度、骨质增生、钙化、椎间隙狭窄和间隙不等宽；不能直接看清椎间盘 |
| CT | 包含骨性信息，并可观察椎间盘；但不能清楚显示神经和脊髓受压 |
| MRI | 清楚观察椎间盘、神经根、脊髓和相关软组织受压 |

当题目问“最有价值地明确根/髓受压”，优先 MRI；X线仍是常规骨性筛查。

# 3｜颈椎病：按压迫对象分型

<!-- kianos:kp id="orthopedics-o04-kp05" -->

## KP05｜颈椎病五型总览：最常见与最严重

> **讲义定位 →** 外科 Lecture PDF P195。  
> **主提示**：5型｜根最常｜髓最重｜交感/椎A/食管各1组。

| 类型 | 主要对象/表现 |
|---|---|
| 神经根型 | 颈肩痛、上肢放射痛、麻木无力；最常见 |
| 脊髓型 | 持物不稳、踩棉花感、四肢长束征、二便；最严重 |
| 交感神经型 | 心悸、出汗或心动过缓、低血压等；症状多、体征少 |
| 椎动脉型 | 猝倒、眩晕、视物模糊 |
| 食管型 | 吞咽困难 |

颈椎病好发 C5–6，当前 Study 写女性多见。

---

<!-- kianos:kp id="orthopedics-o04-kp06" -->

## KP06｜神经根型颈椎病：局限上肢放射痛 + 根性体征

> **讲义定位 →** 外科 Lecture PDF P195–196，书页 P159–160。  
> **主提示**：症状4｜Eaton/Spurling｜首选保守｜鉴别3。

典型：

- 颈肩痛；
- 向上肢放射；
- 上肢感觉障碍/麻木；
- 上肢运动障碍/无力；
- Eaton 征、Spurling 征阳性。

治疗：当前 Study 首选保守，包括按摩、颌枕带牵引等；保守失败再进入手术方向。

主要鉴别：胸廓出口综合征、周围神经卡压综合征、肩周炎等。区别关键不是“都有肩痛”，而是是否存在根性放射、皮节/肌节和反射组合。

---

<!-- kianos:kp id="orthopedics-o04-kp07" -->

## KP07｜脊髓型颈椎病：范围广、硬瘫轴和二便红旗

> **讲义定位 →** 外科 Lecture PDF P195、P200。  
> **主提示**：4主症｜Hoffmann+Babinski｜禁2｜处理1。

表现：

- 持物不稳；
- 行走踩棉花感；
- 四肢感觉、运动障碍；
- 下肢肌张力和腱反射可增高；
- Hoffmann、Babinski 阳性；
- 可有二便障碍。

当前 Study 冻结：

- 脊髓型最严重；
- 禁止按摩、推拿和颌枕带牵引；
- 治疗偏急诊/手术方向。

（易混：上肢在受压节段可有 LMN 样反射减弱，下肢因长束受压呈 UMN 样亢进；同一患者可出现“上肢根性 + 下肢髓性”组合。）

---

<!-- kianos:kp id="orthopedics-o04-kp08" -->

## KP08｜交感、椎动脉和食管型：症状来源不同

> **讲义定位 →** 外科 Lecture PDF P195–196。  
> **主提示**：交感症多征少｜椎A猝倒眩视｜食管吞咽｜均先保守。

- 交感型：交感兴奋或抑制表现，常“症状多、体征少”；
- 椎动脉型：体位相关供血变化可出现猝倒、眩晕、视物模糊，倒地后可恢复；
- 食管型：骨赘等压迫可致吞咽困难；
- 当前 Study 对这些类型多采用保守治疗入口。

鉴别：交感/椎动脉型可与美尼尔病鉴别；美尼尔病强调反复旋转性眩晕和听力下降。

## KP09｜颈椎病体征与节段：Eaton、Spurling、Hoffmann、Babinski

> **讲义定位 →** 外科 Lecture PDF P195、P201–204。  
> **主提示**：根2征｜髓2征｜C4–8动作/感觉｜m–n→n。

- Eaton、Spurling：神经根型入口；
- Hoffmann、Babinski：脊髓长束受压入口。

节段判断必须合并：

```text
感觉区
+ 关键动作
+ 深反射
+ 影像节段
```

Current Study 常用：C5 肩外展、C6 屈肘/桡骨膜反射与拇指侧、C7 伸肘/中指、C8 屈指/尺侧手。完整原图必须回 Study。

<!-- kianos:kp id="orthopedics-o04-kp10" -->

## KP10｜颈椎病主要鉴别：根、髓与非脊柱疾病

> **讲义定位 →** 外科 Lecture PDF P196。  
> **主提示**：根鉴3｜髓鉴2｜交/椎鉴1｜感觉分离？

| 当前类型 | 主要鉴别 |
|---|---|
| 神经根型 | 胸廓出口、周围神经卡压、肩周炎 |
| 脊髓型 | 脊髓空洞症、肌萎缩侧索硬化 |
| 交感/椎动脉型 | 美尼尔病等 |

脊髓空洞症当前 Study 识别：痛温觉受损，而触觉及深感觉相对存在，形成感觉分离。与急性颈髓中央管周围综合征“无感觉分离”的 Source 口径区分。

# 4｜腰椎间盘突出：类型、根性定位与红旗

<!-- kianos:kp id="orthopedics-o04-kp11" -->

## KP11｜腰椎间盘突出六型：纤维环、后纵韧带和髓核位置

> **讲义定位 →** 外科 Lecture PDF P196，书页 P160。  
> **主提示**：6型｜膨—突—脱—游｜Schmorl｜经骨｜2层屏障。

| 类型 | 当前 Study 定义 |
|---|---|
| 膨出型 | 纤维环部分破裂，表层仍完整 |
| 突出型 | 纤维环完全破裂，髓核突向椎管，后纵韧带完整 |
| 脱出型 | 髓核突破后纵韧带，根部仍在椎间隙 |
| 游离型 | 髓核与原椎间盘完全脱离 |
| Schmorl 结节 | 髓核经软骨终板裂隙突入椎体 |
| 经骨突出型 | 髓核沿软骨终板与椎体间血管通道向前纵韧带方向突出 |

（易混：类型命名围绕“纤维环—后纵韧带—是否游离—向椎体内/前方”的空间关系，必须回原图。）

<!-- kianos:kp id="orthopedics-o04-kp12" -->

## KP12｜腰突临床主链：腰痛 + 坐骨神经痛 + 前屈受限 + 侧凸

> **讲义定位 →** 外科 Lecture PDF P196–197。  
> **主提示**：4表现｜腰痛神经1｜腿痛神经1｜内奸外患。

- 腰痛：Study 归于窦椎神经接口；
- 下肢放射痛：坐骨神经/神经根路径；
- 腰部活动受限，尤其前屈；
- 可出现腰椎侧凸。

髓核与神经根位置：

- 髓核在根内侧 → 腰椎凸向健侧、弯向患侧；
- 髓核在根外侧 → 腰椎凸向患侧、弯向健侧。

咳嗽、用力排便增加压力，可使放射痛加重。

## KP13｜L4、L5、S1：动作—感觉—反射三联

> **讲义定位 →** 外科 Lecture PDF P197，书页 P161。  
> **主提示**：L4伸膝+膝反｜L5伸踝/足｜S1屈踝/足+踝反｜感觉3区。

| 根 | 对应周围神经接口 | 运动 | 感觉 | 深反射 |
|---|---|---|---|---|
| L4 | 股神经 | 伸膝 | 膝前、小腿前内、内踝 | 膝反射 |
| L5 | 腓总神经接口 | 伸踝、伸足 | 小腿前外、足背内侧 | Study未给稳定单一深反射 |
| S1 | 胫神经接口 | 屈踝、屈足 | 小腿后、足外、外踝 | 踝/跟腱反射 |

（易混：这里是“神经根—代表周围神经动作”的考试映射，不等于整条周围神经损伤只影响一个根；O5 会建立完整周围神经层级。）

## KP14｜直腿抬高与加强：+/+、+/-、-/- 三种模式

> **讲义定位 →** 外科 Lecture PDF P197。  
> **主提示**：+/+根压｜+/-腰扭/梨状｜-/-6类。

- **直腿抬高(+) + 加强(+)**：突出型、脱出型、游离型，提示神经根受压；
- **直腿抬高(+) + 加强(-)**：急性腰扭伤、梨状肌综合征；
- **两者均(-)**：膨出型、Schmorl结节、经骨突出型、慢性腰肌劳损、第三腰椎横突综合征、腰椎管狭窄等。

（易混：单一阳性试验不是诊断终点；必须与放射痛、动作、感觉、反射和 MRI 合并。）

## KP15｜腰突治疗分流：无根压、根压、马尾红旗

> **讲义定位 →** 外科 Lecture PDF P197。  
> **主提示**：3层｜无根压保守｜有根压先保守→无效手术｜二便急诊。

- 膨出型、Schmorl结节、经骨突出型：Study 归为无神经根受压，保守治疗；
- 突出型、脱出型、游离型：有根压，先保守；无效进入手术；
- 出现二便障碍，提示马尾受压 → 急诊手术方向；
- 仅有鞍区感觉异常而没有括约肌障碍，当前 Study 写“不一定立即手术”。

```text
SOURCE_BOUNDARY
以上按当前外科学 Study 冻结；不使用外部指南静默升级手术指征。
```

## KP16｜腰椎管狭窄：症状多、体征少 + 神经源性间歇跛行

> **讲义定位 →** 外科 Lecture PDF P197–200。  
> **主提示**：2特征｜症多征少｜神经源跛行｜与腰突/血管比。

腰椎管狭窄最有区分力的模式：

- 症状较多，阳性体征相对少；
- 神经源性间歇性跛行。

与腰椎间盘突出比较：腰突更强调明确根性放射痛、直腿抬高及 L4/L5/S1 组合。与血管源性跛行比较，后者归周围动脉疾病，需结合脉搏、皮温和血管证据。

# 5｜把 N11 Recall 落到 O4

## KP17｜硬瘫与软瘫：颈髓、腰根和周围神经怎样分层

> **讲义回看 →** N11；外科串·脊髓神经损伤平面。  
> **主提示**：硬vs软10轴｜广/局｜肌电｜反射｜病理征。

| 轴 | 硬瘫/痉挛性 | 软瘫/弛缓性 |
|---|---|---|
| 部位 | UMN及其纤维 | LMN及其纤维 |
| 范围 | 广泛 | 局限 |
| 肌张力 | 增高 | 降低 |
| 腱反射 | 亢进 | 减弱 |
| 病理征 | 阳性 | 阴性 |
| 肌萎缩 | 不明显 | 明显 |
| 肌电 | 可正常 | 异常 |

应用：

- 脊髓型颈椎病 → 下肢硬瘫/长束征；
- 神经根型、腰突 → 相应肌节与反射的局限 LMN 样改变；
- 马尾和周围神经 → 软瘫模式。

（易混：急性脊休克阶段可暂时软瘫，不能机械把“软”直接等同周围神经。）

# 6｜高密度比较

## 6.1 神经根型 vs 脊髓型颈椎病

| 轴 | 神经根型 | 脊髓型 |
|---|---|---|
| 范围 | 上肢局限、根性分布 | 四肢或平面以下广泛 |
| 疼痛 | 颈肩痛、上肢放射痛 | 可不以放射痛为主 |
| 反射 | 受累根反射可下降 | 下肢深反射可亢进 |
| 病理征 | 通常无 | Hoffmann/Babinski 可阳性 |
| 特殊征 | Eaton、Spurling | 持物不稳、踩棉花、二便 |
| 当前 Study 治疗 | 首选保守 | 手术方向，禁按摩/颌枕牵引 |

## 6.2 腰突 vs 腰椎管狭窄

| 轴 | 腰椎间盘突出 | 腰椎管狭窄 |
|---|---|---|
| 核心 | 髓核/椎间盘刺激压迫根 | 椎管空间整体变小 |
| 体征 | 根性定位相对明确 | 症状多、体征少 |
| 试验 | 有根压时直腿抬高及加强可阳性 | 常可阴性 |
| 区分线索 | L4/L5/S1三联 | 神经源性间歇性跛行 |
