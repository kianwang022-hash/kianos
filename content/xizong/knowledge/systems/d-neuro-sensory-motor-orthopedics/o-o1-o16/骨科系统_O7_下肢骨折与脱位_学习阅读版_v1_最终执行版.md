# O7｜下肢骨折与脱位
## 下肢是承重系统：血供、稳定性、年龄和能否早期活动共同决定结局
> **中心问题**：面对下肢骨折与脱位，怎样先判断能否安全承重，再结合受力、移位、血供与神经风险以及关节功能确定处理目标？

# 1｜Framework｜先问“还能不能安全承重”，再问具体骨折名

下肢病例的统一主线：

```text
高能/跌倒/扭转外力
→ 髋—股骨—膝—胫腓—踝足哪一层失稳
→ 关节内还是关节外？血供是否容易中断？
→ 大血管 / 坐骨-胫-腓总神经 / 间室是否危险？
→ 年龄、骨质、活动需求、卧床风险
→ 复位 / 固定 / 置换
→ 尽可能恢复承重与关节匹配
```

学习顺序：

```text
髋脱位
→ 股骨颈
→ 转子间
→ 股骨干
→ 髌骨
→ 胫腓骨
→ 踝扭伤 / 三踝骨折
→ 跟骨
```

# 3｜KP Active Recall

<!-- kianos:kp id="orthopedics-o07-kp01" -->
## KP01｜下肢创伤总入口：承重+血供+关节匹配+卧床代价
> **主提示：承重4问｜血供｜关节内外｜神经血管｜年龄/活动**

### Detailed Expansion

下肢不是上肢知识的镜像。判断优先级应加入：

- 是否影响承重；
- 是否为关节内损伤、需要更高关节面匹配；
- 是否中断股骨头等关键血供；
- 是否存在大失血、间室或血管神经风险；
- 老年长期卧床的代价是否改变治疗方向。

当前 Study 还给出一个年龄/骨质快速串联：**中老年常见的四肢骨折重点包括肱骨近端、桡骨远端和股骨近端**。这只是识别入口，不替代各部位模型。

**Routing**：CORE + CONNECTION + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o07-kp02" -->
## KP02｜髋关节脱位：后脱最常见，中心脱最凶险
> **主提示：后最常｜中心最险｜Shenton｜后3内｜前2外｜神经1**

### Detailed Expansion

- 髋脱位多见于车祸、高处坠落等较强外力；
- 后脱位最常见；
- 中心脱位最凶险：可合并腹膜后血肿与休克；
- 所有当前 Study 髋脱位均要看**弹性固定、Shenton线连续性**；
- 后脱：屈曲、内收、内旋；臀部可触及股骨头，下肢缩短，可伤坐骨神经；
- 前脱：屈曲、外展、外旋；腹股沟可触及股骨头，下肢长度不定。

（易混：后脱的“内内”与前脱的“外外”用姿势恢复，不要只背病名。）

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o07-kp03" -->
## KP03｜Epstein：从“单纯/后壁小片”一路加重到股骨头骨折
> **主提示：I小/单｜II大后壁｜III粉碎｜IV后壁+顶｜V股骨头**

### Detailed Expansion

当前后脱位 Epstein I–V：

1. 单纯脱位或髋臼后壁小骨折片；
2. 后壁大块骨折；
3. 后壁粉碎骨折；
4. 后壁 + 顶部骨折；
5. 合并股骨头骨折。

它不是独立背诵表，而是在回答：**关节内有没有越来越严重的结构破坏，能否继续单纯闭合复位。**

**Routing**：CORE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp04" -->
## KP04｜髋脱位治疗：I型争取早期闭合复位；II–V/中心转切开
> **主提示：I型Allis｜24–48h｜麻醉特殊｜牵引2–3w｜II–V/中心手术｜坐骨观察2–3m**

### Detailed Expansion

- 后脱 Epstein I：Allis提拉法 + 皮牵引/丁字鞋2–3周；当前 Source 把24–48小时作为黄金时期，且必须全麻或腰麻复位。
- Epstein II–V、中心脱位：切开复位 + 内固定。
- 后脱伴坐骨神经受累多数可逐渐恢复；当前 Source 写若2–3个月仍无恢复迹象则手术探查。

（特殊：桡骨头半脱位无需麻醉；髋脱位恰相反，当前 Source 强调充分麻醉以松弛肌肉。）

**Routing**：CORE + SPECIAL + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp05" -->
## KP05｜股骨颈骨折分型：部位、Pauwels、Garden、颈干角是四个不同问题
> **主提示：部位3｜Pauwels2阈｜Garden4｜颈干角2阈｜血供1**

### Detailed Expansion

四套坐标不要混：

- **部位**：头下型最重 → 经颈型 → 基底型最轻；
- **Pauwels**：外展型＜30°相对稳定；内收型＞50°不稳定；
- **Garden**：I不完全/嵌插；II完全不移位；III完全部分移位仍接触（最常见）；IV完全完全移位；
- **颈干角**：髋内翻≤110°；髋外翻≥140°。

股骨头最重要的血供，当前 Source 强调旋股内侧动脉分支的**骺外侧动脉**。因此分类最终服务于血供、稳定性和治疗。

**Routing**：CORE + CONFUSABLE + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp06" -->
## KP06｜股骨颈临床：腹股沟压痛+45–60°外旋+短缩三征
> **主提示：压痛1｜外旋45–60｜短缩3征｜并发2**

### Detailed Expansion

- 腹股沟中点压痛；
- 外旋畸形45–60°；
- 下肢短缩/大转子上移：Nelaton线、Bryant三角底边缩短、Shoemaker征；
- 并发症接口：股骨头坏死、脂肪栓塞。

（易混：转子间骨折外旋可达90°，且髋部肿胀瘀斑更明显。）

**Routing**：CORE + RECOGNITION + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o07-kp07" -->
## KP07｜股骨颈治疗：先年龄/耐受，再移位和预期寿命
> **主提示：老年耐受差｜寿命短半髋｜寿命长III/IV全髋｜闭复+螺钉｜前倾角**

### Detailed Expansion

当前 Study 的分流主轴：

- 老年、全身情况差不耐受手术：按 Source 先用防旋鞋或牵引过渡，待允许后尽快手术；
- 合并症多、预期寿命短：半髋/股骨头置换；
- 合并症少、预期寿命长且 Garden III/IV 有移位：全髋置换；
- 闭合复位 + 螺钉内固定为另一主要路径，当前 Lecture旁注把年轻、Garden I/II 等作为重要入口；
- 复位还要注意前倾角12–15°。

（边界：保留 Study 考试路径，不把现代手术决策细则外推。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp08" -->
## KP08｜股骨颈 vs 转子间：关节囊内血供风险 vs 囊外出血肿胀
> **主提示：颈45–60｜转子90｜压痛位置｜肿胀瘀斑｜坏死风险**

### Detailed Expansion

转子间骨折：跌倒/病理性骨折，中老年骨质疏松；转子间压痛、下肢缩短、外旋可达90°，髋部肿胀瘀斑多见，当前 Study 采用手术。

与股骨颈比较：

- 股骨颈：腹股沟压痛、外旋45–60°、血供/股骨头坏死更突出；
- 转子间：囊外，局部肿胀瘀斑与90°外旋更突出。

当前 Source 的“下肢短缩”串联还包括：**股骨颈骨折、股骨转子间骨折、股骨干骨折、髋关节后脱位，以及部分髋前脱位**。

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o07-kp09" -->
## KP09｜股骨干：大骨髓腔=失血/脂肪栓塞；下1/3再叠加腘血管与神经
> **主提示：中1/3外成角｜下1/3前/后｜全身2危｜下段4危｜<3牵引/>3手术**

### Detailed Expansion

- 中1/3：向外成角；
- 下1/3：近折端向前、远折端向后；
- 系统性并发：脂肪栓塞、休克；
- 下1/3还要警惕腘血管、胫神经、腓总神经、骨筋膜室综合征；
- 当前治疗：＜3岁垂直悬吊皮牵引（儿童禁骨牵引），＞3岁手术。

**Routing**：CORE + CONNECTION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp10" -->
## KP10｜髌骨骨折：直接粉碎，间接横形；目标是伸膝装置+关节面
> **主提示：暴力2→形态2｜合并3｜<0.5保守｜严重粉碎特殊**

### Detailed Expansion

- 直接暴力 → 粉碎性骨折；
- 间接暴力/股四头肌强烈收缩 → 横形骨折；
- 可伴交叉韧带、侧副韧带、半月板损伤；
- 无移位或移位＜0.5cm：保守，膝伸直位固定；
- 严重粉碎、不能恢复软骨面完整：当前 Source 可行髌骨摘除。

第一轮核心：髌骨不只是“骨块”，还承担伸膝与髌股关节匹配。

**Routing**：CORE + CONNECTION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp11" -->
## KP11｜胫腓骨：部位决定神经、间室、感染和不愈合风险
> **主提示：腓颈→神经1｜胫中下1/3｜胫上/中/下3风险｜开放感染**

### Detailed Expansion

- 腓骨骨折好发腓骨颈 → 可伤腓总神经；
- 胫骨干好发中下1/3（三棱形/四边形交界）；
- 胫骨上1/3：严重缺血坏死、骨筋膜室；
- 中1/3：骨筋膜室 + 远端血供减弱 → 延迟/不愈合；
- 下1/3：血供弱 → 延迟/不愈合；螺旋形常伴后踝骨折；
- 胫骨表浅，因此开放伤/感染风险特别重要。

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o07-kp12" -->
## KP12｜开放小腿双骨折：污染程度决定内固定还是外固定架
> **主提示：短+轻→？｜长+重→？｜共同先做1**

### Detailed Expansion

按当前 Study：

```text
时间短 + 污染轻 → 清创 + 内固定
时间长 + 污染重 → 清创 + 外固定架
```

共同底层不是“固定器械偏好”，而是先控制污染、保护软组织与血供，再获得足够稳定。

**Routing**：CORE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o07-kp13" -->
## KP13｜踝扭伤：跖屈位更脆弱；内强外弱；急性期先冷
> **主提示：韧带3｜最强/最弱｜体位1｜急性处理1**

### Detailed Expansion

当前 Source：

- 内侧副/三角韧带最强；
- 外侧副韧带最薄弱；
- 下胫腓韧带为第三组；
- 跖屈位容易扭伤；
- 急性期立即冷敷。

**Routing**：CORE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp14" -->
## KP14｜三踝骨折：关节内骨折要追求关节面匹配
> **主提示：ORIF｜内螺｜外板｜后踝1/4–1/3**

### Detailed Expansion

当前 Study：三踝骨折行切开复位内固定；内踝螺钉、外踝接骨板；后踝若影响胫骨约1/4–1/3关节面亦内固定。

//MI-D：跟骨骨折以 **Bohler角/跟骨结节关节角改变** 作为当前 Outline 的识别入口，原图优先。

机制抓法：关节内骨折若关节面明显失配，长期更易走向创伤性关节炎，所以复位质量要求高。

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o07-kp15" -->
## KP15｜下肢整合：髋血供、长骨出血、胫骨间室、关节内匹配是四条红线
> **主提示：髋血供｜大失血3｜间室2｜神经3｜关节内｜早期活动目标**

### Detailed Expansion

病例快速扫四条：

1. 髋/股骨颈：复位与血供；
2. 骨盆/中心髋脱位/股骨干：大量出血与休克接口；
3. 股骨下段、胫骨上/中段：血管神经 + 间室；
4. 髋、膝、踝关节内损伤：关节匹配与创伤性关节炎。

治疗最终不是“把骨头接上”，而是恢复安全负重、关节活动与长期功能。

**Routing**：CORE + CONNECTION + MI-G
