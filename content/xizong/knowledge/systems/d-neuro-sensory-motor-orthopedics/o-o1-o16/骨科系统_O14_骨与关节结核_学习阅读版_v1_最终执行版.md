# O14｜骨与关节结核
## 结核不是“慢性化脓”：它以缓慢破坏、冷脓肿和负重结构失稳为核心，脊柱与髋关节还要额外判断神经压迫和功能重建
> **中心问题**：面对慢性骨关节痛、结构破坏和冷脓肿，怎样定位骨、关节或脊柱病变，并判断是否已威胁稳定、神经和功能，从而决定抗结核与手术处理？
>

> **FIRST PASS｜NATURAL_SOURCE_UNITS**  
> `KianOS Block orientation → Source Unit 1：外科 P165–166 连续完成脊柱结核 / 冷脓肿 / 早迟发截瘫 → 返回 KianOS，完成 O14-LG01–LG02 retrieval + closure → Source Unit 2：外科 P166–170 连续完成髋及周围关节结核 / 鉴别 → 返回 KianOS，完成 O14-LG03 retrieval + O14-LG04 discrimination closure → Block Recall`
>
> H21、R7 与 O13 都是 benefit / bounded reactivation，不是 D hard prerequisite。若共同结核、抗结核入口或化脓性感染对照尚未形成，只补当前 O14 判断所需最小语言，不阻塞骨关节结核 Primary Source。
>
> 本文件只负责骨、关节与脊柱的器官特异 Primary，不重复原发/继发/播散结核全文。KP Detailed Expansion 用于 retrieval 后核对、解释、repair 与 reference，不默认要求连续二次通读。

# 1｜Framework｜慢性疼痛 + 结构破坏 + 冷脓肿，先判断位置，再判断是否威胁稳定与神经

```text
肺结核等原发灶
→ 血源播散到骨与关节
→ 干酪样坏死、骨与软骨破坏
→ 关节间隙 / 椎间隙狭窄
→ 冷脓肿
→ 畸形、失稳或脊髓 / 马尾压迫
```

病例固定跑：

```text
缓慢还是急性？
→ 脊柱 / 膝 / 髋？
→ 是否有冷脓肿与间隙改变？
→ MRI确认范围
→ 抗结核 + 制动
→ 是否有手术指征，且没有手术禁忌？
```

# 3｜KP Active Recall

## KP01｜骨关节结核总入口：为什么偏爱负重、活动多又肌肉附着少的部位
> **主提示：来源1｜好发4条件｜部位排序3｜单发｜慢性损伤接口**

### Detailed Expansion

当前 Study：肺结核等病灶经血源播散至骨与关节。好发条件：

- 负重大；
- 活动多；
- 容易慢性损伤；
- 肌肉附着少。

发病率排序：

```text
脊柱结核 > 膝关节结核 > 髋关节结核
```

多为单发病灶。肌肉组织对结核有一定抵抗作用，因此肌肉附着较少的区域更符合当前 Study 的好发解释。

**Routing**：CORE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o14-kp02" -->
## KP02｜临床电影：隐匿缓慢，疼痛先出现，冷脓肿却不红不热
> **主提示：起病1｜全身3｜局部最先1｜破坏2｜冷脓肿3｜少数就诊原因**

### Detailed Expansion

典型：

- 起病缓慢、隐匿；
- 低热、盗汗、消瘦；
- **疼痛是最先出现的局部症状**；
- 椎体或关节破坏；
- 椎间隙或关节间隙狭窄；
- 冷脓肿通常无红、热。

脊柱冷脓肿可表现为椎旁软组织影或腰大肌影增宽。冷脓肿可成为少数患者就诊的直接原因。

（易混：化脓性感染多急、高热、明显红热；结核慢、冷脓肿、结构破坏。）

**Routing**：CORE + RECOGNITION + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o14-kp03" -->
## KP03｜诊断：MRI负责早期范围，X线空间关系帮助区分结核与转移瘤
> **主提示：早期1｜破坏+间隙｜冷脓肿影2｜转移瘤间隙｜椎弓根接口**

### Detailed Expansion

早期诊断：**MRI**。

结核的稳定空间提示：

```text
椎体 / 关节破坏
+ 椎间隙 / 关节间隙狭窄
+ 可有冷脓肿
```

脊柱转移瘤可累及椎体，但更常强调椎弓根，且椎间隙多保持正常。若只有椎体破坏而没有间隙改变，不应仅凭一个影像词直接报结核。

**Routing**：CORE + CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o14-kp04" -->
## KP04｜治疗总原则：药物为主、局部制动；手术必须同时满足“有指征、无禁忌”
> **主提示：主治疗2｜手术双门槛｜术前2–4周｜术后≥12月｜禁忌2**

### Detailed Expansion

当前 Study：

1. 抗结核药物治疗为主；
2. 同时局部制动；
3. 有手术指征且无禁忌时才手术；
4. 术前抗结核2–4周；
5. 术后继续抗结核，总疗程不少于12个月。

结构化正文中的手术禁忌：

- 全身中毒症状明显；
- 合并其他脏器活动期结核。

（SOURCE_CONFLICT：邻近旁注以“无禁忌症”标签列出同样两项，见 O14-SC01。）

逻辑：全身感染未控制时贸然局部清除，可能扩大感染与手术风险。

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o14-kp05" -->
## KP05｜寒性脓肿：不能因为看到“脓肿”就照搬化脓性感染切开引流
> **主提示：不主张3｜原因1｜唯一切开场景2｜vs O13｜窦道后果**

### Detailed Expansion

不主张：

- 反复抽脓；
- 注入抗结核药；
- 常规切开引流。

原因：容易形成经久不愈窦道。

只有寒性脓肿发生混合感染，且全身中毒症状明显时，才考虑切开引流。

（易混：O13化脓性感染强调通畅引流；O14寒性脓肿不能机械照搬。）

**Routing**：CORE + CONFUSABLE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o14-kp06" -->
## KP06｜腰椎 vs 胸椎结核：成人边缘型压间隙，儿童中心型更易后凸截瘫
> **主提示：最常见1｜成人/儿童｜边缘/中心｜间隙窄/常正常｜拾物｜后凸截瘫**

### Detailed Expansion

| 轴 | 腰椎结核 | 胸椎结核 |
|---|---|---|
| 常见度 | 最常见 | 次之 |
| 人群 | 成人多 | 儿童多 |
| 病变型 | 边缘型多 | 中心型多 |
| 椎间盘/间隙 | 易侵犯椎间盘，间隙狭窄 | 间隙多正常 |
| 体征 | 拾物试验阳性多 | 后凸畸形、截瘫多 |

胸椎位置本身后凸且越高越容易影响脊髓，因此截瘫风险更突出。

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o14-kp07" -->
## KP07｜早期 vs 迟发截瘫：一个是“活动物直接压”，一个是“陈旧结构与血管慢慢毁”
> **主提示：早期4压物｜迟发4机制｜活动/静止｜血管1｜软化结局**

### Detailed Expansion

早期 / 活动型截瘫：

- 脓液；
- 干酪样坏死物；
- 死骨；
- 进入椎管直接压迫脊髓。

迟发 / 静止型截瘫：

- 瘢痕组织；
- 椎体脱位；
- 脊柱后凸畸形；
- 脊髓血管栓塞，导致脊髓变性软化。

一句话：

```text
早期 = 活动病灶内容物直接压迫
迟发 = 结构畸形、瘢痕与血管损害
```

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o14-kp08" -->
## KP08｜脊柱结核病灶清除术：六类指征都围绕“药物失败、结构失稳或神经受压”
> **主提示：无缓解｜后凸｜死骨/脓肿｜窦道｜不稳｜髓/马尾压**

### Detailed Expansion

指征：

1. 抗结核治疗无缓解；
2. 严重后凸畸形；
3. 较大死骨及寒性脓肿；
4. 窦道经久不愈；
5. 脊柱不稳定；
6. 脊髓或马尾神经受压。

不是见到脊柱结核就手术；仍需通过 KP04 的“有指征 + 无禁忌”双门槛。

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o14-kp09" -->
## KP09｜髋关节结核：儿童髋病可以先表现为膝痛
> **主提示：人群1｜转移痛1｜局部3｜间隙/破坏｜冷脓肿｜病例入口**

### Detailed Expansion

髋关节结核多见于儿童和青少年。儿童可先诉膝部疼痛，不能因此把病变错误定位到膝。

典型：

- 慢性髋痛或膝部牵涉痛；
- 髋活动受限；
- 屈曲挛缩；
- 关节间隙变窄、虫蚀样骨质破坏；
- 可有冷脓肿。

**Routing**：CORE + RECOGNITION + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o14-kp10" -->
## KP10｜4字试验：阳性只说明髋/骶髂周围结构受限，不等于结核
> **主提示：4病配对｜TB｜AVN｜AS｜内收肌｜阳性意义边界**

### Detailed Expansion

当前 Study 的4字试验阳性疾病：

- 股内收肌损伤；
- 股骨头坏死；
- 髋关节结核；
- 强直性脊柱炎。

所以4字试验不是结核特异试验。必须结合起病速度、全身症状、MRI、间隙与骨质破坏。

**Routing**：CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o14-kp11" -->
## KP11｜Thomas征：髋屈曲挛缩的共同出口，不只见于髋结核
> **主提示：TB｜前囊｜髂腰肌｜髂股韧带｜骨软骨病｜代表什么**

### Detailed Expansion

Thomas征阳性见于：

- 髋关节结核；
- 髋关节前方关节囊挛缩；
- 髂腰肌挛缩；
- 髂股韧带挛缩；
- 股骨头骨软骨病。

它表达的是髋关节屈曲挛缩/伸展受限，不是某一个病名的专属标签。

**Routing**：CONFUSABLE + RECOGNITION + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o14-kp12" -->
## KP12｜髋结核手术分流：先判病变停在滑膜、骨，还是已毁掉全关节
> **主提示：滑膜2级｜骨/全关节1术｜纤维强直1术｜畸形1术｜年龄边界**

### Detailed Expansion

当前 Study：

| 病变状态 | 处理 |
|---|---|
| 单纯滑膜结核 | 关节腔注入异烟肼；无效可滑膜切除 |
| 单纯骨结核或全关节结核 | 病灶清除术 |
| 纤维性强直 | 关节融合术 |
| 明显畸形 | 截骨矫形术 |

这是一条病变范围—功能目标分流，不扩写人工关节置换等现代术式。

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o14-kp13" -->
## KP13｜O14整合：化脓、结核、转移瘤和退变的脊柱空间轴
> **主提示：急/慢｜间隙4方向｜冷脓肿｜椎弓根｜骨赘/竹节｜神经红旗**

### Detailed Expansion

| 疾病 | 起病 / 全身 | 骨与间隙 | 代表性附加证据 |
|---|---|---|---|
| 化脓性感染 | 急，高热 | 早期以感染/脓肿为主，后期可破坏 | 深压痛、脓液、WBC↑ |
| 脊柱结核 | 慢，低热盗汗 | 椎体破坏 + 椎间隙狭窄 | 冷脓肿、椎旁/腰大肌影 |
| 转移瘤 | 肿瘤背景 | 椎体/椎弓根破坏，间隙多正常 | ECT / MRI / 活检链 |
| 脊柱OA | 退变 | 边缘骨赘 + 间隙狭窄 | 中老年机械性疼痛 |
| AS | 炎性轴性 | 骶髂关节变窄融合 + 竹节椎 | 男青年、活动后减轻 |

任何出现脊髓/马尾压迫、进行性无力或括约肌异常，都必须调用 N11 / O3 的神经红旗。

**Routing**：CORE + CONFUSABLE + CONNECTION + MI-G

# 4｜Framework Reconstruction

```text
慢性单发骨关节痛
+ 低热盗汗消瘦
+ 结构破坏/间隙狭窄
± 冷脓肿
→ 骨关节结核
→ MRI
→ 抗结核 + 制动
→ 有指征且无禁忌再手术

脊柱：腰成人边缘型 vs 胸儿童中心型
→ 早期直接压迫 vs 迟发畸形/瘢痕/血管

髋：儿童膝痛
→ 4字 / Thomas
→ 滑膜、骨/全关节、强直、畸形分流手术
```

# 5｜MI-G

- 脊柱＞膝＞髋；慢性单发，疼痛最早；
- 冷脓肿无红热，MRI早期诊断；
- 抗结核 + 制动；手术需“有指征、无禁忌”；
- 术前2–4周、术后总疗程≥12个月按当前 Study；
- 寒性脓肿不反复抽/注/切，混合感染+明显中毒才切开；
- 腰椎成人边缘型、间隙狭窄；胸椎儿童中心型、后凸截瘫；
- 早期截瘫直接压，迟发截瘫畸形/瘢痕/血管；
- 髋结核儿童可先膝痛；4字、Thomas均非特异；
- 髋结核按滑膜—骨/全关节—强直—畸形分流。

# 6｜MI-D

- 术前/术后抗结核时间数字；
- 拾物试验；
- 脊柱病灶清除六类指征完整名单；
- 4字和Thomas完整疾病配对；
- 髋结核各类手术名称。
