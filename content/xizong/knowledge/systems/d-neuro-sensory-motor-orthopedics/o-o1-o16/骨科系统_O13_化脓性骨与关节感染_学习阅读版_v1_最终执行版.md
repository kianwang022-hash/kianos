# O13｜化脓性骨与关节感染
## 同样是“金葡菌 + 高热 + 局部痛”，关键在于感染先落在骨髓腔还是关节腔，以及是否已经形成死骨、死腔和窦道
> **中心问题**：面对高热和骨关节局部疼痛，怎样先判断感染位于骨髓腔还是关节腔，再区分急慢性及是否形成脓肿、死骨或死腔，从而决定引流或清除？

# 1｜Framework｜先判感染空间，再判急慢性与是否需要“引流 / 清除”

```text
病原进入
→ 骨干骺端微循环停留，或直接进入关节腔
→ 炎症、渗出、脓肿与压力上升
→ 局部疼痛 + 全身感染表现
→ 早期影像 / 穿刺确认
→ 抗生素 + 制动 + 是否需要引流
```

若骨髓炎迁延：

```text
骨坏死
→ 死骨
→ 周围反应性新生骨形成包壳
→ 脓液沿窦道排出
→ 慢性骨髓炎
→ 病灶清除 + 消灭死腔 + 冲洗引流 + 闭合
```

所以病例固定跑四问：

1. 病变中心在骨还是关节？
2. 是急性高热期，还是慢性窦道/死骨期？
3. 当前首要证据来自 MRI、分层穿刺还是关节穿刺？
4. 现在应该抗生素与引流，还是已经具备慢性病灶清除条件？

## KP01｜空间入口：骨髓腔感染与关节腔感染先看什么不同
> **主提示：骨1中心｜关节1中心｜共同4｜关键体征各1｜后果2路**

### Detailed Expansion

两者都可有：

- 金黄色葡萄球菌为主；
- 儿童多见；
- 急性起病、寒战高热；
- 白细胞升高与局部剧痛。

但空间不同：

```text
骨髓炎：长骨干骺端 → 骨坏死 / 脓肿 → 骨膜下和软组织
关节炎：关节腔 → 渗出增多 / 关节肿胀 → 软骨与功能受损
```

最有力的局部提示：

- 骨髓炎：**局限性明显深压痛**；
- 膝化脓性关节炎：明显关节肿胀，可有**浮髌试验**。

**Routing**：CORE + CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o13-kp02" -->
## KP02｜急性血源性骨髓炎：为什么儿童膝周干骺端最典型
> **主提示：菌1｜人群1｜部位2端｜菌栓链5｜骨膜结果｜病理折接口**

### Detailed Expansion

当前 Study 的连续链：

```text
儿童长骨干骺端血流特点
→ 大量菌栓易停留
→ 骨组织迅速坏死
→ 形成脓肿
→ 向骨膜下、软组织扩散
→ 后期骨膜受刺激形成反应性新生骨
```

好发在膝关节上下：

- 股骨下端；
- 胫骨上端。

感染早期骨质脆弱，可出现病理性骨折接口。骨膜反应并不等于恶性骨肿瘤；感染同样可刺激骨膜增生。

**Routing**：CORE + CONNECTION + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o13-kp03" -->
## KP03｜急性骨髓炎识别：高热只是背景，深压痛才把病变压回骨内
> **主提示：全身3｜局部2｜关键1｜表浅红肿价值｜病例入口**

### Detailed Expansion

典型组合：

```text
儿童
+ 急性寒战高热
+ WBC↑
+ 膝周长骨疼痛
+ 局限性明显深压痛
```

红、肿、皮温升高和活动受限都可出现，但不能替代深压痛的定位价值。原因在于病灶位于深部骨髓腔，表浅变化可能较晚或缺乏特异性。

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o13-kp04" -->
## KP04｜急性骨髓炎检查：早期首选 MRI，最佳证据来自分层穿刺
> **主提示：首选1｜最佳1｜分层目的｜X线2周｜血常规角色｜别把表菌带入**

### Detailed Expansion

当前 Study 固定：

- 早期首选：**MRI**；
- 最佳检查：局部脓肿**分层穿刺**，涂片发现脓细胞或细菌；
- X线：发病最初约2周可阴性，不能作为早期排除工具。

“分层”不是形式：进针—抽吸—再进针—再抽吸，用于避免把表浅脓肿或皮肤细菌带入更深的骨髓腔，并帮助确认病变深度。

**Routing**：CORE + RECOGNITION + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o13-kp05" -->
## KP05｜急性骨髓炎治疗：抗菌只是第一层，局部压力失控要及时减压引流
> **主提示：抗生素4词｜覆盖2路｜停药4条件｜局部2术｜制动｜支持边界**

### Detailed Expansion

全身抗生素原则：

```text
早期 + 足量 + 联合 + 全程
```

当前 Study 结构化正文给出：一种针对 G⁺ 球菌，一种广谱；持续至：

- 症状消失；
- 体征消失；
- 血象正常；
- 手术引流液清亮。

（SOURCE_CONFLICT：同页旁注另写“体温正常即可停药”，与上述正文冲突，见 O13-SC01。）

局部：

- 早期钻孔灌洗；
- 或开窗减压引流；
- 石膏或皮肤牵引制动。

若足量抗生素后全身好转，但局部疼痛、肿胀继续加重，说明局部脓肿/压力问题未解决，应在原抗生素基础上考虑钻孔引流，而不是只换药或加止痛药。

（边界：支持治疗中的输血/球蛋白按当前 Study 记忆，不外推临床常规。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o13-kp06" -->
## KP06｜化脓性关节炎：儿童髋＞膝，关节腔被渗出物快速占满
> **主提示：菌1｜儿童｜部位排序｜全身3｜局部3｜膝特殊1**

### Detailed Expansion

当前 Study：

- 金黄色葡萄球菌为主；
- 儿童多见；
- 髋关节多于膝关节；
- 急性寒战、高热、WBC↑；
- 关节附近剧痛、明显肿胀、活动受限；
- 膝关节可有浮髌试验。

早期关节间隙可因大量渗出而增宽；后期软骨破坏后才可出现间隙变窄。不能用“间隙变窄”单独排除化脓性关节炎。

**Routing**：CORE + SPECIAL + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o13-kp07" -->
## KP07｜关节穿刺三阶段：清—混—黄白，代表渗出向化脓推进
> **主提示：穿刺1｜浆液性颜色｜纤维蛋白性颜色｜脓性颜色｜诊断+治疗双角色**

### Detailed Expansion

关节穿刺既帮助早期诊断，也为局部处理提供入口：

- 浆液性：清；
- 纤维蛋白性：混浊；
- 脓性：黄白色。

它表达的是关节腔内容物从较清的渗出向纤维蛋白和脓液增加的连续变化。不要把三种外观当成三个互不相关病名。

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o13-kp08" -->
## KP08｜化脓性关节炎治疗：固定功能位，但关节腔必须获得有效清除
> **主提示：全身2｜固定1位｜局部2级｜升级条件2｜术后1**

### Detailed Expansion

当前治疗链：

1. 全身抗生素与支持治疗；
2. 患肢石膏或皮肤牵引，固定关节于功能位；
3. 关节腔注射抗生素，或膝关节置管持续灌洗；
4. 若局部处理无效，或已经化脓：关节镜下手术；
5. 术后持续冲洗、彻底引流。

核心不是“固定”或“打药”单选，而是：

```text
控制全身感染
+ 保持关节安全位置
+ 清除关节腔脓液
```

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o13-kp09" -->
## KP09｜慢性骨髓炎：死骨、包壳、窦道构成一个自我维持的感染空间
> **主提示：三结构｜病程1｜窦道排什么｜为何药物难清｜治疗主轴**

### Detailed Expansion

慢性骨髓炎的稳定身份：

```text
局部骨组织失血坏死 → 死骨
周围骨膜反应形成新生骨 → 包壳
脓液向外排出 → 窦道
```

死骨和瘢痕组织本身缺少有效血供，单靠全身抗生素难以消除感染灶，因此治疗以手术为主。

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o13-kp10" -->
## KP10｜病灶清除术：清到“新鲜出血”，不是只把可见脓液吸走
> **主提示：术前抗生素2天｜清除5项｜终点1｜大死骨时点｜病理折风险**

### Detailed Expansion

当前 Study 的病灶清除：

- 摘除全部死骨；
- 清理脓液；
- 切除坏死组织；
- 切除肉芽和瘢痕组织；
- 切除窦道；
- 凿去封闭髓腔的硬化骨；
- 直到组织新鲜并有出血。

术前2天开始全身抗生素。

大块死骨不能过早摘除：应等待包壳充分形成。否则可能留下长段骨缺损，引起病理性骨折。

**Routing**：CORE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o13-kp11" -->
## KP11｜消灭死腔：清完病灶后仍留空腔，感染仍会回来
> **主提示：死腔为什么危险｜4方法｜冲洗引流｜病段切除部位3｜闭合1**

### Detailed Expansion

清除感染后还要处理无效腔：

- 碟形 / Orr 手术；
- 肌瓣填塞；
- 抗生素骨水泥填塞；
- 术后持续冲洗、彻底引流；
- 肋骨、腓骨、髂骨翼等不重要部位可整段切除；
- 伤口一期缝合。

框架：

```text
病灶清除
→ 消灭死腔
→ 冲洗引流
→ 必要病段切除
→ 闭合伤口
```

**Routing**：CORE + SPECIAL + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o13-kp12" -->
## KP12｜慢性骨髓炎急性发作：先控制急性炎症，不在包壳未成熟时做彻底清除
> **主提示：急性期2处理｜有脓1｜不做1｜原因2｜稳定期再做什么**

### Detailed Expansion

急性发作期：

- 以抗生素为主；
- 积脓时切开引流；
- **不做病灶清除术**。

原因：周围尚未形成稳定完整包壳，贸然清除可能扩大缺损、使感染扩散。待急性炎症控制、慢性病灶条件成熟后，再进入病灶清除与死腔处理。

**Routing**：CORE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o13-kp13" -->
## KP13｜儿童髋的特殊传播：骺板在囊内，骨髓炎可以直接变成关节炎
> **主提示：髋囊内1｜膝囊外1｜传播结果｜骨vs关节快速轴4｜O14接口**

### Detailed Expansion

特殊解剖：

- 儿童髋关节骺板位于关节囊内，骨髓炎脓液可绕过骺板进入关节腔；
- 膝关节囊在骺板外，骨髓炎相对不易按同一路径进入关节腔。

病例快速比较：

| 轴 | 急性骨髓炎 | 化脓性关节炎 | 骨关节结核 |
|---|---|---|---|
| 起病 | 急 | 急 | 缓慢 |
| 关键局部 | 深压痛 | 关节肿胀/浮髌 | 疼痛 + 冷脓肿/破坏 |
| 早期证据 | MRI / 分层穿刺 | 关节穿刺 | MRI |
| 处理中心 | 抗生素 + 减压引流 | 抗生素 + 关节腔清除 | 抗结核 + 制动，指征性手术 |

**Routing**：SPECIAL + CONFUSABLE + CONNECTION + MI-G

# 4｜Framework Reconstruction

闭卷重建：

```text
急性高热 + 骨深压痛
→ 急性血源性骨髓炎
→ MRI / 分层穿刺
→ 抗生素 + 钻孔/开窗引流 + 制动

急性高热 + 关节肿胀
→ 化脓性关节炎
→ 关节穿刺：清→混→黄白
→ 抗生素 + 固定功能位 + 注药/冲洗，必要关节镜

窦道 + 死骨 + 包壳
→ 慢性骨髓炎
→ 成熟后病灶清除 + 消灭死腔 + 引流 + 闭合
```

# 5｜MI-G

- 急性骨髓炎：儿童、膝周干骺端、金葡菌、深压痛；
- 早期首选 MRI，最佳分层穿刺，X线2周内可阴性；
- 抗生素“早期、足量、联合、全程” + 及时减压引流；
- 化脓性关节炎：儿童髋＞膝，关节穿刺清—混—黄白；
- 慢性骨髓炎：死骨—包壳—窦道；
- 病灶清除术清到新鲜出血；大块死骨等包壳形成；
- 急性发作期抗生素/引流，不做病灶清除；
- 儿童髋骺板在囊内，骨髓炎易进入关节腔。

# 6｜MI-D

- 抗生素两路覆盖及停药条件；
- 当前 Study 支持治疗措辞；
- Orr、肌瓣、抗生素骨水泥等死腔处理名单；
- 可整段切除的非重要骨部位；
- 关节腔持续灌洗和关节镜术式细节。
