# 1｜Framework

```text
膝半屈 + 内/外翻 + 重力挤压 + 旋转
→ 半月板/侧副/交叉韧带某一结构超过耐受
→ 疼痛、卡锁或方向性不稳
→ 特异应力/抽屉/旋转试验
→ MRI定位软组织
→ 关节镜最终确认
```

O9不是“十个查体试验清单”。先建立**结构—受力—方向性松弛**，试验才有意义。

# 2｜KP Active Recall

<!-- kianos:kp id="orthopedics-o09-kp01" -->
## KP01｜半月板损伤四要素：半屈、内/外收、重力挤压、旋转
> **主提示：4要素｜为什么半屈？｜结果2**

### Detailed Expansion

当前 Source 把半月板损伤要素概括为：膝半屈、内收或外展、重力挤压、旋转力量。它们共同让半月板在负重下受到**挤压 + 剪切**，从而形成撕裂与机械症状。

P154同时提示：膝伸直时两侧侧副韧带较紧张，关节更稳定；因此“半屈”不是随机背景，而是稳定结构与旋转自由度都发生变化的受伤姿态。

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o09-kp02" -->
## KP02｜红红—红白—白白：血供越往中央越差，愈合潜力越低
> **主提示：3区｜血供方向｜愈合方向**

### Detailed Expansion

- 红—红区：滑膜缘有血运区；
- 红—白区：有/无血运交界；
- 白—白区：完全无血运，多不能愈合。

它是治疗与预后接口，但当前 Source 未要求完整缝合技术，故不外扩。

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o09-kp03" -->
## KP03｜两个身份：桶柄状撕裂 vs Donoghue三联征
> **主提示：桶柄=形态2词｜Donoghue=3结构**

### Detailed Expansion

- 半月板桶柄状撕裂：穿过半月板全层的纵行撕裂；
- Donoghue：前交叉韧带断裂 + 内侧副韧带损伤 + 内侧半月板损伤。

前者是**撕裂形态**，后者是**复合损伤组合**，不是同一分类维度。

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o09-kp04" -->
## KP04｜查体试验地图：半月板靠旋转挤压，侧副靠侧向应力，交叉靠前后移位
> **主提示：半月板4｜侧副2｜交叉2｜轴移1**

### Detailed Expansion

| 目标结构 | 当前 Source 试验 |
|---|---|
| 半月板 | Apley研磨、McMurray旋转挤压、过伸过屈、蹲走 |
| 侧副韧带 | Apley、侧方应力 |
| 交叉韧带 | Lachman、抽屉 |
| ACL断裂后的不稳 | 轴移试验 |

抽屉方向：向前松弛增加提示前交叉；向后增加提示后交叉。

**Routing**：CORE + RECOGNITION + CONFUSABLE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o09-kp05" -->
## KP05｜为什么“一个Apley”能碰到两类结构：动作组合不同，受力对象不同
> **主提示：Apley两身份｜压+旋｜侧向应力｜不能单看试验名**

### Detailed Expansion

当前 Outline 同时把 Apley 放在半月板与侧副韧带入口。学习时不要把“某试验=某病”写成一一映射；需要结合动作、疼痛/松弛及其他体征共同定位。

**Routing**：CONFUSABLE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o09-kp06" -->
## KP06｜MRI vs 关节镜：先无创看软组织，最终直接看关节内结构
> **主提示：首选1｜金标1｜各回答什么**

### Detailed Expansion

当前 Study：**MRI首选，关节镜金标准**。MRI适合软组织定位；关节镜可直接观察关节内结构并作为最终证据层。当前文件不扩写具体手术操作。

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o09-kp07" -->
## KP07｜膝损伤病例出口：疼痛不是定位，方向性不稳/卡锁才把结构暴露出来
> **主提示：机制｜卡锁｜不稳方向｜试验验证｜MRI→镜**

### Detailed Expansion

统一病例链：

```text
受伤体位/方向
→ 机械性卡锁？方向性不稳？
→ 针对半月板/侧副/交叉做试验
→ MRI
→ 必要时关节镜确认
```

与 O7 髌骨骨折的骨性损伤分流：X线首先回答骨折；O9主要处理软组织稳定结构。

**Routing**：CORE + CONNECTION + MI-G
