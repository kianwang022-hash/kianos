# 0｜先记一条完整处理链

```text
先救命
→ 保护搬运与临时固定
→ 判断开放污染
→ 查并记录神经血管
→ X线等确认类型、移位与稳定性
→ 决定是否复位及复位标准
→ 选择固定
→ 动态复查
→ 在稳定前提下尽早功能锻炼
→ 监测愈合、感染和早晚并发症
```

骨折治疗不是只让骨折线消失。真正要同时维护：

```text
对位 / 对线
+ 稳定
+ 血供与软组织
+ 防感染
+ 关节与肌肉功能
```

# 2｜为什么会骨折、怎样先分类

<!-- kianos:kp id="orthopedics-o02-kp01" -->

## KP01｜骨折四类原因：暴力位置、骨本身与累积负荷

> **讲义定位 →** 外科 Lecture PDF P226，书页 P183。  
> **主提示**：4原因｜直—间—病—疲｜各例2｜疲劳3部位+2检查。

| 原因 | 当前 Study 角色 | 典型例子 |
|---|---|---|
| 直接暴力 | 受力处直接骨折 | 胫骨干、髌骨粉碎性骨折 |
| 间接暴力 | 力传导或肌肉强烈收缩，骨折远离受力处 | 肱骨髁上、桡骨远端、髌骨横形、髂前上棘撕脱 |
| 病理骨折 | 骨髓炎、骨肿瘤等使骨本身异常，轻微外力即可骨折 | 后续骨感染/肿瘤 Block Apply |
| 疲劳/应力/行军骨折 | 反复轻微外力累积 | 腓骨干下1/3、第2/3跖骨、肋骨 |

疲劳骨折早期 X 线可能不明显，Study 指向 **MRI、核素**作为早期诊断工具。

（易混：病理骨折强调“骨先病”；疲劳骨折强调“骨原本可正常但重复应力累积”。）

---

<!-- kianos:kp id="orthopedics-o02-kp02" -->

## KP02｜稳定、不完全与开放：三个维度不能混

> **讲义定位 →** 外科 Lecture PDF P226。  
> **主提示**：3维｜稳定5例｜不完全2例｜开放定义。

- **稳定性骨折**：骨折端不易继续移位；Study 例：横形、青枝、嵌插、裂缝、压缩骨折。
- **不完全骨折**：骨连续性未完全中断；Study 例：青枝、裂缝骨折。
- **开放性骨折**：骨折端与外界相通，可直接相通，也可因刺破尿道、膀胱、直肠等形成间接相通。

三者回答不同问题：

```text
稳定性 → 还会不会继续移位
完全性 → 骨连续性断到什么程度
开放性 → 是否与外界/污染腔隙相通
```

（易混：稳定与愈合快慢不是同一维度；Study 明确提示，愈合速度更受接触面积和血供影响。）

# 3｜开放性骨折：先把污染和软组织边界处理好

<!-- kianos:kp id="orthopedics-o02-kp03" -->

## KP03｜开放骨折的第一原则：从“开放”转为“闭合”

> **讲义定位 →** 外科 Lecture PDF P226–227，书页 P183–184。  
> **主提示**：定义｜戳出污染禁1事｜清创时窗2｜目标1。

骨折端已戳出伤口且被污染时，急救阶段**严禁把污染骨端直接推回**。当前 Study 的时间口径：

- 伤后 **6–8小时内**清创，争取一期愈合；
- 有效抗生素条件下可提及 **24小时内**的 Source 口径。

核心目标不是追求表面闭合，而是清除污染和失活组织、保护有活力结构，降低深部感染和骨髓炎风险。

（边界：此处保留当前外科 Study 的考试口径，不扩写现代创伤中心完整分级和抗菌方案。）

---

<!-- kianos:kp id="orthopedics-o02-kp04" -->

## KP04｜开放骨折清创：洗—切—保—修

> **讲义定位 →** 外科 Lecture PDF P227。  
> **主提示**：4动作｜皮1–2mm｜密凿/松刮｜保5类｜骨片2分。

### 洗

- 皮肤清洗；
- 去除明显污染。

### 切

- 切除污染、失去活力的组织；
- 创缘皮肤切除约 1–2 mm；
- 密质骨凿除或咬除；
- 松质骨刮除。

### 保

尽量保留骨外膜；保留有活力、仍与组织相连的骨片。

### 修

保留并修复神经、血管、肌腱、关节韧带和关节囊。

粉碎性骨折：游离骨片可去除；仍与软组织相连的骨片应尽量保留，清除过多会造成骨质缺损并影响愈合。

# 4｜怎样诊断骨折

<!-- kianos:kp id="orthopedics-o02-kp05" -->

## KP05｜骨折三个特有体征及“没有也不能排除”

> **讲义定位 →** 外科 Lecture PDF P227，书页 P184。  
> **主提示**：3特征｜有1即诊断｜5类可无｜禁诱发1。

骨折特有体征：

1. 畸形；
2. 异常/反常活动；
3. 骨擦音或骨擦感。

出现其中一个即可诊断骨折；但检查时不能为“确诊”而故意诱发骨擦感。

可不出现特有体征的范围：

- 不完全骨折；
- 嵌插骨折；
- 脊柱骨折；
- 耻骨、坐骨骨折。

因此：

> **有特有体征可确诊；没有特有体征不能排除。**

# 5｜骨折怎样愈合

<!-- kianos:kp id="orthopedics-o02-kp06" -->

## KP06｜临床愈合标准：“不动—不痛—见骨痂”

> **讲义定位 →** 外科 Lecture PDF P227，书页 P184。  
> **主提示**：3标准｜不动｜不痛2处｜X线1征｜不要求？

1. 局部无异常活动；
2. 局部无压痛和纵向叩击痛；
3. X线见连续性梭形骨痂，骨折线模糊。

（特殊：临床愈合标准不要求“完全没有畸形”；畸形愈合仍然属于已经发生愈合，只是功能和对位结果不理想。）

---

<!-- kianos:kp id="orthopedics-o02-kp07" -->

## KP07｜骨折愈合三期：2周—3/6月—1/2年

> **讲义定位 →** 外科 Lecture PDF P227。  
> **主提示**：3期｜2周纤维｜3–6月骨性｜1–2年板层｜成骨2路。

### 1. 血肿炎症机化期｜约2周

骨折血肿、炎症和肉芽组织逐渐机化，形成**纤维性骨痂**。

### 2. 原始骨痂形成期｜约3–6个月

- 膜内成骨：形成内、外骨痂，较早、较快，骨外膜作用重要；
- 软骨内成骨：形成连接骨痂，包括环状和腔内骨痂；
- 骨痂相连形成桥梁骨痂/编织骨，逐渐达到抵抗肌肉收缩、剪力和旋转力的强度。

### 3. 骨痂改造塑形期｜约1–2年

- 应力轴线上成骨形成板层骨；
- 应力轴线外破骨细胞清除多余骨痂。

//若病理修复模型已形成，可直接复用“血肿—肉芽组织—纤维修复”；若未形成，只补当前骨愈合所需最小修复语言。O2 在此加入骨特异的成骨与机械应力重塑。

<!-- kianos:kp id="orthopedics-o02-kp08" -->

## KP08｜延迟愈合、不愈合与畸形愈合：先分时间、骨痂和硬化

> **讲义定位 →** 外科 Lecture PDF P227。  
> **主提示**：延迟4–8月｜不愈合9月+3月｜硬化｜处理3件。

当前 Study 口径：

- 超过约 **4–8个月**仍无连续性骨痂并缺乏骨性进展 → 延迟愈合；
- 超过 **9个月**，且针对延迟愈合治疗 **3个月**仍未达骨性愈合，并出现骨端硬化 → 不愈合；
- 不愈合处理方向：切除硬化骨、植骨、内固定。

（易混：**不愈合**是骨性连接失败；**畸形愈合**已经愈合，只是旋转、成角、缩短等位置异常。）

---

<!-- kianos:kp id="orthopedics-o02-kp09" -->

## KP09｜影响愈合：全身2类 + 局部5轴

> **讲义定位 →** 外科 Lecture PDF P227。  
> **主提示**：全身2｜局部5｜接触—血供—软组织—稳定—锻炼。

### 全身

- 年龄；
- 健康和营养等总体状况。

### 局部

1. 接触面积：斜形、螺旋形通常接触面积大，愈合较快；横形较慢；
2. 血供：骨折部位、滋养动脉和软组织损伤；
3. 复位损伤：反复手法复位或不当切开复位损伤骨膜、软组织；
4. 稳定：牵引过重使断端分离、固定不牢干扰骨痂；
5. 锻炼时机：过早或不当活动可破坏愈合条件。

（易混：稳定性骨折“不易移位”，不等于一定愈合更快；愈合速度还看接触面积、血供和治疗方式。）

# 6｜早期并发症与立即处理

<!-- kianos:kp id="orthopedics-o02-kp10" -->

## KP10｜骨折早期并发症总图

> **讲义定位 →** 外科 Lecture PDF P228，书页 P185。  
> **主提示**：4大早期｜休—脂—脏/神血—室｜各入口。

1. 休克；
2. 脂肪栓塞；
3. 内脏、神经、血管等组织损伤；
4. 骨筋膜室综合征。

骨盆、股骨干、髋关节中心脱位等可因大量出血导致休克；成人长骨/骨盆骨折可发生脂肪栓塞，Study 强调主要栓塞肺动脉。

一般处理顺序在当前 Lecture 中表述为：

```text
补液/抗休克
→ 处理重要组织损伤
→ 处理骨折
```

具体部位的血管、神经和脏器优先级在区域 Block 中细化。

<!-- kianos:kp id="orthopedics-o02-kp11" -->

## KP11｜骨筋膜室综合征：持续剧痛是最早红旗

> **讲义定位 →** 外科 Lecture PDF P228、P231。  
> **主提示**：2好发｜5P｜最早1｜外固定先1步｜最终处理。

当前 Study 好发部位：

- 前臂掌侧；
- 小腿骨筋膜室。

表现包括高度肿胀和 5P 综合征；最早期重点是**持续性剧烈疼痛**，疼痛后期转为无痛可能提示神经功能进一步丧失，而不是好转。

若外固定过紧：先解除过紧固定；仍有骨筋膜室高压时立即切开减压，防止 Volkmann 缺血性肌挛缩、坏疽和肌红蛋白相关肾损害。

（易混：远端动脉搏动尚存在不能排除早期骨筋膜室综合征。）

# 7｜晚期并发症

<!-- kianos:kp id="orthopedics-o02-kp12" -->

## KP12｜晚期并发症：卧床、感染、关节、营养与缺血五路

> **讲义定位 →** 外科 Lecture PDF P228，书页 P185。  
> **主提示**：晚期8｜卧床4｜外骨化/内关炎｜手足萎｜头舟坏｜最重1。

### 长期卧床相关

- 关节僵硬；
- 下肢 DVT，可致 PE；
- 坠积性肺炎；
- 压疮。

### 局部结构后果

- 感染，可发展为化脓性骨髓炎；
- 创伤性骨化/骨化性肌炎：常见于关节外骨折接口；
- 创伤性关节炎：关节内骨折接口；
- 急性骨萎缩：常见手足骨折，疼痛与损伤程度可不一致，伴血管舒缩紊乱和骨质疏松；
- 缺血性骨坏死：股骨颈、腕舟骨等血供脆弱部位；
- Volkmann 缺血性肌挛缩：Study 视为最严重的晚期并发症之一。

（易混：关节外骨折偏向骨化性肌炎；关节内骨折破坏关节面，更怕创伤性关节炎。）

# 8｜复位、固定与功能锻炼

<!-- kianos:kp id="orthopedics-o02-kp13" -->

## KP13｜复位标准：必须完全纠正什么，允许保留多少缩短

> **讲义定位 →** 外科 Lecture PDF P228，书页 P185。  
> **主提示**：必矫3｜长干≥1/3｜干骺≥3/4｜短缩成1儿2。

必须完全矫正：

- 旋转移位；
- 成角移位；
- 分离移位。

当前 Study 的功能复位数字：

- 长骨干横形骨折，骨折端对位至少 **1/3**；
- 干骺端至少 **3/4**；
- 下肢缩短：成人不超过 **1 cm**，儿童不超过 **2 cm**。

（特殊：关节内骨折和前臂双骨折等强调解剖复位，因为分别涉及关节面和旋转功能。）

---

<!-- kianos:kp id="orthopedics-o02-kp14" -->

## KP14｜手法复位与切开复位：目标不同，代价也不同

> **讲义定位 →** 外科 Lecture PDF P229，书页 P186。  
> **主提示**：先手法｜切开2优｜9指征｜解剖vs功能。

一般先考虑手法复位。切开复位的优点：

- 更容易达到解剖复位；
- 固定可靠后可较早活动、便于护理，减少僵硬和萎缩。

Study 中切开复位主要指征：

- 手法复位未达功能复位；
- 关节内、前臂或小腿双骨折未达解剖复位；
- 断端间软组织嵌入；
- 主要血管、神经、韧带或脊髓损伤；
- 不稳定骨折；
- 多处骨折；
- 陈旧骨折不愈合；
- 老年四肢骨折需尽早离床；
- 开放性骨折。

（边界：概论列出的是“可考虑切开复位的条件”，具体各论仍需按部位分型判断，不能见到老年人就机械选手术。）

<!-- kianos:kp id="orthopedics-o02-kp15" -->

## KP15｜固定：外固定、牵引和内固定分别解决什么

> **讲义定位 →** 外科 Lecture PDF P229。  
> **主提示**：固定2类｜牵引2作用｜儿童骨牵引？｜目标4。

- **外固定**：石膏、夹板、外固定架、牵引等；
- **内固定**：在骨折部位直接提供稳定。

牵引既可用于复位，也可用于维持位置。当前 Study 提醒：儿童骨牵引需谨慎/禁止性边界，具体年龄和部位按各论学习。

固定目标：维持对位对线、保护软组织和血供、减轻疼痛、为愈合和功能锻炼提供机械条件。

## KP16｜稳定固定与早期功能锻炼为什么不矛盾

> **讲义定位 →** 外科 Lecture PDF P229。  
> **主提示**：固定保1｜锻炼防2｜前提1｜过早后果。

```text
固定
→ 骨折端保持稳定、血供与软组织不再反复受损

在不影响固定的前提下尽早功能锻炼
→ 防关节僵硬
→ 防肌肉萎缩
→ 改善功能恢复
```

错误的两端：

- 固定不牢或过早不当负荷 → 干扰骨痂；
- 为“保护骨折”长期完全不动 → 关节僵硬、肌萎缩、DVT、肺炎和压疮。

> 骨科目标是**生物学愈合 + 机械稳定 + 功能恢复**，不是只追求一张完美 X 线片。
