# 0｜统一入口：骨科题先跑“五问”，不要先猜病名

```text
1｜结构：骨、关节、软骨、肌腱、韧带、肌肉、神经、血管，谁先坏？
2｜病因：外伤、过载/退变、缺血、感染、免疫、畸形、肿瘤，哪一类？
3｜稳定：对位、对线、关节匹配和承重还能不能维持？
4｜危险：生命、脊髓/马尾、神经血管、皮肤、间室是否受威胁？
5｜证据与功能：用什么确认；最终要恢复什么动作、承重或保护功能？
```

同样是“疼痛”，可能来自骨折、关节内病变、韧带损伤、神经根刺激、周围神经卡压、感染、缺血或肿瘤；同样是“无力”，可能是疼痛抑制、肌腱断裂、周围神经损伤、神经根受压、脊髓病变或肌肉本身失效。

> **本 Block 的最低地图**：症状入口 → 结构定位 → 稳定性 → 危险结构 → 证据 → 功能目标。

# 1｜总 Framework

```text
A｜症状入口
疼痛 / 肿胀 / 畸形 / 活动受限 / 麻木 / 无力 / 肿块
        ↓
B｜结构定位

        ↓
C｜病因分流
急性外伤｜慢性过载/退变｜缺血｜感染｜免疫｜畸形｜肿瘤

D｜稳定与危险

E｜证据工具
X线看骨与对位｜CT看复杂骨性空间｜MRI看椎间盘/神经/脊髓/韧带等软组织

F｜处理目标
先救命 → 再保肢/保神经血管 → 恢复稳定与对位 → 控制病因 → 尽早恢复功能
```

# 2｜从主诉反推结构

<!-- kianos:kp id="orthopedics-o01-kp01" -->

## KP01｜骨科共同五问：先定位，再命名

> **讲义定位 →** System Guide Block 12；外科学讲义骨科全章共同入口。  
> **主提示**：病例入口｜先回答哪五个问题，才能决定下一步？

面对任何骨科病例，先完整说出：

1. 哪种结构最可能受损；
2. 是哪类机制导致；
3. 是否仍稳定；
4. 是否存在必须立即处理的危险结构；
5. 用什么证据确认，最终功能目标是什么。

这五问是后续所有部位口诀之前的总开关。若一开始就从年龄或某个体征直接猜病名，很容易漏掉开放伤、血管损伤、脊髓受压或间室高压。

---

<!-- kianos:kp id="orthopedics-o01-kp02" -->

## KP02｜疼痛、畸形、活动受限、麻木和无力分别先提示什么

> **讲义定位 →** 外科骨科全章病例入口；N5、N11 Recall。  
> **主提示**：主诉5｜定位4层｜痛点≠病灶？

| 主诉 | 第一轮先想 | 不应直接等同 |
|---|---|---|
| 疼痛 | 骨膜/骨、关节、软组织、神经根/神经、缺血或炎症 | 疼痛部位不一定就是原发病灶 |
| 畸形 | 骨折移位、脱位、长期挛缩或发育异常 | 畸形本身不能说明是否稳定 |
| 活动受限 | 疼痛保护、机械阻挡、关节破坏、肌腱/肌肉失效、神经失控 | “不能动”不一定是瘫痪 |
| 麻木 | 神经根、周围神经、脊髓、局部缺血 | 单一感觉点不能独立定位 |
| 无力 | 疼痛抑制、肌腱断裂、周围神经、根、脊髓或肌肉 | 肌力下降不自动等于 LMN 损伤 |

（易混：**牵涉痛、放射痛和局部压痛**回答的不是同一个问题；必须与感觉分布、反射、肌力和影像合并。）

<!-- kianos:kp id="orthopedics-o01-kp03" -->

## KP03｜骨科七类病因：同一结构可以被不同机制破坏

> **讲义定位 →** System Guide Failure Modes；外科学骨科目录页。  
> **主提示**：同一结构受损｜列出主要病因家族；怎样结合病程分流？

```text
外伤：骨折、脱位、韧带/半月板、神经血管损伤
过载/退变：慢性劳损、椎间盘退变、OA
缺血：股骨头坏死等
感染：化脓性骨髓炎、化脓性关节炎、骨关节结核
免疫：RA、AS 的骨科表现
畸形：斜颈、发育性髋脱位、马蹄内翻足、脊柱侧凸
肿瘤：原发、转移、病理骨折
```

病因决定后续证据和治疗目标：外伤强调稳定与危险结构；感染强调病灶和源控制；退变强调压迫对象与功能；肿瘤强调年龄—部位—影像—病理。

//串联：若炎症、修复、免疫与肿瘤共同语言已在其他 owner 形成，可直接 Recall；若尚未形成，只做当前骨科五问所需的最小局部 repair。O1 不承担这些领域的完整 Primary 初见。

# 3｜稳定性与危险结构

<!-- kianos:kp id="orthopedics-o01-kp04" -->

## KP04｜“稳定”不是“现在看起来没移位”

> **讲义定位 →** System Guide Block 12–13；外科骨折概论。  
> **主提示**：稳定4轴｜对位—对线—匹配—承重｜移位≠不稳？

骨科稳定性至少同时看：

- 骨折端能否维持对位、对线；
- 关节面是否保持匹配；
- 韧带、关节囊或脊柱稳定结构是否完整；
- 在肌肉牵拉、体位改变或承重下是否继续移位。

因此：

- “当前 X 线无明显移位”不保证动态稳定；
- “已有移位”说明位置异常，但仍需判断是否可维持复位；
- 脊柱稳定性与是否已经出现神经损伤是两条并行判断；
- 固定目标不是单纯让图像好看，而是维持稳定、保护血供并允许功能恢复。

---

<!-- kianos:kp id="orthopedics-o01-kp05" -->

## KP05｜骨科急危优先级：先救命，再保肢，再保功能

> **讲义定位 →** System Guide MI-G；外科骨折、脊柱、骨盆、神经损伤章节。  
> **主提示**：4层优先｜命—肢—神经—功能｜红旗7。

第一轮必须立即识别：

1. 大出血或休克；
2. 开放伤与严重污染；
3. 肢体无脉、苍白或进行性缺血；
4. 严重/进行性感觉运动缺失；
5. 骨筋膜室综合征；
6. 脊髓或马尾受压、二便障碍；
7. 高位颈髓导致的通气风险。

```text
生命危险
→ 血管与组织存活
→ 脊髓/周围神经
→ 对位、稳定和功能
```

（特殊：影像很重要，但不能让“等影像”延误明显骨筋膜室高压、进行性神经损伤或失血性休克的处理。）

---

<!-- kianos:kp id="orthopedics-o01-kp06" -->

## KP06｜神经血管检查为什么必须在处理前后重复

> **讲义定位 →** System Guide Block 12；后续 O2–O8 共同调用。  
> **主提示**：前后2次｜血运4｜神经4｜记录3。

### 血运至少记录

- 皮温与颜色；
- 毛细血管再充盈；
- 远端动脉搏动；
- 疼痛、肿胀及缺血趋势。

### 神经至少记录

- 关键动作；
- 关键感觉区；
- 肌力；
- 必要的反射或特殊体征。

复位、牵引、固定或手术前后重复记录，才能判断神经血管异常来自原始损伤，还是处理后新出现/加重。

//串联：具体正中、尺、桡、坐骨、胫、腓总神经动作—感觉地图后置 O5；脊髓/根/周围神经层级可在需要时调用 N11，未形成则最小 reactivation。

# 4｜选择证据工具

<!-- kianos:kp id="orthopedics-o01-kp07" -->

## KP07｜X线、CT、MRI、核素、肌电和关节镜各回答什么

> **讲义定位 →** 外科骨科概述、脊柱、退变、膝损伤、股骨头坏死等连续章节。  
> **主提示**：按诊断疑问选工具｜各自能确认什么、不能替代什么？

| 工具 | 本系统主要回答 |
|---|---|
| X线 | 骨折、脱位、对位对线、关节间隙、骨质与骨赘等基础骨性问题 |
| CT | 复杂骨折、重叠部位、骨性空间与细小骨折线 |
| MRI | 椎间盘、神经、脊髓、韧带、半月板等软组织及受压；部分早期缺血性病变 |
| 核素 | 代谢活跃分布；早期疲劳骨折、股骨头缺血坏死等接口 |
| 肌电/电生理 | 周围神经和肌肉功能；帮助判断损伤层级与恢复 |
| 关节镜 | 关节内结构的直接观察；膝半月板/韧带的金标准接口 |

（易混：外科学讲义明确把 **X线**作为骨科常规检查；诊断脊髓、神经、韧带、半月板等软组织损伤时，首选 **MRI**。影像选择必须围绕“要回答的问题”，而不是按昂贵程度排序。）

---

<!-- kianos:kp id="orthopedics-o01-kp08" -->

## KP08｜证据链：症状—体征—影像—病理，各自解决一层问题

> **讲义定位 →** 骨科共同诊断语言。  
> **主提示**：同一病例｜各层证据分别减少哪一种不确定性？

```text
症状：患者感受到什么，提供入口
体征：哪种动作、感觉、反射、稳定或血运异常，帮助定位
影像：结构在哪里、怎样移位/压迫/破坏
病理：感染、免疫、肿瘤等最终组织身份
```

一个阳性体征应当嵌入完整证据链。例如直腿抬高试验只说明坐骨神经/神经根受牵拉的可能，仍需结合放射痛分布、肌力、感觉、反射和 MRI；骨肿块的影像提示生物学行为，但最终病理身份不能被单一 X 线征替代。

# 5｜治疗与功能目标

<!-- kianos:kp id="orthopedics-o01-kp09" -->

## KP09｜骨科治疗不是“把骨头接上”，而是同时守住五个目标

> **讲义定位 →** 骨折概论与各骨科疾病共同治疗语言。  
> **主提示**：处理目标｜除骨性复位，还须守住什么？固定与功能恢复怎样兼容？

1. 处理生命危险；
2. 保护皮肤、血管、神经、肌肉和感染边界；
3. 恢复或维持对位、关节匹配和稳定；
4. 控制导致结构破坏的病因；
5. 在不破坏稳定的前提下尽早恢复功能。

因此“固定”和“功能锻炼”不是对立项：固定提供机械条件，合理活动防止关节僵硬和肌肉萎缩。具体复位、固定和锻炼边界在 O2 及部位性 Block 中完整学习。

<!-- kianos:kp id="orthopedics-o01-kp10" -->

## KP10｜N11 怎样进入骨科：先报层级，再报病名

> **讲义回看 →** `神经系统_N11_神经定位桥梁_学习阅读版_v1_最终执行版.md`。  
> **主提示**：4层｜脊髓—圆锥/马尾—根—神经｜硬/软｜广/局。

骨科病例出现麻木、无力、反射或二便异常时，先定位层级：

```text
范围广 + 病理征/肌张力异常
→ 先想脊髓或高位中枢通路

根性放射痛 + 皮节/肌节/反射组合
→ 先想神经根

某条神经关键动作 + 特定感觉区 + 局限畸形
→ 先想周围神经

鞍区感觉 + 括约肌
→ 圆锥/马尾红旗
```

随后再把层级放入具体结构病：脊柱骨折、颈椎病、腰椎间盘突出、区域骨折伴神经损伤等。

（易混：病名可相似，定位层级不能混。颈椎病可以是根型或髓型；腰椎间盘突出通常是根性问题，不自动等于腰段脊髓损伤。）

> 若 N11 已形成，直接把该定位坐标作为 Recall 调用；若尚未形成，O1 只补当前病例五问所需的最小定位语言，不要求先完成整个 N11 Block。真正要求 N11 hard readiness 的是后续 O3 / O4 / O5。
