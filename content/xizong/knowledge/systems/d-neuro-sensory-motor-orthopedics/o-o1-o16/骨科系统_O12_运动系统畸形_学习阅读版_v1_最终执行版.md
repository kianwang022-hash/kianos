# O12｜运动系统畸形
## 发育中的结构不是静态照片：年龄、负重和生长会不断放大偏差，治疗窗口因此比单纯病名更重要
> **中心问题**：面对发育性运动系统畸形，怎样结合年龄、结构偏移、负重后的放大效应和功能影响，判断还能否保守矫正以及治疗窗口？
>

> **FIRST PASS 固定流程**  
> `Framework → 对应外科 Lecture / 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> 本文件不是第二份外科 Lecture。完整深度学习仍由 `外科学讲义_AI阅读版.md` 与原 PDF 视觉层承担；本文件负责认知地图、主动提取、快速核对、Memory Routing 与 Coverage / Lecture Routing。

# 1｜Framework｜畸形病例先问“什么年龄、哪里偏、负重后怎样放大、现在还能不能保守矫正”

本 Block 的统一逻辑：

```text
先天 / 发育性结构异常
→ 生长、肌力和负重持续作用
→ 方向性偏差逐步固定或加重
→ 外观异常 + 功能异常 + 继发力线问题
→ 年龄越小，保守矫形窗口通常越重要
→ 结构逐渐固定后，进入手术重建边界
```

三个当前正式 Primary：

```text
先天性肌性斜颈
→ 局部肌肉挛缩 + 头颈方向异常

发育性髋关节脱位
→ 髋臼/韧带/股骨头关系异常 + 站立后负重放大

特发性脊柱侧凸
→ 结构性侧弯 + 生长中加重风险 + Cobb角决定处理层级
```

病例先跑四问：

1. 现在处于哪个发育阶段？
2. 是可逆姿势/功能性偏斜，还是已经结构性异常？
3. 是否已经影响步态、平衡、胸廓或关节匹配？
4. 当前处于观察、支具/矫形还是手术窗口？

# 3｜KP Active Recall

<!-- kianos:kp id="orthopedics-o12-kp01" -->
## KP01｜发育性畸形总入口：年龄不是背景变量，而是治疗决策本身
> **主提示：4问｜年龄｜可逆/结构｜负重放大｜窗口｜功能目标**

### Detailed Expansion

当前三类疾病虽然部位不同，但共同点是：

```text
结构或软组织发育异常
→ 生长继续
→ 姿势/负重不断给偏差加力
→ 畸形可能从“可矫”走向“固定”
```

因此病例不能只问“是什么病”，还要问：

- 新生儿、婴儿、幼儿还是青少年？
- 站立/行走前后是否改变表现？
- 当前是否仍有保守矫形机会？
- 若已有固定结构异常，手术目标是什么？

**Routing**：CORE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o12-kp02" -->
## KP02｜先天性肌性斜颈：患侧SCM挛缩，头偏患侧、下颌转健侧
> **主提示：肌肉1｜头/下颌2方向｜面部1｜<1岁治4｜1–4岁手术**

### Detailed Expansion

当前 Study：

```text
一侧胸锁乳突肌挛缩
→ 头偏向患侧
→ 下颌转向健侧
→ 患侧面部发育较小
```

治疗按年龄：

- ＜1岁：按摩、热敷、手法矫正、矫形帽外固定；
- 胸锁乳突肌切断/松解术的最佳年龄：**1–4岁**。

（易混：病例中的方向题要分“头偏”与“下颌转”，两者不是同向。）

**Routing**：CORE + RECOGNITION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp03" -->
## KP03｜DDH病因与病理：髋臼浅+韧带松，站立前就已埋下“不稳定”
> **主提示：病因2｜病理6｜女/左｜站前/行走2阶段｜核心失配**

### Detailed Expansion

发育性髋关节脱位当前 Study 的两大重要病因：

1. 原发性髋臼发育不良；
2. 关节韧带松弛。

站立前期可见的病理语言包括：

- 髋臼浅、平；
- 关节囊与韧带松弛；
- 股骨头较小；
- 圆韧带增粗；
- 股骨颈前倾角增大；
- 股骨头可仍位于髋臼内，也可已脱出。

当前 Study 还强调：女性多见、左侧多见。

先建立“**髋臼—股骨头匹配不足 + 软组织稳定性差**”，再去记体征和年龄治疗。

**Routing**：CORE + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp04" -->
## KP04｜DDH站立前期：不会走路时，靠皮纹、短缩和“弹入弹出”发现
> **主提示：皮纹/会阴2｜短缩｜弹响｜Ortolani/Barlow｜屈曲外展｜Allis**

### Detailed Expansion

当前 Study 的站立前期识别入口：

- 患侧皮纹异常/不对称；
- 会阴改变；
- 下肢短缩；
- 可有弹响；
- Ortolani / Barlow 等弹入、弹出试验；
- 髋屈曲外展相关检查；
- Allis / Galeazzi 等短缩体征。

Lecture 特别提示：**Ortolani/Barlow 不推荐在＞3个月儿童反复作为同样检查入口**；年龄增加后识别重心转向影像和站立行走体征。

**Routing**：CORE + RECOGNITION + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp05" -->
## KP05｜DDH站立行走期：负重后，短缩与失稳被放大成跛行和Trendelenburg
> **主提示：步态2｜单腿站立1｜屈髋｜股骨头活动｜vs站前**

### Detailed Expansion

进入站立行走期后，病例不再以“弹入弹出”为中心，而转向：

- 跛行；
- 双侧病变可出现摇摆式步态；
- Trendelenburg / 单腿站立相关体征；
- 屈髋畸形接口；
- 当前 Lecture 还描述股骨头随负重出现异常的“泵样”移动。

核心变化：**负重把原来的结构不匹配转换成可见的步态和骨盆稳定问题。**

**Routing**：CORE + RECOGNITION + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o12-kp06" -->
## KP06｜DDH影像：婴儿先超声，3个月后转X线；Shenton线是空间关系门禁
> **主提示：筛查1｜>3月检查1｜Shenton｜为什么原图｜年龄切换**

### Detailed Expansion

当前 Study 的检查分流：

- 早期筛查：**超声**；
- 出生约3个月后：**X线**作为重要检查入口；
- X线空间判断包括 Shenton 线连续性等。

这部分不能只背“超声/X线”。髋臼、股骨头、Shenton线都依赖二维空间关系，必须回 Study 原图确认。

**Routing**：CORE + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp07" -->
## KP07｜DDH治疗按年龄切换：吊带→闭复位→切开复位→骨盆重建
> **主提示：0–6月｜6月–1.5岁｜1.5–3岁｜≥3岁｜Salter接口**

### Detailed Expansion

当前 Lecture 的年龄分流：

```text
0–6个月
→ Pavlik 吊带，维持屈曲外展

6个月–1.5岁
→ 闭合复位 + 当前Source“人位”固定

1.5–3岁
→ 切开复位

≥3岁
→ 切开复位 + 骨盆截骨/重建方向
```

当前 Study 以 Salter 骨盆截骨术作为后段重要术式接口，并给出更细年龄和髋臼条件；这些细节进入 MI-D，以当前 Source 为考试口径。

第一轮主线：**年龄越大，单纯软组织/体位矫形越难，结构重建比例上升。**

**Routing**：CORE + BOUNDARY + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp08" -->
## KP08｜脊柱侧凸先分结构性/非结构性：能不能在去除原因后恢复，是第一刀
> **主提示：最常结构1｜非结构6因｜可逆性｜神经根接口｜先天性边界**

### Detailed Expansion

当前 Study：

- 最常见的结构性脊柱侧凸：**特发性脊柱侧凸**；
- 非结构性侧凸本身没有固定的脊柱结构改变，去除原因后可改善。

Lecture 的非结构性原因包括：

- 神经根受刺激，如腰椎间盘突出；
- 癔症；
- 髋关节挛缩；
- 姿势不当；
- 下肢不等长；
- 炎症。

（易混：先天性脊柱侧凸属于结构性范畴，不要因为“先天/功能异常”而放进非结构性。）

//Recall O4：腰椎间盘突出完整神经根压迫模型不在本 Block 重学。

**Routing**：CORE + CONFUSABLE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o12-kp09" -->
## KP09｜特发性脊柱侧凸：肩背不等高+剃刀背，严重胸廓畸形可把问题推到呼吸循环
> **主提示：外观3｜最常见比例｜分型年龄｜严重出口1｜功能目标**

### Detailed Expansion

当前 Study 的典型入口：

- 双肩/背部不等高；
- 胸廓不对称；
- 剃刀背 / razorback 等体表畸形；
- 特发性脊柱侧凸是最常见结构性侧凸，Lecture病例页给出约75%–80%的考试口径；
- 可按发病年龄分婴儿、少儿、青少年和成人型。

严重胸廓畸形可使肺受压、通气受限；当前 Study 进一步把严重长期后果连接到慢性肺心病。

//Recall 呼吸 R9：这里不重新教学肺高压/肺心病，只保留“胸廓畸形→通气/肺循环负担”的接口。

**Routing**：CORE + CONNECTION + RECOGNITION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o12-kp10" -->
## KP10｜Cobb角：>10诊断；<20观察；20–40支具；>40手术
> **主提示：>10｜<20｜20–40｜>40｜治疗目标3**

### Detailed Expansion

当前 Study 的 Cobb 角考试分流：

```text
>10°      → 诊断侧凸
<20°      → 观察随访
20–40°    → 支具
>40°      → 手术
```

治疗目标不是追求一个漂亮数字，而是当前 Lecture 病例所强调的：

- 矫正畸形；
- 获得稳定；
- 维持平衡。

（边界：全部现代生长潜力评分、不同手术构型和精细随访频率不在当前 Source 范围。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D
