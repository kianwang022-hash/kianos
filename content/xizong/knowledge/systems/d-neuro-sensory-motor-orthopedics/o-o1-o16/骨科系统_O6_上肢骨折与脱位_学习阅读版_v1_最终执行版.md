# 1｜Framework｜上肢不是“十几个骨折名”，而是一条从肩带到腕手的功能链

上肢的共同任务不是承重，而是把肩带提供的大范围定位，逐级传给肘、前臂旋转和腕手精细功能。因此同样叫“骨折”，考试真正反复追问的是：

```text
外力方向 / 着地方式
→ 哪个骨或关节首先失稳
→ 近、远骨折端被哪些肌肉继续牵拉
→ 移位 / 特殊体位 / 特征体征
→ 邻近神经血管是否受威胁
→ 复位方向 + 固定方式
→ 保住肩肘活动、前臂旋转与手功能
```

本 Block 按空间顺序学习：

```text
肩带：锁骨
→ 肩：盂肱关节、肱骨近端
→ 上臂：肱骨干
→ 肘：肱骨髁上、肘关节、桡骨头
→ 前臂：Galeazzi / Monteggia / 双骨折
→ 腕：Colles / Smith / Barton
```

**第一轮抓三件事：受力—移位—危险结构。** 命名、角度、固定时长等精确事实再通过 MI-D 固化。

## KP01｜上肢创伤总入口：先结构，再移位，再神经血管，最后功能
> **主提示：结构5段｜受力→移位｜危险2类｜复位/固定｜功能3层**

### Detailed Expansion

面对任一上肢外伤，先不要用病名口诀抢答：

1. **结构**：肩带、肩、上臂、肘、前臂还是腕；骨折还是脱位；
2. **移位**：着地/牵拉方向 + 肌肉牵引决定近、远折端；
3. **危险结构**：血管灌注、命名神经、皮肤开放；
4. **治疗方向**：多数先复位；手法常配外固定，切开常配内固定；
5. **功能目标**：肩肘活动、前臂旋转、腕手精细动作均应被保护。

（易混：影像显示“对位尚可”不等于神经血管检查可省略；复位前后都需重新评价。）

**Routing**：CORE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o06-kp02" -->
## KP02｜锁骨中1/3：两端被不同肌肉拉开，先保住肩带与深部结构
> **主提示：中1/3｜近/远2方向｜姿势2｜危险3｜治2**

### Detailed Expansion

- 好发于**锁骨中1/3**。
- 中1/3骨折：近折端被胸锁乳突肌牵拉向**上、后**；远折端受胸大肌等影响向**下、前**。
- 典型入口：胸骨柄—肩峰连线隆起/压痛；患者常健手托患肘、头向患侧倾斜。
- 深部风险：肺、锁骨下血管、臂丛神经。
- 当前 Study 治疗：儿童青枝、成人无移位 → 三角巾悬吊；中段有移位 → 手法复位 + 横形8字绷带外固定。

（易混：锁骨骨折的“托肘、头倾”可与肩脱位外观相似，真正定位要回到骨连续性与关节体征。）

**Routing**：CORE + RECOGNITION + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o06-kp03" -->
## KP03｜肩关节脱位：前脱最常见；方肩+Dugas+弹性固定先把“脱位”坐实
> **主提示：前最常｜体征4｜并发2｜前治3步｜后治1｜特殊固定**

### Detailed Expansion

肩关节脱位以**前脱位**最常见。当前 Study 的识别组合：

```text
弹性固定
+ 方肩畸形
+ 肩胛盂空虚感
+ Dugas征阳性
```

还可合并肱骨大结节撕脱骨折及上肢神经血管损伤。

- 前脱位：Hippocrates足蹬法复位；Dugas转阴提示复位成功；三角巾悬吊约3周。
- 关节囊破损明显：当前 Source 采用搭肩位胸肱绷带固定。
- 后脱位：当前 Lecture 口径为手术。

**不要只背“前脱”**：病例先证明关节失配，再问方向与处理。

//串联：P208特别提醒粘连性肩关节囊炎/肩周炎不能因为疼痛就长期三角巾固定，其完整慢性损伤模型后置 O11。

**Routing**：CORE + RECOGNITION + CONFUSABLE + CONNECTION + MI-G

## KP04｜肱骨近端骨折：中老年+外科颈；Neer先看“四块是否真正移位”
> **主提示：人群1｜部位1｜Neer4块/2阈｜并发3｜治4档**

### Detailed Expansion

- 多见于中老年骨质疏松，好发**外科颈**。
- Neer用头、干、大结节、小结节四部分的移位判断；Study阈值：**移位>1 cm 或成角>45°**。
- 合并损伤按当前 P209 Study 原文：**胸长神经、腋神经、腋血管**；空间关系仍需回原图核对。
- 治疗层级：
  - Neer I、轻度II → 三角巾悬吊；
  - 重度II、III、非老年IV → 切开复位内固定；
  - 老年IV → 人工肱骨头置换。

（边界：这是当前考试口径，不扩写现代复杂肩关节置换选择。）

**Routing**：CORE + BOUNDARY + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o06-kp05" -->
## KP05｜肱骨干：桡神经沟先决定危险；三角肌止点决定移位轴
> **主提示：桡神经1段｜止点上/下｜近端2方向｜远端规律｜牵引内/外**

### Detailed Expansion

肱骨干中下1/3后外侧邻近桡神经沟，因此骨折首先要联想到桡神经。

当前 Study 的移位表：

| 骨折线 | 近折端 | 远折端 | 治疗牵引方向 |
|---|---|---|---|
| 三角肌止点以上 | 内、前 | 外、近端 | 内收位牵引 |
| 三角肌止点以下 | 外、前 | 近端 | 外展位牵引 |

理解方式不是死记箭头，而是：**骨折线改变了哪些肌肉仍连在哪一段骨上**。

//串联：桡神经损伤完整表现可 Recall O5；若 O5 未形成，只补当前“伸腕/伸指 + 感觉”危险检查所需最小接口。

**Routing**：CORE + CONNECTION + VISUAL_ONLY + MI-G

<!-- kianos:kp id="orthopedics-o06-kp06" -->
## KP06｜肱骨髁上骨折：儿童、前倾角、伸直型；早期最怕血管神经+骨筋膜室
> **主提示：<10岁｜前倾30–50｜伸/屈2机制｜危险4｜5P｜晚3｜治1**

### Detailed Expansion

- 解剖基础：肱骨干与肱骨髁轴线有**30–50°前倾角**；多见＜10岁。
- **伸直型最常见**：手掌着地；近折端前下、远折端后上；肘前可触及断端，肘后突、半屈位。
- 早期可损伤肱动脉及正中、尺、桡神经；前臂肿胀后可发展骨筋膜室综合征。
- 当前 Lecture 强调：高度肿胀、5P、动脉搏动减弱/消失时，若形成骨筋膜室综合征应立即切开减压，以防缺血性肌挛缩。
- 晚期：骨化性肌炎、肘内翻（提携角＜0°）、肘外翻（＞15°）。
- 伸直型：手法复位 + 后侧石膏托屈肘位。
- **屈曲型**：肘后着地；近折端后下、远折端向前，近折端可刺破皮肤形成开放伤与感染风险。

（易混：肘后三角是否改变用于与肘关节脱位分流，见下一KP。）

**Routing**：CORE + RECOGNITION + CONFUSABLE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o06-kp07" -->
## KP07｜肘脱位 vs 髁上骨折：儿童肘外伤先看肘后三角
> **主提示：后脱最常｜三角变/不变｜弹性固定｜空虚感｜环抱复位**

### Detailed Expansion

肘关节脱位以**后脱位**多见：

- 肘后三角关系改变；
- 弹性固定；
- 肘后空虚感；
- 肘后突，常半屈位；
- 当前治疗：环抱式手法复位 + 长臂石膏托 + 三角巾悬吊。

病例鉴别轴：

```text
儿童肘部外伤
→ 肘后三角改变：更支持肘脱位
→ 肘后三角保持：更支持肱骨髁上骨折
```

**Routing**：CORE + CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o06-kp08" -->
## KP08｜桡骨头半脱位：＜5岁+上牵史；三个“不”形成低摩擦识别
> **主提示：桡骨头半脱位：年龄｜机制史｜X线？｜麻醉？｜固定？**

### Detailed Expansion

- 多见＜5岁，原因是环状韧带发育未完善；
- 常有手、腕被动向上牵拉史；
- 当前 Study 称其为**X线唯一阴性的脱位**；
- 无需麻醉即可手法复位；
- 复位后无需固定。

“年龄 + 牵拉史”比单纯肘痛更有识别力。

**Routing**：CORE + SPECIAL + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o06-kp09" -->
## KP09｜Galeazzi vs Monteggia：一条记“谁骨折、谁脱位、在上还是下”
> **主提示：G=桡下+尺头｜M=尺上+桡头｜复位顺序特殊×1**

### Detailed Expansion

- **Galeazzi**：桡骨干下1/3骨折 + 尺骨头脱位。
- **Monteggia**：尺骨干上1/3骨折 + 桡骨头脱位；当前 Source 强调先复位桡骨。

不要只背人名。用两问恢复：

```text
骨折的是哪根？发生在上1/3还是下1/3？
脱位的是尺骨头还是桡骨头？
```

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o06-kp10" -->
## KP10｜前臂双骨折：前臂旋转逼着你追求解剖复位
> **主提示：目标1｜先稳定｜全不稳上下段顺序｜锻炼3时点**

### Detailed Expansion

前臂两骨 + 骨间膜共同承担旋前旋后，因此当前 Study 要求**解剖复位**，避免成角/旋转畸形。

- 先复位稳定性骨折；
- 两者均不稳定：下段先桡骨；中上段先尺骨；
- 功能锻炼按 Source：2周手指/腕；4周肘/肩；8–10周X线证实愈合后再做前臂旋转。

（边界：时程属于当前 Study MI-D，考试按 Source；不泛化为所有现实患者统一康复处方。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o06-kp11" -->
## KP11｜Colles / Smith / Barton：先看着地面，再看远折端，再问是否有关节面+腕脱位
> **主提示：手掌/手背｜远端背/掌｜共同桡侧｜畸形2｜Barton定义**

### Detailed Expansion

| 类型 | 受力 | 远折端 | 近折端 | 关键身份 |
|---|---|---|---|---|
| Colles（伸直型） | 手掌着地 | 桡侧 + 背侧 | 掌侧 | 枪刺刀 / 餐叉畸形；常见 |
| Smith（屈曲型） | 手背着地 | 桡侧 + 掌侧 | 背侧 | 与Colles掌背方向相反 |
| Barton | — | — | — | 桡骨远端**关节面骨折伴腕关节脱位**；多数表现近似Colles，少数近似Smith |

Colles 当前治疗：手法复位 + 屈腕尺偏位石膏外固定。

（特殊：同样是“手掌着地”，当前 Study 提醒：**＜10岁更要想到伸直型肱骨髁上骨折；中老年更要想到 Colles**，本质是年龄与骨质改变了力量链的薄弱点。）

（易混：Galeazzi不是桡骨远端关节面骨折，而是桡骨干下1/3骨折 + 尺骨头脱位。）

**Routing**：CORE + CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o06-kp12" -->
## KP12｜上肢创伤整合：危险优先于命名，旋转/关节匹配优先于“差不多对齐”
> **主提示：血管4入口｜神经3轴｜关节内｜旋转功能｜复位前后复查**

### Detailed Expansion

上肢创伤真正需要即时升级的不是“忘了一个人名骨折”，而是：

- 肱骨髁上 → 肱动脉 / 神经 / 骨筋膜室；
- 锁骨、肩、肱骨近端 → 深部神经血管；
- 肱骨干 → 桡神经；
- 关节脱位 → 复位前后神经血管；
- 前臂双骨折 → 旋转功能与解剖复位；
- 桡骨远端关节面受累 → 关节匹配与创伤性关节炎风险。

病例最终仍回到：

```text
结构 → 受力 → 移位 → 危险结构 → 复位质量 → 功能目标
```

**Routing**：CORE + CONNECTION + MI-G

# 5｜MI-G｜第一轮必须即时掌握

- 肱骨髁上骨折：肱动脉、正中/尺/桡神经、骨筋膜室综合征与立即减压入口；
- 肱骨干中下1/3与桡神经；

- 肩脱位方肩 + Dugas + 弹性固定；

- Colles / Smith / Barton 与 Galeazzi / Monteggia 的基本身份；
