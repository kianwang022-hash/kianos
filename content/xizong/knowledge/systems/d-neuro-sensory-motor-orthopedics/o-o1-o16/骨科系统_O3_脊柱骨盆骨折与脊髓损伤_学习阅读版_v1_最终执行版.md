# O3｜脊柱、骨盆骨折与脊髓损伤
## 学习阅读版 v1｜最终执行版

> **中心问题**：轴性骨骼受伤后，怎样同时判断结构是否稳定、是否存在脊髓/圆锥/马尾损伤，以及是否有骨盆大出血、呼吸失败和二次损伤风险？
>
> **文件性质**：O2 骨折共同框架在躯干轴性结构中的高危应用。这里始终并行两条判断：**结构稳定性**与**神经/循环危险性**；不能只看骨折片，也不能只报神经平面。
>
> **Primary Study**：`外科学讲义_AI阅读版.md`，27跟课 PDF P186–193，书页 P151–157。
>
> **Primary Outline**：外科 SUR-U038，**19 / 19**。
>
> **前序调用**：O2 骨折概论；N11 脊髓—圆锥—马尾定位；循环休克；呼吸泵。
>
> **第一轮流程**：Framework → Lecture / 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete。

# 0｜本 Block 必须同时回答“两张表”

```text
结构表
外力方向 → 骨/韧带损伤 → 是否失稳 → 椎管/骨盆环是否受威胁

功能表
运动 + 感觉 + 反射/肌张力 + 括约肌 + 呼吸/循环
→ 脊髓、圆锥、马尾或神经丛层级
```

> **骨折稳定性与神经损伤是相关但独立的判断。**稳定骨折也可伴神经问题；不稳定骨折尚无神经缺失也必须防二次损伤。

# 2｜现场、影像与共同入口

<!-- kianos:kp id="orthopedics-o03-kp01" -->

## KP01｜脊柱骨折共同入口：T10–L2、X线、MRI和安全搬运

> **讲义定位 →** 外科 Lecture PDF P186，书页 P151。  
> **主提示**：好发T10–L2｜X常规｜MRI软4｜搬运2法。

- 脊柱骨折好发于 **T10–L2**；
- X线是骨科常规检查；
- 诊断脊髓、神经、韧带等软组织损伤时，Study 指向 **MRI**；
- 急救搬运采用**平托法、滚动法**，核心是让头颈躯干保持整体，避免屈曲、旋转和二次移位。

（易混：搬运的首要目标不是“让患者舒服”，而是维持轴线；高处坠落伴双下肢不能活动时，应先按脊柱合并脊髓损伤保护。）

---

<!-- kianos:kp id="orthopedics-o03-kp02" -->

## KP02｜脊柱损伤判断顺序：稳定性与神经功能并行

> **讲义定位 →** O1/O2 Framework + 外科 5.7。  
> **主提示**：2轴｜稳不稳｜神经5件｜先后？

```text
结构轴：骨折/脱位/韧带 → 是否稳定 → 是否可能继续压迫椎管
功能轴：肌力｜感觉｜反射/肌张力｜括约肌｜呼吸/自主功能
```

不能把“没有神经损伤”解释为“骨折稳定”，也不能把已有瘫痪当作放弃稳定保护的理由。任何复位、牵引和搬运都必须防止二次脊髓损害。

# 3｜颈椎屈曲与垂直压缩损伤

<!-- kianos:kp id="orthopedics-o03-kp03" -->

## KP03｜颈椎屈曲型：压缩骨折与骨折—脱位

> **讲义定位 →** 外科 Lecture PDF P186–187。  
> **主提示**：屈曲2型｜压缩1/3｜脱位先看椎间盘｜2路径。

### 压缩型骨折

- 压缩小于 **1/3**：Study 采用支具固定；
- 否则：手术方向。

### 骨折—脱位

- 无椎间盘突出：颅骨牵引复位后前路融合，或后路切开复位固定；
- 有椎间盘突出：复位前先前路切除椎间盘、植骨融合内固定，再处理后路复位固定。

核心理由：脱位复位可能使突出的椎间盘进一步压迫脊髓，因此先确认椎间盘与椎管内容物。

（边界：术式按当前 Study 口径保留，不扩写现代分型和入路选择。）

---

<!-- kianos:kp id="orthopedics-o03-kp04" -->

## KP04｜Jefferson 与爆裂型：同属垂直压缩，碎片方向不同

> **讲义定位 →** 外科 Lecture PDF P187，书页 P152。  
> **主提示**：垂压2｜J=C1双弓+CT｜爆=C3–7粉碎｜处理轴。

- **Jefferson 骨折**：C1 寰椎前、后弓双侧骨折；X线可能不易显示，务必加做 CT。骨块多向椎管周围移位，Study 采用 Halo 架固定约12周或颅骨牵引。
- **爆裂型骨折**：C3–C7 粉碎性骨折，碎片可进入椎管，神经风险更高，治疗偏手术。

（易混：Jefferson 的“碎块向四周”解释了为什么可不立即造成典型脊髓压迫；不能因此忽略稳定性评估。）

# 4｜过伸、齿状突与寰枢损伤

<!-- kianos:kp id="orthopedics-o03-kp05" -->

## KP05｜颈椎过伸：Hangman 与无骨折脱位过伸损伤

> **讲义定位 →** 外科 Lecture PDF P187。  
> **主提示**：过伸2｜Hangman=C2椎弓根｜移位定治疗｜Whiplash扩容。

- **Hangman/缢死者骨折**：C2 枢椎椎弓根骨折；无移位可 Halo 架或牵引固定，有移位偏手术。
- **无骨折—脱位的过伸损伤/Whiplash**：可造成脊髓受压；当前 Study 提及后路椎板成形、扩大椎管容积的治疗方向。

//串联：脊髓中央管周围综合征多见于颈椎过伸损伤，常表现上肢瘫重于下肢。

---

<!-- kianos:kp id="orthopedics-o03-kp06" -->

## KP06｜齿状突骨折与寰—枢椎脱位

> **讲义定位 →** 外科 Lecture PDF P187。  
> **主提示**：齿突Ⅰ/Ⅲ/Ⅱ无移位固定｜其余手术｜寰枢牵引→融合。

当前 Study 口径：

- 齿状突Ⅰ型、Ⅲ型和无移位Ⅱ型：Halo 架固定 6–8周；Ⅲ型可固定12周；
- 有移位Ⅱ型等：手术；
- 寰—枢椎脱位：牵引复位后做寰—枢椎融合术。

（特殊：C1、C2 之间无椎间盘，齿状突是重要稳定结构；学习时必须回原图。）

# 5｜胸腰椎与骨盆

<!-- kianos:kp id="orthopedics-o03-kp07" -->

## KP07｜Chance 骨折：横向撕裂性损伤

> **讲义定位 →** 外科 Lecture PDF P188，书页 P153。  
> **主提示**：Chance｜横裂3部｜机制1｜稳定？

Chance 骨折是经椎体、椎弓和棘突的**横向撕裂性骨折**。它不是单纯椎体压缩，而是后方结构也被牵开，提示应重点判断整体稳定性和椎管内容物。

（边界：当前 Study 以识别与结构特点为主，不扩写完整胸腰椎分型。）

---

<!-- kianos:kp id="orthopedics-o03-kp08" -->

## KP08｜骨盆骨折：先看环稳定，再看出血与伴随损伤

> **讲义定位 →** 外科 Lecture PDF P188，书页 P153。  
> **主提示**：体征4｜失血500–5000｜并发6｜不选脊髓。

提示体征：

- 骨盆分离试验、挤压试验阳性；
- 双下肢不等长；
- 会阴部瘀斑，尤其提示耻骨/坐骨骨折。

并发症：

- 失血性休克；
- 腹膜后血肿；
- 脂肪栓塞；
- 长期卧床相关 DVT/血栓栓塞；
- ARDS；
- 后尿道、膀胱、直肠、腰骶神经丛、坐骨神经损伤。

当前 Study 特别提醒：成人 L1 以下没有脊髓主体，骨盆骨折伴神经问题多考虑神经丛/周围神经，而不是直接选“脊髓损伤”。

<!-- kianos:kp id="orthopedics-o03-kp09" -->

## KP09｜骨盆骨折最先处理什么：休克优先，尿道顺序保留 Source Conflict

> **讲义定位 →** 外科 Lecture PDF P188、P191。  
> **主提示**：早期最危=休克｜首开通道｜尿道顺序2口径。

骨盆骨折失血量可达 **500–5000 mL**。当前 Study 冻结：

```text
最早系统性危险 = 失血性休克
首要动作 = 快速建立补液/输血通道并抗休克
```

关于“骨盆骨折 + 尿道损伤 + 休克”的后续顺序，Lecture 明确保留两种解释：

- 若“处理尿道损伤”指先导尿/膀胱造瘘，则可放在骨盆固定前；
- 若指正式尿道修补，则通常在骨盆处理后。

```text
SOURCE_CONFLICT / 待核对
稳定结论：休克必须最先处理
不稳定项：尿道临时引流与正式修补的相对顺序
```

# 6｜脊髓损伤总分流

<!-- kianos:kp id="orthopedics-o03-kp10" -->

## KP10｜脊髓震荡、不完全与完全损伤

> **讲义定位 →** 外科 Lecture PDF P188–190，书页 P154–155。  
> **主提示**：3层｜震荡最轻可恢复｜不全留功能｜完全全失。

- **脊髓震荡**：最轻微，功能可恢复；
- **不完全脊髓损伤**：损伤平面以下仍保留部分运动或感觉；
- **完全脊髓损伤**：平面以下感觉、运动功能完全丧失。

这三层先确定“残留功能程度”，再进入具体综合征和损伤平面。马尾神经损伤属于周围神经根集合损伤，不归入不完全性脊髓综合征。

---

<!-- kianos:kp id="orthopedics-o03-kp11" -->

## KP11｜四种不完全脊髓综合征：前、后、中、半

> **讲义定位 →** 外科 Lecture PDF P188–189。  
> **主提示**：4综合征｜前最重下>上｜后丢深｜中央上>下无分离｜半同深运/对浅。

| 综合征 | 当前 Study 主体表现 |
|---|---|
| 前脊髓综合征 | 最严重；可伴脊髓前中央动脉闭塞；下肢瘫重于上肢 |
| 后脊髓综合征 | 运动、痛温觉相对存在；本体感觉/深感觉障碍 |
| 中央管周围综合征 | 多见颈椎过伸；上肢瘫重于下肢；当前 Study 写“无感觉分离” |
| Brown-Séquard 半切 | 同侧运动与本体感觉障碍，对侧痛温觉障碍 |

逻辑来自通路交叉：皮质脊髓束和后索在脊髓内同侧行走；痛温觉纤维进入脊髓后较早交叉。

（易混：脊髓空洞症是慢性中央病变，典型痛温觉受损而触觉/深感觉相对保留；与急性中央管周围综合征的 Source 口径不同。）

---

<!-- kianos:kp id="orthopedics-o03-kp12" -->

## KP12｜完全脊髓损伤与脊休克：急性软瘫不等于 LMN 损伤

> **讲义定位 →** 外科 Lecture PDF P189。  
> **主提示**：脊休克2–4周｜先软后硬｜4平面组合。

完全脊髓损伤后，脊休克期可表现为平面以下软瘫、反射消失。当前 Study 口径：约 **2–4周**后若反射弧完整，可转为硬瘫：

- 肌张力增高；
- 腱反射亢进；
- 病理征阳性。

因此急性期看到软瘫不能直接判为周围神经/LMN 损伤，必须结合损伤机制、感觉平面和后续变化。

---

<!-- kianos:kp id="orthopedics-o03-kp13" -->

## KP13｜完全损伤四平面：上肢软/硬与下肢软/硬怎样组合

> **讲义定位 →** 外科 Lecture PDF P189。  
> **主提示**：C1–4四硬｜C5–T1上软下硬｜T2–L1下硬｜L2–S3下软。

当前 Study 表：

| 损伤平面 | 恢复脊休克后主要模式 |
|---|---|
| C1–C4 | 四肢硬瘫；高位还威胁呼吸 |
| C5–T1 | 上肢软瘫、下肢硬瘫 |
| T2–L1 | 上肢正常、下肢硬瘫 |
| L2–S3 | 上肢正常、下肢软瘫 |

核心是：损伤平面内的下运动神经元可造成节段性软瘫；平面以下长束中断造成硬瘫。

//串联：N11 已建立 UMN/LMN；O3 只把它放进创伤平面。

---

<!-- kianos:kp id="orthopedics-o03-kp14" -->

## KP14｜脊髓圆锥与马尾：共同鞍区/括约肌，运动表现不同

> **讲义定位 →** 外科 Lecture PDF P190。  
> **主提示**：共同2｜鞍区+二便｜圆锥下肢？｜马尾软瘫。

共同表现：

- 会阴/鞍区感觉障碍；
- 括约肌功能丧失、二便异常。

当前 Study 区分：

- 脊髓圆锥损伤：下肢运动可相对正常；
- 马尾神经损伤：下肢运动障碍，表现为软瘫。

（边界：完整圆锥/马尾综合征的现代临床谱不在当前 Source；本 Block冻结 Study 明确支持的考试轴。）

# 7｜并发症与治疗出口

<!-- kianos:kp id="orthopedics-o03-kp15" -->

## KP15｜脊髓损伤并发症：肺—肾—压疮—自主神经

> **讲义定位 →** 外科 Lecture PDF P190。  
> **主提示**：并发7｜肺3｜泌尿3｜压疮｜自主高热。

- 坠积性肺炎；
- 呼吸道感染；
- 呼吸衰竭；
- 尿潴留；
- 泌尿生殖道感染；
- 结石；
- 压疮；
- 自主神经功能紊乱，可出现高热。

这些并发症来自长期卧床、咳痰和通气泵失败、排尿障碍、感觉缺失和交感调节中断。第一轮要把它们挂回相应系统，而不是背孤立名单。

<!-- kianos:kp id="orthopedics-o03-kp16" -->

## KP16｜脊髓损伤当前 Study 的治疗时间、手术与气管切开指征

> **讲义定位 →** 外科 Lecture PDF P190。  
> **主提示**：黄金6–8h｜治疗2｜手术4｜气切4。

当前 Study 冻结口径：

- 伤后 **6–8小时**为黄金时期；
- 使用甲泼尼龙、高压氧疗；
- 手术指征：骨折—脱位、复位不满意、碎骨片突入椎管、椎管内活动性出血；
- 气管切开指征：上颈椎损伤、呼吸衰竭、呼吸道感染且痰液不易咳出、窒息。

## KP17｜O3 病例算法：先轴线、再双轴、最后命名

> **讲义定位 →** 本 Block Integration。  
> **主提示**：现场4步｜结构2问｜神经5件｜红旗5。

```text
高能外伤/背颈痛/双下肢异常
→ 保持轴线，平托或滚动
→ 呼吸与循环；骨盆大出血？
→ 结构：颈/胸腰/骨盆，是否失稳？
```
