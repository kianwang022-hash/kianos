# 0｜统一入口：听觉要跨过“空气—固体—液体—毛细胞—神经”五种载体

听觉不是“声波直接刺激听神经”。完整链条：

```text
空气声波
→ 外耳道
→ 鼓膜振动
→ 听骨链
→ 前庭窗 / 卵圆窗
→ 耳蜗外淋巴与基底膜行波
→ 螺旋器毛细胞机械—电换能
→ 感受器电位
→ 内毛细胞释放递质
→ 听神经动作电位
→ 颞横回听觉中枢
```

中间有三个关键转换：

1. **空气 → 固体机械振动**：鼓膜、听骨链；
2. **固体 → 液体 / 基底膜行波**：前庭窗、外淋巴、基底膜；
3. **机械 → 电**：毛细胞机械门控通道、K⁺内流、受体电位。

> **本 Block 最低地图**：声波 → 鼓膜 / 听骨 → 卵圆窗 → 基底膜 → 毛细胞 → 听神经 AP。

# 2｜外耳和中耳：把声波“高保真”送到耳蜗

<!-- kianos:kp id="neuro-n07-kp01" -->

## KP01｜鼓膜 + 咽鼓管：一个高保真振动，一个维持两侧压力平衡

> **讲义定位 →** 生理 Lecture PDF P314，书页 P275。  
> **主提示**：鼓膜形状｜高保真｜咽鼓管2作用｜何时开｜阻塞→内陷。

### 鼓膜

- 位于外耳与中耳之间；
- 呈漏斗状，不是平面；
- 当前 Study 强调失真小、频率响应好，可较真实地跟随声波振动。

### 咽鼓管

连接鼻咽与中耳鼓室：

```text
平时鼻咽端多闭合
→ 吞咽 / 打哈欠时开放
→ 空气进入鼓室
→ 鼓室压力与外界大气压趋于平衡
→ 鼓膜保持正常位置和传音功能
```

若炎症导致咽鼓管阻塞：

```text
外界空气不能补入鼓室
→ 鼓室原有空气逐渐被吸收
→ 鼓室压力下降
→ 鼓膜内陷
→ 传音受影响
```

<!-- kianos:kp id="neuro-n07-kp02" -->

## KP02｜听骨链做“增压减幅”；鼓膜张肌 / 镫骨肌保护强声，但来不及挡爆炸

> **讲义定位 →** 生理 Lecture PDF P315，书页 P276。  
> **主提示**：听骨链2结果｜压强↑振幅↓｜保护肌2｜强声可/爆炸不。

鼓膜和听骨链把大面积、较大振幅的鼓膜振动传到较小面积的前庭窗：

> **压强增加，振幅减小。**

这使空气中的振动更有效地进入耳蜗液体，是当前 Study 对中耳“阻抗匹配”意义的核心表达。

### 保护反射

声压过大时：

- 鼓膜张肌；
- 镫骨肌

可反射性收缩，限制传入内耳的振动，保护耳蜗。

但：

> 肌肉收缩需要时间，因此对**突发爆炸声**保护作用有限。

（易混：中耳的目标不是把“振幅也放大”，而是**增压 + 减幅**。）

# 3｜气导、骨导与故障层定位

<!-- kianos:kp id="neuro-n07-kp03" -->

## KP03｜气导是正常主路，骨导绕过外中耳；传音聋 vs 感音聋先按层分

> **讲义定位 →** 生理 Lecture PDF P317，书页 P278。  
> **主提示**：气导2路+主路｜骨导1路｜传音病变层｜感音病变层｜气/骨变化。

### 气传导：正常主导

主要路径：

```text
声波
→ 外耳道
→ 鼓膜
→ 听骨链（锤—砧—镫）
→ 前庭窗 / 卵圆窗
→ 前庭阶外淋巴
→ 耳蜗机械振动
```

当前 Study 还列一条经鼓室空气 → 蜗窗 / 圆窗 → 鼓阶的气导旁路。

### 骨传导

```text
声波使颅骨振动
→ 耳蜗骨壁振动
→ 耳蜗液体 / 基底膜振动
```

其正常效能远低于气导，但可绕过部分外耳、中耳结构。

### 两类障碍接口

| 故障层 | 当前 Study 定位 | 传导方向 |
|---|---|---|
| 传音性耳聋 | 外耳 / 中耳，如鼓膜、咽鼓管、鼓室、听骨链 | 气导异常；骨导相对保留 / 显现 |
| 感音性耳聋 | 耳蜗，如螺旋器、毛细胞、血管纹 | 气导、骨导均异常 |

> 本处只学习“故障在哪一层”；完整耳聋分类、听力图和临床处理属于 Source Boundary。

# 4｜耳蜗机械：前庭窗推液体，圆窗给压力找出口

<!-- kianos:kp id="neuro-n07-kp04" -->

## KP04｜耳蜗三腔 + 两窗：前庭/鼓阶外淋巴，蜗管内淋巴

> **讲义定位 →** 生理 Lecture PDF P315–316，书页 P276–277。  
> **主提示**：3腔｜外/内淋巴｜前庭窗起点｜蜗窗终点｜液体不可压→3位移。

耳蜗主空间：

| 腔 | 液体 |
|---|---|
| 前庭阶 | 外淋巴 |
| 蜗管 / 中阶 | 内淋巴 |
| 鼓阶 | 外淋巴 |

- 前庭阶在蜗底从**前庭窗 / 卵圆窗**接受镫骨振动；
- 鼓阶在蜗底通过**蜗窗 / 圆窗**缓冲压力；
- 前庭阶和鼓阶可相通，不与蜗管直接混合。

当镫骨使前庭窗膜内移：

```text
外淋巴被推动（液体不可压缩）
→ 前庭膜 / 基底膜发生位移
→ 圆窗膜向外移释放压力
→ 基底膜上下振动
→ 螺旋器受到机械刺激
```

若振动方向反转，上述位移方向也相反。

> 这是一组必须看 P315–316 原图的空间关系。

# 5｜耳蜗先建立一个特殊的“高K⁺电池”

<!-- kianos:kp id="neuro-n07-kp05" -->

## KP05｜血管纹：维持内淋巴高K⁺与约+80mV耳蜗内电位

> **讲义定位 →** 生理 Lecture PDF P318，书页 P279。  
> **主提示**：内/外淋巴离子｜+80｜血管纹3转运｜缺氧/哇巴因｜袢利尿剂NKCC。

当前 Study 的离子环境：

- 前庭阶 / 鼓阶外淋巴：高 Na⁺、低 K⁺，电位参考约 0；
- 蜗管内淋巴：高 K⁺、低 Na⁺，耳蜗内 / 内淋巴电位约 **+80 mV**；
- 毛细胞静息电位约 -80～-70 mV。

血管纹负责建立和维持这套特殊环境，涉及：

- Na⁺-K⁺泵；
- Na⁺-K⁺-2Cl⁻同向转运体；
- K⁺通道。

故：

```text
缺氧 / ATP不足 / 哇巴因
→ 主动转运受损
→ 内淋巴正电位难维持
→ 毛细胞换能受损

袢利尿剂抑制血管纹NKCC
→ 内淋巴高K⁺ / 正电位下降
→ 感音性听力障碍接口
```

（串联：NKCC 在泌尿已学过；这里只学习它为什么也会进入耳蜗电环境。）

# 6｜基底膜先把频率拆开，再让毛细胞读出

<!-- kianos:kp id="neuro-n07-kp06" -->

## KP06｜行波学说：所有波从蜗底出发，高频停得早，低频走得远

> **讲义定位 →** 生理 Lecture PDF P319，书页 P280。  
> **主提示**：起点1｜向顶｜最大振幅1点｜高频底｜低频顶｜损伤反推。

不同频率的声波都会：

```text
从耳蜗底部、靠近前庭窗处开始
→ 沿基底膜向蜗顶传播
→ 在某一位置达到最大振幅
→ 随后迅速衰减
```

频率—位置：

| 频率 | 行波传播 | 最大振幅位置 | 对应损伤 |
|---|---|---|---|
| 高频 | 传播短、衰减快 | 靠蜗底 | 蜗底损伤 → 高频听力受影响 |
| 低频 | 传播远 | 靠蜗顶 | 蜗顶损伤 → 低频听力受影响 |

一句话：

> **高频在底，低频在顶；低调走得更远。**

这使耳蜗本身先完成机械“频率分析”，不同位置的毛细胞再把位置编码送给听神经。

## KP07｜毛细胞机械—电换能：向长纤毛偏→机械通道开→K⁺内流→去极化

> **讲义定位 →** 生理 Lecture PDF P320，书页 P281。  
> **主提示**：基底膜↑/↓｜纤毛方向｜机械门控｜K⁺方向｜去/超极化｜Ca→递质。

当前 Study 的换能链：

```text
基底膜运动
→ 螺旋器与盖膜相对位移
→ 毛细胞纤毛弯曲
```

当短纤毛向长纤毛方向偏转：

```text
机械门控非选择性阳离子通道开放
→ 因内淋巴高K⁺且电位为正，K⁺进入毛细胞
→ 毛细胞去极化
→ 基底侧电压门控Ca²⁺通道开放
→ Ca²⁺内流
→ 内毛细胞释放递质
→ 听神经动作电位
```

反方向偏转 → 机械门控通道关闭趋势 → 毛细胞超极化。

（易混：多数细胞谈 K⁺常想到外流；耳蜗毛细胞顶部接触**高K⁺、正电位内淋巴**，所以机械通道开放时 K⁺可内流并去极化。）

<!-- kianos:kp id="neuro-n07-kp08" -->

## KP08｜内毛细胞传信号，外毛细胞做放大器

> **讲义定位 →** 生理 Lecture PDF P320。  
> **主提示**：内=Ca/递质/AP｜外=长短变化｜马达蛋白｜放大基底膜｜敏感性↑。

### 内毛细胞

```text
去极化
→ Ca²⁺通道开放
→ Ca²⁺内流
→ 释放递质
→ 听神经产生动作电位
```

因此内毛细胞更偏向：**把已经分解出的声学信息传给神经。**

### 外毛细胞

当前 Study：

- 去极化时胞体缩短；
- 超极化时胞体伸长；
- 借助马达蛋白快速改变长度；
- 加强局部基底膜运动，提高内毛细胞对相应频率的敏感性。

因此：

> **内毛细胞偏“输出”，外毛细胞偏“机械放大”。**

# 7｜输出不只有AP：耳蜗微音器电位是毛细胞群体的高保真局部电位

<!-- kianos:kp id="neuro-n07-kp09" -->

## KP09｜耳蜗微音器电位：局部、等级、高保真、不适应，位相随声波倒转

> **讲义定位 →** 生理 Lecture PDF P321，书页 P282。  
> **主提示**：来源｜局部电位6特征｜频率/幅度保真｜不适应｜位相倒转。

耳蜗微音器电位 = 多个毛细胞感受器电位的复合表现。

当前 Study 特征：

- 局部电位；
- 等级性；
- 无明确阈值；
- 无潜伏期 / 不应期；
- 可总和；
- 传播衰减；
- 与声波频率和幅度高度一致，失真小；
- 不易疲劳、不适应；
- 声音位相倒转时，微音器电位位相也倒转。

（易混：听神经动作电位具有神经 AP 性质；耳蜗微音器电位仍是毛细胞群体的局部电位。）

## KP10｜听阈与听域：先区分“能听哪些频率”与“每个频率最小需要多强”

> **讲义定位 →** 生理 Lecture PDF P321，书页 P282。  
> **主提示**：听域2维｜20–20000｜最敏1–3k｜听阈定义｜最大可听阈。

### 听域

人耳能感受声音的**频率和强度范围**。

当前 Study 数字：

- 频率约 **20–20,000 Hz**；
- 对 **1,000–3,000 Hz** 最敏感。

### 听阈

对某一特定频率，刚能引起听觉的**最小声音强度**。

### 最大可听阈

声音强度继续增加，到引起鼓膜疼痛 / 达到可忍受最大强度的上限。

因此图上：

```text
下界 = 不同频率的听阈
上界 = 最大可听阈
两条曲线之间 = 听域
```

数字进入 MI-D；第一轮先理解“频率范围”和“强度阈值”是两条轴。

## KP11｜整条听觉链的故障定位：传音、耳蜗电环境、机械频率图、毛细胞、神经

> **讲义定位 →** 生理 Lecture PDF P322–324。

用一张“哪里断了”表收口：

| 故障层 | 直接后果 | 当前定位线索 |
|---|---|---|
| 外耳 / 鼓膜 / 听骨 / 咽鼓管 | 声波难有效进入耳蜗 | 传音性障碍；气导更受影响 |

| 基底膜局部 | 特定频率最大振幅区损坏 | 蜗底高频、蜗顶低频 |
| 内毛细胞 | 递质输出到听神经下降 | 感觉输出失败 |
| 外毛细胞 | 局部放大下降 | 相应频率敏感性下降 |
| 听神经 / 中枢 | 动作电位传入 / 感觉形成受损 | 当前仅作边界，不展开临床 |

完整链：


# 8｜三张高价值比较表

## 8.1 气导 vs 骨导

```text
气导：外耳道—鼓膜—听骨—前庭窗—耳蜗（正常主导）
骨导：颅骨 / 耳蜗骨壁—耳蜗液体（低效旁路）
```

## 8.2 内淋巴 vs 外淋巴

| 轴 | 内淋巴 | 外淋巴 |
|---|---|---|
| 位置 | 蜗管 | 前庭阶、鼓阶 |
| 离子特征 | 高K⁺、低Na⁺ | 高Na⁺、低K⁺ |
| 电位 | 约 +80mV耳蜗内电位 | 参考约0 |
| 关键结构 | 血管纹维持 | 与前庭 / 鼓阶机械传播相关 |

## 8.3 内毛 vs 外毛

```text
内毛：机械电换能后 → Ca²⁺ → 递质 → 听神经
外毛：电位变化 → 细胞长度改变 → 放大基底膜运动
```
