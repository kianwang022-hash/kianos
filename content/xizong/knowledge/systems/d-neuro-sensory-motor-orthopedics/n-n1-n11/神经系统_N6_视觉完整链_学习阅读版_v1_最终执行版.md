# 0｜统一入口：视觉是“先把像送对地方，再把光变成神经信号”

视觉不是单一的“眼睛看见”。它至少连续通过四层：

```text
光线
→ 折光系统把物像落到视网膜
→ 感光细胞完成光—电换能
→ 双极 / 水平 / 无长突 / 神经节网络加工
→ 神经节细胞动作电位
→ 视神经—视交叉—视束—外侧膝状体—视辐射
→ 枕叶视觉中枢
→ 形成视觉
```

故任何视觉题都可先定位故障层：

```text
成像错误？
→ 折光 / 调节 / 瞳孔

视网膜换能错误？
→ 感光细胞 / 视色素 / cGMP / 视杆视锥

空间整合错误？
→ 视野 / 双眼视觉 / 视敏度

神经传导错误？
→ 视神经 / 视交叉 / 视束 / 视辐射 / 皮层
```

> **本 Block 最低地图**：折光成像 → 感光局部电位 → 神经节 AP → 视路 → 枕叶。

# 2｜先把像准确送到视网膜

<!-- kianos:kp id="neuro-n06-kp01" -->

## KP01｜视觉两套系统：折光负责成像，感光负责把光变成神经电信号

> **讲义定位 →** 生理 Lecture PDF P297，书页 P260。  
> **主提示**：折光/感光2系统｜成像部位｜倒像｜局部电位→AP｜中枢。

视觉先分两层：

1. **折光系统**：把光线聚焦于视网膜，形成上下左右颠倒的倒像；
2. **感光系统**：把光信号转换成神经电信号。

真正能沿神经长距离传导的是动作电位：

```text
感光细胞局部电位
→ 视网膜网络加工
→ 神经节细胞动作电位
→ 视神经
→ 枕叶视觉中枢
```

（易混：感光细胞本身产生局部感受器电位，**不是**直接把动作电位一路传到皮层。）

## KP02｜四个折光体：空气—角膜前表面折光最强；看远正常不需调节

> **讲义定位 →** 生理 Lecture PDF P298，书页 P261。  
> **主提示**：折光体4｜最强界面1｜远6m｜远点｜近点｜弹性方向。

折光系统包括：

- 角膜；
- 房水；
- 晶状体；
- 玻璃体。

入眼光线折射最主要发生在：

> **空气—角膜前表面。**

原因不是晶状体不重要，而是空气与角膜折射率差明显大于眼内各折光介质之间的差异。

### 看远 vs 看近

- 约 6 m 以外的远物，入眼近似平行光；正视眼通常**无需调节**即可成像在视网膜；
- 近物发出辐射光，未经调节时焦点偏在视网膜后，需要增强折光能力。

定义：

- **远点**：不做任何调节时能看清的最远距离；
- **近点**：做充分调节时能看清的最近距离。

晶状体弹性越好 → 调节能力越强 → 近点越近。

<!-- kianos:kp id="neuro-n06-kp03" -->

## KP03｜看近三联：晶状体变凸最重要，另加缩瞳与双眼会聚

> **讲义定位 →** 生理 Lecture PDF P298–299，书页 P261–262。  
> **主提示**：看近3反应｜睫状肌M链5步｜缩瞳作用2｜会聚N2｜复视。

### 1｜晶状体调节：最重要

```text
副交感 ACh
→ 睫状肌 M 受体
→ 睫状肌收缩
→ 悬韧带 / 睫状小带松弛
→ 晶状体靠自身弹性变凸
→ 屈光度↑
→ 近物焦点前移到视网膜
```

### 2｜瞳孔调节反射 / 近反射

```text
虹膜环形肌 / 瞳孔括约肌收缩（M）
→ 瞳孔缩小
→ 减少球面像差 + 色像差
→ 成像更清晰
```

### 3｜视轴会聚 / 辐辏

```text
内直肌收缩（躯体运动神经，ACh-N2）
→ 双眼向鼻侧会聚
→ 物像落在双眼视网膜对称点
→ 单视，避免复视
```

眼外肌瘫痪或眼球内占位压迫 → 物像落到非对称点 → 复视。

（易混：睫状肌、瞳孔括约肌是 M；内直肌是骨骼肌 N2。都用 ACh，但神经与受体不同。）

## KP04｜对光反射 vs 近反射：都能缩瞳，但启动和目的不同

> **讲义定位 →** 生理 Lecture PDF P300，书页 P263。  
> **主提示**：强/弱光方向｜单眼照双眼缩｜中枢｜对光/近反射目的｜是否看近调节。

### 瞳孔对光反射

- 强光 → 瞳孔缩小，减少入眼光量、保护视网膜；
- 弱光 → 瞳孔扩大，增加入眼光量；
- 光照一侧眼 → 双眼瞳孔同时缩小；
- 当前 Study：中枢在**中脑**。

### 与瞳孔近反射比较

| 轴 | 对光反射 | 瞳孔近反射 |
|---|---|---|
| 启动 | 光强变化 | 看近物 |
| 结果 | 缩瞳 | 缩瞳 |
| 主要意义 | 调节入眼光量、防强光损伤 | 减少球面 / 色像差、提高清晰度 |
| 看近三联的一部分？ | 否 | 是 |

（易混：2018 / 2023 类题常把“瞳孔对光反射”混进看近三联。）

# 3｜折光系统故障：先问焦点落在视网膜前还是后

<!-- kianos:kp id="neuro-n06-kp05" -->

## KP05｜近视、远视、老视、散光：焦点和调节能力是两条不同轴

> **讲义定位 →** 生理 Lecture PDF P300。  
> **主提示**：近/远/老3机制｜焦点前后｜近/远点｜凹/凸镜｜散光曲率+柱面。

| 轴 | 近视 | 远视 | 老视 |
|---|---|---|---|
| 第一故障 | 眼轴过长或折光过强 | 眼轴过短或折光过弱 | 晶状体弹性下降 |
| 未调节远物焦点 | 视网膜前 | 视网膜后 | 远点通常不受影响 |
| 调节 | 近物需求较少 | 看远、看近均需额外调节 | 看近调节不足 |
| 近点 | 近移 | 远移 | 远移 |
| 远点 | 近移 | 当前 Study 视为正常远点消失 / 需调节看远 | 正常 |
| 矫正 | 凹透镜 | 凸透镜 | 看近用凸透镜 |

**散光**：角膜或晶状体不同经线曲率不等 → 光线不能聚焦同一焦平面 → 物像变形 / 模糊；规则散光用柱面镜。

当前 Study 分类：

> 屈光不正 = 近视 + 远视 + 散光；**不包括老视**。

## KP06｜房水与三个短临床接口：青光眼看“生成—排出”，白内障看晶状体，飞蚊看玻璃体

> **讲义定位 →** 生理 Lecture PDF P301，书页 P264。  
> **主提示**：房水5步｜青光眼故障｜减少生成2类｜促排1类｜白晶/飞玻。

当前 Study 的房水通路：

```text
睫状体产生
→ 后房
→ 经瞳孔
→ 前房
→ 前房角 / 小梁网
→ 巩膜静脉窦
→ 静脉循环
```

青光眼的 Lecture 入口：房水循环 / 排出障碍 → 眼压病理性升高。

治疗只保留当前 Source 的机制配对：

- 减少房水生成：β受体阻断剂（如噻吗洛尔）、碳酸酐酶抑制剂（如乙酰唑胺）；
- 促进房水排出：M受体激动剂毛果芸香碱 → 缩瞳 → 前房角间隙扩大。

另外两个识别接口：

- 白内障 → **晶状体混浊**；
- 飞蚊症 → **玻璃体混浊**。

> 这些只是当前生理 Lecture / Outline 自带的短接口，不扩写完整眼科诊疗。

# 4｜视网膜：光先到感光细胞，动作电位最后才在神经节细胞出现

<!-- kianos:kp id="neuro-n06-kp07" -->

## KP07｜视网膜四层：色素上皮保护，感光换能，双极中继，神经节放AP

> **讲义定位 →** 生理 Lecture PDF P301，书页 P264。  
> **主提示**：由外向内4层｜RPE 3作用｜谁换能｜谁AP｜盲点缺谁。

当前 Study 由外向内的主链：

```text
色素上皮细胞
→ 感光细胞（视杆 / 视锥）
→ 双极细胞
→ 神经节细胞
```

### 色素上皮三大角色

1. 黑色素吸收散射光，维持“暗室”环境；
2. 为外层视网膜输送营养、参与感光细胞代谢并吞噬外段脱落膜盘；
3. 细胞间紧密连接参与**血—视网膜屏障**。

### 电信号分工

- 视杆 / 视锥：完成感光换能，产生局部感受器电位；
- 神经节细胞：达到阈值后产生动作电位；其轴突汇成视神经。

**生理性盲点** = 视神经盘 / 视神经乳头，因视神经离开眼球处**没有感光细胞**。

<!-- kianos:kp id="neuro-n06-kp08" -->

## KP08｜光换能反常链：光来了，cGMP通道反而关闭，感光细胞超极化

> **讲义定位 →** 生理 Lecture PDF P302–303，书页 P265–266。  
> **主提示**：光→视紫红质→GPCR→Gt→PDE→cGMP↓｜通道关｜Na暗流↓｜K漏｜超极化。

当前 Study 用视杆细胞说明光换能：

```text
光
→ 视紫红质发生光化学变化
→ 视蛋白（GPCR）激活
→ Gt / transducin
→ cGMP-PDE激活
→ cGMP水解、浓度↓
→ 外段cGMP门控阳离子通道关闭
→ Na⁺暗电流↓（同时少量Ca²⁺内流也↓）
→ 内段K⁺漏出继续
→ 膜电位更负
→ 超极化型感受器电位
→ 递质释放改变
```

特殊之处：

> 多数兴奋细胞受刺激时去极化；**感光细胞受光刺激时产生超极化型局部电位**。

Ca²⁺内流下降还能解除对鸟苷酸环化酶的抑制，使 cGMP 合成回升，形成当前 Study 的适应 / 稳态接口。

<!-- kianos:kp id="neuro-n06-kp09" -->

## KP09｜感光细胞不放AP：局部电位先改递质，神经节细胞才点燃视神经

> **讲义定位 →** 生理 Lecture PDF P302。  
> **主提示**：感光细胞电位类型｜递质｜AP细胞1｜视神经来源｜枕叶。

```text
视杆 / 视锥超极化感受器电位
→ 影响突触末梢递质释放
→ 双极 / 视网膜网络整合
→ 神经节细胞达到阈值
→ 动作电位
→ 神经节细胞轴突组成视神经
→ 枕叶视觉中枢
```

因此视觉中的“局部电位—动作电位”分界必须记清：

- 光换能发生在感光细胞；
- 长距离 AP 由神经节细胞输出。

（易混：这正是 N5 感觉共同语言在视觉中的具体实现。）

# 5｜视锥与视杆：一个换分辨率，一个换灵敏度

<!-- kianos:kp id="neuro-n06-kp10" -->

## KP10｜视锥 vs 视杆：明/暗、色/无色、高视敏/高光敏是四条主轴

> **讲义定位 →** 生理 Lecture PDF P303–304，书页 P266–267。  
> **主提示**：明/暗｜3/1色素｜中央/周围｜单线/会聚｜视敏/光敏｜反应快慢。

| 轴 | 视锥细胞 | 视杆细胞 |
|---|---|---|
| 主要视觉 | 明视觉 | 暗视觉 |
| 颜色 | 三类视锥色素，形成色觉 | 一种视紫红质，无色觉 |
| 分布 | 中央多；中央凹只有视锥 | 周围多 |
| 与后级联系 | 会聚少，中央凹近一对一单线 | 多对一会聚明显 |
| 视敏度 / 分辨率 | 高 | 低 |
| 光敏度 | 低 | 高 |
| 对光反应 | 快 | 慢，利于时间总和提高弱光敏感性 |

核心 trade-off：

```text
单线、少会聚
→ 每个空间点被保留
→ 分辨率高

多对一会聚
→ 多个弱输入相加
→ 灵敏度高，但空间信息被合并
```

## KP11｜视紫红质与VitA：11-顺见光变全反，暗处再合成；缺VitA→夜盲接口

> **讲义定位 →** 生理 Lecture PDF P304。  
> **主提示**：视紫红质2成分｜11顺→全反｜漂白｜暗处再生｜VitA｜夜盲。

视杆细胞的视色素为**视紫红质**，由视蛋白 + 视黄醛组成。

当前 Study 的光化学方向：

```text
暗处：11-顺视黄醛 + 视蛋白
→ 视紫红质

光照
→ 11-顺视黄醛变为全反型
→ 与视蛋白分离
→ 视紫红质漂白 / 分解

暗处
→ 全反型经色素上皮处理回到11-顺
→ 再与视蛋白结合
→ 视紫红质重新合成
```

视黄醛由 VitA 转变而来，因此当前 Study 串联：

> 肝硬化或长期 VitA 摄入不足 → 视紫红质再生受影响 → 夜盲症接口。

这不是本 Block 展开的营养治疗模型，只保留机制链。

## KP12｜视敏度：中央凹“细胞密 + 单线联系”，不是因为光敏度最高

> **讲义定位 →** 生理 Lecture PDF P304。  
> **主提示**：定义｜中央凹2原因｜视角倒数｜1分角｜光敏≠视敏。

视力 / 视敏度是眼分辨物体两点间最小距离的能力，即**空间分辨能力**。

中央凹视敏度高的结构基础：

1. 视锥细胞密度高、直径小；
2. 视锥—双极—神经节的会聚少，接近单线联系。

因此：

> **中央凹高视敏度 ≠ 高光敏度。**

高光敏度属于周边视杆系统；它靠大量会聚换取弱光检测能力。

当前 Study 低频数字：标准视力 1.0 对应约 **1 分角**，进入 MI-D，不阻塞主链。

## KP13｜明适应 vs 暗适应：明快锥恢复，暗慢杆恢复

> **讲义定位 →** 生理 Lecture PDF P305，书页 P268。  
> **主提示**：暗→明/明→暗｜锥/杆｜快/慢｜先看不清原因｜两阶段。

| 轴 | 明适应 | 暗适应 |
|---|---|---|
| 场景 | 暗处 → 明处 | 明处 → 暗处 |
| 主体 | 视锥系统恢复主导 | 视杆系统恢复主导 |
| 速度 | 快 | 慢 |
| 初始看不清 | 暗处积累的视紫红质进入强光迅速分解，耀眼 | 明处视紫红质已大量分解，刚进暗处光敏度低 |
| 后续恢复 | 视杆色素分解后，视锥继续工作 | 视色素逐渐合成，后期主要靠视杆视紫红质增多 |

当前 Study 细节：暗适应早期有视锥色素贡献，后期主要是视杆视紫红质再生；精确分钟数进入 MI-D。

## KP14｜视野、双眼视觉、视后像与融合：四个概念不要互相替代

> **讲义定位 →** 生理 Lecture PDF P306–307，书页 P269–270。  
> **主提示**：视野定义｜3因素｜颞>鼻/下>上｜双眼3意义｜分辨力不是｜后像/融合。

### 1｜视野

单眼固定注视正前方一点时，该眼能看到的最大空间范围。

影响因素：

- 感光细胞分布范围；
- 面部结构遮挡；
- 物体颜色。

当前 Study 方向：

- 颞侧视野 > 鼻侧；
- 下方视野 > 上方；
- 颜色视野：白 > 黄 > 蓝 > 红 > 绿；
- 与物体大小、形状无关。

### 2｜双眼视觉

基础：视交叉**部分交叉**，使每侧大脑半球能同时获得双眼信息。

意义：

- 弥补单眼生理盲点；
- 扩大视野；
- 产生立体视觉 / 视差感。

不负责：增强感觉系统分辨能力——那是 N5 的侧向抑制。

### 3｜视后像 / 视觉融合

- 视后像：刺激结束后视觉形象不会立即消失；
- 视觉融合：重复闪光频率足够高后，不能分辨相邻刺激时间差，主观形成连续光感。

Lecture 的帧率例子属于 RECOGNITION / MI-D，不作为视觉主机制门槛。

## KP15｜视路全链：神经节轴突→视神经→视交叉→视束→LGN→视辐射→枕叶

> **讲义定位 →** 生理 Lecture PDF P308，书页 P271。
