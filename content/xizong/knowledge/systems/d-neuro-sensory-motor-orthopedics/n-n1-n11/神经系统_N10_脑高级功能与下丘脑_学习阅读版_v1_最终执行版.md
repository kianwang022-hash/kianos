# 0｜统一入口：一个系统保存经验，一个系统把内环境变成行为

本 Block 包含两个相邻但不同的中心问题。

### 高级功能

```text
感觉 / 行为输入
→ 联络区和突触网络加工
→ 建立联系或调整反应
→ 形成短期 / 长期记忆
→ 通过语言、动作和决策表达
```

### 下丘脑

```text
温度、容量、渗透压、激素和昼夜信号
→ 下丘脑感受与比较
→ 自主神经输出
+ 垂体 / 神经内分泌输出
+ 摄食、饮水、情绪等行为输出
→ 恢复稳态
```

> **本 Block 最低地图**：经验输入 → 网络可塑性 → 记忆 / 语言；内环境输入 → 下丘脑 → 自主 + 内分泌 + 行为。

# 2｜学习：神经系统怎样改变对刺激的反应

<!-- kianos:kp id="neuro-n10-kp01" -->

## KP01｜联合型 vs 非联合型学习：要不要在两个事件间建立联系

> **讲义定位 →** 生理 Lecture PDF P386，书页 P336。  
> **主提示**：联合定义2对象｜重复接近｜例1｜非联合1刺激｜2类型。

### 联合型学习

两种刺激，或一种行为与一种刺激，在时间上反复接近，最终在脑内逐渐形成联系。

经典入口：条件反射的建立和消退。

### 非联合型学习

不要求在两个刺激或刺激—反应之间建立联系，只需同一个刺激重复出现，即可改变机体对它的反应。

包括：

- 习惯化；
- 敏感化。

（易混：LTP是学习记忆的细胞机制接口，不等于“非联合型学习第三类”。）

---

<!-- kianos:kp id="neuro-n10-kp02" -->

## KP02｜习惯化 vs 敏感化；再与感受器适应分层

> **讲义定位 →** 生理 Lecture PDF P386。  
> **主提示**：刺激强度2｜突触效能方向｜行为意义｜感受器适应在哪层

| 轴 | 习惯化 | 敏感化 |
|---|---|---|
| 刺激 | 反复温和、无意义 | 伤害性刺激 |
| 突触效能 | 短时程减弱 | 短时程增强 |
| 行为意义 | 忽略重复无意义信息 | 提高对潜在伤害的警戒 |
| 例 | 单调声音不再引起探究反射 | 创伤后轻触也引起明显疼痛 |

### 与感受器适应的边界

- **适应**：感受器层面，同一刺激持续后传入频率下降；
- **习惯化**：大脑 / 神经网络层面，对重复刺激的行为反应减弱。

两者都可由单一刺激重复引起，但故障层不同。

# 3｜记忆：按“内容”和“时间”建立两套坐标

<!-- kianos:kp id="neuro-n10-kp03" -->

## KP03｜记忆四格：陈述 / 非陈述 × 短时 / 长时，不是同一条分类轴

> **讲义定位 →** 生理 Lecture PDF P387，书页 P337。  
> **主提示**：内容轴2｜时间轴2｜可否交叉｜可否转化/强化。

记忆可按不同维度分类：

```text
内容 / 提取方式：陈述性 vs 非陈述性
保存时间：短时程 vs 长时程
```

它们不是互斥的四个“同级盒子”。例如一段陈述性知识可以先以短时形式存在，再经重复形成长时记忆。

Study强调：

- 陈述性与非陈述性可在反复练习中发生转化接口；
- 短时程记忆可经反复运用、强化转为长时程。

## KP04｜陈述性 vs 非陈述性：能不能说出来、是否依赖意识、主要网络

> **讲义定位 →** 生理 Lecture PDF P387。  
> **主提示**：意识有/无｜易忘/难忘｜内容2例｜脑区3/3｜可转化。

| 轴 | 陈述性记忆 | 非陈述性记忆 |
|---|---|---|
| 内容 | 可用语言表述或以影像保持的事实 / 事件 | 操作程序、技能和规律性行为 |
| 与意识 | 有关 | 相对无意识 / 程序化 |
| 遗忘 | 较容易 | 较不容易 |
| Study脑区 | 海马、内侧颞叶、杏仁核等 | 基底神经节 / 纹状体、皮层小脑、感觉运动皮层等 |
| 例 | 回忆某段经历 | 游泳、开车 |

反复练习可使原先需要意识控制的行为逐渐程序化，形成非陈述性成分。

（易混：非陈述性不等于“没有神经记忆”，只是提取不主要依赖有意识语言报告。）

<!-- kianos:kp id="neuro-n10-kp05" -->

## KP05｜短时程 vs 长时程：秒分—易扰—容量限；时年—巩固—可终身

> **讲义定位 →** 生理 Lecture PDF P387。  
> **主提示**：时长2｜干扰2｜容量2｜代表脑区各1｜重复→转化

### 短时程记忆

- 保存数秒到数分钟；
- 易被干扰；
- 容量有限；
- Study主要联系前额叶。

### 长时程记忆

- 可保存数小时、数天、数年，甚至终身；
- 形成后相对稳定；
- Study联系海马及其他脑区对信息的分级加工；
- 反复运用和强化可促短时记忆向长时记忆转化。

（边界：完整记忆巩固分子机制和临床遗忘综合征不在当前 Source 范围。）

<!-- kianos:kp id="neuro-n10-kp06" -->

## KP06｜LTP：高频刺激后，EPSP增强并持续很久

> **讲义定位 →** 生理 Lecture PDF P387；回看N2。  
> **主提示**：诱导刺激｜EPSP效应｜突触后Ca²⁺链｜受体改变2｜意义1

长时程增强（LTP）：高频刺激突触前神经元后，突触后神经元的 EPSP 增强，并可持续较长时间。

Study给出的最低机制链：

```text
高频刺激
→ 突触后细胞内Ca²⁺浓度升高
→ 启动第二信使反应
→ 更多受体进入突触后膜 / 受体效能增强
→ 同样输入引起更大EPSP
→ 突触连接长期增强
```

意义：各种形式学习和记忆的重要细胞基础。

（易混：LTP是持续的突触增强，不是短暂的EPSP时间总和；后者发生在当次输入，前者改变后续传递效能。）

## KP07｜左右半球优势：左偏语言，右偏非语词空间与图像

> **讲义定位 →** 生理 Lecture PDF P387，书页 P337。  
> **主提示**：左1大类｜右5类｜右利手谁优势｜形成2因素。

在人类多数右利手成年人：

- 左侧大脑皮层为语言优势半球；
- 右侧半球在非语词性认知方面更占优势，包括空间辨认、深度知觉、触—压觉认识、图像视觉认识和音乐欣赏等。

## KP09｜Wernicke + 弓状束：理解网络坏，还是听说连接坏

> **讲义定位 →** 生理 Lecture PDF P387–388。  
> **主提示**：W部位｜流畅但什么坏2｜弓状连接谁2｜复述障碍｜输入/输出是否保留。

### Wernicke语言理解中枢

Study定位于左侧颞叶后端 / 颞上回后端。

损伤可形成流畅失语：

- 说话流畅，甚至过多；
- 言不达意，杂乱词 / 自创词；
- 对口语和文字的理解均明显受限。

### 弓状束

连接 Wernicke 与 Broca。

损伤形成传导性失语：

- 基本理解和自发输出可相对保留；
- 对部分词组织、尤其复述出现障碍。

（易混：Study同时列“听觉语言中枢”和Wernicke，解题按题干所问层级使用其当前口径，不自行用外部神经语言学合并重写。）

# 5｜下丘脑：把神经信号接到垂体与行为

## KP11｜大细胞 vs 小细胞神经元：轴突去后叶，门脉去前叶

> **讲义定位 →** 生理 Lecture PDF P388，书页 P338。  
> **主提示**：大核2｜激素2｜输出路径｜小细胞7肽｜输出路径

### 视上核、室旁核等大细胞神经元

合成：

- ADH / VP / AVP；
- OT / 催产素 / 缩宫素。

运输路径：

```text
下丘脑合成
→ 轴浆运输沿下丘脑—垂体束
→ 神经垂体储存
→ 受刺激后释放入血
```

不是经垂体门脉到后叶。

### 下丘脑小细胞神经元

合成下丘脑调节肽，例如：

- TRH；
- CRH；
- GnRH；
- GHRH；
- 生长抑素；
- 催乳素释放因子；
- 催乳素抑制因子。

经垂体门脉调节腺垂体。

## KP13｜腹内侧 vs 外侧：内拒食，外摄食 + 摄水；先看刺激还是破坏

> **讲义定位 →** 生理 Lecture PDF P388–389。  
> **主提示**：内/外2区｜饱/食/水3中枢｜刺激/破坏方向4。

- 下丘脑腹内侧核：饱食中枢；
- 下丘脑外侧区：摄食中枢 + 摄水 / 渴觉中枢。

题目必须先看操作：

```text
刺激腹内侧 → 摄食受抑
破坏腹内侧 → 失去饱食信号，摄食增加

刺激外侧区 → 摄食 / 饮水增加
破坏外侧区 → 摄食 / 饮水减少
```

## KP15｜渴觉双入口：AngII找穹隆下器，晶体渗透压找终板血管器

> **讲义定位 →** 生理 Lecture PDF P389，书页 P339。  
> **主提示**：室周器2｜各最敏1｜渗透刺激排序｜容量链｜晶渗链｜共同输出2

下丘脑前部室周器：

1. **穹隆下器**：对 AngII 最敏感；
2. **终板血管器**：渗透压感受器，对 NaCl 形成的晶体渗透压升高最敏感；对葡萄糖、尿素较弱，甘露醇和蔗糖也可刺激。

### 低容量 / 低压力入口

```text
血容量↓ / 心肺容量感受器、压力感受器输入↓
→ 孤束核与体液链
→ AngII↑
→ 穹隆下器
→ 外侧区渴觉
+ SON/PVN ADH输出
→ 饮水 + 保水
```

### 高晶体渗透压入口

```text
血浆晶体渗透压↑
→ 终板血管器
→ 外侧区渴觉
+ SON/PVN ADH输出
→ 饮水 + 水重吸收
```

（易混：循环血量增加可使尿量增加，但不一定产生口渴；糖尿病多饮需经高血糖—渗透性利尿—容量下降链解释。）
