# 0｜统一入口：先问“题目到底在问哪一层”

本章最容易错，不是因为受体表太长，而是因为四个层级被混在一起：

```text
神经
→ 释放递质
→ 递质结合受体
→ 所在细胞产生受体效应
→ 多个细胞与局部代谢共同形成器官综合效应
```

必须固定区分：

```text
受体 → 效应
= 这个受体位于某细胞上，被激动后直接发生什么

神经 → 效应
= 该神经兴奋时，所有递质、受体、器官状态和间接代谢效应的合结果
```

三个高频反例：

1. ACh激动骨骼肌终板 N2 → 骨骼肌收缩；但不能说“副交感神经使骨骼肌收缩”，因为这里的ACh来自躯体运动神经。
2. ACh激动汗腺 M → 温热性发汗；但不能说“副交感神经使汗腺分泌”，因为小汗腺由交感胆碱能纤维支配。
3. α1直接使冠脉、骨骼肌血管收缩；但防御反应时交感神经可使骨骼肌血管舒张，冠脉也呈综合性舒张，因为走的是另外的递质与代谢链。

> **本 Block 的最低地图**：先定神经 → 再定递质 → 再定受体 → 再定受体所在细胞 → 最后判断综合器官效应。

# 1｜总 Framework

<!-- kianos:framework id="neuro-n03-framework-main" -->

```text
A｜信息物质
递质：承担主要突触信息传递
调质：增强或削弱传递效能
递质共存：同一神经元释放多种化学媒质，协调同一功能

B｜传出线路
躯体运动神经：ACh → N2
自主节前：全部ACh → N1
副交感节后：多数ACh → M；少数VIP / NO / GRP等
交感节后：多数NA → α / β；少数ACh → M

C｜受体直接效应
ACh：M / N1 / N2
NA：α1 / α2 / β1 / β2 / β3
→ 由受体所在细胞决定直接方向

D｜神经综合效应
交感：应急、动员、血流重新分配
副交感：休整、消化、储能、排泄和生殖
→ 不能机械照着单个受体反推整条神经

E｜器官比较
瞳孔：α1开大肌 vs M括约肌
心脏：β1四正 vs M四负
胰岛：α2 / β2 / M方向不同
唾液：两者都↑，但量与黏稠度不同

F｜状态依赖
紧张性是否存在
有孕 / 无孕子宫
幽门收缩 / 舒张状态
→ 同一神经并非任何时刻都给固定方向
```

# 2｜先把“信息物质”和“线路”分清

<!-- kianos:kp id="neuro-n03-kp01" -->

## KP01｜递质、调质与递质共存：主要信号之外还可以有“增益器”

> **讲义定位 →** 生理 Lecture PDF P356，书页 P312。  
> **主提示**：定义2类｜界限是否绝对｜共存1定义｜唾液ACh+VIP 2分工｜意义1。

### 神经递质

由突触前神经元合成并释放，特异性作用于突触后神经元或效应细胞受体，产生一定效应，是该突触的主要信息媒质。

### 神经调质

同一神经元还可合成其他化学物质，它们不一定直接承担主要信息传递，而是增强或削弱该突触中递质的传递效率。

Study同时提醒：递质与调质之间并非总有绝对界限，作用机制也可重叠。

### 递质共存

同一神经元内存在两种或两种以上递质 / 调质。

经典例子：唾液腺副交感纤维中 ACh 与 VIP 共存。

```text
ACh → 促进唾液腺分泌
VIP → 舒张唾液腺血管、增加血供，并增强胆碱能受体亲和力
→ 两者协调 → 大量稀薄唾液
```

**递质共存的意义**：多条作用并行，协调完成同一生理功能，而不是要求一种递质独自承担所有环节。

（易混：同一神经元可以共存多种化学媒质，不等于每次刺激都以完全相同的比例释放。）

## KP02｜胆碱能纤维：4类ACh线路，再记“前B后C、交短长/副长短”

> **讲义定位 →** 生理 Lecture PDF P357，书页 P313。  
> **主提示**：ACh纤维4类｜2条交感胆碱能｜交感前/后长短｜副交感前/后长短｜前B后C。

### 释放ACh的四类纤维

1. 躯体运动神经；
2. 所有自主神经节前纤维；
3. 多数副交感神经节后纤维；
4. 少数交感神经节后纤维：
   - 温热性发汗；
   - 防御反应时骨骼肌血管的交感舒血管纤维。

因此：

```text
ACh
≠ 副交感专属递质
```

它也可来自躯体运动神经、自主节前纤维和少数交感节后纤维。

### 自主神经的两级结构

| 系统 | 节前纤维 | 节后纤维 | 结构原因 |
|---|---|---|---|
| 交感 | 短 | 长 | 神经节靠近脊髓，离效应器远 |
| 副交感 | 长 | 短 | 神经节多位于效应器壁内或附近 |

- 节前纤维：薄髓鞘，B类；
- 节后纤维：无髓，C类。

多数交感节后纤维释放 NA；多数副交感节后纤维释放 ACh。少数例外必须单独识别，不能用“交感=NA、副交感=ACh”机械覆盖。

（特殊：精神性发汗为交感肾上腺素能；温热性发汗为交感胆碱能。）

## KP03｜M受体：心4负｜血管舒｜眼2肌｜支气管缩｜消泌兴奋｜腺体分泌

> **讲义定位 →** 生理 Lecture PDF P358–359，书页 P314。  
> **主提示**：心4负｜血管5地舒｜眼2肌｜支气管1｜消泌“肌缩括松”+LES特殊｜腺2类｜阻断2。

M受体属于 GPCR。当前 Study 可先用一句话抓总方向：

> **抑制心脏；在列出的血管床舒张；多数其它平滑肌和腺体活动增强。**

### 1｜心脏与冠脉

- 心脏四负效应：负性变时、变力、变传导、变兴奋；
- 血压下降；
- 当前 Study 串联：心肌活动受抑 → 腺苷减少 → 冠脉收缩。

（边界：这里保留当前 Study 的考试链，不用外部知识静默改写。）

### 2｜特定血管舒张

M受体介导以下血管舒张：

- 冠脉；
- 骨骼肌血管；
- 唾液腺 / 胃肠外分泌腺血管；
- 脑膜血管；
- 外生殖器血管。

但“某处M受体舒张”不等于“该处一定由副交感神经支配”，必须继续问ACh来自哪条神经。

### 3｜眼

```text
虹膜环形肌 / 瞳孔括约肌收缩 → 缩瞳
睫状肌收缩 → 悬韧带松弛 → 晶状体变凸 → 屈光度↑ → 看近物
```

### 4｜呼吸、消化、泌尿

- 支气管平滑肌收缩 → 口径↓、阻力↑；
- 消化和泌尿平滑肌收缩；
- 括约肌舒张；
- **LES在本表按平滑肌处理为收缩**，但吞咽时存在VIP / NO介导的状态性舒张，见KP11。

### 5｜腺体

- 分泌增加；
- 温热性发汗；
- 唾液大量、稀薄。

阻断剂：阿托品、后马托品。

//串联：阿托品后可见闭汗、散瞳、心率加快；不导致骨骼肌松弛，因为骨骼肌终板是N2，不是M。

## KP04｜N受体：N1负责“自主换元+髓质”，N2负责“终板收缩”

> **讲义定位 →** 生理 Lecture PDF P358–359；回看N2/N4。

N受体属于烟碱型、配体门控非选择性阳离子通道，效应快速。

| 受体 | 位置 | 直接效应 | Study阻断剂举例 |

## KP05｜α受体：α1多数兴奋收缩，α2保留“小肠与胰岛”特殊

> **讲义定位 →** 生理 Lecture PDF P358–360。  
> **主提示**：α1血管3｜眼1｜消泌2｜汗毛2｜子宫有孕1｜唾液1｜α2肠1+胰岛2｜阻断3+1。

### α1受体

Study中的高频方向是**兴奋 / 收缩**：

- 皮肤和内脏血管收缩为主 → 血压↑；
- 冠脉、骨骼肌血管直接收缩；
- 虹膜辐射肌 / 瞳孔开大肌收缩 → 扩瞳；
- 消化、泌尿平滑肌活动受抑背景下，括约肌收缩；
- 少量黏稠唾液分泌；
- 精神性发汗；
- 立毛肌收缩；
- 有孕子宫收缩。

阻断剂：酚妥拉明、酚苄明、哌唑嗪。

### α2受体

当前 Study 明确保留：

- 小肠平滑肌舒张；
- 胰岛素、胰高血糖素分泌均下降；并强调 α2效应强于β2。

阻断剂举例：育亨宾；非选择性α阻断剂也可阻断。

（易混：精神性发汗走NA—α1；温热性发汗走ACh—M。）

## KP06｜β受体：β1“1颗心+1个球旁”，β2舒张5类，β3脂解

> **讲义定位 →** 生理 Lecture PDF P358–360；Recall循环B2。  
> **主提示**：β1 2处｜四正+肾素｜β2血管/眼/支气管/消泌/无孕子宫5类｜β3 1事｜阻断3/1。

### β1受体

两个西综高频位置：

1. 心肌细胞：四正效应；
2. 肾小球旁细胞：肾素释放↑ → RAAS兴奋。

当前 Study 串联：β1使心肌代谢增加、腺苷增加 → 冠脉综合性舒张。

阻断剂：普萘洛尔、美托洛尔、阿替洛尔。

### β2受体

主要表现为平滑肌舒张：

- 皮肤和内脏、冠脉、骨骼肌血管的**直接受体效应**为舒张；
- 睫状肌舒张 → 悬韧带绷紧 → 晶状体变扁 → 屈光度↓；
- 支气管舒张 → 气道阻力↓；
- 消化、泌尿平滑肌舒张；
- 无孕子宫舒张。

阻断剂：普萘洛尔；Study另列丁氧胺。

### β3受体

- 脂肪分解↑；
- 血游离脂肪酸↑。

（易混：受体表里“β2使皮肤和内脏血管舒张”是直接效应；交感兴奋时这些血管的综合效应仍由α1占优势而收缩。）

# 5｜最重要的判断边界：受体效应不等于整条神经效应

<!-- kianos:kp id="neuro-n03-kp07" -->

## KP07｜三个反例锁死层级：血管、汗腺、骨骼肌

> **讲义定位 →** 生理 Lecture PDF P356、P359–360。  
> **主提示**：骨骼肌血管3条链｜冠脉2层｜汗腺2型｜骨骼肌ACh来源｜结论1句。

### 1｜骨骼肌血管

存在三条不同链：

```text
NA → α1 → 骨骼肌血管收缩
NA / Adr → β2 → 骨骼肌血管直接舒张
防御反应：交感舒血管纤维 → ACh → M → 骨骼肌血管舒张
```

静息时交感缩血管纤维有紧张性，综合表现偏收缩；防御反应时交感胆碱能舒血管链可被动员。

### 2｜冠脉

```text
受体直接层：α1收缩；β2或M可舒张
器官综合层：交感β1使心肌代谢↑ → 腺苷↑ → 冠脉舒张
副交感M使心肌活动↓ → 当前Study链为腺苷↓ → 冠脉收缩
```

所以题目问“激动某受体”还是“交感 / 副交感兴奋”时，答案可能不同。

### 3｜汗腺与骨骼肌

- 温热性发汗：交感胆碱能 → ACh → M；
- 精神性发汗：交感肾上腺素能 → NA → α1；
- 骨骼肌收缩：躯体运动神经 → ACh → N2。

共同结论：

> **递质只告诉你化学身份；神经来源、受体位置和器官状态才决定整条生理效应。**

# 6｜交感神经：应急时把资源重新分配到“跑、看、呼吸、供能”

## KP08｜交感综合效应：14器官｜血流重分配｜血糖5路｜2条胆碱能特殊

> **讲义定位 →** 生理 Lecture PDF P360，书页 P316。  
> **主提示**：心冠脑肌4｜皮内脏毛3｜支眼汗3｜消泌子3｜血糖5路｜胆碱能2特殊。

交感兴奋的核心不是“所有器官都兴奋”，而是：

> **动员机体潜能，把血流和能量从暂时不优先的区域转向心、肺和骨骼肌，以应对环境急变。**

| 器官 / 任务 | 综合效应 | 主要链 |
|---|---|---|
| 心脏 | 四正 | β1 |
| 冠脉 | 舒张 | 心肌β1 → 代谢 / 腺苷↑ |
| 脑血管 | 舒张 | Study综合效应 |
| 防御时骨骼肌血管 | 舒张 | 交感胆碱能ACh → M |
| 皮肤、内脏血管 | 收缩，血流重新分配 | α1 |
| 立毛肌 | 收缩 | α1 |
| 支气管 | 舒张 | β2 |
| 瞳孔 | 扩大 | α1使开大肌收缩 |
| 睫状肌 | 舒张、看远 | β2 |
| 汗腺 | 温热性 / 精神性发汗 | M / α1 |
| 消化 | 平滑肌舒张、括约肌收缩、少量黏稠唾液 | β2 / α2、α1 |
| 泌尿 | 逼尿肌等舒张、括约肌收缩、RAAS↑ | β2、α1、β1 |
| 子宫 | 无孕舒张；有孕收缩 | β2；α1 |
| 血糖 | 升高 | 胰岛素↓、糖原分解↑、脂解↑、蛋白分解↑、糖异生↑ |

脂肪分解提供甘油，蛋白分解提供氨基酸，均可进入糖异生，支持血糖升高。

（易混：交感作用范围广，但不是所有交感分支每次都同等兴奋；Study强调存在不同整合形式。）

## KP09｜NA vs Adr：受体偏好决定升压/强心，再由反射改写最终HR

> **讲义定位 →** 生理 Lecture PDF P360；讲义回看循环B2。  
> **主提示**：NA/Adr受体偏好｜NA单用HR终向｜Adr小/大剂量血管｜α阻断翻转｜递质/激素身份。

这是循环B2已完整学习的内容，本处只做自主神经语境中的必要 Recall：

| 物质 | 当前 Study 受体偏好 | 典型定位 |
|---|---|---|
| NA / NE | α1 > β1 > β2 | 广泛缩血管，偏升压 |
| Adr | α1 = β1 = β2 | β1强心充分；剂量与血管受体分布共同决定方向 |

### 单用NA为何最终HR可下降

```text
NA直接β1 → HR↑（较弱）
NA同时α1广泛缩血管 → BP明显↑
→ 窦弓反射：迷走↑、交感↓
→ 反射性减慢超过直接β1效应
→ 最终HR↓
```

### Adr剂量与翻转

在骨骼肌、肝等β2较多血管：

- 小剂量 Adr：β2优势 → 舒张；
- 大剂量 Adr：α1效应显现 → 收缩；
- 先阻断α后再给Adr：缩血管效应消失、β2保留 → 血压下降，即肾上腺素作用翻转。

（边界：NA作为交感节后递质，Adr / NA也可作为肾上腺髓质激素；完整剂量和药理仍以循环B2为Primary。）

# 7｜副交感：不是“交感全部反过来”，而是相对局限的休整系统

## KP10｜副交感总角色 + 只受交感5类 + 副交感舒血管4地

> **讲义定位 →** 生理 Lecture PDF P360–361。  
> **主提示**：副交感4任务｜只交感5类｜副交感舒血管4地｜交感广/副交感局限｜不能对比2例。

副交感活动相对局限，主要有利于：

- 保护机体；
- 休整恢复；
- 促进消化、吸收和储能；
- 加强排泄和生殖功能。

### 只受交感神经支配

口诀对应：

```text
汗腺

肾
肾上腺髓质
多数血管
```

因此不能写：

- “副交感抑制汗腺”；
- “副交感与交感共同直接控制大多数血管”。

### 副交感舒血管纤维的局限分布

Study列出：

- 唾液腺；
- 胃肠外分泌腺；
- 脑膜；
- 外生殖器。

多数血管平时只有交感缩血管纤维具有紧张性控制。

（易混：骨骼肌血管的交感舒血管纤维是“交感”，虽然它释放ACh并作用M受体。）

## KP11｜副交感特殊递质与LES：同一迷走神经可按时相换化学语言

> **讲义定位 →** 生理 Lecture PDF P357、P360–361。  
> **主提示**：肽/气体递质3｜胃容受2物｜LES食过/食入2时相｜G细胞1链｜ACh不是唯一。

多数副交感节后纤维释放ACh，但少数为肽能 / 非胆碱能纤维。

当前 Study 重点：

- VIP、NO：平滑肌舒张；参与胃容受性舒张和吞咽时LES舒张；
- GRP（胃泌素释放肽，又称蛙皮素 / 铃蟾素接口）：作用G细胞 → 胃泌素释放。

### LES的状态性控制

```text
食物经过食管
→ 副交感兴奋
→ VIP + NO
→ LES舒张
→ 食团通过

食物进入胃后
→ 副交感兴奋
→ ACh
→ LES收缩
→ 防止反流
```

因此“副交感使LES舒张还是收缩”不能脱离当前功能状态。

（易混：受体表中M使LES收缩，是ACh直接效应；吞咽期舒张主要走VIP / NO。）

//串联：完整胃容受性舒张和胃液头期分泌已归消化系统；这里仅固定递质身份。

# 8｜三个器官比较：眼、心冠、胰岛

## KP12｜交感 vs 副交感：瞳孔2肌｜心冠2链｜胰岛3受体方向

> **讲义定位 →** 生理 Lecture PDF P360。  
> **主提示**：瞳孔α1/M 2肌｜心β1/M 4正负｜冠脉腺苷↑/↓｜胰岛α2/β2/M 3方向。

| 器官 | 交感 / NA侧 | 副交感 / ACh侧 |
|---|---|---|
| 瞳孔 | α1 → 辐射肌 / 开大肌收缩 → 扩瞳 | M → 环形肌 / 括约肌收缩 → 缩瞳 |
| 心脏 | β1 → 四正 | M → 四负 |
| 冠脉综合效应 | 心肌β1 → 代谢、腺苷↑ → 舒张 | 心肌M → 活动、腺苷↓ → 当前Study链为收缩 |
| 胰岛 | α2使胰岛素、胰高血糖素↓；β2使二者↑，α2效应占优 | M使胰岛素↑、胰高血糖素↓ |

眼部还需分开两块肌肉：

- α1使瞳孔开大肌收缩；
- M使瞳孔括约肌收缩；
- β2使睫状肌舒张、看远；
- M使睫状肌收缩、看近。

（易混：交感和副交感都可使“某块肌肉收缩”，但因作用肌不同，瞳孔最终方向相反。）

## KP13｜自主神经的3个共性：都能分泌、都可紧张、效应都受当前状态改写

> **讲义定位 →** 生理 Lecture PDF P361，书页 P317。  
> **主提示**：共性3｜唾液量/质2对｜无紧张5组｜子宫有/无孕｜幽门收/舒状态。

### 共性1｜两者都可增加唾液，但“量与质”不同

```text
交感：NA → α1 → 少量黏稠唾液
副交感：ACh → M → 大量稀薄唾液
```

### 共性2｜两者都可有紧张性活动

例如心交感和心迷走神经平时都有紧张性。

没有紧张性的高频纤维：

- 骨骼肌血管交感舒血管纤维；
- 唾液腺副交感舒血管纤维；
- 胃肠外分泌腺副交感舒血管纤维；
- 脑膜副交感舒血管纤维；
- 外生殖器副交感舒血管纤维。

在血管相关神经中，Study强调**交感缩血管纤维**具有典型紧张性。

### 共性3｜效应大小与方向可受效应器当前状态影响

- 无孕子宫：β2为主 → 舒张；
- 有孕子宫：α1为主 → 收缩；
- 幽门处于收缩状态时，刺激迷走可使其舒张；
- 幽门处于舒张状态时，刺激迷走可使其收缩。

这说明自主神经不是一个机械开关；受体表达、激素环境和器官当前状态共同决定最终反应。

（边界：子宫完整周期、妊娠与分娩模型后置生殖系统。）
