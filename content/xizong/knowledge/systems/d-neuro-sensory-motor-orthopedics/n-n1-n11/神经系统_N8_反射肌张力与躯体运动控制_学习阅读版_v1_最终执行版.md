# 0｜统一入口：运动是一条闭环，不是一根单向电线

完整运动电影：

```text
高级联络皮层 + 基底神经节 + 皮层小脑
→ 选择目标、策划动作
→ 运动皮层 + 脊髓小脑
→ 组织时序、方向、力度并持续校正
→ 脑干 + 脊髓
→ 下行命令、姿势反射、α运动神经元
→ NMJ + 骨骼肌
→ 产生力和位移
→ 肌梭 / 腱器官 / 皮肤与前庭反馈
→ 再次修正动作
```

所以面对运动题，先问四层：

```text
计划错？
协调错？
下行执行错？
外周执行器 / 反馈错？
```

> **本 Block 最低地图**：策划 → 协调 → 执行 → 本体反馈 → 动态校正。

# 2｜三级控制与最后公路

<!-- kianos:kp id="neuro-n08-kp01" -->

## KP01｜三级运动控制：最高策划，中间协调，最低执行

> **讲义定位 →** 生理 Lecture PDF P366，书页 P318。  
> **主提示**：3级｜最高3结构/1任务｜中间2结构/3任务｜最低2结构｜头面/躯干。

### 最高水平｜决定“要做什么”

- 大脑皮层联络区；
- 基底神经节；
- 皮层小脑。

共同负责随意运动的总体策划。这里先形成动作目标、顺序和方案，不直接等同于最终肌肉收缩。

### 中间水平｜把计划组织成可执行命令

- 大脑皮层运动区；
- 脊髓小脑。

负责运动的协调、组织与实施，并根据反馈不断改写命令。

### 最低水平｜把命令真正送到肌肉

- 脑干；
- 脊髓。

脑干偏向头面部骨骼肌和姿势控制；脊髓偏向躯干、四肢及局部反射执行。

（易混：三个水平不是互不相干的串联站点。高位可直接或间接下行；低位仍保留局部反射与反馈能力。）

<!-- kianos:kp id="neuro-n08-kp02" -->

## KP02｜运动单位与α运动神经元：一条“最后公路”带动一组肌纤维

> **讲义定位 →** 生理 Lecture PDF P367，书页 P319；回看 N4。  
> **主提示**：1α+全部肌纤维｜大/小2特点｜精细/粗大2例｜最后公路。

**运动单位**：一个 α 运动神经元及其支配的全部梭外肌纤维。

- 运动单位小：一个神经元支配肌纤维少，动作精细；
- 运动单位大：支配肌纤维多，单次招募可产生更大力量。

α 运动神经元把来自皮层、脑干、脊髓中间神经元和感觉传入的所有信息汇总，最终决定梭外肌是否收缩，因此被称为躯体运动的**最后公路 / 最后共同通路**。

//串联：N4 的“大小原则”可解释运动单位怎样按需求逐级招募；若当前尚未形成，只需回激这一条，不要求先完成整个 N4。

# 3｜屈肌反射：伤害时先撤回，再稳住身体

<!-- kianos:kp id="neuro-n08-kp03" -->

## KP03｜脊髓姿势反射：牵张、对侧伸肌、节间反射；屈肌本身主要避伤

> **讲义定位 →** 生理 Lecture PDF P367–368，书页 P319–320。  
> **主提示**：姿势反射3｜屈肌是否算？｜各1作用。

Study 将脊髓参与的姿势反射归为：

1. 牵张反射；
2. 对侧伸肌反射；
3. 节间反射。

**屈肌反射本身**主要作用是使受伤肢体迅速回撤，避免进一步损伤；它不是为了维持姿势而发生。真正维持身体支撑的是同时出现的对侧伸肌反射。

（易混：屈肌反射与对侧伸肌反射经常成套出现，但功能重点不同：前者“撤”，后者“撑”。）

---

<!-- kianos:kp id="neuro-n08-kp04" -->

## KP04｜屈肌 + 对侧伸肌：同侧屈、同侧伸抑；对侧伸、对侧屈抑

> **讲义定位 →** 生理 Lecture PDF P368。  
> **主提示**：同侧2方向｜对侧2方向｜交互抑制2处｜环式后发放。

伤害性刺激进入脊髓后，通过多突触中间神经元形成四个方向：

```text
同侧屈肌运动神经元兴奋 → 屈曲撤回
同侧伸肌运动神经元抑制 → 不与屈肌对抗

对侧伸肌运动神经元兴奋 → 支撑体重
对侧屈肌运动神经元抑制 → 让伸肌充分发挥
```

两侧拮抗肌之间都使用交互抑制，以避免相反肌群同时强烈收缩。

环式联系可使刺激消失后反射仍持续短时间，即**后发放 / 后放电**；这有利于完整撤回肢体，而不是在刺激一消失时立即松开。

# 4｜肌梭—牵张反射：读长度，维持姿势

<!-- kianos:kp id="neuro-n08-kp05" -->

## KP05｜肌梭：与梭外肌并联；感受部分与梭内收缩端串联

> **讲义定位 →** 生理 Lecture PDF P369–370，书页 P321–322。  
> **主提示**：并联1｜串联1｜感受器2名｜Ia/II｜α/γ/β各管谁。

肌梭是骨骼肌的长度感受器：

- 整个肌梭与梭外肌纤维**并联**；
- 肌梭中央感受部分与两端梭内肌收缩部分**串联**。

主要传入：

- Ⅰa 类纤维；
- Ⅱ类纤维。

运动输出：

- α 运动神经元 → 梭外肌；
- γ 运动神经元 → 梭内肌两端；
- β 运动神经元 → Study 中作为兼顾梭内 / 梭外的接口。

> 核心不是背“并联 / 串联”两个词，而是理解：肌肉长度变化必须拉动肌梭中央感受区，才能改变传入放电。

---

<!-- kianos:kp id="neuro-n08-kp06" -->

## KP06｜牵张反射完整链：外拉或γ内拉，最终都使Ⅰa放电增加

> **讲义定位 →** 生理 Lecture PDF P369–371。  
> **主提示**：外因1｜内因1｜Ia↑→α→梭外缩｜γ作用1｜负反馈终点。

### 外因｜外力把整块肌肉拉长

```text
梭外肌被拉长
→ 并联肌梭被拉长
→ 中央感受区受牵
→ Ⅰa / Ⅱ传入放电↑
→ 同名肌 α 运动神经元兴奋
→ 梭外肌收缩、长度回落
→ 肌梭牵拉减轻、放电回落
```

这是抵抗突然而来的长度改变。

### 内因｜γ运动神经元主动拉紧肌梭

```text
γ运动神经元持续放电
→ 梭内肌两端收缩
→ 中央感受区被内部拉紧
→ Ⅰa放电↑
→ α运动神经元兴奋
→ 梭外肌收缩
```

γ系统提高肌梭对长度变化的敏感性，使肌梭在梭外肌缩短时仍保持“在线”。

（易混：γ不直接产生主要外部力量；它先调肌梭灵敏度，再经Ⅰa—α环路改变梭外肌。）

<!-- kianos:kp id="neuro-n08-kp07" -->

## KP07｜腱器官—反牵张反射：读张力，过大时抑制同名肌

> **讲义定位 →** 生理 Lecture PDF P370、P372，书页 P322、P324。  
> **主提示**：腱器官｜张力｜串联｜Ib｜同名α抑制｜保护。

高尔基腱器官：

- 位于肌腱；
- 是**张力感受器**；
- 与梭外肌纤维**串联**；
- 传入为 Ⅰb 类纤维。

张力过大时：

```text
腱器官放电↑
→ Ⅰb传入
→ 脊髓抑制性中间神经元
→ 同名肌 α运动神经元受抑
→ 梭外肌舒张
→ 防止肌肉、肌腱承受过大张力
```

（易混：反牵张反射的“反”不是指肌肉被缩短，而是指最终效应与牵张反射相反：同名肌被抑制、舒张。）

<!-- kianos:kp id="neuro-n08-kp08" -->

## KP08｜肌梭 vs 腱器官：长度 / 张力；并联 / 串联；ⅠaⅡ / Ⅰb

> **讲义定位 →** 生理 Lecture PDF P372。  
> **主提示**：长/张｜并/串｜IaⅡ/Ib｜缩/松｜等长/等张2×2。

| 轴 | 肌梭 | 腱器官 |
|---|---|---|
| 主要感受 | 肌长度及其变化 | 肌张力 |
| 与梭外肌关系 | 并联 | 串联 |
| 传入 | Ⅰa、Ⅱ | Ⅰb |
| 反射终点 | 同名肌收缩 | 同名肌抑制 / 舒张 |
| 主要意义 | 姿势、长度稳定 | 过度张力保护 |

### 等长与等张时怎样判断

- **等长收缩**：肌长度不变、张力增加 → 肌梭变化不明显，腱器官放电增加；
- **等张收缩**：张力相对不变、肌肉缩短 → 肌梭放电减少，腱器官变化不明显。

这是做题时最省力的判断：先问题干改变的是**长度**还是**张力**。

<!-- kianos:kp id="neuro-n08-kp09" -->

## KP09｜腱反射 vs 肌紧张：快单突触用于动作检查，慢多突触用于姿势维持

> **讲义定位 →** 生理 Lecture PDF P372，书页 P324。  
> **主提示**：快/慢｜单/多｜快/慢肌纤维｜动作/姿势｜例子。

牵张反射分两类：

| 轴 | 腱反射 | 肌紧张 |
|---|---|---|
| 刺激 | 快速牵拉 | 缓慢、持续牵拉 |
| 中枢联系 | 单突触为主 | 多突触 |
| 主要效应纤维 | 快肌纤维 | 慢肌纤维交替活动 |
| 表现 | 快速、短暂收缩 | 缓慢、持续、疲劳少 |
| 作用 | 检查反射弧 / 动作性反射 | 维持姿势最基本反射 |

常见腱反射包括膝反射等；肌紧张则让抗重力肌在站立时维持基础张力。

# 5｜脊休克与脑干姿势控制

<!-- kianos:kp id="neuro-n08-kp10" -->

## KP10｜脊休克：永久丢的是长束功能；暂时丢的是断面以下反射

> **讲义定位 →** 生理 Lecture PDF P373，书页 P325；外科 O3 后续再应用。  
> **主提示**：永久2｜暂失5｜机制1｜恢复5｜屈↑伸↓。

脊髓与高位中枢突然离断后：

### 永久性部分

- 损伤平面以下感觉传导丧失；
- 随意运动丧失。

它们取决于被中断的长传导束，不因脊休克结束而自动恢复。

### 暂时性脊休克

高位中枢易化输入突然消失，断面以下脊髓反射活动暂时显著降低：

- 牵张反射下降 / 消失；
- 发汗反射下降；
- 血管舒张、血压下降；
- 尿潴留、排便障碍；
- 肌张力下降，表现软瘫。

### 恢复后

数周至数月，部分脊髓反射重新出现：

- 肌张力与牵张反射增强；
- 发汗和血管反射恢复；
- 血压回升；
- 排尿、排便可由潴留转为失禁；
- 屈肌反射增强，伸肌反射相对减弱。

（边界：外科 Lecture 对创伤场景另给“2–4周后软瘫转硬瘫”的口径；精确时程在 N11 登记为 Source Context Difference，不在这里静默统一。）

## KP11｜脑干肌张力：抑制区4组，易化区3组；平时两者动态平衡

> **讲义定位 →** 生理 Lecture PDF P373–374，书页 P325–326。  
> **主提示**：抑制4｜易化3｜各下行对象｜谁占优势→张力方向。

### 肌紧张抑制区

Study 列出的高频结构：

- 延髓腹内侧网状结构；
- 小脑前叶蚓部；
- 纹状体尾状核；
- 大脑皮层运动区。

主要通过抑制 α / γ 运动神经元或其上游通路，降低伸肌牵张反射。

### 肌紧张易化区

- 脑干大片网状结构；
- 前庭核；
- 小脑前叶两侧部与后叶中间部等 Study 所列结构。

共同提高 α / γ 运动神经元活动，使抗重力伸肌张力增加。

> 正常姿势不是“易化一直开着”，而是抑制与易化两套系统持续动态平衡。

## KP12｜去大脑 vs 去皮层僵直：全伸还是上屈下伸，关键看红核是否保留

> **讲义定位 →** 生理 Lecture PDF P374–375，书页 P326–327。  
> **主提示**：切口/病变层｜姿势｜易化>抑制｜γ/α2路｜红核保不保。

### 去大脑僵直

动物在中脑上、下丘之间切断脑干，抑制区与大脑皮层联系被切断，易化区优势显著：

- 头后仰；
- 四肢伸直；
- 伸肌牵张反射过强；
- 主要表现为伸肌张力过高。

两种机制：

- **γ僵直**：网状脊髓束 → γ系统 → 肌梭敏感性↑ → Ⅰa—α环路增强；
- **α僵直**：前庭脊髓束等直接提高 α 运动神经元活动。

### 去皮层僵直

- 下肢伸直；
- 上肢半屈。

Study 用“去大脑 = 去皮层 + 红核受损”帮助定位：红核仍能影响上肢屈肌时，保留上屈；红核输出进一步丢失后，四肢更偏伸直。

（易混：僵直是异常牵张反射 / 肌张力模式，不等于正常主动用力。）

# 6｜基底神经节：选择并准备动作

<!-- kianos:kp id="neuro-n08-kp13" -->

## KP13｜直接与间接通路：一条放行，一条刹车；黑质DA按D1/D2共同利于运动

> **讲义定位 →** 生理 Lecture PDF P376，书页 P328。  
> **主提示**：直接1终点｜间接1终点｜D1↑/D2↓｜DA总效应｜职责1。

基底神经节位于皮层—丘脑—皮层回路中，核心职责是运动的**策划、选择、准备和启动**。

### 直接通路

皮层兴奋纹状体后，经基底神经节输出核的抑制链，最终减少对丘脑的抑制：

```text
丘脑活动↑
→ 运动皮层更容易发动运动
```

### 间接通路

经外侧苍白球、丘脑底核等中继，最终加强基底神经节输出核对丘脑的抑制：

```text
丘脑活动↓
→ 不合适运动被压制
```

### 黑质多巴胺

- 激动 D1 → 促进直接通路；
- 激动 D2 → 抑制间接通路。

两条作用都使运动更容易发生。

（易混：基底神经节不是最后执行肌肉收缩；它更像“动作方案选择器和启动门”。）

## KP14｜帕金森 vs 亨廷顿：黑质DA少 / 纹状GABA少；张力与运动方向相反

> **讲义定位 →** 生理 Lecture PDF P376、P380。  
> **主提示**：病变2｜递质2｜张力↑/↓｜运动↓/↑｜静止震颤/舞蹈｜治疗角色。

| 轴 | 帕金森病（震颤麻痹） | 亨廷顿病（舞蹈病） |
|---|---|---|
| 主要病变 | 黑质多巴胺能神经元 | 纹状体中型多棘 GABA 神经元 |
| 通路结果 | 直接通路减弱、间接通路增强 | 间接通路抑制减弱，运动相对放行 |
| 肌张力 | 增高、铅管样 / 齿轮样僵硬接口 | 降低 |
| 随意运动 | 减少、启动慢、动作迟缓 | 过多、不自主舞蹈样动作 |
| 其他表现 | 静止性震颤、面具脸等 Study 表现 | 上肢和头部舞蹈样动作 |

### Study 支持的治疗角色

- 帕金森：补多巴胺前体、减弱纹状体胆碱能影响；Study另列丘脑底核高频刺激等接口；
- 亨廷顿：减弱多巴胺效应或减少囊泡储存的药物接口。

（边界：当前文件保留 Lecture 的考试口径与药物角色，不用外部指南升级成完整现代治疗路径；完整疾病诊疗后置。）

## KP16｜基底神经节 vs 小脑：一个选动作，一个校动作

> **讲义定位 →** 生理 Lecture PDF P377–378，书页 P329–330。

# 8｜皮层、下行束与瘫痪定位

<!-- kianos:kp id="neuro-n08-kp17" -->

## KP17｜皮层—下行束—Babinski：联络区策划，运动区发动，侧束管远端精细

> **讲义定位 →** 生理 Lecture PDF P378–379，书页 P330–331。  
> **主提示**：策划/发动2区｜核束/脊髓束2靶｜侧远端/前近端｜Babinski阴/阳｜3种生理性阳性。

### 策划与发动

- 随意运动总体策划：大脑皮层联络区；
- 最终发动：大脑皮层运动区。

### 两条主要下行束

- **皮质脑干束 / 皮质核束**：调控头面部骨骼肌；
- **皮质脊髓束**：调控躯干和四肢。

皮质脊髓束中：

- 侧束偏远端肢体、精细运动；
- 前束偏躯干和近端肌。

### Babinski

- 阴性：足趾屈曲，为正常跖反射；
- 阳性：拇趾背伸、其余趾扇形分开，提示皮质脊髓侧束 / 上运动神经元通路受损。

Study 允许出现阳性的非病理场景包括：

- 婴幼儿；
- 成人深睡眠；
- 麻醉状态。

（易混：Babinski 是病理反射，不等于深反射本身；它与锥体束对原始反射的抑制丢失有关。）
