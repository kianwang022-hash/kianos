# 0｜统一入口：突触不是“把动作电位原样传过去”

轴突上的动作电位是一种全或无、沿膜再生的电信号。到达末梢后，它先被转成化学信号，再被下一级细胞重新解释：

```text
突触前动作电位
→ 末梢Ca²⁺内流
→ 囊泡动员、着位、融合、出胞
→ 递质跨越突触间隙
→ 突触后受体改变离子通透性
→ EPSP或IPSP
→ 时间总和 + 空间总和
→ 轴突始段决定是否爆发新动作电位
```

因此突触有三项最重要的“加工能力”：

1. **转换**：电 → 化学 → 局部电；
2. **整合**：多个 EPSP / IPSP 做代数和；
3. **调门**：在突触前或突触后减少、增加传递效能。

> **本 Block 的最低地图**：释放 → 受体 → 局部电位 → 总和 → 抑制 / 易化。


# 2｜突触类型与囊泡地图

<!-- kianos:kp id="neuro-n02-kp01" -->

## KP01｜化学突触 vs 电突触：谁单向、谁快速、谁能深度调节

> **讲义定位 →** 生理 Lecture PDF P345，书页 P302。  
> **主提示**：化学7特征｜电突触3特征｜单突触反射1｜定向/非定向。

### 化学突触的七个高频特征

1. 单向传递；
2. 突触延搁；
3. 兴奋节律可改变；
4. 可发生总和；
5. 易疲劳；
6. 对内环境和药物变化敏感；
7. 可出现后发放与反馈。

递质只能从突触前膜释放并作用于突触后膜，因此化学传递单向。每多经过一个突触，就多一次释放、扩散、受体响应过程，反射时间随突触数增加。

**唯一单突触反射**：腱反射，如膝跳反射。

### 电突触

结构基础是缝隙连接：

- 双向；
- 低电阻；
- 快速。

电流可直接在两细胞胞质间流动，不需要递质释放和受体转换。

### 定向 vs 非定向化学传递

| 类型 | 结构 | 作用范围 |
|---|---|---|
| 定向突触 | 典型突触前膜—间隙—突触后膜 | 递质作用范围局限；经典神经元突触与NMJ |
| 非定向突触 | 曲张体释放，无典型紧密突触前后膜 | 可影响较多效应器细胞；自主节后、单胺能纤维常见 |

（易混：神经纤维上的动作电位可双向传导，不等于化学突触也双向。）

## KP02｜三类突触囊泡：大小、是否致密、装什么

> **讲义定位 →** 生理 Lecture PDF P345。  
> **主提示**：3囊泡｜小亮2类递质｜小密1类｜大密1类｜活性区分布。

| 囊泡 | 典型递质 | 分布特点 |
|---|---|---|
| 小而清亮 | ACh、氨基酸递质：谷氨酸、GABA、甘氨酸 | 多集中于活性区 |
| 小而致密 | 儿茶酚胺类 | 多集中于活性区 |
| 大而致密 | 神经肽类 | 可较均匀分布于末梢，并从多个部位释放 |

突触前末梢中囊泡密集、准备释放的膜区域称为**活性区**；突触后膜下富集受体、细胞骨架和信号蛋白的区域称**突触后致密区 / PSD**。

//识别：囊泡外观与递质类别属于 MI-D，但“不同囊泡携带不同递质、释放空间不同”要理解。

# 3｜递质怎样从囊泡走到突触间隙

<!-- kianos:kp id="neuro-n02-kp03" -->

## KP03｜递质释放5步：动员—摆渡—着位—融合—出胞

> **讲义定位 →** 生理 Lecture PDF P346，书页 P303。  
> **主提示**：5步｜Ca-CaMK｜Rab2个｜SNARE3件｜膜面积方向。

```text
① 动员
Ca²⁺-CaMKⅡ
→ 突触蛋白磷酸化
→ 囊泡从细胞骨架解离

② 摆渡
Rab3 / Rab27小G蛋白
→ 游离囊泡移向活性区

③ 着位 / 锚定
囊泡VAMP / v-SNARE
+ 突触前膜t-SNARE（syntaxin、SNAP-25）
→ 囊泡固定并做好融合准备

④ 融合
囊泡膜与突触前膜融合
→ 细胞膜面积增加

⑤ 出胞
囊泡内容物释放到突触间隙
```

这一过程不是五个彼此孤立的名词，而是：

> 从“囊泡还被骨架绑住”到“囊泡被送到活性区并与膜合并”的连续物流过程。

（易混：Rab3 / Rab27负责摆渡；SNARE蛋白负责着位和融合，不要交换。）

//MI-D：VAMP、syntaxin、SNAP-25的全称与四股α螺旋细节进入延迟记忆。

## KP04｜递质释放量最直接看 Ca²⁺：频率、幅度、时程都通过它起效

> **讲义定位 →** 生理 Lecture PDF P346。  
> **主提示**：关键1｜AP 3变量｜外液Ca/Mg方向｜速度为什么无关。

递质释放量与进入末梢的 Ca²⁺量正相关。

```text
动作电位到达末梢
→ 电压门控Ca²⁺通道开放
→ Ca²⁺内流
→ 囊泡融合与出胞
```

促进递质释放的因素：

- 动作电位频率增加；
- 动作电位幅度增加；
- 动作电位时程延长；
- 细胞外 Ca²⁺升高；
- 细胞外 Mg²⁺降低。

这些因素最终都使末梢 Ca²⁺内流增加。

**动作电位传导速度不影响递质释放量**：一个动作电位无论传得快慢，到达末梢后都只触发一次通道开放；关键在末梢电位的频率、幅度、时程及外液离子环境。

（易混：“速度快”不等于“单位时间动作电位多”；影响释放的是频率，而不是单个冲动沿轴突移动的速度。）

# 4｜从着位、清除到受体：药物与毒素可在哪一层改变突触

<!-- kianos:kp id="neuro-n02-kp05" -->

## KP05｜三类干预位点：释放、清除、再摄取 / 储存

> **讲义定位 →** 生理 Lecture PDF P346–347。  
> **主提示**：着位3毒｜清除3药｜储存1药｜柔软/痉挛2麻痹。

### A｜影响囊泡着位 / 释放

| 因素 | 当前 Study 机制 | 结果 |
|---|---|---|
| 肉毒素 | 抑制 NMJ ACh 囊泡释放 | 柔软性麻痹；临床可放松局部过度收缩肌肉 |
| 破伤风毒素 | 抑制闰绍细胞释放甘氨酸 | 回返抑制丢失，痉挛性麻痹 |
| 蜘蛛毒 | 促进 ACh 持续释放 | 先增强，后递质耗竭 |

### B｜影响递质清除

| 因素 | 机制 | 结果 |
|---|---|---|
| 有机磷 | 不可逆抑制 AChE | ACh积聚，胆碱能传递增强 |
| 新斯的明 | 可逆抑制 AChE | ACh水解减少，传递增强 |
| 阿米替林 | 抑制突触前膜再摄取 | 间隙递质作用增强 |

### C｜影响囊泡储存

利血平抑制囊泡膜对递质的摄取，使多巴胺等递质不能回到囊泡、被酶降解，最终递质耗竭、突触传递下降。

（边界：这些是“突触位点—方向”的机制接口；完整中毒、精神药理和帕金森 / 舞蹈病诊疗均后置。）

## KP06｜受体层肌松：筒箭毒碱 vs 琥珀胆碱

> **讲义定位 →** 生理 Lecture PDF P347，书页 P304。  
> **主提示**：竞争/非竞争｜N2阻断/持续激动｜早期/晚期｜新斯的明救谁。

| 轴 | 筒箭毒碱 | 琥珀胆碱 |
|---|---|---|
| 类型 | 竞争性肌松药 | Study称非竞争性 / 去极化型肌松药 |
| 受体作用 | 与 N2 结合但无内在活性，阻断 ACh | 激动 N2，且不被 AChE迅速分解 |
| 终板结果 | EPP幅度下降，难达阈值 | 早期去极化 / 肌肉收缩，随后持续去极化 |
| 后续膜状态 | 普通肌膜动作电位难产生 | 电压门控Na⁺通道持续失活、受体脱敏 |
| 新斯的明 | 可增加ACh与其竞争，能够解救 | 增加ACh会加重持续激动，不能解救 |

重症肌无力则是自身抗体破坏 N2-ACh受体；新斯的明通过抑制 AChE、增加间隙 ACh，提高剩余受体被激活的机会。

（易混：琥珀胆碱不是“占住受体却不激动”，而是持续激动导致去极化阻滞。）

# 5｜突触后电位：中枢用局部电位做加减法

<!-- kianos:kp id="neuro-n02-kp07" -->

## KP07｜EPSP vs IPSP：先看递质，再看离子，再看膜电位方向

> **讲义定位 →** 生理 Lecture PDF P348，书页 P305。  
> **主提示**：局部电位6特征｜EPSP 2离子｜IPSP 2离子｜去/超极化。

突触后电位属于局部电位，具有：

- 幅度小、等级性；
- 无全或无；
- 无不应期；
- 电紧张扩布；
- 随距离衰减；
- 可以总和。

| 轴 | EPSP | IPSP |
|---|---|---|
| 递质例 | 谷氨酸 | GABA、甘氨酸 |
| 突触后主要离子 | Na⁺内流增多，兼有K⁺外流 | Cl⁻内流或K⁺外流 |
| 膜电位 | 去极化 | 超极化 |
| 对输出 | 更接近阈值 | 更远离阈值 |

EPSP 中虽然 Na⁺和 K⁺通道都可开放，但静息状态下 Na⁺内向电化学驱动力更大，所以以 Na⁺内流为主。

IPSP 可分快、慢：快IPSP典型依赖 Cl⁻通道，慢IPSP更明确依赖 K⁺通道开放。

（易混：EPSP / IPSP 都不是动作电位；它们的幅度可以改变、可以叠加、会衰减。）

## KP08｜时间总和、空间总和与轴突始段判定

> **讲义定位 →** 生理 Lecture PDF P348。  
> **主提示**：2总和｜EPSP±IPSP｜代数和｜最终判定点1。

一个突触后神经元通常同时接收很多突触：

- 同一突触短时间内反复产生局部电位 → **时间总和**；
- 不同突触同时产生局部电位 → **空间总和**。

```text
所有EPSP叠加
− 所有IPSP抵消
→ 当前膜电位的代数和
→ 传播到轴突始段
→ 达阈值：爆发动作电位
→ 未达阈值：不输出
```

因此突触前、后神经元的放电频率往往不同：下一级神经元输出的是多个输入整合后的结果，而不是照抄某一上游神经元的节律。

（易混：局部电位可以同向叠加、异向抵消；动作电位因不应期和全或无，不能按同一方式叠加幅度。）

# 6｜突触后抑制：直接让目标神经元产生 IPSP

<!-- kianos:kp id="neuro-n02-kp09" -->

## KP09｜GABA_A vs GABA_B：一个开Cl⁻，一个开K⁺

> **讲义定位 →** 生理 Lecture PDF P349，书页 P306。  
> **主提示**：突触后对象｜A通道/Cl⁻｜B-GPCR/K⁺｜共同结果。

```text
抑制性中间神经元兴奋
→ 释放GABA或甘氨酸
→ 作用于目标神经元的胞体 / 树突突触后膜
→ 产生IPSP
→ 目标神经元更难达到阈值
```

| 受体 | 类型 | 效应器 | 结果 |
|---|---|---|---|
| GABA_A | 离子通道型 | Cl⁻通道开放，Cl⁻内流 | 快速超极化 |
| GABA_B | GPCR | K⁺通道开放，K⁺外流 | 较慢超极化 |

（易混：这里讨论的是胞体 / 树突，细胞内 Cl⁻低，故 Cl⁻内流；突触前抑制发生在轴突末梢，Cl⁻方向不同。）

## KP10｜回返抑制：传出通路用负反馈及时收尾

> **讲义定位 →** 生理 Lecture PDF P349。  
> **主提示**：传出｜环式负反馈｜闰绍/甘氨酸｜2意义｜2阻断。

典型回路：

```text
运动神经元兴奋
→ 轴突侧支兴奋闰绍细胞
→ 闰绍细胞释放甘氨酸
→ 反过来抑制原运动神经元及同群神经元
```

作用：

1. 及时终止活动；
2. 使同一中枢内神经元活动同步化。

两个高频破坏点：

- 破伤风毒素阻碍闰绍细胞释放甘氨酸；
- 士的宁阻断甘氨酸受体。

二者均使回返抑制丢失、兴奋性升高，可出现惊厥 / 痉挛。

//串联：破伤风毒素由外周末梢经逆向轴浆运输进入脊髓，再影响抑制性递质释放；N1与N2在这里接成一条完整机制链。

## KP11｜传入侧支 / 交互抑制：兴奋伸肌时同时放松屈肌

> **讲义定位 →** 生理 Lecture PDF P349–350。  
> **主提示**：传入｜1条兴奋主路+1条抑制侧支｜屈伸协调｜不是侧向抑制。

```text
伸肌肌梭传入冲动
├─ 直接兴奋伸肌运动神经元 → 伸肌收缩
└─ 经侧支兴奋抑制性中间神经元
   → 抑制屈肌运动神经元
   → 屈肌舒张
```

这种抑制多见于传入通路，保证拮抗肌活动协调，因此又叫**交互抑制**。

（易混：传入侧支抑制 ≠ 侧向抑制。前者协调拮抗肌；后者在感觉系统中增强中心与周边差异、提高分辨率。）

（特殊：成年人寒冷战栗时，屈肌与伸肌可同时发生不随意收缩，不按普通交互抑制的运动目的理解。）

## KP12｜突触前抑制的结构：B作用于A末梢，不直接接触C

> **讲义定位 →** 生理 Lecture PDF P351，书页 P308。  
> **主提示**：感觉传入｜轴突-轴突｜A/B/C关系｜仅B兴奋时C？｜输出看EPSP幅度。

设：

- A：兴奋性传入末梢；
- B：抑制性中间神经元；
- C：A的突触后神经元。

结构：

```text
A轴突末梢 → C胞体 / 树突：兴奋性突触
B轴突末梢 → A轴突末梢：轴突-轴突式突触
B与C不直接形成突触
```

结果：

- 仅 A 兴奋 → C 产生正常 EPSP；
- 仅 B 兴奋 → C 无直接反应；
- B 先兴奋、A 再兴奋 → A释放兴奋性递质减少 → C仍产生 EPSP，但幅度下降。

所以它叫：

- **突触前**：变化发生在 A→C 突触的突触前末梢A；
- **去极化抑制**：C仍产生去极化 EPSP，但幅度小、不易达阈值；
- 多见于感觉传入通路，用于过滤过多感觉信息。

## KP13｜突触前抑制3条机制 + 与突触后抑制最终对照

> **讲义定位 →** 生理 Lecture PDF P351–352。  
> **主提示**：GABA_A Cl⁻外｜GABA_B K⁺外｜Ca敏感性↓｜前EPSP↓/后IPSP。

### 三条突触前机制

1. **GABA_A**：轴突末梢内 Cl⁻较高，通道开放后 Cl⁻外流，使末梢提前去极化；传来的动作电位幅度变小、时程变短，Ca²⁺内流减少。

2. **GABA_B**：K⁺通道开放，K⁺外流增加，复极化加速，动作电位时程缩短，Ca²⁺内流减少。

3. **抑制性自身受体**：使递质释放多个步骤对 Ca²⁺的敏感性降低。

共同终点：

```text
末梢Ca²⁺内流 / Ca²⁺效能下降
→ 兴奋性递质释放减少
→ C神经元EPSP幅度下降
```

### 最终对照

| 轴 | 突触前抑制 | 突触后抑制 |
|---|---|---|
| 结构 | 轴突—轴突 | 轴突—胞体 / 树突 |
| 直接对象 | 上游末梢A | 目标神经元C |
| 递质释放 | A释放减少 | 抑制性神经元释放GABA / 甘氨酸 |
| C膜电位 | 仍为EPSP，但幅度下降 | 产生IPSP |
| 常见作用 | 感觉输入过滤 | 回返、交互等中枢刹车 |

> **判题顺序**：先问抑制发生在哪一层，再看目标细胞最终产生 EPSP 还是 IPSP。

## KP14｜突触后易化 vs 突触前易化

> **讲义定位 →** 生理 Lecture PDF P353，书页 P310。  
> **主提示**：后易化1｜前易化8步｜5-HT/cAMP｜K通道关｜EPSP↑。

### 突触后易化

多个 EPSP 在突触后膜发生时间 / 空间总和，使膜电位更接近阈值，输出更容易发生。

### 经典突触前易化

```text
B神经元兴奋
→ 释放5-HT
→ 作用于A末梢GPCR
→ cAMP↑
→ K⁺通道磷酸化并关闭
→ 动作电位复极延缓、时程延长
→ Ca²⁺内流增加
→ A释放兴奋性递质增加
→ C的EPSP幅度增大
```

突触前易化与突触前抑制可共享轴突—轴突结构，区别在于对末梢动作电位、Ca²⁺内流和递质释放的方向相反。
