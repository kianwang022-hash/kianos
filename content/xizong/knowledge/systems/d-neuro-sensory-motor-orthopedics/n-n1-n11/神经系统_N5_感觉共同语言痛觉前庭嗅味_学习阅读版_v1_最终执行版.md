# 0｜统一入口：所有感觉先说同一种“电语言”

无论刺激最初是光、声、机械牵拉、组织损伤还是化学物质，神经系统最后都必须把它翻译成神经元能处理的电信号：

```text
外界 / 体内刺激
→ 特定感受器受到刺激
→ 感受器换能
→ 感受器电位 / 受体电位（局部电位）
→ 达到传入神经触发条件
→ 动作电位
→ 频率、招募和空间分布编码
→ 中枢投射与加工
→ 特定感觉 / 反射 / 行为
```

因此感觉题不应先背器官名，而应先问五件事：

1. **刺激是什么**：机械、化学、温度、伤害性刺激？
2. **谁感受**：毛细胞、游离神经末梢、皮肤机械感受器等？
3. **怎样换能**：先产生什么局部电位？
4. **怎样编码**：频率、招募、中心—周边差异如何变化？
5. **投到哪里**：形成特定感觉，还是维持皮层觉醒？

> **本 Block 最低地图**：刺激 → 受体电位 → 动作电位编码 → 中枢投射 → 感觉；前庭、痛觉只是这条共同链的不同实现。

# 1｜总 Framework

<!-- kianos:framework id="neuro-n05-framework-main" -->

```text
A｜共同换能语言
适宜刺激
→ 感受器电位（局部电位）
→ 传入神经AP
→ 强度 / 时间 / 空间编码

B｜时间编码
恒定刺激持续
→ AP频率可逐渐下降 = 适应
→ 快适应偏“变化探测”
→ 慢适应偏“持续状态监测”

C｜空间编码
一个局部刺激激活一组通路
→ 中心兴奋 + 周边抑制
→ 侧向抑制
→ 边界更清楚、两点分辨↑

D｜前庭
直线加速度 / 重力 → 椭圆囊、球囊囊斑
角加速度 → 半规管壶腹嵴
→ 毛细胞 → 前庭反应 / 眼震颤

E｜痛觉
组织损伤与致痛介质
→ 游离神经末梢
→ Aδ快痛 / C慢痛
→ 不易适应，持续报警

F｜投射
特异性：接替 / 联络核 → 点对点 → 特定皮层 → 特定感觉
非特异性：髓板内核 / 网状系统 → 弥散 → 广泛皮层 → 觉醒状态

G｜Source Boundary
嗅觉 / 味觉在当前正式范围只明确出现为“快适应感受器”等接口
→ 不凭模型常识补出完整换能和通路
```

# 2｜感觉共同语言：先换能，再编码

<!-- kianos:kp id="neuro-n05-kp01" -->

## KP01｜适宜刺激与换能：先把物理 / 化学能变成局部电位

> **讲义定位 →** 生理 Lecture PDF P330–331，书页 P290–291。  
> **主提示**：适宜刺激1定义｜非适宜强度｜痛觉特殊｜换能2级｜局部→AP。

### 1｜适宜刺激

一种感受器通常对某一种形式的刺激最敏感，这种刺激称为**适宜刺激**。

当前 Study 例子：

- 视网膜感光细胞 → 一定波长的电磁波；
- 耳蜗毛细胞 → 一定频率的机械振动。

感受器并非只能响应适宜刺激；非适宜刺激足够强也可引起反应，但所需强度明显更大。

当前 Study 的特殊记忆点：

> **痛觉感受器不按普通“单一适宜刺激”模式理解。**

### 2｜换能不是直接“变成感觉”

```text
刺激能量
→ 感受器首先产生感受器电位 / 受体电位
→ 本质为局部电位
→ 最终转换为传入神经动作电位
→ 中枢才读取这些神经冲动
```

局部电位负责“把刺激翻译成电”，动作电位负责“不衰减地把信息送远”。

（易混：**受体电位 ≠ 动作电位**。受体电位可以等级变化、会衰减；动作电位仍遵循全或无和再生传播。）

## KP02｜适应：快适应检测变化，慢适应监测持续状态

> **讲义定位 →** 生理 Lecture PDF P330–331。  
> **主提示**：定义1｜快4例+意义｜慢5类+意义｜不适应2例｜≠疲劳/习惯化。

**适应**：恒定强度刺激持续存在时，传入神经动作电位频率逐渐降低。

### 快适应感受器

当前 Study 例：

- 皮肤环层小体；
- 麦斯纳小体；
- 味觉；
- 嗅觉。

意义：对**刺激变化、新刺激**特别敏感，适合发现环境是否发生了新的变化。

### 慢适应感受器

当前 Study 例：

- 颈动脉窦；
- 颈动脉体；
- 肌梭；
- 腱器官；
- 关节囊感受器；
- 痛觉感受器不易适应。

意义：适合持续监测血压、姿势和组织损伤等需要长期报警的状态。

当前 Study 另列：

- 温度敏感神经元不适应；
- 耳蜗微音器电位不适应。

### 三者不能混

| 概念 | 发生层级 | 当前核心 |
|---|---|---|
| 感受器适应 | 感受器 / 传入端 | 恒定刺激下 AP 频率下降；加大刺激仍可再增强 |
| 传递疲劳 | 化学突触 / NMJ | 常与递质耗竭有关 |
| 习惯化 | 中枢学习 | 对重复无害刺激的中枢反应下降 |

（易混：适应之后**改变刺激强度**仍可重新提高传入冲动；这与单纯递质耗竭不同。）

## KP03｜侧向抑制：中心更亮、周边更暗，空间分辨力就更高

> **讲义定位 →** 生理 Lecture PDF P331。  
> **主提示**：中心兴奋｜周边抑制｜中间神经元｜结果2｜双眼视觉不是。

一个局部刺激通常不会只激活一条传入纤维，而会激活一个空间群。若所有邻近通路都同样兴奋，边界反而模糊。

当前 Study 的处理方式：

```text
刺激中心区
→ 直接兴奋下一神经元

刺激周边区
→ 经抑制性中间神经元
→ 抑制邻近后续神经元

中心—周边兴奋差被拉大
→ 刺激边界更清楚
→ 感觉分辨能力↑
→ 两点辨别能力↑
```

因此：

> **侧向抑制 = 感觉系统增强空间分辨率的重要信息处理方式。**

（易混：双眼视觉主要扩大视野、弥补盲点并形成立体视觉；**增强感觉分辨力的是侧向抑制**。）

# 3｜前庭：先分直线加速度与角加速度

<!-- kianos:kp id="neuro-n05-kp04" -->

## KP04｜前庭器官：耳石器官管直线，半规管管旋转

> **讲义定位 →** 生理 Lecture PDF P326，书页 P286。  
> **主提示**：器官3｜毛细胞｜内淋巴相通｜椭圆水平｜球囊垂直｜半规角加速。

前庭器官包括：

1. 椭圆囊；
2. 球囊；
3. 半规管。

它们的感受细胞都是**毛细胞**，且当前 Study 强调其液体环境与蜗管内淋巴相通。

### 耳石器官 / 囊斑

| 结构 | 当前主要刺激 |
|---|---|
| 椭圆囊囊斑 | 水平直线变速运动，如突然刹车 |
| 球囊囊斑 | 垂直直线变速运动，如乘电梯 |

### 半规管 / 壶腹嵴

> 主要感受**旋转变速 / 角加速度**。

因此遇到平衡题，第一问不是“哪个半规管”，而是：

```text
直线加速度？ → 耳石器官 / 囊斑
角加速度？   → 半规管 / 壶腹嵴
```

（易混：半规管不是单纯感受“头在什么位置”，而是当前 Study 强调的旋转变速运动。）

## KP05｜三轴—三平面—三半规管：先定绕哪根轴，再定运动平面

> **讲义定位 →** 生理 Lecture PDF P327–328，书页 P287–288。  
> **主提示**：3轴方向｜轴⊥平面｜纵→水平/外｜冠→矢状/后｜矢→冠状/前。

当前 Study 的空间坐标：

| 轴 | 轴方向 | 绕轴运动所在平面 | 主要半规管 |
|---|---|---|---|
| 垂直 / 纵轴 | 上下 | 水平面 | 水平 / 外半规管 |
| 冠状轴 | 左右 | 矢状面 | 后半规管 |
| 矢状轴 | 前后 | 冠状面 | 上 / 前半规管 |

核心几何原则：

> **绕某一轴旋转，运动发生在与该轴垂直的平面。**

例如：

- 绕垂直轴转 → 水平面旋转 → 水平眼震；
- 前后翻滚 → 绕冠状轴 → 矢状面运动 → 后半规管；
- 侧空翻 → 绕矢状轴 → 冠状面运动 → 前 / 上半规管。

当前 Study 特殊：晕船对**前 / 上半规管与后半规管**刺激较大。

> 这组空间关系必须看 P327–328 原图，不建议纯文字硬背。

## KP06｜眼震颤：慢相跟前庭刺激，快相由中枢矫正；头尾一致、中间相反

> **讲义定位 →** 生理 Lecture PDF P329，书页 P289。  
> **主提示**：头左4步｜停转反向｜慢/快2相｜头尾一致｜3管→3眼震。

以头开始向左转为例：

```text
头向左开始旋转
→ 内淋巴因惯性相对向右
→ 两眼缓慢向右偏移（前庭慢相）
→ 中枢快速把眼球拉回左侧（快相）
```

当前 Lecture 的方向记忆是：**头开始向左，快相也向左；中间慢相先向右。**

旋转突然停止时，内淋巴仍因惯性继续原方向运动，前庭刺激方向改变，眼震相位随之反转。

当前 Study 的空间配对：

| 主要受刺激结构 | 眼震主要方向 |
|---|---|
| 水平 / 外半规管 | 水平眼震 |
| 上 / 前半规管 | 垂直眼震 |
| 后半规管 | 旋转性眼震 |

低摩擦理解：

> **头最终往哪转，眼震快相最终往哪；中间慢相先反着走。**

# 4｜痛觉：一个报警系统分成“快定位”和“慢持续”

<!-- kianos:kp id="neuro-n05-kp07" -->

## KP07｜快痛 vs 慢痛：Aδ快且清楚，C慢且持续、定位差

> **讲义定位 →** 生理 Lecture PDF P330，书页 P290；Recall N1纤维分类。  
> **主提示**：Aδ/C｜有/无髓｜快/慢｜定位｜持续｜内脏痛。

| 轴 | 快痛 | 慢痛 |
|---|---|---|
| 传入纤维 | Aδ | C |
| 髓鞘 | 有 | 无 |
| 传导 | 快 | 慢 |
| 定位 | 清楚 | 不清楚 |
| 持续 | 较短 | 较长 |
| Study接口 | 快速警报、定位 | 持续警报；内脏痛定位差 |

这不是两种独立疾病，而是同一损伤信息通过不同传入纤维产生不同时间与空间体验。

（易混：若 N1 已形成，可直接 Recall Aδ 是有髓快痛、C 是无髓慢痛；未形成时只补当前快慢痛所需的最小纤维接口。）

## KP08｜痛觉报警链：组织损伤先释放介质，再激活游离神经末梢

> **讲义定位 →** 生理 Lecture PDF P330。  
> **主提示**：受体1形态｜损伤→介质｜介质群｜Aδ/C｜为何不易适应。

痛觉感受器的结构身份：**游离神经末梢**。

当前 Study 的连续链：

```text
伤害性刺激
→ 组织损伤
→ 局部释放致痛物质
→ 游离神经末梢兴奋
→ Aδ / C传入
→ 中枢形成痛觉
```

Lecture 列出的致痛 / 炎症相关物质包括：

- 缓激肽；
- 前列腺素；
- P物质；
- K⁺、H⁺；
- 组胺、5-HT；
- CGRP；
- NGF；
- IL、TNF 等细胞因子。

它们不用在本 Block 再做“炎症介质大全”；这里的作用只是解释：

> **组织损伤怎样把局部化学环境转成持续的疼痛传入。**

痛觉不易适应具有保护意义：损伤尚未解除时，报警不能迅速消失。

# 5｜中枢投射：既要告诉你“是什么感觉”，也要让皮层保持能接收感觉的状态

<!-- kianos:kp id="neuro-n05-kp09" -->

## KP09｜中央后回投射：躯干四肢交叉，头面双侧，身体总体倒置

> **讲义定位 →** 生理 Lecture PDF P332，书页 P292。  
> **主提示**：躯干四肢交叉｜头面双侧｜下/上/脸3层｜面积看精细度｜可塑性。

当前 Study 的中央后回感觉投射规律：

1. 躯干、四肢感觉主要为**交叉性投射**；
2. 头面部感觉为**双侧性投射**；
3. 身体代表区总体“上下倒置”：
   - 下肢 → 顶部；
   - 上肢 → 中部；
   - 头面部 → 底部；
4. 头面部本身按当前 Study 为正立；
5. 皮层投射区域大小与**感觉分辨精细程度**相关，而不是简单与身体部位体积相关。

Lecture 还强调感觉皮层具有可塑性：长期感觉输入改变后，皮层功能分配可发生重组。

（易混：刺激右侧坐骨神经 → 最大诱发电位在左侧中央后回顶部；三叉感觉因双侧投射 → 两侧中央后回底部。）

## KP10｜特异 vs 非特异投射：一个告诉“是什么”，一个维持“能醒着接收”

> **讲义定位 →** 生理 Lecture PDF P333，书页 P293。  
> **主提示**：起始核2组｜点/弥散｜特定/广泛｜特定感觉/觉醒｜网状系统。

| 轴 | 特异性投射系统 | 非特异性投射系统 |
|---|---|---|
| 当前 Study 起始核 | 接替核、联络核 | 髓板内核 |
| 投射方式 | 点对点 | 弥散 |
| 投射范围 | 大脑皮层特定区域 | 大脑皮层广泛区域 |
| 主要意义 | 引起各种特定感觉、激发皮层特定输出 | 维持 / 改变大脑皮层兴奋状态，为特异感觉提供觉醒基础 |

低摩擦理解：

```text
特异系统：告诉皮层“这是什么、在哪里”
非特异系统：让整个皮层“保持上线、能处理信息”
```

当前 Study 将非特异投射与**脑干网状结构上行唤醒系统**相连；多突触接替使其较易受镇静催眠药影响。

## KP11｜网状结构实验：刺激→醒+快波，切断→睡+慢波

> **讲义定位 →** 生理 Lecture PDF P333。  
> **主提示**：刺激网状结构2结果｜中脑头端切断2结果｜醒快/睡慢。

当前 Study 的经典实验：

```text
刺激猫脑干网状结构
→ 从睡眠中唤醒
→ EEG去同步化快波

在中脑头端切断网状结构
→ 持久昏睡
→ EEG同步化慢波
```

一句话：

> **醒着快而不同步；睡着慢而同步。**

本处只建立“非特异投射—觉醒”的接口。EEG、NREM / REM、完整睡眠—觉醒调控在 N9 正式学习，当前不提前展开。

# 6｜三张高价值比较表

## 6.1 快适应 vs 慢适应

| 轴 | 快适应 | 慢适应 |
|---|---|---|
| 最擅长 | 检测变化、新刺激 | 监测持续状态 |
| 传入频率 | 恒定刺激下下降快 | 下降慢 / 可长期维持 |
| 代表 | 环层小体、麦斯纳、味觉、嗅觉 | 颈动脉窦/体、肌梭、腱器官、关节囊、痛觉不易适应 |
| 典型价值 | 探索变化 | 血压、姿势、损伤报警 |

## 6.2 直线 vs 旋转

| 刺激 | 主要感受器 | 当前例子 |
|---|---|---|
| 水平直线加速度 | 椭圆囊囊斑 | 刹车 |
| 垂直直线加速度 | 球囊囊斑 | 电梯 |
| 角加速度 | 半规管壶腹嵴 | 转头、旋转 |

## 6.3 特异 vs 非特异投射

```text
“是什么 / 在哪里” → 特异性投射
“皮层是否处于可处理信息的兴奋状态” → 非特异性投射
```
