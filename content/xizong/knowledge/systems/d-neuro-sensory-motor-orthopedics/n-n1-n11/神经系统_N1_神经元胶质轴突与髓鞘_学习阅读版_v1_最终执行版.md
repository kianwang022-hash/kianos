# 0｜统一入口：一个神经元要同时完成“五件事”

神经元不是一根单纯导线，而是一套有明确分区的长距离信息系统：

```text
树突 / 树突棘接收大量输入
→ 胞体整合局部电位
→ 轴突始段决定是否达到阈电位
→ 轴突与髓鞘把动作电位送到远端
→ 轴突末梢向下一级细胞传递信息
```

与此同时，它还必须维持另一条看不见的物流线：

```text
胞体合成蛋白、囊泡和细胞器
→ 顺向轴浆运输送往末梢
→ 靶组织和胶质细胞提供神经营养因子
→ 逆向运输回胞体
→ 调整神经元代谢、结构和存活
```

胶质细胞则围绕这两条主线承担：

```text
支撑与隔离
+ 髓鞘与高速传导
+ K⁺与递质环境稳定
+ 吞噬和免疫
+ 损伤后的修复 / 胶质瘢痕
```

> **本 Block 的最低地图**：接收 → 决策 → 传导 → 运输 → 营养 / 支持。

# 2｜神经元的结构分工与放电入口

<!-- kianos:kp id="neuro-n01-kp01" -->

## KP01｜胞体、树突、轴突与树突棘：先分清“接收—整合—输出”

> **讲义定位 →** 生理 Lecture PDF P337，书页 P295。  
> **主提示**：3功能区｜突触主位｜树突棘3点｜智障2特征。

### 结构分工

| 结构 | 当前 Study 角色 |
|---|---|
| 胞体 | 细胞代谢与合成中心；接收、整合大量局部电位 |
| 树突 | 接收上一级神经元输入；分支多、接触面大 |
| 树突棘 | 中枢突触主要形成部位；数量、形态可改变 |
| 轴突 | 通常每个神经元只有一条；负责把动作电位送往远端 |
| 轴突末梢 | 分支后与下一级神经元或效应细胞形成突触 |

树突棘的数量和形态具有易变性，因此 Study 将它作为**脑功能可塑性的结构基础**。不同个体、同一个体不同阶段，突触接触与传递效能都可以变化。

智力障碍儿童的树突棘在当前 Study 中表现为：

- 数量较少；
- 形态细长，接触面积较小。

这意味着形成有效突触的结构条件减少，脑功能可塑性下降。

（易混：神经元通常只有一条轴突，但树突、轴突末梢分支和突触数目可以很多。）

## KP02｜动作电位为什么先从轴突始段或第一个郎飞结爆发

> **讲义定位 →** 生理 Lecture PDF P338，书页 P296。  
> **主提示**：首发2处｜阈值3因｜Na⁺通道密度｜胞体只产生？

神经元收到的 EPSP / IPSP 先以局部电位形式在树突和胞体传播、总和。真正决定是否向下传递的是轴突入口：

```text
局部电位总和
→ 轴突始段 / 第一个郎飞结
→ 电压门控Na⁺通道密度高
→ 阈电位更接近静息电位
→ 最先达到阈值
→ 爆发动作电位
```

Study 给出的阈电位影响因素：

1. 电压门控 Na⁺ 通道的分布密度；
2. 电压门控 Na⁺ 通道的功能状态；
3. 细胞外 Ca²⁺ 浓度。

轴突始段和郎飞结的 Na⁺ 通道密度高，因此兴奋性更高。胞体、树突主要承担局部电位整合，而不是通常意义上的动作电位首发点。

（特殊：题目可写“轴突始段”或“第一个郎飞结”；核心逻辑都是高密度电压门控 Na⁺ 通道。）

//串联：低 Ca²⁺ 时阈值改变、兴奋性升高，可与低钙惊厥接口相连；完整钙稳态不在本 Block 重学。

# 3｜神经纤维怎样传导动作电位

<!-- kianos:kp id="neuro-n01-kp03" -->

## KP03｜神经纤维的定义与4个传导特征

> **讲义定位 →** 生理 Lecture PDF P338。  
> **主提示**：定义2层｜4特征｜离体/体内方向｜疲劳对象。

**神经纤维**通常指神经元的细长突起，主要是轴突，并包括其周围包绕的胶质结构。它有两项核心功能：

- 兴奋传导；
- 物质运输。

### 四个传导特征

1. **双向性**：离体刺激神经纤维中段，局部电流可向两侧传播。  
   但在体内，神经元有“树突 → 胞体 → 轴突 → 下一神经元”的结构极性，整体信息流通常表现为单向。

2. **完整性**：结构和功能均需完整。  
   轴突断裂、膜功能受损或 Na⁺ 通道被局麻药阻断，都可使传导停止。

3. **绝缘性 / 互不干扰性**：一根神经干内含多条纤维，但局部电流进入大容量细胞外液后迅速分散、衰减，不会轻易串入相邻纤维。

4. **相对不疲劳性**：动作电位可不断再生，传导本身相对不疲劳；化学突触和神经—肌接头则可能因递质耗竭发生疲劳。

（易混：**疲劳**是突触递质耗竭；**感受器适应**是持续刺激时传入冲动频率下降；**习惯化**属于简单学习。三者不是同一概念。）

## KP04｜局部电流、髓鞘与传导速度：为什么有髓纤维又快又省

> **讲义定位 →** 生理 Lecture PDF P338。  
> **主提示**：本质1｜速度3因｜0.6∶1｜有髓3优势｜脱髓鞘3病。

动作电位的传导方式是**局部电流**，本质是：

> 已兴奋膜段产生局部电流，使相邻未兴奋膜段依次达到阈值并再生新的动作电位。

### 传导速度的三个主要因素

| 因素 | 方向 |
|---|---|
| 纤维直径 | 直径增大 → 内阻下降 → 速度增快 |
| 髓鞘 | 有髓纤维在郎飞结间跳跃传导 → 快、耗能少 |
| 温度 | 温度升高、代谢与通道活动加快 → 速度增快 |

Study 另给出一个精确记忆点：

> 轴索直径 : 神经纤维总直径约为 **0.6 : 1** 时，传导速度达到峰值。

髓鞘并不让动作电位“穿过髓鞘连续跑”，而是使有效膜电流跨越被绝缘的节间区，在郎飞结处重新产生动作电位。

```text
髓鞘完整
→ 节间漏电少
→ 郎飞结间跳跃
→ 传导快、耗能少

脱髓鞘
→ 漏电增加
→ 下一郎飞结难达阈值
→ 传导减慢甚至中断
```

//串联：Study 举例糖尿病、多发性硬化、吉兰–巴雷综合征均可通过脱髓鞘造成感觉和运动障碍；这里只理解“髓鞘—速度”接口，不展开疾病诊疗。

（特殊：低温可使神经传导减慢，形成低温麻醉接口。）

## KP05｜周围神经纤维分类：A/B/C与Ⅰ–Ⅳ怎样挂回功能

> **讲义定位 →** 生理 Lecture PDF P339，书页 P297。  
> **主提示**：A4亚型｜Ⅰ–Ⅳ｜快慢AC｜前后BC｜触压BCD｜Ⅰa/Ⅰb。

Study 使用两套分类：

- 按传导速度：A、B、C，多用于传出纤维；
- 按直径和来源：Ⅰ、Ⅱ、Ⅲ、Ⅳ，多用于感觉传入纤维。

| 速度分类 | 对应感觉分类 | 髓鞘 | 主要功能 |
|---|---|---|---|
| Aα | Ⅰa / Ⅰb | 有 | 躯体运动；Ⅰa肌梭、Ⅰb腱器官；本体感觉 |
| Aβ | Ⅱ | 有 | 触压觉、本体感觉 |
| Aγ | — | 有 | 支配梭内肌 |
| Aδ | Ⅲ | 有 | 快痛、温度、触压觉 |
| B | — | 有 | 自主神经节前纤维 |
| C | Ⅳ | 无 | 慢痛、温度、触压觉；自主神经节后纤维 |

低摩擦记忆：

- **快慢 AC**：Aδ 快痛，C 慢痛；
- **前后 BC**：B 节前，C 节后；
- **触压 BCD**：Aβ、Aδ、C 均可传触压觉；
- **Ⅰa 肌梭，Ⅰb 腱器官**。

（易混：Aβ传本体感觉与精细触压；Aδ/C主要挂浅感觉，但两者也有触压觉接口。）

# 4｜轴突不是空电线：还要持续运货和维持靶组织

<!-- kianos:kp id="neuro-n01-kp06" -->

## KP06｜轴浆运输：两种顺向、一种逆向

> **讲义定位 →** 生理 Lecture PDF P339。  
> **主提示**：顺向2速｜逆向1｜驱/动力蛋白｜3类货｜病毒/毒素2。

| 类型 | 方向 | 相对速度 | 马达蛋白 | 主要货物 |
|---|---|---|---|---|
| 快速顺向 | 胞体 → 末梢 | 最快 | 驱动蛋白 / kinesin | 囊泡、线粒体、分泌颗粒等膜性细胞器 |
| 慢速顺向 | 胞体 → 末梢 | 最慢 | Study 归入顺向运输 | 微管蛋白、神经微丝蛋白等细胞骨架与可溶性成分、营养因子 |
| 逆向 | 末梢 → 胞体 | 居中 | 动力蛋白 / dynein | 神经营养因子、狂犬病毒、破伤风毒素、HRP示踪物 |

完整意义：

```text
胞体合成
→ 顺向把结构材料、能量装置和分泌囊泡送到远端
→ 末梢从靶组织摄取反馈信号
→ 逆向送回胞体
→ 调整神经元存活与功能
```

//串联：狂犬病毒和破伤风毒素可利用逆向轴浆运输进入中枢；本 Block 只建立运输入口，感染和毒素的完整模型后置。

（识别：HRP 利用逆向运输进行神经通路示踪。）

## KP07｜功能性作用 vs 营养性作用：为什么断神经后肌肉会逐渐萎缩

> **讲义定位 →** 生理 Lecture PDF P340，书页 P298。  
> **主提示**：2作用｜2类因子来源｜顺/逆运输｜去神经萎缩2病。

### 两种神经作用

| 作用 | 方式 | 时间特征 | 结果 |
|---|---|---|---|
| 功能性作用 | 末梢释放递质、引发效应器活动 | 快 | 肌肉收缩、腺体分泌等 |
| 营养性作用 | 释放营养因子、调节靶组织代谢与结构 | 慢而持续 | 维持蛋白合成、代谢和组织状态 |

按当前 Study 术语：

- **营养因子**由神经元产生，经顺向运输到靶组织；
- **神经营养因子**主要由被支配肌肉、星形胶质细胞产生，经逆向运输反馈至神经元。

神经切断后：

```text
功能性传入立即消失
+ 营养性作用长期缺失
→ 肌肉糖原合成减慢、蛋白分解加速
→ 去神经性萎缩
```

Study 接口：脊髓灰质炎 / 小儿麻痹症、肌萎缩侧索硬化可因运动神经元损害出现去神经性肌萎缩。

（易混：神经营养作用不是动作电位，也不是肌肉活动减少本身；它是长期代谢与结构支持。）

# 5｜神经网络不是一条线：四种连接决定扩散、整合和延续

<!-- kianos:kp id="neuro-n01-kp08" -->

## KP08｜中枢神经元4种联系方式

> **讲义定位 →** 生理 Lecture PDF P340。  
> **主提示**：4联系｜传入1｜传出1｜环式正/负｜单线例1。

| 联系形式 | 结构 | 常见位置 / 意义 |
|---|---|---|
| 单线联系 | 一对一或会聚程度很低 | 视锥系统；提高视敏度、分辨力 |
| 辐散式 | 一个神经元投向多个神经元 | 传入通路多见；把一个输入分送多个中枢 |
| 聚合 / 会聚式 | 多个神经元汇入一个神经元 | 传出通路多见；汇总多种指令 |
| 环式 / 回返式 | 后一级经侧支返回前一级 | 可负反馈终止，也可正反馈延续 |

环式联系两种结果：

```text
负反馈
→ 回返抑制
→ 及时终止活动、促进同一中枢同步化

正反馈
→ 后发放 / 后放电
→ 原刺激停止后，冲动仍延续一段时间
```

Study 将屈肌反射和突触可塑性作为后发放接口。

（易混：**辐散多见传入、会聚多见传出**；不是因为传入一定只有一条，而是当前 Study 的高频方向。）

//串联：侧向抑制利用中心兴奋、周边抑制提高感觉分辨率；完整机制在 N2 / N5 再调用。

# 6｜胶质细胞：不负责动作电位，却决定神经环境能否运行

<!-- kianos:kp id="neuro-n01-kp09" -->

## KP09｜星形胶质细胞：支持、稳K⁺、代谢与修复

> **讲义定位 →** 生理 Lecture PDF P340，书页 P298。  
> **主提示**：8角色｜K⁺清除2转运｜ATP不足链｜胶质瘢痕2面。

星形胶质细胞是脑内数量多、功能复杂的胶质细胞。Study 给出的角色包括：

- 机械支持；
- 神经元之间隔离；
- 屏障；
- 营养；
- 神经元迁移引导；
- 增生与修复；
- 免疫应答；
- 稳定细胞外液 K⁺；
- 代谢部分递质和活性物质；
- 对递质作出反应并反向调节神经元。

### K⁺缓冲链

星形胶质细胞膜上的 Na⁺-K⁺泵和 Na⁺-K⁺-2Cl⁻同向转运体可把过多的细胞外 K⁺转入细胞：

```text
ATP供应不足 / 胶质功能下降
→ Na⁺-K⁺泵能力下降
→ 细胞外K⁺升高
→ 神经元静息电位更接近阈电位
→ 兴奋性升高
→ 癫痫接口
```

### 修复的双刃剑

```text
损伤后星形胶质增生
→ 清除碎片、填补缺损、分泌营养和基质
→ 有利于局部修复

过度增生
→ 与其他胶质、成纤维细胞形成胶质瘢痕
→ 可抑制神经再生
```

（边界：完整胶质瘤和癫痫诊疗不在本 Block。）

## KP11｜神经元 vs 胶质：有没有树突轴突、化学突触、动作电位和增殖

> **讲义定位 →** 生理 Lecture PDF P341，书页 P299。  
> **主提示**：6轴比较｜AP谁有｜化学突触谁有｜谁可分裂。

| 比较轴 | 神经元 | 神经胶质细胞 |
|---|---|---|
| 数量 | 少 | 多 |
| 突起 | 有树突、轴突之分 | 有突起，但无树突、轴突之分 |
| 细胞间联系 | 可形成化学突触和电突触 | 不形成典型化学突触，普遍可有缝隙连接 |

| 动作电位 | 有 | 无 |
| 分裂增殖 | 通常无，属于永久细胞 | 有增殖能力 |

神经元承担信息接收、整合、传导、传递以及部分神经分泌；胶质主要维持神经元运行环境、结构和修复。

（易混：胶质有静息电位，但不能因此推出能产生动作电位。）

# 7｜脊髓病变：这里只建立 Lecture 自带的最低定位桥梁

<!-- kianos:kp id="neuro-n01-kp12" -->

## KP12｜薄束楔束 vs 脊髓丘脑侧束：先问“传什么、在哪里交叉”

> **讲义定位 →** 生理 Lecture PDF P342，书页 P300。  
> **主提示**：后索2感觉｜侧束2感觉｜同/对侧｜谁在脊髓交叉。

| 通路 | 主要功能 | 脊髓内当前判断 |
|---|---|---|
| 薄束、楔束（后索） | 本体 / 深感觉 + 精细触压觉 | 在脊髓内同侧上行，后续再交叉 |
| 脊髓丘脑侧束 | 痛觉、温度觉 | 进入脊髓后交叉，故传导对侧痛温觉 |

因此脊髓局灶病变时：

- 后索受损 → 同侧深感觉、精细触压觉障碍；
- 脊髓丘脑侧束受损 → 对侧痛温觉障碍；
- 锥体束在脊髓内也未再次交叉，损伤可形成同侧运动障碍接口。

> 本处只建立“束—感觉—交叉”的最小语言；完整传导通路、节段定位和临床神经系统检查后置 N11。

## KP13｜四种不完全性脊髓损伤：用“前—后—中央—半切”定位

> **讲义定位 →** 生理 Lecture PDF P342。  
> **主提示**：前最重｜后深丢｜中央上重｜半切同深动/对浅。

| 综合征 | 当前 Study 入口 |
|---|---|
| 前脊髓综合征 | 不完全损伤中最严重；主要运动、痛温觉障碍，后索深感觉可相对保留 |
| 后脊髓综合征 | 运动、痛温觉保留，本体 / 深感觉障碍 |
| 脊髓中央管周围综合征 | 多见颈椎过伸；上肢瘫痪重于下肢；Study强调“无感觉分离” |
| Brown-Séquard半切综合征 | 同侧运动和本体感觉障碍；对侧痛温觉障碍 |

半切综合征的核心不是背表，而是回到交叉：

```text
同侧锥体束受损 → 同侧运动障碍
同侧后索受损 → 同侧深感觉障碍
已在脊髓交叉的痛温束受损 → 对侧痛温觉障碍
```

（易混：前脊髓综合征和中央管周围综合征的上下肢轻重方向不同；按当前 Lecture 原图核对。）

## KP14｜脊髓内 vs 脊髓外肿瘤：痛温觉先丢哪一段

> **讲义定位 →** 生理 Lecture PDF P343，书页 P301。  
> **主提示**：侧束外→内4序｜内瘤先2段｜外瘤先2段。

脊髓丘脑侧束纤维在脊髓内按：

```text
骶 → 腰 → 胸 → 颈
由外向内排列
```

因此：

- **脊髓内肿瘤**从中央向外压迫 → 先影响更靠内的颈、胸纤维 → 颈胸部痛温觉先丧失；
- **脊髓外肿瘤**从外向内压迫 → 先影响外侧的骶、腰纤维 → 骶腰部痛温觉先丧失。

（边界：当前 Lecture 只把它作为痛温觉定位题，不扩写完整脊髓肿瘤临床模型。）
