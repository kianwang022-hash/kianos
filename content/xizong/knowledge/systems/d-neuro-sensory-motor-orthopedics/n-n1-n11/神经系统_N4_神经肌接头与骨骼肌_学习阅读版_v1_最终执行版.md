# 0｜统一入口：神经命令变成力，要连续跨过六道门

骨骼肌收缩不是“ACh一来，肌肉就缩”这么短。完整电影是：

```text
① 运动神经动作电位到达末梢
→ ② Ca²⁺触发ACh量子式释放
→ ③ N2开放形成终板电位，再点燃肌膜动作电位
→ ④ T管把电兴奋送到细胞深部，三联管释放SR Ca²⁺
→ ⑤ Ca²⁺解除肌丝位阻，横桥周期把化学能变成机械能
→ ⑥ 前负荷、后负荷、收缩性、运动单位和频率决定最终张力
```

舒张也不是“刺激停了自然松开”：

```text
ACh被AChE清除
+ 肌质网Ca²⁺泵消耗ATP回收Ca²⁺
+ ATP使横桥与肌动蛋白分离并复位
→ 肌浆Ca²⁺下降
→ 位阻恢复
→ 肌肉舒张
```

> **本 Block 的最低地图**：NMJ传令 → 肌膜放电 → 三联管释钙 → 横桥产力 → 负荷 / 招募 / 频率调力 → ATP完成收缩与舒张。

## KP01｜肌肉3类 + NMJ三部分：前膜放ACh，终板膜收命令，普通肌膜放AP

> **讲义定位 →** 生理 Lecture PDF P46，书页 P41。  
> **主提示**：肌3类｜横纹2类｜随意/非随意2组｜NMJ 3部分｜终板/普通肌膜2通道。

### 肌组织分类

| 肌组织 | 横纹 | 神经调控 | 意识控制 |
|---|---|---|---|
| 骨骼肌 | 有 | 躯体运动神经 | 随意肌 |
| 心肌 | 有 | 自主神经调节 | 非随意肌 |
| 平滑肌 | 无典型横纹 | 自主神经调节 | 非随意肌 |

本 Block只学习骨骼肌；心肌在循环、平滑肌在相关器官系统学习。

### 神经—肌接头三部分

1. **接头前膜**：运动神经末梢；含大量ACh囊泡，按囊泡为单位量子式释放；
2. **接头间隙**：充满细胞外液；ACh跨越此处，易受药物影响；
3. **接头后膜 / 终板膜**：骨骼肌细胞膜的特化区域，富含N2型ACh受体。

最重要的膜差异：

```text
终板膜：N2型ACh受体 = 化学 / 配体门控非选择性阳离子通道
普通肌膜：电压门控Na⁺通道
```

化学传递从前膜到后膜，方向单一；普通肌膜上的动作电位则可沿肌膜再生传播。

（易混：终板膜和普通肌膜都属于同一骨骼肌细胞膜，但通道构成和任务不同。）

## KP02｜N2与终板电位：3阳离子，Na⁺内流占主，EPP只是局部导火索

> **讲义定位 →** 生理 Lecture PDF P47，书页 P42。  
> **主提示**：N2 2身份｜通透3阳离子/排1阴离子｜Na主因1｜EPP 4性质｜AP在哪产生。

N2型ACh受体同时是受体和通道：

- 配体：ACh；
- 通道：非选择性阳离子通道；
- 对Na⁺、K⁺、Ca²⁺有通透性；
- 对Cl⁻无通透性；
- 尤其对Na⁺、K⁺高度通透。

通道开放后：

```text
Na⁺内流 + K⁺外流
但静息时Na⁺内向电化学驱动力远大于K⁺外向驱动力
→ 净正电荷内流
→ 终板膜去极化
→ 终板电位EPP
```

EPP的身份：

- 局部电位；
- 可总和；
- 随距离衰减；
- 本身不是动作电位，不出现动作电位式反极化；
- 作为“导火索”电紧张扩布到邻近普通肌膜。

普通肌膜电压门控Na⁺通道开放后，才产生全或无、不衰减传播的肌膜动作电位。

（易混：N2通道开放后的Na⁺内流**不是直接产生动作电位**；它先形成EPP，EPP再激活普通肌膜的电压门控Na⁺通道。）

## KP03｜电—化学—电全链：Ca²⁺触发释放，AChE终止，mEPP是一量子

> **讲义定位 →** 生理 Lecture PDF P47、P56。  
> **主提示**：电化电7步｜释放关键1离子｜AChE 1作用｜EPP/mEPP 4轴｜疲劳在哪。

### 完整传递链

```text
运动神经AP到达末梢
→ 接头前膜电压门控Ca²⁺通道开放
→ Ca²⁺内流
→ 大量ACh囊泡出胞
→ ACh结合终板膜N2
→ EPP电紧张扩布
→ 普通肌膜电压门控Na⁺通道开放
→ 肌膜AP传遍整条肌纤维
```

**触发大量囊泡释放的关键是末梢Ca²⁺内流。**

多数ACh被终板膜间隙侧AChE迅速水解，使EPP持续时间短，终板能接受下一次命令。

### EPP vs mEPP

| 维度 | 微 / 小终板电位 mEPP | 终板电位 EPP |
|---|---|---|
| 触发 | 静息时囊泡随机自发释放 | 运动神经AP到达、Ca²⁺内流 |
| 囊泡 | 1个 | 多个同步释放 |
| ACh / N2开放 | 少 | 多 |
| 本质 | 单个量子造成的微小局部去极化 | 大量mEPP总和形成的局部电位 |

Study低频数字：一次神经末梢兴奋可引发约 **125个囊泡**释放，并激活约 **2×10⁵个通道**；数字进入MI-D，不阻塞主链。

### 疲劳边界

- 动作电位沿神经和肌膜传导相对不疲劳；
- NMJ化学传递可因递质耗竭而疲劳。

（易混：疲劳发生在化学传递层，不是动作电位“传着传着变小”。）

## KP04｜NMJ干预：AChE抑制2情境｜MG 1位点+1药｜筒箭毒1位点

> **讲义定位 →** 生理 Lecture PDF P48，书页 P43。  
> **主提示**：AChE抑制→ACh？｜有机磷M/N 2组｜MG位点+药｜筒箭毒位点+EPP方向。

### 新斯的明 / 有机磷

```text
抑制AChE
→ ACh水解减少
→ 接头及其它胆碱能部位ACh蓄积
```

- NMJ：可出现肌束颤动等N样表现；
- M受体部位：心率减慢、针尖样瞳孔、大量出汗等。

### 重症肌无力接口

当前 Study：自身抗体结合并破坏N2型ACh受体，终板对ACh反应下降。

新斯的明减少ACh水解，可增强剩余受体所接收到的信号，改善症状。

### 筒箭毒碱

```text
阻断N2
→ Na⁺内流减少
→ EPP去极化幅度↓
→ 难以达到普通肌膜阈值
→ 肌膜AP与后续收缩失败
```

因此可用作肌松药。

（边界：完整有机磷中毒诊疗后置F模块；完整重症肌无力临床模型不在当前Source范围。）

## KP05｜肌节与滑行：2线3带｜粗细不变｜暗带不变、明带和H带缩短

> **讲义定位 →** 生理 Lecture PDF P48，书页 P43。  
> **主提示**：肌节2条Z｜M/H/暗/明4定位｜收缩3带变化｜粗细长度｜滑向哪。

### 肌节结构

- 相邻两条Z线之间：一个肌节，是骨骼肌收缩和舒张的基本单位；
- 暗带：粗肌丝所在区域，部分与细肌丝重叠；
- M线：暗带中央；
- H带：M线两侧、仅有粗肌丝的较亮区域；
- 明带：仅有细肌丝；Z线位于明带中央。

### 肌丝滑行理论

收缩时：

```text
细肌丝向M线方向滑行
→ 粗细肌丝重叠增加
→ 肌节缩短
```

粗、细肌丝本身长度不变，因此：

| 结构 | 收缩时 |
|---|---|
| 暗带 | 不变 |
| 明带 | 缩短 |
| H带 | 缩短 |
| 相邻Z线距离 / 肌节 | 缩短 |

（易混：不是肌丝本身缩短，而是相互滑行；暗带不变。）

## KP06｜T管、L管与三联管：横管传电，纵管管钙，终池放钙

> **讲义定位 →** 生理 Lecture PDF P49，书页 P44。  
> **主提示**：T 2身份/作用｜L 2组成｜纵网1泵｜终池1通道｜三联管3件。

### T管 / 横管

- 本质：肌膜向细胞内部凹陷；
- 方向：与肌原纤维垂直；
- 作用：把肌膜动作电位快速传到肌纤维深部。

### L管 / 纵管

本质是肌质网 / 肌浆网 / 内质网，即细胞内Ca²⁺库，包括：

1. **纵行肌质网**：膜上Ca²⁺泵把肌浆Ca²⁺逆浓度回收到肌质网；
2. **连接肌质网 / 终池 JSR**：与T管相接；膜上RyR是Ca²⁺释放通道。

### 三联管

```text
一条T管
+ 两侧终池
= 三联管
```

它是骨骼肌兴奋—收缩耦联的关键结构，把“肌膜电兴奋”转成“肌质网Ca²⁺释放”。

（易混：T管传递电兴奋；L管负责Ca²⁺储存、释放和回收。第一笔“横/竖”口诀只帮助记方向，不能替代结构。）

## KP07｜骨骼肌兴奋—收缩—舒张全链：L型变构拔塞，RyR放钙，Ca²⁺泵回收

> **讲义定位 →** 生理 Lecture PDF P50，书页 P45。  
> **主提示**：AP→T｜L型1动作｜RyR｜Ca瞬变｜结合1蛋白｜收缩｜回收1泵｜收/舒都耗能。

完整链：

```text
肌膜AP沿T管进入细胞深部
→ T管 / 肌膜L型Ca²⁺通道被激活并发生构象改变
→ 产生“拔塞样效应”
→ 激活终池RyR
→ 终池Ca²⁺顺浓度进入肌浆
→ 肌浆Ca²⁺瞬时升高：钙瞬变
→ Ca²⁺结合肌钙蛋白
→ 横桥周期启动、肌肉收缩
→ 纵行肌质网Ca²⁺泵消耗ATP回收Ca²⁺
→ 肌浆Ca²⁺下降
→ 位阻恢复、肌肉舒张
```

**动作电位引起骨骼肌收缩的关键**：胞质Ca²⁺浓度瞬时升高，而不是单纯“L型通道开放”或“RyR存在”。

骨骼肌收缩和舒张都耗能：

- 收缩需要横桥ATP循环；
- 舒张需要Ca²⁺泵回收Ca²⁺，也需要ATP使横桥脱离。

（易混：终池Ca²⁺顺浓度释放；回收到肌质网是逆浓度主动运输。）

## KP08｜骨骼肌 vs 心室肌E-C：三联/二联｜拔塞/开门｜SR 100%/80–90%

> **讲义定位 →** 生理 Lecture PDF P56–57，书页 P51–52。  
> **主提示**：关键结构3/2联｜L型拔塞/开放｜胞外Ca 0/10–20｜SR 100/80–90｜舒张去向｜CCB差异。

| 维度 | 骨骼肌 | 心室肌 |
|---|---|---|
| 关键结构 | 三联管：T管+两侧终池 | 二联管：T管+单侧终池 |
| L型Ca²⁺通道 | 构象改变，机械耦联“拔塞”RyR | 真正开放，胞外Ca²⁺进入 |
| 触发RyR | L型通道构象耦联 | 胞外Ca²⁺触发Ca²⁺释放（CICR） |
| Ca²⁺来源 | 当前Study口径：SR释放100% | SR约80–90%，胞外约10–20% |
| 舒张 | Ca²⁺由纵行肌质网泵100%回收 | 80–90%回SR，10–20%经Na⁺-Ca²⁺交换 / 膜Ca²⁺泵排出 |
| CCB | 不抑制骨骼肌收缩主链 | 可抑制心肌收缩 |

因此钙通道阻滞剂可抑制心肌L型Ca²⁺内流，却不会按同一路径阻断骨骼肌收缩。

（易混：骨骼肌L型Ca²⁺通道名为“钙通道”，当前主效应却是构象耦联，不以大量胞外Ca²⁺内流为关键。）

# 4｜Ca²⁺怎样解除位阻，ATP怎样驱动横桥

<!-- kianos:kp id="neuro-n04-kp09" -->

## KP09｜粗肌丝1蛋白，细肌丝3蛋白：收缩2个、调节2个

> **讲义定位 →** 生理 Lecture PDF P51，书页 P46。  
> **主提示**：粗1蛋白2功能｜细3蛋白3功能｜7:1:1｜收缩2｜调节2｜位阻是谁。

### 粗肌丝

由肌球蛋白 / 肌凝蛋白构成。肌球蛋白头部形成横桥，具有：

- ATP酶活性；
- 与肌动蛋白结合的能力。

### 细肌丝

由三种蛋白构成：

1. **肌动蛋白 / 肌纤蛋白**：有横桥结合位点；
2. **原肌球蛋白 / 原肌凝蛋白**：静息时遮盖肌动蛋白结合位点，产生位阻效应；
3. **肌钙蛋白**：有Ca²⁺结合位点。

Study比例：

```text
肌动蛋白 : 原肌球蛋白 : 肌钙蛋白 = 7 : 1 : 1
```

分类：

- 收缩蛋白：肌球蛋白、肌动蛋白；
- 调节蛋白：原肌球蛋白、肌钙蛋白。

（易混：真正遮挡横桥结合位点的是原肌球蛋白；真正结合Ca²⁺的是肌钙蛋白。）

## KP10｜横桥周期：Ca²⁺解除位阻，ADP状态亲，ATP状态分

> **讲义定位 →** 生理 Lecture PDF P51–52，书页 P46–47。  
> **主提示**：解除位阻3步｜结合—扭动—分离—复位4步｜45°｜ADP亲/ATP分｜ATP 2作用。

### 解除位阻

```text
肌浆Ca²⁺↑
→ Ca²⁺结合肌钙蛋白
→ 原肌球蛋白移位
→ 肌动蛋白横桥结合位点暴露
```

### 横桥周期

```text
1. 横桥与肌动蛋白结合
2. 横桥向桥臂方向扭动约45°，产生棘齿作用
   → 细肌丝滑向M线；ADP解离
3. 新ATP与横桥结合
   → 横桥对肌动蛋白亲和力下降
   → 横桥与肌动蛋白分离
4. 横桥ATP酶水解ATP
   → 横桥复位，准备下一周期
   → 与ADP结合状态对肌动蛋白亲和力高
```

ATP有两项关键作用：

1. 水解供能，使横桥复位；
2. ATP结合横桥后降低其对肌动蛋白的亲和力，使横桥分离。

所以ATP既支持收缩循环，也支持舒张。

（易混：张力大小取决于某一时刻参与结合的横桥数；缩短速度与横桥周期长短相关。）

//串联：等长收缩时肌肉长度不变，但横桥仍可扭动并拉伸弹性桥臂，从而产生张力；不是“没有横桥活动”。

# 5｜五个因素怎样调节骨骼肌收缩

<!-- kianos:kp id="neuro-n04-kp11" -->

## KP11｜五因素总览 + 前负荷：初长度决定重叠，最适肌节2.0–2.2 μm

> **讲义定位 →** 生理 Lecture PDF P53，书页 P48。  
> **主提示**：影响5类｜前负荷=什么｜主/被/总3张力｜一定范围方向｜最适肌节数字。

骨骼肌收缩的五类影响因素：

1. 前负荷 / 初长度；
2. 后负荷；
3. 肌肉收缩能力 / 收缩性；
4. 空间总和 / 运动单位招募；
5. 时间总和 / 刺激频率。

### 前负荷

前负荷是肌肉收缩前承受的负荷，决定肌肉开始收缩前的长度，即初长度。

- 被动张力：肌肉被拉长后产生的弹性回缩力；
- 主动张力：在某一初长度下主动收缩产生的张力；
- 总张力：主动张力 + 被动张力。

在一定范围内：

```text
前负荷 / 初长度↑
→ 粗细肌丝重叠和横桥工作条件改善
→ 主动张力↑
```

最适肌节长度：**2.0–2.2 μm**，可产生最大主动张力。

（边界：不是前负荷无限增加、张力就无限增加；超过最适范围后重叠变差。）

---

<!-- kianos:kp id="neuro-n04-kp12" -->

## KP12｜后负荷：张力↑｜速度↓｜程度↓｜起始晚｜等长↑｜等张↓

> **讲义定位 →** 生理 Lecture PDF P53–54，书页 P48–49。  
> **主提示**：后负荷↑六方向｜零负荷/极大负荷2极值｜等长/等张2定义｜最常见顺序。

后负荷是肌肉开始收缩后需要克服的负荷，可用“举哑铃”理解。

当后负荷增加：

| 变量 | 方向 |
|---|---|
| 肌肉产生的主动张力 | ↑ |
| 缩短速度 | ↓ |
| 缩短程度 / 距离 | ↓ |
| 开始缩短时间 | 延迟 |
| 等长收缩时间 | ↑ |
| 等张收缩时间 | ↓ |

逻辑：肌肉先通过等长收缩增加张力；当张力足以克服后负荷，才进入等张缩短。

极值：

- 后负荷为0：可从一开始进入等张收缩；
- 后负荷极大、无法克服：一直等长收缩，不能缩短。

定义：

- 等长收缩：长度不变，张力增加；
- 等张收缩：张力相对恒定，肌肉缩短。

骨骼肌常见形式：**先等长，后等张。**

（易混：后负荷增加时主动张力增加，不是下降；被动张力属于前负荷 / 初长度语境。）

<!-- kianos:kp id="neuro-n04-kp13" -->

## KP13｜收缩性：与前后负荷无关的3组内在条件，增强时两曲线右上/上移

> **讲义定位 →** 生理 Lecture PDF P54，书页 P49。  
> **主提示**：定义边界｜内在3组｜Ca/亲和力｜ATP酶｜结构能量蛋白｜2曲线方向。

肌肉收缩能力 / 收缩性，是与前负荷和后负荷无关的肌肉内在产力特性。

主要决定因素：

1. 肌浆Ca²⁺浓度及肌钙蛋白对Ca²⁺的亲和力 → 决定活化横桥数；
2. 横桥ATP酶活性 → 决定横桥循环效率；
3. 肌原纤维肥大、能量代谢水平、功能蛋白表达等。

收缩性增强：

- 长度—张力曲线向上移：同样初长度产生更大张力；
- 张力—速度曲线向右上移：同样张力下速度更快，同样速度下能产生更大张力。

（易混：前负荷、后负荷改变“收缩力表现”，但不等于改变肌肉内在收缩能力。）

## KP14｜空间总和：运动单位是基本招募单元，按大小原则由小到大加入

> **讲义定位 →** 生理 Lecture PDF P54，书页 P49。  
> **主提示**：运动单位1定义｜等级性｜空间总和｜招募↑方向｜大小原则收/松2顺序。

### 运动单位

```text
一个运动神经元
+ 其轴突末梢分支所支配的全部肌纤维
= 一个运动单位
```

同一运动单位内的肌纤维随该运动神经元动作电位共同活动。

### 收缩等级性与空间总和

骨骼肌整体张力不是全或无：

```text
参与收缩的运动单位少 → 张力小
招募更多运动单位同步收缩 → 张力增大
```

空间总和又称多纤维 / 多运动单位总和。

### 大小原则

- 收缩逐渐增强：先招募小运动单位，再逐渐加入大运动单位；
- 舒张：大运动单位先退出，小运动单位后退出，最小运动单位最后停止。

（易混：心肌整体收缩近似全或无，不发生骨骼肌式运动单位招募总和。）

## KP15｜时间总和：AP不重叠，机械收缩可重叠；频率靠维持Ca²⁺形成强直

> **讲义定位 →** 生理 Lecture PDF P55，书页 P50。  
> **主提示**：AP/收缩能否叠｜单/不全/完全3型｜叠加时相2｜本质1Ca｜骨骼肌多数｜肌紧张。

动作电位时程远短于一次机械收缩时程：

- 动作电位因绝对不应期不能彼此叠加；
- 后一个动作电位却可在前一次机械收缩尚未结束时到来，使收缩叠加。

| 类型 | 时相关系 |
|---|---|
| 单收缩 | 前一次收缩和舒张完全结束后才来下一刺激 |
| 不完全强直收缩 | 后一次收缩叠加于前一次舒张期 |
| 完全强直收缩 | 后一次收缩叠加于前一次收缩期 |

本质：

```text
AP频率↑
→ 肌质网反复释放Ca²⁺
→ Ca²⁺尚未完全回收又再次升高
→ 肌浆Ca²⁺维持在较高水平
→ 更多横桥持续参与
→ 张力叠加
```

骨骼肌生理活动多表现为完全性强直收缩，可产生最大张力。

静息时运动神经低频放电，使骨骼肌保持微弱而持续的收缩，称为**肌紧张**。

（易混：这里的“肌紧张”是低频冲动维持的骨骼肌基础张力；后续运动Block还会学习反射性肌张力调控。）
