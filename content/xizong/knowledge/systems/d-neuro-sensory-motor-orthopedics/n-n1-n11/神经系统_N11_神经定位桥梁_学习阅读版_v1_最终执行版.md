# N11｜神经定位桥梁
## 面对无力、麻木与反射异常，先报损伤层级，再讨论具体病名

> **FIRST PASS｜INTEGRATION_PRIMARY**  
> `先满足真实 hard readiness：N1 + N5 + N8 → KianOS 直接做定位整合 / retrieval → 仅在束位、根/神经/脊髓空间关系、外科精确措辞或不确定处定向回原 Source / 原图 → LG closure → Block Recall`
>
> **不要制造新的完整 N11 Lecture 通读。** N11 的 Primary 动作是整合已经形成的 N1 / N5 / N8 模型；外科 P155–157、P188–202 只承担定向视觉、措辞和边界核对，O3 / O4 / O5 的疾病 Primary 仍保留给各自 Block。
>
> **中心问题**：面对一个感觉或运动障碍病例，怎样用分布、肌力、肌张力、深浅反射、病理征、萎缩和括约肌功能，依次区分大脑 / 脊髓、神经根、周围神经与肌肉层；又怎样识别需要立即处理的高位脊髓、进行性压迫和马尾风险？
>
> **文件性质**：D 神经生理 Core 向 O1–O16 骨科疾病过渡的 **Integration Bridge**。它不新建一套神经内科学，也不抢占 O3、O4、O5 的外科 Primary ownership。
>
> **Outline身份**：**0 个新 Primary**。生理定位题已分别归 N1 / N5 / N8；外科脊髓、颈腰椎和周围神经题继续在 O3 / O4 / O5 首次完整归账。

# 0｜统一入口：定位不是猜病名，而是寻找“哪一级线路断了”

同样一句“腿没力”，可能来自：

```text
大脑皮层 / 下行束
脊髓
神经根
周围神经
NMJ
骨骼肌
骨关节疼痛导致的假性无力
```

最小定位顺序：

```text
① 症状分布：单侧 / 双侧？远端 / 近端？皮节 / 命名神经？
→ ② 中枢还是外周：是否有病理征、广泛反射改变？
→ ③ UMN还是LMN：硬 / 软、深反射、萎缩
→ ④ 神经根还是周围神经：皮节肌节 vs 命名神经领地
→ ⑤ 脊髓、圆锥还是马尾：长束、鞍区、括约肌、软硬瘫
→ ⑥ 是否紧急：呼吸、进行性肌力、二便、鞍区、急性创伤
```

> **本 Block 最低地图**：分布 → 硬软 → 反射 → 感觉 → 括约肌 → 平面 → 紧急度。

# 1｜总 Framework

<!-- kianos:framework id="neuro-n11-framework-main" -->

```text
A｜先判中央还是外周
中央：范围常广、可有Babinski、深反射↑、肌张力↑
外周：分布较局限、深反射↓、肌张力↓、萎缩明显

B｜再判传导束组合
后索：同侧深感觉 / 精细触压
脊髓丘脑侧束：对侧痛温
皮质脊髓束：同侧运动（在脊髓内）
→ 组合决定脊髓综合征

C｜根还是神经
根：皮节 + 肌节 + 反射，常有脊柱放射痛
神经：符合一个命名周围神经的感觉 / 运动领地

D｜脊髓还是圆锥 / 马尾
脊髓：长束体征、平面以下UMN模式
圆锥：鞍区 + 括约肌，Study表下肢运动可正常
马尾：鞍区 + 括约肌 + LMN软瘫

E｜颈椎两条线
神经根型：颈肩痛→上肢放射、局灶麻木无力
脊髓型：持物不稳、踩棉花、四肢 / 二便、病理征

F｜腰椎两条线
椎间盘突出：m-n椎间盘压第n根
椎管狭窄：症状多、体征少 + 神经源性间歇跛行

G｜紧急门禁
高位颈髓 / 呼吸
进行性瘫痪
脊髓型压迫
二便障碍 + 鞍区
急性脊柱创伤
→ 不能只按普通疼痛保守观察
```

# 2｜第一步：中央还是外周

<!-- kianos:kp id="neuro-n11-kp01" -->

## KP01｜神经定位六问：分布—硬软—反射—感觉—二便—急缓

> **讲义定位 →** N8、外科 Lecture P201–202综合。  
> **主提示**：6问｜分布｜硬软｜深浅反射/征｜感觉｜二便｜急缓。

面对无力 / 麻木先固定顺序：

1. 分布：单肢、半身、双下肢、四肢，还是一个手指 / 足缘？
2. 肌张力：增高还是降低？
3. 反射：深反射、浅反射、Babinski怎样？
4. 感觉：有无明确平面、皮节、命名神经领地或感觉分离？
5. 自主功能：尿潴留、失禁、鞍区感觉是否存在？
6. 时间：急性外伤、突然发生、逐渐进展还是活动诱发？

先完成层级定位，再讨论病名和治疗。

<!-- kianos:kp id="neuro-n11-kp02" -->

## KP02｜UMN vs LMN：硬广征阳深反高；软局萎缩深反低

> **讲义定位 →** N8 KP18；外科 Lecture P202。  
> **主提示**：硬/软｜广/局｜征+/−｜深↑/↓｜浅都↓｜萎缩轻/重｜肌电。

| 轴 | UMN / 硬瘫 | LMN / 软瘫 |
|---|---|---|
| 肌张力 | 增高 | 降低 |
| 深反射 | 增强 | 减弱 / 消失 |
| 浅反射 | 减弱 | 减弱 |
| 病理征 | 阳性 | 阴性 |
| 肌萎缩 | 不明显 | 明显 |
| 麻痹范围 | 较广 | 较局限 |
| 肌电图 | Study表可正常 | 异常 |

两个重要时间修正：

- 急性脊髓离断可先因脊休克表现软瘫，之后转为硬瘫；
- “软瘫”不自动等于周围神经损伤，必须结合急性脊休克背景。

<!-- kianos:kp id="neuro-n11-kp03" -->

## KP03｜中央 vs 外周：中央看长束组合，外周看反射弧和命名分布

> **讲义定位 →** N1 / N8 / 外科P201–202。  
> **主提示**：中央4线索｜外周4线索｜疼痛能否定位｜萎缩速度。

### 更支持中央 / 脊髓

- 明确感觉平面；
- 双侧或范围较广；
- Babinski阳性、深反射亢进；
- 同时出现运动、感觉和括约肌组合；
- 传导束模式，如同侧深感觉 / 运动 + 对侧痛温。

### 更支持外周 / 反射弧

- 局限在一根神经或一组肌；
- 肌张力与深反射降低；
- 明显去神经性萎缩；
- 感觉与运动符合命名神经领地；
- 可有Tinel征等周围神经再生接口。

（易混：疼痛和无力也可来自骨关节本身；必须先确认是否真有神经定位体征。）

# 3｜脊髓：用三条束和四种模式定位

<!-- kianos:kp id="neuro-n11-kp04" -->

## KP04｜脊髓三束最低坐标：后索同深，侧丘对浅，锥体同动

> **讲义定位 →** N1 KP12；生理原图P342。  
> **主提示**：后索2感觉/同侧｜侧丘2感觉/对侧｜锥体运动/同侧｜交叉地点。

在脊髓内：

- 薄束、楔束后索：同侧上行，传本体 / 深感觉与精细触压；
- 脊髓丘脑侧束：进入脊髓后交叉，传对侧痛温；
- 皮质脊髓束：已在更高处完成主要交叉，在脊髓内损伤表现同侧运动障碍。

因此脊髓半切的最低组合：

```text
同侧运动障碍
+ 同侧深感觉障碍
+ 对侧痛温障碍
```

> 不先背综合征名字，先画三条束的侧别。

<!-- kianos:kp id="neuro-n11-kp05" -->

## KP05｜四类不完全脊髓损伤：前最重、后深丢、中央上重、半切交叉组合

> **讲义定位 →** N1 KP13；外科 Lecture P188–189。  
> **主提示**：前最重｜后深丢｜中央上重无分离｜半切同动深/对浅。

| 模式 | 当前Source最低定位 |
|---|---|
| 前脊髓综合征 | 运动和痛温受累明显；下肢可重于上肢；属于较严重模式 |
| 后脊髓综合征 | 深感觉障碍；运动、痛温可保留 |
| 中央管周围综合征 | 常见颈椎过伸背景；上肢瘫重于下肢；Study强调急性期无典型感觉分离 |
| 脊髓半切 | 同侧运动 + 深感觉障碍，对侧痛温障碍 |

（易混：脊髓中央管周围综合征与慢性脊髓空洞症不是同一模型；完整鉴别后置O3/O4。）

<!-- kianos:kp id="neuro-n11-kp06" -->

## KP06｜脊休克 vs 完全性长束损伤：反射可恢复，断掉的传导不自动恢复

> **讲义定位 →** N8 KP10；外科 Lecture P189。  
> **主提示**：永久2｜暂时反射｜软→硬｜深反/征方向｜时程冲突。

完全脊髓损伤后要分两层：

### 长传导束损伤

损伤平面以下感觉和随意运动功能丧失，是结构中断的主体。

### 脊休克

急性期高位易化输入突然丢失，表现软瘫、反射与肌张力下降；恢复期可转为：

- 肌张力增高；
- 腱反射亢进；
- 病理征阳性。

### SOURCE_CONFLICT｜N11-SC01

- 生理 Lecture：反射恢复描述为“数周至数月”；
- 外科 Lecture：创伤章节给出“2–4周后软瘫变硬瘫”。

本文件按来源场景保留两者，不冻结一个跨所有病例的唯一精确时程。

# 4｜神经根还是单根周围神经

<!-- kianos:kp id="neuro-n11-kp07" -->

## KP07｜神经根：皮节 + 肌节 + 反射；周围神经：命名神经的混合领地

> **讲义定位 →** 外科 Lecture P194–202。  
> **主提示**：根3件｜神经3件｜放射痛｜跨几根神经｜脊柱诱发征。

### 神经根病变

- 感觉沿皮节；
- 运动沿肌节；
- 可改变对应深反射；
- 常伴颈肩 / 腰痛向肢体放射；
- 脊柱动作或牵拉可诱发。

一根神经根可通过神经丛进入多个终末周围神经，因此根性损伤不一定完全符合一根命名神经。

### 单根周围神经病变

- 感觉落在该命名神经皮肤领地；
- 运动落在其支配肌群；
- 反射改变取决于该反射弧是否经过该神经；
- 常有局部创伤、卡压或Tinel征接口。

（边界：完整臂丛、桡 / 正中 / 尺及下肢神经损伤Primary后置O5。）

---

<!-- kianos:kp id="neuro-n11-kp08" -->

## KP08｜周围神经最低识别：桡伸、正中对掌、尺骨间；高位损伤表现更多

> **讲义定位 →** 外科 Lecture P155–157。  
> **主提示**：桡1姿势｜正中1姿势｜尺1姿势｜肌皮/腋2接口｜高低位规律。

当前只保留进入O5前的最低识别：

- 桡神经损伤：伸腕 / 伸指等受损，典型垂腕接口；
- 正中神经损伤：旋前、屈指和拇指对掌等受损，大鱼际萎缩 / 猿手接口；
- 尺神经损伤：手指内收外展受损，爪形手、Froment / 夹纸试验接口；
- 腋神经：三角肌萎缩、方肩；
- 胸长神经：前锯肌失效、翼状肩。

同一神经损伤位置越高，位于其下游的感觉和运动支路越多，因此表现越广。

（边界：不在此背完整神经分支、手术与恢复；进入O5时一次学全。）

# 5｜脊髓圆锥与马尾：二便和鞍区是定位闸门

<!-- kianos:kp id="neuro-n11-kp09" -->

## KP09｜脊髓 vs 圆锥 vs 马尾：长束硬瘫，圆锥二便鞍区，马尾再加软瘫

> **讲义定位 →** 外科 Lecture P189–190。  
> **主提示**：脊髓长束｜圆锥2核心+运动｜马尾2核心+软瘫｜共同鞍区二便。

### 脊髓主体病变

- 可出现明确感觉平面；
- 损伤平面以下长束性运动 / 感觉组合；
- 脊休克恢复后偏UMN硬瘫。

### 脊髓圆锥

Study最低表述：

- 会阴 / 鞍区感觉障碍；
- 括约肌功能丧失，二便障碍；
- 下肢运动可正常。

### 马尾神经

- 会阴 / 鞍区感觉障碍；
- 括约肌功能障碍；
- 由于属于神经根束，可出现下肢LMN型运动障碍 / 软瘫。

> 二便障碍 + 鞍区感觉异常不是普通腰痛线索，而是必须立即升级定位的风险组合。

# 6｜颈椎与腰椎压迫的最低定位

<!-- kianos:kp id="neuro-n11-kp10" -->

## KP10｜颈椎神经根型 vs 脊髓型：上肢放射局灶，还是四肢广泛 + 病理征

> **讲义定位 →** 外科 Lecture P194–196。  
> **主提示**：根型4｜髓型5｜Eaton/Spurling｜Hoffmann/Babinski｜最常/最重。

| 轴 | 神经根型 | 脊髓型 |
|---|---|---|
| 典型入口 | 颈肩痛向上肢放射 | 持物不稳、踩棉花感 |
| 分布 | 上肢局灶感觉 / 运动障碍 | 四肢感觉、运动障碍，范围广 |
| 体征 | Eaton、Spurling接口 | Hoffmann、Babinski；可呈硬瘫 |
| 二便 | 通常不是主轴 | 可有二便障碍 |
| Study身份 | 最常见 | 最严重 |
| 紧急度接口 | 多先保守评估 | Source明确急诊手术、禁按摩和颌枕牵引 |

N11只冻结“根 vs 髓”的定位和风险层级；完整影像、适应证和术式归O4。

## KP11｜腰椎间盘压根：m-n压n；L4伸膝、L5伸踝足、S1屈踝足

> **讲义定位 →** 外科 Lecture P194、P197。  
> **主提示**：m-n→n｜L4伸膝/膝反｜L5伸踝足/足背内｜S1屈踝足/踝反｜二便特殊。

Study规律：

> 第 m–n 椎间盘突出，压迫第 n 神经根。

| 受累根 | 常见椎间盘 | 主要运动 | 感觉 | 深反射 |
|---|---|---|---|---|
| L4 | L3–4 | 伸膝 | 膝前、小腿前内、内踝 | 膝反射 |
| L5 | L4–5 | 伸踝、伸足 | 小腿外前、足背内侧 | Study表未冻结专属反射 |
| S1 | L5–S1 | 屈踝、屈足 | 小腿后、足外、外踝 | 踝 / 跟腱反射 |

### 两个重要边界

- 腰椎间盘突出通常压神经根；成人腰段脊髓已在更高位置终止，不能把腰突病例机械说成“压腰段脊髓”；
- 二便障碍提示马尾受压，是Source明确的急诊手术入口；单纯鞍区感觉异常的处置口径应回O4完整模型，不在N11自行升级。

# 7｜四张高价值定位表

## 7.1 “硬还是软”只能作为第一层


## 7.2 “根还是神经”靠分布

```text
根：皮节 + 肌节 + 反射 + 脊柱放射痛
神经：命名神经感觉区 + 其支配肌群 + 局部损伤史
```

## 7.3 “脊髓还是马尾”靠长束与反射

```text
脊髓：平面以下长束组合，恢复后偏硬瘫
马尾：根束组合，偏软瘫；鞍区 + 二便
```

## 7.4 “神经根型还是脊髓型颈椎病”

```text
上肢放射局灶 + 根性诱发征 → 根型
四肢广泛 + 病理征 + 踩棉花 / 二便 → 脊髓型
```
