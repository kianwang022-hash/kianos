### Accepted mother model

D is modeled as an **information → control → execution → structure → feedback** system with parallel structural-failure branches:

```text
sensory transduction / coding
→ neural conduction
→ synaptic / receptor integration
→ network state + central control
→ descending command
→ NMJ / skeletal-muscle force
→ bone / joint / tendon / ligament plant
→ sensory feedback
```

Trauma, compression, ischemia, overload, infection, immune inflammation, developmental abnormality and tumor may enter at different neural/structural layers. The diagnostic task is to locate the failed layer, stability and danger before naming the disease.

This is a System-level compression model, **not** a claim that vision, sleep, fractures, arthritis and tumors form one serial disease chain.
