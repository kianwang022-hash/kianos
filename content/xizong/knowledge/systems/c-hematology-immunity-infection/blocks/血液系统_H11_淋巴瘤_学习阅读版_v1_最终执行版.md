# H11｜淋巴瘤
## 面对无痛性淋巴结肿大，先确认“组织内单克隆肿瘤”，再按部位—结构—细胞来源—侵袭性—分期建立HL与NHL两套模型
> **中心问题**：面对无痛性淋巴结肿大，怎样先确认淋巴组织内的克隆性肿瘤，再按部位、结构、细胞来源、侵袭性和分期区分 HL 与 NHL？
>

> **FIRST PASS 固定流程**
>
> `Framework → Lecture → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> 本 Block 同时整合内科临床与当前 Lecture 中的病理、免疫表型和染色体；H12完整免疫学仍后置，本处只学习诊断所需的最低 B / T / NK 接口。

# 1｜Framework｜淋巴瘤不是“淋巴细胞多”，而是淋巴结构被异常克隆占据

## 1.1 中心电影

```text
某一B / T / NK或前体淋巴细胞出现异常克隆
        ↓
在淋巴结或结外淋巴组织持续扩增
        ↓
正常结构被替代 / 破坏
        ↓
局部：进行性无痛性淋巴结或结外肿块
全身：发热、盗汗、消瘦、瘙痒
播散：邻近扩展、跳跃扩展、骨髓 / 肝 / 多个结外器官
        ↓
淋巴结活检确认组织类型
+ 免疫表型 / 染色体确认细胞身份
+ 分期确认范围
        ↓
组织类型决定生物学行为
分期决定治疗范围
```

## 1.2 四个维度必须同时看

| 维度 | 关键问题 |
|---|---|
| 部位 | 淋巴结还是结外？颈部、纵隔、胃肠、鼻腔、皮肤、骨髓？ |
| 结构 | 滤泡、弥漫、结节、硬化、炎细胞背景是否保留？ |
| 来源 | B、T、NK、前体、浆细胞，还是RS细胞相关？ |
| 行为 | 惰性、侵袭性、高度侵袭性；局限还是播散？ |

## 1.3 病例顺序

```text
进行性无痛性淋巴结 / 结外肿块
→ 查B症状与酒后痛
→ 淋巴结活检确诊
→ 形态 + 免疫表型 + 染色体定类型
→ 先看骨髓 / 肝 / 多结外器官，完成分期
→ 再按HL / NHL、细胞来源和侵袭性进入治疗
```

# 3｜共同入口：先确认淋巴瘤，再谈亚型

<!-- kianos:kp id="hematology-h11-kp01" -->
## KP01｜典型入口：进行性、无痛性淋巴结肿大；酒后痛是HL特殊线索

> **主提示：进展｜无痛｜颈/锁骨常｜酒后痛HL｜白血病别漏**

### Detailed Expansion

淋巴瘤的典型临床入口是进行性、无痛性淋巴结肿大。HL 少数患者可出现饮酒后淋巴结疼痛。

但无痛性淋巴结肿大也可见：

- ALL、CLL；
- AML有时；
- 其他非血液系统疾病。

所以它是“进入淋巴瘤优先框架”的信号，不是单点确诊。

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="hematology-h11-kp02" -->
## KP02｜确诊靠淋巴结活检；骨髓穿刺主要负责分期，不替代组织结构

> **主提示：确诊=结活检｜骨穿=分期｜一般血病骨穿｜溶贫查病因**

### Detailed Expansion

淋巴瘤病变起始于淋巴结或结外淋巴组织，诊断必须保留组织结构，因此确诊检查是淋巴结活检。

- 骨髓穿刺：用于判断骨髓是否受累、完成分期；
- 不能仅凭外周淋巴细胞增多或骨髓淋巴细胞增多取代淋巴结组织学。

当前 Lecture 的比较规律：多数血液病用骨髓穿刺；淋巴瘤是“淋巴结活检”的特殊项。

**Routing**：CORE｜BOUNDARY｜MI-G

---

<!-- kianos:kp id="hematology-h11-kp03" -->
## KP03｜贫血两条路：骨髓浸润使Ret↓；温抗体自免溶使Ret↑↑、Coombs+

> **主提示：浸髓→三系↓+Ret↓｜温抗体→Hb↓+Ret↑↑+Coombs｜Evans接口**

### Detailed Expansion

### 肿瘤浸润骨髓

```text
淋巴瘤细胞进入骨髓
→ 正常造血被压制
→ Ret↓、可全血细胞减少
```

### 合并温抗体自身免疫性溶血

```text
红细胞外周破坏
→ Hb↓
→ 骨髓代偿
→ Ret↑↑
→ Coombs阳性
```

若再合并 ITP，可形成 Evans 综合征并出现多系细胞减少。关键是必须看 Ret，不把“淋巴瘤 + 贫血”机械归为骨髓浸润。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

<!-- kianos:kp id="hematology-h11-kp04" -->
## KP04｜A / B组：B症状只认三件，瘙痒不在正式分组门槛

> **主提示：热>38｜盗汗｜6月体重↓>10%｜任1=B｜瘙痒≠门槛**

### Detailed Expansion

当前 Lecture：

- 不明原因发热 >38℃；
- 盗汗；
- 6个月内体重下降 >10%。

任意一项即 B 组；均无则 A 组。

瘙痒可见于 HL，尤其某些临床模式，但不属于当前 B 组正式三门槛。

**Routing**：CORE｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="hematology-h11-kp05" -->
## KP05｜分期先“倒着看”：骨髓 / 肝 / 弥漫结外先定IV，再看膈肌两侧

> **主提示：I一组｜II同膈≥2｜III跨膈±E/S｜IV骨髓/肝/多结外/远结｜脾韦氏=结**

### Detailed Expansion

| 分期 | 当前Lecture定义 |
|---|---|
| I | 1组淋巴结；局灶单个结外可记IE |
| II | 膈肌同侧≥2组淋巴结；可有IIE |
| III | 膈肌上下淋巴结；可有IIIE、IIIS或IIIE+S |
| IV | 骨髓或肝受累；一个结外器官多灶；多个结外器官；孤立结外伴远处非区域淋巴结等 |

特殊：脾和咽淋巴环 / Waldeyer环不算结外器官，分别视作一组淋巴组织。

病例算法：先找IV期证据，再判断是否跨膈，最后数同侧区域。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

<!-- kianos:kp id="hematology-h11-kp06" -->
## KP06｜HL vs NHL：先分别成立，再比较扩散、首发部位和白血病化

> **主提示：HL低发｜结首发颈｜邻近扩｜不白化｜预后较好；NHL高发｜1/3结外｜跳跃｜可白化**

### Detailed Expansion

| 轴 | HL | NHL |
|---|---|---|
| 发病率 | 低 | 高 |
| 首发 | 淋巴结，颈部最常见 | 约2/3淋巴结、1/3结外 |
| 扩散 | 由近及远、相邻区域 | 可跳跃 |
| 白血病转化 | 当前Source：无 | 当前Source：可 |
| 总体考试印象 | 预后相对好 | 预后相对差、异质性大 |

NHL结外部位当前 Source举例：胃肠以回肠、胸部以肺门 / 纵隔、骨骼以胸腰椎常见。

**Routing**：CORE｜CONFUSABLE｜BOUNDARY｜MI-G

# 4｜NHL：先看来源和生物学行为，再背亚型

<!-- kianos:kp id="hematology-h11-kp07" -->
## KP07｜NHL治疗共同入口：CHOP；CD20+加R；早期惰性加放疗；胃MALT加抗Hp

> **主提示：CHOP4｜CD20→R｜I/II惰性化+放｜胃MALT抗Hp**

### Detailed Expansion

当前 Lecture：

- NHL以化疗为主，常用 CHOP：环磷酰胺 + 阿霉素 / 多柔比星 + 长春新碱 + 泼尼松；
- CD20阳性加利妥昔单抗，形成R-CHOP；
- I、II期惰性淋巴瘤可化疗 + 放疗；
- 胃MALT还需抗Hp治疗。

治疗不是按“淋巴结大小”决定，而是受组织类型、CD20、侵袭性和分期共同影响。

**Routing**：CORE｜BOUNDARY｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h11-kp08" -->
## KP08｜弥漫大B：我国成人最常见；双表达 / 双打击预后差，可由滤泡性转化

> **主提示：中国成人最常｜myc+BCL2表达｜myc+BCL2/6异位｜预后差｜滤泡→p53失活**

### Detailed Expansion

当前 Source：

- DLBCL 是我国成人最常见 NHL；
- 双表达：MYC与BCL2高表达；
- 双打击：MYC与BCL2或BCL6异位；
- 两者均提示预后差；
- 滤泡性淋巴瘤可因 p53 失活转变为 DLBCL。

其形态为弥漫性大异型淋巴细胞，必须回原图理解“弥漫”与“滤泡结构消失”。

**Routing**：CORE｜RECOGNITION｜CONNECTION｜VISUAL_ONLY｜MI-G

<!-- kianos:kp id="hematology-h11-kp09" -->
## KP09｜滤泡性：生发中心B细胞、t(14;18) / BCL2高表达、惰性但可转侵袭

> **主提示：脾/髓/腹股沟｜单克隆｜14;18｜BCL2↑｜CD10/BCL6｜惰性→DLBCL**

### Detailed Expansion

- 多累及脾、骨髓、腹股沟淋巴结；
- 来源于生发中心B细胞，CD10、BCL6阳性；
- t(14;18)导致BCL2高表达；
- 反应性滤泡是多克隆，肿瘤滤泡是单克隆且BCL2高；
- 属惰性淋巴瘤，可反复复发并转为DLBCL。

（视觉门禁：正常滤泡、反应性滤泡和肿瘤性滤泡结构。）

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

<!-- kianos:kp id="hematology-h11-kp10" -->
## KP10｜小淋巴 / CLL：成熟小B细胞、假性增殖中心、CD5+23、五四门槛

> **主提示：欧美成人最常｜成熟小B｜假中心10/6−｜血B≥5｜髓淋≥40%｜5+23｜惰性**

### Detailed Expansion

当前 Source：

- 欧美成人最常见 NHL 类型；
- 以成熟小淋巴细胞为主；
- 幼淋巴细胞灶性成团形成假性“增殖中心”，不表达CD10、BCL6；
- 外周血B淋巴细胞 ≥5×10⁹/L；
- 骨髓淋巴细胞 ≥40%；
- B细胞标记CD19 / 20 / 79a，同时CD5、CD23阳性；
- 属惰性淋巴瘤。

（易混：CD5阳性还见套细胞；用CD23、CyclinD1 / BCL1和染色体继续分。）

**Routing**：CORE｜CONFUSABLE｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h11-kp11" -->
## KP11｜惰性—侵袭—高度侵袭：成熟度决定速度，但“慢”不等于良性

> **主提示：惰5｜高侵2｜套=惰中最侵｜全部恶性｜化疗敏感≠都可治愈**

### Detailed Expansion

当前 Lecture：

- 惰性：小淋巴、边缘区、滤泡性、淋巴浆细胞性、皮肤T；
- 高度侵袭性：Burkitt、淋巴母 / 前体；
- 其余侵袭性类型按当前具体亚型理解；
- 所有淋巴瘤均为恶性；
- 病理10版口径称套细胞淋巴瘤为“惰性淋巴瘤中侵袭性最强”。

分化成熟通常使病程较慢，但并不把肿瘤变成良性。

**Routing**：CORE｜BOUNDARY｜CONFUSABLE｜MI-G｜MI-D

## KP12｜淋巴母 / 前体：15岁以下高频；B型多以白血病，T型多以胸腺肿块

> **主提示：<15岁｜B-ALL儿童+白血病｜T-ALL青少年+胸腺｜CD34/TdT｜高侵**

### Detailed Expansion

前体 / 淋巴母细胞肿瘤可表现为白血病或淋巴瘤：

- B-ALL：儿童多见，常以白血病形式，WBC可升但当前Source提示一般不超过100×10⁹/L；
- T-ALL：青少年多见，常见胸腺 / 纵隔肿块；
- 免疫表型常见CD34、TdT；
- 属高度侵袭性。

主体急性白血病分类已在H9，本处只学习“骨髓 / 血液 vs 组织肿块”的表现接口。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

## KP13｜Burkitt的三型与EBV：地方性颌骨、散发性回盲部、免缺淋巴结 / 骨髓

> **主提示：EBV｜地方颌｜散发回盲｜免缺结/髓｜非洲儿童最常**

<!-- kianos:kp id="hematology-h11-kp14" -->
## KP14｜Burkitt形态与行为：小无裂细胞 + 满天星 + Ki67高，长得快所以对化疗敏感

> **主提示：小无裂｜空泡｜星空=巨噬｜预后差提示｜8;14｜Ki67高｜单化可愈**

### Detailed Expansion

- 肿瘤细胞为形态一致的小无裂细胞；
- 胞质内可见空泡；
- 反应性巨噬细胞散在其间形成“满天星 / 星空”现象；当前Source把该现象作为预后差提示，但强调不具特异性；
- t(8;14)涉及c-MYC；
