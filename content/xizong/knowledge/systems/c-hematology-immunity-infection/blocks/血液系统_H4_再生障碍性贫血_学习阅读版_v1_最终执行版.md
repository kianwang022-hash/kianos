# H4｜再生障碍性贫血
## 不是“贫血更严重”，而是骨髓工厂整体低增生，三系都交不出货

> **中心问题**：当骨髓造血整体衰竭时，怎样从三系减少、Ret低、骨髓低增生、巨核细胞显著减少和“多无肝脾肿大”证明这是生产失败；又怎样用中性粒细胞、血小板和Ret判断近期感染与出血风险并选择治疗层级？
>
> **文件性质**：血液系统第四个 canonical Block。H1提供 CBC—Ret—骨髓证据语言，H3提供贫血的 MCV × Ret入口；本 Block把“生成不足”推进到真正的全骨髓衰竭。
>
> **Primary Study**：`内科学讲义_AI阅读版.md` P187–189《再生障碍性贫血》。
>
> **Primary Outline**：内科 U074–U075，**8 + 5 = 13 / 13**。
>
> **Source boundary**：AA与MDS、白血病、PNH、脾亢的鉴别只建立当前病例分流所需接口；MDS与克隆性造血完整模型后置 H7，PNH完整模型后置 H5。当前 Source没有把“急性造血功能停滞”展开成独立疾病模型，只保留识别边界。

# 1｜总 Framework

<!-- kianos:framework id="hematology-h04-framework-main" -->

```text
骨髓工厂整体停摆
  ↓
三类故障入口
  ├─ 种子：造血干 / 祖细胞缺陷，CD34+细胞↓
  ├─ 土壤：造血微环境异常，造血组织↓、脂肪化
  └─ 虫子：免疫抑制造血，CD8+T细胞与负调控因子↑
  ↓
三系产量下降
  ├─ RBC↓ → 贫血，因寿命较长可较晚出现
  ├─ WBC / 中性粒细胞↓ → 感染
  └─ Plt↓ → 出血；下降明显且治疗后最难恢复
  ↓
外周证据
  ├─ Ret低
  ├─ 正细胞性贫血
  ├─ NAP↑
  └─ 多无肝脾肿大
  ↓
骨髓证据
  ├─ 多部位穿刺 ± 活检
  ├─ 增生低下、骨髓小粒空虚
  ├─ 三系↓，尤其巨核细胞
  ├─ 脂肪细胞 / 淋巴细胞↑
  └─ 胸骨偶有局灶增生活跃，但巨核细胞仍少
  ↓
严重度与治疗
  ├─ SAA：Ret、ANC、Plt三项中符合两项
  ├─ VSAA：ANC进一步下降
  ├─ Plt<20：当前Study要求立即输注血小板
  ├─ <40岁 + 无感染 + 合适供者 + 重型：HSCT首选
  ├─ 免疫抑制：当前Study用于全部AA
  └─ 促造血：雄激素偏非重型；生长因子偏重型
```

# 2｜KP Active Recall

<!-- kianos:kp id="hematology-h04-kp01" -->
## KP01｜AA核心身份：三系少、Ret低、骨髓低增生

> **主提示：三系3果｜Ret方向｜正细胞｜骨髓1本质｜肝脾？**

### 1｜三系减少不是三个独立病

```text
骨髓整体造血衰竭
→ RBC、粒系、巨核—血小板系均减少
→ 贫血 + 感染 + 出血
```

它与“只缺铁”“只破坏RBC”“只破坏Plt”不同。AA的核心是：

> **工厂整体产量下降，而不是单一成品被耗掉。**

### 2｜三条证据必须互相支持

- CBC：全血细胞减少；
- Ret：低，提示红系没有形成匹配的代偿；
- 骨髓：增生低下而非红系代偿增生；
- 贫血：当前 Study为正细胞性；
- 查体：多无肝脾肿大。

（易混：全血细胞减少只是范围信号，不等于AA；巨幼、MDS、白血病、PNH、脾亢等仍需骨髓、形态、溶血和器官证据分流。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP02｜病因：感染、化学、射线；化学因素再分剂量相关与无关

> **主提示：病因3类｜化学2组｜各举2｜停药后？｜//识别：急性造血停滞**

### 1｜三类病因

1. **病毒感染**：肝炎病毒、微小病毒B19等；
2. **化学因素**；
3. **长期接触射线**。

### 2｜化学因素的两种Study口径

| 类型 | 当前Study示例 | 与剂量关系 |
|---|---|---|
| 抗肿瘤药、苯 | 骨髓抑制 | 与剂量相关 |
| 氯霉素、磺胺 | 骨髓抑制 | 与剂量无关 |

当前 Study另写明：后者停药后再障不会继续发展。本文件保留该考试口径，不用外部资料静默改写。

### 3｜急性造血功能停滞只作边界识别

当前 Outline要求知道：急性造血功能停滞可发生于已有血液病患者。Lecture旁注给出的血象方向为：

```text
Hb↓ + Plt↓ + WBC↑
```

它不等同于AA的典型全血细胞减少，也不在本 Block扩成独立诊疗模型。

**Routing**：CORE｜RECOGNITION｜BOUNDARY｜MI-D

<!-- kianos:kp id="hematology-h04-kp03" -->
## KP03｜“种子—土壤—虫子”：AA三层发病机制

> **主提示：种子1标志｜土壤2变｜虫子2细胞+3因子｜最终共同结局**

### 1｜种子缺陷

- 造血干 / 祖细胞缺陷；
- 骨髓 **CD34⁺细胞减少**；
- 减少程度与病情相关。

### 2｜土壤不佳

- 造血微环境异常；
- 造血组织减少；
- 脂肪组织增加，形成骨髓脂肪化；
- Source还描述静脉窦壁水肿、出血、毛细血管坏死等组织改变。

### 3｜虫子出现

- 外周血及骨髓淋巴细胞比例增高；
- 以 **CD8⁺T细胞比例升高**为主，CD4 / CD8下降；
- Th1、γδT细胞比例可升高；
- 负调控因子 **IL-2、TNF、IFN-γ**增多；
- 髓系细胞凋亡亢进。

三层不是互斥病因，而是共同指向：

> **有效造血细胞减少 + 微环境不利 + 免疫抑制增强 → 骨髓低增生。**

（边界：完整T细胞免疫学后置 H12；这里只学AA所需最小免疫链。）

**Routing**：CORE｜CONNECTION｜MI-G｜MI-D

## KP04｜三系下降的时相：Plt最明显最难恢复，贫血可较晚出现

> **主提示：三系下降3后果｜哪一系最早/最重/最难恢复｜贫血时相｜寿命解释**

### 1｜三系后果

| 细胞系 | 下降后的主要表现 |
|---|---|
| RBC / Hb | 贫血 |
| WBC / 中性粒细胞 | 感染 |
| Plt | 出血 |

### 2｜为什么Plt最敏感

- 血小板来自巨核细胞胞质；
- 巨核细胞在骨髓中本来数量较少；
- 血小板寿命在三系成品中较短；
- 工厂停摆后，血小板下降最明显，并且治疗后最难恢复。

### 3｜为什么贫血可较晚

成熟RBC寿命较长。骨髓停止交货后，外周原有RBC仍可维持一段时间，因此当前 Study强调：

> 贫血常在较晚期出现。

**Routing**：CORE｜CONNECTION｜MI-G

## KP05｜外周血四线索：Ret低、正细胞、NAP高、淋巴比例高

> **主提示：Ret2阈｜正细胞｜NAP方向｜淋巴比例｜（易混：NAP低5类？）**

### 1｜Ret

- AA一般：`Ret <1%`；
- 重症方向：`Ret <0.5%`；
- 重型分层正式使用 **Ret绝对值**，见 KP09。

Ret低的意义是：

```text
贫血存在
+ 骨髓却没有加快交货
→ 生产不足
```

### 2｜贫血形态

当前 Study把AA归为：

> **正细胞性贫血**。

它是“造不出”，不是以“造大”或“造小”为主。

### 3｜NAP

- AA：NAP↑；
- NAP主要存在于成熟阶段中性粒细胞和巨噬细胞。

当前 Study要求直接识别 NAP↓ 的组合：

- 急粒；
- 慢粒；
- SLE；
- PNH；
- 病毒感染：正常或下降。

（易混：NAP不是血清ALP；前者是中性粒细胞碱性磷酸酶。）

### 4｜淋巴细胞比例

骨髓和外周血中淋巴细胞比例可升高，属于非造血细胞 / 免疫异常方向，不等于淋巴细胞绝对性恶性增殖。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G｜MI-D

## KP06｜“多无肝脾肿大”是高价值阴性体征

> **主提示：无肝脾3病｜AA为何不大｜有肝脾时转向4类｜阴性≠确诊**

### 1｜当前Study记忆组

```text
再障
+ ITP
+ 急性风湿热
→ 多无肝脾肿大
```

### 2｜AA为什么常不大

AA的主体是骨髓造血衰竭，不是：

- 肿瘤性浸润；
- 脾脏代偿性清除RBC；
- 脾亢性滞留；
- 明显髓外造血。

因此“没有肝脾肿大”能帮助把病例送向AA，但不能单独确诊。

### 3｜若存在明显肝脾肿大

优先重新检查：

- 溶血与脾清除；
- 脾亢；
- 白血病 / 淋巴瘤等浸润；
- 克隆性造血或其它系统疾病。

（特殊：Source提示ITP反复发作时可轻度脾大；该内容完整归H6。）

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP07｜确诊策略：多部位骨髓穿刺，或穿刺 + 活检；不能只靠单点或单独活检

> **主提示：确诊2方案｜为何多部位｜穿刺看什么｜活检看什么｜单独活检？**

### 1｜当前Study确诊入口

- 髂骨、胸骨等 **多部位骨髓穿刺**；
- 或 **骨髓穿刺 + 活检**。

不应选择：

> 单独骨髓活检作为唯一确诊依据。

### 2｜为什么强调多部位

AA多数部位低增生，但胸骨偶可存在局灶性增生活跃。只取一个部位可能低估或误判整体状态。

### 3｜穿刺与活检的分工

| 检查 | 主要观察 |
|---|---|
| 骨髓穿刺 | 细胞组成、比例、成熟和形态；像看“工人” |
| 骨髓活检 | 造血组织、脂肪化、结构和微环境；像看“工厂” |

H1已经建立该语言；H4把它应用到“多点低增生”的疾病证据。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP08｜骨髓象：低增生、巨核显著少、脂肪与淋巴多

> **主提示：增生方向｜三系｜巨核1句｜骨髓小粒｜脂肪/淋巴｜CD4/CD8｜胸骨特殊**

### 1｜主体改变

- 骨髓增生低下；
- 三系造血细胞减少；
- **巨核细胞减少最突出，可“全片未见巨核细胞”**；
- 骨髓小粒空虚。

### 2｜非造血成分

- 脂肪细胞增加；
- 淋巴细胞增加；
- CD8⁺T细胞比例升高，CD4 / CD8降低。

### 3｜胸骨的特殊

有时胸骨可见局灶性增生活跃，但：

> 巨核细胞仍减少。

所以“某一点活跃”不能推翻多部位整体衰竭。

### 4｜巨核细胞比较接口

- AA：巨核细胞数量显著减少 / 全片未见；
- ITP：数量正常或升高，但产板型显著减少；
- MDS：病态巨核细胞，如小巨核、核分叶异常。

后两者完整模型分别见 H6、H7。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

## KP09｜重型与极重型：三项取二，极重看ANC再降一级

> **主提示：SAA3数取2｜VSAA1数｜骨髓前提｜SAAⅠ/Ⅱ｜NSAA**

### 1｜重型再障 SAAⅠ型｜当前Study

骨髓广泛重度低下，并在以下三项中符合 **两项**：

| 指标 | 门槛 |
|---|---:|
| Ret绝对值 | `<15 ×10⁹/L` |
| 中性粒细胞 | `<0.5 ×10⁹/L` |
| Plt | `<20 ×10⁹/L` |

### 2｜极重型

若重型基础上：

```text
中性粒细胞 <0.2 ×10⁹/L
→ 极重型再障 VSAA
```

### 3｜非重型与SAAⅡ型

- NSAA：未达到SAAⅠ型标准；
- NSAA病情恶化并达到SAAⅠ型标准：当前 Study称 SAAⅡ型。

这里最重要的不是背标签，而是理解：

> ANC越低，感染风险越高；Plt越低，出血风险越高；Ret越低，红系恢复能力越差。

**Routing**：CORE｜RECOGNITION｜MI-G｜MI-D

## KP10｜AA鉴别入口：先问低增生、病态、破坏还是分布

> **主提示：AA vs MDS/白血/PNH/脾亢｜骨髓｜形态｜Ret｜溶血｜肝脾**

| 分支 | 第一判断轴 | 当前去向 |
|---|---|---|
| AA | 骨髓低增生、Ret低、巨核少、多无肝脾肿大 | 本 Block |
| MDS | 病态 / 无效造血、异常形态与克隆证据 | H7 |
| 白血病 | 原始细胞 / 克隆占位、浸润证据 | H9–H10 |
| PNH | 慢性血管内溶血、Hb尿、可三系少 | H5 |
| 脾亢 | 分布 / 滞留增加，常有脾大 | 后续比较接口 |

### 固定病例顺序

```text
三系少
→ Ret低还是高
→ 骨髓低增生还是病态 / 占位
→ 有无异常形态 / 原始细胞
→ 有无溶血证据
→ 有无肝脾肿大
```

（边界：本表只用于把病例送往正确 Block，不提前展开H7–H10完整疾病模型。）

**Routing**：CORE｜CONFUSABLE｜BOUNDARY｜MI-G

## KP11｜近期危险：感染和出血优先于“把Hb补到正常”

> **主提示：近期危险2｜ANC看什么｜Plt看什么｜Plt<20动作｜RBC何时**

### 1｜感染风险

中性粒细胞严重下降时，患者无法有效抵御感染。重型 / 极重型分层把 ANC列为核心指标，正是因为它直接决定近期危险。

### 2｜出血风险

血小板下降最明显、恢复最慢。当前 Study规定：

```text
Plt <20 ×10⁹/L
→ 立即输注血小板
```

### 3｜红细胞支持

必要时输红细胞。当前 Block不扩写输血全章，成分选择和输血反应 Recall H2。

> 支持治疗是在防止感染、出血和严重缺氧；它不等于修复骨髓病因。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

# 3｜高密度比较与病例算法

## 3.1 AA最小证据矩阵

| 层 | AA方向 | 不能单独替代什么 |
|---|---|---|
| CBC | 三系减少 | 不能单凭三系少确诊 |
| Ret | 低 | 不能说明骨髓组织结构 |
| MCV | 正细胞方向 | 不能排除其它正细胞贫血 |
| 查体 | 多无肝脾肿大 | 阴性体征不是确诊 |
| 骨髓穿刺 | 低增生、三系少、巨核显著少 | 单点可能漏局灶 |
| 骨髓活检 | 造血组织少、脂肪化 | 单独活检不是当前Study唯一确诊方案 |
| 严重度 | Ret / ANC / Plt | 不以Hb单项定义SAA |

## 3.2 病例固定起手式

```text
乏力 + 感染 + 出血
→ CBC是否三系少
→ Hb形态 + Ret
→ 肝脾 / 淋巴结
→ 多部位骨髓穿刺 ± 活检
→ 低增生还是病态 / 占位
→ 若AA，立刻看ANC、Plt、Ret绝对值
→ 先处理感染 / 出血风险
→ 再选HSCT / 免疫抑制 / 促造血
```
