# H23｜伤寒、细菌性痢疾与感染性肠溃疡
## 不先背“谁在哪”：先用组织结构推导炎症类型、溃疡方向与并发症

> **FIRST PASS 固定流程**  
> `Framework → 病理Lecture与原图 → Recall D12/D10/D11 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **中心问题**：同样出现发热和肠道病变，为什么伤寒形成急性单核—巨噬细胞增生与平行溃疡，菌痢形成假膜与浅地图状溃疡；又怎样把它们与肠结核、阿米巴、UC、CD、消化性溃疡和胃癌放进同一“部位—炎症—溃疡—并发症”坐标？
>

# 0｜总 Framework｜病原偏好哪种组织，就长出哪种溃疡

```text
病原 / 感染模型
→ 优先落在某段肠道与某种结构
→ 诱发特定组织反应
→ 形成特定溃疡方向和深度
→ 决定出血、穿孔、狭窄 / 梗阻风险
```

## 0.1 三个核心模型

### 伤寒

```text
全身单核—巨噬细胞系统增生
→ 回肠末端集合 / 孤立淋巴小结受累
→ 伤寒细胞聚集成伤寒小结
→ 圆形 / 椭圆形溃疡，长轴与肠长轴平行
→ 出血最常见，穿孔最严重
```

### 细菌性痢疾

```text
直肠、乙状结肠
→ 黏膜纤维素性炎 / 假膜
→ 表浅、不规则、地图状溃疡
→ 黏液脓血便、里急后重
```

### 中毒性痢疾

```text
特异体质儿童
→ 全身中毒反应重
→ 肠道局部病变反而轻
→ 卡他性 / 滤泡性炎
```

## 0.2 四轴比较

```text
部位｜炎症类型｜溃疡形态｜并发症
```

## KP01｜肠道感染四轴：部位—炎症—溃疡—并发症

> **主提示：4轴｜先结构后口诀｜哪轴决定梗阻｜哪轴决定出血/穿孔**

### Detailed Expansion

面对肠道病理病例：

1. **部位**：回盲部、回肠末端、直乙结肠、盲升结肠，还是胃 / 十二指肠；
2. **炎症**：肉芽肿、急性增生、假膜、变质、连续慢性炎；
3. **溃疡**：横 / 环、纵向平行、地图、烧瓶、连续浅、裂隙深或火山口；
4. **并发症**：出血、穿孔、瘢痕狭窄 / 梗阻。

结构关系比孤立口诀更稳定：淋巴管环形走向可形成横向溃疡；淋巴小结长轴排列则形成平行溃疡。

**Routing**：CORE｜CONNECTION｜MI-G

## KP02｜伤寒共同身份：急性病，却以单核—巨噬细胞增生为主

> **主提示：系统1｜器官4｜肠部位1｜炎症特殊1｜哪里不增生**

### Detailed Expansion

当前病理Study：伤寒引起全身单核—巨噬细胞系统增生，可见于肝、脾、骨髓、淋巴结等，肠道以回肠末端集合和孤立淋巴小结最突出。

伤寒是“急性增生性炎”的特殊例子。Study旁注提示胆囊可储存伤寒杆菌，但胆囊不属于本处增生主场。

**Routing**：CORE｜SPECIAL｜MI-G

## KP03｜伤寒小结：伤寒细胞吞3类东西，聚集成急性肉芽肿

> **主提示：伤寒细胞本质｜吞3类｜聚集结果｜与结核区别2轴**

### Detailed Expansion

伤寒细胞是巨噬细胞，胞质内可吞噬：

- 红细胞；
- 伤寒杆菌；
- 细胞碎片。

伤寒细胞聚集形成伤寒小结，当前Source称急性肉芽肿 / 急性增生性炎。

与结核比较：伤寒没有以干酪坏死和典型Langhans巨细胞为主的慢性结核结节模型；两者虽都可见巨噬细胞聚集，但炎症时相与形态身份不同。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

## KP04｜伤寒溃疡为什么与肠长轴平行

> **主提示：结构1｜形状2｜方向1｜梗阻方向｜对比肠结核**

### Detailed Expansion

伤寒累及回肠末端淋巴小结。淋巴小结呈圆形 / 椭圆形并沿肠长轴排列，所以溃疡也多为圆形 / 椭圆形，长轴与肠管长轴平行。

因其不形成环形瘢痕收缩，通常不以肠梗阻为主要结局。

（易混：肠结核沿黏膜淋巴管环形走向，故溃疡长轴与肠长轴垂直，容易狭窄梗阻。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP05｜伤寒四期与两大并发症：第三周溃疡期最危险

> **主提示：4期｜各约1周｜溃疡期第几周｜最常见/最严重**

### Detailed Expansion

当前Study补充肠伤寒四期：

```text
髓样肿胀期
→ 坏死期
→ 溃疡期
→ 愈合期
```

每期约1周，溃疡期常在起病第3周。

- 肠出血：最常见并发症；
- 肠穿孔：最严重并发症。

病灶累及淋巴小结并形成深溃疡，可进入富血管的黏膜下层，解释出血和穿孔风险。

**Routing**：CORE｜MI-G｜MI-D

## KP06｜伤寒的四个系统识别 + 蜡样变性

> **主提示：脾/皮肤/中性粒/Widal4｜蜡样变性本质｜肌3**

### Detailed Expansion

当前Source四个识别点：

- 脾大；
- 玫瑰疹；
- 中性粒细胞常减少；
- 肥达反应阳性。

伤寒还可出现横纹肌蜡样变性，本质为凝固性坏死，常累及膈肌、腹直肌、股内收肌。

这些是病理 / 考试识别，不扩展完整临床诊断价值。

## KP07｜菌痢入口：直肠 / 乙状结肠 + 黏液脓血便 + 里急后重

> **主提示：部位2｜症状2｜为什么里急后重｜炎症主型1**

### Detailed Expansion

细菌性痢疾好发直肠和乙状结肠。下段肠道特别是直肠受刺激，可出现：

- 黏液脓血便；
- 里急后重。

典型病理主线为黏膜纤维素性炎，形成假膜性炎。

**Routing**：CORE｜RECOGNITION｜MI-G

## KP08｜假膜性炎：纤维蛋白贴在黏膜表面，像多了一层膜

> **主提示：黏膜炎1型｜渗出物｜为什么叫假膜｜代表2病｜与卡他谁更重**

### Detailed Expansion

```text
黏膜血管通透性明显升高
→ 纤维素 / 纤维蛋白渗出
→ 覆盖并黏附在黏膜表面
→ 形成“假膜”
```

当前Study代表为细菌性痢疾和白喉。纤维素分子量大，提示局部血管损伤和通透性改变较卡他性浆液渗出更明显。

**Routing**：CORE｜CONNECTION｜MI-G

## KP09｜急性菌痢溃疡：表浅、不规则、地图状

> **主提示：深浅｜形态3｜穿孔/梗阻方向｜病程3步**

### Detailed Expansion

急性菌痢典型过程：

```text
急性卡他性炎
→ 假膜性炎
→ 溃疡形成并愈合
```

溃疡多为表浅、不规则、地图状，主要局限黏膜及浅层，通常不引起肠梗阻，穿孔也多不发生。

（易混：病理一般溃疡可深达肌层，但菌痢和UC是浅溃疡特殊例子。）

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

## KP10｜中毒性痢疾：全身重、肠道轻；局部是卡他 / 滤泡性炎

> **主提示：年龄｜体质｜全身/局部2方向｜炎症2型｜假膜？**

### Detailed Expansion

当前Study：中毒性痢疾多见2–7岁特异体质儿童，表现为全身中毒反应重而肠道局部病变轻。

局部可表现：

- 卡他性炎：黏膜浆液性炎；
- 滤泡性炎：淋巴滤泡增生。

它不是典型重度假膜 / 深溃疡模型。病例不能因为肠道症状不重就排除严重全身感染。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP13｜菌痢 vs UC：都可浅溃疡、累及直乙结肠，但疾病模型不同

> **主提示：菌痢 vs UC｜共同点｜病变范围｜溃疡/炎症特征｜疾病模型差别**

### Detailed Expansion

共同：

- 可累及直肠、乙状结肠；
- 可有黏液脓血便、里急后重；

- 菌痢：感染性、假膜性炎、表浅不规则地图状溃疡；
- UC：慢性免疫性炎症，连续弥漫性浅溃疡；完整严重度、并发症和治疗归D12。

## KP17｜病例反向算法：先部位，再炎症，再溃疡，最后并发症

> **主提示：4步｜4典型病例｜危急2｜回D12/D10/D11**

### Detailed Expansion

```text
发热 + 肠道症状 / 病理图
        ↓
1. 部位
   回盲｜回肠末｜直乙｜盲升｜胃十二指肠
        ↓
2. 炎症
   肉芽肿｜急性增生｜假膜｜变质｜慢性连续炎
        ↓
3. 溃疡
   横环｜纵向平行｜地图｜烧瓶｜连续浅｜裂隙深｜火山口
        ↓
4. 并发症
   出血｜穿孔｜狭窄梗阻
```

- 平行溃疡 + 回肠末 + 伤寒小结 → 伤寒；
- 直乙 + 假膜 + 地图浅溃疡 → 菌痢；
- 儿童全身重局部轻 → 中毒性痢疾；
- 环形溃疡 + 回盲 + 肉芽肿 → 肠结核，回D12。

# 4｜Memory Routing

## MI-G

- 伤寒是急性增生性炎；
