# H15｜风湿诊断语言与治疗角色
## 先认“临床综合征—器官组合—证据角色—治疗目标”，再认具体病名

> **中心问题**：风湿病常同时出现关节、皮肤、血液、肾、肺和神经表现；面对一个多系统病例，怎样先判断它属于炎症性、退变性、晶体性、感染相关还是弥漫性结缔组织病，再把抗体、补体、ESR / CRP和药物放回正确角色，而不是“见到一个抗体就认病、见到关节痛就只治疼”？
>
> **文件性质**：血液—免疫—感染系统第十五个 canonical Block，是 H16–H19 的诊断与治疗语言 Gate。H12 已建立抗体、免疫复合物与T细胞损伤最低语言；本 Block 只把这些语言转换成风湿病例的进入坐标，不提前复制 SLE、RA、干燥和血管炎完整模型。
>
> **Primary Study**：`内科学讲义_AI阅读版.md` 讲义顺序 P270–272《风湿系统总论》。
>
> **Primary Outline**：内科 U101 **12 / 12**。

```text
A｜临床入口
关节 / 肌肉 / 皮肤 / 黏膜 / 血管 / 腺体
+ 肾 / 肺 / 血液 / 神经等器官组合
        ↓

退变性骨关节病

        ↓
```

> **先从器官组合认出“哪类系统病”，再用特异抗体与活动指标校正；治疗时先分“只改善疼痛”还是“真正控制病程”。**

# 3｜KP Active Recall
    <!-- kianos:kp id="hematology-h15-kp01" -->
    ## KP01｜风湿病入口：关节病只是表面，系统组合才决定方向

    > **主提示：入口6类｜系统器官5组｜慢性为主｜自身免疫多数｜先综合征后抗体**

    ### 快速核对

风湿性疾病可累及：

```text
关节 / 软骨 / 滑膜 / 滑囊 / 肌肉 / 肌腱 / 韧带
+ 皮肤、血管、腺体、肺、肾、血液、神经等器官
```

当前 Study 强调：多数风湿病与自身免疫异常密切相关，且大多呈慢性过程。因此病例入口不应是“某个抗体阳性”，而应先问：

1. 主要症状是关节、肌肉、皮肤、腺体还是血管？
2. 是否同时存在肾、肺、血液或神经受累？
3. 是急性单关节，还是慢性对称多关节 / 脊柱中轴？
4. 证据提示炎症、退变、晶体沉积还是感染相关？

（易混：风湿病不等于“风湿热”，也不等于所有关节痛。）

    **Routing**：CORE｜CONNECTION｜MI-G

    <!-- kianos:kp id="hematology-h15-kp02" -->
    ## KP02｜风湿病五大高频分类：先把病放进正确抽屉

    > **主提示：结缔7｜脊柱5｜骨关节1类｜遗代内分泌2组｜感染3**

    ### 快速核对

| 分类 | 当前 Study 代表 |
|---|---|
| 弥漫性结缔组织病 | SLE、RA、炎症性肌病、干燥、系统性血管炎、SSc、重叠综合征 |
| 血清阴性脊柱关节病 | AS、银屑病关节炎、反应性关节炎、肠病性关节炎、未分化脊柱关节病 |
| 骨关节病 | OA / 退行性改变 |
| 遗传、代谢、内分泌相关 | Marfan / 免疫缺陷；痛风 / CPPD；淀粉样变、肢端肥大、甲减、甲旁亢等 |
| 感染相关 | 风湿热、Lyme病、Poncet综合征 |

### 使用方式

分类不是背目录，而是把病例送入不同逻辑：

- **结缔组织病**：多系统 + 自身抗体；
- **脊柱关节病**：RF阴性只是命名背景，主体看中轴 / 附着点和对应疾病；
- **OA**：退变逻辑；
- **痛风**：晶体沉积，急性单关节；
- **感染相关**：先找病原或感染背景。

    **Routing**：CORE｜RECOGNITION｜MI-G

    ---
    <!-- kianos:kp id="hematology-h15-kp03" -->
    ## KP03｜临床综合征优先：关节轴、系统轴、时间轴三步定位

    > **主提示：关节4问｜系统5问｜急慢2轴｜对称/侵蚀｜器官组合**

    ### 快速核对

```text
关节轴：中轴还是外周？单发还是多发？对称吗？侵蚀吗？
系统轴：皮肤黏膜、肾、肺、血液、神经、腺体、血管？
时间轴：急性突发、反复发作，还是慢性持续？
```

典型入口：

- 急性、夜间、单侧第一跖趾关节 → 痛风入口；
- 慢性、对称小关节、晨僵 → RA入口；
- 皮疹 + 血细胞减少 + 肾小球证据 → SLE入口；
- 口眼干 + 腮腺 / 肾小管证据 → 干燥入口；
- 缺血、出血、肾肺或周围神经组合 → 血管炎入口。

这些只是路由，不替代后续 Block 的完整诊断。

    **Routing**：CORE｜CONNECTION｜MI-G

    <!-- kianos:kp id="hematology-h15-kp04" -->
    ## KP04｜风湿证据四层：筛查、特异、活动、器官损害

    > **主提示：筛查2｜特异5组｜活动3类｜器官4层｜活检何时**

    ### 快速核对

| 层级 | 解决的问题 | 代表 |
|---|---|---|
| 广谱筛查 | 是否值得进入自身免疫方向 | ANA、RF等 |
| 疾病特异校正 | 哪个疾病模型最匹配 | dsDNA/Sm、CCP、SSA/SSB、ANCA等 |
| 活动度 | 现在是否活跃、是否消耗 | dsDNA、补体、ESR/CRP及疾病特异器官指标 |
| 器官损害 | 落在哪个器官、严重到什么程度 | CBC、尿沉渣/肾功能、影像、活检 |

### 关键边界

```text
抗体阳性
≠ 自动确诊

抗体阴性
≠ 对所有疾病都自动排除

活动指标升高
≠ 已经说明具体器官损害
```

病例必须把实验室结果放回临床综合征与器官证据中解释。

    **Routing**：CORE｜CONFUSABLE｜MI-G

    <!-- kianos:kp id="hematology-h15-kp05" -->
    ## KP05｜ANA与RF：广谱入口，不是疾病身份证

    > **主提示：ANA角色2｜RF角色2｜阳性不等于｜阴性边界｜后续特异抗体**

    ### 快速核对

- **ANA**：进入 SLE及其它结缔组织病的重要筛查入口；阳性并非 SLE独有；
- **RF**：RA常见，但也可见于干燥、SLE、SSc、感染和肿瘤；RF阴性也不能单独排除 RA；
- 真正进入具体疾病时，还需特异抗体与临床组合：
  - SLE：dsDNA、Sm及器官证据；
  - RA：CCP / ACPA；
  - 干燥：SSA / SSB + 腺体证据；
  - 血管炎：ANCA + 受累血管 / 活检。

（易混：RF名字里有“类风湿”，但它不是RA专属抗体。）

    **Routing**：CORE｜CONFUSABLE｜MI-G

    ---
    <!-- kianos:kp id="hematology-h15-kp06" -->
    ## KP06｜补体、ESR与CRP：反映活动，不代替病名和器官定位

    > **主提示：补体看消耗｜ESR/CRP看炎症｜谁不特异｜病名靠什么｜器官靠什么**

    ### 快速核对

- **ESR / CRP**：提示炎症活动，但不说明是哪一种风湿病；
- **补体下降**：可提示免疫复合物消耗等方向，在 SLE等疾病中有活动价值；
- **疾病活动**必须与特异抗体、临床表现和器官指标共同判断；
- **器官损害**仍靠尿沉渣、血细胞、影像、肺功能、活检等直接证据。

因此诊断链不是：

```text
ESR高 → 风湿病
```

而是：

```text
临床综合征
→ 特异证据校正
→ 活动度评估
→ 器官损害分层
```

    **Routing**：CORE｜BOUNDARY｜MI-G

    ## KP07｜风湿治疗四层：止痛、快速压炎、控制病程、靶向通路

    > **主提示：NSAID1役｜GC2役｜传统慢｜靶向/生物快｜谁控病程**

    ### 快速核对

```text
NSAIDs
→ 主要改善疼痛和炎症症状

糖皮质激素
→ 快速压制炎症；可作桥梁或危重器官控制

传统DMARDs
→ 起效慢，但可控制病情进展

靶向DMARDs / 生物DMARDs
→ 起效较快，干预特定免疫通路
```

最重要的治疗边界：

> **NSAIDs和糖皮质激素可以快速改善症状，但不能替代真正控制病程的DMARDs。**

具体疾病使用哪一种组合，后续 H16–H19分别学习。

    **Routing**：CORE｜CONFUSABLE｜MI-G

    ## KP08｜NSAIDs与COX-2选择性：改善疼痛，不控制病程

    > **主提示：作用1｜胃肠差异1｜代表2｜不能做什么｜禁忌回Source**

    ### 快速核对

- NSAIDs主要用于止痛和抗炎；
- 选择性 COX-2抑制剂可减少胃肠道不良反应；
- 当前 Study代表：**塞来昔布、美洛昔康**；
- 不能因为疼痛缓解就认为疾病进展已被控制；
- 完整禁忌证、心血管 / 肾脏风险与剂量不在本 Source 中系统展开。

//串联：RA中 NSAIDs通常与 DMARDs同服；痛风急性期可作为一线之一。

    **Routing**：CORE｜BOUNDARY｜MI-G｜MI-D

    <!-- kianos:kp id="hematology-h15-kp09" -->
    ## KP09｜糖皮质激素：快速控制炎症，但角色取决于疾病严重度

    > **主提示：快1｜桥梁1｜危重1｜不能单独长期替代谁｜器官受累**

    ### 快速核对

GC的共同角色是**快速压炎**：

- 可在慢起效 DMARDs生效前作桥梁；
- 器官危重或系统性血管炎等可需要更强的短期控制；
- 不应因为快速有效，就把它等同于所有疾病的长期唯一病程控制药。

后续差异：

- SLE危象 → 大剂量冲击接口；
- RA一般小剂量、短疗程桥梁，血管炎 / 重要器官受累可中到大量；
- 干燥无内脏损害不以GC为主体；
- 血管炎与贝赫切特内脏 / 眼炎可使用GC + 免疫抑制剂。

    **Routing**：CORE｜CONNECTION｜MI-G

    ## KP10｜DMARDs三层：传统慢，靶向与生物较快

    > **主提示：传统10类｜靶向3｜生物2｜速度2组｜代表配对**

    ### 快速核对

| 类别 | 当前 Study代表 | 起效 |
|---|---|---|
| 传统 DMARDs | MTX、柳氮磺吡啶、硫唑嘌呤、环磷酰胺、环孢素、MMF、羟氯喹、来氟米特、雷公藤、他克莫司 | 慢 |
| 靶向 DMARDs | 乌帕替尼、巴瑞替尼、托法替布 | 快 |
| 生物 DMARDs | 利妥昔单抗、阿巴西普 | 快 |

### 角色而不是清单

- 传统DMARDs是病程控制底座；
- 靶向 / 生物制剂在特定疾病和传统治疗不足时提供更定向控制；
- 本 Block只冻结类别与代表药，不扩剂量、筛查、感染预防或现代序贯方案。

    ## KP13｜痛风入口：急性、夜间、单侧第一跖趾；慢性看痛风石

    > **主提示：急3｜部位1｜慢性1｜急药3｜降尿酸2路**

    ### 快速核对

```text
急性起病
+ 午夜 / 清晨突然剧痛
+ 单侧第一跖趾关节最常见
→ 痛风入口
```

慢性期特征：**痛风石**，可见于耳廓、关节周围、鹰嘴、跟腱、髌骨滑囊等。

- 急性期：秋水仙碱、NSAIDs、糖皮质激素；
- 慢性降尿酸：抑制合成（别嘌呤醇、非布司他）或促进排泄（苯溴马隆）。
