# H6｜出血性疾病
## 先定位“哪一层止不住”，再进入 ITP；不能看到紫癜、Plt低或 APTT 延长就直接报病名

> **Primary Study**：`内科学讲义_AI阅读版.md` P197–202《出血性疾病》。

# 2｜KP Active Recall

<!-- kianos:kp id="hematology-h06-kp01" -->
## KP01｜ITP 核心身份：免疫既加速破坏，也压低生成

> **主提示：2免疫路｜破坏+生成｜3标志｜最终1结果**

### 1｜不是单纯“脾把血小板吃掉”

当前 Study把 ITP 的发病机制放在两条免疫路：

- **细胞免疫**：以 **CD8⁺ T细胞**异常为主；
- **体液免疫**：血小板相关抗体 **PAIg（IgG）**、血小板相关补体 **PAC3**；部分患者还可见抗心磷脂抗体、抗核抗体。

共同结果：

```text
外周血小板破坏增加
+
巨核细胞 / 产板过程受影响，血小板生成减少
→ Plt显著下降
→ 皮肤黏膜出血
```

（易混：ITP不是“巨核细胞完全消失”；骨髓仍可代偿性维持正常或略增，但成熟和产板失败。）

//串联：抗体攻击RBC→温抗体自免溶；攻击Plt→ITP；二者并存→Evans。

**Routing**：CORE｜CONNECTION｜CONFUSABLE｜MI-G

## KP02｜ITP 临床画像：育龄女性、浅表黏膜出血、多无肝脾大

> **主提示：人群2｜出血6｜肝脾？｜Hb2型｜WBC？**

### 1｜人群与起病

- 育龄期女性多见；
- 起病较隐匿。

### 2｜出血模式

血小板数量显著减少后，以皮肤黏膜出血为主：

- 出血点 / 瘀点；
- 紫癜；
- 瘀斑；
- 鼻出血；
- 牙龈出血；
- 月经过多。

### 3｜肝脾与三系边界

- **多无肝脾肿大**；反复发作可有轻度脾大；
- WBC多正常；
- 慢性失血可并发缺铁，故Hb可呈小细胞低色素；也可表现为正细胞性贫血。

（易混：孤立Plt减少更支持ITP；全血细胞减少要回H4 / H7等骨髓整体故障。没有脾大不能单独确诊ITP，但明显肝脾大应迫使你重新审查诊断。）

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h06-kp03" -->
## KP03｜骨髓：巨核数量不低，问题在成熟与产板

> **主提示：最重要检查｜数量方向｜成熟4变｜产板型｜AA/MDS/ITP**

### 1｜最重要检查

当前 Study将 **骨髓穿刺**列为 ITP最重要的检查。

### 2｜巨核细胞四组变化

- 数量：正常或增多；
- 体积：偏小；
- 胞质颗粒：减少；
- 幼稚 / 颗粒型巨核细胞：增多；
- 成熟的产板型巨核细胞：**显著减少**。

核心解释：

```text
外周Plt被破坏
→ 骨髓试图代偿
→ 巨核数量可正常或↑

但免疫过程又影响巨核成熟 / 产板
→ 产板型巨核细胞显著↓
```

### 3｜三病巨核细胞比较

| 疾病 | 巨核细胞核心方向 |
|---|---|
| ITP | 数量正常或↑；成熟障碍；产板型显著↓ |
| 再障 | 巨核细胞显著↓，可“全片未见” |
| MDS | 病态造血：小巨核、核少分叶或多核等 |

MDS完整模型后置 H7。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

## KP04｜外周血与止血试验：数量坏、体积大、功能正常；凝血时间正常

> **主提示：Plt3特征｜WBC｜Hb2型｜BT/CRT/回缩｜4凝血时间**

### 1｜血细胞层

- Plt数量：显著减少；
- 平均血小板体积：偏大；
- 血小板功能：当前 Study写为正常；
- WBC：多正常；
- 血细胞形态：无明显异常；
- Hb：可正细胞性；慢性失血合并缺铁时可小细胞低色素。

（易混：尿毒症的经典入口是血小板**功能**异常，而ITP主体是数量显著减少。）

### 2｜一期止血层

- BT延长；
- CRT阳性；
- 血凝块收缩不良。

### 3｜凝血层

- TT正常；
- PT正常；
- CT正常；
- APTT正常。

原因是 ITP主体不在凝血因子级联，而在血小板数量。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP05｜Evans：ITP + 温抗体自免溶，不能只按“Plt低”处理

> **主提示：2病合并｜3溶血证据｜RBC+Plt｜WBC边界｜脾大？**

Evans综合征是：

```text
温抗体自身免疫性溶血性贫血
+
ITP
```

因此病例除Plt减少和皮肤黏膜出血外，还应寻找H5的溶血证据：

- Coombs试验阳性；
- UCB升高；
- Ret明显升高；
- 可伴贫血、黄疸和脾大方向。

（易混：RBC↓ + Plt↓、WBC正常时不能只在“再障vsITP”二选一；先看Ret、UCB、Coombs和骨髓。当前 Lecture旁注提示严重时粒系也可能受影响，因此“必须只有两系减少”不能当硬门槛。）

**Routing**：CORE｜CONNECTION｜CONFUSABLE｜MI-G

## KP06｜ITP 急症：看活动性出血与危险场景，不只看一个Plt数值

> **主提示：4急症入口｜Plt<10还缺什么｜2颅内警报｜手术/分娩**

当前 Study列出的急症入口：

1. 重症 ITP：**Plt＜10×10⁹/L 且伴活动性出血**；
2. 出血评分 ≥5分；
3. 颅内出血风险 / 表现；
4. 近期将实施手术或分娩。

颅内危险的题干提示包括：

- 口腔黏膜血疱；
- 视物模糊。

核心边界：

> Plt极低是危险信号，但急症判断仍要结合活动性出血、危险部位和近期侵入性事件。

**Routing**：CORE｜RECOGNITION｜MI-G

## KP07｜ITP 急症治疗：先补血小板，再快速压免疫 / 促生成

> **主提示：首选1｜激素/丙球｜促板3类｜长春？｜切脾｜慢药边界**

### 1｜当前 Study列出的急症手段

- **输注血小板：首选**；
- 大剂量糖皮质激素；
- 丙种免疫球蛋白；
- 促血小板生成药：rhTPO、艾 / 海曲泊帕、罗米 / 普司亭；
- 长春类药物；
- 切脾。

### 2｜角色分层

```text
输Plt
→ 直接补充当前止血所需成品

大剂量GC / IVIG
→ 快速降低免疫性破坏

TPO通路
→ 推动生成

切脾
→ 处理破坏与免疫场所接口
```

免疫抑制剂起效慢，当前 Study明确 **不单独用于急症**。

## KP08｜ITP 一线：GC首选；出血可先于Plt改善，6–8周内停

> **主提示：一线首选｜4机制｜先改善什么｜6–8周｜复发｜妊娠1药**

### 1｜糖皮质激素的四个作用方向

- 抑制单核—巨噬细胞系统对血小板的破坏（主要）；
- 减少自身抗体生成；
- 改善毛细血管通透性；
- 刺激骨髓造血及血小板向外周释放。

### 2｜时间与疗程

- 出血症状可在Plt明显上升前先改善；
- 起效后尽快减量；
- 当前 Study要求 **6–8周内停用**；
- 停药后易复发，但复发时再次使用仍可有效。

### 3｜妊娠入口

当前 Study写：妊娠合并ITP可用 **丙种免疫球蛋白**，不适合激素。保留该考试口径，不扩写完整产科管理。

（易混：ITP的GC疗程不能套用肾病综合征“足量—缓减—长期维持”的路径。）

**Routing**：CORE｜CONFUSABLE｜MI-G｜MI-D

## KP10｜出血性疾病七层分类：先定位故障层，再找病名

> **主提示：血管｜Plt数量4因｜Plt质量4例｜凝血4例｜抗凝｜纤溶｜复合2病**

### 1｜血管壁异常

代表：过敏性紫癜 / IgA相关血管炎接口，常见四肢对称紫癜。

### 2｜血小板数量减少

按机制分：

- 生成减少：再障、白血病；
- 破坏过多：ITP；
- 消耗过度：DIC；
- 分布异常：脾亢。

### 3｜血小板质量异常

- 血小板无力症：GPⅡb / Ⅲa缺陷；
- 巨大血小板综合征：GPⅠb缺陷；
- 尿毒症；
- 感染。

### 4｜凝血异常

- 血友病：遗传缺乏因子Ⅷ / Ⅸ / Ⅺ；
- 肝硬化：凝血因子合成减少；
- 尿毒症；
- 维生素K缺乏。

### 5–7｜其余层

- 抗凝异常；
- 纤溶异常；
- 复合性异常：DIC、vWD。

（易混：DIC不能只塞进“凝血因子少”；它同时消耗Plt和凝血因子，并继发纤溶。vWD同时牵涉Plt黏附与FⅧ稳定。）

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G

## KP11｜出血形态定位：浅表、深部、延迟

> **主提示：血管1型｜Plt5处｜凝血5深｜男女倾向｜延迟→哪层**

| 故障层 | 当前 Study的典型出血模式 |
|---|---|
| 血管性 | 女性较多；以紫癜为主 |
| 血小板性 | 紫癜、瘀斑、眼底出血、月经过多、内脏出血；总体偏浅表 / 黏膜 |
| 凝血障碍性 | 男性 / 遗传倾向；外伤或手术后渗血不止、脐带出血、肌肉血肿、关节出血、深部内脏出血 |
| 纤溶异常 | 创伤或手术后**延迟性**出血 |

病例起手：

```text
牙龈 / 鼻 / 月经 / 紫癜
→ 先看Plt与血管

膝关节积血 / 肌肉血肿
→ 先看凝血因子与APTT / PT

手术当时止住，过后再出
→ 想纤溶
```

（边界：牙龈出血是黏膜出血，不属于深部凝血障碍的典型入口。）

**Routing**：CORE｜RECOGNITION｜MI-G

## KP15｜3P、FDP、D-二聚体：都指向纤溶，但回答的问题不同

> **主提示：FDP做什么｜3P原理3步｜D-D是什么｜阳性只说明哪层｜//串联：PE**

### 1｜FDP

纤维蛋白 / 纤维蛋白原被纤溶酶降解后产生FDP。当前 Study强调FDP还可与纤维蛋白单体结合，阻止其聚合，因而有抗凝方向。

### 2｜3P试验

```text
FDP + 纤维蛋白单体
→ 形成可溶复合物
→ 加鱼精蛋白后，FDP更偏向与鱼精蛋白结合
→ 纤维蛋白单体被释放并自行聚合
→ 出现絮状 / 胶冻状沉淀
```

因此3P阳性提示FDP较多、纤溶亢进方向。

### 3｜D-二聚体

当前 Study将其作为最简单的纤维蛋白降解产物之一，强调“有纤溶就会出现”，因此敏感，但不能独立给出病因。

//串联：PE中D-二聚体用于排除接口已在呼吸 R9学习；H6只保留其“纤溶标记物”身份。

## KP16｜DIC 最低运行模型：边凝边耗边溶，所以可同时血栓与出血

## KP18｜最终病例算法：先看出血形态，再用Plt—PT—APTT—TT定位

> **主提示：形态3分｜Plt｜PT/APTT/TT｜骨髓｜溶血｜急症｜5个反例**

```text
出血患者
→ 浅表黏膜还是深部 / 关节 / 肌肉，是否延迟
→ CBC / Plt
→ BT / CRT / 血块回缩
→ PT / APTT / TT / Fbg
→ 必要时FDP / D-D / 3P、抗凝面板
→ 若孤立Plt显著低：骨髓巨核细胞与成熟 / 产板
→ 若RBC也低：Ret / UCB / Coombs排Evans
→ 若多系低：回H4 / H7
→ 若活动性重度出血：先判断急症并即时止血
→ 再进入疾病特异治疗
```

### 五个不能机械跳结论的点

1. 紫癜 ≠ 一定ITP，也可血管壁异常、其它Plt病；
2. Plt低 ≠ 一定ITP，也可生成少、消耗、分布异常；
3. APTT延长 ≠ 一定血友病，也可vWD或共同途径异常；
4. PT / APTT正常 ≠ 没有出血病，ITP可完全正常；
5. 多无脾大 ≠ ITP专属，再障等也可无肝脾肿大。
