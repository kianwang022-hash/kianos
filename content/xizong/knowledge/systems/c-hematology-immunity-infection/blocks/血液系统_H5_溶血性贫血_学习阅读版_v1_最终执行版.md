# 2｜KP Active Recall

<!-- kianos:kp id="hematology-h05-kp01" -->
## KP01｜溶血总入口：贫血、黄疸 / 尿深、脾常大

> **主提示：3大表现｜哪项不恒有｜急性加什么｜原位为何可无脾大**

当前 Study把溶血最重要的临床入口压成：

- 贫血；
- 黄疸 / 尿色深；
- 脾脏常增大。

但“脾大”不是所有溶血的必要条件：

- 血管外溶血多在脾，常有脾大；
- 急性血管内溶血更突出 Hb尿、腰痛和AKI，脾可不大；
- 原位溶血发生在骨髓内，可有黄疸但不以脾大为主。

因此病例不能用“没有脾大”直接排除溶血。

### 溶血诊断必须有两类证据

```text
RBC破坏增加
+
骨髓红系代偿
```

Ret高只能证明骨髓在回应；黄疸也可能来自肝胆疾病。必须把两类证据拼在一起。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP02｜病因第一分层：RBC自身异常 vs RBC外部异常

> **主提示：内因3类｜各2例｜PNH特殊2件｜外因4类｜各举2–3**

### 1｜红细胞自身异常

#### 膜

- 遗传性球形红细胞增多症；
- 遗传性椭圆形红细胞增多症；
- PNH：膜锚链蛋白异常，但属于**获得性**。

#### 酶

- 丙酮酸激酶缺乏症；
- G6PD缺乏症。

#### 珠蛋白

- 结构异常：镰刀形细胞贫血，HbS点突变，缬氨酸取代谷氨酸；
- 数量异常：珠蛋白生成障碍性贫血 / 地中海贫血 / 海洋性贫血。

总体规律：

> RBC自身异常多为遗传性；PNH是“自身膜异常但后天获得”的重要特殊。

### 2｜红细胞外部异常

| 类型 | 当前Study例子 |
|---|---|
| 免疫 | 自免溶、SLE、病毒、药物；血型不合输血、新生儿溶血 |
| 血管 / 机械 | TTP/HUS、DIC、败血症；钙化AS、人工瓣；行军性Hb尿 |
| 生物 | 蛇毒、疟疾、黑热病 |
| 理化 | 大面积烧伤、亚硝酸盐等中毒 |

（边界：这些疾病在H5只承担“外部攻击RBC”的角色；完整TTP/HUS、DIC、感染和烧伤模型仍归各自系统。）

**Routing**：CORE｜RECOGNITION｜BOUNDARY｜MI-G｜MI-D

## KP03｜三种破坏位置：血管外、血管内、骨髓内原位

> **主提示：90%在哪｜血管外3表现｜血管内急4+慢2｜原位3病｜切脾边界**

### 1｜血管外溶血

- 更常见；
- 主要在脾，也可在其它单核—巨噬细胞系统；
- 多数起病慢；
- 贫血、黄疸、尿深、脾大；
- 多数可从切脾中获益，但需看具体病因。

当前 Study常见例子：

- 遗传球；
- 地贫；
- 温抗体型自免溶；
- 丙酮酸激酶缺乏症。

### 2｜血管内溶血

RBC在循环内破裂，释放游离Hb。

#### 急性方向

- 寒战、发热；
- 腰痛；
- Hb尿：酱油 / 浓茶 / 红葡萄酒色；
- AKI。

#### 慢性方向

当前 Study以PNH为代表：

- 可有脾大；
- 可有含铁血黄素尿。

常见例子：

- 冷抗体型自免溶；
- 蚕豆病；
- PNH；
- 血型不合输血；
- 输低渗液。

### 3｜原位溶血

骨髓内无效红系生成，是一种特殊血管外破坏。

当前 Study组：

- β-地中海贫血；
- 巨幼细胞性贫血；
- MDS。

### 4｜可同时发生两种位置

- 镰刀形细胞贫血；
- G6PD缺乏症。

（易混：血涂片见破碎RBC只能证明破坏，不能仅凭破碎形态判断血管内还是血管外。）

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

<!-- kianos:kp id="hematology-h05-kp04" -->
## KP04｜骨髓代偿：Ret、粒红比与有核RBC是一组

> **主提示：Ret正常/溶血2范围｜粒红比方向｜外周3形态｜PNH特殊**

### 1｜Ret

- 正常：0.5%–1.5%；
- 溶血代偿可达 **5%–20%**。

Ret明显升高说明骨髓红系正在加速交货，但不能单独证明病因就是溶血；急性失血同样可使Ret升高。

### 2｜粒红比

红系增生明显时：

```text
红系分母增大
→ 粒红比降低
→ 可出现倒置
```

### 3｜外周血形态

可见：

- 中、晚幼有核RBC；
- Howell–Jolly小体；
- Cabot环。

它们是“红系交货加速 / 成熟压力”的线索。

### 4｜PNH特殊

PNH是慢性溶血，Ret增高有时不明显。不能因Ret没有显著升高就机械排除。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

## KP05｜破坏证据：触珠蛋白、游离Hb、Hb尿、Rous与RBC寿命

> **主提示：敏感1｜游离Hb方向｜尿2种｜Rous何时｜最可靠1｜碎片能定位？**

### 1｜触珠蛋白 / 结合珠蛋白

- 明显下降；
- 当前 Study称其为反映溶血的敏感指标。

血管内、外溶血均可下降，但程度可不同；不能把它机械当成“只属于血管内”。

### 2｜血浆游离Hb

血管内溶血时明显升高。游离Hb超过结合能力后可被肾小球滤过。

### 3｜两种尿

#### Hb尿

- 尿隐血试验阳性；
- 尿沉渣镜检无相应RBC；
- 见于血管内溶血。

#### 含铁血黄素尿

- Rous试验阳性；
- 当前 Study强调慢性血管内溶血 / PNH。

### 4｜最可靠指标

> 红细胞寿命缩短最可靠，但临床较少使用。

### 5｜破碎RBC

见破碎和畸形RBC说明RBC受损，但：

> 对鉴别血管内和血管外溶血没有决定性帮助。

### 6｜Hb尿 vs 血尿

```text
尿隐血(+)
→ 看尿沉渣
   ├─ RBC >3个/HP：血尿
   └─ 无相应RBC：Hb尿方向
```

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP06｜溶血性黄疸：UCB升，尿胆原升，尿胆红素阴性

> **主提示：UCB｜CB/TB阈｜胆素原｜尿胆红素｜尿粪颜色｜为何不痒**

### 1｜当前Study方向

```text
血UCB↑
CB / TB <0.2
尿胆原↑
尿胆红素试验(-)
尿色深、粪色深
```

### 2｜为什么尿胆红素阴性

- UCB / 未结合 / 游离 / 间接胆红素为脂溶性；
- 不经尿液直接排出；
- 肝脏仍能把增加的UCB处理后经胆道入肠；
- 肠道胆素原增加，尿胆原和粪胆素方向增加。

所以：

> “尿深”不等于“尿胆红素阳性”。

### 3｜为什么可有黄疸但通常不痒

当前 Study把皮肤巩膜黄染归于UCB增加，而瘙痒更多与胆汁淤积 / CB相关；H5只保留这一鉴别方向。

### 4｜前序生化Recall边界

完整血红素—胆绿素—UCB—CB—胆素原代谢归M10。H5只应用到“溶血性黄疸”的方向判断。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP07｜遗传球：表面积 / 体积小，挤不过脾窦，渗透脆性高

> **主提示：家族｜膜形1｜变形/脆性/ESR｜血管外｜胆石｜切脾年龄+风险**

### 1｜形态与脾清除

球形RBC失去正常双凹圆盘的表面积 / 体积优势：

```text
可塑变形性↓
→ 不易通过脾窦狭窄裂隙
→ 在脾滞留、破坏
→ 血管外溶血
```

### 2｜常见线索

- 家族史；
- 球形细胞增多；
- 渗透脆性升高；
- 胆囊结石；
- 当前 Study归为小细胞高色素方向。

### 3｜渗透脆性

当前 Study例：

- 正常RBC约在0.44% NaCl开始破裂；
- 遗传球约在0.62% NaCl开始破裂。

更高浓度就破裂，说明对低渗环境耐受更差，渗透脆性升高。

### 4｜治疗

- 首选切脾；
- 当前 Study建议年满6岁后，以降低肺炎链球菌所致脾切除后凶险性感染 OPSI风险。

### 5｜球形RBC不是遗传球专属

还可见于：

- 温抗体型自身免疫性溶血。

### 6｜SOURCE_CONFLICT H5-SC01

当前内科 P192写“遗传球血沉↓”；但H1已登记生理P91同页存在“↓”与“不变”两种方向。H5不冻结唯一ESR答案：

> **回原生理页与正式答案源定点核对。**

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G｜MI-D

## KP08｜G6PD缺乏：PPP断了NADPH，GSH守不住膜

> **主提示：通路1｜关键酶｜NADPH→GSH→膜｜触发2｜内/外｜确诊1+辅助1**

### 1｜前序生化链

```text
磷酸戊糖途径
→ G6PD
→ NADPH
→ 维持GSH还原状态
→ GSH保护RBC膜免受氧化损伤
```

G6PD缺乏后：

```text
NADPH↓
→ 还原型GSH不足
→ RBC膜不稳定
→ 氧化应激下破裂
→ 溶血
```

### 2｜触发

当前 Study列出：

- 吃蚕豆；
- 服药后等。

“蚕豆病”是G6PD缺乏症的一种触发型表现，不等于全部G6PD缺乏。

### 3｜位置

G6PD缺乏可血管内、也可血管外溶血；蚕豆病在当前 Study归血管内溶血。

### 4｜检查

- G6PD活性测定：确诊；
- 高铁血红蛋白还原试验 MHbRT：常用检查。

（边界：全部氧化药物名单和遗传学不在当前Source完整展开。）

**Routing**：CORE｜CONNECTION｜CONFUSABLE｜MI-G

## KP09｜地贫：珠蛋白“数量”异常，小细胞低色素但铁不是主断点

> **主提示：遗传｜数量异常｜小低色｜靶形｜脆性方向｜2检查｜根治1**

### 1｜身份

珠蛋白生成障碍性贫血 / 地中海贫血 / 海洋性贫血：

> 珠蛋白链数量异常。

与镰刀形贫血的“珠蛋白结构异常”分开。

### 2｜当前Study线索

- 家族史；
- 小细胞低色素；
- MCHC `<32%`；
- 靶形RBC；
- 渗透脆性下降；
- 异丙醇试验；
- Hb电泳 HbEP。

靶形RBC表面积 / 体积相对增大，对低渗液耐受增加，所以渗透脆性下降；与遗传球相反。

### 3｜溶血位置

- α地贫：当前 Study强调脾脏方向；
- β地贫：可有骨髓内原位溶血。

### 4｜治疗

当前 Study写：

> 异基因HSCT可根治。

完整分型、输血与铁负荷方案不在本Block扩写。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G｜MI-D

## KP10｜温抗体 vs 冷抗体：温柔打补丁，冷酷直接破坏

> **主提示：IgG/IgM｜37/0–5℃｜内/外｜确诊各1｜球形谁有｜治疗各2｜全血少谁？**

| 轴 | 温抗体型自免溶 | 冷抗体型自免溶 |
|---|---|---|
| 常见度 | 多见 | 较少 |
| 抗体 | IgG | IgM |
| 活跃温度 | 37℃ | 0–5℃ |
| 抗体性质｜当前Study | 不完全抗体 | 完全抗体 |
| 主要溶血位置 | 血管外 | 血管内 |
| 诊断 | Coombs / 抗人球蛋白试验 | 冷凝集素试验 |
| 涂片 | 可有球形RBC | 不以球形为主提示 |
| 治疗 | GC首选；利妥昔单抗；切脾 | 保暖；利妥昔单抗 |


## KP12｜PNH临床：晨起酱油尿 + 缺铁 + 骨髓衰竭 + 异常血栓

## KP16｜最终病例算法：先证实溶血，再定位，再做针对性检查

> **主提示：证实2组｜定位3｜内/外因｜形态｜靶向检查｜5个反例**

```text
Hb下降
→ Ret是否升高 / 是否匹配
→ 有无UCB↑、触珠蛋白↓、RBC寿命缩短
→ 有无血浆游离Hb↑、Hb尿、Rous(+)
→ 有无脾大 / 胆石 / 慢性经过
→ 血管内、血管外或原位
→ RBC自身异常还是外部攻击
→ 膜 / 酶 / 珠蛋白 / 免疫 / 微血管
→ 选择渗透脆性、酶活性、HbEP、Coombs、FLAER等
```

### 五个不能机械跳结论的点

1. Ret高 ≠ 一定溶血，也可急性失血；
2. 黄疸 ≠ 一定溶血，也可肝胆疾病；
3. 尿深 ≠ 一定Hb尿，也可尿胆素增加；
4. 破碎RBC ≠ 能定位血管内 / 外；
5. 球形RBC ≠ 只见于遗传球，也见温抗体自免溶。
