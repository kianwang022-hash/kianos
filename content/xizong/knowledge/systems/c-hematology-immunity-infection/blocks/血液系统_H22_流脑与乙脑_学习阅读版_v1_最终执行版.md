# H22｜流脑与乙脑
## 先判“脑膜还是脑实质”，再认化脓性渗出或神经元变质

> **FIRST PASS 固定流程**  
> `Framework → 病理Lecture与原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **中心问题**：两种中枢感染都可出现发热和神经系统表现，为什么流脑主要是脑膜 / 蛛网膜下腔化脓，而乙脑主要是脑实质神经元损伤；这种空间差异又怎样决定病理图和症状侧重？
>
> **Source boundary**：当前 Source支持病原、传播、季节、病变部位、炎症类型与经典病理；不支持完整神经内科诊断、脑脊液算法、抗感染方案、重症监护和预后管理。

# 0｜第一轮主链

```text
中枢感染
→ 先判主要病变空间

流脑
脑膜炎双球菌
→ 软脑膜 / 软脊膜
→ 蛛网膜下腔中性粒细胞性脓性渗出
→ 脑膜刺激征、脑神经麻痹更突出
→ 暴发型可局部轻、全身出血与循环衰竭重

乙脑
乙脑病毒
→ 大脑皮质、基底核、视丘等脑实质
→ 神经元变性坏死 + 液化性软化
→ 筛状软化灶、淋巴细胞套、胶质细胞反应
→ 颅内高压更突出
```

# 1｜Framework｜用“层次—炎症—细胞—危险”四轴比较

| 轴 | 流脑 | 乙脑 |
|---|---|---|
| 病原 | 脑膜炎双球菌 | 乙脑病毒 |
| 季节 / 传播 | 冬春；飞沫呼吸道 | 夏秋；蚊媒 |
| 主要空间 | 软脑膜、软脊膜 / 蛛网膜下腔 | 脑实质：皮质、基底核、视丘等 |
| 炎症类型 | 化脓性炎 | 变质性炎 |
| 主要细胞 / 变化 | 中性粒细胞脓性渗出 | 神经元损伤、淋巴细胞套、胶质细胞反应 |
| 症状侧重 | 脑膜刺激征、脑神经麻痹 | 颅内高压更重 |
| 危险特殊 | 暴发型：广泛出血、循环衰竭 | 广泛脑实质损伤与软化 |

# 2｜KP Active Recall

<!-- kianos:kp id="hematology-h22-kp01" -->
## KP01｜一眼分流：流脑看膜，乙脑看实质

> **主提示：流脑1层/1腔｜乙脑3部位｜炎症2型｜症状2侧重**

### Detailed Expansion

- 流脑：主要累及软脑膜、软脊膜，脓性渗出位于蛛网膜下腔；
- 乙脑：主要累及大脑皮质、基底核、视丘等脑实质；
- 流脑为化脓性炎；乙脑为变质性炎；
- 流脑脑膜刺激征和脑神经麻痹更突出，乙脑颅内高压更重。

（易混：病名都有“脑”，但病理空间不是同一层。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP02｜病原、季节与传播：四个低摩擦识别词

> **主提示：流脑病原/季节/路｜乙脑病原/季节/媒介**

### Detailed Expansion

- 流脑：脑膜炎双球菌；冬春多见；飞沫呼吸道传播；
- 乙脑：乙脑病毒；夏秋多见；蚊子为重要媒介。

脑膜炎双球菌与淋病奈瑟球菌均为当前Study提示的革兰阴性球菌特殊例子；完整微生物学不展开。

**Routing**：RECOGNITION｜SPECIAL｜MI-D

<!-- kianos:kp id="hematology-h22-kp03" -->
## KP03｜脑膜三层与蛛网膜下腔：脓液为什么在那里

> **主提示：由内向外3层｜炎症起点2膜｜渗出腔1｜主细胞1**

### Detailed Expansion

当前Study的最低解剖：

```text
脑 / 脊髓表面
→ 软脑膜 / 软脊膜
→ 蛛网膜
→ 硬脑膜 / 硬脊膜
```

流脑累及贴近脑、脊髓表面的软膜；中性粒细胞大量进入软膜与蛛网膜之间的蛛网膜下腔，形成脓性渗出。

**Routing**：CORE｜VISUAL_ONLY｜MI-G

---

<!-- kianos:kp id="hematology-h22-kp04" -->
## KP04｜流脑病理：中性粒细胞性化脓 + 血管扩张充血

> **主提示：部位2｜渗出1｜主细胞｜血管2变化｜症状2**

### Detailed Expansion

流脑典型病理：

- 软脑膜、软脊膜化脓性炎；
- 蛛网膜下腔大量脓性渗出；
- 中性粒细胞为主；
- 血管扩张、充血。

对应临床侧重为脑膜刺激征与脑神经麻痹。当前文件不自行补写脑脊液或抗菌药方案。

**Routing**：CORE｜VISUAL_ONLY｜MI-G

---

<!-- kianos:kp id="hematology-h22-kp05" -->
## KP05｜暴发型流脑：局部脑膜病变可轻，全身反而最重

> **主提示：局部方向｜全身2灾难｜毒素接口｜不能被什么迷惑**

### Detailed Expansion

急性暴发型流脑可出现：

```text
脑膜炎相对较轻
+ 广泛出血
+ 循环衰竭
```

当前Study把它解释为脑膜炎双球菌内毒素大量入血、形成严重全身反应。病例中不能因脑膜局部表现不突出而低估危险。

**Routing**：CORE｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="hematology-h22-kp06" -->
## KP06｜乙脑总体病理：病毒落在脑实质，主角是神经元损伤

> **主提示：部位3｜炎症1型｜坏死1型｜上重下轻｜症状1**

### Detailed Expansion

乙脑主要累及脑实质，以大脑皮质、基底核、视丘等为重，当前Study称病变“上重下轻”。

病毒导致神经元变性坏死，脑组织富含脂质，坏死倾向液化并形成脑软化；因此乙脑归入变质性炎，颅内高压更突出。

**Routing**：CORE｜MI-G

---

<!-- kianos:kp id="hematology-h22-kp07" -->
## KP07｜乙脑两张特征图：筛状软化灶 + 血管周围淋巴细胞套

> **主提示：特征灶1｜本质1｜血管周围谁｜形态1字｜各代表什么**

### Detailed Expansion

- **筛状软化灶**：乙脑特征病变，反映脑实质多灶性软化；
- **血管周围淋巴细胞套**：淋巴细胞围绕血管分布，形成“套”样形态。

两者都必须回病理原图：前者看实质软化空间，后者看炎细胞围血管关系。

**Routing**：CORE｜VISUAL_ONLY｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h22-kp08" -->
## KP08｜三类胶质细胞：星形修复、小胶质吞噬、少突卫星

> **主提示：星形2件｜小胶质3件｜少突1现象｜别混3结果**

### Detailed Expansion

| 细胞 | 当前Study中的角色 |
|---|---|
| 星形胶质细胞 | 增生并形成胶质纤维瘢痕 |
| 小胶质细胞 | 增生形成胶质结节；吞噬神经组织崩解产物；参与噬神经现象 |
| 少突胶质细胞 | 参与卫星现象 |

小胶质细胞吞噬脂质后，胞质可呈空泡状，称格子细胞 / 泡沫细胞。不要与动脉粥样硬化泡沫细胞的病理场景混淆。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

---

<!-- kianos:kp id="hematology-h22-kp09" -->
## KP09｜噬神经现象 vs 卫星现象：谁围谁、谁吞谁

> **主提示：噬神经=谁吞谁｜卫星=谁围谁｜格子细胞来源｜结节来源**

### Detailed Expansion

- 噬神经现象：小胶质细胞吞噬受损神经元 / 神经组织崩解产物；
- 卫星现象：少突胶质细胞围绕神经元；
- 格子细胞 / 泡沫细胞：吞噬脂质后的小胶质细胞；
- 胶质结节：小胶质细胞增生聚集。

这是乙脑最容易混乱的细胞身份组，必须依靠原图完成空间记忆。

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h22-kp10" -->
## KP10｜三病入口：流脑、乙脑、结核性脑膜炎

> **主提示：流脑膜/脓｜乙脑实质/筛｜结脑部位1｜传播季节｜危险各1**

### Detailed Expansion

| 模型 | 主要空间 / 病理 | 当前识别 |
|---|---|---|
| 流脑 | 脑膜、蛛网膜下腔化脓 | 冬春、飞沫、脑膜刺激；暴发型循环衰竭 |
| 乙脑 | 脑实质变质、筛状软化、胶质反应 | 夏秋、蚊媒、颅内高压 |
| 结核性脑膜炎 | 脑底病变明显 | 儿童多见；共同结核机制从H21 Recall |

完整神经临床诊疗均不在当前Source范围。

**Routing**：CONFUSABLE｜CONNECTION｜BOUNDARY｜MI-G
