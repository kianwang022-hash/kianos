# 1｜Framework｜先确认“急性原始细胞病”，再问是哪一系、哪一型、有没有立即危险

## 1.1 中心问题

急性白血病最容易被误学成一串 FAB、CD、染色体和方案。真正的病例主链只有四步：

```text
造血细胞获得克隆性增殖优势
+ 分化停滞在较早阶段
        ↓
原始 / 早幼细胞在骨髓扩张
        ↓
正常造血被压制           白血病细胞向骨髓外浸润
贫血｜感染｜出血          胸骨｜肝脾｜淋巴结｜CNS｜睾丸｜软组织
        \                     /
         \                   /
          └──── 临床发现入口 ────┘
                    ↓
外周血找线索
→ 骨髓确认“急性”
→ 形态 / 细胞化学定方向
→ 流式确认系别
→ 染色体 / 融合基因精确分型与预后
                    ↓
先处理 DIC、白细胞淤滞、肿瘤溶解 / 高尿酸等危急出口
→ 再进入亚型治疗
```

## 1.2 五层证据不是重复检查

| 证据层 | 主要回答的问题 |
|---|---|
| 外周血 | 有没有贫血、血小板减少、异常白细胞和原始细胞线索？ |
| 骨髓 | 是否达到急性白血病的原始细胞门槛？ |
| 形态 / Auer | 细胞看起来像哪一系、哪一分化阶段？ |
| 细胞化学 / 流式 | 髓系、单核系、B、T、NK等身份是什么？ |
| 染色体 / 融合基因 | 最准确的亚型、预后与靶向入口是什么？ |

不能把其中任何一层当成“全部诊断”。

## 1.3 当前 Block 的五个出口能力

1. 解释为什么急性白血病的白细胞可高、正常或低；
2. 从贫血—感染—出血与浸润表现反推共同上游；
3. 用骨髓、细胞化学、流式和遗传学完成 AML / ALL 分流；
4. 第一时间识别 APL / DIC、白细胞淤滞和高尿酸肾病；
5. 按当前 Study 口径恢复 AML、ALL 的主要治疗和缓解判断。

# 3｜第一层：急性白血病究竟是什么

<!-- kianos:kp id="hematology-h09-kp01" -->
## KP01｜病因与“二次打击”：一个事件给增殖优势，另一个事件截断分化

> **主提示：病因4类｜前病4｜二击2件｜结果2**

### Detailed Expansion

当前 Lecture 的病因 / 易感入口包括：

- 电离辐射；
- 苯等化学因素，烷化剂及部分抗肿瘤药；
- HTLV 等生物因素及免疫异常；
- 遗传易感，如 Down、Fanconi、Bloom、共济失调—毛细血管扩张等接口。

可进一步发展为白血病的疾病，当前 Source 列：

```text
MDS｜NHL｜骨髓瘤｜PNH
```

“二次打击”不是必须背基因名，而是记两种功能事件：

```text
打击A：克隆细胞获得增殖 / 生存优势，凋亡受阻
打击B：转录与分化程序异常，成熟停滞
        ↓
大量增殖 + 分化障碍
```

**Routing**：CORE｜CONNECTION｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h09-kp02" -->
## KP02｜急性 vs 慢性：按“分化停在哪”，不是按病程叫法

> **主提示：早停=急｜晚停=慢｜4类型｜儿童1**

### Detailed Expansion

- **急性白血病**：分化停滞在较早阶段，多为原始及早幼细胞，病情进展快；
- **慢性白血病**：分化停滞在较晚阶段，多为中、晚幼及成熟细胞，病情进展相对慢。

当前 Source 的四类总坐标：

```text
AML｜CML｜ALL｜CLL
```

其中 ALL 是儿童最多见的白血病类型，并可按 B、T、NK 来源进一步识别。

（易混：急 / 慢不是简单按“发病几天”命名，而是按肿瘤细胞成熟程度。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP03｜ALL 的 FAB：只抓细胞大小与空泡，完整名称进入 MI-D

> **主提示：L1小≤12｜L2大>12｜L3大+空泡｜越小越成熟？**

### Detailed Expansion

当前 FAB 口径：

| 类型 | 形态入口 |
|---|---|
| L1 | 原始 / 幼淋巴细胞以小细胞（≤12 μm）为主 |
| L2 | 以大细胞（>12 μm）为主 |
| L3 / Burkitt型 | 大细胞为主，胞质内明显空泡 |

L3空泡与糖原染色接口相连，但 H11 会再说明 Burkitt 在淋巴瘤段的成熟细胞与命名边界；这里不提前强行统一。

**Routing**：CORE｜VISUAL_ONLY｜BOUNDARY｜MI-D

## KP04｜AML 的 FAB：看哪一系、停在哪一阶段、各阶段占比多少

> **主提示：M0微｜M1未｜M2部｜M3早幼｜M4粒单｜M5单｜M6红｜M7巨核**

### Detailed Expansion

当前 Study 表：

| 型别 | 当前Lecture识别门槛 |
|---|---|
| M0 微分化 | 原始细胞>30%，CD13 / CD33阳性，无Auer小体 |
| M1 急粒未分化 | 原粒细胞占非红系有核细胞 NEC ≥90% |
| M2 急粒部分分化 | 原粒细胞占 NEC 30%–89% |
| M3 APL | 早幼粒细胞占 NEC ≥30% |
| M4 急粒—单 | 原始细胞≥30%；各阶段粒细胞≥20%；各阶段单核细胞≥20%；嗜酸≥5%称M4Eo |
| M5 急单 | 原 / 幼单核≥30%；各阶段单核≥80%；Source另分M5a / M5b |
| M6 红白血病 | 原始细胞占NEC≥30%；幼红细胞≥50% |
| M7 急巨核 | 原始巨核细胞≥30%；血小板抗原阳性 |

第一轮主轴不是八张卡，而是：

```text
确认急性门槛
→ 看原始细胞属于哪一系
→ 看是否已有一定分化
→ 再用化学 / 流式 / 遗传确认
```

# 4｜第二层：临床表现来自“正常造血被压制”和“肿瘤细胞外侵”两条链

<!-- kianos:kp id="hematology-h09-kp05" -->
## KP05｜骨髓衰竭三联：贫血、感染、出血来自同一个上游

> **主提示：红↓→贫｜正常白↓→感染｜板/凝血↓→出血｜M3-DIC**

### Detailed Expansion

原始细胞在骨髓扩张后，会压制正常三系造血：

- 红系输出不足 → 贫血；
- 正常成熟粒细胞不足 → 发热、感染；
- 血小板减少及凝血异常 → 出血。

出血还可叠加：感染、白血病细胞浸润血管壁、血管内淤滞等；但当前 Lecture 将其主要归入“正常骨髓造血受抑制”。

APL / M3 特别容易并发 DIC，是急性白血病中必须第一时间识别的危急入口。

**Routing**：CORE｜CONNECTION｜MI-G

---

<!-- kianos:kp id="hematology-h09-kp06" -->
## KP06｜胸骨压痛与肝脾大：一个是向心性造血区被占，一个是髓外造血 / 浸润

> **主提示：胸骨压痛｜肝脾轻中｜巨脾多CML｜急性可大但非特异**

### Detailed Expansion

- 胸骨处造血活跃，白血病细胞增殖浸润后可出现高度特征性的胸骨压痛；
- 肝脾可因髓外造血和肿瘤浸润而肿大，多为轻中度；
- 巨脾更提示 CML 或其急性变，完整模型后置 H10。

所以“有脾大”不能直接区分急慢性，但“巨脾 + 成熟粒细胞谱”会把病例推向 CML。

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="hematology-h09-kp07" -->
## KP07｜绿色瘤、牙龈和皮肤：把髓系亚型挂到最有识别度的髓外表现

> **主提示：M2绿瘤—眼眶｜M4/5牙龈肿｜M4/5蓝紫皮结｜出血≠肿胀**

### Detailed Expansion

- 粒细胞肉瘤 / 绿色瘤：多见 AML，尤其 M2；最常累及眼眶；
- 牙龈增生、肿胀与皮肤蓝紫色结节：多见 M4、M5，反映单核系细胞较强的迁移与组织浸润；
- 牙龈出血：仍归“正常造血受抑 / 血小板减少”的出血链，不等同于牙龈浸润。

**Routing**：CORE｜SPECIAL｜RECOGNITION｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h09-kp08" -->
## KP08｜无痛淋巴结与纵隔：先想淋巴瘤，但 ALL / CLL 不能漏；T系连到胸腺

> **主提示：无痛结→淋巴瘤优先｜ALL/CLL常｜T系纵隔｜AML可｜CML几乎无**

### Detailed Expansion

白血病也可造成无痛性淋巴结肿大：

- ALL、CLL 更常见；
- T细胞来源可出现纵隔淋巴结 / 胸腺肿块；
- AML 有时可有；
- CML 几乎无淋巴结肿大。

因此病例出现“无痛性淋巴结肿大”时，优先进入 H11 淋巴瘤框架，同时用 CBC、原始细胞和骨髓证据排白血病。

**Routing**：CORE｜CONNECTION｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h09-kp09" -->
## KP09｜CNS与睾丸：化疗庇护所解释“缓解期仍复发”

> **主提示：ALL多｜缓解期｜CNS第一｜睾丸第二｜MTX鞘内｜双睾放疗**

### Detailed Expansion

血脑屏障、血睾屏障使部分化疗药难以进入，白血病细胞可在这些部位残留。

### CNS白血病

- 最常见髓外浸润部位；
- ALL最常见，儿童尤甚；M4、M5、M2亦可；
- 头痛、呕吐、颈强直；脑脊液可见原始 / 幼稚细胞；
- 当前 Lecture：鞘内甲氨蝶呤为首选，可合用阿糖胞苷、糖皮质激素；颅脊椎照射作为发生后的挽救接口。

### 睾丸白血病

- 次常见髓外浸润部位；
- 多见ALL缓解后的幼儿、青年；
- 多为一侧无痛性肿大，但可双侧浸润；
- 当前 Lecture采用双侧睾丸局部放疗。

**Routing**：CORE｜SPECIAL｜CONNECTION｜MI-G｜MI-D

# 5｜第三层：外周血只找线索，骨髓和分型证据才完成诊断

<!-- kianos:kp id="hematology-h09-kp10" -->
## KP10｜血象：白细胞高、正常、低都可能，关键是“正常细胞被压 + 异常细胞是否入血”

> **主提示：Hb/RBC/Ret↓｜Plt↓｜WBC多↑可正/↓｜10/100/<1｜涂片原幼**

### Detailed Expansion

常见急性白血病血象：

- Hb、RBC、Ret↓，多为正细胞性贫血；
- Plt↓；
- WBC常↑，血涂片可见原始和幼稚细胞。

当前数字入口：

```text
WBC >10×10⁹/L  → 白细胞增多性白血病
WBC >100×10⁹/L → 白细胞淤滞症风险
WBC <1×10⁹/L   → 白细胞不增多性急性白血病
```

少数患者 WBC 正常或下降，外周血甚至很难找到原始细胞；这并不能排除骨髓内急性白血病。

（易混：WBC高不等于正常抗感染白细胞多。）

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h09-kp11" -->
## KP11｜骨髓确诊：多数活跃，少数低增生；FAB与WHO看不同门槛

> **主提示：首选骨穿细胞学｜多活跃｜少数低增生｜FAB30｜WHO20**

### Detailed Expansion

急性白血病确诊首选骨髓穿刺细胞学检查：

- 多数骨髓增生活跃；
- 少数可低增生，称低增生性急性白血病；
- 当前 Study：FAB 原始细胞≥30%；WHO 原始细胞≥20%。

外周血是线索，骨髓才回答“原始细胞是否达到急性门槛”。

**Routing**：CORE｜BOUNDARY｜MI-G

## KP12｜Auer小体：支持髓系分化；成堆提示M3，但“无Auer”不等于急淋

> **主提示：真髓系｜M0/ALL阴｜AML多阳｜成堆M3｜假样边界**

### Detailed Expansion

当前 Lecture 的考试口径：

- ALL、AML-M0：Auer小体阴性；
- AML除M0外可阳性；MDS高原始细胞型可见；
- 成堆 Auer 小体高度提示 M3 / APL；
- Source 还列骨髓瘤可见Auer样结构，并有旁注“并非真Auer、只是长得像”。

所以：

```text
Auer阳性 → 强烈支持髓系
Auer阴性 → 不能直接等于ALL
```

## KP13｜细胞化学：MPO找粒，NSE+NaF找单，PAS成块找淋

> **主提示：粒=MPO｜单=NSE+NaF≥50｜淋=PAS块/粗+双酶阴｜M3强阳**
