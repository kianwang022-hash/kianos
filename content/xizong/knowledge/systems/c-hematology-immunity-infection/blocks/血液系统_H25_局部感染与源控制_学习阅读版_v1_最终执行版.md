# H25｜局部感染与源控制
## 不先背切口：先判断感染是局限、弥漫、封闭高压，还是已有坏死组织必须处理

# 2｜总 Framework

<!-- kianos:framework id="hematology-h25-framework-main" -->

## 2.1 两种病原行为先决定病变形态

```text
金葡菌
→ 凝血酶接口
→ 纤维蛋白形成
→ 感染较局限
→ 疖、痈、脓肿倾向

乙型溶血性链球菌
→ 透明质酸酶
→ 结缔组织屏障被打开
→ 感染弥漫
→ 蜂窝织炎、丹毒倾向
```

## 2.2 源控制不是“所有感染都切开”

```text
没有脓腔 / 非化脓性炎
→ 不因红肿就机械切开

形成脓腔 / 失活组织 / 深间隙高压
→ 抗菌药难以替代排脓、减压、清除坏死

特殊急症
→ 小儿颌下蜂窝织炎：早期减压防窒息
→ 手部多数化脓性感染：肿痛明显即处理，不等波动
```

## 2.3 手部为什么门槛更低

```text
空间狭小 + 纤维隔 / 腱鞘限制
→ 炎性渗出后压力迅速升高
→ 神经、血管、肌腱受压缺血
→ 疼痛加重、功能受限
→ 延误可发生指骨坏死、骨髓炎或肌腱坏死
```

# 3｜KP Active Recall

<!-- kianos:kp id="hematology-h25-kp01" -->
## KP01｜源控制总轴：抗菌药杀病原，切开 / 清创 / 引流移除“持续感染源”

> **主提示：5空间｜4危险｜3外科动作｜抗菌≠什么｜升级H26**

### Detailed Expansion｜快速核对

H20已学：不是所有浅表、局限感染都必须用抗菌药；即使用药，也不能减免外科处理。H25只保留这条执行逻辑：

```text
封闭脓腔
坏死 / 失活组织
异物或无法自行排出的内容
深间隙压力
持续污染或扩散通路
        ↓
抗菌药不能单独解除机械与空间问题
        ↓
切开｜清创｜引流｜减压
```

因此“源控制”不是见感染就切，而是识别病原持续存在、药物难以到达或组织压力已经威胁功能的场景。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

## KP02｜金葡菌 vs 乙链：凝固局限与透明质酸弥漫

> **主提示：酶各1｜组织结果2｜代表各2｜药物类2｜反向识别**

### Detailed Expansion｜快速核对

| 轴 | 金黄色葡萄球菌 | 乙型溶血性链球菌 |
|---|---|---|
| 当前 Study酶接口 | 凝血酶 | 透明质酸酶 |
| 组织结果 | 纤维蛋白形成，较局限 | 透明质酸降解，较弥漫 |
| 浅部代表 | 疖、痈 | 蜂窝织炎、丹毒 |
| 当前药物类接口 | 青霉素类、头孢菌素类 | 青霉素类、头孢菌素类 |

这是一条“病原行为 → 组织空间”的推导轴，不代表每个病例都能只凭外观确定病原。

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="hematology-h25-kp03" -->
## KP03｜疖 vs 痈：一个脓点 vs 多个相邻毛囊 + 更大失活区

> **主提示：脓点1/多｜范围｜好发｜糖尿病｜波动后动作**

### Detailed Expansion｜快速核对

- **疖**：单个毛囊及周围感染，典型为**一个脓点**；出现波动感后，当前 Study处理为碘伏点涂并剔除脓栓。
- **痈**：多个相邻毛囊及周围组织化脓，表现为**多个相邻脓点**；好发项背部，常合并糖尿病。
- 痈出现波动后，需要切开引流并清除：
  - 已化脓组织；
  - 尚未化脓但已经失活的组织。

（易混：普通痈的波动后切开，不等于危险三角内的唇痈可随意切开。）

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h25-kp04" -->
## KP04｜唇痈危险三角：禁挤、禁切；海绵窦方向先于局部排脓

> **主提示：危险区｜禁2｜静脉特殊｜并发症｜头痛/意识警报｜普通痈切口4点**

### Detailed Expansion｜快速核对

唇部危险三角的静脉回流可向眼静脉、海绵窦方向传播，相关静脉缺少静脉瓣。因此当前 Study强调：

```text
唇痈
→ 严禁挤压
→ 严禁局部切开
→ 防止感染逆行进入海绵窦
```

出现头痛、意识障碍时，必须警惕海绵状静脉窦炎 / 血栓方向。

普通痈出现波动后的切口口径：十字切口、超过病变边缘、深达筋膜、填塞脓腔；同时清除失活组织。危险三角例外不能被普通痈规则覆盖。

**Routing**：CORE｜SPECIAL｜RECOGNITION｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h25-kp05" -->
## KP05｜蜂窝织炎：疏松结缔组织弥漫化脓，边界不清；波动后引流

> **主提示：组织3处｜炎症1｜边界｜何时切｜常见菌群接口**

### Detailed Expansion｜快速核对

蜂窝织炎累及皮肤、肌肉、阑尾等疏松结缔组织，属于化脓性炎，病变弥漫且边界不清。

```text
弥漫炎症
→ 尚无明确脓腔时不机械套用“脓肿切开”
→ 出现波动感，提示脓液局限
→ 切开引流
```

当前 Lecture在不同部位给出不同病原倾向：皮肤表面常见金葡菌；消化道、泌尿道、胆道感染常见 G−杆菌与厌氧菌。这里只保存部位接口，不扩写抗菌谱。

**Routing**：CORE｜BOUNDARY｜MI-G

<!-- kianos:kp id="hematology-h25-kp06" -->
## KP06｜丹毒：皮肤淋巴管网、非化脓、边界清楚，所以不切开

> **主提示：部位1层｜菌1｜原发灶3｜皮疹3色/形｜复发→1｜切不切**

### Detailed Expansion｜快速核对

丹毒的当前 Study身份：

- 主要累及皮肤淋巴管网；
- 多为乙型溶血性链球菌；
- 属**非化脓性炎**；
- 好发下肢、面部；
- 原发灶可为足癣、口腔溃疡、鼻窦炎；
- 典型为边界清楚的片状红疹，周围鲜红、中间较淡；
- 很少发生组织坏死和化脓，**不切开引流**；
- 治愈后易复发，症状消失后仍按 Study口径继续用药；反复发作可因淋巴回流受阻形成象皮肿。

（易混：边界清楚 + 非化脓 + 不切，是与蜂窝织炎最稳的三轴。）

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h25-kp07" -->
## KP07｜三种特殊蜂窝织炎：颌下防窒息、产气有捻发、新生儿金葡坏疽

> **主提示：小儿颌下=早切防1｜产气=菌群/体征｜新生儿=菌1｜普通规则为何失效**

### Detailed Expansion｜快速核对

1. **小儿颌下蜂窝织炎**：离气道近，可出现喉头水肿；当前 Study要求**早期切开减压，防止窒息**，不等波动。
2. **产气性皮下蜂窝织炎**：厌氧菌多见，可出现捻发感；与 H27 的肌肉气性坏疽仍不是同一疾病模型。
3. **新生儿皮下坏疽**：当前 Study提示金葡菌多见。

这三个入口提示：同名“蜂窝织炎”也必须按解剖位置、宿主与气体 / 坏死信号重新判断处理阈值。

**Routing**：SPECIAL｜RECOGNITION｜CONFUSABLE｜MI-G

## KP08｜切开时机总表：一般等波动；气道、手部高压和厌氧坏死不等

> **主提示：一般1｜早切3组｜永不切1｜甲沟例外｜判断变量4**

### Detailed Expansion｜快速核对

| 场景 | 当前 Study时机 |
|---|---|
| 一般脓肿 / 疖 / 痈 / 普通蜂窝织炎 | 出现波动后切开或排脓 |
| 小儿颌下蜂窝织炎 | 早期减压，防窒息 |
| 手部化脓性感染（甲沟炎除外） | 肿痛明显即及时切开，不等波动 |
| 破伤风 / 气性坏疽污染伤 | H27早期彻底清创引流 |
| 丹毒 | 非化脓性炎，不切开 |
| 甲沟炎 | 出现波动后甲沟旁纵切 |

真正决定时机的是：有没有封闭高压、神经血管 / 肌腱缺血、气道威胁或快速坏死，而不是统一等待某个体征。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP09｜甲沟炎：甲侧开始，U形 / 甲下脓肿；波动后旁侧纵切

> **主提示：起点｜扩展2型｜可进展哪病｜切开时机｜切口方向**

### Detailed Expansion｜快速核对

甲沟炎位于指甲两侧，可形成：

- U形脓肿；
- 甲下脓肿；
- 向末节指腹扩展为脓性指头炎。

当前 Study处理：出现波动感后，在甲沟旁作纵行切开引流。它是“手部化脓性感染肿痛明显即切”的主要时机例外。

**Routing**：CORE｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h25-kp10" -->
## KP10｜脓性指头炎三段痛：针刺→跳痛→痛反减，最后一步反而更危险

> **主提示：诱因2｜痛3段｜痛减原因｜不切2并发｜初期体位**

### Detailed Expansion｜快速核对

常见入口为鱼刺刺伤或甲沟炎蔓延。疼痛进程：

```text
针刺样疼痛
→ 剧烈跳痛 + 肿胀加重
→ 疼痛反而减轻
```

最后的“痛减”不是好转，而可能是局部高压导致神经末梢缺血、破坏。若延误，可出现：

- 末节指骨缺血坏死；
- 骨髓炎。

初发时：悬吊前臂、平放患手。肿痛明显时及时切开。

**Routing**：CORE｜SPECIAL｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h25-kp11" -->
## KP11｜指头炎切口与麻醉：侧纵切，三条不越界；禁鱼口、禁肾上腺素

> **主提示：侧纵｜近端不越哪纹｜远端不越甲沟多少｜大脓腔｜死骨｜麻醉禁1**

### Detailed Expansion｜快速核对

当前 Study的操作边界：

- 末节指侧面纵行切口；
- 不作鱼口状切口，避免瘢痕影响手功能；
- 近端不超过指节横纹；
- 远端不超过甲沟的 1/2；
- 脓腔较大时可对口引流；
- 有死骨时清除；
- 指神经阻滞麻醉**不加肾上腺素**。

这些是 MI-D中的高频精确边界；第一轮先抓“及时减压 + 不损害指端血供和功能”。

**Routing**：CORE｜VISUAL_ONLY｜MI-G｜MI-D

## KP12｜掌深间隙：第三掌骨掌中隔把鱼际与掌中分开

> **主提示：隔膜位置｜桡/尺2间隙｜掌中体征3｜鱼际体征3｜是否互通**

### Detailed Expansion｜快速核对

第三掌骨处的掌中隔把掌深间隙分为：

| 间隙 | 侧别 | 当前 Study表现 |
|---|---|---|
| 鱼际间隙 | 桡侧 | 鱼际肿胀；1、2指活动受限；不能对掌 |
| 掌中间隙 | 尺侧 | 掌心凹消失 / 掌心隆起；3、4、5指活动受限 |

当前 Lecture强调二者被纤维隔分开，不能把所有掌部肿胀视作一个可自由蔓延的腔。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

## KP13｜掌部切口：近端不过掌横纹；手背肿不等于切手背

> **主提示：何时切｜近端保护谁｜手背为何肿｜严禁切哪｜病灶真正在哪**

### Detailed Expansion｜快速核对

掌深间隙感染肿痛明显时及时切开引流。当前 Study两条关键边界：

- 切口近端不超过掌横纹，避免损伤掌浅弓；
- 严禁切开肿胀的手背。

手掌皮肤厚、角化坚韧；掌部感染可经淋巴回流使薄而松弛的手背明显水肿。因此：

```text
最肿的位置
≠
感染源所在的位置
```

必须按掌深间隙定位，而不是追着手背水肿切开。

**Routing**：CORE｜SPECIAL｜VISUAL_ONLY｜MI-G

## KP15｜腱鞘炎 / 滑囊炎：明显肿痛就切；延误坏肌腱，切口还要避正中神经

> **主提示：时机｜延误1后果｜术后2｜滑囊切口距腕纹｜保护谁**

### Detailed Expansion｜快速核对

## KP16｜局部感染最终算法：先判空间，再判压力 / 坏死 / 功能，最后决定源控制时机
