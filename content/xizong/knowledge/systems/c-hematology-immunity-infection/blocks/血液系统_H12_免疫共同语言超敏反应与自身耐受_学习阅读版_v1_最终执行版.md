> **Primary Study**：`病理学讲义_AI阅读版.md` PDF P90–94，重点为 P91 的Ⅰ—Ⅳ型超敏反应；P90 的 B / T / CD4 / CD8 与排斥内容只提取最低共同语言。原图核对使用 `27病理精编版合集【带导图】.pdf` PDF P106–110。

```text
  ├─ Ⅰ：速发型
```

## KP01｜最低免疫词典：只学后面真正会反复用到的角色

> **主提示：B→？｜CD4帮？｜CD8做？｜抗体直打vs成团沉积｜补体到哪层｜完整级联？**

### 1｜B细胞与抗体

当前 Study 可安全建立：

```text
B细胞
→ 产生抗体
→ 参与体液免疫
```

证据接口来自：

- Bruton 综合征：B细胞和γ球蛋白缺陷；
- 慢性排斥：CD4 T细胞可促进 B细胞产生特异性抗体并激活补体；
- Ⅱ型与Ⅲ型超敏均以抗体相关损伤为主线。

### 2｜CD4与CD8

- **CD4 T细胞**：辅助性 T细胞；当前 Source 显示其可连接 B细胞、CD8、NK和巨噬细胞等途径；
- **CD8 T细胞**：细胞毒性 T细胞接口；
- Ⅳ型迟发型超敏由 T细胞介导。

### 3｜抗体的两种高频损伤方式

```text
抗体直接针对细胞 / 固定结构
→ Ⅱ型

抗原与抗体先形成免疫复合物
→ 复合物沉积并形成血管炎样损伤
→ Ⅲ型
```

### 4｜补体只学到“接口”

当前可以使用：

```text
抗体 / 免疫复合物
→ 补体与白细胞被调用
→ 清除目标时也可损伤正常组织
```

但不展开完整补体级联与各片段功能。

（边界：完整正常免疫学为显式 Source Gap。）

## KP02｜分类起手式：先判“损伤动作”，不要先背疾病名单

> **主提示：时相快/迟｜效应器4路｜落点3类｜最后再挂疾病**

面对一个免疫损伤题，先问：

1. **来得快还是来得迟？**
2. **主要是过敏性速发、抗体直打、免疫复合物，还是 T细胞？**
3. **损伤落在细胞、固定基底结构，还是血管 / 滤过结构与间质？**
4. **题目强调的是疾病总体，还是某一个特殊表现？**

这一顺序可以防止两个常见错误：

- 看到“SLE”就机械选同一种超敏反应；
- 看到“抗体”就一律归Ⅱ型，忽略免疫复合物形成后的Ⅲ型损伤。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP04｜Ⅱ型细胞毒型：抗体针对细胞或固定靶点

> **主提示：Ⅱ=毒｜体液+ADCC｜细胞/固定靶｜8例｜特殊：SLE全血细胞↓**

### 1｜当前 Study 的机制身份

```text
抗体针对细胞或固定结构
→ 体液免疫为主
→ 抗体依赖的细胞介导毒性作用 ADCC 接口
→ 细胞损伤 / 功能异常
```

这里的“细胞毒型”不能理解成只有 CD8 T细胞参与；当前 Lecture 的考试口径明确把它放在**体液免疫 / 抗体相关**损伤中。

### 2｜当前 Study 列举的8个例子

1. 急性排斥反应血管型；
2. 输血；
3. 溶血；
4. 风湿；
5. 甲亢；
6. 急进性肾炎Ⅰ型；
7. 肺出血—肾炎综合征；
8. SLE导致的全血细胞减少。

### 3｜高价值边界

- **多数 SLE**：Ⅲ型；
- **SLE全血细胞减少**：Ⅱ型；
- **多数肾小球肾炎**：Ⅲ型；
- **抗GBM相关的急进性肾炎Ⅰ型 / Goodpasture**：Ⅱ型。

（易混：疾病名相同，不代表所有器官表现都由同一超敏类型解释。）

## KP05｜Ⅲ型免疫复合物 / 血管炎型：先成团，再沉积

> **主提示：Ⅲ=免血｜复合物→沉积→血管/滤过损伤｜5例｜超急归类冲突**

### 1｜最低机制链

```text
抗原 + 抗体
→ 形成免疫复合物
→ 在组织中沉积
→ 调用补体 / 白细胞接口
→ 形成血管炎样或滤过结构损伤
```

当前 Source 重点不是完整解释复合物为何选择某一器官沉积，而是要求先识别：

> **Ⅲ型的病理语言是“免疫复合物 + 血管炎 / 沉积”。**

### 2｜当前 Study 列举的5类例子

1. 超急性排斥反应；
2. 类风湿；
3. 大动脉炎；
4. 多数 SLE；
5. 多数肾小球肾炎。

### 3｜超急性排斥的来源冲突

当前 Lecture 同时保留两条表述：

- 10版教材表格把超急性排斥归入Ⅲ型；
- 讲义旁注明确写：按定义其本质更接近Ⅱ型，但病理表现类似Ⅲ型。

本文件不擅自裁决。考试时按当前 Study 显示的题目口径答题；完整冲突在 H14 再登记。

## KP08｜同一疾病可跨型：必须看题目正在问哪个损伤层

> **主提示：SLE总体vs全血细胞↓｜GN多数vs抗GBM｜排斥超急/急血管/急细胞/慢**

### 1｜SLE

```text
多数器官损伤 / 免疫复合物沉积
→ Ⅲ型

自身抗体攻击血细胞导致全血细胞减少
→ Ⅱ型
```

### 2｜肾小球肾炎

```text
多数GN
→ 免疫复合物相关
→ Ⅲ型

急进性肾炎Ⅰ型 / Goodpasture
→ 抗GBM固定靶
→ Ⅱ型
```

### 3｜移植排斥

不同时间、攻击方向与病理层级并不相同：

- 超急：预存抗体 + 血管灾难；
- 急性血管型：血管内膜损伤；
- 急性细胞型：T细胞浸润；
- 慢性：血管内膜纤维化。

## KP11｜免疫反应不等于“越强越好”：清除威胁与组织损伤可同时发生

> **主提示：效应器4路｜目标正确也可伤组织｜目标错=自身免疫｜反应弱=感染/肉芽肿？**

当前资料允许形成两条并行认识：

### 1｜反应存在，但代价过高或落点错误

```text
抗体 / 复合物 / T细胞被动员
→ 可以参与清除威胁
→ 也可损伤血细胞、血管、基底膜和间质
```

### 2｜反应不足，也会造成组织损害

```text
免疫环节缺失
→ 病原控制失败
→ 机会性感染、肿瘤和异常组织反应增加
```

病理 Study 在 HIV 场景指出：免疫力严重下降时可见大量病原，却少见典型肉芽肿。它说明：

> **病理形态不仅由病原决定，也由宿主能否组织免疫反应决定。**

这一条是 H12 → H13 → H20 的核心连接。

**Routing**：CORE｜CONNECTION｜MI-G

## KP12｜病例分类算法：四步定位，不从疾病名开跑

> **主提示：时相｜效应器｜落点｜特殊表现｜最后疾病**

```text
① 时相
   立刻 / 很快？还是数日后 / 慢性？

② 效应器
   过敏性速发？抗体直打？复合物？T细胞？

③ 落点
   血细胞 / 固定基底膜？
   血管 / 肾小球 / 真皮交界？
   间质T细胞浸润？

④ 特殊表现
   同一疾病的某个表现是否换了损伤类型？

⑤ 最后挂回疾病
```
