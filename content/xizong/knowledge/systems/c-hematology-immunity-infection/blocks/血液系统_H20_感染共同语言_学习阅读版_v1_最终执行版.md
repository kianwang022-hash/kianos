# H20｜感染共同语言
## 先问“病原从哪来、落在哪、宿主怎样反应、是否有源要处理”，再问具体病名

> **FIRST PASS 固定流程**  
> `Framework → Lecture → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **中心问题**：面对发热、局部红肿痛、脓液、器官功能下降或免疫缺陷宿主，怎样用同一套坐标判断感染的入口、空间、宿主反应、播散风险与源控制需求，而不是一开始就背病原—药物名单？
>
> **文件性质**：血液—免疫—感染系统第20个 canonical Block，是感染支路的入口。它只建立当前 Source 支持的最低共同语言；H21–H24进入特异感染，H25–H27承担局部感染、脓毒症、破伤风和气性坏疽。

# 0｜第一轮只抓住这一条主链

```text
病原暴露 / 屏障破坏
→ 进入特定解剖空间
→ 定植、侵袭或形成感染灶
→ 宿主按自身免疫能力产生组织反应
→ 病变被局限，或沿局部 / 淋巴 / 血道播散
→ 抗菌药作用于可到达、可杀灭的病原
+ 外科处理移除脓腔、坏死组织、异物或梗阻等持续感染源
→ 消退、修复；或进入慢性化、脓毒症与器官功能障碍
```

最小五问：

```text
病原｜部位｜宿主｜组织反应｜源控制
```

这五问比“先猜一种细菌”更稳定，因为同一病原可落在不同器官，同一器官也可由不同病原造成；宿主免疫状态还会改变病理图是否典型。

# 1｜Framework｜感染是一场“进入—定植—反应—控制—结局”的空间事件

## 1.1 三层地图

### A｜病原层

- 从何处进入；
- 是否仍在持续输入；
- 是单一病原还是混合感染；
- 是否在长期抗菌药选择压力下发生菌群交替。

### B｜宿主—组织层

- 落在黏膜、实质、浆膜、血管、骨髓、深间隙还是异物 / 导管表面；
- 宿主是免疫完整、免疫缺陷，还是粒细胞数量 / 功能异常；
- 当前组织反应偏化脓、假膜、变质、增生或肉芽肿。

### C｜处置层

```text
是否局限
→ 是否形成脓腔、坏死、异物、梗阻或封闭空间高压
→ 标本能否对应真实感染空间
→ 是否需要经验性抗菌药
→ 是否需要引流、清创、解除梗阻或去除感染灶
→ 是否已出现全身失控
```

## KP01｜感染五问：病原—部位—宿主—反应—源控制

> **主提示：5问｜先空间后病名｜最后1危险出口**

### Detailed Expansion

面对感染病例，依次回答：

1. **病原 / 暴露**：入口与传播路径是什么；是否可能混合感染？
2. **部位 / 空间**：病原真正位于气道、肺泡、尿路、胆道、肠腔、浆膜、血管、骨、深间隙还是异物表面？
3. **宿主**：免疫是否完整；是否存在HIV、长期广谱抗菌药、免疫抑制或局部屏障破坏？
4. **组织反应**：化脓、假膜、变质、增生、肉芽肿，还是反应反而很弱？
5. **源控制**：是否存在抗菌药难以单独解决的脓腔、坏死、异物、梗阻或封闭空间？

最后再问：是否已经从局部感染跨入全身失控和器官功能障碍。完整脓毒症模型归H26。

**Routing**：CORE｜CONNECTION｜MI-G

<!-- kianos:kp id="hematology-h20-kp02" -->
## KP02｜感染不等于“病原出现”：定植、侵袭与持续感染灶要分层

> **主提示：出现≠致病｜3层｜组织证据｜持续源4类**

### Detailed Expansion

当前共同框架把过程拆成：

```text
病原到达
→ 可仅停留 / 定植
→ 穿越屏障并侵袭组织
→ 形成局部感染灶
→ 若病原、坏死物或阻塞持续存在，感染可反复或慢性化
```

判断不能只靠“培养到一种微生物”，还要把临床表现、真实取材空间和组织反应放在一起。H20不建立完整污染 / 定植判定标准，只冻结这一层级意识。

**Routing**：CORE｜BOUNDARY｜MI-G

<!-- kianos:kp id="hematology-h20-kp03" -->
## KP03｜同一病原在不同宿主中，病理图可以完全不同

> **主提示：免疫完整1图｜免疫缺陷2后果｜病原多≠反应强｜H13接口**

### Detailed Expansion

免疫完整宿主可形成明显中性粒细胞渗出、肉芽肿或局部包裹；免疫缺陷宿主则可能：

- 病原负荷更高、播散更广；
- 反而缺少典型肉芽肿或局部炎症反应；
- 同时增加机会性感染和肿瘤风险。

H13已建立“HIV晚期病原很多而肉芽肿少”的反例。本 Block只把它升级为感染共同判断：

```text
组织反应弱
≠
感染一定轻
```

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP04｜五类组织反应：化脓、假膜、变质、增生、肉芽肿

> **主提示：5型｜主细胞 / 主变化｜代表H22–H24｜哪个可并存**

### Detailed Expansion

| 组织反应 | 当前最低身份 | 后续代表 |
|---|---|---|
| 化脓性炎 | 中性粒细胞 + 脓性渗出 | 流脑、淋病、局部化脓感染 |
| 假膜性炎 | 黏膜表面纤维素性渗出形成假膜 | 菌痢 |
| 变质性炎 | 实质细胞变性、坏死为主 | 乙脑 |
| 增生性炎 | 单核—巨噬细胞等增生为主 | 伤寒急性增生性炎 |
| 肉芽肿性炎 | 巨噬细胞 / 上皮样细胞主导的慢性特异性增生 | 结核、慢性虫卵结节、梅毒树胶肿接口 |

同一疾病不同阶段可兼有变质、渗出与增生，不应把表格机械当成互斥标签。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP05｜外科感染的基本身份：混合感染常见；病程分3类

> **主提示：感染构成1｜病程3｜亚急性时段｜为什么要多病原意识**

### Detailed Expansion

当前外科 Study：

- 外科感染常为多种细菌的**混合感染**；
- 病程分急性、亚急性和慢性；
- 亚急性病程为 **3周—2个月**。

混合感染意识的实际作用是：同一灶内可有不同需氧条件与病原，不能仅凭一个表面表现假定单一病原；但完整病原配对和经验方案不在当前 Source 范围。

**Routing**：CORE｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h20-kp06" -->
## KP06｜特异感染、机会感染与二重感染：三个名字问的是三件事

> **主提示：特异4例｜机会=宿主？｜二重=用药链｜常见替代菌1**

### Detailed Expansion

- **特异性感染**：当前 Study列举结核、破伤风、气性坏疽、真菌如念珠菌感染；其病原与组织反应具有较特定模型。
- **条件 / 机会感染**：平时不致病或致病性低的病原，在宿主抵抗力下降时引起感染；院内感染作为当前例子。
- **二重感染 / 菌群交替**：长期广谱抗菌药抑制敏感菌，不敏感菌趁机生长，当前 Source以假丝酵母菌 / 念珠菌为常见例子。

（易混：机会感染强调“宿主条件改变”；二重感染强调“长期广谱抗菌药造成生态选择”。）

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

<!-- kianos:kp id="hematology-h20-kp07" -->
## KP07｜抗菌药不能替代源控制：外科感染的双支治疗

> **主提示：不是都用｜药物做什么｜外科基本原则2件｜持续源4类**

### Detailed Expansion

当前 Source明确：

- 不是所有外科感染都必须使用抗菌药；表浅且局限的疖可不使用；
- 即使使用抗菌药，也不能免除外科处理；
- 外科治疗基本原则是：**去除感染灶 + 通畅引流**。

System Guide进一步把持续感染源概括为：

```text
脓腔｜坏死组织｜异物｜梗阻
```

这些因素可使药物难以到达、病原持续存在或压力不断升高。因此“有感染”不能自动等同于“加一种抗菌药”。

**Routing**：CORE｜CONNECTION｜MI-G

## KP09｜联合抗菌药4类指征：不是“病重就多上几种”

> **主提示：未明/免缺｜混合3例｜长疗程耐药2例｜降毒1配对**

### Detailed Expansion

当前 Source的联合用药指征：

1. 病因未明，或免疫缺陷者的严重感染；
2. 单一抗菌药不能控制的混合感染，如脓毒症、继发性腹膜炎、感染性心内膜炎；
3. 需要长期用药、病原易耐药，如结核、尿路感染；
4. 为减少个别药物剂量、降低毒性，如两性霉素B + 氟胞嘧啶。

这是一组“为什么联合”的分类，不是本 Block自行建立完整药理方案。

**Routing**：CORE｜MI-G｜MI-D

## KP10｜标本必须匹配感染空间：血、脓、穿刺液、导管不是同一证据

> **主提示：空间先行｜4标本｜培养阴性2方向｜确证边界**

### Detailed Expansion

外科 Lecture后续脓毒症段提供的标本接口包括：

- 血培养；
- 脓液 / 穿刺液培养；
- 导管内采样；
- 器官特异取材，如关节液、肝脓肿穿刺液等。

H20只提炼通则：

```text
怀疑哪个空间
→ 尽量从那个空间取材
→ 再把培养结果与临床和组织反应对照
```

多次血培养阴性时，当前 Source提示厌氧菌或真菌接口；完整采样时机、数量和脓毒症处理归H26。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

## KP12｜局部还是全身：感染严重度不能只看发热和WBC

> **主提示：局部4证据｜全身3入口｜三低反例｜器官功能=后续谁**

### Detailed Expansion

局部判断关注：感染空间、脓腔 / 坏死、疼痛与功能、是否可引流。全身判断关注：体温、循环状态、意识与器官功能。

当前外科 Source提醒：G⁻杆菌感染可出现血压、体温、WBC“三低”，因此：

```text
没有高热 / 没有白细胞升高
≠
排除严重感染
```

但H20不展开脓毒症诊断和1小时处置；器官功能障碍、休克和抗菌药时效归H26。

**Routing**：CORE｜CONFUSABLE｜BOUNDARY｜MI-G

## KP13｜感染反向定位算法：从病例回到五问

> **主提示：入口→空间→宿主→反应→源｜3分流｜何时升级**

### Detailed Expansion

```text
发热 / 局部症状 / 影像或培养异常
        ↓
1. 找入口与真实感染空间
        ↓
2. 判断宿主免疫能力与组织反应是否匹配
        ↓
3. 分流
   ├─ 特异感染 → H21–H24
   ├─ 局部化脓 / 深间隙 → H25
   └─ 全身失控 / 器官功能障碍 → H26
        ↓
4. 同时决定抗菌药与源控制是否缺一不可
```

H20出口是“会定位和分流”，不是背完全部病原和药物。

**Routing**：CORE｜CONNECTION｜MI-G
