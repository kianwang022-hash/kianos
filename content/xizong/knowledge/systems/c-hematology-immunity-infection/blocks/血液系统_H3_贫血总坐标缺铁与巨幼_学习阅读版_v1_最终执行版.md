# H3｜贫血总坐标、缺铁与巨幼细胞性贫血
## Hb只告诉你“有贫血”；MCV × Ret才开始告诉你“为什么”

> **中心问题**：确认 Hb下降后，怎样先用 MCV判断红细胞“做得大、正常还是小”，再用 Ret判断骨髓“有没有回应”；缺铁为何先耗尽仓库、再影响红细胞内铁、最后才使 Hb下降；Vit B12 / 叶酸缺乏为何产生“核幼浆老”的大细胞性贫血？
>
> **文件性质**：血液系统第三个 canonical Block，也是全部贫血的共同入口。H4再障、H5溶血、H7 MDS及后续肿瘤性贫血都从本 Block的 `Hb → MCV → Ret → 特异证据` 调用。
>
> **Primary Study**：`内科学讲义_AI阅读版.md` P180–186《缺铁性贫血与贫血概述》，并 Recall H1、D4、M3及正式生化 Source中与巨幼细胞性贫血直接相连的最低机制。
>
> **Primary Outline**：内科 U071–U073，按单元 metadata **11 + 11 + 8 = 30 / 30**。
>
> **Source boundary**：当前正式内科 Lecture对贫血总论与 IDA支持完整，对巨幼细胞性贫血主要支持“病因—大细胞形态—核幼浆老—原位溶血—B12吸收和神经接口”。完整 B12 / 叶酸实验室分辨、替代剂量和全部一碳通路仍归正式生化 M8及后续 Source，不在本 Block凭模型常识补齐。

# 1｜总 Framework

<!-- kianos:framework id="hematology-h03-framework-main" -->

```text
Hb下降
  ↓
第一轴｜MCV：红细胞平均大小
  ├─ <80 fL：小细胞
  ├─ 80–100 fL：正细胞
  └─ >100 fL：大细胞
  ↓
第二轴｜Ret：骨髓红系反应
  ├─ 高 / 明显高：正在补偿，优先搜索丢失、破坏或治疗反应
  └─ 低 / 反应不足：优先搜索原料、EPO、成熟、干祖细胞、骨髓环境
  ↓
第三层｜特异证据
  ├─ 铁仓库 / 运输 / 利用
  ├─ B12 / 叶酸与DNA成熟
  ├─ 溶血证据
  ├─ 肾功能 / EPO
  └─ 骨髓形态、克隆或浸润
```

两个典型反面：

```text
缺铁
→ Hb原料不足
→ 胞浆血红蛋白化落后
→ 核老浆幼
→ 小细胞低色素

B12 / 叶酸缺乏
→ 核苷酸 / DNA合成障碍
→ 胞核成熟落后
→ 核幼浆老
→ 大细胞 / 大椭圆红细胞
```

## KP01｜先确认贫血与严重度：Hb是定义入口，不是病因答案

> **主提示：男/女/孕3阈｜轻中重极重4档｜Hb先于RBC｜严重度≠病因**

### 1｜当前 Study诊断阈值

| 人群 | 贫血Hb阈值 |
|---|---:|
| 成年男性 | `<120 g/L` |
| 成年女性 | `<110 g/L` |
| 孕妇 | `<100 g/L` |

### 2｜严重度

| 严重度 | Hb |
|---|---:|
| 轻度 | `>90 g/L` |
| 中度 | `60–90 g/L` |
| 重度 | `30–59 g/L` |
| 极重度 | `<30 g/L` |

Hb下降可早于 RBC计数明显下降，因为一枚 RBC可以“还在，但Hb装得少”。因此：

> 诊断贫血先看 Hb；病因分类再看 MCV、Ret和特异证据。

（边界：阈值按当前 Study考试口径；不在本文件引入不同海拔、吸烟或指南修正。）

**Routing**：CORE｜CONFUSABLE｜MI-G｜MI-D

## KP02｜贫血三大来源：造不出、丢出去、坏得快

> **主提示：生成不足3层｜丢失2时相｜破坏｜每类举2–4｜Ret方向**

### 1｜红细胞生成不足

```text
原料 / 利用异常
→ 缺铁、铁利用障碍、B12 / 叶酸缺乏

干祖细胞 / 骨髓异常
→ 再障、MDS、白血病 / 淋巴瘤 / 骨髓瘤占位

调节信号不足
→ 肾性贫血，EPO↓
```

### 2｜红细胞丢失过多

- 急性失血；
- 慢性失血，如月经过多、消化道出血、ITP相关反复出血等。

### 3｜红细胞破坏过多

- 溶血。

### 4｜Ret把三类进一步分开

```text
丢失 / 破坏后，骨髓有能力回应
→ Ret通常上升

生成不足 / 成熟障碍
→ Ret低或不恰当地正常
```

但巨幼贫可因骨髓内原位溶血使 Ret表现复杂；不能把一个百分比脱离时相和贫血程度机械使用。

**Routing**：CORE｜CONNECTION｜MI-G

## KP03｜MCV三分：大、正、小只描述形态，不直接等于病名

> **主提示：>100｜80–100｜<80+MCHC<32｜各类代表｜Ret增多也可大**

### 1｜三类标准

| 类型 | MCV | MCHC｜当前 Study |
|---|---:|---:|
| 大细胞性 | `>100 fL` | 不以低色素为主轴 |
| 正细胞性 | `80–100 fL` | `32%–36%` / 320–360 g/L |
| 小细胞低色素性 | `<80 fL` | `<32%` / 320 g/L |

### 2｜代表病因

#### 大细胞

- 巨幼细胞性贫血；
- 严重肝病；
- 溶血 / 急性失血后 Ret大量增多；
- MDS。

（易混：Ret本身比成熟 RBC大，所以“MCV大”不自动等于 B12 / 叶酸缺乏。）

#### 小细胞低色素

- IDA；
- 铁粒幼细胞性贫血；
- 转铁蛋白缺乏；
- 慢性失血；
- 慢性病贫血；
- 珠蛋白生成障碍 / 地中海贫血；
- MDS可出现。

#### 正细胞

- 多数溶血；
- 急性失血早期；
- 再障；
- 白血病；
- 多数骨髓瘤；
- 肾性贫血；
- ITP相关贫血；
- MDS。

> MCV是第一轮分流，不是最终诊断；同一疾病可因阶段、并发症或病态造血跨类别。

**Routing**：CORE｜CONFUSABLE｜MI-G｜MI-D

<!-- kianos:kp id="hematology-h03-kp04" -->
## KP04｜Ret轴：看“骨髓反应是否匹配”，不只看高或低

> **主提示：正常0.5–1.5｜明显高3类｜正常/轻高4类｜低3类｜时相/原位溶血**

### 1｜正常值与意义

Ret正常约 **0.5%–1.5%**，主要反映骨髓红系增生和近期输出。

### 2｜当前 Study分组

| Ret方向 | 代表 |
|---|---|
| 明显升高，可达5%–20% | 溶血、急性失血、巨幼贫原位溶血 |
| 正常或轻度升高 | IDA、巨幼贫、ITP、少数MDS；补充原料后可迅速升高 |
| 下降 | 再障、多数MDS、白血病 |

### 3｜为什么Ret不能机械二分

- 急性失血太早时，骨髓尚未完成增产，Ret未必立刻升；
- IDA / 巨幼在原料未纠正时，骨髓想造但成品受限；
- 巨幼贫和MDS可有骨髓内原位溶血，外周Ret与骨髓活跃度不完全同义；
- 百分比还会受总 RBC数影响。

当前第一轮只用：

> **贫血程度与Ret反应是否“相称”**。

更精细的校正 Ret / 生成指数不在当前 Source中静默补入。

**Routing**：CORE｜CONFUSABLE｜SPECIAL｜MI-G

## KP05｜MCV × Ret四格：贫血病例固定从这里起手

> **主提示：小/正/大×Ret高低｜四条主分支｜下一步证据各1组**

```text
                    Ret高 / 有反应             Ret低 / 反应不足
小细胞              慢性失血恢复期等           IDA、铁利用 / Hb合成障碍
正细胞              急性失血、溶血             再障、肾性、骨髓抑制 / 占位
大细胞              Ret增多、原位溶血接口       B12 / 叶酸、MDS、肝病等
```

固定算法：

```text
1. Hb是否达到贫血阈值？
2. MCV在哪一格？
3. Ret反应是否匹配？
4. 选择下一组证据：
   小细胞 → 铁代谢 / 慢性失血
   大细胞 → B12 / 叶酸、肝病、MDS、Ret增多
   正细胞 → 溶血 / 失血、肾功能、骨髓
5. 用病史和特异检查确认
```

（边界：这张四格是搜索树，不是“每格只有一个病”。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP06｜一般贫血表现：组织缺氧后，循环用高输出代偿

> **主提示：一般表现5｜心脏3改变｜高排量｜是否可逆｜先分一般vs组织缺铁**

### 1｜共同缺氧表现

- 乏力；
- 头晕；
- 心悸；
- 苍白；
- 活动耐量下降等。

### 2｜循环代偿

```text
Hb / CaO₂下降
→ 组织供氧受限
→ 心率与回心 / 心输出代偿
→ 左心扩大、心尖区收缩期杂音接口
→ 严重时高排量心衰
```

当前 Study认为多数改变在贫血纠正后可恢复。

### 3｜病例阅读边界

一般贫血表现回答“缺氧造成什么”；组织缺铁表现回答“铁依赖酶和上皮营养出了什么问题”。二者可同时存在，但不能互相替代。

**Routing**：CORE｜CONNECTION｜MI-G

## KP07｜IDA病因：慢性失血最重要，再分需求、摄入和吸收

> **主提示：丢失3组｜需求4人群｜吸收3入口｜慢性失血≈IDA｜查病因优先**

### 1｜铁丢失过多

当前 Study最强调：

> **慢性失血是缺铁性贫血最常见、最重要的原因。**

例子：

- 月经过多、ITP、痔、PUD、消化道肿瘤、静脉曲张破裂；
- 反复咯血 / 肺出血；
- PNH、冷抗体溶血、机械性血红蛋白尿等导致铁随尿丢失接口。

### 2｜摄入不足或需求增加

- 婴幼儿；
- 青少年；
- 孕妇；
- 哺乳期。

### 3｜吸收障碍

- A型胃炎；
- 胃大部切除术后；
- 长期腹泻 / IBD等。

胃酸可帮助食物铁保持溶解和还原方向，但当前 Study同时强调：

> 人体铁的重要来源是衰老 RBC回收；遇到 IDA仍要优先排查慢性失血，不能看到胃病就自动把全部病因归为吸收障碍。

**Routing**：CORE｜CONNECTION｜MI-G

## KP08｜铁的四种身份：吸二、运三、用二、储三

> **主提示：吸/运/用/储4价态｜运输载体｜储存2形式2位置｜回收主来源**

### 1｜价态与任务

| 任务 | 铁价态｜当前 Study |
|---|---|
| 肠道吸收 | Fe²⁺ |
| 血中运输 | Fe³⁺ |
| 合成Hb等利用 | Fe²⁺ |
| 铁蛋白 / 含铁血黄素储存 | Fe³⁺ |

口诀方向：

```text
吸二
运三
用二
储三
```

### 2｜运输与储存

- 运输：Fe³⁺与转铁蛋白结合，形成血清铁运输体系；
- 储存：铁蛋白、含铁血黄素，主要位于单核—巨噬系统，也有血清铁蛋白读数。

（易混：血清铁 SI是运输铁；血清铁蛋白 SF是储存铁指标，二者不是一个“铁”。）

### 3｜循环回收

衰老 RBC被巨噬细胞清除后，铁可回收再利用。慢性失血会把铁真正带出体外，因此长期最容易掏空仓库。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP09｜组织缺铁：不是单纯缺氧，而是铁依赖组织和酶也失去功能

> **主提示：精神2｜发育2｜免疫2｜外胚叶5｜舌｜Plummer-Vinson｜一般贫血区别**

当前 Study按四组组织缺铁表现组织：

### 1｜精神 / 行为

- 烦躁易怒；
- 异食癖。

### 2｜发育

- 儿童智力低下；
- 生长发育迟缓。

### 3｜体力 / 免疫接口

- 体力和耐力下降；
- 易感染。

### 4｜黏膜与外胚叶营养障碍

- 匙状 / 勺状 / 反甲；
- 皮肤干燥；
- 毛发干枯、易脱落；
- 口腔炎、口角炎；
- 舌乳头萎缩、镜面 / 光滑舌；
- Plummer–Vinson综合征：吞咽困难。

舌象边界：

- 缺铁可见镜面 / 光滑舌；
- 巨幼可见牛肉舌，也可见镜面 / 光滑舌；
- 不能只凭一个舌象定病。

吞咽困难边界：

- 进行性：食管癌、外压、GERD狭窄等；
- 间歇性：贲门失弛缓、GERD、Plummer–Vinson等；
- 癔球症：有异物感但无真正吞咽障碍。

完整消化疾病已在 D9–D11后续 owner，本处只保留贫血识别接口。

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G｜MI-D

## KP10｜IDA三阶段：先空仓库，再缺功能铁，最后Hb才下降

> **主提示：阶段3｜仓库3指标｜功能铁2↓6↑｜末期4指标｜最敏感/最可靠**

### Stage 1｜贮存铁耗尽

当前 Study：

- 血清铁蛋白 `SF <12 μg/L`：**最敏感**；
- 骨髓小粒可染铁 / 细胞外铁消失：**最可靠**；
- 铁粒幼红细胞 `<15%`：不是储存铁本身，但属于耗尽证据之一。

此时可尚无 Hb下降。

### Stage 2｜红细胞内铁缺乏

下降：

- 血清铁 SI；
- 转铁蛋白饱和度 TS。

升高：

- 未结合铁的转铁蛋白 TF；
- 总铁结合力 TIBC；
- 可溶性转铁蛋白受体 sTfR；
- 锌原卟啉 ZPP；
- 游离原卟啉 FEP；
- FEP / Hb。

理解：

```text
货少
→ 血清铁↓
→ 转铁蛋白空车↑
→ TIBC↑
→ 饱和度↓
→ 卟啉缺Fe²⁺不能成血红素
→ FEP / ZPP↑
```

### Stage 3｜缺铁性贫血

- Hb↓；
- `MCV <80 fL`；
- `MCH <27 pg`；
- `MCHC <32% / 320 g/L`；
- 涂片：RBC小、中央淡染区扩大；
- RBC正常或↓；WBC多正常；Plt多正常或↑，严重时三系都可受影响。

> 缺铁从“库存”到“功能铁”再到“成品Hb”，所以 SF最先下降，Hb最后下降；治疗后则 Ret先回应，仓库最后补满。

**Routing**：CORE｜CONNECTION｜VISUAL_ONLY｜MI-G｜MI-D

## KP11｜IDA治疗与反应：病因治疗最根本，Ret最先告诉你补铁有效

> **主提示：根本1｜是否输血｜口服/有机｜促吸收2/抑制3｜Ret5–10d｜Hb2周/2月｜停铁4–6月**

### 1｜先处理病因

- 胃肠道失血：反复隐血、影像 / 内镜接口；
- 月经过多：寻找妇科原因；
- 其它长期丢铁来源：针对病因处理。

只补铁、不止血，仓库仍会继续漏。

### 2｜补充方式｜当前 Study

- 一般不需要输血；
- 必要时输浓缩红细胞；
- 首选有机铁；
- 首选口服铁，注射铁保留给口服效果不佳等接口。

促吸收：

- Vit C；
- 稀盐酸接口。

抑制吸收：

- 谷类；
- 乳类；
- 茶。

（特殊：伴消化性溃疡时不应机械与稀盐酸同服。）

### 3｜反应时间轴

```text
补铁
→ Ret最先升高，5–10天达高峰
→ Hb约2周开始升高
→ 约2个月恢复正常
→ Hb正常后仍继续4–6个月
→ 待铁蛋白 / 仓库恢复后停药
```

这解释了“服铁1周 Hb没升、但Ret已升”并不等于治疗失败。

**Routing**：CORE｜RECOGNITION｜MI-G｜MI-D

## KP12｜四类小细胞贫血铁谱：缺铁、慢性病、铁粒幼、地贫

> **主提示：SI/TS/SF/TIBC/髓内/髓外6轴｜IDA饥渴｜ACD锁铁｜铁粒幼堆铁｜地贫Hb链**

| 指标 | IDA | 慢性病贫血 ACD | 铁粒幼细胞性贫血 | 地中海贫血 |
|---|---|---|---|---|
| 血清铁 SI | ↓ | ↓ | ↑ | ↑ |
| 转铁蛋白饱和度 TS | ↓ | ↓ | ↑ | ↑ |
| 血清铁蛋白 SF | ↓ | ↑ | ↑ | ↑ |
| TIBC | ↑ | ↓ | 正常 / 不低 | 正常或↓ |
| 骨髓细胞内铁 | ↓ | ↓ | ↑，环形铁粒幼细胞>15% | ↑ |
| 骨髓细胞外铁 | ↓ | ↑ | ↑ | ↑ |

### 1｜IDA：真缺铁

```text
仓库空 + 运输货少
→ SI / TS / SF↓
→ 肝代偿增加转铁蛋白
→ TIBC↑
→ 骨髓内外铁都↓
```

### 2｜ACD：有铁但被锁住

```text
慢性炎症
→ 铁调素↑
→ 肠吸收↓ + 巨噬细胞放铁↓
→ 血清铁低
→ 铁蛋白 / 骨髓外储存铁高
```

### 3｜铁粒幼：利用失败

铁不缺，但不能正确用于血红素合成，铁堆在幼红细胞线粒体周围，环形铁粒幼细胞增加。

### 4｜地贫：珠蛋白链问题

铁可正常或增多，核心断点不是缺铁，而是珠蛋白生成障碍。完整地贫 / 溶血模型归 H5。

（易混：慢性病贫血不等于慢性失血；前者是炎症锁铁，后者是真正把铁带出体外。）

## KP14｜巨幼机制：DNA合成慢，胞核停在幼稚状态，胞浆继续成熟

> **主提示：B12/叶酸→FH4/一碳｜核苷酸/DNA｜分裂慢｜核幼浆老｜大细胞/原位溶血**

### 1｜共同机制最低链

```text
叶酸 / Vit B12缺乏
→ 有效四氢叶酸 / 一碳单位利用受限
→ 核苷酸与DNA合成障碍
→ 幼红细胞分裂减慢
→ 胞核成熟落后于胞浆
→ 核幼浆老
→ 大细胞 / 大椭圆红细胞
```

完整甲基转移、一碳单位形态、嘌呤 / dTMP通路归 M8–M9；当前只保留足以解释细胞形态的主链。

### 2｜为什么可以出现原位溶血

成熟失败的异常幼红细胞可在骨髓内被破坏：

```text
无效造血
→ 骨髓内原位溶血
→ UCB接口
→ Ret可出现复杂方向
```

所以巨幼贫并非简单“骨髓完全不活跃”；它可表现为骨髓想造、但成品大量失败。

### 3｜为什么是“大细胞”

细胞分裂次数减少而胞浆继续生长，形成体积增大的细胞；外周典型形态为大椭圆形 RBC。

## KP15｜B12吸收Recall：胃释放—R蛋白—胰换手—IF—终末回肠

> **主提示：胃2步｜R蛋白｜胰1步｜IF｜回肠受体｜4故障入口｜胃≠吸收地**

> **动作身份：Recall D4。** 本 Block不重新完整讲营养吸收，只把吸收链用于巨幼贫病因定位。

```text
食物蛋白-B12
→ 胃酸 / 胃蛋白酶释放B12

→ 到十二指肠，胰蛋白酶降解R蛋白
```

1. 胃酸 / 食物释放阶段失败；
2. 壁细胞或内因子缺乏；
3. 胰蛋白酶不足，不能从R蛋白换手；
4. 终末回肠病变或切除。

A型胃炎、胃大部切除可同时影响胃酸和内因子；当前巨幼主轴更重视内因子—B12吸收失败。

## KP18｜最终病例算法：Hb → MCV → Ret → 特异证据 → 病因位置
