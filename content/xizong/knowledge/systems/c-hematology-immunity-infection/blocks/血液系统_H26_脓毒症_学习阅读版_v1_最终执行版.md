# 1｜第一轮主链

```text
局部 / 器官感染未被控制
→ 病原、毒素与宿主反应进入全身
→ 体温、WBC和全身状态出现高或低极端
→ 血压 / 灌注下降，或器官功能恶化
→ 三条线同时推进
   A 病原线：培养 + 静脉抗菌
   B 感染源线：引流 / 清创 / 解除原发灶
   C 循环线：休克时补充血容量并调用B12
→ 复评是否仍有未控制病灶或进行性器官损害
```

最小六问：

```text
感染灶｜体温｜WBC｜血压/灌注｜病原线索｜源控制是否完成
```

# 2｜总 Framework

<!-- kianos:framework id="hematology-h26-framework-main" -->

## 2.1 不是“高热 + WBC高”才算严重感染

```text
宿主仍有强反应
→ 寒战、高热、WBC显著升高

宿主反应失衡 / G−方向
→ 低体温、WBC减少、低血压
→ 三低并不排除感染，反而提示危险
```

## 2.2 三条治疗线不能互相替代

```text
静脉抗菌药
→ 控制可被药物到达的病原

处理原发感染灶
→ 移除脓腔、坏死、导管或持续污染源

休克容量支持
→ 先恢复有效循环与组织灌注
```

只完成其中一条，剩余故障仍会持续推动全身失控。

## KP01｜局部感染升级脓毒症：感染证据 + 全身失控 / 器官威胁，而不是只看发热

> **主提示：局部灶｜全身4信号｜高低双向｜器官威胁｜三线并行**

## KP02｜高与低都可：高热 / WBC高不专属，低温 / WBC低也不排除感染

> **主提示：温度2向｜WBC2向｜类白｜最危险误判｜看什么替代单指标**

### Detailed Expansion｜快速核对

```text
高热 + WBC↑
→ 可见于脓毒症，但不是其专属

低体温 + WBC↓
→ 仍可见于严重感染，不能因“没高热”而否定
```

病例要把单一指标放回组合：感染灶、全身状态、血压 / 灌注、器官功能和病原提示。

<!-- kianos:kp id="hematology-h26-kp03" -->
## KP03｜G−杆菌三低与冷休克：血压低、体温低、WBC低

> **主提示：三低｜冷休克｜发生时相2特征｜高热能否排除｜调用B12哪条**

### Detailed Expansion｜快速核对

当前 Study对 G−杆菌方向的高频提示：

- 多见；
- 可有“三低”：血压低、体温低、WBC低；
- 易出现冷休克；
- 感染性休克可发生较早、持续较长。

高热或 WBC高并不能反向排除 G−感染；“三低”是概率较高的特殊表现，不是机械必备条件。

一旦低血压 / 低灌注，立即调用循环 B12的休克判断，而不是停在“是什么菌”。

**Routing**：CORE｜SPECIAL｜CONNECTION｜MI-G

## KP04｜病原提示四分：G−三低，金葡迁徙脓肿，厌氧坏死恶臭，真菌眼部栓塞征

> **主提示：G−3低｜金葡4表现｜厌氧3｜真菌2眼征｜只是提示还是确诊**

### Detailed Expansion｜快速核对

| 方向 | 当前 Study提示 |
|---|---|
| G−杆菌 | 三低、冷休克；休克早且久 |
| 金葡菌 | 寒战高热、皮疹、心肌炎、迁徙 / 转移性脓肿 |
| 厌氧菌 | 常与需氧菌混合；坏死明显、易脓肿；恶臭 |
| 真菌 | 结膜瘀斑、视网膜灶性絮样斑等栓塞表现 |

这些是识别线索，不能替代培养，也不能据此自行建立完整抗菌方案。

## KP05｜培养取样：寒战发热时血培养；局部灶取脓液 / 穿刺液；导管感染取导管内样本

> **主提示：血培养时机｜局部2样本｜导管1例｜为什么多部位｜先采还是先拖药**

### Detailed Expansion｜快速核对

当前 Study检查路径：

1. **血培养**：在寒战、发热时进行；
2. **局部感染源**：脓液或穿刺液培养；
3. **导管相关感染**：可从导管内采样送检，如肠外营养中心静脉导管相关感染。

培养用于把“全身反应”追溯到病原与感染源。当前 Source没有给出完整采血组数、部位或抗菌前后算法；不得自行补写。

**Routing**：CORE｜RECOGNITION｜BOUNDARY｜MI-G

## KP07｜治疗前两线：1小时内静脉抗菌 + 处理原发感染灶

> **主提示：时限1｜给药途径｜两线2｜抗菌为何不替源控｜复评什么**

### Detailed Expansion｜快速核对

当前 Lecture给出的核心治疗：

```text
1小时内静脉使用抗生素
+
处理原发感染灶
```

这两件事必须并行：

- 抗菌药针对病原；
- 源控制处理脓腔、坏死、导管、梗阻或持续污染。

若抗菌后仍恶化，不能只机械换药，还要重新问“感染源是否真正清除”。

（边界：具体经验性方案、剂量、降阶梯和疗程不在当前 Source。）

## KP08｜休克第三线：抗菌 / 源控制同时补充血容量，完整血流动力学回B12

> **主提示：休克时加1线｜补什么｜不能等哪2事｜B12四故障｜器官出口3**

### Detailed Expansion｜快速核对

当前 Study：脓毒症患者若发生休克，应在抗菌和处理原发灶的同时补充血容量。

```text
感染控制线继续
+
循环复苏线立即启动
```

循环 B12负责：容量、泵、阻力、阻塞和灌注目标。H26不重复完整液体、升压药或监测参数。

病例出现呼吸衰竭、AKI或 DIC线索时，分别调用呼吸、泌尿与循环 / 血液已学模型；这些是同一全身失控的器官出口，不是 H26另造三套疾病正文。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

<!-- kianos:kp id="hematology-h26-kp09" -->
## KP09｜脓毒症最终算法：灶—全身—灌注—培养—抗菌—源控—复苏

> **主提示：7步｜高低双向｜4病原提示｜3条并行｜复评失败原因3**

### Detailed Expansion｜快速核对

```text
疑似感染
→ 1. 找局部 / 器官感染灶
→ 2. 看全身异常：高热或低温、WBC↑或↓、全身不适
→ 3. 查血压 / 灌注与器官功能
→ 4. 寒战发热时血培养 + 局部脓液 / 穿刺液 / 导管采样
→ 5. 1小时内静脉抗菌
→ 6. 同时处理原发感染灶
→ 7. 有休克同时补充血容量并调用B12
→ 复评：病原是否覆盖？源是否清除？灌注是否恢复？
```

这条链的核心不是背“脓毒症表现名单”，而是把感染学与循环任务拆成可以同时执行的三条线。

**Routing**：CORE｜RECOGNITION｜CONNECTION｜MI-G
