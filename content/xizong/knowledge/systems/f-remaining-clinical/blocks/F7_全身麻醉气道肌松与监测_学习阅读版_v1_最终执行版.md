# F7｜全身麻醉、气道、肌松与监测
## 患者“不动”不等于没有痛觉；患者“睡着”也不等于气道、通气和循环安全

> **中心问题**：全身麻醉为什么必须把催眠 / 遗忘、镇痛、反射抑制、肌松和生命支持拆开；不同药物各自负责哪一层；为什么肌松药只能使骨骼肌麻痹，却不能证明患者没有意识或疼痛？
>
> **Primary Study**：`27外科精编版【带导图】.pdf` SUR27-U36，PDF P267–P268《麻醉前准备、全身麻醉与肌松药》；旧跟课页码仅保留 provenance。  
> **Primary Outline**：外科 U056 前10个题目身份，**10 / 10**。  
> **本 Block 身份**：这里建立全麻的“目标—药物—气道—循环”分层。F5术前风险语言可复用，但不是进入本 Block 的硬门槛；缺失时只做局部 reactivation。F8 后续可继续复用这里的麻醉功能分层。

# 3｜KP Active Recall

<!-- kianos:kp id="final-f07-kp01" -->
## KP01｜全麻六层：药物目标与生命支持必须拆开

> **主提示：4麻醉目标｜2生命支持｜肌松≠2件｜安全底线**

### Detailed Expansion｜快速核对

System Guide把全麻拆成：

```text
催眠 / 遗忘
+ 镇痛
+ 反射抑制
+ 肌松
+ 气道 / 通气
+ 循环支持与监测
```

其中肌松只让骨骼肌不能收缩；它本身**没有麻醉作用**，不能提供催眠和镇痛。患者不动，既可能是麻醉充分，也可能只是被肌松药麻痹。

因此，判断麻醉是否安全，不能只看“有没有体动”，还要分别判断意识、疼痛、气道、通气和循环。

**Routing**：CORE｜BOUNDARY｜MI-G

## KP02｜麻醉前代谢门槛：血糖、尿糖和尿酮

## KP04｜全麻气道梗阻：最常见入口问题是什么，怎样识别？

> **主提示：梗阻最常1｜插管女20–22｜男22–24｜先处理哪层**

### Detailed Expansion｜快速核对

当前Study：

- 全麻时呼吸道梗阻最常见原因：**舌后坠**；
- 气管导管尖至门齿距离：女性 `20–22 cm`，男性 `22–24 cm`。

这两点共同说明：全麻诱导后，意识和咽喉保护性反射下降，气道管理必须独立于“药物是否已经起效”判断。

`20—22—24` 是MI-D数字，但“舌后坠先威胁气道”属于MI-G。

**Routing**：CORE｜DECISION｜MI-G｜MI-D

<!-- kianos:kp id="final-f07-kp05" -->
## KP05｜吸入麻醉药的血 / 气分配系数怎样影响起效与可控性？

> **主提示：** 血气分配｜平衡速度｜中枢浓度可控性｜比较方向

> **主提示：系数代表什么｜越小→可控性方向｜呼吸抑制→CO₂早期6**

### Detailed Expansion｜快速核对

血 / 气分配系数表示药物在血液中的溶解度。当前Study：

```text
血 / 气分配系数越小
→ 药物在中枢神经系统内的浓度越容易控制
```

若呼吸中枢受抑、CO₂蓄积，当前Study列出的早期表现包括：

- 呼吸加深加快；
- 血压升高；
- 心率加快；
- 肌紧张增加；
- 面色潮红；
- 甚至发绀。

这里的“早期兴奋样表现”来自CO₂蓄积和应激 / 反射方向，不应误判为通气安全。

**Routing**：CORE｜MECHANISM｜CONFUSABLE｜MI-G

<!-- kianos:kp id="final-f07-kp08" -->
## KP08｜肌松药提供了什么，又明确不提供什么？

> **主提示：** 骨骼肌｜意识｜镇痛｜反射｜气道支持

> **主提示：有1作用｜无2作用｜必须与哪2层配合｜错判风险**

### Detailed Expansion｜快速核对

当前Study明确：肌松药**无麻醉作用，仅能使骨骼肌麻痹**。

```text
肌肉不能动
≠ 没有意识
≠ 没有疼痛
```

所以临床目标必须分层：肌松药负责运动执行器，催眠 / 镇痛药负责意识与痛觉，气道和通气支持负责生命功能。

这一点也是N4神经肌接头知识在麻醉中的直接Apply。

**Routing**：CORE｜BOUNDARY｜CONNECTION｜MI-G

<!-- kianos:kp id="final-f07-kp09" -->
## KP09｜非去极化肌松：N2怎样受影响，逆转思路是什么？

> **主提示：** N2占位/激活｜神经肌接头效应｜逆转思路

> **主提示：代表2｜N2机制1｜是否先肌颤｜新斯的明｜维库特殊1**

### Detailed Expansion｜快速核对

当前Study的竞争性 / 非去极化肌松药：

- 筒箭毒碱；
- 维库溴铵。

机制：

```text
与ACh竞争终板膜N2受体
→ 占据受体但不激活阳离子通道
→ 终板不能正常去极化
→ 骨骼肌松弛
```

- 不出现去极化型“先肌纤维收缩”；
- 中毒时可用新斯的明治疗；
- 当前Study：维库溴铵适合心肌缺血。

**Routing**：CORE｜MECHANISM｜MI-G

<!-- kianos:kp id="final-f07-kp10" -->
## KP10｜去极化肌松：N2为何会从激动走向阻滞？

> **主提示：** N2初始作用｜持续去极化｜为何转为阻滞

> **主提示：代表1｜N2激动｜先颤后松｜2升｜新斯的明能否｜K外流链**

### Detailed Expansion｜快速核对

琥珀胆碱属于去极化肌松药：

```text
激动N2受体阳离子通道
→ Na⁺内流、K⁺外流
→ 终板持续去极化
→ 肌松前可见肌纤维收缩 / 肌颤
→ 随后不能被新的ACh正常激动
→ 去极化阻滞与肌松
```

当前Study特殊：

- 可升高眼压，青光眼禁用；
- 可升高血钾，出现肌震颤、心律失常；
- 中毒时**不能**用新斯的明治疗。

（易混：它不是“阻断受体不让开”，而是先激动、持续去极化后形成阻滞。）

**Routing**：CORE｜MECHANISM｜CONFUSABLE｜MI-G

## KP11｜心脏手术三配对：吸入、静脉、肌松各一个

> **主提示：吸入1｜静脉1｜肌松1｜共同场景**

### Detailed Expansion｜快速核对

当前Study小结：适合心脏手术的三类药物分别是：

## KP12｜全麻风险算法：先问当前缺的是哪一层

> **主提示：催眠？镇痛？肌松？｜气道？通气？循环？｜药物≠目标｜监测缺口**

### Detailed Expansion｜快速核对

遇到围麻醉异常，不先问“用了哪种药”，而先定位功能层：

```text
患者是否有意识 / 疼痛？
是否只是肌松不足或残余肌松？
气道是否梗阻？
通气是否不足、CO₂是否蓄积？
循环是否受抑或容量不足？
是否存在药物特殊风险：高钾、眼压、血压变化？
```

当前Study支持上述最低风险框架，但没有完整现代监测、困难气道、苏醒与拔管清单。因此在第一轮中：

- 能分层判断问题；
- 能识别当前Lecture高频药物配对；
- 不自行生成专科算法。

**Routing**：CORE｜DECISION｜BOUNDARY｜MI-G

# 4｜高密度比较

## 4.1 吸入 vs 静脉 vs 肌松

| 轴 | 吸入麻醉药 | 静脉麻醉药 | 肌松药 |
|---|---|---|---|
| 当前主要作用层 | 全麻维持 / 麻醉作用 | 诱导、镇静 / 麻醉 | 骨骼肌运动执行器 |
| 能否单独证明无痛 | 不能仅凭药名推断 | 不能仅凭“睡着”推断 | **不能** |
| 生命风险接口 | 呼吸抑制、血流动力学 | 呼吸 / 循环抑制或交感兴奋 | 呼吸肌麻痹、残余阻滞、高钾等 |
| 代表 | 氧化亚氮、地氟烷、七氟烷 | 依托咪酯、丙泊酚、氯胺酮等 | 筒箭毒碱、维库溴铵、琥珀胆碱 |

## 4.2 非去极化 vs 去极化肌松

| 轴 | 非去极化 | 去极化 |
|---|---|---|
| 代表 | 筒箭毒碱、维库溴铵 | 琥珀胆碱 |
| N2作用 | 竞争占位，不激活 | 激动并持续去极化 |
| 肌松前肌颤 | 无典型先肌颤 | 可有 |

# 5｜Memory Routing

## 5.1 MI-G

1. 全麻不是单一“睡着”，而是催眠、镇痛、反射抑制、肌松和生命支持协作；
2. 肌松药不提供催眠和镇痛；
3. 全麻气道梗阻最常见原因是舌后坠；
4. 血 / 气分配系数越小，中枢浓度越容易控制；
5. 丙泊酚抑制呼吸和心血管；
6. 氯胺酮镇痛强、兴奋交感，并有三压升高 / 幻觉风险；
7. 非去极化与去极化肌松机制不同；
8. 琥珀胆碱可肌颤、高钾、眼压升高；
9. 新斯的明可用于非去极化中毒，不能用于琥珀胆碱中毒；
10. 气道、通气、循环安全优先于表面“麻醉看起来够深”。
