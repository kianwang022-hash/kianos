# F5｜围术期术前评估与优化
## 术前不是把所有指标“修到完美”，而是判断手术能否等、哪些风险可逆、哪些失代偿必须先处理

> **FIRST PASS 固定流程**  
> `Framework → 外科 Lecture / 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **中心问题**：面对需要手术的患者，怎样先按急诊、限期、择期决定可等待时间，再审查心肺肝肾、营养、感染、糖代谢、血压、凝血和用药，完成“不延误必要手术，也不带着可纠正高风险进入手术室”的平衡？
>
> **Primary Study**：`外科学讲义_AI阅读版.md`，书页 P211，对应 27 跟课 PDF P262。  
> **Primary Outline**：外科 U054 术前 Q1–Q10，**10 / 10**。

# 1｜Framework｜术前评估的第一问题不是“异常有多少”，而是“手术能等多久”

```text
疾病是否立即威胁生命 / 器官？
├─ 急诊：边复苏边手术，不能等所有指标完美
├─ 限期：不能无限拖延，但可完成必要分期与优化
└─ 择期：先纠正可逆风险，再在最佳条件手术
```

然后按同一风险链审查：

```text
器官储备
心 / 肺 / 肝 / 肾 / 神经
        ↓
代谢与修复基础
营养 / 血糖 / 电解质 / 贫血 / 凝血 / 感染
        ↓
药物与误吸风险
降压药 / 降糖药 / 胰岛素 / NSAIDs / 抗血小板
+ 禁食禁饮 / 胃肠准备 / 备皮
        ↓
形成决策
立即手术 / 简短优化后手术 / 暂缓择期手术
```

### 三条贯穿轴

1. **紧急度**：等待本身会不会造成更大伤害？
2. **可逆性**：哪项处理能在有限时间内实质降低风险？
3. **储备**：肝肾、心肺和修复能力能否承受麻醉、失血与手术应激？

### 一句话恢复

> **F5先定急诊/限期/择期，再抓“活动性失代偿、误吸、出血、感染与修复失败”五类风险；急诊不等完美，择期不带着可纠正的高风险进入手术室。**

## KP01｜急诊、限期、择期手术：区分依据是什么，各自为什么能或不能等？

> **主提示：** 时间敏感性｜进展风险｜等待空间｜优化窗口

> **主提示：3类｜时间容忍度｜急诊4例｜限期1类｜择期4例**

### Detailed Expansion

| 类型 | 当前 Study 角色 | 例子 |
|---|---|---|
| 急诊手术 | 延误会迅速危及生命或器官 | 嵌顿/绞窄疝、急性消化道穿孔、急性完全性肠梗阻、大血管破裂 |
| 限期手术 | 可短时准备，但不能无限等待 | 恶性肿瘤等 |
| 择期手术 | 可在充分评估和优化后安排 | 良性肿瘤、单纯疝、慢性阑尾炎、胆囊结石等 |

判断不是死背病名，而是问：**等待会不会使死亡、缺血、穿孔、梗阻或肿瘤进展风险显著增加？**

## KP02｜术前总决策：紧急度×器官储备×可逆风险

> **主提示：3轴｜急诊怎么做｜择期怎么做｜5高危层**

### Detailed Expansion

```text
手术是否紧急？
→ 器官是否处于失代偿？
→ 营养/感染/贫血/凝血/代谢风险能否快速纠正？
→ 药物和禁食是否已处理？
→ 决定立即、短时优化或暂缓
```

五个高价值风险层：

1. 气道、呼吸与循环不稳定；
2. 严重肝肾功能失代偿；
3. 活动性感染；
4. 贫血、血小板或凝血障碍；
5. 营养不良、高血糖及长期免疫抑制导致的修复失败。

（边界：风险存在不等于一律不能手术；必须放回紧急度。）

**Routing**：CORE + INTEGRATION + MI-G

## KP03｜戒烟酒与脑卒中：当前 Study 的等待/优化时间怎样重建？

> **主提示：** 戒烟｜戒酒｜脑卒中｜当前Study时间｜不扩现代指南

> **主提示：烟酒4周｜卒中≥2周/最好6周｜目的3｜急诊边界**

### Detailed Expansion

当前 Study：

- 术前戒烟戒酒 **4周**；
- 脑卒中后手术推迟至少 **2周**，最好 **6周**。

这些时间用于择期/限期风险优化，旨在降低呼吸、循环和神经并发症。若手术本身是急诊救命，不能机械套用等待窗口。

**Routing**：SPECIAL + BOUNDARY + MI-D

## KP07｜糖尿病术前：饮食、口服药、长效药与胰岛素分别怎样处理？

> **主提示：** 饮食控制｜口服药｜长效药｜胰岛素｜当前Study时间

> **主提示：饮食型｜口服药｜长效2–3d｜胰岛素晨｜血糖5.6–11.2｜为什么不求正常**

### Detailed Expansion

当前 Study：

- 仅饮食控制：不需特殊准备；
- 口服降糖药：继续至术前 1 天；
- 长效降糖药：术前 2–3 天停；
- 平时用胰岛素：手术日晨停用；
- 维持血糖约 5.6–11.2 mmol/L 的轻度升高状态。

**27 外科精编 Source Precision（PDF P267）**：术前血糖控制目标一般以**空腹血糖 <8.3 mmol/L**为宜；尿糖可以阳性，但**尿酮应阴性**；酮症酸中毒属于择期手术禁忌证。该条是术前考试 Precision，不替代围术期 5.6–11.2 mmol/L 的总体风险控制范围。

Lecture强调不要求强行降至完全正常，以免低血糖。

（边界：具体药物半衰期、SGLT2i等现代分类和胰岛素输注方案不在当前 Source。）

## KP08｜高血压术前：用药与精确阈值怎样处理，Source 冲突在哪里？

> **主提示：** 是否继续用药｜戒断风险｜精确阈值冲突｜不得静默统一

> **主提示：药不停｜防1｜正文140/90｜题目160/100｜当前怎么答**

### Detailed Expansion

稳定原则：

- 继续降压药；
- 避免停药后的戒断 / 反跳；
- 不要求仅因紧张导致的瞬时升高就机械停止手术。

数字冲突：

- 正文写 BP≤140/90 mmHg；
- 附题接受 160/100 mmHg 以下不予特殊处理，另一个病例约150–160/85–95也可手术。

因此：

```text
机制题：优先答继续用药、防戒断、综合稳定性
精确阈值题：按题目所在Source口径与原页核对
```

不得用外部指南静默选一个数字覆盖另一个。

**Routing**：CORE + SOURCE_CONFLICT + MI-G

## KP12｜术前 Go / Delay：怎样按紧急度与可逆风险走完决策？

> **主提示：** 紧急度｜失代偿｜误吸｜出血｜感染｜修复｜哪些可等

> **主提示：先3类｜5风险｜急诊动作｜择期动作｜最后确认4**

### Detailed Expansion

```text
A. 定急诊 / 限期 / 择期
B. 查气道、呼吸、循环及活动性失代偿
C. 查肝肾储备和透析/过渡需求
D. 查感染、营养、血糖、贫血、血小板/凝血
E. 查禁食、胃肠准备、降糖/降压/抗血小板药物
F. 决定：边复苏边手术 / 简短优化 / 暂缓择期
```

典型错误：

- 急诊病人等待所有化验“正常”；
- 择期病人带着可纠正的严重感染或失代偿进入手术；
- 为了“正常血糖”造成低血糖；
- 随意停降压药造成反跳；
- 忽视停药本身的血栓风险边界，而把数字当成现实通用处方。
