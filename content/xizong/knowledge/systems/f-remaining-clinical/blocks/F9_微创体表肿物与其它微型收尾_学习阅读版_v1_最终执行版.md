<!-- kianos:kp id="final-f09-kp12" -->
## KP12｜皮样囊肿：眉梢 / 骨缝 + 哑铃状

> **主提示：胚胎身份｜好发2｜形态1｜与皮脂腺3轴比较**

### Detailed Expansion｜快速核对

当前Study：

- 皮样囊肿属于单胚层囊性畸胎瘤；
- 好发于眉梢和颅骨骨缝；
- 可呈哑铃状。

与皮脂腺囊肿比较：

| 轴 | 皮脂腺囊肿 | 皮样囊肿 |
|---|---|---|
| 好发 | 头面、背部 | 眉梢、颅骨骨缝 |
| 表面 | 小黑点 | 无此典型入口 |
| 内容 / 形态 | 豆渣物 | 哑铃状、胚胎发育来源 |

**Routing**：MICRO_PRIMARY｜CONFUSABLE｜MI-G

<!-- kianos:kp id="final-f09-kp13" -->
## KP13｜体表肿物六轴：先定位来源，再看恶性警报

> **主提示：年龄｜部位｜层次/来源｜颜色表面｜质地活动｜生长转移**

### Detailed Expansion｜快速核对

面对陌生体表肿物：

```text
1. 年龄与部位
2. 皮肤层次 / 组织来源
3. 色素与表面开口
4. 囊性还是实性、软还是硬
5. 是否活动、是否固定
6. 是否快速增大、破溃、出血、疼痛 / 瘙痒、转移
```

由此分流：

- 老年头面、慢性局部浸润、鼠咬状 → 基底细胞癌；
- 不对称 / 不规则 / 颜色不均 / >6 mm → 黑色素瘤；
- 基底层痣 + 摩擦区动态变化 → 交界痣警报；
- 软、分叶、黄色 → 脂肪瘤；
- 小黑点、豆渣物 → 皮脂腺囊肿；
- 眉梢 / 骨缝、哑铃状 → 皮样囊肿。

**Routing**：CORE｜DISCRIMINATION｜MI-G
