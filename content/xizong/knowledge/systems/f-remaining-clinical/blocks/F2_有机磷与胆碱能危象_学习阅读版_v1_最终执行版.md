## KP01｜有机磷胆碱能危象的根故障是什么，怎样扩散到不同受体层？

> **主提示：** 酶｜递质｜受体层｜不可逆接口｜从根故障推表现

### Detailed Expansion

当前内科 Study：

- 有机磷主要蓄积于肝脏；
- 抑制胆碱酯酶。

这里可调用 M1 的不可逆酶抑制语言：有机磷与胆碱酯酶活性中心相关 Ser 羟基结合，形成磷酰化胆碱酯酶，使有效酶活性下降；若该语言当前不稳，只做支撑本推导所需的局部 reactivation。

于是：

```text
AChE活性↓
→ ACh水解↓
→ 突触 / 接头处 ACh 积聚
→ M、N1、N2和中枢胆碱能部位持续受刺激
```

所以后面的所有表现，本质不是几十个孤立症状，而是**同一递质的多个受体 / 解剖位置同时失控**。

**Routing**：CORE｜MECHANISM｜CONNECTION｜MI-G

## KP02｜M样表现怎样从受体所在器官与效应方向推导？

> **主提示：** 心｜眼｜胃肠｜括约肌｜腺体｜肺｜共同受体逻辑

### Detailed Expansion

当前 Study 的 M 样表现：

| 部位 | 表现 | 受体 / 效应方向 |
|---|---|---|
| 心脏 | 心率下降 | M 受体负性心脏效应 |
| 眼 | 视物模糊 | 睫状肌接口 |
| 瞳孔 | 针尖样瞳孔 | 瞳孔括约肌收缩 |
| 胃肠 | 腹痛、腹泻 | 平滑肌活动增强 |
| 泌尿 / 消化 | 大小便失禁 | 括约肌 / 自主效应接口 |
| 腺体 | 大汗、流泪、流涎 | 分泌增加 |
| 支气管 | 咳嗽、气促、呼吸困难 | 分泌增加 + 平滑肌收缩 |
| 肺部 | 湿啰音；严重时肺水肿 | 分泌 / 液体增加语境 |

低摩擦识别：

```text
M = “湿 + 慢 + 缩 + 动”
湿：汗、泪、涎、气道分泌
慢：心率下降
缩：瞳孔缩小、支气管平滑肌收缩
动：胃肠平滑肌活动增强
```

但考试最终仍以 Source 的具体症状为准，不用口诀替代细节。

**Routing**：CORE｜RECOGNITION｜MI-G

<!-- kianos:kp id="final-f02-kp03" -->
## KP03｜N1 与 N2 分别位于哪里，为什么会产生不同表现？

> **主提示：** N1｜N2｜NMJ｜神经节/肾上腺｜呼吸肌｜循环方向

### Detailed Expansion

### N2｜神经肌接头

当前 Study：

```text
ACh持续刺激N2
→ 肌纤维颤动、肌强直性痉挛
→ 进一步出现肌无力、瘫痪
→ 呼吸肌麻痹
→ 呼吸衰竭
```

这和 N4 的终板模型直接闭环：N2 是 NMJ 的阳离子通道型受体；过度持续刺激并不意味着“肌肉会一直更有力”，而会走向传递失败和麻痹。

### N1｜自主神经节 / 肾上腺髓质

当前 Lecture：

- 自主神经节 N1；
- 肾上腺髓质 N1；
- 交感通路 / 儿茶酚胺释放增加；
- 可见血压增高、心律失常。

因此，“有机磷既心率下降又可血压升高 / 心律失常”不是矛盾：

```text
M心脏效应 → 心率下降
N1/交感-肾上腺髓质 → CA↑ → 血压↑ / 心律失常
```

不同受体层同时存在，题目看哪一层占主导。

**Routing**：CORE｜CONFUSABLE｜MECHANISM｜MI-G

## KP04｜呼吸危险：哪几条机制会叠加到同一个终点？

> **主提示：** 气道分泌｜平滑肌｜NMJ｜中枢接口｜为什么优先呼吸

### Detailed Expansion

有机磷的呼吸危险不是一条链，而是多条链同时汇聚：

```text
M：气道腺体分泌↑
        +
M：支气管平滑肌收缩
        +
N2：呼吸肌麻痹
        +
重症CNS：意识 / 呼吸中枢受损接口
        ↓
通气与氧合迅速失败
→ 呼吸衰竭
```

这解释了为什么治疗不是只盯着“胆碱酯酶数值”，而必须同时做：

- 迅速去除毒物；
- 紧急复苏；
- 对抗 M 样气道效应；
- 处理 N 样肌肉问题；
- 持续监测意识和呼吸。

**Routing**：CORE｜DECISION｜CONNECTION｜MI-G

## KP05｜轻、中、重：分度真正依赖哪一层受体/中枢参与？

> **主提示：** M层｜N层｜中枢/呼吸层｜分度阈值｜湿啰音陷阱

### Detailed Expansion

当前 Study 分度：

| 程度 | 临床表现 | 胆碱酯酶活力 |
|---|---|---|
| 轻度 | 仅 M 样症状 | 50%–70% |
| 中度 | M + N 样，如肌纤维颤动 | 30%–50% |
| 重度 | M + N，并伴脑水肿、抽搐、昏迷、呼吸肌麻痹、肺水肿等严重表现之一 | <30% |

### 高频陷阱｜“湿啰音”不自动等于重度

Lecture明确区分：

- **肺部湿啰音**：可只是 M 样的腺体分泌增加；
- **双肺满布湿啰音 / 明确肺水肿**：进入重度危险语境。

因此不能看到“湿啰音”三个字就机械判重度，要看 Source 是否明确是肺水肿 / 满布湿啰音，以及是否有严重中枢或呼吸肌表现。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

## KP06｜去污：有机磷治疗第一件事仍是“迅速清除毒物 + 紧急复苏”

> **主提示：** 总关键2｜皮肤4步｜眼冲4液｜口服3液｜敌百虫/对硫磷禁

### Detailed Expansion

当前 Lecture 把治疗关键写得很清楚：

> **迅速清除毒物和紧急复苏。**

### 1｜皮肤 / 毛发

- 迅速脱去污染衣物；
- 肥皂水清洗污染皮肤；
- 清洗毛发；
- 清洗指甲等可能残留部位。

### 2｜眼部

Source列：

- 清水；
- 生理盐水；
- 2% 碳酸氢钠；
- 3% 硼酸。

### 3｜口服洗胃

当前 Study列：

- 清水；
- 2% 碳酸氢钠；
- 高锰酸钾溶液。

但有两组特异禁忌：

```text
敌百虫 + 碱性环境
→ 可转为毒性更强的敌敌畏
→ 禁用2% NaHCO₃

对硫磷 + 强氧化环境
→ 可转为对氧磷
→ 禁用高锰酸钾
```

Lecture attached 2023 题进一步固定：可用 2% NaHCO₃ 的选项为对硫磷、敌敌畏、乐果，排除敌百虫。

## KP07｜四类药的任务分工：外周M、中枢、酶/N、选择性抗胆碱

> **主提示：** 外周M2药｜中枢1药｜复能剂1类｜新型1药｜任务不能互换

### Detailed Expansion

当前 Study 的药物分层：

| 药物 / 类别 | 当前 Study 主要任务 |
|---|---|
| 阿托品、山莨菪碱 | 外周性抗胆碱，缓解外周 M 样症状 |
| 东莨菪碱 | 中枢性抗胆碱，缓解中枢症状 |
| 胆碱酯酶复活药，如氯解磷定 | 恢复 ChE 活性，缓解外周 N 样症状 |
| 盐酸戊乙奎醚 | 新型选择性抗胆碱药；Study称作用较强、持续较久，对心率 / 心肌耗氧影响较小 |

最重要的是理解“任务不同”：

```text
阿托品
→ 阻断M受体效应
→ 并没有直接把被抑制的AChE恢复

复能剂
→ 处理酶 / N样接口
→ 不能代替阿托品快速控制外周M样分泌和支气管效应
```

因此二者不是“选一个更强的”，而是**打不同故障层**。

**Routing**：CORE｜DECISION｜CONFUSABLE｜MI-G

## KP08｜氯解磷定：复能剂也有毒性，过量反而可压回胆碱酯酶

> **主提示：** 主要作用2｜ADR4｜过量2危｜为什么不能只猛加

### Detailed Expansion

当前 Lecture：氯解磷定等胆碱酯酶复活药可：

- 恢复胆碱酯酶活性；
- 缓解外周 N 样症状。

Study列不良反应：

- 眩晕；
- 复视；
- 视力模糊；
- 血压升高。

用量过大可：

- 引起癫痫；
- 反而抑制胆碱酯酶活性。

所以“酶活性低 → 复能剂越多越好”是错误推理。治疗需要观察毒物控制、受体症状和药物自身毒性。

**Routing**：SPECIAL｜BOUNDARY｜MI-D

## KP09｜阿托品化、原中毒未控制、阿托品中毒：怎样从多轴证据区分？

> **主提示：** 湿/干｜瞳孔｜肺部｜心率｜尿潴留｜中枢｜三态对照

### Detailed Expansion

### 1｜原有机磷中毒仍占主导

典型方向：

- 针尖样瞳孔；
- 大汗、流涎；
- 肺部湿啰音 / 分泌；
- 心率偏慢；
- 重症可有中枢异常。

### 2｜阿托品化｜治疗达到有效抗M剂量的 Study 终点

当前 Lecture列：

- 瞳孔扩大；
- 皮肤干燥无汗；
- 口干；
- 肺啰音消失；
- 颜面潮红；
- 心率升至约 90–100 次/分。

核心不是追求某一个数字，而是：

```text
过度分泌被压下去
→ 肺部更干净
→ 外周M样症状明显逆转
```

### 3｜阿托品中毒

当前可稳定读取的高价值警报：

- 瞳孔**明显**扩大；
- 尿潴留；
- 明显中枢毒性，如抽搐、昏迷、烦躁不安、神志模糊等。

所以：

> **阿托品化是治疗目标；阿托品中毒是治疗过量。**

不能把“越干、瞳孔越大”当成越成功。

**Routing**：CORE｜CONFUSABLE｜DECISION｜MI-G

## KP11｜吗啡中毒：怎样从瞳孔、呼吸、意识识别并确定解毒方向？

> **主提示：** 瞳孔｜呼吸｜循环｜意识｜特异拮抗方向

### Detailed Expansion

当前 Lecture 的吗啡中毒表现：

- 针尖样瞳孔；
- 呼吸减慢；
- 可见潮式呼吸；
- 可见 Biot / 间停呼吸；
- 血压明显下降；
- 昏迷。

解救：**纳洛酮**。

这组串联用于比较：

```text
有机磷：缩瞳 + 大量分泌 + N样肌颤 / 肌麻痹
吗啡：缩瞳 + 中枢呼吸抑制 + 昏迷
```

# 3｜三张必须一眼分开的表

## 3.1 M vs N1 vs N2 vs CNS

| 层 | 核心位置 | 当前 Study 代表表现 | 主要治疗接口 |
|---|---|---|---|
| M | 腺体、平滑肌、心脏 | 流涎、多汗、缩瞳、腹泻、支气管分泌 / 痉挛、HR↓ | 阿托品 / 山莨菪碱 |
| N1 | 自主神经节、肾上腺髓质 | BP↑、心律失常 | 复能 + 支持接口 |
| N2 | NMJ | 肌颤 / 强直 → 无力 / 瘫痪 → 呼吸肌麻痹 | 胆碱酯酶复能剂 |
| CNS | 中枢胆碱能系统 | 意识障碍、惊厥等重症接口 | 东莨菪碱 / 生命支持接口 |

## 3.2 轻 / 中 / 重

```text
仅M
→ 轻

M + N
→ 中

M + N + 脑水肿 / 抽搐 / 昏迷 / 呼吸肌麻痹 / 肺水肿之一
→ 重
```

## 3.3 原中毒 vs 阿托品化 vs 阿托品中毒

| 轴 | 原有机磷中毒 | 阿托品化 | 阿托品中毒 |
|---|---|---|---|
| 瞳孔 | 针尖样 | 扩大 | 明显扩大 |
| 皮肤 / 分泌 | 汗、泪、涎多 | 干燥、口干 | 过度抗胆碱方向 |
| 肺 | 湿啰音 / 分泌 | 啰音消失 | 不是治疗目标 |
| 心率 | 可下降 | 约90–100/min方向 | 过量抗胆碱方向 |
| 尿 | 可失禁 | — | 尿潴留 |
| CNS | 重症可异常 | 应改善 | 烦躁、神志模糊、抽搐 / 昏迷等明显毒性 |
