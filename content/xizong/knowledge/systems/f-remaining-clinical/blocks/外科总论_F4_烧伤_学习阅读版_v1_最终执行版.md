# 1｜Framework｜烧伤不是“皮肤局部烫伤”，而是屏障—血管—容量—感染的时间化疾病

```text
热损伤
→ 皮肤与血管内皮受损
→ 血管通透性↑
→ 液体、蛋白外渗 + 蒸发丢失
→ 血浆胶体渗透压↓、组织液胶体渗透压↑
→ 水肿 + 有效循环血量↓
→ 低血容量性休克风险
```

与此同时：

```text
皮肤屏障破坏 + 坏死组织
→ 创面污染与细菌繁殖
→ 急性感染 / 感染性休克
→ 清除坏死组织、覆盖创面和系统支持
```

判断顺序固定为：

```text
1. 是否存在吸入性损伤 / 气道水肿风险？
2. 面积多大——全身复苏负荷有多高？
3. 深度多深——能否自行修复，是否留瘢痕 / 需植皮？
4. 严重度是否因休克、吸入性损伤或复合伤被升级？
5. 当前处于渗出休克期、感染期，还是修复期？
6. 动态灌注、尿量、呼吸和创面是否提示治疗不足？
```

### 面积、深度、严重度不要混

| 维度 | 回答的问题 |
|---|---|
| 面积 | 全身液体丢失与复苏负荷有多大 |
| 深度 | 哪一层被毁、痛觉如何、能否再生、是否留瘢痕 |
| 严重度 | 面积 + 深度 + 休克/吸入性损伤/复合伤后的整体分层 |
| 分期 | 当前最主要危险是容量、感染，还是创面修复 |

### 一句话恢复

> **烧伤先保气道，再用面积决定复苏、用深度决定创面命运；前 24–48 小时主要防容量失败，随后防感染和坏死组织持续成为感染源。**

## KP01｜烧伤早期为什么会同时出现明显水肿与有效循环容量下降？

> **主提示：** 内皮/毛细血管｜液体与蛋白分布｜组织间隙｜有效循环容量｜休克

> **主提示：内皮伤｜通透↑｜蛋白/液外渗｜两胶渗方向｜水肿+ECV↓**

### Detailed Expansion

```text
烧伤直接损伤内皮细胞与基底膜
→ 血管通透性↑
→ 液体和蛋白外渗
→ 血浆胶体渗透压↓
→ 组织液胶体渗透压↑
→ 组织水肿
+ 有效循环血量↓
```

这条链解释：

- 创面局部肿胀并不等于血管内容量充足；
- 水肿越明显，患者仍可能处于低容量；
- 补液是烧伤休克期的主治疗，而不是只在创面涂药。

//Recall：四类休克与灌注终点回循环；F4只负责烧伤作为低容量入口。

## KP03｜烧伤面积：成人、儿童和手掌法分别怎样估算？

## KP04｜Ⅰ度与浅Ⅱ度：怎样从损伤层次推导修复能力？

> **主提示：** 损伤层次｜再生基础｜疼痛/水疱｜修复能力

> **主提示：Ⅰ度 vs 浅Ⅱ度｜损伤层次｜创面/水疱｜感觉｜愈合时间｜瘢痕**

### Detailed Expansion

| 轴 | Ⅰ度 | 浅Ⅱ度 |
|---|---|---|
| 层次 | 表皮浅层 | 部分表皮生发层或真皮乳头层 |
| 创面 | 红斑、干燥、无水疱 | 湿润红润、大小不一水疱 |
| 感觉 | 烧灼感，拔毛剧痛 | 疼痛显著、感觉过敏，拔毛痛 |
| 愈合 | <1周 | 10天–2周 |
| 修复 | 完全修复 | 生发层保存，可自行修复 |

Ⅰ度：不进入严重度和补液公式，创面无需特殊处理。浅Ⅱ度水疱皮含残存生发层，可作为生物敷料。

**Routing**：CORE + CONFUSABLE + MI-G

## KP05｜深Ⅱ度与Ⅲ度：怎样从残余结构推导痛觉、瘢痕与植皮需求？

> **主提示：** 残余结构｜痛觉｜创面特征｜瘢痕｜植皮需求

> **主提示：层次2｜红白vs蜡焦｜小疱vs无疱｜迟钝vs无痛｜3–4周vs植皮**

### Detailed Expansion

| 轴 | 深Ⅱ度 | Ⅲ度 |
|---|---|---|
| 层次 | 部分真皮网状层 | 皮肤全层，甚至皮下脂肪、肌肉、骨或内脏 |
| 创面 | 湿润、红白相间，可有小水疱 | 蜡白/焦黄/炭化，树枝状栓塞血管，干燥无水疱 |
| 感觉 | 温度低、痛觉迟钝，拔毛微痛 | 发凉、痛觉消失，拔毛不痛且易拔 |
| 结局 | 3–4周，瘢痕增生 | 需植皮，瘢痕增生 |

深Ⅱ度生发层破坏较多，水疱皮保留会增加感染风险，当前 Study要求去除；Ⅲ度感觉消失不是“损伤轻”，而是神经末梢也被毁。

## KP07｜烧伤时相：容量、感染与修复问题怎样随时间切换？

> **主提示：** 早期容量｜感染期｜修复期｜各期主问题

> **主提示：3期｜2–3h急｜6–8h峰｜24–48h｜感染主死因｜修复目标**

### Detailed Expansion

1. **体液渗出与回吸收期**：伤后 2–3 小时渗出最急剧，6–8 小时达高峰，一般持续 24–48 小时；核心危险是低血容量性休克。
2. **急性感染期**：坏死组织和屏障破坏形成感染基础，感染性休克是主要死因。
3. **创面修复 / 康复期**：创面覆盖、瘢痕和功能恢复成为主问题。

三期不是绝对断开；气道、灌注、感染和创面需持续并行监测，只是主矛盾随时间变化。

## KP08｜烧伤补液：第1/第2个24h怎样按当前 Study 计算与分配？

> **主提示：** 谁计面积｜1.5 ml/kg/%｜+2000 ml 5%G｜晶:胶2:1（广泛深度1:1）｜前8h一半｜第2日晶胶减半｜尿量动态

### Detailed Expansion

27 外科精编原页已核对：

```text
计入面积：Ⅱ度 + Ⅲ度（Ⅰ度不计）
第1个24h补液总量
= Ⅱ+Ⅲ度烧伤面积(%) × 体重(kg) × 1.5 ml
+ 2000 ml 5%葡萄糖液

晶体 : 胶体 = 2 : 1
（原页注：广泛深度烧伤时 1 : 1）

前8h：输入第1个24h总量的一半
后16h：输入另一半

第2个24h：上一日晶胶液减半 + 2000 ml 5%葡萄糖液
```

注意：第二日是**晶胶液部分减半**，不是整个总量机械减半。补液是否有效也不能只看“公式已算完”，仍需动态看灌注、意识、循环、呼吸和尿量。

## KP09｜急性感染期：为什么仅靠抗菌药不够，创面 source control 怎样进入？

> **主提示：** 坏死组织｜感染源｜削/切痂｜植皮｜抗菌药角色

## KP11｜水疱皮：浅Ⅱ与深Ⅱ应怎样处理，依据是什么？

> **主提示：** 浅Ⅱ｜深Ⅱ｜疱皮处理｜组织深度依据

> **主提示：浅Ⅱ为什么留｜大疱怎么做｜深Ⅱ为什么去｜感染轴**

### Detailed Expansion

- 浅Ⅱ度：保留水疱皮；较大水疱可抽去疱液。水疱皮内仍有残存表皮生发层，可作生物敷料。
- 深Ⅱ度：去除水疱皮。生发层破坏更多，保留可能增加感染风险。

不能只用“有无水疱”判断深度，必须结合创面颜色、湿润度、痛觉、温度和拔毛反应。

**Routing**：CORE + CONFUSABLE + MI-G

## KP12｜包扎还是暴露：怎样由部位、深度和敷料要求决定？

> **主提示：内层1+药2｜外层1｜超缘3–5｜暴露2类｜消毒2禁1**

### Detailed Expansion

包扎：

- 内层油质纱布，防止粘连；
- 当前 Study可加碘伏、磺胺嘧啶银；
- 外层吸水敷料吸收渗液；
- 包扎范围超出创缘 3–5 cm。

暴露疗法：

- 会阴部烧伤；
- Ⅲ度创面等不易包扎或包扎增加感染风险的部位。

创面消毒：苯扎溴铵或氯己定；不能用酒精。

## KP13｜吸入性损伤：怎样从环境、部位与呼吸线索识别？

> **主提示：** 环境｜面颈口鼻｜炭屑/声嘶｜呼吸症状｜气道优先

> **主提示：环境1｜部位3｜症状7｜检查金1｜气道动作1｜大声呼叫？**

### Detailed Expansion

高风险线索：

- 密闭环境；
- 面、颈、前胸，尤其口鼻烧伤；
- 刺激性咳嗽；
- 痰中炭屑；
- 声嘶；
- 吞咽困难或疼痛；
- 呼吸困难、哮鸣；
- 火灾中大声呼叫可增加吸入机会。

最直接、准确检查：纤维支气管镜，可见气道黏膜炎症反应。

当前 Study治疗入口：**及早气管切开**。核心不是等低氧明显后再处理，而是预判气道水肿可能进展。

**Routing**：CORE + RECOGNITION + BOUNDARY + MI-G

## KP14｜烧伤病例：怎样按优先级串起评估、复苏与创面决策？

> **主提示：** 关键决策节点｜先后优先级｜何时进入复苏｜何时进入创面处理

> **主提示：6步｜气道最先｜面积管什么｜深度管什么｜三期切换｜动态终点**

### Detailed Expansion

```text
第一步：吸入性损伤 / 气道危险？
第二步：面积估算，判断全身复苏负荷
第三步：深度判断，预测自行愈合、瘢痕或植皮
第四步：严重度整合，休克/吸入/复合伤可升级
第五步：判断当前时相——容量期、感染期、修复期
第六步：并行推进复苏、创面处理、感染控制与器官监测
```

典型错误：

- 只看创面，漏掉吸入性损伤；
- 把痛觉消失当作轻伤；
- 面积和深度互相替代；
- 公式算完就不再看尿量与灌注；
- 抗菌药代替坏死组织处理。

**Routing**：CORE + INTEGRATION + MI-G
