# 1｜Framework｜术后判断靠“生命层级 + 时间轴 + 空间证据”

```text
手术结束
→ 苏醒与气道保护
→ 呼吸 / 循环 / 出血监测
→ 根据术式与麻醉选择体位
→ 管道、胃肠、排尿与活动逐步恢复
→ 识别发热、肺部、尿潴留、内出血等并发症
→ 观察切口愈合、积血、血清肿、感染和裂开
```

## 1.1 三层优先级

### 第一层｜立即生命危险

- 气道梗阻或误吸；
- 呼吸衰竭；
- 循环不稳定；
- 进行性内出血；
- 切口完全裂开伴肠管 / 网膜脱出。

### 第二层｜器官恢复失败

- 肺膨胀不全、感染、肺栓塞；
- 尿潴留；
- 胃肠动力迟迟不恢复；
- 术后感染。

### 第三层｜切口与管道

- 切口分类和愈合等级；
- 积血、血清肿、感染、裂开；
- 引流管何时拔除。

## 1.2 三个定位轴

```text
时间：术后多久出现？
空间：胸腔、腹腔、尿路、切口还是引流管？
证据：生命体征、引流量/性质、发热、尿量、切口形态如何？
```

### 一句话恢复

> **F6先排气道—呼吸—循环—出血，再用时间和空间定位恢复偏离；切口积血最常见，咳嗽/腹胀后淡红液要警惕裂开，完全裂开应立即无菌覆盖并进入紧急处理。**

## KP03｜拆线时间：不同部位怎样重建当前 Study 时间梯度？

> **主提示：** 头颈｜下腹会阴｜躯干｜四肢｜减张｜时间梯度

> **主提示：5部位数字｜张力越大越晚｜伤口异常时不机械拆**

### Detailed Expansion

当前 Study：

- 头、面、颈：4–5 天；
- 下腹、会阴：6–7 天；
- 躯干其他部位：7–9 天；
- 四肢：10–12 天；
- 减张缝合：14 天。

规律：血供较好、张力较小者较早；张力较大、活动部位和减张缝合较晚。若感染、营养不良、长期糖皮质激素或腹压持续升高，不能只按日历机械拆线。

## KP12｜切口积血 vs 血清肿：怎样从内容物、来源与处理区分？

> **主提示：** 内容物｜来源｜体征｜腹股沟处理边界

> **主提示：最常1｜积血3征｜颈部危险｜血清肿机制｜处理2｜腹股沟禁1**

### Detailed Expansion

**切口积血**：切口并发症中最常见；表现为隆起、肿胀、血液外渗。甲状腺术后颈部积血可压迫气管，形成窒息危险。

**切口血清肿**：多因术中切断较多淋巴管，常见乳房、腹股沟区手术。当前 Study：皮下血清肿可空针抽吸 + 敷料压迫，但**腹股沟区禁止空针抽吸**。

（易混：积血偏出血证据；血清肿偏淋巴回流损伤。两者都可肿胀，但引流物性质不同。）

**Routing**：CORE + CONFUSABLE + BOUNDARY + MI-G

## KP14｜切口裂开：怎样识别并区分部分/完全裂开后的处理？

> **主提示：** 诱因｜淡红液｜部分/完全｜覆盖｜减张缝合

> **主提示：诱因4｜预警1｜完全定义2｜立即2步｜预防4｜禁动作1**

### Detailed Expansion

风险 / 诱因：

- 营养不良；
- 术后剧烈咳嗽；
- 腹胀、腹内压升高；
- 长期糖皮质激素 / 免疫抑制；
- 糖尿病、感染等修复不良背景。

预警：咳嗽或腹胀后切口流出淡红色液体。
