## 先阻断污染，再处理失活组织；是否缝合取决于时间、污染和组织条件

# 1｜Framework｜所有无菌与创伤题都先问“污染是否仍在继续，组织是否仍有生命”

本 Block 有两条相连但不能混为一谈的主线。

```text
手术无菌主线
灭菌 / 消毒选择
→ 建立皮肤与器械边界
→ 维持无菌区
→ 污染一旦发生立即纠正
→ 降低医源性接种
```

```text
开放伤主线
先判生命危险
→ 止血并阻断继续污染
→ 判断开放程度、异物与组织活力
→ 冲洗 / 清创 / 去除失活组织
→ 判断时间与污染负荷
→ 一期缝合 or 暂不一期缝合
→ 监测感染与愈合
```

病例顺序固定为：

```text
1. 是否心跳呼吸骤停、窒息、张力性气胸或休克？
2. 是否仍有四肢大出血或持续污染？
3. 伤口是闭合还是开放；贯通还是盲管？
4. 有无异物、失活组织、深部结构损伤？
5. 时间窗、部位血供和污染程度是否允许一期缝合？
6. 哪些感染风险需要调用 H20 / H25–H27，而不是在本 Block 重讲？
```

### 一句话恢复

> **无菌术守住的是“不要把病原体带进去”；开放伤处理解决的是“已经被污染后，先救命止血，再把异物和失活组织拿掉，最后按时间与污染决定是否关闭伤口”。**

## KP01｜无菌术的三层目标：物品、手术区、操作过程

> **主提示：3层｜灭菌vs消毒｜边界破坏→？｜最终目标1**

### Detailed Expansion

无菌术不是只背“哪种器械怎么泡”，而是三层风险控制：

```text
物品层：器械 / 敷料 / 导管是否达到灭菌或消毒要求
空间层：皮肤、无菌区和手术台边界是否正确建立
过程层：穿衣、戴手套、传递与操作中是否持续保持边界
```

最终目标是减少手术过程中病原体被带入组织。任何一层失效，都应立即纠正，而不是等手术结束再补救。

（易混：无菌术是预防污染；感染灶的切开引流属于 H25 的源控制，不是同一个动作。）

**Routing**：CORE + CONNECTION + MI-G

## KP02｜灭菌 vs 消毒：芽孢是分界线

> **主提示：定义2｜芽孢｜对象差别｜创面药3只消毒**

### Detailed Expansion

- **灭菌**：杀灭包括芽孢在内的全部微生物；用于需要达到无菌要求的器械与物品。
- **消毒**：杀灭致病微生物，但不保证杀灭芽孢；用于皮肤、创面及特定环境。

当前 Lecture 特别提醒：苯扎溴铵、氯己定及相关创面消毒药属于**消毒**，不能因为名称熟悉就升级为灭菌手段。

（易混：消毒强度不等于灭菌；“泡过药液”也不自动意味着已经灭菌，必须看药物、浓度、时间和对象。）

**Routing**：CORE + CONFUSABLE + MI-G

## KP03｜灭菌方法—器械匹配：蒸、低温气体、煮、泡、干热、辐射

> **主提示：6法｜最常1+2周｜不耐高温1组｜煮1h｜泡10h｜干热3类**

### Detailed Expansion

| 方法 | 当前 Study 对象 / 特点 |
|---|---|
| 高压蒸汽 | 最常用；适合大多数物品；有效期 2 周 |
| 化学气体：环氧乙烷、过氧化氢低温等离子体、低温甲醛蒸汽 | 不耐高温的仪器、导管、内镜 |
| 煮沸 1 小时 | 耐高温的金属器械、玻璃、橡胶 |
| 戊二醛等化学药液浸泡 10 小时 | 锐利器械、内镜 |
| 干热 / 火烧 | 玻璃、粉剂、油剂 |
| 电离辐射 | 当前 Lecture 列为灭菌方式之一 |

选择逻辑先看：

```text
是否耐热 / 耐湿
→ 是否锐利、空腔或精密
→ 方法能否到达目标部位
→ 是否达到所需时间
```

## KP04｜手术区皮肤消毒与无菌区：方向、15 cm、肩腰腋中线

> **主提示：范围15｜普通方向｜感染/肛门反向｜无菌区4边界**

### Detailed Expansion

皮肤消毒：

- 切口周围约 **15 cm**；
- 普通手术区由中心向四周；
- 感染区或肛门区由外周向中心，避免把污染向外扩散。

当前 Study 的无菌区域包括：

- 肩部以下；
- 腰部以上；
- 身体前面至腋中线；
- 双侧手臂；
- 手术台面以上。

这些是空间门槛，必须回原图建立位置感；文字只用于恢复边界。

**Routing**：CORE + VISUAL_ONLY + MI-G

## KP05｜无菌边界一旦破坏：立即重新洗手、消毒并更换手套

### Detailed Expansion

触发：

## KP07｜创伤分类与第一优先级：皮肤是否完整不是最先处理的问题

> **主提示：闭/开｜贯/盲｜生命危险4｜先后顺序**

### Detailed Expansion

分类：

- 皮肤或黏膜完整：闭合伤；
- 破坏：开放伤；
- 开放伤可为贯通伤（有出入口）或盲管伤（有入口、无出口）。

但患者到达时第一问题不是分类，而是是否存在：

- 心跳呼吸骤停；
- 窒息；
- 张力性气胸；
- 休克。

```text
生命危险处理
→ 控制大出血
→ 再完成伤口与深部结构评估
```

//Recall：张力性气胸完整模型归呼吸 R10；休克归循环 B12；F3只拥有优先级。

**Routing**：CORE + CONNECTION + RECOGNITION + MI-G

## KP08｜止血带：只在加压包扎无效的四肢大出血使用

> **主提示：适应1｜禁材2｜每1h松1–2min｜总≤4h｜风险1**

### Detailed Expansion

当前 Study：

- 适用于加压包扎不能止血的**四肢大出血**；
- 禁用细绳、电线，因接触面积小、压强大，易损伤神经和软组织；
- 每隔 1 小时放松 1–2 分钟；
- 使用不超过 4 小时。

本质是用暂时阻断血流换取救治时间，但必须警惕肢体缺血坏死。

（边界：止血带不是一般小伤口的第一选择，也不代替后续血管损伤评估。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="remaining-f03-kp09" -->
## KP09｜清创：不是“把伤口洗干净”，而是恢复可存活组织边界

> **主提示：目标4｜创缘1–2mm｜异物/失活｜血管神经保护｜后续决定1**

### Detailed Expansion

清创要解决：

```text
去除异物与明显污染
+ 切除失活组织
+ 判断深部结构损伤
+ 尽量保留有活力组织
→ 为引流、修复和缝合创造条件
```

当前 Lecture 明确：切除创缘皮肤约 **1–2 mm**。

清创不能机械扩大：过度切除会增加组织缺损；清除不足又会保留感染基础。血管、神经、肌腱和骨组织的复杂修复属于对应创伤 / 骨科模型，F3只建立共同清创入口。

**Routing**：CORE + BOUNDARY + CONNECTION + MI-G

## KP10｜一期缝合时间窗：普通6–8h，头面12h，头皮24h

> **主提示：普通6–8｜头面12｜头皮24｜为什么部位不同｜满足条件后动作**

### Detailed Expansion

当前 Study：

- 普通开放伤：伤后 6–8 小时内；
- 头面部：12 小时内；
- 头皮：24 小时内；

在清创充分、污染和组织条件允许时，可清创后一期缝合。头面及头皮时间更宽，与其血供较丰富有关。

（易混：F6 的“Ⅱ类可能污染切口”把 6 小时内清创缝合列为一个切口分类例；F3解决的是开放伤是否一期关闭，F6解决术后切口分类与并发症。）

**Routing**：CORE + CONFUSABLE + MI-G + MI-D

<!-- kianos:kp id="remaining-f03-kp11" -->
## KP11｜哪些伤口不一期缝合：时间、火器、渗液、污染、感染风险

> **主提示：不一期5类｜先清创仍不关｜后续看什么3｜延期/二期边界**

### Detailed Expansion

当前 Lecture明确列出：

- 超过当前时间窗；
- 火器伤；
- 渗液多；
- 污染重；
- 感染概率大。

处理逻辑：

```text
清创并控制污染
→ 不机械一期缝合
→ 保持引流与观察
→ 根据感染、组织活力和修复情况进入后续处理
```

这里必须避免一个常见错误：**清创完成 ≠ 必须立即关闭伤口**。

（边界：延期一期、二期闭合的完整定义和具体时间当前 Source 不足，见 F3-SG01。）
