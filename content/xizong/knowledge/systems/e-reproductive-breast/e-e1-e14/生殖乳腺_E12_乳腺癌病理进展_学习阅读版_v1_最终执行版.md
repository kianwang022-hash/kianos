# E12｜乳腺癌病理进展
## 从正常导管 / 小叶与肌上皮，走到异型增生、原位癌、浸润与扩散

> **中心问题**：乳腺上皮怎样从普通增生进入异型增生和原位癌；真正改变疾病身份的屏障是什么；导管与小叶来源、非特殊型与特殊型、酒窝征与橘皮样变、淋巴与血道扩散怎样被组织成一条连续病理链？
>
> **Primary ownership**：本 Block 唯一 Primary 为乳腺癌的器官特异病理身份、危险背景与分类。TNM、分子亚型的临床身份和检查证据归 E13；手术、放疗、化疗、内分泌与 HER2 靶向归 E14。
>
> **分类边界**：病理学与外科学当前 Study 使用的乳腺癌分类口径并不完全相同。本文件分层保存，不强行合并，也不以外部指南静默替换。

# 2｜总 Framework

<!-- kianos:framework id="reproductive-e12-framework-main" -->

```text
A｜正常结构
小叶 / 腺泡分泌上皮
→ 乳管输送
→ 肌上皮位于上皮外围
→ 基底膜包围上皮单元

B｜增生与风险背景
雌激素暴露时间延长
+ 肥胖 / 增生性乳腺病变
+ BRCA缺陷
→ 上皮克隆异常风险增加

普通型导管增生
→ 细胞呈流水样分布

异型 / 非典型导管增生
→ 细胞分布均匀、形态单一
→ 当前Study列为癌前病变

C｜原位癌
恶性上皮仍局限于导管 / 小叶单位
→ 肌上皮 / 基底膜边界仍未被突破

DCIS
├─ 高级别、核分裂多
└─ 中央粉刺样坏死 → 粉刺癌

LCIS
→ 核分裂少
→ 癌变间期长
→ 常双侧、多象限

D｜浸润癌
突破原有边界进入间质
→ 肌上皮缺失成为关键证据
→ 可发生局部牵拉、淋巴和血道扩散

浸润癌非特殊型
→ 最常见
→ 巢状 / 腺样，边界不清，间质纤维多

浸润性小叶癌
→ 单行 / 串珠 / 细索
→ 围绕导管呈靶环
→ 可有特殊转移部位

E｜特殊型与生物学身份
部分特殊型预后较好
→ 小管 / 高分化、髓样伴大量淋巴、黏液、分泌、实性乳头等

预后较差
→ 炎性乳癌最差
→ 浸润性微乳头、富于脂质、高级别化生等

F｜结构受累形成体征
Cooper韧带受侵收缩
→ 酒窝征

真皮内淋巴管阻塞
→ 皮肤水肿
→ 橘皮样变

G｜扩散
淋巴转移最早最常见
→ 首先同侧腋窝淋巴结

血道可早期发生
→ 骨、肺、肝、肾上腺、脑
→ 中线 / 椎旁静脉系统可连接骨转移

H｜受体接口
ER+
→ 当前Study：预后较好，内分泌治疗入口

HER2+
→ 当前Study：预后较差，靶向治疗入口
```

### 一句话恢复

> **乳腺癌先看“导管 / 小叶”，再看“肌上皮 / 基底膜”，然后才看具体形态、扩散和受体。**

# 3｜KP Active Recall

<!-- kianos:kp id="reproductive-e12-kp01" -->
## KP01｜正常乳腺病理坐标：导管 / 小叶—肌上皮—基底膜

> **主提示：2上皮单位｜外围1层｜屏障1层｜原位/浸润看什么**

### 快速核对

- 小叶 / 腺泡上皮：分泌单元；
- 导管上皮：运输单元；
- 肌上皮：位于导管和腺泡上皮外围；
- 基底膜：限定上皮与间质；
- 原位 / 浸润的核心不是肿块大小，而是这套边界是否突破。

### 详细展开

SR6 已经建立肌上皮的正常射乳功能。E12把同一结构转换为病理证据：

```text
肌上皮 / 基底膜完整
→ 上皮异常仍被圈在原单位内

边界消失 / 突破
→ 进入间质
→ 浸润身份成立
```

**Routing**：CORE｜VISUAL_ONLY｜BOUNDARY｜MI-G

<!-- kianos:kp id="reproductive-e12-kp02" -->
## KP02｜普通型导管增生：流水样分布

> **主提示：分布1词｜细胞是否单一｜风险层级**

### 快速核对

当前 Study：

- 普通型导管增生；
- 增生细胞呈**流水样分布**；
- 不是异型导管增生；
- 不能因“增生”二字直接等同癌。

### 详细展开

“流水样”描述不同细胞在导管内呈流动、杂乱而非单调一致的分布。它是一种形态识别锚，必须回原图确认。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

<!-- kianos:kp id="reproductive-e12-kp03" -->
## KP03｜异型导管增生：均匀 + 单一，进入癌前风险层

> **主提示：分布1｜形态1｜与普通型差｜当前Study身份**

### 快速核对

当前 Study：

- 细胞分布较均匀；
- 细胞呈单一形态；
- 与普通型流水样分布不同；
- 导管上皮非典型 / 异型增生列为癌前病变。

### 详细展开

癌前病变表示风险提高，不等于必然癌变。这里的关键是从多样、流水样的普通增生，转为单调、均一的异常克隆方向。

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="reproductive-e12-kp04" -->
## KP04｜雌激素暴露链：先看“暴露时间”，不是背孤立危险因素

> **主提示：早1晚1｜生育2｜肥胖｜增生病变｜方向**

### 快速核对

当前 Study 的风险方向：

- 月经初潮早；
- 绝经晚；
- 晚育或不育；
- 肥胖；
- 乳腺增生性病变，尤其异型导管增生。

共同轴：

> **雌激素暴露时间延长或外周来源增加。**

### 详细展开

易错方向：

```text
月经早 + 绝经晚
→ 生殖期延长
→ 雌激素暴露时间增加

不是：
月经晚 + 绝经早
```

肥胖与绝经后外周脂肪芳香化接口在 SR4 已完整学习，这里只 Apply。

**Routing**：CORE｜CONNECTION｜CONFUSABLE｜MI-G

<!-- kianos:kp id="reproductive-e12-kp05" -->
## KP05｜遗传、肌上皮与象限：三个高价值定位点

> **主提示：基因1｜缺失细胞1｜象限1**

### 快速核对

- 遗传风险接口：**BRCA** 缺陷；
- 浸润癌与硬化性腺病鉴别：浸润癌腺腔周围**无肌上皮细胞**；
- 乳腺癌好发：**外上象限**。

### 详细展开

这三个信息分别属于：

```text
上游风险
→ BRCA

组织屏障
→ 肌上皮

器官空间
→ 外上象限
```

不能互相替代。BRCA不能证明当前肿块已浸润；外上象限也不能代替病理确诊。

**Routing**：CORE｜RECOGNITION｜VISUAL_ONLY｜MI-G

<!-- kianos:kp id="reproductive-e12-kp06" -->
## KP06｜病理分类 vs 外科分类：同一肿瘤保留两套职责

> **主提示：病理先分2类｜外科分类差异｜为什么不合并**

### 快速核对

### 病理学主分类

```text
非浸润癌
→ DCIS + LCIS

浸润癌
→ 非特殊型 + 特殊型
```

### 外科学当前分类

- 原位癌：LCIS、DCIS；DCIS下含粉刺型、非粉刺型，并列 Paget 入口；
- 浸润癌：按外科 Study 分为非特殊癌与特殊癌，名单与病理教材并非完全一致。

### 详细展开

病理分类回答“组织来源、屏障和形态”；外科分类服务于临床识别和决策。两者不能因名称相似就强制扁平化。

**Routing**：BOUNDARY｜CONFUSABLE｜MI-G

<!-- kianos:kp id="reproductive-e12-kp07" -->
## KP07｜原位癌：恶性细胞已成立，但尚未进入间质

> **主提示：癌细胞有无｜屏障破没破｜两大原位**

### 快速核对

```text
恶性上皮细胞
+ 仍局限于导管 / 小叶单位
+ 肌上皮 / 基底膜边界未突破
= 原位癌
```

两类：

- 导管原位癌 DCIS；
- 小叶原位癌 LCIS。

### 详细展开

“原位”不是“还没癌变”，而是癌细胞已经形成，只是尚未跨入间质。它和异型增生的差别是恶性程度；和浸润癌的差别是屏障。

**Routing**：CORE｜BOUNDARY｜MI-G

---

<!-- kianos:kp id="reproductive-e12-kp08" -->
## KP08｜DCIS与粉刺癌：中央坏死是视觉锚

> **主提示：来源｜高级别2征｜坏死外观｜属于哪类**

### 快速核对

当前 Study：

- DCIS / 导管内癌；
- 高级别时恶性程度高、核分裂象多；
- 若中央出现坏死，形似粉刺；
- 称**粉刺癌**；
- 仍属于导管原位癌 / 非浸润癌。

### 详细展开

粉刺样坏死并不自动意味着已经浸润。身份判断仍回到导管外围屏障是否被突破。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="reproductive-e12-kp09" -->
## KP09｜LCIS：核分裂少、间期长、双侧多象限

> **主提示：核分裂｜间期｜单双侧｜象限**

### 快速核对

当前 Study 的 LCIS：

- 核分裂象少见；
- 癌变间期较长；
- 常累及双侧乳房；
- 可累及多个象限。

### 详细展开

LCIS 的识别不是靠明显粉刺坏死，而靠“小叶来源 + 多中心 / 双侧倾向 + 较长间期”的组合。

**Routing**：CORE｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="reproductive-e12-kp10" -->
## KP10｜浸润癌非特殊型：最常见的浸润癌

> **主提示：最常1｜旧名｜排列｜边界｜间质**

### 快速核对

当前 Study：

- 浸润癌非特殊型最常见；
- 旧称浸润性导管癌；
- 癌细胞可呈巢状等结构；
- 边界不清；
- 间质纤维组织多，质地可硬。

### 详细展开

“非特殊型”不是缺少恶性证据，而是没有进入某个特征鲜明的特殊组织学类型。病例常通过无痛硬肿块进入，最终仍需病理证实。

**Routing**：CORE｜RECOGNITION｜MI-G

---

<!-- kianos:kp id="reproductive-e12-kp11" -->
## KP11｜浸润性小叶癌：单行排列 + 靶环

> **主提示：来源前序｜细胞一致｜排列2种｜围绕谁**

### 快速核对

当前 Study：

- 可由 LCIS 突破基底膜而来；
- 癌细胞大小较一致；
- 核分裂象少见；
- **单行 / 串珠 / 细索状排列**；
- 围绕正常导管呈**靶环 / 眼眶样**。

### 详细展开

这组形态必须成套识别。单行排列不是所有腺癌的共同表现，而是当前小叶癌最有价值的组织学锚。

**Routing**：CORE｜VISUAL_ONLY｜MI-G

## KP12｜小叶癌特殊转移：出现“异常地点”也要先认原发谱系

> **主提示：5个特殊部位｜为什么先判来源**

### 快速核对

当前 Study 列举浸润性小叶癌可转移至：

- 脑脊液；
- 浆膜表面；
- 卵巢；
- 子宫；
- 骨髓。

### 详细展开

看到卵巢、子宫或浆膜病灶时，不能只按当地原发肿瘤解释。病理形态若提示小叶癌，应保留乳腺原发的转移可能。

## KP13｜预后较好的特殊型：先记“共同是特殊形态”，再记名单

> **主提示：小管/高分化｜髓样条件｜黏液｜分泌｜实性乳头**

### 快速核对

当前病理 Study 的较好预后类型包括：

- 小管癌 / 高分化腺癌；
- **有大量淋巴细胞浸润**的髓样癌；
- 黏液癌；
- 分泌性癌；
- 实性乳头状癌等。

### 详细展开

关键边界：

```text
髓样癌
+ 大量淋巴细胞浸润
→ 当前Study列入较好预后

“髓样癌”三个字单独出现
→ 不能删掉淋巴细胞条件
```

**Routing**：SPECIAL｜CONFUSABLE｜MI-D

<!-- kianos:kp id="reproductive-e12-kp14" -->
## KP14｜髓样癌原图：边界清、癌细胞大、间质少、淋巴细胞多

> **主提示：边界｜癌细胞｜间质｜淋巴**

### 快速核对

当前 Study 对髓样癌的形态锚：

- 巢状等结构；
- 边界较清楚；
- 癌细胞大；
- 间质较少；
- 大量淋巴细胞浸润。

### 详细展开

这组形态与“预后较好”连在一起。若缺少大量淋巴细胞背景，不应机械套用该预后身份。

**Routing**：VISUAL_ONLY｜SPECIAL｜MI-G / MI-D

<!-- kianos:kp id="reproductive-e12-kp15" -->
## KP15｜预后较差与炎性乳癌：皮肤红肿可无明显肿块

> **主提示：最差1｜可无肿块｜像炎症｜治疗接口**

### 快速核对

当前 Study：

- 炎性乳癌预后最差；
- 可无明显肿块；
- 主要表现为弥漫性皮肤红肿 / 炎症样改变；
- 当前外科 Source：主要采用化疗、放疗方向。

另列预后较差：

- 浸润性微乳头状癌；
- 富于脂质性癌；
- 高级别化生性癌等。

### 详细展开

E11 已经建立安全分流：

```text
红肿 + 痛 + 寒战高热 + WBC↑ + 痛性淋巴结
→ 急性乳腺炎

红肿但不痛、无典型感染证据、无痛淋巴结
```
