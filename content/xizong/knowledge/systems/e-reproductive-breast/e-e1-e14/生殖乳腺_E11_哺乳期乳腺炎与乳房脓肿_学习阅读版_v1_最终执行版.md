# 1｜Framework｜从正常泌乳到封闭脓腔

<!-- kianos:framework id="reproductive-e11-framework-main" -->

```text
正常：
PRL产乳
+ OT射乳
+ 导管通畅
+ 有效排空
        ↓
哺乳期若排空不足
→ 乳汁淤积
        ↓
细菌入侵
（金葡菌经淋巴管多见）
        ↓
急性乳腺炎
红 + 肿 + 热 + 痛
+ 寒战高热
+ WBC↑
+ 患侧淋巴结痛性肿大
        ↓
治疗同时做两件事
乳汁排空
+ 抗感染
        ↓
若局部形成波动感 / 穿刺抽脓
→ 已进入乳房脓肿
→ 抗生素不能替代源控制
→ 切开引流
        ↓
切口按脓肿空间
表浅 → 放射状
乳晕下 → 乳晕边缘弧形
深部 / 乳房后 → 乳房下缘弧形
        ↓
分隔脓腔需打通
大脓腔可最低位对口引流
```

一句话：

> **淤积是入口，感染是过程，脓腔是必须改变处理方式的空间门槛。**

## KP01｜正常乳腺如何走到感染：先有“排空失败”

<!-- kianos:kp id="reproductive-e11-kp04" -->
## KP04｜治疗第一原则之一：乳汁要排空

> **主提示：为什么排｜停排的后果｜与抗生素并列**

### 快速核对

当前 Study明确强调：

> **排空乳汁。**

原因链：

```text
排空不足
→ 淤积持续
→ 局部感染环境不解除
```

### 详细展开

“抗感染”与“排空”不是二选一。前者处理病原，后者处理促使感染持续的局部功能问题。单纯停止排空会加重乳汁淤积。

**Routing**：CORE｜MECHANISM｜MI-G

## KP05｜哺乳与抗感染：按当前 Study 记，不自行现代化

> **主提示：患侧｜健侧｜严重/乳瘘｜抗菌1｜禁4类**

### 快速核对

当前 Study：

- 患侧停止哺乳；
- 健侧不停止；
- 若感染严重，或脓肿引流后并发乳瘘 → 停止哺乳 + 溴隐亭；
- 抗菌药举例：苯唑西林等；
- 当前 Study 列为禁用：
  1. 四环素类；
  2. 磺胺类；
  3. 喹诺酮类；
  4. 氨基糖苷类。

### 详细展开

这是高风险的 **Source-bound 考试口径**。本文件不使用外部临床指南纠正、替换或扩写，因为当前生产合同要求忠于 Study Source。

## KP06｜什么时候从“乳腺炎”升级为“脓肿模型”

> **主提示：波动｜穿刺｜封闭空间｜下一动作**

### 快速核对

当前 Study：

```text
出现波动感
→ 穿刺抽脓
→ 仍需切开引流
```

### 详细展开

这一步的结构意义是：

```text
弥漫感染
→ 局部液化、形成封闭脓腔
→ 抗菌药不能替代机械排脓
```

P0 的共同语言：脓肿是器官或组织内局限性化脓性炎症；E11只把这条共同语言落到乳房空间。

**Routing**：CORE｜DECISION_GATE｜MI-G

## KP08｜引流不是“开个口”：分隔要打通，大腔要有低位出口

> **主提示：分隔｜手指｜大脓腔｜最低位**

### 快速核对

当前 Study：

- 用手指轻轻分离脓肿分隔；
- 脓腔较大时可在最低部作对口引流。

### 详细展开

源控制的目标是让脓液真正排出。如果多房分隔未打通，即使有切口仍可能排不干净；大腔体需要考虑最低位引流。

**Routing**：TREATMENT_LOGIC｜MI-D

<!-- kianos:kp id="reproductive-e11-kp09" -->
## KP09｜急性乳腺炎 vs 炎性乳癌：红肿不等于感染

> **主提示：年龄方向｜痛？｜寒战高热？｜WBC？｜淋巴结痛？**

### 快速核对

按当前 Study 对比：

| 轴 | 急性乳腺炎 | 炎性乳癌 |
|---|---|---|
| 人群 | 初产妇 / 哺乳期方向 | 中老年方向 |
| 疼痛 | 痛 | 可不痛 |
| 寒战高热 | 常有 | 无典型寒战高热 |
| WBC | 升高 | 不以WBC升高为特征 |
| 淋巴结 | 痛性 | 可无痛性肿大 |
| 肿块 | 炎症区域 | 可无明显肿块 |

### 详细展开

这一 KP 只是**安全分流**：

```text
红肿乳房
≠
自动等于感染
```

一旦证据不支持典型感染，必须进入 E12–E14 的乳腺癌模型，而不是在 E11 硬解释。

**Routing**：CONFUSABLE｜SAFETY_GATE｜MI-G

## KP10｜E11反向算法：淤积—感染—脓腔—源控制

> **主提示：哺乳期｜炎症证据｜排空｜波动｜切口**

### 快速核对

```text
哺乳期红肿疼痛
→ 有无寒战高热 / WBC↑ / 痛性淋巴结？
   ↓
符合急性感染
→ 排空乳汁 + 抗感染
   ↓
有无波动感 / 穿刺脓液？
├─ 无 → 仍在乳腺炎路径
└─ 有 → 乳房脓肿
        → 按空间选切口
        → 打通分隔 / 充分引流

若红肿但不痛、无发热、WBC不高、淋巴结无痛
→ 转 E12–E14 排炎性乳癌
```

### 详细展开

这是 E11 的最终 Framework Reconstruction：病例必须先判断是否进入了“封闭感染空间”，因为这一结构变化会改变治疗方式。

**Routing**：FRAMEWORK_RECONSTRUCTION｜MI-G
