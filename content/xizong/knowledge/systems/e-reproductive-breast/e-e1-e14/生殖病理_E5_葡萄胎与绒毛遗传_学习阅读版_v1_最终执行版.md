>
> **FIRST PASS 固定流程**：`Framework → 病理 Lecture P99–101 + 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **Source boundary**：完整妇产科症状、清宫流程、hCG随访和后续妊娠管理无独立临床 Source，不扩写。p57只按当前 Study 的“完全性阴性、部分性阳性”与亲本来源方向学习；不自行补成完整基因印记课程。

# 1｜Framework｜先看受精来源，再看绒毛长成什么样

```text
正常受精 / 正常胎盘
→ 绒毛有滋养层、间质和功能性血管
→ 胎盘分泌 hCG
        ↓
异常受精与亲本遗传构成
        ↓
绒毛发育异常
        ├─ 间质高度水肿、黏液样变
        ├─ 绒毛增大为透明水泡状
        ├─ 血管消失或仅留无功能毛细血管
        └─ 滋养层细胞异型增生
        ↓
葡萄胎
        ├─ 完全性：全部绒毛受累、父源、无胎儿、p57−
        └─ 部分性：部分绒毛受累、父母双方、可有胎儿、p57+
```

第一轮只抓三条坐标：

| 坐标 | 完全性 | 部分性 |
|---|---|---|
| 绒毛与胎儿 | 全部绒毛水泡状；无胎儿组织 | 部分绒毛水泡状；可有胎儿组织 |
| 遗传来源 | 染色体全部父源 | 染色体来自父母双方 |
| p57 | 无核染色 | 有核染色 |

核型和受精组合随后作为 MI-D 挂回这三条主线。

## KP03｜正常绒毛三层：滋养层—间质—血管

> **讲义定位 →** 病理 Lecture PDF P99–101 + 原图｜**主提示：绒毛3层｜葡萄胎分别坏在哪｜为什么要回原图**

### 快速核对

把绒毛先拆成：

1. 外层滋养层细胞；
2. 绒毛间质；
3. 间质内胎儿毛细血管。

葡萄胎的三个核心病理变化分别落在：

- 滋养层：异型增生；
- 间质：高度水肿、黏液样变性；
- 血管：消失或少量无功能。

### Detailed Expansion

“葡萄状”不是抽象肿瘤名字，而是绒毛这一具体结构发生水泡化。只有先看懂正常绒毛，E6 才能理解：

- 侵袭性葡萄胎为什么仍“有绒毛”；
- 绒癌为什么“无绒毛、无自身间质和血管”。

**Routing**：CORE｜VISUAL_ONLY｜CONNECTION｜MI-G

## KP05｜完全性 vs 部分性：先看全部/部分绒毛，再看胎儿

> **讲义定位 →** 病理 Lecture PDF P101｜Outline U011 葡萄胎 Q3  
> **主提示：全部/部分绒毛｜胎儿有无｜完全2字/部分3字**

### 快速核对

| 项目 | 完全性葡萄胎 | 部分性葡萄胎 |
|---|---|---|
| 水泡状绒毛 | 所有绒毛 | 部分绒毛 |
| 胎儿组织 | 无 | 可有 |
| 倍性大方向 | 二倍体 | 三倍体 |
| 亲本来源 | 全部父源 | 父母双方 |
| p57 | 阴性 | 阳性 |

### Detailed Expansion

这张表的主线是“完全”与“部分”：

- 完全性不只是全部绒毛水泡化，也缺乏胎儿组织；
- 部分性保留部分相对正常的发育，因此可见胎儿组织。

不要先背核型而忘掉病理形态。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

## KP06｜完全性葡萄胎：空卵 + 父源二倍体

> **讲义定位 →** 病理 Lecture PDF P101｜**主提示：空卵｜1精自复制/2精双受精｜46XX主｜父源100%**

### 快速核对

当前 Study 的完全性葡萄胎：

```text
主要：
23X精子 + 无染色体空卵
→ 精子染色体自我复制
→ 46XX

另一路：
两个23X/23Y精子 + 空卵
→ 46XX或46XY
```

结论：

- 二倍体；
- 46XX最常见，也可46XY；
- 染色体全部来自父亲；
- 无胎儿组织；
- p57无核染色。

### Detailed Expansion

完整性葡萄胎中，母亲提供的是**无染色体的空卵**。这条结构解释了为什么：

```text
有妊娠组织背景
但没有母源染色体贡献
→ 无胎儿组织
→ p57方向为阴性
```

具体印记分子机制未在当前 Source 展开。

**Routing**：CORE｜CONFUSABLE｜MI-G / MI-D

```text
正常母源卵参与
+ 额外父源染色体
→ 三倍体
→ 部分绒毛异常
→ 可有胎儿组织
→ p57阳性
```

## KP08｜p57：不单背加减号，要挂回亲本来源

> **讲义定位 →** 病理 Lecture PDF P101｜Outline U011 葡萄胎 Q3  
> **主提示：完全−｜部分+｜各自亲本来源｜不能替代哪两项**

### 快速核对

```text
完全性葡萄胎：
全部父源 → p57核染色阴性

部分性葡萄胎：
父母双方 → p57核染色阳性
```

### Detailed Expansion

p57 是当前 Study 中帮助区分亲本来源的病理标志，但不能替代：

- 绒毛是全部还是部分水泡化；
- 有无胎儿组织；
- 核型与受精来源。

正确方式是把四类证据合起来，而不是看到一个免疫组化结果就孤立作答。

**Routing**：CORE｜RECOGNITION｜BOUNDARY｜MI-G

## KP09｜E5反向算法：绒毛 → 胎儿 → 亲本 → p57

> **主提示：4步｜全部/部分｜胎儿｜父源/双亲｜p57±**

### 快速核对

面对葡萄胎题：

```text
1. 所有绒毛还是部分绒毛水泡化？
2. 有无胎儿组织？
3. 染色体全部父源，还是父母双方？
4. p57核染色阴性还是阳性？
```

### Detailed Expansion

四步若成套一致：

- 全部 + 无胎儿 + 全父源 + p57− → 完全性；
- 部分 + 可有胎儿 + 双亲来源 + p57+ → 部分性。

若题目出现肌层 / 血管侵犯或远处病灶，立即离开 E5，进入 E6 的“侵犯—转移”坐标。
