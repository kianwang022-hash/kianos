# E2｜高危HPV—SIL—宫颈癌
## 从病毒抑癌通路失活，到上皮层次扩大、基底膜突破和扩散

> **中心问题**：高危 HPV 如何把宫颈鳞柱交界处的上皮从挖空细胞 / 异型增生推进到 LSIL、HSIL、原位癌和浸润癌；为什么“累及全层”或“累及腺体”仍可能没有浸润，而真正的身份改变取决于基底膜？
>
> **Primary ownership**：一般 HPV / 尖锐湿疣的感染病理已在 H24；本 Block 首次完整建立 **HPV16/18 → E6/E7 → p53/RB → SIL/CIN → 原位 / 浸润 → 扩散与 Study 分期** 的器官特异 Primary。
>
> **FIRST PASS 固定流程**：`Framework → 病理 Lecture P96–97 + 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **Source boundary**：分级、浸润深度和临床分期严格按当前 Study 口径保存，不用外部 FIGO / 指南静默替换。HPV疫苗、筛查程序、完整妇科肿瘤治疗均 Defer。

# 1｜Framework｜先看上皮层次，再看屏障，最后看范围

```text
鳞柱交界 / 移行带
        ↓
高危HPV持续感染（16 / 18）
        ↓
E6 → p53失活
E7 → RB失活
        ↓
上皮细胞异型与克隆扩张
        ↓
LSIL / CIN I
        ↓
HSIL / CIN II–III
        ↓
可累及全层
但只要基底膜没破
        ↓
仍属上皮内病变 / 原位阶段
        ↓
突破基底膜
        ↓
微小浸润 → 浸润癌
        ↓
直接蔓延 + 淋巴扩散
        ↓
临床分期按扩展范围推进
```

三个必须分开的坐标：

| 坐标 | 问什么 |
|---|---|
| 上皮层次 | 异型细胞占下1/3、下2/3、>2/3或全层？ |
| 屏障 | 表面 / 腺体基底膜有没有被突破？ |
| 范围 | 癌局限宫颈，还是进入盆腔、阴道、盆腔壁、膀胱 / 直肠等？ |

## KP02｜LSIL / HSIL：先看异型细胞占了上皮多少层

> **讲义定位 →** 病理 Lecture PDF P96｜Outline U011 宫颈癌 Q2–Q3  
> **主提示：LSIL=CIN?｜下?｜轻度｜HSIL=CIN?+?｜下? / >?或全层｜病理核分裂在哪**

### 快速核对

| Study分层 | 对应 | 累及范围 | 异型 |
|---|---|---|---|
| LSIL | CIN I | 下 1/3 | 轻度 |
| HSIL | CIN II | 下 2/3 | 中度 |
| HSIL | CIN III | 下 2/3 以上或全层 | 重度 / 原位癌方向 |

- 病理性核分裂象主要见于高级别 / CIN III方向；
- 当前 Study：**LSIL常可自行消退**。

### Detailed Expansion

层次是“上皮内病变有多广”，不是“已经向间质浸润多深”。因此**全层异型**仍可以只是原位阶段，只要基底膜完整。

System Guide把这些数字列入 MI-D：第一轮需要知道层次递进和 LSIL / HSIL 身份，但不要求因数字不熟而停住整条癌变链。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G / MI-D

## KP03｜CIN III累及腺体：走进腺口不等于走进间质

> **讲义定位 →** 病理 Lecture PDF P96｜Outline U011 宫颈癌 Q4  
> **主提示：表面→腺口→腺体｜破没破哪层｜为什么仍可原位**

### 快速核对

```text
表面异型细胞
→ 沿基底膜、经宫颈腺口
→ 进入宫颈腺体并替代部分 / 全部腺上皮
→ 但腺体基底膜仍完整
= CIN III累及腺体
≠ 间质浸润
```

### Detailed Expansion

这里有两层“看到肿瘤细胞的位置”和“屏障是否突破”：

- 细胞可以出现在腺体内；
- 但只要仍被腺体基底膜圈住，就没有进入间质。

这是 E2 最重要的屏障判断之一。

**Routing**：CORE｜BOUNDARY｜VISUAL_ONLY｜MI-G

> **讲义定位 →** 病理 Lecture PDF P97｜Outline U011 宫颈癌 Q6

## KP06｜宫颈癌组织身份与空间：鳞癌 + 鳞柱交界 / 移行带

> **讲义定位 →** 病理 Lecture PDF P97｜Outline U011 宫颈癌 Q7–Q8  
> **主提示：最常病理1｜好发部位1｜原始/新交界｜与化生是否有关**

### 快速核对

- 当前 Study：宫颈癌最常见病理类型为**鳞癌**；
- 好发于**鳞—柱状上皮交界处 / 移行带**；
- HPV感染**原始鳞柱交界**：不一定与鳞状上皮化生有关；
- HPV感染**新鳞柱交界**：与 E1 的异位后鳞化过程有关。

### Detailed Expansion

“宫颈癌与化生有关吗”不能用一个绝对答案处理，必须先问 HPV 落在哪个鳞柱交界。E1建立了“原始→异位→鳞化→新交界”，E2在这个空间上叠加高危HPV。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

- **原位癌 / 0期**：未突破基底膜；

## KP10｜E2反向算法：层次 → 基膜 → 分子 → 范围

> **主提示：4问顺序｜层次｜基膜｜HPV分子｜扩散范围**

### 快速核对

面对任何宫颈题先问：

```text
1. 异型细胞占上皮多少层？
2. 表面 / 腺体基底膜有没有突破？
3. 有无高危HPV—E6/E7—p16证据？
4. 已经扩展到宫颈、盆腔、阴道还是更远？
```

### Detailed Expansion

这样可以避免四类常见错误：

- 全层异型 = 自动浸润；
- 腺体累及 = 自动间质侵犯；
- p16阳性 = 自动宫颈癌晚期；
- 分期数字 = 组织学级别。

它们分别属于层次、屏障、分子和范围四个坐标。

**Routing**：CORE｜DECISION｜CONFUSABLE｜MI-G
