## KP03｜上皮性卵巢肿瘤真正跨入恶性的门槛是什么？

> **讲义定位 →** 病理 Lecture PDF P102｜Outline U011 上皮 Q2  
> **主提示：乳头/砂粒体是否足够｜决定性组织学证据**

### 快速核对

当前 Study 对恶性上皮性肿瘤的共同判断：

```text
癌细胞浸润卵巢间质
→ 囊腺癌
```

不能单靠：

- 乳头；
- 实性结节；
- 砂粒体；
- 双侧；

任一单项直接定癌。

### Detailed Expansion

这些形态能提高某一候选的可能性，但“浸润间质”才完成良性囊腺瘤向囊腺癌的身份改变。

```text
有乳头
≠
必然恶性

乳头多 + 砂粒体 + 间质浸润
→ 更支持浆液性囊腺癌
```

**Routing**：CORE｜BOUNDARY｜CONFUSABLE｜MI-G

## KP04｜浆液性卵巢肿瘤应从哪些形态轴识别？

> **讲义定位 →** 病理 Lecture PDF P102 + 原图｜Outline U011 上皮 Q1–Q2  
> **主提示：囊液｜乳头｜单双侧｜砂粒体｜最后再判浸润**

### 快速核对

当前 Study 的浆液性肿瘤：

- 发病率较高；
- 囊腔内清亮囊液，可有实性结节；
- 乳头多见，恶性者更多；
- 双侧卵巢受累较多见；
- 恶性称**浆液性囊腺癌**；
- 恶性证据：间质浸润；
- 可见砂粒体 / 钙化小体。

### Detailed Expansion

浆液性肿瘤的高信息密度图像是：

```text
清亮囊液
+ 乳头
+ 双侧倾向
+ 砂粒体
```

但最后必须回到“间质浸润”。砂粒体是高价值识别点，不是单独的癌证据。

**Routing**：CORE｜VISUAL_ONLY｜RECOGNITION｜MI-G / MI-D

<!-- kianos:kp id="repro-path-e7-kp05" -->
## KP05｜黏液性卵巢肿瘤应从哪些形态轴识别？

> **讲义定位 →** 病理 Lecture PDF P102 + 原图｜Outline U011 上皮 Q1  
> **主提示：囊性结构｜囊液｜乳头｜单双侧｜最后再判浸润**

### 快速核对

当前 Study 的黏液性肿瘤：

- 多个囊腔；
- 囊内黏稠囊液和实性结节；
- 乳头少见；
- 单侧卵巢受累较多见；
- 恶性称**黏液性囊腺癌**；
- 癌细胞浸润间质。

### Detailed Expansion

与浆液性相比，黏液性更像：

```text
多囊
+ 黏稠内容物
+ 乳头少
+ 单侧
```

但一旦出现双侧黏液性恶性病变，定位逻辑要立刻转向“继发 / 转移性”而不是继续只比较原发上皮亚型。

**Routing**：CORE｜VISUAL_ONLY｜MI-G

## KP06｜如何用同一组坐标比较浆液性与黏液性肿瘤？

> **主提示：囊液｜乳头｜单双侧｜砂粒体｜浸润门槛**

### 快速核对

| 轴 | 浆液性 | 黏液性 |
|---|---|---|
| 囊腔内容 | 清亮囊液 + 实性结节 | 多囊 + 黏稠囊液 + 实性结节 |
| 乳头 | 多见，恶性者更多 | 少见 |
| 侧别 | 双侧多见 | 单侧多见 |
| 特殊形态 | 砂粒体 / 钙化小体 | 当前 Study 无同类主标志 |
| 恶性门槛 | 间质浸润 | 间质浸润 |

### Detailed Expansion

比较表的职责是缩小候选，不是替代病理门槛。

```text
先凭内容物 / 乳头 / 侧别猜类型
→ 再凭间质浸润判良恶
```

**Routing**：CORE｜DISCRIMINATION｜MI-G / MI-D

## KP07｜砂粒体：支持浆液性恶性方向，但不能单独定癌

> **讲义定位 →** 病理 Lecture PDF P102｜Outline U011 上皮 Q2  
> **主提示：对应哪型｜多见良/恶哪边｜还见2处｜最终仍看什么**

### 快速核对

- 卵巢浆液性囊腺癌可见砂粒体 / 钙化小体；
- 当前 Study：砂粒体样钙化多见于恶性者；
- 串联：甲状腺乳头状癌、脑膜瘤也可见；
- 最终仍以癌细胞**浸润间质**判断恶性。

### Detailed Expansion

砂粒体是“形态识别岛”，不是卵巢特异标志，也不是恶性绝对证据。它应挂在浆液性模型下，而不是独立背成“见砂粒体就是卵巢癌”。

**Routing**：SPECIAL｜RECOGNITION｜CONFUSABLE｜MI-D

## KP08｜原发黏液癌 vs Krukenberg：单侧/双侧 + 胃肠来源

> **讲义定位 →** 病理 Lecture PDF P102｜Outline U011 上皮 Q3  
> **主提示：原发多哪侧｜继发多哪侧｜典型原发灶1｜双侧恶性先想谁**

### 快速核对

```text
原发卵巢黏液性癌
→ 单侧多见

继发卵巢黏液性癌
→ 胃肠黏液癌，尤其胃印戒细胞癌
→ 种植性转移至卵巢
→ 双侧多见
→ Krukenberg瘤
```

### Detailed Expansion

反向病例：

```text
双侧卵巢黏液性恶性肿瘤
→ 不先默认“两个原发卵巢癌”
→ 先寻找胃肠原发灶
```

当前 Study 直接冻结：

> 双侧卵巢恶性肿瘤首先考虑 Krukenberg 瘤。

**Routing**：CORE｜CONNECTION｜DECISION｜MI-G

## KP09｜E7反向算法：谱系 → 类型 → 良恶 → 原发/转移

> **主提示：4步｜来源｜浆/黏｜浸润｜单双侧+胃肠**

### 快速核对

```text
1. 先报三大谱系；
2. 上皮性再分浆液 / 黏液；
3. 用间质浸润判癌；
4. 黏液性恶性若双侧，先查胃肠原发。
```

### Detailed Expansion

这套顺序可以防止：

- 看到“卵巢肿瘤”就只想到畸胎瘤；
- 看到乳头就直接诊断癌；
- 看到黏液就忽略原发 / 转移；
- 看到双侧就继续按单一原发卵巢模型解释。

**Routing**：CORE｜DECISION｜MI-G
