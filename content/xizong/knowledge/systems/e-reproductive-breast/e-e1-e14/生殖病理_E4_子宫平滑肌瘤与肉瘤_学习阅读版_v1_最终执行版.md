# E4｜子宫平滑肌瘤与平滑肌肉瘤
## 同一平滑肌来源：先区分良性克隆、继发变性和恶性细胞证据

> **中心问题**：子宫平滑肌来源的肿块，为什么不能用“有无包膜、大小、是否发生坏死”单独判断良恶性；平滑肌瘤的旋涡 / 束状结构、玻璃样变和妊娠期红色变性，与平滑肌肉瘤的显著异型和核分裂增多怎样分层理解？
>
> **Primary ownership**：本 Block 首次完整建立子宫平滑肌肿瘤的器官特异病理模型。E3 的腺肌病是异位内膜组织进入肌层，不是平滑肌肿瘤；两者不得因“肌”字重复建账。
>
> **FIRST PASS 固定流程**：`Framework → 病理 Lecture P98–99 + 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`
>
> **Source boundary**：只建立当前病理 Study 的位置、组织形态、变性和良恶性证据；不扩写肌瘤症状、超声、FIGO位置分类、妇科手术和肉瘤临床治疗。

# 1｜Framework｜先分“肿瘤身份”与“肿瘤内部发生的变性”

```text
子宫平滑肌
        ↓
克隆性生长
        ↓
平滑肌瘤
良性
细胞接近正常
旋涡 / 编织 / 束状
        ↓
肿块长大后可发生继发变性
        ├─ 玻璃样 / 透明变性：最常见
        └─ 红色变性：妊娠期多见
              血管血栓
                 ↓
              局部坏死 + 出血

另一条恶性支路：
平滑肌肉瘤
→ 边界不清
→ 细胞异型显著
→ 核分裂象增多（Study重点）
```

这里最容易犯的错误：

```text
肌瘤发生坏死 / 出血
→ 就叫肉瘤
```

错误。先问坏死属于**继发变性**，还是同时存在真正的**细胞恶性证据**。

## KP02｜平滑肌瘤：良性但无包膜，细胞仍很像正常平滑肌

> **讲义定位 →** 病理 Lecture PDF P99｜Outline U011 平滑肌瘤 Q2  
> **主提示：良/恶｜包膜有无｜细胞异型方向｜别用哪一个指标单判**

### 快速核对

当前 Study：

- 子宫平滑肌瘤 = **良性肿瘤**；
- **无包膜**；
- 瘤细胞与正常子宫平滑肌细胞相似；
- 细胞异型性小。

### Detailed Expansion

这是一条“良性肿瘤不一定有完整包膜”的反例。良恶性判断必须综合分化、异型、核分裂和浸润 / 边界等，不可建立“有包膜=良性、无包膜=恶性”的机械规则。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP04｜玻璃样变：肌瘤最常见变性，不等于恶变

> **讲义定位 →** 病理 Lecture PDF P99｜Outline U011 平滑肌瘤 Q3  
> **主提示：最常变性1｜旋涡结构被什么替代｜变性≠什么**

### 快速核对

- **最常见肌瘤变性**：玻璃样变 / 透明变性；
- 当前 Study：原有旋涡状结构被透明样物质取代；
- 这是继发变性，不等于恶性转化。

### Detailed Expansion

“玻璃样变”是形态性变性语言。题目若只给肌瘤内透明样改变，不应直接升级成肉瘤；真正的恶性判断仍要回到 KP06 的细胞异型和核分裂。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

## KP05｜红色变性：妊娠期多见，血栓是上游

> **讲义定位 →** 病理 Lecture PDF P99｜Outline U011 平滑肌瘤 Q3

### 快速核对

## KP06｜平滑肌肉瘤：边界不清 + 显著异型 + 核分裂增多

> **讲义定位 →** 病理 Lecture PDF P99｜Outline U011 平滑肌瘤 Q4  
> **主提示：肉瘤3证据｜边界｜异型｜核分裂｜Study“主要”抓谁**

### 快速核对

当前 Study 的平滑肌肉瘤：

- 肿瘤**边界不清**；
- 细胞**异型显著**；
- **核分裂象增多**，为当前 Study 强调的主要病理变化。

### Detailed Expansion

不要用“肿块很大”“有坏死”“没包膜”单独诊断恶性。平滑肌瘤本身就可无包膜、也可发生坏死 / 出血性红变；肉瘤需要真正的恶性细胞 / 生长证据。

**Routing**：CORE｜BOUNDARY｜CONFUSABLE｜MI-G

<!-- kianos:kp id="repro-path-e4-kp07" -->
## KP07｜E4反向算法：先看细胞恶性证据，再解释变性

> **主提示：来源｜排列｜变性2｜肉瘤3证据｜大小/坏死能否单判**

### 快速核对

```text
子宫平滑肌肿块
→ 先看细胞是否接近正常、排列是否旋涡/束状
→ 若是：肌瘤模型
   ↓
   再判断玻璃样变 / 红色变性
→ 若边界不清 + 显著异型 + 核分裂↑
   ↓
   肉瘤方向
```

### Detailed Expansion

稳定顺序是：

1. **组织来源**；
2. **良恶性细胞 / 生长证据**；
3. **继发变性**。

不要把第三层的坏死 / 出血反过来替代第二层。

**Routing**：CORE｜DECISION｜MI-G

# 4｜高频 Discrimination Tree

|---|---|
| 腺肌病 vs 平滑肌瘤 | 前者是内膜腺体+间质异位于肌层；后者是平滑肌肿瘤 |
