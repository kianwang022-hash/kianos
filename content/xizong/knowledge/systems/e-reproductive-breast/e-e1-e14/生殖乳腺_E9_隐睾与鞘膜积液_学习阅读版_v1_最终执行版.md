# 1｜Framework｜先问“睾丸在哪里”，再问“液体与腹腔通不通”

<!-- kianos:framework id="reproductive-e09-framework-main" -->

```text
A｜阴囊空虚
→ 先想睾丸下降是否完成
→ 隐睾
→ 年龄决定当前Study处理节点

B｜阴囊 / 精索区包块
→ 先判断是不是以液体为主
→ 透光试验阳性、无气液咕咕声
→ 鞘膜积液方向

C｜再做两个定位动作
能否摸到睾丸？
平卧后是否缩小 / 消失？

        ↓

睾丸鞘膜积液
→ 摸不到睾丸
→ 平卧不消失

精索鞘膜积液
→ 摸得到睾丸
→ 平卧不消失

交通性鞘膜积液
→ 摸得到睾丸
→ 平卧可缩小 / 消失

D｜若包块含肠管 / 气液、咳嗽冲击等
→ 回 D14 腹股沟疝
```

一句话：

> **隐睾是“位置问题”；鞘膜积液是“液体—交通问题”。**

## KP01｜隐睾：先把它定义成“位置没完成”

> **主提示：阴囊1征｜本质1｜年龄是主轴**

### 快速核对

当前 Study 的直接识别入口是：

- **阴囊空虚感 / 阴囊内未触及正常睾丸**；
- 本质：睾丸下降没有完成；
- 后续处理首先按年龄节点，而不是先背复杂术式。

### 详细展开

胎儿时期睾丸从腹腔方向逐步下降至阴囊。本 Block只使用这条最低胚胎—解剖链，把“阴囊空虚”定位成睾丸位置异常；完整男性生殖生理已在 SR2 完成，不再重复。

**Routing**：CORE｜MI-G

## KP03｜隐睾两个特殊分支

> **主提示：萎缩+对侧正常｜双侧不能下降｜各1动作**

### 快速核对

当前 Study：

- 未降睾丸萎缩，且对侧睾丸正常 → **切除未降睾丸**；
- 双侧睾丸均不能下降 → **睾丸自体移植术**。

### 详细展开

这两个分支是当前外科讲义的直接考试配对，不在本 Block用一般医学知识重写。看到病例先判断它是否已经进入“特殊分支”，再调用对应 Source 结论。

**Routing**：SPECIAL｜MI-D｜SOURCE_BOUND

<!-- kianos:kp id="reproductive-e09-kp04" -->
## KP04｜鞘突：只建一条最小桥

> **主提示：下降时带下什么｜未闭→2方向｜疝去哪里**

### 快速核对

```text
睾丸下降
→ 相应腹膜结构随之向阴囊方向延伸
→ 鞘突 / 鞘膜腔形成

若相关通道未闭
→ 可与腹股沟斜疝有关
→ 也可形成交通性鞘膜积液
```

### 详细展开

这里的目标只是解释为什么“腹股沟斜疝”和“交通性鞘膜积液”会共享一个发育接口。完整疝囊、腹股沟管、内环、嵌顿与修补全部留在 D14。

**Routing**：CONNECTION｜RECALL_APPLY｜BOUNDARY

<!-- kianos:kp id="reproductive-e09-kp05" -->
## KP05｜鞘膜积液的共同识别：液体，不是含气肠管

> **主提示：透光｜气液声｜两问入口**

### 快速核对

当前 Study：

- **透光试验阳性**；
- **无气液咕咕声**；
- 下一步只做两问：
  1. 能否摸到睾丸？
  2. 平卧后是否缩小/消失？

### 详细展开

这一步先把“液体性包块”与含气/肠内容物的疝方向分开。不要在第一步就强背三种积液名称；先用物理证据证明“这是液体模型”。

**Routing**：RECOGNITION｜DISCRIMINATION｜MI-G

---

<!-- kianos:kp id="reproductive-e09-kp06" -->
## KP06｜三类鞘膜积液：摸睾丸 × 平卧变化

> **主提示：睾丸/精索/交通｜摸到？｜平卧？**

### 快速核对

| 类型 | 能否摸到睾丸 | 平卧后 |
|---|---|---|
| 睾丸鞘膜积液 | × | 不消失 |
| 精索鞘膜积液 | √ | 不消失 |
| 交通性鞘膜积液 | √ | 可缩小 / 消失 |

### 详细展开

```text
先看睾丸是否被积液包裹到难以触及
→ 再看液体是否能随体位与腹腔方向交通
```

因此最有辨别价值的并不是三个病名，而是两个结构问题。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

---

<!-- kianos:kp id="reproductive-e09-kp07" -->
## KP07｜阴囊/腹股沟包块反向算法

> **主提示：空虚｜透光｜摸睾丸｜平卧｜疝接口**

### 快速核对

```text
阴囊空虚？
├─ 是 → 隐睾 → 按年龄 / 特殊分支
└─ 否 → 有包块
       ↓
透光阳性、无气液声？
├─ 是 → 鞘膜积液
│      ↓
│   摸睾丸 + 平卧变化
│   → 睾丸 / 精索 / 交通性
└─ 否或有肠管样证据
       → 回D14腹股沟疝
```

### 详细展开

这是 E9 的最终 Framework Reconstruction。病例不先问“背到哪个口诀”，而先问“位置异常还是液体异常；液体是否交通”。

**Routing**：FRAMEWORK_RECONSTRUCTION｜MI-G
