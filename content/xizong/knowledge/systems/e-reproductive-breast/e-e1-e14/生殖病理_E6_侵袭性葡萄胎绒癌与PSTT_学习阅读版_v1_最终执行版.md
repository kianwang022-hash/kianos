>
> **FIRST PASS 固定流程**：`Framework → 病理 Lecture P100–102 + 原图 → Framework Reconstruction → KP Active Recall → Outline optional / low-pressure → TTSX Lecture-attached Questions → Block Complete`

# 1｜Framework｜五轴一次定位

```text
先问1：有无绒毛？
        ├─ 有 → 良性葡萄胎 / 侵袭性葡萄胎
        └─ 无 → 绒癌 / PSTT

再问2：哪类细胞？
        ├─ 两种滋养层细胞 → 葡萄胎 / 绒癌
        └─ 单一中间型滋养细胞 → PSTT

再问3：是否进入肌层 / 血管？
        ├─ 否 → 良性葡萄胎
        └─ 是 → 侵袭性葡萄胎 / 绒癌 / PSTT

再问4：是否真正转移？
        ├─ 侵袭性葡萄胎：几乎不
        ├─ 绒癌：明显，血道为主
        └─ PSTT：可转移

再问5：激素与形态？
        ├─ hCG主导 + 出血坏死显著 → 绒癌方向
        └─ hPL多数阳性 + 一般无明显出血坏死 → PSTT
```

最重要的一刀：

```text
侵犯
≠
转移
```

侵袭性葡萄胎可以侵犯子宫肌层 / 血管，却因为水泡状绒毛到远处后无法继续生长，几乎不形成真正转移。

## KP01｜三病第一刀：有绒毛还是无绒毛

> **讲义定位 →** 病理 Lecture PDF P100｜Outline U011 比较 Q3  
> **主提示：良性有｜侵袭有｜绒癌无｜为什么这1轴最值钱**

### 快速核对

- 良性葡萄胎：有水泡状绒毛；
- 侵袭性葡萄胎：仍有水泡状绒毛；
- 绒癌：无绒毛，也无自身绒毛间质和血管。

### Detailed Expansion

“有无绒毛”同时反映分化程度与生物学行为：

- 侵袭性葡萄胎虽然进入肌层 / 血管，仍保留葡萄胎绒毛身份；
- 绒癌与正常绒毛结构差异最大，细胞异型和恶性行为也更强。

因此遇到滋养细胞病变，先问绒毛，比先背病名更稳定。

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

## KP02｜共同来源：两种滋养层细胞，差别主要在增生与异型程度

> **讲义定位 →** 病理 Lecture PDF P100｜Outline U011 比较 Q2  
> **主提示：两种细胞｜良<侵<绒癌｜异型/坏死出血同方向**

### 快速核对

葡萄胎与绒癌均涉及：

- 合体滋养层细胞；
- 细胞滋养层细胞。

程度方向：

```text
良性葡萄胎
< 侵袭性葡萄胎
< 绒癌
```

同时递增：

- 滋养层细胞增生；
- 细胞异型；
- 坏死与出血。

### Detailed Expansion

同源不等于同一病。三者共享细胞来源，但绒毛保存、侵犯、转移和出血坏死的程度逐步改变。PSTT则在这一轴上另起一支：单一中间型滋养细胞。

**Routing**：CORE｜CONNECTION｜MI-G

## KP03｜侵袭性葡萄胎的身份由哪些结构和行为证据确定？

> **讲义定位 →** 病理 Lecture PDF P100｜Outline U011 比较 Q1、Q4  
> **主提示：绒毛｜局部侵犯｜远处行为｜不要把侵犯直接当转移**

### 快速核对

```text
侵袭性葡萄胎
= 水泡状绒毛侵入子宫肌层和/或血管
= 能侵犯
但几乎不发生真正转移
```

### Detailed Expansion

当前 Study 同时使用两个口径：

- 表格称“恶性 / 侵袭性葡萄胎”；
- 旁注从生物学行为称其“交界性”。

原因：

```text
像良性：
保留绒毛，几乎不转移

像恶性：
水泡状绒毛进入肌层 / 血管
```

这不是矛盾，而是“病名口径”和“行为解释”两个层面。

**Routing**：CORE｜BOUNDARY｜CONFUSABLE｜MI-G

## KP04｜侵袭性葡萄胎进入血管后，为什么仍不能等同于真正转移？

> **讲义定位 →** 病理 Lecture PDF P100｜Outline U011 比较 Q4、Q7  
> **主提示：入血结构｜远处能否持续生长｜术语边界｜与绒癌对比**

### 快速核对

```text
侵袭性葡萄胎的水泡状绒毛
→ 进入低压子宫静脉
→ 成为不溶于血液的栓子
→ 到阴道血管造成栓塞
→ 出血、坏死
→ 蓝紫色结节
```

但：

- 绒毛在远处不能继续生长；
- 因而不属于真正肿瘤转移。

### Detailed Expansion

真正转移要求：

```text
肿瘤细胞到达远处
+ 在远处继续增殖形成病灶
```

侵袭性葡萄胎的阴道结节是**栓塞性损伤**，不是远处克隆继续生长。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP05｜绒癌“三无”：无绒毛、无自身间质、无自身血管

> **讲义定位 →** 病理 Lecture PDF P100｜Outline U011 比较 Q2–Q4  
> **主提示：三无｜靠谁供血｜为什么出血坏死显著**

### 快速核对

绒癌：

- 无绒毛；
- 无自身绒毛间质；
- 无自身绒毛血管；
- 滋养层细胞异型显著；
- 出血、坏死显著。

### Detailed Expansion

绒癌并非“不需要营养”。当前 Study 的解释是：

```text
绒癌侵袭宿主血管
→ 肿瘤细胞直接处于母体血液中
→ 获得营养
→ 同时更容易进入血流
→ 血道转移
```

因此“无自身血管”和“高度血道转移”并不冲突。

**Routing**：CORE｜VISUAL_ONLY｜CONNECTION｜MI-G

## KP09｜PSTT：hPL多数阳性 + 单一中间型滋养细胞

> **讲义定位 →** 病理 Lecture PDF P102 + 原图｜Outline U011 PSTT Q1–Q3  
> **主提示：激素hPL/hCG｜细胞1型｜绒毛有无｜侵/转｜出血坏死对比**

### 快速核对

胎盘部位滋养细胞肿瘤 PSTT：

- 多数 **hPL阳性**；
- 少数 **hCG阳性**；
- 单一的**中间型滋养细胞**；
- 无绒毛；
- 可侵犯子宫肌层；

### Detailed Expansion

PSTT 与绒癌都可：

- 无绒毛；
- 侵犯；
- 转移。

但第一层鉴别是：

```text
绒癌：
两种滋养层细胞
+ hCG共同背景
+ 出血坏死显著

PSTT：
单一中间型滋养细胞
+ hPL多数阳性
+ 一般无明显出血坏死
```

## KP10｜E6反向算法：绒毛—细胞—侵犯—转移—激素

> **主提示：5轴｜绒毛｜细胞｜侵犯｜转移｜hCG/hPL**

### 快速核对

```text
1. 有无绒毛？
2. 两种滋养层，还是单一中间型？
3. 是否进入肌层 / 血管？
4. 是否能在远处继续生长形成真正转移？
5. hCG还是hPL更突出？
```

### Detailed Expansion

稳定结论：

- 有绒毛 + 不侵犯 → 良性葡萄胎；
- 有绒毛 + 侵肌层 / 血管 + 几乎不转移 → 侵袭性葡萄胎；
- 无绒毛 + 两种滋养层 + 出血坏死 + 血道转移 → 绒癌；
- 无绒毛 + 单一中间型 + hPL多数阳性 → PSTT。

# 6｜Memory Routing

## MI-G

- 三病先看有无绒毛；
- 侵袭性葡萄胎：有水泡状绒毛、侵犯肌层 / 血管、几乎不真转移；

- 三者全部比较细节；
- 原发灶切除后转移灶可自行消退；
- 绒癌化疗敏感性的 Study 理由；
- 完整转移部位；
- 完整化疗方案、分期与随访。
