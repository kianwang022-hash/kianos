# E8｜卵巢生殖细胞与性索间质肿瘤
## 卵母细胞看成熟度、胚层与 AFP；卵泡细胞看激素与特征性结构

> **中心问题**：卵母细胞来源的肿瘤，怎样通过成熟 / 未成熟组织、胚层构成、AFP 与 Schiller–Duval 小体定位；卵泡相关细胞来源的肿瘤，又怎样通过雌激素、核沟、Call–Exner 小体和脂质丰富胞质区分粒层细胞瘤与卵泡膜细胞瘤？
>
> **Primary ownership**：E7 已完成卵巢三大谱系和上皮性肿瘤。本 Block 首次完整建立两条支路：①**生殖细胞支路**：畸胎瘤—卵黄囊瘤；②**性索间质支路**：粒层细胞瘤—卵泡膜细胞瘤。无性细胞瘤、胚胎性癌、卵巢绒毛膜癌及支持—间质细胞瘤仅保留名称 / 识别接口，不用一般医学知识扩写。
>
> **FIRST PASS 固定流程**：`Framework Orientation → Source Unit 1：病理 Lecture P103 生殖细胞谱系 / 成熟度 / AFP + 原图 → 回到 KianOS：恢复生殖细胞分支 → Source Unit 2：P103 性索间质激素 / 形态 + 原图 → 回到 KianOS：恢复性索间质分支 → Block Recall → Outline / TTSX 只在真实边界且已有 reviewed binding 时检查 → Block Complete`

> **Source boundary**：当前 Source 只支持病理谱系、成熟度、标志物和特征性形态；不扩写卵巢肿瘤年龄分层、临床表现、影像、分期、手术或化疗。正常卵泡“两细胞—两促性腺激素”只作生理 Recall，不机械套成肿瘤内分泌机制。

## KP02｜畸胎瘤良恶性真正由什么决定？

> **讲义定位 →** 病理 Lecture PDF P103｜Outline U011 畸胎瘤 Q1  
> **主提示：成熟度｜胚层数量能否单独决定｜成熟/未成熟方向**

### 快速核对

- **成熟畸胎瘤**：良性；
- **未成熟畸胎瘤**：恶性；
- 畸胎瘤通常含 **≥2 个胚层**组织；
- 良恶性取决于**组织成分成熟度**，不是单纯看胚层数量。

### Detailed Expansion

当前 Source 的组织例子包括：

- 皮肤；
- 毛囊；
- 脂肪；
- 骨；
- 软骨；
- 神经组织等。

“多种组织混在一个肿瘤里”提示畸胎瘤，但最终良恶要问：

```text
这些组织像成熟成人组织
还是像原始胚胎组织？
```

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP08｜粒层细胞瘤与卵泡膜细胞瘤如何从恶性度、形态和激素方向区分？

> **讲义定位 →** 病理 Lecture PDF P103｜Outline U011 性索 Q1  
> **主提示：良恶方向｜形态锚｜激素方向｜不要只背病名**

| 肿瘤 | 当前 Study 生物学 | 激素 |

所以这里学习的是肿瘤身份和最终激素方向，不重建一套肿瘤内完整合成通路。
