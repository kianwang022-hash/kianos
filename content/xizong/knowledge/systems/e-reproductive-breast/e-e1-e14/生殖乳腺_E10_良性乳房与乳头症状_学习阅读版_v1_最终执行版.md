# E10｜良性乳房疾病与乳头症状
## 不要从“乳房有包块”直接猜病名：先读年龄、痛不痛、是否周期性、活动度、溢液和乳头改变

> **FIRST PASS 固定流程**  
> `Framework Orientation → Source Unit 1：外科 Lecture 的离散肿块 + 周期性良性病 → 回到 KianOS：恢复肿块 / 周期模型 → Source Unit 2：乳头溢液 + 炎症性 mimic 的可用 Source → 回到 KianOS：恢复乳头证据 / 炎症性 mimic；视觉关系仍按 VISUAL_SOURCE_GAP fail-closed → Block Recall → Outline / TTSX 只在真实边界且已有 reviewed binding 时检查 → Block Complete`
>
> **中心问题**：乳房肿块、周期性胀痛、乳头溢液或凹陷怎样被分成不同结构问题；纤维腺瘤、乳腺囊性增生病、乳管内乳头状瘤与浆细胞乳腺炎分别靠什么高价值证据成立？
>
> **Primary ownership**：本 Block拥有“良性乳房疾病 + 乳头症状”的完整外科 Primary。乳腺癌只作为鉴别警报出现；癌前病变、原位/浸润、TNM、分子亚型和治疗后置 E12–E14，不制造 duplicate Primary。
>
> **Source boundary**：治疗、恶变风险、乳头溢液颜色等均按当前 Study 口径保留，不用外部指南静默替换。

# 1｜Framework｜乳房症状先过六个变量

<!-- kianos:framework id="reproductive-e10-framework-main" -->

```text
乳房肿块 / 疼痛 / 溢液 / 凹陷
        ↓
1｜年龄
青年？中年？中老年？

2｜痛不痛
周期性胀痛？持续炎性痛？无痛？

3｜单发还是多发
单个局限肿块？
多发颗粒 / 结节？

4｜边界与活动
清楚、易推动？
边界不清、固定 / 粘连？

5｜是否随月经变化
月经后疼痛和肿块减轻？
→ 囊性增生方向

6｜乳头证据
血性 / 黄绿色 / 多色 / 无色？
是否进行性凹陷？
        ↓

青年 + 单发无痛 + 边界清 + 易推动
→ 纤维腺瘤

中年 + 周期性胀痛 + 多发颗粒/结节 + 月经后减轻
→ 乳腺囊性增生病

血性溢液 + 常摸不到肿块
→ 乳管内乳头状瘤优先

无菌炎症 + 慢性纤维化 + 凹陷/粘连
→ 浆细胞乳腺炎

无痛硬固定 / 皮肤或淋巴警报
→ 只提示转 E12–E14 排癌
```

一句话：

> **E10 学的是症状定位，不是把所有乳房疾病压成一张“肿块表”。**

# 2｜Memory Routing

## MI-G

- 纤维腺瘤：青年、单发、无痛、边界清、易推动；
- 囊性增生：中年、周期性胀痛、多发颗粒/结节、月经后减轻；
- 血性溢液首先想到乳管内乳头状瘤，同时不能忘记乳腺癌也可血性；
- 浆细胞乳腺炎是无菌性炎症，可形成肿块、粘连和乳头凹陷；
- 乳头溢液颜色只作加权证据，不取代整体模型；
- 无痛硬固定、进行性凹陷、皮肤改变、无痛淋巴结属于排癌警报。

## MI-D

- 全部年龄数字；
- 乳头溢液完整颜色配对；
- 乳管内乳头状瘤恶变率；
- 囊性增生的具体治疗条件；
- 单纯乳房切除术的 Current Study 指征；
- 乳腺癌全部细节后置 E12–E14。

# 3｜KP Active Recall

<!-- kianos:kp id="reproductive-e10-kp01" -->
## KP01｜先把乳房肿块分成“局限肿块、周期性组织反应、导管病、炎症纤维化、恶性警报”

> **主提示：5类｜6变量｜先模型后病名**

### 快速核对

病例先读：

```text
年龄
→ 疼痛
→ 单/多发
→ 边界与活动
→ 月经相关
→ 乳头 / 皮肤 / 淋巴
```

再进入：

- 纤维腺瘤；
- 囊性增生；
- 导管内乳头状瘤；
- 浆细胞乳腺炎；
- 乳腺癌警报。

### 详细展开

同样是“乳房肿块”，可能来自局限良性肿块、激素周期相关的弥漫反应、慢性炎症纤维化或恶性克隆。第一轮最重要的是把证据放到正确轴上。

**Routing**：FRAMEWORK｜MI-G

---

<!-- kianos:kp id="reproductive-e10-kp02" -->
## KP02｜纤维腺瘤：青年、单发、无痛、清楚、会动

> **主提示：年龄｜单发｜痛？｜质地/边界｜活动｜淋巴**

### 快速核对

当前 Study：

- 20–25岁多见；
- 多数单发；
- 无痛；
- 质硬 / 橡皮球样；
- 生长缓慢；
- 边界清楚；
- 易推动；
- 淋巴结不肿大。

### 详细展开

它与乳腺癌最容易在“单发、无痛、质硬”三个词上产生表面相似；真正把它拉回良性方向的是**边界清楚、活动度好、生长缓慢、无淋巴结异常、年龄偏青年**。

**Routing**：CORE｜CONFUSABLE｜MI-G

---

<!-- kianos:kp id="reproductive-e10-kp03" -->
## KP03｜纤维腺瘤治疗：切除 + 常规病理

> **主提示：做什么｜为什么病理｜不把它当癌**

### 快速核对

当前 Study：

```text
切除肿瘤
+ 常规病理检查
```

理由口径：需要排除恶性可能。

### 详细展开

“需要病理”不等于“它就是恶性”。这里训练的是证据层级：临床高度偏良性，但最终切除标本仍进入组织学确认。

**Routing**：TREATMENT_BOUNDARY｜MI-G

---

<!-- kianos:kp id="reproductive-e10-kp04" -->
## KP04｜乳腺囊性增生病：最强证据是“周期性”

> **主提示：人群｜周期痛｜多发结节｜质地｜月经后**

### 快速核对

当前 Study：

- 中年多见；
- 周期性乳房胀痛；
- 多发 / 颗粒样肿块；
- 结节大小不等、质韧；
- **月经后疼痛减轻，肿块可略缩小**。

### 详细展开

它不是靠“某个固定肿块形态”成立，而是靠**乳房组织随月经周期反复变化**建立身份。SR3 的周期语言在这里直接 Apply。

**Routing**：CORE｜CONNECTION｜MI-G

---

<!-- kianos:kp id="reproductive-e10-kp05" -->
## KP05｜囊性增生治疗：对症—复查—可疑时取材

> **主提示：轻症｜重症药1｜复查｜可疑→什么｜特殊切除指征**

### 快速核对

按当前 Study：

- 一般对症治疗；
- 症状重：他莫昔芬 / 三苯氧胺；
- 定期复查；
- 肿块无明显消退或可疑恶变 → 切除活检；
- 中重度不典型增生 + 对侧乳腺癌或乳腺癌家族史 → 当前 Study 给出单纯乳房切除术接口。

### 详细展开

这一组属于 **Source-bound 治疗记忆**。本 Block不把它扩成现代风险管理，也不把“囊性增生”直接等同癌前病变；题目要的是当前 Lecture 的处理分层。

**Routing**：SOURCE_BOUND｜MI-D

---

<!-- kianos:kp id="reproductive-e10-kp06" -->
## KP06｜乳管内乳头状瘤：血性溢液比肿块更有价值

> **主提示：最典型1｜摸到肿块？｜阻塞后颜色｜治疗**

### 快速核对

当前 Study：

- **最易出现血性乳头溢液**；
- 常不能触及明显肿块；
- 导管阻塞后溢液可呈棕褐色；
- 治疗：切除病变乳管 + 常规病理检查。

### 详细展开

核心定位是“导管内病变”：

```text
导管内病灶
→ 脆弱血管 / 出血
→ 血液沿乳管到乳头
→ 血性溢液
```

当前讲义另给 6–8% 恶变率，归 MI-D；第一轮不因数字阻塞主线。

**Routing**：CORE｜RECOGNITION｜MI-G

---

<!-- kianos:kp id="reproductive-e10-kp07" -->
## KP07｜乳头溢液颜色地图：只做加权证据

> **主提示：无色｜多色｜黄绿｜血性2类**

### 快速核对

当前 Study：

| 溢液 | 方向 |
|---|---|
| 浆液 / 无色 | 正常月经或早期妊娠接口 |
| 多种颜色 | 乳腺囊性增生病 |
| 黄绿色脓性 | 感染 |
| 血性 | 乳管内乳头状瘤；乳腺癌也可 |

### 详细展开

不能把颜色当成单独的“诊断条形码”。例如血性溢液可见于乳头状瘤，也可见乳腺癌；必须继续结合年龄、肿块、活动度、皮肤和淋巴证据。

**Routing**：CONFUSABLE｜MI-D + MI-G

---

<!-- kianos:kp id="reproductive-e10-kp08" -->
## KP08｜浆细胞乳腺炎：无菌炎症也能像癌

> **主提示：无菌｜急性可见1皮肤征｜慢性3征｜为什么易混**

### 快速核对

当前 Study：

- 属**无菌性炎症**；
- 急性炎症表现可有橘皮样变；
- 慢性阶段可有：
  - 边界不清肿块；
  - 乳头凹陷；
  - 皮肤粘连。

### 详细展开

慢性炎症后的纤维化和粘连可以制造“边界不清、凹陷、粘连”等恶性样外观。因此 E10 的目标不是见到某个癌样体征就直接定癌，而是知道需要进入后续证据层。

**Routing**：CORE｜CONFUSABLE｜BOUNDARY

---

<!-- kianos:kp id="reproductive-e10-kp09" -->
## KP09｜乳头凹陷：先天、慢性炎症、癌、结核都可

> **主提示：4类｜哪个是慢性炎症｜哪个后置癌**

### 快速核对

当前 Study 的候选：

1. 乳头先天发育不良；
2. 浆细胞乳腺炎；
3. 乳腺癌；
4. 乳腺结核。

### 详细展开

乳头凹陷是一种**结构牵拉结果**，不是一个单病名。当前 Block只完整学习浆细胞乳腺炎的慢性纤维化接口；乳腺癌和乳腺结核分别去后续肿瘤 / 感染模型。

**Routing**：DISCRIMINATION｜MI-G

<!-- kianos:kp id="reproductive-e10-kp10" -->
## KP10｜E10反向病例算法

> **主提示：痛/周期｜单多｜会不会动｜溢液｜凹陷｜癌警报**

### 快速核对

```text
周期性胀痛 + 多发颗粒/结节 + 月经后减轻
→ 囊性增生

青年 + 单发无痛 + 边界清 + 易推动
→ 纤维腺瘤

血性溢液 + 常摸不到肿块
→ 乳管内乳头状瘤优先
→ 仍需保留乳腺癌候选

肿块 + 凹陷/粘连 + 慢性炎症方向
→ 浆细胞乳腺炎

无痛硬固定 + 皮肤/淋巴异常
→ 不在E10硬做癌诊断
→ 转E12–E14
```

### 详细展开

E10 的出口是一个“良性乳房 / 乳头症状分流器”。它负责把病例送到正确后续模型，而不是替代乳腺癌系统。

**Routing**：FRAMEWORK_RECONSTRUCTION｜MI-G
