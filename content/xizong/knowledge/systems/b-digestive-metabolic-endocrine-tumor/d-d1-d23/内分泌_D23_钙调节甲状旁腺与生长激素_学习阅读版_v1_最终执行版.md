# D23｜钙调节、甲状旁腺与生长激素
## 用“钙磷稳态轴 + GH—IGF 生长轴”连接骨、肾、肠与全身代谢

> **中心问题**：血钙、血磷怎样由 CT、PTH 与钙三醇通过骨—肾—肠协同维持；甲状旁腺功能异常为何表现为低钙兴奋性升高、骨痛或肾结石；GH 又怎样通过 IGF 促进生长，同时把能量利用从糖转向脂肪？
>
> **Primary ownership**：三种钙调节激素、甲状旁腺功能减退 / 亢进的当前外科边界，以及 GH—IGF 正常生理在本 Block 首次完整学习。甲状腺激素和髓样癌来源已在 D21 完成 Primary；内分泌共同语言已在 D6 完成；肾脏 1α-羟化酶与 CKD-MBD 接口已在泌尿完成。本 Block 只简洁 Recall，不制造重复 Primary。

# 2｜总 Framework

<!-- kianos:framework id="dme-d23-framework-main" -->

## 2.1 钙磷稳态轴

```text
血钙 / 血磷偏移
        ↓
三类传感与激素输出
CT｜PTH｜钙三醇
        ↓
三器官
骨：储库 / 重塑
肾：激活VitD + 调节排出接口
肠：吸收入口
        ↓
血钙、血磷回到可运行范围
```

核心方向：

```text
CT       → 降钙、降磷
PTH      → 升钙、降磷
钙三醇   → 升钙、升磷
```

## 2.2 GH—IGF 生长轴

```text
下丘脑 GHRH / SST
        ↓
腺垂体 GH（脉冲、慢波睡眠高峰）
        ├─ 直接：升糖、脂解、脂肪酸氧化、蛋白合成
        └─ 间接：肝 / 靶细胞产生 IGF
                    ↓
                骨、肌、内脏生长
```

## 2.3 两轴的共同语言

> **钙磷轴维持“矿物原料与骨重塑”，GH—IGF 轴决定“生长程序与底物供给”。** 两者在骨上相遇，但不能混成同一种激素作用。

# 3｜钙磷稳态：三种激素与三器官

<!-- kianos:kp id="dme-d23-kp01" -->
## KP01｜三种钙调节激素总表：先背净方向，再追来源与受体

> **主提示：三激素｜来源｜受体｜靶器官｜净钙磷方向**

### 快速核对

| 激素 | 来源 | 性质 / 受体 | 主要靶器官 | 血钙 / 血磷净效应 |
|---|---|---|---|---|
| CT | 甲状腺滤泡旁 / C细胞 | 肽类 / GPCR | 骨、肾 | ↓ / ↓ |
| PTH | 甲状旁腺主细胞 | 肽类 / GPCR | 骨、肾 | ↑ / ↓ |
| 钙三醇 | 皮肤前体 → 肝25位羟化 → 肾1α羟化 | 类固醇样 / 核受体 | 小肠、骨、肾 | ↑ / ↑ |

`TH` 来自滤泡上皮、属于胺类而主要经核受体作用，其完整生理和缺乏后果已在 D21 学习。髓样癌来自 C 细胞、分泌 CT，也已归 D21；本节只用它帮助建立“甲状腺附近三种细胞—三种激素”的空间定位。

（易混：甲状腺激素、降钙素、PTH来自三个不同细胞身份；不要因位置接近混成一条轴。）

<!-- kianos:kp id="dme-d23-kp02" -->
## KP02｜降钙素 CT：高钙餐后的快速短暂刹车

> **主提示：CT：来源｜受体｜骨/肾作用｜钙磷方向｜刺激因素｜时程**

### 快速核对

```text
血钙↑ / 胃肠激素↑
→ CT↑
→ 抑制破骨、促进成骨
→ 骨钙磷释放↓、沉积↑
→ 血钙↓、血磷↓
```

CT 对血钙的影响**快速、短暂**，尤其用于高钙饮食后的恢复。其骨作用有两个方向：

- 破骨 / 骨吸收下降；
- 成骨 / 骨形成增加。

//串联：髓样癌来源于 C 细胞并分泌 CT；完整肿瘤模型见 D21。

（边界：病理 P82 旁注的 CT 方向与正式生理章节冲突，见 D23-SC01。）

<!-- kianos:kp id="dme-d23-kp03" -->
## KP03｜PTH：低血钙主控的“升钙降磷”信号

> **主提示：PTH：来源｜受体｜骨/肾｜钙磷方向｜主控信号｜Mg例外**

### 快速核对

- 来源：甲状旁腺主细胞；
- 受体：GPCR；
- 主要靶器官：骨、肾；
- 最终方向：升血钙、降血磷；
- 最重要调节：血钙直接反馈。

当前 Lecture 数字：

```text
血钙降至 7.5 mg/dL → PTH最大兴奋
血钙升至 10.5 mg/dL → PTH最大抑制
```

其它方向：

```text
血磷↑ / CT↑ → 血钙↓ → PTH↑
血镁↓ → PTH↓
持续低钙 → 甲状旁腺增生
```

PTH 还激活肾小管上皮 1α-羟化酶，借钙三醇间接增强肠道钙吸收。

（易混：血磷升高对 PTH 的影响在本 Lecture 中通过“先降低血钙”完成，不要把被调变量混掉。）

## KP04｜钙三醇：皮肤—肝—肾三站把 VitD 变成激素

> **主提示：VitD激活3站｜两次羟化｜1α酶｜受体｜肠/骨/肾｜钙磷方向｜缺乏后果**

### 快速核对

```text
皮肤胆固醇相关前体
→ 7-脱氢胆固醇
→ 紫外线形成 VitD₃
→ 肝25位羟化
→ 25(OH)VitD₃
→ 肾1α-羟化
→ 1,25(OH)₂VitD₃
= 钙三醇 / 活化VitD
```

- 性质 / 受体：类固醇样、核受体；
- 靶器官：小肠、骨、肾；
- 净结果：升血钙、升血磷；
- 缺乏接口：儿童佝偻病；成人骨软化、骨质疏松。

口诀只作定位：**一个羟基一个肝，两个羟基两个肾。**

//串联：肾脏 1α-羟化酶完整器官位置已在泌尿 K1 学过；本 Block 负责把它放回钙磷激素轴。

<!-- kianos:kp id="dme-d23-kp05" -->
## KP05｜三激素对骨：CT刹车，PTH看剂量，钙三醇双向但净升钙磷

> **主提示：CT/PTH/钙三醇对骨｜成骨/破骨｜剂量/时程效应｜协同关系**

### 快速核对

| 激素 | 骨吸收 / 破骨 | 骨形成 / 成骨 | 最终考试抓手 |
|---|---|---|---|
| CT | ↓ | ↑ | 把 Ca/P 移回骨，降钙降磷 |
| PTH 大剂量、持续 | ↑；延迟增强破骨 | — | 骨量减少、骨质疏松接口 |
| PTH 小剂量、间歇 | — | ↑ | “小有成就” |
| 钙三醇 | 直接促进骨吸收 | 高 Ca/P 与骨钙素等接口促进骨形成 | 直接作用为主，净升钙升磷 |

钙三醇与 PTH 有协同：缺乏钙三醇时，PTH 对骨的作用明显减弱。

（易混：PTH“快速升血钙”与“破骨细胞增加的延迟效应”不是同一个时间层；题目可分别问。）

## KP06｜钙磷反馈网：谁感受什么，谁激活 1α-羟化酶

> **主提示：钙磷反馈：高钙/低钙/低磷各影响谁｜PTH→1α｜钙三醇自抑｜低Mg例外**

### 快速核对

```text
血钙↑
→ CT↑
→ PTH↓
→ 钙三醇生成方向↓

血钙↓
→ PTH↑
→ 肾1α-羟化酶↑
→ 钙三醇↑
→ 肠 / 骨 / 肾联合升钙

血磷↓ → 钙三醇↑
钙三醇↑ → 抑制自身生成（1α-羟化酶负反馈）
血镁↓ → PTH释放与作用受限 → PTH↓
```

高磷和 CT 在当前 Lecture 中可通过降低血钙而继发使 PTH 上升。

> **被调变量顺序**：先问血钙 / 血磷如何变化，再问激素方向；不要直接用“激素作用于骨”机械反推分泌。

## KP07｜甲状腺术后甲旁减：低钙让神经肌肉过度兴奋

> **主提示：甲状腺术后甲旁减｜低钙兴奋性链｜表现｜查钙磷｜补钙/活性VitD｜预防**

### 快速核对

```text
甲状旁腺误切 / 血供受损
→ PTH↓
→ 血钙↓
→ 膜屏障作用↓
→ 阈电位靠近静息电位
→ 神经肌肉兴奋性↑
→ 麻木、抽搐甚至呼吸肌痉挛
```

临床识别：

- 针刺样麻木；
- 痉挛、抽搐；
- 腱反射亢进；
- Chvostek 征；
- Trousseau 征；
- 严重时呼吸困难。

检查：血钙、血磷。治疗：补充钙剂，可加骨化三醇。手术预防重在保护甲状腺背面的甲状旁腺及血供；若误切，当前外科 Lecture 提到可移植至胸锁乳突肌。

（易混：甲状腺术后数小时出现切口饱满和呼吸困难，先考虑血肿压迫；低钙抽搐通常需要“麻木 / 痉挛 / 体征 + 血钙”证据分流。完整术后致命急症见 D21。）

## KP10｜GH vs IGF：一个发指令，一个执行生长

> **主提示：GH/IGF来源｜2受体/2通路｜直接/间接｜PRL交叉**

### 快速核对

| 项目 | GH | IGF |
|---|---|---|
| 来源 | 腺垂体生长激素细胞；为腺垂体含量最多激素之一 | GH诱导肝细胞及靶细胞产生 |
| 受体 | 酪氨酸激酶结合型 / 细胞因子受体 | 受体酪氨酸激酶 |
| 信号 | JAK—STAT | MAPK、PI3K |
| 角色 | 直接调物质代谢，并诱导 IGF | 承担重要间接促生长效应 |

GH 与 PRL 化学结构同源性较高，作用有少量交叉：GH 有较弱泌乳始动作用，PRL 也有较弱促生长作用。完整泌乳—射乳轴后置正常生殖桥。

（易混：GH受体不是自身带酪氨酸激酶活性的受体；IGF受体才是受体酪氨酸激酶。）

## KP11｜GH的“高高瘦瘦”：升糖、脂解、蛋白合成

> **主提示：GH代谢：糖/脂/蛋白｜骨肌内脏生长｜过量后果｜协同激素**

### 快速核对

- **糖**：减少外周葡萄糖利用、降低胰岛素敏感性 → 血糖升高；过多可致垂体性糖尿；
- **脂**：脂肪分解和脂肪酸氧化增加 → 能量来源由糖向脂肪转移；
- **蛋白**：促进蛋白合成，对骨、肌肉和内脏生长重要；
- **过量**：脂肪动员过度，可出现酮症与脂肪肝接口。

促进生长发育的协同网络在当前 Lecture 中包括：GH、TH、雄激素、雌激素和胰岛素。TH 对神经系统发育尤其重要，不能用 GH 替代。

//串联：GC 也可使能量来源向脂代谢转移，但其核心是应激与分解代谢；GH 同时承担生长和蛋白合成。

## KP12｜GH分泌与疾病识别：慢波高峰、底物信号、三年龄结局

> **主提示：GHRH/SST｜促5抑4｜慢波峰/脉冲｜GH-IGF反馈｜3年龄结局**

### 快速核对

#### 促进 GH

- GHRH；
- 慢波睡眠，入睡后约1小时高峰；
- 低血糖、饥饿、运动、应激；
- 精氨酸；
- VP、TRH、TH、睾酮、雌激素、胰高血糖素等当前 Lecture 列出的促进接口。

#### 抑制 GH

- 生长抑素 SST；
- 快波睡眠；
- 高血糖；
- 衰老；
- GH 与 IGF-1 的负反馈。

GH 为脉冲式分泌，夜间占比较高。

#### 三个最低疾病身份

```text
幼儿GH缺乏 → 侏儒症
幼儿GH过多 → 巨人症
成人GH过多 → 肢端肥大症
```

IGF-1 明显升高可作为肢端肥大识别接口。完整 GH 临床诊断 / 试验 / 影像 / 治疗属于 `D23-SG01`，本文件不扩写。

# 6｜高密度比较表

## 6.1 三种钙调节激素

| 比较轴 | CT | PTH | 钙三醇 |
|---|---|---|---|
| 来源 | C细胞 | 甲旁主细胞 | 皮肤—肝—肾 |
| 受体 | GPCR | GPCR | 核受体 |
| 靶器官 | 骨、肾 | 骨、肾 | 肠、骨、肾 |

## 6.2 甲旁减 vs 甲旁亢

| 轴 | 甲旁减 | 甲旁亢 |
|---|---|---|
| 激素 | PTH↓ | PTH↑ |
| 血钙 | ↓ | ↑ |
| 主症状 | 麻木、抽搐、反射亢进、呼吸肌痉挛 | 骨痛 / 骨质疏松、结石 |
| 关键检查 | 血钙、血磷 | 血钙发现、PTH确认、影像定位 |
| 当前场景 | 甲状腺术后 | 单发腺瘤最常见 |

## 6.3 GH 与三类代谢

| 物质 | GH方向 | 结果 |
|---|---|---|
| 糖 | 外周利用↓、抗胰岛素 | 血糖↑ / 垂体性糖尿接口 |
| 脂 | 分解↑、FA氧化↑ | 能量由糖转脂；过量可酮症 / 脂肪肝 |
| 蛋白 | 合成↑ | 骨、肌、内脏生长 |
