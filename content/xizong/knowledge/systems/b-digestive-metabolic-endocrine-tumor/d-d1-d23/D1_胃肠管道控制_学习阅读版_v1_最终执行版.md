## KP01｜消化道平滑肌：为什么适合做“长期运行的柔性管道”

> **主提示：6特性｜AP 3差异｜紧张2意义｜伸展最大1｜敏感/不敏感**

### 详细展开

消化道既要容纳体积不断变化的内容物，又要长时间维持推进、混合和分段，因此其平滑肌不是“快速爆发型”，而是“慢、稳、可扩张”的执行器。

| 特性 | Study 口径 | 功能意义 |
|---|---|---|
| 兴奋性 | 较低 | 避免轻微刺激即持续强烈收缩 |
| 收缩速度 | 舒缩缓慢 | 适合持续推进与混合 |
| 动作电位 | 上升支慢、幅度低、持续时间长 | 0 期主要依赖 Ca²⁺内流，而非快 Na⁺内流 |
| 自律性 | 有，节律较慢 | 形成基本电节律 / 慢波 |
| 紧张性 | 持续轻微收缩 | 维持形状、位置、压力；是其他收缩形式的基础 |
| 伸展性 | 强，胃最大 | 容量可明显增加而腔内压不必同步大幅升高 |

### 刺激选择性

- 对食物造成的**机械牵张、温度和化学刺激敏感**：这些信息能调节运动和分泌。
- 对电刺激、刀割和针刺相对不敏感：与其平滑肌自身的生理特性相符。

### 消化、吸收与排出

```text
机械性消化
磨碎 + 混合 + 向远端推进

化学性消化
消化酶把大分子拆成可吸收小分子

吸收
营养物质跨黏膜进入血液或淋巴
```

（易混：**消化**是腔内拆解；**吸收**是跨黏膜进入内环境。两者不是同义词。）

## KP02｜慢波：胃肠运动的“节拍器”，不是每次收缩本身

> **主提示：定义｜局部电位6例｜ICC位置｜起搏离子链4步｜频率3处｜决定3项**

### 1｜身份

慢波是在静息电位基础上，自发出现的节律性轻度去极化和复极化，也称**基本电节律**。

它属于**局部电位**，本身通常没有达到动作电位阈值。

当前 Study 列举的局部电位包括：

- 慢波；
- 终板电位；
- EPSP；
- IPSP；
- 感受器电位；
- 发生器电位。

### 2｜起源与机制

```text
环形肌—纵行肌交界处的Cajal间质细胞 ICC
→ ICC内Ca²⁺↑
→ Ca²⁺激活Cl⁻通道
→ Cl⁻外流，负电荷外移
→ ICC膜去极化
→ 经缝隙连接向平滑肌扩布
→ 平滑肌L型Ca²⁺通道开放
→ 形成节律性膜电位波动
```

（易混：慢波**不由平滑肌细胞本身起搏**；ICC 是起搏细胞和两肌层间的电活动桥梁。）

### 3｜三个代表频率

- 胃：约 **3 次 / min**；
- 十二指肠：约 **12 次 / min**；
- 回肠末端：约 **8–9 次 / min**。

不能机械推成“越往下越快”：十二指肠快于回肠末端。

### 4｜慢波真正决定什么

慢波决定胃肠平滑肌收缩的：

- **频率 / 节律**；
- **传播速度**；
- **传播方向**。

它不直接决定主要收缩强度；强度主要看后续动作电位的数量。

## KP03｜慢波—机械阈—电阈—动作电位—收缩：两道门槛

> **主提示：机械阈 vs 电阈｜有无AP｜强度2因素｜节律由谁｜0期离子**

### 1｜第一道门：机械阈

```text
慢波去极化超过机械阈
→ L型Ca²⁺通道有一定开放
→ 少量Ca²⁺内流
→ 可出现轻度平滑肌收缩
```

此时不一定产生动作电位。

收缩幅度与：

- 慢波幅度；
- 慢波在机械阈以上停留的时间；

呈正相关。

### 2｜第二道门：电阈 / 阈电位

```text
慢波进一步达到电阈
→ 在慢波顶端出现成簇动作电位
→ Ca²⁺内流显著增加
→ 收缩明显增强
```

每个慢波上出现的动作电位越多，收缩越强；这是收缩强度的主要决定因素。

### 3｜三者分工

| 对象 | 主要回答 |
|---|---|
| 慢波 | 何时收缩、以什么节律和方向传播 |
| 动作电位频率 / 每慢波锋电位数 | 收缩有多强 |
| 收缩 | 最终机械结果 |

（易混：不是动作电位**幅度**决定主要收缩强度，而是动作电位的**频率 / 数目**。）

### 4｜离子基础

- 消化道平滑肌动作电位 0 期：以 **L 型 Ca²⁺电流**为主。
- 神经、骨骼肌和心肌快反应细胞 0 期：以快 Na⁺电流为主。

## KP04｜ENS：消化道自带的“本地控制器”

> **主提示：2神经丛｜各管谁｜递质3｜外神经切断后？｜巨结肠链**

### 1｜两套神经丛

| 神经丛 | 位置 | 主要控制对象 |
|---|---|---|
| 黏膜下神经丛 | 黏膜下层 | 上皮细胞、腺细胞、局部转运和分泌 |
| 肌间神经丛 | 环形肌与纵行肌之间 | 平滑肌活动和胃肠运动 |

两者通过复杂纤维联系共同构成肠神经系统 ENS。

### 2｜常见递质

当前 Study 强调：

- ACh；
- VIP；
- P 物质。

后续器官模型还会调用 NO、GRP 等，但本 Block 不把所有递质做成无边界名单。

### 3｜局部独立性

外在自主神经主要是对 ENS **调节和改档**。去除外在神经后，ENS 仍可独立调节：

- 胃肠运动；
- 分泌；
- 局部血流；
- 水和电解质转运。

因此：

```text
外在神经切断
≠ 胃肠道完全失去运动与分泌
```

### 4｜//串联：先天性巨结肠

```text
ENS先天发育不良 / 受损段缺少神经节细胞
→ 该段不能正常蠕动、处于功能性梗阻
→ 粪便在近端淤积
→ 近端结肠扩张
```

当前只用来验证 ENS 的本地控制价值；完整外科诊疗后置。

## KP05｜外在自主神经：先分“管壁、括约肌、腺体”，再判断方向

> **主提示：交感4效应｜副交感4效应｜递质｜慢波是否依赖｜特殊：唾液**

### 1｜交感神经

```text
交感节后纤维释放 NA
→ 慢波幅度↓
→ 管壁平滑肌 β₂：舒张
→ 括约肌 α₁：收缩
→ 腺体分泌↓
```

整体结果：抑制胃肠推进和消化。

（特殊：唾液分泌不是这个总规律，交感和副交感都可促进唾液；D2 完整学习。）

### 2｜副交感神经

```text
迷走 / 盆神经调节ENS
→ 多数节后纤维释放ACh
→ 慢波幅度↑
→ 管壁平滑肌M受体：收缩
→ 括约肌经抑制性肽能通路：舒张
→ 腺体分泌↑
```

副交感还可调用 VIP、NO、GRP 等非胆碱能递质。

### 3｜为什么管壁与括约肌方向相反

消化内容物要向前推进，必须同时发生：

```text
上游管壁收缩
+
下游括约肌舒张
```

若把“副交感促进消化”机械理解为“所有平滑肌都收缩”，就会把门关死。

### 4｜慢波边界

自主神经可改变慢波**幅度**和跨阈概率，但慢波的产生依赖 ICC，**不依赖自主神经作为起搏源**。

## KP06｜平滑肌收缩：Ca²⁺—CaM—MLCK 把电和化学信号变成张力

> **主提示：无T管｜Ca来源2｜收缩调控链3步｜电-机械｜药物-机械｜舒张3出口**

### 1｜联管结构与三类肌细胞的 Ca²⁺来源边界

- 骨骼肌：**三联管**；讲义口径近乎全部 Ca²⁺来自肌质网。
- 心肌：**二联管**；细胞外 Ca²⁺先进入，再触发肌质网 CICR。
- 平滑肌：**无 T 管、无联管结构**，肌质网相对不发达；胞质 Ca²⁺以细胞外进入为主，也可由肌质网释放。

### 2｜收缩主链

```text
胞质Ca²⁺↑
→ Ca²⁺结合钙调蛋白CaM
→ 激活肌球蛋白轻链激酶MLCK
→ 肌球蛋白轻链MLC磷酸化
→ 横桥ATP酶活性↑
→ 肌球蛋白与肌动蛋白结合
→ 平滑肌收缩
```

（易混：平滑肌不依靠肌钙蛋白启动横桥，而依靠 **CaM—MLCK**。）

### 3｜电—机械耦联

```text
牵张 / 化学刺激
→ 动作电位
→ L型Ca²⁺通道开放
→ 细胞外Ca²⁺大量进入
→ 少量CICR
→ 收缩
```

因此 Ca²⁺通道阻滞剂可使平滑肌舒张。

### 4｜药物—机械耦联

不必先产生动作电位：

```text
配体
→ GPCR—Gq
→ PLC
→ IP₃
→ 肌质网IP₃受体开放
→ Ca²⁺释放
→ 收缩
```

### 5｜舒张

```text
胞质Ca²⁺下降
+ MLCK失活
+ MLCP使MLC去磷酸化
→ 横桥ATP酶活性下降
→ 平滑肌舒张
```

Ca²⁺下降依赖肌质网 Ca²⁺泵、细胞膜 Ca²⁺泵和 Na⁺—Ca²⁺交换等；过程较慢，与平滑肌舒张缓慢相呼应。

## 3｜高密度比较轴

### 3.1 慢波、动作电位与收缩

| 轴 | 慢波 | 动作电位 | 收缩 |
|---|---|---|---|
| 身份 | 局部电位 / 基本电节律 | 达阈后的锋电位 | 机械结果 |
| 来源 | ICC 起搏 | 平滑肌膜 L 型 Ca²⁺通道 | Ca²⁺—CaM—MLCK |
| 主要决定 | 频率、速度、方向 | 主要收缩强度 | 推进、混合、维持张力 |
| 必然关系 | 有慢波不一定有 AP | 有 AP 常伴强收缩 | 可在机械阈后轻度出现 |

### 3.2 ENS 与外在自主神经

| 轴 | ENS | 外在自主神经 |
|---|---|---|
| 角色 | 本地反射和执行网络 | 根据整体状态改档 |
| 能否独立 | 可在去除外在神经后继续工作 | 依赖中枢与外周通路 |
| 典型控制 | 运动、分泌、血流、转运 | 交感总体抑制；副交感总体促进 |

## 4｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 慢波由 ICC 起搏，决定运动节律、速度和方向。
2. 慢波本身不等于收缩；机械阈可致轻度收缩，电阈产生动作电位和强收缩。
3. 收缩强度主要看每个慢波上的动作电位数量。
4. ENS 两神经丛的对象及其局部独立性。
5. 交感 / 副交感必须按管壁、括约肌和腺体分别判断。
6. 平滑肌 Ca²⁺—CaM—MLCK 主链。

### MI-D｜允许卡片化后置

- 胃、十二指肠、回肠末端慢波具体频率；
- 慢波波幅约 10–15 mV；
- 局部电位完整名单；
- 全部肠神经递质、受体和药物；
- 平滑肌 Ca²⁺回收通道完整名单；
- 先天性巨结肠低频细节。
