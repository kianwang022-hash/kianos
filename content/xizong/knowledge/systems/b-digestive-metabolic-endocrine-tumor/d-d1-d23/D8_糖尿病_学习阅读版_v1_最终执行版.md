## 2｜Framework｜先把糖尿病放回“状态切换失败”

### 2.1 正常底座

```text
餐后
胰岛素↑
→ 葡萄糖摄取 / 利用↑
→ 糖原、TAG、蛋白质合成↑
→ 脂解、糖异生、酮体生成受抑

空腹
胰岛素↓ + 胰高血糖素相对↑
→ 肝糖原动员 / 糖异生
→ 脂肪动员
→ 维持血糖和供能
```

### 2.2 两条主要失效路线

```text
T1DM
β细胞免疫性或特发性破坏
→ 胰岛素绝对缺乏
→ 糖不能有效利用 + 脂解 / 蛋白分解明显↑
→ 易自发DKA

T2DM
胰岛素抵抗（始发 / 特征）
→ β细胞代偿性高分泌
→ 分泌模式和数量逐渐失代偿
→ β细胞功能缺陷（关键）
→ 高血糖 + 全身代谢 / 血管损害
```

### 2.3 四层病例决策

```text
第一层｜是否正在危象？
DKA / HHS / 低血糖 / 其他昏迷

第二层｜是否达到糖尿病诊断？
症状 + FPG / 2hPG / 随机血糖 / HbA1c

第三层｜属于哪一型、还剩多少β细胞功能？
病程、体型、酮症、自身抗体、C肽 / 释放曲线

第四层｜已经损伤哪里？
肾 / 视网膜 / 神经 / ASCVD / 足 / 感染
→ 再选择长期治疗层级
```

# Unit A｜分型与自然史

## KP01｜糖尿病分型：先辨“绝对缺乏、抵抗失代偿、单基因或线粒体”

> **讲义定位 →** 内科P253
>
> **主提示：** T1两型｜T2两环｜MODY 5特征｜线粒体3点｜混合接口×2

### Detailed Expansion

1. **T1DM**：胰岛β细胞破坏，导致胰岛素绝对缺乏。
   - 1A：免疫介导，为主要类型；
   - 1B：特发性，缺乏明确自身免疫证据。
2. **T2DM**：可表现为“以胰岛素抵抗为主伴进行性分泌不足”，或病程后期转为“以分泌不足为主伴胰岛素抵抗”。
3. **MODY**：
   - 发病＜25岁；
   - 常染色体显性遗传；
   - 三代或以上家族史；
   - 自身抗体多阴性、无酮症倾向；
   - 至少5年内不依赖胰岛素，部分对磺酰脲反应。
4. **线粒体基因突变糖尿病**：母系遗传、起病早、常伴神经性耳聋；当前Study另提示乳酸酸中毒与用药接口，进入MI-D。
5. Study还列出LADA、缓慢进展免疫介导成人糖尿病、酮症倾向T2DM等混合接口；第一轮只识别其“不按年龄 / 体型机械归类”的意义。

（边界：完整基因分型和治疗差异不在当前Source范围。）

## KP02｜T1DM：外界触发怎样转成β细胞选择性破坏

> **讲义定位 →** 内科P253；病理P84
>
> **主提示：** 触发1｜免疫2路｜抗体3｜病理4点｜结果1

### Detailed Expansion

```text
遗传易感个体
+ 外界因素（Study例：柯萨奇病毒）
→ 病毒直接损伤β细胞
或激活自身免疫
→ T细胞介导细胞免疫为主要损伤路径
+ 体液抗体可作为分型 / 风险证据
→ β细胞进行性破坏
→ 胰岛素绝对缺乏
```

当前Study列举的抗体：ICA、IAA、GAD。它们用于确定高危人群、预测发病、协助分型与治疗判断，不等同于单独完成糖尿病诊断。

病理口径：β细胞数目减少、淋巴细胞浸润，可伴纤维素样坏死。

（易混：T1DM主要问题是“绝对缺乏”；年龄小、体型瘦只是高概率线索，不是定义。）

## KP03｜T2DM自然史：抵抗先起、β细胞失代偿决定发病

> **讲义定位 →** 内科P253–254；病理P84
>
> **主提示：** 靶器官3｜始发1｜代偿2｜关键1｜分泌缺陷3｜病理2

### Detailed Expansion

1. 胰岛素靶器官主要为肝、骨骼肌、脂肪组织。
2. **胰岛素抵抗**是多数T2DM的特征和始发因素：相同胰岛素水平产生的效应下降。
3. 早期β细胞通过增加分泌进行代偿；当前Study同时以脂质超载、炎症作为抵抗机制入口。
4. 随病程推进出现**β细胞功能缺陷**，它是发病关键和最后共同机制：
   - 最大分泌量下降；
   - 脉冲和第一时相减弱 / 消失、峰值延迟；
   - 胰岛素原 / 胰岛素比例改变。
5. 早期第二时相可代偿升高，峰值延迟可造成餐后血糖峰与胰岛素峰错位，部分患者出现餐后低血糖。
6. 病理：早期代偿性分泌同时伴淀粉样蛋白沉积；后期β细胞数量减少。

（易混：胰岛素抵抗是始发 / 特征；β细胞功能缺陷是关键。不要互换。）

## KP04｜T1DM vs T2DM：真正的比较轴不是年龄与胖瘦

> **讲义定位 →** 内科P254
>
> **主提示：** 机制｜β细胞｜抗体｜起病｜危象｜死因｜胰岛素｜C肽曲线

### Detailed Expansion

| 比较轴 | T1DM 1A | T2DM |
|---|---|---|
| 主机制 | 胰岛素绝对缺乏 | 抵抗 + 进行性分泌不足 |
| β细胞 | 自身免疫破坏，数量严重不足 | 早期尚可代偿，后期减少 |
| 起病线索 | 青少年可急；成人LADA可慢 | 多为慢性、隐匿 |
| 体型 / 年龄 | ＜40岁、偏瘦多见 | ＞40岁、偏胖多见 |
| 急性危象 | 有自发DKA倾向 | ＞50岁更易HHS；诱因下亦可DKA |
| 当前Study主要死因 | 肾病 | 心脑血管病 |
| 起病初期胰岛素 | 多数需要；可有蜜月期 | 多数暂不需要，但严重高血糖可短期强化 |
| C肽 / 胰岛素 | 低，曲线低平 | 可高 / 正常 / 低，峰延迟 |

（边界：表中年龄、体型和危象倾向只用于概率判断；分型仍需病程、自身抗体与β细胞功能证据。）

## KP05｜临床入口：三多一少与“视物模糊不等于视网膜病变”

> **讲义定位 →** 内科P253–254
>
> **主提示：** 三多一少各机制｜视物模糊2方向｜哪一种不等于视网膜病变

### Detailed Expansion

```text
高血糖
→ 滤过葡萄糖负荷↑、超过小管重吸收能力
→ 尿糖↑、小管液溶质浓度↑
→ 水重吸收↓、渗透性利尿
→ 多尿 → 多饮
```

葡萄糖利用障碍使机体动员脂肪和蛋白质，出现体重下降；细胞能量利用不足可伴多食。

血糖快速升高可改变房水和晶状体渗透压，使屈光度改变而视物模糊。它不必然意味着已经发生糖尿病视网膜病变；DR属于长期微血管并发症。

# Unit B｜急性代谢危象

<!-- kianos:kp id="dme-d08-kp06" -->
## KP06｜糖尿病并发症总地图：急、慢、感染与足

> **讲义定位 →** 内科P254
>
> **主提示：** 糖尿病并发症4组｜急性｜感染｜微/大血管｜神经｜足的构成要素

### Detailed Expansion

- **急性代谢并发症**：DKA、HHS。
- **感染**：血糖控制差时更常见且更重；Study列举泌尿感染、真菌性生殖道感染、肺结核等接口。DKA合并严重感染时，体温正常或降低可提示预后不良。
- **微血管病变**：基底膜增厚与微循环障碍，主要包括糖尿病肾病、视网膜病变、糖尿病心肌病。
- **ASCVD**：可累及主动脉、冠脉、脑、肾和肢体动脉。
- **神经病变**：Study称为最常见慢性并发症。
- **糖尿病足**：下肢远端神经异常 + 周围血管病变 + 感染 + 深层组织破坏共同形成。

## KP07｜DKA机制：为什么“糖很多”却转向大量产酮

> **讲义定位 →** 内科P254–255；Recall M7
>
> **主提示：** DKA：胰岛素不足→脂解/β氧化→酮体｜OAA去哪｜蛋白分解接口

### Detailed Expansion

```text
胰岛素绝对或显著不足
→ 组织葡萄糖利用障碍
→ 脂解↑，脂肪酸进入肝线粒体β氧化
→ 乙酰CoA大量生成

同时糖代谢紊乱
→ 草酰乙酸不足，TCA入口受限
→ 乙酰CoA转向乙酰乙酰CoA → HMG-CoA → 酮体
```

酮体包括乙酰乙酸、β-羟丁酸和丙酮；丙酮经肺排出形成烂苹果味。蛋白质分解增加，又提供生糖 / 生酮氨基酸，使高血糖和高血酮进一步加重。

（易混：DKA并不是“没有血糖”，而是高血糖背景下细胞无法正常利用并转向脂肪 / 蛋白分解。）

## KP08｜DKA识别：酮症 + 高AG代酸 + 严重失水

> **讲义定位 →** 内科P255
>
> **主提示：** DKA识别：人群/诱因｜高糖/酮症｜高AG代酸｜脱水｜呼吸/气味｜Na/渗透

### Detailed Expansion

- T1DM多见；感染是最常见诱因。T2DM在应激等诱因下也可发生。
- 血糖多为11.1–33.3 mmol/L；Study明确存在低于11.1的特殊情形，不据单一血糖排除。
- 尿糖、尿酮强阳性；血酮体≥3 mmol/L或尿酮++以上是重要证据。
- 呼气烂苹果味；Kussmaul深快呼吸。
- 高AG代谢性酸中毒：pH↓、HCO₃⁻↓、CO₂结合力↓、BE数值降低 / 负值增大、AG↑。
- 严重失水：高糖、高酮、酸性代谢物导致渗透性利尿，合并呕吐 / 摄入减少。
- 可出现低血容量性休克：血压低，但早期 / 过程中仍可因渗透性利尿而尿量多。
- 总Na⁺和总K⁺均可缺失，但检测浓度受失水、酸中毒和肾功能影响，不能直接代表体内储备。

## KP09｜DKA治疗主轴：先液体，再小剂量RI，血糖下降后补糖

> **讲义定位 →** 内科P255
>
> **主提示：** DKA治疗顺序｜补液｜RI｜何时加糖｜盐/糖先后｜监测项目

### Detailed Expansion

1. **补液是关键**：当前Study用0.9% NaCl，最初1–2小时补1000–2000 mL，原则为先快后慢、先盐后糖。
2. **胰岛素**：小剂量普通 / 短效胰岛素RI静脉滴注，0.1 U/kg·h。当前Study强调只有短效普通RI可静脉用于抢救DKA / HHS。
3. 血糖降至13.9 mmol/L时，改用5%葡萄糖生理盐水或5%葡萄糖 + 胰岛素，以继续抑制酮体而避免低血糖和血糖下降过快。
4. 同步监测血糖、酮体 / 酸碱、K⁺、尿量和循环状态。

（边界：以上剂量为当前Study考试口径，不替代临床医嘱。）

## KP10｜DKA补钾与补碱：浓度正常不代表总钾正常

> **讲义定位 →** 内科P255–256
>
> **主提示：** DKA补K：总钾 vs 血钾｜何时先补K｜何时可补｜何时停｜补碱门槛/风险

### Detailed Expansion

### 补钾

- K⁺<3.5 mmol/L：补液和胰岛素开始时立即补钾；Study进一步提示K⁺<3.3时优先补钾。
- K⁺正常、尿量>40 mL/h：开始治疗时补钾。
- K⁺正常、尿量<30 mL/h：暂缓，待尿量增加。
- K⁺>5.5 mmol/L：暂缓补钾，持续监测。

原因：DKA体内总钾常严重缺失；治疗前血钾可因酸中毒、细胞外移和血液浓缩而正常甚至升高。胰岛素和补液后K⁺进入细胞 / 被稀释，低钾风险上升。

### 补碱

一般经补液和胰岛素后酸中毒可纠正。当前Study仅在pH≤6.9时补等渗NaHCO₃，并要求先纠正低钾。

不恰当补碱可导致：氧解离曲线左移、低钾、碱中毒、反常性脑脊液酸中毒、脑水肿。

## KP11｜HHS识别：极高血糖与高渗主导，酮症不突出

> **讲义定位 →** 内科P255–256
>
> **主提示：** HHS：人群｜高糖/高渗｜酮症程度｜Na方向｜最关键检查｜与DKA对照

### Detailed Expansion

- 多见于＞50岁T2DM；超过2/3既往无糖尿病史，不能因无病史排除。
- 血糖多33.3–66.8 mmol/L，尿糖强阳性。
- 尿酮阴性或弱阳性，不以明显酸中毒为主。
- 血浆渗透压多为320–430，血Na⁺正常或升高，Study提示可>150。
- 最重要检查为血浆渗透压；需结合血糖和电解质，Study公式：

```text
有效血浆渗透压 = 2 ×（Na⁺ + K⁺）+ 血糖
```

（易混：电解质浓度受脱水程度影响，对DKA / HHS鉴别价值较小；DKA重点看酮体和血气，HHS重点看渗透压。）

## KP12｜HHS治疗：补液量更大，胰岛素剂量更小，通常不补碱

> **讲义定位 →** 内科P256
>
> **主提示：** HHS治疗：补液量｜液体选择｜何时低渗｜RI剂量｜何时加糖｜补碱？

### Detailed Expansion

- 24小时补液量可达6000–10000 mL；当前Study认为HHS失水通常比DKA更严重。
- 先使用等渗0.9% NaCl恢复血容量。
- 仅在已经输入生理盐水后、无休克 / 休克已纠正、血浆渗透压>350且血Na⁺>155时，才考虑低渗液。
- 普通RI静脉滴注0.05–0.1 U/kg·h；血糖降至16.7 mmol/L时改用5%葡萄糖 + 胰岛素。
- 通常不补NaHCO₃；补钾原则同DKA。
- 当前Study另列CRRT可降低严重HHS发生MODS风险，作为MI-D接口保留。

## KP17｜糖尿病诊断：尿糖只提示，静脉血糖 / HbA1c才进入标准

> **讲义定位 →** 内科P258
>
> **主提示：** 糖尿病诊断：标本｜有症状时4条标准｜FPG/2h/随机/HbA1c阈值｜尿糖边界

### Detailed Expansion

- 血糖测定以静脉血浆为标准；Study强调血浆值高于全血。
- 有典型糖尿病症状时，以下任一项达到即可进入诊断：
  - FPG ≥7.0 mmol/L；
  - OGTT 2hPG ≥11.1 mmol/L；
  - 随机血糖 ≥11.1 mmol/L；
  - HbA1c ≥6.5%。
- 尿糖阳性只是线索，不能单独诊断；尿糖阴性也不能排除。肾糖阈和GFR变化可造成假阴性 / 假阳性入口。

（边界：无典型症状时的重复确认细节不在当前正文外推。）

## KP18｜IFG、IGT与控制目标：诊断阈值和治疗目标不是一回事

## KP19｜HbA1c、糖化白蛋白与尿糖：分别看多长时间、受什么干扰

> **讲义定位 →** 内科P258–259
>
> **主提示：** HbA1c vs GA｜各反映多久｜各受什么干扰｜尿糖边界

### Detailed Expansion

- HbA1c反映约2–3个月平均血糖；不能反映瞬时血糖、血糖波动，也不能确认是否发生过低血糖。

- 糖化白蛋白 / 果糖胺反映约2–3周；肾病综合征、肝硬化等改变白蛋白更新的状态可干扰结果。

## KP20｜C肽与胰岛素释放：不是诊断糖尿病，而是看β细胞还剩多少功能

> **讲义定位 →** 内科P259；Recall D7
>
> **主提示：** C肽用途｜外源胰岛素是否干扰｜T1 vs T2曲线｜刺激试验2类

### Detailed Expansion

- 胰岛素原裂解产生胰岛素和C肽；一个内源胰岛素对应一个C肽。
- 外源胰岛素会干扰胰岛素测定，而C肽较能反映内源β细胞功能。
- T1DM：C肽 / 胰岛素低，释放曲线低平；T2DM：可高、正常或低，高峰常延迟。
- 静脉葡萄糖—胰岛素释放试验、高糖钳夹试验：反映葡萄糖介导的第一时相。
- 胰高血糖素—C肽、精氨酸—C肽：反映非葡萄糖刺激的分泌功能。

（边界：这些试验用于分型和功能评估，不替代糖尿病诊断阈值。）

## KP21｜综合管理与胰岛素适应证：先判断是否必须用胰岛素

> **讲义定位 →** 内科P259–260
>
> **主提示：** 五驾马车｜注射2类｜胰岛素6组｜T2介入5情形｜911短强

### Detailed Expansion

“五驾马车”：健康教育、医学营养、运动、病情监测、药物治疗。

1. T1DM一经诊断开始并终身替代（LADA早期为Study例外）；
2. 某些特殊类型；
3. 新发、消瘦、与T1DM难鉴别；
4. DKA、HHS、DKD等严重并发症；
5. 手术、妊娠、分娩等应激状态；

## KP22｜胰岛素制剂与清晨高血糖：先看整夜曲线

> **讲义定位 →** 内科P260–261
>
> **主提示：** 胰岛素制剂4类｜哪种可静脉｜作用时程｜清晨高血糖3型｜调整方向

### Detailed Expansion

- 普通短效RI：可静脉抢救DKA / HHS；皮下注射控制一餐后血糖。
- 速效类似物：门冬、赖脯、谷赖；餐前控制一餐。
- 中效：中性精蛋白，可供基础或覆盖两餐。
- 长效 / 长效类似物：精蛋白锌、甘精、地特、德谷；供基础胰岛素。
- 常用方案：三餐前短 / 速效 + 睡前长效，即“三短一长”。

清晨空腹血糖高先测夜间多点血糖：

1. 整夜均高：夜间胰岛素不足 → 增加；
2. 夜间3.9–6，黎明4–8点升高：黎明现象 → 针对黎明补充；
3. 夜间<3.9后反跳：Somogyi效应 → 减少夜间胰岛素。

## KP23｜GLP-1RA、二甲双胍与α-糖苷酶抑制剂

> **讲义定位 →** 内科P261–262
>
> **主提示：** GLP-1RA/二甲双胍/α糖苷酶抑制剂｜机制｜代表药｜主要风险/禁忌｜用药时点

### Detailed Expansion

### GLP-1RA

代表：艾塞那肽、利拉鲁肽、司美格鲁肽、替尔泊肽；Study把替尔泊肽列为GLP-1/GIP双受体激动剂。

## KP24｜磺酰脲、格列奈与噻唑烷二酮：分泌、早相与增敏

### Detailed Expansion

### 磺酰脲类

- 格列苯脲、格列齐特、格列喹酮；

## 3｜MI-G｜第一轮必须即时恢复

1. T1DM＝β细胞破坏→胰岛素绝对缺乏；T2DM＝抵抗始发 + β细胞缺陷关键。
2. DKA：酮症 + 高AG代酸 + 严重失水；HHS：极高血糖 + 高渗，酮症不突出。
3. DKA补液优先；RI 0.1 U/kg·h；13.9 mmol/L后补糖。
4. DKA总钾常缺失；补钾要结合血钾与尿量。
5. HHS血糖33.3–66.8、渗透压320–430；最重要检查为血浆渗透压。
6. DKD：弥漫最常见 / 影响最大；K-W结节最具特征。
7. DR：NPDRⅠ–Ⅲ → PDRⅣ–Ⅵ；新生血管是增生入口。
8. 诊断阈值：FPG 7、2hPG / 随机11.1、HbA1c 6.5。
9. HbA1c看2–3个月，不看瞬时、波动和是否低血糖。
