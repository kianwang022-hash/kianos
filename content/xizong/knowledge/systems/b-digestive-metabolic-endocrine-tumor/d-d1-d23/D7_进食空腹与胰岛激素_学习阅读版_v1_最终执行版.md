## KP01｜胰岛素受体与IRS：信号怎样从膜进入细胞

> **主提示：** 胰岛素受体类型｜自身磷酸化｜IRS｜PI3K-AKT vs MAPK｜各主效应

胰岛素受体是酪氨酸激酶受体。胰岛素结合后，受体发生磷酸化并招募IRS，形成两条主要输出：

```text
IRS → PI3K → PIP3 → AKT
→ GLUT4转位、糖脂蛋白代谢效应

IRS → MAPK
→ 生长 / 基因表达接口
```

当前Study IRS分布：

- IRS-1：骨骼肌；
- IRS-2：肝、胰岛B细胞；
- IRS-3：脑、脂肪；
- IRS-4：脑、垂体。

Study解释：IRS-2产生同等效应所需浓度高于IRS-1，故IRS-1↓、IRS-2↑可与胰岛素抵抗相连。

## KP02｜胰岛素对糖代谢：减少来源、增加去路

> **主提示：** 胰岛素对糖：摄取/利用/储存/生成｜肝肌脂差别｜GLUT4在哪

```text
血糖去路↑
= 外周组织摄取↑ + 氧化利用↑ + 糖原合成↑

血糖来源↓
= 肝糖原分解↓ + 糖异生↓
```

胰岛素通过PI3K通路增加横纹肌与脂肪细胞膜上的GLUT4，促进葡萄糖进入；同时提高糖氧化关键酶活性，促进糖原合成。

（易混：肝细胞摄取葡萄糖的转运体语言与GLUT4并不相同；当前主线只需记GLUT4主要在横纹肌和脂肪。）

## KP03｜胰岛素对脂肪、蛋白与生长：它是全身储存信号

> **主提示：** 胰岛素对脂/蛋白/钾/生长｜合成 vs 分解方向｜氮平衡｜与GH关系

- 脂类：促进脂肪合成与储存，抑制脂解接口；
- 蛋白质：促进氨基酸利用与蛋白合成，抑制分解，形成正氮平衡，血氨基酸和尿素可下降；
- K⁺：促进K⁺进入细胞，连接高钾治疗；
- 生长：直接经胰岛素受体，也可经GH / IGF接口；单独作用促生长有限，与GH协同时更明显。

//串联：这解释为什么胰岛素或促胰岛素分泌药可增加体重；完整临床药物选择后置D8。

## KP04｜胰岛素双相分泌：先释放库存，再持续生产

> **主提示：** 双相分泌：快相来源/时程｜慢相来源/时程｜餐后意义

血糖急剧升高后：

1. 快速相：约5min内释放已储存胰岛素，峰值来得快；储量有限，5–10min后回落；
2. 慢速相：随后逐渐增加，在较长时间维持高水平，分泌量大，是控制持续餐后高血糖的重要阶段。

（易混：T2DM早期可出现第一时相减弱 / 消失、峰值延迟；完整疾病意义在D8。）

## KP05｜葡萄糖刺激B细胞：GLUT2—GK—ATP—KATP—Ca²⁺全链

> **主提示：** 葡萄糖→B细胞分泌胰岛素全链｜感糖酶｜KATP｜Ca²⁺｜出胞

```text
葡萄糖经GLUT2进入B细胞
→ 葡萄糖激酶磷酸化并进入氧化
→ ATP/ADP↑
→ ATP敏感K⁺通道关闭
→ K⁺外流↓，膜去极化
→ L型电压门控Ca²⁺通道开放
→ Ca²⁺内流
→ 胰岛素颗粒融合、出胞
```

这是D7最重要的闭环：葡萄糖既是代谢底物，也是B细胞的分泌信号。

## KP06｜促胰岛素分泌剂：关KATP、需B细胞、不看血糖

> **主提示：** 促泌剂2类｜共同靶点｜是否需B细胞｜是否依赖血糖｜主要风险

当前生理Study串联：

- 磺酰脲类，如格列齐特；
- 格列奈类，如瑞格列奈。

共同点：关闭B细胞KATP，触发去极化和Ca²⁺内流，促进胰岛素分泌；必须有一定功能的B细胞；分泌刺激不依赖当时血糖，因此主要风险为低血糖，并可增加体重。

（边界：适应证、禁忌证、代表药和选择顺序后置D8。）

## KP07｜神经调节：迷走促储存，交感保血糖

> **主提示：** 迷走 vs 交感｜受体/递质｜胰岛素方向｜运动时意义｜A/G细胞接口

- 迷走神经释放ACh作用M受体，促进胰岛素分泌；
- 交感释放NA：
  - α₂受体抑制胰岛素和胰高血糖素；
  - β₂受体促进二者；
  - NA对α₂作用占优，因此交感总体抑制胰岛素。

运动 / 应急时交感抑制胰岛素，有助于避免葡萄糖过快进入储存，维持血糖供应。

（易混：交感不是对所有胰岛激素绝对“只抑制”；关键是α₂占优。）

## KP08｜肠促胰素与前馈：为什么口服葡萄糖促胰岛素更强

> **主提示：** 肠促胰素2｜来源｜DPP4｜口服 vs 静脉效应｜前馈意义｜对应药物2类

食物尚在肠道时：

```text
K细胞 → GIP
L细胞 → GLP-1
→ 直接促进胰岛素
→ 为即将吸收入血的营养物提前准备
```

这就是肠—胰轴和前馈机制，解释口服等量葡萄糖比静脉葡萄糖引起更多胰岛素分泌。

- GIP：胰岛素↑、胰高血糖素↑；
- GLP-1：胰岛素↑、胰高血糖素↓；
- 两者可被DPP-4快速降解。

机制性药物接口：DPP-4抑制剂减少降解；GLP-1RA模拟GLP-1；替尔泊肽为GLP-1 / GIP双受体激动接口。完整临床使用后置D8。

## KP09｜旁分泌、营养底物与K⁺：多数促进，特殊抑制

> **主提示：** 胰岛素分泌：促进因素｜抑制因素｜长期高底物后果｜K⁺接口

促进胰岛素：

- 胰高血糖素：直接旁分泌 + 升糖间接；
- PACAP等；
- 血氨基酸、脂肪酸、酮体；
- 升糖激素先使血糖↑，再间接促胰岛素。

抑制胰岛素的高价值特殊：

- 生长抑素；
- 胰抑素；
- 甘丙肽；
- 神经肽Y；
- 交感α₂占优；
- 低血钾。

长时间高血糖、高氨基酸、高血脂持续刺激B细胞，可形成B细胞功能衰竭接口。

胰岛素促进K⁺入细胞，可用于高钾治疗；原醛导致低钾时可使胰岛素分泌下降、糖耐量下降。

## KP10｜胰高血糖素：空腹时主要把肝变成燃料输出器

> **主提示：** 胰高血糖素：来源｜受体通路｜主靶器官｜糖代谢｜脂/酮接口

胰高血糖素由胰岛A细胞分泌，经GPCR—cAMP—PKA通路，主要作用于肝脏。

```text
空腹 / 低血糖
→ 胰高血糖素相对占优
→ 肝糖原分解↑
→ 糖异生↑
→ 肝向血液输出葡萄糖
→ 脂肪动员和酮体形成接口
```

当前Study还把胰高血糖素与抑制胃酸 / 胃运动、抑制胰液分泌等接口相连，列入MI-D，不抢占主干。

（易混：骨骼肌不是胰高血糖素的主要靶器官。）

## KP11｜胰岛素 vs 胰高血糖素：来源、受体、靶器官、代谢四轴

> **主提示：** 胰岛素 vs 胰高血糖素｜来源｜受体｜靶器官｜合成/分解｜K⁺｜分泌调节

| 轴 | 胰岛素 | 胰高血糖素 |
|---|---|---|
| 来源 | B细胞 | A细胞 |
| 受体 | 酪氨酸激酶受体 | GPCR—cAMP—PKA |
| 主要靶器官 | 肝、骨骼肌、脂肪等 | 主要肝脏 |
| 总代谢方向 | 合成、储存、利用 | 分解、动员、输出 |
| 血糖 | ↓ | ↑ |
| 其他 | K⁺入细胞、促生长 | 肝燃料输出、消化液接口 |

两者不是简单开关，而是在进食、空腹和应激中以比例变化共同决定底物流向。

## KP13｜空腹 / 应激状态整合：怎样维持血糖并切换燃料

> **主提示：** 空腹/应激：糖原→糖异生｜脂解→酮体｜反调节激素｜胰岛素/胰高比值

```text
空腹 / 运动 / 应激
→ 血糖与胰岛素下降
→ 胰高血糖素 + 交感 / 反调节激素相对占优
→ 肝糖原分解维持早期血糖
→ 糖异生接力
→ 脂肪组织脂解，FA供能
→ 肝酮体输出接口
→ 蛋白分解在长期 / 高应激时增加
```

- 胰高血糖素更像“空腹肝脏动员信号”；
- 儿茶酚胺、GC、GH、TH等在不同状态产生升糖倾向，但各自完整轴后置；
- 过度动员 + 胰岛素不足可走向DKA，完整模型在D8。
