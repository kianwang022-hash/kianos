# D16｜病毒性肝炎
## 先看坏死发生在哪里、跨过哪些结构，再判断病型与结局

> **中心问题**：病毒感染后，肝细胞从水样变性、点状坏死，怎样升级为界面坏死、桥接坏死和大块坏死；坏死的位置与范围又怎样决定急性、慢性、重型、再生、纤维化和肝硬化风险？
>
> **文件性质**：消化系统肝胆胰支路的第一个 canonical Block。这里完整建立病毒性肝炎的病理运行模型；肝硬化、门静脉高压和肝性脑病进入 D17，HCC进入 D18。
>
> **Primary Study**：`病理学讲义_AI阅读版.md` PDF P6–12《病毒性肝炎》。
>
> **Primary Outline**：病理 U006，**28 / 28**。
>
> **边界**：本 Block以病理形态、病型与病毒特殊为主体；不补写完整肝炎临床诊疗、抗病毒方案、血清学组合或外部指南。胆红素完整代谢已在 M10 Primary，这里只调用“肝细胞处理与胆汁输出受损可致黄疸”。

# 1｜总 Framework

<!-- kianos:framework id="digestive-d16-framework-main" -->

```text
病毒性肝炎 = 以肝细胞损伤为主的变质性炎
  ↓
第一层｜细胞损伤形式
  ├─ 水样 / 气球样变：急性普通型最常见
  ├─ 嗜酸性变 → 嗜酸性坏死 / Councilman小体：凋亡
  ├─ 脂肪变：HCV、HDV较多见
  └─ 溶解性坏死：点状—碎片/界面—桥接—亚大块/大块
  ↓
第二层｜组织反应
  ├─ 淋巴细胞 + 单核细胞浸润
  ├─ Kupffer细胞增生
  ├─ 残存肝细胞再生
  ├─ 小胆管增生
  └─ 星状细胞等产胶原 → 纤维化
  ↓
第三层｜病型
  ├─ 急性普通型：广泛水样变 + 轻度点状坏死
  ├─ 慢性较轻：点状 + 轻度界面坏死
  ├─ 慢性较重：明显界面 + 桥接坏死 → 肝硬化风险高
  ├─ 急性重型：大块坏死 + 网状支架塌陷，几乎无再生/纤维化
  └─ 亚急性重型：亚大块坏死 + 结节再生 + 纤维化 → 可进肝硬化
  ↓
第四层｜病毒特殊
  ├─ HAV / HEV：粪—口、通常仅急性；妊娠HEV重症风险
  ├─ HBV：DNA；毛玻璃样细胞 / 砂粒样核
  ├─ HCV：最易慢性；脂肪变 + 门管区淋巴滤泡 + 胆管损伤
  ├─ HDV：依赖HBV；脂肪变接口
  └─ EBV：点状坏死 + 窦内淋巴/单核细胞单列样排列
```

## KP01｜病毒性肝炎的总病理身份

> **主提示：病毒性肝炎病理身份｜损伤形态3｜坏死4级｜反应2方向**

### 详细展开

病毒性肝炎的中心不是“肝里有炎细胞”，而是：

> **病毒相关损伤以肝细胞变性、凋亡和溶解性坏死为主，因此归入变质性炎。**

当前 Study 的形态语言分三层：

1. **变性**：水样 / 气球样变、嗜酸性变、脂肪变；
2. **细胞死亡**：Councilman小体所代表的凋亡，以及不同范围的溶解性坏死；
3. **组织反应**：淋巴—单核细胞浸润、Kupffer细胞增生、肝细胞再生、胆管增生与纤维化。

（易混：**脂肪变性 ≠ 脂肪坏死**。病毒性肝炎可以有脂肪变性；Study列出的典型脂肪坏死场景是重症胰腺炎等，不要因“脂肪”二字混同。）

**Routing**：CORE｜CONFUSABLE｜MI-G

<!-- kianos:kp id="digestive-d16-kp02" -->
## KP02｜水样、嗜酸性与脂肪变：三种肝细胞方向

> **主提示：水样/嗜酸性/脂肪变｜各形态｜可逆/坏死关系｜哪些病毒更常见**

### 详细展开

| 形态 | Study要点 | 主要定位 |
|---|---|---|
| 水样 / 气球样变 | 肝细胞体积增大、胞质疏松淡染，气球样改变 | 急性普通型最常见 |
| 嗜酸性变 | 胞质浓缩、嗜酸性增强，可进一步形成嗜酸性坏死 | 可见于病毒性肝炎 |
| 嗜酸性坏死 | 单个肝细胞皱缩、嗜酸性，形成Councilman小体 | 本质是凋亡 |
| 脂肪变 | 细胞内脂滴蓄积 | HCV、HDV较多见 |

抓住方向：

```text
水进入 / 细胞肿胀 → 水样、气球样变
蛋白浓缩 / 细胞皱缩 → 嗜酸性变
细胞程序性死亡 → Councilman小体
脂质蓄积 → 脂肪变
```

（特殊：肝脏在Study中可出现凝固性和液化性坏死；病毒性肝炎这里重点识别的是溶解性坏死的范围分类。）

**Routing**：CORE｜SPECIAL｜CONFUSABLE｜MI-G

## KP03｜四级溶解性坏死：点—界—桥—块

> **主提示：点/界/桥/块｜位置｜范围｜病型｜结局**

### 详细展开

| 坏死 | 空间身份 | 常见病型 / 含义 | 结局重点 |
|---|---|---|---|
| 点状坏死 | 一个至数个肝细胞的小灶性溶解 | 急性普通型特征；慢性较轻也可见 | 支架保留时可完全再生 |
| 碎片状 / 界面坏死 | 肝小叶周边、界板处肝细胞成片坏死，炎症越过界板 | 慢性肝炎入口 | 持续存在提示慢性活动性损伤 |
| 桥接坏死 | 坏死带连接门管区—门管区、中央静脉—中央静脉或门管区—中央静脉 | 较重慢性肝炎 | 与肝硬化形成最密切 |
| 亚大块 / 大块坏死 | 大范围肝实质坏死并致网状支架塌陷 | 亚急性 / 急性重型 | 肝衰竭；能否再生和纤维化决定后续 |

最短恢复链：

```text
坏死范围增大
→ 原有肝小叶支架破坏加重
→ 再生越来越难按原结构恢复
→ 纤维隔连接并重新分割
→ 肝硬化风险上升
```

//串联：D17为什么以“桥接坏死 + 修复/纤维化”为硬前置？

**Routing**：CORE｜CONNECTION｜MI-G

## KP04｜Councilman小体：看似“坏死”，本质是凋亡

> **主提示：形成链3步｜本质1｜与溶解性坏死差异**

### 详细展开

```text
肝细胞嗜酸性变
→ 细胞皱缩、胞质强嗜酸
→ 嗜酸性小体 / Councilman小体
```

它在当前 Study 中的本质是：

> **单细胞凋亡。**

与大片溶解性坏死相比：

- Councilman小体偏向单个细胞的程序性死亡；
- 溶解性坏死按受累范围形成点状、界面、桥接和大块；
- 二者可在同一病毒性肝炎标本中并存。

（易混：名称中出现“嗜酸性坏死”不等于这里按一般坏死机制理解；考试要求认出它的凋亡身份。）

**Routing**：CONFUSABLE｜RECOGNITION｜MI-G

## KP05｜渗出、增生与纤维化：谁来清除、再生和造胶原

> **主提示：炎细胞2｜增生4类｜产胶原主角｜再生细胞3特征**

### 详细展开

### 1｜渗出

主要为：

- 淋巴细胞；
- 单核细胞。

它符合病毒性损伤以单核细胞系统反应为主的形态背景。

### 2｜增生 / 修复反应

- **Kupffer细胞**：吞噬与清除；
- **残存肝细胞**：再生；
- **小胆管**：可增生；
- **成纤维细胞 / 肝星状细胞等**：合成胶原，推动纤维化。

Study把肝星状细胞放在“导致肝硬化最重要的产胶原细胞”位置。

### 3｜再生肝细胞

当前讲义强调其可表现为：

- 体积较大；
- 核较大、可见双核；
- 排列和正常肝索不完全一致。

关键边界：

> **有再生不等于恢复正常结构。** 若网状支架已塌陷，再生细胞会在纤维隔包围下形成异常结节，进入D17的假小叶模型。

**Routing**：CORE｜CONNECTION｜MI-G

<!-- kianos:kp id="digestive-d16-kp06" -->
## KP06｜急性普通型：肝大、广泛水样变、轻度点状坏死

> **主提示：肉眼2｜镜下4｜特征坏死1｜结局**

### 详细展开

急性普通型的核心不是“大面积坏死”，而是：

```text
广泛水样 / 气球样变
+ 轻度点状坏死
+ 嗜酸性小体
+ 轻度淋巴—单核浸润
```

肉眼上可见肝脏肿大；镜下以广泛细胞肿胀为主，坏死范围较小。

为什么多数能恢复：

- 点状坏死只破坏少量细胞；
- 网状支架多保留；
- 肝细胞再生能力强；
- 因此可以发生完全性再生。

（易混：急性普通型最常见的肝细胞改变是**水样变性**，特征性坏死是**点状坏死**；不要把重型肝炎的大块坏死提前套入。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP07｜慢性普通型：轻重看界面与桥接，不只看炎细胞多少

> **主提示：慢轻3点｜慢重3坏死｜肝硬化门槛**

### 详细展开

| 病型 | 主要形态 |
|---|---|
| 较轻慢性肝炎 | 点状坏死为主，可有轻度碎片 / 界面坏死；门管区慢性炎细胞浸润 |
| 较重慢性肝炎 | 明显碎片 / 界面坏死 + 桥接坏死，可伴小叶结构破坏与纤维化 |

判断慢性程度时，优先追踪：

1. 炎症是否越过界板；
2. 坏死是否把两个结构“桥接”起来；
3. 是否已出现进行性纤维化与小叶重构。

```text
持续界面损伤
+ 桥接坏死
→ 修复性纤维隔
→ 原小叶被重新分割
→ 肝硬化
```

//串联：D17假小叶不是单纯“纤维多”，而是坏死—支架破坏—结节再生—纤维隔共同造成结构重建。

**Routing**：CORE｜CONNECTION｜MI-G

<!-- kianos:kp id="digestive-d16-kp08" -->
## KP08｜急性重型 vs 亚急性重型：都塌架，差在再生和纤维化

> **主提示：急重 vs 亚急重：色｜坏死范围｜支架｜再生｜纤维化｜结局**

### 详细展开

| 比较轴 | 急性重型肝炎 | 亚急性重型肝炎 |
|---|---|---|
| 肉眼 | 肝体积缩小、质软；切面黄色或红褐色改变 | 黄绿色等改变，病程相对延长 |
| 坏死 | 大块坏死，可广泛累及小叶 | 亚大块坏死 |
| 网状支架 | 塌陷 | 塌陷 |
| 残存肝细胞 | 少，明显再生不突出 | 可有明显结节状再生 |
| 纤维化 | 来不及形成或不突出 | 可形成纤维化 |
| 结局 | 急性肝衰竭、死亡风险高 | 可进入坏死后性大结节性肝硬化 |

最关键的逻辑不是背颜色，而是：

```text
损伤速度极快
→ 大量肝细胞死亡
→ 来不及再生和纤维化
= 急性重型

病程稍延长
→ 坏死仍大，但再生与纤维化已启动
= 亚急性重型
```

**Routing**：CORE｜DISCRIMINATION｜MI-G｜MI-D

## KP09｜HAV与HEV：粪—口、通常急性；HEV有两个特殊

> **主提示：传播1｜慢性？｜HEV特殊×2**

### 详细展开

HAV与HEV在当前 Study 的共同轴：

- 主要经消化道 / 粪—口传播；
- 通常只引起急性肝炎；
- 一般不进展为肝硬化。

HEV的两个特殊：

1. **免疫抑制患者**感染后可慢性化，甚至进展为肝硬化；
2. **妊娠合并HEV**更容易发生暴发型 / 急性重型肝炎。

（边界：本 Block不扩写流行病学、疫苗和抗病毒治疗。）

**Routing**：RECOGNITION｜SPECIAL｜MI-G

## KP10｜HBV：DNA病毒；毛玻璃看surface，砂粒核看core

> **主提示：HBV：病毒类型｜毛玻璃细胞看什么｜砂粒核看什么｜复制接口**

### 详细展开

### 1｜毛玻璃样肝细胞

```text
肝细胞胞质内充满细颗粒
→ 胞质不透明、似毛玻璃
→ HBsAg阳性
→ 光面 / 滑面内质网增生
```

记忆轴：**surface在胞质表面感，HBsAg进入smooth ER。**

### 2｜砂粒样细胞核

```text
肝细胞核呈砂粒样
→ 核内HBcAg多
→ 提示HBV复制活跃
```

### 3｜病毒身份

HBV属于DNA病毒。讲义以“BBPP巨”并列常见DNA病毒识别；完整病毒分类不是本 Block主体，放入MI-D。

（易混：毛玻璃样胞质主要对应HBsAg；砂粒样核主要对应HBcAg与复制活跃。）

## KP11｜HCV与HDV：谁最易慢性，谁依赖HBV

> **主提示：HCV：慢性1 + 形态3｜HDV：依赖谁 + 脂变接口**

### 详细展开

### HCV

当前 Study最重要的身份：

- 最易转为慢性肝炎；
- 与肝硬化关系密切；
- 慢性病变除一般慢性肝炎形态外，常见：
  1. 肝细胞脂肪变；
  2. 门 / 汇管区淋巴滤泡形成；
  3. 胆管损伤。

### HDV

- 需要HBV提供包膜相关条件，具有依赖性；
- 也可见脂肪变性接口；
- 其完整感染方式和临床管理不在当前 Source范围内扩写。

//串联：HCV长期慢性损伤 → D17纤维化/肝硬化 → D18 HCC风险。

**Routing**：CORE｜SPECIAL｜CONNECTION｜MI-G

## KP12｜EBV肝炎与五型病毒快速比较

> **主提示：EBV：点坏｜门管｜窦内单列｜五型：传播/慢性/特殊**

### 详细展开

EBV肝炎在当前 Lecture 中的识别点：

- 点状坏死；
- 门管区炎细胞浸润；
- 肝血窦内淋巴细胞、单核细胞增多，可呈“单列样”排列。

五型病毒的第一轮比较：

| 病毒 | 传播/依赖 | 慢性化 | Study特殊 |
|---|---|---|---|
| HAV | 粪—口 | 通常无 | 急性为主 |
| HBV | 当前Block不展开完整传播谱 | 可 | DNA；毛玻璃样细胞、砂粒样核 |
| HCV | 当前Block不展开完整传播谱 | 最易 | 脂肪变、淋巴滤泡、胆管损伤 |
| HDV | 依赖HBV | 可 | 与HBV共/重叠感染接口 |
| HEV | 粪—口 | 通常无；免疫抑制例外 | 妊娠重型风险 |

# 3｜高密度核对

## 3.1 坏死形态一张表

| 看什么 | 点状 | 碎片/界面 | 桥接 | 亚大块/大块 |
|---|---|---|---|---|
| 范围 | 1至数个细胞小灶 | 小叶周边界板 | 坏死带连接两结构 | 广泛肝实质 |
| 典型病型 | 急性普通型 | 慢性肝炎 | 较重慢性 | 重型肝炎 |
| 支架 | 多保留 | 局部破坏 | 明显破坏 | 塌陷 |
| 结局 | 可完全再生 | 慢性活动 | 最关联肝硬化 | 肝衰；亚急性可硬化 |

## 3.2 病型一张表

| 病型 | 变性 | 坏死 | 再生/纤维化 |
|---|---|---|---|
| 急性普通型 | 广泛水样/气球样 | 轻度点状 + 嗜酸性小体 | 多可完全恢复 |
| 慢性较轻 | 可有水样/脂肪变 | 点状 + 轻度界面 | 轻度纤维化 |
| 慢性较重 | 持续损伤 | 明显界面 + 桥接 | 进展性纤维化，可肝硬化 |
| 急性重型 | 大量细胞死亡 | 大块 | 支架塌陷，几乎无明显再生/纤维化 |
| 亚急性重型 | 持续坏死 | 亚大块 | 结节再生 + 纤维化，可大结节硬化 |
