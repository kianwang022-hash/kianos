# D13｜腹膜感染与腹部损伤
## 从“腹膜被刺激”到“出血—污染—源控制—探查”

> **中心问题**：急腹症出现腹痛、腹膜刺激征、移动性浊音或休克时，怎样先判断腹腔内是感染、消化液、血液还是脏器破裂，再决定穿刺、影像、复苏、引流或剖腹探查？
>
> **Primary ownership**：腹膜解剖与感染、原发/继发性腹膜炎、腹腔脓肿、腹部损伤的分类—器官定位—检查—探查在本 Block 首次完整学习。

# 3｜腹膜与腹膜炎

<!-- kianos:kp id="digestive-d13-kp01" -->
## KP01｜腹膜：渗出、吸收、修复三种能力同时带来利与弊

> **主提示：面积1｜功能3｜盆腹膜特殊｜壁/脏神经｜痛定位｜粘连链**

### 快速核对

- 腹膜面积几乎与全身皮肤面积相等，约 1.5 m²；
- 三项功能：渗出、吸收、修复；
- 盆腹膜吸收相对较差，因此引流时常利用重力让脓液向盆腔集中；
- 壁腹膜由体神经支配：定位准确，出现压痛、反跳痛、肌紧张，改变体位疼痛加剧；
- 脏腹膜由自主神经支配：定位不准确。

```text
腹膜受刺激
→ 纤维素渗出
→ 若未完全溶解吸收
→ 机化/粘连
→ 粘连性肠梗阻
```

（易混：腹膜修复快不等于不会留下后遗症；“修复”本身可造成粘连。）

---

<!-- kianos:kp id="digestive-d13-kp02" -->
## KP02｜原发 vs 继发腹膜炎：源在腹腔内还是从别处到来

> **主提示：继发来源1｜感染性质｜常见菌2｜原发4路｜3路菌-人群配对**

### 快速核对

**继发性腹膜炎**：多继发于腹腔空腔脏器穿孔或损伤；常为混合感染，大肠杆菌、厌氧菌多见。

**原发/自发性腹膜炎**：腹腔内无明确穿孔源，当前 Study 列四路：

1. 血行播散：链球菌，多见婴幼儿；
2. 上行感染：淋球菌，多见女性；
3. 透壁性：大肠杆菌，多见肝硬化腹水；
4. 直接扩散。

```text
继发性：先找穿孔/坏死/损伤源
原发性：先看宿主背景与传播路径
```

<!-- kianos:kp id="digestive-d13-kp03" -->
## KP03｜继发性腹膜炎识别：持续剧痛 + 腹膜刺激征 + 毒素入血

> **主提示：腹痛3词｜标志体征3｜全身2｜恶化4｜原发部位原则**

### 快速核对

- 腹痛：持续、剧烈，原发部位最显著；
- 标志体征：压痛、反跳痛、肌紧张；
- 毒素入血：发热、脉快；
- 病情恶化：腹胀加重、脉快，但体温反而下降，腹水炎细胞增加；
- 肠鸣音可因麻痹性肠梗阻而减弱。

（易混：病情恶化时体温下降不代表感染改善，可能是循环衰竭和机体反应下降。）

## KP04｜腹腔穿刺液：六种液体先指向六类源

> **主提示：穿刺液6型｜颜色/凝固/气味/酶｜分别指向哪个源**

### 快速核对

| 穿刺液 | 当前外科 Lecture 指向 |
|---|---|
| 不凝血 | 腹腔内出血，多为实质脏器损伤 |
| 草绿色透明液 | 结核性腹膜炎 |
| 黄色浑浊、含胆汁、无臭 | 胃十二指肠穿孔 |
| 含淀粉酶的血性液 | 急性重型胰腺炎 |
| 稀薄脓性、略臭 | 急性阑尾炎 |
| 臭味重的血性液 | 绞窄性肠梗阻 |

为什么腹腔内出血常“不凝”？讲义以腹膜去纤维蛋白作用解释。

## KP05｜腹膜炎处理：体位、胃肠休息、抗感染与源控制

> **主提示：腹膜炎处理：体位｜胃肠休息/支持｜抗感染｜休克｜源控制/切口｜时间窗**

### 快速核对

- 半卧位：减少毒素吸收、利于引流，也利于呼吸循环；
- 禁食、补液、胃肠减压；
- 当前 Lecture 以三代头孢等作为抗感染接口；
- 休克或持续源未控制者需手术探查；
- 继发性腹膜炎的当前切口口径：右旁正中切口；
- 讲义强调尽早处理，避免化学性腹膜炎继续发展为化脓性腹膜炎，争取在 6–8 h 内处理。

（边界：完整抗菌覆盖和现代脓毒症流程后置 H25–H27。）

## KP06｜膈下 vs 盆腔脓肿：高处牵连胸膜，低处刺激直肠膀胱

> **主提示：膈下5表现+首选｜盆腔来源2｜刺激2系｜首选检查｜引流2路｜药物2类**

### 快速核对

**膈下脓肿**：

- 发热、上腹痛、呃逆；
- 膈肌抬高；
- 可有胸膜炎；
- 首选 B 超。

**盆腔脓肿**：

- 多继发于阑尾炎、腹盆腔手术后；
- 肛门下坠感、里急后重；
- 可有尿频、尿急、尿痛；
- 首选直肠指检：直肠前壁触痛、波动性肿块；
- 可经直肠前壁或阴道后穹窿穿刺后切开引流；
- 当前 Lecture 使用三代头孢 + 甲硝唑。

```text
膈下 → 膈/胸膜接口
盆腔 → 直肠/膀胱接口
```

# 4｜腹部损伤：先用“出血轴—污染轴”组织全部器官

<!-- kianos:kp id="digestive-d13-kp07" -->
## KP07｜损伤分类：皮肤、腹膜与伤道是三件不同的事

> **主提示：闭/开放看什么｜穿透/非穿透看什么｜最常器官2｜伤口-伤情边界2**

### 快速核对

- 闭合伤 vs 开放伤：看腹部皮肤是否完整；
- 非穿透伤 vs 穿透伤：看腹膜是否完整；
- 闭合伤最常见脾损伤；
- 开放伤最常见肝损伤；
- 穿透伤的入口、出口与伤道不一定在一条直线上；
- 伤口大小与伤情严重程度不一定成正比。

（易混：一个小入口也可能有深部多器官伤；不能按皮肤伤口大小推断腹腔损伤。）

---

<!-- kianos:kp id="digestive-d13-kp08" -->
## KP08｜两条主轴：实质脏器主要丢血，空腔脏器主要污染

> **主提示：出血5证据｜污染4证据｜实质3器官｜空腔4组｜休克/腹膜炎节奏**

### 快速核对

**出血轴**：Hb↓、BP↓、早期休克、移动性浊音、肠鸣音减弱/消失。脾、肝、胰等实质脏器出血更明显；胰腺位于腹膜后，早期腹腔内血液可不多。

**污染轴**：腹痛、压痛、反跳痛、肌紧张，肠鸣音减弱/消失；空腔脏器消化液和细菌刺激腹膜。

```text
实质脏器破裂 → 血容量丢失 → 休克为主
空腔脏器破裂 → 内容物外漏 → 腹膜炎为主
```

但二者可重叠：肝损伤既可大量出血，又有胆汁刺激；胰腺位于腹膜后但胰液刺激强。

<!-- kianos:kp id="digestive-d13-kp09" -->
## KP09｜腹膜关系决定腹膜炎“早/晚”，刺激物决定“轻/重”

> **主提示：腹膜关系→腹膜炎早/晚｜刺激物→轻/重｜各器官位置怎么推**

### 快速核对

| 器官 | 腹膜炎节奏 | 原因框架 |
|---|---|---|
| 脾 | 早而轻 | 腹膜关系密切；血液刺激轻 |
| 肝 | 早而重 | 腹膜内 + 胆汁刺激 |
| 胃前壁、空回肠、十二指肠1部 | 早而重 | 内容物迅速入腹腔 |
| 胃后壁、十二指肠2/3部、胰腺 | 晚而重 | 腹膜后/网膜囊；消化液刺激强 |
| 大部分结肠、直肠上段 | 晚而重 | 内容物较干、扩散慢 |
| 直肠下段 | 无典型腹膜炎 | 腹膜反折以下 |

腹膜外/后位记忆：胃后、十二指肠水平/降部、胰、输尿管、直肠下段、肾、肾上腺。

（易混：早期腹部体征轻不等于损伤轻；十二指肠2/3部损伤可全身进行性恶化。）

# 5｜器官特异模型

<!-- kianos:kp id="digestive-d13-kp10" -->
## KP10｜脾损伤：左上腹、早期休克、腹膜炎早而轻

> **主提示：脾损伤：背景/部位｜休克｜腹膜炎节奏｜治疗｜儿童特殊｜延迟破裂**

### 快速核对

- 左上腹外伤、左膈肌抬高；
- 常早期失血性休克；
- 腹膜炎早而轻；
- 处理：脾修补或切除，同时抗休克；
- <6 岁切脾后可自体脾片移植，以避免以肺炎链球菌感染为主的 OPSI；
- 可行回收式自体输血；
- 预防延迟性脾破裂：绝对卧床 >1 周。

（边界：当前不扩写脾损伤分级和所有保脾介入方案。）

<!-- kianos:kp id="digestive-d13-kp11" -->
## KP11｜肝损伤：双重血供导致大出血，胆汁让腹膜刺激更重

> **主提示：肝损伤：双血供→出血｜胆汁→腹膜刺激｜特殊通路｜修补｜Pringle时间**

### 快速核对

- 右上腹外伤、右膈肌抬高；
- 多有早期休克，腹膜炎早而重；
- 血液进入胆道/十二指肠 → 呕血或黑便；
- 累及肝静脉主干或下腔静脉 → 空气栓塞；
- 中央型肝破裂血肿 → 可继发肝脓肿；
- 处理：肝修补 + 抗休克；
- 大量活动性出血可阻断肝十二指肠韧带/门管三联入肝血流：每次 <20–30 min，肝硬化 <15 min。

（易混：肝破裂血液可混有胆汁，不作为清洁回收式自体输血的典型场景。）

<!-- kianos:kp id="digestive-d13-kp12" -->
## KP12｜小肠、十二指肠与胰腺：同属空腔/消化液系统，但空间不同

> **主提示：空回肠3线｜D2/3识别6｜胰腺背景4｜各治疗方向**

### 快速核对

**空回肠**：

- 多无早期休克；
- 腹膜炎早而重；
- 中下腹/脐周痛，肝浊音界可缩小/消失；
- 肠修补或切除吻合。

**十二指肠2/3部**：

- 腹膜后，腹膜炎晚而重；
- 呕血/黑便；
- 腰背或右上腹痛；
- 可有睾丸痛、阴茎异常勃起；
- 腹部体征相对轻，但全身情况进行性恶化；
- X线/CT线索：腰大肌轮廓模糊、腹膜后花斑样积气、右肾间隙/肠系膜根部气泡；骶前可触捻发音。

**胰腺**：

- 上腹受力、方向盘/车把样背景只是**机制线索**，不能看到这种受伤方式就直接等同胰腺损伤；27精编明确提醒闭合性腹部外伤仍应先按整体概率与体征考虑更常见的肝、脾等实质脏器损伤，胰腺损伤本身约占 1%–2% 的 Source 口径；
- 左上腹及背痛；
- 腹腔穿刺液可为高淀粉酶血性液；
- 可形成假性囊肿。

（边界：具体修补/引流术式按原外科 Lecture，不在本 Block扩写现代胰十二指肠损伤分级。）

## KP13｜结肠与直肠损伤：污染程度和腹膜反折决定路径

> **主提示：结肠节奏｜轻/重污染2处理｜直肠上/下症状｜2种造口策略**

### 快速核对

**结肠损伤**：多无早期休克，腹膜炎晚而重；

- 污染轻/右侧：修补或切除一期吻合；
- 污染重/左侧：造口或外置，3–4 周后二期处理。

**直肠上段**：在腹膜反折以上，可出现腹膜炎；修补/切除 + 乙状结肠双腔造口。

**直肠下段**：腹膜反折以下，主要为直肠周围感染而非典型腹膜炎；采用乙状结肠造口等分流接口。

（易混：肝浊音界缩小/消失更提示腹腔游离气体，不是所有结肠损伤都必然出现。）

# 6｜检查与探查

<!-- kianos:kp id="digestive-d13-kp14" -->
## KP14｜检查选择：不稳先动作，稳定再定位

> **主提示：不稳先动作｜稳定再定位｜穿刺/US/CT/X线各解决什么｜何时不再等检查**

### 快速核对

当前 Lecture：

- 腹腔穿刺为腹部损伤首选/金标准检查，阳性率约 90%；
- 可见不凝血、消化液；怀疑结肠损伤可做腹腔灌洗；
- 禁忌：严重腹胀、中晚期妊娠、躁动不配合、腹腔粘连；
- 肝、脾、胰、肾等实质脏器：超声/CT；肾损伤以 CT 重要；
- X线：膈下游离气体提示空腔脏器穿孔；腹膜后气体提示十二指肠后部等损伤；
- 若损伤和休克已经明确，不为“补一张片子”延误救治。

```text
不稳定 → 复苏 + 迅速判定探查
稳定   → 穿刺 / US / CT / X线按问题选择
```

## KP15｜剖腹探查：先全局看清，再按最致命损伤处理

> **主提示：指征1｜切口1｜探查顺序8站｜先探后治原则｜粘连边界｜关腹2事**

### 快速核对

指征：抗休克处理中病情仍进行性恶化等，需急诊探查。

- 切口：正中切口；
- 探查顺序：

```text
肝、脾
→ 胃
→ 十二指肠1部
→ 空肠、回肠
→ 结肠
→ 盆腔
→ 胃后壁、胰腺
→ 十二指肠其余部分
```

原则：

- 先完成系统探查，再优先处理最严重/最致命损伤；
- 不随意分离原有粘连组织；
- 关腹前盐水冲洗，按需要放置引流。

（易混：探查顺序与最终救治优先级不是同一个概念。）

## KP16｜急腹症动作算法：生命体征—腹膜—液体—空间—源控制

> **主提示：先稳4项｜腹膜3征｜穿刺6液｜实/空分流｜后位警报｜手术3触发**

### 快速核对

```text
1. 看循环与意识
BP / P / 神志 / 尿量 / Hb
        ↓
2. 看壁腹膜
压痛 / 反跳痛 / 肌紧张
        ↓
3. 看腹腔液体
血？胆汁？胰液？脓液？臭血？
        ↓
4. 看器官与空间
实质 vs 空腔
腹膜内 vs 腹膜后
        ↓
5. 决定动作
稳定：定位检查
感染：抗菌 + 引流/源控制
持续出血、穿孔、进行性恶化：探查
```

三条不能继续观察的核心触发：

- 血流动力学持续不稳；
- 腹膜炎进行性加重/明确穿孔；
- 持续出血或污染源未控制。
