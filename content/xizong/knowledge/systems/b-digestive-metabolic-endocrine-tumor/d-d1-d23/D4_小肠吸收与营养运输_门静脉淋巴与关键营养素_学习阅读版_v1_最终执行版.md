# D4｜小肠吸收与营养运输
## 进入门静脉还是先走淋巴

> **中心问题**：食物已经被拆成单糖、氨基酸、小肽、脂肪酸等小单元后，它们怎样跨越小肠上皮；哪些直接进入门静脉，哪些要先组装成乳糜微粒走淋巴；铁、钙和 B12 为什么各有独立门槛？
>
> **Primary ownership**：小肠主要吸收部位、跨细胞 / 细胞旁路径、门静脉 / 淋巴分流、B12、脂类、糖、氨基酸 / 小肽、铁和钙吸收在本 Block 首次完整学习。

## 2｜总 Framework

```text
A｜先决定在哪里吸收
小肠上部：绝大多数营养物
回肠：B12 + 胆盐
大肠：水和盐类回收
        ↓
B｜再决定怎样跨上皮
跨细胞：顶端膜进入 → 细胞内加工 → 基底侧输出
细胞旁：经紧密连接间隙进入细胞间液
        ↓
C｜水溶性营养物
单糖 / 氨基酸 / 小肽 / 多数水溶性维生素
→ 载体或继发性主动转运
→ 基底侧进入毛细血管
→ 门静脉 → 肝
        ↓
D｜长链脂质
胆盐微胶粒送达顶端膜
→ 脂质进入上皮
→ 重合成TAG
→ apoB48组装乳糜微粒
→ 出胞 → 毛细淋巴管 → 胸导管 → 血
        ↓
E｜特殊门槛
B12：胃—胰—回肠接力
铁：Fe³⁺还原为Fe²⁺，DMT1进入，FPN1输出
钙：VitD与需求量主导，可溶性和肠腔环境决定可吸收性
```

### 一句话恢复

> **小肠上部负责大多数吸收，回肠收 B12 和胆盐；水溶性小分子多经门静脉，长链脂质先在上皮重装成乳糜微粒走淋巴；B12、铁和钙各自有独立的“准入证”。**

## KP01｜为什么小肠是主要吸收部位：结构、时间和消化程度同时占优

> **主提示：4优势｜三级放大｜主要部位｜回肠2特殊｜大肠水盐｜高位瘘/短肠**

### 1｜四个基础优势

1. 大多数食物已被胰酶等分解为可吸收小分子；
2. 食物在小肠停留较长，约 3–8 h；
3. 绒毛内毛细血管和毛细淋巴管丰富；
4. 环状皱襞—绒毛—微绒毛形成三级放大，吸收面积巨大。

Study 补充：正常小肠约 4–5 m，三级结构可把面积放大约 600 倍。

### 2｜部位分工

- 口腔、食管：一般不承担明显营养吸收；
- 胃：吸收少量水和乙醇等；
- 十二指肠、空肠上段：糖、蛋白、脂肪等绝大多数吸收；
- 回肠：**Vit B12 与胆盐**的特殊吸收；同时是吸收储备段；
- 大肠：主要吸收水和盐类，讲义口径可吸收内容物中约 80% 水、90% Na⁺ / Cl⁻。

### 3｜临床接口

```text
高位小肠瘘
→ 主要吸收区被绕过 / 丢失
→ 营养吸收显著受损
→ 可需肠外营养

短肠综合征
→ 有效面积和接触时间下降
→ 广泛吸收不良
```

（边界：低位小肠瘘对吸收的影响相对较小，但不能机械理解为所有低位瘘均无需营养支持；当前只保留 Study 的考试方向。）

## KP02｜吸收路径：顶端进入只是半程，最终必须离开基底侧进入血或淋巴

> **主提示：跨细胞4步｜细胞旁｜血管2字/淋巴3字｜门静脉首过｜长链特殊**

### 1｜跨细胞路径

```text
肠腔
→ 顶端膜 / 刷状缘进入上皮细胞
→ 细胞内加工或暂存
→ 基底侧膜输出
→ 毛细血管或毛细淋巴管
```

考试常把“从肠腔进入上皮细胞”称作吸收，但完整生理过程应追踪到血液或淋巴。

### 2｜细胞旁路径

部分水、离子等可经相邻上皮细胞间的紧密连接区域进入细胞间隙，再到循环。

### 3｜血液 vs 淋巴

- **中、短链脂肪酸**：水溶性较好，可经毛细血管直接进入门静脉。
- **长链脂肪酸及多数脂类消化产物**：在上皮内重装成乳糜微粒，进入毛细淋巴管。
- 脂溶性维生素 A、D、E、K 随脂类以淋巴途径为主。

### 4｜为什么门静脉与淋巴不同

```text
门静脉路径
→ 先到肝脏
→ 进入首过加工、储存和代谢

淋巴路径
→ 经胸导管进入体循环
→ 长链脂质先绕开门静脉首过
```

这正是后续“吸收 → 物质代谢 M1–M10”的入口。

## KP03｜Vit B12：胃酸放人、R蛋白护送、胰蛋白酶换手、内因子带回肠

> **主提示：食物结合态｜胃2步｜肠2步｜回肠受体｜缺陷3类｜巨幼贫**

### 1｜胃内第一段接力

食物中的 B12 多与蛋白质结合。

```text
胃酸 + 胃蛋白酶
→ B12从食物蛋白中释放
→ 游离B12迅速与R蛋白结合
```

R 蛋白来自唾液和胃液，在胃内对 B12 的亲和力高于内因子，因此胃中主要形成 B12—R 蛋白复合物。

### 2｜小肠换手

```text
B12—R蛋白复合物进入小肠
→ 胰蛋白酶降解R蛋白
→ B12再次游离
→ 与壁细胞分泌的内因子结合
```

内因子—B12 复合物可抵抗肠腔酶的破坏。

### 3｜回肠吸收

```text
内因子—B12复合物到达回肠末端
→ 顶端膜受体识别
→ 受体介导入胞
→ B12进入上皮并转运
```

受体介导入胞的其他代表包括 LDL、运铁蛋白等。

### 4｜三个故障入口

- 胃酸**缺乏**：B12 难从食物蛋白释放；
- 内因子缺乏：不能形成有效复合物；
- 胰蛋白酶缺乏：不能从 R 蛋白完成换手；
- 回肠病变 / 切除：最终受体吸收失败。

结果可进入巨幼细胞性贫血模型。

（易混：胃酸“减少”不一定达到影响 B12 的缺乏程度；A 型胃炎常为明显缺乏，B 型胃炎可正常或减少。）

## KP04｜脂类吸收：微胶粒只负责送到岸边，乳糜微粒才负责离开上皮

> **主提示：腔内3角色Recall｜静水层｜顶端释放｜长链4步｜载脂蛋白｜中短链去向｜胆盐去向**

### 1｜到达顶端膜前｜Recall D3

- 胰脂肪酶水解脂肪；
- 辅脂酶将胰脂肪酶锚定在脂滴表面；
- 胆盐与脂肪消化产物形成混合微胶粒；
- 微胶粒穿过静水层，把脂质递送至上皮顶端膜。

（易混：混合微胶粒是**吸收前的腔内运输结构**，不是入淋巴的颗粒。）

### 2｜长链脂质进入上皮后

```text
长链脂肪酸 + 一酰甘油进入上皮
→ 在内质网重新合成三酰甘油TAG
→ 与胆固醇酯、磷脂、脂溶性维生素及apoB48组装
→ 形成乳糜微粒CM
→ 高尔基体包装
→ 基底侧出胞
→ 毛细淋巴管
→ 胸导管
→ 体循环
```

### 3｜中、短链脂肪酸

水溶性较好，在上皮内不必重装成乳糜微粒，可直接从基底侧进入毛细血管和门静脉。

### 4｜胆盐的去向

胆盐通常不随脂质进入上皮，而留在肠腔继续参与运输，最后主要在回肠重吸收并进入肠肝循环。

### 5｜为什么总体脂肪以淋巴途径为主

膳食脂肪中长链脂肪酸占多数，因此总体脂类吸收以乳糜微粒—淋巴途径为主。

## KP05｜单糖吸收：葡萄糖 / 半乳糖借 Na⁺梯度，果糖走易化扩散

> **主提示：葡/半顶端｜果糖顶端｜基底侧共同｜Na/K泵供能｜速度顺序**

### 1｜葡萄糖与半乳糖

```text
顶端膜：与Na⁺同向转运
→ 利用Na⁺电化学梯度
→ 继发性主动转运进入上皮

基底侧：载体易化扩散
→ 进入毛细血管
```

Na⁺梯度最终由基底侧 Na⁺—K⁺泵维持，因此能量间接来自 ATP。

### 2｜果糖

顶端膜和基底侧主要依赖载体易化扩散，不与 Na⁺同向转运。

### 3｜速度比较

```text
己糖 > 戊糖
半乳糖、葡萄糖 > 果糖 > 甘露糖 > 戊糖（如核糖）
```

（易混：载体易化扩散不等于简单扩散；它仍具有特异性、可饱和和竞争等载体特征。）

## KP06｜氨基酸与小肽：小肽借 H⁺进入，吸收反而更快

> **主提示：AA vs 小肽：顶端驱动力｜入胞后处理｜谁更快｜AA速度3类**

### 1｜氨基酸

多数氨基酸在顶端膜通过与 Na⁺相关的继发性主动转运进入上皮；基底侧再经载体进入血液。

吸收速度：

```text
中性氨基酸 > 碱性氨基酸 > 酸性氨基酸
```

### 2｜二肽、三肽等寡肽

```text
顶端膜：H⁺同向转运
→ 继发性主动转运进入上皮
→ 细胞内被肽酶进一步水解为氨基酸
→ 基底侧输出入血
```

当前 Study 强调：寡肽吸收速度可快于游离氨基酸。

（易混：氨基酸与寡肽不是共用同一套顶端转运；前者主要挂 Na⁺梯度，后者挂 H⁺梯度。）

## KP07｜铁吸收：先把 Fe³⁺变成可进入的 Fe²⁺，再决定输出还是随黏膜脱落

> **主提示：部位｜促3｜抑3｜价态4步｜2转运体｜铁蛋白门控｜主病因边界**

### 1｜部位与需求调节

铁主要在小肠上部吸收。机体缺铁时，对相同摄入量的吸收比例可提高，体现需求量调节。

### 2｜促进因素

- 机体需求量增加；
- HCl：促进铁盐溶解；
- Vit C：将食物中较多的 Fe³⁺还原为更易吸收的 Fe²⁺。

### 3｜抑制因素｜Study 口径

- 谷类；
- 乳类；
- 茶。

### 4｜价态与转运

```text
吸收：Fe²⁺
→ 顶端DMT1等进入黏膜细胞

运输：Fe³⁺
→ 经基底侧FPN1输出后进入血浆运输体系

利用：Fe²⁺
储存：Fe³⁺（铁蛋白等）
```

讲义口诀方向：**吸二、运三、用二、储三**。

### 5｜黏膜门控

未输出入血的铁可在黏膜细胞内氧化为 Fe³⁺并结合铁蛋白暂存；若始终未被利用，可随上皮更新脱落排出，形成“黏膜阻滞”式调节。

### 6｜贫血边界

胃大部切除或 A 型胃炎造成 HCl 缺乏，可不利于铁吸收；但 Study 同时强调：

- 体内铁大量来自衰老红细胞回收；
- 缺铁性贫血更常见、更重要的原因是慢性失血，而非单纯胃酸减少。

完整贫血模型归血液系统。

## KP08｜钙吸收：需求量与 Vit D 是主轴，能否保持可溶决定能否进入

> **主提示：吸收率｜主因素2｜促进5｜抑制3｜酸度｜肠腔钙皂 vs 血中钙皂｜大多粪排**

### 1｜基本特点

- 食物钙只有约 **20%–30%**被吸收；
- 大部分随粪便排出；
- 必须以可溶的 Ca²⁺状态存在才能被吸收。

### 2｜两个主决定因素

1. 机体对钙的需求量；
2. **Vit D**，为最重要促进因素。

### 3｜促进因素｜Study 口径

- HCl / 酸性环境：促进钙盐溶解；
- Vit D；
- 乳酸；
- 葡萄糖；
- 脂肪酸、氨基酸等。

肠腔 pH 较低、钙保持离子化时更利于吸收。

### 4｜抑制因素

- 草酸；
- 磷酸；
- 植酸；

它们与 Ca²⁺形成难溶复合物 / 沉淀，降低可吸收性。

### 5｜两个“钙皂”方向相反

```text
肠腔内
脂肪酸 + Ca²⁺ → 钙皂
→ Study口径：可再与胆汁酸形成水溶性复合物
→ 有利于肠道吸收

急性重症胰腺炎的血液 / 组织内
脂肪坏死释放脂肪酸 + 血Ca²⁺ → 钙皂
→ 消耗血钙
→ 低钙血症
```

关键不是“钙皂永远升钙或降钙”，而是形成位置和后续去向不同。

（边界：PTH / 钙三醇 / 降钙素完整轴归 D23。）

---

## 3｜综合定位：吸收不良发生在哪一层

```text
第一层｜腔内消化失败
胰酶不足 / 胆盐不足
→ 大分子未被拆解或脂质无法形成微胶粒

第二层｜黏膜进入失败
小肠黏膜病变 / 运输体异常 / 面积减少
→ 顶端膜吸收不足

第三层｜上皮内加工失败
长链脂质不能重合成或组装乳糜微粒

第四层｜输出通路失败
门静脉 / 淋巴运输异常

第五层｜特殊部位失败
回肠病变
→ B12 + 胆盐共同受影响
```

### 三个高价值反推

| 线索 | 优先想到的机制层 |
|---|---|
| 脂肪泻 + ADEK缺乏 | 胰酶、胆盐、上皮脂质处理 / 淋巴路径 |
| 巨幼贫 + 胃 / 胰 / 回肠病史 | B12 接力链 |
| 缺铁 + 慢性失血 / 胃酸缺乏 | 铁丢失或铁吸收；先分主次 |

## 4｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 小肠上部是主要吸收区，回肠特异吸收 B12 和胆盐。
2. 水溶性小分子多进入毛细血管 / 门静脉；长链脂质经乳糜微粒进入淋巴。
3. B12 的胃酸—R蛋白—胰蛋白酶—内因子—回肠完整接力。
4. 微胶粒只负责把脂质送到顶端膜；乳糜微粒负责从上皮离开。
5. 葡萄糖 / 半乳糖借 Na⁺梯度，果糖走易化扩散。
6. 寡肽经 H⁺继发主动转运，速度可快于氨基酸。
7. 铁：Fe²⁺吸收、Fe³⁺运输 / 储存；Vit C 和 HCl 促进。
8. 钙：需求量 + Vit D 主导；可溶性决定能否吸收。
