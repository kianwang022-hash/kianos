# 2｜Framework｜同一扇门的双向故障

```text
正常
吞咽时：抑制性神经 → VIP / NO → LES松弛 → 食团通过
入胃后：胆碱能等 → LES张力恢复 → 防止反流

故障A｜门关不住
抗反流屏障↓ / 清除↓ / 黏膜抵抗↓
→ 胃肠内容物反流
→ GERD
→ RE或NERD
→ 出血 / 狭窄 / Barrett

故障B｜门打不开
食管下2/3肌间神经丛受损
→ LES不能松弛
→ 功能性出口阻塞
→ 间歇性吞咽困难 + 食管扩张 + 鸟嘴征
→ Heller肌层切开
→ 抗反流屏障变弱，术后可GERD
```

## 2.1 病例先问四件事

```text
症状方向：反流烧心，还是食团通过受阻？

```

## KP01｜GERD、RE与NERD：先证明反流，再看有没有黏膜破损

> **讲义定位 →** 内科 P78、P80  
> **主提示：** 反流物4｜GERD定义｜RE/NERD按1轴｜胃镜阴性≠排除

### 快速核对

胃酸、胃蛋白酶、非结合胆盐和胰酶等反流入食管或食管外组织；有糜烂/溃疡为 RE，无糜烂但有客观反流证据可为 NERD。

### Detailed Expansion

GERD 的核心不是“胃镜一定看见炎症”，而是胃肠内容物反复进入不应到达的食管及食管外组织并产生症状或损害。

```text
反流 + 食管黏膜糜烂 / 溃疡 → 反流性食管炎 RE
反流 + 胃镜无糜烂 / 溃疡 → 非糜烂性反流病 NERD
```

NERD 仍需反流监测提供客观证据，并可结合 PPI 试验性治疗反应；胃镜阴性不能排除 GERD。

**Routing**：CORE｜BOUNDARY｜CONFUSABLE｜MI-G

<!-- kianos:kp id="dme-d09-kp02" -->
## KP02｜GERD三层故障：屏障、清除、黏膜抵抗

> **讲义定位 →** 内科 P79；Recall D2  
> **主提示：** GERD三层：屏障｜清除｜黏膜抵抗｜LES/裂孔疝各在哪层

### 快速核对

```text
抗反流屏障失败（最重要，尤其LES功能）
+ 食管清除下降
+ 食管黏膜抵抗下降
→ GERD
```

### Detailed Expansion

1. **抗反流屏障**：LES结构或功能异常最重要；当前 Study 还把膈肌脚、His角和膈食管韧带放入同一屏障接口。
2. **食管清除**：蠕动把反流物推回胃，唾液帮助冲洗和稀释；能力下降时暴露时间延长。
3. **黏膜抵抗**：长期饮酒、吸烟、刺激性食物或药物等可使食管黏膜更易损伤。

食管裂孔疝可同时破坏屏障，并影响食管下段蠕动，因此是“一因双击”。

**Routing**：CORE｜CONNECTION｜MI-G

<!-- kianos:kp id="dme-d09-kp03" -->
## KP03｜哪些因素把LES压低或把胃内压推高

> **讲义定位 →** 内科 P79  
> **主提示：** 压力↑2类｜食物2｜激素5｜药4｜不会降压4｜术后1

### 快速核对

胃内/腹内压升高可从下方“顶门”；高脂、巧克力及一组激素/平滑肌松弛药可降低 LES 张力；贲门失弛缓本身不反流，Heller术后才可反流。

### Detailed Expansion

- 胃内压增高：胃排空延迟、胃扩张；
- 腹内压增高：便秘、肥胖、妊娠、腹水；
- 食物：高脂食物、巧克力；
- Study列出的相关体液因素：胰高血糖素、促胰液素、CCK、前列腺素、VIP；
- 药物：CCB、地西泮、硝酸甘油、抗胆碱药等。

当前 Outline 强调“记少不记多”：胃泌素、胃动素、ACh及治疗GERD的药物不放入“使LES压力下降”名单。

（易混：贲门失弛缓＝LES不能松弛，不是LES压力下降；反流发生在术后屏障被切开。）

**Routing**：CORE｜SPECIAL｜CONFUSABLE｜MI-G/MI-D

## KP04｜清除与黏膜抵抗：为什么唾液少也会反流病加重

> **讲义定位 →** 内科 P79；Recall D2  
> **主提示：** 食管清除2部分｜唾液/重力｜黏膜抵抗｜干燥为什么加重｜裂孔疝双层影响

### 快速核对

食管蠕动负责推进，唾液负责冲洗/稀释；干燥综合征使唾液减少，反流物停留更久。黏膜屏障下降则使同样暴露造成更重损伤。

### Detailed Expansion

```text
蠕动下降 / 唾液减少
→ 反流物清除变慢
→ 酸和酶接触时间延长
→ 症状及黏膜损伤增加
```

干燥综合征在当前 Study 归入“清除作用降低”；长期饮酒、吸烟、刺激性饮食和 NSAIDs 等归入“黏膜屏障降低”。不要因二者最终都加重损伤而混淆故障层。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP05｜GERD表现：食管内4类，食管外5站

> **讲义定位 →** 内科 P79  
> **主提示：** 典型2｜痉挛3｜食管外5站｜哮喘季节性边界

### 快速核对

典型是反流、烧心；痉挛可致刺痛、间歇性吞咽困难和胸骨后异物感；反流还可伤牙、咽喉、声带、气道与肺。

### Detailed Expansion

**食管症状**：

- 反流、烧心：最常见典型症状；
- 胸痛：多由食管痉挛产生，Study描述多为刺痛；
- 吞咽困难：多呈间歇性；
- 胸骨后异物感。

**食管外症状**：

1. 牙蚀症；
2. 咽喉炎、癔球症；
3. 声嘶；
4. 慢性咳嗽、非季节性哮喘、吸入性肺炎；
5. 肺间质纤维化接口。

（易混：癔球症有堵塞/异物感，但没有真正的吞咽受阻；支气管哮喘的典型过敏触发可有季节性，而GERD相关哮喘在当前Source强调非季节性。）

**Routing**：CORE｜RECOGNITION｜CONFUSABLE｜MI-G

## KP06｜GERD胸痛 vs 心绞痛；间歇性 vs 进行性吞咽困难

> **讲义定位 →** 内科 P79；外科 P12–13  
> **主提示：** 共性2｜GERD体位｜心绞痛2缓解｜吞咽3型分流

### 快速核对

GERD胸痛与体位、餐后和腹压关系明显；心绞痛可因休息或硝酸甘油缓解并常有ECG证据。间歇吞咽困难偏痉挛/失弛缓，进行性受阻要警惕食管癌。

### Detailed Expansion

二者都可发生纵隔胸痛并向颈部、上肢或上腹放射，因此放射方向本身不特异。

| 轴 | GERD | 心绞痛 |
|---|---|---|
| 常见关系 | 餐后、卧位、弯腰、腹压升高加重；站立/坐位减轻 | 劳力或心肌缺血背景 |
| 痛感 | Study多描述刺痛/烧灼 | 多为绞痛 |
| 缓解 | 改变体位、抑酸 | 休息或硝酸甘油可能缓解 |
| 证据 | 反流监测/内镜 | ECG等循环证据 |

吞咽困难再分：

```text
GERD痉挛：多间歇
贲门失弛缓：多间歇 + 鸟嘴征
食管癌：典型进行性
```

**Routing**：CORE｜DISCRIMINATION｜RECOGNITION｜MI-G

## KP07｜GERD三大并发症：出血、狭窄、Barrett

> **讲义定位 →** 内科 P80  
> **主提示：** 并发症3｜狭窄修复链｜Barrett化生｜腺癌接口｜随访1

### 快速核对

GERD并发症只有当前Source明确的三类：上消化道出血、食管狭窄、Barrett食管。

### Detailed Expansion

1. **出血**：可有呕血/黑便，肠内血液刺激使肠鸣音增多；完整UGIB决策归D10。
2. **狭窄**：反复损伤→肉芽组织→纤维瘢痕→收缩；多数可内镜扩张，极少数严重瘢痕狭窄需手术。
3. **Barrett食管**：食管下段鳞状上皮被柱状/腺上皮取代，是食管腺癌的癌前病变，需定期胃镜随访。

（边界：食管穿孔不是当前Study列出的GERD并发症；食管鳞癌也不是Barrett的直接癌变方向。）

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

## KP08｜检查与LA分级：反流监测证明“有反流”，胃镜证明“有损伤”

> **讲义定位 →** 内科 P80  
> **主提示：** 反流监测 vs 胃镜｜各回答什么｜NERD如何证实｜LA分级轴

### 快速核对

- GERD金标准：食管反流监测，包括pH或阻抗-pH；
- RE最准确：胃镜；
- NERD：胃镜阴性 + 反流客观证据 + PPI试验有效。

### Detailed Expansion

| LA级别 | 当前Study口径 |
|---|---|
| A | 黏膜破损长径＜5mm |
| B | 至少一处长径＞5mm |
| C | 破损融合，累及＜75%食管周径 |
| D | 破损融合，累及＞75%食管周径 |

反流监测回答“反流是否过度”；内镜回答“黏膜是否已糜烂、溃疡及严重程度”。两者不是互相替代。

（边界：恰为75%时Source未裁决。）

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G/MI-D

## KP09｜抑酸治疗阶梯：PPI、P-CAB、H2RA与抗酸剂

> **讲义定位 →** 内科 P80–81  
> **主提示：** 首选/最佳｜PPI靶酶/疗程｜P-CAB机制/6优点｜H2RA人群/疗程｜抗酸边界

### 快速核对

PPI是首选、最佳；P-CAB与K⁺竞争结合质子泵；H2RA用于轻中度；弱碱抗酸剂只适合轻症短时缓解。

### Detailed Expansion

- **PPI**：奥美拉唑、泮托拉唑；不可逆结合 H⁺-K⁺-ATP酶；疗程4–8周。
- **P-CAB**：伏诺拉生；与K⁺竞争结合H⁺-K⁺-ATP酶；Source强调酸环境稳定、不需酸激活、起效快、持续久、夜间作用确切、个体差异小等。
- **H2RA**：法莫替丁/西咪替丁；适合轻中度；疗程8–12周。
- **抗酸剂**：铝碳酸镁、磷酸铝、硫糖铝、氢氧化铝等；中和酸，临时缓解，不等同抑制分泌。

**Routing**：CORE｜CONFUSABLE｜MI-G/MI-D

## KP11｜贲门失弛缓：肌间神经丛损伤怎样变成功能性梗阻

> **讲义定位 →** 外科 P12–13；Recall D2  
> **主提示：** 人群2｜相关因素1｜损伤位置｜LES效应｜症状｜钡餐｜黏膜边界

### 快速核对

青年女性、与精神因素等相关；食管下2/3肌间神经丛受损→LES不能松弛→间歇性吞咽困难；钡餐鸟嘴样狭窄，狭窄部黏膜光滑。

### Detailed Expansion

正常吞咽依赖抑制性神经使LES及时松弛。贲门失弛缓中，Source把损伤定位于食管下2/3肌间神经丛：

```text
抑制性松弛控制失败
→ LES持续高张 / 不能松弛
→ 食团滞留
→ 食管扩张、蠕动减弱
→ 间歇性吞咽困难与呕吐
→ 钡餐末端鸟嘴样狭窄
```

“黏膜尚光滑”提示功能性出口问题，不是黏膜内不规则肿物造成的狭窄。

**Routing**：CORE｜RECOGNITION｜VISUAL_ONLY｜MI-G

## KP12｜Heller术与三病分流：失弛缓、GERD、食管癌

> **主提示：** Heller切哪里｜解决1｜代价1｜三病症状轴｜证据轴
