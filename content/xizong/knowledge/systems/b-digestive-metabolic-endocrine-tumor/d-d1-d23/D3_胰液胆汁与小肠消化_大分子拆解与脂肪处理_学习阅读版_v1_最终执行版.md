# D3｜胰液、胆汁与小肠消化
## 把大分子拆成可吸收单元

> **中心问题**：酸性食糜进入十二指肠后，胰腺怎样同时提供 HCO₃⁻和消化酶；胆汁怎样帮助脂肪乳化与转运；小肠运动怎样让内容物充分混合；为什么酶原激活位置和胆胰共同出口极其重要？
>
> **Primary ownership**：胰液、胰酶原激活、促胰液素 / CCK、胆汁与胆盐、肠肝循环、小肠与大肠主要运动、三种常考胃肠激素比较在本 Block 首次完整学习。

## 2｜总 Framework

```text
胃排出酸性食糜
        ↓
A｜先中和
十二指肠酸
→ S细胞促胰液素
→ 胰管 / 胆管上皮分泌HCO₃⁻和水
→ 中和HCl，建立胰酶适宜环境
        ↓
B｜再拆解
蛋白质消化产物 / 脂肪酸
→ I细胞CCK
→ 胰腺腺泡释放胰酶 / 酶原
→ 肠激酶激活胰蛋白酶原
→ 胰蛋白酶激活其他酶原
        ↓
C｜脂肪专门处理
胆盐乳化脂滴
+ 辅脂酶把胰脂肪酶固定在脂滴表面
→ 脂类被水解
→ 胆盐形成混合微胶粒，准备进入上皮
        ↓
D｜胆汁调度
肝持续产胆汁
→ 非消化期储于胆囊并浓缩
→ CCK使胆囊收缩、Oddi舒张
→ 胆盐回肠重吸收并肠肝循环
        ↓
E｜机械混合与推进
小肠分节运动：混合、接触黏膜、促进血淋巴回流
蠕动：推进
大肠：吸水、储存、集团蠕动排出
```

### 一句话恢复

> **酸先叫促胰液素来中和，蛋白产物和脂肪叫 CCK 来放酶、挤胆囊；肠激酶点燃胰蛋白酶级联，胆盐和辅脂酶专门解决脂肪，小肠分节运动把所有成分充分混匀。**

## KP01｜三种消化液缺失：先判断“哪类营养物最受影响”

> **主提示：胃液缺乏｜胰液缺乏｜胆汁缺乏｜糖/蛋白/脂肪/ADEK方向**

### 1｜胃液缺乏

- 糖类消化：总体影响小；
- 蛋白质消化：有影响，但后续胰蛋白酶系统可承担主要消化；
- 脂肪消化：影响小；
- B12 吸收：若伴内因子缺乏则显著受损；
- HCl 缺乏还可降低促胰液素刺激和铁、钙溶解。

### 2｜胰液缺乏

胰液是消化三大营养物质最强、最全面的消化液。

- 蛋白质和脂肪消化明显受损；
- 糖类仍可由唾液淀粉酶、肠刷状缘酶等部分补偿，因此并非完全不能消化；
- 脂肪消化障碍最突出，可出现脂肪泻；
- 继发脂溶性维生素 A、D、E、K 吸收障碍。

### 3｜胆汁缺乏

胆汁无消化酶，主要影响：

- 脂肪乳化；
- 胰脂肪酶作用效率；
- 混合微胶粒形成；
- 脂类和 A、D、E、K 吸收。

糖和蛋白质的酶解不以胆汁为必需。肝硬化等导致胆汁 / 胆盐供应不足时，首先受累的也是脂类消化吸收。

### 定位原则

```text
脂肪泻 + ADEK缺乏
→ 优先考虑胰液不足或胆汁不足

三大营养物普遍消化差，尤以脂肪和蛋白明显
→ 胰腺外分泌问题更重
```

## KP02｜胰液双细胞模型：腺泡给酶，导管给碱性水

> **主提示：最强消化液｜腺泡 vs 导管｜分泌物｜神经｜功能2｜调节主导**

### 1｜两类细胞

| 细胞 | 主要分泌 | 直接任务 |
|---|---|---|
| 胰腺腺泡细胞 | 各类胰酶 / 酶原 | 分解糖、脂肪、蛋白质和核酸 |
| 胰管 / 导管细胞 | HCO₃⁻ + 水 | 中和胃酸，提供胰酶适宜 pH，冲洗酶入十二指肠 |

### 2｜为什么胰液偏碱

胃排出的食糜含 HCl。若不先中和：

- 小肠黏膜受到酸损伤；
- 胰酶难以在合适环境工作。

因此 HCO₃⁻不是“附带成分”，而是酶解能够顺利进行的前置条件。

### 3｜调节性质

胰液分泌以**体液调节为主**，但神经与体液协同：

- 迷走 ACh / 胃泌素样作用：主要作用于腺泡、酶多水少；
- 促胰液素：偏导管、HCO₃⁻和水；
- CCK：偏腺泡、胰酶；
- 内脏大神经属交感神经，对胰液分泌影响不明显。

（易混：不能把“胰液分泌以体液为主”理解为没有神经调节。）

## KP03｜胰酶原激活：必须在肠腔启动的级联保险

> **主提示：首个酶原｜首激活酶｜自激｜下游酶原3+｜安全意义｜提前激活后果**

### 1｜启动顺序

```text
小肠刷状缘肠激酶 / 肠肽酶
→ 胰蛋白酶原 → 胰蛋白酶
```

随后胰蛋白酶：

- 自催化激活更多胰蛋白酶原；
- 激活糜蛋白酶原；
- 激活羧基肽酶原；
- 按当前 Study，激活核糖核酸酶原、脱氧核糖核酸酶原等其他酶原。

### 2｜为什么先以酶原形式分泌

胰腺必须把“生产消化酶”和“消化底物”空间分开：

```text
胰腺内：安全合成、储存、运输酶原
小肠腔：遇到肠激酶后集中激活
```

否则蛋白酶会消化胰腺自身。

### 3｜//串联：急性胰腺炎

```text
胰内酶原提前激活
→ 胰蛋白酶级联失控
→ 胰腺自我消化
→ 水肿、坏死、出血及全身炎症接口
```

当前只建立“提前激活”的机制门槛；完整病因、分级、并发症与治疗归 D20。

## KP04｜促胰液素 vs CCK：一个“冲水中和”，一个“放酶挤胆囊”

> **主提示：来源/刺激各1｜第二信使｜胰液成分各1｜胆囊/Oddi｜协同**

### 1｜促胰液素 Secretin

```text
十二指肠HCl（最强）
+ 蛋白质消化产物、脂肪酸
→ 小肠上部S细胞
→ 促胰液素
→ cAMP
→ 胰管细胞：HCO₃⁻ + 水↑↑
```

同时：

- 促进胆管上皮分泌水和 HCO₃⁻；
- 抑制胃酸和胃排空；
- 对胰外分泌部有营养作用。

### 2｜CCK / 促胰酶素

```text
蛋白质消化产物（最强）
+ HCl、脂肪酸
→ 小肠上部I细胞
→ CCK
→ Ca²⁺信号
→ 胰腺腺泡：胰酶↑↑
→ 胆囊收缩 + Oddi括约肌舒张
```

还可：

- 促进胆汁排出；
- 抑制胃运动和胃排空；
- 总体抑制胃酸；
- 促进胃蛋白酶原；
- 对胰外分泌部有营养作用。

### 3｜协同

促胰液素和 CCK 不是各自独立：一个提供碱性液体和适宜环境，一个提供酶；共同使胰液既“有量”又“有消化力”。迷走神经还能增强体液激素作用。

### 4｜抑制轴

当前 Study 列出：

- 生长抑素；
- 胰高血糖素；
- 胰多肽；

可抑制胰液分泌，进入 MI-D。

## KP05｜胆汁的生产—储存—排出：肝持续生产，胆囊按餐调度

> **主提示：产地2｜胆囊2功能｜肝胆汁vs胆囊胆汁｜消化/非消化路径｜Oddi门控｜无酶**

### 1｜生产与储存

- 肝细胞持续产生胆汁；
- 肝内胆管上皮可增加水和 HCO₃⁻；
- 非消化期胆汁进入胆囊储存、浓缩；
- 消化期经胆总管进入十二指肠。

### 2｜胆囊的角色

胆囊：

- 储存胆汁；
- 吸收水和电解质、浓缩胆汁；
- 在进食后收缩，将胆汁送入肠腔。

胆囊不是胆汁的生产器官。

### 3｜肝胆汁与胆囊胆汁

- 肝胆汁偏弱碱性；
- 胆囊吸收 HCO₃⁻等后，胆囊胆汁可偏弱酸性；
- 胆囊胆汁因水被吸收而更浓。

### 4｜重要边界

胆汁**不含与消化有关的酶**。它通过胆盐等物理化学作用帮助脂肪消化和吸收。

## KP06｜胆盐—辅脂酶—混合微胶粒：脂肪消化需要三个不同角色

> **主提示：胆盐2作用｜辅脂酶1作用｜胰脂肪酶1作用｜微胶粒过静水层｜胆盐是否入细胞**

### 1｜胆盐：乳化 + 运输准备

胆盐具有双嗜性：

- 降低脂滴表面张力，把大脂滴分散成小脂滴，增加酶接触面积；
- 与脂肪酸、一酰甘油、胆固醇、脂溶性维生素等形成混合微胶粒。

### 2｜胰脂肪酶：真正水解

胰脂肪酶负责水解三酰甘油，产生脂肪酸和一酰甘油等。

### 3｜辅脂酶：把酶固定在脂滴表面

胆盐覆盖脂滴后可能把胰脂肪酶从表面排开；辅脂酶的作用是**锚定胰脂肪酶，防止其被清除**。

（易混：辅脂酶不直接水解脂肪，也不是“激活胰脂肪酶”的主要答案；其关键是锚定。）

### 4｜混合微胶粒

```text
脂肪消化产物 + 胆盐
→ 混合微胶粒
→ 通过小肠上皮表面的静水层
→ 把脂质递送到顶端膜
```

胆盐通常留在肠腔，不随脂质一起进入上皮；随后在回肠被重吸收。

### 5｜结石接口

胆盐、卵磷脂帮助胆固醇溶解。Study 口径中胆盐 : 卵磷脂约 **2–3 : 1**有利于胆固醇保持溶解；比例失衡可促胆固醇析出和结石形成。

## KP07｜肠肝循环与胆囊调节：胆盐反复使用，CCK负责“挤”和“开门”

> **主提示：回收部位｜回肝路径｜意义｜CCK 2动作｜Secretin作用｜切胆囊边界**

### 1｜肠肝循环

```text
肝脏分泌胆盐入胆汁
→ 十二指肠参与脂肪处理
→ 回肠重吸收
→ 门静脉回肝
→ 再分泌入胆汁
```

意义：

- 节省胆盐合成；
- 维持胆盐池；
- 回肝胆盐对胆汁分泌有促进作用，即利胆效应。

（易混：讲义强调胆盐对胆汁分泌有促进作用，但对胆囊运动没有明显直接作用；胆囊运动的核心激素是 CCK。）

### 2｜餐后胆汁排出

- CCK：胆囊强烈收缩 + Oddi 括约肌舒张；
- 促胰液素：促进胆管上皮分泌 HCO₃⁻和水；
- 迷走与胃泌素也有较弱促进接口。
- 食物刺激胆汁分泌的强度按当前 Study：**蛋白质 > 脂肪 > 糖**。

### 3｜胆囊切除后的边界

- 肝仍持续产生胆汁，故一般消化可维持；
- 失去集中储存和餐后大量释放，摄入大量脂肪时消化能力可能下降；
- 不会再形成胆囊结石，但其他胆道部位仍可形成结石。

## KP08｜小肠运动：分节运动负责“混”，蠕动负责“送”

> **主提示：运动5类｜特有1｜分节来源/时相/梯度｜4意义｜MMC Recall**

### 1｜主要运动形式

- 紧张性收缩；
- 消化间期 MMC；
- 蠕动；
- 逆蠕动；
- 蠕动冲；
- 分节运动。

### 2｜分节运动

分节运动是小肠特有且最有利于消化吸收的运动形式。

- 主要由**环形肌**节律性收缩形成；
- 主要发生在消化期；
- 上段频率高、下段频率低，形成向远端的总体推进倾向。

### 3｜四类意义

1. 使食糜与消化液充分混合；
2. 反复接触黏膜，提高消化和吸收机会；
3. 挤压肠壁血管和淋巴管，促进血液 / 淋巴回流；
4. 通过频率梯度帮助内容物逐渐向远端移动。

（易混：分节运动以混合为主，不是大距离推进的主要形式。）

### 4｜MMC Recall

胃和小肠共有消化间期 MMC，继续承担“清道夫”作用。

## KP09｜大肠运动与细菌：慢速回收水盐，餐后集中推进

> **主提示：运动4类｜袋状往返特点｜集团蠕动触发｜胃/小/大共同轴｜细菌产物/维生素**

### 1｜运动形式

- 紧张性收缩；
- 袋状往返运动；
- 分节推进和多袋推进；
- 集团蠕动 / 大量推进。

### 2｜袋状往返运动

- 内容物在结肠袋之间缓慢往返；
- 长距离推进少；
- 有利于水、Na⁺、Cl⁻等吸收。

### 3｜集团蠕动

- 强而长距离的推进；
- 常在早餐后出现；
- 可由胃—结肠 / 十二指肠—结肠反射及 ENS 参与；
- 把内容物推向直肠，形成排便入口。

### 4｜大肠细菌

可：

- 发酵 / 腐败食物残渣；
- 产生脂肪酸、气体、吲哚等；
- 合成维生素 **K 和 B 族**。

（特殊：当前题纲问“不产生维生素 C”。）

## KP10｜胃泌素—促胰液素—CCK：三激素用共同轴比较

> **主提示：来源3｜最强刺激3｜营养作用｜LES｜胃酸/排空｜胰液｜胆囊｜小肠**

### 1｜来源、分泌方式与最强刺激

三者均由胃肠黏膜内分泌细胞释放，主要经血液到达靶细胞，属于胃肠激素的内分泌调节。

| 激素 | 主要来源 | 代表最强刺激 |
|---|---|---|
| 胃泌素 | 胃窦幽门部 G 细胞 | GRP、蛋白质消化产物、胃扩张 |
| 促胰液素 | 小肠上部 S 细胞 | HCl |
| CCK / 促胰酶素 | 小肠上部 I 细胞 | 蛋白质消化产物 |

脂肪酸也可刺激促胰液素和 CCK。

### 2｜总角色

- **胃泌素**：总体“兴奋胃”，尤其促 HCl；但幽门收缩更强，故总效应延缓胃排空。
- **促胰液素**：兴奋胰胆肠“水和 HCO₃⁻”，抑制胃酸和胃排空。
- **CCK**：兴奋胰酶和胆囊，抑制胃酸与胃排空。

### 3｜共同轴

| 轴 | 胃泌素 | 促胰液素 | CCK |
|---|---|---|---|
| LES | 收缩 | 舒张 | 舒张 |
| 胃酸 | ↑ | ↓ | 总效应↓ |
| 胃蛋白酶原 | ↑ | ↑ | ↑ |
| 胃运动 | ↑，但幽门收缩更强 | ↓ | ↓ |
| 胰液 | 胰酶↑ | HCO₃⁻和水↑↑ | 胰酶↑↑ |
| 胆汁 / 胆囊 | 胆汁与胆囊有促进 | 胆管HCO₃⁻和水↑ | 胆囊收缩最强、Oddi舒张 |
| 营养作用 | 胃肠上皮 | 胰外分泌部 | 胰外分泌部 |

（易混：问“加强胃运动和胆囊收缩”时，不能只凭“缩胆囊素”字面判断。CCK 强烈收缩胆囊，但抑制胃运动；胃泌素才促进胃运动。）

### 4｜GIP 前馈接口

食物中的葡萄糖、脂肪酸和氨基酸可促进 GIP 分泌；GIP 可在血糖明显升高前促进胰岛素，属于前馈接口。完整餐后—空腹调节归 D7。

## KP11｜从症状反推故障位置：中和、酶解、胆盐还是运动

> **主提示：酸未中和｜酶不足｜胆盐不足｜运动异常｜脂肪泻4入口｜下一步D4**

### 1｜酸未被中和

可能后果：

- 十二指肠黏膜受酸刺激；
- 胰酶工作环境受损；
- 促胰液素轴和导管 HCO₃⁻分泌异常需被考虑。

### 2｜胰酶不足

- 蛋白和脂肪消化明显下降；
- 尤其脂肪泻和 ADEK 缺乏；
- 若胰蛋白酶不足，B12—R 蛋白复合物的后续处理也会受影响，D4再整合。

### 3｜胆盐不足

- 脂滴乳化下降；
- 混合微胶粒不足；
- 脂肪及脂溶性维生素吸收下降。

### 4｜运动异常

- 分节运动不足：混合和黏膜接触减少；
- MMC 减弱：残渣和细菌清除下降；
- 蠕动过强 / 过弱：推进过快或潴留，均可影响消化吸收。

### 5｜交给 D4 的接口

D3 只完成：

```text
大分子 → 小分子 / 微胶粒
```

D4 继续回答：

```text
小分子怎样跨顶端膜
→ 在上皮内如何加工
→ 经基底侧进入门静脉还是淋巴
```

## 3｜高密度比较轴

### 3.1 腺泡 vs 导管

| 轴 | 腺泡细胞 | 导管细胞 |
|---|---|---|
| 主要产物 | 胰酶 / 酶原 | HCO₃⁻ + 水 |
| 核心刺激 | CCK、ACh、胃泌素样作用 | 促胰液素、VIP |
| 信号倾向 | Ca²⁺ | cAMP |
| 作用 | 化学分解 | 中和与冲洗 |

### 3.2 胰液 vs 胆汁

| 轴 | 胰液 | 胆汁 |
|---|---|---|
| 是否有消化酶 | 有，且最全面 | 无 |
| 主要对象 | 糖、蛋白、脂肪、核酸 | 脂类消化和吸收 |
| 碱性水 | 导管 HCO₃⁻ | 胆管上皮 HCO₃⁻ |
| 关键调节 | 促胰液素 + CCK | CCK + 促胰液素 + 肠肝循环 |

### 3.3 小肠 vs 大肠运动

| 轴 | 小肠 | 大肠 |
|---|---|---|
| 核心混合 | 分节运动 | 袋状往返 |
| 核心推进 | 蠕动 / 蠕动冲 | 分节推进、多袋推进、集团蠕动 |
| 主要任务 | 消化 + 吸收 | 水盐回收 + 储存 + 排出 |

---

### 3.4 胃、小肠、大肠运动归属

| 归属 | 运动形式 |
|---|---|
| 三者共有 | 紧张性收缩、蠕动 |
| 胃与小肠共有 | 消化间期 MMC |
| 胃特有 | 容受性舒张 |
| 小肠特有 | 分节运动 |
| 大肠特色 | 袋状往返、分节 / 多袋推进、集团蠕动 |
