# D2｜口腔、食管与胃
## 推进、抗反流、储存、排空和胃酸

> **中心问题**：食物怎样被唾液处理并通过 LES 进入胃；胃怎样同时完成“容纳—磨碎—分泌—保护—间断排空”，又避免酸和蛋白酶伤害自身？
>
> **Primary ownership**：唾液、LES、胃运动、胃排空、消化期胃液分泌、胃液细胞来源、胃酸调节及黏膜保护在本 Block 首次完整学习。

## 2｜总 Framework

```text
A｜口腔准备
唾液湿润 / 溶解 / 初步淀粉消化 / 清洁防御
→ 神经反射调节
        ↓
B｜食管门控
食团到达LES
→ VIP + NO使LES舒张
食团入胃后
→ ACh使LES恢复收缩
→ 防止反流
        ↓
C｜胃容量与运动
头区：储存 + 容受性舒张
尾区：蠕动、磨碎、混合、推进
消化间期：MMC清扫残渣与细菌
        ↓
D｜胃排空
胃内压力与运动促进
十二指肠酸 / 脂肪 / 高渗 / 扩张刹车
→ 糖 > 蛋白 > 脂肪
        ↓
E｜胃液
壁细胞：HCl + 内因子
主细胞：胃蛋白酶原
黏液细胞 / 上皮：黏液 + HCO₃⁻
G / ECL / D：胃泌素 / 组胺 / 生长抑素
        ↓
F｜攻击—防御平衡
HCl + 胃蛋白酶帮助消化
黏液-HCO₃⁻ + 紧密连接 + 血流 + PG / EGF等保护
→ 失衡才进入炎症、溃疡和出血模型
```

### 一句话恢复

> **口腔先润滑，LES按食团开关，胃头区无压扩容、尾区磨碎推进；胃酸与蛋白酶负责攻击性消化，黏液—HCO₃⁻和细胞保护负责守住胃壁，十二指肠负责下游限流。**

## KP01｜唾液：低渗、近中性、先润滑再初步消化

> **主提示：性质3｜成分5｜功能4｜淀粉酶pH｜排泄特殊**

### 1｜性质与成分

- 无色、无味；
- **低渗**；
- pH 约 **6.6–7.1**，接近中性；
- 水约占 99%。

主要成分：

- 唾液淀粉酶；
- 黏蛋白；
- 溶菌酶；
- IgA；
- Na⁺、K⁺、Ca²⁺、Cl⁻、SCN⁻等。

唾液淀粉酶的最适 pH 与唾液接近，为约 **6–7**。

### 2｜四类功能

1. **湿润和溶解食物**：便于吞咽，并帮助味觉形成。
2. **初步消化淀粉**：将部分淀粉水解为麦芽糖等。
3. **清洁和防御**：清除残渣、稀释和中和有害物；溶菌酶与 IgA 参与抗微生物。
4. **排泄接口**：某些重金属、氰化物及狂犬病毒等可随唾液排出。

（边界：胃酸很快使唾液淀粉酶失活，因此它不是全程糖消化的主力。）

## KP02｜唾液调节：交感、副交感都促分泌，但“量与质”相反

> **主提示：调节类型｜副交感2递质+量/质｜交感2递质+量/质｜条件/非条件｜特殊1**

### 1｜调节性质

唾液分泌几乎主要受**神经调节**；胃泌素不影响唾液分泌。

- 望梅止渴：条件反射；
- 食物入口刺激：非条件反射。

### 2｜副交感

```text
ACh → 腺细胞M受体 → IP₃ / Ca²⁺ → 分泌↑
VIP → 腺体血管舒张 → 局部血流↑
```

结果：**量多、固体少、稀薄唾液**。唾液分泌对副交感依赖更强。

### 3｜交感

```text
NA → 腺细胞分泌 + 血管收缩
NPY → 血管收缩
```

结果：**量少、固体多、黏稠唾液**。

（易混：交感和副交感对多数器官常呈相反效应，但对唾液腺都可促进分泌；区别在分泌量、固体含量和血流。）

### 4｜//串联：干燥综合征

当前 Lecture 口径：SSA、SSB 等自身抗体相关损伤唾液腺，可出现：

- 口干，严重者进固体食物需饮水送服；
- 猖獗性龋齿；
- 食管清除能力下降，GERD 风险增加。

完整风湿免疫病模型后置。

## KP03｜LES：一扇没有明显解剖门的生理高压区

> **主提示：性质｜压力差｜功能1｜食团到/入胃2递质｜收缩/舒张因素**

### 1｜身份与功能

LES 没有明显的环形平滑肌增厚，不是典型解剖括约肌，而是食管下段形成的**生理性高压区**。

- 静息压力通常比胃内高约 **5–10 mmHg**；
- 核心功能：构成最重要的抗反流屏障。

### 2｜食团经过时的双相控制

```text
食团进入食管
→ 机械感受器
→ 迷走抑制性 / 肽能纤维
→ VIP + NO
→ LES舒张，允许食团入胃

食团已进入胃
→ 迷走胆碱能纤维
→ ACh
→ LES收缩，恢复抗反流屏障
```

### 3｜体液和药物因素

**促 LES 收缩**：

- 胃泌素；
- 胃动素；
- ACh。

**促 LES 舒张**：

- 促胰液素；
- CCK；
- VIP；
- 前列腺素；
- 抗胆碱药、钙拮抗剂、地西泮等代表性药物接口。

记忆原则：当前 Study 中，促进胃动力的一组更倾向使 LES 收缩；抑制胃运动的一组更倾向使 LES 舒张。

（边界：这是本讲义的考试组织法，不扩成所有药物和临床病因清单。）

## KP04｜贲门失弛缓：门打不开；GERD：门关不住

> **主提示：损伤部位｜门效应｜症状｜钡餐｜术式后果｜vs GERD**

### 1｜失弛缓的机制链

```text
食管下2/3肌间神经丛受损
→ 抑制性神经控制不足
→ LES不能正常松弛
→ 食物通过受阻
→ 吞咽困难
→ 钡餐“鸟嘴样”狭窄
```

治疗接口：Heller 食管下段贲门肌层切开。

### 2｜术后为什么会反流

```text
切开降低LES阻力
→ 食物更易进入胃
但抗反流屏障同时减弱
→ 术后可出现GERD
```

### 3｜最小比较

| 轴 | 贲门失弛缓 | GERD |
|---|---|---|
| LES 主故障 | 不能松弛 | 张力下降 / 屏障不足 |
| 主要结果 | 食团进入胃困难 | 胃内容物反流入食管 |
| 当前定位 | D2 机制接口 | D9 完整疾病模型 |

## KP05｜胃的功能分区与 4 种运动：头区收、尾区磨、空腹清扫

> **主提示：头/尾功能｜4运动｜MMC 4期｜2调节因子｜蠕动始/主/方向/作用**

### 1｜头区与尾区

- **头区**：胃底 + 胃体上 1/3，主要负责储存。
- **尾区**：胃体下 2/3 + 胃窦，运动较强，负责磨碎、混合并向十二指肠推进。

### 2｜胃的 4 种运动

1. 紧张性收缩；
2. 消化间期移行性复合运动 MMC；
3. 蠕动；
4. 容受性舒张。

### 3｜MMC：空腹“清道夫”

```text
Ⅰ期：只有慢波、无收缩；与NO相关
Ⅱ期：不规则锋电位和收缩
Ⅲ期：每个慢波上成簇锋电位，规则高幅收缩；与胃动素相关
Ⅳ期：向下一Ⅰ期过渡
```

作用：清扫食物残渣、脱落细胞、细菌、吞入的唾液和黏液。

MMC 减弱可连接：

- 功能性消化不良；
- 小肠细菌过度繁殖。

### 4｜胃蠕动

- 始于胃中部；
- 以尾区为主；
- 起搏源位于胃大弯上部；
- 沿纵行肌向幽门传播；
- 作用：磨碎、混合并推进食糜。

（易混：胃没有把“分节运动”作为其特有主要运动；分节运动是小肠消化吸收的重要形式。）

## KP06｜容受性舒张：容量显著增加，胃内压却不明显上升

> **主提示：胃特有｜刺激3处｜长/短反射｜2递质｜结果2｜失败表现**

### 1｜触发来源

- 食物刺激口、咽、食管感受器；
- 食物进入胃造成机械刺激；
- 食糜进入十二指肠造成机械、化学刺激。

### 2｜反射与递质

```text
迷走—迷走长反射
+
壁内神经丛短反射
→ 抑制性迷走肽能纤维
→ VIP + NO
→ 胃底、胃体上部舒张
```

### 3｜功能结果

- 胃容量明显增加；
- 胃内压不明显升高。

因此同时：

- 避免食物刚进入即迅速排入十二指肠；
- 减少胃内压骤升造成反流的倾向。

容受性舒张受损可出现**早饱**。

（易混：迷走神经不只释放 ACh；胃容受性舒张和 LES 松弛依赖 VIP + NO，阿托品不能解释全部迷走效应。）

## KP07｜胃排空：胃推动，下游十二指肠按处理能力限流

> **主提示：时间2｜三营养物速度序｜直接/原动力｜胃促2反射｜肠抑4刺激+激素｜胃泌素总效应**

### 1｜基本参数

- 进食后约 **5 min** 开始排空；
- 约 **4–6 h** 完全排空；
- 排空是间断进行，而非无控制连续倾倒。

速度：

```text
糖类 > 蛋白质 > 脂肪
```

### 2｜动力

- **直接动力**：胃与十二指肠之间的压力差。
- **原动力**：胃平滑肌收缩。

### 3｜促进：胃内因素

食物扩张胃：

- 迷走—迷走长反射；
- 壁内神经丛短反射；

促进胃运动和排空。

### 4｜抑制：肠内因素

酸、脂肪、高渗食糜、十二指肠扩张：

```text
肠—胃反射
+
促胰液素 / CCK / GIP等肠抑胃素
→ 胃运动↓
→ 胃酸分泌↓
→ 胃排空延缓
```

### 5｜胃泌素的“看似矛盾”

胃泌素：

- 促进胃运动；
- 更明显增强幽门括约肌收缩；

所以**总效应是延缓胃排空**。

（易混：胃泌素“促进胃运动”不能直接推出“促进胃排空”。必须把幽门这扇门一起算进去。）

## KP08｜消化期胃液分泌：头期—胃期—肠期同时起跑但主导方式不同

> **主提示：三期比例｜消化力方向｜主导调节递变｜头2路｜胃3路｜肠期边界**

### 1｜三期总表

| 期别 | 感受食物位置 | 分泌量 | 消化力 | 主导调节 |
|---|---|---:|---|---|
| 头期 | 食物尚未入胃；视听嗅、咀嚼吞咽 | 30% | 强 | 神经为主 |
| 胃期 | 食物进入胃 | 60% | 强 | 神经 + 体液 |
| 肠期 | 食物进入十二指肠 | 10% | 弱 | 体液为主 |

三期均可有神经和体液成分，只是越靠上神经占比越高，越靠下体液占比越高。

### 2｜头期两条通路

```text
条件 / 非条件反射
→ 迷走神经
├─ ACh直接刺激胃腺 / 壁细胞
└─ GRP刺激G细胞 → 胃泌素
```

头期本质带有前馈性质：食物尚未真正进入胃，分泌已启动。

### 3｜胃期三类入口

1. 胃底、胃体扩张 → 迷走—迷走长反射；
2. 胃壁扩张 → ENS 短反射；
3. 胃内蛋白质消化产物直接刺激 G 细胞。

共同促胃液分泌。

### 4｜肠期边界

生理实验中，十二指肠食糜可经体液因素引起少量胃液分泌；但在整体机体中，酸、脂肪和高渗食糜的下游抑制更重要，因此肠对胃的**总效应偏抑制**。

（边界：不要把“肠期有 10% 胃液分泌”推成“食物入肠总体促进胃”。）

## KP09｜胃液细胞地图：消化、保护、B12 三条功能线

> **主提示：壁2｜主1｜黏液2来源｜G/ECL/D三角｜功能3线｜IF疾病链**

### 1｜核心细胞

| 细胞 | 主要分泌物 | 核心作用 |
|---|---|---|
| 壁细胞 | HCl、内因子 | 酸性消化；促进 B12 回肠吸收 |
| 主细胞 | 胃蛋白酶原 | 在酸性环境中转为胃蛋白酶 |
| 表面上皮 / 黏液细胞 | 黏液、HCO₃⁻ | 形成黏液-HCO₃⁻屏障 |
| G 细胞 | 胃泌素 | 促酸、促胃蛋白酶原、促上皮生长等 |
| ECL 细胞 | 组胺 | 通过 H₂受体强力促壁细胞泌酸 |
| D 细胞 | 生长抑素 | “全抑制”轴，抑制 G / ECL / 壁细胞等 |

### 2｜胃蛋白酶

- 主细胞分泌的是无活性胃蛋白酶原；
- HCl 和既有胃蛋白酶共同激活，形成正反馈；
- 最适 pH 约 **1.8–3.5**，pH > 5 时失活；
- 胃内蛋白消化不完全，胰蛋白酶系统是后续主力。

### 3｜内因子—B12 接口

```text
壁细胞 / 内因子受损
→ 内因子缺乏
→ B12不能在回肠有效吸收
→ 巨幼细胞性贫血
```

A 型萎缩性胃炎和胃大部切除术是讲义给出的直接接口。

（易混：胃酸减少不等于内因子一定缺乏；D4 再完整学习 B12 的胃—胰—回肠接力。）

## KP10｜胃酸：既是消化工具，也是必须被约束的攻击因素

> **主提示：最大分泌决定｜作用5｜泌酸链｜碱潮｜pH｜下游2激素**

### 1｜最大分泌能力

**壁细胞数量**决定胃酸最大分泌量；质子泵活性影响当下分泌，但不替代“有多少壁细胞”这个容量上限。

### 2｜胃酸五类作用

1. 激活胃蛋白酶原，并提供酸性环境；
2. 使蛋白质变性，更易被蛋白酶水解；
3. 杀灭随食物进入的微生物；
4. 入十二指肠后促进促胰液素、CCK 等释放，带动胰液、胆汁和肠液；
5. 增加钙、铁等在肠腔内的溶解，有利于吸收。

### 3｜壁细胞泌酸机制

```text
CO₂ + H₂O
--碳酸酐酶→ H₂CO₃
→ H⁺ + HCO₃⁻

顶端膜：H⁺—K⁺—ATP酶把H⁺泵入分泌小管
K⁺经通道循环
Cl⁻经基底侧Cl⁻/HCO₃⁻交换进入细胞
再经顶端Cl⁻通道入腔
→ H⁺ + Cl⁻形成HCl

HCO₃⁻入血
→ 餐后碱潮
```

### 4｜下游接口

## KP11｜胃酸调节网：ACh—胃泌素—组胺三路放大，HCl—D细胞—SST负反馈刹车

> **主提示：促酸3主轴｜迷走3靶点｜胃泌素直/间接｜抑酸6类｜CCK净效应｜HCl负反馈2路**

### 1｜三条主促酸轴

```text
ACh → 壁细胞M受体
胃泌素 → 壁细胞 / ECL的CCKB受体
组胺 → 壁细胞H₂受体
→ 共同激活H⁺—K⁺泵
```

胃泌素作用于 ECL 细胞促进组胺释放，这条间接放大可能比直接刺激壁细胞更重要。

### 2｜迷走神经的三类靶点

- ACh 直接刺激壁细胞；
- ACh 刺激 ECL 释放组胺；
- GRP 刺激 G 细胞释放胃泌素；
- ACh 还抑制 D 细胞释放生长抑素，解除刹车。

### 3｜其他促酸因素｜MI-D集合

当前 Study 还列出：

- 胃内食物和扩张；
- Ca²⁺；
- 糖皮质激素 / 皮质醇；
- 缬酪肽 Valosin；
- 低血糖 / 胰岛素；
- 乙醇、咖啡、牛奶、茶。

这些不应挤掉三条主轴。

### 4｜抑酸因素

- 生长抑素；
- HCl 负反馈；
- VIP 总效应；
- 小肠脂肪及肠抑胃素：促胰液素、CCK、GIP、胰高血糖素、神经降压素等；
- 肠内高渗液及肠—胃反射；
- 前列腺素、EGF。

### 5｜HCl 两路负反馈

```text
HCl↑
├─ 直接抑制G细胞
└─ 刺激D细胞 → 生长抑素↑
→ 胃泌素和胃酸下降
```

### 6｜CCK 的易混边界

CCK 可经不同受体产生促酸和抑酸效应，但当前 Study 的**总效应为抑制胃酸**。同时，胃泌素、促胰液素、CCK 都可促进胃蛋白酶原分泌。

## KP12｜胃黏膜防御：屏障、血流和修复共同对抗 HCl—胃蛋白酶

> **主提示：3层屏障｜PG/EGF 4作用｜直接保护6物质｜适应性保护｜NSAID链｜溃疡天平**

### 1｜三层防御

1. **黏液-HCO₃⁻屏障**：黏液减慢 H⁺向黏膜扩散，HCO₃⁻在近上皮侧中和 H⁺。
2. **上皮与紧密连接 / 胃黏膜屏障**：限制 H⁺反向进入黏膜。
3. **黏膜血流和修复能力**：带走反向扩散的酸，提供修复所需氧和底物。

### 2｜前列腺素与 EGF

主要作用：

- 抑制胃酸；
- 抑制胃蛋白酶原；
- 促进黏液和 HCO₃⁻；
- 舒张黏膜微血管、增加血流并促进修复。

### 3｜直接细胞保护物质

当前 Study 列出：

- 铃蟾素 / GRP 相关轴；
- PGE₂、PGI₂；
- EGF；
- 生长抑素；
- 神经降压素；
- CGRP。

### 4｜适应性细胞保护

食物、胃酸、胃蛋白酶或反流胆汁造成的经常性轻微刺激，可诱导黏膜持续少量释放前列腺素、生长抑素等，使防御系统处于准备状态。

### 5｜//串联：NSAID 与消化性溃疡

```text
传统NSAID抑制COX
→ 生理性前列腺素↓
→ 黏液 / HCO₃⁻ / 黏膜血流与修复下降
→ 防御减弱
→ 在胃酸和胃蛋白酶存在时更易发生黏膜损伤 / 溃疡
```

当前只建立“攻击—防御天平”；HP、PUD 病理、出血和治疗归 D10。

### 3.1 胃的四种运动
