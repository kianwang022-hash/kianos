# D6｜内分泌共同语言
## 轴、反馈、受体与病变定位

> **中心问题**：一种激素究竟从哪里来、怎样到达靶细胞、通过什么受体起效、由什么反馈控制；当激素过多、过少或靶组织不响应时，怎样先确认功能状态，再沿“下丘脑—垂体—靶腺—靶组织”定位，而不是看到一个激素升高就直接猜疾病？
>
> **Primary ownership**：本 Block 首次完整建立激素的一般特性、分泌方式、化学分类、下丘脑—垂体—靶腺轴、长 / 短 / 超短反馈、功能过多 / 过少 / 抵抗的病因层级、原发 / 继发 / 异位定位，以及高血压—低血钾的跨腺体定位接口。后续甲状腺、肾上腺、钙磷、GH与生殖只调用这套语言。

## 2｜总 Framework

```text
A｜一个激素的完整身份
来源细胞
→ 分泌方式
→ 血液 / 组织液 / 腔内运输
→ 靶细胞受体
→ 信号转导
→ 细胞固有功能改变
→ 终末效应反馈

B｜下丘脑—垂体—靶腺轴
下丘脑释放 / 抑制激素
→ 腺垂体促激素
→ 外周靶腺激素
→ 靶组织
↖ 长反馈
   ↖ 短反馈
      ↖ 超短反馈

C｜功能异常三大类
激素过多
├─ 腺体肿瘤
├─ 异位 / 伴瘤内分泌
└─ 自身抗体刺激

激素过少
├─ 靶腺破坏
├─ 上游压迫 / 缺血 / 感染 / 放射 / 手术
└─ 合成 / 释放不足

效应不足但激素不低
└─ 靶组织抵抗 / 受体通路异常

D｜临床定位顺序
先确认真的过多 / 过少
→ 再看上游促激素与终末激素方向
→ 原发 / 继发 / 三级 / 异位 / 抵抗
→ 需要时刺激或抑制试验
→ 最后影像定位

E｜高血压+低血钾坐标
甲状腺：甲亢
肾上腺皮质：原醛 / 库欣
肾上腺髓质：嗜铬
肾小管：Liddle
```

### 一句话恢复

> **激素先由来源和分泌方式进入体液，再靠受体选择靶细胞；临床上先确认功能，再比较上游促激素与终末激素，用反馈方向定位原发、继发、异位或抵抗。**

## KP01｜激素的一般特性：4项、1个决定因素、1个核心边界

> **主提示：** 激素一般特性4｜靶向由什么决定｜能否供能/赋新功能

四个一般特性：

1. 特异作用；
2. 信使作用；
3. 高效作用；
4. 激素间相互作用。

特异性主要由靶细胞受体的分布和亲和力决定。激素作为第一信使，启动靶细胞已有的效应程序；它不作为底物 / 产物直接参与代谢，也不向靶细胞额外提供能量或赋予全新功能。

（特殊：激素特异性不是绝对，可与不同受体发生交叉，只是亲和力不同。）

<!-- kianos:kp id="digestive-d06-kp02" -->
## KP02｜激素相互作用：协同、拮抗、竞争、允许

> **主提示：** 协同/拮抗/竞争/允许｜各判据｜经典例｜允许作用别误判

- **协同**：共同作用大于简单相加；
- **拮抗**：效应方向相反；
- **竞争**：结构相近或共享受体，争夺结合；当前Study例为醛固酮与孕激素竞争盐皮质激素受体；
- **允许作用**：某激素本身不直接完成该效应，但使另一激素能够充分发挥。

糖皮质激素可上调肾上腺素能受体并增强心血管对儿茶酚胺的反应；当前Study还强调醛固酮允许作用强于糖皮质激素。

（易混：允许作用不是协同；竞争不必然等于完全拮抗。）

## KP03｜六种分泌方式：距离、方向和介质

> **主提示：** 分泌方式6｜按距离/方向/介质区分｜局部方式｜外分泌边界

1. 远距 / 血运分泌：入血后作用远处；
2. 旁分泌：经组织液局部作用邻近细胞；
3. 自分泌：反馈作用于分泌细胞自身；
4. 内在 / 胞内分泌：在细胞内调节自身合成等活动；当前Study用儿茶酚胺合成调节作例；
5. 腔分泌：释放至胃肠腔内发挥作用；
6. 神经内分泌：神经元合成的激素进入血液。

（易混：腔分泌虽进入管腔，但没有“经导管排出的外分泌腺液”这一必要身份；旁分泌与自分泌都局部，但靶点不同。）

## KP04｜下丘脑大细胞神经元：ADH / OT的“合成—运输—储存—释放”

> **主提示：** ADH/OT：下丘脑核团｜合成→运输→储存→释放｜后叶角色

```text
下丘脑视上核 / 室旁核大细胞神经元合成
→ 轴浆运输经垂体束
→ 神经垂体储存
→ 刺激时释放入血
```

- ADH / VP：视上核为主；作用于集合管等，完整模型已在泌尿学习；
- OT：室旁核为主；参与射乳和子宫收缩，完整生殖接口后置。

当前Source冲突的安全表达：**神经垂体不合成，只储存和释放。**

## KP05｜下丘脑小细胞—腺垂体：促激素轴与无靶腺激素

> **主提示：** 小细胞调节肽→门脉→腺垂体｜促激素轴｜无靶腺激素｜双重调节

下丘脑小细胞神经元分泌释放 / 抑制激素，经垂体门脉调节腺垂体。

### 促激素

- TSH、ACTH、FSH、LH；
- 分别构成甲状腺、肾上腺皮质、性腺轴。

### 无靶腺激素

- GH、PRL、MSH；
- 直接作用靶组织；受下丘脑释放和抑制信号双重调节。

（易混：GH是腺垂体激素，不是下丘脑激素；ADH / OT不由腺垂体合成。）

## KP06｜激素分泌调节：神经为主、体液为主、直接反馈

> **主提示：** 神经为主4｜直接反馈3｜促激素双控｜无靶腺双调｜例外正反馈

### 以神经调节为主的Study例

- OT：催产 / 射乳反射；
- 儿茶酚胺：交感—肾上腺髓质；
- 夜间迷走神经促进胰岛素；
- 胃液头期迷走—GRP—G细胞—胃泌素。

### 以体液调节为主

- 血糖→胰岛素；
- 血钙→PTH；
- 血Na⁺ / K⁺→醛固酮；
- 胰岛激素间旁分泌调节。

促激素受下丘脑调节肽和靶腺激素反馈；无靶腺激素受下丘脑释放 / 抑制双重调节。

## KP07｜反馈层级：长、短、超短与排卵正反馈

> **主提示：** 长/短/超短反馈｜各回到哪层｜多数方向｜排卵正反馈例外

- **长反馈**：终末靶腺 / 靶组织激素反馈上位腺体；
- **短反馈**：垂体激素反馈下丘脑；
- **超短反馈**：下丘脑神经元受自身调节肽影响。

多数轴采用负反馈，稳定工作区间。排卵期 / 卵泡期末高水平雌激素可触发LH、FSH高峰，是当前Study的重要正反馈例外。

（易混：激素越多分泌越多不自动等于正反馈；必须看反馈信号是否推动原过程继续增强。）

## KP08｜激素化学分类：本质—储存释放—受体三联

> **主提示：** 激素化学分类｜储存/释放方式｜受体位置｜TH特殊｜脂类补充

| 类型 | 来源 / 本质 | 分泌方式 | 受体大方向 |
|---|---|---|---|
| 肽 / 蛋白质 | 氨基酸经肽键聚合 | 囊泡储存、出胞 | 膜受体 |
| 胺类 | 酪氨酸 / 色氨酸衍生 | 儿茶酚胺出胞；TH为特殊 | 儿茶酚胺膜受体；TH多核受体 |
| 类固醇 | 胆固醇衍生 | 合成后扩散 | 多为胞内 / 核受体 |

当前Study另把：

- 钙三醇；
- 类花生酸PG / TX / LT；

作为脂类激素接口。

（易混：胺类不等于全部水溶；TH化学上是胺类，作用方式却更像脂溶性激素。）

## KP09｜膜受体 vs 胞内受体：速度、放大与转录

> **主提示：** 膜受体 vs 胞内受体｜溶解性｜第二信使/转录｜速度/放大｜靶向由谁定

- 水溶性激素通常不能自由穿膜，经膜受体—第二信使—激酶放大，起效相对快；
- 脂溶性激素可进入细胞，结合胞质 / 核受体，调节基因转录，起效相对慢、持续较久；
- 受体数量、亲和力和下游通路共同决定敏感性。

Recall P0：GPCR、RTK、核受体等机制已完整学习，D6只把它们挂到激素身份和临床定位上。

## KP10｜激素过多：腺体、异位、抗体三入口

> **主提示：** 激素过多3入口｜腺体/异位/抗体｜上游促激素怎么定位｜先功能后定位

当前内科Study三类入口：

1. 内分泌腺肿瘤 / 增生；
2. 伴瘤内分泌 / 异位分泌，如小细胞肺癌异位ACTH接口；
3. 刺激性自身抗体，如TSAb。

定位时不能只看终末激素高：

```text
终末激素高 + 上游促激素低
→ 倾向靶腺自主分泌

终末激素高 + 上游促激素不被抑制 / 也高
→ 考虑上游驱动或异位分泌
```

具体阈值与动态试验后置对应疾病。

<!-- kianos:kp id="digestive-d06-kp11" -->
## KP11｜激素过少与抵抗：腺体坏、上游少、靶组织不听

> **主提示：** 激素过少/抵抗｜原发腺体损伤｜上游不足｜靶组织抵抗｜终末激素低时看什么

激素过少可来自：

- 自身免疫破坏：T1DM、桥本、Addison接口；
- 垂体肿瘤压迫；
- 产后大出血导致Sheehan；
- 感染、放射、手术等；
- 合成或释放环节失败。

若激素水平不低甚至升高，但靶组织效应不足，应考虑激素抵抗 / 受体通路异常。

```text
终末激素低 + 促激素高 → 原发靶腺功能减退倾向
终末激素低 + 促激素低/不当正常 → 上游功能减退倾向
```

（边界：不同轴存在结合蛋白、脉冲和节律影响，不能脱离取样条件机械套公式。）

## KP12｜内分泌临床定位：功能确认—轴方向—动态试验—影像

> **主提示：** 内分泌定位顺序：功能→层级→动态试验→影像｜过多/过少各用哪类试验

稳定决策顺序：

```text
1. 症状 / 基础化验提示过多或过少
2. 复核取样时间、节律、脉冲与结合蛋白接口
3. 同时看终末激素和上游促激素方向
4. 判断原发 / 继发 / 三级 / 异位 / 抵抗
5. 需要时：过多状态做抑制试验；过少状态做刺激试验
6. 生化定位成立后再做影像
```

核心门槛：**定位之前，先确认“功能异常真的存在”。**

（边界：D6不提供所有疾病的完整动态试验表。）

## KP13｜高血压+低血钾：先定位器官，再区分原醛与Liddle

> **主提示：** 高压+低K先定位器官｜原醛 vs Liddle：A/R轴｜用药靶点

当前Study入口：

- 原发性醛固酮增多症；
- 库欣综合征；
- 嗜铬细胞瘤；
- 甲亢；

### 原醛 vs Liddle

| 轴 | 原醛 | Liddle |
|---|---|---|
| 主体位置 | 肾上腺皮质 | 集合管主细胞ENaC |
| 机制 | 醛固酮↑，保Na排K | ENaC遗传性过度激活 |
| 肾素 | ↓ | ↓ |
| 醛固酮 | ↑ | ↓ |
| 肾上腺增生 | 可有 | 无 |
| 治疗 | 螺内酯等 | 阿米洛利 / 氨苯蝶啶 |

```text
ENaC↑ → Na⁺重吸收↑ → 水钠潴留、高血压
                    → 管腔负电 / 浓度差推动K⁺分泌 → 低钾
```

Liddle中醛固酮本身低，故醛固酮受体拮抗剂效果差，应直接抑制ENaC。
