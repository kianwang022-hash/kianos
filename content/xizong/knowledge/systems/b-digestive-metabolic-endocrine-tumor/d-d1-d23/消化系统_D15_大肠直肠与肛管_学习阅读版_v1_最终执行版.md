# D15｜大肠、直肠与肛管
## 从排便改变和便血，到肿瘤位置、齿状线与括约肌保护

> **中心问题**：中老年出现排便习惯改变、便血、梗阻或里急后重时，怎样先定位右结肠、左结肠、直肠或肛管，再用检查、浸润、括约肌和齿状线决定治疗；肛周疼痛、肿块、脓液又怎样分流到痔、肛裂、脓肿或肛瘘？
>
> **Primary ownership**：大肠癌、直肠癌、齿状线上下、痔、肛裂、直肠肛管周围脓肿、肛瘘及直肠指检整合在本 Block 首次完整学习。

# 2｜总 Framework

```text
排便改变 / 便血 / 里急后重 / 腹部肿块 / 肛周疼痛
        ↓
A｜先判位置
右结肠：肿块、贫血、消瘦
左结肠：便细、便血、梗阻
直肠：里急后重、肛门下坠、指检可触
肛管：齿状线以下，疼痛敏感
        ↓
B｜再证实肿瘤
DRE → 结肠镜病理 → CT/MRI/腔内超声分期
        ↓
C｜再判手术结构
结肠：按血供与肠段切除
直肠：括约肌/肛提肌 + 距肛缘/齿状线 + 急性梗阻
        ↓
D｜再看转移
淋巴最早最常见；晚期门静脉至肝
        ↓
E｜肛周分流
鲜血无痛脱出 → 内痔
周期性排便痛 → 肛裂
持续跳痛/波动 → 脓肿
反复脓血、条索 → 肛瘘
```

### 一句话恢复

> **大肠癌先靠排便改变和便血进入，再按右肿块/左梗阻/直肠刺激定位；肛管病则由齿状线决定“痛不痛、往哪转移、是什么癌、是哪种痔”。**

# 3｜大肠癌共同模型

<!-- kianos:kp id="digestive-d15-kp01" -->
## KP01｜大肠癌入口：排便改变最早，便血最需报警

> **主提示：人群1｜最早最常1｜报警1｜右/左/直肠三入口｜IBD接口**

### 快速核对

- 中老年；
- 最早、最常见症状：排便习惯和粪便性状改变；
- 最主要报警症状：便血；
- 右侧结肠：腹部肿块、贫血、低热、消瘦；
- 左侧结肠：便细、便血、梗阻；
- 直肠：便血、里急后重、肛门下坠、梗阻性细便。

//串联：D12 的 UC/CD 长期慢性炎症属于癌前风险接口，但脓血便并不等于已癌变。

---

<!-- kianos:kp id="digestive-d15-kp02" -->
## KP02｜病理身份与扩散：腺癌为主，淋巴最早，肝是晚期血道枢纽

> **主提示：突破层级｜大体3型｜组织型3｜最早转移1｜血道首站｜牛眼征边界**

### 快速核对

当前病理 Lecture：

- 肿瘤突破黏膜肌层到达黏膜下层后，按本讲义进入癌的层级；
- 中晚期大体：溃疡型最多；隆起/息肉/蕈伞型偏右侧；浸润型偏左侧；
- 组织学以腺癌最多，直肠肛门附近可见鳞癌；黏液腺癌/胶样癌在本讲义中预后差；
- 癌最早、最常见为淋巴转移；
- 晚期血道转移常至肝；转移性肝癌可呈牛眼征。

（易混：牛眼征是转移性肝癌的影像表现，不只属于“大肠癌肝转移”。）

---

<!-- kianos:kp id="digestive-d15-kp03" -->
## KP03｜检查层级：DRE先摸入口，结肠镜定性，影像做分期

> **主提示：DRE→结肠镜→影像｜各回答什么｜CEA能/不能做什么**

### 快速核对

- 首选：直肠指检；约 70% 低位直肠癌可触及不规则、质硬、易出血肿物；
- 金标准：结肠镜 + 病理；
- 筛查：大便隐血试验，可持续阳性；
- CT/MRI、腔内超声/超声内镜：明确局部浸润、转移和分期；
- CEA：辅助诊断、判断预后、监测复发；与分期有关；术后不降提示残留，持续升高提示复发。

（边界：CEA 正常不能排除癌，也不能作为缩小切除范围的依据。）

<!-- kianos:kp id="digestive-d15-kp04" -->
## KP04｜术前肠道准备：0123 只做 Memory Gate，不替代手术决策

> **主提示：术前肠道准备：抗生素｜饮食｜灌肠｜禁食禁饮｜目的**

### 快速核对

当前 Lecture：

- 预防性使用抗生素；
- 术前 2–3 天进流食；
- 术前 1 天及手术当天清晨灌肠，可用聚乙二醇/甘露醇接口；
- 围术期禁食禁饮按当前外科流程处理。

目的：降低肠内容物与污染风险，为吻合和手术操作创造条件。

# 4｜结肠癌：左右两边是两种临床节奏

<!-- kianos:kp id="digestive-d15-kp05" -->
## KP05｜右侧 vs 左侧结肠癌：右“拢”肿块，左“浸”梗阻

> **主提示：右侧 vs 左侧结肠癌｜症状/大体｜为何右肿块左梗阻｜最常部位**

### 快速核对

| 轴 | 右侧结肠 | 左侧结肠 |
|---|---|---|
| 常见大体 | 隆起型 | 浸润型 |
| 临床 | 腹部肿块、低热、贫血、消瘦 | 梗阻、大便细、便血 |
| 原因 | 肠腔较宽、内容物较稀；肿瘤消耗/出血 | 肠腔较窄、内容物干硬，浸润收缩 |

结肠癌部位中乙状结肠多见；大肠癌整体以直肠癌更常见。

（易混：右侧出血可被稀释，不一定表现为明显鲜血便；可先以缺铁性贫血进入。）

---

<!-- kianos:kp id="digestive-d15-kp06" -->
## KP06｜结肠切除：按肿瘤所在血管—肠段切，而不是凭“升/降结肠”命名

> **主提示：结肠癌按血供/肠段选术式｜4种切除对应范围｜远端切缘｜命名陷阱**

### 快速核对

- 盲肠、升结肠、肝曲 → 右半结肠切除；
- 横结肠中部 → 横结肠切除；
- 脾曲、降结肠 → 左半结肠切除；
- 乙状结肠 → 乙状结肠切除；
- 当前 Lecture：肿瘤远端距切缘 ≥10 cm。

（易混：干扰项常写“升结肠切除术/降结肠切除术”；当前讲义按右半/左半结肠血管与淋巴清扫范围组织。）

---

<!-- kianos:kp id="digestive-d15-kp07" -->
## KP07｜结肠癌并急性梗阻：右侧可一期，左侧看水肿污染

> **主提示：结肠癌+急性梗阻｜右侧 vs 左侧｜何时一期｜水肿污染时怎么处理两端**

### 快速核对

- 右半：右半结肠切除 + 一期回肠—结肠吻合；
- 左半：可切除 + 一期吻合，或先支架、限期切除；
- 若近端肠管扩张、水肿明显：切除肿瘤，近端造口、远端封闭。

```text
先排绞窄/穿孔/腹膜炎
→ 再决定是否能安全一期吻合
```

（易混：术式差异不是“左右固定公式”，核心仍是血供、扩张水肿、污染和患者耐受。）

# 5｜直肠癌：保肛决策围绕括约肌、肛提肌、距离和急性状态

<!-- kianos:kp id="digestive-d15-kp08" -->
## KP08｜直肠癌识别：低位肿瘤把“便意系统”变成持续刺激

> **主提示：直肠癌：排便/便意症状4｜好发位置｜DRE触感｜直乙交界怎么分**

### 快速核对

- 便血；
- 里急后重；
- 肛门下坠感；
- 梗阻、大便变细；
- 大肠癌中直肠癌最常见，且低位直肠癌常见；
- DRE：不规则、质硬、易出血；
- 直肠—乙状结肠交界处肿瘤按直肠癌处理。

（易混：黏液脓血便也可见 UC、细菌性痢疾等；中老年排便改变 + DRE 肿物更支持直肠癌。）

---

<!-- kianos:kp id="digestive-d15-kp09" -->
## KP09｜第一决策层：肛门外括约肌和肛提肌是否受累

> **主提示：受累→1术式｜未受累→2保肛路径｜临时造口目的｜结构优先**

### 快速核对

- 肛门外括约肌/肛提肌受累 → 腹会阴切除 Miles，不保肛；
- 未受累 → 即使位置低，也可考虑结肠—直肠低位吻合 Dixon，或结肠—肛管超低位吻合 Parks/ISR；
- 临时性回肠造口可降低吻合口漏的临床风险接口。

```text
保肛的核心先看肿瘤是否侵犯控制结构
→ 不是只看肿瘤直径
```

（边界：具体影像评估、全直肠系膜切除和现代保肛技术不扩写。）

---

<!-- kianos:kp id="digestive-d15-kp10" -->
## KP10｜第二决策层：5/7 cm 距离算法与 Source 冲突

> **主提示：2距离阈值｜返折上下｜Miles vs Dixon｜切缘另核**

### 快速核对

当前 Lecture 的传统距离算法：

- 腹膜返折以下、距肛缘 <7 cm 或距齿状线 <5 cm → Miles；
- 腹膜返折以上、距肛缘 ≥7 cm 或距齿状线 ≥5 cm → Dixon。

`SOURCE_CONFLICT / 待核对`：

- 同一 Lecture 在“括约肌未受累可低位吻合”段写 Dixon 切缘 ≥1 cm；
- 后续传统距离算法/题目段写 Dixon 远端切缘 ≥2 cm。

本文不静默选一。考试使用时：

1. 先看题目是否直接给“括约肌/肛提肌受累”；
2. 再看题目是否按 5/7 cm 传统表述；
3. 切缘数字回当前 Source 页和题目口径核对。

## KP11｜Hartmann：本可 Dixon 但不能一期吻合，或本可 Miles 但耐受不了

> **主提示：Hartmann三步｜两类适应证｜急梗阻/不能一期吻合｜远端怎么处理**

### 快速核对

Hartmann：经腹切除直肠/病变段 + 近端造口 + 远端封闭。

适应：

1. 急性肠梗阻，不宜一期 Dixon 吻合；
2. 原本需 Miles，但患者不能耐受更大手术。

（易混：Hartmann 不是单纯姑息造口；它包含病变切除、近端造口和远端封闭。）

<!-- kianos:kp id="digestive-d15-kp12" -->
## KP12｜肝转移：牛眼征说明“转移灶”，可切除时允许同步处理

> **主提示：结直肠癌肝转移：血流路径｜肝为何常是首站｜牛眼征｜何时同步切除**

### 快速核对

```text
结直肠静脉血
→ 门静脉
→ 肝
```

晚期血道转移常到肝；影像可见边缘环形强化、中央相对低密度的牛眼征。

当前 Lecture：若肝/肺或局部转移灶可切除、预后条件合适，可考虑原发灶与转移灶同时手术；病例中局限肝左外叶/某段的小转移灶可与结肠癌根治术联合切除。

（边界：完整可切除性标准、化疗转换和介入方案不在 D15扩写。）

# 6｜病理癌前与分子 Memory Island

<!-- kianos:kp id="digestive-d15-kp13" -->
## KP13｜癌前病变与基因：两条大肠癌通路只建考试坐标

> **主提示：癌前4类｜息肉病5型｜腺瘤3型/最高风险｜原癌3｜抑癌6｜MMR2族**

### 快速核对

**癌前病变**：

- 息肉病：FAP、增生性息肉病、幼年性息肉病、Peutz–Jeghers、Gardner、Turcot 等当前 Lecture 列表；
- 腺瘤：管状最常见，绒毛状更易癌变，另有混合型；
- 慢性血吸虫病；
- IBD：UC，CD 也可。

**相关基因**：

- 原癌：c-MYC、RAS、BRAF；
- 抑癌：TP53、p16、APC、DCC、MCC、DPC；
- 错配修复：MLH、MSH，连接遗传性非息肉病性大肠癌/Lynch。

MI-G 只抓：**APC—KRAS/RAS—TP53 + MLH/MSH**。其余进入 MI-D。

（边界：不在此扩写完整腺瘤—癌序列、微卫星不稳定和遗传咨询。）

# 7｜齿状线与肛管疾病

<!-- kianos:kp id="digestive-d15-kp14" -->
## KP14｜齿状线上下：一条线同时改变组织、痛觉、淋巴、癌种和痔

> **主提示：上/下：胚层｜黏膜/皮肤｜A/V｜淋巴｜神经痛｜癌种｜痔**

### 快速核对

| 轴 | 齿状线以上 | 齿状线以下 |
|---|---|---|
| 外科分界 | 直肠 | 肛管 |
| 胚层 | 内胚层 | 外胚层 |
| 表面 | 黏膜，易破裂出血 | 皮肤，相对不易破裂 |
| 动脉 | 直肠上为主，另有直肠下/骶正中 | 肛管动脉 |
| 静脉 | 直肠上V→门V | 直肠下/肛管V→下腔V |
| 淋巴 | 肠系膜下A旁、髂内 | 腹股沟浅 |
| 神经 | 内脏，痛觉不敏感 | 阴部神经/躯体，痛觉敏感 |
| 癌 | 腺癌 | 鳞癌 |
| 痔 | 内痔 | 外痔 |

（VISUAL_ONLY：必须回原图看齿状线、静脉与淋巴方向。）

## KP15｜痔：肛垫下移和静脉曲张，先看出血—脱出—疼痛

> **主提示：本质2｜内痔4度｜一般痛否｜痛3例外｜外痔血栓3｜混合/环状**

### 快速核对

- 本质：肛垫下移、静脉曲张；
- Ⅰ度：出血；
- Ⅱ度：出血 + 脱出，可自行还纳；
- Ⅲ度：需手还纳；
- Ⅳ度：不能还纳或还纳后再脱出；
- 内痔通常无痛；血栓、嵌顿、感染时可痛；
- 血栓性外痔：剧痛、暗紫色硬性肿块，剥离痔内血栓；
- Ⅲ/Ⅳ度内痔与外痔融合为混合痔；环状脱出呈梅花状为环状痔。

内痔好发截石位 3、7、11 点。

## KP16｜肛裂：便秘—裂伤—括约肌痉挛形成疼痛恶性循环

> **主提示：人群｜位置2体位｜侧方警报｜痛3阶段｜鲜血｜三联征｜首选/无效治疗**

### 快速核对

- 青壮年便秘多见；
- 好发后正中线：截石位 6 点、膝胸位 12 点；
- 侧方肛裂应想到 CD 等肠炎或肿瘤；
- 典型：排便剧痛 → 间歇期缓解 → 内括约肌痉挛痛；可有鲜血；
- 三联征：肛裂、前哨痔/皮垂、肛乳头肥大；
- 首选保守：高锰酸钾坐浴、润便、扩张；无效可肛裂切除、内括约肌切断或当前 Lecture 的挂线接口。

（易混：切断外括约肌会造成失禁；治疗针对内括约肌痉挛。）

## KP17｜直肠肛管周围脓肿：位置越高，全身症状越重

> **主提示：直肠肛管脓肿3间隙｜高低位症状差｜最常/最少｜波动后动作**

### 快速核对

| 类型 | 局部症状 | 全身症状 | 特点 |
|---|---|---|---|
| 肛周脓肿 | 明显 | 不明显 | 最常见 |
| 骨盆直肠间隙脓肿 | 不明显 | 明显 | 最少见 |
| 坐骨肛管/直肠间隙脓肿 | 明显 | 明显 | 可有直肠/膀胱刺激征 |

局部可见红肿热痛、持续跳痛；触及波动感提示脓腔，需要切开引流。

```text
位置越高 → 局部不易显现、全身吸收更重
位置越低 → 局部红肿痛更明显
```

## KP18｜肛瘘：脓肿是急性期，反复脓血和条索是慢性通道

> **主提示：急/慢关系｜最常类型｜表现2｜最重要判断轴｜低/高×单/复杂4术式**

### 快速核对

- 肛周感染急性期可表现为脓肿，慢性期形成肛瘘；
- 最常见：括约肌间型，属于低位肛瘘；
- 表现：条索状肿物，反复流出脓血性分泌物；
- 治疗最重要：明确瘘管行程及与括约肌关系，减少括约肌损伤。

| 类型 | 当前 Lecture 处理 |
|---|---|
| 低位单纯 | 切除首选，或挂线 |
| 低位复杂 | 切开，或切开 + 挂线 |
| 高位单纯 | 挂线 |
| 高位复杂 | 切开 + 挂线 |

记忆：挂线适用面广；只有低位单纯可直接切除而较少损伤括约肌。

## KP19｜直肠指检触感地图：硬、软、条索、波动分别指向不同结构

> **主提示：DRE触感：硬/软/条索/波动｜各指向什么｜哪些病难靠DRE**

### 快速核对

| 疾病 | DRE 典型触感/角色 |
|---|---|
| 直肠癌 | 不规则、质硬、易出血 |
| 直肠息肉 | 柔软、光滑、可推动、有蒂，可出血 |
| 内痔 | 柔软血管团 |
| 肛瘘 | 条索状肿物 |
| 盆腔脓肿 | 直肠前壁触痛、波动性肿块 |
| 前列腺增生/癌/炎 | 直肠指检评估前列腺；增生可见中央沟变浅/消失 |
| 肛裂 | 一般不需 DRE，避免剧痛 |

（边界：DRE 对高位结肠病变检出有限；摸到血不等于一定是直肠癌。）
