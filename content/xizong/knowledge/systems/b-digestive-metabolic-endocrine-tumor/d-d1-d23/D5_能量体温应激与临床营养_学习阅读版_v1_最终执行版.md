# D5｜能量、体温、应激与临床营养
## 从“底物氧化”到“ATP—热—体温—应激—营养支持”

> **中心问题**：糖、脂肪和蛋白质进入体内后，怎样转化为ATP、热和机械功；机体怎样测量并调节能量消耗与体温；手术、感染、创伤和烧伤为何把“合成—储存”切换成“分解—动员”；当患者不能靠正常进食满足需求时，怎样先判断营养状态，再选择肠内或肠外营养，并识别高风险并发症？

## 2｜总 Framework

```text
A｜能量输入与去路
糖 / 脂 / 蛋白
→ 乙酰CoA / TCA / OXPHOS
→ ATP
├─ 主动转运、分泌、合成、肌肉收缩
├─ 最终多转为热 → 维持体温 / 散失
└─ 对外机械功 → 外界物体势能 / 动能

B｜怎样判断“烧的是什么、烧得多少”
热价：1g食物氧化释放多少能量
氧热价：消耗1L O2产生多少热
RQ = VCO2 / VO2：偏向判断氧化底物
直接 / 间接测热 → BMR / REE

C｜体温闭环
温度感受器
→ PO/AH比较器 / 调定点
→ 产热：肝、肌肉、褐色脂肪、激素
→ 散热：辐射、传导、对流、蒸发、皮肤血流
→ 核心温度回到工作区间

D｜应激状态切换
手术 / 创伤 / 感染 / 烧伤
→ 交感—儿茶酚胺 + 应激激素
→ 分解代谢↑、糖异生↑、胰岛素抵抗接口
→ 高血糖、负氮平衡、能量需求↑

E｜营养决策
先评估：体重 / BMI / 肌脂 / 蛋白 / 氮平衡 / TLC
→ 需求是否增加？
→ 肠道是否可用、能否达标？
├─ 能用：EN
└─ 不能用 / 达不到：PN
→ 监测导管、吸入、代谢、电解质、肝胆、骨与再喂养风险
```

### 一句话恢复

> **D5先把底物的能量去路和体温闭环建立起来，再把手术/创伤应激看成“从合成转向分解”的状态切换，最后用“营养状态—需求—肠道功能—输入途径—并发症”决定EN或PN。**

## KP01｜ATP、热与机械功：能量最后去了哪里

> **主提示：** ATP两类功｜内功/外功最后去哪｜CP角色｜能量守恒

```text
营养物质化学能
→ ATP
→ 主动转运 / 腺体分泌 / 合成 / 肌肉活动
```

体内耗能过程释放的能量多数最终转为热：一部分维持体温，一部分散出体外。骨骼肌若对外界物体做功，则该部分能量先转化为外界物体的机械能，不立即计入机体热量。

ATP既是直接供能形式，也是高能磷酸键的暂时载体；磷酸肌酸CP在骨骼肌、心肌、脑等高耗能组织中作为快速ATP缓冲库。

（易混：肌肉收缩**不对外做功**时，能量更接近全部转为热；举起哑铃时，一部分转成哑铃势能。）

## KP02｜热价 vs 氧热价：一个按食物重量，一个按耗氧量

> **主提示：** 热价 vs 氧热价｜三底物排序｜蛋白物/生差别｜与耗氧量别混

| 比较轴 | 热价 | 氧热价 |
|---|---|---|
| 定义 | 1g食物氧化释放的能量 | 食物氧化消耗1L O₂产生的热量 |
| 当前Study最高者 | 脂肪 | 糖 |
| 关键边界 | 蛋白质体内不能完全氧化 | 不随总耗氧量改变 |

蛋白质体外燃烧可完全释放能量，而体内仍以尿素等形式带走部分能量，因此物理热价高于生物热价。

## KP03｜呼吸商RQ：三底物、四类特殊状态和一个公式

> **主提示：** RQ公式｜三底物典型值｜特殊状态4｜RQ vs 氧热价

```text
RQ = 一定时间内CO₂排出量 / O₂摄取量
```

- 糖：1.0；
- 蛋白质：0.8；
- 脂肪：0.7。

当前Study特殊：

- 长期饥饿：约0.8；
- 糖尿病：约0.7；
- 长期糖摄入过多、糖转脂：可>1；
- 过度通气、代谢性酸中毒：CO₂排出增加，可>1。

（边界：RQ既受底物氧化影响，也可能被肺通气和酸碱状态拉动，不能把一次测值机械等同于单一底物。）

## KP04｜能量代谢怎样测：直接、间接、双标记水

> **主提示：** 直接测什么｜间接测什么｜RQ怎么接氧热价｜双标记水适用场景

- **直接测热法**：安静、避免外功，直接测一定时间散热量。
- **间接测热法**：测耗氧量和CO₂产生量，按RQ查氧热价，推算能量消耗。
- 当前基础状态计算使用非蛋白混合食物RQ约0.82，对应氧热价约20.2 kJ/L，再结合耗氧量与体表面积计算BMR。
- **双标记水法**：用稳定同位素在自由活动状态下估算能量消耗，适合儿童等研究场景。

（易混：直接测热看热量；间接测热看气体交换；BMR不是随便静坐就能测。）

## KP05｜影响能量代谢：4因素、1个最主要、3种食物排序

> **主提示：** 能量代谢4因素｜最主要1｜食物特动排序｜温度双端效应

四个主因素：

1. **肌肉活动**：最主要；
2. 精神紧张：无意识肌紧张、交感及激素活动使代谢↑；
3. 食物特殊动力效应：蛋白质＞糖＞脂肪；
4. 环境温度：低于20℃或高于30℃均可使能量代谢↑。

三个易混排序：

```text
特殊动力效应：蛋白 > 糖 > 脂
促进胆汁分泌：蛋白 > 脂 > 糖
胃排空速度：糖 > 蛋白 > 脂
```

食物特殊动力效应来自消化、吸收、合成与储存耗能，也与口咽—交感—褐色脂肪及促胰液素 / 胆汁酸的产热接口有关。

## KP06｜基础代谢率BMR：6条件、1公式、升降两组

> **主提示：** BMR测定条件｜换算公式｜相对值怎么算｜升/降因素｜甲状腺最典型

测定条件：清醒、安静无精神紧张、禁食≥12h、静卧无肌紧张、无剧烈运动≥2h、环境20–25℃。

```text
BMR相对值
=（实测值－正常平均值）/ 正常平均值 ×100%
```

当前Study疾病方向：

- 升高：红细胞增多、白血病、甲亢最明显、伴呼吸困难的心脏病、体温升高、糖尿病；
- 降低：甲减最明显、Addison病、垂体功能低下性肥胖、肾病综合征、病理性饥饿。

（边界：BMR是严格基础状态下的能量代谢率；REE在临床营养中更强调静息状态与疾病应激。）

## KP07｜体温的生理变动：核心温度、日节律、性别与年龄

> **主提示：** 核心体温｜日节律｜排卵/孕激素｜性别差｜新生儿特点

- 生理学所说体温是机体核心部分平均温度；鼓膜温度接近下丘脑温度，可反映脑温。
- 日节律：清晨低、午后高，通常波动不超过1℃；节律中枢在下丘脑视交叉上核。
- 女性平均体温略高；排卵日最低，排卵后孕激素使调定点升高。
- 儿童体温较成人高，但新生儿调节中枢不成熟，体温不恒定、易受环境影响。
- 当前Study对比：男性BMR通常高于女性，年龄越小BMR越高。

## KP08｜产热器官与战栗：静息、运动、寒冷三场景

> **主提示：** 静息/运动/寒冷主要产热器官｜成人 vs 新生儿｜战栗前后｜是否做外功

- 安静时主要产热器官：肝；
- 运动时：骨骼肌；

## KP09｜非战栗产热：UCP怎样把质子势能变成热

> **主提示：** 非战栗产热：人群/组织｜UCP怎么解耦｜甲状腺激素 vs 快速激素

```text
呼吸链泵H⁺至膜间隙
→ H⁺经UCP返回线粒体基质
```

## KP10｜散热四方式：何时辐射最重要，何时只剩蒸发

> **主提示：** 散热4方式｜通常谁主导｜皮温≤环境时只剩什么｜不感蒸发量级

- 辐射：皮温高于环境时通常最主要；
- 传导：直接接触较冷物体；
- 对流：气体 / 液体流动带走热，是传导的特殊形式；
- 蒸发：水汽化吸热。

当皮肤温度≤环境温度时，辐射、传导、对流不能净散热，蒸发成为唯一有效方式。

不感蒸发来自皮肤和呼吸道黏膜，不依赖汗腺；当前Study24h约600–700ml，婴幼儿速率更高。

## KP11｜汗液形成：主动分泌、等渗起点、低渗终点

> **主提示：** 汗液形成：分泌方式｜初始张力｜导管重吸收｜最终张力｜大量出汗后ADH

- 小汗腺几乎遍布全身；手掌、足趾分布最密，躯干分泌能力最强。
- 汗腺细胞主动分泌初始等渗液；流经导管时，醛固酮促进NaCl重吸收，而导管对水通透性低，最终汗液低渗。
- 大量出汗丢失低渗液：血浆渗透压↑ → ADH↑ → 尿量↓；严重可出现高渗性脱水。
- 短时间出汗速度过快时，导管来不及充分回收NaCl，汗中盐浓度可升高。

（易混：初始汗等渗；最终排出汗低渗。）

## KP12｜温热性 vs 精神性发汗：神经、部位、中枢、任务四轴

> **主提示：** 温热性 vs 精神性发汗｜神经递质｜部位｜中枢｜任务

| 轴 | 温热性发汗 | 精神性发汗 |
|---|---|---|
| 交感纤维 | 胆碱能，ACh→M | 肾上腺素能，NA→α₁ |
| 汗腺 | 全身小汗腺 | 掌心、足底、前额为主 |
| 中枢 | PO/AH | 大脑皮层运动区 |
| 作用 | 体温调节 | 精神紧张 / 情绪激动 |

两者可同时存在。低血糖可经交感兴奋使皮肤潮湿；DKA / HHS昏迷常因脱水而皮肤干燥，属于后续D8识别接口。

## KP13｜体温控制器：感受器、PO/AH、调定点与负反馈

> **主提示：** 温度感受器｜PO/AH｜冷/热神经元分布｜敏感度/适应｜调定点负反馈

```text
皮肤 / 黏膜 / 内脏温度感受器
+ 下丘脑 / 脑干 / 脊髓温度敏感神经元
→ PO/AH体温调节中枢
→ 产热 / 散热 / 皮肤血流 / 行为
```

- PO/AH热敏神经元较多；脑干网状结构和下丘脑弓状核冷敏神经元较多。
- 温度敏感神经元对约0.1℃变化即可改变放电，无适应现象。
- 升温时热敏神经元放电↑；降温时冷敏神经元放电↑。
- 自主性调节以负反馈为主，也可由前馈减少波动；行为性调节包括增减衣物、改变环境等。

（易混：体温日节律中枢在视交叉上核；体温调节中枢在PO/AH。）

## KP14｜发热 vs 中暑：调定点是否改变

> **主提示：** 发热 vs 中暑｜调定点是否变｜起始/退热表现｜中暑故障层

### 发热

```text
致热原 / PG等
→ 调定点上移
→ 当前体温低于新调定点
→ 寒战、皮肤血管收缩、产热↑
→ 体温升高
```

恢复期调定点回落，现有体温高于调定点，于是出汗、血管扩张、散热↑。

### 中暑

调定点不变；体温升高来自体温调节中枢功能障碍或散热能力不足，属于非调节性体温升高。

//串联：当前只建立“调定点”边界，不扩写完整感染、热射病或解热药治疗。

## KP15｜营养评价：6类证据先判断“库存是否够”

> **主提示：** 营养评价6类证据｜各反映什么库存/功能｜常用阈值

六类证据：

1. 体重变化；
2. BMI；
3. 肌肉与脂肪：肱三头肌皮褶、上臂围、握力；
4. 血浆蛋白：白蛋白，以及更敏感的前白蛋白、转铁蛋白、视黄醇结合蛋白；
5. 氮平衡；
6. 总淋巴细胞计数TLC。

当前Study门槛：

- 体重丢失>10%，或3个月内>5%：提示营养不良；
- BMI<18.5：营养不良；24–28：超重；≥28：肥胖；
- BMI≥30者能量摄入按正常25–30 kcal/kg的70–80%；
- TLC<1.8×10⁹/L：营养不良接口。

（边界：这些指标要合并判断，不能仅凭白蛋白或BMI单项下结论。）

## KP16｜应激代谢与REE：为什么患者越重，越“分解”

> **主提示：** 应激触发｜糖/脂/蛋白方向｜氮平衡｜血糖｜REE随严重度怎么变

```text
手术 / 创伤 / 感染 / 烧伤
→ 应激与交感信号
→ 蛋白质分解↑ + 脂肪动员↑ + 糖异生↑
→ 血糖↑、负氮平衡、愈合与免疫风险
```

当前Study静息能量消耗REE增幅：

- 手术：约10%；
- 严重创伤、多发骨折、感染：约20–30%；
- 大面积烧伤：约50–100%。

应激不是“葡萄糖储存增加”，而是分解和动员增强。营养支持要补需求，但过量供能同样会造成高血糖、脂肪肝、CO₂负荷和代谢并发症接口。

## KP17｜肠内营养EN：只要肠道可用，优先让它工作

> **主提示：** EN适应前提｜途径按时长怎么选｜制剂类型｜最常见/最严重并发症｜胰腺炎接口

### 路径

- <2周：口服、鼻胃 / 鼻十二指肠、鼻空肠；
- >2周：胃造口、空肠造口。

### 制剂

1. 非要素 / 整蛋白型：最常用；
2. 要素型：氨基酸、小肽等，无需充分消化，适合部分胃肠功能受损；
3. 组件型：按特殊缺口补充；
4. 疾病专用型：按糖尿病、慢性肾衰等调整。

### 并发症

- 机械性；
- 胃肠道：腹胀、腹泻最常见，常与输注过快有关；
- 代谢性；
- 感染性：吸入性肺炎最严重。

重症胰腺炎按当前Study：禁食期TPN；肠功能恢复后尽早转EN，常用鼻空肠或空肠造口绕开胃、十二指肠刺激。

## KP18｜肠外营养PN：何时用、从哪里进、给什么

> **主提示：** PN何时用｜外周 vs 中心按时长｜三大营养素｜能量比例｜配伍边界

### 适应证入口

1周以上不能进食、胃肠功能障碍或EN不能达标，如高位小肠瘘、短肠、重症胰腺炎、AKI、严重感染 / 烧伤、UC长期腹泻、肿瘤治疗期严重呕吐等。

脑外伤昏迷、甲亢术后饮水呛咳等若肠道可用，优先管饲EN；幽门梗阻可绕行空肠，不自动等于PN。

### 输入途径

- <2周：外周静脉；
- >2周：中心静脉，如PICC、锁骨下、颈内静脉。

### 当前Study供给

- 葡萄糖3–3.5 g/kg·d，严重应激2–3；供能50–60%；
- TAG 0.7–1.3 g/kg·d；供能30–40%；
- 氨基酸1.2–1.5 g/kg·d；
- 糖脂比1:1，应激1:2；
- 氮:热量=1:(150–200)；
- 必需:非必需氨基酸=1:2。

谷氨酰胺营养肠黏膜；肝功能不全加用支链氨基酸。营养液中不添加其他药物。

## KP19｜PN并发症：导管、再喂养、肝胆、肠屏障与骨

> **主提示：** PN并发症5类｜导管感染｜再喂养标志｜肝胆｜肠屏障｜骨

### 导管

- 置管非感染并发症：气胸最常见；空气栓塞最严重；
- 导管感染：立即拔管、抗菌治疗、导管尖端培养。

### 代谢

- 必需脂肪酸缺乏：伤口愈合延迟、皮肤干燥脱屑、脱发；
- 再喂养综合征：低磷为标志，伴低钾、低镁、维生素缺乏和心衰风险；
- 过量单一葡萄糖：高血糖、脂肪肝接口。

### 肝胆与肠道

长期缺乏肠内食物刺激 → CCK等肠激素↓、胆汁淤积；肠黏膜萎缩、通透性↑ → 细菌与内毒素移位；谷氨酰胺消耗和过量供能也可加重肝功能损害。

### 骨

代谢性骨病可有骨钙丢失、骨质疏松、关节痛甚至骨折，并出现血 / 尿钙与ALP变化的Study接口。
