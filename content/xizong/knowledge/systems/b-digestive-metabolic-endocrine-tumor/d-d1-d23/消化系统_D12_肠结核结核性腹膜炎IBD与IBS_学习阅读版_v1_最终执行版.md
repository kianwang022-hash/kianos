# 3｜结核支路：共同病理只 Recall，器官路径在此 Learn

## KP01｜结核共同病理如何落到肠道与腹膜

> **主提示：** 共同病理4词｜肠道链4段｜腹膜链3段

### 快速核对

结核共同病理基础：

```text
结核杆菌
→ 细胞免疫 / 变态反应
→ 上皮样细胞、Langhans巨细胞、干酪样坏死
→ 慢性纤维化、狭窄、空洞或播散
```

肠结核器官链：

```text
空洞性肺结核痰液被吞咽
→ 回盲部停留 / 淋巴组织丰富
→ 环形横行溃疡或增生
→ 瘢痕狭窄、肠梗阻
```

结核性腹膜炎入口：

```text
肠结核 / 肠系膜淋巴结结核 / 输卵管结核
→ 直接蔓延腹膜
→ 渗出、粘连或干酪坏死
```

## KP02｜肠结核识别：低热、右下腹和两种肠型

> **主提示：热型3｜痛部2｜排便3态｜溃疡型2｜增生型2｜并发症1**

### 快速核对

- 发热以低热为主，也可中热、高热；约 1/3 呈弛张热，少数稽留热；
- 腹痛多在右下腹或脐周；
- 可腹泻、便秘或二者交替；
- **溃疡型**：腹泻为主，多无脓血和里急后重；
- **增生型**：便秘、右下腹肿块更突出；
- 最常见重要出口：**肠梗阻**。

```text
慢性低热盗汗 + 右下/脐周痛
├─ 腹泻、多无脓血 → 溃疡型
└─ 便秘、包块       → 增生型
```

（易混：右下腹痛并不只属于肠结核；CD 也常在回肠末端/邻近结肠。）

<!-- kianos:kp id="digestive-d12-kp03" -->
## KP03｜肠结核位置与形态：为什么偏爱回盲部并形成环形溃疡

> **主提示：感染途径1｜来源1｜好发部位1｜环形原因2｜肉芽肿身份｜结局2**

### 快速核对

- 多经口感染，主要来自空洞性肺结核患者反复吞咽含菌痰液；
- 好发回盲部；
- 肠黏膜淋巴管呈环形走向，溃疡多为环形/横行，长轴与肠管长轴垂直；
- 病理身份：干酪性肉芽肿；
- 修复后胶原纤维增生、收缩，使肠腔狭窄并引起梗阻。

```text
回盲部暴露与淋巴组织
→ 结核性肉芽肿 / 干酪坏死
→ 环形横行溃疡
→ 纤维化收缩
→ 狭窄 / 梗阻
```

//串联：CD 是纵行裂隙状深溃疡 + 非干酪性肉芽肿。

<!-- kianos:kp id="digestive-d12-kp04" -->
## KP04｜肠结核检查：镜下确诊，钡剂只提供行为线索

> **主提示：肠结核：内镜确诊｜镜下证据4｜钡剂线索｜痰/粪证据边界｜试治何时用**

### 快速核对

**结肠镜是首选和金标准**：

- 回盲部；
- 环形/横行溃疡或肿块；
- 干酪性肉芽肿；
- 抗酸杆菌。

钡灌肠可见**跳跃征/激惹征**：钡剂刺激溃疡面裸露神经，病变肠段迅速收缩排空，病变上下肠段反而充盈良好。

```text
粪便 / 痰中找到TB
≠ 确诊肠结核
```

原因：肺结核患者可吞下含菌痰液。抗结核 2–6 周试验性治疗有反应可帮助诊断，但不是用来替代组织证据。

（易混：“病变跳跃性”属于 CD 分布；“钡灌肠跳跃征”属于肠结核行为征象。）

## KP05｜肠结核治疗：抗结核为主，四类失败转外科

> **主提示：关键1｜疗程口径｜手术4类｜完全/不完全边界**

### 快速核对

- 治疗关键：抗结核，多用短程疗法；
- 手术指征：
  1. 诊断困难需开腹探查；
  2. 急性肠穿孔；
  3. 完全性肠梗阻；
  4. 慢性穿孔瘘管、不完全性梗阻或大出血，经内科治疗无效。

```text
可控制的感染与炎症 → 抗结核
结构已失败 / 急腹症   → 外科
```

（边界：完整抗结核药物组合与耐药方案不在 D12 重写。）

# 4｜结核性腹膜炎：从来源、腹水到三种分型

<!-- kianos:kp id="digestive-d12-kp06" -->
## KP06｜结核性腹膜炎识别：慢性低热 + 弥漫隐痛 + 柔韧感

> **主提示：来源3｜热1｜痛3｜腹膜范围｜柔韧感边界｜生殖接口**

### 快速核对

常由腹腔内结核灶直接蔓延：

- 肠结核；
- 肠系膜淋巴结结核；
- 输卵管结核。

临床：慢性低热、盗汗；脐周、下腹或全腹持续性隐痛；可呈弥漫性腹膜炎；触诊可有揉面/柔韧感。

```text
结核对腹膜的慢性、较温和刺激
→ 渗出 + 纤维素 + 粘连
→ 腹部呈柔韧感
```

（易混：柔韧感并非特异，可见于癌性腹膜炎和血性腹水；必须结合结核背景、腹水和组织证据。）

---

<!-- kianos:kp id="digestive-d12-kp07" -->
## KP07｜腹水证据：先证明渗出，再找结核倾向

> **主提示：结核性腹水：渗出证据｜细胞谱｜SAAG/蛋白/比重/Rivalta｜ADA｜培养**

### 快速核对

当前内科 Lecture：

- 草黄色最多，其次淡血性、乳糜性；
- SAAG < 11；
- 细胞 > 500×10⁶/L；
- 多数比重 > 1.018；
- Rivalta 试验阳性；
- 蛋白 > 30 g/L；
- 单个核细胞/淋巴细胞为主；
- ADA > 45，尤其 ADA2 对本病有一定特异性；
- 腹水结核杆菌培养阳性率低，但可帮助排除普通细菌和肿瘤。

（特殊：结核患者若合并低蛋白血症，比重和蛋白值可能不典型；不能逮住单一指标排除。）

`SOURCE_CONFLICT / 待核对`：内科写“草黄色”，外科腹腔穿刺速识别表写“草绿色透明液”。当前分别保留其学科语境。

## KP08｜腹腔镜、X线与三型：证据和并发症各有入口

> **主提示：腹膜结核：腹腔镜证据/禁忌｜X线入口｜三型按腹水/粘连/干酪鉴别**

### 快速核对

- 腹腔镜：金标准；广泛腹膜粘连时禁用；
- 并发肠梗阻：X 线辅助；
- 治疗关键：抗结核，多用短程疗法。

| 分型 | 主身份 | 典型出口 |
|---|---|---|
| 渗出型 | 渗出、腹水 | 腹水最突出 |
| 粘连型 | 纤维粘连 | 肠梗阻 |
| 干酪型 | 干酪坏死、包块 | 毒血症、急腹症、穿孔、肠瘘；可需延长疗程 |

（易混：腹部肿块可来自大量纤维组织包裹，药物进入差；不是看见包块就直接判恶性肿瘤。）

# 5｜IBD 共同底座：不是感染，而是慢性复发性免疫炎症

<!-- kianos:kp id="digestive-d12-kp09" -->
## KP09｜IBD 共同机制与 Source 边界

> **主提示：IBD共同机制：因素4→共同终点｜病程｜是否感染｜抗生素边界｜CD/UC分流**

### 快速核对

```text
环境因素
+ 遗传易感
+ 肠道微生态
+ 免疫调节失衡
→ 黏膜屏障损伤
→ 慢性复发性炎症
```

- UC 与 CD 都与免疫有关；
- 常呈慢性复发过程；
- 不是由某一微生物直接造成的感染性肠炎；
- 广谱抗生素不能作为控制 IBD 主炎症的核心治疗；
- 但 CD 的腹腔/肛周脓肿等感染性并发症仍需抗感染和引流。

（边界：当前 Source 不支持在此扩写完整正常免疫学和所有生物制剂通路。）

# 6｜Crohn 病：节段性、全层、深溃疡和结构并发症

<!-- kianos:kp id="digestive-d12-kp10" -->
## KP10｜CD 识别：右下腹、进食后加重、瘘与肛周病变

> **主提示：痛部1｜进食关系｜包块｜肛周3｜分布2词｜最常并发1**

### 快速核对

- 腹痛多位于右下腹或脐周，进食后可加重；
- 可有腹部包块；
- 腹腔脓肿、肛周脓肿、瘘管和肛周病变偏向 CD；
- 病变节段、跳跃，可累及全消化道；
- 最常见并发症：肠梗阻。

```text
全层慢性炎症
→ 深溃疡 / 纤维化
→ 偏心性狭窄、梗阻
→ 穿透形成瘘与脓肿
```

（易混：CD 可有低热，但其核心不是“结核性低热”；需看纵行深溃疡、非干酪肉芽肿和节段分布。）

<!-- kianos:kp id="digestive-d12-kp11" -->
## KP11｜CD 镜下地图：纵行裂隙、鹅卵石和非干酪肉芽肿

> **主提示：CD内镜：好发部位｜分布｜溃疡演进｜鹅卵石｜肉芽肿｜狭窄**

### 快速核对

结肠镜是首选和金标准：

- 回肠末端及邻近结肠常见；
- 节段性、跳跃性；
- 早期鹅口疮样改变；
- 后期纵行裂隙状深溃疡；
- 鹅卵石/铺路石样；
- 非干酪性肉芽肿；
- 偏心性肠腔狭窄。

（易混：肠结核是环形横行溃疡 + 干酪肉芽肿；CD 是纵行深溃疡 + 非干酪肉芽肿。）

## KP12｜CD 检查与并发症：小肠、肛周和结构失败分别看什么

> **主提示：小肠检查4｜CTE/MRE场景2｜并发症5｜脓肿处理2｜癌变边界**

### 快速核对

若主要在小肠，可用：

- 小肠镜；
- 胶囊内镜；
- CTE；
- MRE。

CTE/MRE 还可用于肛周脓肿手术后的疾病评估。

并发症：

1. 肠梗阻（最常见）；
2. 腹腔或肛周脓肿；
3. 瘘管；
4. 癌变、出血；
5. 急性穿孔。

脓肿需充分引流，并按 Study 使用甲硝唑、喹诺酮类等抗感染接口。

# 7｜溃疡性结肠炎：连续黏膜炎症、脓血便与中毒性巨结肠

<!-- kianos:kp id="digestive-d12-kp13" -->
## KP13｜UC 识别：左下腹、黏液脓血和便后缓解

> **主提示：部位2｜分布2词｜主诉3｜疼痛链3步｜活动期2｜镜下3**

### 快速核对

- 好发直肠及乙状结肠；
- 病变连续、弥漫；
- 左下腹痛、黏液脓血便、里急后重；
- 常见链：腹痛 → 便意 → 便后缓解；
- 活动期重要表现：腹泻、黏液血便；
- 结肠镜为首选和金标准：连续分布的浅溃疡，可见隐窝脓肿、杯状细胞减少、中心性狭窄。

（易混：抗菌药无效 + 长期黏液脓血便 + 左下腹痛，更支持 UC 而非慢性细菌性痢疾。）

## KP14｜UC 严重度：五轴判断，不看外周白细胞作为分度项

> **主提示：便次｜血｜脉｜温｜Hb｜ESR｜非分度项1**

当前 Lecture 的轻/重边界：

| 指标 | 轻度 | 重度 |

## KP15｜中毒性巨结肠：重度 UC 从黏膜炎走向肠壁麻痹

> **主提示：本质1｜诱因4｜腹部3｜毒血2｜首选检查｜影像4｜最重肠段｜禁忌2**

### 快速核对

本质：**麻痹性肠梗阻**。

诱因：

- 钡灌肠；
- 低钾；
- 抗胆碱药；
- 阿片药。

表现：全腹膨隆、压痛，肠鸣音减弱；明显毒血症，高热、WBC 显著升高。

首选 X 线：

- 结肠扩张；
- 肠壁变薄；
- 结肠袋消失；
- 横结肠最严重。

```text
肠麻痹 → 内容物/气体淤积 → 肠壁扩张变薄
→ 屏障减弱 → 细菌/毒素移位 → 明显毒血症
```

（易混：铅管征代表慢性纤维化、肠壁硬和缩短；与急性中毒性巨结肠不共存。此时不做结肠镜或钡灌肠。）

## KP16｜UC vs CD：六轴一次恢复

> **主提示：部位｜分布｜痛-便/食｜溃疡深浅｜肉芽肿｜狭窄｜影像｜并发症**

### 快速核对

| 轴 | UC | CD |
|---|---|---|
| 好发部位 | 直肠、乙状结肠 | 回肠末端、邻近结肠；可全消化道 |
| 分布 | 连续、弥漫 | 节段、跳跃 |
| 腹痛 | 左下腹；便后缓解 | 右下腹；进食后可加重 |
| 大便 | 黏液脓血、里急后重 | 多无脓血；左侧/直肠受累可有 |
| 溃疡 | 浅 | 纵行裂隙状深溃疡 |
| 形态 | 隐窝脓肿、杯状细胞↓ | 鹅口疮、鹅卵石/铺路石 |
| 肉芽肿 | 非核心 | 非干酪性肉芽肿 |
| 狭窄 | 中心性；慢性铅管 | 偏心性；线样征 |
| 最常重要并发症 | 重度者中毒性巨结肠 | 肠梗阻 |
| 瘘/脓肿/肛周病变 | 少 | 多 |

## KP17｜并发症网络：出血、穿孔、梗阻、癌变不是同一机制

> **主提示：TB/CD/UC并发症｜各最常哪一类｜穿孔场景｜梗阻机制｜癌变｜瘘/脓肿**

### 快速核对

- 肠结核：最常梗阻；可穿孔、出血；
- 结核性腹膜炎：粘连型最常梗阻；干酪型可穿孔/瘘；
- CD：最常梗阻，瘘、脓肿突出；
- UC：重度暴发时易中毒性巨结肠和急性穿孔；慢性纤维化可形成铅管征和梗阻；可癌变；
- UC、CD 均可成为大肠癌风险接口。

```text
狭窄/粘连 → 梗阻
深穿透炎症 → 瘘/脓肿/穿孔
长期黏膜炎症 → 癌变风险
肠壁麻痹扩张 → 中毒性巨结肠/穿孔
```

## KP18｜5-ASA：轻中度 UC 的局部黏膜抗炎底座

> **主提示：适应2阶段｜局部剂型2部位｜原型1｜前体3｜依菌否｜抗生素能否合用｜小/大肠**

### 快速核对

- 适用于轻、中度 UC：活动期诱导 + 缓解期维持；
- 灌肠剂：直肠和乙状结肠；
- 栓剂：直肠。

| 药物 | 身份 | 是否依赖大肠细菌 | 可否与抗生素合用 | 小肠病变 |
|---|---|---|---|---|
| 美沙拉嗪 | 5-ASA 原型 | 否（依 pH/时间等释放） | 可 | 可 |
| 奥沙拉嗪 | 前体 | 是 | 不宜 | 不适合 |
| 巴柳氮 | 前体 | 是 | 不宜 | 不适合 |
| 柳氮磺吡啶 SASP | 传统前体 | 是 | 不宜 | 不适合 |

## KP19｜激素、免疫抑制与生物制剂：诱导快慢决定角色

> **主提示：IBD药物角色：激素｜免疫抑制剂｜生物制剂｜诱导 vs 维持｜无效后升级**

### 快速核对

**糖皮质激素**：

- 5-ASA 疗效不佳或重度 UC；
- 只用于活动期诱导，不用于长期维持；
- 症状控制后逐渐减量，不能突然停；
- 活动期口服泼尼松；重度可静注氢化可的松/甲泼尼龙；
- 无效可用英夫利昔单抗或环孢素补救。

**免疫抑制剂**：起效慢，主要维持；硫唑嘌呤、巯嘌呤，不耐受可用甲氨蝶呤。

**生物制剂/小分子**：可诱导也可维持。

- 英夫利昔单抗、阿达木单抗：抗 TNF；
- 维得利珠单抗：抗整合素，阻断淋巴细胞向肠道炎症部位迁移；
- 乌司奴单抗：抗 IL；
- 乌帕替尼：JAK 抑制剂。

## KP20｜CD 治疗：局部轻病、全身活动和瘘管三条线

> **主提示：活动期主药｜局部三部位药1｜瘘管激素边界｜内外科联合｜维持2路**

### 快速核对

- 活动期常用糖皮质激素诱导；
- 病变局限回肠末端、回盲部或升结肠的轻中度 CD，可用布地奈德；
- 肛瘘慎用激素，不利于瘘管闭合；
- 肛瘘应采用内科（如英夫利昔单抗）+ 外科治疗；
- 缓解期以免疫抑制剂维持；若活动期用生物制剂/小分子诱导，通常继续同种药物维持。

（易混：5-ASA 是 UC 底座；当前 Lecture 对 CD 疗效评价差，不把它当 CD 主线。）

## KP21｜IBD 肠外表现：与活动度无关还是随控制缓解

> **主提示：共存4｜可缓解7｜判断问法1**

### 快速核对

**与病情活动度无关 / 与疾病共存**：

- 原发性硬化性胆管炎；
- 强直性脊柱炎；
- 淀粉样变性；
- 骶髂关节炎。

**控制肠病后可缓解**：

- 杵状指；
- 结节性红斑；
- 坏疽性脓皮病；
- 口腔溃疡；
- 外周关节炎；
- 巩膜外层炎；
- 前葡萄膜炎/虹膜睫状体炎。

判断轴不是“有没有肠外表现”，而是：**肠道炎症缓解后它是否随之消退。**

# 9｜IBS：器质性结构未被证明损坏，但肠脑调控失配

<!-- kianos:kp id="digestive-d12-kp22" -->
## KP22｜IBS 识别与诊断：功能性、排便相关、绝无脓血

> **主提示：IBS：排便相关痛｜便型｜病程｜无报警征｜排除器质病**

### 快速核对

核心：**内脏高敏感性**。

共同参与：胃肠动力异常、肠道免疫激活、微生态失衡、精神心理因素 → 肠—脑互动异常。

识别：

- 青壮年，慢性病程；
- 腹痛部位不定，多下腹/左下腹；
- 极少在睡眠中痛醒；
- 可有黏液，但**绝无脓血**；
- 排便不净感，排便/排气后缓解；
- 多无明显体征，体重通常无明显下降。

诊断：

- 反复腹痛、腹胀/不适与排便相关；
- 伴大便性状和/或频率改变；
- 症状至少 6 个月，近 3 个月符合；
- 常规检查和结肠镜无可解释症状的器质性、系统性、代谢性疾病。

（边界：检查的任务是排除器质性病变，不是“用正常内镜直接证明某一分子机制”。）

---

<!-- kianos:kp id="digestive-d12-kp23" -->
## KP23｜IBS 分型与治疗：按主症状选工具

> **主提示：Bristol四型｜解痉4｜止泻4｜通便3｜感觉2｜菌群2｜短期边界**

### 快速核对

**分型**：

- 便秘型：>1/4 为 Bristol 1–2，<1/4 为 6–7；
- 腹泻型：>1/4 为 6–7，<1/4 为 1–2；
- 混合型：两端均 >1/4；
- 不定型。

**治疗分流**：

- 解痉：匹维溴铵、奥替溴铵、曲美布汀、阿尔维林；抗胆碱药短期；
- 止泻：洛哌丁胺、地芬诺酯；蒙脱石散、药用炭；
- 便秘：聚乙二醇；鸟苷酸环化酶激动剂；Cl⁻通道激动剂；
- 内脏感觉/难治症状：5-HT 再摄取抑制剂、三环类如阿米替林；
- 菌群/炎症接口：利福昔明短期；双歧杆菌、乳酸杆菌。

（MI-D：完整药物名单可卡片化；第一轮先会按“痛—泻—秘—感觉—菌群”五路选药。）
