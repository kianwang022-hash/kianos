## 2｜总 Framework

```text
A｜共同建材层
PPP → 磷酸核糖 → PRPP
+ Asp / Gln / CO2
+ 嘌呤额外调用Gly与一碳单位
→ 为核苷酸从头合成备料

B｜嘌呤线
PRPP
--PRPP酰胺转移酶→ PRA
→ 在核糖上逐步建嘌呤环
→ IMP
├─ 腺苷酸代琥珀酸 → AMP
└─ XMP → GMP
→ AMP/GMP分支交叉调节

补救：现成A / I / G + PRPP → AMP / IMP / GMP
分解：嘌呤 → 尿酸

C｜嘧啶线
Gln + CO2 + ATP
--CPS-II→ 氨基甲酰磷酸
+ Asp → 氨基甲酰天冬氨酸
→ 乳清酸（先造环）
+ PRPP → UMP → UDP → UTP → CTP

D｜脱氧与dTMP线
NDP --核糖核苷酸还原酶/NADPH→ dNDP
dUDP / dCMP → dUMP
dUMP + N5,N10-CH2-FH4
--胸苷酸合酶→ dTMP

E｜抗代谢物线
6-MP → 嘌呤合成
别嘌呤醇 → 黄嘌呤氧化酶
阿糖胞苷 → CDP还原 / dCDP
5-FU → 胸苷酸合酶
MTX → FH2还原酶 / FH4
氮杂丝氨酸 → Gln依赖反应
```

### 一句话恢复

> **PRPP是共同活化核糖；嘌呤在它上面造环得到IMP，嘧啶先造乳清酸再接它得到UMP；二磷酸核苷酸再被NADPH还原，dUMP靠FH₄生成dTMP，抗代谢物分别堵住这些门。**

## KP01｜共同原料与PRPP：碱基和核苷酸为什么差一个“活化核糖”

> **主提示：** 碱基共同3｜核苷酸再加1｜PRPP来源｜合成酶反馈2类｜作用2

当前Study：

- 嘌呤、嘧啶**碱基**共同从头原料：天冬氨酸、谷氨酰胺、CO₂；
- 嘌呤、嘧啶**核苷酸**共同从头原料：上述三者 + 磷酸核糖；
- 磷酸核糖来自PPP，并先活化为 **PRPP / 磷酸核糖焦磷酸**。

```text
磷酸核糖 --PRPP合成酶→ PRPP
```

PRPP合成酶同时服务嘌呤与嘧啶，并接受两类终产物负反馈，用于协调合成速度。

（易混：PRPP不等于嘌呤或嘧啶环本身；它提供活化核糖骨架和反应推动力。）

## KP02｜嘌呤与嘧啶建环：双环 / 单环，以及“先接糖还是先造环”

> **主提示：** 嘌呤 vs 嘧啶：环数｜共同原料｜先接糖还是先造环｜原子来源图边界

- 嘌呤碱基：A、G；由六元环 + 五元环融合；
- 嘧啶碱基：C、U / T；一个六元环。

从头合成最关键的结构差异：

```text
嘌呤：先有PRPP，在核糖上逐步搭建嘌呤环
嘧啶：先合成含嘧啶环的乳清酸，再与PRPP连接
```

原子来源图中：

- 嘧啶环由氨基甲酰磷酸与天冬氨酸构成；
- 嘌呤环还调用甘氨酸和一碳单位。

## KP03｜嘌呤从头合成：PRPP怎样先到IMP，再分成AMP与GMP

> **主提示：** PRPP→PRA｜关键酶｜首产物IMP｜AMP中间物｜GMP中间物｜交叉供能

```text
PRPP + Gln
--PRPP酰胺转移酶→ PRA
→ 逐步建立嘌呤环
→ IMP
```

IMP是首个嘌呤核苷酸，也是AMP / GMP共同前体。

### AMP支路

```text
IMP + Asp
→ 腺苷酸代琥珀酸
→ AMP + 延胡索酸
```

### GMP支路

```text
IMP → XMP
+ Gln → GMP
```

当前Study的交叉调节：

- AMP抑制AMP分支，GMP抑制GMP分支；
- GTP促进AMP合成；
- ATP促进GMP合成。

（易混：腺苷酸代琥珀酸既出现在嘌呤合成，也出现在M8肌肉嘌呤核苷酸循环；语境决定它是“造AMP”还是“脱氨循环中间物”。）

## KP04｜嘌呤补救合成：脑和骨髓为什么更重视“捡现成的”

> **主提示：** 部位2｜APRT｜HGPRT｜腺苷激酶｜底物→产物3｜缺陷1

当前Study把补救合成主要放在脑、骨髓胞浆：

```text
A + PRPP --APRT→ AMP
I / G + PRPP --HGPRT→ IMP / GMP
腺嘌呤核苷 --腺苷激酶→ AMP
```

价值：节省从头合成原料与能量，为对嘌呤需求较高的组织提供快速回收入口。

HGPRT缺失连接 **Lesch-Nyhan综合征 / 自毁容貌综合征**。

（易混：补救合成用现成碱基或核苷；从头合成用小分子原料逐步造环。）

## KP08｜嘧啶补救与分解：C先变U，T走向β-氨基异丁酸

> **主提示：** 补救2类底物｜转移酶/激酶｜C→U｜U终点｜T终点｜TK肿瘤接口

### 补救合成

- PRPP + U / T / 乳清酸，经相应磷酸核糖转移酶；
- 尿苷 / 胸苷经尿苷激酶、胸苷激酶等磷酸化。

## KP09｜核糖核苷酸还原：为什么只在二磷酸水平脱氧

```text

--核糖核苷酸还原酶 + NADPH→
```
