## 1｜Canonical Knowledge Hierarchy

### M9 母模型｜给快速增殖系统持续供应核苷酸，并能定位“供给链被卡在哪”

```text
G-6-P → PPP → ribose-5-P → PRPP
├─ 嘌呤：在 PRPP 上逐步造环 → IMP → AMP / GMP
│       ↔ 补救回收

└─ 嘧啶：先造环 → 乳清酸 → 接 PRPP → UMP → UTP / CTP

```

M9 的重点不是记药名，而是建立**核苷酸供给网络 + 阻断坐标系**。

### L1｜PRPP与嘌呤供给—补救—清除｜KP01–KP05

**Core relation**
```text
ribose-5-P → PRPP
→ de novo purine：PRA → … → IMP
   ├─ AMP
   └─ GMP
↔ salvage：APRT / HGPRT / adenosine kinase
→ degradation：hypoxanthine/xanthine --XO→ uric acid
```

**Boundary**
- “碱基共同原料”与“核苷酸共同原料”差一个 PRPP / ribose-phosphate 层；
- 嘌呤从头是在 PRPP 上逐步造环；嘧啶不是；
- 补救合成是“捡现成碱基/核苷”，不是从头路线的缩写版。

**Precision**
- 首个嘌呤核苷酸 IMP；
- HGPRT：I/G → IMP/GMP 补救；
- AMP/GMP 分支存在自反馈与交叉能量调节；
- XO 是尿酸生成关键入口。

**Connection**
- HGPRT / Lesch-Nyhan、痛风只保留机制接口；
- PRPP / ribose 来自 M3 PPP。

#### KP01｜共同原料与PRPP：碱基和核苷酸为什么差一个“活化核糖”

> **主提示：** 碱基共同3｜核苷酸再加1｜PRPP来源｜合成酶反馈2类｜作用2

当前Study：

- 嘌呤、嘧啶**碱基**共同从头原料：天冬氨酸、谷氨酰胺、CO₂；
- 嘌呤、嘧啶**核苷酸**共同从头原料：上述三者 + 磷酸核糖；
- 磷酸核糖来自PPP，并先活化为 **PRPP / 磷酸核糖焦磷酸**。

```text
磷酸核糖 --PRPP合成酶→ PRPP
```

PRPP合成酶同时服务嘌呤与嘧啶，并接受两类终产物负反馈，用于协调合成速度。

（易混：PRPP不等于嘌呤或嘧啶环本身；它提供活化核糖骨架和反应推动力。）

#### KP03｜嘌呤从头合成：PRPP怎样先到IMP，再分成AMP与GMP

> **主提示：** PRPP→PRA｜关键酶｜首产物IMP｜AMP中间物｜GMP中间物｜交叉供能

```text
PRPP + Gln
--PRPP酰胺转移酶→ PRA
→ 逐步建立嘌呤环
→ IMP
```

IMP是首个嘌呤核苷酸，也是AMP / GMP共同前体。

##### AMP支路

```text
IMP + Asp
→ 腺苷酸代琥珀酸
→ AMP + 延胡索酸
```

##### GMP支路

```text
IMP → XMP
+ Gln → GMP
```

当前Study的交叉调节：

- AMP抑制AMP分支，GMP抑制GMP分支；
- GTP促进AMP合成；
- ATP促进GMP合成。

（易混：腺苷酸代琥珀酸既出现在嘌呤合成，也出现在M8肌肉嘌呤核苷酸循环；语境决定它是“造AMP”还是“脱氨循环中间物”。）

#### KP04｜嘌呤补救合成：脑和骨髓为什么更重视“捡现成的”

### L2｜嘧啶供给、脱氧转换与dTMP一碳入口｜KP06–KP10

**Core relation**
```text
Gln + CO₂ + ATP --CPS-II→ carbamoyl phosphate
+ Asp → pyrimidine ring → orotate
+ PRPP → OMP → UMP → UTP → CTP

NDP --ribonucleotide reductase + NADPH→ dNDP
```

- 首个嘧啶核苷酸 UMP；
- 核糖核苷酸在**二磷酸水平**还原；
- current Source：UTP + Gln → CTP；
- dUMP 可由 dUDP/dCMP 等入口汇入。

**Connection**
- M8 提供 FH₄ / B12 / 一碳；
- G1–G3 后续消费 dNTP/NTP 作为 DNA/RNA 原料。
