## 2｜总 Framework

```text
Gly + succinyl-CoA + Fe²⁺
→ heme synthesis
→ heme proteins

heme breakdown
→ biliverdin → UCB
→ albumin transport
→ liver conjugation → CB
→ bile → intestine → urobilinogen / stercobilin / urinary products

parallel hepatic chemistry
→ Phase I: oxidation / reduction / hydrolysis
→ Phase II: conjugation
→ water solubility / excretion generally increase
```

M10 的核心不是背黄疸表格，而是定位**故障发生在生成、肝处理还是排出**；生物转化则是同一肝脏“改变分子以利排出”的第二套化学工具。

### 一句话恢复

> **血红素合成 → UCB生成/白蛋白运输 → 肝结合CB → 肠道排出 → 三类黄疸定位 → Ⅰ相/Ⅱ相生物转化**

## KP06｜UCB运输与肝结合：为什么必须靠白蛋白，怎样变成CB

> **主提示：** UCB为什么要白蛋白｜肝摄取/胞内载体｜结合酶/供体｜CB怎么形成

### 血中运输

UCB脂溶，不直接溶于血浆，需要与白蛋白结合运输。当前Study：1分子白蛋白可结合2分子UCB。

## KP07｜肠道胆素原与肠肝循环：粪色和尿色从哪里来

> **主提示：** CB入肠→胆素原｜3去路｜粪色来源｜尿中哪部分｜肠肝循环

```text
CB随胆汁入肠
→ 肠道细菌作用
→ 胆素原
```

胆素原三条去路：

1. 大部分留在肠道，遇氧形成胆素 / 粪胆素，使粪便着色；
2. 少量重吸收进入肠肝循环，多数再由肝处理并排入胆道；

## KP08｜UCB vs CB：脂溶 / 水溶决定能否进入尿液

> **主提示：** UCB vs CB：结合状态｜溶解性｜血中运输｜能否入尿｜凡登白/CB-TB

| 比较轴 | UCB | CB |
|---|---|---|
| 结合 | 未与葡糖醛酸结合 | 已结合葡糖醛酸 |

## KP09｜三类黄疸：按“生成—肝处理—胆道排出”定位

> **主提示：** 黄疸3类按哪一环定位｜主升胆红素｜尿胆红素｜尿胆原｜粪色

### 1｜溶血性黄疸

```text
RBC破坏↑ → UCB生成过多
→ 肝处理有上限
→ 血UCB为主
```

当前Study方向：

- CB/TB < 0.2；
- 尿胆红素阴性；
- 肠道胆素原、粪胆素和尿胆素增加；
- 粪色、尿色可加深。

### 2｜梗阻性黄疸

```text
UCB在肝内结合正常
→ CB不能顺利排入肠道
→ CB反流入血并入尿
```

当前Study方向：

- CB/TB > 0.5；
- 尿胆红素阳性，尿色深；
- 肠道胆素原减少；
- 粪色浅，严重时白陶土样。

### 3｜肝细胞性黄疸

```text
肝细胞摄取 / 结合 / 排泄多层受损
→ UCB与CB均可升高
```

当前Study方向：

- CB/TB 0.2–0.5；
- 尿胆红素可阳性；
- 尿胆素原可下降、正常或轻度升高；
- 粪色与尿色方向需结合肝处理和胆道排泄程度判断。

## KP10｜生物转化的任务：让非营养物质“更好排”，但不保证一定解毒

> **主提示：** 生物转化对象｜核心任务｜水溶性/活性方向｜为什么不等于“解毒”

对象：

- 药物、毒物等外源化合物；
- 激素等内源非营养物；
- 胆红素、氨等需要肝处理的内源物接口。

当前Study三个核心结果：

1. 多数非营养物活性降低或激素被灭活；
2. 多数情况下水溶性增加，利于胆汁 / 尿液排泄；
3. 既可解毒，也可能把原物转为活性更强或毒性更大的产物。

因此：

> **生物转化 ≠ 一定解毒；“转化后怎样”取决于具体产物。**

### 血红素合成与含铁卟啉入口

**Core relation**
```text
Gly + succinyl-CoA
--ALA synthase + PLP/B6→ ALA
→ 中间段胞浆
→ 回线粒体 + Fe²⁺
→ heme
→ Hb / myoglobin / cytochromes / peroxidases...
```

**Boundary**
- 成熟 RBC 无线粒体，不能合成血红素；
- ALA synthase 属于合成限速入口；heme oxygenase 属于分解入口；
- 含铁卟啉蛋白能贡献胆红素，但完整各蛋白生理不在 M10。

**Precision**
- 合成空间：线粒体 → 胞浆 → 线粒体；
- ALA synthase 需 PLP/B6，受 heme 反馈并可被 androgen 诱导；
- current Source 的 lead-inhibited enzyme list 按 P077 保留。

**Connection**
- M2 提供 succinyl-CoA / mitochondria；
- M8 提供 Gly / PLP；
- 血液系统调用 heme synthesis / hemolysis interface。

### UCB→CB→肠道与三类黄疸

**Core relation**
```text
heme
→ biliverdin
→ UCB (lipid-soluble)
→ albumin-bound blood transport
→ liver uptake + glucuronidation
→ CB (water-soluble)
→ bile → intestine
→ urobilinogen
   ├─ fecal stercobilin
   ├─ partial enterohepatic return
   └─ small renal urinary route
```

**Boundary**
- UCB 脂溶、白蛋白结合、不能直接进尿；
- CB 水溶，可反流入血并出现在尿中；
- 尿胆红素 = 尿 CB，不等于尿胆素原 / 尿胆素。

**Precision**
- 溶血性：生成负荷↑ → UCB 主导；
- 梗阻性：胆道排出受阻 → CB 主导、尿色深、粪色浅；
- 肝细胞性：摄取/结合/排出多环节混合受损；
- current Study 的 CB/TB 比例按 P075 Source 口径保留。

**Connection**
- 溶血完整证据归血液；
- 肝细胞损伤归 D16/D17；
- 胆道梗阻归 D19。

### Ⅰ相/Ⅱ相生物转化

**Core relation**
```text
non-nutrient / drug / hormone
→ Phase I：oxidation / reduction / hydrolysis
   → introduce or expose functional groups
→ Phase II：conjugation
   → glucuronide / sulfate / acetyl / glycine etc.
→ usually water solubility↑ and excretion easier
```

**Boundary**
- 生物转化不等于“一定解毒”；也可能生成更活跃/更有毒中间物；
- CYP / monooxygenase 与呼吸链 cytochrome c oxidase 不是同一系统；
- 完整 CYP 亚型、诱导/抑制药物表归药理 owner。

**Precision**
- current 27 新增 2025N146：Ⅰ相 = 氧化、还原、水解；结合属于Ⅱ相；
- P450 / monooxygenase 是Ⅰ相关键接口；
- Ⅱ相 current Source 常见结合基团：glucuronate、sulfate、acetyl、glycine。

**Connection**
- UCB→CB 本身就是肝内结合增溶的经典接口；
- PAPS 来自 M8 含硫代谢；
- 肝对激素/药物/毒物的完整临床后果交回相应系统。
