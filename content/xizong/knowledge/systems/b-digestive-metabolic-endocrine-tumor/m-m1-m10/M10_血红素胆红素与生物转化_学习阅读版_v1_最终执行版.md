# M10｜血红素、胆红素与生物转化
## 从铁卟啉合成与分解，到UCB—CB—胆素原和肝内两相转化

## 2｜总 Framework

```text
A｜血红素合成线
甘氨酸 + 琥珀酰CoA
--ALA合酶/B6→ 卟啉前体
→ 中间阶段在胞浆
→ 回线粒体 + Fe2+
→ 血红素
+ 珠蛋白 → Hb

B｜胆红素生成线
衰老RBC / 含铁卟啉蛋白
→ 血红素
--血红素加氧酶→ 胆绿素
--NADPH相关还原→ UCB
→ 白蛋白运输至肝

C｜肝处理与排泄线
UCB → 肝摄取 / Y-Z蛋白转运
→ 内质网UGT + UDP-葡糖醛酸
→ CB
→ 胆汁 → 肠道
→ 胆素原
├─ 氧化为粪胆素
├─ 少量肠肝循环
└─ 少量经肾 → 尿胆素

D｜黄疸定位线
生成过多 → 溶血性 / UCB
肝摄取结合排泄失败 → 肝细胞性 / 混合
胆道排出受阻 → 梗阻性 / CB

E｜生物转化线
非营养物质 / 激素 / 药物
→ Ⅰ相：氧化、还原、水解
→ Ⅱ相：葡糖醛酸、硫酸、乙酰、甘氨酰等结合
→ 活性与水溶性改变
→ 胆汁 / 尿液排泄
```

### 一句话恢复

> **血红素在“线粒体—胞浆—线粒体”中合成，分解后变成脂溶性UCB，由白蛋白送肝，结合葡糖醛酸成为水溶性CB，再经胆汁—肠道排出；黄疸按生成、肝处理和胆道排出三层定位，生物转化则用Ⅰ相加功能团、Ⅱ相做结合。**

## KP06｜UCB运输与肝结合：为什么必须靠白蛋白，怎样变成CB

> **主提示：** UCB为什么要白蛋白｜肝摄取/胞内载体｜结合酶/供体｜CB怎么形成

### 血中运输

UCB脂溶，不直接溶于血浆，需要与白蛋白结合运输。当前Study：1分子白蛋白可结合2分子UCB。

### 肝内处理

```text

→ UCB进入肝细胞
→ Y / Z蛋白送至内质网
→ UGT + UDP-葡糖醛酸
→ CB
```

CB＝结合胆红素＝直接胆红素，水溶性增加，可进入胆汁。

## KP07｜肠道胆素原与肠肝循环：粪色和尿色从哪里来

> **主提示：** CB入肠→胆素原｜3去路｜粪色来源｜尿中哪部分｜肠肝循环

```text
CB随胆汁入肠
→ 肠道细菌作用
→ 胆素原
```

胆素原三条去路：

1. 大部分留在肠道，遇氧形成胆素 / 粪胆素，使粪便着色；
2. 少量重吸收进入肠肝循环，多数再由肝处理并排入胆道；

## KP08｜UCB vs CB：脂溶 / 水溶决定能否进入尿液

> **主提示：** UCB vs CB：结合状态｜溶解性｜血中运输｜能否入尿｜凡登白/CB-TB

| 比较轴 | UCB | CB |
|---|---|---|
| 结合 | 未与葡糖醛酸结合 | 已结合葡糖醛酸 |
| 溶解性 | 脂溶性 | 水溶性 |
| 血中运输 | 依赖白蛋白 | 可溶于水相 |
| 尿中 | 不能形成尿胆红素阳性 | 反流入血后可经尿排出 |
| 凡登白 | 间接反应 | 直接反应 |

肝细胞性黄疸同时有UCB与CB，表现为双相反应。

（易混：**尿胆红素＝尿CB**；尿胆素原 / 尿胆素是肠道胆素原支路产物，不是同一个检测对象。）

## KP09｜三类黄疸：按“生成—肝处理—胆道排出”定位

> **主提示：** 黄疸3类按哪一环定位｜主升胆红素｜尿胆红素｜尿胆原｜粪色

### 1｜溶血性黄疸

```text
RBC破坏↑ → UCB生成过多
→ 肝处理有上限
→ 血UCB为主
```

当前Study方向：

- CB/TB < 0.2；
- 尿胆红素阴性；
- 肠道胆素原、粪胆素和尿胆素增加；
- 粪色、尿色可加深。

### 2｜梗阻性黄疸

```text
UCB在肝内结合正常
→ CB不能顺利排入肠道
→ CB反流入血并入尿
```

当前Study方向：

- CB/TB > 0.5；
- 尿胆红素阳性，尿色深；
- 肠道胆素原减少；
- 粪色浅，严重时白陶土样。

### 3｜肝细胞性黄疸

```text
肝细胞摄取 / 结合 / 排泄多层受损
→ UCB与CB均可升高
```

当前Study方向：

- CB/TB 0.2–0.5；
- 尿胆红素可阳性；
- 尿胆素原可下降、正常或轻度升高；
- 粪色与尿色方向需结合肝处理和胆道排泄程度判断。

## KP10｜生物转化的任务：让非营养物质“更好排”，但不保证一定解毒

> **主提示：** 生物转化对象｜核心任务｜水溶性/活性方向｜为什么不等于“解毒”

对象：

- 药物、毒物等外源化合物；
- 激素等内源非营养物；
- 胆红素、氨等需要肝处理的内源物接口。

当前Study三个核心结果：

1. 多数非营养物活性降低或激素被灭活；
2. 多数情况下水溶性增加，利于胆汁 / 尿液排泄；
3. 既可解毒，也可能把原物转为活性更强或毒性更大的产物。

因此：

> **生物转化 ≠ 一定解毒；“转化后怎样”取决于具体产物。**

## KP13｜三类肝化学实例与酶诱导：同一器官怎样处理胆红素、氨和药物

> **主提示：** 肝处理3条化学链：胆红素｜氨｜药物/激素；酶诱导后结果为何可双向

当前Study用三类实例收口肝脏化学枢纽：

```text
UCB + UDP-葡糖醛酸 → CB
NH3 → 尿素
VitD3 → 25(OH)VitD3
```

共同结果：把难以排泄或需要调控的物质转成更适合运输、利用或排出的形式。

肝药酶诱导接口：苯巴比妥等可诱导相关酶，使底物代谢加快；当前不扩写完整药物相互作用。

激素也可在肝内被灭活。

（边界：酶诱导后“活性下降还是毒性增加”必须看具体底物和产物，不能只凭“代谢变快”机械判断。）
