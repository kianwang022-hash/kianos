# M6｜胆固醇、磷脂与胆汁酸
## 从胞浆合成脂质，到膜结构、胆汁循环与激素前体的共同分流

## 2｜总 Framework

```text
A｜胆固醇输入与储存
血浆游离胆固醇 --LCAT→ 胆固醇酯
细胞游离胆固醇 --ACAT→ 胆固醇酯

B｜胞浆合成线
线粒体乙酰CoA
→ 与草酰乙酸形成柠檬酸
→ 柠檬酸出线粒体
→ 胞浆裂解再生乙酰CoA
→ 乙酰乙酰CoA
→ HMG-CoA
--HMG-CoA还原酶→ 甲羟戊酸
→ 鲨烯
→ 胆固醇

C｜胆固醇去路
胆固醇
├─ 更新生物膜 / 酯化储存
├─ --7α羟化酶→ 初级胆汁酸 → 次级 / 结合型 → 肠肝循环
├─ 皮肤7-脱氢胆固醇 → VitD3 → 肝25-OH → 肾1,25-(OH)₂
└─ 肾上腺皮质 / 性腺 → 类固醇激素

D｜甘油磷脂生成线
葡萄糖 → DHAP → 3-磷酸甘油
+ 2脂酰CoA
→ 磷脂酸
├─ DAG + CDP-胆碱/乙醇胺 → 卵磷脂 / 脑磷脂
└─ CDP-DAG → PI / PS / 心磷脂

E｜甘油磷脂切割线
PLA1切1位脂肪酸
PLA2切2位脂肪酸
PLC切磷酸—甘油之间 → DAG
PLD切X基团一侧
```

### 一句话恢复

> **胆固醇由胞浆乙酰CoA合成，经酯化、胆汁酸、VitD和类固醇分流；磷脂由共同甘油骨架合成，再由不同磷脂酶切出不同信号或脂肪酸接口。**

## KP01｜LCAT vs ACAT：同是胆固醇酯化，空间和脂酰基来源不同

> **主提示：** 血浆/细胞｜谁合成｜脂酰基2｜apo接口｜共同结果

| 轴 | LCAT | ACAT |
|---|---|---|
| 全名角色 | 卵磷脂胆固醇脂酰基转移酶 | 脂酰CoA胆固醇脂酰基转移酶 |
| 合成来源 | 肝合成后进入血浆 | 相应组织细胞合成 |
| 作用空间 | 血浆 | 细胞内 |
| 脂酰基来源 | 卵磷脂 | 脂酰CoA |
| 结果 | 游离胆固醇→胆固醇酯 | 游离胆固醇→胆固醇酯 |

- 两者都在胆固醇第3号碳的羟基处形成酯；
- LCAT由 M5 已学的 apoAⅠ激活，服务 HDL逆向转运；
- ACAT把细胞内胆固醇转为更适合储存的胆固醇酯。

（易混：LCAT不是脂蛋白脂肪酶 LPL；ACAT也不是乙酰CoA羧化酶 ACC。）

## KP02｜乙酰CoA怎样出线粒体：柠檬酸—丙酮酸循环

> **主提示：** 为什么不能直出｜5步｜输出2物｜NADPH｜能量充足接口

```text
线粒体乙酰CoA + 草酰乙酸
→ 柠檬酸
→ 柠檬酸转运到胞浆
--柠檬酸裂解酶→ 胞浆乙酰CoA + 草酰乙酸
→ 草酰乙酸 → 苹果酸 → 丙酮酸
→ 丙酮酸回线粒体
```

该循环完成两件事：

1. 把“不能自由穿膜”的乙酰CoA碳源以柠檬酸形式送到胞浆；
2. 苹果酸酶反应可形成 NADPH，为胆固醇 / 脂肪酸合成提供还原力。

M7会再次调用此链用于脂肪酸合成，但不再完整初见。

## KP03｜胆固醇合成主链：从乙酰CoA到甲羟戊酸、鲨烯和胆固醇

> **主提示：** 部位2｜原料3｜中间物4｜关键酶｜药物｜不能直穿

### 部位与原料

- 主要组织：肝、小肠；
- 亚细胞：胞浆、滑面内质网；
- 原料：乙酰CoA、NADPH、ATP等。

乙酰CoA由线粒体侧以柠檬酸形式输出后在胞浆再生；NADPH可由磷酸戊糖途径及柠檬酸—丙酮酸循环提供。三酶链为乙酰乙酰CoA硫解酶 → HMG-CoA合酶 → HMG-CoA还原酶。

### 主链

```text

→ 乙酰乙酰CoA
→ HMG-CoA
--HMG-CoA还原酶→ 甲羟戊酸
→ 鲨烯
```

- HMG-CoA还原酶是当前 Study 的关键 / 限速酶；

## KP04｜HMG-CoA还原酶调节：底物充足、进食与激素怎样改变合成

## KP06｜胆汁酸两套分类：初级/次级与游离/结合不能混成一条轴

> **主提示：** 生成地2｜初级2｜次级2｜结合2对象｜胆盐定义｜关键酶

### 按生成位置

- **初级胆汁酸**：肝内生成，当前 Study列胆酸、鹅脱氧胆酸；
- **次级胆汁酸**：经肠道细菌作用形成，当前 Study列脱氧胆酸、石胆酸。

### 按是否结合

- 游离型：单纯胆汁酸；
- 结合型：与甘氨酸或牛磺酸结合；其盐即胆盐语言。

### 关键反应

```text
胆固醇
--胆固醇7α羟化酶→ 胆汁酸
```

（易混：“初级/次级”回答生成来源；“游离/结合”回答是否与氨基酸结合。结合型初级胆汁酸并不因此变成次级胆汁酸。）

## KP07｜肠肝循环：有限胆汁酸池怎样反复使用并反馈合成

> **主提示：** 肝→肠→回肠→门静脉→肝｜结合型｜节省｜反馈2｜丢失后果

```text
肝生成并分泌胆汁酸 / 胆盐
→ 进入肠道参与脂肪处理
→ 主要在回肠重吸收
→ 门静脉回肝
→ 再以结合型排入胆汁
```

意义：

- 使有限胆汁酸反复利用；
- 维持胆盐池和脂类消化吸收；
- 回流胆汁酸对自身新合成形成反馈。

胆汁酸肠肝循环减少、消化道丢失增多、肝合成能力下降，或胆汁中胆固醇排出过多，均可按当前 Embedded Question成为胆固醇沉淀 / 结石接口。

（边界：完整胆石风险轴、影像与手术归D19。）

## KP09｜甘油磷脂基本结构：一套骨架怎样兼容不同头基

> **主提示：** 甘油骨架｜1/2位脂肪酸｜3位磷酸-X｜头/尾｜X决定什么

```text
甘油骨架
+ 1位脂肪酸
```

## KP10｜甘油磷脂合成：共同起点后分为DAG与CDP-DAG两条路

> **主提示：** 糖→DHAP→G3P｜加2脂酰CoA｜磷脂酸｜两路各2/3产物｜甲基化

### 共同起点

```text
葡萄糖
→ 磷酸二羟丙酮 DHAP
→ 3-磷酸甘油
+ 2脂酰CoA
→ 磷脂酸
```

### 路线A｜甘油二酯途径

```text
磷脂酸 → DAG
DAG + CDP-胆碱 → 卵磷脂
DAG + CDP-乙醇胺 → 脑磷脂 / 磷脂酰乙醇胺接口
```

当前 Study还把乙醇胺→胆碱→卵磷脂的 SAM甲基化路径作为特殊考点。

<!-- approved-27-audit: B2-M6-04 -->
特殊转化链可压缩为：丝氨酸 → 乙醇胺 → 磷酸乙醇胺 → CDP-乙醇胺 → 脑磷脂；乙醇胺经 SAM 甲基化可转为胆碱，再进入卵磷脂接口。

### 路线B｜CDP-甘油二酯途径

形成当前 Study列出的：

- 磷脂酰肌醇；
- 磷脂酰丝氨酸；
- 心磷脂。

## KP11｜四类磷脂酶：切割位置决定产物与信号接口

> **主提示：** PLA1/PLA2/PLC/PLD｜各切哪里｜主要产物｜DAG/脂肪酸信号接口

| 酶 | 当前 Study 切割位置 / 结果 |
|---|---|
| PLA1 | 水解1位脂肪酸酯键 |
| PLA2 | 水解2位脂肪酸酯键 |

## 3｜Framework Reconstruction｜三条流闭卷重建

```text
胆固醇合成流：线粒体乙酰CoA → 柠檬酸出线粒体 → HMG-CoA还原酶 → 胆固醇
胆固醇分流：酯化 / 膜 / 胆汁酸 / VitD / 类固醇
磷脂流：DHAP → G3P → 磷脂酸 → DAG路 / CDP-DAG路 → 四类磷脂酶
```

