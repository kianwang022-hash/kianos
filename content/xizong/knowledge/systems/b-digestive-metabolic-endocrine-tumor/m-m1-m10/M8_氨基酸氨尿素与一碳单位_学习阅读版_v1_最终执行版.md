## KP01｜氨基酸分类：同一个分子可以同时属于多条分类轴

> **主提示：** 酸2/碱3｜支链3/芳香3｜必需9｜纯生酮2｜条件3

### 1｜按侧链酸碱性

- 酸性：天冬氨酸、谷氨酸；
- 碱性：赖氨酸、精氨酸、组氨酸。

（特殊：赖氨酸有两个氨基，但不能反推“所有碱性氨基酸都有两个氨基”。）

### 2｜按结构 / 代谢人设

- 支链氨基酸：缬氨酸、异亮氨酸、亮氨酸；
- 芳香族氨基酸：苯丙氨酸、酪氨酸、色氨酸；
- 含硫接口：甲硫氨酸、半胱氨酸、同型半胱氨酸、胱氨酸。

### 3｜按营养必需性

当前Study的营养必需氨基酸：

```text
组氨酸、异亮氨酸、亮氨酸、赖氨酸、甲硫氨酸、
苯丙氨酸、苏氨酸、色氨酸、缬氨酸
```

条件性接口：

- 苯丙氨酸可生成酪氨酸；
- 甲硫氨酸可支持半胱氨酸形成；
- 精氨酸在特定生长状态下进入条件性必需语言。

### 4｜按碳骨架去路

- 当前Study最重要的纯生酮边界：**亮氨酸、赖氨酸不作糖异生原料**；
- 其余氨基酸至少可接入生糖方向，部分兼有生酮接口。

<!-- approved-27-audit: B3-M8-01 -->
低频名单下沉 Detail：非极性氨基酸与生糖兼生酮氨基酸的具体顺序仍以原图核验为准；当前只保留“纯生酮2 vs 其余可入生糖、其中部分兼生酮”的稳定比较轴。

（易混：支链氨基酸不是“都纯生酮”；芳香族氨基酸也不是“都只在同一路代谢”。）

## KP02｜等电点：溶液pH决定氨基酸净电荷方向

> **主提示：** pH相对pI三种情况｜净电荷方向｜酸性/碱性AA分类

氨基酸同时有酸性羧基和碱性氨基，可发生两性解离。

| 条件 | 当前Study净电荷 |
|---|---|
| pH < pI | H⁺多，整体偏正电 |
| pH = pI | 兼性离子，净电荷为0 |
| pH > pI | 解离增加，整体偏负电 |

- 天冬氨酸、谷氨酸pI较低，生理pH下偏负电；
- 精氨酸、赖氨酸、组氨酸pI较高，生理pH下偏正电。

（易混：等电点是“净电荷为0时的溶液pH”，不是氨基酸自身固定电荷，也不是“完全不带任何局部电荷”。）

## KP03｜编码、非蛋白与翻译后修饰氨基酸：有没有密码子、是否进入蛋白质

> **主提示：** 编码20+1｜非蛋白4｜修饰3｜是否入蛋白判据｜密码子边界

### 编码氨基酸

- 当前Study表述为20+1种；
- 有对应密码子，可在翻译时直接进入多肽链。

### 无密码子、也不作为天然蛋白质组成单元

- 鸟氨酸；
- 瓜氨酸；
- 精氨酸代琥珀酸；
- 同型半胱氨酸。

前三者是尿素循环中间物；同型半胱氨酸属于甲硫氨酸循环接口。

### 无独立密码子，但可存在于蛋白质

- 胱氨酸：由两个半胱氨酸氧化形成二硫键；
- 羟脯氨酸：由脯氨酸翻译后修饰；
- 羟赖氨酸：由赖氨酸翻译后修饰。

判断顺序：

```text
有没有密码子？
→ 没有时，再问是否由编码氨基酸翻译后修饰而来
→ 是：可存在于蛋白质
→ 否：多为代谢中间物
```

## KP04｜含硫氨基酸、二硫键与PAPS：硫怎样进入结构和结合反应

> **主提示：** 含硫4｜二硫键｜PAPS身份｜生物转化接口｜同型半胱氨酸

- 半胱氨酸的巯基可参与GSH与蛋白质二硫键；
- 两个半胱氨酸氧化形成胱氨酸；
- 甲硫氨酸进入SAM循环；
- 同型半胱氨酸位于甲硫氨酸再生接口。

当前Study把硫酸根的活化形式记为 **PAPS（3'-磷酸腺苷-5'-磷酸硫酸）**，用于后续生物转化结合反应。

```text
含硫氨基酸代谢
→ 硫酸根
→ PAPS活化
→ 作为硫酸结合供体参与排泄性转化
```

（易混：PAPS是活化硫酸供体；SAM是活性甲基供体；两者都含腺苷结构，但任务不同。）

## KP05｜SAM循环：甲硫氨酸怎样提供活性甲基

> **主提示：** 活性甲基｜4产物｜同型半胱氨酸｜B12/FH4接口｜（易混：SAM vs 一碳）

甲硫氨酸经活化形成 **S-腺苷甲硫氨酸（SAM）**。本Block只需抓住其角色：

> **SAM把活性甲基转给受体，转甲基后进入同型半胱氨酸接口。**

当前Study四个高频甲基化产物：

- 肉碱；
- 肾上腺素；
- 肌酸；
- 胆碱。

代表链：

```text
去甲肾上腺素 + SAM甲基 → 肾上腺素
乙醇胺 + SAM甲基 → 胆碱
```

（易混：SAM直接提供“活性甲基”；FH₄承载不同形式的一碳单位。二者相连，但不能互相替代。）

## KP06｜苯丙氨酸—酪氨酸：一个入口分成递质、色素和分解三支

> **主提示：** 苯丙→酪｜3分支｜关键酶4｜疾病4｜终产物2

### 共同入口

```text
苯丙氨酸 --苯丙氨酸羟化酶→ 酪氨酸
```

该入口异常与苯丙酮尿症接口相连；完整遗传病模型后置。

### 三条分支

1. **儿茶酚胺支路**

```text
酪氨酸 → 多巴胺 → 去甲肾上腺素 → 肾上腺素
```

Study强调酪氨酸羟化酶为该支路关键入口，帕金森病只作机制接口。

2. **黑色素支路**

```text
酪氨酸 --酪氨酸酶→ 黑色素
```

酪氨酸酶缺乏连接白化病。

3. **分解支路**

```text
酪氨酸 → 尿黑酸 → 延胡索酸 + 乙酰乙酸
```

尿黑酸氧化酶缺陷连接尿黑酸尿症；延胡索酸接TCA / 生糖，乙酰乙酸接生酮。

//串联：甲状腺激素也以酪氨酸残基为结构来源，但完整合成和调节后置D21。

## KP08｜氨基酸总分流：脱氨后“碳骨架”和“氮”分别去哪

> **主提示：** 脱氨后2产物｜α-酮酸3路｜NH₃三路｜碳/氮分流

氨基酸代谢首先拆成两类对象：

```text
氨基酸 --脱氨基→ α-酮酸 + NH3
```

### α-酮酸三条独立去路

- 回合成非必需氨基酸；
- 接入糖或脂质方向；
- 进入TCA，氧化为CO₂、H₂O并形成ATP。

### NH₃三条独立去路

- 合成尿素：主要去路；
- 合成谷氨酸、谷氨酰胺等；
- 合成其他含氮化合物。

## KP09｜转氨基：只是搬氨基，为什么ALT / AST又能成为损伤指标

> **主提示：** 转氨基做什么/不做什么｜Glu枢纽｜ALT/AST反应与器官｜辅酶

转氨反应本质：

```text
氨基酸1 + α-酮酸1
⇌ α-酮酸2 + 氨基酸2
```

它把氨基在氨基酸之间转移，**不直接释放NH₃**。谷氨酸承担氨基汇聚枢纽。

<!-- approved-27-audit: B3-M8-02 -->
Glu 是当前 Study 的代谢最活跃氨基酸，也是氨基汇聚/再分配枢纽；该提示不等同于“转氨基直接产生 NH₃”。

### ALT

```text
谷氨酸 + 丙酮酸
⇌ α-酮戊二酸 + 丙氨酸
```

- ALT＝谷丙转氨酶＝丙氨酸氨基转移酶；
- 肝细胞含量高，肝损伤时可升高。

### AST

```text
谷氨酸 + 草酰乙酸
⇌ α-酮戊二酸 + 天冬氨酸
```

- AST＝谷草转氨酶＝天冬氨酸氨基转移酶；
- 心肌、肝等损伤时可升高；当前Study同时提示其已不作为特异性心肌标志物。

两类转氨酶均调用PLP / VitB6。

## KP10｜联合脱氨：肝肾脑与心肌骨骼肌为什么走两套组合

> **主提示：** 肝肾脑 vs 心骨肌｜联合脱氨两套组合｜关键酶｜辅因子｜嘌呤核苷酸循环接口

### 肝、肾、脑

```text
其他氨基酸 --转氨→ 谷氨酸
谷氨酸 --L-谷氨酸脱氢酶→ α-酮戊二酸 + NH3
```

- 属于氧化脱氨；
- L-谷氨酸脱氢酶既可用NAD，也可用NADP；
- 谷氨酸成为多数氨基酸把氮汇总后真正释放的枢纽。

### 心肌、骨骼肌

```text
转氨基
+ 嘌呤核苷酸循环
→ 释放NH3
```

主要环节：

```text
天冬氨酸 + IMP
→ 腺苷酸代琥珀酸
→ AMP + 延胡索酸
→ IMP + NH3
```

ADA / 腺苷酸脱氨酶参与末段。当前Study还保留：ADA在淋巴细胞活性高，胸水ADA升高与结核 / 脓胸识别、ADA缺乏与联合免疫缺陷接口；完整免疫和胸膜疾病后置。

## KP12｜丙氨酸—葡萄糖循环：肌肉怎样把氮送肝、把碳再拿回来

> **主提示：** 肌→肝4步｜氮去向｜碳去向｜葡萄糖回流｜功能2

### 肌肉端

```text
氨基酸氮汇入谷氨酸
+ 丙酮酸
--ALT→ 丙氨酸
→ 入血送肝
```

### 肝端


## KP14｜尿素循环五步：前两步在线粒体，后面在胞浆

> **主提示：** 线粒体2｜胞浆3｜5中间物｜5酶｜鸟氨酸回收

### 线粒体阶段

1. **生成氨基甲酰磷酸**

```text
NH3 + CO2 + ATP
--CPS-I→ 氨基甲酰磷酸
```

2. **生成瓜氨酸**

```text
鸟氨酸 + 氨基甲酰磷酸
--OCT→ 瓜氨酸
```

瓜氨酸移出线粒体进入胞浆。

### 胞浆阶段

3. **形成精氨酸代琥珀酸**

```text
瓜氨酸 + 天冬氨酸
--精氨酸代琥珀酸合成酶→ 精氨酸代琥珀酸
```

4. **裂解**

```text
精氨酸代琥珀酸
--裂解酶→ 精氨酸 + 延胡索酸
```

5. **生成尿素并回收鸟氨酸**

```text
精氨酸
--精氨酸酶→ 尿素 + 鸟氨酸
```

鸟氨酸重新进入线粒体，循环继续。

## KP15｜尿素的原料、能量与TCA接口：谁真正提供两个氮

> **主提示：** 尿素2个N来源｜ATP/高能键账｜延胡索酸-TCA接口｜载体是否供N｜跨区室

- 一个来自游离NH₃；
- 一个来自天冬氨酸。

鸟氨酸、瓜氨酸和精氨酸代琥珀酸是循环载体 / 中间物，不是两个氮的直接来源。

### 能量

当前Study：

- 每形成1分子尿素消耗3个ATP；
- 实际消耗4个高能磷酸键。

### 与TCA连接

```text
精氨酸代琥珀酸
→ 延胡索酸
→ 苹果酸 / 草酰乙酸接口
→ 再生成天冬氨酸或接能量代谢
```

因此尿素循环既处理氮，也通过延胡索酸与碳代谢连接。

## KP18｜叶酸—B12—同型半胱氨酸：为什么一碳障碍会走向巨幼变
