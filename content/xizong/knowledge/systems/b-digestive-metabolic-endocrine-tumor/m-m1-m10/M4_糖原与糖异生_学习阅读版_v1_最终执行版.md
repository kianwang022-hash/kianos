# M4｜糖原与糖异生
## 以 G-6-P 为分流枢纽，在储存、局部供能与全身保糖之间切换

> **中心问题**：餐后肝和肌怎样把葡萄糖储成糖原；空腹时肝怎样分解糖原或用乳酸、甘油和氨基酸重新合成葡萄糖；为什么肌糖原只能为自己供能，不能直接维持血糖？

## 2｜总 Framework

```text
G-6-P 枢纽
├─ 当前有糖：进入糖酵解 / PPP 或储成糖原
├─ 短期空腹：优先分解肝糖原输出葡萄糖
└─ 空腹延长：乳酸 / 甘油 / 生糖氨基酸 → 糖异生 → G-6-P → 血糖

组织边界：
肝有 G-6-P酶 → 能对外输出葡萄糖
肌无 G-6-P酶 → 糖原只服务局部做功
```

M4 的核心是**状态下的方向选择**，不是背两条互相独立的路径。

### 一句话恢复

> **G-6-P 是状态枢纽：有糖时存，短期空腹先取肝糖原，空腹延长则用乳酸/甘油/氨基酸重新造糖。**

## KP03｜糖原分解：磷酸化酶把糖原拆成 G-1-P

> **主提示：** 断键方式与产物｜组织调节信号｜供能路线｜能量口径

```text
糖原
--糖原磷酸化酶→ G-1-P
↔ G-6-P
```

- 分解关键酶：糖原磷酸化酶；
- 因产物直接是 G-1-P / G-6-P，进入糖酵解时绕过了“游离葡萄糖→G-6-P”的耗 ATP 步骤；
- 以一个进入糖酵解的葡萄糖单位计，肌糖原起步时当前 Study 计净 **3 ATP**，而游离葡萄糖起步为净 2 ATP；不是整分子糖原无论长短都只产生 3 ATP。
- P013 的组织比较表重点列出：肝糖原磷酸化酶受胰高血糖素调节，肌糖原磷酸化酶受肾上腺素调节，均联系磷酸化。原图还标出肝的肾上腺素调节；不能把比较表理解成肝只接受一种激素。完整激素信号链仍归 D7。

（易混：磷酸化酶不是“给糖原加磷酸使其失活”，而是催化磷酸解生成 G-1-P。）

## KP05｜糖异生为什么不是糖酵解倒放

> **主提示：** 共用与绕行｜反应方向｜底物去向｜区室定位｜原图边界
>
> **讲义定位：** 27生化跟课版合集【不带导图】.pdf｜BIO27-S03｜PDF P014–P015；可逆反应例回看 P007（M2 既有内容）。

糖异生要把三碳原料重新接回葡萄糖。它不是每一步都另造一套反应：**可逆部分可以与糖酵解共用，三个不可逆点才必须另用四种酶绕行**。先分清“哪一段共用、哪一个节点必须换酶”，再恢复反应方向，才不会把四种绕行酶误当成糖异生涉及的全部酶。

例如磷酸甘油酸激酶催化 **1,3-二磷酸甘油酸 ↔ 3-磷酸甘油酸**。P007 列出这一反应，P014 展示它在两条通路中的反向使用：糖酵解方向生成 ATP，糖异生方向需要消耗 ATP。这是共用的可逆反应；丙酮酸激酶所在的单向节点则不能这样倒用。

| 糖酵解不可逆点 | 糖异生绕行及底物去向 |
|---|---|
| 丙酮酸激酶：PEP→丙酮酸 | 丙酮酸羧化酶：丙酮酸→草酰乙酸；PEP羧激酶：草酰乙酸→PEP |
| PFK-1：F-6-P→F-1,6-BP | 果糖双磷酸酶-1：F-1,6-BP→F-6-P |
| 己糖/葡萄糖激酶：G→G-6-P | G-6-P酶：G-6-P→G |

第一个节点需要两步：先由丙酮酸羧化酶加上 CO₂，形成草酰乙酸，再由 PEP 羧激酶接到 PEP。**部位不是整条通路的一张标签**：丙酮酸羧化酶只在线粒体，需生物素；PEP 羧激酶在当前讲义中有线粒体和胞浆两种位置。果糖双磷酸酶-1、G-6-P酶仍按当前 Study 的胞浆语言理解，不在此自行改写更细的亚细胞定位。

P014–P015 原图还区分线粒体与胞浆，并画出苹果酸／天冬氨酸衔接路线。不能把草酰乙酸直接画成自由穿膜的箭头；完整穿梭关系仍 **SOURCE_BOUND，回当前原图核对**。这段文字用于恢复已学路线，不替代连续原讲义接触。

这里要分清：“糖异生涉及哪些酶”不等于“糖异生有哪些绕行关键酶”。可逆共用反应与四个单向绕行必须分开判断。

**需要精记：** 四种绕行酶与三个原节点的配对，以及丙酮酸羧化酶的线粒体／生物素坐标。**SOURCE_CONFLICT**：P015 的 FBPase-1 抑制物行仍保持本 Block 已声明的冲突，不从绕行表推断抑制物身份。

## KP06｜糖异生原料：乳酸、甘油、氨基酸从不同入口汇合

> **主提示：** 原料入口｜碳骨架资格｜调节身份｜相邻归属
>
> **讲义定位：** 27生化跟课版合集【不带导图】.pdf｜BIO27-S03｜PDF P014–P015。

“能够糖异生”不表示必须先走到同一个起点。先找到原料接入糖异生链的位置，才能判断它要经过哪些绕行、能不能套用从丙酮酸起步的耗能账。

| 原料 | 本组需要恢复的入口 | 随入口判断的边界 |
|---|---|---|
| 乳酸 | 乳酸→丙酮酸，再接草酰乙酸／PEP绕行 | 完整外周—肝往返在下一 KP 的 Cori 循环恢复 |
| 甘油 | 甘油—甘油激酶→α-磷酸甘油→磷酸二羟丙酮 | 在三碳中间物处接入，不必先退回丙酮酸；甘油来自甘油三酯分解 |
| 生糖氨基酸 | 经生糖碳骨架接入；当前图用丙氨酸／丙酮酸、天冬氨酸／草酰乙酸衔接 | 本组只判定生糖资格与入口；完整碳骨架分类仍归 M8 |

甘油的入口解释了当前 Source 所说“步骤和耗能较少”。P015 明确写出甘油激酶这一步每分子消耗 1 ATP，并按两分子甘油合计 2 个高能磷酸键。它从磷酸二羟丙酮接入，不能套用两分子丙酮酸起步的六个高能磷酸键总账；NADH 的生成与使用另看原图，不与 ATP 支出混算。

### 氨基酸的生糖边界

- 亮氨酸、赖氨酸：纯生酮，不能作为糖异生碳源；
- 异亮氨酸、苯丙氨酸、酪氨酸、色氨酸、苏氨酸：生糖兼生酮；
- 其余当前 Study 按生糖氨基酸入口处理。

理解任务是判断碳骨架有没有生糖去路；上述当前讲义例外名单需要精记，不把整个 M8 碳骨架分类搬到这里。

### 脂肪动员：碳源与调节身份分开

脂肪三酯拆开后，**甘油可以接入糖异生**；大部分脂肪酸的碳流则进入乙酰 CoA，不能经 PDH 逆转为丙酮酸。乙酰 CoA 不是净糖异生碳源，却能激活丙酮酸羧化酶。于是同一次脂肪动员可以提供甘油入口和糖异生调节信号，不能据此说“脂肪酸本身直接净变葡萄糖”。

脂肪动员的完整酶／转运链归 M7，氨基酸完整分类归 M8；这里保留已经成立的入口与身份边界。

## KP07｜Cori 循环：把外周乳酸送回肝重新造糖

> **主提示：** 往返碳流｜组织分工｜生理意义｜还原当量衔接
>
> **讲义定位：** 27生化跟课版合集【不带导图】.pdf｜BIO27-S03｜PDF P015 的肝—血液—肌图与乳酸碳数标注。

Cori 循环把外周产乳酸与肝造糖接成一次往返。先跟住碳骨架：外周把一分子六碳葡萄糖变成两个三碳乳酸，乳酸经血液回肝；肝把它转成丙酮酸，再沿糖异生重建葡萄糖，送回外周使用。

```text
肌肉 / RBC：葡萄糖 → 乳酸
→ 血液运至肝
→ 乳酸 → 丙酮酸 → 糖异生 → 葡萄糖
→ 再供外周使用
```

P015 原图把肌与肝放在血液两侧：**外周利用糖供能，肝承担回收三碳骨架、重新造糖的工作**。它不是让同一组织把糖酵解和糖异生简单反复运行，也不是一条凭空产能的循环。

意义仍按当前 Source 保留：

- 避免乳酸持续堆积和酸中毒；
- 保存碳骨架，减少能源物质直接丢失。

乳酸→丙酮酸产生的还原当量可在糖异生逆向步骤中使用，这是当前原图所示的还原当量自给接口；不要把 **NADH 衔接**与 **ATP/GTP 耗能**混为同一笔账。肝从两分子乳酸重建一分子葡萄糖要消耗六个高能磷酸键，具体位置由下一 KP 逐项恢复。

**需要精记：** 外周→血液→肝→葡萄糖返回外周的方向，以及“两分子三碳乳酸对应一分子六碳葡萄糖”的计数边界。先恢复组织分工，再记能量数字。

## KP08｜糖异生能量账：为什么“造糖”比拆糖贵

> **主提示：** 起点与终点计数｜哪些位置付能量｜各步骤如何合账｜不同入口能否同算
>
> **讲义定位：** 27生化跟课版合集【不带导图】.pdf｜BIO27-S03｜PDF P015 通路旁 ATP/GTP 标记与两分子底物；可逆磷酸甘油酸激酶反应见 P007。

先固定账本单位：**从两个三碳丙酮酸起步，生成一个六碳葡萄糖**。如果从乳酸起步，先转为丙酮酸，再经过同一段耗能路线。不是把一个三碳底物的耗能直接当作一个葡萄糖的总账。

| 耗能位置 | 每个三碳骨架 | 合成一个葡萄糖所需的两套反应 |
|---|---|---|
| 丙酮酸→草酰乙酸 | 1 ATP | 2 ATP |
| 草酰乙酸→PEP | 1 GTP | 2 GTP |
| 3-PG→1,3-BPG | 1 ATP | 2 ATP |
| 合计 | 2 ATP + 1 GTP | **4 ATP + 2 GTP = 6个高能磷酸键** |

前两个位置随丙酮酸→PEP绕行付能量；第三个位置是磷酸甘油酸激酶在糖异生方向的反应。这样既能说明“哪些反应共用”，也能解释“共用的可逆反应为什么在这个方向要耗 ATP”。

把这笔账接回 Cori：外周先用葡萄糖供能并留下乳酸，肝再付出能量回收碳骨架、恢复血糖；因此 **碳循环闭合不等于能量免费**。乳酸的还原当量衔接不改变这里的 ATP/GTP 支出。

计数时要分清：六个高能磷酸键对应两分子丙酮酸／乳酸造一分子葡萄糖。甘油在磷酸二羟丙酮处接入，绕过前面的耗能步骤；P015 按两分子甘油标注甘油激酶步骤消耗 2 ATP，不能把不同入口都算成 6。

**需要精记：** 三个付能量位置与 ATP/GTP 配对、两套三碳骨架的倍数。理解任务是从入口重建账本，而不是脱离底物数量背一个“6”。

## KP09｜胰高血糖素怎样把“降糖通路”切换为“升糖通路”

## 3｜Framework Reconstruction 与高密度比较轴

闭卷恢复三条路线：

```text
存糖：G → G6P → G1P → UDPG → 糖原
取糖：糖原 → G1P → G6P → 肝输出血糖 / 肌供能

```

再回答：为什么肝能补血糖、肌不能；为什么脂肪酸碳骨架通常不能净变葡萄糖，但脂肪动员仍促进糖异生。

---

### G-6-P与糖原存取

**Core relation**
```text
G-6-P
↔ G-1-P
→ UDPG → 糖原合成

糖原
→ G-1-P → G-6-P
→ 肝：G-6-P酶 → 游离葡萄糖入血
→ 肌：无 G-6-P酶 → 留在细胞内供能
```

**Boundary**
- 糖原合成与分解是两套受控方向，不是同一路径简单倒放；
- 肝 / 肌差异的关键是组织表达边界，不是“肌糖原不能分解”；
- PPP 是相邻 G-6-P 分支，Primary 归 M3。

**Precision**
- 合成关键酶：糖原合酶；分解关键酶：糖原磷酸化酶；
- UDPG 使用 UTP；
- 糖原起步进入糖酵解可绕过一次 ATP 消耗。

**Connection**
- D7/D8 调用“肝输出 vs 肌自用”状态，不复制 M4 通路本体。

---

### 糖异生、Cori与能量账

**Core relation**
```text
糖酵解的3个不可逆控制点
→ 糖异生用4个酶绕行
→ 乳酸 / 甘油 / 生糖氨基酸从不同入口汇合
→ 按具体入口计算耗能：2 丙酮酸 / 乳酸造 1 葡萄糖为 4 ATP + 2 GTP
→ 重建 G-6-P / 葡萄糖
```

**Boundary**
- 糖异生不是糖酵解倒放；
- 大部分脂肪酸碳流到乙酰CoA后不能净生糖；甘油可以；
- 乙酰CoA主要作为状态/调节信号和能量来源接口，不是净糖异生碳源。

**Precision**
- 丙酮酸羧化酶、PEPCK、FBPase-1、G-6-Pase；
- PC 在线粒体且需生物素；PEPCK 可跨线粒体 / 胞浆语言；
- 2 丙酮酸 / 乳酸 → 1 葡萄糖消耗 6 个高能磷酸键。

**Connection**
- Cori 循环把外周乳酸回收到肝；
- 氨基酸碳骨架完整分类归 M8，脂肪动员归 M7。

---

### 胰高血糖素与空腹时间轴

**Core relation**
```text
进食 → 储存优先
短期空腹 → 肝糖原分解优先
空腹延长 → 糖异生占比上升

胰高血糖素
→ F-2,6-BP方向下调
→ 糖酵解↓ / 糖异生↑
→ 肝糖输出↑
```

**Boundary**
- M4 只拥有通路方向切换；完整胰岛素 / 胰高血糖素受体与内分泌整合归 D7；

**Connection**
