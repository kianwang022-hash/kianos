## 1｜Canonical Knowledge Hierarchy

### M3 母模型｜成熟 RBC 用同一个 G-6-P 购买三种生存能力

```text
成熟 RBC 无线粒体
→ G-6-P 成为核心分流点
├─ 糖酵解 → ATP + NAD⁺再生 → 维持细胞基本供能
├─ 2,3-DPG 旁路 → Hb-O₂亲和力↓ → 组织放氧↑
└─ PPP → NADPH → GSH维持还原态 → 抵抗氧化损伤
```

M3 的重点不是背三条旁路，而是理解：**同一个细胞因为“无线粒体”这一约束，把葡萄糖分流成能量、放氧调节和抗氧化三种功能。**

### L1｜RBC 代谢约束、ATP与放氧｜KP01–KP03

**Core relation**
```text
无线粒体
→ 不能做 TCA / OXPHOS / β氧化
→ 糖酵解成为唯一直接供能
→ 2,3-DPG 从糖酵解中分流
→ 用部分能量机会换取更强组织放氧
```

**Boundary**
- 2,3-DPG 是放氧调节变量，不是高能化合物；
- 旁路不直接产 ATP，但回主路后仍可继续后段糖酵解；
- Hb完整结构 / 氧解离曲线由呼吸 / 血液 owner 负责。

**Precision**
- 成熟 RBC 唯一直接供能方式：无氧糖酵解；
- 2,3-DPG↑ → Hb-O₂亲和力↓ → 曲线右移 → 放氧↑。

**Connection**
- M2 提供糖酵解语言；
- 血液系统只调用这里的 ATP / 2,3-DPG 机制，不复制 M3 Core。

#### KP01｜成熟 RBC 的代谢约束：为什么只能依靠葡萄糖

> **主提示：** 缺线粒体｜不能4路｜主代谢2｜功能分支3｜唯一供能

成熟 RBC 没有线粒体，因此不能进行：

- 丙酮酸氧化脱羧；
- TCA；
- 氧化磷酸化；
- 脂肪酸 β 氧化与从头合成脂肪酸。

它有两条主代谢途径：无氧糖酵解与 PPP；2,3-DPG旁路位于糖酵解内部，是调放氧的功能分支。

当前 Study 把无氧糖酵解定义为成熟 RBC 获得能量的唯一方式。

---

<!-- kianos:kp id="biochem-m3-kp02" -->
#### KP02｜RBC 糖酵解：无线粒体时怎样持续供能

> **主提示：** RBC为何只能糖酵解｜终点｜净ATP｜NAD⁺怎么再生｜供能边界

```text
葡萄糖
→ 糖酵解
→ 丙酮酸
→ 乳酸
```

- 净得 2 ATP；
- 乳酸分支再生 NAD⁺，让糖酵解持续；
- 当前 Source 将无氧糖酵解定义为成熟 RBC 获得能量的唯一方式；
- 当前 Source 未进一步拆分 ATP 在成熟 RBC 内的具体用途，本文件不静默补写。

---

<!-- kianos:kp id="biochem-m3-kp03" -->
#### KP03｜2,3-DPG旁路：牺牲部分直接产能，换取组织放氧

> **主提示：** 来源｜旁路2步｜回哪｜Hb亲和方向｜曲线｜协同4｜供能边界

```text
1,3-DPG
→ 2,3-DPG
→ 3-PG
→ 重新进入糖酵解
```

- 2,3-DPG降低 Hb 与 O₂亲和力；
- 氧解离曲线右移，促进组织放氧；
- 当前 Study 将体温↑、CO₂↑、pH↓与 2,3-DPG↑列为右移协同因素；
- 2,3-DPG 可回到糖酵解后段，因此不是永久死路。

<!-- approved-27-audit: B1-M3-02 -->
2,3-DPG 旁路本身不直接产生 ATP；回到 3-PG 后仍可沿主糖酵解后段继续形成 ATP。

（易混：2,3-DPG不是高能化合物；它的主要角色是调节 Hb 放氧，不是“生成大量ATP”。）

### L2｜PPP—NADPH—GSH氧化防御｜KP04–KP07

**Core relation**
```text
G-6-P --G6PD→ PPP
→ NADPH + 5-P核糖 + CO₂
→ NADPH维持 GSH 还原态
→ GSH清除过氧化物
→ 保护 Hb / 膜蛋白与 RBC 稳定
```

**Boundary**
- PPP 不以直接产 ATP 为主要目标；
- NADPH 与 NADH 是两套不同还原当量：前者主打还原合成 / 抗氧化，后者主打乳酸再生 NAD⁺或进入呼吸链；
- “NADPH不是 OXPHOS 供能载体”不能被压成“只能生物转化”。

**Precision**
- 起点 G-6-P；关键酶 G6PD；
- PPP 输出 NADPH、5-P核糖、CO₂；
- G6PD↓ → NADPH↓ → GSH再生↓ → 氧化损伤 / 溶血接口。

**Connection**
- 5-P核糖 → M9；
- NADPH合成代谢 → M6/M7；
- G6PD缺陷完整临床 → 血液 H5。

<!-- kianos:kp id="biochem-m3-kp04" -->
#### KP04｜PPP：不直接以 ATP 为目标的葡萄糖分流

> **主提示：** 部位｜起点｜关键酶/抑制｜3产物｜2核心用途｜非OXPHOS

```text
G-6-P
--G6PD→ 磷酸戊糖途径
→ 5-磷酸核糖 + NADPH + CO₂
```

- 部位：胞浆；
- 关键酶：G6PD；
- 当前 Study：NADPH 对 G6PD 形成抑制；
- 5-磷酸核糖：核苷酸原料，完整代谢后置 M9；
- NADPH：还原力，服务 GSH、合成代谢与生物转化接口；
- PPP不是呼吸链 / 氧化磷酸化，也不以直接产生 ATP 为主。

---

<!-- kianos:kp id="biochem-m3-kp05" -->
#### KP05｜NADPH—GSH循环：把过氧化物还原成水

> **主提示：** 2反应｜2酶｜NADPH供谁｜GSH/GSSG｜结果｜RBC膜

```text
H₂O₂ + 2GSH
--GSH过氧化物酶→ 2H₂O + GSSG

GSSG + NADPH + H⁺
--GSH还原酶→ 2GSH + NADP⁺
```

- GSH 直接把过氧化物还原为水；
- 自身被氧化为 GSSG；
- NADPH再把 GSSG还原回 GSH；
- 结果是持续保留抗氧化能力，维持 RBC 膜稳定。

（易混：NADPH不是糖酵解中用于乳酸生成的 NADH。）

---

<!-- kianos:kp id="biochem-m3-kp06" -->
#### KP06｜G6PD缺陷：为什么“抗氧化链”先断

> **主提示：** G6PD↓→哪条抗氧化链断｜触发因素｜红细胞损伤/溶血方向｜证据边界

```text
G6PD活性不足
→ PPP产生NADPH能力下降
→ GSSG难以还原成GSH
→ 过氧化物清除不足
→ RBC膜与蛋白受氧化损伤
→ RBC破裂 / 溶血接口
```

当前 Study 以蚕豆等氧化剂为典型触发，并提示可出现血管内外溶血。完整诱因、遗传、实验室与治疗归血液 H5。

---

<!-- kianos:kp id="biochem-m3-kp07" -->
#### KP07｜NADH vs NADPH：名字相近，工作分区不同

> **主提示：** 来源｜主要用途｜RBC各做什么｜呼吸链能否用｜GSH｜核糖

| 变量 | 当前 Block 主角色 |
|---|---|
| NADH | 糖酵解脱氢产生；无氧时把氢交给丙酮酸形成乳酸；有线粒体组织可送入呼吸链 |
| NADPH | PPP产生；提供还原力，维持 GSH，还参与合成 / 生物转化接口 |
| ATP | 糖酵解直接供能 |
| 2,3-DPG | 调节 Hb—O₂亲和力 |
| 5-P核糖 | 核苷酸原料 |

一眼判别：

```text
问“供能/乳酸/呼吸链” → 先想NADH
问“抗氧化/GSH/还原合成” → 先想NADPH
```
