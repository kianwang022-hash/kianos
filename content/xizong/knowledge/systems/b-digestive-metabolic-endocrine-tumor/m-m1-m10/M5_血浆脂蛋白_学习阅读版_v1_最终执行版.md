# M5｜血浆脂蛋白
## 从“小肠与肝输出脂质”，到组织卸货、受体回收和胆固醇逆向转运

> **中心问题**：脂肪、胆固醇和磷脂疏水，怎样借助脂蛋白在血浆中运输；外源与内源脂质分别由谁装载；载脂蛋白、LPL、LCAT 和受体怎样决定颗粒的去向；运输失衡为什么会把脂质留在肝内或送进血管壁？
>
> **Primary ownership**：本 Block 首次完整建立 CM、VLDL、LDL、HDL 四类脂蛋白的来源—主要载荷—方向—降解，以及 apo、LPL、LCAT、LDL受体和清道夫受体的共同语言。循环系统的动脉粥样硬化只在这里 Recall / Apply，不重新展开血管病理；胆固醇合成与胆汁酸归 M6。

## 1｜Canonical Knowledge Hierarchy

### M5 母模型｜把疏水脂质变成有身份、有方向、有交接规则的血浆物流

```text
脂质必须装入特定颗粒
→ 颗粒身份决定来源与主要货物
→ apo / 酶 / 受体决定每一站如何卸货、回收或转运
→ 三条主物流：
   外源 CM
   内源 VLDL → IDL → LDL
   HDL 逆向胆固醇回收
→ 任一交接点失败 → 特定颗粒积聚 / 肝脂质滞留 / 血管壁负荷
```

M5 的压缩目标不是背 CM/VLDL/LDL/HDL 四行表，而是能从**来源 → 载荷 → 方向 → 交接接口 → 故障结果**恢复整套物流。

### L1｜脂蛋白身份、组成与方向｜KP01–KP03

**Core relation**
```text
来源 + 主要载荷 + 蛋白/脂质比例
→ 定义颗粒身份
→ 决定是“送出去”还是“收回来”
```

**Boundary**
- 游离脂肪酸主要搭白蛋白，不搭脂蛋白颗粒；
- 密度高低是组成结果，不是运输方向本身；
- LDL 并非由肝直接以最终形态分泌，而是 VLDL/IDL 血浆转化结果。

**Precision**
- CM：小肠 / 外源 TAG+胆固醇；
- VLDL：肝 / 内源 TAG；
- LDL：内源胆固醇向组织；
- HDL：肝外胆固醇逆向回肝；
- 蛋白比例 HDL>LDL>VLDL>CM，TAG 方向相反。

**Connection**
- 小肠组装前的吸收归 D4；
- 颗粒内胆固醇后续去路归 M6。

#### KP01｜为什么需要脂蛋白：把疏水脂质变成可定向运输的血浆颗粒

> **主提示：** 3脂类｜apo3角色｜4颗粒｜方向轴

##### 详细展开

当前 Study 将血浆脂蛋白看作：

```text
脂类（TAG / 胆固醇 / 磷脂）
+ 蛋白质 / 载脂蛋白 apo
→ 可在血浆中运输的复合颗粒
```

脂类在本系统中的总角色先作一次定位：供能、保温、构成生物膜、帮助脂溶性维生素吸收，并可通过DAG等连接信息传递；这些功能分别在M6、M7与D5继续展开。

apo不只是“外壳蛋白”，至少承担四类决定性任务：

1. 携带并稳定脂类；
2. 作为受体识别标志，决定颗粒被谁摄取；
3. 激活或调节脂类代谢酶，决定何时卸货或酯化。
4. 作为脂类交换的连接蛋白；本处仅保留角色，不展开 CETP 或完整交换网络。

四类颗粒不是按“好坏”分类，而是按**来源、主要载荷和运输方向**分工。

（易混：游离脂肪酸 FFA 不靠脂蛋白运输，主要与白 / 清蛋白结合。）

#### KP02｜四类脂蛋白总地图：来源、主要载荷与方向

> **主提示：** 4类脂蛋白｜来源｜主要载荷｜运输方向

| 颗粒 | 当前 Study 特征 | 主要来源 | 主要任务 |
|---|---|---|---|
| CM | apoB48 | 小肠 | 运输外源性脂肪、胆固醇 |
| VLDL | 前β | 肝 | 主要运输内源性脂肪 / TAG |
| LDL | β | 血浆中由 VLDL→IDL→LDL | 运输内源性胆固醇至组织 |
| HDL | α | 小肠、肝、血浆 | 逆向运输肝外胆固醇回肝 |

最稳定的识别不是颗粒大小，而是：

```text
来源在哪里
→ 装的主要是什么
→ 是送出去，还是收回来
```

（易混：LDL并非由肝直接按最终形态分泌；当前 Study 强调其来自 VLDL—IDL 的血浆转化。）

<!-- kianos:kp id="biochem-m5-kp03" -->
#### KP03｜密度、组成与电泳：油越多越轻，蛋白越多越密

> **主提示：** 蛋白排序｜TAG排序｜胆固醇排序｜电泳3｜密度规律

当前 Study 的三条排序：

```text
蛋白质：HDL > LDL > VLDL > CM
TAG / 脂肪：CM > VLDL > LDL > HDL
胆固醇：LDL > HDL > VLDL > CM
```

因此：

- 脂质尤其TAG越多，颗粒密度越低；
- 蛋白质比例越高，颗粒密度越高；
- 电泳名称：VLDL为前β、LDL为β、HDL为α；CM以 apoB48 作为当前最醒目标记。

（MI-D：完整含量百分比、粒径排序和所有电泳迁移细节不阻塞第一轮。）

### L2｜CM、VLDL→LDL、HDL三条运输线｜KP04–KP07

**Core relation**
```text
外源线：小肠 → CM → LPL卸TAG → 外源脂质交给组织
内源线：肝 → VLDL → LPL卸TAG → IDL → LDL → 胆固醇交给组织
回收线：肝外胆固醇 → HDL → 回肝
```

**Boundary**
- CM 与混合微胶粒不是同一种颗粒；
- LDL受体回收与清道夫摄取回答不同问题；
- HDL 的核心是胆固醇逆向转运，不是“清除所有血脂”。

**Precision**
- CM：apoB48；
- LDL受体识别核心接口：apoB100 / apoE；
- HDL—apoAⅠ—LCAT；
- LDL current Study：约 2/3 受体通路、约 1/3 清道夫接口。

**Connection**
- VLDL输出不足 → 肝 TAG 滞留 / 脂肪肝接口；
- ox-LDL / 清道夫摄取 → 动脉粥样硬化接口，但完整血管病理不在 M5。

#### KP04｜CM外源线：小肠把膳食长链脂质交给血液

> **主提示：** CM外源线：小肠装配｜关键apo｜入血路径｜LPL卸货｜主要载荷

##### 1｜组装入口｜Recall D4

```text
膳食长链脂肪酸 + 一酰甘油进入小肠上皮
→ 重合成TAG
→ 与胆固醇、磷脂等 + apoB48组装
→ CM
→ 淋巴 → 胸导管 → 血液
```

##### 2｜进入血浆后的任务

CM主要运输：

- 外源性 TAG / 脂肪；
- 外源性胆固醇。

##### 3｜卸货节点

当前 Study 将 CM 与 VLDL共同归为 LPL 主要处理对象：

```text
CM携带TAG
→ apoCⅡ—LPL接口
→ TAG被水解、脂质交给组织
```

（易混：混合微胶粒存在于肠腔，CM存在于上皮—淋巴—血液；二者不是同一种颗粒。）

<!-- kianos:kp id="biochem-m5-kp05" -->
#### KP05｜VLDL—IDL—LDL内源线：肝先输出TAG，再留下胆固醇运输颗粒

> **主提示：** 肝起点｜主货物｜LPL｜两次转化｜输出失败｜终点

```text
肝内合成TAG
→ VLDL输出
→ LPL逐步卸下TAG
→ IDL
→ LDL
```

- VLDL的主任务是运输**内源性脂肪 / TAG**；
- VLDL增多可表现为高脂血症方向；
- 当前 Study 特别强调：VLDL输出功能不足时，肝内TAG难以运出，可形成脂肪肝接口；
- 随TAG不断被卸下，颗粒逐步转向以胆固醇运输为主的 LDL。

（边界：完整脂肪肝病因树与临床诊疗不在此展开。）

<!-- kianos:kp id="biochem-m5-kp06" -->
#### KP06｜LDL交付与回收：受体通路和清道夫通路回答不同问题

> **主提示：** LDL：关键apo｜受体通路 vs 清道夫通路｜清除比例｜胞内胆固醇去向｜反馈

##### 1｜受体介导入胞

当前 Study：约 **2/3 LDL** 经多种细胞的 LDL受体清除，以肝为主。

```text
LDL上的 apoB100
→ LDL受体识别
→ 受体介导入胞
→ 溶酶体处理
→ 释放游离胆固醇与氨基酸
```

细胞内胆固醇可用于：

- 更新生物膜；
- 经 ACAT酯化储存；
- 在相应组织形成胆汁酸、类固醇激素或 VitD接口。

同时形成反馈：

- 抑制 HMG-CoA还原酶，减少自身合成；
- 抑制 LDL受体表达，减少继续摄取。

完整酯化与合成调节在 M6 学全。

##### 2｜清道夫通路

当前 Study：约 **1/3 LDL** 可被巨噬细胞和血管内皮细胞的清道夫受体吞噬、清除。

//串联循环：LDL尤其 ox-LDL 增多，是动脉粥样硬化的重要脂质负荷入口；血管壁病理已在循环完成，不在此重讲。

#### KP07｜HDL逆向转运：不是向组织送货，而是把胆固醇带回肝

> **主提示：** 来源3｜逆向起终点｜apoAⅠ｜LCAT｜自身结局｜保护方向

```text
肝外组织 / 血管壁胆固醇
→ HDL接收
→ apoAⅠ激活LCAT
→ 血浆内胆固醇酯化接口
→ HDL逆向运回肝
→ 胆固醇后续降解 / 排出
```

- HDL可在小肠、肝和血浆形成；
- 当前 Study 以“逆向转运胆固醇到肝”定义其核心任务；
- 在此过程中 HDL自身也可被降解；
- HDL降低时，当前 Study把它放在高脂血症风险方向。

（易混：HDL并非简单“清除全部血脂”；它的核心方向是胆固醇逆向转运。）

### L3｜apo—酶—受体交接与故障定位｜KP08–KP10

**Core relation**
```text
apo = 身份 / 受体识别 / 酶激活标签
酶 = 决定卸货或酯化
受体 = 决定颗粒/胆固醇被谁接收
→ 接口缺陷决定哪类货物积聚
```

**Boundary**
- LPL（血管侧颗粒卸 TAG）≠ HSL（脂肪细胞内动员储存 TAG）；
- LCAT（血浆胆固醇酯化）≠ ACAT（细胞内胆固醇酯化）；
- 白蛋白运输 FFA，不是 apo 的替代品。

**Precision**
- apoAⅠ → LCAT；
- apoCⅡ → LPL；
- apoB100 / apoE → LDL受体接口；
- B48 是 CM 身份标志。

**Connection**
- LCAT/ACAT 完整化学归 M6；
- HSL / 脂肪动员归 M7；
- 异常结果应先定位运输接口，再进入临床疾病 owner。

#### KP08｜关键 apo：识别、激酶与颗粒身份怎样一一对应

> **主提示：** apo B48/B100/E/AⅠ/CⅡ｜各代表身份/识别/酶激活哪一层｜总角色归类

| apo | 当前 Study 角色 |
|---|---|
| apoB48 | CM的特征性身份标志 |
| apoB100 | LDL受体识别标志 |
| apoE | 也可识别 LDL受体 |
| apoAⅠ | 识别HDL受体；激活LCAT |
| apoCⅡ | 激活LPL |

```text
颗粒身份：B48
受体识别：B100 / E / AⅠ接口
酶激活：AⅠ→LCAT；CⅡ→LPL
```

（MI-D：其它 apo、全部交换过程和低频缺陷病不作为当前门槛。）

<!-- kianos:kp id="biochem-m5-kp09" -->
#### KP09｜LPL、LCAT、ACAT和白蛋白：四个名字分别处理哪一层

> **主提示：** LPL/LCAT/ACAT/白蛋白｜各在何处｜处理什么底物｜需要哪个辅因子/载体

- **LPL**：当前 Study 主要水解富含TAG的 CM、VLDL；由 apoCⅡ激活；
- **LCAT**：在血浆中酯化胆固醇，由 apoAⅠ激活；完整反应 M6；
- **ACAT**：在细胞内酯化胆固醇，完整反应 M6；
- **白 / 清蛋白**：运输游离脂肪酸 FFA，不是由 apo代替。

（易混：LPL是脂蛋白脂肪酶；M7的 HSL 是脂肪细胞内脂肪动员关键酶，故一个管“血中颗粒卸货”，一个管“脂肪库动员”。）

<!-- kianos:kp id="biochem-m5-kp10" -->
#### KP10｜从异常结果反推运输故障层

> **主提示：** TG↑/LDL↑/HDL↓/脂肪肝｜分别先定位哪段运输故障｜特殊蛋白边界

```text
外源TAG负荷高
→ CM方向

内源TAG输出高
→ VLDL方向

肝内脂肪运不出
→ VLDL输出故障接口

胆固醇向组织负荷高
→ LDL方向

逆向回收不足
→ HDL方向
```

低频但有明确 Source 身份的两个点：

- 游离脂肪酸由白蛋白运输；
- 主要在肝外组织合成的血浆蛋白接口是 γ球蛋白，来源指向浆细胞。

（边界：这是一张代谢物流定位图，不等同于完整血脂检查、临床分型或治疗方案。）
