# 0｜统一入口：表达量是多道闸门的共同结果

```text
DNA能否暴露
→ 启动子是否可被识别
→ 激活 / 抑制因子组合
→ RNA能否被正确加工并运出
→ mRNA是否稳定或被RNAi压制
→ 翻译与蛋白降解速度
→ 最终蛋白量与细胞表型
```

原核侧重快速、成组调节；真核侧重染色质、独立基因与多层精细调控。

## KP01｜基因表达的两种特异性与三类基因

> **讲义定位 →** 生化 Lecture PDF P163，印刷页 P138。  
> **主提示**：时/空2特异｜管家/诱导/阻遏｜协同｜3层调控｜基本控制点

    同一个体多数细胞拥有相同遗传信息，真正决定细胞差异的是表达组合。

- **时间 / 阶段特异性**：胎儿与成人可表达不同；
- **空间 / 组织特异性**：胰岛素基因广泛存在，但主要在胰岛 β 细胞表达。

按环境依赖可分：

- 管家基因：多数细胞持续、相对稳定表达；
- 可诱导基因：特定刺激后升高；
- 可阻遏基因：特定条件下降低。

基因表达可在 DNA/染色质、转录/转录后、翻译/翻译后各层被调节；讲义将**转录起始**视为最重要、最复杂的基本控制点。

<!-- approved-27-audit: B4B-G4-01 -->
表达的必要入口是转录，之后可有翻译；DNA复制不是基因表达。多个调控因素可共同或协同作用。

**Routing**：CORE｜MI-G

## KP02｜染色质开放与表观调控：DNA能不能被读到

> **讲义定位 →** 生化 Lecture PDF P163，印刷页 P138。  
> **主提示**：活性染色质特征｜组蛋白层级｜甲基化/乙酰化方向｜开放性与转录｜降解接口

    活性染色质的共同方向是“更开放、更容易让调节蛋白与 DNA 结合”：

1. 出现核酸酶高敏位点；
2. H1减少、H2A-H2B稳定性下降，H3/H4发生多种修饰；
3. 核小体松弛，DNA裸露增加。

讲义最稳定的方向对：

```text
DNA / CpG甲基化
→ 染色质更紧
→ 不利转录

组蛋白乙酰化
→ 染色质更松
→ 利于转录
```

翻译后层还可通过“泛素标记 + 蛋白酶体 + ATP”清除异常蛋白和短寿蛋白，改变最终蛋白量。

（易混：DNA复制不等于基因表达；产生功能RNA也属于表达，不一定进入翻译。）

<!-- approved-27-audit: B4B-G4-02 -->
本KP按当前26 Study表述修饰与活性染色质的整体方向，不外推成无例外的现代机制规则。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP03｜操纵子的共同语言：调节基因、调控序列与结构基因

> **讲义定位 →** 生化 Lecture PDF P164，印刷页 P139。  
> **主提示**：I/CAP/P/O/ZYA｜各结合谁｜多顺反子｜正/负调控

    乳糖操纵子用一套最小语言说明原核怎样把多个结构基因一起控制：

| 结构 | 结合 / 产物 |
|---|---|
| 调节基因 I | 编码阻遏蛋白 |
| CAP结合位点 | 结合 cAMP-CAP |
| P 启动子 | 结合 RNApol |
| O 操纵序列 | 结合阻遏蛋白 |
| Z/Y/A | 编码分解乳糖的三类酶 |

<!-- approved-27-audit: B4B-G4-03 -->
Z编码β-半乳糖苷酶，Y编码半乳糖苷通透酶，A编码硫代半乳糖苷乙酰转移酶。

Z/Y/A 共用调控入口并转录为多顺反子 mRNA。负调控看阻遏蛋白是否占据 O；正调控看 cAMP-CAP 是否提高 RNApol 活性。

**Routing**：CORE｜MI-G

## KP04｜乳糖操纵子的负调控：有没有乳糖决定门能否打开

> **讲义定位 →** 生化 Lecture PDF P164，印刷页 P139。  
> **主提示**：无乳糖 vs 有乳糖｜阻遏蛋白/操纵序列｜诱导物｜ZYA转录结果

    ```text
无乳糖
→ I基因产生阻遏蛋白
→ 阻遏蛋白结合O
→ RNApol无法有效通过
→ ZYA关闭

有乳糖
→ 乳糖进入并形成别乳糖
→ 别乳糖使阻遏蛋白变构
→ 阻遏蛋白离开O
→ 解除负调控
```

乳糖回答“是否需要生产分解乳糖的酶”。但解除阻遏只表示可以转录，转录量高不高还要看葡萄糖—cAMP-CAP轴。

（易混：阻遏蛋白结合 O，不是 P；RNApol 结合 P。）

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP05｜CAP正调控与四种营养组合

> **讲义定位 →** 生化 Lecture PDF P165，印刷页 P140。  
> **主提示**：葡萄糖↔cAMP｜CAP结合谁｜4组合｜大量/少量/关闭

    ```text
无葡萄糖
→ cAMP↑
→ cAMP-CAP形成
→ 结合启动子上游CAP位点
→ RNApol活性↑

有葡萄糖
→ cAMP低
→ CAP正调控弱
```

| 乳糖 | 葡萄糖 | 阻遏 | CAP | 表达 |
|---|---|---|---|---|
| 无 | 任意 | 在 | 不论 | 关闭 |
| 有 | 无 | 解开 | 强 | 大量表达 |
| 有 | 有 | 解开 | 弱 | 少量表达 |

因此：乳糖决定“开门”，葡萄糖决定“开门后开多大”。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP06｜色氨酸操纵子：阻遏粗调 + 衰减精调

> **讲义定位 →** 生化 Lecture PDF P166–167，印刷页 P141–142。  
> **主提示**：诱导/阻遏型｜高Trp粗调｜低/高Trp发卡2型｜原核前提

    色氨酸操纵子属于阻遏型，目标是控制“合成色氨酸的酶”。

### 粗调：阻止起始

```text
高Trp + 阻遏蛋白
→ 可结合O
→ 转录不能起始
```

### 精调：衰减已起始转录

- 低 Trp：tRNA^Trp不足，核糖体停在前导肽 UGG → 形成 2–3 发卡，无 poly-U终止 → 转录继续；
- 高 Trp：前导肽顺利翻译 → 形成 3–4 发卡 + U尾 → 已起始转录提前终止。

这一机制依赖原核“转录与翻译同空间、可同步进行”。

<!-- approved-27-audit: B4B-G4-04 -->
色氨酸操纵子按R/P/O、前导序列和EDCBA结构基因识别；前导肽与衰减构成精调层。

（易混：粗调管“能否起始”；衰减管“已经起始后是否提前停”。）

**Routing**：CORE｜VISUAL_ONLY｜CONFUSABLE｜MI-G

## KP07｜真核顺式作用元件：同一条DNA上的调控入口

> **讲义定位 →** 生化 Lecture PDF P168–169，印刷页 P143–144。  
> **主提示**：顺式定义｜启动子3盒｜增强/沉默/绝缘｜外显内含｜单顺反子

    顺式作用元件是与被调结构基因位于同一 DNA 分子上的调控序列，主要包括：

- 启动子：提供转录起始入口；II类启动子核心有 TATA/Hogness 盒，上游可有 GC盒、CAAT盒；
- 增强子：提高启动子效率，讲义强调可在不同位置、距离和方向发挥作用；
- 沉默子：抑制转录；
- 绝缘子：置于增强子/沉默子与启动子之间，限制其跨区作用。

真核结构基因可为断裂基因，每个基因有更独立的调控入口，形成单顺反子表达。

<!-- approved-27-audit: B4B-G4-05 -->
启动子类别最小接口：I/II/III类分别与RNApol I/II/III及其相应产物相连。

**SOURCE_CONFLICT / 待核对**：P169 关于增强子“是否严格启动子专一”与解释性文字的“无专一性”存在内部冲突。本文不冻结该一项；只保留位置/距离/方向相对灵活、需通过蛋白质与启动子系统协作的稳定主线。

**Routing**：CORE｜BOUNDARY｜MI-G/MI-D

## KP08｜反式作用因子：DNA结合域、激活域与核受体

> **讲义定位 →** 生化 Lecture PDF P169–170，印刷页 P144–145。  
> **主提示**：2大结构域｜DNA结合3模体｜激活3富集｜通用/特异｜核受体3域

    转录因子由其它基因编码，可扩散并结合顺式元件，故属于反式作用因子。

### 两类核心结构域

1. **DNA结合域**：锌指、亮氨酸拉链、螺旋—环—螺旋；
2. **转录激活域**：酸性、富谷氨酰胺、富脯氨酸等，主要进行蛋白质—蛋白质相互作用。

### 类型

- 通用 / 基本转录因子：帮助某类 RNApol 与启动子组装；
- 特异转录因子：结合增强子、沉默子或上游元件，决定时空特异性；HIF、MyoD为讲义接口。

<!-- approved-27-audit: B4B-G4-07 -->
当前26 Source接口：SP1→GC盒，C/EBP→CAAT盒，MyoD→肌细胞，HIF→缺氧；不写“最重要”superlative。

核受体是配体依赖型转录因子：含配体结合域、DNA结合域和转录激活域。醛固酮—核受体—诱导蛋白是前序内分泌 / 泌尿的 Recall，不在本 Block重讲。

**Routing**：CORE｜CONNECTION｜MI-G/MI-D

## KP09｜RNApol II前起始复合物：从TATA盒到开放复合体

> **讲义定位 →** 生化 Lecture PDF P171，印刷页 P146。  
> **主提示**：D-A-B-Fpol-E-H｜TBP/TAF｜H 3活性｜CTD磷酸化

    讲义顺序：

```text
TFIID
→ TFIIA
→ TFIIB
→ TFIIF–RNApol II
→ TFIIE
→ TFIIH
```

- TFIID 的 TBP 识别 TATA盒，TAF协助；
- A/B加强并稳定初始复合物；
- F携 RNApol II 加入；
- E募集H并稳定开放区；
- TFIIH有 ATP酶、解旋酶、蛋白激酶活性，打开 DNA 并磷酸化 RNApol II 的 CTD，使聚合酶离开启动子进入延长。

中介子、TAF等把增强子上的激活因子与基本转录机器连接起来。

<!-- approved-27-audit: B4B-G4-09 -->
TFIIE稳定开放单链区；TFIIF在RNApol II进入延长后仍随聚合酶。完整解旋酶总表只作识别。

//MI-D：完整 TF 顺序要识别，但第一轮先抓 D识别TATA、H打开并磷酸化。

## KP10｜转录后调控与RNA干扰：mRNA做出来以后还能被降解或压住

> **讲义定位 →** 生化 Lecture PDF P172–176，印刷页 P147–151。  
> **主提示**：加工/转运2层｜mi/si来源｜RISC｜完全/不完全互补｜lncRNA｜蛋白降解

    转录后调控包括前体 mRNA 加工、核输出、稳定性、RNA干扰和翻译效率。

### siRNA

```text
长dsRNA
→ Dicer切为21–23nt siRNA
→ 加入RISC
→ 完全互补靶mRNA
→ 降解
```

### miRNA

内源形成并进入 RISC：

- 完全互补时可降解靶 mRNA；
- 不完全互补结合 3′UTR 时抑制翻译。

两者共同点是 RISC；主要差别在来源、单双链和是否常以不完全互补抑制翻译。lncRNA 只作“>200 nt 长链非编码 RNA”识别接口，完整功能不在当前 Source 展开。

<!-- approved-27-audit: B4B-G4-10 -->
RNAi三类识别：piRNA、miRNA、siRNA；共同执行复合物为RISC。Cue保持“三类—来源/配对—RISC”。

蛋白质水平还可通过泛素—蛋白酶体清除短寿和异常蛋白，使“表达量”不只由转录决定。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G/MI-D
