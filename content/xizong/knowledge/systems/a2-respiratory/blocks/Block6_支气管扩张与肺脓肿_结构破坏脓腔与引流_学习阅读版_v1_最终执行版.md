## 0｜这个 Block 到底解决什么

两种疾病都可表现为“大量脓痰、咯血、空腔影”，但故障位置不同：

```text
支气管扩张症
反复感染
→ 段 / 小支气管管壁支撑结构被破坏
→ 周围纤维牵拉 + 咳嗽跨壁压
→ 支气管永久扩张、管壁纤维性增厚
→ 脓痰长期潴留

肺脓肿
病原进入肺实质
→ 化脓、坏死、液化
→ 坏死物经支气管排出
→ 肺实质内形成含液气平的脓腔
```

共同治疗逻辑不是只“杀菌”：

```text
控制病原
+
让分泌物 / 脓液排出去
+
处理大咯血与持续感染源
```

### 本 Block 的总任务

> **面对大量脓痰、咯血或空腔时，先分清是“扩张的含痰气道”还是“肺实质坏死脓腔”，再决定清痰、止血、抗感染和引流。**

## 1｜总 Framework

```text
A｜先定结构层级

段 / 小支气管
有软骨、平滑肌、弹力纤维支撑
→ 支撑被破坏后有明显永久扩张潜能

末梢肺组织
呼吸性细支气管、肺泡管、肺泡囊、肺泡
→ 弹性框架破坏更偏肺气肿与回缩下降

        ↓

B｜支扩三股扩张力

管壁支撑结构破坏（最关键）
+ 周围肺组织纤维化牵拉
+ 咳嗽使管腔内压 / 跨壁压升高
→ 持久扩张 + 管壁纤维性增厚

        ↓

C｜扩张之后为什么仍会阻塞

扩张气道成为“痰盂”
→ 大量脓痰潴留
→ 气流受阻、固定湿啰音、反复感染
→ 进一步破坏管壁
→ 恶性循环

        ↓

D｜肺脓肿三条入口

吸入性：厌氧菌、右肺、单发为主
血源性：金葡菌、菌栓、双肺外周多发
继发性：坏死性肺炎 / 支扩 / 肿瘤 / TB / 异物 / 邻近灶

        ↓

E｜治疗围绕三件事

抗感染
→ 对病原与风险分层

排出分泌物
→ 雾化、体位引流、支气管引流

处理危险
→ 大咯血窒息、持续脓腔、脓胸与感染源
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 支扩定义必须同时包含**持久性扩张 + 管壁纤维性增厚**；
2. 支扩三机制：支撑结构破坏、周围纤维牵拉、跨壁压升高；第一项最关键；
3. 支扩发生在段 / 小支气管，肺气肿主要累及末梢肺组织；
4. “支气管扩张”不等于气道阻力下降：脓痰潴留可造成阻塞；
5. 阻塞是支扩的结果，不是最主要发病基础；
6. 支扩典型：长期大量脓痰、固定持久湿啰音、咯血、杵状指；干性支扩可仅反复咯血；
7. HRCT 是支扩金标准，印戒征 / 双轨征 / 薄壁囊腔是关键影像语言；
8. 大咯血危险首先是窒息，不以外观看到的血量机械判断病情；
9. 支扩急性感染先判断有无铜绿假单胞菌高危因素；
10. 肺脓肿三型：吸入性、血源性、继发性；吸入性最常见；
11. 吸入性肺脓肿：厌氧菌、误吸、右肺、体位决定肺段；
12. 血源性肺脓肿：金葡菌、双肺外周多发、血培养；
13. 肺脓肿治疗必须达到影像空洞消失 / 明显吸收后才停药；
14. 薄壁囊腔、厚壁脓腔、结核空洞和癌性空洞不能只靠“有洞”鉴别。

### MI-D｜进入 MarginNote 3 卡片流

- 杵状指11种疾病；
- 大咯血数值与止血药禁忌；
- 铜绿假单胞菌高危条件；
- 抗假单胞菌药物完整名单与“不能选”项；
- HRCT各影像征名称；
- 不同体位误吸的精确肺段；

# Unit A｜支气管扩张：为什么“管腔变大”仍是阻塞病

## KP01｜支扩身份与三股扩张力：支撑先坏，牵拉和压力再把它拉开

> **讲义定位 →** 病理 Lecture PDF P68；内科 Lecture PDF P27  
> **Outline →** 病理 U001｜支扩1–3；内科 U009｜诱发因素1  
> **主提示：** 定义2件｜病因主轴｜扩张力3｜关键1｜结果2｜（边界：牵拉性扩张≠支扩症？）

### 1｜定义

> **支气管管腔持久性扩张，并伴管壁纤维性增厚的慢性疾病。**

只看到影像上支气管变宽，不足以自动等同支气管扩张症；当前 Study 强调管壁结构破坏后的纤维性修复。

### 2｜最重要的病因背景

- 支气管肺炎，尤其麻疹、百日咳后，最主要；
- 慢支炎；
- 肺结核；
- 其他反复化脓感染。

### 3｜三股力量

```text
① 慢性化脓性炎
→ 破坏弹力纤维、平滑肌、软骨
→ 支气管失去支撑结构（最关键）

② 周围肺组织慢性炎症与纤维化
→ 胶原纤维收缩
→ 从外侧牵拉支气管

③ 反复咳嗽
→ 管腔内压升高
→ 跨壁压升高
→ 从内侧撑大管腔
```

最终：

```text
持久扩张
+ 管壁肉芽组织修复、纤维性增厚
```

（边界：特发性肺纤维化可因间质胶原收缩出现牵拉性支气管扩张，但若支气管壁未被破坏，不按本节支气管扩张症模型解释；完整 ILD 后置 R8。）

## KP02｜支扩 vs 肺气肿：都是弹性结构损伤，但层级和结果相反

> **讲义定位 →** 病理 Lecture PDF P69；回看 R3  
> **Outline →** 病理 U001｜支扩5–6及比较串  
> **主提示：** 层级2｜结构破坏｜弹性下降位置｜支撑丢失结果｜阻塞身份｜肺心病

| 轴 | 支气管扩张症 | 肺气肿（腺泡中央型） |
|---|---|---|
| 主要层级 | 段 / 小支气管，传导区 | 终末细支气管、一级呼吸性细支气管及末梢肺组织 |
| 关键结构 | 弹力纤维、平滑肌、软骨等管壁支撑 | 小气道壁与肺泡间隔弹性框架 |
| 失去支撑后 | 有软骨支撑的较大气道被撑大 → 永久扩张 | 小气道纤维化、狭窄；肺泡端过度扩张 |
| 阻塞的角色 | 支扩发生后的痰液潴留结果 | 发病基础和恶性循环的重要组成 |
| 弹性下降位置 | 段 / 小支气管 | 末梢肺组织、肺泡间隔 |
| 慢支关系 | 可为病因，但最主要病因是支气管肺炎 | 常见且重要病因 |
| 肺心病 | 可因广泛炎症纤维化并发 | 常见并发 |

### “大的越大，小的越小”

```text
段 / 小支气管有软骨支撑
→ 支撑破坏后容易扩张

终末与一级呼吸性细支气管本无软骨
→ 破坏修复后更易纤维化狭窄
```

（易混：支扩虽“管腔扩张”，仍可因大量痰液阻塞表现为阻塞性通气障碍；内科 Lecture 还提示广泛周围纤维化时可出现限制性成分，不能只凭一个字母给整个患者定性。）

## KP03｜支扩诱发因素：反复感染是主轴，阻塞是诱因而非核心病理基础

> **讲义定位 →** 内科 Lecture PDF P27  
> **Outline →** 内科 U009｜诱发因素1  
> **主提示：** 因素7类｜最常见｜阻塞身份｜（特殊×3：A1AT、黄甲、纤毛？）

当前 Study 列举：

- 感染；
- 免疫异常，如白血病、风湿系统疾病、炎症性肠病；
- 气道阻塞；
- α₁-抗胰蛋白酶缺乏；
- 黄甲综合征；
- 原发性纤毛不动征 PCD；
- Kartagener征。

判断层级：

```text
诱发因素
→ 使分泌物难清、感染反复或管壁易受损

核心病理基础
→ 管壁支撑结构破坏
```

所以“气道阻塞”可诱发支扩，但不能取代“管壁结构破坏”成为最主要病变基础。

## KP04｜好发部位与干性支扩：哪里更容易积痰，哪里反而自带引流

> **讲义定位 →** 内科 Lecture PDF P27、P39  
> **Outline →** 内科 U009｜好发部位1；U013｜好发部位2  
> **主提示：** 普通支扩1｜干性1｜原因链｜干性症状｜//串联：TB？

### 普通支扩

> **左肺下叶多见。**

Study解释：

- 下叶受重力影响，分泌物不易排出；
- 左侧受心脏等解剖关系影响，痰液更不易清除；
- 右主支气管粗、短、陡，虽更易误吸，也相对更易咳出。

### 干性支扩

> **上叶尖后段多见，常与肺结核有关。**

```text
病变位置较高
→ 支气管形成相对自然引流
→ 脓痰不易大量潴留
→ 可仅以反复咯血为主要表现
```

//串联：继发性肺结核上叶尖后段模型在 R7 完整学习。

## KP05｜临床表现：痰盂、固定湿啰音、咯血和杵状指

> **讲义定位 →** 内科 Lecture PDF P27–28  
> **Outline →** 内科 U009｜临床表现1–2  
> **主提示：** 症状4｜啰音2｜咯血3点｜干性1｜杵状指｜杂音链｜（特殊：量≠严重度？）

### 1｜大量脓痰与固定湿啰音

```text
扩张气道内长期积聚脓痰
→ 像“痰盂”
→ 长期咳嗽、大量脓痰
→ 气流通过液体形成固定、持久湿啰音
```

痰液也可造成狭窄，出现干啰音。

### 2｜咯血

- 约50%–70%可咯血；
- 管壁破坏可累及支气管动脉；
- 咯血量与疾病严重程度不完全相关；
- 干性支扩可仅反复咯血。

> 血块堵住气道时，外面看到的血量可减少，但窒息风险并未下降。

### 3｜杵状指与其他接口

- 支扩可有杵状指；
- 长期咯血可致贫血；
- 贫血使循环代偿、回心血量增加，可出现左心扩大和相对性二尖瓣关闭不全，心尖部收缩期杂音。

### 4｜杵状指 MI-D

当前 Study 串联：肝硬化、系统性硬化症、支扩、ILD、亚急性感染性心内膜炎、炎症性肠病、慢性肺脓肿、慢性脓胸、梅毒、法洛四联症、肺癌。

## KP06｜HRCT：看见的是扩张气道，而不是只看一张“蜂窝图”

> **讲义定位 →** 内科 Lecture PDF P28–29  
> **Outline →** 内科 U009｜金标准1  
> **主提示：** 金标准｜影像6｜印戒结构2｜薄壁含义｜（边界：异病同影？）

> **支气管扩张症金标准：HRCT。**

典型影像语言：

- 多发薄壁囊腔：囊状扩张；
- 管壁增厚、平行双轨：柱状扩张 / 双轨征；
- 印戒征：扩张支气管直径超过伴行肺动脉；
- 卷发征；
- 串珠征；
- 蜂窝征；
- 部分囊腔可见液平。

（易混：“蜂窝”不是单一疾病专属；克雷伯肺炎、支扩、ILD均可出现类似描述，必须结合病史、痰、咯血和结构分布。）

（边界：病理强调管壁纤维性增厚；影像学所谓“薄壁囊腔”是相对影像描述，不等于支气管壁没有纤维化。）

# Unit B｜支扩治疗：清痰、止血、抗感染

## KP07｜清除分泌物：让“痰盂”排空，但不能排得过快

> **讲义定位 →** 内科 Lecture PDF P28  
> **Outline →** 内科 U009｜治疗1  
> **主提示：** 稀释2｜体位1｜速度边界｜治疗目标

### 三步

1. 雾化吸入高渗生理盐水；
2. 乙酰半胱氨酸等祛痰；
3. 体位引流：头低、臀部抬高，利用重力排痰。

```text
分泌物变稀
+ 体位帮助引流
→ 扩张气道不再长期储痰
→ 减少阻塞和感染负荷
```

（边界：排痰不宜过快，避免大量分泌物突然进入中央气道造成窒息。）

## KP08｜支扩咯血：先看窒息危险，再看中量药物和大咯血去向

> **讲义定位 →** 内科 Lecture PDF P28  
> **Outline →** 内科 U009｜治疗2  
> **主提示：** 中量2药｜作用方向｜禁忌4｜大咯血2阈值｜弥漫/局限2去向｜首要危险

### 1｜中等量咯血

- 垂体后叶素：大剂量 VP / ADH 收缩血管；
- 酚妥拉明：α受体阻断、扩血管，降低肺血管压力。

当前 Study 边界：

- 垂体后叶素禁用于高血压、冠心病、肾衰、妊娠；
- 酚妥拉明可用于伴高血压或肺心病者。

### 2｜大量咯血

当前 Study 界定：

```text
>500 mL / d
或
>100 mL / 次
```

处理方向：

```text
病变弥漫
→ 支气管动脉栓塞

病变局限
→ 手术切除
```

> 大咯血最先威胁的是气道阻塞与窒息，而不是单纯失血量。

（边界：完整大咯血急救体位、气道与介入操作细则不在本 Block 扩写。）

## KP09｜急性感染：先判有无铜绿假单胞菌高危

> **讲义定位 →** 内科 Lecture PDF P28–29  
> **Outline →** 内科 U009｜治疗3–5  
> **主提示：** 感染3征｜无高危病原1/药物4类｜假单胞高危4｜药物4类｜不能选3

### 1｜何时认为急性感染加重

- 发热；
- 痰量增加；
- 脓性成分增加。

### 2｜无铜绿假单胞菌高危

优先针对流感嗜血杆菌。当前 Study 可选：

- 氨苄西林；
- 阿莫西林；
- 二、三代头孢；
- 呼吸喹诺酮。

### 3｜铜绿假单胞菌高危因素

```text
近期住院
或 FEV1 <30%预计值
或 每年≥4次急性加重 / 近3个月使用抗生素
或 近2周口服泼尼松 >10 mg/d
```

### 4｜抗假单胞菌药物口径

| 类别 | 当前 Study 举例 | 不能机械选 |
|---|---|---|
| 氨基糖苷 | 妥布霉素 | 庆大霉素因毒性不作为此处常规首选 |
| β-内酰胺 | 头孢他啶、头孢哌酮、头孢吡肟、哌拉西林-他唑巴坦 | 头孢曲松不作为本节抗假单胞主药 |
| 喹诺酮 | 环丙沙星、左氧氟沙星 | 诺氟沙星 |
| 碳青霉烯 | 亚胺培南、美罗培南 | 厄他培南 |

（边界：按当前 Study 记忆，不扩成完整抗菌药谱。）

## KP10｜支扩鉴别：COPD、肺结核和慢性肺脓肿

> **主提示：** 共性｜COPD 2差｜TB 2差｜慢脓肿4轴｜痰层数｜壁厚

| 鉴别 | 共同点 | 更支持支扩 | 更支持另一病 |
|---|---|---|---|
| COPD | 长期咳痰、阻塞性表现 | 大量脓痰、咯血、杵状指、固定湿啰音 | COPD多无明显咯血和杵状指 |
| 肺结核 | 咯血 | 大量脓痰；无感染时可不发热，急性感染时高热 | 长期低热、盗汗、上肺病灶 |
| 慢性肺脓肿 | 长期大量脓痰、咯血、杵状指 | 痰分4层；薄壁囊腔 | 痰分3层；厚壁空洞 |

（边界：当前 Study 只提供痰分层数量，没有在此正式展开每层内容，不自行补造。）

# Unit C｜肺脓肿：肺实质化脓坏死后形成脓腔

## KP11｜肺脓肿三型：入口决定病原、位置和检查

> **讲义定位 →** 内科 Lecture PDF P31  
> **Outline →** 内科 U010｜三型总览  
> **主提示：** 三型｜最常见｜病原主轴｜单/多｜中心/外周｜检查入口

| 类型 | 主要入口 | 常见病原 / 形态 | 位置与数量 |
|---|---|---|---|
| 吸入性 | 误吸口鼻分泌物 | 厌氧菌为主 | 右肺多，通常单发，体位决定肺段 |
| 血源性 | 菌栓经肺动脉 | 金葡菌 | 双肺外周多发空洞 / 液气囊腔 |
| 继发性 | 既有肺病、阻塞或邻近感染 | 随原发病变化 | 与原病灶相邻或阻塞远端 |

共同主链：

```text
化脓性炎
→ 肺实质坏死、液化
→ 坏死物经支气管排出
→ 空腔内进入空气
→ 形成液气平
```

## KP12｜吸入性肺脓肿位置：右主支气管 + 重力 + 体位

> **讲义定位 →** 内科 Lecture PDF P31、P39  
> **Outline →** 内科 U010｜吸入性4；U013｜好发部位3  
> **主提示：** 右肺原因｜仰卧2段｜坐位1段｜右侧卧2段｜误吸病史6

### 为什么右肺多见

右主支气管更粗、短、陡，误吸物更易进入右肺。

### 体位决定沉积部位

| 误吸体位 | 好发肺段 |
|---|---|
| 仰卧位 | 上叶后段或下叶背段 |
| 坐位 | 下叶后基底段 |
| 右侧卧位 | 右上叶前段或后段 |

### 高危误吸背景

- 醉酒；
- 脑卒中；
- 昏迷；
- 麻醉；
- 癫痫；
- 药物过量；
- 鼻窦炎、牙槽脓肿等口鼻感染源。

（易混：R5 小叶性肺炎也偏下叶背侧；必须结合“误吸病史—脓臭痰—液气平空洞”的完整链。）

## KP13｜吸入性肺脓肿：厌氧菌、脓臭痰、液气平与6–8周影像终点

> **讲义定位 →** 内科 Lecture PDF P31–32  
> **Outline →** 内科 U010｜吸入性1–5  
> **主提示：** 病原｜症状4｜影像2期｜治疗2层｜疗程｜停药终点｜（特殊：脆弱拟杆菌？）

### 1｜病例入口

```text
误吸风险
+ 高热
+ 大量脓臭痰
+ 可咯血
+ 排出大量脓痰后体温可下降
```

### 2｜影像时相

```text
早期
→ 大片、边缘不清的浓密模糊浸润影

坏死物经支气管排出后
→ 出现空洞与液气平
```

所以早期尚无空洞，不能据此排除肺脓肿。

### 3｜治疗口径

- 多数厌氧菌：青霉素；
- 脆弱拟杆菌：甲硝唑 + 林可霉素类；
- 疗程通常6–8周。

停药看影像，而不是只看退热或痰臭消失：

```text
空洞周围炎症吸收
→ 空洞缩小、消失
→ 最后仅余少量纤维条索影
→ 停药
```

## KP14｜血源性肺脓肿：金葡菌菌栓停在双肺外周小血管

> **讲义定位 →** 内科 Lecture PDF P31  
> **Outline →** 内科 U010｜血源性1–2  
> **主提示：** 病原｜原发灶5｜路径链｜部位/数量｜痰方向｜检查｜治疗

### 1｜常见病原与原发灶

- 金黄色葡萄球菌多见；
- 皮肤外伤、疖、痈；
- 骨髓炎；
- 右心感染性心内膜炎等。

### 2｜路径

```text
原发化脓灶
→ 细菌进入静脉形成菌栓
→ 右心
→ 肺动脉
→ 栓塞双肺外周小血管
→ 多发化脓坏死和空洞 / 液气囊腔
```

与吸入性相比：

- 双肺外周；
- 多发；
- 原发灶与全身毒血症可更突出；
- 呼吸道脓痰可相对不典型。

### 3｜检查与治疗

- 血培养；
- 苯唑西林或头孢呋辛。

//串联：与金葡菌肺炎属于同一感染谱的不同阶段；R5已学其多发易变空洞。

## KP15｜继发性肺脓肿：先找到持续存在的感染源或阻塞

> **讲义定位 →** 内科 Lecture PDF P31  
> **Outline →** 内科 U010｜继发性1  
> **主提示：** 来源4类｜坏死性肺炎3菌｜既有病3｜异物人群｜邻近灶1

继发性肺脓肿常见于：

1. 坏死性肺炎：金葡菌、克雷伯杆菌、铜绿假单胞菌等；
2. 既有肺病继发感染：支扩、肺癌、肺结核；
3. 支气管异物阻塞，尤其小儿；
4. 邻近病灶直接累及，如阿米巴肝脓肿侵犯右下肺。

治疗不能只重复抗菌：

```text
若异物 / 肿瘤 / 阻塞仍在
→ 引流不畅
→ 感染源持续
→ 脓腔难以消失
```

因此必须同时处理原发病和引流障碍。

## KP16｜空腔鉴别与病例算法：先问“气道扩了”还是“肺实质坏了”

> **讲义回看 →** R5、R6全 Block；R7/R11后续  
> **Outline →** 内科 U009–U010综合  
> **主提示：** 壁厚｜数量｜液平｜痰｜热型｜部位｜卫星灶｜来源

### 1｜四类空腔入口

| 模型 | 核心结构 | 常见影像 / 临床 |
|---|---|---|
| 支扩囊腔 | 扩张支气管，管壁纤维化 | 多发薄壁囊腔、印戒/双轨；长期大量脓痰、咯血 |
| 肺脓肿 | 肺实质化脓坏死 | 厚壁空洞、液气平；高热、脓臭痰 |
| 结核空洞 | 干酪样坏死排出 | 无壁/薄壁/厚壁按病型；低热盗汗、上肺；R7完整学习 |
| 癌性空洞 | 肿瘤坏死 | 肿块背景、壁不规则等完整模型后置R11 |

### 2｜病例五步

```text
Step 1：病程
急性高热还是多年反复？

Step 2：分泌物
大量脓痰、脓臭痰、干性咯血还是痰少？

Step 3：病史
百日咳/TB、误吸、皮肤化脓灶、异物/肿瘤？

Step 4：影像
薄壁多发支气管囊腔、单发液平脓腔、双肺外周多发空洞？

Step 5：治疗目标
清痰、止血、抗菌、支气管动脉栓塞、解除阻塞或引流？
```

## 3｜高密度比较表

| 轴 | 支气管扩张症 | 吸入性肺脓肿 | 血源性肺脓肿 |
|---|---|---|---|
| 主故障层 | 支气管壁支撑结构破坏、永久扩张 | 吸入病原致肺实质化脓坏死 | 菌栓致双肺外周化脓坏死 |
