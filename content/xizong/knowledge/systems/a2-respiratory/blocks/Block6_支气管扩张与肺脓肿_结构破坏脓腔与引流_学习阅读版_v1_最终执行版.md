## 0｜这个 Block 到底解决什么

大量脓痰、咯血和空腔影可来自不同故障层。支气管扩张症是气道管壁支撑损伤后，牵拉与跨壁压促进持久扩张及纤维性修复；扩张的气道仍可因痰液潴留而阻塞，感染又进一步损伤管壁。肺脓肿则是肺实质化脓坏死、液化后，坏死物经支气管排出形成脓腔；空气与残液同存时才可见液气平，早期尚无空洞也不排除。

这两支不构成必经先后。误吸和血源性肺脓肿各有独立入口；支扩只有在继发感染等条件下才可桥接继发性肺脓肿。结构位置、引流条件和感染入口共同解释痰、咯血、数量、分布及影像，再决定抗感染、清除分泌物或脓液、控制持续来源与处理气道危险。

### 本 Block 的总任务

> **面对脓痰、咯血或空腔影，能定位扩张气道与坏死肺实质，恢复储痰—感染—再损伤的反馈或脓腔的进入—坏死—引流关系，并按当前气道危险、病原和持续源选择处理方向。**

## 1｜总 Framework

**气道结构支。** 感染、免疫/清除障碍、阻塞等诱因 → 分泌物难清、感染反复或管壁易损。管壁支撑破坏是核心基础，周围纤维牵拉与咳嗽跨壁压进一步促进扩张 → 持久扩张与纤维性修复。扩张后储痰 → 气流受阻、感染反复 → 管壁再损伤，形成反馈。阻塞既可位于诱因端，也可由扩张后的痰液潴留产生。

**肺实质脓腔支。** 误吸口鼻分泌物、血源菌栓、既有肺病/阻塞或邻近感染是三个并行入口，改变病原、位置与检查选择；它们汇入化脓性坏死 → 液化 → 坏死物经支气管排出 → 脓腔进入空气。气液同存才可有液气平，早期可只有浸润。支扩继发感染属于第三入口的条件桥，不是全部肺脓肿的上游。

**观察回到结构与来源。** HRCT观察气道相对伴行血管的扩大、分布和形态；空洞壁、数量、液平、痰、热型、部位、卫星灶与原发源共同分辨病因。纤维牵拉性扩张、末梢肺气肿、结核或肿瘤空洞分别回各自模型，不能只靠“有洞”或“蜂窝”定病。

**干预切断反馈或持续源。** 清除分泌物改善储痰与引流；感染加重按病原和铜绿假单胞菌风险选择抗菌；脓腔还要追持续阻塞与原发感染源，并按综合临床、炎症和影像反应调整疗程。咯血若威胁气道，先处理窒息与循环危险，不能等待课程血量阈值；普通体位引流也须重新评估气道保护和正在出血的条件。

```text
【支撑受损的气道，与弹性受损的末梢肺组织】

段/小支气管依靠软骨、平滑肌和弹力纤维等支撑；管壁支撑破坏可形成持久气道扩张。终末/一级呼吸性细支气管本无软骨，损伤修复可使小气道纤维化狭窄；肺气肿的末梢肺组织弹性框架破坏则使回缩与对小气道牵拉下降，呼气更易受限。两者故障层和力学结果不同，完整肺气肿回R3 KP03。支扩广泛周围纤维化还可增加限制性成分，并可并发肺心病，完整肺循环/右心负荷回R9。

〈支扩 vs 肺气肿：都是弹性结构损伤，但层级和结果相反〔层级2｜结构破坏｜弹性位置/方向｜支撑变化｜阻塞身份｜肺心病〕〉

反复感染、免疫异常、气道阻塞或清除功能缺陷等，使分泌物难清、感染反复或管壁易受损。α₁-抗胰蛋白酶缺乏、黄甲综合征、纤毛相关疾病等特殊入口继续保留。诱因回答损伤从何而来，管壁支撑破坏回答扩张赖以形成的病理基础；气道阻塞可在诱因端参与，不能取代核心结构损伤。

〈支扩诱发因素：反复感染是主轴，阻塞是诱因而非核心病理基础〔诱因7项/最常见｜诱因vs病理基础｜特殊3组〕〉

管壁支撑被破坏后，周围肺组织纤维牵拉与咳嗽引起的跨壁压升高共同促进扩张；修复留下课程定义所要求的持久扩张和管壁纤维性增厚。扩张后形成储痰空间 → 分泌物潴留与气流受阻 → 感染反复 → 管壁进一步损伤。纤维牵拉可参与这条链，但单有ILD牵拉性气道变宽不自动成立支扩症，完整区别回R8 KP06。

〈支扩身份与三股扩张力：支撑先坏，牵拉和压力再把它拉开〔定义2件｜病因主轴｜扩张力3/关键1｜修复结局｜牵拉性扩张边界〕〉

支气管走行和引流条件改变哪一处更易积痰。普通支扩常见于引流较差的下叶等部位；课程干性支扩常与上叶尖后段的结核背景、较好引流相关，可少痰而反复咯血。位置解释症状差别，结核的完整感染/空洞模型仍回R7。

〈好发部位与干性支扩：哪里更容易积痰，哪里反而自带引流〔普通vs干性部位｜引流条件→痰/咯血｜TB接口〕〉

潴留分泌物解释大量脓痰与固定、持久湿啰音；炎症及支气管动脉相关病变解释反复咯血。干性支扩痰少并不消除出血风险。血块可堵塞气道，外见血量减少不等于危险下降；贫血、高排血量或心脏结构改变引出的杂音须按原条件判断。杵状指是长期病变的观察线索，其完整疾病名单留原Core/MI-D。

〈临床表现：痰盂、固定湿啰音、咯血和杵状指〔症状4｜啰音2｜咯血3点｜干性1｜杵状指｜杂音链｜咯血量/严重度边界〕〉

HRCT读取的首先是扩张气道及其分布：印戒征比较支气管与伴行肺动脉，双轨、囊状/柱状/串珠及液平反映不同形态。影像“薄壁”是相对形态，并不否认管壁纤维性修复；蜂窝样影可由不同结构组成，必须连同病史和真实空间区分。

〈HRCT：看见的是扩张气道，而不是只看一张“蜂窝图”〔HRCT｜影像6型/液平｜印戒2结构｜薄壁vs纤维化｜同影异病〕〉

【清除分泌物与控制感染回作用于反馈，出血另按危险处理】

稀释分泌物及合适的清除方式 → 减少储痰、改善引流，试图削弱储痰—感染反馈。盐水、NAC、体位等选择合看气道反应、病变肺段、耐受以及反流/误吸风险，排出也不宜过快。正在咯血或不能保护气道时，须重新评估方式，不能强行套用普通体位引流。

〈清除分泌物：让“痰盂”排空，但不能排得过快〔稀释2｜体位1｜速度边界｜治疗目标〕〉

痰量、脓性、发热等变化提示感染加重，抗菌处理需结合既有病原和铜绿假单胞菌高危条件。当前四组风险、药物组及排除/非首选项由原Core恢复，不能因一种药被列出便当作所有支扩感染的通用处方。控制感染回作用于管壁损伤，持续阻塞和引流障碍也要寻找并处理。

〈急性感染：先判有无铜绿假单胞菌高危〔感染3征｜无高危：病原/选药4组｜假单胞高危4组｜选药4组｜排除项3/非首选1〕〉

咯血危险由气道是否被堵、氧合与循环状态共同决定。课程日量/单次数值用于恢复量级，不是窒息风险或启动救治的必要条件。先保护气道、稳定循环，再合并相应止血与介入评估。课程中量药物中，垂体后叶素经VP/ADH收缩血管，酚妥拉明经α受体阻断扩血管、降低肺血管压力，作用方向和适用/禁忌条件不同。持续显著出血可考虑支气管动脉栓塞，局限病变也可栓塞；手术还需可切除性、肺储备、病因及其他止血措施成败等条件。

〈支扩咯血：先看窒息危险，再看中量药物和大咯血去向〔中量2药｜禁忌4｜大量2阈值｜气道优先｜栓塞/手术条件〕〉

【肺实质化脓坏死：三个独立入口汇入脓腔形成】

肺脓肿的吸入性、血源性和继发性入口各自决定最先追问的病原、位置与证据。共同过程为化脓性炎 → 肺实质坏死、液化 → 坏死物经支气管排出 → 空腔进入空气；同时残留气体和液体时可形成液气平。脓腔形成需要相应病程，早期无洞不能排除。

〈肺脓肿三型：入口决定病原、位置和检查〔三型｜最常见｜病原主轴｜单/多｜中心/外周｜检查入口〕〉

吸入性入口由口鼻感染源、意识/吞咽等误吸背景连接气道。右主支气管粗、短、陡使右侧更常受累，具体肺段还受误吸当时重力与体位影响：课程仰卧、坐位、右侧卧各自对应原肺段，不能把“右肺”替代这些条件。通常单发的分布也要与其他入口比较。

〈吸入性肺脓肿位置：右主支气管 + 重力 + 体位〔侧别解剖｜体位3：肺段2/1/2｜误吸背景6｜口鼻感染源〕〉

误吸相关厌氧感染可出现高热、脓臭痰，坏死物排出后体温可下降；早期影像可能只有浸润，后续才出现空洞/液气平。抗感染需同时保留课程药物与耐药、混合感染、药敏边界，脆弱拟杆菌并非一律固定双药。临床停药综合临床、炎症和影像反应；课程6–8周及空洞周围炎症吸收、脓腔缩小/消退的影像过程，不能缩成所有病例固定周数或单看退热的规则。

〈吸入性肺脓肿：厌氧菌、脓臭痰、液气平与6–8周影像终点〔病原｜症状4｜影像2期｜治疗2层｜疗程/停药终点｜脆弱拟杆菌特殊〕〉

血源性入口中，皮肤、骨等来源的病原/菌栓经静脉到右心，再进入肺动脉；右心感染性心内膜炎的赘生物脱落则从右心直接进入肺动脉。菌栓停留于双肺外周小血管，形成多发病灶，因此取证优先追血培养和原发灶。常见金葡菌须区分MSSA/MRSA条件，菌血症还须复查血培养、查心内膜炎及远处灶并控源；药物/疗程合并这些病情，不能套普通肺炎短疗程。

〈血源性肺脓肿：金葡菌菌栓停在双肺外周小血管〔病原｜原发灶5｜路径链｜部位/数量｜痰方向｜检查｜治疗〕〉

继发性入口来自坏死性肺炎、支扩/肿瘤/结核继发感染、异物造成的阻塞，或邻近感染如肝脓肿累及肺。它是气道支与脓腔支之间的条件桥：已有支扩或阻塞可能持续储留感染物，但并不解释所有误吸或血源性脓肿。治疗要追具体病原、解除持续阻塞和引流障碍、控制原发源。

〈继发性肺脓肿：先找到持续存在的感染源或阻塞〔来源4类｜坏死性肺炎3菌｜既有病3｜异物人群｜邻近灶1〕〉

【痰与空腔的相似外观，要回到病变层级和来源】

支扩、COPD、结核和慢性肺脓肿可共享咳痰、气短或影像异常。持续/可变病程、痰、热型、好发位置和壁的特点共同分流；末梢弹性破坏、结核干酪坏死或坏死脓腔各有自己的上游。原“痰4层/3层”只保留当前课程记忆范围，不补造未给出的层内容。

面对空腔，同时看壁厚、数量、液平、痰、热型、部位、卫星灶与来源，确认是气道扩大还是肺实质破坏。典型形态只提供证据权重，不能因无液平或早期无洞排除肺脓肿。结核薄壁/无壁/厚壁空洞回R7 KP09–10，癌性空洞回R11 KP17；慢性肺循环阻力与右心负荷回R9 KP01，脓胸另回R10。
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 支扩定义必须同时包含**持久性扩张 + 管壁纤维性增厚**；
2. 支扩三机制：支撑结构破坏、周围纤维牵拉、跨壁压升高；第一项最关键；
3. 支扩发生在段 / 小支气管，肺气肿主要累及末梢肺组织；
4. “支气管扩张”不等于气道阻力下降：脓痰潴留可造成阻塞；
5. 阻塞可为支扩诱因，也可由扩张后痰液潴留产生；核心病理基础仍是管壁支撑结构破坏；
6. 支扩典型：长期大量脓痰、固定持久湿啰音、咯血、杵状指；干性支扩可仅反复咯血；
7. HRCT 是支扩金标准，印戒征 / 双轨征 / 薄壁囊腔是关键影像语言；
8. 大咯血危险首先是窒息，不以外观看到的血量机械判断病情；
9. 支扩急性感染先判断有无铜绿假单胞菌高危因素；
10. 肺脓肿三型：吸入性、血源性、继发性；吸入性最常见；
11. 吸入性肺脓肿：厌氧菌、误吸、右肺、体位决定肺段；
12. 血源性肺脓肿：金葡菌、双肺外周多发、血培养；
13. 肺脓肿停药须综合临床、炎症与影像反应，不能只看退热、痰臭消失或固定周数；
14. 薄壁囊腔、厚壁脓腔、结核空洞和癌性空洞不能只靠“有洞”鉴别。

## KP01｜支扩身份与三股扩张力：支撑先坏，牵拉和压力再把它拉开

> **主提示：** 定义2件｜病因主轴｜扩张力3/关键1｜修复结局｜牵拉性扩张边界

### 1｜定义

> **支气管管腔持久性扩张，并伴管壁纤维性增厚的慢性疾病。**

只看到影像上支气管变宽，不足以自动等同支气管扩张症；当前 Study 强调管壁结构破坏后的纤维性修复。

### 2｜最重要的病因背景

- 支气管肺炎，尤其麻疹、百日咳后，最主要；
- 慢支炎；
- 肺结核；
- 其他反复化脓感染。

### 3｜三股力量

```text
① 慢性化脓性炎
→ 破坏弹力纤维、平滑肌、软骨
→ 支气管失去支撑结构（最关键）

② 周围肺组织慢性炎症与纤维化
→ 胶原纤维收缩
→ 从外侧牵拉支气管

③ 反复咳嗽
→ 管腔内压升高
→ 跨壁压升高
→ 从内侧撑大管腔
```

最终：

```text
持久扩张
+ 管壁肉芽组织修复、纤维性增厚
```

（边界：特发性肺纤维化可因间质胶原收缩出现牵拉性支气管扩张，但若支气管壁未被破坏，不按本节支气管扩张症模型解释；完整 ILD 后置 R8。）

## KP02｜支扩 vs 肺气肿：都是弹性结构损伤，但层级和结果相反

> **讲义定位 →** 病理 Lecture PDF P69；回看 R3  
> **Outline →** 病理 U001｜支扩5–6及比较串  
> **主提示：** 层级2｜结构破坏｜弹性位置/方向｜支撑变化｜阻塞身份｜肺心病

| 轴 | 支气管扩张症 | 肺气肿（腺泡中央型） |
|---|---|---|
| 主要层级 | 段 / 小支气管，传导区 | 终末细支气管、一级呼吸性细支气管及末梢肺组织 |
| 关键结构 | 弹力纤维、平滑肌、软骨等管壁支撑 | 小气道壁与肺泡间隔弹性框架 |
| 失去支撑后 | 有软骨支撑的较大气道被撑大 → 永久扩张 | 小气道纤维化、狭窄；肺泡端过度扩张 |
| 阻塞的角色 | 可为上游诱因，也可为扩张后潴痰的结果；管壁支撑破坏仍是核心基础 | 小气道病变、弹性回缩下降等共同促成气流受限 |
| 弹性下降位置 | 段 / 小支气管 | 末梢肺组织、肺泡间隔 |
| 慢支关系 | 可为病因，但最主要病因是支气管肺炎 | 常见且重要病因 |
| 肺心病 | 可因广泛炎症纤维化并发 | 常见并发 |

### “大的越大，小的越小”

```text
段 / 小支气管有软骨支撑
→ 支撑破坏后容易扩张

终末与一级呼吸性细支气管本无软骨
→ 破坏修复后更易纤维化狭窄
```

（易混：支扩虽“管腔扩张”，仍可因大量痰液阻塞表现为阻塞性通气障碍；内科 Lecture 还提示广泛周围纤维化时可出现限制性成分，不能只凭一个字母给整个患者定性。）

## KP03｜支扩诱发因素：反复感染是主轴，阻塞是诱因而非核心病理基础

> **讲义定位 →** 内科 P27｜PDF P33  
> **Outline →** 内科 U009｜诱发因素1  
> **主提示：** 诱因7项/最常见｜诱因vs病理基础｜特殊3组

当前 Study 列举：

- 感染；
- 免疫异常，如白血病、风湿系统疾病、炎症性肠病；
- 气道阻塞；
- α₁-抗胰蛋白酶缺乏；
- 黄甲综合征；
- 原发性纤毛不动征 PCD；
- Kartagener征。

判断层级：

```text
诱发因素
→ 使分泌物难清、感染反复或管壁易受损

核心病理基础
→ 管壁支撑结构破坏
```

所以“气道阻塞”可诱发支扩，但不能取代“管壁结构破坏”成为最主要病变基础。

## KP04｜好发部位与干性支扩：哪里更容易积痰，哪里反而自带引流

> **讲义定位 →** 内科 P27｜PDF P33；内科 P39｜PDF P47  
> **Outline →** 内科 U009｜好发部位1；U013｜好发部位2  
> **主提示：** 普通vs干性部位｜引流条件→痰/咯血｜TB接口

### 普通支扩

> **左肺下叶多见。**

Study解释：

- 下叶受重力影响，分泌物不易排出；
- 左侧受心脏等解剖关系影响，痰液更不易清除；
- 右主支气管粗、短、陡，虽更易误吸，也相对更易咳出。

### 干性支扩

> **上叶尖后段多见，常与肺结核有关。**

```text
病变位置较高
→ 支气管形成相对自然引流
→ 脓痰不易大量潴留
→ 可仅以反复咯血为主要表现
```

//串联：继发性肺结核上叶尖后段模型在 R7 完整学习。

## KP05｜临床表现：痰盂、固定湿啰音、咯血和杵状指

> **讲义定位 →** 内科 P27–28｜PDF P33–34  
> **Outline →** 内科 U009｜临床表现1–2  
> **主提示：** 症状4｜啰音2｜咯血3点｜干性1｜杵状指｜杂音链｜咯血量/严重度边界

### 1｜大量脓痰与固定湿啰音

```text
扩张气道内长期积聚脓痰
→ 像“痰盂”
→ 长期咳嗽、大量脓痰
→ 气流通过液体形成固定、持久湿啰音
```

痰液也可造成狭窄，出现干啰音。

### 2｜咯血

- 约50%–70%可咯血；
- 管壁破坏可累及支气管动脉；
- 咯血量与疾病严重程度不完全相关；
- 干性支扩可仅反复咯血。

> 血块堵住气道时，外面看到的血量可减少，但窒息风险并未下降。

### 3｜杵状指与其他接口

- 支扩可有杵状指；
- 长期咯血可致贫血；
- 严重、持续贫血可造成高动力循环，出现功能性收缩期杂音；讲义进一步串联左心扩大、相对性二尖瓣关闭不全。后者需要相应心脏结构证据，不能从“支扩＋杂音”直接推定二闭。

### 4｜杵状指 MI-D

当前 Study 串联：肝硬化、系统性硬化症、支扩、ILD、亚急性感染性心内膜炎、炎症性肠病、慢性肺脓肿、慢性脓胸、梅毒、法洛四联症、肺癌。

## KP06｜HRCT：看见的是扩张气道，而不是只看一张“蜂窝图”

# Unit B｜支扩治疗：清痰、止血、抗感染

## KP07｜清除分泌物：让“痰盂”排空，但不能排得过快

> **讲义定位 →** 内科 P28｜PDF P34  
> **Outline →** 内科 U009｜治疗1  
> **主提示：** 稀释2｜体位1｜速度边界｜治疗目标

### 三步

1. 雾化吸入高渗生理盐水；
2. 乙酰半胱氨酸等祛痰；
3. 体位引流：讲义为头低、臀部抬高；实际按受累肺段、耐受性和反流/误吸风险选择，可采用不头低的改良体位，不是所有人统一倒置。

```text
分泌物变稀
+ 体位帮助引流
→ 扩张气道不再长期储痰
→ 减少阻塞和感染负荷
```

排痰不宜过快。吸入高渗盐水等黏液活性治疗前需评估气道反应，易支气管痉挛者考虑先用支气管舒张剂；正在咯血或不能有效保护气道时，应重新评估清除方式，不能强行套用普通体位引流。

## KP08｜支扩咯血：先看窒息危险，再看中量药物和大咯血去向

> **讲义定位 →** 内科 P28｜PDF P34  
> **Outline →** 内科 U009｜治疗2  
> **主提示：** 中量2药｜禁忌4｜大量2阈值｜气道优先｜栓塞/手术条件

### 1｜中等量咯血

- 垂体后叶素：大剂量 VP / ADH 收缩血管；
- 酚妥拉明：α受体阻断、扩血管，降低肺血管压力。

当前 Study 边界：

- 垂体后叶素禁用于高血压、冠心病、肾衰、妊娠；
- 酚妥拉明可用于伴高血压或肺心病者。

### 2｜大量咯血

当前 Study 界定：

```text
>500 mL / d
或
>100 mL / 次
```

讲义的处理分支：

```text
病变弥漫
→ 支气管动脉栓塞

病变局限
→ 手术切除
```

> 大咯血最先威胁的是气道阻塞与窒息；少于上述量也可能危及生命，不能等到计量达标才处理。

上述“弥漫→栓塞、局限→手术”是课程简化分支。现代处理先保护气道和稳定循环，持续显著咯血常优先考虑支气管动脉栓塞，局限病变同样可以栓塞；手术须综合可切除性、肺储备、病因及其他止血措施成败，不能仅凭“局限”决定。药物止血不能延误气道及介入评估。

（边界：完整大咯血急救体位、气道与介入操作细则不在本 Block 扩写。）

## KP13｜吸入性肺脓肿：厌氧菌、脓臭痰、液气平与6–8周影像终点

> **讲义定位 →** 内科 P31–32｜PDF P38–39  
> **Outline →** 内科 U010｜吸入性1–5  
> **主提示：** 病原｜症状4｜影像2期｜治疗2层｜疗程/停药终点｜脆弱拟杆菌特殊

### 1｜病例入口

```text
误吸风险
+ 高热
+ 大量脓臭痰
+ 可咯血
+ 排出大量脓痰后体温可下降
```

### 2｜影像时相

```text
早期
→ 大片、边缘不清的浓密模糊浸润影

坏死物经支气管排出后
→ 出现空洞与液气平
```

所以早期尚无空洞，不能据此排除肺脓肿。

### 3｜治疗口径

以下为讲义考试用药表，不能脱离耐药、混合感染和药敏直接当作通用处方：

- 多数厌氧菌：讲义列青霉素；
- 脆弱拟杆菌：甲硝唑 + 林可霉素类；
- 讲义疗程通常6–8周。

临床边界：已有随机研究证明青霉素耐药可造成厌氧肺感染治疗失败；含β-内酰胺酶抑制剂的方案（如氨苄西林/舒巴坦）也有临床研究支持。脆弱拟杆菌不等于一律固定双药；需结合感染来源、混合菌与敏感性选择。这里只纠正“见菌名就固定处方”，不把历史试验升级为2026统一首选。

停药综合临床、炎症与影像反应，而不是只看退热或痰臭消失；6–8周不是每个病例的固定终点。讲义影像终点：

```text
空洞周围炎症吸收
→ 空洞缩小、消失
→ 最后仅余少量纤维条索影
→ 停药
```

### 2｜路径

```text
                                  肺动脉
                                    ↓
                             双肺外周小血管菌栓
                                    ↓
                      多发化脓坏死和空洞 / 液气囊腔
```

与吸入性相比：

- 双肺外周；
- 多发；
- 原发灶与全身毒血症可更突出；
- 呼吸道脓痰可相对不典型。

### 3｜检查与治疗

- 血培养；
- 讲义列苯唑西林或头孢呋辛，须先区分MSSA与MRSA；这些药不能覆盖MRSA。
- 菌血症背景还需复查血培养、寻找心内膜炎和远处感染灶，并控制原发灶；不能把一个肺部影像诊断等同于完整病因评估。MRSA需专门抗MRSA方案，疗程与药物结合菌血症/心内膜炎及肺部感染确定，不直接套普通肺炎短疗程。

//串联：与金葡菌肺炎属于同一感染谱的不同阶段；R5已学其多发易变空洞。

## KP15｜继发性肺脓肿：先找到持续存在的感染源或阻塞

> **讲义定位 →** 内科 P31｜PDF P38  
> **Outline →** 内科 U010｜继发性1  
> **主提示：** 来源4类｜坏死性肺炎3菌｜既有病3｜异物人群｜邻近灶1

继发性肺脓肿常见于：

1. 坏死性肺炎：金葡菌、克雷伯杆菌、铜绿假单胞菌等；
2. 既有肺病继发感染：支扩、肺癌、肺结核；
3. 支气管异物阻塞，尤其小儿；
4. 邻近病灶直接累及，如阿米巴肝脓肿侵犯右下肺。

治疗不能只重复抗菌：

```text
若异物 / 肿瘤 / 阻塞仍在
→ 引流不畅
→ 感染源持续
→ 脓腔难以消失
```

因此必须同时处理原发病和引流障碍。

## KP16｜空腔鉴别与病例算法：先问“气道扩了”还是“肺实质坏了”

> **讲义回看 →** R5、R6全 Block；R7/R11后续  
> **Outline →** 内科 U009–U010综合  
> **主提示：** 壁厚｜数量｜液平｜痰｜热型｜部位｜卫星灶｜来源

### 1｜四类空腔入口

| 模型 | 核心结构 | 常见影像 / 临床 |
|---|---|---|
| 支扩囊腔 | 扩张支气管，管壁纤维化 | 多发薄壁囊腔、印戒/双轨；长期大量脓痰、咯血 |
| 肺脓肿 | 肺实质化脓坏死 | 厚壁空洞、液气平；高热、脓臭痰 |
| 结核空洞 | 干酪样坏死排出 | 无壁/薄壁/厚壁按病型；低热盗汗、上肺；R7完整学习 |
| 癌性空洞 | 肿瘤坏死 | 肿块背景、壁不规则等完整模型后置R11 |

上述均为典型线索，壁厚、数量、液平和部位存在交叉，不能用单一影像特征排除或确诊；早期肺脓肿尚未形成空洞也不能排除。

### 2｜病例五步

```text
Step 1：病程
急性高热还是多年反复？

Step 2：分泌物
大量脓痰、脓臭痰、干性咯血还是痰少？

Step 3：病史
百日咳/TB、误吸、皮肤化脓灶、异物/肿瘤？

Step 4：影像
薄壁多发支气管囊腔、单发液平脓腔、双肺外周多发空洞？

Step 5：治疗目标
清痰、止血、抗菌、支气管动脉栓塞、解除阻塞或引流？
```

| 轴 | 支气管扩张症 | 吸入性肺脓肿 | 血源性肺脓肿 |
