## 0｜这个 Block 到底解决什么

呼吸系统的最终失败不是统一的一种病，而是两项核心功能失控：

```text
氧合失败
空气到了肺泡，但不能有效进入动脉血
→ PaO₂下降为主
→ Ⅰ型呼衰入口

通气失败
空气不能有效进出肺泡，CO₂排不出去
→ PaCO₂升高
→ Ⅱ型呼衰入口
```

ARDS是氧合失败中的典型危重模型：

```text
全身或肺部严重炎症 / 损伤
→ 肺毛细血管内皮 + 肺泡上皮受损
→ 高通透性非心源性肺水肿
+ 表面活性物质下降、肺泡塌陷
→ 肺内分流、顺应性下降、严重VA/Q失调
→ 高浓度氧也难纠正的低氧
```

### 本 Block 的总任务

> **面对顽固低氧、PaCO₂升高、意识改变或双肺弥漫影时，能先判断氧合失败还是通气失败，再识别ARDS、Ⅰ / Ⅱ型呼衰、心源性肺水肿和通气支持门槛。**

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 呼吸窘迫是快、深、费力；ARDS早期过度通气可出现 PaCO₂下降和呼吸性碱中毒。
2. ARDS常在高危事件后1周内、尤其72小时内出现进行性呼吸困难与顽固低氧。
3. ARDS核心是**肺毛细血管内皮 + 肺泡上皮**两种细胞损伤。
4. 内皮损伤→高通透性非心源性肺水肿；II型肺泡上皮损伤→表活下降、肺泡塌陷。
5. ARDS是限制性通气入口 + 换气 / 分流失败；顺应性下降、肺内分流是低氧核心。
6. PaO₂ / FiO₂≤300是当前 Study必要氧合条件；200 / 100分轻中重。
7. 鉴别心源性肺水肿首选心脏超声；PAWP<18支持ARDS，但>18不能排除并存。
8. PEEP的任务是复张肺泡、增加呼气末肺容量、减少分流和反复开闭。
9. 肺保护：小潮气量4–8 mL/kg、平台压≤30 cmH₂O、允许一定高碳酸血症。
10. 俯卧位使背侧重力依赖区肺泡复张，减少功能性分流。
11. Ⅰ型：PaO₂<60且PaCO₂正常 / 低；Ⅱ型：PaCO₂>50，伴或不伴低氧。
12. 慢性Ⅱ型COPD强调低浓度氧；严重急性哮喘虽是Ⅱ型，不套用同一低氧逻辑。
13. 呼吸兴奋剂只适合“中枢可被兴奋、传出和呼吸肌仍能执行、气道通畅”的通气障碍。
14. 只有慢性Ⅱ型呼衰有肾HCO₃⁻代偿；急性Ⅱ型来不及。
15. 慢性Ⅱ型呼衰pH升高常是医源性：补碱、过度利尿、过度通气、补KCl不足。
16. 机械通气升高胸内压可使回心、CO和血压下降；不能只盯血气。

### MI-D｜定位后进入卡片流

- ARDS危险因素完整名单与时间窗；
- FiO₂估算公式、P/F分级数字；
- PAWP阈值与影像时相；
- PEEP起始 / 适用范围与全部不良反应；
- 小潮气量、平台压、允许性高碳酸血症数字；
- 呼吸兴奋剂药名；
- 机械通气全部并发症；
- pH、PaCO₂、BE、HCO₃⁻、K⁺、AB / SB完整数字表；
- 补碱阈值及利尿剂使用边界。

## KP03｜ARDS核心：内皮与肺泡上皮两种细胞同时失守

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** 2细胞｜通透性｜表活｜水肿/不张｜限制+分流

### 1｜肺毛细血管内皮

损伤后：

```text
通透性↑
→ 液体、蛋白、纤维蛋白、细胞成分渗出
→ 肺间质和肺泡水肿
```

### 2｜肺泡上皮

尤其II型肺泡上皮损伤：

```text
表面活性物质↓
→ 表面张力↑
→ 肺泡 / 小气道萎陷、不张
```

### 3｜共同后果

- 肺容积下降；
- 顺应性下降；
- 限制性通气障碍入口；
- 弥散距离增加；
- 肺内分流与严重VA/Q失调；
- 顽固性低氧。

## KP04｜高通透性肺水肿与透明膜：呼吸膜先变厚，肺泡再失去有效面积

> **讲义定位 →** 内科 Lecture P54；回看R5病毒性肺炎  
> **Outline →** 内科 U021｜核心机制1；病理DAD只Recall  
> **主提示：** 内皮渗漏｜非心源性｜透明膜｜厚度/面积2轴｜湿肺

### 1｜非心源性肺水肿

ARDS的液体进入肺泡，起点是屏障通透性增加，而不是左房 / 肺静脉压力先升高。

```text
内皮损伤
→ 富含蛋白的液体渗出
→ 间质 / 肺泡水肿
→ 非心源性肺水肿
```

### 2｜透明膜

蛋白性渗出物和坏死成分贴附肺泡壁，可形成透明膜。

### 3｜厚度与面积两个阶段

```text
渗出尚未充满肺泡
→ 扩散距离↑、呼吸膜“变厚”

渗出充满 + 肺泡塌陷
→ 有效交换面积↓、肺容积↓
```

### 4｜肉眼识别

- 湿肺：暗红、水肿、重量增加；
- 小 / 婴儿肺：肺容积减小；
- 白肺：弥漫性渗出影像接口。

## KP05｜II型肺泡上皮与表活：为什么肺泡会反复塌陷并越来越难撑开

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** II型细胞｜表活↓｜表面张力↑｜不张｜顺应性↓｜反复开闭

```text
II型肺泡上皮损伤
→ 表面活性物质↓
→ 肺泡表面张力↑
→ 肺泡、小气道萎陷
→ 肺不张
→ 肺顺应性↓
→ 吸气所需压力↑
```

若肺泡在每个呼吸周期反复开放—闭合，会形成新的机械损伤；因此治疗不仅要“给氧”，还要维持适当呼气末肺容量。

（易混：ARDS的“表面张力增加”不是肺气肿；肺气肿是弹性框架破坏、回缩动力下降。）

## KP06｜ARDS低氧主链：分流为什么比单纯弥散障碍更顽固

> **讲义定位 →** 内科 Lecture P54–55  
> **Outline →** 内科 U021｜核心机制1–2  
> **主提示：** 不张/充液｜有血无气｜分流｜VA/Q｜吸氧不良

```text
肺泡充液或塌陷
→ 肺泡通气接近0
但仍有血流经过
→ 血液未经充分氧合直接回到左心
→ 肺内分流↑
→ 高浓度氧也难以完全纠正
```

同时存在：

- 呼吸膜增厚；
- 有效面积减少；
- 肺内不同区域损伤不均；
- VA/Q严重失调。

> ARDS低氧不是只有“膜变厚”；**肺内分流是当前 Study的核心解释。**

## KP07｜肺血管与右心：缺氧性收缩 + 微血栓怎样形成急性肺心病

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** 缺氧收缩｜内皮/微血栓｜PVR｜肺高压｜急性肺心病2因｜最常见PE

```text
严重低氧
→ 肺小动脉收缩

内皮损伤
→ 内皮下胶原暴露、肺微血栓

两者共同
→ PVR↑
→ 肺动脉高压
→ 右室急性后负荷↑
→ 急性肺心病
```

//串联：急性肺心病的上游包括急性肺血栓栓塞、ARDS / 重症肺炎等；按当前 Study 题目口径，**最常见病因是急性肺血栓栓塞症**。二者都能使右室后负荷骤升，但 PE 的起点是肺动脉机械阻塞，ARDS 的起点是弥漫性屏障损伤、低氧收缩与微血栓。

# Unit B｜ARDS证据与肺保护通气

## KP08｜氧合指数：FiO₂已经很高，PaO₂仍上不去

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜检查1–2  
> **主提示：** 首选｜P/F≤300｜200/100分度｜FiO₂估算｜含义

### 1｜首选检查

> 动脉血气分析。

### 2｜氧合指数

```text
PaO₂ / FiO₂ ≤ 300
→ 当前 Study的ARDS必要氧合条件
```

分度：

| 程度 | PaO₂ / FiO₂ |
|---|---|
| 轻度 | 200–300 |
| 中度 | 100–200 |
| 重度 | ≤100 |

### 3｜FiO₂估算

当前 Study：

```text
吸入氧浓度（%）≈ 21 + 4 × 氧流量（L/min）
```

例如40%氧、PaO₂ 80 mmHg：

```text
P/F = 80 / 0.40 = 200
```

> 比值低说明“增加吸入氧浓度后，动脉氧分压仍难升高”。

## KP10｜影像时相与重力依赖区：为什么背侧更容易水肿和塌陷

> **讲义定位 →** 内科 Lecture P55–56  
> **Outline →** 内科 U021｜检查5；U022｜6  
> **主提示：** X线→CT｜背侧/基底｜早中晚3期｜不均一

### 1｜检查顺序

X线发现双肺弥漫改变，CT进一步显示分布与程度。

### 2｜当前 Study时相

```text
早期
→ 轻度肺间质改变

继之
→ 非心源性肺水肿、双肺弥漫斑片影

后期
→ 肺间质纤维化
```

### 3｜重力依赖区

仰卧时：

- 背侧 / 靠脊柱肺区为重力依赖区；
- 更易出现肺水肿、肺不张；
- 前胸侧非依赖区相对保留。

这解释了ARDS为何呈不均一“baby lung”模型，也解释俯卧位的作用。

## KP11｜氧疗与机械通气：ARDS不是只“多吸一点氧”

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗1–2  
> **主提示：** 高浓度｜PaO₂/SaO₂目标｜尽早通气｜压力>容量

### 1｜氧疗目标

当前 Study：

- 高浓度吸氧；
- PaO₂≥60 mmHg；
- SaO₂≥90%。

### 2｜为何需要尽早机械通气

ARDS存在分流、肺泡塌陷和顺应性下降，单纯提高FiO₂往往不足；多数患者需尽早机械通气。

### 3｜通气模式边界

当前 Study强调压力控制较容量控制更常用，核心理由是：

> 既要送入气体，又要限制压力，避免残余健康肺泡过度扩张。

不在此扩写现代呼吸机全部模式和参数。

## KP12｜PEEP：撑开塌陷肺泡，但胸内压与气压伤不能被忽略

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗3–4  
> **主提示：** 最重要｜5→8–18｜复张4效｜气压伤｜回心↓｜容量门槛

### 1｜当前 Study参数

```text
先从5 cmH₂O起
→ 逐步至8–18 cmH₂O适当范围
```

### 2｜四个目标

- 增加呼气末肺容量；
- 使萎陷肺泡 / 小气道再开放；
- 改善弥散与VA/Q，减少肺内分流；
- 防止肺泡在呼吸周期反复开闭。

### 3｜两类主要风险

```text
压力过高
→ 肺气压伤

胸内压↑
→ 静脉回心↓
→ CO↓、血压↓
```

因此：

- 从低水平开始；
- 血容量不足者需纠正容量不足；
- 不能只追求更高PEEP与更漂亮的PaO₂。

## KP13｜小潮气量与平台压：保护残余健康肺，而不是把所有肺泡“吹满”

> **讲义定位 →** 内科 Lecture P56  
> **Outline →** 内科 U022｜5  
> **主提示：** 4–8 mL/kg｜平台≤30｜健康肺过扩｜允许CO₂｜pH 7.25–7.3

### 1｜肺保护参数

```text
潮气量 4–8 mL/kg
平台压 ≤30 cmH₂O
```

### 2｜为什么不是大潮气量

ARDS肺泡损伤不均：病变肺泡难打开，气体更易进入剩余健康肺泡。大潮气量会使“baby lung”过度扩张，增加机械损伤。

### 3｜允许性高碳酸血症

小潮气量可能使CO₂排出不足；当前 Study允许：

```text
一定程度CO₂潴留
pH约7.25–7.3
```

目标是用可接受的CO₂代价减少肺泡过度扩张，不要求把所有血气数字立即恢复正常。

## KP14｜俯卧位：把背侧大体积肺组织从“压在下面”变成可复张区

> **讲义定位 →** 内科 Lecture P56；Recall生理VA/Q  
> **Outline →** 内科 U022｜6  
> **主提示：** 背侧依赖区｜水肿/不张｜翻上方｜复张｜分流↓

```text
仰卧
→ 背侧肺受重力、心脏压迫
→ 水肿 / 不张更重

俯卧
→ 背侧体积较大的肺组织置于上方
→ 压迫减轻、肺泡复张
→ 功能性动静脉短路↓
→ 氧合改善
```

俯卧位的本质是重新分配通气、压力与肺血流，不是单纯改变舒适度。

## KP15｜相对干肺：减少继续渗漏，但不能把患者利到低容量、低钾和碱中毒

> **讲义定位 →** 内科 Lecture P56、P59  
> **Outline →** 内科 U022｜7  
> **主提示：** 入<出｜利尿接口｜哮喘补液｜PEEP+低容量风险｜过利尿3害

### 1｜ARDS方向

- 限制液体入量；
- 维持肺相对干；
- 可用利尿剂接口。

### 2｜严重哮喘方向

严重急性发作可因大汗、呼吸功增加而缺液，当前 Study强调补液；不能把ARDS“相对干”机械套到所有呼吸危重症。

### 3｜安全边界

过度利尿可造成：

- 血容量不足，使PEEP相关回心下降更明显；
- 痰液黏稠；
- 低钾、低氯性代谢性碱中毒，氧解离曲线左移并加重组织卸氧困难。

## KP16｜Ⅰ型 vs Ⅱ型：核心差别不是病名，而是PaCO₂是否因通气失败升高

> **讲义定位 →** 内科 Lecture P58；Recall R2  
> **Outline →** 内科 U023｜分类1–2  
> **主提示：** Ⅰ：O₂<60/CO₂正低｜Ⅱ：CO₂>50±低氧｜换气vs通气｜代表病

| 轴 | Ⅰ型呼衰 | Ⅱ型呼衰 |
|---|---|---|
| 血气 | PaO₂<60；PaCO₂正常或低 | PaCO₂>50；伴或不伴PaO₂<60 |
| 主要故障 | 肺换气障碍 | 肺泡通气障碍 |
| O₂ | 进入动脉血失败 | 进入肺泡不足，同时CO₂排不出 |
| 急性代表 | ARDS、急性PE、急性肺水肿 / 左心衰、严重肺部感染 | 严重哮喘、脑干出血、膈肌麻痹 / MG、镇静催眠药中毒、气管异物 |
| 慢性 / 急性代表 | ILD | COPD、脊柱侧凸 / 胸廓畸形 |

（边界：ILD也有“限制性通气”表现，但其呼衰主要矛盾可为换气 / 弥散；COPD也有换气障碍，但CO₂潴留体现通气失败。）

## KP17｜吸氧浓度：慢性COPD型Ⅱ型需要低浓度，不能把规则套到所有Ⅱ型

> **讲义定位 →** 内科 Lecture P58；Recall R2化学感受器  
> **Outline →** 内科 U023｜分类2  
> **主提示：** Ⅰ高浓度｜慢Ⅱ<35%｜低氧驱动｜急性哮喘例外｜PaO₂可正常边界

### 1｜Ⅰ型

换气失败、低氧突出，当前 Study采用高浓度吸氧方向。

### 2｜慢性Ⅱ型COPD

```text
长期PaCO₂↑
→ 中枢化学感受器适应
→ 低氧对外周化学感受器的刺激更重要
→ 高浓度氧可削弱低氧驱动
```

因此强调低浓度氧，当前 Study写作 `<35%`。

### 3｜不能过度泛化

- 严重急性哮喘也是急性Ⅱ型呼衰，但可给予高浓度氧；
- Ⅱ型定义不再要求吸氧后PaO₂仍低：即使PaO₂被纠正，只要PaCO₂>50，仍属于Ⅱ型呼衰。

## KP18｜呼吸兴奋剂：只有完整反射弧和可执行呼吸肌时才可能有效

> **讲义定位 →** 内科 Lecture P58  
> **Outline →** 内科 U023｜呼吸兴奋剂1–2  
> **主提示：** 急/慢药｜中枢适应｜气道通畅｜禁2慎1｜COPD弱效边界

### 1｜药物

- 急性呼衰：多沙普仑；
- 慢性呼衰：阿米三嗪。

### 2｜适合

以呼吸中枢抑制为主的通气障碍，例如脑干出血、镇静催眠剂中毒接口。

### 3｜使用前提

```text
中枢能被兴奋
+ 传出神经完整
+ 呼吸肌能收缩
+ 气道通畅
```

### 4｜不适合 / 禁慎用

- 换气障碍：兴奋呼吸肌不能修复呼吸膜；
- 神经传导障碍、呼吸肌完全病变：禁用；
- 脑缺氧、脑水肿未纠正且频繁抽搐：慎用。

（边界：COPD核心有小气道阻塞，呼吸兴奋剂作用弱且可能增加呼吸功，当前 Study认为机械通气更有效；其过量主要只是加强已经疲劳的呼吸肌运动，**不作为造成碱中毒的典型原因**。）

## KP19｜呼衰全身表现：慢性低氧增红细胞，急性低氧 / CO₂影响脑和眼

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理1  
> **主提示：** 慢低氧HIF→EPO→RBC｜昏迷/抽搐｜球结膜水肿｜急慢边界

### 1｜慢性低氧

```text
HIF-1↑
→ EPO↑
→ 红细胞数量↑
→ 提高携氧能力的代偿
```

急性低氧来不及完成这一红系代偿。

### 2｜中枢神经

急性低氧或CO₂潴留可导致：

- 意识障碍 / 昏迷；
- 抽搐；
- 脑血管舒张、脑血流增加、颅压升高。

### 3｜眼部

缺氧与CO₂潴留可出现球结膜水肿，是高碳酸血症 / 颅压升高的重要线索。

## KP20｜慢性Ⅱ型呼衰酸碱电影：呼酸→肾保HCO₃⁻→失代偿→缺氧性代酸

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理2–3  
> **主提示：** 急无肾代偿｜慢呼酸｜HCO₃↑｜失代偿｜缺氧代酸/高K

### 1｜急性 vs 慢性

- 急性Ⅱ型：CO₂迅速升高，肾脏来不及增加HCO₃⁻；
- 慢性Ⅱ型：肾脏有时间保留HCO₃⁻形成碱储备。

### 2｜当前 Study连续过程

```text
CO₂长期潴留
→ 呼吸性酸中毒

肾HCO₃⁻重吸收↑
→ HCO₃⁻↑
→ pH接近正常：代偿性呼酸

病情继续恶化
→ 肾代偿不足
→ pH↓：失代偿性呼酸

严重缺氧
→ 无氧代谢、酸性产物↑
→ 合并代谢性酸中毒
→ H⁺入细胞、K⁺出细胞等
→ 高钾入口
```

（边界：当前 Lecture用“呼酸 + 代碱”描述HCO₃⁻代偿；正式酸碱分类与代偿公式在泌尿K5统一。）

## KP21｜pH升高与机械通气并发症：治疗本身也会制造新的Failure Mode

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理4；机械通气1  
> **主提示：** pH↑4因｜CO₂降至原水平｜并发7类｜回心链

### 1｜慢性Ⅱ型呼衰pH升高四因

1. 补碱不当；
2. 利尿过量；
3. 机械通气过度；
4. KCl补充不及时。

机械通气可使PaCO₂迅速下降，但肾脏保留的HCO₃⁻下降较慢：

```text
CO₂快速下降 + HCO₃⁻仍高
→ 代谢性碱中毒 / 混合紊乱
```

因此当前 Study强调：慢性Ⅱ型呼衰机械通气时，PaCO₂应降至患者原有水平，而不是骤然“正常化”。

### 2｜机械通气并发症七组

- 呼吸机所致肺损伤：肺水肿、高氧性肺损伤；
- 呼吸机所致膈肌功能障碍；
- 呼吸机相关肺炎；
- 代谢性碱中毒及混合酸碱紊乱；
- 气胸、纵隔 / 皮下气肿、间质性肺气肿；
- 气囊压迫：黏膜缺血、气道狭窄、气管软化、气管—食管瘘；
- 胸内压↑→回心↓→CO↓→血压↓。

> 机械通气不是“把血气调好”就结束，还必须同时监测肺、气道、感染、膈肌与循环。

## KP22｜酸碱快速入口与呼吸危重五步算法

> **讲义定位 →** 内科 Lecture P60  
> **Outline →** 内科 U023｜酸碱1–7；全部可见问句均路由  
> **主提示：** pH｜PaCO₂｜BE/HCO₃/CO₂CP｜K｜AB/SB｜补碱边界｜五步

### 1｜当前 Study快速阈值

| 指标 | 方向 |
|---|---|
| pH<7.35 | 酸中毒失代偿 |
| pH>7.45 | 碱中毒失代偿 |
| PaCO₂<35 mmHg | 呼吸性碱中毒方向 |
| PaCO₂>45 mmHg | 呼吸性酸中毒方向 |
| BE<-2.3 | 代谢性酸中毒方向 |
| BE>+2.3 | 代谢性碱中毒方向 |
| HCO₃⁻<22 | 代谢性酸中毒方向 |
| HCO₃⁻>27 | 代谢性碱中毒方向 |
| CO₂结合力（CO₂CP）↑ | HCO₃⁻ / 碱储备升高方向；可见于代碱或呼酸代偿，不能脱离pH、PaCO₂单独定性 |
| K⁺<3.5 | 多与代碱方向相伴 |
| K⁺>5.5 | 多与代酸方向相伴 |

### 2｜AB / SB当前 Study入口

```text
AB = SB <22
→ 代酸

AB = SB >27
→ 代碱

AB > SB
→ 呼酸方向

AB < SB
→ 呼碱方向
```

### 3｜补碱边界

当前 Study 强调：呼吸系统疾病导致的酸中毒，首先应改善气道、氧合与肺泡通气，不常规直接补碱；仅当 **pH<7.2** 时，才保留使用 **5% NaHCO₃** 的考试口径。完整适应证、剂量与混合酸碱处理后置泌尿 K5。

### 4｜五步危重算法

```text
Step 1｜稳定性
意识、呼吸功、血压、沉默肺 / 气道、紫绀

Step 2｜血气
PaO₂低？PaCO₂高？pH是否失代偿？

Step 3｜故障层
氧合失败：弥散 / VA-Q / 分流 / 肺血管
通气失败：气道 / 中枢 / 胸壁 / 神经肌肉 / 呼吸肌疲劳

Step 4｜立即支持
高浓度氧、低浓度氧、PEEP、NIV / 有创通气按病因和危重度选择

Step 5｜防止治疗伤害
过度通气、PEEP低回心、过利尿、低K碱中毒、气压伤、VAP
```

（边界：完整代偿公式、混合性酸碱定量、阴离子间隙与肾性处理统一后置泌尿K5。）

## 3｜高密度比较表

### 3.1 ARDS vs 心源性肺水肿
