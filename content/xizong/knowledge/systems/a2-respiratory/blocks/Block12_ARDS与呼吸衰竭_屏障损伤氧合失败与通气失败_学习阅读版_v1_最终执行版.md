## 0｜这个 Block 到底解决什么

呼吸系统的最终失败不是统一的一种病，而是两项核心功能失控：

```text
氧合失败
空气到了肺泡，但不能有效进入动脉血
→ PaO₂下降为主
→ Ⅰ型呼衰入口

通气失败
空气不能有效进出肺泡，CO₂排不出去
→ PaCO₂升高
→ Ⅱ型呼衰入口
```

ARDS是氧合失败中的典型危重模型：

```text
全身或肺部严重炎症 / 损伤
→ 肺毛细血管内皮 + 肺泡上皮受损
→ 高通透性非心源性肺水肿
+ 表面活性物质下降、肺泡塌陷
→ 肺内分流、顺应性下降、严重VA/Q失调
→ 高浓度氧也难纠正的低氧
```

### 本 Block 的总任务

> **面对顽固低氧、PaCO₂升高、意识改变或双肺弥漫影时，能先判断氧合失败还是通气失败，再识别ARDS、Ⅰ / Ⅱ型呼衰、心源性肺水肿和通气支持门槛。**

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 呼吸窘迫常快而费力，深浅不固定；ARDS早期过度通气可出现 PaCO₂下降和呼吸性碱中毒。
2. ARDS常在高危事件后1周内、尤其72小时内出现进行性呼吸困难与顽固低氧。
3. ARDS核心是**肺毛细血管内皮 + 肺泡上皮**两种细胞损伤。
4. 内皮损伤→高通透性非心源性肺水肿；II型肺泡上皮损伤→表活下降、肺泡塌陷。
5. ARDS是限制性通气入口 + 换气 / 分流失败；顺应性下降、肺内分流是低氧核心。
6. PaO₂ / FiO₂≤300是当前 Study必要氧合条件；200 / 100分轻中重。
7. 鉴别心源性肺水肿首选心脏超声；PAWP<18支持ARDS，但>18不能排除并存。
8. PEEP的任务是复张肺泡、增加呼气末肺容量、减少分流和反复开闭。
9. 肺保护：按预测体重给小潮气量、限制平台压，结合耐受性允许一定高碳酸血症；数字与版本见KP13。
10. 俯卧位使背侧重力依赖区肺泡复张，减少功能性分流。
11. Ⅰ/Ⅱ型传统室内空气判据与给氧后血气须分开；Ⅱ型突出PaCO₂>50 mmHg，详见KP16。
12. 慢性Ⅱ型COPD强调低浓度氧；严重急性哮喘虽是Ⅱ型，不套用同一低氧逻辑。
13. 呼吸兴奋剂只适合“中枢可被兴奋、传出和呼吸肌仍能执行、气道通畅”的通气障碍。
14. 急性早期肾代偿尚不充分，慢性更充分；代偿性HCO₃⁻升高不等于合并代碱。
15. 慢性Ⅱ型呼衰pH升高常是医源性：补碱、过度利尿、过度通气、补KCl不足。
16. 机械通气升高胸内压可使回心、CO和血压下降；不能只盯血气。

### MI-D｜定位后进入卡片流

- ARDS危险因素完整名单与时间窗；
- FiO₂估算公式、P/F分级数字；
- PAWP阈值与影像时相；
- PEEP起始 / 适用范围与全部不良反应；
- 小潮气量、平台压、允许性高碳酸血症数字；
- 呼吸兴奋剂药名；
- 机械通气全部并发症；
- pH、PaCO₂、BE、HCO₃⁻、K⁺、AB / SB完整数字表；
- 补碱阈值及利尿剂使用边界。

# Unit A｜ARDS：屏障损伤怎样形成顽固低氧

## KP01｜呼吸窘迫：早期过度通气为什么可使PaCO₂下降

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜呼吸窘迫1–3  
> **主提示：** 呼吸型式｜2感受器｜通气/CO₂｜5场景

### 1｜临床型式

- 呼吸快；
- 讲义概括为呼吸深；实际可呈浅快，不能把“深”作为必备体征；
- 呼吸费力；
- 患者主观严重憋气。

### 2｜反射链

```text
PaO₂↓
→ 颈动脉体 / 主动脉体

肺充血、水肿
→ 毛细血管旁J感受器

两路参与呼吸反射（J感受器刺激可引起浅快呼吸）
→ 若有效肺泡通气量相对CO₂生成量增加，形成过度通气
→ PaCO₂↓
→ 呼吸性碱中毒入口
```

### 3｜当前 Study的过度通气场景

急性哮喘早期、ARDS、癔症、急性PE、急性肺水肿。

（易混：ARDS早期PaCO₂低不代表肺功能正常；它反映低氧驱动下的代偿性过度通气。）

## KP03｜ARDS核心：内皮与肺泡上皮两种细胞同时失守

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** 2细胞｜通透性｜表活｜水肿/不张｜限制+分流

### 1｜肺毛细血管内皮

损伤后：

```text
通透性↑
→ 液体、蛋白、纤维蛋白、细胞成分渗出
→ 肺间质和肺泡水肿
```

### 2｜肺泡上皮

尤其II型肺泡上皮损伤：

```text
表面活性物质↓
→ 表面张力↑
→ 肺泡 / 小气道萎陷、不张
```

### 3｜共同后果

- 肺容积下降；
- 顺应性下降；
- 限制性通气障碍入口；
- 弥散距离增加；
- 肺内分流与严重VA/Q失调；
- 顽固性低氧。

## KP04｜高通透性肺水肿与透明膜：厚度增加与有效面积减少

> **讲义定位 →** 内科 Lecture P54；回看R5病毒性肺炎  
> **Outline →** 内科 U021｜核心机制1；病理DAD只Recall  
> **主提示：** 内皮渗漏｜非心源性｜透明膜｜厚度/面积2轴｜湿肺

### 1｜非心源性肺水肿

ARDS的液体进入肺泡，起点是屏障通透性增加，而不是左房 / 肺静脉压力先升高。

```text
内皮损伤
→ 富含蛋白的液体渗出
→ 间质 / 肺泡水肿
→ 非心源性肺水肿
```

### 2｜透明膜

蛋白性渗出物和坏死成分贴附肺泡壁，可形成透明膜。

### 3｜厚度与面积两条作用轴

```text
渗出尚未充满肺泡
→ 扩散距离↑、呼吸膜“变厚”

渗出充满 + 肺泡塌陷
→ 有效交换面积↓、肺容积↓
```

上述为讲义便于理解的分解，实际水肿、塌陷与交换面积减少可并存，并非必须严格先后发生。

### 4｜肉眼与功能识别

- 湿肺：暗红、水肿、重量增加；
- 小 / 婴儿肺（baby lung）：可参与通气的功能性肺量减少，不等于整只肺肉眼必然缩小；
- 白肺：弥漫性渗出影像接口。

## KP05｜II型肺泡上皮与表活：为什么肺泡会反复塌陷并越来越难撑开

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** II型细胞/表活/张力｜不张链｜顺应性/吸气压｜反复开闭损伤｜呼气末容量

```text
II型肺泡上皮损伤
→ 表面活性物质↓
→ 肺泡表面张力↑
→ 肺泡、小气道萎陷
→ 肺不张
→ 肺顺应性↓
→ 吸气所需压力↑
```

若肺泡在每个呼吸周期反复开放—闭合，会形成新的机械损伤；因此治疗不仅要“给氧”，还要维持适当呼气末肺容量。

（易混：ARDS的“表面张力增加”不是肺气肿；肺气肿是弹性框架破坏、回缩动力下降。）

## KP06｜ARDS低氧主链：分流为什么比单纯弥散障碍更顽固

> **讲义定位 →** 内科 Lecture P54–55  
> **Outline →** 内科 U021｜核心机制1–2  
> **主提示：** 不张/充液｜局部气/血配对｜分流｜VA/Q｜吸氧反应

```text
肺泡充液或塌陷
→ 肺泡通气接近0
但仍有血流经过
→ 血液未经充分氧合直接回到左心
→ 肺内分流↑
→ 高浓度氧也难以完全纠正
```

同时存在：

- 呼吸膜增厚；
- 有效面积减少；
- 肺内不同区域损伤不均；
- VA/Q严重失调。

> ARDS低氧不是只有“膜变厚”；**肺内分流是当前 Study的核心解释。**

## KP07｜肺血管与右心：缺氧性收缩 + 微血栓怎样形成急性肺心病

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** PVR上游2支｜肺高压/右室后负荷｜急性肺心病：ARDSvsPE

```text
→ 肺小动脉收缩
```

# Unit B｜ARDS证据与肺保护通气

## KP08｜氧合指数：FiO₂已经很高，PaO₂仍上不去

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜检查1–2  
> **主提示：** 首选｜P/F定义/诊断门槛｜分度3档｜FiO₂估算｜含义

### 1｜首选检查

> 动脉血气分析。

### 2｜氧合指数

```text
PaO₂ / FiO₂ ≤ 300
→ 当前 Study的ARDS必要氧合条件
```

分度：

| 程度 | PaO₂ / FiO₂ |
|---|---|
| 轻度 | 200 < P/F ≤300 |
| 中度 | 100 < P/F ≤200 |
| 重度 | ≤100 |

P/F单位为mmHg，FiO₂代入小数。按Berlin定义使用上述分级时，还须满足相应正压条件（PEEP≥5 cmH₂O；轻度可为CPAP≥5），以及起病时间、双肺影像和水肿来源等条件；P/F降低单独不能确诊ARDS。此处标明定义版本，不把它说成全部现代定义的唯一入口。

### 3｜FiO₂估算

当前 Study：

```text
普通低流量鼻导管的粗略估算：
吸入氧浓度（%）≈ 21 + 4 × 氧流量（L/min）
```

该估算受呼吸型式、分钟通气量和装置影响，不能套用于面罩、高流量装置或呼吸机；分级优先采用可靠的实际设定/测定FiO₂。

例如40%氧、PaO₂ 80 mmHg：

```text
P/F = 80 / 0.40 = 200
```

> 比值低说明“增加吸入氧浓度后，动脉氧分压仍难升高”。

## KP09｜ARDS vs 心源性肺水肿：先看起点，再看超声与PAWP

> **讲义定位 →** 内科 Lecture P55；Recall循环左心衰  
> **Outline →** 内科 U021｜检查3–4  
> **主提示：** 屏障vs压力｜首选检查｜PAWP阈值/边界｜并存条件

| 轴 | ARDS | 心源性肺水肿 |
|---|---|---|
| 起点 | 屏障通透性↑ | 左心 / 肺静脉压力↑ |
| 水肿 | 非心源性、富蛋白渗漏 | 静水压性 |
| 首选鉴别 | 心脏超声 | 心脏超声 |
| PAWP | 当前 Study通常<18 mmHg | 通常>18 mmHg |
| 边界 | PAWP>18仍不能排除ARDS，可与心衰并存 | — |

Swan–Ganz心导管用于测量肺小动脉 / 肺毛细血管楔压。

## KP10｜影像时相与重力依赖区：为什么背侧更容易水肿和塌陷

> **讲义定位 →** 内科 Lecture P55–56  
> **Outline →** 内科 U021｜检查5；U022｜6  
> **主提示：** X线/CT顺序｜背侧/基底｜早中晚3期｜不均一

### 1｜检查顺序

X线发现双肺弥漫改变，CT进一步显示分布与程度。

### 2｜当前 Study时相

```text
早期
→ 轻度肺间质改变

继之
→ 非心源性肺水肿、双肺弥漫斑片影

后期
→ 肺间质纤维化
```

### 3｜重力依赖区

仰卧时：

- 背侧 / 靠脊柱肺区为重力依赖区；
- 更易出现肺水肿、肺不张；
- 前胸侧非依赖区相对保留。

这解释了ARDS为何呈不均一“baby lung”模型，也解释俯卧位的作用。

## KP11｜氧疗与机械通气：ARDS不是只“多吸一点氧”

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗1–2  
> **主提示：** 氧合目标｜支持升级｜2模式｜保护目标

### 1｜氧疗目标

当前 Study：

- 高浓度吸氧；
- PaO₂≥60 mmHg；
- SaO₂≥90%。

### 2｜为何需要尽早机械通气

ARDS存在分流、肺泡塌陷和顺应性下降，单纯提高FiO₂往往不足；讲义强调多数患者尽早机械通气。实际按低氧程度、呼吸功、意识及循环状况选择和及时升级支持，不能把ARDS诊断直接等同于人人立即插管；FiO₂随氧合反应滴定，避免不必要的持续高氧。

### 3｜通气模式边界

讲义的选项口径是“压力控制较容量控制更常用”。肺保护的关键则是实际潮气量、平台压及患者反应；压力控制和容量控制均可实施肺保护，压力控制本身不保证潮气量安全，容量控制也不等于不能限压。

不在此扩写现代呼吸机全部模式和参数。

## KP12｜PEEP：撑开塌陷肺泡，但胸内压与气压伤不能被忽略

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗3–4  
> **主提示：** PEEP目的｜起始/调节范围｜肺泡4效｜风险2链｜容量门槛

### 1｜当前 Study参数

```text
先从5 cmH₂O起
→ 逐步至8–18 cmH₂O适当范围
```

### 2｜四个目标

- 增加呼气末肺容量；
- 使萎陷肺泡 / 小气道再开放；
- 改善弥散与VA/Q，减少肺内分流；
- 防止肺泡在呼吸周期反复开闭。

### 3｜两类主要风险

```text
压力过高
→ 肺气压伤

胸内压↑
→ 静脉回心↓
→ CO↓、血压↓
```

因此：

- 从低水平开始；
- 血容量不足者需纠正容量不足；
- 不能只追求更高PEEP与更漂亮的PaO₂。

## KP13｜小潮气量与平台压：保护残余健康肺，而不是把所有肺泡“吹满”

> **讲义定位 →** 内科 Lecture P56  
> **Outline →** 内科 U022｜5  
> **主提示：** 潮气量/体重基准｜平台压｜CO₂代价｜pH条件

### 1｜肺保护参数

```text
潮气量 4–8 mL/kg 预测体重（PBW，不是实际体重）
平台压：讲义≤30 cmH₂O；ATS肺保护推荐表述为<30 cmH₂O
```

### 2｜为什么不是大潮气量

ARDS肺泡损伤不均：病变肺泡难打开，气体更易进入剩余健康肺泡。大潮气量会使“baby lung”过度扩张，增加机械损伤。

### 3｜允许性高碳酸血症

小潮气量可能使CO₂排出不足；当前 Study允许：

```text
一定程度CO₂潴留
pH约7.25–7.3
```

目标是用可接受的CO₂代价减少肺泡过度扩张，不要求把所有血气数字立即恢复正常。讲义的pH范围不是所有患者必须达到或均可安全耐受的固定目标；须同时评估酸血症、颅内压、右心负荷和循环状态，不能为追求高CO₂而主动降低通气。

## KP17｜吸氧浓度：慢性COPD型Ⅱ型需要低浓度，不能把规则套到所有Ⅱ型

> **讲义定位 →** 内科 Lecture P58；Recall R2化学感受器  
> **Outline →** 内科 U023｜分类2  
> **主提示：** 氧合目标｜CO₂潴留3因｜控制给氧｜血气复查

### 1｜Ⅰ型

换气失败、低氧突出，当前 Study采用高浓度吸氧方向。

### 2｜慢性Ⅱ型COPD

```text
长期PaCO₂↑
→ 中枢化学感受器适应
→ 低氧对外周化学感受器的刺激更重要
→ 过量给氧可降低部分通气驱动
同时：低氧性肺血管收缩被解除→VA/Q失配加重；Haldane效应→血液释出CO₂
→ CO₂可升高，不能只归因于“靠缺氧呼吸”
```

讲义用 `<35%` 提示控制给氧；临床对有高碳酸血症风险者通常先以SpO₂ 88–92%为目标并复查血气，再按结果调整，不以固定氧浓度代替目标监测，也不能因担心CO₂而放任严重低氧。

### 3｜不能过度泛化

- 严重急性哮喘发生通气衰竭时可为Ⅱ型，氧疗同样按病情和目标滴定，不能机械套用COPD方案；
- Ⅱ型定义不再要求吸氧后PaO₂仍低：已确立通气衰竭时，即使PaO₂被给氧纠正而PaCO₂仍>50，也不能据此取消Ⅱ型判断；仍结合治疗前血气、酸碱状态和病因。

## KP19｜呼衰全身表现：慢性低氧增红细胞，急性低氧 / CO₂影响脑和眼

## KP20｜慢性Ⅱ型呼衰酸碱电影：呼酸→肾保HCO₃⁻→失代偿→缺氧性代酸

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理2–3  
> **主提示：** 急慢代偿｜CO₂/HCO₃/pH｜混合紊乱｜血K条件

### 1｜急性 vs 慢性

- 急性Ⅱ型：早期以非肾性缓冲为主，肾性适应尚不充分，不宜绝对写成“急性完全没有肾反应”；
- 慢性Ⅱ型：经时间积累，肾排酸、保留和生成HCO₃⁻的适应更充分。

### 2｜当前 Study连续过程

```text
CO₂长期潴留
→ 呼吸性酸中毒

肾HCO₃⁻重吸收↑
→ HCO₃⁻↑
→ pH接近正常：代偿性呼酸

病情继续恶化
→ 肾代偿不足
→ pH↓：失代偿性呼酸

严重缺氧
→ 无氧代谢、酸性产物↑
→ 合并代谢性酸中毒
→ 可出现血钾异常，须结合酸的类型、肾排钾、药物和组织损伤实测判断
→ 不能把缺氧性乳酸酸中毒机械等同于必然高钾
```

讲义用“呼酸 + 代碱”描述HCO₃⁻升高，但合适范围内的肾性代偿仍是单纯呼酸；只有超出预期代偿并结合病因才判断合并代碱。完整代偿公式在泌尿K5统一。

## KP21｜pH升高与机械通气并发症：治疗本身也会制造新的Failure Mode

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理4；机械通气1  
> **主提示：** pH↑4因｜机械通气CO₂目标｜并发7类｜回心链

### 1｜慢性Ⅱ型呼衰pH升高四因

1. 补碱不当；
2. 利尿过量；
3. 机械通气过度；
4. KCl补充不及时。

机械通气可使PaCO₂迅速下降，但肾脏保留的HCO₃⁻下降较慢：

```text
CO₂快速下降 + HCO₃⁻仍高
→ 代谢性碱中毒 / 混合紊乱
```

因此当前 Study强调：慢性Ⅱ型呼衰机械通气时，PaCO₂应降至患者原有水平，而不是骤然“正常化”。

### 2｜机械通气并发症七组

- 呼吸机所致肺损伤：肺水肿、高氧性肺损伤；
- 呼吸机所致膈肌功能障碍；
- 呼吸机相关肺炎；
- 代谢性碱中毒及混合酸碱紊乱；
- 气胸、纵隔 / 皮下气肿、间质性肺气肿；
- 气囊压迫：黏膜缺血、气道狭窄、气管软化、气管—食管瘘；
- 胸内压↑→回心↓→CO↓→血压↓。

> 机械通气不是“把血气调好”就结束，还必须同时监测肺、气道、感染、膈肌与循环。

## KP22｜酸碱快速入口与呼吸危重五步算法

> **讲义定位 →** 内科 Lecture P60  
> **Outline →** 内科 U023｜酸碱1–7；全部可见问句均路由  
> **主提示：** pH｜PaCO₂｜BE/HCO₃/CO₂CP｜K｜AB/SB｜补碱边界｜五步

### 1｜当前 Study快速阈值

| 指标 | 方向 |
|---|---|
| pH<7.35 | 酸血症；再判断原发过程与混合紊乱 |
| pH>7.45 | 碱血症；正常pH也不能排除混合紊乱 |
| PaCO₂<35 mmHg | 呼吸性碱中毒方向 |
| PaCO₂>45 mmHg | 呼吸性酸中毒方向 |
| BE<-2.3 mmol/L | 代谢性酸中毒方向 |
| BE>+2.3 mmol/L | 代谢性碱中毒方向 |
| HCO₃⁻<22 mmol/L | 代谢性酸中毒方向 |
| HCO₃⁻>27 mmol/L | 代谢性碱中毒方向 |
| CO₂结合力（CO₂CP）↑ | HCO₃⁻ / 碱储备升高方向；可见于代碱或呼酸代偿，不能脱离pH、PaCO₂单独定性 |
| K⁺<3.5 mmol/L | 多与代碱方向相伴 |
| K⁺>5.5 mmol/L | 多与代酸方向相伴 |

PaCO₂、HCO₃⁻的方向还可能属于代偿：低PaCO₂可为代酸的呼吸代偿，高HCO₃⁻可为呼酸的肾代偿。BE和血钾也不能单独确定混合紊乱；上述参考范围沿用讲义，须看实验室范围及完整血气。

### 2｜AB / SB当前 Study入口

AB（实际碳酸氢盐）是实际血气条件下血浆 HCO₃⁻ 浓度，受呼吸与代谢两方面影响。SB（标准碳酸氢盐）是血液按规定气体条件平衡后的血浆 HCO₃⁻：Siggaard-Andersen 定义采用 pCO₂ 5.33 kPa（约40 mmHg）、pO₂ >80 kPa，以减少当下 CO₂ 差异对比较的影响。因此 AB 与 SB 的差别帮助辨认呼吸因素，SB 的偏移提供代谢线索；两者都不能单独替代完整酸碱判断。名称由内科原 PDF 物理P72／书P60核实；标准化定义补充依据：[Siggaard-Andersen，Acid-base and oxygen status of the blood](https://www.siggaard-andersen.dk/OsaTextbook.htm)，Standard bicarbonate 条目（本地候选查阅2026-10-04）。这是课程传统指标的定义支持，不把其比较式升级为现代独立诊断算法。

```text
AB = SB <22
→ 代酸

AB = SB >27
→ 代碱

AB > SB
→ 呼酸方向

AB < SB
→ 呼碱方向
```

AB/SB的浓度单位为mmol/L；这组是讲义的快速线索，不能取代pH、PaCO₂与预期代偿的联合判断。

### 3｜补碱边界

当前 Study 强调：呼吸系统疾病导致的酸中毒，首先应改善气道、氧合与肺泡通气，不常规直接补碱；仅当 **pH<7.2** 时，才保留使用 **5% NaHCO₃** 的考试口径。这只是讲义考试阈值，不是pH一低于7.2就自动输碱的临床指令；纯呼吸性酸中毒首先改善通气，碳酸氢钠可增加CO₂负荷，须区别是否合并代酸并评估排CO₂能力。完整适应证、剂量与混合酸碱处理后置泌尿 K5。

### 4｜五步危重算法

```text
Step 1｜稳定性
意识、呼吸功、血压、沉默肺 / 气道、紫绀

Step 2｜血气
PaO₂低？PaCO₂高？pH是否失代偿？

Step 3｜故障层
氧合失败：弥散 / VA-Q / 分流 / 肺血管
通气失败：气道 / 中枢 / 胸壁 / 神经肌肉 / 呼吸肌疲劳

Step 4｜立即支持
```

## 3｜高密度比较表

### 3.1 ARDS vs 心源性肺水肿

| 轴 | ARDS | 心源性肺水肿 |
|---|---|---|
| 上游 | 炎症 / 屏障损伤 | 左心压力负荷 / 泵衰 |
| 水肿机制 | 通透性↑，非心源性 | 肺静脉静水压↑ |
| 低氧 | 分流突出，常顽固 | 弥散 / 肺泡充液；纠正心衰后改善 |
| 心超 | 无必须的左心衰证据 | 可见左心结构 / 功能异常 |
| PAWP | 通常<18 | 通常>18 |
| 治疗主轴 | 肺保护通气、PEEP、相对干肺、处理原发病 | 强心 / 利尿 / 降前后负荷等循环主轴 |

### 3.2 氧合失败 vs 通气失败

| 轴 | 氧合失败 | 通气失败 |
|---|---|---|
| 核心字母 | PaO₂ | PaCO₂ |
| 主要机制 | 弥散、VA/Q、分流、肺血流 | 肺泡通气量下降 |
| 呼衰类型 | Ⅰ型为主 | Ⅱ型 |
| 代表 | ARDS、PE、ILD、肺水肿 | COPD、严重哮喘、中枢、神经肌肉、胸壁 |
| 支持重点 | 氧合、复张肺泡、纠正匹配 | 开气道、减负、增加有效通气、排CO₂ |
