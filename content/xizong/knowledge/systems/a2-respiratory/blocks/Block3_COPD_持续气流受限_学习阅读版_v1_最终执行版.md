## 0｜这个 Block 到底解决什么

COPD 的核心不是“咳痰喘很多年”，而是：

> **气道和末梢肺组织的慢性结构性损伤，最终形成支气管扩张剂后仍存在的持续气流受限。**

它同时包含两条相互强化的故障链。

### 气道链

```text
吸烟 / 感染等长期刺激
→ 纤毛上皮损伤、杯状细胞和腺体增生
→ 黏液增多、清除下降
→ 小气道炎症、壁纤维化和管腔狭窄
→ 呼气气流受限
```

### 肺实质链

```text
中性粒细胞弹性蛋白酶活跃
+ α1-抗胰蛋白酶保护下降
→ 肺腺泡弹力结构破坏
→ 弹性回缩力下降
→ 呼气动力下降、气道更易提前闭合
→ 残气与过度充气
```

两条链汇合后：

```text
肺泡通气量下降
+ VA/Q 高低并存
+ 弥散面积减少
→ 低氧 ± CO₂潴留
→ 呼吸衰竭、肺高压 / 肺心病、气胸
```

### 本 Block 的总任务

> **看到中老年吸烟、慢性咳痰喘或呼气性呼吸困难时，能由病理结构反推肺功能、血气、体征、并发症和治疗目标。**

## 1｜总 Framework

```text
A｜先建立解剖定位

传导区
气管 → 主/叶/段/小支气管 → 细支气管 → 终末细支气管

末梢肺组织 / 肺腺泡
呼吸性细支气管 → 肺泡管 → 肺泡囊 → 肺泡

        ↓

B｜慢支先把“气道”变成黏、窄、硬

纤毛损伤
+ 杯状细胞 / 腺体增生
+ 黏液腺化生
+ 慢性炎细胞浸润
+ 管壁结构破坏和纤维化
→ 分泌物潴留 + 小气道狭窄

        ↓

C｜肺气肿再把“肺泡弹性框架”拆掉

小气道不完全阻塞
+ 弹性蛋白酶 / 抗蛋白酶失衡
→ 末梢肺组织弹力纤维破坏
→ 肺泡扩大、融合、肺大疱
→ 回缩无力、毛细血管床减少

        ↓

D｜形成 COPD 的持续气流受限

气道阻力↑
+ 弹性回缩↓
→ 呼气受限
→ RV / FRC / TLC↑
→ 内源性 PEEP↑
→ 呼吸功↑、呼吸肌疲劳

        ↓

E｜通气与换气一起失败

VA↓
+ VA/Q↓（通气差）
+ VA/Q↑（血流少）
+ DLCO↓（面积少）
→ 低氧 ± CO₂潴留

        ↓

F｜临床按阶段处理

持续气流受限证据
→ 严重度 / 症状 / 急性加重风险
→ 稳定期控制
→ AECOPD 急救
→ 并发症与后续 Block
```

### 四个最重要的判断轴

```text
FEV1/FVC
→ 有没有持续气流受限？

FEV1%pred
→ 气流受限严重到什么程度？

RV / FRC / TLC / RV:TLC
→ 有多少残气和过度充气？

PaCO₂
→ 肺泡通气是否已经不足？
```

## 2｜Memory Routing

### MI-G｜会阻断后续推理，第一轮必须即时掌握

1. 传导区、终末细支气管与肺腺泡的空间边界；
2. 慢支“首先累及较大气道、主要病变集中于小气道”的双重口径；
3. 慢支病理从内向外：上皮—杯状细胞 / 腺体—炎症—管壁结构；
4. 肺气肿不是只累及肺泡，而是末梢肺组织 / 肺腺泡异常扩大与弹性减弱；
5. 肺弹性阻力下降为何使呼气更困难；
6. 慢支 → 腺泡中央型肺气肿的完整链；
7. COPD 先“动态顺应性下降”，后“静态顺应性升高”；
8. COPD 诊断必须强调支气管扩张剂后 `FEV1/FVC < 70%`；
9. `FEV1/FVC` 定性与 `FEV1%pred` 定量的职责边界；
10. COPD 可同时出现 VA/Q↓ 与 VA/Q↑；
11. 肺泡通气下降是 CO₂潴留和总体通气失败的主要机制；
12. COPD 多见慢性Ⅱ型呼衰，但血气给出时仍可表现为Ⅰ型；
13. COPD 三个并发症：呼衰、肺心病、自发性气胸；
14. 稳定期与急性加重期必须先分开；
15. A/B/E 分组的输入是症状与既往急性加重风险，不是 FEV1%pred；
16. 急性加重出现意识状态改变时进入最重分级并考虑有创通气。

# Unit A｜先看疾病发生在哪里

## KP01｜气道树与肺腺泡：COPD 同时损害“管”和“泡”

> **讲义定位 →** 病理 Lecture PDF P54–56｜呼吸道与肺腺泡概述  
> **Outline →** 病理 U001｜慢支炎 1–3  
> **主提示：** 传导区终点；末梢肺组织构成；肺腺泡、肺小叶；I / II 型肺泡上皮；为什么这一地图能区分慢支、肺气肿、支扩和肺炎。

### 1｜传导区

```text
气管
→ 主支气管
→ 叶支气管
→ 段支气管
→ 小支气管
→ 细支气管
→ 终末细支气管【传导区最后】
```

这些结构的主要任务是输送空气，不直接承担肺泡气体交换。

### 2｜末梢肺组织 / 肺腺泡

```text
呼吸性细支气管
→ 肺泡管
→ 肺泡囊
→ 肺泡
```

- 肺腺泡是肺的基本功能单位；
- 肺小叶由若干终末细支气管及其远端结构组成，内含多个肺腺泡；
- I 型肺泡上皮：薄，主要承担气体交换；
- II 型肺泡上皮：分泌肺表面活性物质，并参与肺泡上皮修复接口；
- 肺泡间隔内含毛细血管、弹力纤维等。

### 3｜这张地图怎样服务后续疾病

```text
慢支
→ 从较大支气管向小气道发展，主要病变集中小气道

肺气肿
→ 末梢肺组织 / 肺腺泡扩大，弹性结构破坏

支扩
→ 主要是段、小支气管管壁支撑结构破坏

肺炎
→ 根据肺泡、细支气管周围或间质定位
```

（易混：慢支与肺气肿最终都可影响小气道，但肺气肿的形态主体不是“大支气管狭窄”，而是末梢肺组织异常扩张和弹性破坏。）

## KP02｜慢性支气管炎完整人设：把气道变成“黏、窄、硬”

> **讲义定位 →** 病理 Lecture PDF P58–60｜慢性支气管炎  
> **Outline →** 病理 U001｜慢支炎 4–8  
> **主提示：** 病因；首先 / 主要累及部位；3+2；从内向外讲病理；两类化生；为什么产生咳、痰、喘；哪些“增生”不能误叫异型增生。

### 1｜身份与病因

慢支是：

> **支气管黏膜及其周围组织的慢性炎症。**

主要病因按当前 Study：

- 吸烟；
- 病毒、细菌等感染。

### 2｜“首先”与“主要”不是同一问

```text
烟雾 / 病原从口鼻进入
→ 首先接触较大支气管
→ 逐渐向较小支气管和周围组织扩展

颗粒在细支气管停留更久
→ 主要病变集中于小气道 / 细支气管
```

### 3｜临床定义接口

```text
咳嗽、咳痰等症状
每年至少持续 3 个月
连续 2 年以上
```

该“3+2”是慢支的临床定义接口，不等于内科学 COPD 的持续气流受限诊断。

### 4｜从内向外看病理变化

| 层级 | 病理变化 | 功能结果 |
|---|---|---|
| 纤毛柱状上皮 | 纤毛倒伏 / 脱失，细胞变性、坏死、脱落 | 黏液清除下降 |
| 上皮适应 | 柱状上皮鳞状化生 | 更耐刺激，但失去正常纤毛功能 |
| 杯状细胞 | 数量增多 | 黏液增多 |
| 黏膜下腺体 | 增生肥大，浆液腺黏液腺化生 | 黏液进一步增多 |
| 管壁 | 充血、水肿，淋巴细胞和浆细胞等浸润 | 慢性炎症、管壁增厚 |
| 软骨 / 平滑肌 / 弹力纤维 | 破坏、萎缩或断裂；随后纤维性修复 | 管壁僵硬、狭窄、回缩异常 |

### 5｜为什么出现咳、痰、喘

```text
黏膜受炎症刺激
+ 杯状细胞 / 腺体分泌↑
→ 咳嗽、咳痰

平滑肌痉挛 / 管壁增厚
+ 黏液、渗出物堵塞
→ 气道狭窄
→ 喘息
```

### 6｜两类化生

- 鳞状上皮化生；
- 黏液腺化生。

（易混：慢支可有细胞增生与化生，但当前 Study 不把“软骨细胞不典型 / 异型增生”列为慢支病理。异型增生是肿瘤与部分癌前病变的语言。）

## KP03｜肺气肿：弹性阻力下降，为什么不是“呼吸更省力”

> **讲义定位 →** 病理 Lecture PDF P61｜肺气肿概述  
> **Outline →** 病理 U001｜肺气肿 1–4  
> **主提示：** 肺气肿：病因｜病变部位｜大体/镜下｜弹性变化｜吸气 vs 呼气力学｜呼吸困难

### 1｜病变身份

按当前 Study，肺气肿主要表现为：

- 末梢肺组织 / 肺腺泡过度充气、扩大；
- 肺体积膨大、含气增多；
- 肺泡间隔和弹性结构破坏；
- 肺毛细血管床受压、减少；
- 肺弹性减弱。

最常见病因是慢性支气管炎。

（易混：肺气肿不是仅限“肺泡变大”，它涉及呼吸性细支气管、肺泡管、肺泡囊和肺泡等末梢肺组织。）

### 2｜机械悖论

```text
肺弹性阻力
吸气时 = 阻力
呼气时 = 回缩动力
```

肺气肿时：

```text
弹性结构破坏
→ 吸气时确实更容易被拉开
但
→ 呼气时回缩动力不足
→ 小气道更易提前关闭
→ 气体呼不出去
→ 残气增加
```

所以它的典型功能表现是：

> **呼气性呼吸困难。**

### 3｜结构—功能恶性循环

```text
肺泡过度充气
→ 压迫肺泡间隔毛细血管和弹力纤维
→ 毛细血管床减少、弹性进一步下降
→ 回缩更差
→ 残气更多
→ 肺泡继续扩大、融合为肺大疱
```

## KP04｜慢支怎样发展为腺泡中央型肺气肿

> **讲义定位 →** 病理 Lecture PDF P62｜慢支—肺气肿机制  
> **主提示：** 小气道炎症、黏液、纤毛、管壁纤维化；中性粒细胞弹性蛋白酶；氧自由基与 α1-抗胰蛋白酶；肺大疱与毛细血管床；最后放回 COPD 的动态 / 静态阻力。

### 1｜先堵住小气道

```text
慢支小气道炎症
→ 终末细支气管及近端呼吸性细支气管管壁受损
→ 管壁纤维化、增厚、管腔狭窄

杯状细胞 / 腺体增生
+ 黏液腺化生
+ 纤毛清除下降
→ 黏液潴留
→ 小气道不完全阻塞
```

### 2｜再拆掉肺泡弹性框架

```text
中性粒细胞活化
→ 弹性蛋白酶↑

氧自由基↑
→ α1-抗胰蛋白酶保护作用↓

弹性蛋白酶 / 抗蛋白酶失衡
→ 末梢肺组织弹力纤维破坏
→ 弹性回缩下降
```

### 3｜最后形成过度充气与换气障碍

```text
气体呼不出去
→ 末梢肺组织残气↑、扩大
→ 肺泡破裂、融合为肺大疱
→ 毛细血管受压、破坏
→ 弥散面积↓、VA/Q异常
```

### 4｜放回 R1 的阻力语言

```text
先：小气道狭窄、分泌物阻塞
→ 非弹性阻力↑
→ 动态顺应性↓

后：肺弹性结构破坏
→ 弹性阻力↓
→ 静态顺应性↑
```

> **COPD 的“动低静高”不是两个互相矛盾的结论，而是两类结构损伤在不同测量条件下的表现。**

## KP05｜肺气肿分类：先按肺腺泡受累位置，再看特殊类型

> **讲义定位 →** 病理 Lecture PDF P62–64｜肺气肿分类与原图  
> **Outline →** 病理 U001｜肺气肿 5–10  
> **主提示：** 腺泡中央、腺泡周围 / 间隔旁、全腺泡三类的位置和机制；间质性；代偿性、老年性、瘢痕旁；周围型 vs 瘢痕旁；气胸接口。

### 1｜肺泡性 / 肺腺泡型

| 类型 | 主要受累位置 | 当前 Study 机制 / 特点 |
|---|---|---|
| 腺泡中央型 / 近端型 | 呼吸性细支气管及邻近肺泡明显扩张，远端肺泡管 / 囊相对较轻 | 最常见；常与慢支小气道阻塞相关 |
| 腺泡周围型 / 间隔旁型 / 远端型 | 肺泡管、肺泡囊等腺泡远端明显扩张，邻近胸膜和小叶间隔 | 当前 Study 以肺泡间隔胶原纤维收缩解释；多不合并慢支；胸膜下肺大疱可破裂 |
| 全腺泡型 | 呼吸性细支气管、肺泡管、肺泡囊、肺泡均扩张 | 遗传性 α1-抗胰蛋白酶缺乏接口；当前 Study 提示我国少见 |

### 2｜间质性肺气肿

```text
肋骨骨折 / 胸部穿透伤 / 剧烈咳嗽等
→ 空气进入肺间质
→ 串珠状气泡、皮下气肿
```

（特殊：气胸通常不会造成阻塞性肺气肿，但张力性气胸可形成间质性肺气肿接口。）

### 3｜其他类型

- 代偿性肺气肿：肺病变或肺叶切除后残余肺组织代偿性充气；
- 老年性肺气肿：老年肺弹性回缩减弱、残气增多；
- 瘢痕旁 / 不规则肺气肿：瘢痕附近肺泡破裂融合，位置、大小、形态不规则。

### 4｜周围型 vs 瘢痕旁型

共同点：均可与胶原瘢痕牵拉有关。

区别：

```text
腺泡周围型
→ 受累位置稳定在腺泡远端

瘢痕旁型
→ 受累位置取决于瘢痕在哪里
→ 范围和形态不固定
```

//串联：胸膜下肺大疱破裂可导致自发性气胸；完整气胸空间和处理后置 R10。

# Unit B｜从结构病变进入临床 COPD

## KP06｜COPD 的临床身份：慢支、肺气肿与 COPD 不能简单画等号

> **讲义定位 →** 内科 Lecture PDF P1｜COPD 临床入口  
> **Outline →** 内科 U001｜临床表现 1–3  
> **主提示：** COPD 本质；病理学与内科学口径边界；标志性症状；稳定期 / 加重期痰；典型病例入口；为什么“可能最可能”不能只靠一个体征。

### 1｜内科学的核心身份

> **COPD＝持续性气流受限。**

真正定性需要：

```text
吸入支气管扩张剂后
FEV1/FVC 仍 < 70%
```

### 2｜三层概念不要混

```text
慢支
→ 临床综合征和气道慢性炎症语言

肺气肿
→ 末梢肺组织异常扩大和弹性破坏语言

临床 COPD
→ 持续性、不完全可逆的气流受限语言
```

当前病理 Study 可把慢支、肺气肿放在 COPD 疾病组框架中；内科诊断则要求持续气流受限证据。两种表述层级不同，不强行改成一句完全相同定义。

### 3｜临床入口

- 标志性症状：气短，常在活动后出现；
- 慢支样表现：咳、痰、喘；
- 稳定期：白色泡沫痰为主；
- 急性加重期：黄脓痰为主；
- 典型病例入口：中老年、长期吸烟、反复咳痰喘、活动后呼吸困难。

（易混：中老年吸烟 + 咳痰喘可“首先考虑 COPD”，但不等于只凭症状就已经完成确诊。）

## KP07｜为什么 COPD 是“越吸越容易，越呼越困难”

> **讲义回看 →** R1 气道阻力与弹性回缩；内科 P1–2  
> **主提示：** 呼气性呼吸困难的两套来源；缩唇呼吸为什么有帮助；活动后为何更明显。

### 1｜气道口径的呼吸周期效应

```text
吸气
→ 胸膜腔负压更负、肺体积增大
→ 肺组织对小气道牵拉增强
→ 气道口径增大、阻力下降

呼气
→ 肺体积减小、胸膜腔负压负值减小
→ 对小气道牵拉减弱
→ 狭窄小气道更易闭合
```

### 2｜弹性回缩下降

```text
肺气肿破坏弹力纤维
→ 呼气回缩动力不足
→ 气体更难排出
```

### 3｜缩唇呼吸

```text
缩唇、缓慢呼气
→ 呼气道内压相对维持
→ 小气道提前闭合减慢
→ 可帮助更多残气排出
```

### 4｜活动后加重

活动使氧耗和通气需求增加；而 COPD 已存在气流速度限制与动态过度充气，无法按需求显著增加有效肺泡通气，因此气短更明显。

## KP08｜COPD 体征：肺内残气怎样改变视、触、叩、听

> **讲义定位 →** 内科 Lecture PDF P2；P11 呼吸系统重要体征  
> **Outline →** 内科 U001 临床 4–7；U003 重要体征 1–4  
> **主提示：** 视触叩听完整回答；每个方向背后的“含气增多 / 声音传导 / 气道狭窄 / 分泌物”机制；一般语颤和叩诊坐标。

### 1｜COPD 视触叩听

| 检查 | 典型方向 | 机制 |
|---|---|---|
| 视诊 | 缩唇呼吸；桶状胸 | 残气与过度充气 |
| 触诊 | 语音震颤减弱 | 过多空气使声音传导下降 |
| 叩诊 | 过清音；Kronig峡增宽 | 肺组织含气增多 |
| 边界 | 肺下界、肝浊音界下移 | 过度充气、膈肌下移 |
| 心界 | 心浊音界缩小、心音遥远 | 膨胀肺组织遮挡心脏、增加传导距离 |
| 听诊 | 呼吸音减弱、呼气音延长 | 气流受限、过度充气 |
| 啰音 | 湿啰音或干湿啰音共存 | 分泌物 / 液体 + 气道狭窄 |

（易混：桶状胸并非 COPD 专属，也可见严重哮喘、老年人等；必须结合病史和持续气流受限证据。）

### 2｜呼吸系统体征坐标

```text
语音震颤增强
→ 肺实变、大空洞、胸腔积液上方

语音震颤减弱
→ COPD、哮喘、肺不张、肺水肿、胸膜增厚、胸腔积液、气胸等
```

```text
鼓音 > 过清音 > 清音 > 浊音 / 实音
```

```text
湿啰音
→ 气道内有液体

干啰音 / 哮鸣音
→ 气道狭窄或痉挛
```

# Unit C｜持续气流受限怎样被肺功能和血气“看见”

## KP09｜小气道先受累：动态顺应性下降、静态顺应性升高、内源性 PEEP

> **讲义定位 →** 内科 Lecture PDF P2–4｜COPD 病理生理  
> **Outline →** 内科 U001｜病理生理 1  
> **主提示：** COPD 首先累及哪里；MEFV、闭合容积；动低静高；内源性 PEEP 从何而来；为什么会导致呼吸肌疲劳。

### 1｜最早的小气道指标

COPD 首先累及小气道，可先表现为：

- 最大呼气流速 / 流量—容积曲线 MEFV 下降；
- 闭合容积升高；
- 动态肺顺应性下降。

### 2｜动态顺应性为何下降

```text
黏液 / 渗出物
+ 小气道壁纤维化、狭窄
→ 气道阻力↑
→ 有气流时测得的动态顺应性↓
```

### 3｜静态顺应性为何升高

```text
弹性蛋白酶—抗蛋白酶失衡
→ 末梢肺组织弹性结构破坏
→ 弹性阻力↓
→ 无气流时测得的静态顺应性↑
```

### 4｜内源性 PEEP

```text
呼气受限
→ 呼气末仍有大量残气
→ 肺泡内压在呼气末仍高于大气压
→ 内源性 PEEP
```

下一次吸气前，患者必须先克服这股正压，才能让肺泡内压降到大气压以下：

```text
吸气做功↑
→ 呼吸肌疲劳
→ 通气泵进一步下降
→ CO₂潴留加重
```

## KP10｜COPD 肺功能全图：流速、残气、容积与弥散分别怎么看

> **讲义定位 →** 内科 Lecture PDF P3–4｜肺功能  
> **Outline →** 内科 U001 病理生理 2–3；U002 辅助检查 1–2  
> **主提示：** COPD肺功能：气流｜残气/容积｜弥散｜各指标问什么｜诊断 vs 严重度

| 指标 | COPD 方向 | 主要反映 |
|---|---:|---|
| FEV1 | ↓ | 第一秒快速呼出量 |
| FEV1/FVC | ↓ | 气流速度 / 阻塞定性 |
| 支扩剂后 FEV1/FVC | 仍 <70% | 持续气流受限、COPD 诊断身份 |
| FEV1%pred | ↓ | 气流受限严重程度 |
| VA | ↓ | 真正到达肺泡的有效通气下降 |
| RV | ↑ | 呼气末残气 |
| FRC | ↑ | 平静呼气末肺内气体增加 |
| TLC | ↑ | 过度充气 |
| RV/TLC | ↑；当前 Study 以 >40% 作为肺气肿接口 | 残气在总肺量中的比例 |
| DLCO | ↓ | 肺泡壁 / 毛细血管床破坏后弥散面积减少 |

### 两个诊断职责

```text
支气管扩张剂后 FEV1/FVC <70%
→ 定性：持续气流受限 / COPD

FEV1%pred
→ 定量：GOLD 严重程度
```

当前 Study 的 GOLD 肺功能分级：

- 1级：≥80%；
- 2级：50%–79%；
- 3级：30%–49%；
- 4级：<30%。

## KP11｜COPD 低氧与 CO₂潴留：通气是主矛盾，换气是第二条链

> **讲义定位 →** 内科 Lecture PDF P3｜低氧与 CO₂潴留  
> **Outline →** 内科 U001 病理生理 4–5；U003 低氧机制 1  
> **主提示：** 三个机制；哪个是主要；VA/Q 为什么既高又低；DLCO 为什么只先影响 O₂；何时Ⅰ型、何时Ⅱ型。

### 1｜主要机制：肺泡通气量下降

```text
小气道阻塞
→ 有效肺泡通气 VA↓
→ CO₂排出下降
→ PaCO₂↑
```

这是 COPD 发生 CO₂潴留、并常走向Ⅱ型呼衰的主要机制。

### 2｜VA/Q↓：气少、血相对多

```text
黏液 / 渗出物 / 管壁狭窄
→ 局部通气 VA↓
→ VA/Q↓
→ 功能性动静脉短路 / 分流样低氧
```

### 3｜VA/Q↑：气还在、血减少

```text
肺泡过度膨胀、肺大疱
→ 压迫 / 破坏毛细血管
→ 局部血流 Q↓
→ VA/Q↑
→ 死腔样通气 / 肺泡无效腔增加
```

### 4｜弥散障碍

```text
肺泡间隔与毛细血管床破坏
→ 弥散面积↓
→ DLCO↓
```

CO₂溶解度高、扩散快，因此单纯弥散障碍首先表现为低氧，不易单独造成 CO₂潴留。

### 5｜为何既可Ⅰ型，又常为Ⅱ型

```text
换气障碍占主导
→ PaO₂↓，PaCO₂正常
→ 可呈Ⅰ型呼衰

肺泡通气不足占主导
→ PaCO₂>50 mmHg，常伴低氧
→ 慢性Ⅱ型呼衰
```

> 有血气时必须以实际 PaO₂ / PaCO₂ 为准，不能仅凭“COPD通常Ⅱ型”覆盖题干。

# Unit D｜并发症、证据与诊断坐标

## KP12｜COPD 三个并发症：呼衰、肺心病、气胸

> **讲义定位 →** 内科 Lecture PDF P4｜并发症  
> **Outline →** 内科 U001｜并发症 1–4  
> **主提示：** COPD并发症3｜各上游机制｜典型证据｜气胸症状先后

### 1｜呼吸衰竭

- 多见慢性Ⅱ型：PaCO₂ >50 mmHg，伴或不伴 PaO₂ <60 mmHg；
- 若以 VA/Q失调和弥散障碍为主，也可为Ⅰ型。

完整呼衰诊断与通气策略后置 R12。

### 2｜慢性肺心病

```text
慢性低氧
→ 肺小动脉痉挛、重构
→ 肺动脉高压
→ 右心后负荷↑
→ 右心功能不全
```

接口表现：P2亢进、颈静脉怒张、双下肢水肿等。完整肺高压 / 肺心病后置 R9。

### 3｜自发性气胸

```text
胸膜下肺大疱破裂
→ 气体进入胸膜腔
→ 先突发胸痛
→ 继之呼吸困难
```

可见：鼓音、患侧肋间隙增宽、纵隔向健侧移位、语音震颤和呼吸音减弱或消失。

（易混：肺栓塞也可突然胸痛和呼吸困难，但当前 Study 强调自发性气胸常有“胸痛先、继之呼吸困难”的顺序。）

## KP13｜COPD 诊断、严重度与检查选择

> **讲义定位 →** 内科 Lecture PDF P4–5｜辅助检查  
> **Outline →** 内科 U002｜辅助检查 1–3  
> **主提示：** 一般 COPD、肺性脑病、并发气胸分别首选什么；持续气流受限标准；FEV1%pred；X线能看什么。

### 1｜一般 COPD

首选、最佳检查：肺功能。

```text
支气管扩张剂后 FEV1/FVC <70%

```

### 2｜严重度

### 3｜肺性脑病

## KP14｜阻塞性 vs 限制性：本 Block 只做诊断坐标复用

# Unit E｜稳定期与急性加重期分开处理

## KP16｜稳定期先评估：症状与急性加重风险组成 A / B / E

> **讲义定位 →** 内科 Lecture PDF P5｜稳定期综合评估

```text
A

B
低风险 + 症状多

E
急性加重高风险
```

## KP17｜稳定期治疗：戒烟是上游，支气管扩张剂处理可逆部分

> **讲义定位 →** 内科 Lecture PDF P5｜稳定期治疗  
> **Outline →** 内科 U002｜治疗 1–5、9  
> **主提示：** 最重要预防；A / B / E 支气管扩张方案；ICS何时加入；为什么药物无法逆转所有病理；稳定期与急性期都需要什么。

### 1｜上游措施

> **戒烟是预防 COPD 最重要的措施。**

稳定期还需降低感染诱发急性加重的风险。

### 2｜药物针对“可逆部分”

COPD 同时包含：

```text
不可逆
气道纤维化 / 狭窄
末梢肺组织弹性结构破坏

相对可逆
气道平滑肌痉挛
分泌物与炎症渗出
```

因此稳定期以吸入支气管扩张剂改善气道痉挛和流速。

### 3｜按当前 Study 的 A / B / E

- A组：一种支气管扩张剂；
- B组：LABA + LAMA；
- E组：LABA + LAMA，或在相应指征下 LABA + LAMA + ICS。

常见类别：

- SABA；
- SAMA；
- LABA；
- LAMA；
- 茶碱类。

### 4｜ICS 加用指征

当前 Study 强调：

- 急性加重住院史；
- 每年 ≥2 次中度急性加重；
- 血嗜酸性粒细胞 ≥300；
- 哮喘史或伴哮喘特征。

必要时可用祛痰药。

（易混：ICS 是哮喘长期抗炎核心；COPD 并非所有稳定期患者都常规使用 ICS。）

## KP18｜长期家庭氧疗：改善预后，但不等于解决 CO₂潴留

> **讲义定位 →** 内科 Lecture PDF P6｜长期家庭氧疗  
> **Outline →** 内科 U002｜治疗 6  
> **主提示：** 目标 PaO₂ / SaO₂；低流量；流量和浓度；慢性 CO₂潴留后的化学感受器逻辑；吸氧不能直接做什么。

按当前 Study：

```text
长期家庭氧疗目标
PaO₂ ≥60 mmHg
SaO₂ ≥90%
```

采用低流量：

```text
1–2 L/min
氧浓度约 30%
```

当前 Study 的解释链：

```text

→ 高浓度氧可能削弱该驱动并加重 CO₂潴留
```

> **吸氧可以改善低氧，但不能替代增加肺泡通气来排出 CO₂。**

## KP19｜AECOPD：先识别严重度，再处理感染、气道、炎症和通气

> **讲义定位 →** 内科 Lecture PDF P6｜急性加重期  
> **Outline →** 内科 U002｜治疗 2、7–11；U003 治疗 12–13  
> **主提示：** AECOPD：诱因｜症状/严重度｜支扩/抗菌/激素｜氧疗/通气｜何时有创

### 1｜识别急性加重

最常见原因：感染。

常见表现：

- 咳嗽、咳痰、喘息加重；
- 黄脓痰；
- 可伴发热；
- 气促和血气恶化。

### 2｜当前 Study 分级

| 分级 | 高碳酸血症 / 呼衰 | 意识状态 |
|---|---|---|
| Ⅰ级 | 无 | 无改变 |
| Ⅱ级 | 有 | 无改变 |
| Ⅲ级 | 有 | 有意识改变 / 肺性脑病 |

### 3｜治疗层级

```text
感染
→ 必要抗菌治疗

气道痉挛
→ 吸入支气管扩张剂

住院、炎症加重
→ 口服或静脉全身糖皮质激素

低氧
→ 鼻导管低流量氧疗

严重呼衰
→ 机械通气

意识障碍 / Ⅲ级
→ 有创机械通气接口
```

稳定期和急性加重期都需要支气管扩张剂，但糖皮质激素的给药身份不同：稳定期按特定条件考虑 ICS；需要住院的急性加重可用全身激素。

## KP20｜COPD 急救安全边界：先改善通气，不轻易“补碱和镇静”

> **讲义定位 →** 内科 Lecture PDF P6｜其他治疗  
> **主提示：** 呼吸性酸中毒为何先改善通气；何时补碱；吗啡和意识障碍时镇静药的边界。

### 1｜酸中毒

```text
气道阻塞 / 肺泡通气不足
→ CO₂潴留
→ 呼吸性酸中毒
```

首要处理应是改善通气和病因，而不是直接用碱掩盖 CO₂问题。

按当前 Study：

- 一般不补碱；
- 当 pH <7.2 时可考虑补碱接口。

### 2｜药物安全

- 呼吸系统疾病禁用吗啡等中枢性镇咳 / 抑制呼吸药物的 Study 口径；
- 意识障碍者禁用地西泮等镇静药。

（易混：这不是完整重症镇静方案；本 Block 只保留会加重呼吸中枢抑制的考试边界。）

## KP21｜COPD 出口：先与哮喘建立“持续 vs 可变”的主鉴别轴

> **讲义回看 →** R1–R3；完整比较在 R4 末尾

### 1｜共同点

两者都可出现：

- 呼气性呼吸困难；
- 阻塞性通气障碍；
- FEV1/FVC下降；
- RV增多、过度充气；
- 过清音、语颤和呼吸音减弱；
- 干啰音；
- 严重时低氧、CO₂潴留。

因此这些共同点不能单独完成鉴别。

### 2｜当前主轴

```text
COPD

哮喘

→ 气流受限具有可变性 / 可逆性
```

完整病例、药物和证据对比在 R4 建立后再完成。
