## 0｜这个 Block 到底解决什么

病原经气道、血道或相应局部入口到达肺后，病变可主要占据肺泡、细支气管及周围末梢组织，或肺间质。空间、炎症类型和病原身份是相关但不同的坐标：同一空间可有不同病原，同一病原在严重时也可跨区损伤。

肺泡被渗出物填充会减少含气并改变声音传导；局部通气下降而血流仍在，可形成低VA/Q或分流并导致低氧。纤维素能否被清除决定吸收或机化的结局；发生化脓性坏死、液化且坏死物排出时则可留下空洞。病史、影像、痰和合格病原学检查读取这些不同层次，不能由一个痰色或阴影直接倒推出确诊与处方。

严重度从病例入口持续评估。出现休克时，循环复苏与尽快抗感染并行，取材不应造成明显延误；后续再依据病原证据、药敏和临床反应调整治疗，按坏死脓腔、脓胸或顽固低氧交接相应模型。

### 本 Block 的总任务

> **能用病原入口、病变空间和组织反应解释体征、影像与低氧，合读病原证据并持续识别危重和并发症，使治疗回到病原、氧合、循环及持续感染源。**

## 1｜总 Framework

**入口改变病原可能性。** CAP/HAP由获得环境、入院时有无感染/潜伏和发病时间共同界定。误吸、血源或局部感染入口改变接触的病原及分布，但环境本身不是某一种病理形态的充分原因。

**三个空间并行。** 肺泡渗出填充 → 肺泡实变；细支气管中心化脓并向周围末梢组织扩展 → 小叶性斑片；肺泡间隔水肿、增宽和炎细胞浸润 → 间质性改变。严重损伤可跨区，非典型病原身份不等于间质性病变。肺泡填充减少含气、增强声音传导，局部通气不足可造成低VA/Q/分流；仍含气的支气管与周围实变形成影像对比。

**结局有条件分支。** 经典大叶性纤维素渗出的自然病程有四期，能清除则吸收，清除不足可机化成肺肉质变；化脓性坏死 → 液化 → 经支气管排出 → 空洞是组织破坏的另一支。胸膜受累、肺外感染、休克及严重屏障损伤后的顽固低氧也各有条件，不能把所有肺炎排成同一串终点。

**病原模型是并行比较。** 链球菌的实变/铁锈色痰、金葡菌的多发易变坏死腔、克雷伯的误吸背景/黏稠血痰/叶间隙下坠、支原体的缓起痰少剧咳、军团菌的旅行或空调背景/高热/腹泻低钠、病毒的全身反应/间质与肺泡损伤，用于提出候选并选择证据。病原确认及治疗还须合看样本、药敏、耐药身份、年龄和具体病毒等条件。

**观察与干预贯穿。** 影像读取空间和并发症，微生物检查寻找病原，CURB-65及循环/意识/呼吸状态读取严重度。休克时复苏与抗感染并行；治疗后反应不佳须复核病原、给药与持续感染源，并将脓腔、脓胸、ARDS/呼衰分别交R6、R10、R12。

```text
【获得环境是入口线索，当前严重度持续读取】

医院外获得或院外已感染、入院后仍在潜伏期内发病的情况可属于CAP；HAP要求入院时不存在也不在潜伏期，且达到相应入院后时间条件。误吸口鼻分泌物、人工气道、血源等入口改变病原接触与取证方向。获得环境、进入途径、具体病原仍须分层判断；淋巴相关原范围留在当前Core。

〈CAP vs HAP：先问在哪里获得，再问误吸了谁〔CAP/HAP定义｜途径4/2｜病原5/5｜误吸来源｜淋巴入口边界〕〉

病例一开始就合读意识、呼吸频率、血压、尿素和年龄等严重度变量，随病情反复评估。CURB-65用于严重度入口，不是病原诊断。肺炎合并休克时，循环复苏/补液与尽快抗感染并行；既不等补液完成，也不因取材造成明显用药延误。顽固低氧和双肺弥漫影出现时转入R12的相应评估。

〈CURB-65：先找谁可能不能留在普通肺炎路径〔C-U-R-B-65｜5阈值｜休克优先轴〕〉

【病原造成的组织反应落在三个可交叉的空间】

病变可主要占据肺泡、细支气管及其周围末梢肺组织，或肺间质；据此分别观察实变、斑片和间质性影像。空间与纤维素性/化脓性/间质性炎症需合看，不能把病原类别当作空间定义。非典型病原不必产生间质性肺炎，严重的间质损伤也可进入肺泡。

〈肺炎空间总坐标：肺泡、细支气管周围还是间质〔空间/炎症/影像3轴｜非典型病原vs间质病变｜重症跨界〕〉

在肺泡支路，纤维素和细胞性渗出替代空气，并可经肺泡间孔或沿支气管向邻近肺组织蔓延，形成大片实变。支气管仍含气时，与周围致密肺泡形成支气管充气征；病变延及胸膜时可出现胸膜反应。

〈大叶性肺炎：肺泡被填满，但支气管仍含气〔人群/病原｜肺泡空间｜蔓延2路径｜支气管/胸膜｜实变4征/纵隔｜充气征机制〕〉

含气减少、组织密度增加 → 叩诊变浊，声音传导可增强 → 语颤增强及异常支气管呼吸音。局部通气下降而灌注仍在 → 低VA/Q或分流，出现低氧。体征和影像是上述空间改变的观察结果，纵隔方向及湿啰音还须合看病变和原Core条件。

〈肺实变为何“声音更强”：气体被渗出物替代后的传导变化〔叩诊｜语颤｜呼吸音｜湿啰音｜纵隔｜机制1链〕〉

经典大叶性肺炎的充血水肿、红色肝变、灰色肝变、溶解消散描述同一纤维素性渗出过程的自然病程。若中性粒细胞及蛋白酶对渗出的清除不足，肉芽组织长入并机化 → 肺肉质变；肉芽组织修复与肉芽肿不是同一结构。这是吸收或组织化的分支，不自动接上化脓空洞。

〈大叶性肺炎四期与肺肉质变：纤维素能否被清掉〔四期｜并发4｜最常见/最严重｜肉质变链｜机化/肉芽肿辨别〕〉

在细支气管支路，化脓性炎症以细支气管为中心向周围末梢组织扩展，形成散在或融合斑片。分泌物引流和重力相关分布使双肺下叶背侧常受累；宿主背景、炎症范围与并发症须合看，不能仅以一张斑片影确定病原或断言所有病例都累及胸膜。

〈小叶性肺炎：以细支气管为中心的化脓性斑片病变〔人群/病因｜中心结构｜炎症细胞｜好发部位｜影像｜并发症｜胸膜边界〕〉

在间质支路，肺泡间隔增宽、水肿、单核/淋巴细胞浸润，肺泡渗出起初相对少。严重病毒性损伤可跨入肺泡，出现坏死、出血及透明膜等改变，并加重气体交换失败；这不是每次病毒感染的必经阶段。透明膜相关病毒和核/胞质包涵体的精确位置仍按原Core/Source区分。

〈间质性肺炎与病情进展：主轴在肺泡间隔，但严重时可跨进肺泡〔病原3｜间隔3变｜肺泡渗出方向｜重症跨界｜透明膜4病毒｜包涵体3位点〕〉

若病原和宿主反应造成肺实质化脓性坏死 → 液化，坏死物经支气管排出后可形成空洞；气液同存时可见液平。后续炎症吸收、脓腔处理和纤维修复取决于具体病因。金葡等坏死倾向与通常不空洞的链球菌课程模型需保留各自条件，结核的干酪性空洞回R7，完整肺脓肿回R6。

〈空洞病原与肺炎结局：谁会破坏肺组织〔空洞4病原｜最易1｜坏死/引流/空洞/修复链｜链球菌/结核边界〕〉

【六个病原在同一组轴上比较，线索用于提出和检验候选】

肺炎链球菌常进入青壮年急性实变模型：肺泡红细胞/血红蛋白改变可形成铁锈色痰，实变产生相应体征与充气征。荚膜相关抗吞噬及肺炎链球菌溶血素等致病作用不能缩成“绝不产生损伤”。课程通常无空洞的倾向保留。青霉素等选择需结合药敏与感染条件；治疗后体温不降或复升，要复核病原、耐药、给药和肺外/局部并发灶。

〈肺炎链球菌肺炎：青壮年实变模型〔人群/诱因｜症状4｜实变4征｜影像2｜致病物｜空洞边界｜治疗3｜退热时窗/失败评估〕〉

金葡菌支路的化脓性组织破坏可产生多发、易变的结节、空洞或液气囊腔；脓血痰及皮肤/骨感染、住院等病史共同支持候选。治疗先分相应MSSA与MRSA覆盖。存在血源背景时须追原发灶和血培养，完整血源性肺脓肿回R6 KP14。

〈金葡菌肺炎：最易形成多发易变空洞〔病史4组｜痰｜影像4型/胸膜并发｜空洞倾向｜MSSA/MRSA药物｜血源脓肿接口〕〉

克雷伯支路联系中老年、误吸背景与黏稠血性痰。黏液与血性成分解释砖红胶冻样痰，重度实变/渗出造成肺叶膨胀解释叶间隙下坠；两种线索来自不同变量，病理分布也不能固定为单一形态。抗菌选择按耐药机制、药敏及严重度决定，不能把所有β-内酰胺视作等效。

〈克雷伯杆菌肺炎：误吸、中老年、黏稠血痰与叶间隙下坠〔人群/病史｜痰2特征｜病理型｜影像3｜治疗2层〕〉

支原体常以较缓起病、痰少而持久阵发性剧咳及肺外表现进入候选，影像可由网格走向斑片。β-内酰胺在这一病原上无效；IgM/冷凝集等须结合各自证据限制。课程成人选药不能直接外推儿童、妊娠/哺乳或所有地区，年龄、耐药和疗效共同限制选择。

〈支原体肺炎：缓起、痰少、剧咳和肺外表现〔人群/病史｜缓急/热/WBC｜咳痰｜肺外2｜影像2期｜检查2｜药物3类｜禁忌3〕〉

军团菌同属非典型病原，但可有实质性纤维素性化脓炎；旅行/空调暴露合并急起高热、白细胞升高、腹泻低钠有助于与支原体比较，单一暴露不能定病。尿抗原覆盖范围有限，培养等提供另一取证方向；原六组课程药物保留条件，不作为任意等效互换。空调暴露相关过敏性肺炎另回R8 KP11。

〈军团菌肺炎：非典型病原体中的“急、高热、WBC升高、腹泻低钠”〔非典型身份｜空调/旅行｜年龄｜起病/热/WBC｜痰｜肺外2｜影像｜检查2｜药物6〕〉

病毒性肺炎可有全身反应突出而咳痰较少的表现；上皮和间质损伤严重时跨入肺泡，才接到透明膜和更严重低氧。外周磨玻璃不是单独病原确证。治疗先支持并按具体病毒选择相应药物；重症流感本身不自动构成常规激素适应证，也不用抗生素预防继发细菌感染，存在明确细菌感染再按相应证据用药。

〈病毒性肺炎：全身反应突出，肺部从间质损伤走向透明膜〔季节/起病｜WBC｜症状强弱｜影像4｜病理4｜透明膜4病毒｜包涵体位点｜治疗3〕〉

【证据和治疗反应回看同一病变，按并发支路交接】

影像确认肺内异常及其空间，痰/其他标本培养、IgM或冷凝集、军团菌检查、PCR、胸水培养等回答不同病原问题。结果须合看标本质量、定植可能及检测覆盖范围，炎症指标不能替代病原证据。获得更可靠证据后才把候选与相应治疗条件进一步收窄。

〈肺炎证据层：有无肺炎、是哪种病原、哪项结果最有意义〔影像顺序2｜病原证据5｜痰阈值｜军团菌2检｜IgM含义〕〉

好发部位是对候选的加权，不替代病程、痰、肺外表现、影像和取证。重力依赖下叶斑片、整叶实变、多发空洞或外周磨玻璃都需要回到形成它的空间机制，而不是由位置直接指定病原。

〈好发部位与影像入口：下叶规律，不替代完整病例〔好发部位：大叶1/小叶2｜位置+病程+痰/肺外+影像+证据〕〉

同一病例合读环境、空间、病原线索、证据、严重度与并发症；原五步用于整理信息，危重识别和必要处理不等到最后一步。抗菌后仍不改善须重新寻找未覆盖病原、耐药、给药问题、坏死脓腔或持续源；脓腔回R6 KP11–15，脓胸回R10 KP12，严重屏障损伤及顽固低氧回R12 KP02–06。观察结果由此反馈下一步干预，而不是成为病理过程的新阶段。

〈肺炎病例五步：环境—空间—病原—严重度—并发症〔环境｜空间｜病原线索｜证据｜严重度｜并发去向〕〉
```

# Unit A｜先定环境、证据与严重度

## KP01｜肺炎空间总坐标：肺泡、细支气管周围还是间质

> **讲义定位 →** 病理 Lecture PDF P72；内科 Lecture PDF P33  
> **Outline →** 病理 U002｜肺炎1–4  
> **主提示：** 空间/炎症/影像3轴｜非典型病原vs间质病变｜重症跨界

| 类型 | 主病变空间 | 当前 Study 炎症口径 | 典型影像入口 |
|---|---|---|---|
| 大叶性肺炎 | 肺泡 | 纤维素性炎 | 肺段 / 肺叶实变，支气管充气征 |
| 小叶性 / 支气管肺炎 | 细支气管及周围末梢肺组织 | 化脓性炎，中性粒细胞为主 | 双肺下叶、背侧不规则斑片影 |
| 军团菌肺炎 | 肺实质，可呈小叶或大叶分布 | 纤维素性化脓性炎 | 斑片或实变，可进展 |
| 病毒 / 支原体 / 衣原体肺炎 | 肺泡间隔 / 间质 | 间质性肺炎 | 网格、磨玻璃或后期斑片影 |

### 非典型病原体不等于间质性肺炎

```text
非典型病原体
= 军团菌 + 支原体 + 衣原体
→ 主要按对β-内酰胺类不敏感的病原学口径命名

间质性肺炎
= 病毒 + 支原体 + 衣原体
→ 主要按病变位置命名
```

所以：

- 病毒性肺炎属于间质性肺炎，但病毒不在本节“非典型病原体三联”内；
- 军团菌属于非典型病原体，但其肺炎侵犯肺实质，不属于典型间质性肺炎。

（边界：病情严重时，间质性肺炎也可累及肺泡实质、出现混合渗出甚至坏死，不能把“间质”理解成永不累及肺泡。）

## KP02｜CAP vs HAP：先问在哪里获得，再问误吸了谁

> **讲义定位 →** 内科 Lecture PDF P33  
> **Outline →** 内科 U011｜概论1–5  
> **主提示：** CAP/HAP定义｜途径4/2｜病原5/5｜误吸来源｜淋巴入口边界

### 1｜CAP

```text
医院外发生
或
院外感染有明确潜伏期的病原体，入院后在潜伏期内发病
```

感染途径：

- 空气吸入；
- 误吸上呼吸道定植菌；
- 邻近感染灶蔓延；
- 血行播散。

**没有“淋巴道感染”这一入口。** 肺结核的结核性淋巴管炎属于感染后的播散方式，不是 CAP 病原从外界进入肺的途径。

常见病原：

- 肺炎链球菌，最常见；
- 支原体；
- 衣原体；
- 流感嗜血杆菌；
- 呼吸道病毒。

### 2｜HAP

```text
入院时不存在、也不处于潜伏期
+ 入院≥48 h后医院内新发生
```

主要入口：

- 误吸胃肠道定植菌；
- 人工气道吸入环境病原。

常见病原：

- 大肠杆菌；
- 克雷伯杆菌；
- 鲍曼不动杆菌；
- 铜绿假单胞菌；
- 金黄色葡萄球菌。

（易混：CAP 强调误吸上呼吸道定植菌；HAP 强调胃肠道定植菌与人工气道。当前 Study 同时提示胃肠道定植菌可包括 G⁻杆菌和厌氧菌，但 HAP 高频病原名单不机械等同于“所有厌氧菌”。）

## KP03｜肺炎证据层：有无肺炎、是哪种病原、哪项结果最有意义

> **讲义定位 →** 内科 Lecture PDF P33–34  
> **Outline →** 内科 U011｜概论6–8  
> **主提示：** 影像顺序2｜病原证据5｜痰阈值｜军团菌2检｜IgM含义

### 1｜先确认有无肺炎

```text
胸部X线
→ 需要进一步定位或影像不典型时做CT
```

### 2｜再找病原

| 检查 | 当前 Study 角色 |
|---|---|
| 痰培养 | 讲义列常用及 `≥10⁷ cfu/mL`；该量级须结合合格痰标本、优势菌与临床，不适用于所有采样方式，不能把定植菌自动当病原 |
| 经皮细针吸检 | 敏感性、特异性较高，但有创 |
| 胸腔积液培养 | 正常胸水中无病原，培养阳性可高度支持致病菌 |
| 特异性 IgM / 冷凝集试验 | 讲义用IgM提示近期感染；不同病原的特异性血清学须分别解释，冷凝集不是它们共同的特异确诊试验 |
| PCR | 检测核酸，适合新发或变异病毒 |

军团菌：

```text
培养 = 诊断金标准
尿抗原 = 最常用（讲义口径）
```

军团菌尿抗原通常主要检出嗜肺军团菌血清群1，阴性不能排除其他型；CDC建议与下呼吸道培养或分子检测配合。IgM可受采样时点、持续阳性或交叉反应影响，单次阳性不自动证明本次肺炎病原。

（易混：一般肺炎常用痰培养确定病原；肺结核的“痰涂片首选、培养金标准”属于 R7。）

## KP04｜CURB-65：先找谁可能不能留在普通肺炎路径

> **讲义定位 →** 内科 Lecture PDF P34  
> **Outline →** 内科 U011｜概论9  
> **主提示：** C-U-R-B-65｜5阈值｜休克优先轴

```text
C｜Confusion：意识障碍
U｜Urea：血尿素 >7 mmol/L（不能把这个数值直接当BUN的mg/dL阈值）
R｜Respiratory rate：呼吸频率 ≥30次/分
B｜Blood pressure：收缩压<90 或舒张压≤60 mmHg，满足任一即可
65｜年龄 ≥65岁
```

这五项不是病原诊断，而是严重度入口。病例中出现血压、意识、呼吸频率和肾功能，必须先看是否已进入重症。

```text
肺炎 + 休克
→ 循环复苏 / 补液与尽快抗感染并行
→ 不等待补液完成才给抗菌药；取材也不应造成明显延误
```

//串联：严重肺炎后出现顽固低氧、双肺弥漫影，完整 ARDS / 呼衰模型后置 R12。

# Unit B｜病理空间：肺泡实变、小叶化脓与间质损伤

## KP05｜大叶性肺炎：肺泡被填满，但支气管仍含气

> **讲义定位 →** 病理 Lecture PDF P73；内科 Lecture PDF P34–35  
> **Outline →** 病理 U002｜肺炎5–6；内科 U011｜链球菌1–5  
> **主提示：** 人群/病原｜肺泡空间｜蔓延2路径｜支气管/胸膜｜实变4征/纵隔｜充气征机制

### 1｜身份

- 肺炎链球菌等多见；
- 常见于青壮年；
- 病变主体是肺泡内以纤维素为主的渗出。

### 2｜实变怎样扩展

```text
肺泡内浆液、纤维素和细胞渗出
→ 肺泡气体消失
→ 经Cohn孔或呼吸性细支气管在肺段内蔓延
→ 部分或整个肺大叶实变

跨肺叶
→ 经肺叶支气管播散
```

### 3｜支气管和胸膜

- 支气管通常不受累，腔内仍含气；
- 胸膜多可受累。

因此：

```text
白色高密度实变肺泡
衬托
黑色低密度含气支气管
→ 支气管充气征
```

### 4｜实变体征

- 叩诊浊音或实音；
- 湿啰音；
- 语音震颤增强；
- 异常支气管呼吸音或支气管肺泡呼吸音；
- 单纯实变一般无明显纵隔移位。

（易混：语颤增强还可见大空洞、胸腔积液上方；异常支气管呼吸音不能脱离病变空间单独定病。）

## KP06｜大叶性肺炎四期与肺肉质变：纤维素能否被清掉

> **讲义定位 →** 病理 Lecture PDF P73  
> **Outline →** 病理 U002｜肺炎7–8  
> **主提示：** 四期｜并发4｜最常见/最严重｜肉质变链｜机化/肉芽肿辨别

### 1｜典型自然病程四期

```text
充血水肿期
→ 红色肝样变期
→ 灰色肝样变期
→ 溶解消散期
```

- **充血水肿**：肺泡间隔毛细血管扩张充血，肺泡内浆液为主；
- **红色肝样变**：纤维蛋白 + 大量红细胞进入肺泡；
- **灰色肝样变**：红细胞减少，纤维蛋白与中性粒细胞更突出；
- **溶解消散**：中性粒细胞释放蛋白水解酶，溶解纤维素。

### 2｜并发症总体少见

- 肺肉质变 / 机化性肺炎：最常见；
- 胸膜肥厚和粘连；
- 肺脓肿和脓胸；
- 感染中毒性休克、败血症：最严重。

### 3｜肺肉质变机制

```text
中性粒细胞数量过少或功能缺陷
→ 蛋白酶不足
→ 肺泡内纤维素不能完全溶解吸收
→ 肉芽组织长入并取代纤维素
→ 机化
→ 病肺呈褐色肉样外观
```

（易混：这里是**肉芽组织机化**，不是形成肉芽肿。）

## KP07｜小叶性肺炎：以细支气管为中心的化脓性斑片病变

> **讲义定位 →** 病理 Lecture PDF P73–74；内科 Lecture PDF P33、P39  
> **Outline →** 病理 U002｜肺炎9–14；内科 U013｜好发部位1  
> **主提示：** 人群/病因｜中心结构｜炎症细胞｜好发部位｜影像｜并发症｜胸膜边界

### 1｜典型人群与上游背景

常见于：

- 久病卧床者；
- 老年人；
- 婴幼儿；
- 体弱者；
- 麻疹后、术后、吸入性、坠积性肺炎等并发背景。

### 2｜病变空间

```text
细支气管及其周围末梢肺组织
→ 中性粒细胞为主的化脓性炎
→ 支气管和肺泡均可受累
```

### 3｜位置与影像

- 重力相关：双肺下叶、背侧多见；
- X线：不规则斑片影；
- CT：可沿支气管血管束分布。

### 4｜并发症

相较大叶性肺炎：

> **更多、更严重。**

（边界：病理学考试口径强调小叶性肺炎一般不累及胸膜；内科学并不把这条作为绝对临床规则，不能跨学科机械排除。）

## KP08｜间质性肺炎与病情进展：主轴在肺泡间隔，但严重时可跨进肺泡

> **讲义定位 →** 病理 Lecture PDF P72、P74–75；内科 Lecture PDF P36–37  
> **Outline →** 病理 U002｜肺炎2–4、15–21  
> **主提示：** 病原3｜间隔3变｜肺泡渗出方向｜重症跨界｜透明膜4病毒｜包涵体3位点

### 1｜基本病理

```text
肺泡间隔明显增宽
+ 间质血管扩张充血
+ 间质水肿
+ 淋巴细胞、单核细胞浸润
→ 间质性肺炎
```

肺泡腔通常：

- 无明显渗出；或
- 仅少量浆液。

因此常表现为干咳、痰少。

### 2｜严重时不再“只在间质”

可出现：

- 肺泡内浆液、少量纤维素、红细胞和巨噬细胞混合渗出；
- 肺组织坏死；
- 间质病变特征被实质病变掩盖。

### 3｜透明膜与 R12 边界

流感、麻疹、冠状病毒、腺病毒肺炎可在肺泡内形成透明膜。

```text
严重病毒感染
→ 肺泡上皮 / 呼吸膜损伤
→ 浆液性渗出浓缩贴附肺泡壁
→ 透明膜
```

//串联：弥漫性肺泡损伤与 ARDS 的完整时相、氧合和通气处理后置 R12。

### 4｜病毒包涵体

| 病毒 | 包涵体位置 / 染色 |
|---|---|
| 麻疹病毒 | 胞核 + 胞质 |
| 呼吸道合胞病毒 | 胞质，嗜酸性 |
| 腺病毒、巨细胞病毒 | 讲义列典型核内嗜碱性包涵体；CMV还可有胞质包涵体 |
| 单纯疱疹病毒 | 核内；典型Cowdry A包涵体可嗜酸性，不能因位于细胞核就一概判嗜碱性 |

包涵体多见于增生上皮细胞和多核巨细胞，呈圆形或椭圆形，周围可有透明晕。病理讲义P73将三者合并为“胞核嗜碱性”，此处拆开其形态差异；不能把胞核染色质嗜碱性直接推成所有病毒包涵体均嗜碱性。

# Unit C｜六个病原模型：用病例入口，不用孤立名单

## KP09｜肺炎链球菌肺炎：青壮年实变模型

> **讲义定位 →** 内科 Lecture PDF P34–35；病理 Lecture PDF P73  
> **Outline →** 内科 U011｜链球菌1–5；U012｜链球菌6–9  
> **主提示：** 人群/诱因｜症状4｜实变4征｜影像2｜致病物｜空洞边界｜治疗3｜退热时窗/失败评估

### 1｜识别入口

- 青壮年；
- 受凉、醉酒后；
- 急性寒战、高热；
- 铁锈色痰；
- 外周血 WBC↑；
- 可伴口角单纯疱疹；
- 肺实变体征。

铁锈色痰链：

```text
炎症使红细胞进入肺泡
→ 巨噬细胞分解Hb
→ 含铁血黄素随痰排出
```

### 2｜影像

- 大叶性实变影；
- 支气管充气征；
- 当前 Study 强调通常不形成空洞。

### 3｜致病与免疫口径

```text
荚膜是重要毒力因素
→ 经典大叶性肺炎通常结构破坏较少，治疗后多可消散
→ 同型菌二次感染较少
```

讲义“不产生毒素/绝无空洞”是过度绝对化：肺炎链球菌存在肺炎链球菌溶血素（pneumolysin）；“通常不形成空洞”用于典型病例识别，不能据此绝对排除坏死性并发症。

（边界：病理“大叶性肺炎”是形态分类，不完全等同于肺炎链球菌；若混合化脓菌感染，仍可出现脓肿或脓胸。）

### 4｜治疗

- 讲义首选青霉素，实际需结合药敏、感染部位和当地耐药；
- 耐药时按 Study 可用喹诺酮、头孢噻肟、头孢曲松；
- 合并休克，及时循环复苏并尽快抗感染，不按先后串行延误。

抗菌治疗约3天后体温仍不降或降而复升：讲义提示肺外感染，如脓胸、心包炎、关节炎；同时复核病原、耐药、给药及其他并发症，不能仅凭发热锁定一种原因。

## KP10｜金葡菌肺炎：最易形成多发易变空洞

> **讲义定位 →** 内科 Lecture PDF P35  
> **Outline →** 内科 U012｜金葡菌1–4  
> **主提示：** 病史4组｜痰｜影像4型/胸膜并发｜空洞倾向｜MSSA/MRSA药物｜血源脓肿接口

### 1｜病例入口

- 糖尿病；
- 痈、疖；
- 骨髓炎；
- 住院、频繁使用抗生素；
- 急性寒战高热、WBC↑；
- 脓痰带血。

### 2｜影像

- 多发、易变结节；
- 斑片或实变影；
- 多发空洞；
- 液气囊腔 / 肺气囊；
- 可破入胸膜形成脓气胸。

在“红绿黄臭”中，**金葡菌最易形成空洞**。

### 3｜治疗口径

- 苯唑西林、氯唑西林或头孢呋辛；
- MRSA：万古霉素、替考拉宁、利奈唑胺或头孢洛林。

//串联：金葡菌肺炎与血源性肺脓肿可视作同一化脓感染谱的不同阶段；R6再完整建立菌栓—双肺外周多发脓腔模型。

## KP11｜克雷伯杆菌肺炎：误吸、中老年、黏稠血痰与叶间隙下坠

> **讲义定位 →** 内科 Lecture PDF P35–36  
> **Outline →** 内科 U012｜克雷伯1–4  
> **主提示：** 人群/病史｜痰2特征｜病理型｜影像3｜治疗2层

### 1｜识别入口

- 中老年；
- 醉酒、脑卒中等误吸背景；
- 急性寒战高热、WBC↑；
- 砖红色胶冻状痰。

```text
砖红色
→ 血管受损、痰中含血

胶冻状
→ 痰液黏稠

叶间裂膨出 / 下坠
→ 反映受累肺叶膨胀与大量渗出，不能仅从“咳出痰黏稠”直接推出
```

### 2｜病理与影像

- 当前 Study 归入小叶性肺炎；实际也可出现肺叶实变，形态并非只能一种；
- 斑片或实变；
- 蜂窝状脓肿；
- 易形成空洞。

### 3｜治疗

- β-内酰胺类；
- 重症按 Study 联合喹诺酮或氨基糖苷，如阿米卡星、妥布霉素。

叶间裂膨出是经典线索，并非每例均有，也非特异征。治疗须按药敏和耐药机制选药，不能把全部β-内酰胺视为等效。

（易混：多发小脓腔与纤维化蜂窝肺不是同一病理结构；影像相似时须结合临床，不能仅凭“蜂窝”互相替代诊断。）

## KP12｜支原体肺炎：缓起、痰少、剧咳和肺外表现

> **讲义定位 →** 内科 Lecture PDF P36；病理 Lecture PDF P72  
> **Outline →** 内科 U012｜支原体1–6；病理 U002｜肺炎3–4  
> **主提示：** 人群/病史｜缓急/热/WBC｜咳痰｜肺外2｜影像2期｜检查2｜药物3类｜禁忌3

### 1｜病例入口

- 儿童、青年；
- 外出、郊游史；
- 潜伏约2–3周，起病较缓；
- 低中热或不发热；
- WBC正常或略升；
- 痰少；
- 持久阵发性剧咳，退热后仍可持续；
- 耳痛、皮疹等肺外表现；
- 可自限。

### 2｜影像

```text
早期：间质网格影
→ 后期：沿支气管 / 肺纹理分布的斑片影，多见双肺下叶
```

通常不形成空洞。

### 3｜病原证据

- 讲义列支原体IgM、冷凝集试验；单次IgM及冷凝集阳性均不能独立确诊本次感染，冷凝集尤其缺乏特异性；
- 现代病原确认优先考虑呼吸道标本核酸扩增，血清学必要时比较急性期和恢复期，结合病程解释。

### 4｜治疗口径

当前 Study：

- 讲义因大环内酯耐药问题列喹诺酮（左氧氟沙星、莫西沙星）为首选；该选项口径不能泛化到所有年龄和地区；
- 四环素类也可用；
- β-内酰胺类无效；
- 妊娠、哺乳及 `<18岁` 不用喹诺酮。

临床选药须看年龄、妊娠/哺乳、当地耐药及疗效：儿童通常仍以大环内酯为起点；耐药或无改善时再按年龄和风险选择替代方案，不能把“儿童多见”与“成人喹诺酮首选”直接拼成儿童用药指令。保留讲义选项与临床适用人群的区别。

## KP13｜军团菌肺炎：非典型病原体中的“急、高热、WBC升高、腹泻低钠”

> **讲义定位 →** 内科 Lecture PDF P36–37  
> **Outline →** 内科 U013｜军团菌1–2  
> **主提示：** 非典型身份｜空调/旅行｜年龄｜起病/热/WBC｜痰｜肺外2｜影像｜检查2｜药物6

### 1｜与支原体共同点

- 都属于非典型病原体；
- 可有旅行 / 郊游史；
- 痰少；
- 肺外表现可多；
- 对β-内酰胺类不敏感；
- 影像可由斑片向实变进展。

### 2｜军团菌识别点

```text
年龄偏大
+ 起病较急
+ 高热
+ WBC↑
+ 腹泻 / 消化道表现
+ 低钠血症
+ 空调暴露
```

（特殊：提到“空调”还要想到过敏性肺炎；后者属于 R8。）

### 3｜检查与治疗

- 培养金标准，尿抗原最常用；
- 可用大环内酯、喹诺酮、多西环素、替加环素、复方磺胺甲噁唑、利福平。

（易混：军团菌是非典型病原体，但不是典型间质性肺炎；其病理可呈纤维素性化脓性实质炎。）

## KP14｜病毒性肺炎：全身反应突出，肺部从间质损伤走向透明膜

> **讲义定位 →** 病理 Lecture PDF P74–75；内科 Lecture PDF P37  
> **Outline →** 病理 U002｜肺炎15–21；内科 U013｜病毒1–4  
> **主提示：** 季节/起病｜WBC｜症状强弱｜影像4｜病理4｜透明膜4病毒｜包涵体位点｜治疗3

### 1｜临床入口

- 冬春多见；
- 急性寒战高热；
- WBC多正常或下降，淋巴细胞可升可降；
- 痰少；
- 全身症状突出；
- 肺部体征可轻，也可在重症时明显。

### 2｜影像

- 双肺外周、胸膜下磨玻璃或斑片影；
- 可有实变；
- 大片实变和明显胸腔积液少见；
- 不易形成空洞。

### 3｜病理主链

```text
病毒侵犯肺泡上皮 / 间质
→ 肺泡间隔增宽、水肿、充血
→ 淋巴细胞、单核细胞浸润
→ 肺泡内渗出少
→ 重症时混合渗出、坏死和透明膜
```

### 4｜治疗口径

- 对症支持；
- 抗病毒药：讲义列奥司他韦、利巴韦林、阿昔洛韦等；必须按具体病毒与适应证选择，奥司他韦用于流感，阿昔洛韦用于相应疱疹病毒感染，不能当通用病毒性肺炎药互换；
- 讲义写“重症可酌情使用糖皮质激素”，须补病原/适应证条件：流感肺炎不因重症就常规加激素，另有哮喘急性发作、肾上腺功能不足或难治性休克等适应证时另论；
- 不用抗生素预防继发细菌感染，确有细菌感染再选敏感药。

//串联：严重病毒感染并发 ARDS 时，进入 R12，不在此展开机械通气与氧合策略。

## KP15｜肺实变为何“声音更强”：气体被渗出物替代后的传导变化

> **讲义回看 →** R1 气道与肺泡空间；内科 Lecture PDF P34–35  
> **Outline →** 内科 U011｜链球菌2–3  
> **主提示：** 叩诊｜语颤｜呼吸音｜湿啰音｜纵隔｜机制1链

```text
正常含气肺泡
→ 空气多，声音传导相对弱

肺泡被浆液、纤维素和细胞填满
→ 肺组织密度增加
→ 声音传导增强
→ 语音震颤增强
→ 可闻异常支气管呼吸音
```

同时：

- 含气下降 → 叩诊浊音或实音；
- 液体与气流相互作用 → 湿啰音；
- 单纯实变体积变化不大 → 一般无明显纵隔移位。

（易混：胸腔积液本体使语颤和呼吸音减弱，但积液上方被压实肺组织可传导增强。）

## KP16｜好发部位与影像入口：下叶规律，不替代完整病例

## KP17｜空洞病原与肺炎结局：谁会破坏肺组织

> **讲义定位 →** 内科 Lecture PDF P33、P35–36  
> **Outline →** 内科 U011｜概论5；U012相关空洞题  
> **主提示：** 空洞4病原｜最易1｜坏死/引流/空洞/修复链｜链球菌/结核边界

```text
毒力 / 化脓性坏死
→ 肺组织被破坏、液化
→ 坏死物经引流支气管排出
→ 空间重新充气
→ 空洞
→ 肉芽组织修复
→ 纤维瘢痕
```

“红绿黄臭”：

- 红：金黄色葡萄球菌；
- 绿：铜绿假单胞菌；
- 黄：克雷伯杆菌；
- 臭：厌氧菌。

金葡菌最易形成空洞。

（易混：肺炎链球菌按当前 Study 通常不坏死、不形成空洞；结核空洞来自干酪样坏死，属于 R7；肺脓肿是脓腔与引流模型，属于 R6。）

## KP18｜肺炎病例五步：环境—空间—病原—严重度—并发症

> **讲义回看 →** 本 Block 全部  
> **Outline →** 内科 U011–U013 综合  
> **主提示：** 环境｜空间｜病原线索｜证据｜严重度｜并发去向

### Step 1｜环境

- CAP 还是 HAP？
- 是否误吸、人工气道、住院、旅行、空调、皮肤感染？

### Step 2｜空间

- 整叶实变？
- 双下叶斑片？
- 网格 / 磨玻璃？
- 多发易变空洞？

### Step 3｜病原线索

- 铁锈色；
- 脓血痰；
- 砖红胶冻；
- 痰少剧咳；
- 腹泻低钠；
- 冬春全身症状。

### Step 4｜证据

- X线 / CT；
- 痰培养；
- IgM / 冷凝集；
- 军团菌尿抗原 / 培养；
- PCR；
- 胸水培养。

### Step 5｜严重度与并发症

- CURB-65；
- 休克；
- 坏死空洞；
- 脓胸；
- 顽固低氧 / ARDS；
- 抗菌3天体温不降或复升。
