## 0｜这个 Block 到底解决什么

“肺炎”不是一个只靠病原名单识别的疾病。先问病变占据哪里，再问病原和严重度：

```text
病原进入肺
→ 占据肺泡 / 细支气管及周围末梢肺组织 / 肺间质
→ 形成纤维素性、化脓性或间质性炎症
→ 改变肺泡含气、声音传导、VA/Q与影像
→ 再用环境、病史、痰、肺外表现和病原证据定位病原
→ 判断是否进入重症、坏死空洞、脓胸、休克或ARDS
```

### 本 Block 的总任务

> **看到发热、咳嗽、咳痰或肺部阴影时，先完成“环境—空间—炎症—证据—严重度”五步定位，而不是逮住一个痰色或影像征就定病。**

## 1｜总 Framework

```text
A｜先定获得环境

院外 / 入院潜伏期内
→ CAP

入院≥48 h后新发，入院时不存在也不在潜伏期
→ HAP

        ↓

B｜再定病变空间

肺泡被纤维素与细胞填满
→ 大叶性肺炎 / 肺泡实变

细支气管为中心向周围末梢肺组织扩展
→ 小叶性 / 支气管肺炎

肺泡间隔增宽、水肿、单核淋巴细胞浸润
→ 间质性肺炎

        ↓

C｜用影像和体征证明空间

整叶 / 肺段实变 + 支气管充气征
→ 肺泡有渗出，支气管仍含气

双肺下叶背侧斑片影
→ 小叶性分布

网格 / 磨玻璃 / 外周胸膜下影
→ 间质或病毒性入口

        ↓

D｜再定病原模型

青壮年 + 受凉醉酒 + 铁锈色痰
→ 肺炎链球菌

脓血痰 + 多发易变结节 / 空洞 / 液气囊腔
→ 金葡菌

中老年误吸 + 砖红胶冻痰 + 叶间隙下坠
→ 克雷伯杆菌

儿童青年 + 缓起 + 持久阵发性剧咳 + 痰少
→ 支原体

旅行 / 空调 + 高热 + 腹泻 + 低钠
→ 军团菌

冬春 + 全身症状突出 + WBC正常或低 + 外周磨玻璃
→ 病毒性肺炎

        ↓

E｜最后判断严重度与并发症

CURB-65
+ 血压 / 意识 / 呼吸频率 / 肾功能 / 年龄
+ 坏死空洞 / 胸水 / 休克 / 顽固低氧
→ 决定普通肺炎还是重症与后续模型
```

# Unit A｜先定环境、证据与严重度

## KP01｜肺炎空间总坐标：肺泡、细支气管周围还是间质

> **讲义定位 →** 病理 Lecture PDF P72；内科 Lecture PDF P33  
> **Outline →** 病理 U002｜肺炎1–4  
> **主提示：** 空间3｜炎症3｜影像3｜（易混：非典型病原体 vs 间质性肺炎？）

| 类型 | 主病变空间 | 当前 Study 炎症口径 | 典型影像入口 |
|---|---|---|---|
| 大叶性肺炎 | 肺泡 | 纤维素性炎 | 肺段 / 肺叶实变，支气管充气征 |
| 小叶性 / 支气管肺炎 | 细支气管及周围末梢肺组织 | 化脓性炎，中性粒细胞为主 | 双肺下叶、背侧不规则斑片影 |
| 军团菌肺炎 | 肺实质，可呈小叶或大叶分布 | 纤维素性化脓性炎 | 斑片或实变，可进展 |
| 病毒 / 支原体 / 衣原体肺炎 | 肺泡间隔 / 间质 | 间质性肺炎 | 网格、磨玻璃或后期斑片影 |

### 非典型病原体不等于间质性肺炎

```text
非典型病原体
= 军团菌 + 支原体 + 衣原体
→ 主要按对β-内酰胺类不敏感的病原学口径命名

间质性肺炎
= 病毒 + 支原体 + 衣原体
→ 主要按病变位置命名
```

所以：

- 病毒性肺炎属于间质性肺炎，但病毒不在本节“非典型病原体三联”内；
- 军团菌属于非典型病原体，但其肺炎侵犯肺实质，不属于典型间质性肺炎。

（边界：病情严重时，间质性肺炎也可累及肺泡实质、出现混合渗出甚至坏死，不能把“间质”理解成永不累及肺泡。）

## KP02｜CAP vs HAP：先问在哪里获得，再问误吸了谁

> **讲义定位 →** 内科 Lecture PDF P33  
> **Outline →** 内科 U011｜概论1–5  
> **主提示：** 定义2｜途径4/2｜病原5/5｜误吸来源｜（边界：无哪条途径？）

### 1｜CAP

```text
医院外发生
或
院外感染有明确潜伏期的病原体，入院后在潜伏期内发病
```

感染途径：

- 空气吸入；
- 误吸上呼吸道定植菌；
- 邻近感染灶蔓延；
- 血行播散。

**没有“淋巴道感染”这一入口。** 肺结核的结核性淋巴管炎属于感染后的播散方式，不是 CAP 病原从外界进入肺的途径。

常见病原：

- 肺炎链球菌，最常见；
- 支原体；
- 衣原体；
- 流感嗜血杆菌；
- 呼吸道病毒。

### 2｜HAP

```text
入院时不存在、也不处于潜伏期
+ 入院≥48 h后医院内新发生
```

主要入口：

- 误吸胃肠道定植菌；
- 人工气道吸入环境病原。

常见病原：

- 大肠杆菌；
- 克雷伯杆菌；
- 鲍曼不动杆菌；
- 铜绿假单胞菌；
- 金黄色葡萄球菌。

（易混：CAP 强调误吸上呼吸道定植菌；HAP 强调胃肠道定植菌与人工气道。当前 Study 同时提示胃肠道定植菌可包括 G⁻杆菌和厌氧菌，但 HAP 高频病原名单不机械等同于“所有厌氧菌”。）

## KP03｜肺炎证据层：有无肺炎、是哪种病原、哪项结果最有意义

> **讲义定位 →** 内科 Lecture PDF P33–34  
> **Outline →** 内科 U011｜概论6–8  
> **主提示：** 影像顺序2｜病原证据5｜痰阈值｜军团菌2检｜IgM含义

### 1｜先确认有无肺炎

```text
胸部X线
→ 需要进一步定位或影像不典型时做CT
```

### 2｜再找病原

| 检查 | 当前 Study 角色 |
|---|---|
| 痰培养 | 最常用；致病菌 `≥10⁷ cfu/mL` 才更有意义 |
| 经皮细针吸检 | 敏感性、特异性较高，但有创 |
| 胸腔积液培养 | 正常胸水中无病原，培养阳性可高度支持致病菌 |
| 特异性 IgM / 冷凝集试验 | 提示近期感染；常用于病毒、支原体、衣原体、军团菌等痰少者 |
| PCR | 检测核酸，适合新发或变异病毒 |

军团菌：

```text
培养 = 诊断金标准
尿抗原 = 最常用
```

（易混：一般肺炎常用痰培养确定病原；肺结核的“痰涂片首选、培养金标准”属于 R7。）

## KP04｜CURB-65：先找谁可能不能留在普通肺炎路径

> **讲义定位 →** 内科 Lecture PDF P34  
> **Outline →** 内科 U011｜概论9  
> **主提示：** C-U-R-B-65｜5阈值｜//识别：休克先做什么？

```text
C｜Confusion：意识障碍
U｜Urea：尿素氮 >7 mmol/L
R｜Respiratory rate：呼吸频率 ≥30次/分
B｜Blood pressure：血压 ≤90/60 mmHg
65｜年龄 ≥65岁
```

这五项不是病原诊断，而是严重度入口。病例中出现血压、意识、呼吸频率和肾功能，必须先看是否已进入重症。

```text
肺炎 + 休克
→ 先恢复循环血容量 / 补液
→ 再继续病原与抗感染处理
```

//串联：严重肺炎后出现顽固低氧、双肺弥漫影，完整 ARDS / 呼衰模型后置 R12。

# Unit B｜病理空间：肺泡实变、小叶化脓与间质损伤

## KP05｜大叶性肺炎：肺泡被填满，但支气管仍含气

> **讲义定位 →** 病理 Lecture PDF P73；内科 Lecture PDF P34–35  
> **Outline →** 病理 U002｜肺炎5–6；内科 U011｜链球菌1–5  
> **主提示：** 人群/病原｜空间｜蔓延2｜支气管/胸膜｜实变4征｜支气管充气征

### 1｜身份

- 肺炎链球菌等多见；
- 常见于青壮年；
- 病变主体是肺泡内以纤维素为主的渗出。

### 2｜实变怎样扩展

```text
肺泡内浆液、纤维素和细胞渗出
→ 肺泡气体消失
→ 经Cohn孔或呼吸性细支气管在肺段内蔓延
→ 部分或整个肺大叶实变

跨肺叶
→ 经肺叶支气管播散
```

### 3｜支气管和胸膜

- 支气管通常不受累，腔内仍含气；
- 胸膜多可受累。

因此：

```text
白色高密度实变肺泡
衬托
黑色低密度含气支气管
→ 支气管充气征
```

### 4｜实变体征

- 叩诊浊音或实音；
- 湿啰音；
- 语音震颤增强；
- 异常支气管呼吸音或支气管肺泡呼吸音；
- 单纯实变一般无明显纵隔移位。

（易混：语颤增强还可见大空洞、胸腔积液上方；异常支气管呼吸音不能脱离病变空间单独定病。）

## KP06｜大叶性肺炎四期与肺肉质变：纤维素能否被清掉

> **讲义定位 →** 病理 Lecture PDF P73  
> **Outline →** 病理 U002｜肺炎7–8  
> **主提示：** 四期｜并发4｜最常见/最严重｜肉质变链｜（易混：机化≠肉芽肿）

### 1｜典型自然病程四期

```text
充血水肿期
→ 红色肝样变期
→ 灰色肝样变期
→ 溶解消散期
```

- **充血水肿**：肺泡间隔毛细血管扩张充血，肺泡内浆液为主；
- **红色肝样变**：纤维蛋白 + 大量红细胞进入肺泡；
- **灰色肝样变**：红细胞减少，纤维蛋白与中性粒细胞更突出；
- **溶解消散**：中性粒细胞释放蛋白水解酶，溶解纤维素。

### 2｜并发症总体少见

- 肺肉质变 / 机化性肺炎：最常见；
- 胸膜肥厚和粘连；
- 肺脓肿和脓胸；
- 感染中毒性休克、败血症：最严重。

### 3｜肺肉质变机制

```text
中性粒细胞数量过少或功能缺陷
→ 蛋白酶不足
→ 肺泡内纤维素不能完全溶解吸收
→ 肉芽组织长入并取代纤维素
→ 机化
→ 病肺呈褐色肉样外观
```

（易混：这里是**肉芽组织机化**，不是形成肉芽肿。）

## KP07｜小叶性肺炎：以细支气管为中心的化脓性斑片病变

> **讲义定位 →** 病理 Lecture PDF P73–74；内科 Lecture PDF P33、P39  
> **Outline →** 病理 U002｜肺炎9–14；内科 U013｜好发部位1  
> **主提示：** 人群/病因｜中心结构｜炎症细胞｜好发部位｜影像｜并发症｜胸膜边界

### 1｜典型人群与上游背景

常见于：

- 久病卧床者；
- 老年人；
- 婴幼儿；
- 体弱者；
- 麻疹后、术后、吸入性、坠积性肺炎等并发背景。

### 2｜病变空间

```text
细支气管及其周围末梢肺组织
→ 中性粒细胞为主的化脓性炎
→ 支气管和肺泡均可受累
```

### 3｜位置与影像

- 重力相关：双肺下叶、背侧多见；
- X线：不规则斑片影；
- CT：可沿支气管血管束分布。

### 4｜并发症

相较大叶性肺炎：

> **更多、更严重。**

（边界：病理学考试口径强调小叶性肺炎一般不累及胸膜；内科学并不把这条作为绝对临床规则，不能跨学科机械排除。）

## KP08｜间质性肺炎与病情进展：主轴在肺泡间隔，但严重时可跨进肺泡

> **讲义定位 →** 病理 Lecture PDF P72、P74–75；内科 Lecture PDF P36–37  
> **Outline →** 病理 U002｜肺炎2–4、15–21  
> **主提示：** 病原3｜间隔3变｜肺泡渗出方向｜重症跨界｜透明膜4病毒｜包涵体3位点

### 1｜基本病理

```text
肺泡间隔明显增宽
+ 间质血管扩张充血
+ 间质水肿
+ 淋巴细胞、单核细胞浸润
→ 间质性肺炎
```

肺泡腔通常：

- 无明显渗出；或
- 仅少量浆液。

因此常表现为干咳、痰少。

### 2｜严重时不再“只在间质”

可出现：

- 肺泡内浆液、少量纤维素、红细胞和巨噬细胞混合渗出；
- 肺组织坏死；
- 间质病变特征被实质病变掩盖。

### 3｜透明膜与 R12 边界

流感、麻疹、冠状病毒、腺病毒肺炎可在肺泡内形成透明膜。

```text
严重病毒感染
→ 肺泡上皮 / 呼吸膜损伤
→ 浆液性渗出浓缩贴附肺泡壁
→ 透明膜
```

//串联：弥漫性肺泡损伤与 ARDS 的完整时相、氧合和通气处理后置 R12。

### 4｜病毒包涵体

| 病毒 | 包涵体位置 / 染色 |
|---|---|
| 麻疹病毒 | 胞核 + 胞质 |
| 呼吸道合胞病毒 | 胞质，嗜酸性 |
| 腺病毒、单纯疱疹病毒、巨细胞病毒 | 胞核，嗜碱性 |

包涵体多见于增生上皮细胞和多核巨细胞，呈圆形或椭圆形，周围可有透明晕。

# Unit C｜六个病原模型：用病例入口，不用孤立名单

## KP09｜肺炎链球菌肺炎：青壮年实变模型

> **讲义定位 →** 内科 Lecture PDF P34–35；病理 Lecture PDF P73  
> **Outline →** 内科 U011｜链球菌1–5；U012｜链球菌6–9  
> **主提示：** 人群/诱因｜症状4｜实变4征｜影像2｜致病物｜空洞边界｜治疗3｜3天不退热？

### 1｜识别入口

- 青壮年；
- 受凉、醉酒后；
- 急性寒战、高热；
- 铁锈色痰；
- 外周血 WBC↑；
- 可伴口角单纯疱疹；
- 肺实变体征。

铁锈色痰链：

```text
炎症使红细胞进入肺泡
→ 巨噬细胞分解Hb
→ 含铁血黄素随痰排出
```

### 2｜影像

- 大叶性实变影；
- 支气管充气征；
- 当前 Study 强调通常不形成空洞。

### 3｜致病与免疫口径

```text
肺炎链球菌靠荚膜致病
→ 通常不产生导致肺组织坏死的毒素
→ 结构破坏少，治疗后多可消散
→ 同型菌二次感染较少
```

（边界：病理“大叶性肺炎”是形态分类，不完全等同于肺炎链球菌；若混合化脓菌感染，仍可出现脓肿或脓胸。）

### 4｜治疗

- 首选青霉素；
- 耐药时按 Study 可用喹诺酮、头孢噻肟、头孢曲松；
- 合并休克，先补液。

抗菌治疗约3天后体温仍不降或降而复升：考虑肺外感染，如脓胸、心包炎、关节炎等。

## KP10｜金葡菌肺炎：最易形成多发易变空洞

> **讲义定位 →** 内科 Lecture PDF P35  
> **Outline →** 内科 U012｜金葡菌1–4  
> **主提示：** 病史4｜痰｜影像4｜空洞排名｜MSSA/MRSA药物｜//串联：血源性肺脓肿？

### 1｜病例入口

- 糖尿病；
- 痈、疖；
- 骨髓炎；
- 住院、频繁使用抗生素；
- 急性寒战高热、WBC↑；

## KP11｜克雷伯杆菌肺炎：误吸、中老年、黏稠血痰与叶间隙下坠

### 1｜识别入口

- 醉酒、脑卒中等误吸背景；

## KP12｜支原体肺炎：缓起、痰少、剧咳和肺外表现

> **讲义定位 →** 内科 Lecture PDF P36；病理 Lecture PDF P72  
> **Outline →** 内科 U012｜支原体1–6；病理 U002｜肺炎3–4  
> **主提示：** 人群/病史｜缓急/热/WBC｜咳痰｜肺外2｜影像2期｜检查2｜药物3类｜禁忌3

### 1｜病例入口

- 儿童、青年；
- 外出、郊游史；
- 潜伏约2–3周，起病较缓；
- 低中热或不发热；
- WBC正常或略升；
- 痰少；
- 持久阵发性剧咳，退热后仍可持续；
- 耳痛、皮疹等肺外表现；
- 可自限。

### 2｜影像

```text
早期：间质网格影
→ 后期：沿支气管 / 肺纹理分布的斑片影，多见双肺下叶
```

通常不形成空洞。

### 3｜病原证据

- 支原体 IgM；
- 冷凝集试验。

### 4｜治疗口径

当前 Study：

- 因大环内酯耐药问题，首选喹诺酮，如左氧氟沙星、莫西沙星；
- 四环素类也可用；
- β-内酰胺类无效；
- 妊娠、哺乳及 `<18岁` 不用喹诺酮。

（边界：这是当前 Study 的考试口径，不用外部指南静默改写。）

## KP13｜军团菌肺炎：非典型病原体中的“急、高热、WBC升高、腹泻低钠”

> **讲义定位 →** 内科 Lecture PDF P36–37  
> **Outline →** 内科 U013｜军团菌1–2  
> **主提示：** 非典型身份｜空调/旅行｜年龄｜起病/热/WBC｜痰｜肺外2｜影像｜检查2｜药物6

### 1｜与支原体共同点

- 都属于非典型病原体；
- 可有旅行 / 郊游史；
- 痰少；
- 肺外表现可多；
- 对β-内酰胺类不敏感；
- 影像可由斑片向实变进展。

### 2｜军团菌识别点

```text
年龄偏大
+ 起病较急
+ 高热
+ WBC↑
+ 腹泻 / 消化道表现
+ 低钠血症
+ 空调暴露
```

（特殊：提到“空调”还要想到过敏性肺炎；后者属于 R8。）

### 3｜检查与治疗

- 培养金标准，尿抗原最常用；
- 可用大环内酯、喹诺酮、多西环素、替加环素、复方磺胺甲噁唑、利福平。

（易混：军团菌是非典型病原体，但不是典型间质性肺炎；其病理可呈纤维素性化脓性实质炎。）

## KP14｜病毒性肺炎：全身反应突出，肺部从间质损伤走向透明膜

> **讲义定位 →** 病理 Lecture PDF P74–75；内科 Lecture PDF P37  
> **Outline →** 病理 U002｜肺炎15–21；内科 U013｜病毒1–4  
> **主提示：** 季节/起病｜WBC｜症状强弱｜影像4｜病理4｜透明膜4病毒｜包涵体位点｜治疗3

### 1｜临床入口

- 冬春多见；
- 急性寒战高热；
- WBC多正常或下降，淋巴细胞可升可降；
- 痰少；
- 全身症状突出；
- 肺部体征可轻，也可在重症时明显。

### 2｜影像

- 双肺外周、胸膜下磨玻璃或斑片影；
- 可有实变；
- 大片实变和明显胸腔积液少见；
- 不易形成空洞。

### 3｜病理主链

```text
病毒侵犯肺泡上皮 / 间质
→ 肺泡间隔增宽、水肿、充血
→ 淋巴细胞、单核细胞浸润
→ 肺泡内渗出少
→ 重症时混合渗出、坏死和透明膜
```

### 4｜治疗口径

- 对症支持；
- 抗病毒药：Study列举奥司他韦、利巴韦林、阿昔洛韦等；
- 重症可酌情使用糖皮质激素；
- 不用抗生素预防继发细菌感染，确有细菌感染再选敏感药。

//串联：严重病毒感染并发 ARDS 时，进入 R12，不在此展开机械通气与氧合策略。

## KP15｜肺实变为何“声音更强”：气体被渗出物替代后的传导变化

> **讲义回看 →** R1 气道与肺泡空间；内科 Lecture PDF P34–35  
> **Outline →** 内科 U011｜链球菌2–3  
> **主提示：** 叩诊｜语颤｜呼吸音｜湿啰音｜纵隔｜机制1链

```text
正常含气肺泡
→ 空气多，声音传导相对弱

肺泡被浆液、纤维素和细胞填满
→ 肺组织密度增加
→ 声音传导增强
→ 语音震颤增强
→ 可闻异常支气管呼吸音
```

同时：

- 含气下降 → 叩诊浊音或实音；
- 液体与气流相互作用 → 湿啰音；
- 单纯实变体积变化不大 → 一般无明显纵隔移位。

（易混：胸腔积液本体使语颤和呼吸音减弱，但积液上方被压实肺组织可传导增强。）

## KP17｜空洞病原与肺炎结局：谁会破坏肺组织

> **讲义定位 →** 内科 Lecture PDF P33、P35–36  
> **Outline →** 内科 U011｜概论5；U012相关空洞题  
> **主提示：** 空洞4病原｜最易1｜形成链｜瘢痕｜（易混：链球菌？结核？）

毒力 / 化脓性坏死

## KP18｜肺炎病例五步：环境—空间—病原—严重度—并发症

> **讲义回看 →** 本 Block 全部

> **主提示：** 环境｜空间｜病原线索｜证据｜严重度｜并发去向

### Step 1｜环境

- CAP 还是 HAP？
- 是否误吸、人工气道、住院、旅行、空调、皮肤感染？

### Step 2｜空间

- 整叶实变？
- 双下叶斑片？
- 网格 / 磨玻璃？
- 多发易变空洞？

### Step 3｜病原线索

- 铁锈色；
- 脓血痰；
- 砖红胶冻；
- 痰少剧咳；
- 腹泻低钠；
- 冬春全身症状。

### Step 4｜证据

- X线 / CT；
- 痰培养；
- IgM / 冷凝集；
- 军团菌尿抗原 / 培养；
- PCR；
- 胸水培养。

### Step 5｜严重度与并发症

- CURB-65；
- 休克；
- 坏死空洞；
- 脓胸；
- 顽固低氧 / ARDS；
- 抗菌3天体温不降或复升。
