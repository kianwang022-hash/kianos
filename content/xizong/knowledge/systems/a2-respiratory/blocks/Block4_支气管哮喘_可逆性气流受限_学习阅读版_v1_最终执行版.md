## 0｜这个 Block 到底解决什么

哮喘的慢性炎症与神经—平滑肌调节失衡共同维持气道高反应性。上皮损伤使感觉末梢暴露，刺激后释放的介质又增加渗出；同样的外界刺激因而更容易引起平滑肌痉挛、黏膜水肿和黏液增加。气道口径随发作、缓解和治疗波动，呼气时牵拉减弱使已经狭窄的气道更难排气。

口径下降同时改变气流、声音、残气和气体交换。局部通气不足造成低 VA/Q 与低氧，尚能代偿时通气增加可使 PaCO₂下降；严重阻塞或呼吸肌疲劳使有效肺泡通气不足时，PaCO₂可回升。气流极少时哮鸣音也会减弱，因此危险程度要合读气流、血气、呼吸功、意识与循环。

检查读取这些变量及其可变性；治疗回作用于触发、平滑肌收缩、炎症和氧合/通气。急性危险评估贯穿当前发作，长期控制则通过持续抗炎并回看症状与未来风险，减少下一次发作的条件。

### 本 Block 的总任务

> **能从炎症与高反应性解释一次可变阻塞，用相应证据确认和鉴别，并按当前呼吸循环状态处理急性危险、按炎症与风险安排长期控制。**

## 1｜总 Framework

**底物与发作。** 慢性炎症、上皮损伤及感觉神经敏感，与舒张力量减弱、胆碱能/NANC收缩作用增强共同形成高反应性。触发 → 痉挛、黏膜水肿、黏液增加 → 气道口径可变地下降；呼气牵拉减弱进一步增加阻力 → 呼气延长、残气增加。缓解和治疗可逆转其中的可变成分，发作间期仍可能存在炎症。

**同时出现的后果与观察。** 狭窄处有气流时可形成哮鸣；气流极少时可出现沉默肺。局部通气下降 → 低 VA/Q、低氧；代偿尚能维持时 PaCO₂可下降，严重气流受限/呼吸泵疲劳使有效通气失败时 PaCO₂可回升。肺功能、血气和临床征象分别读取这些变量。高反应性、可逆性和多日变异由相应试验观察；FeNO读取嗜酸性炎症接口，影像读取过度充气并排查其他结构病变。

**干预回到模型。** 脱离触发减少刺激输入；支气管扩张药减轻平滑肌收缩；激素等控制药抑制炎症，ICS是长期主轴，LABA依托ICS。全身激素在急性发作中承担早期抗炎，起效与即时支扩不同，给药途径取决于病情和口服条件。重度/危重发作同时处理气道、炎症、氧合和支持需求，并反复评估通气泵及气道保护；机械通气根据整体状态和治疗反应决策，不由单个PaCO₂数值自动触发。

**复查与分流。** 长期随访把过去四周症状和未来风险反馈给控制治疗。持续阻塞与可变阻塞按病史、暴露和客观变化比较；气道性喘息与左心衰造成的肺静脉淤血按不同上游辨别。完整COPD、心衰、通用呼衰诊疗分别回R3、A1 B11、R12。

## 1A｜同一模型上的自然节点〔完整 Prompt〕

```text
【炎症与神经—平滑肌调节共同形成高反应性】

气道慢性炎症在发作间期仍可能存在。课程过敏链由T细胞、白细胞介素接到B细胞与IgE，再通过肥大细胞/嗜碱性粒细胞释放组胺、白三烯等介质。嗜酸性粒细胞参与浸润、终末效应和免疫调节；中性粒细胞突出的严重/激素抵抗表型是另一接口。上皮损伤释放介质并暴露感觉末梢，使刺激更易放大。

〈哮喘本质与炎症细胞地图：嗜酸性粒细胞是主角，但不是唯一参与者〔本质｜早期反应链｜嗜酸3身份｜中性粒细胞表型｜上皮损伤→放大〕〉

与此同时，β₂舒张能力下降、胆碱能收缩增强，VIP/NO等NANC舒张作用减弱、P物质/神经激肽等收缩作用增强，都使气道更易痉挛。暴露的感觉末梢受刺激后释放P物质、CGRP、神经激肽A等 → 血管扩张、通透性增加与渗出，接回炎症和高反应性。两支在气道汇合，神经失衡不是必须等炎症完成后的下一阶段。

〈神经调节失衡：舒张力量变弱，收缩与感觉炎症变强〔自主调节2方向｜NANC舒/缩2组｜感觉神经→渗出｜高反应性汇合〕〉

【触发改变口径，呼吸周期改变排气难度】

过敏原、冷空气或夜间相关触发作用于上述底物 → 平滑肌痉挛、黏膜水肿、黏液增加 → 口径下降。气流通过狭窄处可产生哮鸣，呼气延长和排气不全使残气增加，可见吸气位、动度减小与过度充气。刺激解除或治疗起效后可缓解，因而表现为反复、诱发、夜间和可缓解的波动。

〈典型哮喘的临床身份：发作性、夜间性、诱发性、可缓解〔发作4特征｜呼吸型式/气流类型｜吸气位/动度/呼吸音｜哮鸣链〕〉

吸气使肺扩张、小气道受到的牵拉增加 → 口径增大；呼气时肺体积与牵拉下降 → 已痉挛/水肿的气道进一步变窄，排气更困难。气道阻力和通气不均可使动态测得顺应性下降。若是肺气肿弹性框架破坏，则肺本身静态顺应性可升高；老年肺的变化还要与胸壁变硬分开。这里复用R1测法和R3肺气肿条件。

〈为什么哮喘“越吸越容易，越呼越困难”：气道口径而非弹性框架是主矛盾〔吸/呼气口径｜3病顺应性｜表型/测法〕〉

【声音、血气和呼吸泵读取当前危险】

哮鸣依赖仍有气流通过：狭窄加重时可以更响，危重且气流极少时反而减弱或消失。沉默肺须连同不能完整讲话、意识变化、呼吸功和胸腹反常运动判断。咳嗽变异性或胸闷变异性可缺乏典型哮鸣，仍需高反应、可逆或明显变异的相应客观证据。

〈典型、严重与不典型哮喘：哮鸣音越响不一定越危险〔听诊3阶段｜沉默肺机制｜严重征象7项｜不典型2型/客观证据3类〕〉

局部通气不足而血流仍在 → 低VA/Q与低氧；代偿性通气增加时，PaCO₂可下降。若阻塞严重或呼吸肌疲劳，代偿不足、有效肺泡通气下降 → PaCO₂从低值回到正常甚至升高，此时须评估恶化和酸碱变化。两种状态取决于当下通气能力，不要求每次发作依次经过。达到呼衰条件后的分型和完整支持回R12。

〈血气演变：PaCO₂ 从下降转为升高，是病情恶化的信号〔血气2阶段｜代偿通气/CO₂方向｜CO₂回升含义｜酸碱/呼衰接口〕〉

活动、讲话、呼吸频率、哮鸣、意识、脉搏和呼吸泵征象共同反映急性严重度。气流和循环极度受损时声音、脉搏可变弱；外表“安静”不能独立判轻。课程四级及数值在原Core恢复，现有分母未明的精确项继续HOLD。

〈急性发作四级：越危重，声音和脉搏反而可能变弱〔哮喘急性发作4级｜活动/讲话/哮鸣｜重度关键数值｜意识/沉默肺｜循环/呼吸泵危险征〕〉

当前出现重度/危重征象时，持续开气道、尽早抗炎、支持氧合及所需补液/酸碱处理并行，并追踪治疗反应、呼吸功、血气、意识和气道保护。全身激素的口服或静脉途径合看严重度、吞咽与吸收条件。呼吸肌疲劳、CO₂回升或意识恶化是紧急评估线索；单次PaCO₂阈值既不自动等于插管指令，也不是等待救治的前提。有创支持按气道保护与通气失败等整体状态判断。

〈严重哮喘急性发作：持续开气道、尽早抗炎、支持氧合并监测通气泵〔严重哮喘：开气道｜抗炎｜氧合｜补液/酸碱｜机械通气指征｜何时有创〕〉

【检查确认观察到的变量及其可变性】

一般诊断情境用肺功能观察阻塞与残气；严重发作优先用血气读取氧合、通气与酸碱。一次阻塞性结果不足以独立确诊哮喘，发作间期肺功能正常也不能排除。检查不是疾病进展中的一个病理阶段。

〈一般哮喘首选肺功能，严重哮喘首选血气〔检查选择2场景｜肺功能5指标｜单次阻塞≠确诊｜间歇正常≠排除〕〉

激发试验观察气道对刺激是否反应过强，须在相应非发作及肺功能条件下考虑；舒张试验观察支扩后可逆性；PEF按既定观察窗记录波动。三者回答不同问题，不要求全部同时阳性。舒张反应也可见于COPD，一次阴性不能永久排除哮喘；原公式、阈值和观察窗保留各自单位与边界。

〈激发、舒张与 PEF：三个工具分别证明什么〔激发/舒张｜PEF公式/观察窗｜证据边界〕〉

FeNO升高连接嗜酸性气道炎症、激素反应及疗效观察；X线观察发作时过度充气并排查结构性原因，间歇期可无明显异常。两者不替代高反应性/可变气流的相应证据；Current未给出的FeNO精确阈值继续留在原Source/HOLD边界。

〈FeNO 与 X 线：一个看嗜酸性气道炎症，一个排查结构和过度充气〔FeNO：方向/细胞/用途2项｜X线：间歇vs发作｜确诊工具边界〕〉

【药物分别回作用于触发、收缩和炎症，随访反馈控制效果】

脱离已知触发减少刺激输入。缓解治疗减轻当前阻塞，控制治疗抑制持续炎症与高反应性，二者在一次急性发作中可以同时需要。快速支扩与全身激素的早期抗炎有不同起效任务，不能把所有“急性用药”写成同速开气道。

〈哮喘治疗总架构：先脱离触发，再区分缓解药与控制药〔触发因素｜缓解/控制｜药物起效｜急慢双线〕〉

糖皮质激素抑制炎症/过敏反应，并通过允许作用恢复β₂反应。吸入用药承担长期控制，急性全身用药和长期全身激素风险各有场景；给药途径、代表药与长期暴露边界回原Core。

〈糖皮质激素：长期控制最重要，也通过允许作用恢复 β2 反应〔抗炎/抗过敏｜β₂允许作用｜给药3场景/代表药｜长期全身激素边界〕〉

β₂激动 → Gs/腺苷酸环化酶/cAMP信号增强 → 降低平滑肌Ca²⁺相关收缩并抑制介质释放，回作用于气道口径。SABA承担短效支扩，长期LABA须依托ICS，共同处理收缩与炎症两个变量。

〈β2受体激动剂：急性发作开气道，长期 LABA 必须依托 ICS〔β₂信号：Gs/AC/cAMP/Ca²⁺｜介质释放｜SABA/LABA场景｜ICS协同/单用边界〕〉

茶碱经抑制PDE等作用提高cAMP，但治疗窗和心律失常等风险限制使用；旧静脉短效茶碱保留课程身份与Current所列非急性常规路径边界。抗胆碱药阻断M3相关Gq—PLC—IP₃—Ca²⁺动员，减弱收缩，SAMA/LAMA各有场景；受体阻断不等于ACh释放必定下降，旧cGMP简化不替代这条受体链。

〈茶碱与抗胆碱药：一类提高 cAMP，一类压低胆碱能收缩〔茶碱机制/风险｜M3通路｜SAMA/LAMA｜课程差异〕〉

在阿司匹林/NSAID相关哮喘背景，COX受抑 → 花生四烯酸更多转向白三烯途径 → 痉挛与炎症，白三烯受体拮抗因而有相应控制位置。色甘酸钠和酮替芬稳定肥大细胞膜 → 减少脱颗粒，承担长期预防。酮替芬还拮抗组胺并增加β₂受体数量；激素的允许作用还涉及受体亲和力。药物适用表型由原Core展开，这些控制/预防机制不能直接充当快速救急。

〈白三烯调节剂、色甘酸钠与酮替芬：控制 / 预防，不用于快速救急〔使用场景｜白三烯适用3型｜NSAID/白三烯通路｜膜稳定2药｜酮替芬vs激素β₂作用〕〉

控制治疗后回看过去四周症状，也检查未来急性加重、肺功能下降与药物不良反应等风险。症状少不自动消除未来风险；这一反馈决定是否需要调整控制，而不是一次发作结束便关闭炎症模型。

〈慢性控制评估：看过去四周症状，也看未来风险〔评估时间窗｜控制4项/3级｜症状vs未来风险｜风险6组〕〉

【相同喘息，按不同上游与时间过程分流】

哮喘与COPD共享阻塞体征、残气和气体交换异常；长期暴露、持续性、可变证据及激素适用条件共同区分。COPD合并肺气肿还有弹性/DLCO接口，两者可以重叠，不用一次舒张反应绝对二分。完整持续阻塞模型回R3 KP21及其前文。

〈COPD vs 支气管哮喘：先找共同阻塞语言，再看持续还是可变〔共同表现10组｜鉴别8轴｜持续vs可变｜共享体征≠定病〕〉

气道炎症/痉挛造成的喘息，与左心衰 → 肺静脉淤血/水肿造成的喘息，是不同故障层。过敏或心血管病史、呼吸型式、痰、心肺体征和影像用于寻找上游，单个夜间端坐或啰音不足以定病。药物合并症边界和旧茶碱身份保留，完整心衰处理回A1 B11。

〈严重支气管哮喘 vs 心源性哮喘：都夜间端坐，但故障层不同〔两类哮喘｜病史/体征/影像｜用药条件〕〉
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 哮喘本质是气道慢性炎症性疾病，不只是一次平滑肌痉挛；
2. 嗜酸性粒细胞是主要浸润细胞和终末效应细胞；中性粒细胞与激素抵抗 / 严重哮喘相关；
3. β2受体功能下降、胆碱能张力升高与 NANC 失衡的方向；
4. 炎症 + 高反应 → 痉挛 / 水肿 / 黏液 → 可变气流受限；
5. 发作性、夜间 / 凌晨、诱因明确、可自行或治疗后缓解；
6. 哮喘是呼气性、阻塞性通气障碍；
7. 危重时哮鸣音可减弱甚至消失，形成沉默肺；
8. 不典型咳嗽 / 胸闷变异性哮喘仍需客观可变气流受限证据；
9. 支气管激发试验证明高反应性；支气管舒张试验证明可逆性；
10. 舒张试验阳性：FEV1 增加 ≥12% 且绝对值 ≥200 mL；
11. PEF 日 / 周变异率反映变异性；
12. 早期哮喘 PaO₂↓、PaCO₂↓；恶化后 PaO₂↓、PaCO₂↑；
13. PaCO₂由低转正常 / 升高是通气泵恶化的重要警报；
14. 急性发作首要快速舒张气道，长期控制核心是 ICS；
15. LABA 不单用，需与 ICS 配合；
16. 重度 / 危重度的沉默肺、意识障碍、胸腹矛盾运动是高危征象；
17. 哮喘与 COPD 的主鉴别是可变 / 可逆 vs 持续 / 不完全可逆；
18. 严重支气管哮喘与心源性哮喘必须结合病史、痰液、啰音、心脏和 X 线。

# Unit A｜先建立炎症与高反应性底物

## KP01｜哮喘本质与炎症细胞地图：嗜酸性粒细胞是主角，但不是唯一参与者

> **讲义定位 →** 内科印刷 P47｜PDF 物理 P57｜病因和发病机制  
> **Outline →** U017｜病因和发病机制 1、3  
> **主提示：** 本质｜早期反应链｜嗜酸3身份｜中性粒细胞表型｜上皮损伤→放大

### 1｜疾病本质

> **支气管哮喘是气道慢性炎症性疾病。**

它不是“发作时才有炎症”，发作间期仍可能存在慢性炎症和气道高反应性。

### 2｜过敏 / 早期反应链

```text
T细胞
→ 白细胞介素
→ B细胞
→ IgE
→ 肥大细胞、嗜碱性粒细胞
→ 组胺、白三烯等炎症介质
→ 哮喘早期反应
```

### 3｜嗜酸性粒细胞

按当前 Study：

- 气道慢性炎症的主要浸润细胞；
- 终末效应细胞；
- 具有免疫调节作用。

### 4｜中性粒细胞与重症表型

```text
中性粒细胞参与突出
与激素抵抗型 / 严重哮喘表型相关
（表型关联，不是所有患者必经的进展顺序）
```

（易混：COPD 炎症过程的重要环节是中性粒细胞活化与聚集；典型哮喘的主要浸润细胞是嗜酸性粒细胞。）

### 5｜上皮损伤

气道上皮受损可释放炎症介质，并暴露感觉神经末梢，使气道对外界刺激更敏感，进一步维持高反应性。

### 1｜两条自主神经方向


## KP04｜为什么哮喘“越吸越容易，越呼越困难”：气道口径而非弹性框架是主矛盾

> **讲义回看 →** R1 气道阻力；内科印刷 P48｜PDF 物理 P58  
> **Outline →** U017｜临床表现 3–4  
> **主提示：** 吸/呼气口径｜3病顺应性｜表型/测法

### 1｜吸气

```text
呼吸肌收缩
→ 胸廓扩大、胸膜腔负压更负
→ 肺扩张
→ 肺组织对小气道牵拉增加
→ 气道口径增大
→ 气道阻力下降
```

### 2｜呼气

```text
肺体积减小
→ 对小气道牵拉下降
→ 已痉挛 / 水肿的气道进一步变窄
→ 阻力升高
→ 呼气更困难
```

### 3｜顺应性对比

```text
哮喘
→ 主要是气道阻力增加
→ 动态顺应性下降
→ 不以弹力纤维破坏和静态顺应性升高为核心

COPD
→ 气道阻力/通气不均可使动态测得顺应性下降
+ 合并肺气肿弹性破坏时静态顺应性可升高

老年性肺气肿
→ 气道可相对正常
→ 弹性回缩随年龄减弱，肺本身静态顺应性可升高
但胸壁变硬可抵消，不把肺顺应性等同整个呼吸系统顺应性
```

## KP05｜典型、严重与不典型哮喘：哮鸣音越响不一定越危险

> **讲义定位 →** 内科印刷 P48、P51｜PDF 物理 P58、P61｜病例入口与急性严重度  
> **Outline →** U017｜临床表现 6；U019｜急性发作严重度相关题  
> **主提示：** 听诊3阶段｜沉默肺机制｜严重征象7项｜不典型2型/客观证据3类

### 1｜典型哮喘

- 发作性喘息伴哮鸣音；
- 过敏原或夜间 / 凌晨触发；
- 可自行或治疗后缓解。

听诊随严重度变化：

```text
轻度
→ 散在哮鸣音

中、重度
→ 双肺弥漫、响亮哮鸣音

危重度
→ 气流极少
→ 哮鸣音减弱或消失
→ 沉默肺 / 寂静肺
```

> **危重哮喘“听不到哮鸣音”不是病情缓解，而可能是气道几乎完全闭塞。**

### 2｜严重发作线索

- 端坐呼吸、大汗；
- 明显三凹征和奇脉；
- 呼吸频率 >30 次/分；
- 不能完整讲话；
- 意识障碍；
- 胸腹矛盾 / 反常运动；
- 呼吸音明显减低或沉默肺。

### 3｜不典型哮喘

咳嗽变异性或胸闷变异性哮喘可只有：

- 咳嗽；或
- 胸闷；

而没有典型喘息 / 哮鸣音。

仍需以下任一客观证据：

- 支气管激发试验阳性；
- 支气管舒张试验阳性；
- PEF 变异率明显增加。

## KP07｜激发、舒张与 PEF：三个工具分别证明什么

> **讲义定位 →** 内科印刷 P48｜PDF 物理 P58｜可变气流受限证据  
> **Outline →** U017 辅助检查 3；U018 辅助检查 4–8  
> **主提示：** 激发/舒张｜PEF公式/观察窗｜证据边界

### 1｜支气管激发试验

回答：

> **气道是否存在高反应性？**

按当前 Study：

- 仅用于非发作期；
- FEV1%pred >70% 时使用；
- 吸入醋甲胆碱、组胺等后 FEV1下降 ≥20% 为阳性。

（特殊：急性发作期不宜做激发试验。）

### 2｜支气管舒张试验

回答：

> **当前气流受限能否逆转？**

阳性标准：

```text
吸入支气管扩张剂后
FEV1较用药前增加 ≥12%
且
绝对值增加 ≥200 mL
```

它是气流可变的重要证据，但阳性并非哮喘独有、阴性也不能一次排除哮喘；不能仅用一次舒张试验把哮喘与COPD绝对二分。

### 3｜PEF

PEF 是用力呼气时的最高流量：

- 发作时下降；
- 可反映严重度并用于连续监测；
- 课程写日变异率>10%、周变异率>20%；原文未给“周变异率”的计算公式，不能与不同观察窗混用；
- GINA的成人平均日内变异常按每天早晚测量、连续约2周：每日(最高−最低)/二者均值×100%，再求各日平均；>10%支持过度变异，儿童阈值另列；
- 明显波动支持气流受限的变异性 / 可逆性。

### 4｜一张决策表

| 临床问题 | 工具 |
|---|---|
| 非发作期，想证明气道高反应性 | 支气管激发试验 |
| 正在存在气流受限，想证明可逆 | 支气管舒张试验 |
| 想在家 / 多日连续观察波动 | PEF及其变异率 |

## KP08｜血气演变：PaCO₂ 从下降转为升高，是病情恶化的信号

> **讲义定位 →** 内科印刷 P49｜PDF 物理 P59｜严重哮喘血气  
> **Outline →** U018｜辅助检查 9  
> **主提示：** 血气2阶段｜代偿通气/CO₂方向｜CO₂回升含义｜酸碱/呼衰接口

### 1｜早期

```text
局部气道阻塞 → 低 VA/Q → PaO₂下降
低氧刺激外周化学感受器
+ 尚能代偿的通气能力
→ 呼吸加深加快、肺泡通气增加
→ PaCO₂下降

低氧来自气体交换失配，不是过度通气造成的下一步。
```

可形成呼吸性碱中毒入口。

### 2｜病情恶化

```text
气道痉挛 / 阻塞继续加重，或呼吸肌疲劳使代偿不足
→ 有效肺泡通气量下降
→ CO₂排出不足 → PaCO₂从低值回到正常甚至升高

同时：低 VA/Q / 有效通气不足可使低氧继续恶化
低氧及 CO₂潴留达到呼衰条件时 → 急性Ⅱ型呼衰（完整分型回 R12）
```

> 在严重喘息患者中，PaCO₂不再低、而回到正常或升高，不能理解为“恢复正常”，应警惕呼吸肌疲劳和通气失败。

# Unit D｜把治疗分成“迅速缓解”和“长期控制”

## KP10｜哮喘治疗总架构：先脱离触发，再区分缓解药与控制药

> **讲义定位 →** 内科印刷 P49｜PDF 物理 P59｜治疗总论  
> **Outline →** U018｜治疗 1–2  
> **主提示：** 触发因素｜缓解/控制｜药物起效｜急慢双线

### 1｜上游措施

> **识别并减少确实相关的触发暴露；对有明确变应原关联者，脱离该暴露是重要上游措施。课程“最有效”不能替代所有哮喘患者的ICS抗炎治疗。**

### 2｜缓解性药物

目标：

```text
迅速解除支气管痉挛
→ 尽快改善气流和症状
```

当前 Study 列入：

- SABA；
- SAMA；
- ICS + 福莫特罗接口；
- 短效茶碱；
- 全身糖皮质激素接口。

该列表混合了急性处理的不同任务：SABA等迅速支扩，全身激素尽早抗炎但不是立即解痉药；茶碱为课程历史接口，现代急性发作不常规静脉使用，见KP13/16。

### 3｜控制性药物

目标：

```text
长期抑制气道慢性炎症
→ 降低高反应性
→ 减少未来发作
```

当前 Study 列入：

- ICS；
- ICS + LABA、ICS + LABA + LAMA等联合；
- 白三烯调节剂；
- LABA（不单用）；
- 缓释茶碱；
- 生物制剂接口。

### 4｜核心原则

```text
急性发作
迅速舒张气道并尽早抗炎/评估氧合

长期控制
以抗炎为核心
```

## KP12｜β2受体激动剂：急性发作开气道，长期 LABA 必须依托 ICS

> **讲义定位 →** 内科印刷 P50｜PDF 物理 P60｜β2受体激动剂  
> **Outline →** U018｜治疗 5–6  
> **主提示：** β₂信号：Gs/AC/cAMP/Ca²⁺｜介质释放｜SABA/LABA场景｜ICS协同/单用边界

### 1｜信号通路

```text
β2受体激动
→ Gs
→ 腺苷酸环化酶 AC
→ cAMP↑
→ 支气管平滑肌胞质 Ca²⁺↓

```

同时：

```text
cAMP / cGMP 比值↑
→ 生物活性物质释放下降
→ 抗炎 / 抗介质释放接口
```

### 2｜临床场景

- 急性发作迅速缓解首选：吸入 SABA，如沙丁胺醇、特布他林；
- 长期控制常用：ICS + LABA；
- 当前 Study 示例：布地奈德 + 福莫特罗、氟替卡松 + 沙美特罗；
- LABA 不单独使用，应与 ICS 配合。

### 3｜为什么和激素协同

```text
β2激动剂
→ 快速打开气道

ICS
→ 控制炎症
+ 恢复 / 提高 β2受体反应
```

## KP13｜茶碱与抗胆碱药：一类提高 cAMP，一类压低胆碱能收缩

> **讲义定位 →** 内科印刷 P50｜PDF 物理 P60｜茶碱、抗胆碱药  
> **Outline →** U018 治疗 7；U019 治疗 8、11–12  
> **主提示：** 茶碱机制/风险｜M3通路｜SAMA/LAMA｜课程差异

### 1｜茶碱

主要机制按当前 Study：

```text
抑制磷酸二酯酶 PDE
→ cAMP降解减少
→ cAMP↑
→ 平滑肌 Ca²⁺↓
→ 支气管舒张
```

另有：拮抗腺苷受体、增强纤毛清除等接口。

场景：

- 口服缓释茶碱：尤其用于夜间哮喘控制；
- 静脉短效茶碱：课程列严重发作接口；GINA 2026不推荐在急性加重中使用静脉氨茶碱/茶碱，因获益有限且存在严重毒性风险；
- 治疗窗窄，当前 Study 安全浓度 6–15 mg/L，归 MI-D。

### 2｜抗胆碱药

```text
阻断ACh对气道平滑肌M3受体的作用
→ 减弱Gq/PLC/IP3介导的Ca²⁺动员
→ 胆碱能收缩下降，支气管舒张
```

课程cGMP↓、cAMP/cGMP↑是旧式简化，不能替代M3–Gq–Ca²⁺主链；拮抗受体也不等于ACh释放量必定下降。

- SAMA：异丙托溴铵，可用于缓解症状；
- LAMA：噻托溴铵，可用于合并 COPD 者接口。

（易混：急性哮喘当前 Study 仍以 SABA 作为迅速缓解首选，SAMA更多作为联合。）

## KP14｜白三烯调节剂、色甘酸钠与酮替芬：控制 / 预防，不用于快速救急

> **讲义定位 →** 内科印刷 P50｜PDF 物理 P60｜其他控制药  
> **Outline →** U019｜治疗 9–10、13–14  
> **主提示：** 使用场景｜白三烯适用3型｜NSAID/白三烯通路｜膜稳定2药｜酮替芬vs激素β₂作用

### 1｜白三烯调节剂

代表：孟鲁司特。

当前 Study：

- 用于控制炎症，不作为快速缓解药；
- 除 ICS 外，可单用于控制炎症的药物接口；
- 尤其适合：
  - 合并过敏性鼻炎；
  - 阿司匹林哮喘；
  - 运动性哮喘。

### 2｜为何适合阿司匹林哮喘

```text
NSAID抑制 COX
→ 花生四烯酸更多转向白三烯途径
→ 白三烯增加
→ 支气管痉挛与炎症
→ 白三烯受体拮抗剂有针对性
```

### 3｜色甘酸钠与酮替芬

共同：

```text
稳定肥大细胞膜
→ 减少脱颗粒
→ 用于长期预防，而非急性救急
```

酮替芬还可：

- 拮抗组胺；
- 上调 β2受体数量。

（易混：当前 Study 强调酮替芬增加 β2受体数量；糖皮质激素既增加数量，又提高亲和力。）

# Unit E｜急性发作：识别危险并评估通气支持

## KP15｜急性发作四级：越危重，声音和脉搏反而可能变弱

> **讲义定位 →** 内科印刷 P51｜PDF 物理 P61｜急性发作严重度  
> **Outline →** U019｜急性发作 15、17–18、21–22  
> **主提示：** 哮喘急性发作4级｜活动/讲话/哮鸣｜重度关键数值｜意识/沉默肺｜循环/呼吸泵危险征

| 程度 | 呼吸 / 活动 | 讲话 | 听诊与高危征象 |
|---|---|---|---|
| 轻度 | 步行或上楼时气短 | 正常 | 散在哮鸣音 |
| 中度 | 稍活动即气短 | 讲话中断 | 弥漫、响亮哮鸣音，可见三凹征 / 奇脉接口 |
| 重度 | 端坐呼吸 | 单字表达 | 弥漫响亮哮鸣音；明显三凹征、奇脉；R>30、PEF<60%、HR>120 |
| 危重度 | 明显通气泵失败 | 不能讲话 / 意识障碍 | 沉默肺；脉率慢或不规则；血压下降；胸腹矛盾运动 |

### 1｜沉默肺

气道并不是更通畅，而是：

```text
严重闭塞
→ 几乎无气流通过
→ 哮鸣音减弱 / 消失
```

### 2｜胸腹矛盾运动

```text
膈肌与呼吸肌极度疲劳
→ 吸气时胸腔负压通过薄弱膈肌牵拉腹部
→ 腹部反而向内凹陷
```

提示通气泵接近衰竭。

### 3｜奇脉

严重气道阻塞时用力吸气，胸腔负压明显增大，肺血管容量和室间隔相互作用可使吸气期左室充盈 / 搏出量下降，脉搏明显减弱。

当前 Study 将严重哮喘、COPD、严重右心衰、心包压塞、缩窄性心包炎、大量胸腔积液、张力性气胸等列为奇脉接口；需结合严重气道阻塞或显著循环影响等条件，不把病名当作每例必有奇脉。完整列表归 MI-D。

题纲 U019 急性发作第22题还问两个排除项：原页（内科印刷P51 / PDF物理P61）将**限制性心肌病、普通自发性气胸**列作典型课程中的非奇脉配对。这里保留源题对照；不能把普通自发性气胸与张力性气胸的高压循环后果混同，也不以该配对否定个别复杂病例。

## KP16｜严重哮喘急性发作：持续开气道、尽早抗炎、支持氧合并监测通气泵

> **讲义定位 →** 内科印刷 P51｜PDF 物理 P61｜严重发作治疗  
> **Outline →** U019｜急性发作 19–20  
> **主提示：** 严重哮喘：开气道｜抗炎｜氧合｜补液/酸碱｜机械通气指征｜何时有创

### 1｜迅速舒张气道

```text
持续吸入 SABA【迅速缓解首选】
+ SAMA 联合接口
```

### 2｜尽早控制炎症

- 静脉氢化可的松；或
- 静脉甲泼尼龙；
- 当前 Study 不选地塞米松作为该处首选表述。

静脉茶碱保留为课程历史接口，不作为现代默认加药；按GINA 2026不推荐急性发作静脉氨茶碱/茶碱。激素途径还看能否吞咽、吸收与危重程度，不把“严重”无条件等同仅能静脉，也不把地塞米松永久排除于所有哮喘方案。

### 3｜支持治疗

- 吸氧；
- 评估脱水、电解质与灌注后补液；课程与ARDS对比不是无限补液指令；
- 课程pH<7.2列补碱接口，但呼酸首要改善通气，不能用单个pH触发自动补碱；

### 4｜机械通气指征

当前 Study 三个重点：

```text
经治疗后 PaCO₂ ≥45 mmHg
或
呼吸肌疲劳 / 胸腹矛盾运动
或
意识障碍
```

上述是危重报警线索；不能凭一次PaCO₂≥45就自动插管，也不能等其升到阈值才救治。须综合治疗反应、呼吸功、疲劳、酸碱、低氧和气道保护；意识恶化、不能保护气道或通气衰竭需紧急评估有创通气。

> **通气指征的实质不是“喘得很厉害”，而是 CO₂排出失败、呼吸泵疲劳或中枢状态恶化。**

# Unit F｜两个高频鉴别树

## KP18｜COPD vs 支气管哮喘：先找共同阻塞语言，再看持续还是可变

> **讲义定位 →** 内科印刷 P53｜PDF 物理 P63｜支气管哮喘鉴别专题  
> **Outline →** U020｜1–2  
> **主提示：** 共同表现10组｜鉴别8轴｜持续vs可变｜共享体征≠定病

### 1｜共同点

两者都可有：

- 呼气性呼吸困难；
- 阻塞性通气障碍；
- FEV1/FVC下降；
- RV增加、过度充气；
- 桶状胸、过清音；
- 语音震颤和呼吸音减弱；
- 呼气音延长；
- X线透亮度增加；
- VA/Q失调；
- 严重时Ⅱ型呼衰。

所以“哮鸣音、桶状胸、一秒率下降”都不是单独的最终鉴别点。

### 2｜核心差异

| 轴 | COPD | 支气管哮喘 |
|---|---|---|
| 典型人群 / 病史 | 中老年、吸烟、长期咳痰喘 | 青年 / 过敏史，反复发作 |
| 症状 | 持续、活动后气短；常有咳痰 | 发作性干咳喘息，夜间 / 凌晨或接触过敏原 |
| 啰音 | 湿啰音或干湿共存 | 干啰音 / 哮鸣音为主，可沉默肺 |
| 气流受限 | 持续、不完全可逆 | 可变、可逆 |
| 关键证据 | 支扩剂后 FEV1/FVC仍<70% | 舒张试验阳性、PEF变异率大、激发试验阳性 |
| VA/Q | 可高可低，并有DLCO下降接口 | 以通气下降导致 VA/Q低为主 |
| 支扩剂 | 稳定期和急性期都使用 | 急性缓解首选SABA；长期LABA不单用 |
| 激素 | 有条件使用 ICS；住院加重期全身激素 | 长期控制以ICS为核心；严重发作尽早静脉激素 |

> **最稳定的主鉴别轴：结构性持续气流受限 vs 炎症 / 痉挛导致的可变性气流受限。**

## KP19｜严重支气管哮喘 vs 心源性哮喘：都夜间端坐，但故障层不同

> **讲义定位 →** 内科印刷 P53｜PDF 物理 P63｜严重哮喘与心源性哮喘  
> **Outline →** U020｜3–5  
> **主提示：** 两类哮喘｜病史/体征/影像｜用药条件

### 1｜共同表现

- 咳、喘、呼吸困难；
- 夜间发作；
- 端坐呼吸。

### 2｜故障层不同

| 轴 | 严重支气管哮喘 | 心源性哮喘 |
|---|---|---|
| 上游 | 气道炎症、高反应、痉挛 | 左心衰、肺静脉淤血 / 肺水肿 |
| 人群 / 病史 | 青年、过敏史 | 中老年，高血压 / 冠心病 / 瓣膜病等 |
| 呼吸困难 | 呼气性 | 混合性 / 心源性 |
| 痰 | 发作性干咳或少痰 | 粉红色泡沫样痰接口 |
| 啰音 | 干啰音为主，可沉默肺 | 湿啰音或干湿共存 |
| 心脏 | 多无明显结构性心脏证据 | 左心扩大、奔马律等接口 |
| X线 | 多正常或透亮度增加 | 左心扩大、肺淤血 / 肺水肿 |

### 3｜药物边界

按当前 Study：

- 支气管哮喘禁用吗啡的考试口径；
- 心源性哮喘禁用肾上腺素的考试口径；
- 课程难辨时列吸入SABA或静脉短效茶碱；不能将静脉茶碱作为通用诊断性试药。应迅速用病史、肺/心体征、床旁影像等分清支气管痉挛与肺水肿，并按循环/呼吸状态处理；茶碱有心律失常风险且不在现代急性哮喘常规路径。

完整左心衰处理仍归循环 B11，不在此展开。
