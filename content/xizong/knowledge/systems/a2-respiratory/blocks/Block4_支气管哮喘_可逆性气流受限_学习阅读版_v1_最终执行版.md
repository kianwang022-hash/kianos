## 0｜这个 Block 到底解决什么

哮喘与 COPD 都会让气道变窄，但哮喘的核心不是肺泡弹性框架被拆掉，而是：

```text
气道慢性炎症
→ 气道高反应性
→ 遇到触发因素后平滑肌痉挛、黏膜水肿、黏液增加
→ 气道口径快速、可变地下降
→ 发作性呼气性呼吸困难
```

解除触发或治疗后：

```text
痉挛缓解
+ 炎症控制
→ 气流受限可部分或明显逆转
→ 发作间期肺功能可接近正常
```

因此哮喘学习始终围绕两条线：

```text
急性发作
→ 迅速把气道打开

慢性基础
→ 长期控制气道炎症与高反应性
```

### 本 Block 的总任务

> **看到反复喘息、夜间发作、过敏诱因或不典型慢性咳嗽时，能证明气道高反应性或气流受限可逆，并根据严重度区分快速缓解、长期控制和立即通气。**

## 1｜总 Framework

```text
A｜炎症底物

T细胞 / IgE / 肥大细胞
+ 嗜酸性粒细胞主导
+ 上皮损伤
+ 重症时中性粒细胞接口
→ 气道慢性炎症

        ↓

B｜神经与平滑肌失衡

β2受体功能↓
+ 胆碱能张力↑
+ NANC舒张介质↓ / 收缩介质↑
+ 感觉神经源性炎症
→ 气道高反应性

        ↓

C｜触发一次可变性气流受限

过敏原 / 冷空气 / 夜间迷走张力等
→ 平滑肌痉挛
+ 黏膜水肿
+ 黏液 / 炎性渗出
→ 呼气性气流受限
→ 哮鸣、残气、VA/Q下降

        ↓

D｜用证据证明哮喘

阻塞性肺功能
+ 支气管激发试验：高反应性
+ 支气管舒张试验：可逆性
+ PEF变异率：变异性

        ↓

E｜按两条治疗线处理

迅速缓解
SABA / SAMA / 短效茶碱 / 全身激素接口

长期控制
ICS为核心
+ ICS-LABA
+ 白三烯 / 其他控制药

        ↓

F｜危险时优先救通气

重度 / 危重度
→ 氧合与血气
→ 持续支扩 + 尽早静脉激素
→ 补液与支持
→ 呼吸肌疲劳 / CO₂回升 / 意识障碍
→ 机械通气
```

### 三个核心证据问题

```text
有没有阻塞？
→ FEV1/FVC、PEF、RV

气道是不是高反应？
→ 支气管激发试验

阻塞能不能逆转 / 是否明显波动？
→ 支气管舒张试验、PEF变异率
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 哮喘本质是气道慢性炎症性疾病，不只是一次平滑肌痉挛；
2. 嗜酸性粒细胞是主要浸润细胞和终末效应细胞；中性粒细胞与激素抵抗 / 严重哮喘相关；
3. β2受体功能下降、胆碱能张力升高与 NANC 失衡的方向；
4. 炎症 + 高反应 → 痉挛 / 水肿 / 黏液 → 可变气流受限；
5. 发作性、夜间 / 凌晨、诱因明确、可自行或治疗后缓解；
6. 哮喘是呼气性、阻塞性通气障碍；
7. 危重时哮鸣音可减弱甚至消失，形成沉默肺；
8. 不典型咳嗽 / 胸闷变异性哮喘仍需客观可变气流受限证据；
9. 支气管激发试验证明高反应性；支气管舒张试验证明可逆性；
10. 舒张试验阳性：FEV1 增加 ≥12% 且绝对值 ≥200 mL；
11. PEF 日 / 周变异率反映变异性；
12. 早期哮喘 PaO₂↓、PaCO₂↓；恶化后 PaO₂↓、PaCO₂↑；
13. PaCO₂由低转正常 / 升高是通气泵恶化的重要警报；
14. 急性发作首要快速舒张气道，长期控制核心是 ICS；
15. LABA 不单用，需与 ICS 配合；
16. 重度 / 危重度的沉默肺、意识障碍、胸腹矛盾运动是高危征象；
17. 哮喘与 COPD 的主鉴别是可变 / 可逆 vs 持续 / 不完全可逆；
18. 严重支气管哮喘与心源性哮喘必须结合病史、痰液、啰音、心脏和 X 线。

- FEV1、PEF、FeNO 等精确阈值；
- 支气管激发剂和扩张剂代表药；
- 缓解药 / 控制药完整名单；
- 各型激素具体药物和给药途径；
- SABA、LABA、SAMA、LAMA 代表药；
- 茶碱安全浓度和特殊适应证；
- 白三烯调节剂特殊类型；
- 色甘酸钠、酮替芬比较；
- 急性发作四级全部数值；
- 奇脉疾病口诀；
- 症状控制和未来风险全部项目；
- 生物制剂和特殊表型治疗接口。

# Unit A｜先建立炎症与高反应性底物

## KP01｜哮喘本质与炎症细胞地图：嗜酸性粒细胞是主角，但不是唯一参与者

> **讲义定位 →** 内科 Lecture PDF P47｜病因和发病机制  
> **Outline →** U017｜病因和发病机制 1、3  
> **主提示：** 疾病本质；T细胞—IgE—肥大细胞早期反应；嗜酸性粒细胞身份；中性粒细胞何时重要；上皮损伤怎样继续放大炎症。

### 1｜疾病本质

> **支气管哮喘是气道慢性炎症性疾病。**

它不是“发作时才有炎症”，发作间期仍可能存在慢性炎症和气道高反应性。

### 2｜过敏 / 早期反应链

```text
T细胞
→ 白细胞介素
→ B细胞
→ IgE
→ 肥大细胞、嗜碱性粒细胞
→ 组胺、白三烯等炎症介质
→ 哮喘早期反应
```

### 3｜嗜酸性粒细胞

按当前 Study：

- 气道慢性炎症的主要浸润细胞；
- 终末效应细胞；
- 具有免疫调节作用。

### 4｜中性粒细胞与重症表型

```text
中性粒细胞参与突出
→ 激素抵抗型哮喘
→ 严重哮喘接口
```

（易混：COPD 炎症过程的重要环节是中性粒细胞活化与聚集；典型哮喘的主要浸润细胞是嗜酸性粒细胞。）

### 5｜上皮损伤

气道上皮受损可释放炎症介质，并暴露感觉神经末梢，使气道对外界刺激更敏感，进一步维持高反应性。

## KP02｜神经调节失衡：舒张力量变弱，收缩与感觉炎症变强

> **讲义定位 →** 内科 Lecture PDF P47｜神经调节失衡  
> **Outline →** U017｜病因和发病机制 2  
> **主提示：** β2、胆碱能张力；NANC 的舒张 / 收缩介质；感觉神经源性炎症；为什么这些变化共同提高气道反应性。

### 1｜两条自主神经方向

```text
β2受体功能下降
→ 交感样舒张能力下降

胆碱能神经张力升高
→ ACh-M受体收缩作用增强
```

### 2｜NANC 神经系统

| 方向 | 介质 |
|---|---|
| 舒张支气管 | VIP、NO |
| 收缩支气管 | P物质、神经激肽等 |

当前 Study 的总体方向：

```text
舒张介质作用下降
+ 收缩介质作用增强
→ 气道更容易痉挛
```

### 3｜感觉神经源性炎症

```text
上皮损伤
→ 感觉神经末梢暴露
→ 外界刺激更易触发
→ P物质、CGRP、神经激肽A等释放
→ 血管扩张、通透性增加、炎症渗出
```

### 4｜最后形成气道高反应性

```text
慢性炎症
+ 平滑肌舒张能力下降
+ 胆碱能收缩增强
+ 感觉神经敏感
→ 同样刺激引起更强支气管痉挛
```

# Unit B｜从高反应性进入一次发作

## KP03｜典型哮喘的临床身份：发作性、夜间性、诱发性、可缓解

> **讲义定位 →** 内科 Lecture PDF P48｜临床表现  
> **Outline →** U017｜临床表现 1–2、5  
> **主提示：** 发作性质、诱因、时间、缓解；呼气性与阻塞性；呼吸音 / 呼吸动度 / 吸气位；干啰音为何主导。

### 1｜典型发作特征

```text
接触过敏原、冷空气等触发
→ 夜间 / 凌晨常发作或加重
→ 发作性喘息、胸闷、咳嗽
→ 可自行或经治疗后缓解
```

### 2｜呼吸困难类型

- 呼气性呼吸困难；
- 呼气音延长；
- 属阻塞性通气功能障碍；
- 发作时残气增加，可呈吸气位、呼吸动度减小；
- 过度充气严重时可见桶状胸接口。

### 3｜啰音

```text
气道平滑肌痉挛、管腔狭窄
→ 气流通过狭窄处形成湍流
→ 干啰音 / 哮鸣音
```

气道内可有炎性渗出，但临床主要矛盾是广泛痉挛，因此以干啰音为主。

## KP04｜为什么哮喘“越吸越容易，越呼越困难”：气道口径而非弹性框架是主矛盾

> **讲义回看 →** R1 气道阻力；内科 P48  
> **Outline →** U017｜临床表现 3–4  
> **主提示：** 吸气 / 呼气时胸膜压和气道牵拉；哮喘、COPD、老年性肺气肿的动态 / 静态顺应性对比。

### 1｜吸气

```text
呼吸肌收缩
→ 胸廓扩大、胸膜腔负压更负
→ 肺扩张
→ 肺组织对小气道牵拉增加
→ 气道口径增大
→ 气道阻力下降
```

### 2｜呼气

```text
肺体积减小
→ 对小气道牵拉下降
→ 已痉挛 / 水肿的气道进一步变窄
→ 阻力升高
→ 呼气更困难
```

### 3｜顺应性对比

```text
哮喘
→ 主要是气道阻力增加
→ 动态顺应性下降
→ 不以弹力纤维破坏和静态顺应性升高为核心

COPD
→ 小气道阻塞：动态顺应性下降
+ 弹性结构破坏：静态顺应性升高

老年性肺气肿
→ 气道可相对正常
→ 主要是弹性成分退化、静态顺应性改变
```

## KP05｜典型、严重与不典型哮喘：哮鸣音越响不一定越危险

> **讲义定位 →** 内科 Lecture PDF P48、P51｜病例入口与急性严重度  
> **Outline →** U017｜临床表现 6；U019｜急性发作严重度相关题  
> **主提示：** 轻 / 中重 / 危重的听诊方向；沉默肺；严重体征；咳嗽 / 胸闷变异性哮喘如何确诊。

### 1｜典型哮喘

- 发作性喘息伴哮鸣音；
- 过敏原或夜间 / 凌晨触发；
- 可自行或治疗后缓解。

听诊随严重度变化：

```text
轻度
→ 散在哮鸣音

中、重度
→ 双肺弥漫、响亮哮鸣音

危重度
→ 气流极少
→ 哮鸣音减弱或消失
→ 沉默肺 / 寂静肺
```

> **危重哮喘“听不到哮鸣音”不是病情缓解，而可能是气道几乎完全闭塞。**

### 2｜严重发作线索

- 端坐呼吸、大汗；
- 明显三凹征和奇脉；
- 呼吸频率 >30 次/分；
- 不能完整讲话；
- 意识障碍；
- 胸腹矛盾 / 反常运动；
- 呼吸音明显减低或沉默肺。

### 3｜不典型哮喘

咳嗽变异性或胸闷变异性哮喘可只有：

- 咳嗽；或
- 胸闷；

而没有典型喘息 / 哮鸣音。

仍需以下任一客观证据：

- 支气管激发试验阳性；
- 支气管舒张试验阳性；
- PEF 变异率明显增加。

# Unit C｜用肺功能、血气和炎症证据证明疾病

## KP06｜一般哮喘首选肺功能，严重哮喘首选血气

> **讲义定位 →** 内科 Lecture PDF P48–49｜辅助检查  
> **Outline →** U017｜辅助检查 1–2  
> **主提示：** 一般 / 严重分别首选；阻塞性肺功能全方向；为什么发作间期也不能只看一次正常结果。

### 1｜检查选择

```text
一般哮喘
→ 首选肺功能

严重哮喘急性发作
→ 首选动脉血气分析
```

### 2｜发作期阻塞性肺功能

按当前 Study：

- FEV1/FVC <70%；
- FEV1%pred <80%；
- PEF下降；
- RV升高；
- RV/TLC升高。

（易混：一次阻塞性肺功能只能说明存在气流受限；哮喘诊断还需证明可变 / 可逆或高反应性。）

### 3｜发作间期可能接近正常

哮喘是可变性疾病，非发作期肺功能可能恢复。因此疑似病例不能因一次正常肺功能直接排除，而要结合激发、PEF变异和病史。

## KP07｜激发、舒张与 PEF：三个工具分别证明什么

> **讲义定位 →** 内科 Lecture PDF P48｜可变气流受限证据  
> **Outline →** U017 辅助检查 3；U018 辅助检查 4–8  
> **主提示：** 激发适用条件与阳性；舒张阳性；PEF意义和变异率；如何选择而不是混成同一试验。

### 1｜支气管激发试验

回答：

> **气道是否存在高反应性？**

按当前 Study：

- 仅用于非发作期；
- FEV1%pred >70% 时使用；
- 吸入醋甲胆碱、组胺等后 FEV1下降 ≥20% 为阳性。

（特殊：急性发作期不宜做激发试验。）

### 2｜支气管舒张试验

回答：

> **当前气流受限能否逆转？**

阳性标准：

```text
吸入支气管扩张剂后
FEV1较用药前增加 ≥12%
且
绝对值增加 ≥200 mL
```

它是哮喘与 COPD 的重要鉴别证据。

### 3｜PEF

PEF 是用力呼气时的最高流量：

- 发作时下降；
- 可反映严重度并用于连续监测；
- 日变异率 >10%；
- 周变异率 >20%；
- 明显波动支持气流受限的变异性 / 可逆性。

### 4｜一张决策表

| 临床问题 | 工具 |
|---|---|
| 非发作期，想证明气道高反应性 | 支气管激发试验 |
| 正在存在气流受限，想证明可逆 | 支气管舒张试验 |
| 想在家 / 多日连续观察波动 | PEF及其变异率 |

## KP08｜血气演变：PaCO₂ 从下降转为升高，是病情恶化的信号

> **讲义定位 →** 内科 Lecture PDF P49｜严重哮喘血气  
> **Outline →** U018｜辅助检查 9  
> **主提示：** 早期和恶化时 PaO₂ / PaCO₂；为什么早期 CO₂低；为什么升高提示急性Ⅱ型呼衰。

### 1｜早期

```text
气道梗阻尚未极重
+ 低氧刺激外周化学感受器
→ 呼吸加深加快、过度通气
→ PaO₂↓
→ PaCO₂↓
```

可形成呼吸性碱中毒入口。

### 2｜病情恶化

```text
气道痉挛 / 阻塞继续加重
→ 肺泡通气量下降
→ CO₂无法排出
→ PaO₂继续下降
→ PaCO₂转为升高
→ 急性Ⅱ型呼衰
```

> 在严重喘息患者中，PaCO₂不再低、而回到正常或升高，不能理解为“恢复正常”，应警惕呼吸肌疲劳和通气失败。

## KP09｜FeNO 与 X 线：一个看嗜酸性气道炎症，一个排查结构和过度充气

> **讲义定位 →** 内科 Lecture PDF P49｜FeNO与X线  
> **Outline →** U018｜辅助检查 10–11  
> **主提示：** FeNO方向、对应细胞和用途；非发作 / 发作期 X线。

### 1｜FeNO

按当前 Study：

- 急性发作期升高；
- 与痰中嗜酸性粒细胞浓度相关；
- 可用于评价气道炎症；
- 可评价对激素治疗的反应性接口。

### 2｜胸部 X 线

- 非发作期：多无明显异常；
- 急性发作期：可见双肺透亮度增加等过度充气表现。

X线不是一般哮喘确诊的主要工具，更常用于排查其他结构性病变或并发症。

# Unit D｜把治疗分成“迅速缓解”和“长期控制”

## KP10｜哮喘治疗总架构：先脱离触发，再区分缓解药与控制药

> **讲义定位 →** 内科 Lecture PDF P49｜治疗总论  
> **Outline →** U018｜治疗 1–2  
> **主提示：** 最有效防治措施；缓解性与控制性药物的任务；为什么同一药有时能跨两类；急性与慢性治疗不能倒置。

### 1｜上游措施

> **脱离变应原是防治哮喘最有效的措施。**

### 2｜缓解性药物

目标：

```text
迅速解除支气管痉挛
→ 尽快改善气流和症状
```

当前 Study 列入：

- SABA；
- SAMA；
- ICS + 福莫特罗接口；
- 短效茶碱；
- 全身糖皮质激素接口。

### 3｜控制性药物

目标：

```text
长期抑制气道慢性炎症
→ 降低高反应性
→ 减少未来发作
```

当前 Study 列入：

- ICS；
- ICS + LABA、ICS + LABA + LAMA等联合；
- 白三烯调节剂；
- LABA（不单用）；
- 缓释茶碱；
- 生物制剂接口。

### 4｜核心原则

```text
急性发作
先舒张气道

长期控制
以抗炎为核心
```

## KP11｜糖皮质激素：长期控制最重要，也通过允许作用恢复 β2 反应

> **讲义定位 →** 内科 Lecture PDF P49｜糖皮质激素  
> **Outline →** U018｜治疗 3–4  
> **主提示：** 为什么是最有效药；抗炎 / 抗过敏；β2允许作用；三种场景的给药途径和代表药。

### 1｜完整作用角色

- 抗炎；
- 抗过敏；
- 抑制磷脂酶A2、前列腺素、组胺等介质接口；
- 减少炎症渗出；
- 上调肾上腺素能受体数量并增加亲和力；
- 增强 β2受体反应性；
- 降低气道高反应性。

因此当前 Study 将其视为：

> **治疗哮喘最有效的药物。**

### 2｜三种场景

| 场景 | 当前 Study 选择 |
|---|---|
| 长期控制炎症 | 吸入 ICS：布地奈德、氟替卡松、倍氯米松 |
| 短期加强治疗 | 口服泼尼松 |
| 严重急性发作 | 尽早静脉氢化可的松或甲泼尼龙 |

（易混：控制炎症不应长期依赖全身口服激素；ICS 是长期主轴。）

## KP12｜β2受体激动剂：急性发作开气道，长期 LABA 必须依托 ICS

> **讲义定位 →** 内科 Lecture PDF P50｜β2受体激动剂  
> **Outline →** U018｜治疗 5–6  
> **主提示：** Gs-AC-cAMP-Ca²⁺链；cAMP/cGMP和介质；SABA / LABA场景；为何LABA不单用。

### 1｜信号通路

```text
β2受体激动
→ Gs
→ 腺苷酸环化酶 AC
→ cAMP↑
→ 支气管平滑肌胞质 Ca²⁺↓
→ 平滑肌舒张
```

同时：

```text
cAMP / cGMP 比值↑
→ 生物活性物质释放下降
→ 抗炎 / 抗介质释放接口
```

### 2｜临床场景

- 急性发作迅速缓解首选：吸入 SABA，如沙丁胺醇、特布他林；
- 长期控制常用：ICS + LABA；
- 当前 Study 示例：布地奈德 + 福莫特罗、氟替卡松 + 沙美特罗；
- LABA 不单独使用，应与 ICS 配合。

### 3｜为什么和激素协同

```text
β2激动剂
→ 快速打开气道

ICS
→ 控制炎症
+ 恢复 / 提高 β2受体反应
```

## KP13｜茶碱与抗胆碱药：一类提高 cAMP，一类压低胆碱能收缩

> **讲义定位 →** 内科 Lecture PDF P50｜茶碱、抗胆碱药  
> **Outline →** U018 治疗 7；U019 治疗 8、11–12  
> **主提示：** 茶碱机制与夜间 / 严重发作接口；SAMA / LAMA；抗胆碱如何改变 cAMP/cGMP；两者与 SABA 的角色差别。

### 1｜茶碱

主要机制按当前 Study：

```text
抑制磷酸二酯酶 PDE
→ cAMP降解减少
→ cAMP↑
→ 平滑肌 Ca²⁺↓
→ 支气管舒张
```

另有：拮抗腺苷受体、增强纤毛清除等接口。

场景：

- 口服缓释茶碱：尤其用于夜间哮喘控制；
- 静脉短效茶碱：严重哮喘急性发作接口；
- 治疗窗窄，当前 Study 安全浓度 6–15 mg/L，归 MI-D。

### 2｜抗胆碱药

```text
阻断迷走 ACh-M受体作用
→ 胆碱能支气管收缩下降
→ cGMP方向下降
→ cAMP/cGMP比值升高
→ 介质释放下降、气道舒张
```

- SAMA：异丙托溴铵，可用于缓解症状；
- LAMA：噻托溴铵，可用于合并 COPD 者接口。

（易混：急性哮喘当前 Study 仍以 SABA 作为迅速缓解首选，SAMA更多作为联合。）

## KP14｜白三烯调节剂、色甘酸钠与酮替芬：控制 / 预防，不用于快速救急

> **讲义定位 →** 内科 Lecture PDF P50｜其他控制药  
> **Outline →** U019｜治疗 9–10、13–14  
> **主提示：** 白三烯能否缓解急性症状；可单用控制炎症的身份；三种特殊哮喘；两种膜稳定药共同和不同作用；与激素上调β2的区别。

### 1｜白三烯调节剂

代表：孟鲁司特。

当前 Study：

- 用于控制炎症，不作为快速缓解药；
- 除 ICS 外，可单用于控制炎症的药物接口；
- 尤其适合：
  - 合并过敏性鼻炎；
  - 阿司匹林哮喘；
  - 运动性哮喘。

### 2｜为何适合阿司匹林哮喘

```text
NSAID抑制 COX
→ 花生四烯酸更多转向白三烯途径
→ 白三烯增加
→ 支气管痉挛与炎症
→ 白三烯受体拮抗剂有针对性
```

### 3｜色甘酸钠与酮替芬

共同：

```text
稳定肥大细胞膜
→ 减少脱颗粒
→ 用于长期预防，而非急性救急
```

酮替芬还可：

- 拮抗组胺；
- 上调 β2受体数量。

（易混：当前 Study 强调酮替芬增加 β2受体数量；糖皮质激素既增加数量，又提高亲和力。）

# Unit E｜急性发作：严重度决定是否立即通气

## KP15｜急性发作四级：越危重，声音和脉搏反而可能变弱

> **讲义定位 →** 内科 Lecture PDF P51｜急性发作严重度  
> **Outline →** U019｜急性发作 15、17–18、21–22  
> **主提示：** 哮喘急性发作4级｜活动/讲话/哮鸣｜重度关键数值｜意识/沉默肺｜循环/呼吸泵危险征

| 程度 | 呼吸 / 活动 | 讲话 | 听诊与高危征象 |
|---|---|---|---|
| 轻度 | 步行或上楼时气短 | 正常 | 散在哮鸣音 |
| 中度 | 稍活动即气短 | 讲话中断 | 弥漫、响亮哮鸣音，可见三凹征 / 奇脉接口 |
| 重度 | 端坐呼吸 | 单字表达 | 弥漫响亮哮鸣音；明显三凹征、奇脉；R>30、PEF<60%、HR>120 |
| 危重度 | 明显通气泵失败 | 不能讲话 / 意识障碍 | 沉默肺；脉率慢或不规则；血压下降；胸腹矛盾运动 |

### 1｜沉默肺

气道并不是更通畅，而是：

```text
严重闭塞
→ 几乎无气流通过
→ 哮鸣音减弱 / 消失
```

### 2｜胸腹矛盾运动

```text
膈肌与呼吸肌极度疲劳
→ 吸气时胸腔负压通过薄弱膈肌牵拉腹部
→ 腹部反而向内凹陷
```

提示通气泵接近衰竭。

### 3｜奇脉

严重气道阻塞时用力吸气，胸腔负压明显增大，肺血管容量和室间隔相互作用可使吸气期左室充盈 / 搏出量下降，脉搏明显减弱。

当前 Study 将严重哮喘、严重右心衰、心包压塞、缩窄性心包炎、大量胸腔积液、张力性气胸等列为奇脉接口；完整列表归 MI-D。

## KP16｜严重哮喘急性发作：持续开气道、尽早抗炎、支持氧合并监测通气泵

> **讲义定位 →** 内科 Lecture PDF P51｜严重发作治疗  
> **Outline →** U019｜急性发作 19–20  
> **主提示：** 严重哮喘：开气道｜抗炎｜氧合｜补液/酸碱｜机械通气指征｜何时有创

### 1｜迅速舒张气道

```text
持续吸入 SABA【迅速缓解首选】
+ SAMA 联合接口
```

### 2｜尽早控制炎症

- 静脉氢化可的松；或
- 静脉甲泼尼龙；
- 当前 Study 不选地塞米松作为该处首选表述。

茶碱可作为严重发作接口。

### 3｜支持治疗

- 吸氧；
- 补液（当前 Study 与 ARDS 限液方向作对比）；
- 当 pH <7.2 时补碱接口。

### 4｜机械通气指征

当前 Study 三个重点：

```text
经治疗后 PaCO₂ ≥45 mmHg
或
呼吸肌疲劳 / 胸腹矛盾运动
或
意识障碍
```

意识障碍提示危重度，需有创机械通气接口。

> **通气指征的实质不是“喘得很厉害”，而是 CO₂排出失败、呼吸泵疲劳或中枢状态恶化。**

# Unit F｜两个高频鉴别树

## KP18｜COPD vs 支气管哮喘：先找共同阻塞语言，再看持续还是可变

> **讲义定位 →** 内科 Lecture PDF P53｜支气管哮喘鉴别专题  
> **Outline →** U020｜1–2  
> **主提示：** 共性；病史 / 年龄 / 痰 / 啰音 / 可逆性 / VA/Q / 药物；什么最有鉴别价值，什么不能单独定病。

### 1｜共同点

两者都可有：

- 呼气性呼吸困难；
- 阻塞性通气障碍；
- FEV1/FVC下降；
- RV增加、过度充气；
- 桶状胸、过清音；
- 语音震颤和呼吸音减弱；
- 呼气音延长；
- X线透亮度增加；
- VA/Q失调；
- 严重时Ⅱ型呼衰。

所以“哮鸣音、桶状胸、一秒率下降”都不是单独的最终鉴别点。

### 2｜核心差异

| 轴 | COPD | 支气管哮喘 |
|---|---|---|
| 典型人群 / 病史 | 中老年、吸烟、长期咳痰喘 | 青年 / 过敏史，反复发作 |
| 症状 | 持续、活动后气短；常有咳痰 | 发作性干咳喘息，夜间 / 凌晨或接触过敏原 |
| 啰音 | 湿啰音或干湿共存 | 干啰音 / 哮鸣音为主，可沉默肺 |
| 气流受限 | 持续、不完全可逆 | 可变、可逆 |
| 关键证据 | 支扩剂后 FEV1/FVC仍<70% | 舒张试验阳性、PEF变异率大、激发试验阳性 |
| VA/Q | 可高可低，并有DLCO下降接口 | 以通气下降导致 VA/Q低为主 |
| 支扩剂 | 稳定期和急性期都使用 | 急性缓解首选SABA；长期LABA不单用 |
| 激素 | 有条件使用 ICS；住院加重期全身激素 | 长期控制以ICS为核心；严重发作尽早静脉激素 |

> **最稳定的主鉴别轴：结构性持续气流受限 vs 炎症 / 痉挛导致的可变性气流受限。**

## KP19｜严重支气管哮喘 vs 心源性哮喘：都夜间端坐，但故障层不同

> **讲义定位 →** 内科 Lecture PDF P53｜严重哮喘与心源性哮喘  
> **Outline →** U020｜3–5  
> **主提示：** 严重哮喘 vs 心源性哮喘｜病史/人群｜痰/啰音｜心脏/X线｜禁忌｜难辨时试用药

### 1｜共同表现

- 咳、喘、呼吸困难；
- 夜间发作；
- 端坐呼吸。

### 2｜故障层不同

| 轴 | 严重支气管哮喘 | 心源性哮喘 |
|---|---|---|
| 上游 | 气道炎症、高反应、痉挛 | 左心衰、肺静脉淤血 / 肺水肿 |
| 人群 / 病史 | 青年、过敏史 | 中老年，高血压 / 冠心病 / 瓣膜病等 |
| 呼吸困难 | 呼气性 | 混合性 / 心源性 |
| 痰 | 发作性干咳或少痰 | 粉红色泡沫样痰接口 |
| 啰音 | 干啰音为主，可沉默肺 | 湿啰音或干湿共存 |
| 心脏 | 多无明显结构性心脏证据 | 左心扩大、奔马律等接口 |
| X线 | 多正常或透亮度增加 | 左心扩大、肺淤血 / 肺水肿 |

### 3｜药物边界

按当前 Study：

- 支气管哮喘禁用吗啡的考试口径；
- 心源性哮喘禁用肾上腺素的考试口径；
- 难以鉴别时，可吸入 SABA 或静脉短效茶碱作为当前 Study 接口。

完整左心衰处理仍归循环 B11，不在此展开。
