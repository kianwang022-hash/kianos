## 0｜这个 Block 到底解决什么

肺血管问题首先改变的不是气道，而是：

```text
PVR↑
→ 右室后负荷↑
→ 右室必须产生更高压力
→ 右室结构和功能改变
→ 肺血流与左心充盈下降
→ 低氧、体循环淤血或低血压
```

关键在于**时间尺度**：

```text
慢性升高
低氧 / 纤维化 / 肺血管床减少
→ 血管痉挛与重构
→ 肺高压
→ 右室向心性肥厚
→ 后期扩张、右心衰

急性升高
DVT脱落堵塞肺动脉
→ PVR骤升
→ 右室来不及肥厚，只能急剧扩张
→ 室间隔左移、左室充盈↓
→ 低血压、晕厥、休克
```

### 本 Block 的中心任务

> **面对呼吸困难、P2亢进、颈静脉怒张或突发胸痛时，先判断肺血管阻力是慢慢升高还是突然升高，再决定证据层和治疗优先级。**

## 3｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. PVR 慢升 → 右室肥厚；PVR 急升 → 右室急剧扩张；
2. 慢性肺心病三类病因：慢性肺病、胸廓病、肺血管病；最常见是慢支并阻塞性肺气肿 / COPD；
3. 缺氧导致肺小动脉痉挛和重构，PVR↑、肺高压是关键环节；
4. 肺血管重构：无肌型细动脉肌化、肌型小动脉中膜增厚、内膜下纵行平滑肌束、胶原增生、血栓机化、毛细血管减少；
5. 肺心病病理诊断标准：肺动脉瓣下 2 cm 处右室前壁肌层 >5 mm；
6. 肺高压体征：P2亢进及通常分裂；可有 Ortner 综合征；
7. 代偿 / 失代偿均可有：颈静脉怒张、三尖瓣区收缩期杂音、肝界下移；机制不同；
8. 仅失代偿期：HJR阳性、三尖瓣区舒张期杂音、肝大压痛、水肿 / 腹水、呼衰；HJR对右心衰最有价值；
9. X线、超声和 ECG 的右心 / 肺动脉高压主要标准；
10. 慢性肺心病急性加重核心：控制感染、改善呼吸、防治并发症；重点“治肺不治心”；
11. 利尿剂、强心苷均不常规使用；知道各自风险与使用边界；
12. 特发性 PAH：超声首选，右心导管金标准；急性血管反应阳性才用 CCB；西地那非按 PDE5 抑制 → cGMP↑ → 肺血管平滑肌舒张理解；
13. PTE 最常来自下肢 DVT；识别 Virchow 三类危险因素；
14. DVT：单侧或双侧不对称肿痛；PTE：突发气促 / 胸痛 / 晕厥 / 少量咯血，三联征并不常齐全；
15. PE 低氧 + 过度通气：PaO₂↓、PaCO₂↓；
16. D-dimer <500 μg/L 用于排除急性 PTE，不能排除慢性；
17. CTPA首选、肺动脉造影 DSA金标准；MRPA / VQ用于严重肾功能不全、碘过敏、妊娠；
18. V/Q：通气保留、灌注缺损，失配；对远端栓塞价值更高；
19. 抗凝是最基本治疗；抗血小板不是本病主轴；
20. 高危 / 大面积 PTE：右室功能不全 + 血流动力学不稳定；先溶栓再普通肝素；
21. 溶栓时间窗 ≤14天，最严重并发症为颅内出血。

# Unit A｜肺血管阻力怎样把肺病变成右心病

## KP01｜慢性 vs 急性 PVR↑：右室为什么一个肥厚、一个扩张

> **讲义定位 →** 病理 Lecture PDF P65–66；内科 Lecture P12、P18  
> **Outline →** 病理 U001｜肺心1、3、5–6；内科 U006｜临床 / 检查  
> **主提示：** 上游2类｜PVR链｜慢→肥厚｜急→扩张｜左室后果2

```text
慢性PVR↑
→ 右室长期压力负荷
→ 向心性肥厚、乳头肌 / 肉柱增粗
→ 后期供血不足、损伤、纤维化与扩张

急性PVR↑
→ 无时间形成肥厚
→ 右室急剧扩张
→ 室间隔向左移
→ 左室容量 / 充盈↓
→ CO↓、低血压 / 休克
```

> 时间决定结构：**慢性先增厚代偿，急性先扩张失衡。**

## KP02｜慢性肺心病病因：肺病、胸廓病、肺血管病三入口

> **讲义定位 →** 病理 Lecture PDF P65；内科 Lecture P12–13  
> **Outline →** 病理 U001｜肺心1；内科 U004｜临床4  
> **主提示：** 病因3类｜最常见1｜慢肺病举例6｜关键环节

### 1｜三类病因

1. **慢性肺疾病**：
   - 慢支并阻塞性肺气肿——最常见；
   - 支气管扩张；
   - 支气管哮喘；
   - 硅肺；
   - 慢性纤维空洞型肺结核；
   - 特发性肺间质纤维化等。
2. **胸廓病变**：严重脊柱侧凸等使胸廓活动受限；
3. **肺血管病变**：广泛或反复肺小动脉栓塞等。

### 2｜共同出口

```text
长期低氧 / 纤维化 / 血管床减少
→ PVR↑
→ 肺动脉高压
→ 右室后负荷↑
→ 慢性肺心病
```

（易混：肺心病完整主体在这里；前序循环仅学习右心后负荷接口。）

## KP03｜肺内血管重构：关键对象是肺小动脉，不是纤维素样坏死

> **讲义定位 →** 病理 Lecture PDF P65  
> **Outline →** 病理 U001｜肺心2–4  
> **主提示：** 触发1｜对象1｜重构7｜毛细血管｜无×1

缺氧主要作用于肺小动脉：

- 无肌型细动脉肌化；
- 肌型小动脉中膜增厚；
- 内膜下出现纵行平滑肌束；
- 小动脉炎；
- 小动脉胶原纤维增生；
- 腔内血栓形成和机化；
- 肺泡间隔毛细血管数量减少。

```text
管壁平滑肌 / 胶原增加
+ 管腔血栓机化
+ 毛细血管床减少
→ 肺循环阻力持续升高
```

（易混：当前病理 Study 强调**胶原增生**，不出现血管纤维素样坏死；后者是胶原纤维坏死。）

## KP04｜右心病理：诊断只抓 1 个厚度标准，其余看“右室变强后失代偿”

> **讲义定位 →** 病理 Lecture PDF P66  
> **Outline →** 病理 U001｜肺心5–6  
> **主提示：** 部位1｜距离/厚度｜形态7｜细胞3｜晚期方向

### 1｜病理形态诊断标准

> 肺动脉瓣下 2 cm 处，右心室前壁肌层厚度超过 5 mm。

### 2｜右心形态

- 心脏重量增加；
- 肺动脉圆锥膨隆；
- 乳头肌和肉柱增粗；
- 室上嵴增厚；
- 室壁肥厚；
- 心腔扩张；
- 外观钝圆。

### 3｜细胞与间质

- 心肌细胞 / 心肌纤维肥大；
- 可有萎缩、损伤；
- 间质纤维化。

```text
长期压力负荷
→ 右室先肥厚增强
→ 血供相对不足、心肌损伤
→ 扩张与失代偿
```

## KP05｜P2 与 Ortner：肺动脉压升高怎样变成听诊和声音嘶哑

> **讲义定位 →** 内科 Lecture P12

> **主提示：** P2方向｜分裂型｜射血/关闭链｜压喉返→综合征

### 1｜第二心音


# Unit B｜慢性肺心病：代偿期和失代偿期不是两套完全不同的体征

## KP06｜三种共同表现：颈静脉、三尖瓣收缩期杂音、肝界下移

> **讲义定位 →** 内科 Lecture P12  
> **Outline →** 内科 U004｜临床2  
> **主提示：** 共同3｜代偿机制3｜失代偿机制3｜痛不痛

| 表现 | 代偿期机制 | 失代偿期机制 |
|---|---|---|
| 颈静脉怒张 | 肺气肿使胸腔负压负值减小，腔静脉回流下降 | 肺气肿 + 右心功能不全 |
| 三尖瓣区收缩期杂音 | 右室肥厚、乳头肌功能障碍 → 相对关闭不全 | 右室扩大 → 三尖瓣环扩大、相对关闭不全 |
| 肝界下移 | 肺气肿、膈肌下移 | 肺气肿 + 淤血性肝大 |

（识别：单靠这三项不能直接判失代偿；必须再找 HJR、水肿、腹水、肝压痛和呼衰。）

## KP07｜失代偿期：右心衰证据 + 呼衰共同出现

> **讲义定位 →** 内科 Lecture P13  
> **Outline →** 内科 U004｜临床3

1. 肝颈静脉回流征阳性——当前 Study 认为对诊断右心衰最有价值；

## KP08｜X线与超声：先看肺动脉，再看右室

> **讲义定位 →** 内科 Lecture P13  
> **Outline →** 内科 U004｜辅助1–2  
> **主提示：** X线4｜数字3｜残根征｜右室移位2｜超声1

### 1｜X线

- 右下肺动脉干横径 ≥15 mm；
- 血管横径 / 气管横径 ≥1.07；
- 肺动脉段凸出高度 ≥3 mm；
- 残根征：中央肺血管扩张、外周肺血管纤细；
- 右心室增大；
- 心脏向左扩大；
- 心尖圆隆、上翘。

### 2｜超声心动图

- 右心室前壁厚度 ≥5 mm。

> X线主要把“肺动脉高压 + 右室增大”画出来；超声把右室壁厚度直接量出来。

## KP09｜ECG：电轴右偏 + V1右室优势 + 肺型P

> **讲义定位 →** 内科 Lecture P13–14  
> **Outline →** 内科 U004｜辅助3–4  
> **主提示：** 轴｜右室3式｜转位｜右房2｜P阈值

当前 Study 的右心负荷方向：

- 电轴右偏 ≥+90°；
- RV1 + SV5 ≥1.05 mV；

## KP10｜急性加重：先治肺，再处理并发症

> **讲义定位 →** 内科 Lecture P14–16  
> **Outline →** 内科 U004｜治疗1–2  
> **主提示：** 原则3｜最重要1｜并发4组｜特征心律1

治疗三条关键原则：

1. 控制感染；
2. 改善呼吸功能；
3. 防治并发症。

> 当前 Study 的核心是 **治肺不治心**：上游肺部问题缓解后，右心负荷才可能下降。

并发症：

- 肺性脑病；
- 酸碱和电解质紊乱；
- 心律失常；
- DVT、休克、消化道出血、DIC。

最具特征的心律失常：**紊乱性房性心动过速**。

## KP11｜利尿剂：减容量可能让痰更稠、酸碱更差

> **讲义定位 →** 内科 Lecture P14  
> **Outline →** 内科 U004｜治疗3  
> **主提示：** 常规？｜风险2｜酸碱链｜若用：剂量/组合

不常规使用，原因：

```text
利尿过多
→ 体液减少
→ 痰液水分减少、黏稠、难排

排钾 / 排氯
→ 低钾低氯碱中毒
→ 呼酸合并代碱
→ 氧解离曲线左移
→ 组织缺氧可加重
```

确需使用时，当前 Study 采用：

- 小剂量；
- 温和利尿；
- 氢氯噻嗪 + 螺内酯。

## KP12｜强心苷：缺氧时易中毒，只在四类情境小剂量使用

> **讲义定位 →** 内科 Lecture P14

## KP14｜IPAH 六类扩血管治疗：CCB只给急性反应阳性者

> **讲义定位 →** 内科 Lecture P15  
> **Outline →** 内科 U005｜治疗1–2

六类治疗：

1. 钙通道阻滞剂 CCB；
2. 前列环素；
3. **PDE5 抑制剂**，如西地那非；
4. NO；

CCB 边界：

- 急性血管反应试验阳性才使用；
- 心动过缓用硝苯地平；
- 心动过速用地尔硫卓。

前列环素：当前 Study 强调扩血管，并可逆转肺血管重构。

### PDE5 第二信使 Source Conflict 裁决｜R9-SC01

当前 Lecture 原页把西地那非相关平滑肌第二信使写作 `cAMP↑`。该句与药物机制的权威来源冲突，因此不再作为 learner Recall target。

canonical 首学机制固定为：

```text
NO
→ sGC
→ cGMP↑
→ 肺血管平滑肌舒张

PDE5
→ 降解 cGMP

西地那非抑制 PDE5
→ cGMP 降解↓
→ 肺血管平滑肌内 cGMP↑
→ 舒张 / 肺血管扩张
```

裁决依据：**FDA REVATIO（sildenafil）Prescribing Information，Clinical Pharmacology §12.1 Mechanism of Action，核验于 2026-09-12**。该标签明确写明 PDE5 负责降解 cGMP，西地那非抑制 PDE5 后增加肺血管平滑肌细胞内 cGMP 并导致舒张。

> 原 Lecture 的 `cAMP↑` 只保留为 source-conflict provenance，避免以后误以为 canonical 曾无依据改写；学习、Recall 与后续机制串联均使用 **PDE5—cGMP**。

## KP16｜PE 血流动力学：堵肺动脉为什么会胸痛、晕厥和休克

> **讲义定位 →** 内科 Lecture P18；回看循环阻塞性休克  
> **Outline →** 内科 U006｜临床3–4；辅助3  
> **主提示：** 阻塞+低氧收缩｜PVR链｜右室3｜左室2｜冠脉/晕厥

```text
血栓机械阻塞肺动脉
+ 低氧性肺血管收缩
→ PVR骤升
→ 右室急剧扩张
→ 室间隔向左移
→ 左室充盈和左心输出量↓
```

肺梗死 / 胸膜受累还可产生胸膜炎性胸痛与少量咯血。

（易混：急性 PE 是急性肺心病的典型上游；慢性肺心病最常见上游仍是 COPD。）

## KP17｜PE 识别：不对称下肢肿痛 + 突发呼吸困难，不等三联征齐全

> **讲义定位 →** 内科 Lecture P18  
> **Outline →** 内科 U006｜临床3–4  
> **主提示：** DVT表现｜PE症状4｜三联仅？｜体征3｜病史6

### 1｜DVT

- 单侧下肢肿胀、疼痛；
- 也可双侧，但常不对称。

### 2｜急性 PTE

- 突发呼吸困难 / 气促，活动后更明显；
- 胸痛：心绞痛样或胸膜炎性；
- 晕厥：可为唯一或首发；
- 咯血：多为少量；
- 心动过速；
- P2亢进及通常分裂；
- 颈静脉怒张等急性右心负荷表现。

只有约 20% 患者同时出现“呼吸困难 + 胸痛 + 咯血”三联征。

> 不能等三联征齐全才进入 PE；先看危险病史和不对称下肢体征。

## KP18｜疑诊检查：D-dimer排除、血气呼碱、ECG看右心

> **讲义定位 →** 内科 Lecture P18、P21  
> **Outline →** 内科 U006｜辅助1–3  
> **主提示：** 6项疑诊｜D-dimer阈值/边界｜血气2↓｜ECG右心4

### 1｜疑诊层

- 下肢静脉超声：找 DVT；
- D-dimer；
- 动脉血气；
- 胸部 X 线；
- 超声心动图：右室功能 / 危险分层；
- ECG。

### 2｜关键结果

- D-dimer <500 μg/L：可排除急性 PTE；敏感性高、特异性低；不能排除慢性 PTE；
- PaO₂↓；
- PaCO₂↓：低氧刺激过度通气，而气道未被严重阻塞；
- ECG：窦性心动过速、右室负荷方向，可出现电轴右偏、右束支传导阻滞、顺钟向转位或 SⅠQⅢTⅢ。

（易混：D-dimer 升高不能单独确诊；当前作用是低值排除。）

## KP20｜抗凝：阻止血栓继续长，是所有层级的最基本治疗

> **讲义定位 →** 内科 Lecture P19  
> **Outline →** 内科 U006｜治疗1–2

### 1｜常用药

- 普通肝素；
- 低分子量肝素；
- 磺达肝癸钠；
- 华法林；

## KP21｜危险分层决定是否溶栓：看血压和右室，不看症状喊得多大声

> **讲义定位 →** 内科 Lecture P19–21  
> **Outline →** 内科 U006｜治疗3–5  
> **主提示：** 低/中/高3层｜右心/血压｜顺序｜高危3门槛｜窗14｜最重并发

| 分层 | 右心功能 / 标志物 | 血压 / 血流动力学 | 当前 Study 治疗 |
|---|---|---|---|
| 低危 | 无右心功能不全 | 正常 | 直接抗凝，不溶栓 |
| 中危 | 右室功能不全，肌钙蛋白 / BNP可升高 | 正常 | 先抗凝，可考虑溶栓 |
| 高危 / 大面积 | 右室功能不全 | 不稳定 | 先溶栓，再普通肝素抗凝 |

高危不稳定门槛：

- 休克 / 收缩压 <90 mmHg；
- 收缩压降低 ≥40 mmHg；
- 心搏骤停。

溶栓：

- rt-PA；
- 尿激酶；
- 链激酶；
- 时间窗 ≤14天；
- 最严重并发症：颅内出血。

> **Source boundary**：讲义强调高危 PE 即使存在绝对溶栓禁忌也可把它视为相对禁忌、先保命；这是当前 Study 考试表述，不在本文件用外部指南静默修订。

## KP22｜慢性肺心病 vs 急性 PE：同为右心负荷，时间、病史和血压不同

> **讲义回看 →** 病理 P65–66；内科 P12–21  
> **Outline →** Batch integration  
> **主提示：** 病史慢/急｜右室肥/扩｜下肢对称/不对称｜PaCO₂方向｜治疗优先

| 轴 | 慢性肺心病 | 急性 PTE |
|---|---|---|
| 时间 | 慢性肺病多年，急性加重常由感染 | 突发，常有制动 / 手术 / 骨折 / DVT |
| 右室 | 先肥厚，后扩张 | 急剧扩张，来不及肥厚 |
| 下肢 | 右心衰可双下肢对称水肿 | DVT常单侧或双侧不对称肿痛 |
| 血气入口 | COPD可低氧 + CO₂潴留 | PaO₂↓、PaCO₂↓ |
| 主要治疗 | 控制感染、改善呼吸、治肺 | 抗凝；高危溶栓 |
| 休克 | 晚期失代偿可有 | 急性阻塞可迅速出现 |

病例顺序：

```text
先看急慢病史
→ 再看DVT与下肢对称性
→ 看右室是肥厚还是急扩
→ 看血压是否不稳
→ 决定治肺、抗凝还是立即溶栓
```
