## 0｜这个 Block 到底解决什么

肺循环通路变窄、减少或被阻挡时，右室为了维持肺血流要承担更高后负荷。后果取决于阻力变化的速度、程度和右室储备：慢性压力负荷可先肥厚适应，持续损伤后才可能扩张失代偿；急性负荷超过能力时，可来不及肥厚就扩张、压低左室充盈和输出，出现低压或休克。不是每次 PVR 上升都必然进入这些终点。

慢性肺病/胸廓病/肺血管病、特发性 PAH 和急性 PTE 从不同上游进入这个模型。DVT 经静脉、右心到肺动脉，阻挡肺循环；它不是慢性肺心病的下一阶段。既有肺病、组织供氧和通用呼衰的完整处理仍在原所属范围。

P2、心腔形态、ECG 和淤血体征是不同观察：P2 亢进不制造右室后负荷，呼衰也不独立证明右心衰。诊断和处理从当前稳定性展开，疑似高危 PE 的危险判断与确诊同时推进，不能等全部检查清单完成后才考虑再灌注。

### 本 Block 的总任务

> **从阻力来源、时间和右室储备解释慢/急两种后果，再把临床证据、上游肺病处理和 PE 抗凝/再灌注接回当前危险。**

## 2｜总 Framework

```text
收缩/重构、血管床减少或栓子阻挡 → PVR增加 → 右室为维持肺血流承担更高后负荷
慢升：肥厚适应；持续损伤/相对缺血等可进至扩张失代偿
急升且超过右室能力：右室急扩、室间隔左移 → 左室充盈/输出↓ → 可低压/休克

上游分支而非疾病阶段
慢肺病/胸廓病/肺血管病 → 低氧收缩、管壁重构、血栓机化或血管床减少
特发性PAH → 独立筛查/确证与血管信号治疗，不能只凭缺少肺病史判定
DVT脱落 → 下腔静脉→右房→右室→肺动脉 → 急性阻挡 + 收缩

观察接各自对象
肺动脉压 → 可P2亢进；分裂取决于射血/传导/阻抗，邻近压迫可Ortner
右室结构/电活动 → 病理、X线/超声、ECG；P2不是负荷的上游原因
体静脉淤血与低输出分别判断；呼衰可独立或先发生，相同体征有不同机制
通气/灌注失配与低输出的组织供氧不足分开，血气并非单病独有

处理从当下状态分流
慢肺心急加重 → 控感染/改善呼吸/防并发；利尿/强心有门槛
疑PE不稳定 → 危险评估与确诊并行，紧急再灌注有禁忌/替代方案，不能等完成检查清单
稳定疑PE → 验前概率选D-dimer等证据；CTPA或合适V/Q等确诊，DSA不人人追加
无禁忌抗凝防血栓扩大；再灌注处理当前阻挡；中危监测/恶化救援，低危不常规溶栓
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

医学关系和条件先独立成形，完整标题〔Prompt〕固定在相应自然节点；隐藏全部注释后仍沿同一模型解释。需要更多细节时展开原 Core，精确残余保留在原 Memory / Precision。

```text
肺循环通路变窄、减少或被阻挡 → 右室为维持肺血流承担更高后负荷
后果取决于阻力上升的速度、程度和右室储备，不是所有PVR增加都会立即右心衰
├─ 慢升：有时间肥厚适应；持续损伤/相对缺血等可使其后扩张、失代偿
└─ 急升且超过右室能力：来不及肥厚，右室扩张、室间隔左移 → 左室充盈/输出↓ → 可低压、晕厥、休克
   〈慢性 vs 急性 PVR↑：右室为什么一个肥厚、一个扩张〔上游慢/急｜PVR/右室后负荷｜结构2结局｜室间隔/左室充盈/输出〕〉

慢性肺心病的上游有慢性肺病、胸廓病和肺血管病三类，COPD是课程最常见入口
R3/R7/R8等既有病种在此接其低氧、纤维化或血管床后果，不重教所有病种
〈慢性肺心病病因：肺病、胸廓病、肺血管病三入口〔病因3类｜最常见1｜慢肺病举例6｜关键环节〕〉
肺小动脉低氧性收缩/管壁重构 + 腔内血栓机化 + 毛细血管床减少 → 持续PVR增加
平滑肌和胶原增生不是纤维素样坏死；不同病理对象不能以一个“变厚”词互换
〈肺内血管重构：关键对象是肺小动脉，不是纤维素样坏死〔缺氧对象｜动脉重构6+毛细血管1｜PVR汇合｜胶原/纤维素样病变辨别〕〉

肺动脉压力与右室负荷留下不同观察
├─ 慢性右室肥厚、肉柱/乳头肌改变及晚期损伤 → 病理结构证据；测量部位与厚度标准分别保留
   〈右心病理：诊断只抓 1 个厚度标准，其余看“右室变强后失代偿”〔部位1｜距离/厚度｜形态7｜细胞3｜晚期方向〕〉
├─ 肺动脉压升高可使P2亢进；P2是压力的观察，不制造右室后负荷
│  S2分裂还取决于射血、传导和阻抗；邻近扩张结构压左喉返神经可出现Ortner嘶哑
│  〈P2 与 Ortner：肺动脉压升高怎样变成听诊和声音嘶哑〔P2方向｜分裂型｜射血/关闭链｜喉返神经/综合征〕〉
├─ X线/超声看肺动脉与右室结构；病理特定部位的壁厚不能与任意超声厚度混用
   〈X线与超声：先看肺动脉，再看右室〔肺动脉3数字/残根征｜右室增大/左扩/心尖｜超声壁厚〕〉
└─ ECG看电轴、右室优势与肺型P；传导阻滞和低电压不等于右房扩大的必然后果
   〈ECG：电轴右偏 + V1右室优势 + 肺型P〔轴｜右室3式｜转位｜肺型P｜传导/低电压边界｜P阈值〕〉

代偿与失代偿不能只靠熟悉体征数目切开
颈静脉怒张、三尖瓣收缩期杂音和肝界下移，在肺气肿/肥厚与右衰时可有不同机制
〈三种共同表现：颈静脉、三尖瓣收缩期杂音、肝界下移〔共同3｜代偿机制3｜失代偿机制3｜痛不痛〕〉
HJR（肝颈静脉回流征）阳性、肝大压痛、水肿/腹水等支持体静脉淤血；前向输出不足是另一条失代偿后果
呼衰可以先于或独立于右心衰，舒张杂音也非必有，不能凭这两项单独宣布右心失代偿
〈失代偿期：右心衰证据与呼衰的区别〔课程5表现｜右心衰证据｜杂音条件｜呼衰边界〕〉

慢肺心当前急加重 → 同时评感染、呼吸和并发症；控制上游肺问题有助于减轻右室负荷
“治肺不治心”强调治疗优先，不取消有条件处理心脏并发症
〈急性加重：先治肺，再处理并发症〔原则3｜最重要1｜并发4组｜特征心律1〕〉
├─ 确需减淤血才评温和小剂量利尿；过量可使痰稠、低钾低氯碱中毒并影响组织释氧
   〈利尿剂：减容量可能让痰更稠、酸碱更差〔使用门槛｜风险2链｜酸碱→释氧｜剂量/利尿组合〕〉
└─ 缺氧增加强心苷毒性；达到现有四类门槛才评小剂量，不能以心率单项判效果
   〈强心苷：缺氧时易中毒，只在四类情境小剂量使用〔使用门槛/毒性风险｜剂量比例｜快排2药｜指征4｜心率判效边界〕〉

特发性PAH保留独立确证和特异治疗支，不是慢肺心的下一阶段
没有已知肺病入口不能单独确诊IPAH；超声筛查和右心导管确证各有角色，阈值保留课程版本
〈IPAH 检查：超声先筛，右心导管确证〔首选｜PASP阈值｜金标准｜mPAP阈值｜有创边界〕〉
按血管信号解释用药：急性血管反应阳性才考虑CCB；其余药物各对相应舒缩/重构环节
NO→sGC→cGMP促舒张，PDE5降解cGMP，西地那非抑制其降解；原cAMP错误只保留Source裁决记录
〈IPAH 六类扩血管治疗：CCB只给急性反应阳性者〔6类｜CCB门槛｜快/慢心率配药｜重构药1｜PDE5-cGMP｜代表药3〕〉

急性PTE从血栓及迁移路径进入同一后负荷模型
损伤、淤滞和高凝促进DVT形成；脱落后经下腔静脉 → 右房 → 右室 → 肺动脉
〈DVT→PTE：栓子来源与三类危险因素〔栓塞身份｜最常来源｜静脉/右心/肺动脉迁移轴｜Virchow3｜危险因素11组〕〉
机械阻挡 + 血管收缩 → PVR突然增加；负荷足够大时发生上述右室急扩和低输出
冠灌注下降可致心绞痛样胸痛；外周梗死/胸膜受累可致胸膜性痛和咯血，疼痛来源分开

突发气促、胸痛、晕厥或不对称腿肿痛结合危险史提高怀疑；不等三联征齐全，无腿征也不排除

## 3｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. PVR 慢升 → 右室肥厚；PVR 急升 → 右室急剧扩张；
2. 慢性肺心病三类病因：慢性肺病、胸廓病、肺血管病；最常见是慢支并阻塞性肺气肿 / COPD；
3. 缺氧导致肺小动脉痉挛和重构，PVR↑、肺高压是关键环节；
4. 肺血管重构：无肌型细动脉肌化、肌型小动脉中膜增厚、内膜下纵行平滑肌束、胶原增生、血栓机化、毛细血管减少；
5. 肺心病病理诊断标准：肺动脉瓣下 2 cm 处右室前壁肌层 >5 mm；
6. 肺高压可有P2亢进及Ortner综合征；分裂宽窄取决于传导、射血时程与阻抗，并非固定；
7. 代偿 / 失代偿均可有：颈静脉怒张、三尖瓣区收缩期杂音、肝界下移；机制不同；
8. 右心失代偿看HJR、肝大压痛、水肿/腹水等；舒张期杂音非必有，呼衰可先于右心衰，不能单凭其判定；
9. X线、超声和 ECG 的右心 / 肺动脉高压主要标准；
10. 慢性肺心病急性加重核心：控制感染、改善呼吸、防治并发症；重点“治肺不治心”；
11. 利尿剂、强心苷均不常规使用；知道各自风险与使用边界；
12. 特发性 PAH：超声首选，右心导管金标准；急性血管反应阳性才用 CCB；西地那非按 PDE5 抑制 → cGMP↑ → 肺血管平滑肌舒张理解；
13. PTE 最常来自下肢 DVT；识别 Virchow 三类危险因素；
14. DVT：单侧或双侧不对称肿痛；PTE：突发气促 / 胸痛 / 晕厥 / 少量咯血，三联征并不常齐全；
15. PE常有低氧与过度通气，PaO₂↓、PaCO₂↓；正常血气不能排除；
16. D-dimer阴性用于合适的低/中验前概率急性PTE排除流程；传统500 μg/L须注明FEU，不能跨试剂/单位硬套，也不用于排除慢性PTE；
17. CTPA主要检查、DSA讲义传统金标准；特殊人群按造影剂、肾功能与妊娠风险选择，不能把MRPA统一视为安全替代；
18. V/Q：通气保留、灌注缺损，失配；对远端栓塞价值更高；
19. 抗凝是最基本治疗；抗血小板不是本病主轴；
20. 高危PTE以血流动力学不稳定判定；紧急评估再灌注与抗凝，溶栓禁忌及替代途径不能省略；
21. 溶栓时间窗 ≤14天，最严重并发症为颅内出血。

### MI-D｜精确残余去向（沿用原准入，不自动制卡）

- 右下肺动脉干、血管 / 气管比和肺动脉段凸出数字；
- ECG 全套电压标准与 P 波阈值；
- 肺心病利尿剂和强心苷完整指征 / 剂量；
- PAH 六类药及代表药；
- PE 危险因素完整清单；
- 抗凝药完整名单、HIT替代、华法林重叠；
- 抗凝疗程细分；
- rt-PA、UK、SK；
- 溶栓禁忌与外部指南差异；
- DSA / MRPA / VQ 的低频细节。

## KP04｜右心病理：诊断只抓 1 个厚度标准，其余看“右室变强后失代偿”

### 1｜病理形态诊断标准

> 肺动脉瓣下 2 cm 处，右心室前壁肌层厚度超过 5 mm。

### 2｜右心形态

- 可有萎缩、损伤；
- 间质纤维化。

→ 血供相对不足、心肌损伤

```

## KP07｜失代偿期：右心衰证据与呼衰的区别

> **讲义定位 →** 内科 Lecture P13  
> **Outline →** 内科 U004｜临床3  
> **主提示：** 课程5表现｜右心衰证据｜杂音条件｜呼衰边界

讲义归入失代偿期的表现：

1. 肝颈静脉回流征阳性——当前 Study 认为对诊断右心衰最有价值；

### PDE5 第二信使 Source Conflict 裁决｜R9-SC01

当前 Lecture 原页把西地那非相关平滑肌第二信使写作 `cAMP↑`。该句与药物机制的权威来源冲突，因此不再作为 learner Recall target。

canonical 首学机制固定为：

```text
NO
→ sGC
→ cGMP↑
→ 肺血管平滑肌舒张

PDE5
→ 降解 cGMP

西地那非抑制 PDE5
→ cGMP 降解↓
→ 肺血管平滑肌内 cGMP↑
→ 舒张 / 肺血管扩张
```

裁决依据：**FDA REVATIO（sildenafil）Prescribing Information，Clinical Pharmacology §12.1 Mechanism of Action，核验于 2026-09-12**。该标签明确写明 PDE5 负责降解 cGMP，西地那非抑制 PDE5 后增加肺血管平滑肌细胞内 cGMP 并导致舒张。

> 原 Lecture 的 `cAMP↑` 只保留为 source-conflict provenance，避免以后误以为 canonical 曾无依据改写；学习、Recall 与后续机制串联均使用 **PDE5—cGMP**。

> **Outline →** 内科 U006｜临床1–2  
> **主提示：** 栓塞身份｜最常来源｜静脉/右心/肺动脉迁移轴｜Virchow3｜危险因素11组

### 1｜来源与路径

栓塞指不溶于血液的异常物质随血流运行后阻塞血管，阻塞物是栓子；血栓只是栓子的一类。PTE指来自静脉系统或右心的血栓栓子阻塞肺动脉或其分支，最常见来源是下肢DVT；最常见不等于唯一来源。

```text
下肢深静脉原位血栓
→ 脱落
→ 下腔静脉
→ 右心房
→ 右心室
→ 肺动脉或其分支
→ 肺血栓栓塞
```

肺血栓栓塞是当前 Study 中最常见的肺栓塞类型。

### 2｜危险因素放回 Virchow 三类

- 内皮损伤；
- 血流淤滞；
- 血液高凝。

高频例：高龄、肥胖、吸烟、口服避孕药、高同型半胱氨酸血症、肿瘤、手术 / 骨折、制动、炎症性肠病、肾病综合征、抗磷脂综合征。

这是正式Prompt要求的11组高频例，不等于原页危险因素表只有这11组。印刷P17表2-11-1另有遗传性与获得性危险因素完整表，作为Source查阅范围保留；正文可识别的妊娠/产褥期、个人/家族血栓史、中心静脉置管及长途旅行等也在该表。当前文字转录有基因名等坏OCR，必须回原表核读，不能凭常识猜出精确拼写或自动扩充本节点必背名单。

## KP16｜PE 血流动力学：堵肺动脉为什么会胸痛、晕厥和休克

> **讲义定位 →** 内科 Lecture P18；回看循环阻塞性休克  
> **Outline →** 内科 U006｜临床3–4；辅助3  
> **主提示：** 机械阻塞/低氧收缩｜PVR/右室/室间隔｜左室充盈/输出｜冠灌/晕厥｜梗死胸膜接口

```text
血栓机械阻塞肺动脉
+ 低氧性肺血管收缩
→ PVR骤升
→ 右室急剧扩张
→ 室间隔向左移
→ 左室充盈和左心输出量↓
→ 低血压、晕厥、休克

同时左心输出量↓
→ 冠脉灌注↓
→ 心肌供需失衡
→ 心绞痛样胸痛
```

肺梗死 / 胸膜受累还可产生胸膜炎性胸痛与少量咯血。

（易混：急性 PE 是急性肺心病的典型上游；慢性肺心病最常见上游仍是 COPD。）

## KP17｜PE 识别：不对称下肢肿痛 + 突发呼吸困难，不等三联征齐全

> **讲义定位 →** 内科 Lecture P18  
> **Outline →** 内科 U006｜临床3–4  
> **主提示：** DVT表现｜PE症状4｜三联仅？｜体征3｜病史6

### 1｜DVT

- 单侧下肢肿胀、疼痛；
- 也可双侧，但常不对称。

### 2｜急性 PTE

- 突发呼吸困难 / 气促，活动后更明显；
- 胸痛：心绞痛样或胸膜炎性；
- 晕厥：可为唯一或首发；
- 咯血：多为少量；
- 心动过速；
- 可有P2亢进；S2分裂并非固定，须结合传导、射血时程和阻抗；
- 颈静脉怒张等急性右心负荷表现。

讲义提示约 20% 患者同时出现“呼吸困难 + 胸痛 + 咯血”三联征。

### 3｜病史六个高识别入口

内科印刷P18列：制动、骨折、手术、服避孕药、抗磷脂综合征、肾病综合征。这六项与症状/下肢证据共同提高怀疑；它们是此处的识别入口，不替代KP15的完整11组危险因素，也不是确诊条件。

> 不能等三联征齐全才考虑PE；危险病史和不对称下肢体征可增加怀疑，但没有下肢症状也不能排除PE。

## KP18｜疑诊检查：D-dimer排除、血气呼碱、ECG看右心

> **讲义定位 →** 内科 Lecture P18、P21  
> **Outline →** 内科 U006｜辅助1–3  
> **主提示：** 6项疑诊｜D-dimer阈值/边界｜血气2轴｜ECG右心4

### 1｜疑诊层

- 下肢静脉超声：找 DVT；
- D-dimer；
- 动脉血气；
- 胸部 X 线：课程可见局部肺透亮度增加、肺纹理稀疏，也可见肺动脉高压和右心扩大；这些是疑诊/背景证据，不独立确诊；
- 超声心动图：右室功能 / 危险分层；
- ECG。

### 2｜关键结果

- D-dimer：须先评估临床验前概率。高敏试验阴性可帮助低/中概率或PE不太可能者排除；高概率者不能凭低值停止检查。讲义500 μg/L常对应FEU口径，不能与DDU直接混用，年龄校正/概率校正须按已验证流程；该阈值不用于排除慢性PTE；
- 常见PaO₂下降、PaCO₂下降：缺氧等刺激增加通气；正常血气不能排除PE，严重衰竭或合并通气障碍时CO₂也可升高；
- ECG：窦性心动过速、右室负荷方向，可出现电轴右偏、右束支传导阻滞、顺钟向转位或 SⅠQⅢTⅢ。

（易混：D-dimer 升高不能单独确诊；当前作用是低值排除。）

## KP19｜确诊检查：CTPA 看血管充盈，V/Q看通气—灌注失配

> **讲义定位 →** 内科 Lecture P18、P21  
> **Outline →** 内科 U006｜辅助4–6  
> **主提示：** 首选｜金标准｜特殊人群2法｜V/Q优势/表现｜CT征2

| 检查 | 当前 Study 角色 |
|---|---|
| CTPA | 确诊首选；肺动脉低密度充盈缺损、轨道征 |
| 肺动脉造影 DSA | 金标准 |
| MRPA | 讲义列特殊人群备选；不能据此认为增强MRPA对妊娠/严重肾损均无风险，需评估钆对比剂、设备能力与准确性 |
| V/Q 显像 | 避免碘对比剂的重要备选；结合胸片及基础肺病选择，妊娠也须按合适方案评估 |

题纲 U006 辅助检查第6题的定位补充：讲义印刷P18 / PDF物理P22列“对远端肺栓塞辅助诊断价值更高”。这是课程检查辨认线索，仍须结合验前概率与显像质量。

V/Q 的核心：

```text
局部气道仍通
→ 通气存在

肺动脉被栓塞
→ 灌注缺损

→ 通气 / 灌注不匹配
```

DSA是讲义的传统金标准，实际通常不作为所有患者必须追加的检查；妊娠也不意味着一律禁止CTPA，须依胸片、风险与可用方案选择。

（易混：COPD可通气和灌注均减低，但不保证每个区域完全匹配；V/Q失配也不是脱离验前概率即可独立定病因。）

## KP20｜抗凝：阻止血栓继续长，是所有层级的最基本治疗

> **讲义定位 →** 内科 Lecture P19  
> **Outline →** 内科 U006｜治疗1–2  
> **主提示：** 基本1｜药5类｜HIT替代｜疗程3层｜抗板边界

### 1｜常用药

- 普通肝素；
- 低分子量肝素；
- 磺达肝癸钠；
- 华法林；
- 新型直接口服抗凝药。

抗凝为无禁忌时的基本治疗。疑似/确诊免疫性HIT时须停肝素并选择非肝素抗凝药；磺达肝癸钠可用于适合的稳定患者，但要看肾功能和出血风险。急性HIT不得在血小板恢复前直接启动华法林。非HIT的常规华法林过渡不仅要重叠至少5天，还须INR达到治疗要求；不能到第5天就自动停肝素。

### 2｜疗程

| 情境 | 当前 Study |
|---|---|
| 短暂 / 可逆危险因素初发，如服雌激素、临时制动 | ≥3个月 |
| 复发、APS、遗传性易栓、持续危险因素、来源不明初发 | 延长抗凝 |
| 合并肿瘤 | 活动性肿瘤/持续风险者常需长期，定期复评肿瘤活动度、出血及获益；并非所有肿瘤史都自动终身 |

### 3｜三类抗栓角色

```text
抗凝：阻止新的纤维蛋白网形成 / 血栓继续扩大
抗血小板：主要针对血小板聚集，不是PTE基本治疗
溶栓：溶解已经形成的纤维蛋白血栓
```

## KP21｜危险分层决定是否溶栓：看血压和右室，不看症状喊得多大声

> **讲义定位 →** 内科 Lecture P19–21  
> **Outline →** 内科 U006｜治疗3–5  
> **主提示：** 低/中/高3层｜右心/血压｜顺序｜高危3门槛｜溶栓时间窗｜最重并发

| 分层 | 右心功能 / 标志物 | 血压 / 血流动力学 | 当前 Study 治疗 |
|---|---|---|---|
| 低危 | 无右心功能不全 | 正常 | 直接抗凝，不溶栓 |
| 中危 | 结合右室、肌钙蛋白及临床风险 | 无持续低血压 | 抗凝、监测；不常规全身溶栓，恶化时考虑救援再灌注 |
| 高危 | 急性右心衰/循环衰竭证据 | 不稳定 | 紧急再灌注评估并安排抗凝；全身溶栓、导管或外科方案按风险与可用性选择 |

高危不稳定门槛：

- 心搏骤停；
- 阻塞性休克：低血压/需升压支持且有低灌注；
- 持续收缩压<90 mmHg，或下降≥40 mmHg持续>15分钟，排除新发心律失常、低血容量或脓毒症等其他原因。

溶栓：

- rt-PA；
- 尿激酶；
- 链激酶；
- 时间窗 ≤14天；
- 最严重并发症：颅内出血。

讲义“高危即使绝对禁忌也溶栓、且溶栓是唯一方法”不能当临床通则。濒死时需个体化权衡，但活动性出血等风险必须评估；有禁忌或溶栓失败可考虑导管/外科再灌注。讲义14天为选项时间窗，不能在窗内忽略适应证，也不应为等检查或完成抗凝而延误抢救。

版本：本表保留课程低/中/高危框架；AHA/ACC 2026已提出A–E分类，本轮不把不同体系无说明混为同一分层。

## KP22｜慢性肺心病 vs 急性 PE：同为右心负荷，时间、病史和血压不同

> **讲义回看 →** 病理 P65–66；内科 P12–21  
> **Outline →** Batch integration  
> **主提示：** 病史慢/急｜右室肥/扩｜下肢对称/不对称｜PaCO₂方向｜治疗优先

| 轴 | 慢性肺心病 | 急性 PTE |
|---|---|---|
| 时间 | 慢性肺病多年，急性加重常由感染 | 突发，常有制动 / 手术 / 骨折 / DVT |
| 右室 | 先肥厚，后扩张 | 急剧扩张，来不及肥厚 |
| 下肢 | 右心衰可双下肢对称水肿 | DVT常单侧或双侧不对称肿痛 |
| 血气入口 | COPD可低氧 + CO₂潴留 | 常见PaO₂↓、PaCO₂↓，并非必需 |
| 主要治疗 | 控制感染、改善呼吸、治肺 | 无禁忌者抗凝；高危评估紧急再灌注 |
| 休克 | 晚期失代偿可有 | 急性阻塞可迅速出现 |

病例顺序：

```text
先看急慢病史
→ 再看DVT与下肢对称性
→ 看右室是肥厚还是急扩
→ 看血压是否不稳
→ 决定治肺、抗凝及是否紧急再灌注，同时核查出血风险
```

## 4｜高密度场景算法

### A｜P2亢进 + 颈静脉怒张

```text
同时看时间、血压和右室，病史或单个体征不独立定病
多年COPD/ILD/TB → 慢性肺心病候选；手术/骨折/制动后突发 → 提高PE怀疑
两者可以共存，不能只凭病史选择治疗

持续低压（时程和其他原因排除见KP21）、阻塞性休克或骤停 → 紧急高危PE评估
无持续低压仍结合临床风险、右室和肌钙蛋白区分低/中危

右室肥厚/超声右室前壁≥5mm支持慢性负荷，仍合读病史；急性扩张和相应标志物用于急性危险判断
P2反映压力，结构与电活动检查分别读取右心，不组成病变发生顺序
```

### B｜PE 按当下危险和问题选择检查

```text
疑似不稳定PE → 危险评估与可行确诊并行，不能等全部检查做完才评再灌注
稳定疑诊 → 先验前概率；合适低/中概率流程中高敏D-dimer阴性可帮助排除，高概率不能据此停查

下肢超声找血栓来源；血气看交换/通气；ECG/超声看右心影响；胸片看背景
这些不是人人必须依次完成的清单

需要确诊 → CTPA首选等相应影像
严重肾功能不全/碘过敏/妊娠 → 结合胸片、基础肺病和对比剂风险选择V/Q或合适影像，MRPA不自动安全
血管造影为课程传统金标准，不要求所有患者追加
```

### C｜治疗优先级

```text
慢性肺心病急加重 → 控感染 + 改呼吸 + 防并发；不常规利尿/强心，达到原条件才评估
无禁忌PTE → 抗凝为基础；血压正常者仍按右室/标志物/临床风险安排监测，中危恶化评救援
符合高危条件 → 紧急再灌注与抗凝策略并行评估，保留溶栓禁忌、导管/外科替代和课程时间窗条件
不能为等全部检查或先完成抗凝延误；不能把14日窗单独当适应证
```
