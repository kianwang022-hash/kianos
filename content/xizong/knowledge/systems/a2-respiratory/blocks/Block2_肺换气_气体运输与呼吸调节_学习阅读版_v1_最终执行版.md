## 0｜这个 Block 到底解决什么

Block 1 只保证：

```text
空气能够进入肺泡
```

但组织真正获得氧，还要再通过五道门：

```text
① 肺泡气体要跨过呼吸膜
② 有通气的肺泡必须有肺血流
③ O₂ 要与 Hb 结合并进入动脉血
④ 到达组织后 Hb 要愿意释放 O₂
⑤ 呼吸中枢要持续调节肺泡通气
```

任一层失败，都可能表现为“缺氧”，但证据完全不同：

```text
肺泡通气失败
→ PaCO₂ 最直接异常

弥散 / VA-Q / 分流失败
→ PaO₂ 下降为主

Hb 数量或结合异常
→ PaO₂ 可正常，氧含量下降

细胞利用障碍
→ PaO₂ 正常，静脉血氧反而可能升高
```

### 本 Block 的总任务

> **看到低氧、CO₂潴留或呼吸困难时，能先定位是通气、弥散、VA/Q、分流、携氧还是控制器出了问题。**

## 1｜总 Framework

```text
A｜肺泡气体怎样跨膜

肺泡与毛细血管分压差
→ 单纯扩散
→ 呼吸膜面积 / 厚度
→ O₂入血、CO₂入肺泡

        ↓

B｜空气和血必须在同一肺泡相遇

VA/Q
├─ 高：血少，死腔样通气
└─ 低：气少，肺内分流样改变

        ↓

C｜气体怎样被血液运输

O₂
├─ 少量物理溶解：决定 PaO₂
└─ 主要与 Hb 结合：决定大部分氧含量

CO₂
├─ 少量物理溶解
├─ 主要 HCO₃⁻
└─ HbCO₂

        ↓

D｜Hb 怎样在肺装氧、在组织卸氧

氧解离曲线
+ 波尔效应
+ 霍尔丹效应

        ↓

E｜控制器怎样调节通气

外周化学感受器
+ 中枢化学感受器
+ 延髓 / 脑桥 / 迷走传入
→ 呼吸频率与深度
```

### 五个组织问题

```text
气有没有到肺泡？
→ VA / PaCO₂

膜能不能过？
→ 呼吸膜 / 弥散

气与血有没有相遇？
→ VA/Q / 分流 / 无效腔

血能不能带？

组织能不能用？

```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 气体交换方向由分压差决定；
2. CO₂ 扩散快于 O₂，因此单纯换气障碍先影响 O₂；
3. 呼吸膜“厚度↑ / 面积↓”是两条不同故障轴；
4. `VA/Q > 0.84`＝相对血少、死腔样；`VA/Q < 0.84`＝相对气少、肺内分流样；
5. 肺通气障碍可同时影响 O₂ 与 CO₂，肺换气障碍主要影响 O₂；
6. PaCO₂ 更直接反映肺泡通气；
7. PaO₂、SaO₂、Hb、氧含量不是一个变量；
8. 物理溶解虽少，但决定分压、是化学结合的桥梁；
9. 氧解离曲线右移＝P50↑＝亲和力↓＝更易卸氧；
10. 波尔效应与霍尔丹效应分别在解释什么；
11. CO 中毒 PaO₂ 可正常，但氧含量和组织供氧下降；
12. 外周化学感受器可感受 PaO₂↓；中枢不能感受缺氧；
13. 外周“快、弱、不易适应”，中枢“慢、强、敏感、易适应”；
14. PaO₂ / PaCO₂ 对呼吸中枢既有间接兴奋，也有高水平直接抑制；
15. 慢性Ⅱ型呼衰主要由低氧驱动呼吸的 Study 逻辑；
16. 脑桥上、下部与迷走传入怎样中断吸气。

### MI-D｜卡片化，不阻塞主线

- 呼吸膜六层；
- 全肺、肺尖、肺底 VA/Q 数值；
- O₂ / CO₂ 各运输形式比例；
- Hb 氧容量计算、正常氧饱和度、P50；
- 氧解离曲线全部移动因素；
- CO 亲和力倍数、发绀阈值；
- PaO₂ 60 / 30 mmHg 等精确阈值；
- 低浓度氧百分比、5% CO₂ 等 Study 数字；
- 长吸式呼吸低频定位。

# Unit A｜肺泡气体怎样跨膜，并与肺血流匹配

## KP01｜肺换气与气体扩散：方向由分压差决定

> **讲义定位 →** 生理 Lecture PDF P186｜肺换气影响因素  
> **Outline →** U016｜影响肺换气 1–8  
> **主提示：** 扩散方向｜Fick因素｜气体扩散能力比较｜为何换气障碍更先影响O₂

### 1｜定义

```text
肺换气
肺泡 ↔ 肺毛细血管之间的气体交换

O₂：肺泡 → 血液
CO₂：血液 → 肺泡
```

方式是单纯扩散。

### 2｜分压差

```text
分压差越大
→ 扩散驱动力越大
→ 扩散速率越快
```

气体总从高分压向低分压扩散，直至动态平衡。

当前 Study 的 PCO₂ 大致排序：

```text
组织细胞
> 组织液
> 组织毛细血管
> 静脉血
> 肺动脉血
> 肺泡气
> 呼出气
> 大气
```

PO₂ 方向相反：大气最高，组织细胞最低。

### 3｜扩散系数

```text
扩散系数 ∝ 溶解度 / √分子量
```

- 溶解度越大，扩散越快；
- 分子量越大，扩散越慢；
- CO₂ 溶解度远高于 O₂，扩散系数约为 O₂ 的 20 倍。

因此：

> **单纯肺换气受损时，O₂ 比 CO₂ 更容易先出问题。**

这也是换气障碍更容易形成Ⅰ型呼衰的基础。

### 4｜温度

按本节：温度↑ → 扩散速率↑。

## KP02｜呼吸膜：是“变厚”还是“面积减少”

> **讲义定位 →** 生理 Lecture PDF P187｜呼吸膜  
> **Outline →** U016｜影响肺换气 7–9  
> **主提示：** 六层结构；厚度 / 距离轴；面积轴；各类疾病放在哪一轴。

### 1｜呼吸膜六层

```text
肺泡表面活性物质层
→ 肺泡上皮细胞层
→ 上皮基底膜
→ 间质层
→ 毛细血管基底膜
→ 毛细血管内皮细胞层
```

平均厚度不到 1 μm，且总面积很大，构成高效气-血屏障。

### 2｜扩散距离增加

```text
肺水肿
肺纤维化
尘肺 / 硅肺
→ 呼吸膜变厚
→ 扩散距离↑
→ 扩散速率↓
```

（易混：肺水肿不一定意味着整个肺泡完全被液体替代；间质和肺泡内液体可使气-血路径变长。）

### 3｜扩散面积减少

```text
肺实变
肺不张
肺气肿
肺毛细血管关闭 / 阻塞
肺叶切除
→ 有效交换面积↓
→ 扩散速率↓
```

- 肺实变：渗出物占据肺泡；
- 肺气肿：肺大疱、肺泡壁和毛细血管床被破坏；
- PE：肺血流通路被阻断，部分肺泡失去有效交换面积。

## KP03｜VA/Q：有空气还要有血，有血还要有空气

> **讲义定位 →** 生理 Lecture PDF P187｜通气 / 血流比  
> **Outline →** U016｜影响肺换气 10–14  
> **主提示：** VA/Q：公式/正常值｜肺尖 vs 肺底｜高/低各代表什么｜死腔样 vs 分流样

### 1｜公式

```text
VA/Q
= 肺泡通气量 / 每分钟肺血流量
```

```text
全肺平均约 0.84
```

其中肺血流量约等于右心室心输出量。

### 2｜直立位肺尖和肺底

受重力影响，肺尖和肺底的通气、血流都不同，且血流变化更明显：

```text
肺尖 VA/Q ≈ 3.3
→ 相对血流不足

肺底 VA/Q ≈ 0.63
→ 相对通气不足
```

这是生理性局部差异；全肺总体仍可维持有效换气。

### 3｜VA/Q 高：大大

```text
VA/Q > 0.84
→ 相对气体多、血流少
→ 部分肺泡气体无人交换
→ 肺泡无效腔↑
→ 死腔样通气
```

典型接口：肺动脉栓塞、DIC、肺气肿中毛细血管床减少。

口诀：**大大**——比值大，肺泡无效腔大。

### 4｜VA/Q 低：短小

```text
VA/Q < 0.84
→ 相对血流多、通气少
→ 静脉血流经通气不足肺泡后仍未充分氧合
→ 功能性动-静脉短路
→ 肺内分流样改变
```

典型接口：哮喘、肺纤维化、肺炎、肺不张、ARDS。

口诀：**短小**——动静脉短路，比值小。

（易混：这里是功能性分流，不等于存在真实解剖通道。）

## KP04｜通气障碍、换气障碍与呼衰：先看 PaCO₂ 还是 PaO₂

> **讲义定位 →** 生理 Lecture PDF P188、P192–193｜通气 vs 换气、VA/Q 代偿  
> **Outline →** U016｜影响肺换气 12–15；V/Q 异常为何主要缺氧  
> **主提示：** 通气障碍 vs 换气障碍；Ⅰ/Ⅱ型呼衰接口；COPD 为何 V/Q 可高可低；V/Q 异常为何主要低氧；俯卧位。

### 1｜通气障碍

```text
空气不能有效进出肺泡
→ O₂进不来
→ CO₂排不出
→ PaO₂↓、PaCO₂↑
→ 容易形成Ⅱ型呼衰
```

典型接口：严重 COPD、哮喘、通气泵失败。

### 2｜换气障碍

```text
气体已到肺泡
但跨膜 / 匹配失败
→ O₂先受影响
→ PaO₂↓
→ PaCO₂常正常或下降
→ 容易形成Ⅰ型呼衰
```

典型接口：肺纤维化、肺水肿、PE、ARDS。

### 3｜COPD 为什么 V/Q 可升可降

```text
小气道不完全阻塞
→ VA↓
→ VA/Q↓

肺气肿破坏 / 压迫毛细血管床
→ Q↓
→ VA/Q↑
```

所以同一个肺中可同时出现低 V/Q 与高 V/Q 区域。

### 4｜V/Q 异常为何通常主要表现为缺氧

1. CO₂ 扩散系数远大于 O₂；
2. 动静脉 PO₂ 差远大于 PCO₂ 差；
3. CO₂ 解离曲线近线性，健康肺泡可通过增加通气代偿排 CO₂；
4. O₂ 解离曲线上段平坦，健康肺泡 Hb 已接近饱和，难以携带更多 O₂ 去补偿病变区。

最终：

```text
PaO₂明显下降
PaCO₂可正常甚至下降
```

### 5｜//串联：ARDS 俯卧位

按本节 Study：

```text
俯卧位
→ 背侧肺免受部分重力和心脏压迫
→ 萎陷肺泡复张
→ 肺内分流减少
→ 换气改善
```

ARDS 完整模型后置 R12。

# Unit B｜血液怎样携带 O₂ 和 CO₂

## KP05｜O₂ 运输：PaO₂、氧含量、氧容量、氧饱和度不是一回事

> **讲义定位 →** 生理 Lecture PDF P188–189｜O₂ 运输  
> **Outline →** U016｜气体运输 1–3  
> **主提示：** 物理溶解与 HbO₂；氧含量、氧容量、氧饱和度；1.34×Hb；为什么 PaO₂ 正常不代表氧含量正常。

### 1｜两种形式

```text
物理溶解于血浆
→ 量很少
→ 决定 PO₂ / PaO₂
→ 是后续化学结合与释放的桥梁

与 Hb 化学结合为 HbO₂
→ 约占 O₂ 运输 98.5%
→ 不需酶
→ 反应快、可逆
```

（特殊：这是氧合，不是氧化；Hb 中 Fe²⁺ 与 O₂ 结合后仍为 Fe²⁺。）

### 2｜氧含量

```text
100 mL 血液中实际含有多少 O₂
= 物理溶解 O₂ + HbO₂
≈ HbO₂
```

### 3｜氧容量

```text
100 mL 血液中的 Hb 最多能结合多少 O₂
```

按 Study：

```text
1 g Hb 最多结合约 1.34 mL O₂
正常 Hb ≈ 15 g / 100 mL
氧容量 ≈ 1.34 × 15 ≈ 20.1 mL / 100 mL
```

### 4｜氧饱和度

```text
SaO₂ = 实际氧含量 / 氧容量
```

正常动脉血氧饱和度约 97%。不是 100%，与部分支气管静脉血直接汇入肺静脉等生理性静脉混合有关。

### 5｜四个变量边界

```text
PaO₂
物理溶解氧形成的分压

SaO₂
Hb 被 O₂ 占据的比例

Hb
可用的载体数量

CaO₂ / 氧含量
血液实际携带的 O₂ 总量
```

所以：

> **PaO₂ 正常，仍可因 Hb 少或 Hb 被 CO 占据而组织缺氧。**

## KP06｜CO₂ 运输：HCO₃⁻ 是主力，HbCO₂ 是高效接口

> **讲义定位 →** 生理 Lecture PDF P189–190｜CO₂ 运输  
> **Outline →** U016｜气体运输 4–7  
> **主提示：** CO₂运输3形式｜各比例｜CA/氯转移｜HbCO₂｜霍尔丹效应

### 1｜三种形式

| 形式 | 当前 Study 占比 / 身份 | 是否需酶 |
|---|---|---|
| 物理溶解 CO₂ | 少量；形成 PCO₂，作为桥梁 | 否 |
| HCO₃⁻ | 约 89%，最主要运输形式 | 生成过程需碳酸酐酶 CA |
| HbCO₂ | 约 6%；但肺部释放比例高，效率高 | 与 Hb 结合不需酶 |

### 2｜HCO₃⁻ 路径

```text
CO₂ 进入红细胞
→ 在 CA 作用下形成 H₂CO₃
→ 解离为 H⁺ + HCO₃⁻
→ HCO₃⁻ 经氯转移进入血浆
→ 血浆中以 NaHCO₃ 为主
```

红细胞内 CA 丰富，因此这条路径高效。

### 3｜乙酰唑胺

```text
抑制碳酸酐酶
→ CO₂ 转化 / 运输受影响
→ 组织 PCO₂↑
```

完整药理和临床使用不在本 Block 展开。

### 4｜HbCO₂ 与霍尔丹效应

```text
组织：HbO₂释放O₂
→ 去氧Hb增多
→ 更容易结合CO₂和H⁺
→ 有利于组织摄取CO₂

肺：Hb与O₂结合形成HbO₂
→ HbCO₂解离
→ CO₂更容易释放入肺泡
```

一句话：

> **Hb 在组织卸氧后更能装 CO₂；在肺装氧后把 CO₂“蹬开”。**

## KP07｜氧解离曲线：上段保装氧，下段保卸氧

> **讲义定位 →** 生理 Lecture PDF P190–191｜氧解离曲线  
> **Outline →** U016｜氧解离曲线 1–4  
> **主提示：** S 形、T / R、协同效应；上中下三段；PaO₂ 60 与 SaO₂ 90；P50。

### 1｜为什么是 S 形

Hb 有 4 个亚基，彼此有协同 / 变构效应：

```text
第一个 O₂ 与 Hb 结合
→ Hb 由 T 型逐渐转为 R 型
→ 其他亚基亲和力↑

第一个 O₂ 从 HbO₂ 解离
→ Hb 由 R 型逐渐转为 T 型
→ 其他亚基更容易释放 O₂
```

按 Study：

```text
T 型（tense）亲和力低
R 型（relax）亲和力高
```

### 2｜三段意义

| 曲线段 | PO₂ 范围 | 形态 | 生理意义 |
|---|---:|---|---|
| 上段 | 60–100 mmHg | 平坦 | 肺部装氧安全区；PaO₂≥60 时 SaO₂通常≥90% |
| 中段 | 40–60 mmHg | 较陡 | 安静组织卸氧 |
| 下段 | 15–40 mmHg | 最陡 | 运动 / 高代谢组织大量卸氧 |

口诀：**上坡缓，下坡陡。**

### 3｜P50

```text
P50
= Hb 氧饱和度达到 50% 时的 PO₂
≈ 26.5 mmHg
```

```text
P50↑ → 曲线右移 → 亲和力↓ → 易卸氧
P50↓ → 曲线左移 → 亲和力↑ → 难卸氧
```

## KP08｜氧解离曲线移动：组织想用氧时往右，想抓紧氧时往左

> **讲义定位 →** 生理 Lecture PDF P191–192｜曲线影响因素  
> **Outline →** U016｜氧解离曲线 5–8  
> **主提示：** 右移 / 左移因素；P50；低温麻醉、宁酸勿碱、库存血、缺氧 / 贫血 / 高原。

### 1｜右移

```text
温度↑
PCO₂↑
H⁺↑ / pH↓
2,3-DPG↑

→ 曲线右移
→ P50↑
→ Hb 对 O₂ 亲和力↓
→ 更易释放 O₂
→ 有利于代谢旺盛组织用氧
```

口诀：**增高右移。**

常见场景：运动、发热、酸性代谢环境、缺氧、贫血、高海拔适应。

### 2｜左移

```text
温度↓
PCO₂↓
pH↑
2,3-DPG↓
CO 中毒

→ 曲线左移
→ P50↓
→ Hb 对 O₂ 亲和力↑
→ 不易释放 O₂
```

### 3｜三个 Study 串联

- **低温麻醉**：降低组织耗氧；同时曲线偏左，Hb 更抓氧；
- **宁酸勿碱**：不恰当补碱可使曲线左移，加重组织卸氧困难；
- **长期库存血**：红细胞糖酵解停止 → 2,3-DPG↓ → 曲线左移 → 氧不易释放。

（边界：这些是生理 Study 串联，不替代临床输血和酸碱治疗决策。）

## KP09｜波尔效应 vs 霍尔丹效应：肺和组织分别怎样互相促进 O₂ / CO₂ 交换

> **讲义定位 →** 生理 Lecture PDF P192–193｜两个效应与 V/Q 代偿  
> **Outline →** U016｜氧解离曲线 9–10  
> **主提示：** 波尔效应看酸度影响 O₂；霍尔丹效应看氧合影响 CO₂；在肺和组织各自推一遍。

### 波尔效应

> **血液酸度改变 Hb 与 O₂ 的亲和力。**

**组织：**

```text
CO₂进入血液
→ H⁺↑、pH↓
→ 氧解离曲线右移
→ HbO₂更易解离
→ 向组织释放 O₂
```

**肺：**

```text
CO₂离开血液
→ H⁺↓、pH↑
→ 氧解离曲线左移
→ Hb 更易结合 O₂
```

### 霍尔丹效应

> **Hb 是否氧合，改变其运输 CO₂ 和 H⁺ 的能力。**

**组织：**

```text
HbO₂卸氧
→ 去氧Hb↑
→ 更易结合CO₂ / H⁺
→ CO₂运输↑
```

**肺：**

```text
Hb装氧形成HbO₂
→ 与CO₂ / H⁺亲和力下降
→ HbCO₂解离
→ CO₂释放↑
```

### 一句话分辨

```text
波尔：酸度 → O₂
霍尔丹：氧合 → CO₂
```

# Unit C｜低氧不一定来自肺：CO、贫血和细胞利用障碍

## KP10｜CO 中毒：PaO₂ 可以正常，但 Hb 不能有效装氧和卸氧

> **讲义定位 →** 生理 Lecture PDF P194｜CO 中毒  
> **Outline →** U016｜CO 中毒 1–7  
> **主提示：** CO中毒：Hb结合/解离｜曲线改变｜PaO₂ vs O₂含量｜组织卸氧｜颜色/刺激/治疗

### 1｜CO 怎样破坏 Hb 运输

按本节 Study：CO 与 Hb 亲和力约为 O₂ 的 250 倍。

```text
在肺
CO 霸占尚未结合 O₂ 的 Hb
→ HbO₂形成↓
→ 动脉血氧含量↓

在组织
CO 与一个亚基结合
→ 其他亚基对 O₂ 亲和力↑
→ 氧解离曲线左移
→ 已形成的 HbO₂ 不易释放 O₂
```

所以 CO **既妨碍结合，也妨碍解离**。

### 2｜对细胞呼吸链

按 Study：CO 可抑制复合体Ⅳ的还原型 Cyt a₃ → O₂ 环节，使呼吸链失效。

### 3｜关键血氧变量

```text
PaO₂：正常
因为肺通气和肺换气本身可正常，物理溶解氧仍形成正常分压

动脉血氧含量：下降
因为 HbO₂↓

静脉血 PvO₂：下降
组织继续摄取物理溶解氧，但 HbO₂ 无法正常解离补充
```

### 4｜颜色与呼吸刺激

- HbCO 呈樱桃红色；
- 缺氧但通常不发绀；
- 外周化学感受器读取 PaO₂，不读取氧含量，因此 PaO₂正常时不能有效通过缺氧刺激呼吸。

### 5｜治疗接口

按本节 Study：

```text
高压氧
→ 大幅提高物理溶解 O₂
→ 在 Hb 被 CO 占据时仍增加血中可用 O₂
```

讲义另保留“吸氧时加入一定 CO₂（约5%）刺激呼吸”的考试口径。完整现代临床路径后置中毒模块，不在此扩写。

## KP11｜发绀、严重贫血、CO 与氰化物：同是缺氧，血氧证据不同

> **讲义定位 →** 生理 Lecture PDF P195｜发绀与四类缺氧比较  
> **Outline →** U016｜发绀 1–3  
> **主提示：** 发绀定义；发绀但不缺氧 / 缺氧但不发绀；四类状态 PaO₂、氧含量、PvO₂、颜色。

### 1｜发绀看什么

按本节 Study：

```text
去氧Hb ≥ 50 g/L（5 g/100 mL）
→ 皮肤黏膜呈紫蓝色
```

```text
缺不缺氧
→ 看氧合 Hb / 氧含量 / 组织氧供

发不发绀
→ 看去氧 Hb 的绝对量
```

### 2｜四类比较

| 状态 | PaO₂ | 动脉血氧含量 | 静脉血 PvO₂ | 皮肤黏膜 |
|---|---|---|---|---|
| 肺通气 / 换气障碍 | ↓ | ↓ | ↓ | 紫蓝，可发绀 |
| CO 中毒 | 正常 | ↓ | ↓ | 樱桃红，缺氧但不发绀 |
| 严重贫血 | 正常 | ↓ | ↓ | 苍白，缺氧但不发绀 |
| 氰化物中毒 | 正常 | 按本节表：正常 | ↑ | 鲜红 |

### 3｜为什么氰化物 PvO₂↑

```text
细胞氧化磷酸化被抑制
→ 组织不能利用 O₂
→ 静脉血仍保留较多 O₂
→ PvO₂↑、静脉血偏鲜红
```

（易混：CO 既影响 Hb 运输又影响细胞利用；氰化物主要从“细胞不能利用氧”切入。）

### 4｜特殊

- 高原可因红细胞增多出现“高原红”；按本节曲线上段逻辑，只要 PaO₂仍≥60 mmHg，SaO₂可保持≥90%；
- 严重贫血虽缺氧，但总 Hb 太少，去氧 Hb 难达到发绀阈值。

## KP13｜外周 vs 中枢化学感受器：感受什么、通过什么路径、谁快谁强

> **讲义定位 →** 生理 Lecture PDF P201–202｜化学感受器比较  
> **Outline →** U017｜化学感受性反射 5–10、16  
> **主提示：** 外周 vs 中枢化学感受器｜刺激物｜传感路径｜血脑屏障/CA｜速度/强度｜CO/贫血例外

### 1｜外周能直接感受什么

```text
动脉 PaO₂↓
动脉 H⁺↑
```

都可直接刺激颈动脉体 / 主动脉体。

### 2｜中枢能感受什么

中枢化学感受器：

```text
不能感受缺氧
不能直接感受动脉血H⁺
主要感受脑脊液H⁺↑
```

动脉血 H⁺极性强，不易通过血脑屏障；CO₂可通过血脑屏障：

```text
PaCO₂↑
→ CO₂进入脑脊液
→ 在CA参与下形成H⁺
→ 刺激中枢化学感受器
```

### 3｜CO₂ 如何刺激外周

按本节 Study，外周和中枢都没有独立 CO₂受体：

```text
CO₂进入外周感受细胞
→ 经CA转为H⁺
→ 感受细胞内H⁺↑
```

细胞内 CA 多、脑脊液 CA 少，所以外周反应快，中枢反应慢。

### 4｜四维比较

| 维度 | 外周化学感受器 | 中枢化学感受器 |
|---|---|---|
| 位置 | 颈动脉体、主动脉体 | 延髓腹外侧 |
| 速度 | 快 | 慢 |
| 强度 / 敏感性 | 较弱 | 强、敏感 |
| 适应 | 不易适应 | 易适应 |
| 能否感受 PaO₂↓ | 能 | 不能 |
| 主要 H⁺位置 | 感受细胞内 H⁺ | 脑脊液细胞外 H⁺ |

口诀角色：外周“豌豆射手”——快、弱、持续；中枢“火爆辣椒”——慢、强、敏感、易适应。

### 5｜CO 中毒和严重贫血为何不刺激呼吸

它们使氧含量下降，但肺通气 / 换气可正常，PaO₂正常；外周化学感受器读的是 **PaO₂**，不是氧含量，因此缺氧驱动不足。

## KP14｜间接兴奋 vs 直接抑制：O₂和CO₂都不能无限刺激呼吸

> **讲义定位 →** 生理 Lecture PDF P202–203｜直接与反射作用  
> **Outline →** U017｜化学感受性反射 10–14  
> **主提示：** PaO₂<60 / <30；PaCO₂过低 / 过高；机械通气过度；为什么一定水平 CO₂ 必需。

### 1｜两股相反作用

```text
PaO₂↓ / PaCO₂↑
→ 刺激化学感受器
→ 反射性兴奋呼吸中枢

但它们严重异常时
→ 对呼吸中枢直接抑制
```

### 2｜PaO₂ 阈值

按本节 Study：

```text
PaO₂ < 60 mmHg
→ 外周化学感受器显著兴奋
→ 呼吸加深加快

PaO₂ < 30 mmHg
→ 直接抑制作用超过反射兴奋
→ 呼吸抑制
```

### 3｜PaCO₂ 不能过低，也不能过高

```text
PaCO₂过低
如机械通气过度
→ 缺少维持呼吸中枢活动的CO₂ / H⁺刺激
→ 呼吸被抑制

PaCO₂过高
→ 直接中枢抑制超过反射兴奋
→ 呼吸被抑制
```

所以一定水平的 PaCO₂ 对维持正常呼吸活动是必需的。

按讲义考试口径，吸氧时可加入约 5% CO₂ 以刺激呼吸运动。此处只保留 Study 口径，不扩写现代临床适应证。

## KP15｜慢性 CO₂ 潴留、Ⅱ型呼衰与低浓度氧：为什么中枢会“适应”

> **讲义定位 →** 生理 Lecture PDF P203｜慢性适应与氧疗  
> **Outline →** U017｜化学感受性反射 15–19  
> **主提示：** 中枢适应机制；慢性Ⅱ型呼衰主要驱动；高浓度氧为何危险；运动停止后通气为何不立即恢复。

### 1｜中枢为什么易适应长期高 CO₂

```text
PaCO₂持续↑
→ 肾脏增加HCO₃⁻保留，调节血液pH
+
血液HCO₃⁻缓慢通过血脑屏障
→ 中和脑脊液H⁺
→ 脑脊液pH回升
→ 中枢化学感受器刺激减弱
```

所以：

```text
CO₂急性驱动强
CO₂慢性驱动弱
```

### 2｜慢性Ⅱ型呼衰的 Study 逻辑

```text
长期PaCO₂↑
→ 中枢对CO₂适应
→ PaO₂↓对外周化学感受器的刺激
成为维持呼吸的重要驱动
```

若吸入高浓度氧：

```text
PaO₂迅速上升
→ 解除外周低氧刺激
→ 通气进一步下降
→ CO₂潴留加重
→ 直接抑制呼吸中枢 / 肺性脑病接口
```

因此本节保留慢性Ⅱ型呼衰给予低流量、低浓度氧，约 25%–30% / 30%左右的考试口径。完整氧疗和通气策略后置 R12。

### 3｜运动停止后为何仍通气增加

```text
运动中产生乳酸和氧债
→ 运动后仍需更多O₂
→ 清除乳酸、补充ATP和磷酸肌酸
→ 肺通气量不会立刻回到基线
```
