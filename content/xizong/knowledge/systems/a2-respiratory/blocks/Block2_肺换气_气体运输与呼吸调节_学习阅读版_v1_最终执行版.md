## 0｜这个 Block 到底解决什么

Block 1 已建立气道、呼吸肌 / 胸廓 / 胸膜腔怎样完成肺泡通气。这里从同一个肺泡交换单位继续：肺泡通气更新气体，肺血流同时送来静脉血；两侧气体分压差驱动扩散，呼吸膜的有效面积和厚度限制通量。

O₂ 从肺进入血液，主要由 Hb 携带，再在组织释放；组织产生的 CO₂ 经血液沿反向路径回肺排出。呼吸控制器在这条通路运转时持续读取血气，改变呼吸频率与深度，反馈调节肺泡通气。

故障发生在不同环节，观察到的证据也不同：

```text
有效肺泡通气不足 → CO₂排出不足 → PaCO₂↑（须结合CO₂生成量）
弥散 / VA-Q / 分流异常 → 肺血氧合受损 → 常以PaO₂↓为主
Hb数量或结合异常 → 携氧量↓，PaO₂仍可正常
细胞利用障碍 → 组织不能正常摄取 / 使用O₂，静脉血氧可升高
控制器或通气输出受损 → 反馈不能有效调节肺泡通气 → 血气继续异常
```

### 本 Block 的总任务

> **沿同一气体通路定位通气、弥散、VA/Q、分流、携氧或利用故障，并说明呼吸控制器怎样反馈改变通气；检查读取这些变量，处置回作用于相应环节。**

## 1｜总 Framework

```text
肺泡通气VA更新肺泡气；肺血流Q同时送来静脉血
→ 在同一交换单位形成肺泡—血液的O₂ / CO₂分压梯度

分压差决定扩散方向；D、有效面积、厚度 / 距离共同约束通量
→ 肺内O₂由肺泡入血，CO₂由血入肺泡

VA与Q失配时：
气相对多 / 血少 → 死腔样通气
气相对少 / 血多 → 流出血未充分氧合 → 分流样混合
膜变厚 / 有效面积减少也可限制交换；这些故障可在同一疾病中并存

肺内装O₂ → 血液以Hb结合为主携带 → 组织卸O₂ / 使用O₂
组织生成CO₂ → 红细胞 / 血浆携带 → 肺内释放CO₂ → 肺泡通气排出
Hb亲和力影响装卸氧；Bohr与Haldane效应把这两个反向过程耦合

并行反馈：血气变化 → 外周 / 中枢感受输入 → 延髓 / 脑桥调节呼吸
→ 频率、深度与吸气时程改变 → 回到肺泡通气VA → 再改变血气
迷走传入参与及时终止吸气；慢性适应或极端血气异常可改变反馈效果
```

### 五个定位问题

| 沿通路观察什么 | 对应的变量或证据 | 要分清的边界 |
|---|---|---|
| 肺泡气有没有有效更新 | VA、PaCO₂ | 每分钟总通气不等于有效肺泡通气；反推VA要考虑CO₂生成 |
| 膜能不能有效交换 | 分压梯度、膜面积 / 厚度 | 梯度决定方向，结构约束通量 |
| 气与血有没有配上 | VA/Q、分流样 / 死腔样 | 肺尖 / 肺底正常梯度不自动等于病变 |
| 血能不能携带、组织能不能利用 | PaO₂、SaO₂、Hb、CaO₂、PvO₂ | 正常PaO₂不保证携氧量或组织供氧正常 |
| 通气反馈有没有有效工作 | 感受输入、呼吸模式、血气变化 | 控制器持续回调VA；急性刺激、极端抑制与慢性适应条件不同 |

## 1A｜同一模型上的自然节点〔完整 Prompt〕

从同一个肺泡追踪 O₂ 去程、CO₂ 回程与通气反馈。括注附在它所解释的变量或关系旁；隐藏全部括注，下面的医学关系仍可连续复述。详细解释、精确记忆与原图继续回看各条原有内容。

```text
肺泡通气VA持续更新肺泡气，肺血流Q同时带来静脉血
→ 两侧分压差驱动O₂从肺泡入血、CO₂从血入肺泡
气体通量 ∝ D × 有效面积 × 分压差 / 厚度
CO₂较易扩散，单纯换气受损常先表现为O₂不足
〈肺换气与气体扩散：方向由分压差决定〔扩散方向｜Fick 4因素｜O₂/CO₂差异〕〉

呼吸膜把肺泡与毛细血管隔开，其结构约束同一扩散过程
水肿 / 纤维化使距离↑；肺泡隔破坏 / 肺切除等使有效面积↓
→ 可交换的气体通量下降
〈呼吸膜：是“变厚”还是“面积减少”〔呼吸膜6层｜厚度/距离vs有效面积｜病变→故障轴〕〉

同一肺泡既需要气，也需要血；VA/Q描述两侧是否匹配
气相对多、血少 → 一部分通气无血可交换 → 死腔样
气相对少、血多 → 一部分血未充分氧合即流出 → 分流样
直立肺尖和肺底都有重力梯度，血流变化更明显 → 肺尖比值较高、肺底较低
这是正常区域差异；功能性分流也不等于另有一条解剖通道
〈VA/Q：有空气还要有血，有血还要有空气〔V̇A/Q̇公式/正常值｜肺尖vs肺底｜高低2方向｜死腔样vs分流样〕〉

进入血液的O₂先以溶解形式形成分压，再与Hb可逆结合
PaO₂对应溶解氧，Hb提供载体；正常Hb的SaO₂描述结合占位，CaO₂描述实际含量
血流把所携O₂送到组织；Hb不足或结合异常时，PaO₂正常仍可携氧不足
COHb / MetHb情境要区分饱和度口径并看共氧测定
〈O₂ 运输：PaO₂、氧含量、氧容量、氧饱和度不是一回事〔O₂形式2｜含量/容量/饱和度｜PaO₂/Hb〕〉

Hb在肺装氧、在组织卸氧，取决于局部分压与Hb亲和关系
亚基协同结合及T / R状态转换 → S形氧解离关系
高分压的平坦段有利肺装氧；较低分压的陡段有利组织卸氧
P50是亲和关系的读数：P50↑对应亲和↓、曲线右移、较易卸氧
〈氧解离曲线：上段保装氧，下段保卸氧〔S形机制/T-R｜3段范围→装卸氧｜分压/饱和度锚｜P50定义/值/方向〕〉

组织温度、PCO₂、H⁺、2,3-DPG升高 → Hb亲和↓ → 更易卸O₂
反向变化以及CO作用可使左移 → 剩余结合的O₂更难卸下
缺氧 / 贫血 / 高原可有2,3-DPG适应；低温同时影响耗氧与亲和
不当补碱、库存血2,3-DPG变化各有条件，不能从一条曲线直接推出治疗决定
〈氧解离曲线移动：组织想用氧时往右，想抓紧氧时往左〔移动因素4主轴＋CO｜P50/亲和/卸氧｜低温/补碱/库存血｜缺氧贫血高原〕〉

组织生成的CO₂溶入血液 → 进入红细胞，经CA催化形成H⁺与HCO₃⁻
HCO₃⁻经氯转移进入血浆运输；另有少量溶解CO₂及HbCO₂
血液回肺后释放CO₂ → CO₂进入肺泡 → 随肺泡通气排出
乙酰唑胺抑制CA，影响的是这条转换 / 运输环节
〈CO₂ 运输：HCO₃⁻ 是主力，HbCO₂ 是高效接口〔CO₂运输3形式｜各比例｜CA/氯转移｜HbCO₂｜霍尔丹效应〕〉

组织：CO₂ / H⁺增加 → O₂亲和下降、卸氧增加（Bohr）
组织：Hb去氧 → 更能携带CO₂ / H⁺（Haldane）
肺内：CO₂排出有利装O₂；Hb氧合又促进CO₂ / H⁺释放
→ O₂去程与CO₂回程在肺和组织相互配合
〈波尔效应 vs 霍尔丹效应：肺和组织分别怎样互相促进 O₂ / CO₂ 交换〔效应2：输入→被调气体｜肺vs组织双向链〕〉

交换环节故障后，用血气读取同一通路的结果
VA不足 → O₂进入不足、CO₂排出不足 → 低氧伴高碳酸，严重时可形成Ⅱ型呼衰
弥散 / VA-Q异常 → 常以低氧为主、PaCO₂可正常或下降，严重时可形成Ⅰ型呼衰
达到呼衰条件时再依实际血气分型；完整诊疗交R12
CO₂较易扩散，较好肺区还可多排CO₂；Hb近饱和的较好肺区却难以多装足够O₂补偿坏区
COPD小气道通气不足与毛细床减少 → 不同肺区可同时出现低VA/Q与高VA/Q
ARDS俯卧位改善受压肺区复张 → 减少分流，是回作用于交换单元的处置接口
〈通气障碍、换气障碍与呼衰：先看 PaCO₂ 还是 PaO₂〔通气vs换气→血气｜Ⅰ/Ⅱ型接口｜COPD V/Q双支｜低氧主导4因｜俯卧位接口〕〉

Hb / 组织利用环节也可故障：CO占用Hb，并使余下位点更难卸O₂，还可损害细胞利用
→ 组织缺氧；PaO₂可正常，CaO₂下降，PvO₂随灌注 / 摄取 / 利用而变，不能固定写下降
普通SpO₂或樱桃红外观不能可靠排除 / 确认CO中毒；COHb共氧测定补充识别证据
脱离暴露停止持续CO输入，既有100%氧接口提高供氧；按既有条件评估高压氧以增加溶解氧
完整中毒路径仍归原模块，旧加CO₂说法不作为这里的救治指令
〈CO 中毒：PaO₂ 可以正常，但 Hb 不能有效装氧和卸氧〔CO机制｜曲线｜分压/含量｜识别/氧疗〕〉

同样是组织缺氧，按原环节并行比较血氧证据：
肺通气 / 换气失败 → PaO₂、CaO₂常下降
严重贫血 → Hb载体少，CaO₂下降而PaO₂可正常
CO → Hb占位 / 卸氧及利用受损，PvO₂不能固定排序
氰化物 → 细胞不能正常利用O₂，PaO₂ / CaO₂可正常而PvO₂升高
发绀读取的是去氧Hb绝对量；贫血或CO可缺氧却不发绀，高原红细胞增多也会改变颜色线索
〈发绀、严重贫血、CO 与氰化物：同是缺氧，血氧证据不同〔发绀定义/阈值｜氧供vs去氧Hb绝对量｜状态4类×血氧4轴｜高原/贫血反例〕〉

控制器在上述通路运转时持续工作，血气与传入信号是它的输入
延髓提供基本节律，脑桥调节模式；外周与中枢感受输入并行到达控制网络
颈动脉体经窦神经 / 舌咽，主动脉体经迷走传入
外周参与呼吸调节，也可在严重低氧 / 酸中毒 / 低压时接危急循环反应
〈呼吸控制器总图：延髓、脑桥、外周与中枢化学感受器〔控制器4部件｜外周传入2路｜颈动脉体vs主动脉体｜呼吸/循环参与条件〕〉

外周直接读取PaO₂下降与血H⁺；CO₂进入外周感受细胞，经CA形成细胞内H⁺ → 兴奋外周输入
中枢主要读取脑脊液H⁺；CO₂可越过血脑屏障，经CA相关转换形成H⁺ → 兴奋中枢输入
血H⁺不易直接越过血脑屏障；两路在速度、强度与适应上不同，并行通过呼吸输出回调VA
CO / 贫血只有含量下降而PaO₂未降时，不等于出现了低PaO₂的化学刺激
〈外周 vs 中枢化学感受器：感受什么、通过什么路径、谁快谁强〔外周 vs 中枢化学感受器｜刺激物｜传感路径｜血脑屏障/CA｜速度/强度｜CO/贫血例外〕〉

低O₂ / 高CO₂可经化学感受反射兴奋呼吸，反射兴奋有适用范围
严重低氧或过高CO₂可直接抑制呼吸中枢；CO₂过低也可因刺激不足而抑制呼吸
→ 血气异常与呼吸增强不是无限单调关系
〈间接兴奋 vs 直接抑制：O₂和CO₂都不能无限刺激呼吸〔O₂双作用｜CO₂两端｜中枢/反射｜适用条件〕〉

长期CO₂潴留 → HCO₃⁻缓冲 / 脑脊液pH代偿 → 中枢H⁺刺激减弱
给氧后PaCO₂变化要沿三路追踪：
低氧性肺血管收缩解除 → 气血匹配可恶化
Hb氧合增加 → CO₂携带能力下降、CO₂释放（Haldane）
部分患者通气下降 → CO₂排出减少
→ 按既有高碳酸风险条件滴定氧疗并复查血气，必要时评估通气支持；完整路径回COPD / 呼衰模块
运动后的代谢恢复、乳酸清除和ATP / CP储备恢复仍可维持通气需求
〈慢性 CO₂ 潴留、Ⅱ型呼衰与低浓度氧：为什么中枢会“适应”〔慢性适应｜氧致高碳酸3路｜滴定｜运动后〕〉

呼吸输出还需要及时终止每次吸气
脑桥下部易化吸气；脑桥上部与迷走传入帮助中断吸气
同时失去上部脑桥与迷走的抑制 → 吸气不能及时中断 → 长吸式呼吸
单独切断双侧迷走 → 深慢呼吸；与课程Kussmaul深快呼吸分开，保留实验 / 损毁条件
这些频率、深度与吸气时程改变都回到肺泡通气VA，再改变血气，闭合反馈
〈脑桥、迷走与长吸式呼吸：谁负责及时“刹住吸气”〔调节3部件｜脑桥损毁→型式｜双迷走切断→型式｜vsKussmaul〕〉
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 气体交换方向由分压差决定；
2. CO₂ 扩散快于 O₂，因此单纯换气障碍先影响 O₂；
3. 呼吸膜“厚度↑ / 面积↓”是两条不同故障轴；
4. `VA/Q > 0.84`＝相对血少、死腔样；`VA/Q < 0.84`＝相对气少、肺内分流样；
5. 肺通气障碍可同时影响 O₂ 与 CO₂，肺换气障碍主要影响 O₂；
6. PaCO₂ 更直接反映肺泡通气；
7. PaO₂、SaO₂、Hb、氧含量不是一个变量；
8. 物理溶解虽少，但决定分压、是化学结合的桥梁；
9. 氧解离曲线右移＝P50↑＝亲和力↓＝更易卸氧；
10. 波尔效应与霍尔丹效应分别在解释什么；
11. CO 中毒 PaO₂ 可正常，但氧含量和组织供氧下降；
12. 外周化学感受器可感受 PaO₂↓；中枢不能感受缺氧；
13. 外周“快、弱、不易适应”，中枢“慢、强、敏感、易适应”；
14. PaO₂降低 / PaCO₂升高可经化学感受反射间接兴奋呼吸；严重低氧或过高CO₂可直接抑制呼吸中枢；
15. 慢性Ⅱ型呼衰的化学驱动适应；给氧后CO₂升高还涉及V/Q恶化、霍尔丹效应及部分通气下降，不能只归于低氧驱动；
16. 脑桥上、下部与迷走传入怎样中断吸气。

### MI-D｜卡片化，不阻塞主线

- 呼吸膜六层；
- 全肺、肺尖、肺底 VA/Q 数值；
- O₂ / CO₂ 各运输形式比例；
- Hb 氧容量计算、正常氧饱和度、P50；
- 氧解离曲线全部移动因素；
- CO 亲和力倍数、发绀阈值；
- PaO₂ 60 / 30 mmHg 等精确阈值；
- 低浓度氧百分比、5% CO₂ 等 Study 数字；
- 长吸式呼吸低频定位。

# Unit A｜肺泡气体怎样跨膜，并与肺血流匹配

## KP01｜肺换气与气体扩散：方向由分压差决定

> **讲义定位 →** 生理 Lecture PDF P186｜肺换气影响因素  
> **Outline →** U016｜影响肺换气 1–8  
> **主提示：** 扩散方向｜Fick 4因素｜O₂/CO₂差异

### 1｜定义

```text
肺换气
肺泡 ↔ 肺毛细血管之间的气体交换

O₂：肺泡 → 血液
CO₂：血液 → 肺泡
```

方式是单纯扩散。

### 2｜分压差与Fick关系

```text
扩散速率 ∝ 扩散系数D × 有效面积A × 分压差ΔP / 膜厚d
```

面积/厚度的具体病变例子见KP02；本KP保留完整四因素，不能把换气只归于分压差。


```text
分压差越大
→ 扩散驱动力越大
→ 扩散速率越快
```

气体总从高分压向低分压扩散，直至动态平衡。

当前 Study 的 PCO₂ 大致排序：

```text
组织细胞
> 组织液
> 组织毛细血管
> 体静脉血（随组织和混合程度变化）
≈ 混合静脉/肺动脉血
> 肺泡气
> 呼出气
> 大气
```

PO₂总方向相反：空气到组织逐级降低。上面的PCO₂只是课程方向图，不是每个区室之间均有恒定严格差值；肺动脉携带的本就是混合静脉血，不能与“静脉血”强行拆成固定高低两级。

### 3｜扩散系数

```text
扩散系数 ∝ 溶解度 / √分子量
```

- 溶解度越大，扩散越快；
- 分子量越大，扩散越慢；
- CO₂ 溶解度远高于 O₂，扩散系数约为 O₂ 的 20 倍。

因此：

> **单纯肺换气受损时，O₂ 比 CO₂ 更容易先出问题。**

这也是换气障碍更容易形成Ⅰ型呼衰的基础。原题U016影响因素6写“换气主要影响PCO₂”，与该节O₂/CO₂扩散差异相冲突；原题原字保留在覆盖表，正文按本节讲义模型解释PaO₂更易先下降。

### 4｜温度

按本节：温度↑ → 扩散速率↑。

## KP02｜呼吸膜：是“变厚”还是“面积减少”

> **讲义定位 →** 生理 Lecture PDF P187｜呼吸膜  
> **Outline →** U016｜影响肺换气 7–9  
> **主提示：** 呼吸膜6层｜厚度/距离vs有效面积｜病变→故障轴

### 1｜呼吸膜六层

```text
肺泡表面活性物质层
→ 肺泡上皮细胞层
→ 上皮基底膜
→ 间质层
→ 毛细血管基底膜
→ 毛细血管内皮细胞层
```

平均厚度不到 1 μm，且总面积很大，构成高效气-血屏障。

### 2｜扩散距离增加

```text
肺水肿
肺纤维化
尘肺 / 硅肺
→ 呼吸膜变厚
→ 扩散距离↑
→ 扩散速率↓
```

（易混：肺水肿不一定意味着整个肺泡完全被液体替代；间质和肺泡内液体可使气-血路径变长。）

### 3｜扩散面积减少

```text
肺实变
肺不张
肺气肿
肺毛细血管关闭 / 阻塞
肺叶切除
→ 有效交换面积↓
→ 扩散速率↓
```

- 肺实变：渗出物占据肺泡；
- 肺气肿：肺大疱、肺泡壁和毛细血管床被破坏；
- PE：肺血流通路被阻断，部分肺泡失去有效交换面积。

## KP03｜VA/Q：有空气还要有血，有血还要有空气

> **讲义定位 →** 生理 Lecture PDF P187｜通气 / 血流比  
> **Outline →** U016｜影响肺换气 10–14  
> **主提示：** V̇A/Q̇公式/正常值｜肺尖vs肺底｜高低2方向｜死腔样vs分流样

### 1｜公式

```text
VA/Q
= 肺泡通气量 / 每分钟肺血流量
```

```text
全肺平均约 0.84
```

其中肺血流量约等于右心室心输出量。

### 2｜直立位肺尖和肺底

受重力影响，肺尖和肺底的通气、血流都不同，且血流变化更明显：

```text
肺尖 VA/Q ≈ 3.3
→ 相对血流不足

肺底 VA/Q ≈ 0.63
→ 相对通气不足
```

这是生理性局部差异；全肺总体仍可维持有效换气。

### 3｜VA/Q 高：大大

```text
VA/Q > 0.84
→ 相对气体多、血流少
→ 部分肺泡气体无人交换
→ 肺泡无效腔↑
→ 死腔样通气
```

典型接口：肺动脉栓塞、DIC、肺气肿中毛细血管床减少。

口诀：**大大**——比值大，肺泡无效腔大。

### 4｜VA/Q 低：短小

```text
VA/Q < 0.84
→ 相对血流多、通气少
→ 静脉血流经通气不足肺泡后仍未充分氧合
→ 功能性动-静脉短路
→ 肺内分流样改变
```

典型接口：哮喘、肺纤维化、肺炎、肺不张、ARDS。

口诀：**短小**——动静脉短路，比值小。

（易混：这里是功能性分流，不等于存在真实解剖通道。）

## KP04｜通气障碍、换气障碍与呼衰：先看 PaCO₂ 还是 PaO₂

> **讲义定位 →** 生理 Lecture PDF P188、P192–193｜通气 vs 换气、VA/Q 代偿  
> **Outline →** U016｜影响肺换气 12–15；V/Q 异常为何主要缺氧  
> **主提示：** 通气vs换气→血气｜Ⅰ/Ⅱ型接口｜COPD V/Q双支｜低氧主导4因｜俯卧位接口

### 1｜通气障碍

```text
空气不能有效进出肺泡
→ O₂进不来
→ CO₂排不出
→ PaO₂↓、PaCO₂↑
→ 容易形成Ⅱ型呼衰
```

典型接口：严重 COPD、哮喘、通气泵失败。

### 2｜换气障碍

```text
气体已到肺泡
但跨膜 / 匹配失败
→ O₂先受影响
→ PaO₂↓
→ PaCO₂常正常或下降
→ 容易形成Ⅰ型呼衰
```

典型接口：肺纤维化、肺水肿、PE、ARDS。

### 3｜COPD 为什么 V/Q 可升可降

```text
小气道不完全阻塞
→ VA↓
→ VA/Q↓

肺气肿破坏 / 压迫毛细血管床
→ Q↓
→ VA/Q↑
```

所以同一个肺中可同时出现低 V/Q 与高 V/Q 区域。

### 4｜V/Q 异常为何通常主要表现为缺氧

1. CO₂ 扩散系数远大于 O₂；
2. 动静脉 PO₂ 差远大于 PCO₂ 差；
3. CO₂ 解离曲线近线性，健康肺泡可通过增加通气代偿排 CO₂；
4. O₂ 解离曲线上段平坦，健康肺泡 Hb 已接近饱和，难以携带更多 O₂ 去补偿病变区。

最终：

```text
PaO₂明显下降
PaCO₂可正常甚至下降
```

### 5｜//串联：ARDS 俯卧位

按本节 Study：

```text
俯卧位
→ 背侧肺免受部分重力和心脏压迫
→ 萎陷肺泡复张
→ 肺内分流减少
→ 换气改善
```

ARDS 完整模型后置 R12。

# Unit B｜血液怎样携带 O₂ 和 CO₂

## KP05｜O₂ 运输：PaO₂、氧含量、氧容量、氧饱和度不是一回事

> **讲义定位 →** 生理 Lecture PDF P188–189｜O₂ 运输  
> **Outline →** U016｜气体运输 1–3  
> **主提示：** O₂形式2｜含量/容量/饱和度｜PaO₂/Hb

### 1｜两种形式

```text
物理溶解于血浆
→ 量很少
→ 决定 PO₂ / PaO₂
→ 是后续化学结合与释放的桥梁

与 Hb 化学结合为 HbO₂
→ 约占 O₂ 运输 98.5%
→ 不需酶
→ 反应快、可逆
```

（特殊：这是氧合，不是氧化；Hb 中 Fe²⁺ 与 O₂ 结合后仍为 Fe²⁺。）

### 2｜氧含量

```text
100 mL 血液中实际含有多少 O₂
= 物理溶解 O₂ + HbO₂
≈ HbO₂
```

### 3｜氧容量

```text
100 mL 血液中的 Hb 最多能结合多少 O₂
```

按 Study：

```text
1 g Hb 最多结合约 1.34 mL O₂
正常 Hb ≈ 15 g / 100 mL
氧容量 ≈ 1.34 × 15 ≈ 20.1 mL / 100 mL
```

### 4｜氧饱和度

```text
正常Hb组成下：SaO₂ = Hb实际结合的O₂量 / Hb可结合的最大O₂量
分子不包括物理溶解O₂；不是总CaO₂/氧容量
```

含COHb/MetHb时，还须区分功能性与分数氧饱和度，并用共氧测定判断异常Hb，不能直接套正常Hb的比例。正常动脉血氧饱和度约97%。不是 100%，与部分支气管静脉血直接汇入肺静脉等生理性静脉混合有关。

### 5｜四个变量边界

```text
PaO₂
物理溶解氧形成的分压

SaO₂
Hb 被 O₂ 占据的比例

Hb
可用的载体数量

CaO₂ / 氧含量
血液实际携带的 O₂ 总量
```

所以：

> **PaO₂ 正常，仍可因 Hb 少或 Hb 被 CO 占据而组织缺氧。**

## KP06｜CO₂ 运输：HCO₃⁻ 是主力，HbCO₂ 是高效接口

> **讲义定位 →** 生理 Lecture PDF P189–190｜CO₂ 运输  
> **Outline →** U016｜气体运输 4–7  
> **主提示：** CO₂运输3形式｜各比例｜CA/氯转移｜HbCO₂｜霍尔丹效应

### 1｜三种形式

| 形式 | 当前 Study 占比 / 身份 | 是否需酶 |
|---|---|---|
| 物理溶解 CO₂ | 少量；形成 PCO₂，作为桥梁 | 否 |
| HCO₃⁻ | 约 89%，最主要运输形式 | 生成过程需碳酸酐酶 CA |
| HbCO₂ | 约 6%；但肺部释放比例高，效率高 | 与 Hb 结合不需酶 |

### 2｜HCO₃⁻ 路径

```text
CO₂ 进入红细胞
→ 在 CA 作用下形成 H₂CO₃
→ 解离为 H⁺ + HCO₃⁻
→ HCO₃⁻ 经氯转移进入血浆
→ 血浆中以 NaHCO₃ 为主
```

红细胞内 CA 丰富，因此这条路径高效。

### 3｜乙酰唑胺

```text
抑制碳酸酐酶
→ CO₂ 转化 / 运输受影响
→ 组织 PCO₂↑
```

完整药理和临床使用不在本 Block 展开。

### 4｜HbCO₂ 与霍尔丹效应

```text
组织：HbO₂释放O₂
→ 去氧Hb增多
→ 更容易结合CO₂和H⁺
→ 有利于组织摄取CO₂

肺：Hb与O₂结合形成HbO₂
→ HbCO₂解离
→ CO₂更容易释放入肺泡
```

一句话：

> **Hb 在组织卸氧后更能装 CO₂；在肺装氧后把 CO₂“蹬开”。**

## KP07｜氧解离曲线：上段保装氧，下段保卸氧

> **讲义定位 →** 生理 Lecture PDF P190–191｜氧解离曲线  
> **Outline →** U016｜氧解离曲线 1–4  
> **主提示：** S形机制/T-R｜3段范围→装卸氧｜分压/饱和度锚｜P50定义/值/方向

### 1｜为什么是 S 形

Hb 有 4 个亚基，彼此有协同 / 变构效应：

```text
第一个 O₂ 与 Hb 结合
→ Hb 由 T 型逐渐转为 R 型
→ 其他亚基亲和力↑

第一个 O₂ 从 HbO₂ 解离
→ Hb 由 R 型逐渐转为 T 型
→ 其他亚基更容易释放 O₂
```

按 Study：

```text
T 型（tense）亲和力低
R 型（relax）亲和力高
```

### 2｜三段意义

| 曲线段 | PO₂ 范围 | 形态 | 生理意义 |
|---|---:|---|---|
| 上段 | 60–100 mmHg | 平坦 | 肺部装氧安全区；PaO₂≥60 时 SaO₂通常≥90% |
| 中段 | 40–60 mmHg | 较陡 | 安静组织卸氧 |
| 下段 | 15–40 mmHg | 最陡 | 运动 / 高代谢组织大量卸氧 |

口诀：**上坡缓，下坡陡。**

原题U016氧解离曲线3写“PaCO₂≥60mmHg”；本节曲线上段讨论的是PaO₂≥60mmHg。保留这一原题符号差异，不能据原题字面把高碳酸设为氧合目标。

### 3｜P50

```text
P50
= Hb 氧饱和度达到 50% 时的 PO₂
≈ 26.5 mmHg
```

```text
P50↑ → 曲线右移 → 亲和力↓ → 易卸氧
P50↓ → 曲线左移 → 亲和力↑ → 难卸氧
```

## KP08｜氧解离曲线移动：组织想用氧时往右，想抓紧氧时往左

> **讲义定位 →** 生理 Lecture PDF P191–192｜曲线影响因素  
> **Outline →** U016｜氧解离曲线 5–8  
> **主提示：** 移动因素4主轴＋CO｜P50/亲和/卸氧｜低温/补碱/库存血｜缺氧贫血高原

### 1｜右移

```text
温度↑
PCO₂↑
H⁺↑ / pH↓
2,3-DPG↑

→ 曲线右移
→ P50↑
→ Hb 对 O₂ 亲和力↓
→ 更易释放 O₂
→ 有利于代谢旺盛组织用氧
```

口诀：**增高右移。**

常见场景：运动、发热、酸性代谢环境、缺氧、贫血、高海拔适应。

### 2｜左移

```text
温度↓
PCO₂↓
pH↑
2,3-DPG↓
CO 中毒

→ 曲线左移
→ P50↓
→ Hb 对 O₂ 亲和力↑
→ 不易释放 O₂
```

### 3｜三个 Study 串联

- **低温麻醉**：降低组织耗氧；同时曲线偏左，Hb 更抓氧；
- **宁酸勿碱**：不恰当补碱可使曲线左移，加重组织卸氧困难；
- **长期库存血**：常规储存中红细胞代谢与2,3-DPG维持受损 → 2,3-DPG↓ → 曲线左移 → 氧不易释放。课程“糖酵解停止”过于绝对，储存细胞仍有代谢活动，变化也受保存液和储存条件影响。

（边界：这些是生理 Study 串联，不替代临床输血和酸碱治疗决策。）

## KP09｜波尔效应 vs 霍尔丹效应：肺和组织分别怎样互相促进 O₂ / CO₂ 交换

> **讲义定位 →** 生理 Lecture PDF P192–193｜两个效应与 V/Q 代偿  
> **Outline →** U016｜氧解离曲线 9–10  
> **主提示：** 效应2：输入→被调气体｜肺vs组织双向链

### 波尔效应

> **血液酸度改变 Hb 与 O₂ 的亲和力。**

**组织：**

```text
CO₂进入血液
→ H⁺↑、pH↓
→ 氧解离曲线右移
→ HbO₂更易解离
→ 向组织释放 O₂
```

**肺：**

```text
CO₂离开血液
→ H⁺↓、pH↑
→ 氧解离曲线左移
→ Hb 更易结合 O₂
```

### 霍尔丹效应

> **Hb 是否氧合，改变其运输 CO₂ 和 H⁺ 的能力。**

**组织：**

```text
HbO₂卸氧
→ 去氧Hb↑
→ 更易结合CO₂ / H⁺
→ CO₂运输↑
```

**肺：**

```text
Hb装氧形成HbO₂
→ 与CO₂ / H⁺亲和力下降
→ HbCO₂解离
→ CO₂释放↑
```

### 一句话分辨

```text
波尔：酸度 → O₂
霍尔丹：氧合 → CO₂
```

# Unit C｜低氧不一定来自肺：CO、贫血和细胞利用障碍

## KP10｜CO 中毒：PaO₂ 可以正常，但 Hb 不能有效装氧和卸氧

> **讲义定位 →** 生理 Lecture PDF P194｜CO 中毒  
> **Outline →** U016｜CO 中毒 1–7  
> **主提示：** CO机制｜曲线｜分压/含量｜识别/氧疗

### 1｜CO 怎样破坏 Hb 运输

按本节 Study：CO 与 Hb 亲和力约为 O₂ 的 250 倍。

```text
在肺
CO 霸占尚未结合 O₂ 的 Hb
→ HbO₂形成↓
→ 动脉血氧含量↓

在组织
CO 与一个亚基结合
→ 其他亚基对 O₂ 亲和力↑
→ 氧解离曲线左移
→ 已形成的 HbO₂ 不易释放 O₂
```

所以 CO **既妨碍结合，也妨碍解离**。

### 2｜对细胞呼吸链

按 Study：CO 可抑制复合体Ⅳ的还原型 Cyt a₃ → O₂ 环节，使呼吸链失效。

### 3｜关键血氧变量

```text
PaO₂：正常
因为肺通气和肺换气本身可正常，物理溶解氧仍形成正常分压

动脉血氧含量：下降
因为 HbO₂↓

静脉血PvO₂：课程在卸氧障碍模型下写下降
实际还受灌注、摄氧与细胞利用障碍影响，不能作所有CO中毒的固定方向
```

### 4｜颜色与呼吸刺激

- HbCO 呈樱桃红色；
- 缺氧但通常不发绀；
- 外周化学感受器读取 PaO₂，不读取氧含量，因此 PaO₂正常时不能有效通过缺氧刺激呼吸。

### 5｜治疗接口

按本节 Study：

```text
高压氧
→ 大幅提高物理溶解 O₂
→ 在 Hb 被 CO 占据时仍增加血中可用 O₂
```

讲义“吸氧加约5%CO₂刺激呼吸”保留为历史课程差异，不作为常规救治指令。CDC当前路径强调立即脱离暴露、给予100%氧并按神经/心脏表现、酸中毒及暴露条件评估高压氧；不能自行向氧气加入CO₂。普通脉氧仪可误导，需结合COHb共氧测定，不能用正常PaO₂或普通SpO₂排除。

## KP11｜发绀、严重贫血、CO 与氰化物：同是缺氧，血氧证据不同

> **讲义定位 →** 生理 Lecture PDF P195｜发绀与四类缺氧比较  
> **Outline →** U016｜发绀 1–3  
> **主提示：** 发绀定义/阈值｜氧供vs去氧Hb绝对量｜状态4类×血氧4轴｜高原/贫血反例

### 1｜发绀看什么

按本节 Study：

```text
去氧Hb ≥ 50 g/L（5 g/100 mL）
→ 皮肤黏膜呈紫蓝色
```

```text
缺不缺氧
→ 看氧合 Hb / 氧含量 / 组织氧供

发不发绀
→ 看去氧 Hb 的绝对量
```

### 2｜四类比较

| 状态 | PaO₂ | 动脉血氧含量 | 静脉血 PvO₂ | 皮肤黏膜 |
|---|---|---|---|---|
| 肺通气 / 换气障碍 | ↓ | ↓ | ↓ | 紫蓝，可发绀 |
| CO 中毒 | 通气/换气尚正常时可正常 | ↓ | 本节课程写↓；实际不固定，见KP10 | 课程樱桃红；临床可不典型，通常不发绀 |
| 严重贫血 | 正常 | ↓ | ↓ | 苍白，缺氧但不发绀 |
| 氰化物中毒 | 正常 | 按本节表：正常 | ↑ | 鲜红 |

### 3｜为什么氰化物 PvO₂↑

```text
细胞氧化磷酸化被抑制
→ 组织不能利用 O₂
→ 静脉血仍保留较多 O₂
→ PvO₂↑、静脉血偏鲜红
```

（易混：CO 既影响 Hb 运输又影响细胞利用；氰化物主要从“细胞不能利用氧”切入。）

### 4｜特殊

- 高原可因红细胞增多出现“高原红”；按本节曲线上段逻辑，只要 PaO₂仍≥60 mmHg，SaO₂可保持≥90%；
- 严重贫血虽缺氧，但总 Hb 太少，去氧 Hb 难达到发绀阈值。

## KP13｜外周 vs 中枢化学感受器：感受什么、通过什么路径、谁快谁强

> **讲义定位 →** 生理 Lecture PDF P201–202｜化学感受器比较  
> **Outline →** U017｜化学感受性反射 5–10、16  
> **主提示：** 外周 vs 中枢化学感受器｜刺激物｜传感路径｜血脑屏障/CA｜速度/强度｜CO/贫血例外

题纲 U017 第3题的PCO₂因素回看 **R1 KP04**：CO₂生成量一定时，有效肺泡通气量与肺泡PCO₂呈反向关系；同时不能忽略组织CO₂生成量的变化。低灌注时的循环参与条件回看 **A1/B2 KP03**。

### 1｜外周能直接感受什么

```text
动脉 PaO₂↓
动脉 H⁺↑
```

都可直接刺激颈动脉体 / 主动脉体。

### 2｜中枢能感受什么

中枢化学感受器：

```text
不能感受缺氧
不能直接感受动脉血H⁺
主要感受脑脊液H⁺↑
```

动脉血 H⁺极性强，不易通过血脑屏障；CO₂可通过血脑屏障：

```text
PaCO₂↑
→ CO₂进入脑脊液
→ 在CA参与下形成H⁺
→ 刺激中枢化学感受器
```

### 3｜CO₂ 如何刺激外周

按本节 Study，外周和中枢都没有独立 CO₂受体：

```text
CO₂进入外周感受细胞
→ 经CA转为H⁺
→ 感受细胞内H⁺↑
```

细胞内 CA 多、脑脊液 CA 少，所以外周反应快，中枢反应慢。

### 4｜四维比较

| 维度 | 外周化学感受器 | 中枢化学感受器 |
|---|---|---|
| 位置 | 颈动脉体、主动脉体 | 延髓腹外侧 |
| 速度 | 快 | 慢 |
| 强度 / 敏感性 | 较弱 | 强、敏感 |
| 适应 | 不易适应 | 易适应 |
| 能否感受 PaO₂↓ | 能 | 不能 |
| 主要 H⁺位置 | 感受细胞内 H⁺ | 脑脊液细胞外 H⁺ |

口诀角色：外周“豌豆射手”——快、弱、持续；中枢“火爆辣椒”——慢、强、敏感、易适应。

### 5｜CO 中毒和严重贫血为何不刺激呼吸

它们使氧含量下降，但肺通气 / 换气可正常，PaO₂正常；外周化学感受器读的是 **PaO₂**，不是氧含量，因此缺氧驱动不足。

## KP14｜间接兴奋 vs 直接抑制：O₂和CO₂都不能无限刺激呼吸

> **讲义定位 →** 生理 Lecture PDF P202–203｜直接与反射作用  
> **Outline →** U017｜化学感受性反射 10–14  
> **主提示：** O₂双作用｜CO₂两端｜中枢/反射｜适用条件

### 1｜两股相反作用

```text
PaO₂↓ / PaCO₂↑
→ 刺激化学感受器
→ 反射性兴奋呼吸中枢

但它们严重异常时
→ 对呼吸中枢直接抑制
```

### 2｜PaO₂ 阈值

按本节 Study：

```text
PaO₂ < 60 mmHg
→ 外周化学感受器显著兴奋
→ 呼吸加深加快

PaO₂ < 30 mmHg
→ 直接抑制作用超过反射兴奋
→ 呼吸抑制
```

### 3｜PaCO₂ 不能过低，也不能过高

```text
PaCO₂过低
如机械通气过度
→ 缺少维持呼吸中枢活动的CO₂ / H⁺刺激
→ 呼吸被抑制

PaCO₂过高
→ 直接中枢抑制超过反射兴奋
→ 呼吸被抑制
```

所以一定水平的 PaCO₂ 对维持正常呼吸活动是必需的。

课程由CO₂刺激呼吸引出“吸氧加约5%CO₂”，不能把这一生理效应变成通用氧疗操作。尤其存在高碳酸血症/通气失败时，不能据此继续加CO₂；氧疗与通气支持须按具体病情和血气滴定。

## KP15｜慢性 CO₂ 潴留、Ⅱ型呼衰与低浓度氧：为什么中枢会“适应”

> **讲义定位 →** 生理 Lecture PDF P203｜慢性适应与氧疗  
> **Outline →** U017｜化学感受性反射 15–19  
> **主提示：** 慢性适应｜氧致高碳酸3路｜滴定｜运动后

### 1｜中枢为什么易适应长期高 CO₂

```text
PaCO₂持续↑
→ 肾脏增加HCO₃⁻保留，调节血液pH
+
血液HCO₃⁻缓慢通过血脑屏障
→ 中和脑脊液H⁺
→ 脑脊液pH回升
→ 中枢化学感受器刺激减弱
```

所以：

```text
CO₂急性驱动强
CO₂慢性驱动弱
```

### 2｜慢性Ⅱ型呼衰的 Study 逻辑

```text
长期PaCO₂↑
→ 中枢对CO₂适应
→ PaO₂↓对外周化学感受器的刺激
成为维持呼吸的重要驱动
```

若吸入高浓度氧：

```text
PaO₂迅速上升
→ 解除外周低氧刺激
→ 通气进一步下降
→ CO₂潴留加重
→ 直接抑制呼吸中枢 / 肺性脑病接口
```

上述是课程“低氧驱动”链的一部分，不能作为COPD氧致高碳酸的唯一或总是主要机制。还包括：解除缺氧性肺血管收缩使V/Q匹配恶化；Hb氧合后携带CO₂能力下降的霍尔丹效应；部分患者通气下降。

课程25%–30%/约30%保留为低浓度氧记忆口径，实际FiO₂取决于设备与通气。对有高碳酸风险的COPD急性加重，按目标SpO₂（常用88%–92%）滴定并复查血气/评估通气支持；不能因怕CO₂潴留而延误严重低氧的纠正，也不能将这一目标套给所有Ⅱ型呼衰或CO中毒。完整路径归R3/R12。

### 3｜运动停止后为何仍通气增加

```text
运动中产生乳酸和氧债
→ 运动后仍需更多O₂
→ 清除乳酸、补充ATP和磷酸肌酸
→ 肺通气量不会立刻回到基线
```

## KP16｜脑桥、迷走与长吸式呼吸：谁负责及时“刹住吸气”

> **讲义定位 →** 生理 Lecture PDF P204｜长吸式呼吸  
> **Outline →** U017｜长吸式呼吸 1–4  
> **主提示：** 调节3部件｜脑桥损毁→型式｜双迷走切断→型式｜vsKussmaul

### 1｜三个部件

```text
脑桥下部：长吸中枢
→ 易化吸气，延长吸气

脑桥上部：呼吸调整中枢
→ 抑制脑桥下部
→ 帮助终止吸气

迷走神经传入
→ 抑制吸气
→ 参与及时中断吸气
```

### 2｜长吸式呼吸

```text
脑桥下部长吸中枢
失去脑桥上部和迷走传入的抑制
→ 吸气不能及时中断
→ 长吸式呼吸
```

### 3｜切断双侧迷走神经

按本节：

```text
呼吸幅度↑
呼吸频率↓
→ 深、慢呼吸
```

（易混：代谢性酸中毒的 Kussmaul 呼吸是深快；双侧迷走切断是深慢。）

## 7｜B2 → 后续呼吸疾病交接

B1 + B2 现在共同提供呼吸系统的正常语言：

```text
气道提供通路，呼吸肌 / 胸廓 / 胸膜腔共同完成肺泡通气
肺泡通气更新肺泡气，肺血流同时送来静脉血 → 同一交换单位
分压梯度与呼吸膜结构共同约束交换，VA/Q决定两侧是否匹配
O₂由肺入血 → Hb携带 → 组织释放 / 利用
组织CO₂经血液反向回肺 → 进入肺泡 → 随通气排出
外周 / 中枢感受输入 → 呼吸频率、深度与时程改变 → 回调肺泡通气 → 再改变血气
```

进入疾病分支前，只需做一次 P0 炎症 Recall：

```text
损伤 / 病原
→ 血管反应
→ 白细胞募集
→ 杀伤
→ 终止
→ 消退 / 机化 / 纤维化
```

然后进入下一批：

```text
Block 3 COPD
持续气流受限

Block 4 哮喘
可逆性 / 变异性气流受限
```

> **总交接句：以后每个呼吸疾病都先问——空气进不去、膜过不去、气血没配上、Hb带不了，还是控制器失效？**
