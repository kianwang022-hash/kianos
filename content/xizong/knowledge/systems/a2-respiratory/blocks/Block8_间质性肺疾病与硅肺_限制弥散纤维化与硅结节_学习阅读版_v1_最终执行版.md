## 0｜这个 Block 到底解决什么

这一组疾病共享的不是同一个病因，而是同一个**功能出口**：

```text
间质内胶原 / 细胞 / 异常物质增加
→ 肺组织变硬、顺应性下降
→ 吸气扩张困难、肺容积下降
→ 呼吸膜增厚或有效交换受阻
→ DLCO下降、低氧
→ 长期可使肺血管床减少 / PVR升高
→ 肺高压与右心负荷
```

但必须先分清三个空间：

```text
真正的肺间质纤维化
→ IPF、结节病晚期、硅肺等

肺泡腔被异常物质填充
→ 肺泡蛋白沉着症：主要低氧机制按Study归肺内分流

免疫 / 过敏性炎症形成斑片损伤
→ 过敏性肺炎、嗜酸性粒细胞肺炎
```

### 本 Block 的中心任务

> **看到进行性气短、干咳、Velcro 啰音、蜂窝影或职业粉尘史时，先判断病变在间质还是肺泡，再用“肺功能—HRCT分布—BALF细胞—肉芽肿 / 硅结节—治疗角色”完成定位。**

## 3｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. ILD 的主功能轴：**限制性通气障碍 + DLCO下降 + 低氧**；
2. IPF 的两个高识别体征：**Velcro 啰音、杵状指**；
3. IPF HRCT：**双肺外带、胸膜下、基底部，网格 / 蜂窝，可伴牵拉性支气管扩张**；
4. 限制性肺功能：RV、TLC、FVC↓；FEV1/FVC正常或↑；RV/TLC正常或略↑；
5. 当前 Study 的低氧主机制配对：COPD / 哮喘—肺泡通气↓；PE / 肺炎—VA/Q失调；ILD—弥散；肺泡蛋白沉着与 ARDS—肺内分流；
6. 牵拉性支气管扩张不等于支气管扩张症；后者还要求支气管壁破坏及纤维性增厚；
7. IPF：BALF中性粒 / 嗜酸粒↑；HRCT不清时外科肺活检；肺移植最有效；
8. 结节病：双肺门淋巴结肿大、BALF CD4 T↑、非干酪性肉芽肿；
9. 结节病分期 I–IV 的“肺门 → 肺内浸润 → 纤维化”方向；
10. 结节病 vs 结核：非干酪 / 干酪、双侧 / 多单侧肺门、PPD多阴 / 多阳；
11. 肺泡蛋白沉着：地图 / 铺路石 / 蝴蝶影，奶白稠厚分层 BALF、PAS+，全肺灌洗；
12. 过敏性肺炎：抗原暴露、马赛克磨玻璃、CD8 T↑，根本是避免接触；
13. 嗜酸性粒细胞肺炎：反肺水肿影、BALF嗜酸粒↑、糖皮质激素；
14. 硅肺脱离暴露后仍可进展：巨噬细胞吞噬—自溶—再释放 SiO2；
15. 硅肺基本病变 = 弥漫纤维化；特征病变 = 硅结节；
16. 硅结节：<5 μm进入肺泡，1–2 μm致病最强；先细胞性、后纤维性；最早肺门淋巴结；同心圆 / 漩涡胶原，可玻璃样变；
17. 硅肺最常见并发症是肺结核，也可肺部感染、慢性肺心病、阻塞性肺气肿。

### MI-D｜进入 MarginNote 3 卡片流

- IPF 三种抗纤维化 / 抗氧化药完整名单；
- IPF 急性加重中抗生素、激素、氧疗、机械通气的当前讲义表述；
- 结节病 6–24 个月疗程；
- 结节病四期精确影像组合；
- 各类 BALF 细胞名单；
- 肺泡蛋白沉着的 PAS、分层与形态称谓；
- 过敏性肺炎的鸽子肺 / 农民肺 / 空调肺；
- SiO2 粒径、硅肺分期、蛋壳样钙化、浮沉实验；
- 低频原图形态与药物细节。

## KP02｜限制性肺功能：核心不是“流速慢”，而是“容量小”

> **讲义定位 →** 内科 Lecture P22；回看 R1 阻塞 / 限制  
> **Outline →** 内科 U007｜概述3  
> **主提示：** 容量3↓｜比值1｜RV/TLC｜阻塞对照

### 1｜限制性通气障碍

```text
肺间质胶原增加 / 胸膜病变 / ARDS等
→ 肺或胸廓难以充分扩张
→ 肺容量下降
```

当前 Study 的指标方向：

| 指标 | 限制性方向 | 它回答什么 |
|---|---:|---|
| RV | ↓ | 呼气后残余容量 |
| TLC | ↓ | 总肺容量 |
| FVC | ↓ | 可用力呼出的总容量 |
| FEV1/FVC | 正常或↑ | 容量和流量可同比下降，比例不一定低 |
| RV/TLC | 正常或略↑ | 不出现阻塞性显著残气占比升高 |

### 2｜与阻塞性的最小边界

```text
阻塞性：气流速度下降为主
→ FEV1、FEV1/FVC、MMFR、PEF↓

限制性：肺容积下降为主
→ RV、TLC、FVC↓
```

（易混：不能因为 FEV1 也可能下降，就把限制性判成阻塞性；关键看 FEV1/FVC 与容量指标。）

## KP03｜低氧机制坐标：通气、VA/Q、弥散、分流不能混成一个词

> **讲义定位 →** 内科 Lecture P22；回看 R2  
> **Outline →** 内科 U007｜概述2  
> **主提示：** 5病→4机制｜ILD主轴｜蛋白沉着特殊｜CO₂边界

当前 Study 固定配对：

| 疾病 | 低氧最主要机制 |
|---|---|
| COPD、支气管哮喘 | 肺泡通气量下降 |
| 肺动脉栓塞、肺炎 | VA/Q 失调 |
| 一般 ILD | 弥散障碍，DLCO↓ |
| 肺泡蛋白沉着症 | 肺内分流 |
| ARDS | 肺内分流 |

```text
间质增厚 / 纤维化
→ 弥散距离↑
→ O₂跨膜受限
→ DLCO↓、PaO₂↓
```

当前 Study 强调：CO₂ 溶解度高、扩散快，**单纯弥散障碍通常只造成缺氧，不形成 CO₂ 潴留**。

（边界：这是一组考试主机制配对，不等于现实疾病永远只有单一机制。）

## KP06｜牵拉性支扩：支气管被拉大，不等于支扩症成立

> **讲义定位 →** 内科 Lecture P22；回看 R6  
> **Outline →** Lecture-only boundary  
> **主提示：** 上游1｜牵拉链｜缺少2｜R6诊断门槛

```text
肺间质胶原纤维增多并收缩
→ 牵拉邻近支气管
→ 影像出现牵拉性支气管扩张
```

但 R6 的支气管扩张症要求：

- 支气管管壁支撑结构破坏；
- 破坏后的肉芽组织 / 纤维修复，使管壁纤维性增厚；
- 临床形成长期脓痰、固定湿啰音、咯血等独立疾病模型。

> **影像上“管腔扩张”只是现象；病因、管壁身份和临床模型决定疾病名称。**

## KP09｜结节病 vs 肺结核：都可上叶和肉芽肿，但坏死与肺门方向不同

> **讲义定位 →** 内科 Lecture P24；回看 R7  
> **Outline →** 内科 U008｜结节病4  
> **主提示：** 共性5｜肉芽肿｜肺门双/单｜PPD｜细胞｜空洞边界

### 1｜共同点

- CD4 T 细胞相关；
- 肉芽肿；
- 可累及上叶；
- 可见肺门淋巴结肿大和蜂窝肺；
- 可有发热、消瘦、盗汗、结节性红斑、关节炎；
- 当前 Study 的治疗时间均可达到至少 6 个月量级。

### 2｜核心比较

| 轴 | 结节病 | 肺结核 |
|---|---|---|
| 肉芽肿 | 非干酪性 | 干酪性 |
| 肺门淋巴结 | 多双侧 | 多单侧 |
| PPD | 多阴性 | 多阳性 |
| BALF / 免疫 | CD4 T↑ | 细胞免疫已在 R7建立 |
| 空洞 | 当前模型不以空洞为主 | 继发结核常有空洞 |

> 先用坏死类型和肺门方向分流，再结合 PPD、影像与组织学；不要仅凭“上叶 + 盗汗”直接定结核。

# Unit D｜三个特殊病：肺泡内容物、抗原暴露与嗜酸性炎症

## KP10｜肺泡蛋白沉着：有血流，但肺泡被物质填住

> **讲义定位 →** 内科 Lecture P24  
> **Outline →** 内科 U008｜其他1；U007｜概述2特殊  
> **主提示：** 低氧机制｜CT 3形｜BALF4｜PAS｜治疗1

### 1｜功能身份

当前 Study 把其低氧最主要机制归为**肺内分流**：

```text
肺泡内大量表面活性物质样成分沉积
→ 肺泡无法正常交换气体
→ 静脉血流经后未充分氧合
→ 功能性动静脉短路
```

- BALF：奶白色、稠厚、可分层；
- PAS 阳性。

### 3｜治疗

- **全肺灌洗**。

（易混：结节病的铺路石是支气管镜黏膜；本病的铺路石是 CT 磨玻璃形态。）

# Unit E｜硅肺：粉尘离开了，巨噬细胞循环仍可继续

## KP13｜硅肺为何脱离暴露后仍进展：巨噬细胞不是终点

> **讲义定位 →** 病理 Lecture PDF P70  
> **Outline →** 病理 U002｜硅肺1  
> **主提示：** 暴露后？｜细胞1｜吞噬链4｜为何循环

```text
SiO₂进入肺泡
→ 巨噬细胞吞噬
→ SiO₂与水形成硅酸
→ 巨噬细胞崩解、自溶
→ SiO₂再次释放
→ 被新的巨噬细胞重新吞噬
→ 反复损伤与纤维化继续
```

因此：

> **停止接触可以阻止新的粉尘输入，但不能立即终止肺内已有颗粒—巨噬细胞循环。**

（边界：当前病理 Study 只建立病理机制，不扩写完整职业病筛查与管理。）

## KP14｜硅结节：粒径、形成顺序、位置与同心圆胶原

> **讲义定位 →** 病理 Lecture PDF P70  
> **Outline →** 病理 U002｜硅肺2–7  
> **主提示：** 基本/特征｜粒径2｜细胞｜结节2步｜最早部位｜胶原形｜玻璃样/Ig｜空洞

### 1｜两层病理身份

- 基本病变：**肺组织弥漫纤维化**；
- 特征病变：**硅结节**。

### 2｜颗粒与形成

- 小于 5 μm 的 SiO₂ 可进入肺泡；
- 1–2 μm 致病性最强；
- 被巨噬细胞吞噬；
- 先形成细胞性结节，后形成纤维性结节。

### 3｜空间和形态

- 最早出现：肺门淋巴结；
- 胶原纤维：同心圆 / 漩涡状排列；
- 可发生玻璃样变；
- 玻璃样变硅结节可含较多免疫球蛋白，当前 Study 据此提示免疫因素参与；
- 多个结节融合后，中央可坏死并形成空洞。

（易混：硅结节的玻璃样变是蛋白质沉积语言；不要与纤维素、纤维素样坏死混同。）

## KP15｜硅肺分期：先肺门，再双肺结节和胸膜，最后融合成块

> **讲义定位 →** 病理 Lecture PDF P71

> **主提示：** I肺门｜II双肺+胸膜+蛋壳｜III融合+广泛胸膜｜浮沉

| 分期 | 当前 Study 主体 |
|---|---|
| I | 主要累及肺门淋巴结，肺门淋巴结肿大 |
| II | 双肺散布结节；胸膜增厚；肺门淋巴结蛋壳样钙化 |

III 期还可出现：

- 肺重量和硬度明显增加；
- 新鲜肺标本可竖立；
- 入水下沉，当前 Study 称“浮沉实验”阳性。

## KP16｜硅肺结局：TB最常见，纤维化还能推高肺循环阻力

> **讲义定位 →** 病理 Lecture PDF P71；回看 R7、预览 R9  
> **Outline →** 病理 U002｜硅肺9  
> **主提示：** 并发4｜最常见1｜纤维化→PVR链｜气道结果

并发症：

1. 肺结核——最常见；
2. 肺部感染；
3. 慢性肺源性心脏病；
4. 阻塞性肺气肿。

```text
弥漫肺纤维化
→ 肺组织变硬、肺血管床受压 / 减少
→ 肺循环阻力↑
→ 肺动脉高压
→ 右心后负荷↑
→ 慢性肺心病
```

同时，纤维化影响小气道，可与阻塞性肺气肿并存。
