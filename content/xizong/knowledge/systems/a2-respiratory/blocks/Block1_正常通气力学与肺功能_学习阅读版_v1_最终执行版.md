## 0｜这个 Block 到底解决什么

肺不是主动开合的气泵。真正的过程是：

```text
呼吸肌改变胸廓
→ 胸膜腔把胸廓与肺耦联
→ 肺容积改变
→ 肺内压相对大气压改变
→ 空气进出肺泡
```

与此同时，空气进出是否顺利还取决于两类负担：

```text
弹性阻力
肺和胸廓是否容易被拉开

非弹性阻力
气体流动时是否被气道“卡住”
```

最终用肺功能把它们“看见”：

```text
容积 / 容量
→ 一次能装多少

FVC / FEV1 / FEV1/FVC
→ 能否快速呼出

VE / VA / VD
→ 每分钟真正到达肺泡多少

RV / FRC / TLC
→ 是否残气、过度充气或容积受限
```

### MI-G｜会阻断后续疾病推导，第一轮必须即时掌握

1. 肺通气、肺换气、气体运输三者的边界；
2. 呼吸肌 → 胸廓 → 胸膜腔 → 肺内压 → 气流的完整链；

10. 阻塞性看“流速”，限制性看“容积”；
11. 静态顺应性与弹性阻力相关，动态顺应性还受气道阻力影响；
12. COPD 的“动低静高”只作为当前力学验证，完整疾病后置。

## KP01｜肺容积与肺容量：一次呼吸中“装了多少、还能装多少、剩下多少”

> **讲义定位 →** 生理 Lecture PDF P169｜通气功能的评价  
> **Outline →** U014｜肺容积和肺容量  
> **主提示：** 8个肺容积/容量｜各定义｜可由哪些量相加｜各代表什么

### 1｜一张容量拼图

| 指标 | 当前 Study 定义 | 核心意义 |
|---|---|---|
| 潮气量 VT / TV | 每次平静吸入或呼出的气体量，约 500 mL | 一次普通呼吸量 |
| 补吸气量 IRV | 平静吸气末再用力吸入的量 | 吸气储备 |
| 补呼气量 ERV | 平静呼气末再用力呼出的量 | 呼气储备 |
| 深吸气量 IC | 平静呼气末用力吸到最大所吸入的量 | `IC = VT + IRV` |
| 余气量 RV | 最大呼气末仍留在肺内、不能呼出的量 | 避免肺泡完全萎陷；反映残气 |
| 功能余气量 FRC | 平静呼气末留在肺内的量 | `FRC = ERV + RV`；约 2500 mL；缓冲肺泡气分压变化 |
| 肺活量 VC | 用力吸气后再用力呼气所能呼出的最大量 | `VC = VT + IRV + ERV`；一次通气最大能力 |
| 肺总量 TLC | 肺能容纳的最大气体量 | `TLC = VC + RV` |

### 2｜为什么 FRC 是“气体缓冲池”

```text
每次真正进入肺泡的新鲜气体
≈ VT - 解剖无效腔
≈ 500 - 150 = 350 mL

平静呼气末肺内已有 FRC ≈ 2500 mL

每次只更新约 350 / 2500 ≈ 1/7
→ 肺泡气分压不会随每一次呼吸剧烈波动
```

//串联：这和大动脉弹性储器缓冲血压变化的角色相似。

### 3｜最容易混淆的两个“呼气末”

- **RV**：最大呼气末；已经尽力呼气后仍剩下；
- **FRC**：平静呼气末；还包括可以继续用力呼出的 ERV。

（易混：RV 不是“平静呼气后剩余”，FRC 才是。）

## KP02｜VC、FVC、FEV：能装多少，不等于能多快呼出来

> **讲义定位 →** 生理 Lecture PDF P170｜用力肺活量  
> **Outline →** U014｜用力肺活量  
> **主提示：** VC vs FVC；FEV1–3；一秒率测什么；FEV1/FVC 与 FEV1%pred 分别做什么。

### 1｜VC 与 FVC

```text
VC
用力吸气后再用力呼气
→ 强调最大“量”

FVC
用力吸气后，再用力并尽快呼气
→ 强调最大“量” + 尽快呼出
```

用力呼气时，小气道可能提前关闭，所以当前 Study 口径中：

```text
VC > FVC
```

### 2｜时间肺活量 FEV

从开始用力呼气起，前 1、2、3 秒内呼出的量分别为：

```text
FEV1
FEV2
FEV3
```

当前 Study 数值记忆：

```text
FEV1 / FVC ≈ 83%
FEV2 / FVC ≈ 96%
FEV3 / FVC ≈ 99%
```

### 3｜两个指标的职责不能混

```text
FEV1 / FVC
→ 一秒率
→ 主要回答：气流速度是否受限？
→ 常用于阻塞 vs 限制的定性识别

FEV1%pred
→ FEV1 占预计值百分比
→ 主要回答：阻塞严重到什么程度？
```

//串联：内科 COPD 以吸入支气管扩张剂后 `FEV1/FVC < 70%` 作为持续气流受限的重要诊断标准；这是后续 COPD Block 的正式 Primary，本处只建立指标身份。

## KP03｜阻塞性 vs 限制性：牙膏“孔小”还是整支“变小”

> **讲义定位 →** 生理 Lecture PDF P170–173｜阻塞性与限制性通气障碍  
> **Outline →** U014｜阻塞与限制对比  
> **主提示：** 机制、呼吸困难类型、主要检测轴、FEV1/FVC、FVC、RV/FRC/TLC、典型疾病。

| 共同轴 | 阻塞性通气障碍 | 限制性通气障碍 |
|---|---|---|
| 感性模型 | 牙膏孔小了 | 整支牙膏小了 / 肺穿紧身衣 |
| 主要负担 | 气道阻塞，非弹性阻力↑ | 弹性阻力↑或胸膜空间限制，肺扩张受限 |
| 主要困难 | 呼气性呼吸困难 | 吸气性呼吸困难 |
| 主要问题 | 流速↓为主 | 容积↓为主 |
| FEV1/FVC | ↓ | 按本节生理口径：基本不变 |
| FEV1 | ↓ | ↓ |
| FVC | 正常或↓；下降程度通常小于 FEV1 | ↓ |
| RV、FRC | ↑ | ↓ |
| TLC | 可↑ | ↓ |
| 典型例子 | COPD / 肺气肿、支气管哮喘 | 肺纤维化、胸膜病变 |

### 推导，而不是只背表

**阻塞：**

```text
气道口径↓
→ 呼气时口径本来就更小
→ 气流速度明显下降
→ FEV1 下降更重
→ FEV1/FVC↓
→ 气体呼不出去
→ RV、FRC↑
```

**限制：**

```text
肺 / 胸廓难以扩张
→ 能吸入和容纳的总体积下降
→ FEV1、FVC、TLC、RV、FRC均下降
→ 比值指标按本节口径基本不变
```

（边界：这是生理学的比较口径。具体疾病诊断必须回到病理和内科，不把一张肺功能表机械等同于疾病。）

## KP04｜VE、VA 与无效腔：每分钟呼了多少，不等于真正交换了多少

> **讲义定位 →** 生理 Lecture PDF P170–172｜肺通气量与肺泡通气量  
> **Outline →** U014｜肺通气量和肺泡通气量  
> **主提示：** VE、VA 公式；解剖 / 肺泡 / 生理无效腔；浅快 vs 深慢；VT↑时各指标方向。

### 1｜两个公式

```text
每分通气量 VE = VT × f

肺泡通气量 VA =（VT - VD）× f
```

- **VE**：每分钟吸入或呼出的总气体量；
- **VA**：每分钟真正到达肺泡、参与气体交换的量；更能代表有效通气。

### 2｜无效腔三层

```text
解剖无效腔
鼻、口至终末细支气管等传导区
→ 有气流，无肺泡开口

肺泡无效腔
气体到了肺泡，但该肺泡没有有效血流
→ 例如肺栓塞

生理无效腔
= 解剖无效腔 + 肺泡无效腔
```

正常时肺泡无效腔很小，计算常按解剖无效腔约 150 mL。

### 3｜为什么深慢优于浅快

在每分通气量相近时，每一口气都先填满固定无效腔：

```text
浅快呼吸
每口 VT 小
→ 无效腔占比大
→ VA↓

深慢呼吸
每口 VT 大
→ 无效腔占比小
→ VA↑
→ 但呼吸做功增加
```

### 4｜VT 增加时的方向

按本节 Study：

```text
VT↑
→ VE↑
→ VA↑
→ IRV↓、ERV↓
→ FRC↓
→ 肺泡 PaCO₂↓
```

//串联：过度通气 → PaCO₂↓ → 呼吸性碱中毒 → 离子化 Ca²⁺↓ → 兴奋性↑ → 手足抽搐。完整酸碱算法后置泌尿系统。

## KP06｜肺通气的原动力与直接动力：谁先动，谁真正推气体

> **讲义定位 →** 生理 Lecture PDF P174｜肺通气动力与呼吸肌  
> **Outline →** U015｜肺通气动力 1–3  
> **主提示：** 原动力、直接动力；主要 / 辅助吸气肌、呼气肌；平静和用力呼吸各肌群状态。

### 1｜动力分层

```text
原动力
呼吸肌收缩 / 舒张
→ 胸廓节律性扩大 / 缩小
→ 呼吸运动

直接动力
大气压 - 肺内压
→ 压力差直接推动空气流动
```

### 2｜呼吸肌

| 情境 | 主要吸气肌：膈肌、肋间外肌 | 辅助吸气肌：胸锁乳突肌、斜角肌 | 呼气肌：腹肌、肋间内肌 |
|---|---|---|---|
| 平静吸气 | 收缩 | 通常不参与 | 舒张 |
| 平静呼气 | 舒张 | 舒张 | 舒张 |
| 用力吸气 | 收缩 | 收缩 | 舒张 |
| 用力呼气 | 舒张 | 舒张 | 收缩 |

口诀：主要吸气肌“**格外**”——膈肌 + 肋间外肌。

### 3｜“主动 / 被动”说的是什么

- 平静吸气需要吸气肌收缩，是主动过程；
- 平静呼气主要依赖吸气肌舒张和弹性回缩，是被动过程；
- 用力呼气需要呼气肌收缩，转为主动过程。

（易混：这里的主动 / 被动描述是否需要肌肉收缩，不是膜转运中的主动 / 被动；骨骼肌收缩和舒张本身都需要能量。）

## KP07｜一次平静呼吸的压力电影

> **讲义定位 →** 生理 Lecture PDF P175–176｜肺内压变化  
> **Outline →** U015｜动力 4–5  
> **主提示：** 平静呼吸4时点｜胸廓/肺容积｜肺内压｜气流方向

### 平静吸气

```text
膈肌 / 肋间外肌收缩
→ 胸廓扩大
→ 肺扩张
→ 肺内压先下降
→ 肺内压 < 大气压
→ 气体流入
→ 随气体进入，肺内压逐渐回升
→ 吸气末：肺内压 = 大气压，气流停止
```

### 平静呼气

```text
吸气肌舒张
→ 胸廓回缩
→ 肺回缩
→ 肺内压先升高
→ 肺内压 > 大气压
→ 气体流出
→ 随气体排出，肺内压逐渐下降
→ 呼气末：肺内压 = 大气压，气流停止
```

### 关键图形任务

闭卷画出：

```text
肺内压：吸气先↓后回到0；呼气先↑后回到0
胸膜腔内压：全程为负，吸气时更负
气流：由压力差决定
```

（易混：吸气末和呼气末没有气流，不是因为呼吸肌都不活动，而是肺内压与大气压暂时相等。）

## KP08｜胸廓为什么能带动肺：胸膜腔负压的形成与公式

> **讲义定位 →** 生理 Lecture PDF P175–176｜胸膜腔、胸腔负压  
> **Outline →** U015｜动力 5–9  
> **主提示：** 胸廓—肺耦联；形成条件；肺内压与肺回缩力；公式；吸气时为何更负。

### 1｜胸廓与肺的耦联

```text
胸廓自然容积 > 肺自然容积
+
胸膜腔密闭、脏壁胸膜紧贴
+
胸膜腔少量浆液产生润滑和吸附

→ 胸廓向外拉
→ 肺向内回缩
→ 两层胸膜趋于分离却不能真正分开
→ 胸膜腔压力低于大气压
```

### 2｜形成条件

1. **胸膜腔密闭——最重要**；
2. 少量浆液使两层胸膜润滑并紧贴；
3. 肺和胸廓均有弹性，且平静状态下方向相反。

（易混：是胸膜腔密闭有助于形成负压，不是“负压维持胸膜腔密闭”。）

### 3｜两个相反的力与公式

```text
肺内压
→ 从肺泡内向外“顶”
→ 使肺泡扩张

肺弹性回缩力
→ 向内“拉”
→ 使肺泡缩小
```

```text
胸膜腔内压
= 肺内压 +（-肺弹性回缩压）
```

吸气末、呼气末肺内压等于大气压；若大气压记作 0：

```text
胸膜腔内压 = -肺弹性回缩压
```

### 4｜吸气时为什么更负

```text
吸气
→ 肺进一步扩张
→ 肺弹性回缩压↑
→ 胸膜腔负压负值↑
→ 更负
```

## KP09｜胸腔负压“又吸气又吸血”：意义、气胸与 Valsalva

> **讲义定位 →** 生理 Lecture PDF P176–177、P181｜胸腔负压意义、气胸、Valsalva  
> **Outline →** U015｜动力 10–11；专题总结 1  
> **主提示：** 胸腔负压四大意义；吸气与回心；气胸链；三凹征；Valsalva 只保留机制接口。

### 1｜四大意义

```text
① 耦联肺与胸廓
② 把呼吸运动的原动力转化为肺内压差
③ 保持肺扩张，降低吸气阻力，防止肺不张
④ 保持腔静脉和胸导管扩张，促进静脉血和淋巴回流
```

一句话：

> **胸腔负压又吸气，又吸血。**

### 2｜吸气为什么增加回心

```text
吸气
→ 胸膜腔内压更负
→ 胸腔大静脉和右心房扩张
→ CVP 下降
→ 外周静脉到右心的压力梯度↑
→ 静脉回心↑
```

### 3｜气胸

```text
胸膜腔积气
→ 胸膜腔密闭被破坏
→ 胸腔负压减小或消失
→ 肺回缩 / 肺不张
→ 吸气阻力↑
→ 限制性通气障碍

同时
→ 胸腔内静脉、淋巴回流受阻
→ 可见颈静脉怒张
```

（特殊：按本节 Study，气胸不会使呼气阻力增加；胸腔负压主要降低吸气阻力。）

### 4｜三凹征

```text
大气道狭窄或严重哮喘
→ 用力吸气
→ 胸膜腔负压显著更负
→ 胸骨上窝、锁骨上窝、肋间隙被吸入
→ 三凹征
```

### 5｜//串联：Valsalva

```text
深吸气后紧闭声门用力呼气
→ 胸内压可转为正压
→ 回心↓、SV↓、血压↓
→ 窦弓反射交感↑

突然放开声门
→ 回心↑、SV↑、血压↑
→ 反射性迷走↑
```

完整临床应用不在本 Block 展开。

# Unit C｜肺为什么会“难拉开”或“难把气呼出去”

## KP10｜肺通气阻力总图与胸廓双弹性

> **讲义定位 →** 生理 Lecture PDF P177｜肺通气阻力概述  
> **Outline →** U015｜阻力 1–3；专题总结 2  
> **主提示：** 弹性 vs 非弹性；各自构成；胸廓在 TLC 67% 上下时阻力方向；肺弹性阻力恒定角色。

### 1｜阻力总图

```text
肺通气阻力
├─ 弹性阻力：静态阻力，约70%
│  ├─ 肺弹性阻力
│  │  ├─ 肺组织弹性成分
│  │  └─ 肺泡表面张力（约占肺弹性阻力2/3）
│  └─ 胸廓弹性阻力
└─ 非弹性阻力：动态阻力
   ├─ 气道阻力（主要）
   ├─ 惯性阻力
   └─ 黏滞阻力
```

### 2｜胸廓的“双弹性”

| 肺容量位置 | 胸廓状态 | 胸廓弹性阻力方向 | 对吸 / 呼气的作用 |
|---|---|---|---|
| `= TLC 67%`，平静吸气末 | 胸廓处自然位置 | 不明显表现 | — |
| `> TLC 67%`，深吸气 | 胸廓被向外撑大，想回缩 | 向内 | 吸气阻力、呼气动力 |
| `< TLC 67%`，呼气 | 胸廓被向内压小，想恢复 | 向外 | 吸气动力、呼气阻力 |

### 3｜肺的弹性阻力没有“双向”

肺被胸腔负压持续拉开，因此始终想回缩：

```text
肺弹性阻力始终向内
→ 始终是吸气的阻力
→ 始终是呼气的动力
```

（易混：胸廓弹性阻力可向内或向外；肺弹性阻力始终向内。）

## KP11｜肺弹性阻力：肺变硬和肺失去回缩力是两种相反故障

> **讲义定位 →** 生理 Lecture PDF P178｜肺弹性阻力  
> **Outline →** U015｜阻力 3–5  
> **主提示：** 肺弹性阻力的两个来源；肺纤维化 / 表活减少 / 肺气肿的方向；为何肺气肿“更容易扩张”却更难呼气。

### 1｜两个来源

```text
肺组织本身弹性成分的回缩力
+
肺泡液-气界面的表面张力
=
肺弹性阻力
```

### 2｜三类方向

```text
肺纤维化
→ 胶原纤维增多
→ 肺弹性阻力↑
→ 肺难扩张
→ 吸气困难

肺泡表面活性物质↓
→ 表面张力↑
→ 肺弹性阻力↑
→ 吸气困难、肺泡易萎陷

肺气肿 / COPD 接口
→ 弹性蛋白酶破坏弹性成分
→ 肺弹性阻力↓
→ 静态顺应性↑
→ 但呼气动力↓
→ 气体更难排出
```

### 3｜核心反直觉

> **顺应性高不等于呼吸功能好。**

肺气肿的肺“容易被拉开”，但像失去弹性的旧气球，不能靠回缩把气挤出去；再叠加小气道阻塞，形成呼气性困难。

## KP12｜肺泡表面活性物质与 Laplace：让大小肺泡都稳定

> **讲义定位 →** 生理 Lecture PDF P178–179｜表面活性物质  
> **Outline →** U015｜阻力 6–10  
> **主提示：** 表面活性物质：来源/成分/成熟｜作用轴｜不能做什么｜Laplace下缺失后果

### 1｜身份

- 位于肺泡内侧液-气界面；
- 由肺泡 **Ⅱ型上皮细胞**合成和分泌；
- 主要脂质为二棕榈酰（软脂酰）磷脂酰胆碱 / 卵磷脂 DPPC；
- 当前 Study：胎儿约 6 个月左右才开始分泌，糖皮质激素可促进成熟。

### 2｜它怎样工作

DPPC 是双嗜性分子，排列在液-气界面，抵消表面张力。

```text
表面活性物质↑
→ 表面张力↓
→ 肺弹性阻力↓
→ 静态顺应性↑
→ 吸气更省力
```

### 3｜五类意义

1. 降低吸气阻力，减少吸气做功；
2. 增大静态肺顺应性；
3. 防止肺泡萎陷 / 肺不张；
4. 减少液体向肺泡内“抽吸”，防止肺水肿；
5. 稳定不同大小肺泡的压力和容积。

### 4｜它不能做什么

```text
不能降低呼气阻力
不能防止肺气肿
```

因为肺泡表面张力本来就是呼气动力的一部分，表活的主要价值是降低吸气负担和稳定肺泡。

### 5｜Laplace 定律

无表面活性物质时：

```text
P = 2T / r

小肺泡半径更小
→ 内压更高
→ 气体从小肺泡流向大肺泡
→ 小肺泡越来越小、最终萎陷
→ 大肺泡越来越大、过度膨胀
```

表面活性物质在小肺泡中密度更高、降低表面张力更多，因此维持大小肺泡稳定。

//串联：早产儿表面活性物质不足可出现新生儿呼吸窘迫综合征；可用糖皮质激素促进成熟，并补充表活。完整新生儿临床不展开。

## KP13｜气道阻力：口径是主轴，吸气时会被肺组织“拉开”

> **讲义定位 →** 生理 Lecture PDF P179–180｜非弹性阻力与气道阻力  
> **Outline →** U015｜阻力 11–16  
> **主提示：** 气道阻力：定义｜各部贡献｜流型/流速/口径｜跨壁压/肺牵引｜自主神经/介质｜吸呼差

### 1｜身份

气道阻力来自：

```text
气体分子之间摩擦
+
气体与气道壁之间摩擦
```

只有气体流动时才出现，所以属于动态 / 非弹性阻力；同时是吸气和呼气的阻力。

### 2｜气道阻力分布

按本节 Study：

```text
鼻部约50%
> 声门约25%
> 气管
> 支气管
> 直径 <2 mm 的细支气管整体约10%
```

单根细支气管很细，但全部细支气管总横截面积很大，所以整体阻力不一定最大。

### 3｜三大影响轴

#### 气流形式

```text
层流 → 阻力较小
湍流 → 阻力↑
```

黏液、渗出、肿瘤、异物造成狭窄时更易湍流。

#### 气流速度

```text
流速↑
→ 单位时间通过的气体更多
→ 摩擦↑
→ 气道阻力↑
```

#### 气道口径——最主要

```text
口径↓ → 阻力↑
```

口径受四类因素调节：

1. **跨壁压**：气道内压↑ → 跨壁压↑ → 气道被动扩大；
2. **肺组织牵引**：吸气时肺扩张 → 对无软骨小气道牵引↑ → 口径↑；
3. **自主神经**：按本节 Study，交感 / 儿茶酚胺经 β₂ 使气道舒张；副交感 ACh 经 M 受体使气道收缩；
4. **化学介质**。

### 4｜化学介质方向

| 舒张气道 | 收缩气道 |
|---|---|
| 儿茶酚胺（β₂） | ACh |
| VIP | P 物质等速激肽 |
| PGI₂、PGE₂ | PGF₂α |
| NO、CO₂ | 组胺、白三烯、TXA₂、ET |
| 糖皮质激素（通过抗炎等） | — |

### 5｜为什么“越吸越容易、越呼越困难”

```text
吸气
→ 跨壁压↑
→ 肺扩张，对小气道牵引↑
→ 气道口径↑
→ 气道阻力↓

呼气
→ 肺容积下降
→ 小气道牵引↓
→ 气道口径变小
→ 气道阻力↑
```

所有人都有这一方向；哮喘等小气道痉挛时，呼气困难被显著放大。

## KP14｜肺顺应性：容易变形，不等于能有效呼吸

> **讲义定位 →** 生理 Lecture PDF P181–182｜阻力与顺应性  
> **Outline →** U015｜专题总结 2–4  
> **主提示：** C 公式；比顺应性；几组大小比较；盐水肺 vs 肺水肿；静态 vs 动态；COPD“动低静高”。

### 1｜定义

```text
肺顺应性 C = 肺容积变化 ΔV / 跨肺压变化 ΔP

跨肺压 = 肺内压 - 胸膜腔内压
```

```text
阻力↑ → 顺应性↓
阻力↓ → 顺应性↑
```

### 2｜比较不同肺总量的人

肺总量大者，同样吸入一部分气体时相对扩张程度较小，可表现出更大绝对顺应性。因此比较不同体型 / 肺总量时，用：

```text
比顺应性 = 顺应性 / 肺容量
```

### 3｜当前 Study 的几组结论

- 平静呼吸时肺顺应性更大；
- 肺本身顺应性 > 肺 + 胸廓总顺应性；
- 肺充满生理盐水时，液-气界面消失 → 表面张力消失 → 顺应性↑；
- 肺水肿患者肺组织变重、间质 / 肺泡异常 → 顺应性↓。

（易混：盐水灌注实验“无液-气界面”与肺水肿不是一回事。）

### 4｜静态 vs 动态

```text
静态顺应性
气流被阻断、憋气时测
→ 只反映弹性阻力

动态顺应性
正常有气流时测
→ 同时受弹性阻力 + 非弹性阻力影响
```

### 5｜COPD：动低静高

```text
先：小气道不完全阻塞
→ 气道阻力↑
→ 动态顺应性↓

后：弹性蛋白被破坏
→ 肺弹性阻力↓
→ 静态顺应性↑
```

这条链是后续 COPD Block 的重要输入。

## KP15｜整合方向矩阵：吸气时每个变量怎样变

| 变量 | 吸气时 |
|---|---|

### 2｜胸腔负压 vs 表面活性物质

| 防肺气肿 | 否 | 否 |
