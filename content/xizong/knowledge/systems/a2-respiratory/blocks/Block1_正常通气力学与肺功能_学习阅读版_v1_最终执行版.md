## 0｜这个 Block 到底解决什么

肺不是主动开合的气泵。真正的过程是：

```text
呼吸肌改变胸廓
→ 胸膜腔把胸廓与肺耦联
→ 肺容积改变
→ 肺内压相对大气压改变
→ 空气进出肺泡
```

与此同时，空气进出是否顺利还取决于两类负担：

```text
弹性阻力
肺和胸廓是否容易被拉开

非弹性阻力
气体流动时是否被气道“卡住”
```

最终用肺功能把它们“看见”：

```text
容积 / 容量
→ 一次能装多少

FVC / FEV1 / FEV1/FVC
→ 能否快速呼出

VE / VA / VD
→ 每分钟真正到达肺泡多少

RV / FRC / TLC
→ 是否残气、过度充气或容积受限
```

```text

→ 肺扩张 / 回缩
→ 肺内压改变

        ↓

C｜再拆解通气负担

弹性阻力（静态，约70%）
├─ 肺弹性阻力
│  ├─ 肺组织弹性成分
│  └─ 肺泡表面张力
└─ 胸廓弹性阻力

非弹性阻力（动态）
├─ 气道阻力
├─ 惯性阻力
└─ 黏滞阻力

D｜最后把病变放回坐标

流速问题为主
→ 阻塞性通气障碍

容积问题为主
→ 限制性通气障碍
```

### 四个组织公式

```text
每分通气量 VE = VT × f

肺泡通气量 VA =（VT - VD）× f

胸膜腔内压 = 肺内压 +（-肺弹性回缩压）

肺顺应性 C = ΔV / ΔP
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

以下直接使用本 Block 原有的通气机械、负荷和肺功能关系：主路是呼吸肌→胸膜耦联→肺泡压差→气流；弹性/流阻同时约束它，肺功能是这些过程的测量读数，不是驱动气流的上游阶段。原有“先认测量语言”的学习入口可以保留为阅读准备，但不能画成医学因果箭头。〈知识标题〔完整正式 Prompt〕〉只贴在对应机制或测量位置；全部隐藏后，连续模型与限定仍须独立成立。

```text
A2 呼吸系统：外界空气 → 传导气道 → 肺泡 → 呼吸膜 → 血液 → 组织
└─ R1 的范围：只解决空气怎样真正进出肺泡；换气/运输接 R2
   肺通气（外界 ↔ 肺泡）≠ 肺换气（肺泡 ↔ 血液）≠ 血液运输
   〈肺通气、肺换气、气体运输：先把三个过程分开〔外呼吸/通气/换气/运输/内呼吸｜过程-位置对应〕〉

① 通气机械电影｜原动力改变空间，直接动力是压力差
│
├─ 平静吸气：吸气肌收缩（原动力）
│  膈肌、肋间外肌 → 胸廓容积↑
│  〈肺通气的原动力与直接动力：谁先动，谁真正推气体〔动力2层｜肌群3组各2｜平静/用力×吸/呼｜主动vs被动〕〉
│              ↓
│  密闭胸膜腔将胸廓运动传给肺；肺向内回缩、胸廓有向外弹性趋势
│  胸膜腔内压更负 → 跨肺压↑ → 肺扩张、肺容积↑
│  （胸膜压 = 肺泡压 − 肺弹性回缩压；“更负”不是肺泡压始终负）
│  〈胸廓为什么能带动肺：胸膜腔负压的形成与公式〔耦联链｜条件3｜压力2向｜胸膜压公式｜吸呼末简化｜吸气胸膜压链〕〉
│  │
│  └─ 同一胸膜/胸内压的并行作用，不是气流的新站点：
│     自主吸气时胸内压下降可促进静脉回心；气胸破坏耦联，
│     张力性气胸还可能压迫回心；Valsalva 按用力四时相另判。
│     〈胸腔负压“又吸气又吸血”：意义、气胸与 Valsalva〔负压4作用｜回心条件｜气胸｜三凹征｜Valsalva〕〉
│              ↓
│  肺泡内压暂低于大气压（直接动力）→ 空气经传导气道流入肺泡
│  气体进入 → 肺泡内压回到大气压 → 吸气末气流暂止
│
└─ 平静呼气：吸气肌舒张，肺/胸廓弹性回缩 → 肺容积↓
   肺泡内压暂高于大气压 → 空气流出 → 呼气末压差消失、气流暂止
   用力呼气时另有呼气肌主动收缩；“末端无气流”不等于所有肌肉不活动。
   〈一次平静呼吸的压力电影〔平静呼吸4时点｜胸廓/肺容积｜肺内压｜气流方向〕〉

② 同一口气的两类负荷｜决定能不能拉开、能不能顺利流动
│
├─ 肺/胸廓扩张要克服弹性负荷；回缩又帮助平静呼气
│  肺组织弹性 + 肺泡表面张力 + 胸廓在不同肺容量的回缩方向
│  （胸廓可向内/向外；肺组织弹性回缩始终向内）
│  〈肺通气阻力总图与胸廓双弹性〔阻力2类｜胸廓平衡位/上下｜肺回缩方向〕〉
│  │
│  ├─ 肺太硬/表面张力↑ → 吸气扩张困难；
│  │  弹性组织破坏 → 回缩动力不足 → 呼气排空不利。
│  │  〈肺弹性阻力：肺变硬和肺失去回缩力是两种相反故障〔回缩来源2｜故障3类方向｜扩张/排空比较〕〉
│  │
│  ├─ Ⅱ型肺泡上皮细胞分泌表活 → 表面张力↓
│  │  → 吸气弹性负担↓、肺泡稳定性↑；
│  │  Laplace 的小/大肺泡问题要带相同张力的模型前提。
│  │  （降低表面张力 ≠ 直接扩张气道，也不等于防肺气肿。）
│  │  〈肺泡表面活性物质与 Laplace：让大小肺泡都稳定〔表活：来源/成分/成熟｜作用轴/边界｜Laplace条件下缺失后果〕〉
│  │
│  └─ 顺应性 C = ΔV / Δ跨肺压：反映“有多容易拉开”
│     静态着重弹性；动态测量还受流阻、区域不均及频率影响；
│     合并肺气肿时可静态高、动态低，不是所有 COPD 必然如此。
│     〈肺顺应性：容易变形，不等于能有效呼吸〔C/比顺应性｜静态/动态｜盐水/水肿｜COPD条件〕〉
│
└─ 空气流动要克服动态/非弹性负荷
   气道口径、流型/流量决定流动压降；口径减小 → 气道阻力↑。
   吸气时肺组织牵引小气道使口径倾向↑；呼气时牵引减弱，
   尤其存在小气道阻塞时，呼气流速更易受限。
   〈气道阻力：口径是主轴，吸气时会被肺组织“拉开”〔气道阻力：定义｜各部贡献｜流型/流速/口径｜跨壁压/肺牵引｜自主神经/介质｜吸呼差〕〉

③ 同一机制的测量读数｜不是产生气流的上游因果步骤
│
├─ 肺能装多少：VT / IRV / ERV / RV → IC / FRC / VC / TLC
│  平静呼气末 FRC ≠ 最大呼气末 RV；肺容量是不同容积的组合。
│  〈肺容积与肺容量：一次呼吸中“装了多少、还能装多少、剩下多少”〔肺容积/容量8项｜定义｜加和关系｜生理含义〕〉
│
├─ 用力呼气能排多少、排得多快：VC / FVC / FEV₁ / FEV₁/FVC
│  FVC 与缓慢 VC 在动态气道关闭时可能不同；
│  一秒率评估气流受限，FEV₁预计值百分比是不同读数。
│  〈VC、FVC、FEV：能装多少，不等于能多快呼出来〔VC/FVC条件｜FEV1–3｜一秒率/预计值〕〉
│
├─ 一分钟实际到达肺泡的有效通气量
│  VE = VT × f；VA =（VT − VD）× f（公式适用的无效腔口径需明确）；
│  浅快与深慢要在每分通气量及无效腔条件相当时比较。
│  〈VE、VA 与无效腔：每分钟呼了多少，不等于真正交换了多少〔通气2公式｜无效腔3类｜深慢/浅快｜VT条件〕〉
│
└─ 由负荷到测量的两种典型障碍方向：
   气道口径↓/呼气流量受限 → FEV₁/FVC 常↓（阻塞轴）；

   单独 FVC↓不能确诊限制；阻塞也可伴气体潴留。
   〈阻塞性 vs 限制性：牙膏“孔小”还是整支“变小”〔阻塞/限制｜流速/容量｜比值｜表型条件〕〉

④ 回到同一口气做变量核验，不开第二套记忆模型
   吸气/呼气各读：肌肉与胸廓 → 胸膜/跨肺压 → 肺容积
   → 肺泡与大气压差 → 气流；再分别检验弹性、流阻和测量变化。

```

## 2｜Memory Routing

### MI-G｜会阻断后续疾病推导，第一轮必须即时掌握

1. 肺通气、肺换气、气体运输三者的边界；
2. 呼吸肌 → 胸廓 → 胸膜腔 → 肺内压 → 气流的完整链；
3. 平静吸气主动、平静呼气被动；用力呼气变为主动；
4. 胸膜腔密闭是形成胸腔负压的最重要条件；
5. 胸腔负压“又吸气又吸血”的意义；
6. 肺弹性阻力始终是吸气阻力、呼气动力；
7. 表面活性物质降低表面张力与吸气弹性负担、稳定肺泡；不能把它当作直接气道扩张剂或防肺气肿药；
8. 气道阻力同时是吸气和呼气阻力，口径是最主要影响因素；
9. FEV1/FVC、FVC、TLC、RV/TLC 分别在测什么；
10. 阻塞性看“流速”，限制性看“容积”；
11. 静态顺应性与弹性阻力相关，动态顺应性还受气道阻力影响；
12. COPD“动低静高”是气流不均与肺气肿弹性破坏叠加的课程模型，须带表型与测量条件，完整疾病后置。

### 1｜一张容量拼图

| 指标 | 当前 Study 定义 | 核心意义 |
|---|---|---|
| 潮气量 VT / TV | 每次平静吸入或呼出的气体量，约 500 mL | 一次普通呼吸量 |
| 补吸气量 IRV | 平静吸气末再用力吸入的量 | 吸气储备 |
| 补呼气量 ERV | 平静呼气末再用力呼出的量 | 呼气储备 |
| 深吸气量 IC | 平静呼气末用力吸到最大所吸入的量 | `IC = VT + IRV` |
| 余气量 RV | 最大呼气末仍留在肺内、不能呼出的量 | 避免肺泡完全萎陷；反映残气 |
| 功能余气量 FRC | 平静呼气末留在肺内的量 | `FRC = ERV + RV`；约 2500 mL；缓冲肺泡气分压变化 |
| 肺活量 VC | 用力吸气后再用力呼气所能呼出的最大量 | `VC = VT + IRV + ERV`；一次通气最大能力 |
| 肺总量 TLC | 肺能容纳的最大气体量 | `TLC = VC + RV` |

### 2｜为什么 FRC 是“气体缓冲池”

```text
每次真正进入肺泡的新鲜气体
≈ VT - 解剖无效腔
≈ 500 - 150 = 350 mL

平静呼气末肺内已有 FRC ≈ 2500 mL

每次只更新约 350 / 2500 ≈ 1/7
→ 肺泡气分压不会随每一次呼吸剧烈波动
```

//串联：这和大动脉弹性储器缓冲血压变化的角色相似。

### 3｜最容易混淆的两个“呼气末”

- **RV**：最大呼气末；已经尽力呼气后仍剩下；
- **FRC**：平静呼气末；还包括可以继续用力呼出的 ERV。

（易混：RV 不是“平静呼气后剩余”，FRC 才是。）

## KP02｜VC、FVC、FEV：能装多少，不等于能多快呼出来

> **讲义定位 →** 生理 Lecture PDF P170｜用力肺活量  
> **Outline →** U014｜用力肺活量  
> **主提示：** VC/FVC条件｜FEV1–3｜一秒率/预计值

### 1｜VC 与 FVC

```text
VC
用力吸气后再用力呼气
→ 强调最大“量”

FVC
用力吸气后，再用力并尽快呼气
→ 强调最大“量” + 尽快呼出
```

VC强调最大可动用气量；缓慢肺活量（SVC）与用力肺活量（FVC）是不同动作下的测量。用力呼气时小气道提前关闭可使FVC小于SVC，阻塞性疾病更明显；正常或无明显动态压缩时二者可接近。课程“VC>FVC”不能当作每个人、每次测量都成立的严格不等式。

### 2｜时间肺活量 FEV

从开始用力呼气起，前 1、2、3 秒内呼出的量分别为：

```text
FEV1
FEV2
FEV3
```

当前 Study 数值记忆：

```text
FEV1 / FVC ≈ 83%
FEV2 / FVC ≈ 96%
FEV3 / FVC ≈ 99%
```

### 3｜两个指标的职责不能混

```text
FEV1 / FVC
→ 一秒率
→ 主要回答：气流速度是否受限？
→ 常用于阻塞 vs 限制的定性识别

FEV1%pred
→ FEV1 占预计值百分比
→ 主要回答：阻塞严重到什么程度？
```

//串联：内科 COPD 以吸入支气管扩张剂后 `FEV1/FVC < 70%` 作为持续气流受限的重要诊断标准；这是后续 COPD Block 的正式 Primary，本处只建立指标身份。

## KP03｜阻塞性 vs 限制性：牙膏“孔小”还是整支“变小”

> **讲义定位 →** 生理 Lecture PDF P170–173｜阻塞性与限制性通气障碍  
> **Outline →** U014｜阻塞与限制对比  
> **主提示：** 阻塞/限制｜流速/容量｜比值｜表型条件

| 共同轴 | 阻塞性通气障碍 | 限制性通气障碍 |
|---|---|---|
| 感性模型 | 牙膏孔小了 | 整支牙膏小了 / 肺穿紧身衣 |
| 主要负担 | 气道阻塞，非弹性阻力↑ | 弹性阻力↑或胸膜空间限制，肺扩张受限 |
| 主要困难 | 呼气性呼吸困难 | 吸气性呼吸困难 |
| 主要问题 | 流速↓为主 | 容积↓为主 |
| FEV1/FVC | 常↓ | 常正常或↑；课程简化为基本不变 |
| FEV1 | ↓ | ↓ |
| FVC | 正常或↓；下降程度通常小于 FEV1 | ↓ |
| RV、FRC | 气体潴留/过度充气时常↑，并非所有病例均↑ | 单纯限制可↓；复杂限制/呼气肌无力等可有RV相对保留或↑ |
| TLC | 可↑ | ↓ |
| 典型例子 | COPD / 肺气肿、支气管哮喘 | 肺纤维化、胸膜病变 |

### 推导，而不是只背表

**阻塞：**

```text
气道口径↓
→ 呼气时口径本来就更小
→ 气流速度明显下降
→ FEV1 下降更重
→ FEV1/FVC↓
→ 气体呼不出去
→ RV、FRC↑
```

**限制：**

```text
肺 / 胸廓难以扩张
→ 能吸入和容纳的总体积下降
→ TLC低于正常下限是确认限制的关键
→ FVC/FEV1可随容量下降
→ 单纯限制时各容量近似同比下降；复杂限制可有RV/TLC升高
```

（边界：课程“非比值均降、比值不变”是典型单纯限制模型；低FVC本身不能确诊限制，TLC正常时还要考虑气体潴留、用力不足等，不能只看比值或呼吸困难类型。）

## KP04｜VE、VA 与无效腔：每分钟呼了多少，不等于真正交换了多少

> **讲义定位 →** 生理 Lecture PDF P170–172｜肺通气量与肺泡通气量  
> **Outline →** U014｜肺通气量和肺泡通气量  
> **主提示：** 通气2公式｜无效腔3类｜深慢/浅快｜VT条件

### 1｜两个公式

```text
每分通气量 VE = VT × f

肺泡通气量 VA =（VT - VD）× f
```

- **VE**：每分钟吸入或呼出的总气体量；
- **VA**：每分钟真正到达肺泡、参与气体交换的量；更能代表有效通气。

### 2｜无效腔三层

```text
解剖无效腔
鼻、口至终末细支气管等传导区
→ 有气流，无肺泡开口

肺泡无效腔
气体到了肺泡，但该肺泡没有有效血流
→ 例如肺栓塞

生理无效腔
= 解剖无效腔 + 肺泡无效腔
```

正常时肺泡无效腔很小，计算常按解剖无效腔约 150 mL。

### 3｜为什么深慢优于浅快

在每分通气量相近时，每一口气都先填满固定无效腔：

```text
浅快呼吸
每口 VT 小
→ 无效腔占比大
→ VA↓

深慢呼吸
每口 VT 大
→ 无效腔占比小
→ VA↑
→ 但呼吸做功增加
```

### 4｜VT 增加时的方向

必须固定其他变量后再推方向：

```text
f与VD不变，VT↑ → VE↑、VA↑
CO₂生成量不变，VA↑ → 肺泡PACO₂及通常PaCO₂↓
```

只抬高吸气末、呼气末不变时，VT↑可使IRV↓，但ERV/FRC不必下降；只有呼气末水平也下移时，ERV/FRC才会随之变小。固定每分通气量时深慢与浅快的比较，也要保留VD近似不变的前提。

//串联：过度通气 → PaCO₂↓ → 呼吸性碱中毒 → 离子化 Ca²⁺↓ → 兴奋性↑ → 手足抽搐。完整酸碱算法后置泌尿系统。

## KP06｜肺通气的原动力与直接动力：谁先动，谁真正推气体

> **讲义定位 →** 生理 Lecture PDF P174｜肺通气动力与呼吸肌  
> **Outline →** U015｜肺通气动力 1–3  
> **主提示：** 动力2层｜肌群3组各2｜平静/用力×吸/呼｜主动vs被动

### 1｜动力分层

```text
原动力
呼吸肌收缩 / 舒张
→ 胸廓节律性扩大 / 缩小
→ 呼吸运动

直接动力
大气压 - 肺内压
→ 压力差直接推动空气流动
```

### 2｜呼吸肌

| 情境 | 主要吸气肌：膈肌、肋间外肌 | 辅助吸气肌：胸锁乳突肌、斜角肌 | 呼气肌：腹肌、肋间内肌 |
|---|---|---|---|
| 平静吸气 | 收缩 | 通常不参与 | 舒张 |
| 平静呼气 | 舒张 | 舒张 | 舒张 |
| 用力吸气 | 收缩 | 收缩 | 舒张 |
| 用力呼气 | 舒张 | 舒张 | 收缩 |

口诀：主要吸气肌“**格外**”——膈肌 + 肋间外肌。

### 3｜“主动 / 被动”说的是什么

- 平静吸气需要吸气肌收缩，是主动过程；
- 平静呼气主要依赖吸气肌舒张和弹性回缩，是被动过程；
- 用力呼气需要呼气肌收缩，转为主动过程。

（易混：这里的主动 / 被动描述是否需要肌肉收缩，不是膜转运中的主动 / 被动；骨骼肌收缩和舒张本身都需要能量。）

## KP07｜一次平静呼吸的压力电影

> **讲义定位 →** 生理 Lecture PDF P175–176｜肺内压变化  
> **Outline →** U015｜动力 4–5  
> **主提示：** 平静呼吸4时点｜胸廓/肺容积｜肺内压｜气流方向

### 平静吸气

```text
膈肌 / 肋间外肌收缩
→ 胸廓扩大
→ 肺扩张
→ 肺内压先下降
→ 肺内压 < 大气压
→ 气体流入
→ 随气体进入，肺内压逐渐回升
→ 吸气末：肺内压 = 大气压，气流停止
```

### 平静呼气

```text
吸气肌舒张
→ 胸廓回缩
→ 肺回缩
→ 肺内压先升高
→ 肺内压 > 大气压
→ 气体流出
→ 随气体排出，肺内压逐渐下降
→ 呼气末：肺内压 = 大气压，气流停止
```

### 关键图形任务

闭卷画出：

```text
肺内压：吸气先↓后回到0；呼气先↑后回到0
胸膜腔内压：全程为负，吸气时更负
气流：由压力差决定
```

（易混：吸气末和呼气末没有气流，不是因为呼吸肌都不活动，而是肺内压与大气压暂时相等。）

## KP08｜胸廓为什么能带动肺：胸膜腔负压的形成与公式

> **讲义定位 →** 生理 Lecture PDF P175–176｜胸膜腔、胸腔负压  
> **Outline →** U015｜动力 5–9  
> **主提示：** 耦联链｜条件3｜压力2向｜胸膜压公式｜吸呼末简化｜吸气胸膜压链

### 1｜胸廓与肺的耦联

```text
胸廓自然容积 > 肺自然容积
+
胸膜腔密闭、脏壁胸膜紧贴
+
胸膜腔少量浆液产生润滑和吸附

→ 胸廓向外拉
→ 肺向内回缩
→ 两层胸膜趋于分离却不能真正分开
→ 胸膜腔压力低于大气压
```

### 2｜形成条件

1. **胸膜腔密闭——最重要**；
2. 少量浆液使两层胸膜润滑并紧贴；
3. 肺和胸廓均有弹性，且平静状态下方向相反。

（易混：是胸膜腔密闭有助于形成负压，不是“负压维持胸膜腔密闭”。）

### 3｜两个相反的力与公式

```text
肺内压
→ 从肺泡内向外“顶”
→ 使肺泡扩张

肺弹性回缩力
→ 向内“拉”
→ 使肺泡缩小
```

```text
胸膜腔内压
= 肺内压 +（-肺弹性回缩压）
```

吸气末、呼气末肺内压等于大气压；若大气压记作 0：

```text
胸膜腔内压 = -肺弹性回缩压
```

### 4｜吸气时为什么更负

```text
吸气
→ 肺进一步扩张
→ 肺弹性回缩压↑
→ 胸膜腔负压负值↑
→ 更负
```

## KP09｜胸腔负压“又吸气又吸血”：意义、气胸与 Valsalva

> **讲义定位 →** 生理 Lecture PDF P176–177、P181｜胸腔负压意义、气胸、Valsalva  
> **Outline →** U015｜动力 10–11；专题总结 1  
> **主提示：** 负压4作用｜回心条件｜气胸｜三凹征｜Valsalva

### 1｜四大意义

```text
① 耦联肺与胸廓
② 把呼吸运动的原动力转化为肺内压差
③ 保持肺扩张，降低吸气阻力，防止肺不张
④ 保持腔静脉和胸导管扩张，促进静脉血和淋巴回流
```

一句话：

> **胸腔负压又吸气，又吸血。**

### 2｜吸气为什么增加回心

```text
吸气
→ 胸膜腔内压更负
→ 胸腔大静脉和右心房扩张
→ CVP 下降
→ 外周静脉到右心的压力梯度↑
→ 静脉回心↑
```

### 3｜气胸

```text
胸膜腔积气
→ 胸膜两层与肺—胸廓机械耦联受破坏
→ 跨肺压下降，胸膜负压可减小或消失
→ 肺回缩 / 肺不张
→ 吸气阻力↑
→ 限制性通气障碍

若发展为张力性气胸，胸膜内压明显升高
→ 回心受阻、循环受损
→ 可有颈静脉怒张（低容量时也可不明显）
```

（特殊：小量/闭合性气胸不必已有明显回心障碍或颈静脉怒张。课程“不会增加呼气阻力”是在强调肺扩张与弹性负担，不能外推为任何气胸都绝无气道口径/流阻变化。）

### 4｜三凹征

```text
大气道狭窄或严重哮喘
→ 用力吸气
→ 胸膜腔负压显著更负
→ 胸骨上窝、锁骨上窝、肋间隙被吸入
→ 三凹征
```

### 5｜//串联：Valsalva

```text
Ⅰ 用力开始：胸内压传递可使动脉压短暂↑
Ⅱ 持续用力：回心↓、SV↓，随后反射性交感代偿
Ⅲ 放松瞬间：胸内压下降，可先出现短暂血压下降
Ⅳ 回心恢复后：SV与仍较高的血管张力共同形成血压超射，反射性心率减慢
```

完整临床应用不在本 Block 展开。

# Unit C｜肺为什么会“难拉开”或“难把气呼出去”

## KP10｜肺通气阻力总图与胸廓双弹性

> **讲义定位 →** 生理 Lecture PDF P177｜肺通气阻力概述  
> **Outline →** U015｜阻力 1–3；专题总结 2  
> **主提示：** 阻力2类｜胸廓平衡位/上下｜肺回缩方向

### 1｜阻力总图

```text
肺通气阻力
├─ 弹性阻力：静态阻力，约70%
│  ├─ 肺弹性阻力
│  │  ├─ 肺组织弹性成分
│  │  └─ 肺泡表面张力（约占肺弹性阻力2/3）
│  └─ 胸廓弹性阻力
└─ 非弹性阻力：动态阻力
   ├─ 气道阻力（主要）
   ├─ 惯性阻力
   └─ 黏滞阻力
```

### 2｜胸廓的“双弹性”

| 肺容量位置 | 胸廓状态 | 胸廓弹性阻力方向 | 对吸 / 呼气的作用 |
|---|---|---|---|
| `≈ TLC 67%`，胸廓自身松弛位置 | 胸廓处自然位置 | 不明显表现 | — |
| `> TLC 67%`，较高肺容量 | 胸廓被向外撑大，想回缩 | 向内 | 吸气阻力、呼气动力 |
| `< TLC 67%`，较低肺容量 | 胸廓被向内压小，想恢复 | 向外 | 吸气动力、呼气阻力 |

胸廓自身零回缩位与肺+胸廓系统在FRC处的平衡位不同；课程把67%TLC直接标为“平静吸气末”过于固定，平静吸气末实际为FRC+VT，不能无条件等于该比例。

### 3｜肺的弹性阻力没有“双向”

肺被胸腔负压持续拉开，因此始终想回缩：

```text
肺弹性阻力始终向内
→ 始终是吸气的阻力
→ 始终是呼气的动力
```

（易混：胸廓弹性阻力可向内或向外；肺弹性阻力始终向内。）

## KP11｜肺弹性阻力：肺变硬和肺失去回缩力是两种相反故障

> **讲义定位 →** 生理 Lecture PDF P178｜肺弹性阻力  
> **Outline →** U015｜阻力 3–5  
> **主提示：** 回缩来源2｜故障3类方向｜扩张/排空比较

### 1｜两个来源

```text
肺组织本身弹性成分的回缩力
+
肺泡液-气界面的表面张力
=
肺弹性阻力
```

### 2｜三类方向

```text
肺纤维化
→ 胶原纤维增多
→ 肺弹性阻力↑
→ 肺难扩张
→ 吸气困难

肺泡表面活性物质↓
→ 表面张力↑
→ 肺弹性阻力↑

→ 但呼气动力↓
```

## KP12｜肺泡表面活性物质与 Laplace：让大小肺泡都稳定

> **讲义定位 →** 生理 Lecture PDF P178–179｜表面活性物质  
> **Outline →** U015｜阻力 6–10  
> **主提示：** 表活：来源/成分/成熟｜作用轴/边界｜Laplace条件下缺失后果

### 1｜身份

- 位于肺泡内侧液-气界面；
- 由肺泡 **Ⅱ型上皮细胞**合成和分泌；
- 主要脂质为二棕榈酰（软脂酰）磷脂酰胆碱 / 卵磷脂 DPPC；
- 当前 Study：胎儿约 6 个月左右才开始分泌，糖皮质激素可促进成熟。

### 2｜它怎样工作

DPPC 是双嗜性分子，排列在液-气界面，抵消表面张力。

```text
表面活性物质↑
→ 表面张力↓
→ 肺弹性阻力↓
→ 静态顺应性↑
→ 吸气更省力
```

### 3｜五类意义

1. 降低吸气阻力，减少吸气做功；
2. 增大静态肺顺应性；
3. 防止肺泡萎陷 / 肺不张；
4. 减少液体向肺泡内“抽吸”，防止肺水肿；
5. 稳定不同大小肺泡的压力和容积。

### 4｜它不能做什么

```text
不是直接降低气道平滑肌张力的支气管扩张剂
不能据此防止肺气肿的弹性组织破坏
```

肺泡表面张力是弹性回缩的一部分，降低它可减轻吸气弹性负担；但“降低弹性回缩”与“气道流阻如何变化”不是同一问题。肺泡稳定与维持肺容积可间接影响小气道，故课程“不能降低呼气阻力”须限于这组弹性模型对照，不宜说成所有条件下总呼气负担绝不改变。

### 5｜Laplace 定律

无表面活性物质时：

```text
P = 2T / r

小肺泡半径更小
→ 内压更高
→ 气体从小肺泡流向大肺泡
→ 小肺泡越来越小、最终萎陷
→ 大肺泡越来越大、过度膨胀
```

表面活性物质在小肺泡中密度更高、降低表面张力更多，因此维持大小肺泡稳定。

//串联：早产儿表面活性物质不足可出现新生儿呼吸窘迫综合征；可用糖皮质激素促进成熟，并补充表活。完整新生儿临床不展开。

## KP13｜气道阻力：口径是主轴，吸气时会被肺组织“拉开”

> **讲义定位 →** 生理 Lecture PDF P179–180｜非弹性阻力与气道阻力  
> **Outline →** U015｜阻力 11–16  
> **主提示：** 气道阻力：定义｜各部贡献｜流型/流速/口径｜跨壁压/肺牵引｜自主神经/介质｜吸呼差

### 1｜身份

气道阻力来自：

```text
气体分子之间摩擦
+
气体与气道壁之间摩擦
```

只有气体流动时才出现，所以属于动态 / 非弹性阻力；同时是吸气和呼气的阻力。

### 2｜气道阻力分布

按本节 Study：

```text
鼻部约50%
> 声门约25%
> 气管
> 支气管
> 直径 <2 mm 的细支气管整体约10%
```

单根细支气管很细，但全部细支气管总横截面积很大，所以整体阻力不一定最大。

### 3｜三大影响轴

#### 气流形式

```text
层流 → 阻力较小
湍流 → 阻力↑
```

黏液、渗出、肿瘤、异物造成狭窄时更易湍流。

#### 气流速度

```text
层流、管径与黏度固定：ΔP随流量↑，R=ΔP/流量可近似不变
湍流成分增加：ΔP增加更快，计算的流阻可随流量↑
```

#### 气道口径——最主要

```text
口径↓ → 阻力↑
```

口径受四类因素调节：

1. **跨壁压**：气道内压↑ → 跨壁压↑ → 气道被动扩大；
2. **肺组织牵引**：吸气时肺扩张 → 对无软骨小气道牵引↑ → 口径↑；
3. **自主神经**：按本节 Study，交感 / 儿茶酚胺经 β₂ 使气道舒张；副交感 ACh 经 M 受体使气道收缩；
4. **化学介质**。

### 4｜化学介质方向

| 舒张气道 | 收缩气道 |
|---|---|
| 儿茶酚胺（β₂） | ACh |
| VIP | P 物质等速激肽 |
| PGI₂、PGE₂ | PGF₂α |
| NO、CO₂ | 组胺、白三烯、TXA₂、ET |
| 糖皮质激素（通过抗炎等） | — |

### 5｜为什么“越吸越容易、越呼越困难”

```text
吸气
→ 跨壁压↑
→ 肺扩张，对小气道牵引↑
→ 气道口径↑
→ 气道阻力↓

呼气
→ 肺容积下降
→ 小气道牵引↓
→ 气道口径变小
→ 气道阻力↑
```

所有人都有这一方向；哮喘等小气道痉挛时，呼气困难被显著放大。

## KP14｜肺顺应性：容易变形，不等于能有效呼吸

> **讲义定位 →** 生理 Lecture PDF P181–182｜阻力与顺应性  
> **Outline →** U015｜专题总结 2–4  
> **主提示：** C/比顺应性｜静态/动态｜盐水/水肿｜COPD条件

### 1｜定义

```text
肺顺应性 C = 肺容积变化 ΔV / 跨肺压变化 ΔP

跨肺压 = 肺内压 - 胸膜腔内压
```

```text
弹性系数E=ΔP/ΔV，顺应性C=1/E
气道流阻R=ΔP/流量，不能直接当作1/C
```

### 2｜比较不同肺总量的人

肺总量大者，同样吸入一部分气体时相对扩张程度较小，可表现出更大绝对顺应性。因此比较不同体型 / 肺总量时，用：

```text
比顺应性 = 顺应性 / 肺容量
```

### 3｜当前 Study 的几组结论

- 平静呼吸时肺顺应性更大；
- 肺本身顺应性 > 肺 + 胸廓总顺应性；
- 肺充满生理盐水时，液-气界面消失 → 表面张力消失 → 顺应性↑；
- 肺水肿患者肺组织变重、间质 / 肺泡异常 → 顺应性↓。

（易混：盐水灌注实验“无液-气界面”与肺水肿不是一回事。）

### 4｜静态 vs 动态

```text
静态顺应性
气流被阻断、憋气时测
→ 只反映弹性阻力

动态顺应性
正常有气流时测
→ 同时受弹性阻力 + 非弹性阻力影响
```

### 5｜COPD：动低静高

```text
气道阻力/区域时间常数不均、呼吸频率变化
→ 动态测得顺应性可下降

合并肺气肿的弹性组织破坏
→ 弹性回缩减弱，静态顺应性可升高
```

“动低静高”是组合表型的力学示例，不是所有COPD的必然方向，也不代表人人固定先小气道、后弹性破坏的时间顺序。动态顺应性随测法和频率变化，峰压法还包含阻力压；不能把它与静态顺应性只作一个固定差值。

## KP15｜整合方向矩阵：吸气时每个变量怎样变

> **讲义回看 →** P174–182｜整个通气力学  
> **Outline →** U015｜专题总结 1–6  
> **主提示：** 吸气变量｜负压/表活｜弹性/流阻｜哮喘3类

### 1｜吸气方向

| 变量 | 吸气时 |
|---|---|
| 胸廓容积 | ↑ |
| 肺容积 | ↑ |
| 肺内压 | 先↓，随气体进入回升至大气压 |
| 胸膜腔内压 | 负值↑，更负 |
| 肺弹性回缩压 | ↑ |
| 表面活性物质密度 | ↓ |
| 肺泡表面张力 | ↑ |
| 肺组织对小气道牵引 | ↑ |
| 气道口径 | ↑ |
| 气道阻力 | ↓ |
| 静脉回心 | ↑ |

### 2｜胸腔负压 vs 表面活性物质

| 共同点 / 区别 | 胸腔负压 | 表面活性物质 |
|---|---|---|
| 降低吸气阻力 | 是：保持肺扩张、对抗弹性回缩 | 是：降低表面张力 |
| 呼气阶段如何解释 | 维持跨肺压/肺容积；不可将弹性作用等同全部流阻 | 降低表面张力而非直接舒张气道；回缩动力与气道流阻分开 |
| 防肺不张 | 是 | 是 |
| 防肺水肿 | 不是核心角色 | 是 |
| 促静脉 / 淋巴回流 | 是 | 否 |
| 稳定大小肺泡 | 否 | 是 |
| 防肺气肿 | 否 | 否 |

### 3｜//串联：哮喘治疗三类接口

当前只用于验证“怎样让气道口径变大 / 炎症减轻”：

```text
抗炎 / 抗过敏
→ 吸入糖皮质激素、白三烯受体拮抗剂

模拟交感 / 儿茶酚胺
→ β₂受体激动剂

拮抗副交感
→ 抗胆碱药
```

完整药物阶梯和急性重症处理后置哮喘 Block。
