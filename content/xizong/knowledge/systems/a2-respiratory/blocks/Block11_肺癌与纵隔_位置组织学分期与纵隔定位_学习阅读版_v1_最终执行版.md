## 0｜这个 Block 到底解决什么

肺癌的位置、组织学与扩展范围回答不同问题；同一肿瘤可同时造成多种局部和全身后果。

```text
肺内肿瘤
├─ 位置：中央 / 周围 / 弥漫，描述长在哪里
├─ 组织：腺 / 鳞 / 神经内分泌 / 其他，描述细胞与形态
└─ 生长与行为
   ├─ 堵塞气道 → 局限性哮鸣和不同条件下的三阻征
   ├─ 侵犯邻近结构 → 相应神经、回流或胸膜 / 心包表现
   ├─ 淋巴 / 血道播散 → 区域结或远处病灶
   └─ 异常分泌等远程作用 → 副癌表现，不能当作该处已有转移

影像读取位置与范围，取材明确组织，分期描述T / N / M，分子检测识别治疗指标
组织学 + 完整范围 + 可切除性 / 耐受 + 分子条件 → 治疗选择
```

肺外胸内肿块从纵隔分区进入：按胸骨角和心包关系定位，再缩小常见肿瘤 / 囊肿范围。它不是肺癌发展的下一阶段；病理U002的鼻咽癌尾部也保留独立回看身份。

### 本 Block 的中心任务

> **从咳嗽、反复同部位炎症、神经或静脉受累等证据反推受影响结构，再合并组织、范围和患者条件判断下一步；不能由一个人群特征、影像征或分期字母直接跳到治疗。**

## 2｜总 Framework

```text
肺内肿瘤：位置与组织学是独立坐标，人群 / 位置倾向不能代替组织确诊
中央 / 周围 / 弥漫描述空间；腺 / 鳞 / 神经内分泌及其他描述形态与来源
SCLC生长快、易早播散且放化疗敏感，仍可因播散 / 耐药预后差；不能推广到整个神经内分泌家族

肿瘤生长与行为的并行支路
├─ 气道局部阻塞 → 局限哮鸣；依阻塞条件可有炎症、肺不张或阻塞性肺气肿
├─ 邻近侵犯 → 食管、胸膜 / 胸壁、心包、SVC与神经各自的表现
│  肺尖侵犯臂丛与交感链分别解释上肢症状和Horner
├─ 淋巴 / 血道播散 → 区域结与远处器官病灶
└─ 异常分泌等远程作用 → 副癌 / 异位内分泌表现，区别直接侵犯与转移

检查分别读取病变，不是人人都走完的一条流程
├─ 筛查接口：低剂量CT
├─ 已见异常 / 疑病灶：CT定位，按病灶可达性选择支镜或经胸壁等取材
├─ 范围：影像、PET/CT与相应证据用于分期；炎症浓聚限制PET特异性
└─ 分子：检测靶点 / 指标，回答相应治疗能否适用

决策合流：组织学 + T / N / M + 可切除性 / 耐受 + 分子指标
├─ SCLC：课程以化疗为主；局限 / 广泛及少数极早期手术各有条件
└─ NSCLC：可切且耐受者评估手术；T4并非一律不可切，晚期还须看分子 / 免疫条件
治疗分别作用于局部肿瘤、全身病灶或特定通路，不由单一分期字母自动决定

胸内定位的另外两个入口
纵隔肿块：先分区再缩小肿瘤 / 囊肿范围；不能接成肺癌后期
鼻咽癌：原病理U002编辑尾部，独立回看，不接入肺癌因果链
```

### 五个固定判断轴

```text
位置轴：中央 / 周围 / 弥漫
组织轴：腺 / 鳞 / 神经内分泌 / 其他
表现轴：原发阻塞 / 局部侵犯 / 转移 / 副癌各自读回机制
证据轴：筛查 / 定位 / 取材 / 分期 / 分子各有任务
决策轴：组织学 + TNM + 可切除性 / 耐受 + 分子条件
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

以位置和组织学作两套坐标，肿瘤生长的各条支路解释表现；检查读取这些改变，治疗合看范围和适用条件。完整标题〔Prompt〕附在相应机制、判断或旁查位置，分类与证据不充当病理过程中的因果箭头。

```text
肺内细胞克隆性增生，伴分化 / 异型性改变；突破基底膜后的浸润与转移要有各自范围证据
位置描述中央 / 周围 / 弥漫，组织学描述细胞类型，两者分别定位；鳞状化生本身不等于癌
〈最小肿瘤 Gate：先问位置、来源、范围，不先背药〔位置3｜组织4｜浸润/转移/范围｜分期→治疗｜化生边界〕〉
吸烟、油烟和瘢痕等是课程风险背景；位置 / 人群倾向只改变怀疑方向，不能据此定组织类型
中央型大体最多与腺癌组织学最常见是不同统计坐标；多发肺灶仍须区别原发分布与转移
〈危险因素与三种大体位置：中央最多见，腺癌却最常见〔危险3｜大体3｜最多1｜胸膜1｜转移癌易混1｜部位/组织最多对照〕〉

组织学旁查为后面的行为与治疗提供条件，类型之间不构成演变顺序
├─ 腺癌常见周围型及女性 / 非吸烟背景，可有CEA、EGFR及早血道转移接口
│  旧“细支气管肺泡癌”范围与AIS不等同；小灶无浸润的AIS不能替代弥漫肺炎样病变
│  〈肺腺癌：女性、非吸烟、周围型 + 三种特殊腺癌〔人群2｜位置1｜特殊3｜外观2｜CEA｜EGFR｜转移倾向〕〉
├─ 鳞癌常见中央型、吸烟背景；鳞化背景、角化 / 桥与三种形态各有层级，形态类型不等于分化等级
│  异位PTHrP可接高钙支，不误称分泌完整PTH
│  〈肺鳞癌：鳞化背景、中央型与角化形态〔人群3｜来源｜形态3/分化区别｜角化2｜基底样｜高钙机制〕〉
├─ 神经内分泌家族含小细胞、大细胞神经内分泌和类癌，恶性度并不相同
│  小细胞生长快可对放化疗敏感，同时易早播散、耐药 → 敏感不保证好预后
│  不能把小细胞的早播散和敏感性自动赋给类癌
│  〈肺神经内分泌轴与小细胞癌：越敏感，不等于预后越好〔APUD 3类｜来源1｜恶性两端｜小细胞6特征｜镜下3｜激素3｜敏感≠预后〕〉
└─ 大细胞未分化与大细胞神经内分泌分开；腺鳞按两种成分判断，课程排序与比例保留原表
   〈大细胞、腺鳞癌与两张排序表〔大细胞1｜腺鳞门槛｜发病率3｜恶性度5｜（易混：大体最多 vs 组织最多）〕〉

同一肿瘤的生长可同时沿四路造成临床后果
├─ 原发刺激 / 气道受累 → 咳嗽、痰血等；消瘦、低热与人群背景提供怀疑线索，不能单独确诊
│  〈典型病例入口：中老年 + 刺激性咳嗽 + 痰血 + 体重下降〔人群1｜症状4｜最常见1｜痰血偏型｜低热边界〕〉
│  一段气道狭窄 → 局限性哮鸣；按阻塞条件分别出现阻塞性炎症、肺不张或肺气肿
│  同部位反复炎症且抗感染后不消退 → 查近端阻塞，不把三阻征写成固定先后
│  右上叶中央肿块合并上叶不张、水平裂上移与肿块轮廓 → 倒S；不套左上叶
│  〈局限性哮鸣音与三阻征：肿瘤堵住一段气道以后发生什么〔局限vs弥漫哮鸣｜原发归属｜三阻3｜发热/同部位反复｜倒S结构链〕〉
├─ 侵犯邻近结构 → 相应局部表现
│  食管受压 / 侵袭对应吞咽困难；喉返受累对应声嘶；SVC回流受阻对应面颈上肢水肿和JVD
│  胸壁 / 壁层胸膜神经受累对应疼痛；胸膜或心包受累可有各自积液，积液性质还需另取证
│  膈神经受刺激可有呃逆；这些表现并行，不能把声嘶接成水肿再接成转移
│  〈局部扩展：压到哪一结构，就出现哪一组表现〔局部扩展6结构｜结构→表现→机制｜SVCvs右心衰｜喉返接口〕〉
│  肺尖肿块若侵犯臂丛 → 上肢痛、感觉及运动障碍；若侵犯交感链 → Horner
│  两支可并存，单有肺尖位置还不等于已侵犯这两组神经
│  〈Pancoast瘤：肺尖肿块怎样同时打到臂丛与交感链〔肺尖位置｜神经2路｜上肢痛/感觉/运动3轴｜Horner4｜位置≠侵犯〕〉
├─ 淋巴与血道播散 → 分别出现区域结和远处器官病灶；不是先有某症状才开始转移
│  课程癌型倾向、右锁骨上与脑 / 肾上腺 / 骨的定位保留，其他器官癌的比较仅作旁查
│  〈肺癌转移：先分淋巴与血道，再看右锁骨上和三器官〔淋巴2型｜血道2型｜右锁骨上｜血道常见器官3｜左锁骨上2癌｜早血道4癌〕〉
└─ 异常分泌等远程功能作用 → 副癌表现，不能解释为对应器官一定已有转移
   副癌包含异位内分泌及课程类癌综合征；骨关节、杵状指、神经肌病仍需相应鉴别
   〈副癌—异位内分泌—类癌：三层概念不能倒置〔概念3层｜肥大骨关节/癌型｜神经肌病/癌型｜杵状指全表→MI-D｜非转移边界〕〉
   激素 / 活性物质作用于远处靶组织 → 相应乳腺、皮质醇、血钠、血钙或类癌表现
   原五组配对和四种类癌表现仍回原Core；2026 N129原题单选C小细胞与一般Lecture配对分开
   不把这道“最常见”裁决扩大为所有NET人群排序，或“只有小细胞可导致”
   〈异位激素配对 + 类癌综合征：Lecture范围与2026单选裁决〔激素5｜癌型5｜表现5｜类癌4表现｜2026 N129单选裁决〕〉

由病变读证据：每种检查回答自己的问题
肿瘤生长不均可表现分叶 / 毛刺；坏死物排出可形成空洞，结合原肿块形态读不规则洞壁
影像形态与倒S帮助定位和鉴别，不替代组织证据；空洞比较各有重叠和课程范围
〈影像三入口：分叶毛刺、癌性空洞、倒S征〔肿块边缘3征｜坏死→癌性空洞｜倒S部位/机制｜空腔鉴别8行〕〉
├─ 低剂量CT是筛查接口；已见X线异常时用CT明确位置、边界和范围
│  根据可达性选择支气管镜或经胸壁等取材；周围 / Pancoast可有不同路径
│  痰细胞学特异性与敏感性分开，隐性肺癌的发现方式不把它变成普遍首选
│  〈低剂量CT、支气管镜、穿刺与痰细胞学：四个问题四种工具〔筛查1｜金标1｜Pancoast取材1｜痰细胞学2特性｜X线后下一步〕〉
├─ “隐性”描述影像未显而细胞 / 病理发现，“早期”描述浸润和结转移范围
│  两者可有交集，却不能从一种发现方式自动推出另一种范围
│  〈隐性肺癌 vs 早期肺癌：发现方式与范围边界不同〔隐性3阴1阳1病理｜早期N条件｜中央2型/壁内｜周围大小门槛｜隐性/早期边界〕〉
└─ PET/CT读取代谢分布，辅助发现、分期及疗效评估；炎症也浓聚，不能单凭浓聚定癌
   基因检测读取可治疗靶点；影像范围与分子身份是不同证据
   〈PET/CT 与基因检测：一个看代谢范围，一个决定治疗靶点〔PET 4用途｜敏感性/特异性｜炎症/假阳边界｜基因1｜腺癌接口〕〉

组织与范围证据汇入治疗判断
├─ T读取原发大小及侵犯范围；3 / 5 / 7 cm及等号只属于原课程大小表，不是完整T分期
│  〈T 分期：3、5、7 cm 与“等号归较小期”〔T1–T4大小4档｜分档等号方向｜大小vs侵犯范围〕〉
├─ N读取区域结侧别和范围；M读取播散位置
│  对侧同癌肺结节归M，须区别第二原发；对侧肺门 / 纵隔结归N3
│  胸水可为恶性、反应性或回流受阻；一次细胞阴性不排恶性，不能以“抽到癌细胞”作唯一M1条件
│  M细分及N2第9版差异沿原Source保留，不与旧题粗类混用
│  〈N 与 M：对侧肺结节是 M1，对侧淋巴结是 N3〔N1–N3三站：侧别/区域｜M1三类｜对侧结节/淋巴结边界〕〉
└─ 组织学 + 完整TNM + 可切除性 / 耐受 + 分子条件 → 选择局部或全身治疗
   SCLC早播散且敏感，课程以依托泊苷加铂化疗为主；局限 / 广泛与少数极早期手术各有条件
   NSCLC I / II期可切且耐受者评估手术，不能手术也可有根治放疗等选择
   T4不能一律判不可切，须看侵犯结构、N / M与多学科条件；晚期不只剩放化疗
   〈SCLC vs NSCLC：为什么一类先化疗，一类先看能否切除〔SCLC首选/方案｜NSCLC分期/可切除性｜不能手术TNM3维｜放疗作用/不良〕〉
   治疗靶点与课程代表药分别对应：EGFR、ALK / ROS1、VEGF-A、PD-1
   帕博利珠单抗直接靶点为PD-1，PD-L1可作选择指标；免疫检查点不等于驱动基因靶向
   是否采用仍看亚型、范围和方案条件，原药物配对不升级为所有患者现代统一一线
   〈四组靶点—药物：只在靶点存在时成立〔EGFR 2药｜ALK/ROS1 1药｜VEGF 1药｜PD-1/PD-L1〕〉

胸内肿块的其他入口保持各自身份
纵隔占位先用胸骨角分上下，下纵隔按心包分前 / 中 / 后，再缩小常见肿瘤和囊肿范围

〈前、中、后纵隔：用空间压缩鉴别范围〔分区2步｜前3｜中3｜后1｜胸腺瘤串联1｜哑铃1〕〉

```

**Residual 边界**：机制、分类、比较和诊断/处理主轴归模型 / Prompt；数值、阈值、比例、药名细节、低频名单等才进入 MI-D / Precision。

## 3｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 大体位置与组织学类型是两套坐标；中央型最多见不等于鳞癌发病率最高；
2. 当前 Study：肺癌组织学发病率 `腺癌 > 鳞癌 > 小细胞癌`；恶性度 `小细胞 > 大细胞 > 腺癌 > 鳞癌 > 类癌`；
3. 中央型 / 肺门型最常见；周围型常侵犯胸膜；弥漫型起源于末梢肺组织、易与转移癌混淆；
4. 腺癌：女性、非吸烟者、周围型；特殊腺癌三类；EGFR突变接口；
5. 鳞癌：男性、吸烟者、中央型；来自支气管上皮鳞化；角化珠和细胞间桥；
6. APUD三类及来源；小细胞癌恶性度最高、早转移、放化疗敏感但预后差；

13. 副癌综合征 > 异位内分泌综合征 > 类癌综合征；2026 全国西综 N129 的“可导致类癌综合征的最常见肺癌类型”单选裁决为**小细胞癌**；

16. T按3、5、7 cm；N按同侧肺内 / 同侧纵隔 / 对侧或锁骨上；M1包括对侧肺结节、恶性胸 / 心包受累和远处器官；
17. 前 / 中 / 后纵隔的代表性肿瘤和胸腺瘤—重症肌无力接口。

## KP02｜危险因素与三种大体位置：中央最多见，腺癌却最常见

> **讲义定位 →** 病理 Lecture P77  
> **Outline →** 病理 U002｜肿瘤1–2  
> **主提示：** 危险3｜大体3｜最多1｜胸膜1｜转移癌易混1｜部位/组织最多对照

### 1｜危险因素

当前 Study 举例：

1. **吸烟**：最常见危险因素，与所有病理类型肺癌风险相关；
2. **空气污染 / 厨房油烟**：厨房油烟对女性腺癌影响较突出；
3. **结核病史**：主要与腺癌相关。

当前 Study 另以“**肺癌是男性最常见恶性肿瘤**”作为流行病学识别入口；它只用于提高病例警觉，不能替代位置、组织学与分期判断。

```text
吸烟是最常见危险因素
≠
只有鳞癌 / 小细胞癌与吸烟有关
```

腺癌虽多见女性和非吸烟者，吸烟仍可增加其风险并影响当前 Study 中的基因 / 靶向治疗接口。

### 2｜大体类型

| 大体位置 | 核心空间 | 直接接口 |
|---|---|---|
| 中央型 / 肺门型 | 大支气管、靠近肺门 | 最常见；易阻塞气道 |
| 周围型 | 外周肺组织 | 常侵犯胸膜 |
| 弥漫型 | 末梢肺组织多灶生长 | 易与肺内转移癌混淆 |

### 3｜两个“最多见”不能混

```text
大体分型中
→ 中央型最多见

组织学分型中
→ 腺癌最常见
```

原因是：腺癌多为周围型，但鳞癌、小细胞癌及其他类型多偏中央型；两个分类统计的是不同对象。

## KP03｜肺腺癌：女性、非吸烟、周围型 + 三种特殊腺癌

> **讲义定位 →** 病理 Lecture P77；内科 Lecture P61–62  
> **Outline →** 病理 U002｜肿瘤3–4a；内科 U024｜1、3、6；U025｜3  
> **主提示：** 人群2｜位置1｜特殊3｜外观2｜CEA｜EGFR｜转移倾向

### 1｜稳定身份

- 女性肺癌中最常见；
- 多见于非吸烟者；
- 多为周围型；
- 当前内科 Study：可有胸水 CEA 增高；
- EGFR 突变多见，进入靶向治疗接口；
- 具有较早血道转移倾向。

### 2｜三种特殊腺癌

| 特殊型 | 当前 Study 识别 |
|---|---|
| 细支气管肺泡癌（旧称） | 讲义以肺炎样弥漫外观识别；不能直接与现代原位腺癌画等号 |
| 黏液癌 | 可呈胶冻状 |
| 瘢痕癌 | 与肺内瘢痕背景相连 |

```text
弥漫型 + 肺炎样
→ 可想到讲义旧称细支气管肺泡癌的肺炎样腺癌接口
→ 但仍需与感染和转移癌鉴别
```

## KP04｜肺鳞癌：鳞化背景、中央型与角化形态

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P61  
> **Outline →** 病理 U002｜肿瘤4b–7、14；内科 U024｜1、4  
> **主提示：** 人群3｜来源｜形态3/分化区别｜角化2｜基底样｜高钙机制

### 1｜人群与位置

- 多见男性；
- 与吸烟关系密切；
- 多为中央型。

### 2｜来源

当前病理 Study：

```text
慢性刺激
→ 支气管上皮鳞状化生
→ 肿瘤过程
→ 鳞状细胞癌
```

（边界：鳞化本身仍不是癌。）

### 3｜课程三种形态口径

| 类型 | 镜下入口 |
|---|---|
| 角化型 | 角化珠、细胞间桥等角化/鳞状分化线索 |
| 非角化型 | 角化不突出；不能仅据此等同于低分化等级 |
| 基底细胞样型 | 癌细胞小、胞质少、栅栏状排列 |

讲义并列“高分化/角化、低分化/非角化”；此对应仅保留为来源差异。角化/非角化/基底样是形态分类，不能与高/低分化等级一一同义。“基底细胞样”描述形态，不意味着另一种肿瘤先转变成它，也不能据此排除基底细胞作为细胞起源的可能性。

### 4｜临床激素接口

讲义写“甲状旁腺激素”；典型体液性肿瘤高钙机制主要是PTH相关蛋白（PTHrP），不是通常由肿瘤分泌完整PTH。

## KP05｜肺神经内分泌轴与小细胞癌：越敏感，不等于预后越好

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P61–62  
> **Outline →** 病理 U002｜肿瘤8–13；内科 U024｜2、5–6、12–13  
> **主提示：** APUD 3类｜来源1｜恶性两端｜小细胞6特征｜镜下3｜激素3｜敏感≠预后

### 1｜APUD / 神经内分泌肿瘤三类

1. 小细胞癌；
2. 大细胞神经内分泌癌；
3. 类癌。

来源：支气管黏膜上皮内的嗜银细胞 / Kulchitsky 神经内分泌细胞。

当前 Study 恶性度两端：

```text
类癌最低
小细胞癌最高
```

### 2｜小细胞癌稳定身份

- 男性、吸烟者；
- 多为中央型；
- 分化最低、恶性度最高；
- 最早、最容易转移；
- 对放疗、化疗最敏感；
- 预后最差。

### 3｜镜下

- 癌细胞小；
- 胞质少，似裸核 / 燕麦细胞；
- 可围绕小血管形成假菊形团。

### 4｜为什么“敏感却预后差”

```text
生长分数高、分裂快
→ 对放化疗敏感

但
早期广泛播散 + 易耐药
→ 长期治疗效果差
→ 预后最差
```

### 5｜异位分泌

可分泌 ADH、ACTH、5-HT 等；完整临床映射在 KP15。

## KP07｜隐性肺癌 vs 早期肺癌：发现方式与范围边界不同

> **讲义定位 →** 病理 Lecture P78–79  
> **Outline →** 病理 U002｜肿瘤15–16  
> **主提示：** 隐性3阴1阳1病理｜早期N条件｜中央2型/壁内｜周围大小门槛｜隐性/早期边界

### 1｜隐性肺癌

- 肺内无明显肿块；
- 无淋巴结转移；
- 影像学检查阴性；
- 痰细胞学可见癌细胞；
- 手术切除后病理证实为支气管黏膜原位癌或早期浸润癌。

它强调的是：

> **常规影像没看到，但细胞学与病理已经暴露肿瘤。**

### 2｜早期肺癌

共同前提：**无淋巴结转移**。

```text
早期中央型
发生于段及以上大支气管
癌仅限管壁内生长
不侵犯肺实质
可分腔内型、管壁浸润型

早期周围型
肺组织内结节
直径 <2 cm
```

（易混：隐性肺癌是“如何被发现”的边界；早期肺癌是“病变范围”的边界。两者可重叠，但不是同义词。）

## KP08｜病理 U002 的鼻咽癌尾部：编辑性归属，不并入肺癌主链

> **讲义定位 →** 病理 Lecture P79–80  
> **Outline →** 病理 U002｜肿瘤17–19  
> **主提示：** EBV肿瘤4｜部位1｜大体1｜组织1｜放疗敏感2

病理 U002 在肺癌之后附带鼻咽癌，需完成 Coverage，但不能制造“肺癌发展成鼻咽癌”的假关系。

### 1｜EBV 相关肿瘤

当前 Study：

- 鼻咽癌，尤其非角化型与EBV密切相关；讲义“分化性鳞癌”的名称存在分类含混，不能当作高分化角化型的同义词；

- NK/T 细胞淋巴瘤。

### 2｜鼻咽癌三项定位

- 讲义写“分化性鳞癌最多见”；现代分类以非角化型占多数，包含分化型与未分化型。此处显式保留名称冲突，不把讲义文字误推成“高分化角化型最多”。

### 3｜治疗敏感性

恶性程度较高的低分化鳞癌和泡状核细胞癌对放疗敏感，当前 Study 以放疗为主。

# Unit B｜肿瘤怎样从“一个肿块”变成临床表现

## KP09｜典型病例入口：中老年 + 刺激性咳嗽 + 痰血 + 体重下降

> **讲义定位 →** 内科 Lecture P61  
> **Outline →** 内科 U024｜临床1–2  
> **主提示：** 人群1｜症状4｜最常见1｜痰血偏型｜低热边界

```text
支扩
→ 长期大量脓痰 + 反复咯血

→ 中老年 + 刺激性咳嗽 + 痰血 + 体重下降
```

病例仍需结合影像、位置和取材，不能只凭一条症状定病。

## KP10｜局限性哮鸣音与三阻征：肿瘤堵住一段气道以后发生什么

> **讲义定位 →** 内科 Lecture P61、P63  
> **Outline →** 内科 U024｜临床3–4；U025｜4  
> **主提示：** 局限vs弥漫哮鸣｜原发归属｜三阻3｜发热/同部位反复｜倒S结构链

### 1｜局限性哮鸣音

```text
局部肿块压迫 / 狭窄一段支气管
→ 气流通过狭窄处
→ 局限性哮鸣音
```

这是**原发肿瘤引起**的表现。

（易混：支气管哮喘为广泛气道痉挛，更常出现双肺弥漫性哮鸣音；支气管结核也可出现局限性哮鸣音。）

### 2｜三阻征

肿瘤阻塞气道可引起：

1. 阻塞性肺炎；
2. 肺不张；
3. 阻塞性肺气肿。

```text
同一部位反复肺炎
+ 抗生素治疗后未完全消退
→ 不只问病原体
→ 要追查近端气道是否被肿块阻塞
```

阻塞性肺炎多为低—中热，与普通急性感染的高热入口不同。

### 3｜倒 S 征

右上叶中央型肺癌：

```text
中央肿块堵塞右上叶支气管
→ 右上叶肺不张
→ 水平裂上提并受肿块牵扯
→ 倒S征
```

左肺没有水平裂，不能机械套用。

# Unit C｜副癌综合征：不是肿瘤压到那里，而是肿瘤“远程发信号”

## KP14｜副癌—异位内分泌—类癌：三层概念不能倒置

> **讲义定位 →** 内科 Lecture P62  
> **Outline →** 内科 U024｜临床11–12；U025｜14  
> **主提示：** 概念3层｜肥大骨关节/癌型｜神经肌病/癌型｜杵状指全表→MI-D｜非转移边界

### 1｜三层范围

```text
副癌 / 伴癌综合征
> 异位内分泌综合征
> 类癌综合征
```

- **副癌综合征**：由肿瘤产生，但不是肿瘤直接侵犯或转移造成的全身功能 / 代谢异常；
- **异位内分泌综合征**：非内分泌来源肿瘤异常分泌激素；
- **类癌综合征**：肿瘤分泌 5-HT 等血管活性物质形成特定表现。

### 2｜两个非内分泌副癌入口

- 肥大性骨关节病，可有杵状指：多见于 NSCLC；
- 神经—肌病综合征，可有肌无力：多见于小细胞癌。

（MI-D｜杵状指完整疾病表：肝硬化、系统性硬化症、支气管扩张、间质性肺病、亚急性感染性心内膜炎、炎症性肠病、慢性肺脓肿、慢性脓胸、梅毒、法洛四联症、肺癌。杵状指只能增加某类慢性肺 / 心 / 消化疾病或肿瘤的概率，不能单独定病。）

## KP15｜异位激素配对 + 类癌综合征：Lecture范围与2026单选裁决

> **Outline →** 内科 U024｜临床13；U025｜14

### 1｜当前 Study 配对

# Unit E｜治疗与 TNM：范围先于药名

## KP19｜四组靶点—药物：只在靶点存在时成立

> **讲义定位 →** 内科 Lecture P64  
> **Outline →** 内科 U025｜治疗3  
> **主提示：** EGFR 2药｜ALK/ROS1 1药｜VEGF 1药｜PD-1/PD-L1

| 靶点 | 当前 Study 代表药 |
|---|---|
| EGFR / HER1 / ERBB1 突变 | 厄洛替尼、吉非替尼 |
| ALK 或 ROS1 重排 | 克唑替尼 |
| 肿瘤血管生成：VEGF-A | 贝伐珠单抗 |
| PD-1 | 帕博利珠单抗（讲义“派姆单抗”） |

讲义将帕博利珠单抗列为PD-L1靶点，需纠正：它直接结合PD-1；PD-L1表达可用于部分方案的选择，但生物标志物不等于药物直接靶点。免疫检查点治疗也不等同于EGFR/ALK驱动基因靶向治疗。

核心原则：

```text
靶向治疗成功
→ 先选择特异性靶标
→ 再选择对应药物
```

表中为课程代表药，不能据此认为它们都是当前所有分期的一线优选。具体疗效还受突变亚型、分期及联合方案影响；此处不扩写完整现代处方。

## KP20｜SCLC vs NSCLC：为什么一类先化疗，一类先看能否切除

> **讲义定位 →** 内科 Lecture P64  
> **Outline →** 内科 U025｜治疗1–2  
> **主提示：** SCLC首选/方案｜NSCLC分期/可切除性｜不能手术TNM3维｜放疗作用/不良

### 1｜小细胞肺癌

```text
早期易广泛播散
+ 对放化疗敏感
→ 当前 Study 首选化疗
→ 依托泊苷 + 铂类
```

“敏感”不代表预后好，见KP05。临床须分局限期/广泛期及适用条件选择放化疗、免疫治疗等；少数很早期且完成纵隔分期者可考虑手术，不能写成SCLC一律不能手术。

### 2｜非小细胞肺癌

- I、II期可切除且能耐受者，手术是重要根治手段；不能手术者仍有相应根治性放疗等选择；
- 讲义以T4、N3、M1作为不能手术的快捷判断，但T4不等于任何情形均不可切除，需看具体侵犯结构、N/M及多学科评估；晚期治疗也不只是放化疗，须结合分子与免疫指标。

### 3｜放疗边界

- 可缩小肿块，缓解呼吸困难、疼痛等；
- 可抑制骨髓造血，导致外周全血细胞减少。

（边界：本文件保留当前讲义的考试化大边界，不外推具体手术术式、放疗剂量、围术期或现代多学科方案。）

## 4｜高密度病例算法

### A｜同一部位反复肺炎

```text
同一肺段反复炎症
+ 抗感染后不完全消退
```
