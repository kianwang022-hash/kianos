## 0｜这个 Block 到底解决什么

面对肺部肿块，最容易犯的错误是把四个问题混成一个：

```text
肿块长在哪里？
≠
镜下是哪类癌？
≠
已经扩展到哪里？
≠
下一步怎样治疗？
```

稳定顺序应是：

```text
第一次定位：大体位置
中央型 / 周围型 / 弥漫型
        ↓
第二次定位：组织来源
腺癌 / 鳞癌 / 神经内分泌癌 / 其他
        ↓
第三次定位：行为范围
原发阻塞 / 邻近侵犯 / 淋巴 / 血道 / 胸膜与远处
        ↓
第四次定位：分期与治疗
T + N + M
→ SCLC 或 NSCLC
→ 手术 / 放疗 / 化疗 / 靶向
```

纵隔肿块则先换一个入口：

```text
不是先猜病名
而是先问：前、中、后纵隔？
→ 再挂该空间最常见的肿瘤或囊肿
```

### 本 Block 的中心任务

> **看到中老年刺激性咳嗽、同一部位反复肺炎、局限性哮鸣音、血性胸水、声音嘶哑、上腔静脉综合征或肺门肿块时，能从空间—组织—扩展—分期连续推导，而不是只背“某癌多见于某人群”。**

## 3｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 大体位置与组织学类型是两套坐标；中央型最多见不等于鳞癌发病率最高；
2. 当前 Study：肺癌组织学发病率 `腺癌 > 鳞癌 > 小细胞癌`；恶性度 `小细胞 > 大细胞 > 腺癌 > 鳞癌 > 类癌`；
3. 中央型 / 肺门型最常见；周围型常侵犯胸膜；弥漫型起源于末梢肺组织、易与转移癌混淆；
4. 腺癌：女性、非吸烟者、周围型；特殊腺癌三类；EGFR突变接口；
5. 鳞癌：男性、吸烟者、中央型；来自支气管上皮鳞化；角化珠和细胞间桥；
6. APUD三类及来源；小细胞癌恶性度最高、早转移、放化疗敏感但预后差；
7. 隐性肺癌与早期肺癌的定义边界；
8. 典型入口：中老年 + 刺激性咳嗽 + 痰中带血 + 体重下降；刺激性咳嗽最常见；
9. 局限性哮鸣音与“三阻征”提示局部气道阻塞；同一部位反复炎症且抗生素后不完全消退要警惕肺癌；
10. SVC、喉返、膈神经、食管、胸壁、心包受累各自表现；
11. Pancoast瘤位于肺尖；臂丛和颈交感受侵分别产生上肢症状与 Horner；
12. 淋巴转移偏小细胞 / 鳞癌，血道转移偏小细胞 / 腺癌；右锁骨上和脑 / 肾上腺 / 骨；
13. 副癌综合征 > 异位内分泌综合征 > 类癌综合征；2026 全国西综 N129 的“可导致类癌综合征的最常见肺癌类型”单选裁决为**小细胞癌**；
14. 低剂量 CT 筛查；支气管镜活检为金标准；PET/CT用于早期灶、转移、分期和疗效；
15. 小细胞癌首选化疗；I、II期 NSCLC首选手术；T4 / N3 / M1当前 Study 不手术；
16. T按3、5、7 cm；N按同侧肺内 / 同侧纵隔 / 对侧或锁骨上；M1包括对侧肺结节、恶性胸 / 心包受累和远处器官；
17. 前 / 中 / 后纵隔的代表性肿瘤和胸腺瘤—重症肌无力接口。

## KP02｜危险因素与三种大体位置：中央最多见，腺癌却最常见

> **讲义定位 →** 病理 Lecture P77  
> **Outline →** 病理 U002｜肿瘤1–2  
> **主提示：** 危险3｜大体3｜最多1｜胸膜1｜转移癌易混1｜（易混：中央最多 vs 腺癌最多）

### 1｜危险因素

当前 Study 举例：

1. **吸烟**：最常见危险因素，与所有病理类型肺癌风险相关；
2. **空气污染 / 厨房油烟**：厨房油烟对女性腺癌影响较突出；
3. **结核病史**：主要与腺癌相关。

当前 Study 另以“**肺癌是男性最常见恶性肿瘤**”作为流行病学识别入口；它只用于提高病例警觉，不能替代位置、组织学与分期判断。

```text
吸烟是最常见危险因素
≠
只有鳞癌 / 小细胞癌与吸烟有关
```

腺癌虽多见女性和非吸烟者，吸烟仍可增加其风险并影响当前 Study 中的基因 / 靶向治疗接口。

### 2｜大体类型

| 大体位置 | 核心空间 | 直接接口 |
|---|---|---|
| 中央型 / 肺门型 | 大支气管、靠近肺门 | 最常见；易阻塞气道 |
| 周围型 | 外周肺组织 | 常侵犯胸膜 |
| 弥漫型 | 末梢肺组织多灶生长 | 易与肺内转移癌混淆 |

### 3｜两个“最多见”不能混

```text
大体分型中
→ 中央型最多见

组织学分型中
→ 腺癌最常见
```

原因是：腺癌多为周围型，但鳞癌、小细胞癌及其他类型多偏中央型；两个分类统计的是不同对象。

## KP03｜肺腺癌：女性、非吸烟、周围型 + 三种特殊腺癌

> **讲义定位 →** 病理 Lecture P77；内科 Lecture P61–62  
> **Outline →** 病理 U002｜肿瘤3–4a；内科 U024｜1、3、6；U025｜3  
> **主提示：** 人群2｜位置1｜特殊3｜外观2｜CEA｜EGFR｜转移倾向

### 1｜稳定身份

- 女性肺癌中最常见；
- 多见于非吸烟者；
- 多为周围型；
- 当前内科 Study：可有胸水 CEA 增高；
- EGFR 突变多见，进入靶向治疗接口；
- 具有较早血道转移倾向。

### 2｜三种特殊腺癌

| 特殊型 | 当前 Study 识别 |
|---|---|
| 细支气管肺泡癌 / 原位腺癌 | 多为弥漫型，呈肺炎样外观 |
| 黏液癌 | 可呈胶冻状 |
| 瘢痕癌 | 与肺内瘢痕背景相连 |

```text
弥漫型 + 肺炎样
→ 先想到原位腺癌 / 细支气管肺泡癌接口
→ 但仍需与感染和转移癌鉴别
```

（易混：这三种均属于腺癌特殊类型，不是所有肺癌都可称“黏液癌 / 瘢痕癌”。）

## KP04｜肺鳞癌：鳞化背景、中央型与角化形态

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P61  
> **Outline →** 病理 U002｜肿瘤4b–7、14；内科 U024｜1、4  
> **主提示：** 人群3｜来源1｜分化3｜角化2｜基底样3｜PTH｜（易混：基底样≠基底细胞癌）

### 1｜人群与位置

- 多见男性；
- 与吸烟关系密切；
- 多为中央型。

### 2｜来源

当前病理 Study：

```text
慢性刺激
→ 支气管上皮鳞状化生
→ 肿瘤过程
→ 鳞状细胞癌
```

（边界：鳞化本身仍不是癌。）

### 3｜三种分化口径

| 类型 | 镜下入口 |
|---|---|
| 高分化 / 角化型 | 角化珠、细胞间桥 |
| 低分化 / 非角化型 | 角化特征不突出 |
| 基底细胞样型 | 癌细胞小、胞质少、栅栏状排列 |

“基底细胞样”只表示形态近似基底细胞，不表示由所谓“肺基底细胞癌”转变而来。

### 4｜临床激素接口

当前内科 Study：鳞癌可异位分泌甲状旁腺激素，导致高血钙。

## KP05｜肺神经内分泌轴与小细胞癌：越敏感，不等于预后越好

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P61–62  
> **Outline →** 病理 U002｜肿瘤8–13；内科 U024｜2、5–6、12–13  
> **主提示：** APUD 3类｜来源1｜恶性两端｜小细胞6特征｜镜下3｜激素3｜敏感≠预后

### 1｜APUD / 神经内分泌肿瘤三类

1. 小细胞癌；
2. 大细胞神经内分泌癌；
3. 类癌。

来源：支气管黏膜上皮内的嗜银细胞 / Kulchitsky 神经内分泌细胞。

当前 Study 恶性度两端：

```text
类癌最低
小细胞癌最高
```

### 2｜小细胞癌稳定身份

- 男性、吸烟者；
- 多为中央型；
- 分化最低、恶性度最高；
- 最早、最容易转移；
- 对放疗、化疗最敏感；
- 预后最差。

### 3｜镜下

- 癌细胞小；
- 胞质少，似裸核 / 燕麦细胞；
- 可围绕小血管形成假菊形团。

### 4｜为什么“敏感却预后差”

```text
生长分数高、分裂快
→ 对放化疗敏感

但
早期广泛播散 + 易耐药
→ 长期治疗效果差
→ 预后最差
```

### 5｜异位分泌

可分泌 ADH、ACTH、5-HT 等；完整临床映射在 KP15。

## KP06｜大细胞、腺鳞癌与两张排序表

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P61  
> **Outline →** 病理 U002｜肿瘤14；内科 U024｜1–2、5  
> **主提示：** 大细胞1｜腺鳞门槛｜发病率3｜恶性度5｜（易混：大体最多 vs 组织最多）

### 1｜大细胞未分化癌

病理 Study 将其作为独立组织类型；内科恶性度排序中位于小细胞癌之后。

### 2｜腺鳞癌

```text
腺癌成分 ≥10%
+
鳞癌成分 ≥10%
→ 腺鳞癌
```

不因其中一方比例更大就忽略另一方。

### 3｜两张排序表

```text
组织学发病率
腺癌 > 鳞癌 > 小细胞癌

恶性度
小细胞癌 > 大细胞癌 > 腺癌 > 鳞癌 > 类癌
```

（易混：中央型是**大体位置**中最多见；腺癌是**组织类型**中最多见。）

## KP07｜隐性肺癌 vs 早期肺癌：发现方式与范围边界不同

> **讲义定位 →** 病理 Lecture P78–79  
> **Outline →** 病理 U002｜肿瘤15–16  
> **主提示：** 隐性3阴1阳1病理｜早期无N｜中央2型/壁内｜周围<2｜（易混：隐性≠早期）

### 1｜隐性肺癌

- 肺内无明显肿块；
- 无淋巴结转移；
- 影像学检查阴性；
- 痰细胞学可见癌细胞；
- 手术切除后病理证实为支气管黏膜原位癌或早期浸润癌。

它强调的是：

> **常规影像没看到，但细胞学与病理已经暴露肿瘤。**

### 2｜早期肺癌

共同前提：**无淋巴结转移**。

```text
早期中央型
发生于段及以上大支气管
癌仅限管壁内生长
不侵犯肺实质
可分腔内型、管壁浸润型

早期周围型
肺组织内结节
直径 <2 cm
```

（易混：隐性肺癌是“如何被发现”的边界；早期肺癌是“病变范围”的边界。两者可重叠，但不是同义词。）

# Unit B｜肿瘤怎样从“一个肿块”变成临床表现

## KP09｜典型病例入口：中老年 + 刺激性咳嗽 + 痰血 + 体重下降

> **讲义定位 →** 内科 Lecture P61  
> **Outline →** 内科 U024｜临床1–2  
> **主提示：** 人群1｜症状4｜最常见1｜痰血偏型｜低热边界

当前 Study 的“可能—最可能”入口：

- 中老年；
- 刺激性咳嗽；
- 痰中带血；
- 体重下降；
- 可有低热。

其中：

- **刺激性咳嗽最常见**；
- 痰中带血在中央型更常见；
- 肿瘤一般不发热或仅低—中热。

### 与三类常见咯血入口比较

```text
肺结核
→ 各年龄可见 + 低热盗汗 + 上肺病变

支扩
→ 长期大量脓痰 + 反复咯血

肺癌
→ 中老年 + 刺激性咳嗽 + 痰血 + 体重下降
```

病例仍需结合影像、位置和取材，不能只凭一条症状定病。

## KP10｜局限性哮鸣音与三阻征：肿瘤堵住一段气道以后发生什么

> **讲义定位 →** 内科 Lecture P61、P63  
> **Outline →** 内科 U024｜临床3–4；U025｜4  
> **主提示：** 哮鸣范围｜原发/扩展？｜三阻3｜发热｜同部位反复｜倒S机制

### 1｜局限性哮鸣音

```text
局部肿块压迫 / 狭窄一段支气管
→ 气流通过狭窄处
→ 局限性哮鸣音
```

这是**原发肿瘤引起**的表现。

（易混：支气管哮喘为广泛气道痉挛，更常出现双肺弥漫性哮鸣音；支气管结核也可出现局限性哮鸣音。）

### 2｜三阻征

肿瘤阻塞气道可引起：

1. 阻塞性肺炎；
2. 肺不张；
3. 阻塞性肺气肿。

```text
同一部位反复肺炎
+ 抗生素治疗后未完全消退
→ 不只问病原体
→ 要追查近端气道是否被肿块阻塞
```

阻塞性肺炎多为低—中热，与普通急性感染的高热入口不同。

### 3｜倒 S 征

右上叶中央型肺癌：

```text
中央肿块堵塞右上叶支气管
→ 右上叶肺不张
→ 水平裂上提并受肿块牵扯
→ 倒S征
```

左肺没有水平裂，不能机械套用。

## KP13｜肺癌转移：先分淋巴与血道，再看右锁骨上和三器官

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P62

### 1｜肺癌内部的转移偏好

# Unit C｜副癌综合征：不是肿瘤压到那里，而是肿瘤“远程发信号”

## KP14｜副癌—异位内分泌—类癌：三层概念不能倒置

> **讲义定位 →** 内科 Lecture P62  
> **Outline →** 内科 U024｜临床11–12；U025｜14  
> **主提示：** 概念3层｜肥大骨关节/癌型｜神经肌病/癌型｜杵状指全表→MI-D｜非转移边界

### 1｜三层范围

```text
副癌 / 伴癌综合征
> 异位内分泌综合征
> 类癌综合征
```

- **副癌综合征**：由肿瘤产生，但不是肿瘤直接侵犯或转移造成的全身功能 / 代谢异常；
- **异位内分泌综合征**：非内分泌来源肿瘤异常分泌激素；
- **类癌综合征**：肿瘤分泌 5-HT 等血管活性物质形成特定表现。

### 2｜两个非内分泌副癌入口

- 肥大性骨关节病，可有杵状指：多见于 NSCLC；
- 神经—肌病综合征，可有肌无力：多见于小细胞癌。

（MI-D｜杵状指完整疾病表：肝硬化、系统性硬化症、支气管扩张、间质性肺病、亚急性感染性心内膜炎、炎症性肠病、慢性肺脓肿、慢性脓胸、梅毒、法洛四联症、肺癌。杵状指只能增加某类慢性肺 / 心 / 消化疾病或肿瘤的概率，不能单独定病。）

## KP15｜异位激素配对 + 类癌综合征：Lecture范围与2026单选裁决

> **讲义定位 →** 病理 Lecture P78；内科 Lecture P62  
> **Outline →** 内科 U024｜临床13；U025｜14  
> **主提示：** 激素5｜癌型5｜表现5｜类癌4表现｜2026 N129单选裁决

### 1｜当前 Study 配对

| 肿瘤分泌物 | 常见肺癌类型 | 主要表现 |
|---|---|---|
| 促性腺激素 | 大细胞癌 | 男性乳腺发育 |
| ACTH | 小细胞癌、类癌 | Cushing 综合征 |
| ADH | 小细胞癌 | 顽固性 / 稀释性低钠 |
| 甲状旁腺激素 | 鳞癌 | 高血钙 |
| 5-HT 等 | 小细胞癌、腺癌 | 类癌综合征 |

### 2｜类癌综合征

- 皮肤潮红；
- 心动过速；
- 腹泻；
- 喘息 / 支气管痉挛。

### 3｜神经内分泌来源与分泌能力不是同一判断

- APUD / 神经内分泌肿瘤有特定细胞来源；
- 腺癌、鳞癌不属于神经内分泌肿瘤，但也可异常分泌激素。

### 4｜2026 单选裁决：最常见 = 小细胞癌

## 4｜高密度病例算法

### A｜同一部位反复肺炎

```text
同一肺段反复炎症
+ 抗感染后不完全消退
→ 查近端气道
→ 是否局限性哮鸣音 / 肺不张 / 阻塞性肺气肿
→ CT定位中央肿块
→ 取材证实
```

### B｜肺门肿块 + 声嘶 / 面颈水肿

```text
肺门 / 中央肿块
→ 声音嘶哑：喉返神经
→ 面颈上肢水肿 + JVD：SVC
→ 胸水 / 心包液：胸膜或心包
→ 再做分期，不把症状直接等同远处转移
```

### C｜肺尖肿块 + 肩臂痛

```text
肺尖位置
+ 肩臂痛 / 麻木 / 运动障碍
→ 臂丛受累

再看
眼睑下垂 + 瞳孔缩小 + 眼球内陷 + 无汗
→ 颈交感受累
→ Pancoast模型
```

### D｜周围肿块 + 胸水

```text
周围型 / 腺癌入口
→ 胸膜受累可有胸痛 / 胸水
→ 胸水细胞学

癌细胞阳性
→ 恶性胸水
→ M1

癌细胞阴性
→ 仍需区分反应性 / 回流受阻 / 其他胸水
```

### E｜治疗顺序

```text
病理类型
→ SCLC vs NSCLC
→ TNM
→ 可切除性
→ 分子靶点
→ 选择手术 / 化疗 / 放疗 / 靶向
```
