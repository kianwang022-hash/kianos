## 0｜这个 Block 到底解决什么

结核杆菌进入后，能否被控制取决于病原与宿主免疫状态。细胞免疫既能组织肉芽肿、局限感染，相关免疫损伤也能造成干酪坏死；两种效应并行。感染可以潜伏或发病，不能把所有病人都排入“感染—肉芽肿—空洞—播散”的固定病程。

初次感染、已有免疫背景和严重免疫低下会改变病灶分布、组织反应与传播倾向。初次感染的淋巴/血道播散可以早于空洞；免疫低下者少空洞或 PPD 弱也不等于病情轻。局限、渗出、坏死物排出、纤维包裹和胸膜受累产生不同病变分支，继发性六型不是六个必经阶段。

症状、体征、影像、PPD 和病原检查分别观察这些病变与免疫/排菌状态。活动性和传染性须分开合读，不能让“任何空洞”或一次涂片独立下结论。化疗则从当前药敏、既往治疗和菌群状态选择，而不是按初治、复治、耐药机械升级。

### 本 Block 的总任务

> **从病原、宿主和组织反应解释病变空间，再用相应证据判断当前感染/疾病、活动/传染与治疗状态；器官专科诊疗保留在原所属系统。**

## 1｜总 Framework

```text
TB进入 + 宿主感染史/免疫能力 → 感染可能被局限、潜伏或发病
细胞免疫的两类效应并行：局限病原/组织肉芽肿；相关免疫损伤/干酪坏死

宿主状态改变形态与分布
初次感染 → 肺灶—淋巴管—肺门结；可淋巴/血道播散，不必先有空洞
已有免疫下再激活/再感染 → 常见上肺、支气管播散、空洞与上旧下新
严重免疫低下 → 可少肉芽肿/空洞、PPD弱，却有更多肺门结、下肺和播散表现

局限/渗出/坏死/引流/修复决定病灶分支
增生局限；浸润渗出；广泛干酪实变；坏死排出形成洞；反复纤维修复；包裹结核球；胸膜受累
六形态可转化或并存，不是六阶段；传播按支气管、淋巴、血流或直接蔓延各走其路
纤维牵拉 → 肺收缩及相应影像；血管床受压/减少 → PVR↑、肺高压 → 右室后负荷↑，交R9
胸水交R10；肺外病理身份在本块，专科诊疗后置

观察读取已有病变，不推动病程
症状/热型/咯血 + 空间/传声体征；影像位置/变化；PPD免疫反应；涂片/培养鉴定/分子证据
活动和传染分开合读：空洞不独立判活动，涂阴不保证不传播

当前治疗分支：六原则/菌群与毒性条件 → 药敏初治方案，或复治先药敏，或合适RR/MDR方案
课程疗程与既有WHO版本分开，不能由病名自动推出固定统一方案
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

医学关系和条件先独立成形，完整标题〔Prompt〕固定在相应自然节点；隐藏全部注释后仍沿同一模型解释。需要更多细节时展开原 Core，精确残余保留在原 Memory / Precision。

```text
TB从排菌来源经传播途径进入宿主；吸入后感染可以被局限、潜伏，也可发病
感染史与当前免疫能力一起决定能否控制；不能把“感染过”直接当作“正在患结核病”
〈传染、感染与发病：吸入TB不等于立刻得结核病〔传染源｜途径3｜易感｜炎症3变｜感染≠病｜潜伏/发病条件〕〉

巨噬细胞吞噬TB，宿主细胞免疫同时产生两类效应
├─ 组织细胞应答、局限病原 → 肉芽肿与控制感染
└─ 相关免疫损伤 → 干酪样坏死；有坏死物排入支气管时才连接空洞
细胞壁成分—免疫/坏死/PPD是课程关联，不能把成分表当成相互独立且必然发生的单因果
〈结核杆菌细胞壁3成分：免疫、坏死/空洞与PPD〔毒素｜细胞壁3成分/3效应｜超敏型｜免疫vs变态｜继发空洞机制〕〉
肉芽肿中上皮样细胞与Langhans巨细胞来自巨噬细胞，周围淋巴细胞和成纤维细胞参与
中央干酪坏死与外围细胞组织反映免疫、损伤和修复的组合，并非每位患者形态都同样完整
〈结核结节：4类细胞围住中央彻底凝固性坏死〔细胞4｜来源链｜巨细胞核形｜中央坏死｜大体4词｜镜下2词〕〉

感染史和免疫状态改变分布，而不排成一个患者的三个必经阶段
├─ 初次感染：肺内灶、淋巴管和同侧肺门淋巴结三者构成原发复合征；可沿淋巴/血流播散，也可控制修复
│  原发的淋巴/血道传播不以先有空洞为前提
│  〈原发性肺结核：初次感染形成“肺灶—淋巴管—肺门结”哑铃〔定义/人群｜复合征3｜部位｜淋巴结侧别｜影像｜播散2｜结局方向〕〉
├─ 已有免疫背景下的再激活或再感染：常有上肺优势、支气管播散、上旧下新及空洞
│  这些是典型倾向，不能凭一个部位排除其他情境
│  〈继发性肺结核：上叶、支气管播散、上旧下新和空洞〔来源2｜宿主/人群｜部位3/左右｜播散｜上下新旧/轻重｜空洞｜原发对照6轴〕〉
└─ 严重免疫低下：结节组织与干酪/空洞反应可少，却可有下肺、肺门结、胸/心包和粟粒播散
   PPD也可弱；“像原发”的影像不能改写感染史，少洞不等于病原少或病情轻
   〈AIDS合并肺结核：继发病人呈现“原发型”影像和免疫反应〔部位｜淋巴结2｜累及2腔｜粟粒｜空洞/肉芽肿｜PPD｜原因链〕〉

病灶的局限、渗出、坏死、引流与纤维修复产生条件分支
六种继发性形态是同一病变模型的不同表现；可有新旧病灶并存，不是六个顺次必经阶段
〈六型总路线：活动性不是按名字长短，而看渗出、空洞与播散〔六型｜非活动1｜最常见活动1｜危重1｜开放1｜胸膜2型〕〉
├─ 增生局限 → 局灶性病变；渗出浸润 → 较活动的浸润灶
│  浸润灶后续可分向干酪性肺炎、慢性空洞或包裹性结核球，取决于坏死、排出和修复
│  〈局灶型 vs 浸润型：一个以增生局限，一个以渗出活动〔局灶vs浸润：部位/影像/病理/活动性｜薄壁空洞｜后续3去向〕〉
├─ 广泛干酪坏死与肺实变 → 干酪性肺炎；坏死物排出 → 空洞
│  薄壁、无壁虫蚀、厚壁分别对应不同病变背景；液平及化脓性空洞比较回R6
│  〈干酪性肺炎与三种结核空洞：薄壁、无壁、厚壁〔危重线索｜实变｜空洞型3｜链球菌对比｜液平边界〕〉
├─ 反复坏死/排出 + 纤维修复 → 慢性厚壁空洞、支气管播散与肺收缩
│  牵拉 → 肺门上提、垂柳征等；血管床受压/减少 → PVR↑、肺高压 → 右室后负荷↑，交R9
│  病理“开放”与当下排菌量、临床传染风险仍分开判断
│  〈慢性纤维空洞型：厚壁三层、上旧下新、垂柳征和肺心病〔部位/播散｜洞壁3层｜纤维化→4影像变化｜并发7组｜病理vs排菌传染性〕〉
└─ 坏死灶包裹、空洞入口阻塞后充填或多个病灶融合 → 结核球；胸膜受累是另一条渗出/增生支
   结核球不自动等于手术；胸水证据接R10，保留ADA与免疫状态条件
   〈结核球与结核性胸膜炎：纤维包裹还是胸膜渗出〔结核球定义｜来源3｜影像4｜鉴别/处理｜胸膜2型｜湿性病理｜干性病理〕〉

病原进入血流 → 按入血位置到肺内或全身；大量一次播散可形成急性粟粒病灶
影像“三均匀”描述这一分布；血播并非原发独有，也不是等到厚壁空洞之后才可能发生
〈血源播散与粟粒性结核：短时间大量入血与急性“三均匀”〔来源｜全身路径｜肺内大小｜影像3轴｜急/慢｜原发/继发边界〕〉
器官去向按传播路径解释：血流、吞入带菌痰、邻近直接蔓延及尿路/生殖道传播不能混为一条
肠、腹膜、肾、骨关节与脑膜在此保留病理身份和好发位置，完整专科诊疗后置
〈肺外结核去向图：本处学病理身份，专科诊疗后置〔来源总则/腹膜例外｜泌尿男生殖来源｜肠5轴｜腹膜触感｜女/淋巴结好发｜肾2征｜骨关节部位+3征｜脑膜2轴〕〉

病灶结构和炎症共同产生可观察的表现，观察不组成病程阶段
├─ 实变、纤维牵拉、胸水和局部气道变窄 → 各自的传声、叩诊、呼吸音和局限哮鸣
│  胸水积液区与上方受压肺的体征分开；小病灶可以体征少
│  〈体征随病变性质变化：实变、纤维收缩、胸水和局部气道狭窄〔小病灶｜实变4征｜纤维3方向｜胸水5方向｜局限哮鸣｜风湿3轴〕〉
├─ 炎症/毒血症 → 发热和全身症状；常见午后低热，危重病型可高热
│  严重毒血症的短程激素需与有效抗结核药合用，不能把退热代替控制病原
│  〈发热与全身症状：长期午后低热是主轴，危重病型可高热〔最常见症状｜热型/时段｜温度4档｜慢性低热4类｜高热2病型｜激素4原则｜全身3〕〉
│  热型比较旁查：先看日内波动，再分有热/无热持续小时还是天、是否渐升渐降
│  〈热型：先看24小时波动，再看有热/无热持续数小时还是数天〔规则热型5+不规则｜日波动2阈值｜有热/无热：小时vs天｜渐升渐降｜代表疾病〕〉
└─ 受累血管损伤 → 咯血；小量与大咯血有不同血管来源
   咯血后发热可来自结核播散、血块吸收、血块阻塞或继发细菌感染，按相应证据分辨
   〈咳痰、咯血与咯血后发热：同一事件有4种去向〔咳痰3阶段｜小咯血机制｜大咯血2来源｜后发热4因｜温度方向〕〉

临床判断把三类证据分别接回上述对象
├─ 影像看位置、形态和变化：渗出/播散可支持活动，钙化/纤维可提示修复
│  任何空洞都不能独立证明活动，钙化也不独立保证全部病灶静止；须与旧片、症状、病原及治疗合读
│  〈影像两层：先看好发位置，再看活动性多形性〔X线→CT｜部位3组｜活动3征｜修复2征｜空洞3壁｜液平边界〕〉
├─ PPD看感染后的迟发免疫反应：阳性不独立确诊结核病，免疫低下等情境阴性也不能排除
│  当前未给PPD毫米判定范围，精确阈值仍保留原HOLD
│  〈PPD：检出“感染过TB并能发生迟发反应”，不是直接确诊结核病〔致敏时程｜细胞/超敏型/抗原｜感染vs疾病｜价值人群｜阴弱原因10项〕〉
└─ 涂片看可检出的抗酸菌量；培养须结合鉴定，分子检测可提供病原和耐药证据
   活动与传染分别判断；涂阴仍可能传播，AFB阳性不独立完成TB菌种鉴定，培养/分子检测不必等涂阴才启动
   〈痰涂片、培养、活动性与传染性：两个坐标不能混〔涂片身份/阈值｜培养身份｜涂阳/涂阴｜菌阳｜菌阴定义｜无活动3全满足｜病理/内科开放边界〕〉

治疗接当前病原状态与药敏，而不把初治、复治、耐药排成必然升级
联合方案覆盖不同代谢菌群；早期、规律、全程、适量、联合、短程保留课程六原则
〈抗结核治疗六原则与A/B/C/D菌群〔原则6｜菌群4｜敏感药3｜休眠1｜全杀2｜半杀2｜抑菌2〕〉
药物的作用菌群与H/R/Z等毒性同时考虑；达到现有肝损伤等条件时评估停药/调整，不能只按药名机械完成疗程
〈H/R/Z/S/E：作用位置与主要不良反应〔5药全称｜杀/抑｜内外｜5不良｜肝毒3｜R肝功2阈值｜H神经毒处理〕〉
├─ 符合药敏初治活动性肺结核情境 → 课程强化/巩固方案；疗程不能外推所有TB或所有结节病
   〈初治活动性肺结核：2个月强化 + 4个月巩固〔每日方案｜强化/巩固｜间歇方案｜总疗程｜Z时段〕〉
└─ 复治/疑耐药 → 先获得药敏证据；RR/MDR按人群、耐药与方案适用条件分流
   课程9–12/18–20个月与已注明WHO版本的适宜短程方案分开，不称所有RR/MDR统一首选9–12个月
   〈复治、RR/MDR：先药敏，再按A/B/C组构建方案〔复治涂阳第1步｜R敏感去向｜RR/MDR定义｜短/长疗程｜A/B/C组｜组方3规则｜PAS机制〕〉

病例重建时合读症状、宿主、位置、形态、病原、活动/传染和治疗状态
一项影像或单次涂片不能替代整条判断；肺炎、脓肿、支扩与肿瘤沿各自证据比较
〈肺结核病例算法：症状—位置—形态—排菌—治疗状态〔症状｜位置｜形态｜活动｜传染｜病型｜化疗状态｜鉴别4病〕〉
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 传染源以排菌的空洞性肺结核为主，飞沫传播最常见；
2. 感染结核杆菌不等于已经发生结核病；
3. 结核杆菌不产毒素，致病与细胞壁成分及宿主免疫反应相关；
4. 多糖—免疫应答，蜡质—干酪坏死/空洞，蛋白质—PPD/皮肤红斑；
5. 结核结节4类细胞 + 中央干酪样坏死；
6. 原发复合征3部分、好发部位与淋巴/血道播散；
7. 继发结核好发部位、右肺尖、支气管播散、上旧下新、常有空洞；
8. AIDS合并TB：下叶、淋巴结、播散、少空洞/肉芽肿、PPD弱；
9. 继发性六型及其活动性；
10. 三种空洞：浸润型薄壁、干酪性肺炎无壁虫蚀、慢纤空厚壁三层；
11. 慢性纤维空洞型的典型病理开放形态、上叶纤维化、肺门抬高、垂柳征与肺心病；实际排菌/传染性仍据病原和治疗状态判断；
12. 急性粟粒性肺结核“三均匀”；
13. 影像中渗出、播散及新旧变化可提示活动，钙化/纤维条索可提示修复；任何空洞不独立证明活动，钙化亦不独立保证全部病灶静止；
14. PPD检测感染而非直接诊断结核病；免疫低下可假阴性；
15. 涂片提供排菌量/传染风险证据之一，培养结合鉴定，分子检测可提供病原及耐药证据；活动与传染分开合读，涂阴不保证不传播；

17. 抗结核六原则；A/B/C菌群敏感药；
18. H/R/Z/S/E主要不良反应和细胞内外杀菌身份；
19. 药敏初治肺TB课程方案2HRZE/4HR；复治先药敏；RR/MDR按适用条件选择，课程9–12/18–20个月与KP23所列WHO版本分开，不能视为统一首选；

# Unit A｜结核特异病理：免疫控制与变态损伤同时发生

## KP01｜传染、感染与发病：吸入TB不等于立刻得结核病

> **讲义定位 →** 病理 Lecture PDF P110、P114；内科 Lecture PDF P42  
> **Outline →** 病理 U013｜传染1–2；内科 U015｜PPD5  
> **主提示：** 传染源｜途径3｜易感｜炎症3变｜感染≠病｜潜伏/发病条件

### 1｜传染链

- 传染源：肺结核患者，尤其空洞性 / 排菌肺结核；
- 最常见传播：呼吸道飞沫；
- 其他途径：消化道、皮肤伤口等；
- 所有人可感，免疫低下者更易发病。

### 2｜进入后仍有两种状态

```text
感染TB
→ 病原被免疫局限、可处于休眠
→ 无临床症状
→ 结核感染，不一定称结核病

抵抗力下降 / 病灶活化
→ 病原繁殖、组织损伤和临床症状
→ 结核病
```

### 3｜仍然属于炎症

结核不同阶段可有：

- 变质；
- 渗出；
- 增生。

但其最有识别价值的病理身份是**慢性干酪性肉芽肿性炎**。

（易混：原发性肺结核的结核性淋巴管炎是感染后的播散，不是病原从外界进入肺的“淋巴感染途径”。）

## KP02｜结核杆菌细胞壁3成分：免疫、坏死/空洞与PPD

> **讲义定位 →** 病理 Lecture PDF P110；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜细胞壁1–2；内科 U014｜继发1；U015｜PPD7  
> **主提示：** 毒素｜细胞壁3成分/3效应｜超敏型｜免疫vs变态｜继发空洞机制

结核杆菌不靠外毒素 / 内毒素直接致病，当前 Study 将细胞壁成分与反应对应：

| 成分 | 主要身份 |
|---|---|
| 多糖 | 血清反应等免疫应答 |
| 蜡质 | 干酪样坏死、空洞 |
| 蛋白质 | 皮肤红斑、PPD阳性 |

```text
免疫反应
→ 有利于限制和控制TB

变态 / 超敏反应
→ 造成干酪样坏死与组织破坏
```

二者在结核中常同时发生；讲义所问蜡质/蛋白质相关超敏反应归于Ⅳ型迟发型，由致敏T细胞参与。表格是课程对应关系，不能理解为每种成分只参与唯一一种生物效应。

### 为什么继发性结核更常有空洞

```text
原发：初次感染时尚未建立特异性免疫，随后可逐渐形成
→ 早期与继发时的致敏背景不同
→ 空洞少

继发：已有特异性免疫
→ 变态反应也明显
→ 干酪坏死、空洞多
```

AIDS时免疫严重下降，变态反应随之减弱，因此又出现少空洞、少肉芽肿和PPD弱的方向。

## KP03｜结核结节：4类细胞围住中央彻底凝固性坏死

> **讲义定位 →** 病理 Lecture PDF P110  
> **Outline →** 病理 U013｜肉芽肿1–3

### 1｜四类细胞

1. 上皮样 / 类上皮细胞；
2. Langhans / 朗汉斯巨细胞；
3. 大量淋巴细胞；
4. 少量反应性增生的成纤维细胞。

```text
单核-巨噬细胞吞噬TB但不能彻底消化
```

Langhans巨细胞胞核常在周边呈马蹄 / U形排列。

- 干燥；
- 淡黄；

镜下：

# Unit B｜原发、继发与免疫低下：三种宿主状态

## KP04｜原发性肺结核：初次感染形成“肺灶—淋巴管—肺门结”哑铃

> **讲义定位 →** 病理 Lecture PDF P111；内科 Lecture PDF P42  
> **Outline →** 病理 U013｜原发1–3；内科 U015｜原发部位4；U013｜好发部位4  
> **主提示：** 定义/人群｜复合征3｜部位｜淋巴结侧别｜影像｜播散2｜结局方向

### 1｜身份

- 机体初次感染TB；
- 尚无特异性免疫；
- 儿童多见。

### 2｜原发复合征三部分

```text
肺内原发灶
+ 结核性淋巴管炎
+ 肺门淋巴结结核
```

- 肺内原发灶：上叶下部或下叶上部近胸膜处；
- 肺门淋巴结多单侧肿大，可有干酪样坏死；
- X线可呈哑铃状影。

### 3｜播散

```text
无成熟特异免疫
→ TB在淋巴道 / 血道中较易播散
→ 可形成粟粒性与肺外结核
```

多数可随细胞免疫建立而纤维化、钙化和自然愈合；营养不良或其他感染时可进展。

（易混：结节病常见双侧肺门淋巴结肿大；原发复合征多为单侧肺门淋巴结病变。）

## KP05｜继发性肺结核：上叶、支气管播散、上旧下新和空洞

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜继发1–2；内科 U015｜部位2；U013｜好发部位5

### 1｜来源与人群

### 2｜好发部位

### 3｜传播和空间特征

```text
主要沿支气管播散
```

| 范围 | 易肺外播散 | 多局限肺内 |

## KP06｜AIDS合并肺结核：继发病人呈现“原发型”影像和免疫反应

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P42、P45  
> **Outline →** 病理 U013｜继发3；内科 U015｜部位3、PPD9；U013｜好发部位6  
> **主提示：** 部位｜淋巴结2｜累及2腔｜粟粒｜空洞/肉芽肿｜PPD｜原因链

免疫系统受损后：

- 下叶病变多；
- 肺门、纵隔淋巴结肿大；
- 胸膜 / 心包渗出和粟粒影可多见；
- 多部位播散；
- 空洞少；
- 肉芽肿少；
- PPD常阴性或弱阳性。

```text
细胞免疫数量 / 功能下降
├─ 对TB的局限能力下降 → 更易播散，肉芽肿组织可少
└─ 相关迟发免疫反应减弱 → 干酪坏死 / 空洞可少，PPD可弱
下叶、肺门 / 纵隔淋巴结和多部位表现是该宿主背景下的课程分布倾向
```

这些是同一宿主背景下可并存的结果；不要把下肺分布解释成少肉芽肿、少空洞的先后原因。

（特殊：当前 Study 还提示晚期HIV淋巴细胞显著减少时，结核性胸水ADA未必升高；只作为低频接口，不据此单独排除结核。）

内科印刷P45还保留HIV/AIDS合并肺结核“药物不良反应较多”的临床提示；它提醒治疗时同时关注药物安全，具体药物毒性仍在KP21展开，不由少空洞或PPD弱推出用药更安全。

## KP08｜局灶型 vs 浸润型：一个以增生局限，一个以渗出活动

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发5–7；内科 U014｜继发3–4  
> **主提示：** 局灶vs浸润：部位/影像/病理/活动性｜薄壁空洞｜后续3去向

### 局灶型

- 肺尖；
- 境界清楚的结节；
- 以增生性病变为主；
- TB数量少、宿主免疫强；
- 多无症状；
- 非活动性，常见于较早期局限阶段。

### 浸润型

- 肺尖和锁骨下；
- 以渗出为主；
- 边缘模糊、密度不均的云雾 / 云絮影；
- 可呈斑点、斑片或实变；
- 可形成薄壁空洞；
- 最常见的活动性继发性肺结核。

去向：

```text
经支气管播散、坏死加重
→ 干酪性肺炎

空洞经久不愈、广泛纤维化
→ 慢性纤维空洞型

干酪灶被纤维包裹
→ 结核球
```

## KP09｜干酪性肺炎与三种结核空洞：薄壁、无壁、厚壁

> **讲义定位 →** 病理 Lecture PDF P113；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜继发8；内科 U014｜继发5  
> **主提示：** 危重线索｜实变｜空洞型3｜链球菌对比｜液平边界

### 干酪性肺炎

- 病情危重；
- 可有急性高热和明显中毒症状；
- 可呈大叶性实变或斑片状病变；
- 可出现虫蚀样 / 无壁空洞。

### 三种空洞

```text
浸润型
→ 薄壁空洞

干酪性肺炎
→ 无壁 / 虫蚀样空洞

慢性纤维空洞型
→ 厚壁空洞
```

（易混：肺炎链球菌肺炎可呈大叶实变，典型病例通常不形成坏死空洞；不能据此绝对排除坏死性并发症，回看R5 KP09。干酪性肺炎因干酪坏死可有无壁空洞。）

## KP10｜慢性纤维空洞型：厚壁三层、上旧下新、垂柳征和肺心病

> **讲义定位 →** 病理 Lecture PDF P113；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发9–10；内科 U014｜继发6  
> **主提示：** 部位/播散｜洞壁3层｜纤维化→4影像变化｜并发7组｜病理vs排菌传染性

### 1｜厚壁空洞三层

由内向外：

1. 干酪样坏死物 + 大量TB；
2. 肉芽组织；
3. 纤维结缔组织。

本质仍是：

```text
坏死
→ 肉芽组织机化
→ 外层纤维化
```

### 2｜肺内播散

空洞与支气管相通：

- 同侧或对侧可见大小不等病灶；
- 支气管播散；
- 上旧下新。

### 3｜纤维化影像

```text
上叶广泛纤维化收缩
→ 肺体积缩小、变形
→ 肺门抬高
→ 肺纹理下垂呈垂柳样
→ 纵隔向患侧移位
```

### 4｜并发症

- 肺气肿；
- 胸膜增厚粘连；
- 气胸 / 脓气胸；
- 大咯血；
- 喉结核；
- 肠结核；
- 慢性肺心病。

```text
广泛纤维化压迫肺血管
→ PVR↑
→ 肺高压
→ 肺心病
```

### 5｜传染性边界

- 病理学：慢性纤维空洞型是典型开放性、传染性强的病型；
- 内科学：是否开放 / 有传染性，以痰涂片阳性、排菌量大为核心。

两者是不同学科的观察层级，不强行改写成同一句定义。

## KP11｜结核球与结核性胸膜炎：纤维包裹还是胸膜渗出

> **讲义定位 →** 病理 Lecture PDF P113–114；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发11–12；内科 U014–U015｜继发7–8  
> **主提示：** 结核球定义｜来源3｜影像4｜鉴别/处理｜胸膜2型｜湿性病理｜干性病理

### 1｜结核球 / 结核瘤

> 孤立、境界清楚、由纤维组织包裹的干酪样坏死灶。

形成来源：

1. 浸润型干酪坏死灶被纤维包裹；
2. 空洞引流支气管阻塞，空洞被干酪物填充；
3. 多个结核灶融合。

当前内科 Study 影像：

- 边界清楚；
- 可钙化、分叶；
- 可形成空洞；
- 周围可有卫星灶。

| 类型 | 病理身份 |
|---|---|
| 湿性，多见 | 浆液纤维蛋白性渗出性炎，形成胸腔积液 |
| 干性 | 增生性病变 |

可遗留胸膜增厚、粘连。

## KP12｜血源播散与粟粒性结核：短时间大量入血与急性“三均匀”

### 1｜全身播散路径

```text
TB在短时间内一次或反复多次大量进入肺静脉分支
→ 左心
→ 体循环
→ 肺、肝、脾、脑膜等全身器官
→ 急性全身粟粒性结核
```

也可形成慢性全身粟粒性结核。

### 2｜急性粟粒性肺结核

- 属于血源播散性肺结核；
- 双肺弥漫约2 mm粟粒影；
- **分布、大小、密度三均匀。**

病理PDF P114还列慢性粟粒性肺结核，但此接受范围未展开它的时间、影像细节；保留该去向，不由急性典型“三均匀”推定所有血源播散都具有同一表现。

（易混：肿瘤肺转移通常大小不等；血源性肺脓肿多为双肺外周多发空洞 / 液气囊腔。）

（边界：原发性肺结核更容易经血道播散，但临床粟粒性结核也可见于继发性肺结核；不要把“更易发生”写成“只能来自”。）

## KP13｜肺外结核去向图：本处学病理身份，专科诊疗后置

> **讲义定位 →** 病理 Lecture PDF P115  
> **Outline →** 病理 U013｜肺外3–9  
> **主提示：** 来源总则/腹膜例外｜泌尿男生殖来源｜肠5轴｜腹膜触感｜女/淋巴结好发｜肾2征｜骨关节部位+3征｜脑膜2轴

### 1｜总规律与来源边界

- 肺外结核多继发于肺结核；
- 结核性腹膜炎常由腹腔内结核灶直接蔓延；
- 泌尿系及男性生殖系结核多继发于肾结核。

### 2｜器官身份表

| 器官 | 当前病理 Primary |
|---|---|
| 肠结核 | 多继发于空洞性肺结核、反复吞入含TB痰；回盲部；溃疡型多；环形溃疡长轴与肠长轴垂直；易肠梗阻 |
| 结核性腹膜炎 | 揉面感 / 柔韧感；常由肠结核、肠系膜淋巴结结核、输卵管结核直接蔓延 |
| 女性生殖系统 | 输卵管结核最常见 |
| 淋巴结 | 颈部淋巴结结核最常见 |
| 肾结核 | 慢性膀胱刺激征；肾自截 |
| 骨与关节 | 腰椎结核最常见；椎体破坏、椎间隙变窄、冷/寒性脓肿 |
| 结核性脑膜炎 | 儿童多见；脑底病变最明显 |

### 3｜把形态名称接回原因

- 肠黏膜淋巴管呈环形走向，解释溃疡长轴与肠长轴垂直；随后环形瘢痕收缩可使肠腔狭窄。这是“环形溃疡—肠梗阻”的结构联系，不是只背一个好发并发症。
- 肾病灶排出的含菌尿刺激膀胱，因此可出现“病变在肾、表现像膀胱”。广泛钙化和尿路闭塞后，含菌尿不再下行，膀胱刺激可减轻、尿培养可阴性，称肾自截；这种表面改善不能当作肾病灶痊愈。
- 课程用局部红、热不显著帮助理解“冷脓肿”；“冷”不等于没有结核性炎症。腹膜揉面感也非结核独有，原Source同时列癌性腹膜炎与血性腹水作比较。

这些解释取自病理PDF P115，只补本页病理身份的原因，不提前展开专科检查与治疗。

### 4｜去重边界

- 肾结核完整器官诊疗在泌尿系统 Recall本页共同结核模型后建立；
- 骨关节结核完整骨科模型后置神经—骨科；
- 肠结核与腹膜炎完整消化模型后置消化；
- 本 Block 不重复造专科治疗路径，但病理 U013 的知识身份已全部归位。

## KP16｜体征随病变性质变化：实变、纤维收缩、胸水和局部气道狭窄

> **讲义定位 →** 内科 Lecture PDF P40  
> **Outline →** 内科 U014｜临床7–11  
> **主提示：** 小病灶｜实变4征｜纤维3方向｜胸水5方向｜局限哮鸣｜风湿3轴

### 1｜病变小时

可无明显体征。

### 2｜渗出 / 坏死范围大

- 浊音或实音；
- 湿啰音；
- 语音震颤增强；
- 异常支气管呼吸音或支气管肺泡呼吸音。

```text
胶原收缩
→ 患侧胸廓塌陷
→ 肺体积缩小
→ 纵隔向患侧移位
```

### 4｜胸腔积液较多

- 患侧胸廓饱满；
- 纵隔向健侧；

> **局限性哮鸣音。**

### 7｜结核性风湿症

- 青少年女性；
- 四肢大关节；
- 受累关节附近环形红斑或结节性红斑。

## KP17｜影像两层：先看好发位置，再看活动性多形性

> **讲义定位 →** 内科 Lecture PDF P42；病理 Lecture PDF P111–114  
> **Outline →** 内科 U015｜影像1–4；U013｜好发部位4–6


## KP18｜PPD：检出“感染过TB并能发生迟发反应”，不是直接确诊结核病

> **讲义定位 →** 内科 Lecture PDF P42  
> **Outline →** 内科 U015｜PPD5–9  
> **主提示：** 致敏时程｜细胞/超敏型/抗原｜感染vs疾病｜价值人群｜阴弱原因10项

### 1｜机制

```text
感染TB后4–8周
→ 形成致敏T淋巴细胞
→ 皮肤再次接触TB抗原
→ IV型迟发型变态反应
→ PPD阳性
```

当前 Study 将PPD皮肤反应与结核杆菌细胞壁蛋白质相关联。

### 2｜检测身份

> **PPD用于判断是否感染过结核杆菌，不直接等同于已经发生结核病。**

其提示结核病价值在婴幼儿、儿童更大，尤其未接种卡介苗者。内科印刷P42同时提示结果受卡介苗和既往感染影响，因此须合读接种史、病史和其他证据，不能把任意PPD阳性独立当作当前结核病。

### 3｜阴性 / 弱阳性不能排除

常见于：

- 长期糖皮质激素；
- 免疫抑制剂；
- 癌症；
- 严重细菌感染；
- 粟粒性结核；
- 麻疹；
- 水痘；
- HIV；
- 结核性脑膜炎；
- 营养不良。

可按原名单分三组核对，成员不增不减：用药2项（长期糖皮质激素、免疫抑制剂）；感染6项（严重细菌感染、粟粒性结核、麻疹、水痘、HIV、结核性脑膜炎）；其余2项（癌症、营养不良）。分组帮助恢复完整10项，不替代具体答案或把所有阴性都归为这10项。

共同逻辑：

```text
免疫反应能力不足
→ 皮肤不能形成足够迟发反应
→ 假阴性 / 弱阳性
```

## KP19｜痰涂片、培养、活动性与传染性：两个坐标不能混

> **讲义定位 →** 内科 Lecture PDF P42–43；病理 Lecture PDF P110、P113  
> **Outline →** 内科 U015｜确诊10–15  
> **主提示：** 涂片身份/阈值｜培养身份｜涂阳/涂阴｜菌阳｜菌阴定义｜无活动3全满足｜病理/内科开放边界

### 1｜痰涂片

- 讲义列“确诊首选”；实际抗酸涂片是快速线索，不能单独鉴定结核分枝杆菌，须区别非结核分枝杆菌；
- 快速；
- 当痰内约 `5000–10000个抗酸杆菌/mL` 可阳性；
- 当前 Study：涂阳表示排菌量大、具有传染性，称开放性肺结核；
- 治愈涂阳患者是降低传播的重要措施。

### 2｜痰培养

- 确诊金标准；
- 鉴定为结核分枝杆菌复合群的培养阳性表示菌阳，支持活动性结核；
- 可出现培养阳性但涂片阴性。讲义把涂阴列作“无传染性”，这一绝对结论应纠正：其传播风险通常较低，但仍可传播；不能据此单独取消防护。
- 现代诊断须纳入快速核酸检测及耐药检测；涂阳也仍需培养/菌种与药敏信息，不是“只有涂阴才培养”。

### 3｜菌阴性肺结核

```text
3次痰涂片阴性
+ 1次痰培养阴性
+ 典型临床表现
+ 典型影像
+ PPD强阳性
→ 菌阴性肺结核
```

以上是讲义菌阴诊断简化组合；临床不能把PPD强阳性当必备确诊条件，也不能由“3涂1培阴性”排除结核。应综合合格取材、分子检测、影像演变、必要的组织学及替代诊断判断。

### 4｜讲义无活动性识别组合

- 无症状；
- 痰检查不排菌；
- X线仅硬结、钙化、纤维化等修复表现。

这些条件用于识别讲义典型静止病灶；不满足全部条件不等于必然活动性结核，应进一步明确原因。确立活动性结核后及时选择有效治疗，并评估传播风险。

### 5｜学科口径边界

```text
病理学开放性
→ 典型指慢性纤维空洞型，与外界相通

内科学开放性
→ 痰涂片阳性、排菌量大
```

一个按病理结构，一个按临床排菌证据，不互相抹平。

## KP22｜初治活动性肺结核：2个月强化 + 4个月巩固

> **讲义定位 →** 内科 Lecture PDF P43  
> **Outline →** 内科 U016｜初治7  
> **主提示：** 每日方案｜强化/巩固｜间歇方案｜总疗程｜Z时段

### 药物敏感肺结核的课程每日方案

```text
2HRZE / 4HR
```

- 前2个月：H + R + Z + E，强化期；
- 后4个月：H + R，巩固期。

### 间歇方案

```text
2H3R3Z3E3 / 4H3R3
```

数字3表示每周3次；这是讲义所列方案标记，不能自行把每日方案减为间歇服药。适用人群、耐药风险与督导条件须另行评估，尤其不能直接泛用于HIV等高风险患者。

讲义“结核病和结节病均至少6个月”不能作为两病通则：这里的6个月是特定药敏肺结核方案；其他结核方案可不同，许多结节病患者无需药物治疗，需要治疗者按受累器官和反应决定疗程（见R8）。

## KP23｜复治、RR/MDR：先药敏，再按A/B/C组构建方案

> **讲义定位 →** 内科 Lecture PDF P44  
> **Outline →** 内科 U016｜复治8–10  
> **主提示：** 复治涂阳第1步｜R敏感去向｜RR/MDR定义｜短/长疗程｜A/B/C组｜组方3规则｜PAS机制

### 1｜复治涂阳

> **先做药物敏感试验。**

- 讲义列利福平敏感者按初治方案；实际还须确认其他药物敏感性、既往疗效及依从性，利福平敏感不等于所有一线药敏感；
- RR-TB：利福平耐药；
- MDR-TB：至少耐异烟肼 + 利福平。

### 2｜疗程

- 讲义短程方案：9–12个月；
- 讲义长程方案：至少4种药，18–20个月。

版本校准：WHO 2025已纳入适合人群的6个月全口服方案（如BPaLM、BDLLfxC），以及相应9个月方案。因此“短程首选＝9–12个月”只能作该课程口径，不能冒充当前完整治疗推荐；实际依药敏、既往用药及方案适用条件选取。

### 3｜药物组别

| 组别 | 当前 Study 药物 |
|---|---|
| A组，首选 | 左氧氟沙星 / 莫西沙星；贝达喹啉；利奈唑胺 |
| B组，次选 | 氯法齐明；环丝氨酸 |
| C组，备选 | 乙胺丁醇、德拉马尼、吡嗪酰胺、亚胺培南-西司他丁 / 美罗培南、阿米卡星、链霉素、卷曲霉素、丙硫异烟胺、PAS等 |

以下A/B/C组方为讲义长程方案框架，不用于自行拼接上述标准化6个月方案。

组方原则：

```text
所有可用A组药 + 至少1种B组药

若A组仅能选1–2种
→ 使用所有B组药

A+B仍不能组成方案
→ 加C组药
```

### 4｜PAS机制

```text
PAS结构类似PABA
→ 干扰叶酸代谢（课程简化为竞争性抑制二氢蝶酸合酶）
→ 四氢叶酸生成受损
→ 一碳单位与核苷酸代谢受阻
→ 抑菌
```

机制校准：PAS研究支持其经叶酸合成途径活化为抗代谢物并抑制二氢叶酸还原酶；不能把它与磺胺的直接竞争抑制完全等同。上述保留课程主线并显式标出差异，未在此扩写完整耐药结核处方。

# Unit G｜整合：活动、传染、空洞与鉴别

## KP25｜肺结核病例算法：症状—位置—形态—排菌—治疗状态

> **讲义回看 →** R7全 Block；R5–R6  
> **Outline →** 病理 U013 + 内科 U013–U016综合  
> **主提示：** 症状｜位置｜形态｜活动｜传染｜病型｜化疗状态｜鉴别4病

### Step 1｜先识别结核概率

```text
长期低热 / 午后低热
+ 盗汗、消瘦
+ 咳嗽、咯血
+ 上肺 / 锁骨区病变
→ 高度怀疑
```

### Step 2｜判宿主与病型

- 儿童、原发复合征、淋巴结 / 播散：原发；
- 成人、上叶、空洞、支气管播散：继发；
- HIV、下叶、淋巴结、多部位、少空洞：免疫低下型。

### Step 3｜看影像活动性

- 渗出；
- 空洞；
- 播散；
- 还是仅钙化 / 纤维条索。

### Step 4｜分开两个证据问题

```text
有没有活动TB？
→ 症状 + 影像演变 + 分子/培养等病原证据 + 治疗史

有没有传染性？
→ 排菌证据、咳嗽/病灶及治疗情况综合；涂阴不等于零风险
```

### Step 5｜判断治疗状态

- 药物敏感肺结核的课程方案：`2HRZE/4HR`；
- 复治涂阳：先药敏；
- RR/MDR：依据药敏与适用条件选择有效方案，区分课程长短程与WHO更新方案。

### Step 6｜四类肺内鉴别

| 疾病 | 更支持线索 |
|---|---|
| 普通肺炎 | 急性寒战高热、下叶实变、链球菌一般无空洞 |
| 肺脓肿 | 误吸 / 化脓灶、高热脓臭痰、液气平厚壁空洞 |
| 支气管扩张 | 多年大量脓痰、固定湿啰音、薄壁支气管囊腔 |
| 肺癌 | 肿块、吸烟、阻塞/局限哮鸣、器官肿瘤模型后置R11 |

## 3｜高密度比较表

### 原发 vs 继发 vs HIV合并TB

| 轴 | 原发性 | 继发性 | HIV / AIDS合并TB |
|---|---|---|---|
| 免疫背景 | 初次感染，无特异免疫 | 已有免疫，内源复发多 | 免疫严重下降 |
| 人群 | 儿童 | 成人 | HIV感染者 |
| 部位 | 上叶下部 / 下叶上部近胸膜 | 上叶尖后、下叶背段/后基底 | 下叶多 |
| 淋巴结 | 单侧肺门结常见 | 非主轴 | 肺门、纵隔结常见 |
| 播散 | 淋巴 / 血道 | 支气管 | 血道、多部位 |
| 空洞 | 少 | 多 | 少 |
| 肉芽肿 | 可随免疫建立形成 | 明显 | 少 |
| PPD | 可转阳 | 常可阳性 | 阴性 / 弱阳性多 |

### 继发性病型最小坐标

| 病型 | 活动性 | 边界 | 空洞 / 影像核心 |
|---|---|---|---|
| 局灶型 | 非活动 | 清楚肺尖结节，增生为主 | 通常无典型活动空洞 |
| 浸润型 | 最常见活动 | 模糊、密度不均、云雾/云絮 | 薄壁空洞 |
| 干酪性肺炎 | 危重活动 | 大叶/斑片实变、明显毒血症 | 无壁虫蚀样 |
| 慢性纤维空洞型 | 慢性活动、排菌强 | 广泛纤维化、肺门抬高、垂柳征 | 厚壁三层 |
| 结核球 | 多为局限 / 晚期包裹 | 边界清楚、钙化/卫星灶 | 可有空洞 |
| 结核性胸膜炎 | 胸膜病型 | 湿性多、干性少 | 胸水或增生 |
