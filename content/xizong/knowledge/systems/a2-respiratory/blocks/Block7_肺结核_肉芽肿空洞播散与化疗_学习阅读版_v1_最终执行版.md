## 0｜这个 Block 到底解决什么

结核的难点不只是病型多，而是**免疫既在控制病原，也在制造组织损伤**：

```text
结核杆菌进入
→ 单核-巨噬细胞吞噬但不能彻底清除
→ 细胞免疫把病灶局限成肉芽肿
→ 变态反应造成干酪样坏死
→ 坏死物被支气管排出后形成空洞
→ 病原可沿支气管、淋巴道或血道播散
→ 病变可修复、钙化，也可持续排菌和传染
```

因此必须同时回答三组问题：

```text
病理身份
肉芽肿、干酪坏死、空洞、纤维化、播散

临床状态
感染还是结核病？活动还是非活动？有无传染性？

治疗状态
初治还是复治？药物作用哪一菌群？是否耐药？
```

### 本 Block 的总任务

> **看到低热盗汗、咯血或上肺空洞时，能从结核特异免疫病理推到病型、影像、排菌证据、活动性、传染性和化疗方案。**

## 1｜总 Framework

```text
A｜病原进入与免疫建立

空洞性肺结核排菌
→ 飞沫为主传播
→ 初次感染者无特异免疫
→ 4–8周后建立致敏T细胞与细胞免疫

        ↓

B｜结核特异病理

巨噬细胞吞噬TB
→ 上皮样细胞 + Langhans巨细胞
+ 淋巴细胞 + 少量成纤维细胞
→ 结核肉芽肿

蜡质相关变态反应
→ 干酪样坏死
→ 坏死物排出形成空洞

        ↓

C｜原发与继发分流

原发：儿童、初次感染、免疫未建立
→ 原发复合征
→ 淋巴 / 血道播散倾向

继发：成人、内源复发为主、已有免疫
→ 上叶优势、支气管播散
→ 空洞、上旧下新、局限肺内

免疫严重低下 / AIDS
→ 又趋向原发型：下叶、淋巴结、播散、少空洞、PPD弱

        ↓

D｜继发性六型

局灶型（非活动）
→ 浸润型（最常见活动）
→ 干酪性肺炎（危重）
→ 慢性纤维空洞型（厚壁、强传染、纤维化）
→ 结核球
→ 结核性胸膜炎

        ↓

E｜证据分层

影像：位置 + 多形性 + 活动/修复
PPD：是否感染、免疫是否能反应
痰涂片：排菌量 / 传染性
痰培养：活动性 / 金标准

        ↓

F｜标准化疗

早期、规律、全程、适量、联合、短程
→ 按菌群状态选择杀菌药
→ 初治方案
→ 复治先药敏
→ RR/MDR按A/B/C组构建方案
```

## 2｜Memory Routing

### MI-G｜第一轮必须即时掌握

1. 传染源以排菌的空洞性肺结核为主，飞沫传播最常见；
2. 感染结核杆菌不等于已经发生结核病；
3. 结核杆菌不产毒素，致病与细胞壁成分及宿主免疫反应相关；
4. 多糖—免疫应答，蜡质—干酪坏死/空洞，蛋白质—PPD/皮肤红斑；
5. 结核结节4类细胞 + 中央干酪样坏死；
6. 原发复合征3部分、好发部位与淋巴/血道播散；
7. 继发结核好发部位、右肺尖、支气管播散、上旧下新、常有空洞；
8. AIDS合并TB：下叶、淋巴结、播散、少空洞/肉芽肿、PPD弱；
9. 继发性六型及其活动性；
10. 三种空洞：浸润型薄壁、干酪性肺炎无壁虫蚀、慢纤空厚壁三层；
11. 慢性纤维空洞型：开放、排菌强、上叶纤维化、肺门抬高、垂柳征、肺心病；
12. 急性粟粒性肺结核“三均匀”；
13. 影像活动性证据：渗出、任何空洞、播散；修复证据：钙化、纤维条索；
14. PPD检测感染而非直接诊断结核病；免疫低下可假阴性；
15. 痰涂片决定当前 Study 的传染性，痰培养是确诊金标准并支持活动性；
16. 活动性与传染性不是同一维度；
17. 抗结核六原则；A/B/C菌群敏感药；
18. H/R/Z/S/E主要不良反应和细胞内外杀菌身份；
19. 初治 `2HRZE/4HR`；复治涂阳先药敏；RR/MDR首选短程9–12个月；
20. 其他器官结核的“来源—好发—特征”病理身份。

### MI-D｜进入 MarginNote 3 卡片流

- 体温分度与五类热型；
- PPD假阴性完整名单；
- 痰涂片阳性菌量阈值；
- 初治间歇方案；
- H/R/Z/S/E全部不良反应；
- RR/MDR A/B/C组药物清单与疗程；
- 结核球形成来源；
- 各肺外结核的精确形态；
- 结核性风湿症、胸水ADA等低频接口。

# Unit A｜结核特异病理：免疫控制与变态损伤同时发生

## KP01｜传染、感染与发病：吸入TB不等于立刻得结核病

> **讲义定位 →** 病理 Lecture PDF P110、P114；内科 Lecture PDF P42  
> **Outline →** 病理 U013｜传染1–2；内科 U015｜PPD5  
> **主提示：** 传染源｜途径3｜易感｜炎症3变｜感染≠病｜潜伏/发病条件

### 1｜传染链

- 传染源：肺结核患者，尤其空洞性 / 排菌肺结核；
- 最常见传播：呼吸道飞沫；
- 其他途径：消化道、皮肤伤口等；
- 所有人可感，免疫低下者更易发病。

### 2｜进入后仍有两种状态

```text
感染TB
→ 病原被免疫局限、可处于休眠
→ 无临床症状
→ 结核感染，不一定称结核病

抵抗力下降 / 病灶活化
→ 病原繁殖、组织损伤和临床症状
→ 结核病
```

### 3｜仍然属于炎症

结核不同阶段可有：

- 变质；
- 渗出；
- 增生。

但其最有识别价值的病理身份是**慢性干酪性肉芽肿性炎**。

（易混：原发性肺结核的结核性淋巴管炎是感染后的播散，不是病原从外界进入肺的“淋巴感染途径”。）

## KP02｜结核杆菌细胞壁3成分：免疫、坏死/空洞与PPD

> **讲义定位 →** 病理 Lecture PDF P110；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜细胞壁1–2；内科 U014｜继发1；U015｜PPD7  
> **主提示：** 毒素？｜细胞壁3成分→3效应｜超敏型｜免疫 vs 变态｜继发空洞为何多

结核杆菌不靠外毒素 / 内毒素直接致病，当前 Study 将细胞壁成分与反应对应：

| 成分 | 主要身份 |
|---|---|
| 多糖 | 血清反应等免疫应答 |
| 蜡质 | 干酪样坏死、空洞 |
| 蛋白质 | 皮肤红斑、PPD阳性 |

```text
免疫反应
→ 有利于限制和控制TB

变态 / 超敏反应
→ 造成干酪样坏死与组织破坏
```

二者在结核中常同时发生。

### 为什么继发性结核更常有空洞

```text
原发：尚无特异性免疫
→ 变态反应较弱
→ 空洞少

继发：已有特异性免疫
→ 变态反应也明显
→ 干酪坏死、空洞多
```

AIDS时免疫严重下降，变态反应随之减弱，因此又出现少空洞、少肉芽肿和PPD弱的方向。

## KP03｜结核结节：4类细胞围住中央彻底凝固性坏死

> **讲义定位 →** 病理 Lecture PDF P110  
> **Outline →** 病理 U013｜肉芽肿1–3  
> **主提示：** 细胞4｜来源链｜巨细胞核形｜中央坏死｜大体4词｜镜下2词

### 1｜四类细胞

1. 上皮样 / 类上皮细胞；
2. Langhans / 朗汉斯巨细胞；
3. 大量淋巴细胞；
4. 少量反应性增生的成纤维细胞。

来源链：

```text
单核-巨噬细胞吞噬TB但不能彻底消化
→ 转为上皮样细胞
→ 聚集并融合
→ Langhans多核巨细胞
```

Langhans巨细胞胞核常在周边呈马蹄 / U形排列。

### 2｜中央干酪样坏死

大体：

- 干燥；
- 淡黄；
- 细腻；
- 质地较实。

镜下：

> **彻底的凝固性坏死，无原组织轮廓，呈无结构嗜酸性红染颗粒物。**

（易混：一般凝固性坏死可保留轮廓；干酪样坏死是“彻底的凝固性坏死”，不保留结构。）

# Unit B｜原发、继发与免疫低下：三种宿主状态

## KP04｜原发性肺结核：初次感染形成“肺灶—淋巴管—肺门结”哑铃

> **讲义定位 →** 病理 Lecture PDF P111；内科 Lecture PDF P42  
> **Outline →** 病理 U013｜原发1–3；内科 U015｜原发部位4；U013｜好发部位4  
> **主提示：** 定义/人群｜复合征3｜部位｜淋巴结侧别｜影像｜播散2｜结局方向

### 1｜身份

- 机体初次感染TB；
- 尚无特异性免疫；
- 儿童多见。

### 2｜原发复合征三部分

```text
肺内原发灶
+ 结核性淋巴管炎
+ 肺门淋巴结结核
```

- 肺内原发灶：上叶下部或下叶上部近胸膜处；
- 肺门淋巴结多单侧肿大，可有干酪样坏死；
- X线可呈哑铃状影。

### 3｜播散

```text
无成熟特异免疫
→ TB在淋巴道 / 血道中较易播散
→ 可形成粟粒性与肺外结核
```

多数可随细胞免疫建立而纤维化、钙化和自然愈合；营养不良或其他感染时可进展。

（易混：结节病常见双侧肺门淋巴结肿大；原发复合征多为单侧肺门淋巴结病变。）

## KP05｜继发性肺结核：上叶、支气管播散、上旧下新和空洞

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜继发1–2；内科 U015｜部位2；U013｜好发部位5  
> **主提示：** 来源2｜人群｜部位3｜右/左｜播散｜空间4特征｜空洞｜原发对比

### 1｜来源与人群

- 再次外源感染；或
- 静止原发灶内源复发，更常见；
- 成人，尤其抵抗力下降者；
- 已有特异性免疫。

### 2｜好发部位

> **上叶尖后段、下叶背段和后基底段；病变常从右肺尖开始。**

### 3｜传播和空间特征

```text
主要沿支气管播散
→ 肺内为主
→ 上部病灶较旧、下部播散灶较新
→ 上重下轻、上旧下新
→ 常有空洞
```

| 轴 | 原发性 | 继发性 |
|---|---|---|
| 宿主 | 初次感染、无特异免疫 | 已有免疫，内源复发为主 |
| 人群 | 儿童 | 成人 |
| 部位 | 上叶下部 / 下叶上部近胸膜 | 上叶尖后、下叶背段/后基底 |
| 播散 | 淋巴、血道 | 支气管 |
| 空洞 | 少 | 多 |
| 范围 | 易肺外播散 | 多局限肺内 |

## KP06｜AIDS合并肺结核：继发病人呈现“原发型”影像和免疫反应

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P42、P45  
> **Outline →** 病理 U013｜继发3；内科 U015｜部位3、PPD9；U013｜好发部位6  
> **主提示：** 部位｜淋巴结2｜累及2腔｜粟粒｜空洞/肉芽肿｜PPD｜原因链

免疫系统受损后：

- 下叶病变多；
- 肺门、纵隔淋巴结肿大；
- 胸膜 / 心包渗出和粟粒影可多见；
- 多部位播散；
- 空洞少；
- 肉芽肿少；
- PPD常阴性或弱阳性。

```text
免疫细胞减少
→ TB更易随血流播散至血流丰富的下肺
→ 不能有效形成肉芽肿
→ 变态反应也弱
→ 干酪坏死 / 空洞减少
```

（特殊：当前 Study 还提示晚期HIV淋巴细胞显著减少时，结核性胸水ADA未必升高；只作为低频接口，不据此单独排除结核。）

# Unit C｜继发性肺结核六型：一条“渗出—坏死—空洞—纤维化”路线

## KP07｜六型总路线：活动性不是按名字长短，而看渗出、空洞与播散

> **讲义定位 →** 病理 Lecture PDF P112–114；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发4；内科 U014｜继发2–3  
> **主提示：** 六型｜非活动1｜最常见活动1｜危重1｜开放1｜胸膜2型

继发性肺结核六型：

1. 局灶型肺结核；
2. 浸润型肺结核；
3. 干酪性肺炎；
4. 慢性纤维空洞型肺结核；
5. 结核球 / 结核瘤；
6. 结核性胸膜炎。

最稳定身份：

```text
局灶型
→ 非活动性

浸润型
→ 最常见活动性继发性肺结核

干酪性肺炎
→ 病情危重

慢性纤维空洞型
→ 病理学典型开放性、传染性强
```

（边界：活动性最终仍要结合症状、排菌和影像，不能只凭病型名称；内科学传染性以痰涂片为核心。）

## KP08｜局灶型 vs 浸润型：一个以增生局限，一个以渗出活动

> **讲义定位 →** 病理 Lecture PDF P112；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发5–7；内科 U014｜继发3–4  
> **主提示：** 局灶4轴｜浸润5轴｜空洞壁？｜上下游去向

### 局灶型

- 肺尖；
- 境界清楚的结节；
- 以增生性病变为主；
- TB数量少、宿主免疫强；
- 多无症状；
- 非活动性，常见于较早期局限阶段。

### 浸润型

- 肺尖和锁骨下；
- 以渗出为主；
- 边缘模糊、密度不均的云雾 / 云絮影；
- 可呈斑点、斑片或实变；
- 可形成薄壁空洞；
- 最常见的活动性继发性肺结核。

去向：

```text
经支气管播散、坏死加重
→ 干酪性肺炎

空洞经久不愈、广泛纤维化
→ 慢性纤维空洞型

干酪灶被纤维包裹
→ 结核球
```

## KP09｜干酪性肺炎与三种结核空洞：薄壁、无壁、厚壁

> **讲义定位 →** 病理 Lecture PDF P113；内科 Lecture PDF P41–42  
> **Outline →** 病理 U013｜继发8；内科 U014｜继发5  
> **主提示：** 危重线索｜实变｜空洞型3｜链球菌对比｜液平边界

### 干酪性肺炎

- 病情危重；
- 可有急性高热和明显中毒症状；
- 可呈大叶性实变或斑片状病变；
- 可出现虫蚀样 / 无壁空洞。

### 三种空洞

```text
浸润型
→ 薄壁空洞

干酪性肺炎
→ 无壁 / 虫蚀样空洞

慢性纤维空洞型
→ 厚壁空洞
```

（易混：肺炎链球菌肺炎可呈大叶实变，但当前 Study 强调不产生坏死空洞；干酪性肺炎因干酪坏死可有无壁空洞。）

（识别：结核空洞多无液平；肺脓肿更常有液气平。）

## KP10｜慢性纤维空洞型：厚壁三层、上旧下新、垂柳征和肺心病

> **讲义定位 →** 病理 Lecture PDF P113；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发9–10；内科 U014｜继发6  
> **主提示：** 部位｜洞壁3层｜播散｜纤维化4征｜并发症6｜传染边界

### 1｜厚壁空洞三层

由内向外：

1. 干酪样坏死物 + 大量TB；
2. 肉芽组织；
3. 纤维结缔组织。

本质仍是：

```text
坏死
→ 肉芽组织机化
→ 外层纤维化
```

### 2｜肺内播散

空洞与支气管相通：

- 同侧或对侧可见大小不等病灶；
- 支气管播散；
- 上旧下新。

### 3｜纤维化影像

```text
上叶广泛纤维化收缩
→ 肺体积缩小、变形
→ 肺门抬高
→ 肺纹理下垂呈垂柳样
→ 纵隔向患侧移位
```

### 4｜并发症

- 肺气肿；
- 胸膜增厚粘连；
- 气胸 / 脓气胸；
- 大咯血；
- 喉结核；
- 肠结核；
- 慢性肺心病。

```text
广泛纤维化压迫肺血管
→ PVR↑
→ 肺高压
→ 肺心病
```

### 5｜传染性边界

- 病理学：慢性纤维空洞型是典型开放性、传染性强的病型；
- 内科学：是否开放 / 有传染性，以痰涂片阳性、排菌量大为核心。

两者是不同学科的观察层级，不强行改写成同一句定义。

## KP11｜结核球与结核性胸膜炎：纤维包裹还是胸膜渗出

> **讲义定位 →** 病理 Lecture PDF P113–114；内科 Lecture PDF P41  
> **Outline →** 病理 U013｜继发11–12；内科 U014–U015｜继发7–8  
> **主提示：** 结核球定义｜来源3｜影像4｜鉴别/处理｜胸膜2型｜湿性病理｜干性病理

### 1｜结核球 / 结核瘤

> 孤立、境界清楚、由纤维组织包裹的干酪样坏死灶。

形成来源：

1. 浸润型干酪坏死灶被纤维包裹；
2. 空洞引流支气管阻塞，空洞被干酪物填充；
3. 多个结核灶融合。

当前内科 Study 影像：

- 边界清楚；
- 可钙化、分叶；
- 可形成空洞；
- 周围可有卫星灶。

需与周围型肺癌鉴别；纤维包裹使药物不易进入，Study多采用手术切除口径。

### 2｜结核性胸膜炎

| 类型 | 病理身份 |
|---|---|
| 湿性，多见 | 浆液纤维蛋白性渗出性炎，形成胸腔积液 |
| 干性 | 增生性病变 |

可遗留胸膜增厚、粘连。

# Unit D｜临床识别：症状和体征来自哪种病变形态

## KP14｜发热与全身症状：长期午后低热是主轴，危重病型可高热

> **讲义定位 →** 内科 Lecture PDF P40  
> **Outline →** 内科 U014｜临床1–5  
> **主提示：** 最常见症状｜热型/时段｜温度4档｜慢性低热4类｜高热2病型｜激素4原则｜全身3

### 1｜发热

肺结核最常见临床表现是发热：

- 多为长期低中热；
- 典型为午后低热。

诊断学分度：

```text
低热 37.3–38.0℃
中热 38.1–39.0℃
高热 39.1–41.0℃
超高热 >41.0℃
```

慢性低热还可见：

- 支原体肺炎；
- 淋巴瘤等肿瘤；
- 风湿病；
- 吸收热等。

### 2｜何时高热

- 大叶性干酪性肺炎；
- 急性粟粒性肺结核。

结核毒血症严重时，当前 Study 允许糖皮质激素，但必须：

```text
早期
+ 足量
+ 短程
+ 同时有有效抗结核治疗
```

### 3｜其他全身症状

- 盗汗；
- 乏力；
- 体重减轻。

（边界：激素抗炎但不杀TB，不能脱离抗结核药单独使用。）

> **讲义定位 →** 内科 Lecture PDF P40

```text

形成空洞

```

# Unit E｜影像、PPD与痰：活动性和传染性必须分开判断

## KP17｜影像两层：先看好发位置，再看活动性多形性

> **讲义定位 →** 内科 Lecture PDF P42；病理 Lecture PDF P111–114  
> **Outline →** 内科 U015｜影像1–4；U013｜好发部位4–6  
> **主提示：** X线→CT｜部位3组｜活动3征｜修复2征｜空洞3壁｜液平边界

### 1｜检查顺序

```text
胸部X线 = 常规首选
→ CT进一步定位和辨别
```

### 2｜三组位置

- 原发：上叶下部、下叶上部近胸膜；
- 继发：上叶尖后段、下叶背段和后基底段；
- HIV / AIDS合并结核：下叶多见。

### 3｜活动性影像

- 渗出：边缘不清、密度不均的云雾 / 云絮影；
- 空洞：无壁、薄壁、厚壁，多无液平；
- 播散。

只要出现渗出、任何空洞或播散，应优先认为有活动性病变。

### 4｜修复 / 局限影像

- 钙化：边界清楚、高密度斑点或结节；
- 纤维条索：边界清楚、密度增高。

（边界：影像有钙化/纤维化并不自动保证完全无活动；必须结合症状和排菌。）

## KP18｜PPD：检出“感染过TB并能发生迟发反应”，不是直接确诊结核病

> **讲义定位 →** 内科 Lecture PDF P42  
> **Outline →** 内科 U015｜PPD5–9  
> **主提示：** 时程｜效应细胞｜超敏型｜壁成分｜检测身份｜价值人群｜假阴性9类

### 1｜机制

```text
感染TB后4–8周
→ 形成致敏T淋巴细胞
→ 皮肤再次接触TB抗原
→ IV型迟发型变态反应
→ PPD阳性
```

当前 Study 将PPD皮肤反应与结核杆菌细胞壁蛋白质相关联。

### 2｜检测身份

> **PPD用于判断是否感染过结核杆菌，不直接等同于已经发生结核病。**

其提示结核病价值在婴幼儿、儿童更大，尤其未接种卡介苗者。

### 3｜阴性 / 弱阳性不能排除

常见于：

- 长期糖皮质激素；
- 免疫抑制剂；
- 癌症；
- 严重细菌感染；
- 粟粒性结核；
- 麻疹；
- 水痘；
- HIV；
- 结核性脑膜炎；
- 营养不良。

共同逻辑：

```text
免疫反应能力不足
→ 皮肤不能形成足够迟发反应
→ 假阴性 / 弱阳性
```

## KP19｜痰涂片、培养、活动性与传染性：两个坐标不能混

> **讲义定位 →** 内科 Lecture PDF P42–43；病理 Lecture PDF P110、P113  
> **Outline →** 内科 U015｜确诊10–15  
> **主提示：** 涂片身份/阈值｜培养身份｜涂阳/涂阴｜菌阳｜菌阴定义｜无活动3全满足｜病理/内科开放边界

### 1｜痰涂片

- 确诊首选；
- 快速；
- 当痰内约 `5000–10000个抗酸杆菌/mL` 可阳性；
- 当前 Study：涂阳表示排菌量大、具有传染性，称开放性肺结核；
- 治愈涂阳患者是降低传播的重要措施。

### 2｜痰培养

- 确诊金标准；
- 培养阳性表示菌阳、支持活动性肺结核；
- 可出现：培养阳性但涂片阴性，即活动性存在而当前 Study按涂阴处理为无明显传染性。

### 3｜菌阴性肺结核

```text
3次痰涂片阴性
+ 1次痰培养阴性
+ 典型临床表现
+ 典型影像
+ PPD强阳性
→ 菌阴性肺结核
```

### 4｜无活动性必须全满足

- 无症状；
- 痰检查不排菌；
- X线仅硬结、钙化、纤维化等修复表现。

否则按活动性处理：需要抗结核治疗，并进一步判断有无传染性。

### 5｜学科口径边界

```text
病理学开放性
→ 典型指慢性纤维空洞型，与外界相通

内科学开放性
→ 痰涂片阳性、排菌量大
```

一个按病理结构，一个按临床排菌证据，不互相抹平。

### 1｜复治涂阳

> **先做药物敏感试验。**

- 利福平敏感：可按初治方案；
- RR-TB：利福平耐药；
- MDR-TB：至少耐异烟肼 + 利福平。

### 2｜疗程

- 短程方案：首选，9–12个月；
- 长程方案：至少4种药，18–20个月。

### 3｜药物组别

| 组别 | 当前 Study 药物 |
|---|---|
| A组，首选 | 左氧氟沙星 / 莫西沙星；贝达喹啉；利奈唑胺 |
| B组，次选 | 氯法齐明；环丝氨酸 |
| C组，备选 | 乙胺丁醇、德拉马尼、吡嗪酰胺、亚胺培南-西司他丁 / 美罗培南、阿米卡星、链霉素、卷曲霉素、丙硫异烟胺、PAS等 |

组方原则：

```text
所有可用A组药 + 至少1种B组药

若A组仅能选1–2种
→ 使用所有B组药

A+B仍不能组成方案
→ 加C组药
```

### 4｜PAS机制

```text
PAS结构类似PABA
→ 竞争性抑制二氢蝶酸合酶
→ 四氢叶酸生成障碍
→ 一碳单位与核苷酸代谢受阻
→ 抑菌
```

（边界：仅按当前 Study 保留组别和方案，不外扩最新耐药结核指南。）

# Unit G｜整合：活动、传染、空洞与鉴别

## KP25｜肺结核病例算法：症状—位置—形态—排菌—治疗状态

> **讲义回看 →** R7全 Block；R5–R6  
> **Outline →** 病理 U013 + 内科 U013–U016综合  
> **主提示：** 症状｜位置｜形态｜活动｜传染｜病型｜化疗状态｜鉴别4病

### Step 1｜先识别结核概率

```text
长期低热 / 午后低热
+ 盗汗、消瘦
+ 咳嗽、咯血
+ 上肺 / 锁骨区病变
→ 高度怀疑
```

### Step 2｜判宿主与病型

- 儿童、原发复合征、淋巴结 / 播散：原发；
- 成人、上叶、空洞、支气管播散：继发；
- HIV、下叶、淋巴结、多部位、少空洞：免疫低下型。

### Step 3｜看影像活动性

- 渗出；
- 空洞；
- 播散；
- 还是仅钙化 / 纤维条索。

### Step 4｜分开两个证据问题

```text
有没有活动TB？
→ 症状 + 影像 + 痰培养

有没有传染性？
→ 痰涂片 / 排菌量
```

### Step 5｜判断治疗状态

- 初治活动性：`2HRZE/4HR`；
- 复治涂阳：先药敏；
- RR/MDR：按短程优先或长程A/B/C组构建。

### Step 6｜四类肺内鉴别

| 疾病 | 更支持线索 |
|---|---|
| 普通肺炎 | 急性寒战高热、下叶实变、链球菌一般无空洞 |
| 肺脓肿 | 误吸 / 化脓灶、高热脓臭痰、液气平厚壁空洞 |
| 支气管扩张 | 多年大量脓痰、固定湿啰音、薄壁支气管囊腔 |
| 肺癌 | 肿块、吸烟、阻塞/局限哮鸣、器官肿瘤模型后置R11 |

## 3｜高密度比较表

### 原发 vs 继发 vs HIV合并TB

| 轴 | 原发性 | 继发性 | HIV / AIDS合并TB |
|---|---|---|---|
| 免疫背景 | 初次感染，无特异免疫 | 已有免疫，内源复发多 | 免疫严重下降 |
| 人群 | 儿童 | 成人 | HIV感染者 |
| 部位 | 上叶下部 / 下叶上部近胸膜 | 上叶尖后、下叶背段/后基底 | 下叶多 |
| 淋巴结 | 单侧肺门结常见 | 非主轴 | 肺门、纵隔结常见 |
| 播散 | 淋巴 / 血道 | 支气管 | 血道、多部位 |
| 空洞 | 少 | 多 | 少 |
| 肉芽肿 | 可随免疫建立形成 | 明显 | 少 |
| PPD | 可转阳 | 常可阳性 | 阴性 / 弱阳性多 |

### 继发性病型最小坐标

| 病型 | 活动性 | 边界 | 空洞 / 影像核心 |
|---|---|---|---|
| 局灶型 | 非活动 | 清楚肺尖结节，增生为主 | 通常无典型活动空洞 |
| 浸润型 | 最常见活动 | 模糊、密度不均、云雾/云絮 | 薄壁空洞 |
| 干酪性肺炎 | 危重活动 | 大叶/斑片实变、明显毒血症 | 无壁虫蚀样 |
| 慢性纤维空洞型 | 慢性活动、排菌强 | 广泛纤维化、肺门抬高、垂柳征 | 厚壁三层 |
| 结核球 | 多为局限 / 晚期包裹 | 边界清楚、钙化/卫星灶 | 可有空洞 |
| 结核性胸膜炎 | 胸膜病型 | 湿性多、干性少 | 胸水或增生 |
