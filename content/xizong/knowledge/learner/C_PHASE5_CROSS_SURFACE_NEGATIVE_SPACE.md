### Attack C｜Can C duplicate already learned A/B owners?

### Alternative 2｜KP-by-KP alternating between KianOS and MarginNote

Rejected. It protects micro-recall at the expense of continuous Source understanding and adds unacceptable switching cost.

Rejected as authority. Fresh Phase-1 review retained a low-switching H1→H27 default because it is reasonable, but reduced hard prerequisites to real causal dependencies and preserved branch flexibility.

Rejected. LGs are local closure units; backend grouping detail should not become another visible syllabus burden.

Rejected. Dense multi-evidence Blocks contain genuinely different cognitive jobs; removing local closure would recreate delayed giant recall.
