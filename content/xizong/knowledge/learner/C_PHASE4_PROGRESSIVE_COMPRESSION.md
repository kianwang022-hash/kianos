# C Hematology · Immunity · Infection — Phase 4 Progressive Compression

Status: **PASS — compression ladder accepted for C Learning candidate**  
Upstream exact partition: **27 Blocks / 423 KPs / 133 Logic Groups**  
Learner Truth: none

## 1｜Problem

C is unusually vulnerable to two opposite failures:

1. **under-compression** — first learning leaves hundreds of tests, antibodies, morphology clues, classifications and treatment names as isolated facts;
2. **premature over-compression** — a short “blood / immune / infection” framework is memorized before the disease evidence layers have been formed.

The accepted solution is progressive compression: preserve full Source contact and local Logic-Group retrieval during first learning, then compress only after the relevant local model exists.

## 2｜Compression ladder

```text
original Lecture/source contact
→ KP retrieval inside one local Logic Group
→ cognition-specific LG closure
→ Block Recall
→ branch Partial-System Reconstruction (non-gating)
→ final C System Reconstruction after all 27 Blocks are actually learned
→ later passes: thinner discrimination / precision / application model
```

No compression stage creates a new medical owner, hierarchy, mastery score or Memory debt.

## 3｜Block Recall

Block Recall is not a replay of every LG title. It must reconstruct the smallest model that still supports localization and application.

Minimum Block-Recall form:

1. **one upstream failure / decision model**;
2. **the decisive evidence layers or discrimination axes**;
3. **the current danger / treatment role when relevant**;
4. **the explicit stop-line / external owner**.

Examples:

- H3: `Hb → MCV → Ret → iron/B12 evidence → production vs loss/destruction owner`;
- H9: `acute identity → lineage/subtype evidence → urgent exit → Source treatment → CR/MRD`;
- H16: `immune-complex / anti-cell / APS branch → antibody role → organ pattern → current danger`;
- H25: `space → pressure/necrosis/source → incision/debridement timing → H26 escalation`.

## 4｜Four non-gating Partial-System Reconstructions

### PSR-C1｜Blood localization — after H1–H6

Target:

```text
which lineage / blood function is abnormal?
→ production/maturation vs peripheral loss/destruction/distribution
→ quantity vs function
→ anemia: MCV × Ret
→ bleeding: platelet/vascular vs coagulation vs fibrinolysis/consumption
→ choose the next evidence layer
```

Closure:

> Given an unfamiliar anemia, pancytopenia, hemolysis or bleeding case, Kian can route it to the correct next model before naming a disease from one isolated test.

### PSR-C2｜Clonal hematology — after H7–H11

Target:

```text
abnormal clone
→ lineage + maturation stage
→ marrow / peripheral / tissue behavior
→ morphology / cytochemistry / immunophenotype / genetics by role
→ urgent subtype / complication
→ prognosis / Current treatment role
```

Closure:

> Kian can explain what each evidence layer adds and refuses to diagnose a clonal disease from WBC count, one CD marker or one chromosome alone.

### PSR-C3｜Immune / rheumatology — after H12–H19

Target:

```text
insufficient defense
vs self-directed injury
vs alloimmune direction
→ effector / target / timing
→ syndrome + organ combination
→ evidence role
→ activity / damage / current danger
→ treatment role
```

Closure:

> A positive antibody is interpreted as screening / specificity / activity / organ association evidence inside a syndrome model, not as the disease itself.

### PSR-C4｜Infection — after H20–H27

Target:

```text
pathogen / exposure
→ anatomical site / source
→ host defense
→ tissue reaction / spread
→ persistent source / pressure / necrosis
→ local vs systemic danger
→ antimicrobial + source-control + perfusion lines when required
```

Closure:

> Kian can localize an infection as a host–pathogen–space problem, identify when drug-only treatment is insufficient and return organ-specific diagnosis/treatment to its canonical System owner.

## 5｜Final C System Reconstruction

Eligible only after private Learner Truth says all 27 Blocks have actually been learned. Repository readiness cannot trigger this step.

Prompt skeleton:

1. Draw blood-cell production → maturation → peripheral readout → clearance / loss.
2. Given an abnormal count or bleeding pattern, localize the first failed layer and choose the next evidence.
3. Draw the clonal branch: clone → lineage/maturation → evidence layers → infiltration / protein / tissue behavior.
4. Draw the immune decision: insufficient defense vs self-directed injury vs alloimmune direction.
5. Draw the infection decision: pathogen–site–host–reaction–source control → systemic danger.
6. Use C failure modes / judgment axes to route back to the smallest owning Block or external System only when needed.

Forbidden final reconstruction:

- reciting H1–H27 titles;
- reciting 133 LG labels;
- re-reading every Precision item;
- importing missing normal immunology or complete infectious-disease medicine;
- treating default learner route as medical ontology.

## 6｜Later-pass thinning

### First pass

- full required original-Lecture contact;
- active retrieval of formally learned KP content inside the accepted LG;
- selective current-owner Precision / Visual cues where they materially aid learning;
- close LG → close Block.

### Second pass

Prioritize:

- disease / mechanism discrimination;
- evidence-role discrimination;
- morphology / visual recognition where decisive;
- high-value Source Precision;
- cases and cross-System application;
- real Wrong / Uncertain repair.

Stable first-pass explanatory detail should not be replayed automatically.

### Late review

Prefer:

```text
System / branch causal skeleton
+ decisive boundaries
+ high-value precision
+ real weak points
+ fresh application / transfer
```

Do not preserve 423 permanent review obligations merely because 423 canonical KPs exist.

## 7｜Memory admission

First exposure does not automatically create review debt.

Admit when evidence justifies it, especially:

- unstable formally learned Core;
- high-value numeric / classification / marker / drug Precision that is decisive for 306;
- repeated confusable discrimination;
- Wrong / Uncertain evidence;
- explicit learner request.

Do not automatically admit:

- every antibody name;
- every morphology descriptor;
- every Source table row;
- every visual caption;
- connection hooks whose target owner has not been formally learned.

## 8｜Compression falsification

### Challenger A｜One Block Lecture, then one Block Recall

Rejected as default for dense C Blocks such as H9/H11/H16/H17 because retrieval distance becomes too long and distinct evidence tasks collapse into one late recall. Whole-LG contact provides local reconstruction while avoiding KP-by-KP app bouncing.

### Challenger B｜Recall after every KP

Rejected. It fragments Source continuity and turns KianOS into a navigation tax.

### Challenger C｜Memorize System Framework first, then fill facts

Rejected. The framework is orientation, not proof that the learner owns morphology/evidence/discrimination needed for cases.

### Challenger D｜Keep every first-pass item in permanent review

Rejected. Later passes must get thinner; fresh application and observed weakness outrank permanent item debt.
