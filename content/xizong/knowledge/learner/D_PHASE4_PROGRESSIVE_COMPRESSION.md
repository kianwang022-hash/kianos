## 3｜Five PSRs

PSRs are **compression opportunities**, not new mandatory hierarchy, mastery stage, Memory debt or route gate.

### PSR-D1｜Signal → Sensation → Actuator

Eligible after N1–N7 are actually learned.

```text
stimulus or motor command
→ membrane/axon
→ synapse/receptor
→ sensory transduction or NMJ
→ AP/coding/force output
→ where is the first failure layer?
```

Must retrieve:

- conduction ≠ synaptic transmission ≠ receptor effect;
- transduction/coding common language;
- special-sense organ-specific mechanics;
- NMJ/muscle execution as an output layer.

Closure:

> In a new physiology scenario, Kian can localize the first failed layer and predict the downstream direction without replaying N1–N7 titles.

### PSR-D2｜Control → Localization

Eligible after N8–N11 are actually learned.

```text
controller / descending system / reflex arc
→ tone + reflex + strength + sensation
→ central / cord / conus-cauda / root / named nerve / NMJ-muscle
→ urgent red flag?
```

Must retrieve:

- planning/selection/correction vs final motor pathway;
- spinal/brainstem timing effects;
- UMN vs LMN;
- tract combination;
- root vs named nerve;
- sphincter/saddle/respiratory/progressive red flags.

Closure:

> A weakness/numbness case is localized before a disease label and the learner can name the smallest next discriminating evidence.

### PSR-D3｜Trauma → Stability → Neurovascular danger

Eligible after O1–O7 are actually learned.

```text
force + structure
→ displacement / stability / congruity
→ open/closed + blood supply + nerve/vessel/compartment/cord risk
→ imaging question
→ reduction/fixation target
→ function / weight bearing
```

Must retrieve:

- O1 entry coordinate;
- O2 common fracture/source-control/healing model;
- N11/O5 neurologic localization only when needed;
- regional upper/lower-limb functional differences;
- hip/femoral-head blood supply, long-bone hemorrhage and compartment danger.

Closure:

> A new trauma case is routed by danger and functional objective rather than by eponym recall.

### PSR-D4｜Load / Perfusion / Growth / Local Function

Eligible after O8–O12 are actually learned.

```text
local tissue / load / blood supply / growth stage
→ pain or functional loss
→ acute tissue deficit vs chronic overuse/entrapment vs ischemic collapse vs developmental fixation
→ evidence
→ function-preserving treatment window
```

Must retrieve:

- hand tissue viability and coverage;
- knee directional stability;
- AVN perfusion-collapse model;
- chronic soft-tissue load vs named-nerve entrapment;
- developmental age window.

Closure:

> Local chronic/focal orthopedic cases are separated by the first failed tissue and time/growth/perfusion mechanism, not by “all chronic bone-joint disease”.

### PSR-D5｜Destructive Structural Disease

Eligible after O13–O16 are actually learned.

```text
pyogenic / TB / degenerative-inflammatory / tumor
→ tempo + tissue/site of origin
→ imaging / aspiration / pathology / source-control evidence
→ stability / neural / function threat
→ owner-appropriate treatment direction
```

Must retrieve:

- pyogenic bone/joint source-control spaces;
- TB slow destruction/cold abscess and spine/hip consequences;
- OA/AS/RA tissue-of-origin discrimination;
- bone tumor aggressiveness→age→site→matrix/periosteal→biopsy;
- explicit return to C/H17/H21/H8/O9 tumor-general when common Primary is external.

Closure:

> A destructive bone/joint/spine case is separated by mechanism and evidence role, and common infection/immune/tumor foundations are not duplicated inside D.
