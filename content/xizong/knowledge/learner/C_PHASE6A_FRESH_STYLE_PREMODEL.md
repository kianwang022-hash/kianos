## 1｜Independent route hypothesis

Low-switching default route:

```text
H1 → H2 → H3 → H4 → H5 → H6
→ H7 → H8 → H9 → H10 → H11
→ H12 → H13 → H14
→ H15 → H16 → H17 → H18 → H19

```

This route is a learner-friendly readiness path, **not medical ontology and not a hard prerequisite chain**. Soft reorder is allowed when hard prerequisites are already satisfied and original-Lecture continuity improves.

Natural non-gating branch reconstructions should occur after:

1. H1–H6: blood-cell / anemia / bleeding localization;
2. H7–H11: clonal hematology evidence hierarchy;
3. H12–H19: immune direction + rheumatic syndrome/evidence language;
4. H20–H27: infection site / host / tissue reaction / source-control / systemic danger.

Final System reconstruction is legal only after actual learner completion of all 27 Blocks.

## 2｜System-level falsification criteria

A C Learning candidate fails if it does any of the following:

- turns KianOS into a second continuous textbook rather than orientation/retrieval/closure;
- bounces normally between KianOS and MarginNote KP-by-KP instead of whole-LG source contact;
- creates a fixed Logic-Group quota or defends a target count;
- treats Block or KP Markdown order as mandatory learner order;
- fills the missing normal-immunology curriculum from model knowledge;
- fills a complete infectious-disease / antimicrobial / vaccination curriculum absent from Current Source;
- duplicates normal hemostasis, RBC metabolism, iron/B12/folate, tumor-molecular foundations or organ-specific infection as new Primary learning;
- converts antibody, CD marker, chromosome, morphology or one laboratory value into a disease identity without its evidence role;
- infers Question→Knowledge relations or learner mastery;
- suppresses Source conflicts, historical wording or Source gaps;
- lets a downstream Projection schema force an upstream semantic regrouping.

## 3｜Block-by-Block independent task model

The count bands below are **rough falsification bands, not quotas**. Exact grouping may fall outside a band if a semantic argument is stronger.

### H1｜造血、CBC、Ret与骨髓诊断语言 — rough 5–7 LG

Must preserve distinct cognitive work:

- RBC structure / physical behavior and what deformability, ESR and osmotic fragility actually measure;
- erythroid production → maturation → Ret → clearance lifecycle;
- WBC count as distribution vs production, without expanding complete immunology;
- megakaryocyte / platelet identity with normal hemostasis only as Recall;
- blood as physical environment where Hct/viscosity, osmotic pressure and pH are not interchangeable;
- final five-layer evidence localization: CBC → Ret → smear → aspirate → biopsy.

**Prediction:** final diagnostic integration should occur after enough cellular/readout substrate exists; KP order may therefore be intentionally non-sequential.

### H2｜血型、交叉配血与成分输血 — rough 5–7 LG

Must keep sufficiently separate:

- ABO antigen/antibody object + attack direction;
- Rh sensitization timing;
- component / amount / crossmatch decision;
- transfusion-reaction discrimination;
- massive-transfusion metabolic / component burden;
- autologous transfusion source/safety boundary.

Failure mode: one compatibility table or one giant “transfusion facts” group.

### H3｜贫血总坐标、缺铁与巨幼 — rough 5–6 LG

Required spine:

```text
Hb → MCV → Ret → specific evidence
```

Natural tasks:

- common anemia coordinate;
- IDA loss → storage depletion → functional iron deficit → Hb / recovery timeline;
- microcytic differential by iron availability / locking / utilization / globin;
- megaloblastic DNA-maturation / B12 absorption and neurologic boundary;
- morphology/range only as routing evidence, never diagnosis by itself.

### H4｜再生障碍性贫血 — rough 3–5 LG

Must distinguish:

- global marrow-factory failure mechanism;
- peripheral + multi-site marrow evidence proving low production;
- severity / immediate infection-bleeding risk;
- treatment and AA-vs-MDS/PNH/other production-failure discrimination.

### H5｜溶血性贫血 — rough 5–7 LG

Required reasoning order:

```text
prove destruction + marrow compensation
→ locate intravascular / extravascular / in-situ
→ identify intrinsic / extrinsic mechanism
→ disease-specific confirmatory evidence / treatment role
```

Must not use Ret, jaundice or splenomegaly alone as diagnosis.

### H6｜出血性疾病 — rough 5–7 LG

Required order:

- locate by bleeding site/time: vascular/platelet vs coagulation vs fibrinolysis;
- map screening tests to the layer they answer;
- ITP as a specific immune destruction + impaired production model;
- ITP marrow/peripheral evidence and close differentials;
- urgent / first-line / later treatment roles.

Normal hemostasis remains Recall from circulation; H6 must not retake Primary ownership.

### H7｜MDS / clonal hematopoiesis — rough 4–5 LG

Must preserve:

- abnormal clone + dysplasia + ineffective output (“active marrow ≠ effective production”);
- morphology / lineage evidence and AA / megaloblastic / AML discrimination;
- blast threshold / FAB-WHO / genetics as different evidence/classification roles;
- risk stratification and treatment role.

### H8｜MM — rough 4–6 LG

Must distinguish:

- plasma-cell clone itself;
- M-protein / free-light-chain product line;
- CRAB / organ outputs from the common clone;
- marrow + protein + organ evidence as independent but converging lines;
- diagnosis/staging/treatment role without reducing the Block to CRAB + M spike + BJP.

### H9｜急性白血病 — rough 6–8 LG

This is a high-density audit hotspot. Must preserve:

- acute clonal / maturation-arrest identity;
- normal-hematopoiesis suppression and tissue-infiltration outputs;
- morphology / Auer / cytochemistry as lineage-direction evidence;
- flow + genetics / fusion evidence as identity / subtype / prognostic evidence;
- high-value differentials including AML/ALL and acute-vs-chronic maturation pattern;
- APL/DIC, leukostasis and tumor-lysis / hyperuricemic danger as urgent exits;
- subtype treatment, CR/MRD and drug-toxicity roles;
- final case algorithm if needed.

Failure mode: FAB, CD markers and chromosomes collapsed into a memory table detached from the question each evidence layer answers.

### H10｜CML — rough 3–5 LG

Must reconstruct:

- mature granulocytic clone + Ph/BCR-ABL identity;
- chronic-phase blood/marrow/spleen pattern;
- reactive leukocytosis vs CML evidence including NAP/clone role;
- chronic → accelerated → blast-crisis progression as loss of maturation order;
- TKI/HSCT/special-person treatment role and acute-leukemia comparison.

### H11｜淋巴瘤 — rough 8–10 LG

Dense morphology/identity Block; over-compression is a major failure risk. Must keep distinct enough:

- lymphoma entry / biopsy / staging / B symptoms;
- HL vs NHL behavior and spread;
- B-cell NHL major architectures / identities;
- T/NK lymphoma identities;
- tissue morphology / visual gates such as starry sky, Pautrier and related structures;
- RS-cell variants and CHL/NLPHL identity;
- CHL subtype morphology / Source-conflict handling;
- immunophenotype / chromosome summary as confirmation, not replacement for tissue structure;
- treatment roles by tissue type/stage.

### H12｜最低免疫共同语言 — rough 4–6 LG

Hard negative-space rule: **no complete normal-immunology backfill**.

Must organize only Current-supported minimum language:

- B/CD4/CD8/antibody/immune-complex minimum roles;
- classify by effector action, target/location and timing;
- I–IV hypersensitivity as retrieval coordinates rather than disease lists;
- same disease can use different damage mechanisms;
- self-tolerance is a boundary concept; mechanism of tolerance loss remains Source Gap;
- case classification / later-owner routing.

### H13｜免疫缺陷与 HIV/AIDS — rough 4–6 LG

Must distinguish:

- primary vs acquired and T / B / combined / granulocyte-function localization;
- “cell exists” vs “function works”;
- HIV target / entry / reservoir chain;
- transmission / fluid identity;
- early-vs-late lymphoid-organ reaction;
- opportunistic infection / malignancy output and reverse localization.

No complete ART / PEP / opportunistic-infection treatment expansion.

### H14｜移植排斥与 GVHD — rough 3–5 LG

Required order:

```text
who attacks whom
→ timing / preformed antibody
→ vascular vs interstitial pathology
```

Must preserve:

- recipient→graft vs graft immune cells→recipient;
- hyperacute vascular disaster;
- acute vascular vs acute cellular vs chronic morphology;
- transfusion-related GVHD interface;
- two explicit Source conflicts (hyperacute II/III and chronic IV/humoral) without forced reconciliation.

### H15｜风湿诊断语言与治疗角色 — rough 4–6 LG

This is a Gate, not four disease mini-textbooks.

Must preserve:

- syndrome / organ-combination first;
- broad screening vs disease-specific vs activity vs organ-damage evidence roles;
- ANA/RF not disease identity;
- NSAID / GC / conventional / targeted / biologic DMARD role distinction;
- SSc / inflammatory myopathy / gout only at Source-supported overview level;
- routing to H16–H19.

### H16｜SLE + APS — rough 6–8 LG

Required model:

1. immune-complex inflammatory multi-organ branch;
2. anti-cell antibody cytopenia branch;
3. antiphospholipid thrombosis / miscarriage branch.

Then keep distinct enough:

- ANA / dsDNA / Sm / ENA / complement by evidence role;
- APS antibodies and thrombotic phenotype;
- pathology visuals / organ deposits;
- clinical organ combination;
- activity vs accumulated damage;
- treatment / crisis;
- current-danger split: inflammatory organ injury vs APS thrombosis.

### H17｜RA — rough 5–7 LG

Must make the mechanism do work:

```text
synovitis → neovascular pannus → cartilage/bone erosion → irreversible deformity
```

Distinct tasks should include:

- pathology / pannus + rheumatoid nodule visuals;
- joint distribution / morning stiffness / deformity / extra-articular phenotype;
- RF vs ACPA/anti-CCP evidence roles;
- MRI early vs X-ray structural stages;
- symptom relief vs early DMARD disease control;
- Current internal vs historical diagnostic frameworks and Source conflict.

### H18｜Sjögren — rough 4–5 LG

Required causal entry:

```text
exocrine gland immune infiltration → salivary/lacrimal failure → oral/ocular consequences
```

Then:

- systemic outputs: nonerosive joint, RTA/low K/alkaline urine, purpura, cytopenia;
- lymphoma/MALT warning as H11 interface, not duplicate lymphoma curriculum;
- SSA/SSB + lip biopsy + salivary/tear evidence roles;
- no-organ vs organ-involvement treatment roles.

### H19｜systemic vasculitis + Behçet — rough 5–7 LG

Must start with vessel caliber / arterial-vs-venous / organ combination, not ANCA.

Natural tasks:

- common vessel-wall injury → stenosis/occlusion vs rupture/aneurysm;
- caliber classification;
- ANCA / AECA / biopsy / angiography by evidence role;
- MPA renal-pulmonary-skin-neuropathy model and treatment boundary;
- explicit `type III RPGN ≠ type III hypersensitivity` trap;
- Behçet all-caliber arterial/venous identity + oral/genital/eye/skin pattern;
- scoring/treatment only to Source-supported precision.

### H20｜感染共同语言 — rough 4–6 LG

Required common coordinate:

```text
pathogen/exposure → site/space → host → tissue reaction → source control → local/systemic outcome
```

Must include:

- colonization/invasion/focus distinction;
- host changes pathology (“weak reaction ≠ mild infection”);
- tissue-reaction families as routing language;
- opportunity vs superinfection and antimicrobial general principles;
- specimen must match the real infection space;
- antibiotics vs source control and local→systemic escalation.

Must not become microbiology/antibiotic pharmacology textbook.

### H21｜结核跨器官整合 — rough 4–6 LG

Hard ownership rule: **not a second TB course**.

Must preserve:

- immune control + delayed-type injury → granuloma + caseation;
- primary vs secondary vs HIV-host patterns;
- dissemination pathways (lymphatic / hematogenous / bronchogenic / oral / direct extension);
- organ map and return to R7/K13/D12/orthopedics etc.;
- granuloma comparison only as discrimination.

PATH-U013 remains Recall/Integration, not new Primary.

### H22｜流脑 vs 乙脑 — rough 3–5 LG

Required first split:

```text
meninges/subarachnoid purulence vs brain-parenchymal neuronal injury
```

Must retain:

- site + inflammatory pattern comparison;
- meningococcal purulence and fulminant systemic danger;
- JE neuronal/liquefactive damage + sieve softening / perivascular cuff;
- astrocyte / microglia / oligodendroglia visual-role discrimination;
- no full neurologic-infection clinical treatment curriculum.

### H23｜伤寒 / 菌痢 / 感染性肠溃疡 — rough 5–7 LG

Required coordinate:

```text
site → inflammatory pattern → ulcer morphology → complication
```

Must keep:

- typhoid acute proliferative / macrophage-nodule model;
- ileal lymphoid-structure → longitudinal/parallel ulcer direction + bleeding/perforation;
- dysentery pseudomembrane → shallow map-like ulcer;
- toxic dysentery “systemic severe / local mild”;
- common ulcer comparison as structural discrimination;
- malaria only as explicit Source-gap/minimum interface, never completed from memory.

### H24｜血吸虫 + STI — rough 5–7 LG

Hard rule: one canonical Block with **two internal continuous units**; do not manufacture one shared natural history.

Unit A must preserve:

- exposure / cercaria vs egg role;
- acute eosinophilic egg lesion → maturation into granuloma;
- chronic pseudo-tuberculous egg nodule and TB discrimination;
- organ interface / Source boundary.

Unit B must preserve:

- syphilitic endarteritis/perivascular plasma-cell inflammation + stage model;
- gumma morphology;
- condyloma HPV6/11 + koilocyte identity;
- gonorrheal acute purulent identity;
- no complete STI clinical management.

### H25｜局部感染与源控制 — rough 5–7 LG

Primary learner variable is **anatomical space / pressure / necrosis / function**, not incision-name memorization.

Must retain:

- localized staphylococcal vs diffuse streptococcal behavior;
- furuncle/carbuncle vs cellulitis/erysipelas spaces and cut/no-cut boundary;
- general fluctuation rule and true early-action exceptions;
- danger triangle and submandibular airway exception;
- paronychia/felon high-pressure logic;
- deep palmar spaces / tendon sheath / bursae visual map and protected incision boundaries;
- final source-control timing algorithm and H26 escalation.

### H26｜脓毒症 — rough 3–5 LG

Hard boundary: preserve Current historical terminology, do not silently replace with modern SOFA/Sepsis guideline.

Must organize **three parallel non-substitutable lines**:

```text
pathogen line: sampling + IV antimicrobial
source line: drain/debride/remove persistent focus
circulation line: shock/perfusion support via B12
```

Also retain:

- high and low temperature/WBC extremes;
- Source-specific pathogen clues as clues, not diagnosis;
- culture-negative source/organism reconsideration;
- local infection → systemic loss of control / organ threat recognition.

### H27｜破伤风 vs 气性坏疽 — rough 3–5 LG

One shared entry only:

```text
spore contamination → hypoxic wound → vegetative growth → exotoxin
```

Then split sharply:

- tetanus: retrograde transport → Renshaw/glycine disinhibition → persistent excitation; triggers, clear consciousness, muscle sequence, airway danger, active/passive immunization boundary;
- gas gangrene: muscle necrosis + edema + gas + hypoxia feedback + hemolysis; rapid recognition and aggressive debridement / muscle-group excision / possible amputation;
- final urgent discrimination: airway protection vs radical source control, with both monitored for systemic toxicity/shock.

## 4｜Cross-Block expectations before candidate comparison

### 4.1 Readiness

Hard dependencies should be sparse. A route that simply turns every prior Block into a prerequisite fails. The strongest natural gates are:

- H1 before disease-level blood evidence;
- H3 before AA/hemolysis anemia branching;
- H7/O9/G1–G5 before clonal tumor Blocks;
- H12 before immune-damage applications;
- H15 before disease-specific rheumatology;
- H20 before infection-specific source-control/systemic reasoning;
- true external canonical owners are recalled only when the Block requires them.

### 4.2 Progressive compression

First pass may be detailed because C contains many precision-heavy diagnostic models. Later passes must thin toward:

- blood: lineage/output + MCV×Ret + marrow/peripheral failure location;
- clonal: clone + maturation + evidence-role hierarchy + urgent exits;
- immune/rheum: defense insufficient vs self-directed vs alloimmune + syndrome/organ evidence roles;
- infection: site + host + tissue reaction + source control + systemic danger.

Canonical KP existence alone must not create permanent review debt.

### 4.3 Visual gates

Visual-only / spatial objects must remain conditional and source-bound, especially:

- blood / marrow morphology;
- H7–H11 tumor morphology / tables;
- SLE / RA pathology;
- H22 glial / CNS pathology;
- H23/H24 ulcer / granuloma morphology;
- H25 hand spaces / incision boundaries;
- H27 muscle viability / gas-gangrene appearance.

KianOS should surface a locator/gate, not replace original Lecture images with prose imagination.
