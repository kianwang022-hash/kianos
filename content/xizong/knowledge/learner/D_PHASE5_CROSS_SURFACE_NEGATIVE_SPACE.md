## 2｜Surface attack

### Attack A — one whole Block Lecture for every Block

Rejected.

It works for compact coherent Blocks such as N1/N2/N3/N9/O2/O6/O7/O8/O9/O10/O12/O15, but fails for long/multi-center Blocks such as N6/N8/O4/O11/O16 where delayed retrieval would create avoidable working-memory loss.

Accepted repair:

> `WHOLE_BLOCK_SOURCE`, `NATURAL_SOURCE_UNITS`, and `INTEGRATION_PRIMARY` are separate Source-contact classes.

### Attack B — one Source trip per Logic Group

Rejected.

This reproduces the C red point: retrieval partitions become device-switch partitions. D has 128 LGs; making every LG a MarginNote trip would destroy continuity.

Accepted rule:

> LG = retrieval/closure unit. Source contact follows the Block’s accepted natural Source unit; several LGs may be retrieved after one continuous Source contact.

### Attack C — all D first learning should stay inside KianOS because Block Core is rich

Rejected.

Canonical Markdown contains rich medical Core but is not automatically the primary Source surface. Original physiology/surgery Lecture remains primary for continuous new explanation, original figures/tables, source-local examples and Lecture-attached questions.

KianOS projects only orientation, stop-line, selective cue, retrieval, closure and compression.

### Attack D — N11/O1 should also require a complete Lecture re-read for symmetry

Rejected.

Both are integration-primary objects:

- N11 = minimum localization synthesis from already-learned N1/N5/N8 plus targeted surgical localization Source;
- O1 = orthopedic structure–stability–danger–evidence/function map over broad surgery material.

Forcing a second full source read would duplicate prior Primary and create artificial friction.

Accepted action:

```text
bounded KianOS integration orientation
→ retrieve already-owned models
→ targeted original Source return only for decisive visual / wording / uncertainty
→ integration closure
```

## 3｜Visual attack

D contains visual relations whose correctness cannot be certified from text-only retrieval:

- optic pathway / visual field;
- cochlear spaces/traveling wave;
- vestibular axes;
- spinal tracts and localization;
- plexus/named-nerve maps;
- root/cord/cauda geometry;
- fracture force/displacement;
- joint congruity / blood supply / compartment anatomy;
- scoliosis/DDH spatial relationships;
- destructive bone/joint and tumor imaging.

Attack: “If the prose and active prompt are correct, visual contact can be optional.”

Rejected.

Accepted rule:

> `VISUAL_REQUIRED` means the spatial relation must have been contacted in the original Source before honest closure. A learner may later recall it textually, but first formation cannot be replaced by prose.

Material debt preserved:

- current O1–O5 repository visual-source gaps remain open Source/asset debt;
- Learning can declare the need and locator intent but cannot manufacture a figure or claim visual closure.

## 6｜Route attack

### Alternative 1 — split Neuro and Orthopedics into independent learner Systems

Not adopted as the Current default because N11→O3/O4/O5, N4→locomotor actuator and neural/structural danger interfaces are real. The six Block families and five PSRs keep compression modular without creating two duplicate top-level owners.

### Alternative 2 — jump from N8 directly to N11, leave N9/N10 later

Legal under readiness and sometimes useful in a locomotor-focused session. Not selected as sole default because N9/N10 are contiguous physiology Source and completing them before N11 lowers Source switching; importantly, they are **not hard prerequisites** for N11.

### Alternative 3 — learn orthopedic disease branches in arbitrary interest order after O1

Legally possible when hard prerequisites/external baseline are satisfied, but not the default: O2→regional trauma, O3/O4/O5 localization cluster and contiguous surgery Source offer real low-switching benefits.

Accepted route remains a low-switching default over a sparse readiness DAG, not an ontology.

## 7｜Repair / Memory attack

Rejected behaviors:

- one failed KP reopens the whole Block by default;
- Wrong / Uncertain means the medical model is definitely absent;
- visual failure is repaired by a longer text explanation instead of returning to the figure;
- a Source conflict is “repaired” by Chat choosing one side;
- cross-System missing baseline creates a permanent new D Memory object;
- every current KP enters future review merely because it exists.

Accepted return policy:

```text
mechanism/localization failure → smallest LG repair
visual relation absent → original visual Source return
precision unstable / model intact → Precision recall / selective Memory
cross-System baseline absent → smallest-sufficient external-owner / Chat repair
Source conflict relevant → Source-context check
stable work → continue
```

Repair never erases original evidence and never proves mastery by itself.

## 9｜Material repair found in Phase 5

The first mental version of D compression risked treating every `VISUAL_REQUIRED` LG as a separate source-return event.

This would recreate LG-by-LG bouncing for visual-heavy Blocks such as N6/N8/O5/O16.

Repair:

> Visual requirement belongs to closure/evidence, **not automatically to a separate handoff**. If several visual LGs are supported by one continuous natural Source unit, the learner contacts those figures continuously in MarginNote and then returns once for multiple LG retrievals.

This repair is now part of the Learning candidate contract.
