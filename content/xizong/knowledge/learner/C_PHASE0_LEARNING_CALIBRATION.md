## 2｜Fresh learner problem

C is not one homogeneous subject. Its 27 Blocks contain six different cognitive shapes:

| Family | Blocks | Dominant learner job |
| --- | --- | --- |
| blood production / readout / transfusion / anemia / bleeding | H1–H6 | localization + mechanism + test interpretation |
| clonal hematology | H7–H11 | lineage / maturation + multi-layer evidence + dangerous subtype discrimination |
| minimum immune / immunodeficiency / alloimmunity | H12–H14 | effector-direction + target + timing + ownership boundary |

| infection pathology / host / spread | H20–H24 | pathogen–site–host–reaction localization + morphology comparison |

Therefore one uniform grouping rule would be wrong.

## 3｜Natural first-learning unit

### Block remains the continuous source unit

The canonical Block remains the main continuous first-learning unit. Original Lecture/source contact stays external-primary on iPad / MarginNote.

Normal surface sequence remains:

```text
KianOS bounded orientation / cue
→ one coherent original-Lecture contact in MarginNote
→ return to KianOS
→ active retrieval
→ local closure
→ later Block Recall
```

KianOS must not become a second continuous C textbook.

### Logic Group is justified in C

Logic Groups are justified because every C Block currently contains 9–32 KPs, and many Blocks contain multiple genuinely different cognitive tasks. A single Block-level delayed Recall would mix distinct jobs and increase reconstruction distance.

But Logic Groups are **not** required by symmetry with A/B. They exist only where they protect one local causal/discrimination/evidence/action problem.

Accepted grouping principle:

```text
one Logic Group
= one local learner question that should be understood/retrieved together
≠ equal KP quota
≠ Markdown section count
≠ teacher page chunk
≠ question taxonomy
```

A narrow C Block may need only 2–3 groups. A dense multi-evidence Block such as H9/H11 may need about 5 groups. No target count is a quota.

## 4｜Cognition-specific Logic Group jobs

Allowed jobs are descriptive, not a required enum:

- `LOCALIZATION`: locate production / destruction / organ / immune / infection failure.
- `CAUSAL_CHAIN`: reconstruct a mechanism from trigger to phenotype.
- `EVIDENCE_STACK`: combine morphology, laboratory, pathology, immunophenotype or genetics without treating one layer as the whole diagnosis.
- `DISCRIMINATION`: separate close diseases / patterns by decisive conditions.
- `DIRECTION_TIMING`: reason about who attacks whom, when, and through what mechanism.
- `SYNDROME_ORGAN_MAP`: reconstruct multi-organ disease from syndrome and organ combination.
- `SOURCE_CONTROL`: connect anatomy / persistent source to treatment necessity.
- `URGENT_PARALLEL_ACTION`: run simultaneous infection/source/perfusion or subtype-emergency tasks.
- `PRECISION_CLUSTER`: keep tightly coupled Source-specific precision together when separating it would increase error.

Mixed-task groups are prohibited unless the tasks cannot be separated without breaking the causal model.

## 6｜Critical negative space

C Learning must not create:

1. a complete normal-immunology curriculum from generic model knowledge;
2. a complete clinical infectious-disease curriculum or antimicrobial/vaccine curriculum;
3. a second Primary for normal hemostasis, RBC metabolism, iron/B12/folate metabolism, tumor-molecular foundations or organ-specific infections;
4. a new Question Truth or inferred Question→KP map;
5. mandatory KP-by-KP surface switching;
6. a universal requirement that every Block have the same number or shape of Logic Groups;
7. a mastery claim from grouping or engineering completion.
