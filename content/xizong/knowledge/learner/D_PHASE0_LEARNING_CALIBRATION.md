## 3｜Natural learner units

### Block remains the main medical problem unit

A Block should still feel like one coherent medical problem. Block identity remains stable and Block Recall remains the local compression endpoint.

### Logic Group is a retrieval / closure unit

```text
one Logic Group
= one local mechanism / localization / discrimination / evidence / action question
≠ fixed KP count
≠ Markdown section count
≠ page range by default
≠ one UI card
≠ one mandatory Source-contact trip
```

Logic Groups may be non-contiguous in stable KP order when causal retrieval genuinely requires it; exact membership is decided in Phase 3.

### Source contact is a separate L decision

D requires three source-contact classes:

1. **WHOLE_BLOCK_SOURCE** — a compact, coherent original-Lecture unit can be consumed continuously before local retrieval.
2. **NATURAL_SOURCE_UNITS** — a long/visually dense/multi-center Block should use a small number of genuine Source sub-units; each sub-unit may contain several Logic Groups.
3. **INTEGRATION_PRIMARY** — no new continuous Primary Lecture exists; KianOS may own the synthesis/retrieval action while the learner returns selectively to already-owned Source figures/sections. This is not permission to turn KianOS into a second textbook.

Hard rule:

> **Logic Group count never determines Source-contact count.**

## 6｜Cognition-specific LG jobs

Descriptive jobs, not a mandatory enum:

- `MECHANISM_CHAIN` — upstream event → intermediate mechanism → output.
- `LAYER_LOCALIZATION` — identify where in neural/structural hierarchy failure first occurs.
- `TRANSDUCTION_CODING` — stimulus → receptor potential → AP/spatial/frequency code.
- `SPATIAL_VISUAL_MODEL` — retrieve geometry/tract/force/displacement/film relationships that prose alone cannot safely substitute.
- `CONTROL_LOOP` — setpoint/input → controller → output → feedback.
- `DISCRIMINATION` — separate near neighbors by decisive conditions.
- `EVIDENCE_STACK` — assign imaging/pathology/exam findings to their actual diagnostic role.
- `STRUCTURE_STABILITY_DANGER` — identify injured structure, stability and time-sensitive neurovascular/space risk.
- `FORCE_DISPLACEMENT_FUNCTION` — external force + muscle pull → displacement → complication → functional goal.
- `SOURCE_CONTROL` — anatomy/dead space/necrosis → why antimicrobial treatment alone may fail.
- `GROWTH_TIME_WINDOW` — age/growth/load → reversibility and treatment window.
- `PRECISION_CLUSTER` — tightly coupled Source-specific number/classification/treatment precision whose separation would increase error.
- `INTEGRATION_BRIDGE` — compress already-learned owners into a new decision coordinate without duplicating their Primary content.

## 7｜Visual and Source-conflict gate

D has unusually high spatial/visual dependence.

A Logic Group may require a `VISUAL_REQUIRED` closure when the decisive relation is spatial, for example:

- tract / field / root / nerve localization;
- eye/ear transduction geometry;
- force direction and fracture displacement;
- joint congruity / blood supply / compartment relation;
- radiographic tumor pattern.

Rule:

> A verbal summary can support orientation and recall, but it cannot certify a visual-dependent relation that the learner has never contacted in the original Source.

O1–O5 current repository visual-source gaps remain engineering/Source debt. L may preserve the requirement and locator intent; it may not manufacture visual closure.

Source conflicts are surfaced only when they can affect a 306 judgment. L may route them to Source context / Precision handling but does not decide them by medical common sense.
