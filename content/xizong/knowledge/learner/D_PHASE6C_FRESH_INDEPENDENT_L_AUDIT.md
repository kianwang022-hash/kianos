## 7｜Material defect — hard-readiness semantics

The candidate's default route is a reasonable low-switching **recommendation**. The material defect is that `system_route.requires` still promotes several helpful/reordered relations into **hard legality**.

Audit rule applied literally:

> Delete the edge. If the later Block can still form from its own Primary Source without hidden guessing or full duplicate teaching — possibly with a bounded local reactivation — the edge is not hard.

### 7.1 False hard edges

#### Neural primary-Source Blocks

Current hard edges that fail the delete-edge test:

```text
N1 → N2
N2 → N3
N2 + N3 → N4
N1 + N2 → N5
N5 → N6
N5 → N7
N2 → N8
N2 → N9
N2 → N10
```

Why this is not merely theoretical:

- N4's Primary physiology Source is P46–59 and teaches the NMJ / skeletal-muscle chain as its own Source object; it is not causally dependent on later N1–N3 Lecture sections.
- N6/N7 occupy P297–325 while N5 occupies P326–336. N5-first is a useful KianOS reordering that gives a common sensory language, but the original Lecture itself forms vision and hearing before N5. Therefore `N5 → N6/N7` cannot be hard legality.
- N5 occupies P326–336 while N1/N2 occupy P337–355. Again, N1/N2-first may improve coherence, but N5 owns and explains its sensory transduction/coding model.
- N9 owns EEG/sleep/wake network-state formation; full N2 is helpful reactivation, not a necessary legal gate.
- N10 contains two distinct Source centers; making the whole Block hard-dependent on N2 over-gates the hypothalamic unit even if N2 improves the learning/plasticity unit.

These relations belong in `default_route` and/or `benefits_from`, not hard `requires`.

#### Orthopedic Primary-Source Blocks

Current hard edges that fail the same test:

```text

O2 → O6
O2 → O7

```

Evidence:

- O11 has two distinct Source/cognitive centers. LG01–LG04 are chronic load / soft-tissue / growth models and do not consume N11. Only LG05's root-vs-named-nerve entrapment discrimination materially benefits from N11. A Block-level hard gate therefore locks unrelated first learning.
