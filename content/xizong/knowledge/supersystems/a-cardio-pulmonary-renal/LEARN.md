## 0｜Highest rule: A does not earn learner time by existing

A is a taxonomy parent and compression/routing layer. That does **not** create a required learner step.

Default learner-facing A action:

> **nothing.**

A-level interaction is admitted only when it is cheaper than reconstructing the same cross-System relation from separate child Systems.

Hard rules:

- no mandatory A Orientation;
- no mandatory A Recall;
- no A completion gate;
- no A Memory/review queue;
- no A question quota;
- no requirement to visit an A page before/after A1/A2/A3;
- stable correct learner fast-passes without A ritual;
- Wrong / Uncertain opens only the smallest responsible seam/child owner.

## 1｜First pass: zero additional mainline

The existing child mainline remains unchanged:

```text
A1 / A2 / A3 System orientation
→ Block / Logic Group + original Lecture
→ KP retrieval / closure
→ Block Recall
→ System Recall
→ System question sweep
→ smallest sufficient repair
```

A is **not inserted** above or between these steps.

### Allowed A behavior in first pass

Only a light **reactivation / connection cue** is allowed when a child owner is already crossing a seam and the cue reduces confusion.

Examples:

- A2 gas-transport learning may briefly reactivate that tissue delivery also depends on circulation flow;
- A3 volume/RAAS learning may reactivate the circulation side of perfusion and effective circulating volume;
- A3 acid–base integration may reactivate A2 PaCO₂ as the respiratory component.

These are `CONNECTION_HOOK`-like actions:

- no extra memorization target;
- no score/rating interaction;
- no completion state;
- no ordinary Memory admission;
- no detour into the other child System's full content.

If the child content already expresses the seam sufficiently, **show no additional A cue at all**.

---

## 2｜Second pass: highest-value trigger window

A-level compression is expected to have its highest potential value in second pass, but still remains **evidence-triggered**, not scheduled by symmetry.

A may activate when one of these occurs:

1. a mixed question/case genuinely requires knowledge from more than one A child System;
2. Wrong / Uncertain evidence shows that the failure is at a cross-System seam rather than inside one child;
3. the learner repeatedly reopens two child Systems to reconstruct the same relation;
4. comparison/discrimination across children is materially slower than one compact seam reconstruction.

### Allowed second-pass actions

- reactivate the relevant seam only;
- localize the first failure before opening detailed child content;
- route to the smallest responsible child owner(s);
- after repair, return to the interrupted question/review path.

### Fast-pass rule

If the learner answers correctly **and** can state the decisive cross-System reason, do not require an A Recall, explanation panel, checkpoint or closure action.

```text
stable correct
→ pass

correct but guessed / seam unclear
→ Uncertain
→ optional seam cue / targeted repair

wrong
→ identify first failing seam or child owner
→ smallest sufficient repair
→ return
```

A-level cue should normally appear **after an independent attempt** when showing it earlier could leak the reasoning path.

## 3｜Late review / final sprint: only if it saves retrieval time

A may survive into late review only as an extremely thin retrieval skeleton.

Candidate rapid cues are limited to:

```text
O₂ delivery: oxygenation / content / flow / use
Perfusion↔volume: circulation → kidney → volume → future circulation
Acid–base: PaCO₂ ↔ HCO₃⁻/H⁺ → A3 B5
```

No long A document should be reread in final sprint.

If opening the A skeleton is slower than directly recalling the relevant A1/A2/A3 model, **skip A entirely**.

A has no independent spaced schedule. It may be reactivated by:

- a real mixed-case weakness;
- Wrong / Uncertain evidence;
- learner-requested rapid reconstruction;
- final-sprint need for faster switching.

---

## 4｜Repair and evidence semantics

A-level integration must never manufacture mastery.

A seam failure may help locate repair, but durable medical learning evidence remains attached to the real child owner whenever a child object is responsible.

Examples:

- oxygenation concept wrong → repair A2;
- CO/perfusion concept wrong → repair A1;
- RAAS/Na-water handling wrong → repair A3;
- acid–base algorithm wrong → repair A3 B5;
- Hb-content failure → route to C/Hematology when formally available.

If the learner knows both child facts but fails only to connect them, A may retain a **repair-only cross-System note/cue**, but this must not become an independent A mastery ladder or recurring Memory object by default.

> **repair evidence ≠ mastery; routing evidence ≠ medical truth.**
