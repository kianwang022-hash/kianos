# 食管与胃肿瘤：来源、深度与治疗目标

> 同样是上消化道肿块，为什么症状、取材深度、淋巴处理和治疗方法不能照搬？

<a id="identity-depth"></a>
## 肿瘤需要来源、屏障与深度三个坐标

先把肿瘤放回正常组织：食管以鳞状上皮为背景，胃以腺上皮为背景；Barrett改变下段食管上皮身份，才产生腺癌接口。细胞与结构异型帮助判断异常程度，一般分化越差、异型越明显，恶性倾向越高，但器官、来源、侵犯和扩散仍需各自证据。共同肿瘤语言在这里服务于定位，无须重新占有共同病理或全部肿瘤类型。特殊血道转移例外的课程名单见同一底稿[四条扩散路线把局部肿块连到远处](#spread)。

管壁从上皮、基底膜、固有层、黏膜肌层到黏膜下、固有肌层，再到外层或邻器官。原位癌没有突破基底膜；黏膜内癌突破上皮边界但仍在黏膜内；进入黏膜下尚未等于进入固有肌层。食管/胃早癌以未侵固有肌层为深度门槛，可有局部淋巴结转移；大小不是定义，远处转移也不是这份早癌身份的适用场景。肺的早癌淋巴限定不能直接搬来。

“没有侵肌层”只给出上限，不能据此推出“已经到黏膜下”。原位、黏膜内和黏膜下都可能尚未侵肌层，所以证据必须指明实际到达的层。再把来源、局部深度、区域淋巴、远处四项分别记录，后面的早癌局部切除与根治判断才不会互相代替。

<a id="esophagus"></a>
## 食管管腔失效连接进行性吞咽困难

食管三处狭窄在起始、左主支气管交叉、膈肌裂孔。胸中段癌最多；中国以鳞癌为主，欧美腺癌较多，后者联系下段Barrett。这里组织型与地区只是候选概率，活检仍完成身份。

早期食管癌仍按未侵固有肌层判断。中晚期大体有髓质、蕈伞、溃疡、缩窄四型：髓质最常见、纤维较少而软；蕈伞向腔内成块；溃疡型较少早期梗阻，但后期瘢痕也会窄；缩窄型纤维多、较早梗阻。没有必要另加一个独立息肉型。肿瘤逐渐减少管腔通畅，产生进行性吞咽困难；GERD痉挛或贲门失弛缓的间歇性模式提供比较，不能以一时吞咽正常排除进展。

邻近侵犯把症状变为定位工具：喉返神经受累声音嘶哑，颈交感受累可Horner的上睑下垂、瞳孔缩小、眼球内陷、少汗，侵气管形成瘘则进食后呛咳。内镜活检是首选/金标准；拉网脱落细胞学偏筛查；钡餐充盈缺损、僵硬、狭窄增加怀疑，却不独立确诊。

可切除病变按当前Study根治切除，上下缘至少5–8cm，并以胃最常用于重建连续性。颈段/胸上段距门齿小于25cm，或远处转移，当前Source列放疗方向；鳞癌放射敏感与某些位置难取安全切缘帮助解释选择。它们不构成“血供少便一律化疗差”的跨肿瘤规律。治疗目标同时问可否安全切除、能否恢复通道及是否已有远处病灶。

<a id="gastric-background"></a>
## 胃癌风险、早癌定义与局部切除是三个门槛

胃癌好发胃窦小弯。HP、亚硝胺、慢性萎缩性胃炎尤其结肠型不完全肠化、腺瘤性息肉及异型增生组成当前高危背景；胃溃疡边缘也可异型增生。这里的HP入口回接同一D10底稿：HP持续黏膜损伤→慢性炎症、腺体萎缩与肠化→异型增生及胃癌风险增加。持续损伤见[病原机制决定检测与根除后的复查](../../bf-lecture-replacement-r2-review/without-annotations/B/d10.md#hp)，细胞身份改变和异型风险见[慢性炎症改变细胞数量、身份与反馈](../../bf-lecture-replacement-r2-review/without-annotations/B/d10.md#remodel)。这是风险链，不能据此断定个体必然发生癌变，也不能替代当前组织取材。

早期胃癌仍局限黏膜/黏膜下，未侵固有肌层，可有局部淋巴结转移。大体凹陷型最多，另有隆起与表浅；微小癌不超过5mm，小癌6–10mm，一点癌为活检发现而后续切除标本未再找到，提示微小灶已由活检去除。这些大小身份没有更改早癌的深度定义。

进入当前ESD选择还需小于2cm、无溃疡、分化型黏膜内癌，并满足原外科P032手写的无淋巴结转移条件。早癌允许区域淋巴转移，ESD并不因此允许：前者命名深度，后者控制局部切除能覆盖的风险。若仅知道“早期”，仍欠黏膜内身份、分化、溃疡、大小与结点条件，不能跳到局部治疗。

<a id="gastric-form"></a>
## 进展形态与组织学回答不同问题

进入固有肌层等进展阶段后，粗大体分溃疡、息肉/蕈伞、浸润三类；Borrmann再分I型界清肿块、II型界清局限溃疡、III型溃疡浸润、IV型弥漫浸润。III型最多，IV型最差，纤维与弥漫浸润使胃壁僵硬成为革囊胃。粗分和四型是同一观察的不同细度，不能把二者并排当七个互斥类型。

胃癌组织学以腺癌为主。黏液在细胞外，且超过肿瘤50%，形成黏液癌/胶样癌的黏液湖；黏液在细胞内把核挤到一侧，形成低黏附的印戒细胞方向，更容易脱落与种植。少见的贲门鳞癌、腺鳞癌、未分化癌、类癌仍属识别接口。大体溃疡型不等于某个唯一细胞型，细胞内外黏液也不能自己完成深度分期。

因此读标本时先定位深度，再说宏观生长方式，随后说细胞与黏液位置；每一步保留观察职责，后面才把它们接到取材、扩散和治疗。原图中的形态与空间入口保留，当前文字没有产生新的像素核验。

<a id="spread"></a>
## 四条扩散路线把局部肿块连到远处

胃癌可以直接侵邻组织、经淋巴、经血道、脱落种植。淋巴是最早、最常见方向，经胃周结点及胸导管可到左锁骨上Virchow；血道经门静脉，肝是典型首站；腹腔种植可到双侧卵巢，尤其印戒细胞癌形成Krukenberg。当前Source也保留卵巢经淋巴/血道的可能性，不能把所有卵巢转移都定为唯一种植机制。食管、胃左锁骨上与肺典型右侧接口应按来源理解。 当前病理不带导图PDF物理P022给出了该精确Recall的课程支持：绒癌、肝细胞癌、甲状腺滤泡癌、肺腺癌列为最早最常血道转移的特殊名单，对照普通癌的淋巴转移倾向；这是一份课程识别表述，不外推为每例先发生同一种转移。完整共同肿瘤课不在这里重建；原O9固定支持owner缺位继续记录，而本槽的名单可直接在本节复习。

分期把上述证据编码而不是重新确诊。Tis为原位；T1a到固有层/黏膜肌层，T1b到黏膜下；T2固有肌层；T3浆膜下而未穿浆膜；T4a穿浆膜，T4b邻器官。N0无区域阳性结点，N1为1–2枚，N2为3–6枚，N3不少于7枚；M独立记录远处。EUS侧重T深度，CT/MRI侧重N、M。一个T1仍需单独记录N，早癌称谓不会删去区域风险。

若病理只提供黏膜下而影像又提示区域结点，二者可以同时成立，不能为保住“早癌”而忽略结点。治疗选择要接收完整的局部、区域、远处输入。

<a id="evidence"></a>
## 胃部症状与溃疡外观只引出取材

中老年腹痛失去既有节律、持续痛、消瘦、贫血，保守处理无效，隐血持续阳性、酸明显下降或缺乏，是胃癌入口；无痛仍不能排除。内镜活检完成确诊，隐血偏筛查，CEA偏辅助、预后与复发判断，不能以标志物替代组织身份。确诊后才由EUS、CT/MRI分别解决深度、区域和远处。

溃疡外观需要八轴一起比较。良性偏圆/椭圆、小于2cm、较深、清楚如刀切、底平坦，皱襞因瘢痕牵拉向病灶集中，钡龛影在胃轮廓外，酸正常或低；癌性偏火山口/盘状、大于2cm、相对较浅、边缘不规则隆起，底坏死出血，皱襞中断或结节，龛影位于壁内可有环堤，酸明显低乃至缺乏。大小、深浅或酸任何单项都不是身份裁决。

胃壁僵硬、皱襞中断与不规则充盈缺损使影像可疑；持续出血和体重变化使病程可疑；最终在边缘等位置取材获得病理。反事实是：即便病灶缩小，若仍有这些警报也不能宣告良性；即便较大，也还需要排除其他来源的大块肿瘤。

<a id="other-lineages"></a>
## 换了来源，取材与治疗也随之改变

胃腺癌来自腺上皮，浸润与纤维反应可使壁僵硬、蠕动中断。胃淋巴瘤来自黏膜相关淋巴组织，当前Study连接非霍奇金/MALT；肿块可很大而蠕动仍通过，内镜可卵石样，EUS看深度、结点并帮助深部活检。相似的体积、不同的壁运动，促使问题从“癌有多大”改为“是哪一类细胞”。Source列CHOP和抗HP路径，是否进入何者取决于病理类型、范围与反应，不能要求每个胃淋巴瘤两者同时用。

GIST来自未定向分化间质细胞，既非腺癌也非淋巴瘤。风险按部位、大小、浸润深度、核分裂/有丝分裂指数与转移综合；CD117/KIT提供支持与伊马替尼靶点接口，Source配对手术与药物。该配对保留KIT阴性和不同分子敏感性的边界，所以标志阴性不自动排除，每个病例也不自动对相同药敏感。较少走腺癌模式的淋巴转移，解释不常规淋巴结清扫。

三者在来源、壁运动、支持性标志、取材深度、淋巴处理、治疗目标上比较。这里聚焦GIST的CD117/KIT—伊马替尼；EGFR肺、ABL白血病、CD20淋巴瘤和HER2乳腺配对回各自章节。现有NCI/GEIS引用只限定这些治疗前提，不新增完整分型或方案。

<a id="treatment"></a>
## 局部、根治与姑息由证据决定

胃癌根治同时处理原发与区域引流，可全胃、近端或远端胃大部切除，配D2淋巴结清扫。当前切断线距肿瘤边缘大于5cm，端部癌额外切食管下端或十二指肠第一部3–4cm。精确组别按Study保留：胃窦癌远端切除不清第2、10组，全胃或远端均不清第13–16组。只挖肿块不能覆盖局部切缘与区域风险，这也解释根治与前面的局部ESD条件为何不同。

邻器官受侵可进入扩大/联合切除，涉及肝、脾、胰、横结肠等；无法根治而出血、穿孔、梗阻时，姑息控制并发症、恢复通道成为目的。当前Source化疗保留S-1±顺铂名称，不展开剂量。不是所有“做了手术”都叫根治，也不能只因有并发症便假定可根治。

整条病例链先辨入口：进行性吞咽困难偏食管管腔问题；GU节律消失、消瘦、持续隐血偏胃腺癌取材；大肿块而蠕动通过考虑淋巴来源；间质背景与KIT支持考虑GIST。内镜病理确定来源，EUS与CT/MRI分别补深度、区域和远处，再选择严格条件下局部治疗、根治或姑息。危急出血、穿孔、梗阻先处理生命和通畅问题，同时取得后续肿瘤证据。

食管与胃都可内镜活检，却在常见部位、组织型、主症、大体生长、扩散和重建目标上有各自模型；胃内三种肿瘤更不能凭器官名共用同一淋巴清扫或药物。答案由真实的来源、侵犯和风险层组合产生，章末的名称只是回到这些位置的入口。
