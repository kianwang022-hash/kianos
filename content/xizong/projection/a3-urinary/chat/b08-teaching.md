# 尿路感染：先找感染所在的位置，再解释为什么会持续和上行

B6的WBC只是炎症证据，并未直接告诉病原和位置。普通细菌尿感多上行，女性较常、大肠埃希菌最常；课程女性尿道短宽直是简化解剖入口。下尿路当前主要膀胱炎，上尿路肾盂加肾间质；肾结核虽在肾却可膀胱刺激，不混进普通菌链，留B13。

> 定位（可略读）：尿感总入口：上行最常见；女性多；E.coli多〔途径/性别/病原主轴｜上vs下尿路｜结核边界〕；为什么女性更常见：Study先抓“尿道短、宽、直”〔女性解剖3词｜结果1｜考试边界。〕。

## 刺激症、全身反应和肾区体征，分别回答哪一层

尿频、尿急和尿痛提示下尿路刺激，不能直接宣布只膀胱炎；肾盂肾炎若没有明显波及膀胱也可缺刺激。发热/血WBC、CRP高是全身轴，腰痛或肋脊角叩/压痛是肾区轴，与菌尿脓尿合看。

尿NAG、β₂微球升、小管浓缩下降，WBC管型形成在肾内，都支持小管/实质受累；血培养阳性支持菌血播散。旧输尿管导尿培养、膀胱冲洗后培养是定位接口。WBC管型价值高却非必要，没有不能单排肾盂肾炎。膀胱炎通常没有高热、明显血液炎症指标升高或肾区痛，两者都可菌尿脓尿，所以仅尿WBC不是上尿路专属。

> 定位（可略读）：肾盂肾炎证据：全身反应 + 肾区 + 小管 / 肾实质支持证据〔临床2轴｜肾实质证据｜小管标志2｜定位培养2｜浓缩功能｜WBC管型非必需〕；急性膀胱炎 vs 急性肾盂肾炎：局部刺激 vs 全身 + 肾区〔膀胱vs肾盂6轴｜局部/全身/肾区｜菌尿/脓尿｜管型支持性｜刺激征可缺〕。

亚硝酸盐是能还原硝酸盐的常G⁻筛查，高特异但有限敏感，需要足够硝酸盐和膀胱停留；阴性不能一概排菌。课程脓尿WBC>5/HP，可伴RBC>3/HP、蛋白>0.15g/d，仍是炎症而非培养证据。

清洁中段培养≥10⁵CFU/mL、沉渣涂片菌>1/HP、膀胱穿刺培养阳性是课程真性细菌尿三证据。10⁵为经典中段/ASB高特异锚，有症状较低菌量也可有意义，导尿穿刺另有解释条件，不到10⁵不等绝不UTI。

> 定位（可略读）：亚硝酸盐 + 脓尿：一个筛菌，一个看炎症〔亚硝酸盐对象/效度｜成立2条件｜脓尿阈值｜伴血/蛋白｜定位边界〕；真性细菌尿：10⁵是经典清洁中段尿锚点，不是所有有症状UTI的万能门槛〔真性菌尿3证据｜中段尿阈值/条件｜有症状低菌量｜穿刺｜菌量vs炎症〕。

## 尿流与结构决定细菌能否被冲走

畸形、结石、肿瘤、BPH、妊娠、VUR反流、糖尿/截瘫神经膀胱及宿主风险，令尿不畅、逆行机会多、更持续上行复发或系统感染。器械亦增机会。旧清洁中段≥10⁵加异常定义复杂、男性基本复杂的考试分类保留，却不把菌量当复杂机制或男性当所有现代体系永久唯一分类。完整残尿/梗阻后接B12。

病原场景提示在这个空间内使用：普通E.coli，结石变形杆菌，血源金葡，器械后铜绿是假定课程挂钩，不由见某菌反推全部病因。

> 定位（可略读）：复杂化核心：尿流 / 结构 / 反流 / 器械 / 宿主风险；男性归类是Study口径〔结构/功能7例｜男性分类边界｜持续/上行/复发风险｜菌量≠复杂性｜梗阻接口〕；特殊病原挂特殊场景：结石、血源、器械〔E.coli规律｜3特殊菌｜各自场景｜不要从菌名单反推全部病因。〕。

感染伴梗阻恶化尤其不能只加抗菌药。再发热、剧烈腰痛/绞痛、血尿可肾乳头坏死，脱落组织堵输尿管，可合败血休克AKI；另有肾盂积脓、肾周脓肿。尿源脓毒症课程梗阻最常见风险，高龄、糖尿、免疫抑制、留导尿、泌尿手术也有，需及时评解除阻塞/源控制，完整方法和复苏仍后owner。

> 定位（可略读）：K8最终病例算法：刺激征→全身→肾区→肾实质证据→复杂化条件〔5步定位｜并发症3组｜梗阻源控制｜慢性小管｜结核边界〕。

## 有菌但无症状，是另一条决策分支

规范培养达到ASB标准而无尿感症状，经典中段≥10⁵。女性通常两份连续同菌/相符量确认持续，男性一份合格培养即可用于确认，旧两次同菌不男女通用。妊娠与将行有尿黏膜创伤的内镜/操作是高收益治疗轴；健康非孕、儿童、许多老人、糖尿、长期导尿、脊髓伤一般不常规筛治。妊娠尿流/反流可提高上行风险，并不是每个检出细菌的人都需要用药。

> 定位（可略读）：无症状细菌尿：先确认“无症状 + 持续菌尿”，再问是否属于高收益治疗人群〔无症状｜菌量阈值/单位｜男女留样｜治疗2类｜不治人群。〕。

需要治疗的感染，先留尿菌标本保障培养，再及时经验治疗，药敏到或临床无效再调整，不能等药敏放任上行播散。课程>72h无效复评是精确口径，严重度、结果、梗阻脓肿要动态源控制。

> 定位（可略读）：先留尿标本 → 立即经验治疗 → 药敏 / 临床无效再调整〔治疗3步/时序｜培养保真vs及时控制｜药敏/复评时点/源控制〕。

疗程跟位置宿主持续性走。旧课程规定，年轻非孕膀胱炎患者疗程3日；免疫功能低下、糖尿病、老年、妊娠或男性患者疗程7日；停药7天后培养仍阳性时延长2周，是课程路线而非所有患者统一方案。症状已无的培养阳不能自动延，先ASB或症状复发/特殊妊娠操作，普通无症状亦不常规治疗后培养。

旧课程列急性肾盂肾炎疗程2周、同一病原复发疗程6周；半年≥2次时采用低剂量抑菌6月；停药6周内同菌株支持复发、之后或不同菌支持再感染。保存时间加菌身份、位置、宿主结构的轴，不升固定现代抑菌处方。

> 定位（可略读）：急性膀胱炎：3日 → 7日 → 2周是当前Study疗程图〔短程对象｜延长5组｜再延长触发｜3疗程/边界。〕；急性肾盂肾炎：2周 / 复发6周 / 频繁发作6月 = Study-specific考试路线〔基础疗程｜复发病原/时距｜频发次数/时窗｜长期方案/疗程｜再感染vs复发。〕。

## 药物要在感染位置达到效应，不能只从尿中名字选

课程常磺胺、β内酰胺如阿莫西林/头孢、喹诺酮；膀胱一线SMZ-TMP、呋喃妥因、匹美西林，其中后两不能整套上移治肾盂，要肾实质/系统有效暴露、药敏耐药。莫西沙星的尿中浓度不适合常规UTI治疗。孕期课程避磺胺喹诺用β内酰胺，未展开细药理。

氨基糖苷类有肾毒性和耳毒性风险，不适合简单膀胱随意首选，但严重住院肾盂/系统感染在合适患者可静脉方案，须肾功能病原药敏及毒监；不是所有UTI绝对禁。这里保原名和已review边界，不扩完整处方。

> 定位（可略读）：常用抗菌药 + 膀胱炎一线 + 莫西沙星 / 妊娠 / 氨基糖苷边界〔常用3类｜膀胱炎一线3｜莫西沙星/妊娠｜氨基糖苷毒性与适用场景〕。

## 长期反复留下的瘢痕，先损小管而不是先损肾小球

反复上尿路感染/化脓炎到纤维化，胶原收缩导致瘢痕、不对称缩小、盂盏变形缩窄。早期浓缩能力下降，出现夜尿、尿比重和渗透压降低；随后分泌和酸化功能受损，可出现RTA及旧PSP试验降低；后期GFR和Ccr下降，Cr和BUN升高，出现水肿与高血压。没有被识别的急病史也不排。旧>6月、IVU金标准仅题源，不成永久定义/技术金标准。

急性期以中性粒细胞为主，慢性期以淋巴细胞和浆细胞为主，课程将两者放在同一化脓性炎症谱中；部分小管萎缩、部分代偿扩张，扩张腔均质红染胶样管型，形似甲状腺滤泡称甲状腺化。项目无独立肾病理Lecture，只保内科明示形态，未扩一套一般病理。

> 定位（可略读）：慢性肾盂肾炎：反复上尿路感染 → 瘢痕 / 不对称 → 小管功能持续损害〔主机制｜Study病程阈值｜Study影像金标准｜结构3｜小管2功能｜晚期肾小球4证据。〕；慢性病理身份：化脓性炎 → 纤维化 → “肾小管甲状腺化”〔急/慢炎细胞｜化脓谱→纤维化｜甲状腺化3件｜小管间质vs肾小球〕。

刺激却无全身、无普通真性细菌尿是课程尿道综合征：非感染性情境可没有脓尿；支原体或衣原体等感染可出现脓尿，仍不同普通菌膀胱炎，完整STI后置。持续刺激而普通培养解释不了，再把肾结核留B13。

最终从刺激→全身/肾区→小管实质支持→结构功能风险→慢瘢痕看位置和持续机制，遇急坏还查乳头、脓肿、脓毒症及梗阻。下一组章会将尿蛋白/血尿的另一条主干放进肾小球免疫模型，而非把所有尿异常归感染。

> 定位（可略读）：尿道综合征：刺激征 + 无全身症状 + 无普通真性细菌尿〔3个否/有｜2分类｜脓尿方向｜支原体衣原体边界｜vs膀胱炎。〕；K8最终病例算法：刺激征→全身→肾区→肾实质证据→复杂化条件〔5步定位｜并发症3组｜梗阻源控制｜慢性小管｜结核边界〕。
