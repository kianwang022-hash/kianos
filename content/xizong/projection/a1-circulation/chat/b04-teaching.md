# B4｜破口处封与固，外围限，纤溶清

局部解释以同一当前版本的 [B4正式模型与Core](../../../knowledge/systems/a1-circulation/blocks/Block4_正常止血与病理循环整合_学习阅读版_v1_Batch2冻结版.md) 为准；文内旧快照与行号只保留历史定位，当前内容按知识身份、标题定位。

循环不仅要送血，还要在破口处止血、在其余地方保持流动。以下是同一局部反应的主链、反馈和失衡分支；不是六个依次启动的小系统。〔完整Prompt〕附在自然节点上，解释可就地展开。

<!-- b4:route:start -->
血管损伤 → 局部缩口＋血小板封口；TF启动与血小板PL平台共同促凝 → 凝血酶放大 → 纤维蛋白生成／聚合 → XIIIa交联 → 回缩加固。

从开始就有抗凝／正常内皮／血流限制扩展；纤溶贯穿平衡并清除网。失衡成栓后，原位阻塞与脱落栓塞分路，只有达到组织缺血性坏死条件才成为梗死。

# 伤口处的耦联模型：封口与加固

## 从“血在流失”到“破口被暂时封住”

血小板反应既构成初级血小板栓，也提供促凝反应平台。凝血与血小板反应相互耦联；凝血复合物利用活化血小板提供的平台。

```text
损伤
├─ 收缩：神经反射＋肌源反应＋局部介质 → 减少失血
└─ 胶原暴露
   → 胶原—vWF—GPIb → 血小板黏附
   → 血小板活化
      ├─ ADP释放、TXA₂生成 → 更多血小板加入 ↺ 局部放大
      ├─ GPIIb/IIIa活化 → 纤维蛋白原桥接 → 聚集 → 初级栓
      └─ 促凝磷脂面暴露 → 凝血因子组装 → 支持凝血复合物组装

邻近正常内皮：PGI₂/NO → 抑制血小板反应、舒张
已有纤维蛋白网以后：血小板与网相连 → 收缩 → 凝块回缩
```

### 1｜先把两个连接对象分开，再填名字

收缩只是在减少局部失血，并没有把血管破口封起来。血小板还得先停在正确位置。

正常内皮原本把血液与内皮下结构隔开；损伤后胶原暴露，vWF把胶原与血小板GPIb连起来。连接的两端是“血管壁—血小板”，所以叫黏附。

接着要解决另一件事：一个血小板抓住壁，不等于很多血小板已经连成塞。活化使GPIIb/IIIa进入高亲和状态，纤维蛋白原在Ca²⁺参与下桥接相邻血小板。两端变成“血小板—血小板”，所以叫聚集。

```text
抓住壁：胶原—vWF—GPIb
连彼此：GPIIb/IIIa—纤维蛋白原—GPIIb/IIIa
```

编号不能靠逻辑凭空推出来，必须记；但“两个名字各该放哪里”可以由连接对象稳定地恢复。这里作桥的是纤维蛋白原，不能提前换成后面的纤维蛋白网。

### 2｜活化不是黑箱：它同时解决数量、连接和平台

ADP释放、TXA₂生成后，会募集和活化附近血小板。新加入者又释放或生成介质，局部信号因此放大。募集回答“参加的血小板够不够”，聚集回答“参加者能不能连起来”；两者配合，但不是同一个动作。

活化还有第三个关键结果：提供促凝磷脂反应面。它让凝血因子在局部集中、组装，因此血小板既是构成初级栓的材料，也是凝血反应的平台。PL不会自己变成纤维蛋白。

这也说明“五动作”不是五道必须依次完成的工序。黏附、释放、聚集与平台形成可以相互促进。收缩则必须等到已有可牵拉的网以后再接回来。

### 3｜临时封口为什么还不够

血管收缩加血小板栓构成一期止血，快，但相对松软。二期止血需要纤维蛋白加固。已有网后，血小板通过连接结构牵拉纤维蛋白，在Ca²⁺、ATP参与下收缩，使凝块回缩、变致密并挤出血清。

一期和二期是相互耦联的过程：活化血小板为凝血提供平台，凝血生成的纤维蛋白又加固血小板栓。

因此“血小板收缩”不是“血管收缩”：前者拉紧已有的网，后者减小局部血流和失血条件。它们属于KP02，但在模型里出现在两个合适位置，不必因为同属一个KP而挤在一起讲。

### 4｜局部放大怎样与外围限制同时成立

损伤处的TXA₂促进聚集和收缩；邻近正常内皮的PGI₂、NO抑制血小板反应并促进舒张。不能只画一条无限增强的正反馈。

这里先处理血小板反应的范围。抗凝限域同时处理凝血酶等活化因子的扩展，两者有关联，但不是同一层“刹车”。

### 故障推演示范

“能黏在壁上，却连不起彼此”：先定位到聚集连接，再回查GPIIb/IIIa活化、纤维蛋白原桥接等。这个描述不能唯一确诊某种受体病。

“血小板少了为什么也影响凝血”：不只丢失封口材料，还可能减少局部反应平台。这是从同一细胞的两种身份推出后果。

### 精确记忆的归位

- 三类收缩来源：神经、肌源、体液；体液再分血小板TXA₂/5-HT与内皮ET
- 颗粒按“预存位置”记：致密体的ADP、ATP、5-HT、Ca²⁺；α颗粒的PF4、β血小板球蛋白等；TXA₂另放新合成，不混成三种储存颗粒
- 黏附缺陷接口：GPIb异常、vWF异常；聚集缺陷接口：GPIIb/IIIa异常或桥接物问题
- 两条抑制信号：PGI₂—cAMP；NO—cGMP。只记配对不能替代共同结果
- 两相聚集按相应实验刺激下的观察模型处理：第一相快、可逆；内源介质放大后第二相较慢、不可逆，不能说所有体内止血都整齐分成两段
- 血清是凝固后的液体，较血浆少了纤维蛋白原等被消耗成分，不能说所有凝血因子全部消失

收束：**先抓住壁 → 再募集并连起彼此；同时搭平台，等网形成后再拉紧。**

## 从“临时塞”到“稳定网”：凝血酶如何被放大

在与血小板反应的耦联中，凝血利用活化血小板提供的PL平台加固止血栓：局部怎样产生足够的凝血酶，把可溶原料变成网，再让网更牢。产出是稳定加固的凝块；随之而来的问题是怎样限制强大的放大系统。

```text
组织损伤 → TF暴露 → TF–VIIa
                     ├─ 激活X → 第一批Xa → 少量凝血酶
                     └─ 激活IX                 │
                                              ├─ 激活V、VIII、XI
                                              └─ 激活血小板

XI → XIa → 激活IX；IXa与已活化的VIIIa在PL平台上组装
                           ↓
              IXa＋VIIIa＋Ca²⁺＋PL → 大量Xa
                                          ↓
                           Xa＋Va＋Ca²⁺＋PL
                                          ↓
                               II → IIa凝血酶
                                          ↓
                 纤维蛋白原 → 纤维蛋白 → 聚合成网
                                          ↓
                               XIIIa交联稳定
                                          ↓
                      加固初级栓＋血小板牵拉回缩
```

图中重复出现Xa是为了显示启动与放大的关系，不是两种Xa。凝血因子不是在几秒内重新大量合成，而是已有酶原被局部激活，反应效率迅速提高。

### 1｜先明确最终任务，再倒推两台机器

身体不是为了“激活一串号码”而凝血。当前功能任务是：生成纤维蛋白，形成稳定支撑。

凝血酶把纤维蛋白原转为纤维蛋白；纤维蛋白可以聚合，XIIIa再催化共价交联，使网更稳定。不要把“聚合”和“交联”混成同一步，否则容易错误推出“没有XIII就完全不能先形成纤维蛋白凝块”。

现在倒推：要制造凝血酶，需要Xa与Va等在平台上组装；要大量制造Xa，需要IXa与VIIIa等组成另一套复合物。

```text
IXa＋VIIIa＋Ca²⁺＋PL → 造Xa
 Xa＋ Va ＋Ca²⁺＋PL → 造凝血酶
```

两组都用Ca²⁺和PL；主酶分别是IXa、Xa；VIIIa、Va主要是辅因子。这样记的是两台机器的输入、搭档和产物，不是一张互不相干的号码表。

### 2｜为什么少量启动信号可以变成局部爆发

TF途径先产生少量Xa和凝血酶。少量凝血酶又激活V、VIII、XI以及血小板，使“制造Xa的能力”和“Xa制造凝血酶的效率”都上升。

```text
少量凝血酶
→ 更多辅因子、活化血小板与上游放大
→ 更多Xa
→ 更多凝血酶
↺ 再增强上游
```

这就是正反馈。它不是另一个游离于母链外的知识点，而是解释“为什么局部很小的起始信号能快速产生足够产物”的一条回路。

XIII也可被凝血酶激活，但它主要加固产物，不与V、VIII、XI、血小板一样归入回头增加凝血酶的四支反馈。

### 3｜体外两条检测路径，不能原样当体内两条独立起跑线

传统内源检测链是XII→XI→IX，与VIII组成复合物后到X；外源路径从TF–VIIa启动。两者最终到X，并且VIIa与IX等之间有联系。

但体内止血的主叙事应是TF启动、细胞表面放大。XII、PK、HK在接触系统和体外检测中重要，并不意味着每次正常止血都必须先从XII开始。因此实验室某条时间延长，不能不看因子身份就等同于同等严重的体内出血。

这个体内/体外区分现在必须讲清；它会影响理解APTT和某些缺陷的后果，不属于可随便后置的纯记忆。

### 4｜从缺陷反推哪台机器受损

血友病A对应VIII，B对应IX，C对应XI。把缺陷放进链条：VIII或IX影响生成Xa的放大复合物；XI位于更上游。课程用VIIa仍可激活IX解释XI缺陷常较轻，但不由一个编号预测个体出血程度。

vWF有两份工作：在血管壁附近帮助黏附；在循环中保护VIII。于是vWF异常可能同时牵涉一期止血和VIII稳定，不能硬塞进“只属于血小板”这一格。

多数凝血因子由肝合成。肝病与VitK则从供应层影响因子。华法林干扰VitK依赖因子的有效生成，已经存在的因子不会立即消失，因此不能把它与试管内立刻螯合Ca²⁺的方式混为一谈。肝硬化因子合成减少与冰冻血浆补因子的接口属于这一供应层；这里只定位缺少什么、补入什么，不从模型决定具体患者的处理，完整出血病诊疗仍归血液系统。

### 精确记忆的归位

先记功能，再用成组检索固定编号：
- 底物与主酶：I、II；外源入口：III、VII；汇合：X；稳定交联：XIII
- 两个辅因子：V搭X，VIII搭IX；Ca²⁺与PL是两套复合物共同条件
- 传统VitK凝血因子组：II、VII、IX、X；后面PC系统也有VitK依赖性，不能把这四个说成全部VitK依赖蛋白
- 课程消耗组：I、II、V、VIII、XIII；不稳定组V、VIII；FVI是历史编号，不是另一个现行因子
- 每个名单都归回KP07；不用再次复制为新KP

收束：**TF点火 → 凝血酶预热 → 平台上的两台机器增压 → 纤维蛋白生成并聚合 → XIIIa交联加固。**

# 空间与时间的限制：限域和拆网

## 局部强反应为什么不会任意扩散

抗凝不是“凝完以后才踩刹车”，而是回看从反应开始就存在的空间限制。既要保留伤口处的高效率，又要保护外围正常流动。

```text
局部有启动信号＋平台 → 凝血酶生成与反馈
外围完整内皮＋抑制系统＋流动清除 → 限制扩展

AT → 抑制活化酶
凝血酶＋TM → PC活化 → APC＋PS → 灭活Va/VIIIa → 拆放大器
Xa出现 → TFPI结合Xa并限制TF–VIIa → 关入口
血流稀释/带走＋局部吸附＋清除 → 限制活性物质积聚
```

### 1｜三个刹车的对象不同

AT主要抑制凝血酶、Xa等已活化的凝血蛋白酶；肝素增强AT作用，因此肝素主要是加强已有抑制系统，不是自己去切掉纤维蛋白网。

把“哪里合成”和“哪里增强”分开：循环AT主要由肝合成，内皮表面硫酸乙酰肝素增强其活性；肥大细胞/嗜碱性粒细胞来源的肝素是另一层表述。正式KP10的抑制组为Ⅱa、Ⅸa、Ⅹa、Ⅺa、Ⅻa及活化血浆激肽释放酶，对Ⅶa作用较弱；PK若指未活化酶原，不能直接当成活化靶酶。

课程还用肝素促进内皮结合TFPI释放解释给定背景下体内作用强于体外。这个比较要带剂量与实验条件，不能推出任何体内实验必强于体外，也不能把体内/体外抗凝混成内源/外源凝血途径。

PC系统则拆掉高效复合物所需的辅因子Va、VIIIa。把它放回凝血放大回路，两台机器同时失去帮手，于是放大能力下降。PS是APC的辅因子；TM是正常内皮上的结合伙伴，帮助凝血酶改换作用方向。

因此PC缺陷与VIII缺陷不能因为都叫“蛋白缺少”就推成同一后果：VIII缺陷削弱促凝放大，PC缺陷却削弱抗凝限制，静脉血栓风险可以升高。先认清缺的是油门还是刹车，再判断方向。

TFPI的逻辑又不同：先有Xa，随后TFPI通过相应结合限制TF–VIIa入口，是负反馈。不能只背三个缩写而看不见各自打断哪一段。

### 2｜同一凝血酶为什么有两种角色

在损伤局部，它促进纤维蛋白生成和反馈放大；与正常内皮TM结合后，它促进PC活化。分子名字相同，但结合环境与所作用的对象变了，结果就可能从促凝转向抗凝。

这是一条可迁移的思考方式：题目给一个分子，不只问它“是什么”，还要看它“和谁结合、在哪里工作”。不能把所有凝血酶出现都读成促凝增强。

vWF保护VIII属于凝血因子稳定性的联系。此处只用它提醒：因子供应、保护与APC灭活不是同一个过程，不把vWF新增成第四个抗凝刹车。

### 3｜血流本身也参与限制

活化因子在局部被稀释、带走、清除，难以一直积聚。静脉淤滞削弱这项限制，局部促凝更容易占优势。这才把“长期卧床”和“静脉血栓”接成机制，而不是只记危险因素名单。

完整内皮的屏障、PGI₂/NO、硫酸乙酰肝素、TM、TFPI、t-PA等分别作用于不同层；它不是一堵只有机械隔离作用的墙。

记忆压缩：**AT抑制酶；PC拆辅因子；TFPI限入口；血流降低局部积聚。**这些短句只在完整机制已经讲过以后使用。

## 怎样拆网，怎样避免拆得过早

同一平衡还需处理已形成的网，不能让所有形成的网永久留在血管里。纤溶处理的是已有纤维蛋白，并参与整个动态平衡，不是只在修复结束的某一刻才突然启动。

```text
t-PA / u-PA等激活物
→ 纤溶酶原变成纤溶酶
→ 降解纤维蛋白
→ 止血栓清除、保持或恢复通畅

t-PA＋纤溶酶原共同结合纤维蛋白 → 激活更高效、更集中
PAI-1限制激活物；α₂-AP限制纤溶酶；凝血酶可激活TAFI，减少纤溶效应
→ 清除与稳定之间保持平衡
```

纤溶酶原主要由肝产生，以无活性酶原存在。t-PA不是直接咬断纤维蛋白的那把剪刀；它先激活纤溶酶原，实际降解由纤溶酶执行。药名相近时，把“激活者”和“执行酶”分开，后面的溶栓药就不容易记错层级。

u-PA不需要同样的纤维蛋白结合条件，课程将其主要来源定位为肾小管/集合管上皮；课程另保留XIIa和激肽释放酶的接触系统接口：平时贡献较小，体外循环负电表面接触时可重要。先记t-PA的局部效率，再把其他激活物挂在同一个上游位置，不额外造四套纤溶模型。

### FDP与D-dimer怎样分开

```text
纤维蛋白原或纤维蛋白被降解 → 可形成FDP
先形成交联纤维蛋白，再被降解 → 产生D-dimer
```

所以D-dimer保留了“先成过交联网、随后发生降解”的信息。它不是看到升高就能唯一判定某一种血栓病；也不能说任何纤维蛋白原降解都必有D-dimer。完整PE排除算法留给呼吸系统。

3P试验是另一种课程识别：可溶性复合物中的纤维蛋白单体被鱼精蛋白解离后，可聚合沉淀。它和D-dimer不是同一检测对象。月经血不易凝固也可以挂回局部纤溶活性，而非当作“没有凝血系统”。

两端失败都能从任务推出：过强→止血栓过早清除、再出血；过弱→血栓清除受阻。不能简单认为“纤溶越强越好”。

```text
血小板/小血管层 → BT课程定位
TF入口＋共同因子 → PT
接触/内源入口＋共同因子 → APTT
加入凝血酶以后形成纤维蛋白的环节 → TT
```

PT与APTT并不是互不相干的两种病：入口不同，后面都依赖X、V、II、I等。因共同部分异常，两者都可能受影响。这里的“X、V、II、I”是检测依赖的因子组合，不是“X依次把V、II、I都切开”的酶反应顺序。

```text
抗板：影响信号/受体/桥接 → 少形成或放大血小板聚集
抗凝：影响活化因子生成或作用 → 少生成新纤维蛋白
```

## 同一系统失衡以后，怎样成为循环问题

正常止血是在适当部位、适当强度下保护血管。内皮异常、血流异常、高凝等改变了促凝与限制的平衡，就可能在血管腔内形成不恰当的血栓。“血管内”不等于“内皮一定完整”，两者不能混为一个条件。

```text
内皮损伤/功能异常 ─┐
血流淤滞/湍流 ────┼→ 促凝与限制失衡 → 病理血栓
高凝状态 ─────────┘                      │
                   ┌────────────────────┼────────────────────┐
                   ↓                    ↓                    ↓
                原位阻塞             脱落随流走           溶解/机化等
                   ↓                    ↓
                  缺血              血栓性栓子
                   │                    ↓
                   │                  栓塞
                   │                    ↓
                   └───────────────→   缺血
                                        ↓
                     阻塞程度/持续时间/侧支/局部氧供与耐受
                                        ↓
                           达到组织坏死条件 → 梗死
```

这张图有两个必须保留的分叉：血栓可以原位阻塞，不必先脱落；血栓也不一定继续走向梗死。把所有名词硬串成必经路线，会使模型在病例里失效。

### 1｜为什么动脉、静脉处理侧重点不同

动脉高剪切环境下，血小板黏附和聚集相对突出；静脉淤滞时，活化因子不易被冲走，凝血和纤维蛋白形成的作用相对突出。因此可理解冠脉疾病为何强调抗板、DVT/PE为何强调抗凝。

这是侧重点，不是物质的绝对二分。动脉血栓也可含纤维蛋白，静脉血栓也有血小板。不能用“白色血栓没有网”来独立解释或决定NSTEMI治疗；是否溶栓要交回疾病证据和风险。

### 2｜四个词分别属于哪种东西

- 血栓：在活体心血管内形成的固体质块
- 栓子：随血流运行的异常物质；脱落血栓是常见来源，不是唯一来源
- 栓塞：栓子阻塞血管这一事件
- 梗死：局部组织发生缺血性坏死这一结局

因此，“有栓塞”不等于“已经梗死”；“有梗死”也不要求必先有游走的栓子。P0的其他栓子类型、梗死形态属于回调接口，不把整套病理总论重新搬进B4。

### 3｜结局如何收束

较小血栓可以溶解；不能完全清除的部分可以机化、出现再通或钙化。再通是部分恢复通道，不等于血管完全回到原样。若已经梗死，后续进入坏死清除与组织修复；修复的形式受组织再生能力影响，不保证原功能完全恢复。

### 整块的答题定位方式

按题干实际信息依次定位，不机械走完九问：

```text
正常止血还是病理血栓
→ 壁/血小板/凝血/抗凝/纤溶哪层
→ 首先改变的连接、酶、辅因子或流动条件
→ 上游怎样触发，下游怎样变化
→ 检查或药物观察/作用哪个位置
```

## 开 Block：它在循环系统里补上什么

B1 解决血怎样被推动，B2 解决压力和容量偏移后怎样调回来，B3 解决心脏怎样按次序发令、传令并收缩。现在还有一个前提：**血既要一直在管里流，又不能在管破了以后一直往外漏。**

B4 因此有两个同时存在的目标：破口处迅速止血；其余地方继续通畅。只学“怎么凝”还不够，还要学“凝在哪里、凝到哪里停、留下的网怎样清除”。之后的冠脉事件、静脉血栓会调用同一套机制，不需要另背一套彼此无关的血栓知识。

先给这张母框，不把所有名字一次填满：

```text
血管损伤
├─ 血管局部收缩 → 减少失血
├─ 血小板识别破口 → 黏附、活化、募集、聚集 → 初级栓
│                                      └─ 促凝磷脂面 → 因子局部组装
└─ TF等促凝入口暴露 ──────────────────────────────┘
                                  ↓
                      少量凝血酶 → 反馈放大
                                  ↓
                 纤维蛋白生成、聚合 → XIIIa交联稳定
                                  ↓
                    网加固初级栓＋血小板牵拉回缩

从开始就有：正常内皮/抗凝/流动清除 → 把放大限制在局部
贯穿平衡并参与清除：纤溶 → 降解纤维蛋白 → 保持或恢复通畅

如果促凝与限制失衡 → 病理血栓
├─ 原位阻塞 → 缺血
└─ 脱落 → 血栓性栓子 → 栓塞 → 缺血
                     只有缺血达到组织坏死条件，才叫梗死
```

伤口处的血小板封口与凝血加固相互支持；外围抗凝限域与纤溶清除同时限制反应。检查和药物观察/改变这张模型的不同位置，失衡后再分辨成栓、栓塞和梗死的条件分支。
