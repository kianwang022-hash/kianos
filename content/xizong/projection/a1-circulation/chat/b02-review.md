# Precision｜把名字放回已有功能位置

数字、名单和受体不另建一棵知识树。先恢复功能，再用下面的比较轴保持精确；这些内容可进入后续复习，不等于今天全量到期。

## 1｜四类反射，按同一组坐标记

| 反射 | 位置与直接刺激 | 主输出与任务 | 不能混掉的条件 |
|---|---|---|---|
| 压力感受性 | 颈动脉窦 / 主动脉弓，机械牵张 | 交感与迷走双向改变，缓冲快速血压波动 | 读取牵张；窦传入接舌咽、弓传入接迷走 |
| 外周化学感受性 | 颈动脉体 / 主动脉体，PaO₂↓、PaCO₂↑、H⁺↑ | 呼吸反应为主；危急时参与升压和重分配 | 课程约80 mmHg以下强调循环作用，不是普适精确开关 |
| 心肺容量感受性 | 心房、心室、肺循环大血管，充盈牵张 | 容量负荷时倾向减少保Na保水、增加利钠排水 | 低压力 / 容量 / 牵张三称谓属于同组 |
| 心交感传入 | 心室壁交感传入末梢，扩张及缺血相关化学刺激 | 增强交感、维压；持续可增加耗氧 | 不与容量卸载反射混同 |

感受器精确定位：动脉外膜下感觉末梢；相同血压下，课程比较颈动脉窦通常比主动脉弓更敏感。课程对外周化学感受器的分工是颈动脉体偏呼吸、主动脉体偏循环；这是重点分工，不表示两者作用完全隔离。

窦弓课程六特点：快、短时缓冲、持续工作、双向负反馈、工作点附近敏感、可重调定。“短时为主”保留；“长期绝无作用”不作为无条件结论。

反射弧受损：快速缓冲丢失→血压更不稳定，不能据此单独判定平均血压固定升或固定降。

心肺感受的课程细项：以中央充盈造成的机械牵张为主，亦列腺苷、前列腺素、缓激肽等化学刺激；保留感受部位与传入路线，不能把两类心肺反射混成一个输出。

脑缺血反应：脑灌注明显不足→交感缩血管增强。库欣接口：颅内压↑→脑灌注受限→相应升压反应。

记忆钩子“窦九弓十”只帮记传入神经编号，不能替代窦神经—舌咽与主动脉弓—迷走的真实路线。心交感传入的化学例子：腺苷、缓激肽、PG、H₂O₂等；它们是刺激身份，不是四条互不相干的反射。

## 2｜五个神经出口与血管纤维

| 出口 | 主要受体 / 方式 | 变量槽位 |
|---|---|---|
| 窦房结 / 传导 | β₁ | 心率、自律性、传导性 |
| 心肌 | β₁ | 收缩性，进而影响SV / CO |
| 微动脉 | α₁为主 | 阻力、器官血流分配 |
| 静脉 | α₁为主 | 容量池、回心与前负荷 |
| 球旁细胞 | β₁ | 肾素释放 |

迷走精确位置：右侧更偏窦房结，左侧更偏房室交界；主要室上组织，心室作用较弱。

| 课程纤维分类 | 递质 / 受体 | 紧张性与场景 | 复习时的限定 |
|---|---|---|---|
| 交感缩血管 | NA→α₁ | 有基础紧张性，分布广 | 皮肤较多、心脑较少；微动脉丰富 |
| 交感舒血管 | ACh→M | 课程归骨骼肌、防御 / 情绪，无日常紧张性 | 物种和人体证据有边界，不能单独解释人体运动充血 |
| 副交感舒血管 | ACh→M等课程路径 | 少数局部器官，非普遍张力控制 | 唾液腺、胃肠外分泌腺、脑膜、外生殖器等课程名单 |
| 后根舒血管 / 轴突反射 | CGRP等 | 伤害刺激附近局部反应 | 感觉神经局部分支，不走常规中枢整合 |

交感缩血管纤维的课程分布两轴：器官轴为皮肤多、心脑少；血管轴为动脉比静脉丰富、微动脉最突出、后微动脉和前括约肌较少。上述分布是组织化检索，不表示缺少这种纤维的血管完全没有其他调控。

微动脉更偏总闸门；后微动脉 / 前括约肌更受局部代谢。真毛细血管无平滑肌。冠脉净效应还要看心肌代谢，不能只从受体配对推到底。

## 3｜儿茶酚胺用“三个条件”记

| 条目 | 记忆内容 | 先恢复的功能 |
|---|---|---|
| 髓质分泌比例 | 约80% Adr、20% NA | 内分泌应急放大 |
| NA身份 | 交感递质，也可作为激素 | 神经末梢与入血途径分开 |
| Adr身份 | 外周主要作激素 | 循环性作用，不等同末梢NA |
| α₁ | 血管收缩 | 阻力 / 容量池 |
| β₁ | 心脏效应、球旁肾素 | 泵与RAAS入口 |
| β₂ | 特定血管床舒张 | 部位选择性 |
| NA整体心率 | 直接加快倾向可被升压后的反射减慢盖过 | 受体效应≠完整反射结果 |
| Adr作用翻转 | α阻断后，β₂舒张可突出 | 被阻断的是哪条支路 |

Adr的课程部位例子是骨骼肌、肝等β₂作用较突出的血管床：较低剂量可突出舒张，较高剂量α效应可改变净方向。冠脉还要把心肌代谢反馈放回来，不能只看受体。

来源调节：交感节前ACh→髓质N₁；ACTH / GC参与应激背景；释放入血可解除自身合成相关抑制；低血糖刺激释放。嗜铬细胞瘤是来源异常接口，诊断与α/β阻断顺序不在此表给治疗方案。

## 4｜RAAS先记入口，再记输出分组

来源三称谓：球旁细胞＝近球细胞＝颗粒细胞。

| 肾素入口 | 实际读取 / 通路 |
|---|---|
| 肾灌注压降低 | 入球动脉壁牵张相关 |
| 致密斑NaCl信号降低 | 到达该部位的小管液信息 |
| 肾交感增强 | 球旁β₁ |

主链：肝来源血管紧张素原—肾素→AngⅠ—ACE→AngⅡ→AngⅢ；主要作用受体AT₁。

课程化学表：CA、缓激肽、PG、小剂量多巴胺偏促；ANP、ET、较大量VP、AngⅡ负反馈偏抑。NO按正式KP的路径/实验条件单列：原生理印刷P139/物理P156归抑制，独立研究还支持cGMP/PDE3/cAMP介导促进；不能从舒血管直接决定肾素方向。

| AngⅡ检索组 | 具体归位 |
|---|---|
| 重构1组 | 肥大 / 凋亡、成纤维与血管细胞变化、ECM / 纤维化 |
| 减弱2项 | 压力反射敏感性；肾素释放的负反馈 |
| 收缩2处 | 微动脉、静脉 |
| 加强3项 | CRH—ACTH—GC轴、口渴、交感中枢活动 |
| 释放3项 | 醛固酮、ADH / VP、交感末梢NA |

“1组”不表示只存在一种重构变化；数量服务检索，不修改组内内容。

口渴定位：AngⅡ→穹窿下器等室周器及相关中枢→口渴/饮水与ADH调节。交感定位：中枢紧张性及神经末梢NA释放，不把这条链混成直接刺激肾上腺髓质CA分泌；球状带醛固酮属于皮质。原题在这里说“血管升压素类型”时，应按本节AngⅡ/AngⅢ语境辨认，不能与ADH/VP混名。

AngⅡ / AngⅢ的课程强项对照：前者突出全身微动脉收缩 / 升压，后者突出直接促醛固酮。肾内另留三轴：浓度与入出球收缩、系膜—Kf、小管Na水重吸收。不能把全身升压、局部滤过率与肾素分泌压成同一个方向。

## 5｜醛固酮与ADH，用“直接改什么”定位

| 比较轴 | 醛固酮 | ADH / VP / AVP |
|---|---|---|
| 性质 | 类固醇 | 肽类神经激素 |
| 来源 | 肾上腺皮质球状带 | 下丘脑视上核、室旁核等大细胞神经元 |
| 储存释放 | 依其内分泌合成分泌过程 | 沿轴突运输，神经垂体储存释放 |
| 主要当前靶点 | 远端肾单位、集合管主细胞等 | 集合管主细胞V₂ |
| 直接机制 | 核受体→ENaC、Na-K泵及课程ATP合酶等表达 / 功能 | V₂→G蛋白→AC→cAMP→PKA→顶端AQP2 |
| 水盐方向 | 保Na、促进排K，影响水盐潴留 | 增水通透性、保水；内髓尿素通透性也变 |
| 强调输入 | AngⅡ、K⁺增加等 | 晶体渗透压增加最重要，严重容量 / 压力输入也参与 |
| 另一作用 | 提高对缩血管物质的敏感性 | 较高浓度V₁缩血管 |

醛固酮课程还保留血Na降低、ACTH等刺激背景，不能把它们与RAAS、K的权重完全等同。ADH促释放名单：渗透压↑、容量↓、压力↓、AngⅡ、应激 / 创伤 / 疼痛 / 恶心等；课程抑制表有乙醇、ANP、咖啡因、GC，具体情境不能由一项单独预测全部尿量。

| 疾病接口 | 断点 | 检索区别 |

| 原醛 | 醛固酮来源过度 | 肾素低、醛固酮高 |

## 6｜利钠肽与长期肾反馈

| 条目 | 放回模型的位置 |
|---|---|
| ANP | 心房牵张相关释放 |
| BNP | 主要心室壁负荷相关信号 |
| 促ANP的充盈情境 | CVP / 容量增加、头低足高、浸水等 |
| 课程其他刺激 | NE、ACh、ADH、K⁺增加等；实际经过的中间环节需保留 |
| 肾小球侧 | 入球舒张、系膜舒张→Kf / GFR；课程方向为GFR↑、滤过分数↑ |
| 小管侧 | cGMP相关途径→减少NaCl与水重吸收 |
| 激素侧 | 抑制肾素、醛固酮、ADH等 |
| 血管 / 结构侧 | 舒张、对抗促缩与重构信号 |

滤过率与滤过分数不是两个名称指同一个量：FF＝GFR / 肾血浆流量。课程把ANP记为GFR↑、FF↑；健康人输注研究中观察到GFR上升而有效肾血浆流量不变或下降，支持这一方向的具体情境。不能据此推成任何扩肾血管都必然提高FF，完整入出球动力学回泌尿。[原始研究](https://jci.org/articles/view/112368)

长期回路：压力→排Na水→ECF / 血容量→回心 / CO→压力反馈。肾功能、摄入与激素条件不能删。BNP的方向和阈值用途也不能混成一件事。

| NO | sGC→cGMP→PKG→胞质Ca²⁺下降等机制→平滑肌舒张 | 抗板、抗增殖等 |
| PGI₂ | 舒张 | 抗板、抗重构 |
| PGE₂ / PGF₂α | 课程分别突出舒张 / 收缩 | PG家族不是统一方向 |
| EDHF相关机制 | K⁺通道 / 超极化相关→舒张 | 局部小血管调节 |
| 缓激肽 | B₂—内皮NO / PGI₂ / EDHF→舒张 | B₁炎症疼痛轴另留 |
| ADM | 多来源，内皮为课程血中重要来源；旁分泌 | 舒张、利尿、抑制AngⅡ / 醛固酮等 |
| CGRP | 舒张，轴突反射递质接口 | 课程“最强”标签要限定口径 |
| 低频其他4项 | 阿片肽、CO、H₂S、IGF-1 | 先保身份与归属，不另铺主线 |

ET课程补充：强冠脉收缩及AngⅡ、NA促缩联动，可盖过其正性肌力表现；内皮素受体拮抗剂保留肺动脉高压的药物接口，不由此扩大到全部肺高压病因。

课程比较标签：CGRP对应“最强舒血管物质”，尾升压素对应“最强缩血管物质”。保留为课程实验口径的配对，不作跨部位、浓度、实验的绝对排名，也不把“物质”自动当作通用临床升压药。

ADM来源逐项：肾上腺髓质嗜铬细胞、血管平滑肌、内皮；当前课程把血中主要来源归内皮。作用除舒张、利尿和抑制AngⅡ/醛固酮外，还保留正性肌力、冠脉舒张和保护心脏的课程接口；不能与肾上腺髓质儿茶酚胺混为一物。

NO的刺激表：ACh、雌激素、NA、切应力、缓激肽等；硝酸甘油接NO相关作用接口，不等同每个刺激都通过完全同一个内皮释放步骤。切应力是内皮感到的血流条件，不能因为ET和NO都可参与反应就只选一个绝对方向。

### 两类CCB的短接口

二氢吡啶类（课程如硝苯地平、氨氯地平）更突出血管平滑肌作用；非二氢吡啶类（维拉帕米、地尔硫䓬）还明显影响心脏传导等。扩血管后是否出现明显反射性心动过速，需看药物、剂型和背景，不能把同一幅度套给全部二氢吡啶类。完整心绞痛或心律失常用药回B6/B10。
