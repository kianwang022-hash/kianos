# B5｜长期压力与内皮损伤，怎样留下血管病底物

B2提供调压与容量机制，B4提供内皮—止血机制。把时间拉长后，高压重构与粥样斑块相互影响，却仍是两条不同的损伤轴。以下模型沿结构后果分支，再用证据和治疗校准；详细解释原地展开。

<!-- b5:route:start -->
压力轴：CO／TPR／容量／大动脉顺应性长期异常 → 高压 → 阻力血管重构＋左室后负荷 → 心脑肾／视网膜损害；肾缺血又可反馈升压。

内膜轴：内皮损伤＋脂质负荷 → 炎症／泡沫细胞 → 脂纹 → 纤维帽＋坏死核心 → 固定狭窄，或易损斑块事件。高压可促内皮损伤，但不能将两种病合并。

## 压力与内膜：先分清损伤的地址

> 定位（可略读）：高血压先放回 P/Q/R/V：血压升高是共同结果，不是单一病因〔MAP关系｜升压4路径｜判断3层〕；原发性 vs 继发性：不是“有没有原因”，而是能否定位单一主病因〔原发vs继发｜共同变量｜搜病因6组线索｜本Block范围〕；危险因素与脂蛋白：先确定进入内膜的脂质负荷〔危险因素｜脂蛋白/apo方向｜LDL与ox-LDL｜继发高脂4项〕。

血压高是结果，不是一个足够的病因解释。CO是泵每分钟提供的量，TPR反映血流遇到的总阻力；容量改变回心与输出，大动脉顺应性又改变每搏输入如何变成收缩压、舒张压和脉压。RAAS只是其中一条调节链，因此“能用RAAS解释升压”不等于所有患者都只有RAAS故障。

原发性是多因素调压网络偏移，不是完全没有原因；继发性意味着有可定位的基础疾病，但仍经这些共同变量升压。年轻起病、突然恶化、难治、低钾或阵发症状、血管杂音、上下肢压差以及肾/内分泌异常，改变的是搜索具体病因的优先级。肾实质、肾血管和缩窄的机制在本块展开；完整内分泌病因回所属系统。

与此同时，脂质负荷、吸烟、高压及糖代谢异常可改变内膜。课程方向是TC/TG/LDL-C/VLDL/CM/apoB升高，以及HDL/apoA降低时风险增加；apo指载脂蛋白，CM是乳糜微粒。课程最强调LDL-C及氧化LDL，但脂蛋白方向不是一个不带条件的病人处方；糖尿病、高胰岛素血症、甲减和肾病综合征的继发高脂接口要保留。课程选项不列饮酒，不意味着饮酒能预防血管病。

```text
持续压力负荷 → 阻力血管重构＋左室后负荷
内皮反复损伤＋脂质进入 → 内膜炎症/修复 → 斑块
高压又可加重内皮损伤：两条轴互相影响，损伤地址仍不同
```

## 从功能性收缩到壁厚腔窄，再看器官怎样受累

> 定位（可略读）：缓进型三步电影：功能紊乱 → 血管病变 → 器官病变〔病程3段｜功能/血管/器官｜可逆/器质性界线〕；玻璃样变：高压怎样把血浆蛋白和ECM压进细小动脉壁〔特征病变｜形成2来源｜好发处｜vs纤维素样坏死〕；高血压肾：双侧对称细颗粒固缩〔原发颗粒肾形态｜细颗粒机制｜AS大瘢痕｜肾缺血/RAAS〕；高血压脑：出血、软化、脑病是三条不同路径〔脑损害3路｜出血部位/血管｜软化本质/修复｜脑病｜Study严重度/死因〕；高血压心与视网膜：同一高压在泵和微血管产生不同重构〔代偿→失代偿：壁/腔/功能｜肥厚→缺血链｜视网膜改变〕；急进 / 恶性高血压：坏死性细动脉炎 + 洋葱皮样增生〔特征2｜肾血管/肾功能｜Study死因｜缓进vs急进4轴〕；高血压心脏病：所有体征都能回到长期左室后负荷〔长期负荷/LVH｜体征6项/机制｜相对MR｜早晚功能〕。

一条小动脉间歇收缩，可以使阻力暂时上升而尚无固定结构损伤。长期压力与屏障异常则让血浆成分进入壁内，加上平滑肌/基质变化，形成玻璃样小动脉硬化：壁厚、腔窄，把功能波动变成持续灌注困难。玻璃样变的均质嗜伊红形态与急进型纤维素样坏死不同；后者还可伴同心层状的“洋葱皮”增生，不能只用程度更重解释两个病理身份。急进型尤其累及肾细小/入球动脉，腔急剧变窄使肾缺血、功能迅速恶化；课程缓进型死因口径为脑出血，急进型为肾衰/尿毒症，是不同病程下的Source比较。

分布决定器官外观。肾内大量细小血管弥漫狭窄，使许多小肾单位缺血萎缩，保存区与萎缩区相间，得到双侧对称细颗粒固缩；较大肾动脉分支被AS堵住，缺血区较大，留下的是大瘢痕。肾缺血又能激活升压链，因此结果可重新成为上游输入。

脑损害必须分叉：深穿支损伤/微动脉瘤破裂走向出血；血管闭塞走向局部缺血和液化坏死的软化灶；急性脑损害/水肿走向脑病。课程最严重/死因口径和基底节、豆状核/内囊位置保留于原owner，不能把三种后果当同一病理过程。

心脏承担另一种代价。长期左室后负荷增加，先用向心性肥厚承担压力；壁厚却同时增加耗氧并使顺应性下降，毛细血管相对供应不足，可先形成舒张障碍，随后失代偿扩张。S4由房缩面对较硬心室解释；A2亢进、抬举样心尖和相对性MR分别要落在压力、肌壁/冲动和腔/瓣环位置。S2反常分裂需要A2相对P2延迟的时序条件，不是“高血压必有”。眼底小动脉狭窄/交叉压迫到出血渗出、视盘水肿，是同一压力损伤的观察窗，并非心脏结果的下一步。

## 数字校准的是证据，不代替病因或紧急程度

> 定位（可略读）：办公室血压与 ABPM 回答不同问题〔测压准备/体位/次数/双侧｜ABPM均值3时段｜用途｜办公室≠动态〕；诊断、分级与单纯收缩 / 舒张期高血压〔Study分级｜SBP/DBP判级规则｜单纯收缩vs舒张｜老年机制〕；危险分层：同一血压数字，器官风险可以完全不同〔风险4轴｜分层矩阵｜因素3组｜眼底4级〕；高血压危象：急症 vs 亚急症看急性靶器官损害〔危象入口｜急症vs亚急症｜血压数值vs急性器官损害｜脑病/恶性接口〕；急症降压：迅速，但不能把灌注一起打掉〔自身调节→灌注风险｜降压3时段｜缺血时调整〕；急症药物：先看最危险的靶器官〔急症vs亚急症给药｜初期利尿条件｜靶器官→药物5场景〕。

先有病理模型，再问我们测到的是哪一种压力证据。诊室读数受准备、体位、上臂水平、测量侧和重复次数影响；初次双侧、以后较高侧，疑直立性低血压再比较卧立位。ABPM给的是24小时、白天和夜间均值，分别回答持续性、昼夜和短时变异；白大衣、隐蔽性和疗效问题不能只靠一次诊室读数。课程均值界线24小时130/80、白天135/85、夜间120/70，不能拿它们当诊室分级阈值。

课程诊室高血压以140和/或90进入，1至3级分别恢复140–159/90–99、160–179/100–109、至少180/110；两数等级不同按较高。单纯收缩期需要SBP高而DBP低于90，单纯舒张期是相反组合；老年大动脉储器退化可以解释前者，但不是年龄替代测量。

同一等级的人并不承担相同风险。危险因素、已有靶器官损害/CKD、临床合并疾病是不同证据层，不能把“吸烟”与“已发生脑卒中”当同等身份。风险矩阵按课程原页读：130–139和/或85–89那一行首格为空，其余低、中/高、高/很高，不能把整段正常高值定义套进去，也不能补空格。年龄、脂质、腰围、LVMI、PWV、ABI、肾功能和白蛋白阈值按本Block正式KP06“危险分层”的风险因素、靶器官损害、合并临床疾病及眼底四级表完整取回，不另造通用指南矩阵。

急症的分界更关键：不是只有数字特别高，而是正在发生急性进行性心脑肾等损害。没有这一证据的严重升压，与有急性损害者处理优先级不同；急进/恶性和脑病还需各自器官证据。长期高压使自身调节工作区右移，因此迅速“一步降到正常”可能同时把灌注打掉。课程降压节奏与药物配对保留为Study版本，不由生理模型自行更新：初期1小时MAP降幅不超过25%，随后2–6小时约160/100，24–48小时渐进，缺血则更谨慎。急症静脉入口与亚急症口服入口不同；课程一般急症接硝普钠，ACS/急心衰接硝酸酯，急脑血管接尼卡地平，妊娠/肾功能不全接拉贝洛尔，小动脉扩张接肼屈嗪；五场景只是该页的药物角色，须连病因与耐受条件，初期呋塞米需心衰或容量负荷等条件，不机械套用。

## 长期干预：改善主导变量，同时保护器官

> 定位（可略读）：生活方式与慢性目标：治疗对象不是数字本身〔Study目标分层｜盐量｜生活方式→变量｜各风险层共同底座〕；药物总原则与联合：同时打多个升压环节〔6原则｜联合逻辑｜4组合｜三药｜SPC〕；ABCD：先记作用层级，再记药名和禁忌〔ABCD作用层｜亚类｜适用/禁忌｜肾功/血钾条件〕；并存病选药：先问患者需要什么，再问药物怕什么〔并存病7组→选药｜亚类/条件｜联合与风险〕；三类继发性高血压：肾实质、肾血管、主动脉缩窄〔继发3类：机制→证据｜最常见｜ACEI/ARB边界｜上下肢压差〕。

限盐改变容量，控重与代谢改善影响交感、内皮与脂质风险；生活方式不是轻症专属。课程一般目标、合并病目标、老年先宽后严及泌尿各病种目标应保留各自测量和疾病作用域，不能压成“所有肾病都同一数字”。精确目标和盐量回本Block正式KP16“生活方式与慢性目标”的课程目标分层及盐<6g/d；各泌尿病种目标按该KP点名的对应章节取回，而不是从一个压力公式推目标。

不同机制联合的意义在于减少另一调压链的补偿，并非任意药物可以叠加。A类改变AngⅡ生成/受体或脑啡肽酶，B类改变心脏β1与肾素输入，C类偏血管或兼顾频率传导，D类改变钠水/容量并有后期阻力效应。先明确作用层。课程六原则是个体化、适当小剂量起始、优先合适长效制剂、合理联合、尽早但平稳达标、不随意停药或频繁改方案；SPC是单片复方制剂，减少服药负担以改善依从性；课程A+C、A+D、C+D、C+B和含利尿剂三药组合还要识别C的亚类。

安全条件决定“看起来同类”能否互换。ACEI干咳与血管性水肿不能同样直接换ARB；ARNI相关禁忌、与ACEI的36小时间隔和RAAS药不得重复叠加，保留当前明确边界。Cr/K异常是复评接口，不等于任何肾功能不全永久禁用；蛋白尿CKD也可能需要这类药，双侧显著肾动脉狭窄则可能因出球张力解除而使滤过下降。β阻断的稳定HFrEF获益不是全类效应，急性失代偿/灌注不足和严重缓慢传导不同于长期稳定状态；非DHP负性肌力/传导限制也不能整包移给氨氯地平。

D类须把袢、噻嗪、保钾及排游离水的接口分清：监测钾与肾功能，痛风不能把全ARB都当氯沙坦，右室梗死不能用降前负荷的办法雪上加霜，托伐普坦也不能套给低容量低钠或高钠。BPH可用α1接口兼顾排尿，但不是常规单药降压首选；课程CCB回避口径不升级成全类绝对禁忌。

## 斑块不是一堆脂肪：伤、炎症与修复共同决定稳定性

> 定位（可略读）：始动环节：内皮反复损伤后，脂质和白细胞才进入内膜〔正常内皮功能｜损伤/脂质/黏附/单核｜炎症证据｜始动/特征细胞/最早肉眼〕；泡沫细胞与脂纹：巨噬细胞和SMC都能吞脂〔2来源｜受体｜最早病变〕；从脂纹到纤维帽与粥样坏死核心〔纤维帽｜坏死核心｜成分5项｜稳定性｜SMC作用2〕；稳定 vs 易损斑块：固定狭窄程度 ≠ 急性事件风险〔稳定vs易损：帽/核心/炎症/后果｜继发改变｜狭窄≠急性风险〕；AS器官地图：同一内膜病变落到不同管路〔血管类型/轻重｜器官8处：部位→后果｜高压轴vsAS轴出口〕。

完整内皮参与抗栓、舒缩与黏附控制。屏障/功能反复受损后，LDL进入内膜并氧化，黏附分子使单核及T细胞迁入，炎症、平滑肌迁移和基质变化持续发生。始动环节、特征细胞与最早肉眼病变分别是内皮损伤、泡沫细胞、脂纹，三者是三个问题的答案，不是同义词。

巨噬细胞摄取脂质可形成泡沫细胞，SMC也可形成肌源性泡沫细胞；受体细项按课程与已记录Source边界，不把未决SMC受体直接写成无条件定论。SMC又能合成胶原等基质形成纤维帽，所以同一个细胞既参与脂质累积，也能提供保护性结构。细胞坏死、脂质和碎屑形成核心；正式 KP24 的课程五项是针状胆固醇结晶、钙盐沉积、淋巴细胞、泡沫细胞、肉芽组织，包含沉积、炎症和修复组织，不能误读为核心中五种同质材料。

决定事件的两个轴是管腔储备与帽稳定性。厚帽、小核心、炎症较少常偏固定狭窄；薄帽、大核心、炎症活跃则可能破裂/侵蚀并触发血栓。炎症介质降解胶原能削弱帽，狭窄不极重也可发生急性冠脉事件。因此“造影狭窄多少”与“突然成栓风险”不是同一个判断。斑块内出血、钙化、动脉瘤、胆固醇或血栓栓塞等改变按相应结构和血流后果理解，而不是把它们串成必经步骤。

同一内膜病变落到冠脉、主动脉分支、颈脑、肾、四肢和肠系膜，结果由灌注区域决定：冠脉接B6，外周闭塞接B9，长期压力负荷接B11。主动脉壁/瓣环/瓣膜的不同结构损伤也不能用一个“动脉硬化”标签替代。课程八处的完整部位—后果对照在本Block正式KP26“AS器官地图”表：冠脉、主动脉、颈动脉、脑动脉、肾动脉、四肢、肠系膜、升主动脉/瓣膜；不能把正文的供区概述当已回答全部细项。到此只需能区分长期压力重构与斑块事件两种底物，并沿病变位置解释后果；后续疾病不是新的第二套血管真相。
