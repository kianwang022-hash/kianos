# Precision｜从模型中恢复精确知识

以下数字按当前课程的正常静息近似保留，不是所有年龄、运动状态或疾病的统一界限。推理条件属于正文；纯名单与数值在这里承接记忆。

## 1｜七期、四瓣膜事件与四心音

| 阶段 | 房室瓣 / 半月瓣 | 容积方向 | 关键位置 |
|---|---|---|---|
| 等容收缩 | 关 / 关 | EDV不变 | 房室瓣关闭、S1；室压快速上升 |
| 快速射血 | 关 / 开 | 快速减少 | 半月瓣开放；射血量最多 |
| 减慢射血 | 关 / 开 | 继续减少 | 后段可凭动能继续前流；末达到ESV |
| 等容舒张 | 关 / 关 | ESV不变 | 半月瓣关闭、S2；室压快速下降 |
| 快速充盈 | 开 / 关 | 快速增加 | 房室瓣开放；可有S3 |
| 减慢充盈 | 开 / 关 | 较慢增加 | 课程正常静息周期中时长最长 |
| 心房收缩 | 开 / 关 | 再增加至EDV | 心室舒张末；S4所在时段 |

正常静息时舒张期通常长于收缩期；心率加快、周期缩短时，舒张期缩短往往更显著。这是当前周期模型的背景条件，不是极端频率下一律成立的时长定律。

开闭四规则：房压大于室压时房室瓣可开，反向时关闭；室压达到超过动脉压的开瓣条件时半月瓣开，流动减速与逆压使其关闭。规则用于正常瓣膜，射血后段还要考虑惯性。

| 极值槽位 | 课程定位 |
|---|---|
| 时间最短 / 最长 | 等容收缩 / 减慢充盈，正常静息模型 |
| 主动脉压最低 / 最高 | 等容收缩末 / 快速射血末 |
| 左室压最低 / 最高 | 快速充盈期间 / 快速射血末 |
| 室压升 / 降最快 | 等容收缩 / 等容舒张 |
| 容积最大 / 最小 | 舒张末及等容收缩 / 射血末及等容舒张 |
| 充盈最多 / 射血最多 | 快速充盈 / 快速射血 |

三压力定位：正常等容收缩阶段，左房压＜左室压＜主动脉压；减慢射血后段也可短暂出现这一压力次序，但半月瓣尚开、已有动能使血继续前流。不能只用同一个压力不等式判定阶段，必须同时看瓣膜与血流状态。

S3不必一律解释为疾病；S4需要有效心房收缩，房颤时不能依赖这一声音。课程把可闻S4作为异常提示，具体临床判断回心脏疾病。

## 3｜负荷、收缩性与储备用同轴对照

| 概念 | 直接含义 | 主要归位 | 不要混成 |
|---|---|---|---|
| 前负荷 | 收缩前的负荷 / 初长度 | EDV、EDP是常用近似坐标 | 压力与容积在任何病理下都相等 |
| 后负荷 | 收缩时克服的负担 | 课程主要用大动脉压代表 | 仅由一个血压读数决定全部室壁应力 |
| 收缩性 | 负荷相近时的内在收缩能力 | Ca²⁺、横桥与功能蛋白 / 能量等 | 实际收缩力的同义词 |
| 异长调节 | 改变初长度 | Frank–Starling | 每个负荷增加都提高输出 |
| 等长调节 | 主要改变内在收缩能力 | 神经体液等常见入口 | 等容收缩这个周期阶段 |

后负荷骤增的课程单因素推演：需建立更高室压才能开瓣→等容收缩期延长；在总收缩时间近似固定的实验条件下，射血期缩短，肌纤维缩短速度与程度下降→当搏SV下降、ESV增加。随后是否恢复输出另看回心与收缩性，不能把这套时长结论直接扩展到全部慢性高血压病例。

前负荷三个课程称谓：初长度、容量负荷、心室舒张末期容积或压力。它们是恢复同一负荷概念的不同入口，EDV与EDP之间仍受顺应性约束。

收缩能力三组：活化横桥数目（Ca²⁺及肌钙蛋白亲和力）、横桥ATP酶活性、肌原纤维 / 能量 / 功能蛋白水平。心肌不能用骨骼肌运动单位募集或强直式时间总和来增加输出。

心肌与骨骼肌长度—张力三轴：都有最适初长度；课程心肌初长度储备相对大、降支不明显，骨骼肌储备相对小、降支明显；心肌连接蛋白等限制过度伸展。比较轴不等于把心室无限拉长仍会不断增力。

储备两层：心输出量储备可从SV储备与HR储备两个方面理解；这不是两种不同单位量的直接相加，实际CO仍为HR×SV。SV储备又分收缩期排空储备与舒张期充盈储备。正常课程中前者更大；疾病中要看哪些余量已被动用，不把所有心衰等同一种腔室变化。

## 4｜充盈、EF与检查各看一面

| 检索项 | 具体内容 |
|---|---|
| 充盈2来源 | 早期舒张充盈与心房收缩；课程约75% / 25% |
| 早期抽吸 | 主动舒张、弹性回缩等共同参与 |
| 房颤机械损失 | 有效房缩消失；快室率再缩短舒张 |

| E/A | 早期松弛异常典型可＜1；假性正常与限制性模式不可漏 |

做功的两种比较：不同动脉压力的个体；同一个人动脉压力改变前后。输出体积相近时，克服的压力越高，外功通常越大。

| 分配 | 中动脉 | 分配至不同器官 |
| 毛细血管前阻力 | 小 / 微动脉 | 主要阻力与分流 |
| 交换 | 真毛细血管 | 物质交换 |
| 毛细血管后阻力 | 较大微静脉 | 影响毛细血管压与回心 |
| 短路 | 动静脉吻合支 | 体温等调节 |
| 容量 | 静脉 | 约容纳60%–70%血量 |

病理“细动脉”对应微动脉；课程强调动脉粥样硬化危害的重要部位为中动脉，完整病变归B5。

R∝ηL/r⁴。黏度四轴：HCT、切率、口径范围、温度。HCT升高一般增黏；较高切率降低表观黏度；微小血管口径效应需限定范围；低温可增黏。血管变窄的r⁴效应不能被“黏度下降一点”完全替代。

微动脉七入口：总闸门、交感支配丰富、主要阻力、主要压降、全身调压、器官分流、收缩后下游联动。后一项在其他条件固定时可见局部流量与毛细血管压下降、组织液与淋巴生成减少；组织代谢需求近似不变时氧提取差可增大。

## 7｜四个压力量与五因素矩阵

| 指标 | 定义 / 计算 | 课程值与限定 |
|---|---|---|
| SBP | 周期最高动脉压 | 理想值示例＜120 mmHg，不在此作诊断分级 |
| DBP | 周期最低动脉压 | 理想值示例＜80 mmHg |
| PP | SBP－DBP | 约30–40 mmHg |
| MAP | 一个周期压力的时间平均 | 正常静息常近似DBP＋1/3 PP；非简单算术平均 |
| CVP | 右房与胸内大静脉压 | 当前课程4–12 cmH₂O，注意与mmHg不同 |

| 单因素变化 | SBP | DBP | PP |
|---|---:|---:|---:|
| 平均充盈压↑ | ↑↑ | ↑ | ↑ |
| SV↑ | ↑↑ | ↑ | ↑ |
| HR适度↑ | ↑ | ↑↑ | ↓ |
| TPR↑ | ↑ | ↑↑ | ↓ |
| 大动脉储器作用↓ | ↑ | ↓ | ↑↑ |

先确认HR未快到拖垮SV、心功能和其他条件近似固定。四形成条件：足够血液充盈、心脏射血、外周阻力、大动脉弹性储器。平均充盈压可因血量增加或循环容积减少而升高。

昼夜节律课程关联视交叉上核，两个高峰约6–10时、16–20时；不能默认人人作息和所有疾病都严格出现同样峰谷。年龄需分阶段：老年大动脉僵硬可伴DBP下降与PP增宽。

## 8｜静脉回心的13项方向，分放两端

| 因素（课程促进回心方向） | 从因素走到回心的短链 | 读题条件 |
|---|---|---|
| 右心泵出增强 | 右房积血减少、压力降低→外周到右房的驱动差增大→回流增加 | 送血端和回流阻力近似不变；不能无限降压后仍无限增流 |
| 自主吸气 | 胸内压更负→胸内右房压力相对外周降低→血更易进入胸腔 | 不套正压通气；右心回流与即时左心输出不是同一个量 |
| 血容量增加 | 在血管容量条件近似固定时，静脉系统充盈提高→送血端压力支持增加 | 血量与血管容量要一起看 |
| 舒张期Ca²⁺回降加快 | 横桥更快解除→主动舒张更快→室内压下降、充盈更顺利 | 这是主动松弛，不是把顺应性定义为速度 |
| 从过快心率适当减慢 | 舒张充盈时间增加→每搏充盈得到支持 | 不能推成心率越慢总回流和CO越高 |
| 心包压力降低 | 心室外部限制减轻→舒张充盈较容易→接受回流的条件改善 | 要结合心腔压力及原有受限状态 |
| 心室顺应性增加 | 同样充盈压力下可容纳更多血→接受端充盈条件改善 | 与主动舒张分开；不能据此推任何情况下总回流必增 |
| 输液增加输入 | 单位时间进入静脉系统的液体增加→中央充盈与回心可增加 | 心脏接不住时可加重淤血，不是鼓励过快补液 |
| 直立转平卧 | 重力造成的低位静脉蓄血减少→更多血回到中央循环 | 总血量没有凭空增加 |
| 微动脉舒张 | 在驱动压近似维持的短时模型中，通过阻力降低→血更易流向静脉侧 | 全身舒张若同时使动脉压明显下降，不能机械判定回心增加 |
| 静脉收缩 | 容量池变小→动员已有静脉血、提高送血压力条件→促进回心 | 不是制造新血量，仍受回流阻力和右心限制 |
| 走路、跑步的节律性肌肉泵 | 挤压把血向近心端推，松弛再充盈；静脉瓣帮助定向→促进回流 | 与持续强力压迫不同 |
| 浸入深水 | 外部静水压力压缩低位静脉容量池→血向胸腔重新分布→中央充盈增加 | 是外压和分布改变，不是水从皮肤直接进入血管 |
方向是有条件的生理推演，不是补液、呼吸或运动治疗指令。持续肌肉压迫与节律性肌肉泵不同；正压通气与自主吸气不同；CVP高可能是送得多，也可能是泵不出。

急性失血先丢总量，刚发生时HCT不必立即下降；随后组织液回补或补液，血浆相对恢复快于红细胞后，HCT可下降。

## 9｜微循环三路、组织液与淋巴

| 通路 | 路径 | 主要用途与状态 |
|---|---|---|
| 迂回 / 营养 | 后微动脉→真毛细血管→微静脉 | 慢、周期开放，主要交换，课程常以肠系膜示例 |
| 直捷 | 后微动脉→通血毛细血管→微静脉 | 快、常开，快速回流与少量交换，骨骼肌示例 |
| 动静脉短路 | 动静脉吻合支 | 绕过正常交换床，快，温度相关开放，皮肤示例 |

三闸门：微动脉总闸门、前括约肌分闸门、较大微静脉后闸门。

动静脉短路的课程具体分布：指趾、耳廓、唇鼻皮肤；平时通常关闭，高温时开放增加皮肤血流，参与散热。不是所有组织都具备完全相同的三通路结构。

局部代谢产物在课程微循环模型中主要调节后微动脉和毛细血管前括约肌，影响营养通路周期性开放；微动脉承担器官血流总调节。营养通路经过真毛细血管，不以通血毛细血管作为该通路的必经段。

经典有效滤过压＝（毛细血管静水压＋组织液胶体渗透压）－（组织液静水压＋血浆胶体渗透压）。实际交换还需屏障通透性等条件；不能把经典式当全部组织完整动态模型。

淋巴课程约2–4 L/d；四功能：回收蛋白、运输脂类、体液平衡、防御免疫。

| 水肿入口 | 例子怎样落位 |
|---|---|
| 毛细血管静水压↑ | 心衰、淤血 |
| 血浆胶体渗透压↓ | 肝病、肾病、营养不良相关蛋白不足 |
| 通透性↑ | 炎症、过敏、烧伤 |
| 淋巴回收受阻 | 丝虫病、丹毒相关淋巴损害、乳癌橘皮样变等 |

## 10｜冠脉把供需和药物接起来

| 供需槽位 | 精确内容 |
|---|---|
| 左冠驱动近似 | 主动脉DBP－LVEDP |
| 右冠条件 | 收缩期压迫通常较小，收缩 / 舒张均可有流量，右室高压可改变时相 |
| 左冠时相 | 等容收缩流量骤减；等容舒张后快速增加；舒张早期高峰 |
| 三主要流量因素 | 舒张时间、舒张灌注压、冠脉舒张 / 阻力 |
| 局部代谢5项 | 腺苷、H⁺、CO₂、乳酸、缓激肽，按课程组织 |
| 其他舒张3项 | NO、CGRP、ADM |
| 课程总体促缩接口 | 迷走的代谢净效应、AngⅡ、较高浓度VP、ET；不等于各分子仅有单一局部作用 |
| 心绞痛共同结果 | 心肌氧供不足以满足耗氧；不是仅见于固定冠心病 |

冠心病、AS、AR、高血压、肥厚型心肌病、肺栓塞、X综合征在这里仅用于供需定位，不直接等同诊断或处理相同。

失血的再分配接口：交感使许多外周血管收缩；心肌和脑的局部代谢/血气调节帮助优先维持重要器官血流。这是相对保护，不能解释成失血再重也保证冠脑灌注正常；全身驱动压过低时保护仍会失败，后续接B2/B12。

β阻断主链：降HR / 收缩活动→降耗氧＋延长舒张灌注时间。课程非缺血区再分配是带条件的次级解释：心肌工作下降→非缺血区代谢性舒张信号减弱；若另有β₂阻断，其血管可相对收缩，而缺血区保留较强局部代谢舒张，可能改变区域分配。不能要求所有药必须阻断β₂，也不能把它当所有病变下必然改善灌注的保证。

硝酸酯三靶点：静脉侧为主减前负荷与壁张力；动脉侧减后负荷；冠脉 / 侧支相关作用改善部分局部条件。固定严重狭窄时不能保证总冠脉流量必升。

## 11｜六条串联，先声明条件再推方向

以下接原题纲末尾六组题；它们是单因素、短时近似模型。先固定题干没有改变的条件，出现同时变化时重跑模型，不能把箭头当成疾病诊断。

| 起始改变 | 一路推到结果 | 哪个条件不能漏 |
|---|---|---|
| 心率在可代偿范围内加快、周期变短 | 舒张时间缩短→单次舒张内动脉向外周流出相对减少→舒张末保留血量较多→DBP升幅较突出，SBP也可升，PP减小 | 若已经明显损害充盈/SV，不能继续沿这行推 |
| SV减少 | 收缩期输入动脉的血量减少→SBP下降较多、DBP也下降→PP倾向减小 | HR、阻力与储器作用近似固定 |
| 题干明确大动脉压升高，后负荷骤增 | 出口负担增大→当搏SV下降、ESV增加；后续EDV是否上升另看回心 | 动脉压是本题给定起点；不能由SV下降反过来删去起点，也不能把瓣膜狭窄等同同一压力条件 |
| 心泵功能瞬间增强 | 左侧输出提高倾向→动脉压得到支持；右侧排空增强→右房/CVP降低倾向→回流驱动差增大 | 总血量、静脉张力和外周条件近似固定 |
| 体循环微动脉收缩 | TPR上升→动脉压/左室后负荷上升→等容收缩可延长；流向静脉侧减少时CVP可下降 | 不能仅凭TPR无条件预测CVP，还要排除同步静脉收缩、血容量和右心变化 |
| 急性失血 | 总循环量减少→回心/输出受限，动脉压和CVP可下降；刚丢全血时HCT未必即降，随后组织液回补/补液使血浆较快恢复，HCT才可下降 | 总量与浓度分开；把“刚发生”和“液体回补后”分开 |
