# 冠脉怎样失去供血，心肌怎样从缺血走向坏死

心脏为了把血送给全身，自己也必须不断得到氧。冠脉问题首先应放回这笔收支：供氧取决于冠脉血流和动脉血氧含量，耗氧则随心率、收缩力和室壁张力增加。心率加快尤其容易同时挤压两边：收缩次数增加，舒张期冠脉灌注时间又缩短。因此贫血可以在没有新狭窄时降低供氧，劳力可以在冠脉储备不足时提高需求；胸痛并不自动等于一处新血栓。

> 定位（可略读）：心肌氧供—耗氧预算：HR升高为何双重不利〔供氧公式/变量｜耗氧3核心｜HR双重作用｜贫血反例〕；固定狭窄与斑块事件：不是“狭窄越来越重”的一条路〔稳定vs易损｜储备/急性风险〕。

血管失去储备与通路突然中断，应当分成两种上游故障。固定狭窄使静息供血尚可而增加流量的空间变小，活动超过这条上限便出现可逆缺血。斑块破裂或糜烂则暴露促血栓表面，把血小板与凝血接到同一个局部事件上，供血可能骤降。狭窄程度与斑块易损性不是同一尺度：一处很窄的稳定病变和一处未必最窄却易破裂的病变，危险方式不同。

```text
需求上升 + 冠脉储备不足 → 供需失衡 → 可逆缺血
斑块事件 → 血小板/凝血 → 血流骤降 → ACS
持续严重缺血 → 心肌坏死 → 电、泵和结构后果
```

## 从可预测的缺血理解症状与药物

稳定型心绞痛的“稳定”指发作方式在一段时间内相对可预测：相似活动触发相似症状，休息或降低需求后缓解。判断要把部位、性质、放射、诱因、持续时间、缓解方式放在一起；课程典型发作持续数分钟、通常小于30分钟，但单凭“很痛”不能判断坏死与否。稳定型也不能被压成所有患者都存在显著大冠脉固定狭窄，微血管功能与痉挛仍可进入供需模型。

> 定位（可略读）：“稳定”和“劳力”分别意味着什么〔稳定5维｜劳力→需求链｜固定供血上限〕；典型胸痛六要素〔胸痛6轴｜稳定模式｜程度≠分类〕；微血管性心绞痛 vs 心脏神经官能症〔症状｜负荷/造影｜硝酸反应局限｜排除路径〕。

微血管性心绞痛可有心绞痛样症状、负荷阳性，却无明显大冠脉狭窄，课程落在微循环故障；并不要求大血管痉挛。神经官能症则常青壮/更年期女性、焦虑背景，痛可针刺、变位置、仅几秒或数小时，伴叹息心悸头晕失眠、疲劳后出现。硝酸酯反应可变，不能由无效判神经性或由有效判缺血；正常造影也不能停止排查致命器质病。

缺血时的交感反应可表现为出汗、皮肤血管收缩，短暂心肌功能障碍还可带来S4、S3、A2延迟或暂时性二尖瓣反流。这些功能变化不能直接改叫乳头肌断裂。课程原文把周围动脉收缩与压力下降并写，存在实际Source表述冲突：局部收缩并不能单独推出全身血压下降，应回到心排量、阻力和容量。活动受限的CCS I–IV分级描述触发症状的活动量，亦不要与“慢性冠脉综合征”的同名缩写混淆。

> 定位（可略读）：缺血发作时的电—机械短暂异常〔发作交感链｜S3/S4/S2逆分裂/暂时MR→机制｜可逆vs结构损害〕。

降耗氧药物必须说明究竟改了哪一个变量。硝酸酯主要降低前负荷，兼降后负荷；β阻断剂降低心率和收缩力，不应另造“所有情况下冠脉流量都增加”的解释。二氢吡啶类CCB主要降低小动脉阻力和后负荷，反射性心率、收缩力增加不等于直接正性肌力；非二氢吡啶类则可降低心率与收缩力。课程表中的空白仍是空白，不能为了四列整齐补造箭头。若症状来自冠脉痉挛，治疗靶点已改变：CCB进入重要接口，不能机械套用β阻断剂单药方案。

> 定位（可略读）：抗心绞痛药先按被调变量理解〔药物4类→前负荷/后负荷/HR/收缩性｜供需2端〕；变异型心绞痛：核心是自发严重痉挛〔痉挛链｜诱因/时机｜ECG动态≠坏死｜药物选择/β阻断边界〕。

症状控制与事件预防还要分别解释。伊伐布雷定通过If影响心率，雷诺嗪通过晚钠电流及钙负荷接口，曲美他嗪通过代谢，尼可地尔通过钾通道和微血管接口，都应回到供需而非药名队列。课程β阻断剂目标心率写作55–60或50–60次/分，必须连耐受条件一起保留。另一方面，抗血小板、调脂、危险因素控制、适当RAAS干预和适应证内的血运重建指向长期事件与重构风险。

> 定位（可略读）：稳定期治疗两目标：症状改善 ≠ 预后改善〔目标2｜症状药组｜事件预防组｜缓痛≠降死亡〕；抗板、降脂、PCI / CABG各改变哪一层〔抗板靶点/代表｜LDL课程目标｜联合降脂｜PCI/CABG条件〕。

阿司匹林不可逆抑制COX-1，吲哚布芬为可逆作用；P2Y12路径中的替格瑞洛、氯吡格雷与后者CYP2C19代谢差别，不意味着活动性消化道出血时可自动换药继续。课程LDL目标按人群区分：稳定ASCVD小于1.8、ACS小于1.4、无ASCVD的糖尿病小于2.6 mmol/L，不能合成健康人统一阈值。药物下仍有症状时评估PCI/CABG；左主干、复杂多支病变或糖尿病等解剖和个体条件影响选择，课程示例不构成现实全部适应证的穷尽清单。

## 供血骤降后，先问是否坏死，再问如何争取时间

ACS可呈UA、NSTEMI、STEMI或猝死，慢性冠脉综合征包含稳定心绞痛、无症状冠心病和缺血性心肌病；二者并非不会互相转入的封闭盒子。新发、静息或恶化的症状说明阈值变化，不能仅凭症状给出坏死结论。课程新发1–2月、活动分级达到III级，或恶化至少一级，是症状分型的具体接口；变异型静息、夜间痉挛可暂时ST抬高而没有坏死。

> 定位（可略读）：CCS vs ACS：先问当前是“稳定供血上限”还是“急性供血骤降”〔Study分类：ACS4/CCS3｜深层区别｜状态转换〕；UA：症状阈值下降，说明病理已经从固定狭窄变成动态事件〔斑块急变｜分型4种｜CCS 4级｜坏死边界〕；UA vs NSTEMI：最关键边界是坏死标志物〔UA vs NSTEMI｜ECG｜标志物动态｜缺血证据〕；NSTEMI vs STEMI：不是“小梗死”和“大梗死”〔NSTEMIvsSTEMI：闭塞/损伤层次/ECG/标志物/再灌注｜血栓相对性〕。

UA与NSTEMI的分界是是否出现符合缺血性梗死的心肌损伤证据。早期一次肌钙蛋白阴性不能机械排除，单次升高也不能证明是缺血性心梗，必须结合动态、症状和ECG。NSTEMI有坏死而没有典型持续ST抬高谱系，STEMI进入紧急再灌注路径；不能把两者简化成“小梗死/大梗死”。血栓中血小板与纤维蛋白、红细胞的相对构成也不是绝对有无关系，NSTEMI不常规走STEMI全身溶栓路径，依据是总体获益和出血风险，不能说因为它“没有纤维蛋白”。群体短期死亡率差别不是个人预后保证。

抗栓同时涉及血小板和凝血，但不是多种药越堆越好。DAPT、抗凝、降耗氧和调脂各有靶点；GP IIb/IIIa主要保留选择性补救接口，不是所有PCI的第三种常规抗板药。磺达肝癸钠间接作用Xa，比伐卢定直接抑制凝血酶，不能混成同类；前者之后PCI时的UFH接口仍要保留。早期侵入策略下未知冠脉解剖，不自动预先加载P2Y12；长期DAPT必须考虑出血和合并抗凝条件。早期β阻断及RAAS药同样要看血压、肾功能、血钾与稳定性。

> 定位（可略读）：UA为什么需要更强抗栓和风险分层〔治疗5层→目标｜危险征象→侵入优先级〕。

若休克、严重心衰、致命心律失常或心停、机械并发症、反复ST抬高或难治性胸痛已经出现，不应等所有生物标志物凑齐才处理。课程极高危小于2小时的侵入策略接口指向这种紧急性，时间口径仍受Source条件约束。

## 缺血持续以后，组织、检查与空间定位怎样对齐

持续胸痛超过30分钟支持AMI的临床入口，但老年或糖尿病患者可不典型，下后壁还可突出胃肠和迷走神经表现。低血压则必须拆成泵输出下降、外周阻力下降和容量不足。相同压力读数可能对应不同充盈状态，肺水肿、高充盈压时盲目补液与低容量状态下谨慎补液并不等价；无机械并发症的心梗休克不能仅按旧课程对应表常规IABP。血压正常或升高也不能排除MI。

> 定位（可略读）：STEMI胸痛与非典型表现〔胸痛5轴｜下后壁胃肠入口｜老年/DM非典型〕；坏死吸收反应 + 低血压的三条路径〔吸收反应3项/时点｜低压3路径｜感染鉴别接口〕；急性右室梗死：右室失效后，左心首先缺“前负荷”〔伴发部位｜CVP/PAWP/肺部｜RV→LV前负荷链｜容量/硝酸酯/利尿条件〕。

右室梗死把这种区别放大：常与下壁/后壁同现，颈静脉怒张、CVP升高而PAWP正常或降低，右室向前输送不足便减少左室前负荷。维持适当充盈和尽快再灌注是同一链上的两项工作，并非所有病例无限补液；硝酸酯和利尿剂若进一步减少回心，可使输出更低。肺淤血与体循环静脉压因此必须分别看。

心肌坏死早期主要是凝固性坏死，核固缩、碎裂或溶解，胞质红染、收缩带以及间质水肿和中性粒反应构成组织层证据。疼痛后1–2天低热、中性粒和ESR升高可来自坏死吸收，不能自动等于感染。课程时程是约4天外围充血/出血带，1–2周坏死溶解并从边缘长入肉芽，约3周机化逐渐形成瘢痕，6–8周愈合。心肌不能有效再生，瘢痕修补了连续性，却没有恢复原来的收缩肌。

> 定位（可略读）：心肌梗死病理时程：坏死 → 清除 → 肉芽 → 瘢痕〔梗死类型/细胞改变｜修复4时点｜肉芽→瘢痕｜修复≠收缩恢复〕；坏死标志物：谁最早、谁最特异、谁回落快〔标志物3种｜升高/回落｜再梗死/再通｜损伤≠梗死〕；ECG三层：缺血、损伤、坏死〔T/ST/Q→3层｜STEMI动态4期｜电投影≠组织切片〕。

血液标志物观测组织损伤，但检测时点和方法改变其解释。传统课程肌红蛋白2小时内升、1–2天回落，敏感但特异性低；cTn约3–4小时后升、持续1–2周，高敏检测不能机械套旧最早时点；CK-MB约4小时内升、3–4天回落，较快回落可帮助短期再梗死判断。持续升高的cTn并非完全失去用途，再次动态仍须结合缺血证据。ECG的T、ST、病理Q分别关联缺血、损伤和坏死，超急性高T到ST抬高、再到ST回落/T倒置及慢性残留变化，是电投影的时间演变，并非组织切片。

> 定位（可略读）：导联—心壁—冠脉：用空间投影定位〔导联5组/广泛前壁｜LAD/LCX/RCA供区｜节律接口〕；梗死部位与节律接口：前壁偏室性，下壁偏缓慢传导〔LAD/RCA｜前壁vs下壁：供区/节律｜前壁AVB意义〕；检查层级：每项检查证明不同东西〔检查8项→证据层｜缺血/坏死/解剖/灌注/活力/机械｜负荷禁用情境〕。

空间定位还要把导联、心壁和供区分层。课程V1–V3看前间壁，V3–V5看心尖/局限前壁，V5–V7看前侧壁，I/aVL看高侧壁并进入原图前侧壁组合，II/III/aVF看下壁；广泛前壁原图括线为V1–V5，I/aVL标±，不能改成每例必阳性。LAD典型供应前壁、心尖、前间壁及部分侧壁和前乳头肌，LCX供应侧壁及左房；右优势型RCA可供下后壁并参与SA/AV结供血。故前壁大片心肌缺血偏向室性风险，下壁偏向缓慢节律与AVB，前壁出现AVB提示广泛病变；个体优势型变化又使导联不能锁定唯一血管。

CTA说明解剖，造影观察管腔，核素心肌显像主要看灌注缺损，核素心腔造影看心腔功能，PET通过代谢评估活力，超声看室壁运动与结构，负荷试验诱发供需失衡，Holter记录动态ST。不同问题决定所需证据，不能排成一种“最佳检查”通吃。急性UA、AMI、心衰、严重心律失常或急性疾病时的负荷试验禁忌，以及课程造影“金标准”的考试范围，都必须连问题和条件一起读取。

## 同一片坏死，可以造成不同的循环故障

坏死以后不是只有泵弱。电活动异常可产生致命节律，收缩受损可同时造成前向低灌注和上游淤血，结构破裂可让血走错路径，附壁血栓可栓塞，修复重构和炎症又产生较晚的后果。新杂音、肺水肿、休克或持续ST各是不同故障层的线索。

> 定位（可略读）：并发症总地图〔并发症6层→代表｜从损伤部件定位〕；乳头肌功能不全 / 断裂：新发MR的两个层级〔乳头肌功能不全vs断裂｜血供/部位｜急性MR→肺水肿/低输出〕；游离壁破裂 vs 室间隔破裂：血流去向决定后果〔两处破裂的血流去向｜各自循环后果｜识别线索与危险〕；室壁瘤 vs Dressler：结构重构 vs 免疫炎症〔室壁瘤：形成/超声/ECG｜Dressler：时程/机制｜早期心包炎对照〕。

乳头肌暂时功能不全与真正断裂的结构危险不同；后乳头肌单一供血与下壁MI相关，断裂可骤成重度MR，让左房压力升高并引起肺水肿，杂音却不保证很响。室间隔破裂让左室血急流向右室，形成新的左向右分流、肺循环负担和低输出，胸骨左缘3–4肋间新收缩期杂音是接口。游离壁破裂则使血进入心包，压塞限制充盈，可能出现PEA；引流并不修复裂口，结构修复必须另行处理。

```text
乳头肌断裂 → 急性MR → 左房压升高 → 肺水肿
室间隔破裂 → 左向右分流 → 肺循环负担 + 低输出
游离壁破裂 → 心包积血/压塞 → 充盈受限 → 循环崩溃
```

晚期瘢痕薄弱局部膨出、矛盾运动形成室壁瘤，持续ST只是支持线索；它与DCM弥漫扩张不同，Q波也不是绝对界线。心梗后数周至数月的Dressler是免疫性心包炎，可伴胸膜/肺炎症，不能与2–3天的早期心包摩擦音并成同一时相，课程发生率约1–3%仍保留为来源精确项。

> 定位（可略读）：Killip vs Forrester：临床严重度 vs 湿 / 冷双坐标〔Killip 4级｜Forrester 2轴/4型｜阈值〕；AMI急性左心衰：肺水肿和低灌注要分开读取〔淤血vs低灌注｜血压/充盈｜利尿-扩管-循环支持｜KillipvsForrester〕；B6 → B11 Preview：MI怎样走向心衰，但不提前重学〔MI→重构→心衰｜LVEF分型｜A–D接口｜绝对vs相对灌注｜长期目标〕。

评估泵后果时，Killip用临床心衰表现分级，I级无明显心衰、IV级心源性休克；课程II级肺啰音少于50%肺野、III级急性肺水肿超过50%，恰好50%的空白不能自行补判。Forrester把充盈和输出分开：PAWP 18 mmHg、CI 2.2 L/(min·m²)两轴，低楔压/高CI为干暖，高楔压/高CI为湿暖，低楔压/低CI为干冷，高楔压/低CI为湿冷；课程边界高楔压含18、低CI含2.2。低压不单独决定补液或利尿，右室故障尤其可能低输出而左充盈不高。完整心衰EF类型、A–D阶段、绝对/相对灌注与神经体液重构机制在B11，当前AMI先处理供血中断及紧急后果。

## 救治动作必须对准故障层与时间窗

再灌注的收益来自保住尚可挽救的组织，不是把已死细胞重新变活。起病时间与医疗系统延迟是两只钟，不能把“3–6小时收益好”读成先等3小时；课程小于12小时、可及时PCI优先，预计延迟大于2小时且符合溶栓条件时考虑溶栓。超过12小时仍有持续缺血、休克或致命节律时，仍须评估再灌注。精确120分钟的起止点在ESC诊断到导丝与AHA首次接触到器械口径间不同，不能悄悄合并。

> 定位（可略读）：再灌注：有无PCI条件，目标都是尽快救回尚可逆心肌〔时间2轴｜PCI/溶栓条件｜可逆vs坏死〕；抗板、抗凝、溶栓、PCI、降耗氧分别作用哪一环〔干预6层→靶点/目标｜抗凝vs溶栓｜急性vs长期〕；溶栓禁忌 + 再通证据〔溶栓禁忌5风险组｜夹层排除｜间接再通4类｜直接证据〕。

抗板抑制血小板，抗凝限制凝血扩展，溶栓作用已形成的纤维蛋白血栓，PCI机械恢复通路，降耗氧和长期调脂/抗重构再接到不同层。再灌注前β阻断、硝酸酯、吗啡或哌替啶不是人人同用的一组药，低压/右室梗死以及阿片风险需要条件，不得延迟通路恢复。课程阿替普酶/rt-PA、重组尿激酶原属特异性纤溶酶原激活剂，尿激酶属非特异性；分类并不免除出血安全评估。

溶栓之前要识别卒中或中枢病变的类型与时点、活动性出血、近期手术创伤/不可压迫穿刺、严重未控高压及主动脉夹层等危险。课程180/110 mmHg为来源阈值，CPR和旧卒中不能不分条件一律判禁忌。CK-MB峰小于14小时从起病算，胸痛缓解、再灌注节律与ST回落大于50%的2小时从溶栓算；这些都是间接线索，不能等价于造影证实，也不能在持续不稳定时硬等2小时。

> 定位（可略读）：主动脉夹层：错误进入溶栓路径可以致命〔MI vs UA｜夹层线索｜溶栓前鉴别〕；最终病例算法：从胸痛到处理优先级〔稳定性｜缺血模式｜ECG｜标志物｜反例｜再灌注｜并发症〕；AMI节律并发症：先看有效循环，再调用B10 / B12〔脉搏/稳定性→快慢｜室性恶性节律｜偶发vs频发｜高阶AVB接口〕。

胸痛算法首先看稳定性，再把症状、ECG、动态标志物、致命鉴别和并发症放在一起。主动脉夹层若累及冠脉开口也能ST抬高，撕裂样胸背痛、起病即峰值、两侧压力/脉搏不对称、新AR及影像改变必须在溶栓前被考虑。MI与UA的症状比较只提供概率，不产生绝对排除。

节律处置又由有效脉搏和稳定性分流：VF或无脉VT进入CPR和非同步电治疗；有脉不稳定快速节律通常需要可靠同步，多形性情况另走非同步接口。无症状、无血流动力学障碍的偶发室早可观察，不能对全部频发室早预防性静脉给药；缓慢节律、尤其高级AVB需起搏接口。课程利多卡因与胺碘酮先后顺序的实际Source冲突仍HOLD，完整节律归B10、休克和骤停归B12。这些分流和急性泵衰支持共同保护输出，再灌注则处理它们共有的缺血上游。
