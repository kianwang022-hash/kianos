# B3｜电信号怎样按时发出、传开，再变成一搏
## 给 Chat 的建模教学稿 · 正式正文对齐版

> 组织规则：[Lecture Replacement Contract](../../../knowledge/learner/LECTURE_REPLACEMENT_CONTRACT.md)。

沿“发令—传播—电机械耦联—观察信号”的整章电影连续教学；七个 LG 只在后台负责覆盖、检索与收口，不作为可见分栏。需要时分别放大细胞波形、起搏、不应期、传导、耦联与调制。样稿不主动向用户出题；故障推演直接说明定位过程。数字只在它改变当前判断时当场使用，其余归精确表。

# 开 Block｜给B1的机械泵接上时间和信号

B1讲的是装血、产压与射血，B2讲的是变量偏了以后怎样调节。B3补上另一层：心肌不能随便各跳各的，它需要合适的发令者、传令顺序和电—机械转换。

ECG 是心电图，AP 是动作电位；CICR 是钙诱导钙释放。先在整搏中定位，后面再展开单细胞波形与电—机械耦联。

先看一部电影：

```text
窦房结自行达到阈值 → 发出本次兴奋
                         ↓
                 兴奋传遍心房
                         ↓
                房室结慢传导延搁
                         ↓
               希—浦系统快速分发
                         ↓
               心室肌依次、协调除极
                         ├─ 全心电活动叠加 → 体表ECG记录
                         │
                         └─ 单细胞Ca²⁺内流 → CICR
                                             ↓
                                     横桥活动 / 收缩
                                             ↓
                                   压力变化 → 射血条件
                                             ↓
                                      有效输出 / 脉搏

复极与通道恢复 → 为下一次兴奋准备
长不应期与收缩重叠 → 避免强直，保留舒张机会
```

ECG是观察电活动的一个窗口，**不是电信号必须先经过ECG才会产生收缩**。同样，有电活动不保证有效射血：后面还要有耦联、足够机械力和合适的充盈 / 负荷。这条边界留给B12再验证。

同一搏从起搏发令、传播到受令心肌的动作电位与收缩；细胞身份、通道恢复和神经药物调制是贯穿这条链的判断轴，不是逐组交接。

# 发令与传播：先确定谁发、怎样传

## 先判细胞身份，再谈某个离子怎样起作用

同一个Ca²⁺通道，在窦房结可参与0期，在心室肌则主要参与平台期。若先不认细胞，后面每一条“升高、降低”都有可能错位。

```text
第一条轴：0期怎样升起来
├─ 快反应：INa为主 → 上升快、幅度大
└─ 慢反应：ICa-L为主 → 上升较慢、幅度较小

第二条轴：4期会不会自己爬向阈值
├─ 工作细胞：相对稳定静息
└─ 自律细胞：自动去极化
```

心室肌是快反应工作细胞；窦房结是慢反应自律细胞；浦肯野是快反应自律细胞。两条轴是交叉的，不能把“快”直接当“自律性高”。

窦房结最容易先发下一次命令，不等于它传得最快；浦肯野传得快，也不等于它应该抢正常节律的主导权。

另外四个观察层要分开：单细胞AP是跨膜电位曲线，传导是细胞间兴奋传播，ECG是全心活动的体表投影，机械输出是后续耦联和负荷下的结果。它们相关，但不能互相冒充证据。

B3只搭P对应心房除极、QRS对应心室除极、ST-T与心室复极过程相关这座桥。临床导联、PR/QT定量和节律诊断不提前搬进来。

## 窦房结为什么不等外来命令就能发下一搏

把心室肌稳定的4期换成缓慢爬升的4期，就从等待触发转为能够自发到达阈值。这里比较的是每次起搏的时间安排，不是0期的传导速度。

```text
上一次复极到最大复极电位
                 ↓
外向K电流逐渐减弱＋If等内向净电流参与
                 ↓
       4期缓慢自动去极化
                 ↓
ICa-T及其他Ca相关机制参与后段推进
                 ↓
达到ICa-L充分参与的阈值范围
                 ↓
       慢反应0期去极化
                 ↓
      K电流复极 → 再开始下一轮
```

窦房结没有稳定静息电位，所以用“最大复极电位”描述最低点；也没有心室肌那样明显的1、2期平台。不能把所有心肌AP都画成同一个五阶段模板。

### 1｜If和INa名字像，触发条件却相反

INa是快反应0期主要电流，去极化达到相应条件时快速开放。If在复极 / 超极化方向被激活，在起搏电位范围提供内向净电流，通道可通过Na⁺和K⁺，不能定义为只通Na⁺的快钠通道。

课程保留IK衰减、If、ICa-T和Na-Ca交换四个贡献位置。教学时先讲外向减少＋内向增加的合力，不把“某一项是唯一主导”扩展成所有物种、窦房结部位和实验条件的定论。

### 2｜电位数字是原图坐标，不是所有通道的硬开关

约－65、－60、－50、－40 mV帮助恢复本课程的窦房结图：最低点、If参与、T型Ca参与、L型Ca触发0期。实际激活是范围和概率，If尤其有细胞与条件差异，不能把一个数字当所有细胞统一阈值。

因此先记它们在图上的相对位置，再记近似数值；不要先背一排负数却分不清哪一个属于工作心肌。

再用开放方式和阻断位置验证差别：L型Ca通道开放较慢、持续较久，课程将维拉帕米/锰放在这里；T型较快且短暂，课程放镍。INa快速开放，课程用TTX/Ⅰ类药定位；If开放较慢，铯/伊伐布雷定定位到起搏支路。INa还在神经和骨骼肌兴奋中出现，L型另有平滑肌接口；它们的分布不能只看心肌一张图。这些是正式KP08的课程对照，不是离开细胞和实验条件的通用药物处方。

### 3｜三细胞对照只换关键开关

心室肌：Na快0期、长平台、稳定4期；窦房结：Ca慢0期、无明显平台、自动4期；浦肯野：快反应AP兼有潜在自律性，适合快速传导。

浦肯野的最大复极电位数值在原图中存在正负方向写法歧义，暂不强制记“＞－90”或“＜－90”的单一数字。保留快0期、潜在自律与快传导，不用错误符号制造精确感。

## 谁先发令，与谁传得快，要分别判断

把一个细胞的AP扩展为细胞之间的传递，再看哪个自律点正常占主导。没有这一步，单细胞图无法解释全心时序。

```text
已兴奋细胞0期速度 / 幅度
          ＋细胞间耦联、直径等结构
          ＋邻旁细胞可兴奋状态
                         ↓
                    传播速度与可靠性

窦房结先达到阈值 → 心房 → 房室结延搁
                         ↓
                希—浦快速分发 → 心室协调激活
```

房室结慢并不是“功能差”，它让房、室机械活动有合理时间关系。浦肯野快，适合把兴奋迅速送到心室各处。快慢是否有利，取决于它处在整条路的什么位置。

### 主导起搏与下位接管

窦房结固有自律频率较高，下位点尚未自行达到阈值，正常冲动已经来到并重置它。抢先占领说明正常窦律怎样获得主导。

长期被较高频率驱动后，下位点的自发活动还可能受抑制，外来驱动突然消失不一定立刻接管，这叫超速驱动阻抑。它是需要监护的起搏器管理背景，不能变成学习者自行调低或停止设备的操作建议。

异位点自己变快、提前夺权，和上游过慢 / 下传受阻后被迫接班不同。前者是主动异位接口，后者是逸搏接口。不是看到“起搏点不在窦房结”就统称一种问题。

4期斜率、起点到阈值的距离共同影响到达阈值的时间；但仍要保留通道是否可用的条件，不能把过度去极化也当作无限加速。

# 受令细胞：波形、恢复与机械输出

## 一条长动作电位怎样由电流接力形成

把受令的心室肌与自行起搏的窦房结对照：心室肌把0–4期完整摆出来。理解顺序不是背五个名字，而是每一阶段内向与外向电流的相对变化。

```text
4期稳定静息 → 刺激达到阈值
                    ↓
0期：快Na通道打开 → 快速内向电流 → 去极化
                    ↓
1期：Na通道失活＋瞬时外向电流 → 初期复极
                    ↓
2期：Ca等内向电流与K外向电流相对平衡
                    ↓
                 平台维持
                    ↓
3期：内向电流减弱、外向复极作用占优势
                    ↓
              回到较负膜电位
                    ↓
4期：维持静息；泵与交换持续维持离子稳态
```

### 1｜平台不是没有离子流

电位变化很慢，意味着净电流相对小，不等于内外电流都为零。ICa-L内向电流与K⁺外向电流相互抗衡，少量Ca²⁺进入还会触发后面的CICR。

因此平台同时有两种重要含义：它延长电活动的时程，也给电—机械耦联提供触发。不能因为Ca²⁺触发量不占全部胞质Ca来源，就把它当成无关紧要的支路。

泵和交换体也不是必须等到4期才突然开始工作。把4期写成“恢复稳态”是阅读分工，实际转运贯穿活动。

### 2｜IK1的名字，不等于K⁺始终向内流

“内向整流”描述电流—电压关系，不是每一刻离子方向的固定标签。IK1帮助维持较负静息，在平台期的外向作用受限，并在终末复极时发挥重要作用。

但电导和实际电流不同。膜电位接近K⁺平衡电位时，推动K⁺外流的驱动力会变小；不能把课程的“复极时IK1恢复”无限推成“越负，K⁺外流永远越大”。

这条边界现在就要保留，否则同一张图会错误推出电位无限负下去。当前不要求展开全部多胺阻断模型，只需区分“通道可通过多少”与“实际被什么力推动”。

### 3｜APD反映整个净电流过程，不能只认一个通道

APD从去极化开始到复极完成。复极占较长时间，因此K⁺电流很重要；平台内向电流、细胞类型和刺激频率也会改变APD。

阻断复极K电流通常可延长相应APD；减少某些平台内向电流可缩短。不能反过来认为任何Na通道阻断都会延长APD，或同一种药在所有细胞都给同方向。

还要把“电流有多大”和“持续多久”分开。课程中的高钙血症常见平台/APD缩短，不能因为Ca²⁺是内向电流，就反推平台一定延长。Ca通道本身存在Ca依赖性失活，进入的Ca还能影响通道后续可用性；复极的结果要看整个净电流随时间怎样变化，不能只盯一个瞬时幅度。原材料把这全部归于INa,late膜屏障、并淡化Ca通道变化的解释，仍需要单独核验，不作为唯一机制。

原课程把普罗帕酮放在延长APD一栏，需要细胞与实验条件限定。当前用药物识别“改哪条电流”，不把其单一表格方向写成全心通用定律。

**关系压缩：先看内外电流的合力，再看通道状态和驱动力；平坦不等于静止，恢复也不等于无限增强。**

## 能不能再次兴奋，取决于通道是否恢复

同一动作电位既有电流过程，也有通道恢复过程。现在看刚经历一次AP的细胞会怎样对待下一次刺激。最重要的是分清：电位曲线回到哪里，与产生并传播下一次AP的能力，不是同一个量。

```text
0期后通道失活 → 不能产生正常传播反应
                 ↓ 复极、时间与状态逐步恢复
有效不应期结束 → 相对不应：需要更强刺激
                 ↓
更多通道恢复＋膜与阈距离改变 → 超常期条件
                 ↓
回到正常反应状态
```

把曲线位置接回功能：当前Study的ERP从0期至3期约－60mV，包括绝对不应和局部反应，不能形成正常传播AP；约－60到－80mV的相对不应阶段只恢复部分Na通道，需阈上刺激，新AP可较小、0期较慢、传导较慢、时程/不应期较短。约－80到－90mV的超常阶段，多数通道恢复且膜—阈距离较近，阈下刺激也可能触发。近似电位属于该课程曲线，功能判断仍需细胞与通道状态条件；不能将每种心肌都套成同一硬阈值。

### 1｜距离近，不保证一定更容易兴奋

膜电位适度接近阈值，所需刺激可减少；但持续过度去极化会让大量快Na通道失活，细胞反而更难形成有效0期。这解释了轻度与严重高钾不能用同一根上升箭头描述。

兴奋性看能否被触发，传导还要看0期形成多强的局部电流及邻居能否响应。严重去极化可同时影响两者，不能只凭“离阈值更近”就判断传得更快。

临床用Ca²⁺拮抗高钾心脏毒性是膜稳定接口，不等于把血钾降下去。当前不提供静脉用药操作，完整处理回泌尿 / 急救。

### 2｜APD与ERP不能画等号

APD是电位波形的时长；ERP是不能产生有效传播反应的功能时段。它们常相关，却可被药物、通道恢复速度和刺激条件不同比例地改变。

所以ERP/APD增大，不要求ERP本身必定绝对延长：若APD缩短更多，比例同样能增加。先把分子、分母分开，才理解课程IA与IB比较。也不能只靠这个比例判断任何药物的临床安全或疗效。

### 3｜早来的兴奋会重新占用一段不应期

超过有效不应期后，足够的异位刺激可引发期前兴奋，随后又有自己的不应期。若下一次正常下传撞进不应期，就可能不能产生正常心室收缩。

这是一条解释停顿的局部机制，不是所有早搏间歇的唯一原因；完整节律还涉及窦房结是否被重置、传导路径等。B10再处理，不在这里把“早搏后必有完全代偿间歇”当规则。

长ERP覆盖大部分收缩期，让心肌不能像骨骼肌那样靠连续刺激形成完全强直。泵必须有舒张与充盈机会，这个电学特征直接服务机械任务。

## 少量Ca²⁺触发，怎样变成真正的机械收缩

把母图中通向机械活动的分支展开。这里终于让电学回到B1的压力、瓣膜与射血。

```text
心室肌平台期ICa-L开放
          ↓
少量外Ca²⁺进入 → 触发SR的RyR释放Ca²⁺
          ↓                    CICR
胞质Ca²⁺增加 → 肌钙蛋白相关开关改变
          ↓
横桥活动 → 心肌产生力
          ↓
在相应充盈 / 负荷条件下 → 压力变化、射血
          ↓
Ca²⁺回收 / 排出、横桥解离 → 舒张 → 继续充盈
```

心肌依赖外Ca触发与肌浆网释放的配合；骨骼肌更突出电压感受器与释放通道的机械耦联。两者都有横纹与横桥，却不能用同一套耦联开关完全替代。

把这一差别沿前面的信号链检查，而不是另背十一行：骨骼肌由运动神经ACh—N2受体启动，心室肌则在已有节律上接受自主神经β1、M等调节；前者静息普通钾漏突出，后者IK1突出。骨骼肌AP短、无平台，心室肌AP长、有平台；内部耦联结构分别为三联管、二联管。结构把电压变化连到肌浆网放Ca，心室肌依赖L型外Ca触发，所以Ca通道阻断可抑制其收缩；骨骼肌对外Ca依赖较低，这类阻断通常不直接抑制其收缩。药物方向由耦联方式解释，不能只凭“都是横纹肌”类推。

功能合胞体让心房和心室分别协调激活，但“全或无”不是每一搏力量都固定。每个细胞的Ca²⁺、活化横桥数及负荷条件仍会改变整体力量。

不能用骨骼肌式募集更多运动单位解释心室增强，也不能靠强直把泵持续挤住：骨骼肌可用运动单位募集形成空间总和，短AP也允许时间总和与强直；心肌的功能合胞体和长ERP使这两种“加力法”不能照搬。B1的前负荷—长度与收缩性区别在这里重新接上：改初长度，与改Ca²⁺ / 横桥能力，是不同途径。长度—张力比较仍带课程作用域：骨骼肌可有明显降支，Study心肌工作范围不见明显降支；不能说心肌无限拉长都更有力。

# 调制：在同一信号链上改变开关

## 神经和药物通过不同开关，改写同一部电影

最后把B2的神经输出翻译到细胞机制。不把“交感四正、迷走四负”只当口诀，而是看同一信号落到哪个细胞、哪个时期、哪种性质。

```text
NA / Adr → β₁ → cAMP相关信号
            ├─ PKA等调节ICa-L → Ca触发 / 收缩增强
            ├─ 受磷蛋白等改变 → SR回收Ca加快 → 舒张加快
            ├─ 慢反应0期增强 → 房室传导加快
            └─ 起搏电流调节 → 更快达到阈值 → 心率增快

ACh → M受体相关信号
      ├─ 抑制相关Ca / If作用
      └─ 激活IK-ACh，使膜更负等
                         ↓
      按心房、窦房结、房室结位置分别判断结果
```

If可受cAMP直接结合调节，不把β₁所有支路都画成必须先经过PKA磷酸化。这个分叉只需占一行，但能避免将来学通道时整幅模型返工。

儿茶酚胺让收缩更强，同时也能让Ca²⁺回收更快、舒张更快；不是“收得更紧所以一定松得更慢”。它使心率加快后的充盈压力有部分缓冲，但仍不能消除极快心率的机械限制。

迷走分布以室上组织更突出：心房收缩、窦房结起搏、房室结传导要分别看。右 / 左侧偏好放精确表，对心室肌支配少，不把“负性收缩”均匀涂满全心。

E-4031是一个很好的反例：阻断复极K电流，可能改变最低电位、通道恢复和下一轮起搏，不能仅用“外向少→心率必快”判断。课程用最大复极不够负、If参与不足解释自律下降；实际研究还显示细胞区域 / 大小差异，因此把它作为特定实验情境，不作为所有K阻断的万能结果。

### 整块最终判断顺序

```text
细胞身份
→ 当前时期
→ 哪个电流、通道状态或驱动力改变
→ 兴奋 / 传导 / 自律 / 收缩 / APD / ERP哪一项受影响
→ 是单细胞变化、全心时序，还是机械输出
```

这条链要保留到复习稿，不能压成“钠快钙慢钾复极”就结束。后者是名字定位，前者才是可用于判断的模型。
