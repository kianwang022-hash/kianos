# 心肌与心包：血为什么装不进，或射不出

呼吸困难、水肿和低输出可以出自同一种循环后果，却来自不同故障。收缩性下降使血排不出去；顺应性下降让血难以装进；动态流出道梗阻让腔越空、收缩越强时出口反而更窄；心包则能从外部限制舒张。EF描述排空比例，正常甚至升高并不排除严重充盈障碍，心界不大也不能排除限制性心肌病或缩窄。

> 定位（可略读）：第一问不是“什么病”，而是“哪里坏了”〔故障4层｜变量→后果→典型定位｜EF/心界反例〕；六个观察量：大小、厚薄、运动、EF、充盈压、病变位置〔观察6量｜大小/厚薄/运动/EF/充盈/位置｜故障定位〕。

判断至少连看心室大小、壁厚、运动、EF、充盈压/心房大小和病变位置。历史课程先按原发、继发、未分类讲心肌病，再按结构功能讲HCM、DCM、RCM；已知病因的DCM不能因为历史分组被写成原因不明。真正有用的比较，是把每个结果放回排空或充盈。

## 排空失败：扩张是在代偿，未必恢复输出

心肌损伤降低收缩性，ESV增加、EF下降，左室扩张尝试维持SV，但超出Frank–Starling有效范围后不能靠更大容积继续救输出。DCM典型左室最早最明显扩大，后期多腔扩大，运动弥漫减弱；瓣环被撑大可出现相对MR/TR。它与冠脉供区相关的节段运动障碍是不同构型，不能只见病理Q就指定MI。

> 定位（可略读）：DCM病因与病理〔病因4组｜扩大先后｜室壁/心尖/心内膜/血栓｜细胞损伤修复〕；DCM机械电影：腔越大不等于泵越强〔收缩性/ESV/EF/心腔｜弥漫vs节段｜瓣环/MR/TR〕；DCM临床：先左衰，后来“呼吸好转”可能更重〔起病/心界/杂音｜左衰/右衰/全心衰｜肺症状变化判读〕；DCM证据：超声、ECG、核素、BNP各看什么〔超声地位/结构功能｜ECG病理Q/ST-T/节律｜核素｜BNP非特异〕；DCM治疗：不是“泵弱就只强心”〔治疗归属｜β阻断免疫接口｜快房颤接口｜长期重构目标〕；DCM三类危险：心衰、血栓、心律失常 / 猝死〔危险3路｜附壁血栓链｜电不稳定链｜ICD指征轴｜HCM共同点〕。

遗传、病毒直接/免疫损伤、酒精、蒽环类等不同上游可汇入这条链。肉眼壁多变薄，也可正常或稍厚，心尖钝圆、心内膜增厚、附壁血栓和纤维化；细胞变性坏死后遗瘢痕，残存细胞也能代偿性肥大。因而“发现肥大细胞”不足以改判HCM，其遗传性非对称肥厚与排列紊乱必须结合整体构型。

左衰造成肺淤血，持续肺压力又增加右室负担；发展至右衰、射入肺循环减少时，肺部症状可相对减轻，却是全心循环更差，不能因少喘就宣称好转。腔大、淤滞和心内膜变化促进血栓/栓塞，纤维化影响电稳定并产生房颤或室性节律/猝死，泵弱则接入HFrEF。完整节律、ICD和心衰分别归B10/B11。

超声看扩张、运动、功能及反流，ECG看Q/ST-T/节律，核素可见摄取异常，BNP因牵张升高而不专属DCM。课程LVEF≤40%描述合并HFrEF，不能反推为全部DCM唯一诊断门槛，还须判断异常负荷或冠脉能否充分解释。治疗不能只叫“强心”，β阻断和减轻长期神经体液/重构有其时间靶点；课程抗β1抗体持续激动/脱敏是解释接口，快房颤时强心苷抑AV结又属节律问题。HCM与DCM可共有房颤、猝死、栓塞及Q/ST-T改变，不能另造共同室早或最常节律排序。

> 定位（可略读）：致心律失常性右室心肌病〔受累心室｜替代组织｜结构→泵/节律2后果〕；克山病与其它心肌病：先按结构身份归类〔病因/受累部位｜心腔-室壁-外形｜病理变化｜DCM表型/并发〕。

特殊表型也按同一方法定位。右室心肌被脂肪/纤维脂肪替代既破坏收缩又改变传导底物，ARVC可右室扩大、右衰与室性节律危险。缺硒相关克山病两侧腔大、壁薄、球形且心尖较重，水肿、空泡脂肪变、坏死和瘢痕呈DCM样表型，可继相对房室瓣反流、心衰、栓塞或猝死；低频完整病因/基因及重量数字仍由来源支持持有。

## 充盈失败：心肌本体硬，与外部压住不同

HCM不只是肌肉厚。常显遗传、肌节/肌球蛋白相关异常与细胞漩涡样排列，典型非对称室间隔肥厚使左室腔小、顺应性下降。课程室间隔/游离壁比值大于1.3是结构接口，心房不是原发肥厚，却会因高充盈压扩大。RCM则因心内膜/心内膜下纤维化或浸润，让心室不易扩张，双房扩大与体、肺静脉淤血突出；心室未必大，淀粉样可弥漫增厚或呈课程毛玻璃样。

> 定位（可略读）：HCM病理身份：遗传、非对称肥厚与排列紊乱〔遗传/蛋白｜排列/肥厚分布｜室间隔比值｜LVvs心房｜功能2轴〕；RCM：心室像穿了紧内衣〔病变部位｜顺应性/充盈压｜双房/淤血｜心室大小｜病因/超声〕；RCM vs 缩窄：同是“装不进去”，一个内衣紧，一个外套紧〔共同血流动力学｜内衣vs外套｜心界/心房｜室间隔/奇脉/叩击音〕；RCM vs 缩窄 vs 心包积液：内衣 / 外套 / 液体〔共同血流动力学｜心界/3定位｜内衣/外套/液体证据〕。

```text
心肌/心内膜变硬 → 顺应性↓ → 充盈压↑ → 双房扩大/静脉淤血
心包纤维化或压力↑ → 外部限制舒张 → 回流受阻 + 有效充盈↓
```

淀粉样、贮积、心内膜弹力纤维增生、高嗜酸、放射或药物等属于RCM病因接口；缩窄是心包增厚、钙化和外部机械限制。二者都可JVD、体循环回流障碍，心界不大或稍大，因此不能只凭“水肿且心不大”命名。双房大和浸润指向心肌，呼吸相关室间隔抖动、心包叩击音、负性心尖及心包影像指向缩窄；RCM无奇脉、缩窄可有是本课程比较口径，连Source范围保留。明显向两侧大且有液体又转向积液，但少量急性积血同样可能很危险。

## HCM在充盈障碍上，还可叠加动态出口

室间隔肥厚与二尖瓣装置几何/位置改变，使瓣叶进入流出血流作用范围，血流拖曳推动其向间隔移动，形成SAM；接近或接触使LVOT更窄，对合受影响还可MR。课程“高速压低吸引”不足以独自启动全部SAM，研究可见正常流速甚至射血前开始，几何和拖曳必须保留，亦不因此否认局部压差。

> 定位（可略读）：SAM 与动态梗阻：为什么收缩越强，出口反而越堵〔SAM结构｜几何/血流作用｜动态反馈｜MR〕；HCM症状：舒张失败 + 缺血 + 动态低输出〔症状4路：呼吸困难/胸痛/低压晕厥/猝死→机制〕；HCM杂音：负荷改变的反事实〔杂音部位/传导｜负荷2轴｜增强/减弱场景｜HCMvsAS〕；HCM证据层：超声看结构 / 梗阻，CMR看组织与风险〔超声地位｜结构/比值/SAM/LVOT/舒张｜CMR-LGE风险〕；HCM治疗：不能机械套“所有心衰都减负荷”〔Study药物首选/替代/新增接口｜慎禁→梗阻变量｜结构治疗2路｜ICD风险轴〕。

```text
前负荷↓/腔更空 或 收缩过强
→ SAM/LVOT梗阻加重 → 前向SV↓
充盈改善/心率与过强收缩降低
→ 腔较充盈 → 动态梗阻减轻
```

同一HCM可以同时“硬”和“堵”。高LVEDP沿左房、肺静脉引起劳力性呼吸困难；肥厚耗氧、相对毛细血管不足、充盈压高及梗阻影响冠灌注而胸痛；运动心率快、舒张短、充盈少加重动态低输出，可低压晕厥；排列紊乱/纤维化又通向室性节律与猝死。胸骨左缘3–4肋喷射杂音不典型按AS向颈传，可兼MR；站立、Valsalva、硝酸酯、大量利尿或强心使杂音增强，卧/蹲、β阻断和非DHP可减弱，这种负荷反事实区别于固定AS。

超声看非对称结构、SAM/LVOT、腔和舒张，CMR的结构与LGE接风险。症状性梗阻患者课程首选β阻断，继承非血管扩张性条件，非DHP替代、丙吡胺/西苯唑啉为课程接口。玛伐凯泰抑制多余横桥和过强收缩，LVEF小于55%的课程安全边界要一起读，不能当作泵弱的强心药。正性肌力、强扩血管、大量利尿或DHP可能让动态梗阻更重，但淤血时谨慎小剂量利尿不是一律禁用，梗阻限制也不套全部非梗阻患者。结构治疗有间隔切除/酒精消融，高危评估ICD。

课程风险八项包括心尖室壁瘤、晕厥、持续VT伴不稳或反复NSVT、早发猝死家族史、骤停史、LVEF小于50%、LGE≥15%左室质量和最大壁厚≥30 mm；原文室速旁SVT笔误仍继承canonical的VT，不与室上速混用，各因素也不单独自动触发同一个ICD指征。

## 炎症同时损坏泵和电活动，修复又改变后续底物

心肌炎从损伤和间质反应解释。病毒性以淋巴/单核浸润伴心肌损伤为主，可分割成条索并遗纤维化；细菌性中性粒小脓肿不同。Fiedler/特发性/孤立性在课程分弥漫间质与巨细胞两型，巨细胞、免疫反应性、风湿性可有肉芽肿的课程归类仍保留，不能因有多核巨细胞就证明完整肉芽肿，现代巨细胞与结节病的细分未在本次重做。

> 定位（可略读）：心肌炎病理分类〔心肌炎4组｜细胞/组织层｜损伤与修复｜肉芽肿课程归类〕；病毒性心肌炎入口：1–3周前驱感染 + 心率不相称〔前驱时程｜心率不相称/节律｜左衰表现｜严重3出口｜Study病原〕；心肌炎证据：损伤标志物 ≠ 组织学证明〔证据5类：活检/CMR/损伤标志物/ECG/BNP｜证明对象与限度〕；心肌炎 vs MI vs DCM vs 心包炎〔鉴别4病×病程/前驱/室壁运动/摩擦音/损伤证据｜病理Q非独有〕；心肌炎转归：炎症怎样走向纤维化、心衰与猝死〔炎症→损伤→修复｜泵功能/电活动2支｜严重结局〕。

1–3周前感染后心悸、心率与体温不相称、节律或胸痛，是病例入口，课程柯萨奇B及埃可、腺、流感等为病原范围。左泵失能可湿啰音、S1低、奔马律、相对MR和呼吸困难，严重至休克、钟摆律或猝死。炎症→坏死→纤维修复既降低收缩形成DCM样，也使传导/复极不均，不能把泵和电分成两个无关病。

cTn/CK-MB证明损伤而不专属心肌炎，ECG的Q/ST-T亦非MI专有，BNP提示牵张而不区分心肌炎与DCM。CMR提供组织影像，课程心内膜心肌活检是组织学金标准接口。前驱感染、急性弥漫损伤支持心肌炎，冠脉背景及节段运动支持MI，慢性隐匿多腔大/弥漫弱支持DCM，体位呼吸相关锐痛、摩擦与弥漫ST支持心包炎；每种支持必须与实际病程、结构和证据校准。

## 外部限制：先有摩擦，后来可能液体分开两层

脏、壁心包间少量浆液润滑，兼固定、保护、限制急性过扩张。病毒、细菌、尿毒症、结缔组织病、肿瘤和MI后等可炎症，无明确病因才称特发/急非特。纤维素在心搏时摩擦，产生高频搔抓双/三相声，屏气仍在，前倾和左3–4肋较清；胸膜摩擦随呼吸且屏气消失。锐痛可向颈肩臂背或上腹，深吸、咳嗽、吞咽和体位改变加重，NSAIDs为课程接口。

> 定位（可略读）：心包正常作用与急性心包炎病因〔心包2层/液体｜功能｜急性病因6组｜特发定义〕；纤维蛋白性心包炎：胸痛和摩擦音来自同一摩擦〔摩擦音：性质/时相/屏气/体位/部位｜胸痛：性质/放射/诱发｜vs胸膜摩擦〕；急性心包炎 ECG vs STEMI：弥漫 vs 冠脉分布〔心包炎vsSTEMI：分布/形态｜aVR/V1｜积液3个ECG表现〕；摩擦音消失不一定好转：积液把脏壁层分开〔纤维素/积液｜脏壁关系｜痛/摩擦变化｜呼吸困难/心界｜转归判读〕；心包炎病因模式：发热、胸痛、摩擦、积液量、细胞一起看〔病因5型×起病/发热/痛摩擦/液量性质/细胞｜血性3重点〕。

心包炎多导联弥漫ST弓背向下抬高，aVR/V1可压低，与STEMI冠脉/心壁分布相区别；积液又可低电压、电交替、窦速。液体把脏壁层分开时痛和摩擦可减轻，呼吸困难和心界扩大却加重，不能把声音消失当炎症/循环好转。摩擦音吸呼气哪相更明显的Source冲突仍不编成Memory。

病因模式要连病程与液体看：急非特有1–3周前驱、急性痛/摩擦明显、量少草黄或血性/淋巴；结核缓慢低热、可干摩擦或多量血性/淋巴；肿瘤缓、无或低热、多量血性而少摩擦；化脓感染灶、高热/中性粒；损伤后有手术或MI史，可发热胸痛而摩擦不必明显。课程血性重点为结核、肿瘤和急非特，但颜色不是独自确定病因的证据。

## 积液到压塞：决定危险的是压力增长与可用充盈空间

> 定位（可略读）：心包积液何时成为压塞：量不是唯一变量〔量/速度｜心包压｜受压先后｜CVP-SV-CO-BP-PP｜小量快vs大量慢〕；压塞体征：Beck、奇脉、Ewart、Kussmaul〔Beck3联｜奇脉机制｜Ewart3征｜Kussmaul征vs呼吸〕；积液证据与穿刺：诊断、病因、治疗是三个问题〔超声/X线/ECG/穿刺4角色｜夹层穿刺风险链〕；心包积液 vs DCM：都可心界向两侧大〔积液vsDCM比较6轴：首故障/心尖/主诉/肺/奇脉/杂音〕。

量与速度共同决定心包压，少量快速积血可比大量慢性积液更危险。右房/右室舒张先受压，回心梯度下降但上游CVP升高，有效心室充盈、SV/CO下降，动脉压和脉压降低，成为阻塞性休克。高静脉压与低输出不是矛盾，恰是外部限充盈的结果。

```text
心包压↑ → RA/RV舒张受压 → 回流梯度↓/CVP↑
                              → 心室有效充盈↓ → SV/CO/BP↓
```

Beck为低动脉压、高静脉压/JVD、心音遥远。吸气增加右心回流，却在受限总空间中挤压LV，使LV充盈、SV再减，产生奇脉。大量液体压左下肺的Ewart是肩胛下浊音、语颤增强和异常支气管呼吸音；Kussmaul征是吸气JVP不降或反升，多提示缩窄等受限充盈，不能与代酸Kussmaul呼吸混名，也不是单纯压塞必备，出现时考虑缩窄成分。

超声看液体、游泳心、RA/RV塌陷与室间隔摆动，X线烧瓶/两侧大但少量可阴性、肺可清，ECG只提供支持；穿刺回答性质/病因，也可减压，不能混为同一证明。夹层可破入心包，降低心包压可能促继续出血，课程列穿刺绝对禁忌的病因条件不能省略。积液与DCM都可两侧心界大，但前者外限充盈、心尖难触或位于心界内侧、肺可清及奇脉，后者泵弱、心尖与扩大较一致、左衰肺湿及相对MR/TR，要由液体和心室功能证据分开。

> 定位（可略读）：最终算法：先判泵弱、泵硬、动态堵，还是外壳限制〔病程｜心室vs心包｜证据4类｜危险3组｜后续接口〕。

最终回到故障层：慢性大而弥漫弱、急性感染后电泵损伤、非对称厚硬伴动态出口、心室不大却双房大，或心包液体/纤维化，分别指向不同上游。超声、CMR、活检、X线和ECG各承担自己的证据层，再判断致命室性节律、急左衰或压塞/休克，调用B10–B12。右室后负荷只保留PVR升高后慢性先肥厚后扩张、急性可直接扩张并减少LV充盈的接口，完整肺高压、肺心病和PE由呼吸系统承担。
