# 全身反馈：感知怎样连到泵与管路

## 先知道哪里变了，再选择正确的报警器

先建立三个槽位：外界发生什么、感受器直接受到什么刺激、输出怎样反向修正。感知与整合给出神经和激素的调节方向，再看它们怎样作用于泵、阻力和容量，不先把每个受体一次讲完。

```text
失血 → 总循环血量减少
     → 静脉系统充盈不足 → 回心减少
     → 心室充盈减少 → SV / CO下降 → 动脉压下降
                                             ↓
                                  窦弓局部壁牵张减少
                                             ↓
                                  传入放电减少
                                             ↓
                              交感增强、迷走减弱
                                             ↓
                           作用于：泵 / 阻力 / 静脉怎样动
```

### 1｜感受器不认识“失血”这个词

压力感受器实际读取的是血管壁机械牵张。失血要先改变回心、泵出和动脉压力，才能改变这个输入。这一步让你不再把“疾病名字→某反射”死记成固定配对。

颈动脉窦与主动脉弓读取牵张，传入分别经舌咽相关通路与迷走通路进入延髓。先讲清传入，再讲输出；不能因为两边都出现“迷走”，就把主动脉弓的感觉传入当成直接抑制心脏的运动传出。

反射不是只会降压。压力高时牵张、放电增加，交感下降而迷走增加；压力低时反过来。因此它缓冲波动，而不是把所有人的血压一律压低。

```text
高压 → 牵张↑ → 传入↑ → 交感↓ / 迷走↑ → 压力回落
低压 → 牵张↓ → 传入↓ → 交感↑ / 迷走↓ → 压力被托住
```

夹闭颈总动脉的题，先看窦局部收到什么信号：窦内压力和牵张下降，随后才反射性升压。“局部读到低压”和“全身最后升压”可以同时成立。它不是把夹闭本身直接当作一个升压受体刺激。

### 2｜重调定意味着参照位置变了

持续高压背景下，反射可围绕更高的工作点缓冲波动，敏感性也可能降低。因此“反射还在工作”不等于“它能独自把长期高压恢复到原正常值”。

如果破坏反射弧，首先丢掉的是缓冲能力：血压波动可变大，而不是由“反射没了”就能断言血压必定持续升高或降低。

课程用它强调短时缓冲与肾—体液长期调压的分工。教学不能把这个分工扩大成“窦弓或交感对长期血压绝无任何作用”；它们与肾脏仍可相互联系。原图要看横轴、纵轴和斜率，不能只背曲线右移：工作点是位置，敏感性是某处输入变化引起输出变化的幅度。

### 3｜“体”读化学，“窦弓”读牵张

颈动脉体、主动脉体面对低氧、高CO₂、高H⁺，呼吸反应首先重要；在严重低灌注等情况下，循环升压与血流重分配的意义明显。

它们不是日常双向压力缓冲器的另一个名字。课程用约80 mmHg以下描述循环参与明显的低压背景，应保留为课程情境数字，不能当成任何人一跨过某个读数就突然启动的开关。

低灌注更严重，脑血流显著减少时还会触发脑缺血反应，增强交感缩血管活动。颅内压过高也能压低脑灌注，库欣反应从这条路进入：灌注受威胁→升高动脉压以对抗。当前只理解入口，完整神经定位留给后续系统。

### 4｜同样是牵张，所在位置决定它代表什么

心肺容量感受器主要读取中央充盈状况。血容量或回心增加，使相应区域牵张增加，课程容量反射主线转向减少交感紧张、增加利钠肽并减少保水保钠倾向，促使容量回落。

这与窦弓反射并不重复：一个更直接监测动脉侧压力，一个更反映心肺充盈和容量。不能把“容量反射”理解为一个受体直接测出全身体液有几升，也不能把它的一条综合输出套给所有孤立心房牵张实验。

心交感传入则读另一类危险：心室扩张、缺血相关化学刺激→交感增强。急时有助维压，持续时却可能增加心肌耗氧，进一步加重缺血，于是从救援转为自我强化。

**关系压缩：先认刺激，再认传入与输出；看起来都能升压的反射，读取的变量和工作情境可以完全不同。**

## 神经命令怎样落到现成的泵和管路

感知—中枢回路给了交感增强、迷走减弱的方向。现在要把方向翻译成可推算的变量。急性失血时身体还来不及补回丢失的血，它首先重新利用仍留在循环里的血。

```text
交感增强
├─ 心脏β₁：心率 / 收缩性等改变 → 提高泵出倾向
├─ 微动脉α₁：收缩 → 阻力增加、器官间重新分流
├─ 静脉α₁：容量减少 → 促进现有血液回心
└─ 球旁细胞β₁：肾素释放 → 启动肾素—容量调整

迷走主要作用室上组织 → 改变心率与房室传导
```

### 1｜强泵、夹管、挤静脉各救一个不同环节

心率和收缩性改变可以支持心输出量；微动脉收缩提高总外周阻力，并使不同器官之间的流量重新分配；静脉收缩把容量池的工作状态改变，促进回心，帮助心室得到充盈。

因此“血管收缩”不够作为完整答案。微动脉与静脉即便都变细，也分别更偏阻力和容量。静脉收缩不是凭空增加全身总血量，微动脉收缩也不等于每个组织得到更多血。

```text
MAP约由CO与TPR共同决定
局部Q取决于该处压差与阻力

TPR↑可以支持全身动脉压
但某处R↑仍可能使该处Q下降
```

这就能理解为什么失血时皮肤冷而苍白，同时血压暂时被托住：全身保压和局部少灌注不矛盾。这个现象帮助定位分配变化，不单凭皮肤表现唯一诊断失血。

心率升高也有条件。不能把“HR越快，CO必定越多”无限延长；B1的充盈时间、心功能与负荷边界仍有效。

### 2｜递质作用与整体反射结果分开读

把神经出口与内分泌放大分开：NA既可作交感递质也可作激素，Adr在外周主要作为激素；课程髓质释放约80% Adr、20% NA。交感节前ACh通过髓质N₁受体促进释放，低血糖与应激可增强这条支路；ACTH/GC参与应激，CA入血解除自身合成酶抑制属于课程合成调节接口。这样比例、来源和调节都归回同一输出链，完整嗜铬细胞瘤诊疗仍后置。

NA对心脏β₁有直接作用，但其强烈血管效应可使血压升高，随后窦弓反射增强，整体心率反而下降。

```text
直接支路：NA → 心β₁ → 加快倾向
反射支路：NA → 血管收缩 → BP↑ → 窦弓 → 心率减慢
                                      ↓
                          完整机体的最终结果取决于综合
```

这样“NA让心率下降”与“β₁让心率上升”就不冲突，因为一个是整个回路的结果，一个是局部受体作用。

Adr也要同时看剂量与血管部位。β₂作用明显的血管床，在低剂量条件下可突出舒张；剂量升高或α效应突出时，方向可不同。α阻断后的作用翻转，是去掉一条支路后另一条支路显现，不是药物突然变成另一个分子。

不要把课程的受体强弱图当作所有组织、所有剂量都严格相等的亲和力定律。需要恢复的是“受体分布×剂量×反射完整性”三个条件。

### 3｜多数血管的日常张力，与局部特殊支配分开

交感缩血管纤维有紧张性，基础状态已有持续放电。减少放电就可以舒张，不一定每次都要另外兴奋一根“舒血管神经”。

课程四类纤维表继续保留，但骨骼肌交感胆碱能舒血管的物种与实验背景要注明，不能用它单独解释人体运动充血。人体活动肌血流必须结合局部代谢、循环儿茶酚胺和缩血管活动等因素。

轴突反射是另一种局部路线：伤害刺激沿感觉神经局部分支引起CGRP等释放，局部舒张；不经过通常的中枢整合。记忆时把它放到“回路在哪闭合”，就不会只剩一个例外名称。

右迷走更偏窦房结、左迷走更偏房室交界，是恢复作用位置的精确项；迷走对心室肌作用较弱，不能把全心所有部位都写成同等下降。

**关系压缩：把神经命令翻译到HR、收缩性、阻力、静脉容量与肾素五个出口，再区分直接效应和最终反射结果。**

# 灌注分配：全身命令与局部需求同时成立

## 全身在保压，局部仍要分配到该去的地方

前面偏重全身输出，现在回到每个器官：全身压力有了，并不保证每处流量都合适。局部内皮和代谢反应让血流更贴近需求。

```text
全身命令 → 微动脉张力 / 器官间分配
局部代谢需求＋内皮状态 → 本地阻力改变
                          ↓
                   合成实际局部血流
                          ↓
          再看组织是否缺血、需求是否得到满足
```

### 1｜同一条血管有促缩和促舒两边

ET一侧偏强而持久的收缩及重构；NO、PGI₂、EDHF等一侧提供舒张与保护。不是背出哪个“最强”就能预测最终血流，还要看部位、浓度、内皮状态和同时存在的刺激。

NO经sGC—cGMP—PKG使平滑肌向舒张方向变化；EDHF相关机制通过超极化降低兴奋—收缩倾向。两条都能舒张，但一个主要记化学信号链，一个主要记膜电状态。

PG家族不能整体等同于舒张。课程把PGI₂、PGE₂与PGF₂α的主要方向区分；PGI₂与NO还抗血小板、抗增殖等，正好给B4内皮限域留下接口。这里不提前搬入B4整章凝血。

### 2｜一个分子的作用取决于在哪条轴上看

缓激肽可以挂炎症疼痛，也能通过内皮介质参与舒张，两者不互相否定。ADM、CGRP等也各有来源与作用位置，其中CGRP连接回神经执行中的轴突反射。

### 3｜器官选择性必须回到局部条件

皮肤和多数内脏在急性保压时可收缩；心脑相对受到优先保护，局部代谢作用重要。活动骨骼肌虽然处于交感兴奋背景，仍可出现局部舒张占优势。这个判断来自多路作用综合，不用“交感一兴奋全身都收缩”替代分析。

微动脉更像器官总闸门，前括约肌更受局部代谢调节；这只是突出分工，两者并非绝对互不影响。真毛细血管没有用来完成这套收缩的平滑肌层，不能把它画成又一道同样的神经收缩阀。

**关系压缩：全身命令给分配方向，局部需求和内皮状态决定实际流量怎样落地。**

# 容量与时间：从保压到水盐反馈，再检验代价

## 先把压力托住，再处理水盐和容量

神经调整的是现有泵和管路怎样工作。持续容量不足时，还要改变进入与排出的Na⁺、水，才可能重新建立容量。肾脏不凭空造水；减少丢失、摄入增加及体液重新分布共同影响恢复。

```text
肾灌注压低 ─ 入球壁牵张变化 ─┐
致密斑NaCl输入低 ─ 局部信号 ─┼→ 球旁细胞释放肾素
肾交感增强 ─ β₁ ────────────┘          ↓
血管紧张素原 ──肾素──→ AngⅠ ──ACE──→ AngⅡ
                                              │
             ┌────────────────┬───────────────┼───────────────┐
             ↓                ↓               ↓               ↓
         血管收缩          交感强化         醛固酮         ADH / 口渴
       保压 / 促回心                        留Na、排K      留水 / 增摄入
             └────────────────┴───────────────┴───────────────┘
                                              ↓
                                    调整ECF、血容量与灌注
                                              ↕
                    利钠肽、压力性利钠利尿等反向限制
```

ACE既参与AngⅡ生成，也参与缓激肽降解。因此ACEI不是只做“AngⅡ少一点”一件事；ARB作用于受体，不能默认复制ACEI的全部下游。ARNI和sGC刺激剂也只按机制入口挂回，不在B2自创治疗组合。

### 1｜肾素三个入口，不能合成一句“肾缺血”

灌注压、致密斑NaCl、β₁交感输入是三种不同信息。它们可在失血时同向出现，但也可被分别改变。先保留三个入口，后面的药物题、肾单位题才有位置挂。

长期低盐摄入可能通过水钠平衡、细胞外液与肾灌注等改变增强RAAS，不能把“吃盐少”直接等同于“血钠浓度必然低”。这是总钠量与血钠浓度的区别。

致密斑读的是到达其所在小管液中的NaCl相关信息，不是直接测血浆Na⁺，也不是只凭低钠血症就能判断肾素必升。球旁、近球、颗粒细胞是同一来源的三种称谓，不要数成三个分泌器官。

NO的肾素方向在课程简表与实验资料间存在条件差异；当前不把它硬编码成“所有情况下都抑制”或“所有情况下都促进”。这不妨碍先完成三个主入口，化学调节名单要带着情境单独校准。

### 2｜AngⅡ把短期救援与后续容量连在一起

先区分课程两个主效应的比较：AngⅡ在RAS中全身微动脉收缩/升压作用最强，AngⅢ直接促醛固酮作用最强，不能将一种“最强”泛化到全部作用。AngⅡ既收缩微动脉，也影响静脉；前者支持阻力和压力，后者影响回心。它还强化交感、促进口渴及醛固酮、ADH等，使“先维持运行”和“再调整容量”连起来。

肾内效应必须看强度和位置。较适度的出球收缩，在一定范围内可支持肾小球滤过压力；更强收缩、入球受累或系膜收缩等又可能降低GFR。不能把“AngⅡ保压”简写成“GFR一定上升”。完整滤过动力学归泌尿，这里只留下改变判断方向的条件。

口渴这一支可挂到穹窿下器等室周器及相关中枢：血中AngⅡ信号影响饮水和ADH相关调节，让身体不仅少排，还能增加摄入。

这套增强还有反馈限制：AngⅡ可减弱压力反射敏感性，同时负反馈抑制肾素；强化交感既有中枢紧张增强，也有末梢NA释放增强。AngⅡ通过CRH—ACTH影响GC，与直接促进醛固酮不同；同样叫“肾上腺皮质激素”，上游链条不一样。长期的细胞肥大、纤维化与重构留在容量调节的长期接口，结合代偿时间轴检验其代价。

### 3｜醛固酮与ADH都能保水，但先改的东西不同

醛固酮主要通过核受体改变ENaC、Na⁺-K⁺泵等的表达和转运能力：重吸收Na⁺、促进K⁺分泌，水潴留随整体水盐处理而变化。它不是直接把集合管水通道打开。

ADH则把水通透性作为直接开关：

```text
下丘脑合成 → 沿轴突运输 → 神经垂体储存释放
                          ↓
                 集合管基底侧V₂
                          ↓
                  AC → cAMP → PKA
                          ↓
                 AQP2进入顶端膜
                          ↓
             水通透性↑ → 水重吸收增加
```

水要真正离开小管，还需相应渗透梯度；“门打开”不等于完全不需要驱动力。内髓集合管尿素通透性的改变，给后续尿浓缩留下接口。V₁的缩血管作用在较高浓度背景更重要，不与V₂抗利尿混成同一个靶点。

这里最该当场理解的是“直接改Na⁺转运”和“直接改水通透性”。性质、来源、受体、离子方向再按这两个功能位置记，就不再是一张孤立激素对照表。

ADH、VP、AVP用于本激素的命名；垂体后叶提取物还可含催产素，不能无条件当作ADH的单一同义词。学习时把“合成部位”和“储存释放部位”也分开。

### 4｜容量与浓度是两个轴

大量饮清水首先改变水与溶质比例，晶体渗透压下降→ADH减少→排出更多稀尿。大量失血则先威胁循环容量和灌注，可通过非渗透压信号增强ADH。这两个场景不必有同一种血钠变化。

```text
渗透压：水相对溶质够不够
有效灌注 / 容量：循环能否维持

两条输入可以同向，也可能冲突
→ 结合严重程度与情境判断，不用一个指标替代全部
```

因此“尿少”只是一个结果，不能直接等于“缺水”“醛固酮升高”或某一种单独激素异常。

### 5｜利钠肽与肾排出让回路闭合

心房或心室壁负荷增加，可增强ANP或BNP信号。它们倾向于利钠、利尿、舒张和对抗重构。ANP可通过滤过、小管及对保钠保水系统的抑制共同作用，不能只记成“一个利尿激素”。

BNP升高常表示壁负荷和代偿信号增强，不表示它是心衰的病因，也不表示代偿已经足够成功。完整诊断阈值以后回B11。

持续较高灌注压力促进排Na⁺排水，ECF及血容量减少后，回心与心输出量趋于降低，构成长时反馈。这条关系受肾功能、激素及摄入条件影响，不把ECF量当成脱离血管阻力和肾脏状态的唯一血压开关。

**关系压缩：肾素看三个入口；AngⅡ连接血管与容量；醛固酮先改Na⁺，ADH先改水通透性；利钠肽与排出反馈把系统拉回来。**

## 用场景把一条路跑通，再判断代偿的时间代价

用场景把感知、神经执行、局部灌注与体液容量反馈联合起来判断。不另背五份答案，而是比较“第一变量不同，后面哪条支路因此被优先调用”。

### 1｜突然站立与真正失血，不是同一种容量改变

站立先让血液向下肢静脉等处重新分布，中央回心减少；总血量并未因此凭空丢失。失血则是循环内总量真正减少。两者早期都可使回心、SV和动脉压力下降，从而出现相似的窦弓反应。

所以相同的心率增快不能反推出相同病因。短暂站立被纠正后，不能强行写完整的数天RAAS容量恢复；持续低灌注才继续追后续接力。

### 2｜等渗容量负荷与清水负荷，不能只看“都喝进液体”

等渗扩容突出ECF和循环充盈变化；清水负荷突出渗透压变化。前者更多调用容量—利钠与保钠保水系统，后者可首先走ADH—水通透性。

出汗或高热若丢水相对更多，则可同时出现渗透压上升和容量下降；“脱水”却不是天然等于每个病例都高钠。题干若给丢失液组成、肾功能或药物条件，要先据此定第一变量。

### 3｜急时有用，持续就可能付出代价

```text
有效灌注不足
→ 交感 / RAAS / ADH增强
→ 心率与收缩增强、阻力增加、回心与水盐潴留
→ 短期支持压力和输出

若低灌注持续
→ 心肌耗氧与电不稳定风险增加
＋后负荷增加
＋水钠潴留、充盈压和淤血增加
＋肥大、纤维化和重构
→ 原有心功能问题可能进一步加重
→ 继续触发代偿
```

这里是B11的必要接口，不是提前完成心衰治疗。ANP/BNP属于反向代偿，不能因为同在“五系统”表里就把它们也写成四条促潴留链的同义词。

药物记忆先选断点，再补名字：β阻断在交感；ACEI/ARB在AngⅡ生成或受体；MRA在醛固酮受体；利尿剂改变排出；ARNI与sGC等分别回自己的机制接口。当前只解释为什么挂在这里，不能从生理图直接推出具体病人应立即用哪种药。

### 最终共同算法

```text
先找第一个偏离变量
→ 找直接刺激，不跳过感受器
→ 把输出落到泵 / 阻力 / 静脉 / 肾
→ 区分立即改变运行与随后改变水盐
→ 加上器官局部修正
→ 再看刺激是否解除、代偿是否出现代价
```

**同一幅模型解释五个场景，靠的是保留条件，而不是让所有题干都走同一套固定箭头。**

# 开 Block｜从“循环怎样运行”到“偏了以后怎样调回来”

在知识结构上，B1给出运行变量：泵每分钟送出多少血、血管造成多大阻力、静脉能送回多少血、局部组织收到多少流量。B2接着处理变化：站起来、失血、喝水或运动以后，这些变量不再停在原来的位置，身体怎样恢复可工作的状态。

先分清目标和手段。维持血压是重要手段，真正要保护的是器官灌注与组织氧供。看到血压回升，不能直接推断丢失的血量、红细胞和氧输送已经全部恢复。

图中的 RAAS 是肾素—血管紧张素—醛固酮系统，ADH 是抗利尿激素，ECF 是细胞外液；SV、CO 延续 B1 的搏出量和心输出量。这里先认它们所在的位置，具体入口和作用在下面展开。

整块先搭这条路：

```text
场景改变 → 找到第一个偏离的变量
                 │
                 ├─ 动脉壁牵张：压力变化
                 ├─ 心肺充盈牵张：中央容量变化
                 ├─ 氧 / CO₂ / H⁺：气体化学与危急低灌注
                 └─ 晶体渗透压：水与溶质比例变化
                 ↓
        相应感受、整合与调节输出
                 ↓
     心脏＋微动脉＋静脉：先改变现有循环的运行
                 ↕
     儿茶酚胺 / RAAS / ADH等：放大并调整水盐处理
                 ↕
        肾排出与摄入：改变ECF和血容量
                 ↕
     利钠肽＋局部内皮 / 代谢：反向调节、重新分配
                 ↓
        再检查灌注、压力、容量与渗透压
                 ↓
      刺激解除 → 反馈减弱；刺激持续 → 评估代偿代价
```

这是共同判断路线，不是每个场景都必须启动全部支路。大量喝清水可以主要从渗透压—ADH进入；急性失血会同时调用压力、容量和肾脏入口。各系统也不是等上一层结束才开工。

感知与神经执行构成全身反馈，局部需求决定灌注如何落地；体液—肾容量反馈改变水盐与容量，再用场景和时间轴区分救援与代价。这些回路同时作用，不能画成必须依次完成的五步。
