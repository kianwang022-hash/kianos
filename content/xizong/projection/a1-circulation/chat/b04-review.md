## 精确记忆｜把名字固定到已有位置

以下表格是答案层，快速重跑母框时可以跳过。记忆先恢复“有几个位置、每个位置做什么”，再补无法凭逻辑推出的编号、药名和名单。不要把看过表格记为Recall通过。

### 1｜快速封口：两种连接、三类来源、五个动作

| 需要恢复的功能 | 关键结构 / 条件 | 失效时先定位 |
|---|---|---|
| 黏附：血小板连接血管壁 | 胶原—vWF—GPIb | 破口附着；GPIb异常、vWF异常接口 |
| 聚集：血小板连接彼此 | GPIIb/IIIa—纤维蛋白原—GPIIb/IIIa；Ca²⁺参与 | 受体活化、桥接物；血小板无力症接口 |
| 释放 / 生成：募集和放大 | ADP、TXA₂等 | 局部信号与参与者增加 |
| 吸附 / 平台：组织凝血反应 | 活化血小板促凝磷脂面PL | 因子局部组装，不是另造一层纤维蛋白 |
| 收缩：拉紧已有网 | 血小板与纤维蛋白连接；Ca²⁺、ATP、收缩装置 | 凝块回缩；必须先有网 |

| 血管收缩的三类来源 | 挂回机制 |
|---|---|
| 神经反射 | 损伤刺激→局部反射性收缩 |
| 肌源反应 | 机械刺激→平滑肌Ca²⁺相关反应→收缩 |
| 局部介质 | 血小板TXA₂ / 5-HT，内皮ET→收缩 |

| 血小板介质按来源记 | 当前内容 |
|---|---|
| 致密体预存 | ADP、ATP、5-HT、Ca²⁺ |
| α颗粒预存 | PF4、β血小板球蛋白等 |
| 新合成 | TXA₂；不放进预存颗粒名单 |

原题“初级血小板栓四步”与“五动作”是不同观察范围：原图列黏附、聚集、释放、吸附/平台；五动作再加已有网后的收缩。不要为了凑同一数量，把收缩提前当作形成初级栓的必经步骤。

记忆钩子：“壁连接”和“彼此连接”先各占一个位置；GPIb与GPIIb/IIIa是要准确记住的标签，不用生造谐音去代替连接模型。

### 2｜两相与两个液体概念

| 对照 | 第一相 | 第二相 |
|---|---|---|
| 典型相应刺激下的速度 | 快 | 较慢 |
| 可逆性 | 可逆 | 不可逆 |
| 课程组织方式 | 低浓度外源致聚剂等 | 内源ADP、TXA₂放大 |

这张表描述相应实验/课程观察，不是所有体内止血必须遵守的两道独立工序。

- PGI₂→cAMP；NO→cGMP；共同指向抑制血小板反应
- 血浆：血液未凝固时的液体成分
- 血清：凝固后的液体，纤维蛋白原等被消耗成分减少；不能简化为“没有任何凝血因子”
- 血管收缩减少失血，凝块回缩拉紧已形成的网，两者不要混称

### 3｜凝血因子：先职业，再编号

| 因子 | 在本模型中的位置 |
|---|---|
| I | 纤维蛋白原，生成纤维蛋白的底物 |
| II | 凝血酶原；IIa为凝血酶 |
| III | TF，主要由组织细胞表达的外源启动入口；与血浆中的凝血因子区别定位 |
| IV | Ca²⁺，离子型因子 |
| V | Va是Xa的辅因子 |
| VII | 与TF配合的酶因子 |
| VIII | VIIIa是IXa的辅因子 |
| IX | IXa与VIIIa等组成生成Xa的复合物 |
| X | Xa是生成凝血酶的关键主酶；内外源共同汇合点 |
| XI | XIa激活IX，参与放大 |
| XII | 接触系统；传统内源检测链与纤溶接口 |
| XIII | XIIIa催化交联，使纤维蛋白网更稳定 |
| PK / HK | 接触系统相关；PK为酶原，HK为辅因子 |

- FVI：历史编号，相当于活化的V；不新增一个现行因子
- 酶 / 酶原课程组：II、VII、IX、X、XI、XII、PK等
- 辅因子课程组：HK、III、IV、V、VIII等；这里同时包含蛋白与离子，不能全叫蛋白酶
- 传统VitK依赖凝血因子4个：II、VII、IX、X。PC也是VitK依赖蛋白，不能把“四个”当所有VitK相关蛋白的穷尽名单
- 课程消耗组5个：I、II、V、VIII、XIII
- 较不稳定：V、VIII；课程强调V最不稳定；vWF保护VIII稳定
- 多数凝血因子由肝合成；具体病理供应变化归对应疾病

| 复合物 | 主酶 | 辅因子 | 共同条件 | 产物 |
|---|---|---|---|---|
| 内源性X酶复合物 | IXa | VIIIa | Ca²⁺、PL | Xa |
| 凝血酶原酶复合物 | Xa | Va | Ca²⁺、PL | IIa |
| TF启动复合物 | VIIa | TF | Ca²⁺与膜环境 | 激活X，并与IX通路相连 |

课程交叉接口：VIIa可激活IX，IXa可促进VII活化；传统两途径最终都到X。不能把早期联系与最终汇合混成一个位置。

先对比前两行，恢复“主酶—辅因子—产物”三对关系，再记共同条件。这样忘了一个编号，也知道应该回查哪一对，不用重新背全部因子。

接触系统局部反馈：XIIa促使PK转为激肽释放酶 → 后者促进XII活化；HK参与表面组装。这个小回路属于接触系统，不能据此把正常体内止血的启动改成“必须先XII”。

### 4｜凝血酶、缺陷与保护

| 关系 | 放回模型 |
|---|---|
| 凝血酶主要下游 | 使纤维蛋白原转为纤维蛋白 |
| 四支反馈 | V、VIII、XI、血小板活化→增强上游放大 |
| XIII支路 | 加固产物，不作为同样方式的四支反馈之一 |
| 与TM结合 | 促进PC系统活化，改变促凝 / 抗凝作用方向 |
| 血友病A / B / C | VIII / IX / XI缺乏；从所处环节理解差别 |
| vWF两角色 | 黏附桥接＋保护VIII；两角色仍归KP09，不另造KP |
| 肝病接口 | 因子供应减少；课程的冰冻血浆接口在于补充凝血因子，不能据此推成所有肝硬化出血都需输注 |

| 体外螯Ca²⁺ | 去掉反应条件，与影响合成不是同一层 |

### 5｜抗凝与纤溶：对象决定记法

| 系统 | 主要对象 / 作用 | 放大或连接条件 |
|---|---|---|
| AT | 抑制IIa、IXa、Xa、XIa、XIIa等活化酶 | 肝素与内皮硫酸乙酰肝素增强作用 |
| PC / PS / TM | APC＋PS灭活Va、VIIIa | PC主要肝来源；TM为内皮凝血酶调节蛋白，也称血栓调节蛋白；凝血酶与TM结合促进PC活化 |
| TFPI | 限制TF–VIIa入口 | 先结合Xa再发挥相应抑制作用 |
| 内皮屏障与介质 | 隔开损伤结构，抑制血小板/凝血，支持纤溶 | 正常空间环境与损伤中心有别 |
| 局部吸附、血流与清除 | 限制活化因子在局部积聚 | 淤滞时这项保护减弱 |

故障对照：VIII缺陷→促凝放大不足；PC缺陷→对Va/VIIIa的限制减弱→静脉血栓风险增加。两种“缺少”落在模型不同侧，不能都当成出血方向。

| 检查 | 观察层 / 依赖组 | 不能偷换的结论 |
|---|---|---|
| BT（出血时间） | 小血管和血小板一期止血 | 不是所有凝血反应的同义计时 |
| PT（凝血酶原时间） | VII＋X、V、II、I | 不能把因子名单画成一条逐个酶解链 |
| APTT（活化部分凝血活酶时间） | XII、XI、IX、VIII＋X、V、II、I | 检测异常不等于所有因子缺陷出血风险相同 |
| TT（凝血酶时间） | 凝血酶作用以后形成纤维蛋白的环节 | 延长不能只凭一项指标唯一确诊 |
| D-dimer | 交联纤维蛋白形成后的降解信息 | 不是阳性即PE，也不是脱离条件的阴性排除开关 |
