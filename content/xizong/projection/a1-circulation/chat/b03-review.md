# Precision｜细胞、时期、电流和性质对号入座

先恢复所在模型，再用表格保持精确。以下电位是当前课程示意坐标，实际激活具有范围；实验性阻断剂用于识别通道，不是用药建议。

## 1｜两条分类轴与四个观察层

| 细胞 | 0期轴 | 4期轴 | 主要任务 |
|---|---|---|---|
| 心房 / 心室工作肌 | 快反应，INa为主 | 稳定静息 | 收缩 |
| 窦房结 / 房室结相关细胞 | 慢反应，ICa-L为主 | 自律机制 | 发令 / 时序传导 |
| 浦肯野 | 快反应，INa为主 | 潜在自律 | 快速分发与下位接管 |

四层：单细胞跨膜AP；细胞间传播；体表ECG；电—机械耦联后的压力与射血。ECG是电活动观测分支，不是机械收缩的上游执行器。

P＝心房除极，QRS＝心室除极，ST-T＝心室复极相关。完整导联、PR/QT与节律诊断归B10。

## 2｜两种动作电位，先记形状再记数字

| 时期 | 心室肌 | 窦房结P细胞 |
|---|---|---|
| 0 | 快INa内向电流 | ICa-L内向电流，上升较慢 |
| 1 | INa失活、Ito外向电流 | 无明显独立1期 |
| 2 | ICa-L等内向与IK外向相对平衡；IK1外向作用受限 | 无工作心肌式明显平台 |
| 3 | ICa-L减弱，IK等复极，IK1参与终末 | IK参与复极 |
| 4 | 稳定静息、维持稳态 | 自动去极化：外向减弱＋内向参与 |

离子稳态的名字补全：Na⁺-K⁺泵维持Na/K梯度，Ca²⁺泵参与Ca回收/外排，Na⁺-Ca²⁺交换参与Ca跨膜转运。课程正向交换可记3Na⁺入、1Ca²⁺出；方向仍由膜电位及离子梯度决定。这些转运贯穿活动，不是到了4期才全部启动。

正反馈两位置：0期去极化→更多可用快Na通道激活→内向电流增强→进一步去极化；3期终末复极伴IK1电导恢复、促进复极，但接近K平衡电位时驱动力减小，不能无限外推。

## 5｜不应期、APD与兴奋性

| 课程时段 | 近似电位位置 | 可形成怎样的反应 |
|---|---|---|
| ERP | 从0期到复极约−60 mV | 不能产生正常传播AP；含绝对不应与局部反应阶段 |
| 相对不应 | 约−60到−80 mV | 较强刺激可触发，AP幅度 / 上升 / 传播可受限 |
| 超常期 | 约−80到−90 mV | 多数通道已恢复，适当情况下阈强度较低 |

相对不应及超常阶段所诱发的AP，在课程比较中可出现0期幅度/速度及传导受限、时程较短；“超常”说的是较小刺激可能触发，不表示产生的AP必定更高、更快。

这些是工作心肌课程图，不直接复制为所有细胞与药物状态的统一阈值。

APD看波形持续多久；ERP看何时能产生有效传播。研究中APD90等有特定测量定义，看到标注时不能与“完全复极时刻”混用。

| 课程药理比较模型 | APD | ERP | 比值 |
|---|---|---|---|
| IA奎尼丁 | 延长 | 延长较突出 | ERP/APD增大 |
| IB利多卡因 | 缩短较突出 | 也可缩短，但较少 | ERP/APD增大 |

这是课程条件下的相对比较，不把数值关系扩大为所有组织、频率和剂量。

IA奎尼丁与IB利多卡因的课程比较用于说明ERP/APD相对关系，不能把APD简单全部归K、ERP简单全部归Na，再把两者从实际膜状态中拆断。

兴奋性共同坐标：通道可用状态＋膜与阈距离。轻度靠近可易触发，严重持续去极化可失活阻滞。高 / 低K方向需带细胞、程度和电导背景，不能只背一张无条件升降表。Ca稳定高K心脏膜效应并不等于降低血钾。

## 6｜传导、起搏与耦联

| 任务 | 决定因素 / 关键链 |
|---|---|
| 传导 | 0期速度与幅度、邻旁兴奋状态、细胞直径与缝隙连接等 |
| 自律 | 4期斜率、最大复极点到阈值的距离、通道恢复条件 |
| 抢先占领 | 下位点未到阈值，正常冲动已来并重置 |
| 超速驱动阻抑 | 长期高频驱动后，自发接管可有延迟 |
| 主动异位 | 下位点主动增强 / 提前出现 |
| 逸搏 | 上游过慢或下传受阻后，下位点被动接管 |
| CICR | L型Ca内流→RyR释放SR Ca→横桥活动 |
| 长ERP意义 | 与机械收缩重叠，阻止完全强直、保留舒张 |

传导结构的三个原题标签：直径、闰盘/缝隙连接、分化。前两项分别回到内阻与细胞间耦联；“分化”按课程理解为传导功能的专门化，不把不同类型心肌排成一条越成熟必定越快的数轴。

自律性高低的观察指标是单位时间自动发放兴奋的频率；4期斜率等是影响这个频率的因素，不能把指标与决定因素混为同一答案。

上游0期大小/速度主要看可用通道、电导和电化学驱动力；整段传播还要看下游细胞达到阈值是否容易。所以“阈值”在问局部0期形成参数与问整条传导时，不能不分对象地一律选或一律排除。

起搏器相关内容只保留风险原理。调整、暂停和起搏依赖评估属于临床监护操作，不能凭本表自行执行。

## 7｜心肌与骨骼肌的比较矩阵

| 轴 | 骨骼肌 | 心室工作肌 |
|---|---|---|
| 神经 / 受体 | 运动神经ACh—N₂ | 自主神经调节，β₁、M等按部位 |
| 静息主要K特性 | 钾漏等 | IK1突出 |
| AP形状 | 短，无长平台 | 平台较长 |
| 耦联结构 | 三联管 | 二联管 |
| SR释放触发 | 电压感受器—释放结构耦联 | 外Ca进入触发CICR |
| 外Ca依赖 | 收缩触发相对较低 | 明显 |
| CCB直接效应 | 通常不靠阻外Ca来抑制骨骼肌收缩 | 可影响心肌Ca触发与收缩 |
| 空间募集 | 可募集运动单位 | 不靠同样方式增强；房室各有功能合胞体 |
| 时间总和 | 可形成强直 | 长ERP限制完全强直 |
| 长度—张力 | 可见明显降支 | 生理范围内受伸展限制，课程降支不明显 |

补充比较：骨骼肌属随意肌分类，心肌属非随意肌；两者工作肌正常4期都不自动去极化。课程骨骼肌曲线可列后超极化，工作心肌对照图不列同样回射。共同机械链为Ca结合肌钙蛋白→原肌球蛋白位置改变→横桥循环/肌丝滑行；A带长度基本不变，I带和H区随收缩缩短。松弛时骨骼肌主要向SR回收Ca，心肌还需跨膜外排与SR回收共同完成。

外Ca触发与SR释放的精确比例依制备、物种和条件，不把原图10%–20% / 80%–90%当人体一律固定的测量常数。
