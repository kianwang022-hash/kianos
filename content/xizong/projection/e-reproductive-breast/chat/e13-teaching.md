# 乳腺癌证据：确诊、范围与分子身份

> 为什么同一肿瘤需要病理、TNM和受体三套信息，影像与标志物各能证明到哪一步？

<a id="diagnosis"></a>
## 临床警报引出影像，组织学完成身份

最早最常见临床入口是乳房肿块：外上象限偏多，常单发、无痛、质硬、边界不清、活动差。青年纤维腺瘤也可单发无痛，清界与活动好是重要比较条件。血性溢液可来自乳头状瘤，也可来自癌；靠乳晕或侵乳管可乳头凹陷。酒窝来自Cooper牵拉，橘皮来自真皮淋巴阻塞，另有卫星结节、溃疡，需继续辨别证据层级。

钼靶毛刺和细小致密沙粒样钙化增加怀疑，超声辅助定位与血流观察；影像发现可疑不等于确诊。活检/病理是Current Study确诊金标准，进一步判原位/浸润、组织类型及受体。当前Source不推荐把部分切除活检当常规首选，未给出的取材技术不补写。MRI、乳管镜、溢液细胞学和乳头病变刮片属于问题特定补充。

CA15-3在当前Lecture连疗效、预后与复发监测；CA125—卵巢、CA19-9—胰腺是既有标志物接口，不能变成确诊替代物。BRCA缺陷连预防性全乳切除的Source接口，风险不等于已患癌。怀疑骨转移时ECT提供敏感性高、特异性有限的骨代谢证据，椎弓根/椎体异常与椎旁静脉是骨转移接口，不单凭ECT自动判M1。

诊断输出必须分别说是不是癌、局部范围、区域淋巴、远处状态和分子身份。一个影像征不能承担这五问。

<a id="extent"></a>
## T的大小与侵犯、N的区域与M的远处

T0是原发未查出，Tis是已找到原位/非浸润癌。T1≤2cm，T2>2且≤5cm，T3>5cm；T4改用侵犯坐标，任意大小合并皮肤溃疡、卫星结节、橘皮，或侵犯肋骨、肋间肌、前锯肌等胸壁，或炎性乳癌。仅粘附胸肌不属T4，酒窝也不能脱离完整规则自动定T4。

Current Study的N0为同侧腋窝未肿大/无区域证据，N1同侧无痛肿大可推动，N2固定或融合，N3同侧胸骨旁或锁骨上肿大。这里按Source的位置与活动性口径，不补现代病理结点数分层。腋窝、胸骨旁、锁骨上属区域N；骨肺肝等远处属M。M0无远处、M1有远处，任何T/N合M1都进入IV期。

Current Study组合表还需保留：N0时T1为I，T2/T3为II，T4为III；N1时T0/T1/T2为II，T3/T4为III；N2/N3时任何T为III。大小边界和组合是版本限定精确事实；它们不能代替原位/浸润病理，也未在这里静默更新AJCC。

<a id="biology"></a>
## 受体、靶点和增殖活性不同

ER/PR回答激素受体与内分泌入口，HER2回答靶向入口，Ki-67回答增殖活性。ER阳性不能判断M，HER2也不能直接定T，Ki-67更不能替代ER。

Current Study的简化亚型表为Luminal A：ER/PR阳性、HER2阴性；Luminal B：ER/PR阳性、HER2阳性；HER2过表达型：ER/PR阴性、HER2阳性；basal-like/三阴性：ER、PR、HER2均阴性，当前Source列其预后最差。该表没有现代Ki-67或PR阈值，不在此扩写；三阴性也并非“所有标志物都阴性”。

由临床警报到可疑影像、活检身份，再到T/N/M与ER/PR/HER2/Ki-67，才能向治疗章交出四类实际输入：局部可控性、腋窝状态、远处状态、分子身份。
