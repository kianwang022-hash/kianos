# 肺结核：免疫怎样围住病原，又怎样留下坏死与空洞

结核的同一宿主反应有两个方向：细胞免疫限制病原，迟发超敏参与干酪坏死。先由免疫与空间解释病型，再把感染、活动性和传播风险分开，最后按药敏和适用条件进入化疗。

## 从接触到发病，中间隔着宿主反应

吸入结核菌不等于立即发生结核病；菌可被局限、休眠，抵抗力下降后再活化。巨噬细胞—上皮样/朗汉斯巨细胞与淋巴细胞围住病灶，同时迟发损伤造成干酪坏死，排出后成空洞。<a class="kp-binding" data-kp-id="respiratory-r07-kp02" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block7_肺结核_肉芽肿空洞播散与化疗_学习阅读版_v1_最终执行版.md#L199">结核杆菌细胞壁3成分：免疫、坏死/空洞与PPD〔毒素｜细胞壁3成分/3效应｜超敏型｜免疫vs变态｜继发空洞机制〕</a> 免疫严重不足时肉芽肿、空洞和PPD反应可减少，播散却增加。

<details id="r07-immune-duality-explain">
<summary>展开感染身份、结核结节与免疫双向作用</summary>

课程传染源以排菌、尤其空洞性肺结核患者为主，呼吸道飞沫是主要传播，消化道和皮肤伤口等是其他入口；所有人可感染，免疫低下者更易发病。  吸入后不一定立即出现结核病：病原可被免疫局限、休眠而无症状，抵抗力下降或病灶活化时再繁殖、损伤组织。感染身份和临床疾病身份因此不能互换。

结核仍有变质、渗出、增生等炎症变化，最有识别意义的是慢性干酪性肉芽肿炎。感染后的淋巴播散也不是病原从外界“经淋巴进入肺”的新途径。

巨噬细胞吞噬但不能彻底消化结核菌，可转为上皮样细胞，聚集融合成 Langhans 巨细胞，核在周边马蹄或U形排列；大量淋巴细胞、少量反应性成纤维细胞共同围住中央病灶。  这是结核结节的四类细胞与来源关系，不是四种各自独立的病变。

中央干酪坏死大体干燥、淡黄、细腻、较实，镜下无原组织轮廓，呈无结构嗜酸性颗粒物。课程称“彻底凝固性坏死”，要与一般凝固坏死仍留轮廓的情形区分。坏死物排出后留下空腔；未排出则还可能被包裹或机化。

结核菌不靠外毒素/内毒素直接致病，课程以多糖关联免疫应答、蜡质关联干酪和空洞、蛋白质关联PPD皮肤反应。这个表是学习对应关系，不能说每种成分只有一个效应。致敏T细胞参与Ⅳ型迟发反应：免疫限制病原，超敏制造损伤，两者常同时发生。继发者已有致敏背景，因此干酪、空洞更突出；严重免疫下降时，不能有效局限，超敏也变弱，反而可能播散多、肉芽肿和空洞少。

```text
结核菌存留 → 巨噬细胞/致敏T细胞
                    ├→ 局限与肉芽肿：限制扩散
                    └→ 迟发损伤：干酪坏死 → 排出 → 空洞
免疫不足 → 两种反应减弱，但病原扩散可增加
```

<summary>展开原发、继发与免疫低下的同轴比较</summary>

原发是初次感染、起初无特异免疫，儿童多见。  肺内灶位于上叶下部或下叶上部近胸膜，连同结核性淋巴管炎、肺门淋巴结结核构成原发复合征，影像可哑铃状。肺门结多单侧、可干酪坏死，与结节病常双侧结的入口不同。尚无成熟免疫使淋巴、血道播散更容易；随后免疫建立，大多数可纤维化钙化愈合，营养不良或其他感染可使进展。

继发可再次外源感染，也更常是静止原发灶内源复发，成人和抵抗力下降背景多见。课程上叶尖后、下叶背段/后基底段，常从右肺尖开始。沿支气管播散使病灶以肺内为主，上部较旧较重、下部较新较轻，常有空洞。这里“原发淋巴血道、继发支气管”是优势方向，不能把它升级成绝无交叉的规定。

晚期HIV/AIDS免疫严重低下时，下叶病变、肺门纵隔淋巴结、胸膜心包渗出、粟粒与多部位播散可以突出，而肉芽肿、空洞、PPD反应减少。  它像原发型，却不是在重写患者的感染史。细胞数量和功能不足既让菌难以被局限，也让皮肤迟发反应变弱；因此PPD阴性不构成安全排除。晚期淋巴细胞缺乏时胸水ADA也可能不升高，这一接口不能独立否定TB。

<details id="r07-lesion-fates-explain">
<summary>展开六型、三种空洞、胸膜与血道播散</summary>

课程六型是局灶、浸润、干酪性肺炎、慢性纤维空洞、结核球、结核性胸膜炎。  不要把它们硬排成所有人必经的六站：它们是在不同增生、渗出、破坏和包裹状态下观察同一个谱。局灶典型非活动，浸润最常见活动，干酪肺炎危重，慢纤空典型开放；实际活动与传播最终仍需症状、影像演变和病原证据。

局灶肺尖结节边界清楚，增生为主、菌少、宿主免疫较强，常无症状。  浸润肺尖/锁骨下以渗出为主，模糊、不均的云雾云絮或斑点斑片实变，可薄壁空洞。加重坏死并支气管播散可成为干酪肺炎；空洞久不愈、周围广泛纤维化可成慢纤空；干酪灶包裹可成结核球。病灶名称由这一关系解释，而不是仅靠形容词记忆。

干酪肺炎可急高热和明显中毒，呈大叶实变或斑片，并有虫蚀样无壁空洞。  它和肺炎链球菌共享实变，但坏死来源不同；链球菌典型通常无洞不是绝无坏死并发症。浸润薄壁、干酪无壁、慢纤空厚壁是课程三种典型，结核多无液平、脓肿常液平同样只是识别趋势。

慢纤空厚壁由内向外是干酪物与大量菌、肉芽组织、纤维结缔组织，呈坏死到修复机化的空间层。与支气管相通可向同侧或对侧播散，留下上旧下新。上叶纤维收缩又缩小变形肺体积、抬高肺门、使纹理下垂如垂柳，纵隔被拉向患侧；肺血管受压增加PVR，进入R9的肺高压肺心病。并发还包括肺气肿、胸膜粘连、气胸/脓气胸、大咯血、喉和肠结核。

病理称这一相通结构典型开放；临床则以排菌量、涂片等评价传播。两个观察层级不能强行写成完全同一句定义。

结核球是纤维包裹、界清孤立的干酪灶，可来自浸润灶包裹、引流支气管堵住而空洞填满干酪物，或多灶融合。  边清、钙化、分叶、洞或卫星灶是影像接口，仍需与周围型癌鉴别。课程“多手术”不能自动变成指征，要看活动性、诊断把握、变化、药效和风险。胸膜型湿性多，为浆液纤维蛋白渗出和积液；干性以增生为主，可留下增厚粘连。ADA>45的课程支持与免疫低下边界留到R10胸水算法。

血道扩散则脱离支气管局部路线。  菌大量进入肺静脉、左心和体循环，能到肝脾脑膜等，形成全身急性或慢性粟粒结核。急性肺粟粒约2mm、双肺弥漫，分布大小密度“三均匀”，与转移大小不等、血源脓肿外周多发空洞比较。原发更易血播，并不表示粟粒只能来自原发。

## 感染、活动、传播，分别需要不同证据

PPD是感染/免疫反应线索，不直接确诊结核病；免疫低下阴性不能排除。活动性要合看症状、影像演变、分子/培养和治疗史；传播风险另看排菌、咳嗽/病灶与治疗。<a class="kp-binding" data-kp-id="respiratory-r07-kp19" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block7_肺结核_肉芽肿空洞播散与化疗_学习阅读版_v1_最终执行版.md#L888">痰涂片、培养、活动性与传染性：两个坐标不能混〔涂片身份/阈值｜培养身份｜涂阳/涂阴｜菌阳｜菌阴定义｜无活动3全满足｜病理/内科开放边界〕</a> 涂阴不是零传播，空洞不自动活动，钙化也不自动全静止。PPD毫米阈值在冻结Current中没有，不能补造。

<p class="model-retrieval-keys"><a class="kp-binding" data-kp-id="respiratory-r07-kp17" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block7_肺结核_肉芽肿空洞播散与化疗_学习阅读版_v1_最终执行版.md#L803">影像两层：先看好发位置，再看活动性多形性〔X线→CT｜部位3组｜活动3征｜修复2征｜空洞3壁｜液平边界〕</a><br>
<a class="kp-binding" data-kp-id="respiratory-r07-kp18" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block7_肺结核_肉芽肿空洞播散与化疗_学习阅读版_v1_最终执行版.md#L839">PPD：检出“感染过TB并能发生迟发反应”，不是直接确诊结核病〔致敏时程｜细胞/超敏型/抗原｜感染vs疾病｜价值人群｜阴弱原因10项〕</a></p>

<details id="r07-three-evidence-axes-explain">
<summary>展开PPD、涂片培养与两个临床证据坐标</summary>

胸片常规首选、CT进一步定位，先按宿主找位置，再看模糊渗出、各种洞和播散，或钙化、界清纤维条索。  前者警惕活动，后者提示修复，但旧残腔和其他空洞病因存在，钙化与活动也可并存。因此必须与既往片、症状、治疗史和病原信息一起判断，不能“见洞即活动”或“见钙化即全静止”。

PPD观察的是接触后约4–8周形成的致敏T细胞再次遇抗原产生Ⅳ型反应，关联细胞壁蛋白。  它支持感染过且能反应，不能直接证明现在结核病；婴幼儿儿童、尤其无BCG的提示价值较大。长期激素、免疫抑制、癌、严重细菌感染、粟粒、麻疹、水痘、HIV、结核脑膜炎、营养不良，都可使反应弱或假阴性。共同原因是反应能力不足，不是菌一定不存在。

抗酸涂片快速，课程痰约5000–10000菌/mL可阳性、菌量大提示传播，但它不能单独区分TB与非结核分枝杆菌。鉴定为TB复合群的培养阳性支持菌阳和活动，培养金标准不意味着只涂阴才培；快速核酸、耐药和药敏信息同样有角色。涂阴风险通常低，却不是零传播，不能取消防护。

课程菌阴组合3次涂阴、1次培阴加典型临床影像、PPD强阳性，只是简化来源，PPD并非必备确诊，阴性取材也不能排除；要综合合格样本、分子检测、演变、必要组织学和替代诊断。无症状、不排菌、仅硬结钙化纤维的典型静止组合有识别意义，不满足不等于自动活动。确立活动后及时有效治疗，再分别评价传播。

```text
PPD → 感染/免疫反应线索
症状 + 演变影像 + 分子/培养 + 治疗史 → 活动性
排菌 + 咳嗽/病灶 + 治疗情况 → 传播风险
                    三条线不能互换
```

异烟肼H有较好的组织、脑脊液、干酪、胸水浓度接口，周围神经炎补B6；利福平R全杀；吡嗪酰胺Z有高尿酸；链霉素S肾/耳毒；乙胺丁醇E视神经炎。  H/R/Z肝毒需要主动监测：canonical明确ALT≥3倍正常上限且有肝炎症状，或无症状≥5倍要停相关药并评估，轻无症状升高不是自动停。保肝不能代替判断；旧严重肝炎2SHE/10HE还含肝毒H，不能当通用安全组方。

药敏肺结核课程2HRZE/4HR，前两月强化H/R/Z/E，后四月巩固H/R；Z主要前期。间歇2H3R3Z3E3/4H3R3的3是每周三次，不能自行减频，尤其高风险/HIV还需另评适用与督导。六个月属于特定药敏肺TB，不是所有结核或结节病通用疗程。

复治涂阳首先药敏；R敏感并不证明其余一线全敏，还要看既往疗效依从。  RR耐R，MDR至少耐H加R。课程短9–12、长18–20月至少4有效药，与canonical已标的WHO2025适用人群六个月全口服BPaLM/BDLLfxC、九个月方案分版本；不是在此新造处方。

课程长程组方A为左氧/莫西、贝达喹啉、利奈唑胺，B为氯法齐明、环丝氨酸，C为E、德拉马尼、Z、亚胺西司他丁/美罗、阿米卡星、S、卷曲霉素、丙硫异烟胺、PAS等。所有可用A加至少一B；A仅一二种则用所有B，不足再C，是长程框架，不能拼入标准六个月方案。PAS的PABA样结构、叶酸与一碳/核苷酸抑制保持课程主线，同时继承研究活化为抗代谢物、抑DHFR的校准，不能完全等同磺胺直接竞争作用。

回到患者，先用消耗症状、位置和宿主提高怀疑，按渗出/坏死/修复找到病型；再分活动与传播、核对既往治疗和药敏，才进入适用方案。  急下叶实变普通肺炎、误吸脓臭液平脓肿、多年脓痰薄壁气道囊腔支扩、吸烟肿块局限哮鸣肺癌，都需结合整体，不让“上肺有洞”取消其他证据。
