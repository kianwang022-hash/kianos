# COPD：气道变窄与回缩变弱，怎样共同困住空气

在相应表型中，两条结构链可汇合：慢支让小气道黏、窄、硬；肺气肿拆掉肺腺泡回缩框架。呼气流速受限 → 排空不充分/过度充气 → 做功增加，同时出现区域VA/Q异常。诊断证据、当前危险与稳定期管理各回答不同问题。

这是同一模型的压缩入口。节点标题可直达当前完整知识，解释在原处展开；本准备稿不代表已学习、Source已接触或Memory已准入。

<summary>展开：入口：症状提示，持续受限才提供功能身份</summary>

慢性咳痰、肺气肿和COPD相关，却描述不同层。慢支是气道慢性炎症及临床综合征，肺气肿是末梢组织异常扩大和弹性破坏，临床COPD强调支气管扩张剂后仍存在的持续气流受限。中老年吸烟、反复咳痰喘和活动气短提供入口，定性仍看肺功能与暴露、其他病因，不能用症状或一个低比值独自完成诊断。

气管一路分成主、叶、段、小支气管、细支气管，终末细支气管是传导区最后；再向远端的呼吸细支气管、肺泡管、囊和肺泡组成肺腺泡。肺小叶含多个腺泡，I型上皮薄而交换，II型分泌表活并参与修复，间隔中毛细管与弹力纤维同时提供交换和机械支撑。COPD可以同时损害传导小气道与这套远端框架，不能把所有形态叫大支气管狭窄。


烟雾和感染刺激首先接触较大支气管，逐渐向小气道发展，而停留与病变集中又使小气道成为重要部位，“首先”与“主要”在问不同事情。内侧纤毛倒伏脱失、上皮坏死脱落降低清除；鳞状化生更耐刺激却失去原纤毛功能，杯状细胞/腺体增生、浆液腺黏液化增加黏液，结果是制造得多而扫得少。

持续管壁水肿、慢性淋巴/浆细胞炎症使壁厚，支撑的软骨、肌与弹力结构损害，再纤维修复让管变硬、窄。咳来自刺激，痰来自分泌与清除失衡，喘来自痉挛、壁厚和腔内分泌阻塞，三种症状由不同环节合成。每年至少三个月、连续两年的“3+2”是慢支临床接口，不是COPD肺功能标准。增生/化生也不能改叫软骨异型增生，后者属于另一类病理语言。

</details>

肺气肿累及整个末梢肺腺泡，肺体积和含气增加、间隔与弹力框架破坏、毛细床受压或减少。正常肺回缩既是吸气阻力也是呼气动力，毁掉它时确实更容易拉大，但呼气向前推气的力量也降低，小气道更易提前闭合。残气加重膨胀，膨胀又压迫/破坏间隔，肺泡融合、大疱与毛细床减少，使机械与换气故障相互强化。


慢支的小气道炎症、黏液清除失败和纤维化提供不完全阻塞；中性粒弹性蛋白酶增加，氧自由基降低α1抗胰蛋白酶保护，蛋白酶/抗蛋白酶失衡又拆弹力结构。课程慢支→中央型肺气肿就这样把两条链接起来，不是每例COPD都必须按同一时间顺序走完。气道阻力与不均通气影响动态C，合并肺气肿失弹性使静态C可高，指标方向仍须看结构和测量条件。

```text
分泌多/清除少 + 小气道狭窄 → 呼气流速受限
蛋白酶保护失衡 → 回缩弱/提前闭合 → 空气排不净
                   两路汇合 → 滞气/过度充气 → 功能负担↑
```


肺气肿分类首先问腺泡哪段坏。中央/近端型重在呼吸细支气管及近邻，远端较轻、常慢支；周围/间隔旁/远端型重肺泡管囊、邻胸膜及小叶间隔，课程以胶原收缩解释，胸膜下大疱可破；全腺泡各段均扩，遗传α1缺乏为接口。周围型位置稳定在远端，而瘢痕旁/不规则型随瘢痕位置、范围和形态变化，不能同名替换。

间质性则气进入间质、串珠气泡/皮下气肿，可创伤或剧咳，张力气胸有接口而普通气胸不等于阻塞型肺气肿；代偿型是余肺充气，老年型回缩减少，均须保留病因和结构身份。原版图10-10与CT页码有版本差别，文字分类不证明已看原图。

</details>

吸气时肺大、牵引强，小气道较开；呼气容积缩小、牵引减弱，狭窄管更易关，再叠回缩弱便出现呼气困难。缩唇缓呼维持气道内相对压力、减慢提前闭合，可帮助排出；活动时需求升而排气速度已有限，气短更明显，不能只由咳痰多少解释。


若呼气受限又没有足够时间排空，下一吸气开始前仍未回到静态平衡，呼末肺泡压高于开口，形成内源性PEEP（呼气末正压）。新吸气需先克服这个阈值再产生流，做功增加、肌疲劳会进一步影响VA和CO₂。单看RV/FRC增大不能证明PEEPi，因为静态大气量与动态来不及排净是不同条件。MEFV下降、闭合容积增和动态C改变提供小气道指标，仍要连测法读取。


肺功能于是要分职责：FEV1/FVC看流速相对量，支扩后仍小于70%是课程持续受限入口；FEV1%pred量严重程度，课程GOLD1≥80、2为50–79、3为30–49、4小于30。RV是最大呼末剩量，FRC是平静呼末，滞气/过充可高，TLC在气肿可高、RV/TLC课程大于40%为气肿接口。DLCO是肺一氧化碳弥散量，低值指向肺气肿/毛细床面积损失，不能推广全部气道为主COPD都低。


这些改变还解释体检。更多含气造成桶状胸、过清音、Kronig峡宽、肺/肝界低，膨胀肺遮挡心让心浊音小、音远；空气多与气流少又使语颤和呼吸音弱、呼气延长。分泌物液体提供湿啰，气道狭窄提供干啰，两种可以同在。桶胸并不专属COPD，严重哮喘和老龄也可，体检仍需病史/持续受限证据。

正常语颤在肩胛间、胸骨旁1–2肋较强，肺底弱；实变、大空洞或积液上方可增强，不等于整个积液区增强。鼓音偏气胸/含气空洞，过清偏过充，浊实偏液体或实变，不同传声介质决定结果。哮喘干鸣为主、COPD及心源哮喘可干湿，仍是支持方向而非单声定病。
