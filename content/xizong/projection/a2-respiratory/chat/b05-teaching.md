# 肺炎：先看肺的哪个空间被占据，再寻找病原

感染进入后占据肺泡、细支气管周围或肺泡间隔，改变声音、影像和氧合。获得环境缩小病原候选，合格证据检验假设；严重度在任何一步都可要求立即处理。

<section data-model-node="alveolar-fill">

## 含气肺泡变成实变，声音和氧合为何一起改变

肺泡被渗出物填满 → 含气减少、组织致密 → 叩诊浊、语颤和声音传导增强；仍含气的支气管被白色实变衬出。血流仍经过通气减少的肺泡，低VA/Q或分流样改变使氧合下降。声音更强不等于换气更好。<a class="kp-binding" data-kp-id="respiratory-r05-kp15" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L733">肺实变为何“声音更强”：气体被渗出物替代后的传导变化〔叩诊｜语颤｜呼吸音｜湿啰音｜纵隔｜机制1链〕</a>

<details id="r05-alveolar-fill-explain">
<summary>展开实变、声音与氧合的同一条链</summary>

正常肺泡的气体减少，被浆液、纤维素和细胞替代时，局部密度升高。叩诊因含气下降而浊或实，声音经致密组织更容易传递，所以语音震颤增强，并可能听到异常支气管或支气管肺泡呼吸音；液体与气流相互作用又产生湿啰音。单纯实变的体积未必明显改变，因此一般不出现明显纵隔移位。

若支气管仍含气，黑色含气管道被周围白色实变肺泡衬出，就是支气管充气征。这首先证明两种空间的含气差异，不是某一种细菌的身份证。胸腔积液本体通常削弱呼吸音和语颤，但上方压实肺可增强传导；不能把一个声音方向脱离所在位置记忆。

肺泡通气减少，而血流仍经过，会形成低 VA/Q 或分流样改变，解释肺炎为何低氧。声音变强和氧合变差并不矛盾：前者来自传导介质，后者来自气体不能充分进入交换空间。

</details>

## 三种分布来自三种受累空间

同一感染问题分成三个空间支路：肺泡纤维素渗出连成大叶实变；细支气管周围化脓形成斑片；肺泡间隔炎症形成网格/磨玻璃、痰少。<a class="kp-binding" data-kp-id="respiratory-r05-kp01" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L133">肺炎空间总坐标：肺泡、细支气管周围还是间质〔空间/炎症/影像3轴｜非典型病原vs间质病变｜重症跨界〕</a> 非典型是病原分类，间质是位置分类；重症可跨入肺泡。纤维素清不净则肉芽组织机化，化脓坏死则可成脓腔，二者不能混。

<details id="r05-spatial-branches-explain">
<summary>展开三种分布、清除与坏死的分岔</summary>

大叶性肺炎的主体是肺泡内纤维素性渗出。 <a class="kp-binding" data-kp-id="respiratory-r05-kp05" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L286">大叶性肺炎：肺泡被填满，但支气管仍含气〔人群/病原｜肺泡空间｜蔓延2路径｜支气管/胸膜｜实变4征/纵隔｜充气征机制〕</a> 它可经 Cohn 孔或呼吸性细支气管在肺段内扩展，跨叶传播再联系肺叶支气管，于是从局部连成部分或整个肺叶实变。典型病变支气管不受累、仍含气，胸膜却可以受累；这与前面的充气征及实变体征相接。肺炎链球菌和青壮年是常见入口，但“大叶性”是形态语言，不完全等于某菌名。

自然病程经典四期是在观察渗出物如何出现又被清除：充血水肿期以毛细血管充血和浆液为主；红色肝样变有纤维蛋白和大量红细胞；灰色肝样变时红细胞减少，纤维蛋白、中性粒细胞更突出；消散期靠中性粒细胞蛋白水解酶溶解纤维素。 <a class="kp-binding" data-kp-id="respiratory-r05-kp06" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L336">大叶性肺炎四期与肺肉质变：纤维素能否被清掉〔四期｜并发4｜最常见/最严重｜肉质变链｜机化/肉芽肿辨别〕</a> 若中性粒细胞数量过少或功能不足，纤维素不能清完，肉芽组织长入取代它，形成机化、褐色肉样肺。这里是肉芽组织，不是肉芽肿。

课程的并发症框架中，肺肉质变/机化最常见，还包括胸膜肥厚粘连、脓肿脓胸；感染中毒性休克、败血症最严重。不能因为经典大叶性通常结构破坏少，就将混合化脓感染的并发症排除。

小叶性肺炎以细支气管及周围末梢肺组织为中心，中性粒细胞化脓性炎症可同时占据支气管和肺泡，不同灶形成不规则斑片。 <a class="kp-binding" data-kp-id="respiratory-r05-kp07" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L378">小叶性肺炎：以细支气管为中心的化脓性斑片病变〔人群/病因｜中心结构｜炎症细胞｜好发部位｜影像｜并发症｜胸膜边界〕</a> 久病卧床、婴幼儿、老年、体弱，以及麻疹后、术后、误吸、坠积背景，使清除和防御条件不同。重力和分泌物沉积联系双下叶背侧分布，CT可沿支气管血管束观察。与课程大叶性比较，它的并发症更多、更严重。病理考试“一般不累及胸膜”是学科范围内的典型口径，不能变成临床绝对排除规则。

间质性肺炎则先在肺泡间隔：间隔增宽、血管充血、水肿，淋巴细胞和单核细胞浸润，肺泡腔通常无明显渗出或只有少量浆液。因此常见干咳、痰少，影像可网格、磨玻璃。病情严重时，浆液、少量纤维素、红细胞和巨噬细胞也可进入肺泡，甚至坏死，不能把“间质”理解成永不侵犯实质。

```text
肺泡填充 → 连片实变 → 含气减少、传导增强、低VA/Q
细支气管周围化脓 → 分散斑片 → 可融合、坏死和并发症
肺泡间隔炎症 → 间隔增宽 → 网格/磨玻璃、少痰
                                    ↓ 重症可跨进肺泡
```

病毒、支原体、衣原体属于典型间质病原范围；军团菌虽属非典型病原体，却可造成纤维素性化脓性肺实质炎。“非典型”在这里是病原学、β-内酰胺不敏感的分类，“间质”是位置分类。病毒不在课程非典型三联内，也不因这一名称失去间质位置。

严重流感、麻疹、冠状病毒、腺病毒损伤肺泡上皮/呼吸膜，渗出浓缩贴附肺泡壁可形成透明膜，完整弥漫性肺泡损伤、ARDS时相留到 R12。 <a class="kp-binding" data-kp-id="respiratory-r05-kp08" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L418">间质性肺炎与病情进展：主轴在肺泡间隔，但严重时可跨进肺泡〔病原3｜间隔3变｜肺泡渗出方向｜重症跨界｜透明膜4病毒｜包涵体3位点〕</a> 病毒包涵体还要区别位置与染色：麻疹可核加胞质，RSV典型胞质嗜酸性；腺病毒、CMV典型核内嗜碱性但CMV也可胞质；HSV典型核内 Cowdry A 可嗜酸性。它们常见于增生上皮和多核巨细胞，圆或椭圆、可有透明晕；不能从“在核内”推出“一律嗜碱性”。

## 环境改变候选病原，证据决定它是否真在致病

CAP联系院外获得；HAP要求入院时不存在且不在潜伏期、入院≥48小时后新发。<a class="kp-binding" data-kp-id="respiratory-r05-kp02" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L167">CAP vs HAP：先问在哪里获得，再问误吸了谁〔CAP/HAP定义｜途径4/2｜病原5/5｜误吸来源｜淋巴入口边界〕</a> 胸片/CT先证明肺炎和空间，病原证据再区分致病、定植与免疫反应。痰阈值须带采样条件，单次IgM不确诊；军团菌尿抗原阴性也不排除其他型。

<details id="r05-exposure-evidence-explain">
<summary>展开环境、取样与证据强度</summary>

CAP 是院外发生，或院外获得、入院后仍在明确潜伏期内发病。空气吸入、误吸上呼吸道定植菌、邻近灶蔓延、血行播散是课程入口；结核感染后的淋巴播散不是 CAP 从外界进入肺的“第五条路”。肺炎链球菌最常见，支原体、衣原体、流感嗜血杆菌和呼吸道病毒也在课程常见范围。

HAP 则要求入院时不存在也不在潜伏期，入院≥48小时后新发生。误吸胃肠道定植菌、人工气道吸入环境病原改变了暴露，大肠杆菌、克雷伯、鲍曼、铜绿假单胞菌、金葡菌是高频候选。胃肠定植可有 G⁻杆菌和厌氧菌，但不等于 HAP 高频名单机械包含所有厌氧菌。

确认肺炎先用胸片，定位不足或影像不典型再进入 CT；影像建立空间，却还没完成病原证明。 <a class="kp-binding" data-kp-id="respiratory-r05-kp03" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L222">肺炎证据层：有无肺炎、是哪种病原、哪项结果最有意义〔影像顺序2｜病原证据5｜痰阈值｜军团菌2检｜IgM含义〕</a> 痰培养要合格标本、优势菌和临床一致：课程≥10⁷ cfu/mL不是任何采样方式通用阈值，也不能让定植菌自动变成致病菌。经皮细针吸检的敏感/特异优势伴随有创代价；原本无病原的胸水培养阳性则可高度支持致病菌。核酸检测寻找具体病原核酸，不与影像或宿主反应互相替代。

单次 IgM 的“近期感染”意义会受采样时点、持续阳性、交叉反应影响；冷凝集不是所有非典型病原共同的特异确诊。军团菌课程培养金标准、尿抗原常用，但尿抗原主要检出嗜肺军团菌血清群1，陰性不排除其他型，要与下呼吸道培养或分子检测配合。这些边界决定线索升级为证据的程度。

## 病原模型要把宿主、分布和病程一起接上

在环境与空间中比较宿主、起病、痰和肺外表现：青壮年铁锈痰实变 → 链球菌；脓血、多发易变空洞 → 金葡；误吸、砖红胶冻 → 克雷伯；缓起剧咳痰少 → 支原体；急高热腹泻低钠 → 军团菌；冬春全身反应、外周磨玻璃 → 病毒。破坏性病原经坏死—排出形成空洞，完整脓腔模型接R6。<a class="kp-binding" data-kp-id="respiratory-r05-kp17" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L784">空洞病原与肺炎结局：谁会破坏肺组织〔空洞4病原｜最易1｜坏死/引流/空洞/修复链｜链球菌/结核边界〕</a> 药物必须带MSSA/MRSA、药敏、年龄/妊娠与具体病毒条件，不能从一个线索直接开药。

<details id="r05-pathogen-models-explain">
<summary>沿同一病例轴展开六种病原和条件用药</summary>

青壮年受凉或醉酒后急性寒战高热，WBC增高，出现实变、铁锈色痰和口角疱疹，是肺炎链球菌的经典组合。 <a class="kp-binding" data-kp-id="respiratory-r05-kp09" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L477">肺炎链球菌肺炎：青壮年实变模型〔人群/诱因｜症状4｜实变4征｜影像2｜致病物｜空洞边界｜治疗3｜退热时窗/失败评估〕</a> 铁锈色从红细胞进入肺泡、巨噬细胞分解 Hb、含铁血黄素随痰排出解释，不是任意出血都同样命名。荚膜是重要毒力因素，经典大叶性通常结构破坏较少、可消散，课程联系同型二次感染较少；但原讲义“不产生毒素、绝无空洞”已由 canonical 限定：存在 pneumolysin，典型通常无空洞不排除坏死并发症。

课程首选青霉素，仍看感染部位、药敏和当地耐药；耐药备选喹诺酮、头孢噻肟、头孢曲松也带条件。抗菌约三天仍不退热或降后复升，要复核病原耐药、给药和并发症，课程提示脓胸、心包炎、关节炎等肺外灶，不能仅凭发热锁定其中一种。

如果病史是糖尿病、痈疖、骨髓炎，或住院频繁抗菌，急性高热脓痰带血，再见多发且易变的结节、斑片、空洞、液气囊腔，要接金葡菌化脓谱。 <a class="kp-binding" data-kp-id="respiratory-r05-kp10" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L529">金葡菌肺炎：最易形成多发易变空洞〔病史4组｜痰｜影像4型/胸膜并发｜空洞倾向｜MSSA/MRSA药物｜血源脓肿接口〕</a> 破入胸膜可形成脓气胸，血行来源又与 R6 的外周多发脓腔连接。用药先区分 MSSA 与 MRSA：课程前者苯唑西林、氯唑西林、头孢呋辛，后者万古霉素、替考拉宁、利奈唑胺、头孢洛林；病原耐药身份不是可略去的前提。

克雷伯则将中老年、醉酒或卒中误吸接到急性高热、砖红胶冻痰。 <a class="kp-binding" data-kp-id="respiratory-r05-kp11" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L563">克雷伯杆菌肺炎：误吸、中老年、黏稠血痰与叶间隙下坠〔人群/病史｜痰2特征｜病理型｜影像3｜治疗2层〕</a> 砖红来自含血，胶冻反映黏稠；叶间裂膨出/下坠来自受累叶膨胀和大量渗出，不能从“痰黏”直接推影像。课程归小叶形态，但也可肺叶实变，可有蜂窝状脓肿和空洞；这些小脓腔不是纤维化蜂窝肺。β-内酰胺及重症联合喹诺酮或阿米卡星、妥布霉素等是课程接口，具体须看药敏和耐药机制，全部β-内酰胺不等效；经典膨出征也非每例、非特异。

这些破坏性病原共同指向一个变化：化脓坏死液化，经支气管引流排出，空间重新充气形成空洞，之后肉芽修复、纤维瘢痕。课程“红绿黄臭”对应金葡菌、铜绿假单胞菌、克雷伯、厌氧菌，金葡最易空洞。肺炎链球菌典型通常无空洞，结核空洞则是干酪坏死，R7承担；脓腔和引流的完整组织在 R6。

接下来不是所有感染都表现为大量脓痰。 <a class="kp-binding" data-kp-id="respiratory-r05-kp12" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L605">支原体肺炎：缓起、痰少、剧咳和肺外表现〔人群/病史｜缓急/热/WBC｜咳痰｜肺外2｜影像2期｜检查2｜药物3类｜禁忌3〕</a> 儿童青年、外出背景、约2–3周潜伏，缓起低中热或无热、WBC正常或略高、持久阵发剧咳却痰少，伴耳痛或皮疹，是支原体模型。它的间质位置接到早期网格，后期沿支气管/肺纹理的双下叶斑片，通常无空洞。IgM和冷凝集不能单次独立确诊；呼吸道核酸、必要时急性恢复期血清比较，应联系病程。

β-内酰胺无效与这一病原类别相接，不是把病人一律改用喹诺酮。课程因大环内酯耐药列左氧/莫西为首选，canonical 明确不能把儿童多见与成人选项拼成儿童处方：年龄、地区耐药、妊娠哺乳、疗效决定选择；课程<18岁及妊娠哺乳不用喹诺酮，儿童通常仍大环内酯起点，四环素替代也看年龄风险。

军团菌与支原体共享痰少、肺外表现、旅行和β-内酰胺不敏感，但年龄偏大、急起高热、WBC高、腹泻低钠及空调暴露将候选转向军团菌。 <a class="kp-binding" data-kp-id="respiratory-r05-kp13" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L650">军团菌肺炎：非典型病原体中的“急、高热、WBC升高、腹泻低钠”〔非典型身份｜空调/旅行｜年龄｜起病/热/WBC｜痰｜肺外2｜影像｜检查2｜药物6〕</a> 斑片可进展为实变，它不是典型间质形态；空调也可连接 R8 的过敏性肺炎，不能见词定病。培养/尿抗原角色延续前述边界。课程大环内酯、喹诺酮、多西环素、替加环素、复方磺胺甲噁唑、利福平保留代表选项，不能当六种可任意互换的经验方案。

病毒性肺炎常在冬春，急起寒战高热、全身症状突出、痰少、WBC正常或低；淋巴细胞可升可降，肺体征轻不表示无明显病变。 <a class="kp-binding" data-kp-id="respiratory-r05-kp14" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L688">病毒性肺炎：全身反应突出，肺部从间质损伤走向透明膜〔季节/起病｜WBC｜症状强弱｜影像4｜病理4｜透明膜4病毒｜包涵体位点｜治疗3〕</a> 外周胸膜下磨玻璃、斑片可接实变，大块实变、显著胸水和空洞并非典型。它从间质上皮损伤接到前述透明膜，重症可能很快进入氧合失败。

对症支持与按病毒抗病毒是不同层：奥司他韦联系流感，阿昔洛韦联系相应疱疹，利巴韦林也须具体适应证，不能把课程药名通用化。重症不是流感常规激素的充分条件；另有哮喘发作、肾上腺不足、难治休克等适应证另论。也不预防性抗菌，确有继发细菌感染再选敏感药。

## 严重度决定能否继续留在普通感染路径

CURB-65评估严重度而不判断病原：意识障碍、血尿素>7 mmol/L、呼吸频率≥30次/分、收缩压<90或舒张压≤60 mmHg、年龄≥65岁。<a class="kp-binding" data-kp-id="respiratory-r05-kp04" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L258">CURB-65：先找谁可能不能留在普通肺炎路径〔C-U-R-B-65｜5阈值｜休克优先轴〕</a> 休克时循环复苏与尽快抗感染并行，取材不应明显延误。病例仍走环境→空间→病原线索/证据→严重度→并发去向；空洞接R6，脓胸接R10，顽固低氧/ARDS接R12。

继续这条关系：[脓胸的抗感染与引流](https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block10_胸膜空间与胸部损伤_积液气胸血胸与胸壁失稳_学习阅读版_v1_最终执行版.md#L518)；[严重事件后的顽固低氧](https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block12_ARDS与呼吸衰竭_屏障损伤氧合失败与通气失败_学习阅读版_v1_最终执行版.md#L244)。

<details id="r05-severity-exit-explain">
<summary>展开部位边界、严重度和完整病例回路</summary>

部位有价值，但要回到完整病例：课程大叶常单侧下叶，小叶多双下叶背侧，联系重力、分泌物与传播；支扩、脓肿、结核和 IPF 的特定肺段分别由后续 Block 负责。 <a class="kp-binding" data-kp-id="respiratory-r05-kp16" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L760">好发部位与影像入口：下叶规律，不替代完整病例〔好发部位：大叶1/小叶2｜位置+病程+痰/肺外+影像+证据〕</a> 位置必须与病程、痰、肺外表现、实变/斑片/网格/空洞和病原证据合读。

CURB-65不判病原，而评估严重度：意识障碍，血尿素>7 mmol/L，呼吸≥30，收缩压<90或舒张压≤60任一，年龄≥65。尿素数值不能直接当 BUN 的 mg/dL；血压条件也不能误作两项同时满足。这些变量是在询问脑、循环、呼吸与肾功能是否已经承受不住。

肺炎并休克时，循环复苏与尽快抗感染并行，取材不应明显延误，不能先补液完成才给抗菌。坏死空洞转向 R6 的脓腔/引流，胸水或脓胸进入 R10，顽固低氧与双肺弥漫影接 R12 的 ARDS/呼衰。不是所有感染最终都按同一个抗菌列表收尾。

面对病例，可以沿获得环境缩小暴露候选，以受累空间解释影像体征，再用病程、痰和肺外线索提出病原假设，用合适样本的病原证据检验；严重度在任何一步都不能等到最后才救治。 <a class="kp-binding" data-kp-id="respiratory-r05-kp18" href="https://github.com/kianwang022-hash/kianos/blob/ce079966ebce7a95fe9a58b174a412f9f033fd3b/content/xizong/knowledge/systems/a2-respiratory/blocks/Block5_肺炎_病变空间病原体与严重度_学习阅读版_v1_最终执行版.md#L813">肺炎病例五步：环境—空间—病原—严重度—并发症〔环境｜空间｜病原线索｜证据｜严重度｜并发去向〕</a> 这条关系既保留诊断的完整性，也避免铁锈痰、空调或磨玻璃一个词独占判断。
