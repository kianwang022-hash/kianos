# 怎样补上缺失功能，同时避免同种免疫伤害

输血问题有两半：患者缺什么，输入物又带进什么。补携氧功能主要需要红细胞，补凝血主要需要相应血浆成分；无目的地输入全血，会同时增加容量、红细胞抗原、血浆蛋白和活性淋巴细胞暴露。因此尽量同型、优先成分、适合时自体、输前鉴定血型及交叉配血，是同一风险模型的四项措施。育龄女性及反复输血者尤其要保留 Rh 相合问题。

## 先确定攻击方向，再谈相容

RBC 膜带抗原，血浆可带相应抗体。多结合位点抗体能桥联红细胞而凝集，进一步补体激活或巨噬清除才造成溶血。受者抗体攻击供者红细胞是主侧；供者血浆攻击受者红细胞是次侧，风险还受输入血浆量和稀释影响。交叉配血据此把供者 RBC+受者血清作为主侧，受者 RBC+供者血清作为次侧。两侧不凝集为相合，主侧凝集不能输；主侧不凝集、次侧凝集是当前历史 Source 的“基本相合”，仅保留紧急、缓慢、少量<200 mL、效价<1:200的旧考试接口。

> 主侧vs次侧：主侧阳性绝不能输，次侧阳性只属旧应急接口〔主侧谁RBC+谁血清｜次侧反向｜相合/不合/基本相合｜应急3条件｜主侧为何优先〕

O 型红细胞无 A/B 抗原，但血浆有抗 A/B；AB 受者血浆无抗 A/B，却仍有 A/B 红细胞抗原。所以“万能”必须拆回红细胞成分还是全血，以及谁攻击谁。P85 对 AB 受者的历史文字混淆攻击方向，H2-SC03 继续保留，不能取代真实抗体筛查和配血。

ABO 糖链先由前体形成 H，再添加 A/B 决定簇；O 保留 H，孟买型连 H 都无，可有抗 A、抗 B、抗 H，故不能按普通 O 型推断。ABH 还存在淋巴细胞、血小板、多数上皮及内皮和体液，唾液较丰富。A1 的 RBC 有 H、A、A1，A2 有 H、A而无“A2抗原”；当前表格给 A1 抗B，A2 抗A1/抗B，B 抗A1/抗A，A1B 无相应抗体，A2B 抗A1，O 抗A1/抗A/抗B。弱 A 反应可使 A2/A2B 朝 B 或 O 误判，表格需回生理 P83 原图精确核对，文字模型不能替代这次图表校准。

## 是否已经致敏，决定时间轴

天然抗体主要是大分子 IgM，接冷抗体语言，不能过胎盘；免疫抗体主要为较小 IgG，接温抗体语言，可过胎盘。ABO 主要用天然 IgM 推理，但成人也可有 IgG 型；正常人不产生针对自身血型抗原的相应抗体。Rh 的 D 是 RBC 膜蛋白身份，阳性有 D、阴性无 D，系统没有天然抗 D。首次接触 D 可以先建立 IgG 致敏，当前 Source 记 2–4个月达高峰，再暴露风险提高。Rh 阴性母亲在孕晚或分娩接触 Rh 阳性胎儿血后，后续妊娠可由 IgG 过胎盘造成溶血；首次分娩后及时特异抗 D 免疫球蛋白用于减少致敏。历史题旁“Rh阴性供者可能有抗D”的例子须以既往致敏和检测解释，不能泛化为阴性者必有抗D，H2-SC01保持未裁决。

## 功能和危险决定制品，而不是只看“贫血”

### 失血量先回答循环和携氧的缺口

失血早期首先威胁有效循环量，处理目标是恢复灌注。失血继续增加，RBC和Hb丢失达到需要补充的程度，才同时需要恢复携氧能力。因此“补容量”和“补红细胞”回答两个问题：晶体液、胶体液接循环缺口，浓缩红细胞接携氧缺口。

当前外科的精确失血量接口保留如下；它依次增加补充目标，不扩成现代大量失血协议。

| 失血量 | 当前外科补充方向 |
|---|---|
| <10%，约<500 mL | 通常不输血，可代偿 |
| 10%–20%，约500–1000 mL | 晶体液、胶体液 |
| 20%–30%，约1000–1500 mL | 晶体/胶体加浓缩红细胞 |
| >30%，约>1500 mL | 晶体/胶体加半浓缩红细胞、半全血 |

> 失血量决定补什么：先恢复循环，再恢复携氧〔失血4档｜晶/胶｜何时加浓红｜>30%比例｜先灌注后携氧〕

### 选浓红还要结合Hb和容量负担

浓缩红细胞主要补携氧能力。若患者有心功能不全，减少不必要容量也是制品选择的一部分。当前考试的Hb接口是另一组判断，不能直接当成上述失血量分档：Hb>100 g/L通常不输，Hb<70 g/L输浓红，70–100 g/L结合情况，心衰等可考虑。精确复苏液种类、速度及目标仍不由这里补齐。

洗涤红主要减少血浆抗体、蛋白和血浆量，接 IgA低下、严重过敏及肾功能不全；去白主要减少白细胞抗原，接多次输血、经产妇及预计反复输血；辐照灭活供者淋巴细胞，预防输血相关 GVHD。FFP 补凝血因子；冷沉淀含较高浓度 FⅠ、FⅧ和 vWF，接纤维蛋白原及甲型血友病方向。H2-SC02已回外科原PDF P234（印刷P190）和P235导图核对：表/导图确写“含无功能白细胞和血小板”，同页解释又写去除大部分白细胞和血小板。这是原材料内部差异，不能再称仅AI转写错误；此处继续保留上述稳定分工，不冻结残留成分。

<!-- kp-location: hematology-h02-kp10 -->
> 成分血选择：缺什么功能，就尽量只补什么〔浓红3阈｜洗涤/去白/辐照区别｜FFP｜冷沉淀3成分｜心/肾/过敏/反复输血〕

自体输血是收集患者自身血液，经处理后回输浓缩红细胞，降低同种免疫风险，但来源必须安全。回收式可用于脾破裂、异位妊娠破裂；肝破裂可能混胆汁，开放胸腹伤>4小时有污染风险。稀释式先采浓度高的后输、后采较稀的先输。预存式当前条件为 Hct≥30%、术前约一月开始至术前三天、每次<10%、间隔≥三天。

## 输后异常要按被伤害的对象分流

当前 Source 最常见发热反应，最严重溶血。反复输血和经产妇的发热多接白细胞免疫，血压常正常；瘙痒、荨麻疹、喉头/会厌水肿、支气管痉挛及重症休克接过敏，通常无高热，重症条目为肾上腺素+GC；过快过多后肺水肿接容量超负荷。寒战高热、腰痛、低压、呼吸困难加黄疸或 Hb 尿，则说明免疫破坏、循环伤害和肾负担连在一起。游离 Hb 及低灌注共同威胁肾，Source 处理列抗休克、肝素、NaHCO₃，有尿利尿，少/无尿或高钾透析；延迟溶血可在1–2周出现。以上是当前考试解释，真实床旁处理依输血反应流程。

表现计数回外科原PDF P233（印刷P189）：寒战、高热、腰痛、呼吸困难、血压下降、黄疸、Hb尿、急性肾衰竭。将“寒战高热”合写时原页是七组，拆开两个表现时为八项；第八不是另加陌生症状。急性肾衰是上述游离Hb与低灌注链的器官结局。

高热若同时有污染线索，还须进入当前 Source 的细菌污染分支，不能只凭发热就归入白细胞免疫反应。

<!-- kp-location: hematology-h02-kp13 -->
> 发热、过敏、超负荷与GVHD：病因对象不同，处理方向也不同〔发热人群2｜过敏表现5/重症2药｜超负荷因1果1｜GVHD谁打谁｜完整机制去哪〕

活性供者淋巴细胞在免疫脆弱受者体内存活并攻击宿主，才是 GVHD，可出现全血细胞减少，方向与受者抗体攻击供者 RBC 不同。大量库存血还同时带来枸橼酸代谢成 HCO₃⁻的碱中毒、RBC钾外移的高钾、螯合钙的低钙、低温及稀释/消耗的凝血异常。“高钾+碱中毒”不能被普通酸钾口诀抹掉；具体酸碱与膜兴奋性处理回泌尿的 owner。

危膜的固定先修位置是泌尿K5 KP08–09：细胞外K⁺明显升高使静息膜电位去极化，早期更近阈值，持续严重去极化却使Na⁺通道失活、传导下降，可至室颤或停搏；有高钾毒性ECG等危险时首先考虑保护心肌。低钙也能改变兴奋性，不能由库存血五种并发症名单推出统一出现先后。这里“最先”读作已有生命危险时的处置优先级，不读作每次大量输血必然先发生高钾。
