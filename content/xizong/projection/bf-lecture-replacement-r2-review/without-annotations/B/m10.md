# M10｜肝怎样把血红素废物和其他化合物变成可处理产物

血红素承担氧运输和电子反应，分解后的疏水色素却须妥善排出。先追它怎样生成，再追白蛋白—肝—胆道—肠道的交接，黄疸便可以按故障位置解释；肝的其他转化仍须看具体反应，不能因发生在肝就都叫解毒。

## 合成要跨两个空间，分解要辨认真正的色素来源

Gly+琥珀酰CoA起步形成卟啉前体，加Fe²⁺成血红素，再加珠蛋白成Hb。起始在线粒体，中间胞浆，终末回线粒体；成熟RBC没有线粒体，不能完成。起始限速ALA合酶用PLP/B6，受血红素反馈，睾酮可诱导而接雄激素促造血。ALA合酶负责合成，血红素加氧酶负责分解；亚铁螯合酶虽附题列入合成调节，不因此成为第二限速酶。

当前Study铅抑制ALA脱水酶、亚铁螯合酶/血红素合成酶、粪卟啉原氧化酶，不选ALA合酶或血红素加氧酶；血/尿ALA可升。名单按当前Source保留，完整铅中毒和卟啉病后置。




胆红素不仅来自Hb，还可来自肌红蛋白、细胞色素、过氧化氢酶/过氧化物酶等含铁卟啉蛋白；共同入口是血红素部分，珠蛋白回氨基酸。主要在脾等单核巨噬系统，血红素经加氧酶成第一个胆色素胆绿素，再经NADPH相关还原成UCB。UCB也叫未结合、游离、间接胆红素，肝前语言用于定位其尚未结合的阶段。



## 溶解性决定运输工具，也决定尿中能看到谁

脂溶UCB在血浆须白蛋白携带，当前Study一白蛋白可结合两UCB。到肝后UCB摄入，由Y/Z蛋白送内质网，UGT用UDP-葡糖醛酸/UDPGA形成水溶CB，随胆汁排出。糖原用UDPG，结合用UDPGA，不能仅凭UDP字样混同；旧UGT需铁句已退役。

未结合指未结合葡糖醛酸，白蛋白运输不使它成为“结合胆红素”。UCB不能造成尿胆红素阳性；CB反流血中可入尿。凡登白UCB间接、CB直接，肝细胞损伤两者都有可呈双相。尿胆红素检测CB，尿胆素原/尿胆素则属于后续肠道支路，是另一对象。



CB入肠后细菌形成胆素原：大部分留肠遇氧成胆素/粪胆素、产生粪色；少量重吸收回肝，多数再处理入胆道；少量经肾氧化成尿胆素、参与尿色。胆汁酸也有肠肝回收，却是另一物质链，不能借同名循环互换化学来源。


## 黄疸先定位生成过量、肝处理损伤或排出堵塞

| 故障位置 | 当前Study血中方向 | 尿与粪的推断 |
|---|---|---|
| RBC破坏增加、生成过量 | UCB为主；CB/TB<0.2 | 尿胆红素阴性；肠胆素原、粪胆素、尿胆素增，粪/尿色可深 |
| 胆道排出堵塞 | CB反流；CB/TB>0.5 | 尿胆红素阳性、尿深；入肠胆素原减少，粪浅，严重陶土色 |
| 肝摄取/结合/排泄多层受损 | UCB及CB均升；CB/TB 0.2–0.5 | 尿胆红素可阳性；尿胆素原可降/正常/轻升，粪尿方向结合损伤程度 |

溶血尿色深可来自胆素支路，并不自动使尿胆红素阳性；梗阻CB已结合却进不了肠，反而入血入尿。这样从分子性状和通道判断，比单背“黄疸都尿黄”精确。比例及组合属于当前讲义口径，复杂箭头回P075/P076；完整溶血证据、肝病和胆道临床分别归H5、D16–D17、D19。


## 其他化合物的转化，要问产物是否更易排出或更有毒

药物、毒物、激素等非营养内外源物可经肝改变，多数降低活性、增加水溶性而利于胆汁/尿排泄，也可活化成更毒产物。P079黄曲霉素氧化为活泼环氧化物、可作用DNA，说明“完成转化”不等于风险消失。

Ⅰ相氧化、还原、水解引入/暴露官能团，代表P450单加氧酶/羟化酶、醇脱氢酶、单胺氧化酶。P450主要位肝内质网/微粒体，加氧羟化既可解毒也可致毒；VitD3→25(OH)D3是羟化接口。P450不能混为呼吸链IV的Cyt c氧化酶。



Ⅱ相接合基团的供体可从已学代谢恢复：

| 结合 | 供体与当前酶定位 |
|---|---|
| 葡糖醛酸，课程最常见 | UDPGA，内质网 |
| 硫酸 | PAPS，胞质 |
| 乙酰 | 乙酰CoA，胞质 |
| GSH | 谷胱甘肽，胞质 |
| 甲基 | SAM，胞质 |
| 甘氨酰 | Gly，线粒体 |

不能用某题四选项代替六类，也不能把“除UGT全胞质”当定位规则，Gly项在线粒体。每种结合都须看产物，水溶性并非无条件增加；UGT属Ⅱ相，不属P450Ⅰ相。


肝在本系统还有三条化学实例：UCB→CB、NH₃→尿素、D3→25(OH)D3。共同点是改变难排或须调控的物质；NH₃氮流归M8，不能因为同在肝而硬塞进Ⅰ/Ⅱ相分类。苯巴比妥等诱导肝药酶、加速底物代谢；激素也可肝内灭活，但诱导后降活性还是增毒性要看底物/产物，不能只凭速度判断。
