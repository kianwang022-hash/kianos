# M1｜蛋白质怎样成为可控的化学执行器

身体把氨基酸排列成蛋白质，得到的为什么不是一条无差别的长链，而是能运输、识别和催化的执行器？要回答这一问题，先建立“序列怎样形成空间功能”，再看催化怎样被控制，最后补上蛋白质本身不能独立完成的化学搬运能力。

## 序列保存折叠信息，空间构象实现功能

多肽主链由肽键连接，序列从N端读到C端；一级结构还包含半胱氨酸二硫键的位置。序列决定局部折叠倾向，局部构象再组织成整条链的空间排布，最终形成结合、运输或催化表面。改变序列与改变折叠是两个故障入口：镰形红细胞贫血用于说明基因改变后氨基酸序列异常；疯牛病、阿尔茨海默病、亨廷顿病用于说明构象异常，序列未必改变。构象病不能被换成“表达量改变”。

层级要按观察对象判断：二级结构看主链局部规则构象，三级结构看一条链主链和侧链全部原子的三维排布，四级结构看多条链的亚基关系。肌红蛋白一条链，最高到三级；结构域多并不能补出四级结构。二硫键有共价连接身份，也能稳定高级构象。

α螺旋说明局部主链怎样重复：通常为右手，每圈约3.6个残基，螺距约0.54nm，主链内侧、R基外伸，主链氢键维持稳定。Gly自由度大且无旋光性，Pro不能正常形成该氢键，连续同电荷残基排斥、过大侧链造成位阻，均不利于形成稳定螺旋。螺旋、折叠、转角按固定方式组合可形成模体，例如亮氨酸拉链、锌指、α螺旋—β转角—α螺旋；后一个组合已不是单个二级结构。链折叠后远隔片段靠拢，可构成相对独立发挥功能的结构域，属于三级层次。酶的活性中心是功能区域；结构域并非全部都在催化。





三级结构主要由疏水相互作用驱动形成内部疏水核心，氢键、离子/盐键、范德华力以及较强的共价二硫键共同稳定。尿素处理核糖核酸酶可破坏空间构象并使酶失活，肽链序列仍保留；去除尿素后可恢复构象和活性。这个反事实说明：失活不必先断肽键，序列中也确实保存了折叠信息。可复性须一级结构完整、变性条件去除；一个可恢复例子不能证明全部变性均可逆。变性、沉淀、凝固与水解分别观察构象、物理状态和肽键，完整关系回当前27 P059–P060、P064–P065原图。


## 同一分子的理化性质，支持不同任务

先比较溶液pH与pI：pH低于pI，质子化增加、净正电；相等时净电荷为零；高于pI则净负电。白蛋白pI约4.7，生理pH下带负电，因此能接到肾小球电荷屏障的滤过限制。pI定义的是净零电荷时的溶液pH，不能脱离环境给蛋白质固定一张电荷标签。

血浆蛋白的任务包括胶体渗透压、缓冲pH、运输和免疫；白蛋白是胶体渗透压主要承担者。当前讲义所讨论的血浆蛋白均为分泌型，多数在肝合成，γ球蛋白来自浆细胞；多数为糖蛋白，白蛋白例外。血浆蛋白也不能等同于球蛋白。食物蛋白则评价在体内的利用率和必需氨基酸组成，含量多或吸收率高不能独自回答营养价值。功能、来源、糖基化和营养利用率是不同问题。

实验分离同样先选差异轴。凝胶过滤让小分子进入孔隙而走较长路线，所以大分子先洗脱；透析、超滤、超速离心也利用大小，但各自膜、孔隙或沉降条件不同。离子交换利用电荷，结合越牢越难洗脱。普通电泳受电荷、大小、形状共同影响，血浆比较中白蛋白最快、γ球蛋白最慢；SDS-PAGE按当前课程模型主要依相对分子质量。盐析、有机溶剂、等电点沉淀利用溶解度，涉及水化膜、电荷层和溶液条件，不能把全部方法套成一个大小排序。




蛋白质还必须被选择性清除。内肽酶切链内肽键，胰蛋白酶、糜蛋白酶、弹性蛋白酶是当前例子；外肽酶从N端或C端切。溶酶体主要处理外源、膜和长寿蛋白；异常、短寿蛋白主要经泛素打标后送蛋白酶体，须泛素和ATP。“打标”选择降解对象，并非合成肽链。正常氧条件下VHL介导HIF的泛素—蛋白酶体降解，缺氧时降解减少、HIF积累并增强EPO基因转录：此处解释选择性清除，完整缺氧与增强子机制归G4。

## 活性中心降低门槛，关键酶控制通量

活性中心的结合基团负责认底物，催化基团直接参与反应；中心外必需基团可稳定构象，也可供变构调节剂或抑制剂结合。蛋白质酶常利用His咪唑基、Ser羟基、Cys巯基和酸性氨基酸羧基。所有酶有执行催化的活性中心，但少数酶为核酸，上述氨基酸名单与三级结构描述只适用于蛋白质酶。

E与S形成ES，再释放E和产物。酶与底物结合时释放的结合能，是降低活化能的重要来源；结合过程还让底物处于更有利于反应的位置与环境。

诱导契合是酶与底物相互诱导构象调整。邻近与定向排列则把底物放到正确的距离和方向，使需要反应的部分更容易接近。疏水口袋的去溶剂化排除水化干扰；酸碱催化与共价催化合称这里的多元催化。这些作用共同促进过渡态形成。

结果是活化能降低，反应更快到达平衡。酶只催化热力学允许的反应，不改变平衡点和方向，反应前后自身质量及化学性质不变。如果平衡不利，单纯增酶并不能把终点改成有利，只能更快到达同一终点。



绝对特异性认特定结构或立体异构体，相对特异性认某类键，例如蛋白酶认肽键。同工酶则催化同一反应而序列、组织分布或动力学不同：LDH1为H4、心肌较丰富，LDH5为M4、骨骼肌及肝较丰富；肝和胰岛β细胞的葡萄糖激酶是己糖激酶IV型，Km高、亲和力低。关键酶另按通路任务定义：相对慢、催化单向反应、可调节，因而决定通量和方向。当前27 P083“只有关键酶值得调节”按本课程的通路调节点口径理解，强调控制整条通路的速度和方向，不能据此判断所有其他酶都不可调。单向不表示产物永远不能回原料，而是返回须另一套酶。

改变执行器数量与改变已有执行器活性要分开。诱导/阻遏合成或降解改变酶量，较慢；酶原激活水解肽键、改变一级结构并形成或暴露活性中心；磷酸化等化学修饰是共价变化，可受激素—信号转导控制，由信号改变已有酶的活性；变构是代谢物在外部位点非共价结合改变构象，后二者及酶原激活属于快调。变构催化、调节部位可同亚基也可分亚基，常呈S形动力学。泛素降解仍改变酶量，不能仅因“修饰”两字改归快速酶活调节。



## 扰动发生在哪里，要同时看容量与底物需求

米氏模型v=Vmax[S]/(Km+[S])中，Km是在半最大速度时的底物浓度，当前模型用Km高表示亲和力低；Km取决于酶、底物及环境，与酶浓度无关。Vmax反映可用酶量。固定酶量和环境，低底物时加底物明显提速，高底物时酶饱和而接近平台。故底物—速率为矩形双曲线，底物充足时酶量—速率为直线，变构酶及Hb接口为S曲线，温度/pH—活性为钟形。测活性须控制温度、pH、时间、足够底物，有些还须激活剂。

可逆抑制按结合对象推参数：竞争者占游离酶活性中心，常结构类似底物，Km升而Vmax不变，加底物可部分克服；非竞争者结合E或ES外部位点，Km不变、Vmax下降，加底物不能恢复容量；反竞争者只结合ES，Km和Vmax同降，底物越多、ES越多，抑制可更明显。Vmax下降单独不能判定非竞争。

同一个米氏模型也能换成Lineweaver–Burk双倒数输入：取倒数得1/v=(Km/Vmax)·1/[S]+1/Vmax。因此横轴是1/[S]、纵轴是1/v，斜率Km/Vmax，纵截距1/Vmax，向左延长的横截距−1/Km。负横截距是直线外推，不表示实验用了负底物浓度。把本章参数变化代回即可读图：竞争性抑制纵截距不变、斜率增加；本章非竞争指Km不变的纯非竞争，横截距不变、纵截距增大；反竞争的Km和Vmax同比下降，斜率不变而成平行线。双倒数与米氏饱和曲线是在看同一模型，不能把倒数轴当成原来的底物/速度轴；变构S曲线也不因换坐标就成为这个米氏模型。此处是由P084已给方程推导的读轴补充，P084–P086没有专门印出双倒数图。

## 辅因子补上化学能力，医学应用各有归属

全酶=酶蛋白+辅因子。前者决定认谁，后者决定递电子、氢、氨基、酰基或CO₂等反应类型。辅因子可为维生素衍生物或金属；金属可中和阴离子、连接酶与底物、参与活性中心、稳定构象。辅酶结合松、非共价，可透析/超滤分离；辅基结合紧，当前Study按不可透析处理。单纯酶回答是否需要辅因子，单体酶回答是否只有一条链，是两个轴。一种辅因子可服务多种酶，同一酶也可含多种：细胞色素氧化酶含血红素和铜，琥珀酸脱氢酶含FAD及铁；PDH为多酶复合体，身份不同。

| 化学搬运 | 维生素与活性形式 |
|---|---|
| 电子/氢 | B2→FMN/FAD；PP→NAD⁺/NADP⁺ |
| α-酮酸脱羧、醛基 | B1→TPP |
| 酰基 | B5/泛酸→CoA |
| 转氨基、氨基酸脱羧、ALA入口 | B6→PLP |
| CO₂/羧化 | B7/生物素 |
| 一碳 | 叶酸→FH₄ |
| 甲基及SAM接口 | B12→甲基钴胺素等 |

PDH需要FAD、Mg²⁺、硫辛酸、TPP、NAD、CoA，缺其中一类能力可以拖慢整个复合体。M2调用此接口，M8调用PLP/FH₄/B12，M10调用PLP。



脂溶性A、D、E、K的应用须按具体任务读：D调钙磷、活性代谢物可结合核受体；A联系视觉且代谢物可调转录；A/C/E列入抗氧化维生素，C仍非脂溶性；K联系γ-谷氨酰羧化酶及凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ形成。C还通过Pro、Lys羟化与胶原成熟支持伤口愈合，和抗氧化不是同一分类轴。

酶也有另一组医学角色：G6PD、ADA、HGPRT、苯丙氨酸羟化酶缺乏可成为病因；胰蛋白酶原提前激活联系胰腺炎；胆碱酯酶被抑制联系中毒；ALT、淀粉酶、碱性/酸性磷酸酶、胆碱酯酶活力用于诊断；尿激酶激活纤溶酶原用于溶栓。完整疾病、缺乏症和治疗归相应后续模型，不能把这些应用硬连成辅因子的一条反应链。
