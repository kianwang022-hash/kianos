# G4｜同一套DNA怎样产生不同时间、组织和数量的表达

基因存在并不保证已经表达。表达先须DNA能被读到，再须转录机器被招来，RNA和蛋白还要保留足够久。以原核营养响应看清开关逻辑，再把真核染色质、顺式/反式和转录后控制接在同一数量问题上。

## 存在、可及和输出是三种状态

胰岛素基因广泛存在却主要β细胞表达，是空间特异；胎儿/成人不同为时间/阶段特异。管家基因多细胞持续相对稳定，可诱导者刺激后升、可阻遏者条件下降，多个因素可协同。表达必要入口是转录，可产功能RNA而不翻译；DNA复制不属表达。DNA/染色质、转录/加工、翻译/翻译后各层可调，课程重点基本控制点为转录起始。

活性染色质更开放：核酸酶高敏位点、H1减少、H2A-H2B稳定性降、H3/H4修饰、核小体松、DNA暴露增加。当前P151方向是DNA/CpG甲基化→紧→不利转录；组蛋白乙酰化→松→利转录。须保留修饰对象，不能把“甲基化抑、乙酰化促”泛化给所有分子或所有现代机制。最终蛋白量还受泛素+蛋白酶体+ATP清除异常/短寿蛋白控制。



## lac同时问“需不需要”和“要做多少”

I编码阻遏蛋白，O结合阻遏，P结合RNApol，另有CAP位点结合cAMP-CAP；Z为β-半乳糖苷酶，Y为半乳糖苷通透酶，A为硫代半乳糖苷乙酰转移酶，ZYA共入口生成多顺反子。阻遏占O为负调，CAP提高RNApol活性为正调，两者结合对象不同。

无乳糖→阻遏占O→关闭；有乳糖形成别乳糖→使阻遏变构离O→解除负调。葡萄糖少→cAMP升→CAP复合物上位点→更强招募/活性；葡萄糖有→cAMP低→正调弱。因此乳糖解除只是许可，不保证大量表达。

| 乳糖 | 葡萄糖 | 两输入合成的结果 |
|---|---|---|
| 无 | 无 | 阻遏仍在，关闭 |
| 无 | 有 | 阻遏仍在，关闭 |
| 有 | 无 | 阻遏离、CAP强，大量 |
| 有 | 有 | 阻遏离、CAP弱，少量 |

若只撤去葡萄糖但没有乳糖，不能用CAP强来越过负调门；若只加入乳糖却仍有葡萄糖，也不能据开门推出强输出。




## trp分别控制起始许可与已起始链的提前终止

色氨酸操纵子为阻遏型、控制合成Trp的酶，结构识别R/P/O、前导及EDCBA。高Trp结合阻遏使其占O，粗调阻起始；衰减在已经起始的前导RNA上决定继续还是早停。

低Trp时已装载Trp的氨酰tRNA不足，核糖体在前导UGG停，RNA形成2–3抗终止发卡，3–4不能形成，继续转录；高Trp时前导翻译顺，形成3–4发卡加U尾而早终止。低Trp不是全部tRNA消失，也不是U序列被删除，是核糖体位置使互斥结构改变。此精调需原核转录/翻译同空间同步，不能直接套真核核内RNA。


## 真核把DNA元件、结合蛋白与基本机器接起来

顺式是与受调基因同一DNA分子的序列：II类核心TATA/Hogness，上游GC/CAAT；I/II/III类分别接对应RNApol/产物。增强子可跨位置/距离/方向提高效率，沉默子抑，绝缘子置于其与启动子间限制跨区。当前P157写增强子对启动子无严格专一性，是课程范围，仍须调节蛋白和启动子合作，不能外推任意增强子等强激活任意启动子。真核断裂基因及较独立入口接单顺反子，组织结构回G1。

反式因子是其他基因编码、可扩散的蛋白：DNA结合域可有锌指、亮氨酸拉链、螺旋—环—螺旋；激活域酸性/富Gln/富Pro，主要接蛋白—蛋白相互作用。通用因子助基本机器，特异因子决定时空；SP1接GC，C/EBP接CAAT，MyoD接肌细胞，HIF接缺氧。核受体具配体结合、DNA结合、激活三域，醛固酮接口调用既有内分泌。

正常氧时VHL介导HIF降解；缺氧降解减、HIF积累，结合EPO增强子、增转录。因而输入变化未必先增加基因转录，降低执行蛋白降解也能增强其下游转录，这是M1蛋白稳态在此的正式机制桥。



基本PIC按当前顺序TFIID→A→B→F–Pol II→E→H：D的TBP认TATA、TAF协助；A/B稳定；F带Pol II；E募H并稳开放单链；H有ATP酶、解旋酶、激酶，开DNA、磷酸化Pol II CTD，使其离启动子延长。TFIIF仍随延长，Mediator/TAF接增强子激活因子与机器。第一轮先理解D识别、H开启/放行，完整因子顺序保留供精记。


## RNA已经产出，仍可被压翻译或清除

加工、核输出、稳定性、RNAi、翻译效率调RNA阶段。长dsRNA经Dicer成21–23nt siRNA，再进RISC、引导完全互补靶RNA降解；内源miRNA经发夹前体、Dicer双链中间体、解链成熟引导RNA入RISC，完全互补可降解，不完全互补3′UTR可抑翻译。比较“mi单链/si双链”须说阶段：前体、中间体和执行链不能混作固定终身形态。

P160列piRNA、miRNA、siRNA，具体Dicer/RISC图展开mi/si，pi只识别，不无条件套前者；lncRNA只留>200nt识别，完整功能无当前支持。最后蛋白还可泛素—蛋白酶体清除。RNA层和蛋白层输出一起解释为何mRNA多不必然成品蛋白同幅增加。
