# 胃黏膜损伤：从防御失衡到急症与重建

> 胃里一直有酸，为什么有时只是炎症，有时形成深部溃疡，而治疗后又会出现新的结构性问题？

<a id="defense"></a>
## 先建立攻击、防御与损伤深度

正常胃黏膜面对胃酸与胃蛋白酶，依靠黏液、局部血流和修复维持屏障。胃炎以黏膜炎症为主；屏障受损而缺损偏浅时，可形成急性糜烂并出血；自身消化与攻击、防御长期失衡形成深部缺损，才进入消化性溃疡。溃疡可深达肌层、暴露黏膜下血管，因而能出血、穿孔、造成梗阻，少数胃溃疡还可癌变。损伤的深度解释后果，不能把所有消化道糜烂都叫消化性溃疡；GERD的食管糜烂仍有自己的身份。

三种急性入口分别拆解屏障。NSAIDs抑制COX-1，使前列腺素减少，黏液、血流和修复条件一起下降；应激时糖皮质激素促酸，又降低前列腺素、黏液和增殖，同时儿茶酚胺造成黏膜缺血；酒精可直接损伤。急性上腹不适、呕血或黑便把这条机制变成临床入口，急诊内镜既辨认糜烂出血，也能止血。精神因素可联系急性胃炎、IBS或十二指肠溃疡诱发，不能代替慢性胃炎的主要病因。

消化性溃疡在当前Study以十二指肠溃疡更多、男性较多，具有慢性、复发、季节周期与疼痛节律等特征；各年龄均可发生。酸提供消化攻击，HP参与屏障破坏，NSAIDs则说明HP并非唯一通道。“无HP便不会复发”的压缩说法不能抹去非HP溃疡。接下来要分别追踪长期炎症改变了哪些细胞、病原怎样维持损伤，以及缺损实际到达哪层。

<a id="remodel"></a>
## 慢性炎症改变细胞数量、身份与反馈

非萎缩性胃炎多在胃窦，黏膜浅层见淋巴细胞和浆细胞。萎缩性则是结构损失：黏膜薄而色浅，皱襞浅或减少，黏膜下血管显露，腺体变小、减少，胃小凹变浅或囊性扩张，伴淋巴、浆细胞浸润，久病可纤维化。出现中性粒细胞提示活动期；慢性炎细胞和活动期细胞回答不同的时间问题。

同样是萎缩，A型与B型的反馈链不同。A型自身免疫，抗壁细胞与内因子抗体阳性，胃体、胃底受损；酸明显下降乃至缺乏，负反馈减少使胃泌素升高，内因子不足使B12吸收受损，出现恶性/巨幼细胞贫血，也可缺铁。B型更常见，以HP、胃窦损伤为主，抗体阴性，酸正常或降低，G细胞受损使胃泌素降低，通常无A型的恶性贫血。当前Study治疗配对为A型糖皮质激素和注射B12，B型根除HP；酸都能降低并不意味着胃泌素也同向变化。

腺上皮可发生假幽门腺化生与肠上皮化生。完全型/小肠型有杯状、吸收、潘氏细胞；不完全型有杯状细胞，当前病理P2还明确分胃型Ⅱa与结肠型Ⅱb，后者连接肠型胃癌风险。化生改变身份，异型增生改变异常程度，不能把二者当同义词，也不能断言每个癌前病变都已有异型增生，肝硬化提供反例。当前Source先处理HP，可补维生素、硒等；药物不能逆转的局灶重度异型增生或原位癌才进入ESD与定期随访门槛。

<a id="hp"></a>
## 病原机制决定检测与根除后的复查

HP的鞭毛帮助穿过黏液到达上皮，尿素酶把尿素分解成氨，在局部中和酸，形成利于生存的微环境；氨、空泡毒素及细胞毒相关蛋白损伤组织，抗原引出持续免疫炎症。这条链可连接慢性胃炎、消化性溃疡、胃癌与胃淋巴瘤；多数急性胃炎、GERD、A型自身免疫胃炎不能直接归因于它。

检测必须区别活跃感染与既往接触。尿素呼气试验利用标记CO2，当前Study列为非侵入首选、金标准和复查方法；侵入性检查首选快速尿素酶试验；粪便抗原简便、准确。抗体可长期存在，所以阳性不能证明根除失败，阴性判读也要看方法。PPI抑制病原活性，会使呼气、尿素酶等检查假阴性，却不按同一机制清掉血清抗体；检测到的信号与想判断的病原状态必须对应。

治疗与确认疗效是两项任务。治疗中，PPI处理酸环境，铋剂连接黏膜保护，抗生素针对HP；当前四联框架是PPI、铋剂和两种抗生素。两药的具体搭配不能由候选药名自行推出，本Source没有在此提供组合选择算法。

复查要确认病原是否仍在，而不是只确认腹痛是否消失。先看治疗已结束多久，再看仍服什么药，最后看检测方法是否会被抑制：根除后至少4周复查，现有独立核对还保留PPI停用2周、抗生素/铋停用4周以减少假阴性的条件。根除与溃疡愈合的抑酸疗程可以重叠，也可先后安排；它们对应清除病原与降低攻击两种目标。

<a id="ulcer"></a>
## 位置与形态解释节律、修复和四类后果

胃溃疡偏中老年、胃窦小弯、餐后痛，防御下降更突出；十二指肠溃疡偏青壮年、球部前壁、饥饿或夜间痛，攻击及酸负荷增加更突出。当前HP率分别约60%–90%与超过90%；胃溃疡I/IV型酸正常或下降，II/III型稍升；十二指肠溃疡也只有一部分酸增加，不能用“DU”推出所有患者高酸，或推出防御完全正常。

典型良性胃溃疡圆或椭圆，多小于2cm，边界清楚如刀切，底较平坦，缺损深到肌层；贲门侧深、幽门侧浅形成阶梯，瘢痕牵拉使皱襞向病灶集中。由腔内向外是中性粒细胞/纤维素渗出、嗜酸性坏死、毛细血管和成纤维细胞组成的肉芽组织、瘢痕。瘢痕层增殖性闭塞性动脉内膜炎减少血供，一方面减少出血，一方面妨碍愈合。深部肌层不能简单再生复原，靠瘢痕填补；表面则再上皮化。

胃镜直接看本体，能活检、辨认出血、梗阻、癌变及残胃问题，也能止血，是首选/金标准。钡餐可见壁外龛影、皱襞集中，十二指肠球部可呈三叶草变形；穿孔或完全梗阻不能用这条检查通道。胃癌溃疡型的壁内龛影在下一章按整组证据鉴别。

出血是最常见并发症。胃溃疡好发、出血、穿孔均常联系小弯；DU球部前壁容易急性游离穿孔，后壁更联系出血和慢性穿透。胃溃疡癌变率低于1%，可始于边缘，DU几乎不癌变。位置还解释特殊型：II型为GU合DU、酸稍升、癌变低；IV型在胃底/体后壁，联系NSAIDs、背痛、不易幽门梗阻；III型幽门管症状最不典型且最易梗阻，也易出血、穿孔。球后溃疡在降部/水平部，有夜间痛、背痛、易出血和向胰腺穿透，可淀粉酶升高、重时梗阻性黄疸，却不易幽门梗阻。巨大溃疡大于2cm，偏老年/长期NSAIDs；儿童可脐周痛；Crohn、胃泌素瘤、放疗术后等难治病例药物反应差、手术易复发。它们通过部位、酸、后果重新接回同一模型。

<a id="bleeding"></a>
## 出血时先判断循环与是否仍在丢血

呕血、黑便和肠鸣音增多把病例引入上消化道出血，但外观还要结合速度、量与位置。咖啡样血表示血液与胃液接触，位置较高或速度快可出现鲜血。少量出血可能先由隐血检查发现，明显出血进入呕血或黑便的观察层，循环受损则进入头晕、休克的判断层。三种表现不是只按一个数字排列的必经过程，考试估量不能取代循环评估。

当前常见病因以消化性溃疡为首，门静脉高压曲张静脉破裂次之；后者的完整机制回肝病章节。

活动性出血需要证据组合：反复新鲜呕血或黑便频率、肠鸣继续增加；补液输血后循环未改善甚至恶化；Hb、红细胞、Hct继续下降；充分补液、尿量足够且排除肾病时BUN仍升高；胃管再次出现新鲜血。止血后黑便仍可持续约3天，因此单见黑便不能判继续出血。BUN的限定尤其关键，若缺少容量和肾功能前提，同一升高可有其他解释。

收缩压低于90mmHg首先支持循环，止血方案同时安排；初步复苏与安全条件具备后及时内镜，不能把时机改成等待全部数值正常。PPI提高局部pH、降低胃蛋白酶对血凝块的消化，也利于血小板聚集。当前内镜分层以活动动脉出血约90%、裸露血管约50%、血凝块25%–30%、无血迹低于5%的再出血风险分别对应PPI加内镜、PPI加内镜、PPI必要时内镜、PPI。

若内镜找不到病灶而仍疑动脉出血，选择性血管造影发现造影剂外溢可定位，并进入经导管栓塞；出血快、短期休克、内科处理无效，高龄伴动脉硬化或曾类似大出血时，Source另列手术探索与贯穿缝扎。复苏、找源与止血针对不同任务，但在同一时间窗口协作。

<a id="perforation-outlet"></a>
## 穿孔与出口梗阻是两种结构失效

游离穿孔让消化液进入腹膜腔，突发上腹刀割样痛迅速遍及全腹，压痛、反跳痛、肌紧张可呈板状腹，肠鸣音降低，肝浊音界缩小或消失。X线膈下新月形游离气体是首选影像入口；腹穿可得黄色浑浊、含胆汁和食物残渣液体。液体沿右结肠旁沟可使右下腹痛，不能脱离起病速度与最重部位改判阑尾炎；包裹可局限成块，发热、右上腹痛、呃逆提示膈下脓肿方向。慢性穿透偏后壁、背痛，可达胰腺使淀粉酶升高或入其他空腔形成瘘，CT帮助判断。

穿孔先禁食、补液、胃肠减压；饱餐后或弥漫腹膜炎按Source修补缝合，争取8小时内。超过8小时仍需处理，时间窗不是放弃治疗的门槛。这里把急性污染腹膜腔与慢性邻器官穿透分开，再用部位把它们联系回深部溃疡。

幽门梗阻则是胃内食物出不去：餐后很快痛、反复呕吐隔夜酸宿食而无胆汁，胃型、蠕动波、振水音来自蓄积和代偿运动。反复丢胃液连接低钾、低氯、碱中毒。先禁食、减压、补液及KCl，Source列平衡盐、5%葡萄糖盐水/生理盐水及高渗温盐水洗胃。减压后缓解偏痉挛或水肿，不缓解偏瘢痕性，可内镜扩张或胃大部切除；M受体拮抗剂降低运动会加重出口故障。术前抗生素槽有已核实的直接冲突：当前内科物理P108/印刷P89确写瘢痕性梗阻手术“术前用抗生素”；同一PDF物理P115的2016N082术前准备题把“应用广谱抗生素”列为选项A，但该原页答案栏写“无答案”；正式仓库题目与已批准解析确定不恰当项为A。两者都涉及术前，不能通过改成“一个是非术前”消掉冲突；本稿保留两条证据，不合成所有梗阻常规抗菌规则，单一正式口径仍需owner决定。

另一类需要改换目标的警报是既往GU疼痛失去节律、消瘦、贫血、持续隐血、酸缺乏，保守超过8周仍不愈。进入下一章胃癌取材链；溃疡缩小也不能证明良性，因为肿瘤可坏死缩小。

<a id="suppression-reconstruction"></a>
## 治疗减少攻击，重建则改变流向

PUD内科治疗三环是抑酸、根除HP、保护黏膜，以抑酸最重要。PPI为当前首选、最佳及维持入口，DU约4周、GU约6–8周；P-CAB与H2受体拮抗剂法莫替丁为其他接口。H2维持后复发者半数以上可没有腹痛，出血或穿孔仍可先出现，故“不痛”不能推导深部缺损消失。保护药中铋剂肾功能不全禁用，米索前列醇因子宫收缩孕妇禁用，另有铝制抗酸剂；当前NSAID预防配对保留PPI加米索前列醇。

需要胃大部切除时，切胃窦减少G细胞/胃泌素，切远端胃体减少壁细胞与主细胞，酸和胃蛋白酶一起下降，并包括幽门与部分球部。切断线按Source是小弯胃左动脉第一分支至大弯胃网膜左动脉最后分支连线；当前内科物理P109/印刷P90原图确实并列“大于2/3–3/4”和“约60%”，二者并不等价；原图可核对不代表能生成无歧义单值，正式数字取舍仍需owner决定。切掉产酸区解决攻击，随后还须恢复食物流向。

Billroth I把残胃接十二指肠，适合I型GU，较符合原生理、并发症较少，但吻合张力与复发较高。Billroth II关闭十二指肠残端，残胃接近端空肠，适合DU等，张力和复发较低、并发症更多；当前吻合口直径3–4cm，太大关联过快排空，太小关联排空障碍。十二指肠、胆汁流入的输入袢和食物前进的输出袢由此变成不同空间。

II式的四个名称只在这套结构下比较：Hoffmeister结肠后、输入袢对小弯、部分胃断端；Polya结肠后、小弯、全部断端；Moynihan结肠前、大弯、全部断端；Eiselsberg结肠前、小弯、部分断端。当前袢长结肠后6–8cm、前8–10cm。原图门禁仍保留；文字流向帮助理解，不能替代首次建立术后空间。

## 术后症状要按时间和流路重新解释

术后呕吐先区分运动失效与结构故障。早期胃瘫可含胆汁、无胃蠕动波，属于功能性运动障碍；保守处理的前提是这一功能诊断已经成立。机械梗阻、缺血或漏需要另查，不能因为看到胃瘫用药名单，就把所有术后呕吐都归到“不再手术”。当前Source只给出下列胃瘫用药例举，未在这里提供逐药选择条件。

术后出血当天偏止血不确切，一周偏吻合黏膜坏死脱落，一个月偏感染侵蚀血管；腔内出血肠鸣增多、内镜辨认，腹腔出血肠鸣减少、腹穿不凝血。胃肠壁缺血坏死与吻合口漏多一周内，十二指肠残端漏可1–2天突发上腹痛、腹膜炎和腹穿胆汁，需修补、造瘘、引流；若输入袢梗阻造成高压，还要解除它。

食物和胆汁是否能到呕吐出口，是区分四类梗阻的共同坐标。急性完全输入袢梗阻形成闭袢，频吐少量食物、无胆汁、吐后不缓解，易绞窄；慢性不完全输入袢仍有间隙，进食约半小时后可吐大量胆汁而无食物。输出袢梗阻可食物加胆汁；吻合口梗阻偏食物无胆汁。怀疑绞窄需手术，不能等腹膜炎完全形成才行动。吐后不缓解也需结合流路，而非只看胆汁有无。

远期过快排空有两个时间机制：进食后约30分钟早期倾倒偏血容量不足、低血压，可呕吐；2–4小时晚期偏餐后低血糖，无呕吐，Source列低糖高脂饮食与生长抑素。术后1–2年碱性反流性胃炎可反流、烧心、胆汁呕吐、消瘦，吐后痛不缓解且抑酸无效；II式结构让新胆汁持续反流，Roux-en-Y改变流向才能解释其治疗接口。吻合口溃疡偏2–3年，残胃癌超过5年；壁细胞和胃酸/内因子减少、排空及消化改变还联系缺铁、巨幼贫、体重减轻、脂肪泻与骨病。

由此回到中心问题：同一份呕血、腹痛或呕吐，可能来自浅层糜烂、深部血管/肌层缺损，也可能来自重建后的流路和运动。先定位损伤或结构，再看循环、污染、出口与远期营养，才能把检测与治疗配给正在失效的环节。
