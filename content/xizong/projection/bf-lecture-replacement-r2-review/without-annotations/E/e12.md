# 乳腺癌病理：先建立屏障，再辨形态与扩散

> 怎样把上皮增生、原位癌、浸润癌与临床皮肤征连成医学模型，同时保留各证据的职责？

<a id="risk"></a>
## 正常边界与增生风险是出发点

正常小叶/腺泡是分泌单位，导管是运输单位，外围肌上皮与基底膜把上皮和间质分开。泌乳时肌上皮提供动力，病理时其保留或缺失变成结构证据；浸润癌腺腔周围无肌上皮，是与硬化性腺病的鉴别接口。

普通型导管增生在Current Study呈流水样分布、细胞不单调一致；异型导管增生偏均匀分布、单一形态，进入癌前风险层。增生增加细胞，异型提高风险，二者都不能只凭名字完成浸润判定。

初潮早、绝经晚、晚育或不育延长雌激素暴露，肥胖连接绝经后外周芳香化，乳腺增生病变尤其异型导管增生也是风险线索。BRCA缺陷属遗传风险，外上象限属好发空间。风险、器官位置与屏障分别回答不同问题，任何一个都不能取代当下肿块的病理身份。

<a id="insitu"></a>
## 原位与浸润的差别是是否进入间质

原位癌已经有恶性上皮细胞，但仍在导管或小叶单位，外围肌上皮/基底膜尚未突破；浸润则进入间质。异型增生与原位癌比较恶性程度，原位与浸润比较屏障，两条轴必须分开。

导管原位癌DCIS，高级别在当前Study的两项特点是恶性程度高、核分裂象多；中央坏死形似粉刺，称粉刺癌。坏死并不把它自动改成浸润。小叶原位癌LCIS在当前Study核分裂少、癌变间期长，常双侧、多象限受累。

病理分类先分非浸润DCIS/LCIS，再分浸润非特殊型与特殊型；外科Study的原位名单另有粉刺/非粉刺与Paget入口，浸润特殊与非特殊名单也不完全相同。病理回答来源、屏障与形态，外科分类服务临床识别，保留两套职责。Paget在此仅有入口支持，不能为补名单扩写新病程。

<a id="morphology"></a>
## 浸润身份成立后，形态与预后还有条件

浸润癌非特殊型最常见，旧称浸润性导管癌，可呈细胞巢、边界不清、纤维间质多而质硬。浸润性小叶癌可由LCIS突破基底膜，细胞较一致、核分裂少，呈单行/串珠/细索，绕正常导管形成靶环或眼眶样。它还有脑脊液、浆膜表面、卵巢、子宫、骨髓等特殊转移出口，局部器官病灶不能都默认为当地原发。

特殊型的预后判断先看本Source实际给出的条件。髓样形态可有较清边界、癌细胞大、间质少、巢状结构及大量淋巴细胞；“髓样癌＋大量淋巴细胞浸润”才是当前Study列入较好预后的完整配对。删掉淋巴细胞条件，不能只凭髓样癌名称保留这一结论，也不在这里把相关性补成未给出的免疫机制。

炎性乳癌的另一组观察条件是弥漫皮肤红肿、可无明显肿块。它需要回到上一章与痛、寒战高热、WBC升高、痛性淋巴结等感染证据比较，不能由“红”字直接定炎症；Current Study列其预后最差，外科Source给化疗、放疗方向。先把这两个有观察条件的例子读清，再将其他特殊型保留为预后识别支持。

| 当前病理Study预后方向 | 完整特殊型名单支持 |
|---|---|
| 较好 | 小管癌／高分化腺癌 |
| 较好，必须保留限定 | 有大量淋巴细胞浸润的髓样癌 |
| 较好 | 黏液癌 |
| 较好 | 分泌性癌 |
| 较好 | 实性乳头状癌等 |
| 较差 | 浸润性微乳头状癌 |
| 较差 | 富于脂质性癌 |
| 较差 | 高级别化生性癌等 |
| 最差 | 炎性乳癌 |

其余类型在此只有名单级预后支持，不补各自预后原因。形态谱系和分子亚型是不同坐标，不从特殊形态自动推出ER/HER2。

<a id="spread"></a>
## 皮肤故障和两种扩散路线各自定位

癌侵犯Cooper/乳房悬韧带→韧带收缩牵拉皮肤→酒窝征；阻塞真皮淋巴管→回流受阻、水肿→橘皮样变。一个是局部牵拉，一个是淋巴水肿。炎症也可有类似外观，最终身份需病理和完整临床证据。

淋巴转移最早最常见，首先同侧腋窝，下一章用N表达范围，再在治疗章处理腋窝。血道转移可早期发生，常见骨、肺、肝、肾上腺、脑，并可经椎旁静脉到骨；不能把“常先淋巴”变成“早期绝不血行”。

完整重建沿导管/小叶来源→肌上皮/基底膜→非特殊/特殊形态→皮肤、区域或远处扩散，最后把ER/HER2交给诊断与治疗owner。当前章负责病理身份和扩散机制，不重复临床TNM表。
