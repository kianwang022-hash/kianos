# 增殖与成熟脱钩，怎样形成急性白血病

中心问题是：为什么白细胞可以很高，患者却感染、贫血和出血？克隆获得增殖/生存优势，同时分化被早期截断，原始细胞占骨髓却无法承担成熟功能。辐射、苯及部分化疗药、HTLV/免疫异常、Down/Fanconi/Bloom/共济失调毛细血管扩张等是当前入口，MDS、NHL、MM、PNH可作前病。急慢的名称首先按分化停在早期还是较晚阶段，不按发病天数；AML/CML/ALL/CLL是两轴坐标，儿童最常见ALL。



## 同一占位产生三系失败与不同的浸润出口

正常红系少造成贫血，正常粒细胞少造成感染，板少及凝血/血管损伤造成出血；APL易DIC需即时识别。胸骨压痛来自活跃造血区浸润，肝脾多轻中度，巨脾更支持CML。M2绿色瘤常眼眶，M4/5牙龈增生与蓝紫皮结反映单核浸润；牙龈出血则属血小板失败，不能与增生混同。无痛结优先想淋巴瘤，也要排ALL/CLL、部分AML；T系可纵隔胸腺块，CML几乎无结。



血象通常Hb/RBC/Ret低、正细胞、Plt低，WBC常高但可正常或低，涂片甚至不易见原始。当前WBC>10×10⁹/L为增多型，<1为不增多型；数高不等于正常防御强。骨穿细胞学是当前首选，多数活跃也有低增生型，FAB≥30%与WHO≥20%分别保留其历史门槛。



## 分型要让形态、功能、表型与遗传各回答自己的问题

### FAB先问系别，再问分化停在哪一阶段

确认急性门槛后，形态分型继续问原始细胞属于哪一系、是否已有一定分化，随后用细胞化学、流式及遗传确认。ALL的旧FAB以大小和空泡区分L1、L2、L3；大小这个读数不能直接等于成熟程度。

| ALL的FAB | 当前形态接口 |
|---|---|
| L1 | ≤12 μm的小细胞 |
| L2 | >12 μm的大细胞 |
| L3 | 大细胞加明显空泡 |

AML的M1与M2都在粒系内比较，前者以未分化的原粒为主，后者已有部分分化；M3则把停滞位置放在早幼粒。M4看粒和单两系，M5看单核为主，M6和M7再分别接红系与巨核系证据。先理解这些分类在问什么，下面的比例才是对同一问题的精确限定。

| AML的FAB | 当前表的精确接口 |
|---|---|
| M0微分化 | 原始>30%，CD13/33阳性，无Auer |
| M1急粒未分化 | 原粒≥90%非红系有核细胞NEC |
| M2急粒部分分化 | 原粒30%–89%NEC |
| M3早幼粒 | 早幼≥30%NEC |
| M4粒—单 | 原始≥30%，粒与单各≥20%；嗜酸≥5%为M4Eo |
| M5单核 | 原/幼单≥30%，单核各期≥80% |
| M6红白血病 | 原始≥30%NEC，加幼红≥50% |
| M7巨核 | 原巨核≥30%，加血小板抗原 |

NEC是非红系有核细胞的分母口径，具体分母和细胞图仍须回Source表校准。P213总结将“原始>30%且无Auer”称M1，而正式P210表归M0，是H9-SC01；这里沿用已采纳的表格主路径，同时保留冲突，不能以常识消掉总结句。



真Auer支持髓系，成堆强提示APL；ALL和M0阴性，所以没有Auer不等于ALL，MM的Auer样只是相似结构。细胞化学MPO找粒、M3强阳而极差分化可阴；NSE加NaF抑制≥50%找单；ALL的PAS成块/粗粒而MPO/NSE阴。酶帮助识别功能来源，不能替代克隆定性。

“AML多阳”的精度单独保留：原内科PDF P257（印刷P211）写AML除M0外可阳性，没有提供阳性率，也没有保证每例可见。因此当前可回答支持髓系及ALL/M0反例，不能把“可阳性”改写为有已核比例的多数阳性；这一量词仍须正式Prompt/Source裁决。



流式用组合：B常CD10/19/20/79a；T常CD1/2/3/4/5/7/8/10；NK16/56；前体TdT、干祖CD34。单个CD10不能独断B或T。M3为13/33/117/9而34与HLA-DR阴，M4/5抓14，M6血型糖蛋白，M7板糖蛋白及41/61。遗传再精确定性：M2 t(8;21)-RUNX1/RUNX1T1，M3 t(15;17)-PML/RARA，M4 t(16;16)-CBFB/MYH11及M4Eo inv16为当前良好轴；急性病中的t(9;22)-BCR/ABL、t(6;9)、11q23、-5/5q-与-7为不良，Ph在CML却是诊断和靶点。



把上述证据同时收敛到早幼为主、颗粒多、成堆Auer、强MPO、34/DR阴、PML-RARA和DIC，才建立APL特殊模型，而不只背M3一行。NAP也是辅助：急粒/CML慢性低，急淋、再障、CML急变、细菌感染或类白反应高；类白反应有毒性粒改变、RBC/Plt相对保留、去因恢复及无特征染色体。NAP一个高低不能代替全链。



## 当前危险来自堵塞、消耗和裂解三个方向

WBC>100×10⁹/L可淤滞脑肺，颅内出血、言语异常、气促低氧提示微循环堵塞；当前接紧急白细胞单采，但M3不推荐，先不立即输红以免增黏。细胞大量裂解释放核酸、嘌呤成尿酸堵肾，Source防治为24小时持续补液、碱尿、化疗同时别嘌呤醇，少无尿及肾衰回AKI接口。感染也须与肿瘤数高分开，G-CSF当前给ALL、老年强化及AML伴感染。

脑警报的第三个例子需要分清来源：讲义P257明确颅内出血与言语不清两项；[City of Hope的AML原发教学资料](https://www.cityofhope.org/conditions-cancer-types/acute-myeloid-leukemia/symptoms)另明确列淤滞可头痛。于是这里以头痛补一个有据的神经警报例，但不声称它是原讲义未写出的固定第三项。脑表现可属出血或缺血/低氧等危险，言语异常、头痛本身不能独断其机制；也不与缓解期CNS庇护所混为同一过程。

当前 Source 讨论 AML 时常默认急粒 M1–M3，本身已有粒系异常增殖，这是不能机械给全部 AML 的理由；这里保留该考试口径，不扩现代适应证。



### APL的分化轴决定特异治疗，也带来分化综合征

治疗选择要接回已经确定的生物学。APL的PML-RARA身份给出特异作用接口：当前讲义中ATRA作用于RARA分化轴，ATO（三氧化二砷）作用于PML接口。当前方案为ATRA+ATO+蒽环类，缓解后上述药物交替维持。

分化治疗可以释放细胞因子，所以在初诊WBC较高或治疗后迅速升高时，要同时警惕分化综合征。发热、低压、胸/心包积液、体重增加、肌骨痛、呼吸窘迫和急性肾衰是当前列出的表现；它们把治疗后的变化重新送回全身及器官危险判断。Source处置保留暂停ATRA、GC、吸氧和利尿等支持。



### 非M3 AML先处理高白和裂解负荷，再进入联合方案

非M3 AML化疗前先用羟基脲、水化作短期预处理。这个阶段接着前述高白细胞危险，也接细胞大量破坏后的高尿酸负荷；随后才进入当前联合化疗方案。

| 简称 | 当前非M3 AML组合 |
|---|---|
| IA | 伊达比星+阿糖胞苷Ara-C |
| DA | 柔红霉素+阿糖胞苷Ara-C |
| HA | 高三尖杉酯碱+阿糖胞苷Ara-C |

高三尖杉酯碱只用于AML，是当前Source的区分点；本段不增加不同组合之间的选择标准。



### ALL的组合从长春新碱和激素向外扩展

ALL化疗前先用地塞米松、水化。当前主方案以长春新碱加泼尼松为基础，DVP在此基础加柔红霉素，DVLP再加入左旋门冬酰胺酶。这样读简称是读取组合的扩展关系，不是把三个名字当成三个互不相关的治疗。

| 简称 | 当前ALL组合 |
|---|---|
| VP | 长春新碱+泼尼松 |
| DVP | 柔红霉素+长春新碱+泼尼松 |
| DVLP | 柔红霉素+长春新碱+左旋门冬酰胺酶+泼尼松 |

左旋门冬酰胺酶只用于ALL，是当前Source的区分点。完整序贯、剂量与个体方案选择仍不由本段补齐；髓外庇护所则继续进入下面的CNS及睾丸问题。



## 缓解需要多层成立，残留不等于消失

CNS和睾丸屏障可留下庇护所，解释ALL缓解期仍复发：CNS最常见髓外，头痛呕吐颈强、CSF幼稚，当前首选鞘内MTX可加Ara-C/GC，发生后照射为挽救；睾丸次常见，幼儿青年无痛肿大、可双侧，当前双侧局部放疗。CR要求症状体征无、髓外无、外周原始无、ANC>1、Plt≥100×10⁹/L、三系恢复且髓原始<5%。发病约10¹⁰–10¹²细胞，CR仍可10⁸–10⁹，MRD监测接复发；整体最常复发骨髓，髓外最常CNS，故外周数正常远不足等于清除。



药物毒性再挂回器官：柔红与高三尖杉接心，长春新碱接末梢神经/便秘，CTX接脱发肝/出血性膀胱炎/髓及性腺，L-ASP接肝胰过敏，Ara-C接小脑，MTX接黏膜肝肾。陌生病例按正常造血失败→骨髓急性门槛→系别与成熟→化学/流式→遗传→DIC/淤滞/尿酸/感染→特异方案→CR/MRD，才能避免从一个WBC、Auer或CD直接跳结论。
