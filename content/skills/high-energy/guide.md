# 高精力自我调节｜总览

这套 Skill 解决的不是“怎么一直精神”，而是：

> **让高质量可用精力更稳定地出现；下降时知道问题在哪一层、该调什么、怎么验证，并逐渐形成自己的操作模型。**

---

## 1｜先看整张地图

High Energy 不是一个问题，而是 5 个时间/决策层级：

| 层级 | 核心问题 | owning Unit |
| --- | --- | --- |
| **此刻 · 判断** | 我现在为什么掉状态？ | U1 状态诊断 |
| **此刻 · 调节** | 现在第一步做什么？ | U2 瞬时恢复 |
| **今天** | 今天高认知任务放哪里？ | U3 日内配置 |
| **这一周** | 这是局部波动还是累积失配？ | U4 周尺度恢复 |
| **长期** | 怎么让好状态越来越像默认？ | U5 长期底盘 |

横穿所有 Unit 的两条线：

- **个人校准**：通用模型 → 你的个人先验；
- **医疗升级边界**：什么时候停止把问题当作生产力优化，进入医疗评估。

---

## 2｜母模型

```text
可用精力 / 认知效率

≈ 睡眠与昼夜节律
× 当前认知负荷
× 注意与唤醒状态
× 身体 / 基础生理状态
× 环境
× 健康状态
```

这不是生理学公式，只是在提醒：

> **相同的“低效率”表象，可能来自不同限制因素；不同层级的问题，也需要不同层级的动作。**

因此：

| 常见表象 | 不能直接推出 |
| --- | --- |
| 不想学 | 累了 |
| 下午效率低 | 一定缺觉 |
| 走神 | 意志力差 |
| 咖啡后精神好 | 已恢复 |
| 休息后舒服 | 高认知表现已恢复 |
| 连续几天都差 | 只是今天状态不好 |

---

## 3｜U1–U5 各自只解决一个决定

### U1｜状态诊断

把“我状态不好”拆成更有信息量的判断：真实困倦、认知疲劳、注意碎片化、启动阻力、压力过高、身体 / 环境 / 健康因素等。

输出不是诊断标签，而是：

```text
最可能
+ 决定性证据
+ 不确定
+ 第一验证动作
```

### U2｜瞬时恢复

把动作从“习惯”改成“匹配当前最大限制因素”。

核心规则：

```text
匹配问题 → 动作尽量小 → 低风险可撤回 → 回到真实任务验证
```

### U3｜日内配置

把任务认知需求和真实容量窗口匹配，而不是迷信固定钟点。

### U4｜周尺度恢复

把单次波动和累积失配分开；普通恢复解释不了时扩大层级或升级医疗边界。

### U5｜长期底盘

优化高杠杆底盘：睡眠、规律活动、饮食 / 普通补水、咖啡因边界、环境和健康边界；稳定后停止优化。

---

## 4｜两个贯穿全 Skill 的硬规则

### 规则 A｜刺激 ≠ 恢复

咖啡、强刺激、短暂兴奋可以改变 警觉性，但不能自动证明限制因素被修复。

### 规则 B｜感觉好一点 ≠ 功能已经回来

任何恢复 / 调整最终都要看真实表现：

```text
采取动作
→ 回到真实任务
→ 看真实表现
→ 更新判断
```

---

## 5｜你不是一次把整套 Skill 背下来

每个 Unit 都按同一认知层级走：

```text
展开学习
→ 主动重建
→ 应用 / 区分
→ 受保护验证
→ 压缩候选
→ 换情境迁移
→ 真实调用
→ 个人校准
```

失败时只修最小对象，然后回到原路径。

压缩不是课后总结；它是**学过、重建过、验证过以后，把展开模型压成未来真正调用的操作模型**。

---

## 6｜医疗边界

这套能力用于自我调节，不是疾病诊断系统。

持续、异常、影响日常生活、普通睡眠/恢复调整解释不了的疲劳，或伴随新的明显症状时，不继续无限优化 生产力技巧。

---

## 7｜现在从哪里开始

```text
总览
→ U1 展开学习
→ U1 主动重建
→ U1 独立验证
→ 证据判定
→ U1 压缩 / 迁移 / 真实调用
```

只有 U1 真正形成能力，才需要继续 U2。
