# 高精力自我调节｜总览

这套 Skill 不训练“疲劳分类学”。

> **真正目标：掉状态时更快恢复；平时不断提高容量与任务效率，让同样负荷越来越不容易把你打下来。**

## 1｜母模型

~~~text
真实可用表现
≈ 当前容量
+ 任务效率
- 综合负荷
~~~

这不是生理学公式，只用于决策。

综合负荷通常是混合的：
- **恢复债**：缺觉、节律紊乱、连续恢复不足；
- **认知负荷**：长时间高强度思考、持续专注、频繁切换；
- **精神负荷**：压力、担忧、持续紧绷、情绪占用；
- **身体负荷**：训练、体力活动、久坐不适和普通身体状态。

现实完全可以是：

> **困 + 脑子转不动 + 不清新。**

这不是分类失败，而是**综合掉状态**。

只有一个区分会改变下一步动作时，才继续细分。

## 2｜先看掉状态的广度和深度

### 局部掉状态
一项功能明显出问题，但整体容量还在，例如注意碎片、启动阻力、久坐后低唤醒。小 reset 可能够。

### 综合掉状态
多个维度一起下降：困、加工变慢、重读增加、不清新、注意下降、压力或身体疲劳叠加。不要反复拿 3–5 分钟小休糊弄，需要一次真正恢复。

### 系统性低状态
足量恢复仍拉不回来，或者一天 / 多天反复塌。扩大到日 / 周负荷与恢复。

## 3｜恢复效率：不是越短越好

~~~text
恢复效率
≈ 恢复的真实功能
÷ 时间成本 + 后续代价
~~~

目标是**最小充分恢复剂量**。

5 分钟休息失败后又低质量硬撑 25 分钟，常常不如一次真正足量恢复高效。

## 4｜高收益动作族

| 当前主要表现 | 第一方向 | 不够时怎么升级 |
| --- | --- | --- |
| 明显困 / 睡眠不足 | 创造真实睡眠机会 / nap | 保护夜间睡眠；降低高认知要求 |
| 脑钝、不清新、认知饱和 | 停同类输入 + 5–10 min 走动 | 再接 10–20 min 真正低输入休息 |
| 精神紧、脑内停不下来 | 慢呼吸 / 脱离压力 cue / 写下下一步 | 更长解压或暂时降任务负荷 |
| 注意碎片 | 去掉竞争刺激 | 单任务重启 |
| 久坐 / 低唤醒 / 身体发钝 | 活动、环境 / 光线 / 姿势修正 | 继续查具体身体限制 |
| 综合掉状态 | 一项激活 + 真正低输入恢复 | 困明显就优先睡；仍拉不回就降档 |

这些时长是起始实验值，不是固定处方。

## 5｜恢复必须用真实任务验收

~~~text
状态下降
→ 恢复
→ 回原任务
→ 功能回来了？
   ├─ 是 → 结束恢复
   └─ 否 → 升级恢复 / 降档 / 扩大时间尺度
~~~

看启动、持续、加工速度、重读 / 推理断裂、准确性和异常主观成本。

**舒服 ≠ 恢复。**

## 6｜更重要：不断把容量做大

### 生理容量
睡眠、有氧、力量、日常活动、足够基础供给和健康边界。

### 认知耐受
逐渐增加高质量认知负荷，但只有表现稳定、普通恢复有效、后续与第二天没有明显恶化才算“练到了”。

一次只增加时长、难度、连续性中的一个。

### 调节能力
让压力、反刍、分心少吃掉可用控制。慢呼吸、mindfulness 可以训练这一层，但不是睡眠替代品。

### 任务效率
知识、结构和自动化提升后，同样任务会更省认知资源。

> **把任务学熟，本身就是有效容量增加。**

直接 Brain Endurance Training 目前证据仍较早期，不作为默认方案。

## 7｜真正值得越来越好的 5 个东西

~~~text
drop latency       多久才开始明显掉状态
recovery latency   掉下来以后多久能回来
rebound quality    回来以后真实功能恢复多少
downstream cost    恢复 / 刺激有没有伤害后续和第二天
rescue frequency   需要紧急救火的次数有没有越来越少
~~~

不是做成分数，只用来判断：**我是不是真的越来越强。**

## 8｜五个 Unit 的角色

| Unit | 真正解决的问题 |
| --- | --- |
| U1 | 这是局部掉状态还是综合 / 系统性下降？ |
| U2 | 现在怎样用最小充分剂量恢复？ |
| U3 | 怎么把高价值任务放在高容量窗口？ |
| U4 | 是否已经从一次波动变成反复救火 / 多日失配？ |
| U5 | 怎样提高生理容量、认知耐受、调节能力和任务效率？ |

分类永远服务于动作。

## 9｜医疗边界

持续、异常、越来越重、影响日常生活，或合理睡眠 / 恢复调整仍解释不了的疲劳，不继续无限做生产力优化。
