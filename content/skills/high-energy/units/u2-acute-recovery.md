# U2｜高效恢复：用最小充分剂量把真实功能拉回来

> **现在做什么，能以最低总成本恢复最多真实功能？**

不是休息越短越好，而是恢复要够用。

## 1｜黄金动作族

| 当前主要表现 | 第一动作 | 起始剂量 | 不够怎么办 |
| --- | --- | --- | --- |
| 明显困 / 睡眠不足 | 睡眠机会 / nap | 现实可行的短睡窗口 | 仍困就保护夜间睡眠 / 降档 |
| 脑钝、不清新、认知饱和 | 停同类输入 + 走动 | 约 5–10 min | 再接约 10–20 min 低输入休息 |
| 精神紧 / 脑内停不下来 | 慢呼吸 / 脱离压力 cue / 写下下一步 | 约 5 min first probe | 更长解压或降任务负荷 |
| 注意碎片 | 去掉通知 / 手机 / 多窗口 | 立即 | 单任务重启 |
| 久坐 / 低唤醒 / 身体发钝 | 活动、姿势、光线 / 环境修正 | 约 5–10 min | 找具体身体限制 |
| 综合掉状态 | 激活 reset + 低输入恢复 | 约 15–25 min 常见起点 | 困明显优先睡；仍拉不回就降档 |

时长只是起始实验值，不是固定处方。

## 2｜最小充分剂量

如果 5 分钟休息无效，又低质量硬撑 25 分钟再休，可能比一次真正 15–25 分钟恢复更浪费。

> **第一小剂量无效，就升级一次；不要无限重复同级小休。**

## 3｜工具真正解决什么

- **短睡**：明显 sleepiness / 睡眠不足背景。
- **走路 / 活动**：低唤醒、久坐、轻中度脑钝；不能补回睡眠。
- **低输入休息**：持续高认知输入后的 saturation；核心是停止处理新信息。
- **慢呼吸 / mindfulness**：压力、过度唤醒、反刍和精神噪声；不是万能恢复。
- **咖啡因**：alertness 工具；价值必须扣掉后续睡眠成本。

## 4｜组合恢复

现实常是混合问题。

例如困 + 脑钝 + 不清新：

~~~text
短暂走动
→ 低输入 / 闭眼
→ 困很明显则升级为睡眠
→ 回任务验证
~~~

组合只用当前最可能互补的 1–2 个动作。

## 5｜验收

回真实任务，看启动、持续、加工、重读 / 推理断裂、准确性和异常费力程度。

~~~text
功能回来 → 结束恢复
只舒服、功能没回来 → 不算恢复
仍明显不行 → 升级恢复 / 降任务强度 / 扩大时间尺度
~~~

真正能力：

> **知道什么时候小 reset 就够，什么时候必须真正恢复，以及什么时候已经不值得继续救火。**
