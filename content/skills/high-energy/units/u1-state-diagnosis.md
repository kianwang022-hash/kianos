# U1｜状态诊断：为什么我现在低能量 / 低效率？

这一单元只解决一件事：

> **低效率出现时，先判断最可能缺的是哪一种资源，再谈恢复。**

如果判断错了：

| 真实问题 | 常见误处理 |
| --- | --- |
| 真困 | 去刷刺激 |
| 启动困难 | 一直休息 |
| 压力过高 | 继续硬顶 |
| 注意力碎片化 | 去睡觉 |
| 认知饱和 | 靠咖啡继续堆负荷 |

所以 U1 的目标不是“知道更多”，而是形成第一层**状态区分能力**。

---

## 1｜三个最容易混淆的词

| 状态 | 核心 | 典型信号 | 最重要的判别点 |
| --- | --- | --- | --- |
| **Sleepiness｜困倦** | 睡眠倾向上升 | 想睡、警觉掉、眼皮重、打哈欠、注意直接断线 | 它不是“我不喜欢这个任务” |
| **Fatigue｜疲劳** | 一个过宽的总称 | 可能包含 mental / physical / illness-related / stress-related fatigue | “我累了”几乎没有诊断价值；必须继续问**哪种功能在什么背景下下降** |
| **Low motivation / resistance｜动力低 / 抗拒** | 不想开始 | 主观上很抗拒，但开始后可能完全正常 | **开始以后，能力是否恢复？** |

> **不想做 ≠ 做不到。**

---

## 2｜判断质量来自 pattern，不来自单一感觉

单个感觉通常信息量很低。

真正有用的判断至少同时看四类信息：

```text
发生前的背景
+ 当下主观感觉
+ 哪一类表现下降
+ 换情境后是否仍存在
```

### 一个状态判断至少回答

| 维度 | 要问什么 |
| --- | --- |
| **背景** | 发生之前做了什么？睡眠、连续高负荷、压力、环境怎样？ |
| **感觉** | 是困、烦、抗拒、紧张，还是只是脑子转不动？ |
| **表现** | 哪种能力实际下降：警觉、理解、推理、持续注意、启动？ |
| **跨情境** | 换任务、去掉刺激、降低认知负荷以后，它还在吗？ |

第一原则：

> **用 pattern 判断，不用一个感觉贴标签。**

---

## 3｜六个主要判断模式

| Pattern | 典型背景 | 更支持它的信号 | 关键反证 / 判别测试 |
| --- | --- | --- | --- |
| **A · 睡眠相关** | 最近明显少睡或作息紊乱 | 多个任务警觉下降、强烈睡意、停下来就想睡、错误像注意掉线 | 完全不困；只有一个讨厌任务不想做；换成喜欢的高认知任务立刻正常 |
| **B · 认知饱和** | 持续高认知负荷之后 | 加工变慢、重读增加、推理链断、选择困难、脑子不想再转，但未必想睡 | 低认知活动仍正常，是很有信息量的信号 |
| **C · 注意碎片化** | 刺激源持续竞争注意 | 无意识切窗口、想拿手机、刚看两行就跳出去、主任务思路被截断 | **移除刺激后，能力是否很快回来？** |
| **D · 启动阻力 / 低唤醒** | 开始前主观非常不想做 | 一旦真正开始，阅读速度、正确率、逻辑逐渐正常 | **进入一个短真实任务块后，功能是否恢复？** |
| **E · 压力 / 过度唤醒** | 紧张、担忧、结果导向明显 | 烦躁、思维反复跳回结果、身体激活、工作记忆难稳定在当前信息 | 有能量，但能量没有有效用于当前任务 |
| **F · 身体 / 环境 / 健康限制** | 久坐、训练、饮食、环境或身体不适 | 僵硬、训练疲劳、饿、饭后过重、闷热、噪声、疼痛等 | 先排普通可逆因素；异常、持续、不符合平时模式时进入健康 / 医疗边界 |

---

## 4｜两个最重要的边界

### 边界 A｜困倦 vs 认知疲劳

| | **困倦** | **认知疲劳** |
| --- | --- | --- |
| 主观核心 | “我需要睡。” | “我不想再继续高负荷认知。” |
| 睡意 | 常明显 | 可以不明显 |
| 典型背景 | 睡眠不足 / 节律因素 | 明确 time-on-task、高认知负荷 |
| 跨任务表现 | 多个活动都费劲 | 低认知活动可能仍正常 |
| 最有信息量的问题 | 我是真的想睡吗？ | 换低负荷活动会不会明显轻松？ |

两者可以同时存在，但**不是同一个东西**。

### 边界 B｜抗拒 vs 容量不足

| | **抗拒 / 启动阻力** | **容量不足** |
| --- | --- | --- |
| 开始前 | 非常不想做 | 可能也不想做 |
| 开始以后 | 功能逐渐正常 | 真实表现仍维持不住 |
| 判断重点 | 不要相信开始前的感受 | 看实际任务表现 |

> **开始前的感觉不是能力测试。**

---

## 5｜最小判断流程

现实里不需要跑完整问卷。第一次可以压缩成：

```text
1. 我是真的困吗？
   ├─ 是 → 先看睡眠相关
   └─ 否
        ↓
2. 是不是连续高负荷以后才掉？
   ├─ 是 → 先看认知饱和
   └─ 否
        ↓
3. 去掉刺激 / 真正开始以后，功能会回来吗？
   ├─ 会 → 注意碎片化 / 启动阻力
   └─ 不会
        ↓
4. 有没有明显压力、身体、环境或健康因素？
```

这不是临床诊断树，只是把“我今天不行”拆成更有信息量的第一层判断。

---

## 6｜现实判断的最小输出

脑内只需要五行：

```text
最可能：
为什么：
还不确定：
先试：
如何验证：
```

例如：

> **最可能：**认知饱和。  
> **为什么：**连续高负荷两小时后出现，不困，但反复重读。  
> **还不确定：**注意碎片化可能也有一点。  
> **先试：**低输入离屏休息或走动。  
> **如何验证：**回来做下一段真实学习，看持续性是否恢复。

优先选：

> **低成本、可逆、信息量高的第一步。**

恢复动作本身不是结论；下一段真实任务才是验证。

---

## 7｜U1 的停止线

### 不需要学这些

- 所有疲劳神经机制；
- 腺苷、皮质醇完整通路；
- 研究效应量；
- recovery score；
- 每一种医学性疲劳的精确分类。

### 这一单元只要求

> **足够好的第一层状态区分能力。**

如果你能在真实场景里说出：

```text
最可能是什么
+ 最有决定性的证据
+ 还有什么不确定
+ 先做什么低风险测试
+ 怎么用下一段表现验证
```

U1 就已经开始变成能力，而不是知识。

## 8｜进入 Verify 前的自检

不看前文，大致能回答即可：

| 问题 | 你应该能抓到的核心 |
| --- | --- |
| 为什么“低效率”不能直接等于“缺觉”？ | 同一表象可能来自不同限制因素 |
| 困倦和认知疲劳最关键的区别？ | 睡意 + time-on-task + 跨任务表现 |
| 怎么区分启动阻力和容量不足？ | 开始以后功能能否恢复 |
| 为什么注意碎片化不一定需要更多休息？ | 问题可能是控制权被刺激竞争，不是容量耗尽 |
| 为什么恢复动作需要 回到真实任务验证？ | 感觉舒服不等于真实表现恢复 |
| 什么时候停止把疲劳当生产力问题？ | 异常、持续、不符合平时模式或伴随明显身体症状 |

如果其中两三个还模糊，只回到对应小节，不用重新读整页，也不用背原句。
