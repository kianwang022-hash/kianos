# High Energy Learning Design

Status: CURRENT INTERNAL LEARNING OWNER  
Role: U1–U5 的最小学习设计与 Chat Evidence 判定边界。  
Learner-facing 内容由 manifest 引用的 Guide / Unit / Verify / Compression / Transfer 资产承担；本页不作为额外课程展示。

## Shared rule

所有 Unit 都遵守：

    展开学习
    → 主动重建
    → 独立验证
    → 失败时只修最小对象
    → 压缩成可调用模型
    → 换情境迁移
    → 真实使用
    → 有重复证据时才个人校准

Direct Verify 默认 NATIVE：先看 Kian 自己能否完成判断。  
真实使用允许 TOOL_ALLOWED；工具能减少执行摩擦，但不能替代需要验证的原生判断。  
出现医疗升级边界时，能力目标变成“知道停止自我优化并求助”，不是继续自我诊断。

## U1｜状态诊断

- **Target**：从混合信号中形成最可能解释，指出决定性证据、主要备选和第一验证动作。
- **Baseline gate**：SOFT。只有在不消耗受保护 Verify 的前提下，简短现实例子才有信息价值。
- **Practice geometry**：对比场景、冲突线索、反例、主次假设。- **Direct demonstration PASS**：不是只报标签；能解释为什么当前证据支持这个判断、什么证据会推翻它，并守住医疗边界。
- **Smallest repair objects**：困倦 vs 认知疲劳；启动阻力 vs 容量不足；注意碎片化；压力过高；医疗升级边界。
- **Compression target**：4 个判断入口 + 5 行最小输出。
- **Transfer target**：混合原因、表象相同但原因不同、主观恢复与功能恢复冲突。
- **Real use**：真实掉状态时至少一次完成“判断 → 第一验证动作 → 回任务看结果”。
- **Maintenance**：EVIDENCE_GATED。

## U2｜瞬时恢复

- **Target**：在 U1 判断基础上选择最小、匹配、可逆的第一动作，并用真实任务验证。
- **Baseline gate**：SKIP。若没有状态判断，直接测“恢复技巧”主要测偏好，不测目标能力。
- **Practice geometry**：同一状态下比较多个动作；同一工具在不同状态下改变价值。
- **Direct demonstration PASS**：动作匹配限制因素；能说明刻意不先做什么；不会把刺激当恢复；给出清楚的回任务验证信号。
- **Smallest repair objects**：状态-动作匹配；工具真正改变什么；刺激 vs 恢复；回任务验证。
- **Compression target**：第一动作路由器 + “匹配 / 小 / 可逆 / 验证”。
- **Transfer target**：工具冲突、第一动作无效、现实约束下只能应急维持。
- **Real use**：一次真实状态下降后，第一动作产生可解释结果；无效也算有价值证据，只要能更新判断。
- **Maintenance**：EVIDENCE_GATED。

## U3｜日内精力配置

- **Target**：把任务认知需求和真实容量窗口匹配，并在现实变化后动态重排。
- **Baseline gate**：SOFT。Kian 已有真实日程经验时，一个短日程重排可暴露直觉偏差；不需要单独消耗新材料。- **Practice geometry**：任务需求分层、容量变化、截止期、睡眠成本和临时占用共同出现。
- **Direct demonstration PASS**：优先保护高价值高认知工作；不会用固定钟点代替真实容量；现实变化后能说明“什么先保、什么先让”。
- **Smallest repair objects**：任务需求分类；容量窗口；高容量机会成本；后续代价；动态重排。
- **Compression target**：任务需求 × 当前容量 × 时段模式 × 后续代价。
- **Transfer target**：个人高容量窗口改变、任务需求升级、今晚可做但会损害明天。
- **Real use**：真实一天发生变化时，完成一次重排并观察结果，而不是强行补齐旧计划。
- **Maintenance**：EVIDENCE_GATED。

## U4｜周尺度负荷与恢复

- **Target**：区分局部波动、多日累积失配、结构错配和持续异常，并选择最小周尺度调整。
- **Baseline gate**：SKIP。没有多日证据时，周尺度判断容易制造解释而不是信息。
- **Practice geometry**：多日趋势、负荷质量变化、普通恢复反应、边界升级。
- **Direct demonstration PASS**：能指出为什么这是局部还是趋势；不只看总学习时长；一次只选一个主要失配做验证；持续异常时退出生产力框架。
- **Smallest repair objects**：时间尺度；睡眠量/规律；负荷质量；恢复反应；单变量调整；医疗升级。
- **Compression target**：4 类周模式 + 7 个高信息信号 + 一个变量验证。
- **Transfer target**：时长不变但切换/压力升高；睡眠改善仍未恢复；主观休息后任务功能仍异常。
- **Real use**：真正出现多日趋势时才调用；没有趋势就不做周恢复仪式。
- **Maintenance**：EVIDENCE_GATED。

## U5｜长期底盘- **Target**：从多个可优化变量中找当前最大瓶颈，做少数高杠杆改变，并知道什么时候停止优化。
- **Baseline gate**：SOFT。已有生活经验可用于暴露“追小技巧而忽略大瓶颈”的倾向，但不要求额外问卷。
- **Practice geometry**：多个底盘同时有缺口、基础已稳定但仍继续优化、长期症状无法解释。
- **Direct demonstration PASS**：优先级由瓶颈/整体影响/可持续/可验证决定；不追补剂或伪精确指标；基础稳定后会停止；持续异常会升级医疗评估。
- **Smallest repair objects**：底盘完整性；瓶颈优先；刺激物边界；停止线；医疗升级。
- **Compression target**：6 个长期底盘 + 瓶颈优先算法 + 停止线。
- **Transfer target**：多个缺口同时存在、优化过头、环境变化造成长期底盘下降。
- **Real use**：只在长期重复救火或明显底盘瓶颈存在时改变一个主要变量，再看真实趋势。
- **Maintenance**：EVIDENCE_GATED。

## Chat adjudication

Chat 收到 Verify / Transfer Handoff 时：

1. 只判当前绑定的 Unit 和 stage；
2. 先看 learner attempt，再读取当前 Unit / Source Review / 本设计中对应条目；
3. PASS 要求能力结构出现，不要求复述教材原句；
4. 若错误原因不同会导致不同修法，才做诊断；
5. REPAIR 只给最小失败对象，不重讲整 Unit；
6. 同题改对不升级为 clean demonstration；
7. Transfer 经 Repair 后，下一次必须使用新的换情境 probe；
8. 不因为表达简短、中文口语化或与教材措辞不同而判失败；
9. 不用健康推断替代证据；医疗边界只判断“是否应升级”，不诊断疾病。## Exit meaning

    Verify PASS
    → 允许释放 Unit 压缩候选

    Compression 完成
    → 允许进入换情境迁移

    Transfer PASS
    → 当前 Unit 达到 CHANGED_CONTEXT_TRANSFER
    → 解锁下一个 Unit Learn

    Real Use
    → 只有真实发生后才形成该层证据

    Stable
    → 需要重复、跨情境的现实证据；不能由页面或一次成功制造
