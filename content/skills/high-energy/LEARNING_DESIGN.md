# High Energy Learning Design

Status: CURRENT INTERNAL LEARNING OWNER  
Role: U1–U5 的最小学习设计与 Chat Evidence 判定边界。  
Parents: content/skills/LEARNING_CONTRACT.md + content/skills/UNIT_CONTRACT.md.

本页只细化 High Energy 的局部能力设计，不重定义通用 Skill 学习阶段。

## Shared rule

所有 Unit 继续继承：

~~~text
展开学习
→ 主动重建
→ Application / Discrimination
→ Direct Demonstration
→ 压缩成可调用模型
→ Changed-context Transfer
→ Real Use
→ 有重复证据时才 Personal Calibration
~~~

这不是仪式；某一步只有在不会改变证据或未来动作时才可跳过。

Direct Demonstration 默认 NATIVE。父契约允许 Protected Verify or equivalent clean performance；只有真正等价、未被答案泄漏污染的 clean performance 才能替代受保护 Verify。普通讨论、认同、重读、页面完成、同题改对或被提示后答对，都不能自动制造 mastery。

Real Use 允许 TOOL_ALLOWED；工具能减少执行摩擦，但不能替代需要验证的原生判断。Real Use 可以支持或反驳模型，也可以重新打开最早负责的失败对象；一次成功不能制造 Stable。

出现医疗升级边界时，能力目标是知道停止普通自我优化并寻求合适评估，不是继续自我诊断。

## Cross-Skill boundary

High Energy 只拥有：恢复 / 负荷 / 容量怎样改变可用表现，以及怎样做恢复与容量方向的判断。

- health-physical owns exact sleep-health / exercise / training / physical-capacity methods and dose logic。High Energy 可以识别“生理容量是瓶颈”，但不复制训练处方、睡眠健康管理或身体能力课程。
- adaptive-learning owns learning-method selection, practice geometry, retention, transfer and automaticity formation。High Energy 可以指出“任务熟练会降低认知成本”，但不复制完整学习方法。
- subject-native learning owners own exact subject progression / evidence。High Energy 不制造 subject mastery 或 pacing。

## U1｜掉状态判断

- Target：判断 local vs combined vs system-level drop；只有会改变动作时才进一步区分原因。
- Baseline gate：SOFT。现实例子可暴露是否过度单标签，但不消耗 protected Verify。
- Practice geometry：混合信号、冲突线索、相同表象不同原因、局部问题伪装成整体下降。
- Direct demonstration PASS：在 fresh / protected 情境中不强行单标签；抓住最决定动作的信号；知道什么时候判断已经够；守住医疗边界。
- Smallest repair objects：过度分类；抗拒 vs 容量不足；忽略 combined drop；错误升级时间尺度；医疗边界。
- Compression target：local / combined / system-level + “只区分会改变动作的因素”。
- Transfer target：多个共同原因、线索冲突、主观舒服但功能未恢复。
- Real use：真实掉状态时迅速进入合适恢复动作，而不是卡在解释。
- Maintenance：EVIDENCE_GATED。

## U2｜高效恢复

- Target：选择高收益动作与最小充分恢复剂量；第一次小剂量无效时及时升级，而不是反复 under-dose。
- Baseline gate：SKIP。脱离状态判断直接测恢复技巧主要测偏好。
- Practice geometry：同一动作在不同状态下价值变化；小休失败；现实时间约束；混合低状态。
- Direct demonstration PASS：动作匹配主要限制；剂量足够且不过度；不会把刺激当恢复；能说明不够时如何升级；给出真实 re-entry 信号。
- Smallest repair objects：动作匹配；剂量不足；重复同级小休；刺激 vs 恢复；re-entry；后续代价。
- Compression target：黄金动作族 + 起始剂量 + 升级规则 + re-entry。
- Transfer target：只有 10/25 分钟、不能睡/不能离开、第一动作无效、明显睡意与其他负荷并存。
- Real use：真实掉状态后，用一次合理恢复得到可解释的 re-entry 结果。
- Maintenance：EVIDENCE_GATED。

## U3｜日内精力配置

- Target：把任务认知需求和真实容量窗口匹配，并在现实变化后动态重排。
- Baseline gate：SOFT。已有日程经验可用于暴露直觉偏差，不额外制造问卷。
- Practice geometry：任务需求分层、容量变化、截止期、睡眠成本和临时占用共同出现。
- Direct demonstration PASS：优先保护高价值高认知工作；不会用固定钟点代替真实容量；现实变化后能说明什么先保、什么先让。
- Smallest repair objects：任务需求分类；容量窗口；高容量机会成本；后续代价；动态重排。
- Compression target：任务需求 × 当前容量 × 时段模式 × 后续代价。
- Transfer target：个人高容量窗口改变、任务需求升级、今晚可做但损害明天。
- Real use：真实一天发生变化时，完成一次合理重排并观察结果。
- Maintenance：EVIDENCE_GATED。

## U4｜周尺度负荷 / 恢复

- Target：识别反复救火、drop latency 提前、recovery latency 变慢和多日累积失配。
- Baseline gate：SKIP。没有多日证据时，周尺度判断主要制造解释。
- Practice geometry：多日趋势、负荷质量变化、普通恢复越来越无效、边界升级。
- Direct demonstration PASS：区分单次波动 vs 趋势；不只看总时长；只选一个主要失配验证；持续异常时退出生产力框架。
- Smallest repair objects：时间尺度；drop latency；recovery latency；rescue frequency；睡眠量/规律；负荷质量；恢复反应；医疗升级。
- Compression target：drop latency + recovery latency + rescue frequency + 最大失配。
- Transfer target：时长不变但切换/压力升高；睡眠改善仍未恢复；换任务/换作息后识别同类趋势。
- Real use：真正出现多日趋势时才调用并调整一个主要变量。
- Maintenance：EVIDENCE_GATED。

## U5｜容量增长

- Target：识别当前最值得提高的容量杠杆，并用真实表现判断是否真的变强。
- Baseline gate：SOFT。已有生活 / 学习经验可暴露追小技巧或把硬撑当训练的倾向。
- Practice geometry：多个瓶颈竞争；硬撑假进步；任务熟练导致成本下降；压力成为主瓶颈；基础稳定后停止优化。
- Direct demonstration PASS：不把 degraded persistence 当 cognitive tolerance；认知负荷进阶一次只改一个维度；能区分 task-specific efficiency 与更一般的 capacity change；具体训练处方路由到 health-physical；具体学习/自动化方法路由到 adaptive-learning 或 subject-native owner；不把实验性 BET 当默认优先级。
- Smallest repair objects：容量类别；硬撑 vs 适应；一个维度进阶；task-efficiency confound；owner boundary；停止线；医疗边界。
- Compression target：四类容量 + 一个当前瓶颈 + 一个可验证增长动作 + 正确 handoff。
- Transfer target：不同瓶颈组合、考试期 vs 非考试期、任务熟练 vs 身体容量提高、实验性 protocol。
- Real use：长期重复瓶颈出现时，选择一个高杠杆增长方向；具体执行由对应 owner 接手。
- Maintenance：EVIDENCE_GATED。

## Chat adjudication

1. 只判当前 Unit / stage；
2. 先看 learner attempt，需要时再读当前 Unit / Source Review / 本设计对应条目；
3. PASS 要求能力结构出现，不要求教材原句；
4. 若错误原因不同会导致不同修法，才做诊断；
5. REPAIR 只给最小失败对象；
6. 同题改对不升级为 clean Direct Demonstration；
7. Transfer 经 Repair 后，下一次必须使用新的 changed-context probe；
8. 不因表达简短、中文口语化而判失败；
9. ordinary discussion / agreement ≠ clean performance；
10. Real Use 可以重新打开最早负责的对象，但不能仅凭一次成功制造 Stable；
11. 医疗边界只判断是否应退出普通自我优化，不诊断疾病。

## Exit meaning

~~~text
Protected Verify PASS
or equivalent clean Direct Demonstration
→ 允许释放 / 使用 Unit Compression

Compression 完成
→ Changed-context Transfer

Transfer PASS
→ 当前 Unit 达到 CHANGED_CONTEXT_TRANSFER
→ 解锁下一个 Unit Learn

Real Use
→ 形成现实层证据；可能支持或反驳前面模型

Stable
→ 需要重复、跨情境、时间上分离的证据
~~~
