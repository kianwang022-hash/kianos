# U2 压缩候选｜瞬时恢复

## 第一动作路由器

| 当前最可能问题 | 第一方向 |
| --- | --- |
| 真困 | 有条件就创造睡眠机会；否则降低高风险 / 高认知要求 |
| 认知疲劳 | 停止继续叠同类高负荷；短休息 / 降负荷 / 短暂走动 |
| 注意碎片化 | 先移除竞争刺激 |
| 启动阻力 / 低唤醒 | 先做一个很短的真实起步块；必要时短暂活动 |
| 压力过高 | 降输入、外化下一步、缩小当前任务 |
| 身体 / 环境限制 | 直接修最具体的身体或环境变量 |

## 4 条规则

~~~text
匹配问题
→ 动作尽量小
→ 低风险、可撤回
→ 必须回原任务验证
~~~

## 一条硬边界

> **刺激 ≠ 恢复。**

咖啡因、短暂兴奋、换刺激都不能跳过“回到真实任务后表现是否恢复”这一步。
