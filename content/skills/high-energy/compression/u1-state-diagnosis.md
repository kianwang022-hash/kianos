# U1 压缩候选｜状态诊断

## 一屏判断

~~~text
低能量 / 低效率
        ↓
1. 真困吗？
   ├─ 是 → 先看睡眠 / 节律
   └─ 否
        ↓
2. 是不是高负荷以后逐渐掉？
   ├─ 是 → 先看认知疲劳
   └─ 否
        ↓
3. 去掉刺激 / 真正开始以后，功能会回来吗？
   ├─ 去刺激后回来 → 注意碎片化
   ├─ 开始后回来   → 启动阻力 / 低唤醒
   └─ 都不回来
        ↓
4. 压力 / 身体 / 环境 / 健康因素
~~~

## 最小输出

~~~text
最可能是什么
+ 决定性证据
+ 还不确定什么
+ 第一验证动作
+ 回到真实任务后看什么
~~~

如果这一页让你漏掉一个真正会改变行动的区分，就展开回 Learn；否则以后优先调用这一屏，而不是重读全文。
