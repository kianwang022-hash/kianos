## S2｜O*NET — occupation as tasks / skills / work context

Sources:
https://www.onetonline.org/
https://www.onetonline.org/help/onet/

Accepted:
- occupations can be described using tasks, work activities, knowledge, skills, abilities, work context, interests and styles;
- task / skill descriptions can provide more decision-relevant information than a title alone;
- transferable skills can connect adjacent occupations.

Boundary:
- O*NET is U.S.-focused and occupationally aggregated;
- a specific employer role may differ greatly from the occupation profile;
- current employer job descriptions and real worker interviews are higher priority for a specific opportunity.

---

## S3｜U.S. BLS Occupational Outlook Handbook

Sources:
https://www.bls.gov/ooh/
https://www.bls.gov/ooh/About/Occupational-Information-Included-in-the-OOH.htm

Accepted:
- career research can compare actual work, environment, entry education / training, pay and projected employment;
- standardized occupational profiles are useful for broad comparison and discovering adjacent roles.

Boundary:
- BLS data are U.S.-specific;
- median pay does not represent an individual's offer;
- employment projections are scenarios / forecasts, not guarantees;
- granular medicine / academia / pharma roles often need more direct evidence.

## S4｜OECD Skills Outlook 2025 / skills-first labour market

Sources:
https://www.oecd.org/en/publications/oecd-skills-outlook-2025_26163cd3-en.html
https://www.oecd.org/en/publications/a-skills-first-labour-market_2e1b85f0-en.html
https://www.oecd.org/en/publications/a-skills-first-labour-market_2e1b85f0-en/full-report/connecting-learning-to-jobs-through-guidance-signalling-and-collaboration_3fb19bb6.html

Accepted:
- labour markets increasingly need explicit skill recognition alongside formal credentials;
- flexible / portable learning pathways can support mobility;
- career guidance should connect labour-market information, skills assessment and training / opportunity navigation;
- credentials and skills can both function as labour-market signals.

Boundary:
- “skills-first” does not mean credentials never matter;
- licensed professions and academic pathways can have hard credential gates;
- OECD patterns do not define a specific local employer's hiring rule.

## S5｜OECD career guidance / transitions

Sources:
https://www.oecd.org/en/topics/career-guidance.html
https://www.oecd.org/en/publications/career-guidance-for-adults-in-a-changing-world-of-work_9a94bfad-en/full-report.html

Accepted:
- career transitions recur across adult life;
- high-quality labour-market information should be objective, current, fit-for-purpose and granular;
- effective guidance should be tailored to an individual's skills and transition context;
- outcomes matter more than merely providing information.

Boundary:
- career counsellor or AI advice is input, not final Decision ownership;
- labour-market forecasts are uncertain and geographic.

## S6｜National Academies — Science of Effective Mentorship in STEMM

Sources:
https://www.nationalacademies.org/publications/25568
https://www.nationalacademies.org/read/25568/chapter/10
https://nap.nationalacademies.org/resource/25568/interactive/program-development-and-management.html

Accepted:
- mentorship is a professional working alliance providing career and psychosocial support;
- effective mentorship is associated with positive training / career outcomes;
- intentionality, trust, clear expectations, responsiveness and feedback matter;
- multiple mentors / mentor maps can provide complementary support;
- mentor / mentee relationship quality is not reducible to mentor prestige.

Boundary:
- evidence is heavily based on STEMM training contexts;
- no mentor profile guarantees a successful individual relationship;
- publication count and academic status are not direct mentoring-quality measures.

## Durable boundaries

### Title is a weak description of actual work

Prefer:
- daily tasks;
- decision ownership;
- stakeholders;
- tools;
- output;
- work context;
- evaluation / promotion criteria.

### Salary is one career outcome

Also inspect:
- hours;
- geography;
- learning;
- autonomy;
- risk;
- transferability;
- future options;
- work meaning;
- environment.

Final weighting belongs to Decision.

### Credential value is conditional

A credential can create value through:
- legal eligibility;
- screening;
- structured skill;
- network / institution access;
- credibility.

More credential is not automatically more career capital.

### Prestige is a noisy proxy

School / employer / mentor prestige can matter because others use it as a signal.

But it can hide:
- poor mentorship;
- low ownership;
- weak skill formation;
- unhealthy culture;
- bad placement for the learner's target path.

### Mentor evaluation requires behavior evidence

Ask about:
- meeting frequency;
- feedback;
- student independence;
- project / authorship allocation;
- conflict;
- funding;
- alumni outcomes;
- expectations.

Do not infer mentoring from publication count alone.

### Career capital should be portable when possible

Useful capital can include:
- skill;
- proof of work;
- credential;
- reputation;
- network;
- ownership experience.

The more organization-specific the asset, the more carefully path dependency should be considered.

### Option value is not a reason to avoid every commitment

Some opportunities compound only with depth and time.

Evaluate:
- reversibility;
- learning;
- lock-in;
- switching cost;
- forgone compounding.

### Career experiments reduce imagination error

Small real exposure can update:
- task fit;
- environment fit;
- skill gap;
- hidden constraints.

It cannot prove long-term satisfaction, so do not overclaim.

### Final choice belongs to Decision

Career Skill should never output a universal “best career”.

It supplies a higher-quality option set and evidence.

## Volatility gate

Before a real career choice, re-check:
- program / degree structure;
- current mentor / team;
- publications and active funding;
- student / employee outcomes;
- current job descriptions;
- salary / hours;
- licensing / credential rules;
- visa / geography;
- hiring market;
- employer strategy;
- application and negotiation conditions.

These are current opportunity facts, not permanent Skill rules.
