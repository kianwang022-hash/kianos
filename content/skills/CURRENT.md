# Skills Current

Role: Skill Library engineering Work Cursor / restart router only.

This file stores no learner state, per-book acceptance ledger or duplicated Skill inventory.

## Current product

Skill Library turns an **accepted/promoted capability need** into durable learner-facing KianOS content through the reusable learning-asset pipeline:

```text
Source
→ Knowledge Reconstruction
→ Learning Logic
→ Content Realization / Closure
→ learner-facing Projection
→ real-use evidence when applicable
```

This is the same causal S/K/L-centered production model governed by root `LEARNING_ASSET_STANDARD.md` and `LEARNING_ACCEPTANCE.md`; Skills do not create a second acceptance framework.

Personal owns why a capability matters to Kian, demand discovery and any accepted personal conclusion. KianOS owns the promoted learner-facing Skill asset and its product semantics. A Personal interest does not automatically become a Skill.

## Work Cursor

**Active broad Skill-Library engineering task:** none.

The registered portfolio is resolved from `manifest.json`; do not duplicate its 17-book inventory or each book's closure narrative here. New or materially changed Skills follow the root Source → Knowledge → Learning → Content → Projection/Runtime/Evidence lifecycle and reopen only their true dependents.

## Boundaries

- Raw books/PDFs/references may remain raw assets until promotion/internalization is justified.
- New Skill content should normally require no new Visual/Runtime family; reuse the generic reader when cognition allows.
- Source/content closure is not learner U.
- Browser reading history is Resume evidence only, not mastery.
- Do not turn all Personal interests into curriculum or build a giant cross-Skill ontology.
- Health/medical Skills remain educational assets, not personal diagnosis/treatment truth.

## Stop / reopen

Normal Skill reading bypasses this engineering Current.

Reopen only for:
- a concrete Skill content/Source defect;
- an accepted new/promoted capability need;
- a generic reader/product defect;
- a real cross-Skill boundary that cannot be represented by the existing owners.

Do not reopen the whole library because more possible Skills or polish can be imagined.
