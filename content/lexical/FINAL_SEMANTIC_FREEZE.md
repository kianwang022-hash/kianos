# Lexical Final Semantic Freeze v1

Status: **FROZEN — FINAL BROAD SEMANTIC STANDARD**

Effective: 2026-09-19

This file freezes the final broad semantic standard for the current Lexical catalog.

## 1. Why this exists

The catalog has already gone through multiple semantic-quality generations. The current campaign is the last broad backfill needed to normalize early batches that were produced before the final ruler stabilized.

This freeze prevents another cycle of:

```text
new semantic idea
→ new global standard
→ reopen thousands of accepted words
→ another broad audit/rebuild
```

That cycle ends here.

## 2. Final semantic ruler

Every Production and Audit judgment uses the same final model:

```text
Core / Decision
Expansion / Leverage
Reference
Repair
```

### Core / Decision

Knowledge whose absence or mis-ranking can materially damage:
- recognition;
- branch selection;
- syntax / collocation choice;
- translation;
- writing;
- broad transfer.

### Expansion / Leverage

Non-Core knowledge with real reusable leverage, including:
- morphology / irregular form;
- high-value word family;
- academic / professional / regional usage;
- pronunciation / spelling / form identity;
- cross-word decision boundaries;
- reusable productive value.

### Reference

Valid lower-current-value material, including specialist, historical, dated, narrow-domain or completeness truth.

Reference remains canonical truth but does not consume default learner attention merely because it is true.

### Repair

Repair is evidence-triggered reactivation of an exact unstable lexical target.

Repair is not a fourth knowledge layer and is not a reason to prebuild tests for every worthwhile fact.

## 3. Final module rules

For every Word owner, Production asks only whether a real allowed gap exists in current truth.

Allowed mutation reasons remain exactly:

- CORRECTNESS_GAP
- COVERAGE_GAP
- DECISION_GAP
- STRUCTURE_GAP
- PHRASEOLOGY_GAP
- OWNERSHIP_GAP
- REGISTER_FORM_GAP
- PRODUCTIVE_VALUE_GAP
- TESTABILITY_GAP
- REDUNDANCY_NOISE

`STYLE_POLISH` alone never authorizes semantic mutation.

Final principles:

- simple words may remain simple;
- rich words may remain rich;
- exam-first does not mean exam-only;
- worth knowing ≠ must be Core;
- worth in Expansion ≠ deserves a standing Repair Test;
- canonical truth may be richer than default Study;
- fake Construction / Relation / Sense objects must move back to the correct owner rather than survive for convenience;
- stable identity must be preserved where truth is continuous;
- B audit may refine accepted content but may not invent a newer ruler.

- the remaining broad inconsistency comes from early batches produced before the final standard stabilized;
- the live backfill board already scopes this normalization to o0001–o1150.

Therefore:

```text
o0001–o1150

o1151–o7946

```

The existing o1151–o1250 candidate may still receive its already-scheduled Fresh Independent Audit because that candidate already exists, but this does not reopen o1151–o7946 as a new Production sweep.

## 5. Production-first completion order

Kian has chosen to finish Production before more audit/materialization work.

Until the Production sweep is complete:

```text
A + C
→ Fresh Read
→ Self Attack
→ smallest stabilized proposal
→ Human Gate only for genuinely new material delta
→ freeze proposal into approved backlog
→ immediately continue to next assigned batch
```

During this phase:

- no new canonical semantic materialization;
- no new B audit launch;
- no merge driven by the current backfill campaign;
- no engineering detours unless they block the semantic review itself.

A reviews remaining low-side batches upward.
C reviews remaining high-side batches downward.

Already completed/frozen Production work is preserved and not repeated.

## 6. Human Gate behavior

For A/C Production:

- if no genuinely new material semantic scope exists, freeze the proposal automatically and continue;
- if genuinely new material scope exists, show only that bounded delta;
- Kian `p` approves only the exact shown delta;
- after `p`, freeze the batch and immediately continue to the next batch;
- do not stop merely because the batch is waiting for future materialization.

A `p` is still a synchronization barrier before recording approval, but synchronization must not turn into a materialization detour during Production-first mode.

## 7. B cannot raise the standard

Fresh Independent Audit remains required later, but B's authority is bounded.

B may:
- PASS;
- flip an incorrect Production judgment;
- refine an upgrade;
- identify identity risk;
- identify a blocker;
- expose a genuinely new material delta that requires one bounded Human Gate.

B may not:
- invent a newer semantic framework;
- require another broad review generation;
- reinterpret style preference as semantic debt;
- use historical audit inflation as authority;
- reopen unrelated accepted owners.

## 8. Post-freeze catalog policy

After the o0001–o1150 Production sweep, later materialization/audit/reconciliation, and final closure:

```text
default = PRESERVE
future semantic change = evidence-triggered local repair only
```

A future semantic mutation must be local and justified by concrete evidence such as:
- factual/correctness error;
- stable-identity defect;
- missing learner-worthy branch demonstrated by real evidence;
- wrong owner placement;
- learner evidence showing a real decision gap;
- authoritative source change or discovered contradiction.

The following are explicitly **not** sufficient to reopen broad semantics:
- a new preferred wording style;
- a new Chat having a different taste;
- a more elegant taxonomy;
- another audit methodology;
- a new desire to make every word equally rich;
- green/red validator noise without semantic evidence;
- “we could make this even better”.

## 9. Broad semantic re-open prohibition

After final closure, no Chat, script, audit or workflow may initiate a new broad semantic re-review of the catalog merely because a newer approach seems possible.

Broad reopening requires an explicit Kian instruction that clearly revokes this freeze.

Absent that explicit revocation:

> **This is the final broad semantic standard.**
