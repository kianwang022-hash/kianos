## Delta-only findings

### 1. o0677 `capacity` — `NO_CHANGE` → `UPGRADE`

**Observed Current issue**

The active ability branch contains the fixed/production pattern:

`capacity to do + sth`

This is malformed learner-facing syntax. The safe pattern is:

`capacity to do sth`

**Audit boundary**

Do not create a new sense merely to fix this string. Reuse the existing ability branch and correct the production pattern. Any reassignment of `capacity for + sth` across physical versus ability branches should be decided only if Sol's reconciliation finds a genuine sense-attachment problem; the audit does not require a new branch for that phrase.

---

### 2. o0706 `cast` — `NO_CHANGE` → `UPGRADE`

**Observed Current issue**

The Current owner represents:

- throw / hurl;
- noun `cast` = actors;
- mold / cast material;
- plaster cast;
- molded object;
- constructions such as `cast doubt on` and `cast light on`.

It does **not** represent the ordinary verb branch:

- `cast sb as X`;
- cast/select actors for a film, play or role.

This is a real semantic-completeness omission with high transfer value, not a stylistic enrichment request.

**Audit boundary**

Add or reuse the stable casting-actors verb branch if one exists in canonical evidence. Preserve the existing throw/mold/noun branches; do not repurpose the noun-actors sense as the verb sense.

---

### 3. o0710 `cat` — production `UPGRADE` needs narrower reconciliation

**Observed Current issue**

The Core cluster includes `a spiteful woman`, but that material is not represented as a normal active learner sense. At the same time, two rare verb senses (`beat with a cat-o'-nine-tails`; `vomit`) already exist at L3.

The production handoff is right that learner-Core is polluted, but a blanket cleanup of rare branches would exceed the authority of semantic ranking.

**Required reconciliation**

- Remove the dated/derogatory `spiteful woman` material from learner-Core compression.
- Keep the ordinary animal sense primary.
- Preserve stable rare L3 verb senses unless Sol separately establishes deprecation/removal authority from canonical evidence.

`L3` means low learner priority; it is not deletion authority.

---

### 4. o0832 `classify` — `NO_CHANGE` → `UPGRADE`

**Observed Current issue**

The reciprocal word-family object on `classify` currently targets:

`sense:class:af4577a133915bb1` = class as a **group of students**.

But the semantic derivation `class → classify` belongs to:

`sense:class:e306d042096c5b10` = **category/type**.

The production handoff correctly upgrades o0828 `class`, but leaves o0832 as `NO_CHANGE`. If the executor byte-preserves o0832, the relation remains semantically asymmetric / half-repaired.

**Required reconciliation**

Repair the reciprocal target on o0832 so `classify ↔ class` anchors to the category/type sense on both sides. Preserve stable IDs and relationship identity wherever possible; this is a relation-anchor correction, not a new lexical sense.
