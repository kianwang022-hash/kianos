# Lexical Semantic Audit Blind-First Protocol

Audit independence is strongest when owner judgment precedes exposure to Production's detailed rationale.

Required order when tool access permits:

1. read audit/content contracts and calibration scenarios;
2. read machine risk manifest if available;
3. read Current owners/dependencies;
4. record provisional owner-based routing / desired semantic state;
5. only then compare production handoff and emit final audit verdicts.

If sequencing cannot be enforced, record `BLIND_FIRST_NOT_ENFORCED`. Such a batch may still produce valid defects but is weaker evidence for reviewer independence or future relaxation of STRICT mode.
