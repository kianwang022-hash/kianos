## Must preserve

### Rule / learning semantics

- purpose = fast, correct, transferable lexical access;
- one Main Word is the learning container;
- smallest unstable lexical object is the Repair unit;
- Coverage is universal; Depth is selective;
- whole-card routing judgment and exact local Repair admission stay separate;
- Fast Pass remains genuinely cheap;
- Direct rich Depth is allowed when useful;
- Recall exists only when it defeats familiarity illusion;
- local `+` admits an exact future Repair target;
- Repair stays narrow and evidence-driven;
- Challenge is a test layer, not semantic truth;
- no fixed daily quota, overdue wall or fake mastery percentage;
- real English context is high-value lexical evidence;
- English and Lexical must not become competing review systems;
- Kian retains final learner agency.

### Content

- current 7,946 canonical Main Words remain the content base;
- Word / Relation / Form-Identity natural ownership remains intact;
- SAFE_SIMPLE / DEPTH_READY / reference-only distinctions remain semantic Content facts;
- rich words may stay rich; simple words may stay simple;
- learner UI may selectively project Content but must not delete or re-author canonical truth;
- private familiarity/mastery state never enters shared Content.

### Existing learner evidence

Existing browser-local evidence / exact target identity / lineage / dormancy / reactivation semantics remain Engineering/Evidence truth until a concrete defect requires change.

## Current hypotheses requiring Human Gate

These are **design hypotheses, not accepted Truth**:

- Vocabulary Home should behave like a compact lexical workbench, not a dashboard or marketing hero.
- Search / Explore should remain a direct canonical lookup path and should not mutate learner state by lookup alone.
- Word Study should clearly distinguish a cheap Fast-Pass path from a chosen Depth encounter.
- The current large centered Word Front may or may not be the correct Recall geometry; it must be judged from real use/screenshot rather than inherited.
- Rich Depth should likely remain one coherent editorial lexical object instead of a stack of disconnected mini-cards.
- Repair should foreground only a small evidence-backed current subset when useful, while the full active inventory remains secondary; it must never become a due wall.
- Challenge should present one high-information test object at a time and return quickly to Coverage/English.
- English-origin lookup should preserve exact return context and visually remain a temporary tool handoff, not a separate study detour.
