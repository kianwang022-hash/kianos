## B. Genuinely new final-standard delta — requires bounded Kian approval

These are the only new learner assets that were not already represented by the prior accepted learner intent.

### Form / identity Expansion

1. **o0102 affiliate — noun/verb pronunciation**
   - noun `affiliate`: final syllable /-ət/
   - verb `affiliate`: final syllable /-eɪt/
   - Same Word identity; POS selects pronunciation.
   - Expansion, not Core. No extra prebuilt pronunciation Test.

2. **o0118 aggregate — noun/adjective vs verb pronunciation**
   - noun/adjective end in /-gət/
   - verb ends in /-geɪt/
   - Expansion / Form.
   - Existing broad `aggregate` Test is retargeted to this exact Form boundary.

3. **o0130 aircraft — invariant plural**
   - `one aircraft / several aircraft`
   - High-value irregular inflection/Form recognition.
   - Expansion; no prebuilt Test.

4. **o0153 alloy — noun/verb pronunciation**
   - noun has initial stress; verb shifts stress to the second syllable.
   - Expansion / Form; no prebuilt Test.

5. **o0154 ally — noun/verb pronunciation**
   - noun `ally` has initial stress; verb `ally` has final stress.
   - Expansion / Form.
   - If a standing Test survives, it targets this exact Form distinction rather than duplicating a generic construction test.

6. **o0189 analysis — irregular plural**
   - `analysis → analyses`
   - High-value irregular plural/Form identity.
   - Expansion; no prebuilt Test.

### New construction / phraseology

15. **o0111 again — `then again`**

### New cross-word Relations

16. **o0181 among ↔ between**
    - Do **not** teach the false rule “between = two, among = three or more”.
    - `between` is used for distinct/separate entities or explicit pairwise/range relations and can involve more than two.
    - `among` places something inside/surrounded by a group or mass.
    - This earns a prebuilt Relation Test because an error changes an exact writing/selection Repair target.

17. **o0182 amount ↔ number**
    - Default countability boundary:
      - `amount of` + uncountable noun
      - `number of` + countable plural noun
    - This earns a prebuilt Relation Test because it drives an exact writing/selection repair.
