## Self-Adversarial Attack summary

The attack explicitly considered but rejected adding more “nice to know” idioms such as `on cloud nine`, `cold turkey`, `clear the air`, and `the coast is clear`. They are valid English, but admitting every recognizable idiom would restart phraseology inflation. The six Section-B items survived because each fills a stronger Form, branch-selection, countability, or highly reusable phrase gap.

It also rejected:
- building exhaustive family trees for adjacent words;
- promoting low-value historical/reference material merely because it exists;
- retaining duplicate Tests for both ends of the same Relation;
- using broad whole-word polysemy Tests when a wrong answer would not identify one smallest repair target.
