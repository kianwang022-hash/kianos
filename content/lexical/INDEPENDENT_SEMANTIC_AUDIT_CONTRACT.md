# LexicalOS Independent Semantic Audit Contract

Status: **CURRENT · BOUNDED_MAINTENANCE**  
Scope authority: `content/lexical/CURRENT.md`  
Semantic ruler: `CONTENT_ASSET_CONTRACT.md`

This file owns the independent semantic challenge method for a **bounded Lexical maintenance repair**. It is not a production campaign, batch scheduler, audit cursor, K-status mirror, or permission to reopen the 7,946-word catalog.

## 1. Activation

Current K acceptance is owned by `ACCEPTANCE.md`. The broad catalog campaign is closed.

Independent semantic audit is activated only when a Current-admitted task changes or seriously questions lexical meaning/identity, such as a concrete semantic, phraseology, construction, register, Form/identity-lifecycle or genuine cross-word Relation defect; an admitted new Source; explicit new scope; or real learner evidence exposing a concrete content defect.

A green validator does not prove semantic correctness. The existence of historical audit evidence or an audit tool does not create work.

## 2. Bounded scope

Audit the smallest semantic closure set that can change the decision:

```text
target Word / Relation / Form owner
+ exact evidence / Source needed for the disputed claim
+ material semantic dependencies
+ reciprocal owner only when relation/identity semantics require it
```

Do not widen scope by ordinal adjacency, an old batch boundary, a historical cursor, or a newer preferred methodology.

If a bounded audit reveals a credible repeated defect class outside the current write/read set, preserve the concrete finding, do not silently expand into a catalog campaign, identify only the smallest additional class supported by evidence, and require an explicit Current/scope decision before broadening beyond bounded maintenance.

Broad semantic re-review remains closed unless a new explicit Current scope decision reopens a catalog-wide program.

## 3. Independent challenge

When practical, form the independent view from the Current owner + evidence before reading the proposed repair rationale.

Challenge only dimensions that can materially change learner truth: missing/over-split meaning, semantic boundary/Core compression, register/frequency/reference-only placement, argument structure/construction/phraseology, Relation ownership/reciprocity, Form/identity lifecycle, Source mismatch, or semantics accidentally encoded in presentation/runtime.

For the bounded scope, terminate with one of:

- **PRESERVE** — Current truth is supported; no semantic mutation;
- **REPAIR** — a concrete evidence-supported owner delta is required;
- **BLOCKED** — evidence, identity or ownership is insufficient; do not guess.

These are local maintenance outcomes, not a replacement K/P/R/E scale.

## 4. Evidence and readback

A decision-changing audit retains only what is needed to reproduce the judgment: exact Current owner revision, material dependency revisions, Source/evidence identity where applicable, affected owner set, semantic reason, and final changed-owner readback when a repair lands.

Do not create a durable Audit Pack merely because an audit happened. Persist bounded proof only when Acceptance, future reproducibility or a real unresolved dependency requires it.

Historical full-catalog Audit Packs remain provenance. Their old cursors, batch sizes, sampling schedules and Chat-role procedures do not govern Current maintenance.

## 5. Tool boundary

Repository audit scripts may provide structural or heuristic evidence. They never decide semantic PASS, choose a repair, or authorize a broad campaign.

A whole-catalog diagnostic is justified only when the defect itself is plausibly systemic. Its output is a candidate/evidence surface, not automatic semantic debt.

## 6. Historical evidence isolation

The following may remain as historical/acceptance evidence but are not Current work cursors:

- `content/lexical/semantic-audit/**`;
- `content/lexical/semantic-reconciliation/**`;
- `content/lexical/audit/knowledge-reacceptance/**`;
- prior full-catalog K acceptance artifacts;
- completed catalog-campaign control/protocol records under `content/lexical/audit/history/**`.

Normal fresh work starts from `CURRENT.md` and the exact Natural Owner, not from those directories.

## 7. Stop rule

Stop when the bounded semantic claim is resolved and the exact affected owner/consumer is verified. Do not continue searching for additional words, batches or generations merely because the audit method could be applied more broadly.
