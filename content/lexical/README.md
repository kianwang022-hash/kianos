# Lexical Content Map

Role: **static orientation for content/lexical/**. Live BUILD / CONTROL routing is owned by CURRENT.md. This README owns no lexical semantic truth, Acceptance status or learner state.

Learner-facing Vocabulary is an English product capability; this directory is the canonical Lexical backend.

## Start here

~~~text
ordinary Vocabulary use
→ English / Vocabulary learner runtime

semantic defect
→ CURRENT.md
→ exact Word / Relation / Form owner

learning model
→ LEARNING_CONTRACT.md

materialization/runtime mechanics
→ CONTENT_EXECUTION.md
→ exact tool/consumer

readiness
→ ACCEPTANCE.md
~~~

## CBA pointers

- **CREATE truth** → `LEARNING_CONTRACT.md` / `CONTENT_ASSET_CONTRACT.md` → exact Word / Relation / Form owner; learner-facing Product/Visual intent → `static-web/LEXICAL_PRODUCT_BRIEF.md`.
- **BUILD entry** → `CURRENT.md` → `CONTENT_EXECUTION.md` only when materialization is needed → actual English Vocabulary consumer.
- **AUDIT** → `ACCEPTANCE.md`; use `INDEPENDENT_SEMANTIC_AUDIT_CONTRACT.md` only when a semantic-audit claim is actually open.
- **REAL USE** → private lexical learner/evidence state.

Detailed learner-optimization CREATE method lives only in root `LEARNING_ASSET_STANDARD.md §4.2`; historical A/B/C/BF execution/audit packs are not normal startup context.

## Zones

### Learning / content rules

- LEARNING_CONTRACT.md — learner-facing lexical learning logic.
- CONTENT_ASSET_CONTRACT.md — semantic/content quality rules.
- EVIDENCE_MEMORY_CONTRACT.md — private lexical Evidence / Repair / identity semantics.

### Canonical lexical truth

- words/ — Word Natural Owners.
- relations/ — cross-word confusable/contrast truth.
- canonical/ — canonical supporting/index assets.
- schema.json / manifest.json — canonical structure/identity support.

### Derived learner assets

- FINAL_LEARNER_OBJECT_CONTRACT.md — final learner-object derivation boundary.
- learner/ — derived learner assets; not learner progress truth.
- final-learner-object-decisions.json — derivation decision support.

### Execution / materialization

- CONTENT_EXECUTION.md — current materialization/execution mechanics.
- tools/ — lexical tooling.
- execution/ — **retained cold provenance only when a Current owner still points to it**; closed unconsumed batch manifests/receipts belong in Git history, not the normal tree.

### Audit / acceptance evidence

- ACCEPTANCE.md — lane Acceptance Truth.
- acceptance/ — durable current acceptance evidence.
- INDEPENDENT_SEMANTIC_AUDIT_CONTRACT.md — independent semantic audit method.
- SEMANTIC_AUDIT_RISK_ROUTER_SPEC.md — semantic-audit risk routing.
- audit/ — retained current/cold evidence only where an explicit consumer still needs it.
- semantic-audit/ / semantic-reconciliation/ / semantic-review/ — retain only evidence still consumed by Current provenance/diagnostics; closed unreferenced packs belong in Git history and are not normal startup context.

## Placement rule

A Word, Relation or Form fact belongs to its Natural Owner, not to an audit report, page component or derived learner object. Historical A/B/C, BF and batch execution state must not re-enter Current routing.

Do not create another catalog-wide cursor or ledger when CURRENT.md and the natural semantic owners already resolve the work.

## Compact rule

**Natural Owners hold lexical truth; derived learner objects consume it; audits prove bounded claims; learner state stays private.**
