## 总模型中的位置与唯一复原索引

沿现有 `subject-model.md` 的“社会主义过渡和建设 → 改革开放 → 新时代”，本章是这条全科长线的历史收束。第九章说明改革开放怎样通过实际改革和理论认识的不断推进改变发展道路；第十章问的是：长期积累产生了怎样的新条件，为什么需要用新的历史方位理解后续任务？

历史阶段不是日历翻页自动产生的。原章已经给出需要一起看的变化：发展基础、制度能力和综合国力进入新的水平，社会主要矛盾与人民需要有新的阶段特征，治理和现代化任务的复杂程度提高。把这些方面连接起来，才能理解“新时代”这一历史判断；只背会议名称，看不到判断所针对的现实问题。

唯一母模型为原 `chapter_compression.timeline`，六个标签与顺序保持原样：

1. 改革开放长期发展
2. 中国特色社会主义事业不断推进
3. 进入新时代
4. 国家治理和现代化任务升级
5. 历史性成就和历史性变革
6. 民族复兴进入新的历史阶段

它是历史承接、阶段判断、任务和成果的组织模型，不是六个互相隔绝的年份。尤其任务升级与成果形成相互交织，不能说治理任务全部完成后才开始有成就，或有了成就便再无新任务。会议是某些判断、部署、总结的节点，不能反过来把本章母模型改成会议表。

## c10-stage-01｜长期发展改变了下一步建设的起点

先接住上一章的结果。改革开放不是一次会议后即告结束的行动，而是在实践中不断调整体制机制、发展道路和理论认识的长期过程。原章明确说，它改变了经济实力、社会结构、制度建设和国际地位，也不断带来新的发展矛盾与治理任务。新历史方位因此有此前积累的基础，不能把新时代讲成忽然从零开始。

这里的机制是：发展会改变能够调动的资源和能力，也会改变需要解决的问题。原来较弱的基础逐步增强，不代表一切问题都消失；原来有效的具体办法，也不能因曾经有效就被认为无需随条件变化而调整。前一句回答新阶段“从哪里来”，后一句回答为什么仍有新的工作。两者一起保留，才不会出现“有成就所以没任务”或“还有问题所以没有成就”的二分法。

Source 在从“一五”到“十四五”的回顾中，将一以贯之的主题概括为把我国建设成为社会主义现代化国家。这是本版所选历史范围的共同主题，不是说各时期有同样条件、同样政策或同样直接目标。贯穿的方向与分阶段的具体任务可以同时成立；历史连续性不要求抹平阶段差异。

从这一起点进入下一段时，保留原章的关键边界：新时代在长期中国特色社会主义实践基础上展开，不是脱离改革开放另起炉灶。为什么还需要新的阶段判断，要看现实条件和任务的变化，不靠单独一个新称呼证明。

## c10-stage-02｜“进入新时代”为什么是一种历史方位判断

**节点主提示（H10／十八大与十九大）：2012年党的十八大和2017年党的十九大在新时代历史阶段判断中，各有什么教材定位？十九大确立何种思想的指导地位？**

首次完整答案：**党的十八大（2012）标志我国进入全面建成小康社会的决定性阶段，开启中国特色社会主义新时代的历史进程**；**党的十九大（2017）作出中国特色社会主义进入新时代、社会主要矛盾发生新变化的重大政治论断，确立习近平新时代中国特色社会主义思想的指导地位**。十八大进入“决定性阶段”并不等于当时已经完成小康目标；历史过程开启和十九大明确论断也是不同问法。乘风K01-N01/N02及腿姐下册PDF16、新思想上册PDF104–105有对应身份。整个习近平新时代中国特色社会主义思想理论体系应交新思想课程，不在本章复制另一门理论课。

**节点主提示（H10／新方位与基本国情）：新时代我国社会主要矛盾变化的两方是什么，有哪两项基本国情/国际地位没有改变？**

首次完整答案：**人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾**成为新时代我国社会主要矛盾；**我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，我国是世界最大发展中国家的国际地位没有变**。主要矛盾变化是判断新历史方位的重要依据，不能由社会需要变化推断社会主义初级阶段已经结束。乘风C10 K01-N02-TBL01原表仅保留重大论断标题，完整两方取自腿姐2027新思想上册PDF104–105作同事实补证；**不据此声称乘风史纲原图完整逐字复核**。

一个新的历史方位需要说明变化的内容。原章把发展基础、制度能力、综合国力的新水平，与社会主要矛盾和人民需要的阶段性特征相联。其教学含义是：不仅比较拥有多少资源，还要问这些基础怎样影响人们需要什么、发展哪些方面仍有不足、国家面对什么新任务。这里沿用成熟章的解释范围，不从没有读到的表格填出社会主要矛盾双方的完整固定表述。

Source 对十八大的可读表述是，标志着中国已经进入全面建成小康社会的决定性阶段，并开启中国特色社会主义新时代。这里的“进入决定性阶段”不能被教成“该目标当时已经全部完成”。进入实现目标的关键阶段与已经实现目标，是不同判断；这一边界在用词首次出现时就要讲，而不是等到背年份时才补救。

关于十九大，当前清楚的文字子项写出确立习近平新时代中国特色社会主义思想的指导地位。把它放回模型：新的理论认识与历史条件相联，是本章所讲实践与理论继续展开的一个历史节点。指导思想的名称在这里值得准确识别，但史纲不据此扩出另一套完整理论结构、全部帽子或最新政策。

Source 的另一个节点把“进入新时代”“社会主要矛盾发生新变化”的政治论断放在表格类型 `K01-N02-TBL01` 下；本轮没有原页收据，无法核表头、行列、前后时期对应关系。成熟章已经支持我们讲阶段变化这一关系，但不支持声称本轮已核对表格全部精确内容。教师可以完成当前这层解释，需要社会主要矛盾的精确双方或前后比较时，必须止于该具体目标，等待PDF69／书68的原表；不能在学生不知道的情况下靠记忆续写。

因此，会议节点服务于历史判断，却不替代判断本身。十八大的阶段起点叙述、十九大的理论定位、原章中的现实变化各有对象，不能只因位置接近就缩成一个会议同时“首次完成一切”的笼统答案。

## c10-stage-03｜新的基础为什么伴随更复杂的治理与现代化任务

二十大提出的**三个务必**（不忘初心、牢记使命；谦虚谨慎、艰苦奋斗；敢于斗争、善于斗争）在乘风K01-N04-I02可完整识别，旧REVIEWED卡继续保留。但腿姐本轮检到的新思想对应页并未把该三组作为史纲C10新增默认整组精背，因此保持**Core的complete recognition与可选旧练习**；首次理解应能区分它们与1949七届二中“两个务必”的历史处境与成员，不因两组都包含艰苦奋斗便误归同一会议。

原章明确列出全面深化改革、全面依法治国、全面从严治党、现代化建设等任务，并指出改革发展稳定、内政外交国防、治党治国治军涉及更高复杂度。这里是当前成熟章的历史解释范围，不是本次新核一份精确政策清单。

怎样理解“复杂度提高”？若任务涉及更多相互联系的领域，解决一方面问题还要顾及它与其他方面的关系，治理能力与制度安排就不能只照顾单个局部。这个解释是对原章“任务升级”的展开，不额外制造某个特定时期的统计事实。它把本章同第九章接上：改革解决一些问题并形成新基础，新的发展条件又要求继续改进治理，二者是历史承接而不是互相否定。

Source 对十九大的清楚子项写到，对新时代推进中国特色社会主义伟大事业和党的建设伟大工程作出全面部署。两个对象同时出现，有助于理解发展事业与党的建设在该历史部署中的关联；不能因词中都有“伟大”便把对象合成一个，也不能自行增加其他未问、未读到的“伟大”列表。党的建设总要求的另一节点断在“组织建设、作”，所以本稿不把它当作已具备完整成员的清单。

二十大部分的中心任务节点也只存到“实现”，不能从半句话恢复整段正式表述。可完整读取的是“三个务必”：不忘初心、牢记使命；谦虚谨慎、艰苦奋斗；敢于斗争、善于斗争。这里把它放在本版历史会议所提出的要求下理解：每一组都含两部分，“斗争”与“善于”不能拆开只保留前者，“牢记使命”也不能吞掉“不忘初心”。这些要求帮助识别 Source 的历史会议表达，不可由其存在推断某项具体政策已经完成、也不可从它推导任意行动都必然正确。

本段收束：更好的基础与更复杂的任务能够同时出现。任务升级说明建设仍在继续，不是说旧阶段毫无成果；部署与要求是行动方向，也不是任务已经全部实现的证据。

## c10-stage-04｜怎样读成就、变革和历史总结

十九届六中全会通过的**《中共中央关于党的百年奋斗重大成就和历史经验的决议》**属于对已有历史实践作总结，不能把被总结事件移动到会议当年。乘风K01-N03-I01有完整题名，原历史精记REVIEWED可选练；2027腿姐本轮同范围没有独立史纲C10整组背诵要求，故不另建主提示卡。关于党百年奋斗四大伟大成就、历史意义的完整条目在乘风K01-N03-I02/I03只有标题，不能由熟悉其他书的术语填满原Source。当前经济实力、综合国力等历史概括亦只陈述本版历史叙述，不冒称2026实时成果统计。

原章把“历史性成就”和“历史性变革”并列，同时保留新的发展不平衡不充分等问题。教学中可先区分观察角度：成就着重已经取得的成果，变革着重发展和治理过程中较深层的变化。它们可以相互联系，但不能把两个词当成对现实没有任何剩余问题的保证。这是帮助读懂原章的解释，不是另造一条需逐字背诵的官方定义。

Source 对十九届六中全会明确给出会议最重要成果：审议通过《中共中央关于党的百年奋斗重大成就和历史经验的决议》。读这里，要区分“通过一个历史总结文件”和“某一历史成果在此才发生”。总结文件回顾已经展开的实践，不会把被总结的所有事件都移动到会议当年。它在本章的作用是把较近阶段放回更长历史过程，避免眼中只剩最近几个会名。

## c10-stage-05｜在同一条民族复兴长线上收束

现在回看全科，最早的问题是外来侵略与内部社会关系使民族独立、人民解放成为紧迫任务；不同救国方案受实践检验，新的思想、组织与群众力量形成，革命道路发展，抗战和国家前途较量之后建立新国家。取得国家政权又提出恢复、过渡和建设任务；社会主义制度建立不等于建设规律已全部掌握，曲折与探索推动后续思想解放、改革开放和现代化道路的发展。

本段复用原章 `whole_course_bridge` 的承接范围，不宣称这几句话重新证明前九章全部史实。收束原标签为：近代危机 → 各阶级救国探索 → 辛亥革命 → 五四与新的领导力量 → 新民主主义革命道路成熟 → 抗战胜利 → 解放战争与新中国 → 社会主义制度建立 → 建设探索 → 改革开放 → 新时代。箭头表示需要解释的历史承接，不是宣称每一步仅有一个原因或全部旧问题必然自动解决。

进入新时代就是在这条长线中理解新的历史阶段。这里的“民族复兴进入新的历史阶段”，不等于全部复兴任务已经完成，更不是取消此前阶段；新的物质、制度、理论基础与新的任务一起进入理解。史纲到此完成历史背景，随后学其他政治科目时调用这一背景，不再把同样近代史重新讲成第二门课程。

Source 对2035年的一个目标标志还有一句点拨。它是本版未来规划的表述，不是一个已经实现的事实；本轮不承担当期政策核验，因此该目标的精确提问保持 itemBLOCKED，交相应当前 Source owner 后才能判断是否适合现在学习和使用。历史课程收束不要求填满所有最新政策。
