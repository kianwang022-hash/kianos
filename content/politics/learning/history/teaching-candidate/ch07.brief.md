## 固定母模型与第一次开场

抗战胜利解除了日本侵略者企图灭亡中国的主要战争威胁，但没有自动决定中国将建立什么国家。第六章结尾的联合抗日，是特定战争任务下的合作；本章要看和平民主愿望、政权方案、社会利益与实际军事力量如何作用，而不是认为共同抗日自然等于共同接受同一种建国方案。

固定索引为原ch07.json chapter_compression.timeline：争取和平民主 → 全面内战 → 战略防御 → 战略进攻 → 第二条战线 → 民主党派政治选择变化 → 战略决战 → 新政协和新国家筹备。第二条战线、党派选择、战场发展会交叠，这是多条过程的教学索引，不是前一项全部结束后一项才出现。以原总模型第七章“国家前途较量”定位本章，不另造单纯战役史或第二套政党史。

先提出一个判断方法：每说某次胜利，补问它改变的是军事实力、社会支持还是国家制度准备。三者有关，但不能互相代替。三大战役摧毁主要军事力量，不等于在同一天完成整个新国家制度；协商建国也不是脱离军事与群众条件自行实现。

## H07-A｜争取和平不是无需准备，战争也不是预设结局

<a id="c07-answer-01"></a>

**节点主提示（H07／和平到内战）：1945年双十协定与1946年重庆旧政协各承诺什么，其后的全面内战从何时何地开始？三者为何不能互作已兑现的国家制度？**

首次完整答案：**1945年10月10日《政府与中共代表会谈纪要》（双十协定）确认和平建国基本方针并同意长期合作、坚决避免内战；1946年重庆政治协商会议达成政府组织、国民大会、和平建国纲领、宪法草案、军事问题五项协议，但非新民主主义性质；1946年6月26日国民党军队进攻中原解放区，全面内战爆发**。协议可具有政治意义却未实际阻止战争；不能拿旧政协当新政协，更不能把签署文件等于建国完成。乘风K02/K03、腿姐2027 PDF193双源支持。

Source K01说抗战后美国在中国采取扶蒋反共政策，国内权力竞争同国际条件相连；其国际格局完整变化首句截断，本稿不补造完整两极格局课程。原章着眼国家前途，保留国民党一党统治方向与共产党和平民主努力的差异，而不把国家统一的愿望直接等同某一方所有政策。

共产党提出“和平、民主、团结”，回应长期战争后群众休养生息和和平建国要求。政治谈判的意义在于争取一个可能的共同政治安排，并不是先保证对方一定履约才值得尝试。国民党一面准备战争一面表示谈判意愿，其目的和条件完整列表在当前Source仅有首项，因此本文不把两条提取开头扩成全套动机答案。

1945年重庆谈判后，10月10日签署《政府与中共代表会谈纪要》，即双十协定，确认和平建国基本方针，同意长期合作、坚决避免内战。这是协议内容与政治努力，不能按后来内战结果反推协议从不存在，也不能由签字推断承诺必然落实。

重庆政治协商会议由国民党、共产党、民主同盟、青年党和无党派人士代表参加，共38人；参与者范围不能同后来新政协组成混为一谈。会议达成政府组织、国民大会、和平建国纲领、宪法草案、军事问题五项协议。它们对应国家怎样组织、政治权利怎样安排、军队怎样处置等现实难题，不是五个互不相关名词。当前Source明说这些协议还不是新民主主义性质；其更完整意义和老/新政协比较表待核，不把老政协直接当成后来新政协已经建立。

与此同时，解放区有练兵、减租、生产三件中心工作。争取和平与保持军事实力、群众利益和经济供给相联系，不是“谈判便停止一切准备”。这种解释来自已接受S01的边界，不能反向推成双方谈判的一切行为都已事先只有战争一个目的。

1946年6月26日，国民党军队进攻中原解放区，成为全面内战起点。Source给1946年6月至1947年6月为战略防御阶段；先前和平尝试未阻止战争，不等于其社会政治意义为零。具体粉碎全面/重点进攻的地区和作战原则当前续行不足，不把军队名、战役名凭记忆灌入精记。

## H07-B｜从防御到进攻，为什么还必须看土地和国统区

<a id="c07-answer-02"></a>

**节点主提示（H07／军事阶段与节点）：解放战争战略防御、进攻、决战如何按时间区别？1947大别山、1948–49三大战役、1949南京各改变什么？**

首次完整答案：**1946年6月—1947年6月战略防御；1947年6月—1948年秋战略进攻，刘邓大军千里跃进大别山揭开战略进攻序幕；1948年秋—1949年初战略决战，辽沈、淮海、平津三大战役基本摧毁国民党主要军事力量；1949年4月23日人民解放军占领南京，标志延续22年的国民党反动统治覆灭**。解放战争**没有战略相持阶段**。时间节点与结果不可偷换，刘邓大军挺进大别山属进攻阶段，不把其事件日期硬记成“1947年6月已到大别山”。乘风K03/K04/K09与腿姐2027 PDF194–195支持。

<a id="c07-answer-03"></a>

**节点主提示（H07／土地和第二条战线）：为什么解放战争的胜利不能只看军队？五四指示的土地转向和国统区第二条战线分别有什么作用？**

首次完整答案：**1946年《关于土地问题的指示》（五四指示）推动减租减息转向“耕者有其田”的土地改革；1947年《中国土地法大纲》继续推进土地制度变革，动员广大农民、巩固群众基础**。**第二条战线**是**国民党统治区内以学生运动为先导的人民民主运动**，配合战场斗争，不是第二个军队战区。农民参与和政治支持并非因政策口号自动发生，仍须看土地利益与群众组织条件。乘风K05/K06、腿姐PDF195支持概念；K05原土地图表跨期政策勾叉需单项核原图，不推断所有富农条款逐字已验。

原S02说明人民解放军逐步转向战略进攻、战略决战，主动权随力量关系改变。这里沿原chapter使用“战略进攻”这一稳定节点；Source K04表同时出现“反攻/进攻”而TIP又否定反攻，且缺完整上下文，不能把文字噪声独立改成一套新的阶段术语。战略进攻具体开始事件、时间和部署的完整论述目前itemBLOCKED。

可以确定的是，1947年10月10日人民解放军总部发出“打倒蒋介石，解放全中国”的口号。它把战争目标指向全国政权问题，不代表当天所有地区均已解放。后来三大战役的胜利被Source定位为国民党赖以统治的主要军事力量基本被摧毁，“主要”“基本”是决定性限定，不能变成所有军队已经消失。

军事力量背后有群众、粮食、运输和社会支持。原S02已把土地政策、农民动员作为社会基础的变化：土地关系触及农民切身利益，实际利益和政治参与能使社会支持持续。不能仅以人口数量大便推出自动支持，也不能只把人民战争讲成指挥官战术优越。五四指示、《中国土地法大纲》及富农/中农政策的完整机制在Source表格中，当前只保留原章土地动员机制，精确政策与跨期勾叉留待原图/全文。

国民党统治区内部同样存在政治经济危机。原章把学生和人民民主运动称为第二条战线；Source TIP明确它是在国统区内部反抗国民党统治、配合解放军外线斗争。因此第二条战线不是另一个由正规军组成的地理战区，更不能与抗战中的敌后战场互换。

Source清楚指出一二·一运动昆明学生提出“反对内战、争取自由”。这是本题可核的一项具体诉求；其余运动事件、通胀财政和腐败因果的完整列表主要在表格或截断段，未核的明细不承担“本章三原因已完整讲授”的证明。已接受模型的政治经济危机可有界解释，具体排列须回Source补读。

## H07-C｜民主党派为什么选择合作，第三条道路为什么受限

<a id="c07-answer-04"></a>

**节点主提示（H07／第三条道路和党派选择）：第三条道路是什么历史方案，五一口号、《对时局的意见》和参加新政协处于怎样不同的政治转折？**

首次完整答案：第三条道路本质是**资产阶级共和国、旧民主主义道路的方案**，主张**政治上英美式民主、经济上改良资本主义、方法上和平改良**；其现实条件遭国民党压制且缺稳固权力基础。**1948年中共“五一口号”提出召开新政协、成立民主联合政府并获民主党派响应；1949年《对时局的意见》表达公开接受共产党领导的政治选择；参与新政协并在新中国参政是民主党派实际政治地位转变的环节**。书面响应、政治声明、实际参政三个层级不是同日同一件事。乘风K07/K08、腿姐2027 PDF196–197互证。

民主党派并非单一阶级政党。Source说明其少数成立于大革命和十年内战时期，多数成立于抗战和解放战争时期；这描述形成时期的分布，不能说所有党派都在同一个节点突然成立。Source的社会基础包括民族资产阶级、城市小资产阶级，以及同这些阶级相联系的知识分子和其他爱国分子，因而属阶级联盟性质。不能只因其中有民族资产阶级便把全体成员、诉求和行动都压成单一阶级的一种声音。

各党派政纲不完全相同，却有爱国反卖国、民主反独裁的共同方向；共产党积极争取团结，民主党派也在实际斗争中逐步选择接受共产党领导。原S03由此解释政治联合基础扩大，不把合作当成党派组织全部取消或所有思想差异消失。其历史选择需看真实力量格局，不讲成任何中间立场都天然没有价值。

第三条道路在本章有三个明确主张：政治上英美式民主但不许地主官僚资本家操纵，经济上改良的资本主义但不容官僚买办资本横行，方法上和平改良。它既不同于国民党的旧道路，也不同于共产党新民主主义建国方向；不能把反对独裁的共同点等同全部纲领相同。

Source从帝国主义不容独立富强资本主义中国竞争、国民党一党专政不容阻碍力量、民族资产阶级自身条件三方面解释受限；第三方面完整续行未返回，所以不制作“三原因全文”题。核心逻辑依原章保留：一个方案能否实行，取决于社会基础、政治组织、权力条件和所处冲突，不能只看它是否看上去折中。此为战后特定中国的历史解释，不外推为一切国家一切和平改革都失败。

1948年五一口号的响应推动新政协与多党合作的政治基础；1949年《对时局的意见》表达合作的政治选择。当前Source警示，这份意见本身不等于民主党派地位已根本变化；参加新政协并在新中国参政才是其地位变化的实际环节。完整五一口号、声明和参政段落仍有截断，保留事件角色，不自行造逐字政治文献内容。

## H07-D｜从旧政权瓦解到新国家准备

<a id="c07-answer-05"></a>

**节点主提示（H07／建国准备三层）：七届二中全会、进驻北平香山与新政协各负责怎样不同的历史转折？“两个务必”与《共同纲领》又在哪一层？**

首次完整答案：**1949年七届二中全会提出党的工作重心由乡村转向城市**，并提出**继续保持谦虚、谨慎、不骄、不躁的作风，继续保持艰苦奋斗的作风**两个务必；**中共中央领导机关和人民解放军总部进驻北平香山标志革命重心实际从农村转向城市**；**1949年中国人民政治协商会议第一届全体会议承担创建新中国的任务**，通过的**《中国人民政治协商会议共同纲领》在一定时期起临时宪法作用**。政策提出、实践转移、制度创建各有独立标志，不能把“临时宪法作用”当作1954年宪法。乘风K10、既有两个务必有界文字证据及腿姐2027下册PDF11、上册PDF197分别支持这些对象。

战略决战与继续进军改变国家权力条件。1949年4月23日人民解放军占领南京，Source以此标志延续22年的国民党反动统治覆灭。该节点同三大战役“主要军事力量基本摧毁”不同；更不能把占领南京自动等同全国每个地方所有新制度已建立。

国家建设需要不同于农村战争的工作。七届二中全会提出迅速夺取全国胜利的方针，Source列解决剩余国民党军队的天津式、北平式、绥远式三种方式；目前只完整给出三名称，不能自行补出各方式的操作与条件。在党即将成为执政党的情况下，毛泽东提出两个务必：务必使同志们继续保持谦虚、谨慎、不骄、不躁的作风；务必使同志们继续保持艰苦奋斗的作风。重点是执政条件变化后继续保持这些作风，不把它同后来三个务必换成一组。完整两句由PDF57对应的原Markdown续行读到，本次没有该页像素检查。全会提出工作重心由乡村转移到城市；随后中央领导、中央机关和解放军总部进驻北平香山，Source以此标志革命重心实际从农村转向城市。政策提出与实际转移有不同证据，必须各自配对，不能只把两个句子都缩成“七届二中转移”。

原S04的最后问题是怎样把政治联盟转化为新国家的制度基础。《论人民民主专政》把国家政权概括为工人阶级（经过共产党）领导、以工农联盟为基础的人民民主专政，为建国作政治理论准备；它与七届二中全会决议共同构成《共同纲领》的基础。新政协承担创建新中国的任务，《共同纲领》把这种政治准备落实为建国初期的共同规范。领导力量、社会基础、理论准备和制度文件因此各有对象，不能只把三个名称并列。《共同纲领》在一定时期起临时宪法作用是Source清楚文字；“临时宪法作用”不是说它就是1954年通过的那部宪法。其完整规定、国体/政体/经济/外交条目在当前提取段不足，不从题库选项或表格残句重新拼一份法条。

军事胜利不只需要解释为战场优劣。Source K11给出社会根源和雄厚群众基础、共产党领导的根本作用、国际无产阶级和人民群众支持等层次；原章将军事发展、土地群众、国统区危机、民主党派选择和建国筹备共同收束。完整胜利经验列表仅有各首行，本文不因熟悉“三大法宝”等术语便宣布原K11已全文覆盖。

新中国建立使民族独立、人民解放取得决定性胜利，同时开始新国家建设与社会制度转型。取得政权与完成社会主义改造不是同日任务。第八章将接着讲新生政权怎样站稳、怎样恢复经济、怎样过渡，而不再只问怎样赢得下一场战役。
