## 固定母模型与第一次开场

第七章以军事政治力量汇向建立新中国收束。新政权建立后，问题转成能否保持安全和秩序、恢复生产与生活、安排所有制和工业化、认识社会主义建设规律。不能用“胜利”一词把这些此后仍需完成的任务全部结算。

固定主链采用修正后的ch08.json chapter_compression.timeline：新中国成立 → 巩固政权和恢复经济 → 过渡时期总路线 → 社会主义工业化与三大改造 → 《论十大关系》与中共八大（1956年，过渡后期与改造收尾交叠） → 1956年底三大改造基本完成、社会主义基本制度建立 → 全面建设社会主义的探索 → 成就与曲折。本章在subject-model.md“后三章”承担国家成立后过渡与探索的位置，下一章才转向1978前后改革开放。

先用三个问题组织第一次讲解：1949后先怎样站稳，过渡时期怎样改变生产力与生产关系，制度建立后怎样建设。它们是同一八节点的三段展开。工业化与改造并行；1956年过渡后期的建设初探与改造收尾交叠，年底改造基本完成后进入全面建设，按上方主链直接恢复。政治制度、经济制度各有建立环节，不能用一个年份替代全部对象。

## H08-A｜新国家成立以后，为什么还要巩固

<a id="c08-answer-01"></a>

**节点主提示（H08／1949与四考验）：1949新中国成立解决了什么问题，初期面临哪四类考验？**

首次完整答案：**1949年新中国成立标志新民主主义革命基本胜利、结束半殖民地半封建社会历史、新民主主义社会在全国范围建立**，但国民经济与所有制转型未自动完成。四考验是**巩固革命成果和新生政权、恢复严重困难的国民经济、维护民族独立主权安全、经受全国执政新考验保持优良作风**。1950–53继续土改是民主革命遗留任务，不是1956农业合作化。乘风K01/K02与腿姐PDF82–84支持。

Source K01明确，新中国成立标志新民主主义革命基本胜利、半殖民地半封建社会结束、新民主主义社会在全国范围建立。民族独立、人民解放这第一项任务基本完成，不等于国民经济已经繁荣，或1956社会主义基本制度当时就全部建成。必须保留“基本”及任务对象，不能从“尚有任务”又倒推成立没有决定性意义。

新中国初期面对四类考验：保卫革命胜利成果和新生政权；战胜严重经济困难，恢复发展经济；巩固民族独立、维护主权安全；经受全国执政考验，保持优良传统作风。这四问分别涉及政治稳定、经济、外部安全和执政自身，彼此不能替代。国家名义成立不自动给出上述问题的解法。

完成民主革命遗留任务包括继续军事行动基本统一大陆、召开地方各界人民代表会议、在新解放区进行土地改革、通过婚姻法改变封建婚姻制度等。Source清楚给新解放区土改时间为1950至1953年春；这里废除封建土地制度同后来农业合作化改变农民个体所有制不是同一轮任务。土地和富农跨期表的勾叉/细则未核，不把“都是改造农村”当作一套不变政策。

原S01把主权安全、恢复经济和稳定秩序放在一起。外交三方针、抗美援朝详细评价在Source表内，现只保留原已接受的安全工作角色，不从残表新签精确口号及完整意义。经济恢复也为过渡提供条件，但K02具体措施和条件三项只有标题，不能自称已教完经济恢复全列表。

执政工作改变对人的要求：Source K02明确执政、接管城市、生活环境变化三种考验，说明取得领导地位后仍需制度和作风约束。三反、五反的对象有党政军机关与大中城市不法资本家之别；两者完整内容当前缺续行，不把名字中的“三”“五”凑成未检清单。

## H08-B｜一化三改为什么是相互配合的过渡

<a id="c08-answer-02"></a>

**节点主提示（H08／一化三改）：过渡总路线‘一化’与‘三改’各指什么，主体和两翼为何同时推进？**

首次完整答案：**社会主义工业化是主体，农业、手工业、资本主义工商业社会主义改造是两翼**；建国初先考虑工业化再改造，**1952年后转为工业化和改造同时并举**，兼顾发展生产力与变革生产关系。第一个五年计划1953年实施、突出发展重工业但非取消其他行业。乘风K03/K04与腿姐PDF85–86有范围支持。

<a id="c08-answer-03"></a>

**节点主提示（H08／农业合作化）：互助组、初级社、高级社的社会主义性质如何分别配对，手工业能否沿用相同组织名称？**

首次完整答案：**互助组—社会主义萌芽性质、初级农业生产合作社—半社会主义性质、高级农业生产合作社—社会主义性质**。手工业同为合作化却分别有**供销小组、供销合作社、生产合作社**等自己的组织名称。性质反映生产资料所有制改变的不同程度，不能因都叫合作即同质。乘风K05与腿姐PDF87、下册PDF25支持。

<a id="c08-answer-04"></a>

**节点主提示（H08／国家资本主义）：工商业和平赎买怎样从低级走向高级，何处四马分肥、何处定股定息？**

首次完整答案：**初级国家资本主义包括委托加工、计划订货、统购包销、经销代销；高级为个别企业与全行业公私合营。初级形式及个别企业公私合营以四马分肥分配利润，全行业公私合营实行定股定息**。这是对民族资本主义工商业的和平赎买和逐步改造，不是一次性发大笔补偿；统购包销不能混为粮食统购统销。乘风K06与腿姐PDF88支持分层，CF利润比例/图栏仍待核。

原章给过渡总路线的基本关系：社会主义工业化发展生产力，农业、手工业、资本主义工商业的社会主义改造调整生产关系，两方面相互配合。Source K03保留认识变化：建国初先考虑工业化再改造，1952年后转为同时推进；这解释认识是在现实经济政治条件中调整，不是从一开始所有步骤都已固定。

当时国营经济力量相对强，是工业化主要基础；资本主义经济弱且发展困难，不能成为工业起飞基础；个体农业改造被视为保证工业发展的必要条件；国际环境也影响选择。以上是Source四项理由的清楚文字范围。必要条件不是任意具体改造方法都会自动成功，不能以总方向替代对实施节奏和方法的检查。

第一个五年计划从1953年实施。指导方针突出集中主要力量发展重工业、建立工业化和国防现代化初步基础，同时相应发展交通、轻工、农业和商业并培养人才，保证社会主义成分稳步增长，在发展生产基础上逐步提高人民物质文化生活。突出重工业不等于其他行业无需发展，也不等于建设成果可以脱离人民生活来评价。

农业合作化有三种过渡组织：互助组具有社会主义萌芽性质，初级农业生产合作社为半社会主义，高级农业生产合作社为社会主义性质。名称与性质反映不同组织发展程度，不能把三者都因“合作”二字判成同一性质。Source的基本原则包括先合作化后机械化、积极发展稳步前进逐步过渡、自愿互利、典型示范逐步推广、发展一批巩固一批、始终以是否增产衡量办得好不好，以及社会改造与技术改造结合；实现合作化以后还要努力用先进技术和装备发展农业经济。先合作不等于永远不要机械化，自愿互利不等于只完成组织数量便算目标实现。

手工业改造提出积极领导、稳步前进，从供销入手、由小到大由低到高，逐步进行社会主义改造和生产改造。农业、手工业合作化到1956年底基本完成；乘风手工业组织节点仍只有标题；本段主提示已按腿姐上册PDF87给出供销小组、供销合作社、生产合作社的同事实参照，不用农业组织名替代，也不将该参照冒称乘风续文已恢复。

资本主义工商业改造在原S02中是总路线第三种改造对象。完整读到的实质是把民族资本主义工商业改造为社会主义性质企业，并对民族资产阶级实行赎买政策。这是在改变企业性质和社会关系，不把“改造”理解成只有企业换个名字。

国家资本主义先分初级、高级两个层次。初级形式包括委托加工、计划订货、统购包销、经销代销，是国家与私人工商业的外部合作，具有社会主义萌芽性质，企业生产经营开始进入国家计划轨道。高级形式总称公私合营，其下再分个别企业和全行业：前者具有不同程度社会主义性质，原表括注半社会主义；后者具有完全社会主义性质。四个初级例子与高级的两分支不是六个同层项目，不能横着扫一行表就抹平合并格的层级。

同一表的分配方式列中，初级和个别企业公私合营都写“四马分肥”，全行业公私合营写“定股定息”。分配名称相同不证明前两者企业性质相同，须仍按阶段和性质各列配对。原表的比例括注已被reader看清，但receipt没有四马各份额、百分数基数或额外期间定义，本轮不补写这些数值含义，也不把它们列为评分内容。

另要区分统购包销与统购统销：前者在63页表内四种初级形式中；64页文字旁注明确后者不属于初级形式，指新中国初期粮食资源的计划经济政策。该旁注仅通过文字读到，不能冒称看过64页像素。这一边界防止两个近似名称混写，并不增加另一张当期经济政策表。

## H08-C｜过渡后期到制度建立，为什么建设道路仍需探索

<a id="c08-answer-05"></a>

**节点主提示（H08／1954和1956）：1954年人大宪法、1956年底三改基本完成，分别标志什么？**

首次完整答案：**1954年9月一届全国人大召开和《中华人民共和国宪法》制定颁布是社会主义民主政治建设的重要里程碑**；**1956年底社会主义三大改造基本完成，标志社会主义基本制度确立和进入社会主义初级阶段**。1949建国主要解决新政权与民族民主革命历史任务，不能把它直接当成1956制度确立。乘风K07与腿姐PDF89支持。

<a id="c08-answer-06"></a>

**节点主提示（H08／建设初探）：《论十大关系》和中共八大的作用、基本方针及主要任务有何区别？**

首次完整答案：**《论十大关系》是开始独立探索适合中国情况社会主义建设道路的良好开端，基本方针为调动一切积极因素为社会主义事业服务**；**中共八大**判断改造后的主要矛盾围绕**人民建设先进工业国的要求与落后农业国现实、经济文化迅速发展需要与现状不能满足**，要求**集中力量发展生产力、实现工业化**，经济建设方针为**既反保守又反冒进，在综合平衡中稳步前进**。乘风K09/K10与腿姐上册PDF90、下册PDF11/21支持主题对应；原CF逐字两长句仍有Source截断，不能称已核全文。提出“第二次结合”探索不等于完成。

<a id="c08-answer-07"></a>

**节点主提示（H08／基本矛盾）：社会主义社会两对基本矛盾是什么，能否同敌我与人民内部两类矛盾相互替换？**

首次完整答案：**生产关系与生产力、上层建筑与经济基础**之间的矛盾是社会主义社会的两对基本矛盾，可经制度自我调整完善解决；**敌我矛盾与人民内部矛盾**是性质不同的社会矛盾，不能一概用同种方法。前者是社会结构关系，后者是社会矛盾性质，概念层级不同。乘风K11及腿姐下册PDF21相关理论支持。

1956年社会主义改造逐步完成，年底基本完成并确立社会主义基本制度，是原章的制度转折；同年过渡后期，《论十大关系》和八大已经开始回答建设道路问题。制度转变不等于工业化全部完成、生产力已达到发达水平，更不等于全部建设规律已经掌握。Source K07还把社会主义基本制度确立称为中国历史上最深刻最广泛的社会变革，这里的评价对象是制度转变，不是某一单项工程。政治方面，Source把第一届全国人民代表大会召开作为人民代表大会制度确立标志；它与所有制改造完成的时间和对象不同。这里接回C07：1946年重庆旧政协没有完成建国，1949年新政协承担创建新中国的任务，《共同纲领》一度起临时宪法作用；1954年一届全国人大通过《中华人民共和国宪法》，不能把前后的会议和文件当成同一项制度事件。

《论十大关系》标志开始探索适合中国国情的社会主义建设道路，基本方针是调动一切积极因素为社会主义事业服务。Source举三个清楚关系：重工业是重点，同时更多发展农业、轻工业；共产党与民主党派长期共存、互相监督；学习一切民族国家长处，但不能照搬。学外国不等于复制全部制度，不照搬也不等于拒绝学习。本文没有完整十项关系原文，因此不会把三个例子冒充全部十项。

八大根据国内形势和主要矛盾变化确定新任务：集中力量发展生产力、工业化并满足人民需要。精确主要矛盾两种表述在本shard只有标题，原章保留的“矛盾变化→建设任务”机制仍可解释，逐字目标必须等正文补齐。经济建设方针既反保守又反冒进，在综合平衡中稳步前进；政治建设强调扩大民主健全法制、有法可依有法必依。八大通过的新党章是共产党全国执政以后制定的第一部党章；“全国执政以后”限定不能去掉而说成党的第一部党章。陈云“三个主体、三个补充”在当前Source仅名称，不能借熟悉知识补为已看原文。

关于社会主义社会的矛盾，Source区分两个基本矛盾与两类社会矛盾。基本矛盾仍为生产关系/生产力、上层建筑/经济基础，教材论述其非对抗性及可经制度自我调整完善解决；社会矛盾另区分敌我矛盾和人民内部矛盾。两个分类维度不同，不能将“基本矛盾非对抗”读成任何具体社会矛盾都没有对抗性，更不能用一种处理方法不分对象套到底。

正确处理人民内部矛盾成为国家政治生活主题，与调动积极因素的建设要求相连。各领域方针配对在表格，当前不签准“政治思想/分配/科学文化/党派”完整卡片。历史方针的八字/十六字年份比较也需原表核验；不把1950年代历史教材转成现行政策问答。

## H08-D｜评价建设探索，要把成就与错误同时放在真实范围里

<a id="c08-answer-08"></a>

**节点主提示（H08／调整和外交事件）：1961年的国民经济八字方针、1971与1972两外交事件分别是什么？**

首次完整答案：**1961年国民经济调整八字方针为调整、巩固、充实、提高**；**1971年10月中华人民共和国恢复在联合国的合法席位和一切合法权利**；**1972年2月尼克松访华，中美发表《上海联合公报》**。一个属于经济纠偏，一个是恢复国际组织席位，一个是中美关系变化，不能把恢复说成首次加入，也不能把公报说成正式建交。1961年调整八字由乘风K12与腿姐下册PDF12互证；1971、1972外交节点的具体年月和事项由乘风K13-N05-I02/I03支持，腿姐上册PDF91只作国际地位改善的概括参照。主要作历史节点识别，不扩成科技年份长表默写。
