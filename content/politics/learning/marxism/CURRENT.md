**Per-chapter finished Content must contain exactly these learning jobs, using the existing owners rather than a new parallel file/system:**
1. **主模型 / mainline:** the high-density chapter reasoning structure needed to reconstruct the chapter's problem, relations, conditions, hierarchy and decisive choice-question boundaries. It must remain source-faithful and map back to the existing canonical spine; a thinner personal view may visually group adjacent nodes but does not create a second canonical model.
2. **Core:** important explanation, mechanism, contrast, boundary and source detail needed to understand/judge correctly but not worth forced active enumeration.
3. **节点主提示 / main prompts:** only knowledge that (a) Leg27 shows is worth active retrieval at the required depth and (b) naturally belongs to a model node so the model can help remember it. The first readable Content must state the full answer and relation before later review uses the compressed prompt.
4. **Residual Precision / Memory:** only retained knowledge that Leg27 justifies as exact retrieval **and** is awkward/unreliable to recover through the model node. Reuse existing IDs/owners when possible. Do not duplicate the same routine burden in both Prompt and Memory.
5. **Source boundary / unresolved gap:** keep any Chengfeng/Leg27 mismatch, UNCLEAR field, or scope limitation explicit and item-scoped. Do not silently repair Source with model knowledge.

**Placement rule — always in this order:**

```text
read actual Chengfeng chapter
→ build / verify the best source-faithful model and Core
→ inspect matching Leg27 retention passage
→ decide whether each proposed item deserves active retrieval and at what depth
→ if worth retrieving and model-bound: Main Prompt
→ if worth exact retrieval but model-resistant: residual Memory
→ if mainly understanding / recognition / lookup: Core / Source only
```

Never start from the old card catalog and work backwards. Never treat “precise”, “listed”, “high frequency”, “already has a card”, or “appears in Chengfeng” as sufficient evidence that Kian should memorize it.

**Required recall-depth judgment:** for every retained group, decide whether the exam job is recognition, option discrimination, conceptual paraphrase, complete membership, exact pairing, or genuinely fixed wording. Do not upgrade a recognition-level point into unaided enumeration merely because a compact numbered prompt is possible.

**Existing-card transition:** preserve IDs, answers and Recall history. As each chapter is reviewed, old cards may remain optional reference/practice, be absorbed conceptually by a model prompt, or remain recommended residual Memory. Do not mass-delete/rebuild the catalog and do not preserve a future burden merely to protect an old card count.

**Local acceptance gate for every chapter before advancing:**
- **Source coverage:** the actual Chengfeng chapter and necessary figures/tables were inspected; the matching Leg27 range was inspected and is not an unresolved UNCLEAR dependency for the selected exact claim.
- **Model quality:** without prompts, the mainline still reconstructs the chapter's real logic, conditions and major exam distinctions.

- **Memory economy:** Prompt + residual Memory cover the selected retention burden without routine duplication; omitted lists remain available in Core/Source rather than being silently converted into Memory debt.
- **Anti-invention:** no Chat-made extra doctrine, invented member count, unsupported source reconciliation or Website-driven structure.
- **Truth boundary:** Content completion is not learner study, Recall success or mastery.

**Write path:** update the existing chapter quick-review / brief / support owner and the minimum necessary Marxism cursor. Do not create another chapter summary system, retention registry, Memory catalog, “final notes” tree or learner-facing fourth layer. Read back the exact saved owner before claiming persistence.
