## 2026-09-18 hierarchy correction

Real learner-facing review exposed two Content defects in the original S02 calibration.

### A. H1 had become too rich

The original semantic object is intentionally rich, but first-entry attention must be smaller:

- H1: four characteristic labels;
- H1: one concise organizing relation explaining how the four form one whole;
- H1: three contemporary-value role labels;
- H2: decisive first-round boundary / exact carry when timely;
- H3: node meanings and the practice deepening chain;
- H4/H5: later precision/reference.

Node meanings therefore no longer ride inside PRIMARY merely because the same `framework_map` owns them.

### B. Edge wording duplicated its own target

The old edge shape encoded:

```text
人民性 → “集中体现为革命性” → 革命性
```

which repeats the target inside `relation`. The semantic edge is now normalized as:

```text
人民性 → “集中体现为” → 革命性
实践性 → “集中体现为” → 革命性
发展性 → “集中体现为” → 革命性
科学性 → “提供科学基础” → 革命性
```

The total organizing relation is owned once as an H1 Anchor:

> 人民性、实践性和发展性集中体现为革命性；革命性以科学性为基础，并与科学性高度统一。

This is a Content correction, not a renderer optimization. UI must render the resolved learner surface; it must not detect/rewrite repeated semantic targets on its own.
