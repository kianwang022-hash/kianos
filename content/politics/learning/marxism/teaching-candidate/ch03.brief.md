# C03 实践、认识、真理与价值：教师连续备课候选

<a id="c03-learner-entry"></a>

### 本章首次进入与前章取回

开章收回 C00/C01 的实践预告：从“实际做事会改变对象，也会改变认识”起步，现在才完整讲实践定义、三特征、三要素、三类型。沿原八节点解释从现实活动到认识、从认识回到现实检验，再进入真理和价值。

先解除两个默认前提：C01 的意识能反映世界，不表示所有反映都正确；C02 的现象/本质是对象关系，感性/理性是认识形式。两者在本章需要建立联系，但不是两组词直接画等号。


本稿派生于既有 ch03 的三单元，不改正式知识身份：POL27-CF-MARX-C03-S01（K01–09）、S02（K10–13）、S03（K14–16）。源书章名为“认识论（实践与认识及其发展规律）”。A/B/C仅是学习去向，必要定义、条件和关系边界现在即解释，C只接精确记忆。教师目标是让学生沿同一问题连续理解：人怎样在客观世界中形成认识，怎样知道认识正确，又怎样把正确认识用于有目的的行动？

## 本轮首课、分组编码与准确检索

<a id="c03-first-lesson"></a>

第一课沿“主体怎样现实接触对象—认识怎样形成与上升—怎样检验—为何还要评价价值—怎样回到改造与自由”连续讲。先以一个调查问题走完实践、材料、判断、行动、结果反馈，说明知道不等于做到；再补定义和准确成员。不要以二十三组精记题顺序取代这条认识循环，也不能把S01概览算成全部形式与条件都已讲。

<a id="c03-encoding-practice"></a>

第一组编码围绕实践：先判断是不是现实改造，再问客观条件、目的组织、社会历史；结构用谁—对象—中介，主体又分能力形态任务；双向转化用能力进入对象、对象因素进入主体区分；类型以生产为基础展开社会政治与科学文化，虚拟另标派生。第二组按来源—动力—目的—检验恢复决定作用，其中动力再展开需要、条件、能力三机制，间接经验不取消实践来源。

<a id="c03-encoding-cognition"></a>

认识过程先分别解释感觉知觉表象、概念判断推理，再编码“单属性—外部整体—记忆再现”与“共同规定—关系肯否—由已知推新判断”。理性依赖感性、感性有待深化、两者相互渗透三关系齐备后，才恢复第一飞跃两条件与四加工词。第二飞跃要讲完整目的、理念、方案、实验、方法、组织宣传，不因更重要就抹掉第一次。两种因素与两阶段是两种分类，不能机械一一对应。

<a id="c03-encoding-truth"></a>

真理组先分正确内容与检验标准，再问同题同条件的唯一正确性；绝对/相对分别抓正确内容和认识能力、范围广度和深度。真误题要固定对象条件，再谈变化与纠错，不把同一正确内容说成同时错误。实践唯一标准用主客观符合与直接现实性解释，逻辑帮助论证却不能替代现实检验；确定与不确定分别定位最终标准和具体历史实践，避免一次成功就永久免检。

<a id="c03-encoding-value-action"></a>

价值组先问对谁有何意义，再分别恢复主体、客观、多维、社会历史四特性。评价虽有主体参与却须真实对象与需要作依据；课程的人民利益等规范尺度明确标作价值立场。最后将真理尺度的合规律与价值尺度的合目的接回实践，再从认识/改造与自由/必然收束。创新以实践基础和理论指导作不同方向，不造对等决定箭头。

<a id="c03-retrieval-rule"></a>

闭卷只呈现选中对象的自足题面，答案、标准和cue在揭示前隐藏。若将表象放进理性阶段，先修阶段与形式；若把灵感等同感性，先修因素与阶段；若以有用证明真，就分事实符合与价值意义；若把相对真理当谬误，先固定正确内容；若知道规律但不能行动，就补实践条件而非把自由仅说成知识量。误述按本题范围最小诊断，未问防误解不因没主动说扣分，补讲后会跟说不登记新无提示成功。

<a id="c03-compression-entry"></a>

同模型压缩仍沿[原章JSON的固定八节点](#c03-canonical-eight)：人通过实践与客观世界发生现实联系 → 实践产生认识并推动认识发展 → 认识从感性材料上升为理性把握 → 理性认识必须回到实践并接受检验 → 真理要求正确反映客观实际，同时具有具体条件和发展性 → 实践是检验真理的唯一标准 → 现实行动还包含价值选择，但价值必须以尊重客观规律为基础 → 认识世界和改造世界最终统一于不断发展的实践。准确目标须从这条原解释展开，不能独立背cue代替模型。原Current Chapter承接FIRST_ROUND_EXACT，无W/U也可由Chat按实际授课选择，但目录准入不自动排程、不推Kian已学、不改NU或原题答案。

## 持续备课阶段与八节点定位

本节只为原完整解释、原B补全和原精记对象增加可回到原段的入口。四个准备阶段可按待讲问题继续、回退或重读，不是四个新NU，也不把一次首课概览当作本章全部题项已经解释。正式知识身份仍用上文三单元。定位完成不等于正式采纳、学生学会或网站已经消费。

<a id="c03-preparation-stages"></a>

### 可继续的准备阶段

- 实践入口准备：沿[节点1](#c03-node-1)至[节点2](#c03-node-2)读原定义、结构、关系、类型和认识来源，再按各节点B补全回到原例。续接问题定位在原段，不另造题情。
- 认识运动准备：沿[节点3](#c03-node-3)至[节点4](#c03-node-4)按原连续正文顺序展开阶段/形式、第一飞跃、第二飞跃、因素分类和认识循环；节点3另挂因素段仅供跨段辨析，不改连续授课顺序，定位仍以原题实际所问为准。
- 真理与价值准备：沿[节点5](#c03-node-5)、[节点6](#c03-node-6)、[节点7](#c03-node-7)展开正确内容及其条件、检验标准、价值关系和双尺度；同时保留[原来源差异](#c03-source-differences)。
- 行动收束准备：沿[节点8](#c03-node-8)回到认识改造、自由条件和创新方向，再恢复下列同一八节点；若某处解释仍不能展开，回对应原段继续，不新增一套闭卷主线。

每一阶段都可接同一准备流程：先读完整解释，再选原B补全；确认选中原题的全部所问子项与条件已解释后，才按[原闭卷规则](#c03-retrieval-rule)准备该题检索。初次提示只用该原对象prompt；items、checking_criteria、memory_cue和admission/admission_basis仍以原JSON为准。本节不复制或修改这些字段，不把定位表当新答案或新准入。需要精确成员、原段只有概括处，继续对照同一个原对象，不凭段落标题推定整题已教。

## 连续讲解主线

### 先把“实践”同想法、经验和一般活动分开

<a id="c03-practice-definition"></a>

现在收回 C00 的书—理论对应：马克思《关于费尔巴哈的提纲》强调实践观点；列宁《唯物主义和经验批判主义》强调生活、实践在认识论中的首要地位。先把“不是只解释思想，而要说明现实活动怎样形成认识”讲明，再进入下列定义与三组三项。两本书按既有 Core 识别，不新建残余记忆；这里要主动恢复的是已经筛中的实践概念结构。


前章说世界具有客观联系和发展规律，尚未回答人凭什么认识它。入口不是坐在脑中推演，而是实践：人能动地改造世界的社会性物质活动。它有目的，却不是纯意识活动；读书思考可以服务实践，不因有思考就自动等于实践。古代把实践限于伦理行为、康德强调道德活动、黑格尔理解为精神活动、费尔巴哈侧重日常生活与生物适应，都未完整把握这种社会物质活动；马克思在《关于费尔巴哈的提纲》中确立科学实践观，“全部社会生活在本质上是实践的”要指社会形成运行依赖人的现实活动，不能把所有社会观念等同一次物质操作。

<a id="c03-practice-characteristics"></a>

三特征同在：客观实在性是主体、客体、工具等要素以及活动条件客观，实践能把观念方案转成现实，所以有直接现实性，客观实在性是实践的本质属性；自觉能动性是按目的主动活动，不等于不受规律约束，建筑师的预先构想区别于动物本能和机器依程序运作；社会历史性是活动处于一定社会关系和历史条件，个人劳动也使用社会形成的知识工具，不能因独自操作就说它无社会性。企业家“既知道又做到”的源题侧重直接现实性，不能只因他有计划就误换成题干未突出的特征。

<a id="c03-practice-structure"></a>

实践结构是主体—中介—客体。主体是有现实活动能力的人，包含个体、群体、人类层次；自然能力与精神能力共同起作用，知识性因素在源表被列为首要能力，但情感意志等非知识因素并未消失。主体提出目的、操作工具、改造对象。客体是实际进入该活动范围的客观对象，不等于全部客观世界；同一棵树尚未进入某次活动时，不是那次活动的客体。中介既有工具设备等物质系统，也有符号、程序等系统；显微镜扩大可观察范围，不证明人的现有感觉能力是最终不可超越的界限。

<a id="c03-practice-relations"></a>

实践关系是主体与客体之间最根本的关系，认识关系和价值关系在实践中生成；认识活动也有主体、对象、中介，但认识的主观反映不能替代实践的现实改造。主体客体化是人的能力在对象中实现，例如把树加工为筷子；客体主体化是对象的因素转入人的能力或身体状态，例如药物被身体吸收发生作用。二者不是单向抹消对象或主体，而是相互作用推动人和世界变化。

<a id="c03-practice-types"></a>

基本类型为物质生产、社会政治、科学文化实践。物质生产最基本，是其他活动的基础；另两类又反作用于生产。科学文化实践要有现实操作、实验和社会活动，不能把脑内想象都叫物质实践。虚拟实践借助网络设备和社会关系，是实践的派生形态，具有交互、开放、间接等特点，具有相对独立性，可扩展人的自由活动，不能另造第四种基本类型，也不能称完全脱离现实条件。

### 实践怎样形成认识，又为何不是一次就学完

<a id="c03-practice-cognition"></a>

实践对认识有四个作用，必须分别讲机制。来源：人在改造对象中取得经验材料；个人通过书本得到的间接经验，最终仍来自他人实践，不能推出每个人必须亲自做过所有事情。动力：新问题提出需要，活动供给材料与工具，活动还提高主体认识能力。目的：认识服务改造世界，不把探索兴趣否认掉，也不把停在解释当最终目的。检验标准：认识是否符合对象，须通过实践比较，后面还要展开唯一性及历史限制。认识具有相对独立性，可以超前预测，也可以错误并造成后果，反作用须经实践，不与实践并列为同等决定作用。袁隆平水稻题以书本、电脑种不出水稻突出实践是认识的基础和来源；D项把第一飞跃说成比第二飞跃更重要，不能倒置。题中并没有两次水稻认识事件，不按错误选项编造题情。

<a id="c03-cognition-essence"></a>

认识本质是主体在实践基础上对客体的能动反映。唯心主义先从思想出发制造或解释对象；旧唯物主义虽坚持物到思想的反映方向，却把反映理解得直观、被动，缺乏实践和发展观点；辩证唯物主义把反映与创造性统一起来。想象龙可重组现实动物材料，创造性不等于凭空无来源，反映性也不等于照相复制。认识深入使我们改正对本质的判断，不使事物本质因我们的想法自行变化。

<a id="c03-cognition-forms"></a>

先重用 C02 的边界：现象和本质都是对象的关系，感性和理性都是主体的认识形式。看见水面折射形成的表象与通过分析认识规律，是认识由表及里的不同环节；表象未必就是错误，理性也未必就是真理。不能把“感性=现象=假，理性=本质=真”作为四词速记。


第一飞跃由感性到理性。感性认识来自直接接触，以具体形象反映现象和外部联系：感觉把握单个属性，是认识起始；知觉综合外部整体；表象是记忆中再现的形象，是感性阶段较高形式。理性认识以抽象形式把握本质、整体与内部联系：概念是思维基本单位，判断联结概念作肯否，推理从已有判断取得新判断。理性较高不是“最后认识”，感性有局限也不是“一定错误”，理性抽象也不保证真。

<a id="c03-first-leap"></a>

理性依赖感性，感性有待发展为理性，二者又相互渗透。感知受已有概念影响，理性须借助语言、形象材料表达。第一飞跃必须有丰富且合乎实际的材料，并经去粗取精、去伪存真、由此及彼、由表及里的加工；堆材料不自动产出本质，套概念也不能代替材料。只重理性而轻经验易教条，只重经验而轻理论易经验主义。源书“纸上得来终觉浅，绝知此事要躬行”提醒实践基础与亲历的重要性，不废除间接经验；“尽信书不如无书”要求批判核实，不反对读书；同一句话老年青年体会不同体现经验影响理解。“理解了的东西才能更深刻地感觉它”“机遇只偏爱有准备的头脑”说明已有理论准备进入观察，不是理性脱离经验。

<a id="c03-second-leap"></a>

收束这一飞跃时要求恢复三件事，而非只说“回到实践”：认识只有用于实践才能达到认识的目的；认识的正确性要在实践中检验；认识也在新实践中发展。由知到行不是自动发生，须结合具体条件使理论具体化，并形成可实行的行动。后面真理标准段再解释为何这一检验不能被理论自洽代替。


第二飞跃由理性到实践，更为重要：因为实践是认识目的，也是检验和发展认识的场所。“更重要”不取消第一飞跃。把理论变成行动要结合具体条件，明确实践目的、形成实践理念、制定实践方案、进行中间实验、运用科学实践方法，并对人民群众组织和宣传，使参与者理解并行动；不是背出理论就已完成现实转化。

<a id="c03-cognition-factors"></a>

理性因素包含理性直观、理性思维，发挥解释、预见、指导作用；非理性因素包括情感意志及联想、想象、猜测、顿悟、灵感，发挥激活、驱动、控制等作用。非理性不等于非理智错误，也不等于感性认识；两类因素都可参与两个认识阶段。科学工作中的审美追求与创造灵感可以促进探索，不能据此让情感代替证据。

<a id="c03-cognition-cycle"></a>

两飞跃不是一次封闭循环。对象本质展开、主体能力和工具提高需要过程，认识因而有反复性；世界及实践不断发展，认识具有无限性，表现为实践—认识—再实践—再认识的上升过程，不是原地同义重复。主观与客观、认识与实践的统一是具体的历史的：判断须符合该对象、时间、地点和发展阶段，条件变后不能固守旧结论。这不是“什么都随意变真”，而是先说明判断适用范围。

### 怎样区分正确认识、可行方案和有价值的目标

<a id="c03-truth-objectivity"></a>

真理是对客观事物及其规律的正确反映，是真理性的认识，不是物质对象本身。其客观性在于真理所正确反映的对象及规律不随主观意愿改变，是否符合对象由实践检验，而非由权威、多数同意或有用程度决定。来源客观本身不能证明正确，谬误也可以有现实来源；表达形式可以主观，但正确内容不能任意制造。把真理解释成多数组织起来的经验，或因为有用就是真理，均混淆了判据。一元性须限定同样条件、同一对象的同一方面、回答同一问题，互相矛盾的判断不能同真；不同方面的正确认识可以互补，同一正确内容可以用不同措辞表达。

<a id="c03-truth-two-aspects"></a>

任何真理都有绝对性和相对性。绝对性是其中含客观正确内容，并承认人类能够不断认识无限发展世界；相对性是当下认识在广度、深度上有限、有待扩展深化。不是两种真理，也不是两套任意表达。相对真理含有绝对真理的成分，发展中不断接近更全面认识；有限的既有结论不能立即充当无限世界的最后总答案。人类认识能力的无限性与个人、时代条件的有限性统一。夸大绝对性成为教条，夸大相对性滑向怀疑与诡辩。

<a id="c03-truth-error"></a>

谬误是对对象的歪曲反映，不能直接叫“相对真理”。在给定对象条件下正确和错误有明确区别；条件改变须重新判断，认识也可通过纠错转化。失败有学习价值，是从错误中发现成因并获得正确认识，不是错误本身因为有用就变成真理。某套认识部分正确部分错误时，应分别判断，不说同一内容在同一条件既真又假，也不把真理说成与谬误的折中。此处与源书“真理中包含着后来暴露的错误因素”等概括的边界见末尾差异。

<a id="c03-practice-test"></a>

为什么只有实践能检验？真理要求主观认识符合客观对象，仅在头脑中作自我证明无法完成双方比较；实践具有直接现实性，把方案施于对象，再依据结果验证。逻辑证明是探索论证真理和扩展认识的重要手段，是实践标准的重要补充、正确思维和表达的必要条件、建立科学理论体系的重要途径；但前提或与对象的对应可能有误，逻辑自洽不等于客观符合，所以它不能独立替代实践标准。实践标准确定性在于唯一、最终、归根到底；不确定性在于具体实践有历史局限，须在社会历史实践中反复检验，不能把一次失败或一次成功绝对化。已确证的客观正确内容在原适用条件下不因意见变化被取消；“这次验证过”的自我标签不能使整套理论永不修正，也不能按阶级各设一种真理标准。

<a id="c03-value-properties"></a>

价值回答对象对主体需要的积极意义，以对象属性、主体需要和二者关系为基础。主体性指对不同主体可能意义不同，不是主观愿望制造属性；客观性指需要及对象属性有实际根据；多维性指同一对象可满足不同需要；社会历史性指需要、利用能力和关系随实践发展。竹子可食、建造、书写等源例不是欲望使属性出现，而是活动把潜在价值变现实价值。

<a id="c03-value-evaluation"></a>

价值评价是认识和判断价值关系，具有主观性，但正确与否依赖对对象状况与主体需要的真实认识，有科学与非科学之分。事实判断问对象是什么，价值判断还问应怎样、是否满足需要；不能把评价意见当现实价值关系本身。源书以最广大人民的需要利益、人类生存发展、社会进步作为规范尺度，必须明确这是本课程采取的价值立场，不能声称从对象事实单凭因果逻辑自动推出全部规范。

<a id="c03-truth-value-unity"></a>

行动有真理尺度与价值尺度：既遵循规律，又满足合理目的。成功实践要二者统一，实践是这种统一的基础。价值目标要以正确认识为前提，需要又推动发现真理；有价值的想法未必正确，正确知识的价值也要在需要及实践条件中实现，不能承诺任何真理立刻带来任意收益。统一仍是具体的历史的，不造固定二维整章应用模板。

### 认识最终怎样进入改造与自由

<a id="c03-knowing-transforming"></a>

认识世界是有效改造世界的必要前提，改造是认识目的。改造客观世界也改变主体的能力与认识，改造主观与客观相互促进，实践使两者统一。人的需要和目的同客观世界实际状况不总一致，主客观矛盾推动认识改造深化；它不是下一章社会基本矛盾的另一个名字。

<a id="c03-freedom-necessity"></a>

自由是人在认识、利用必然中表现的自觉自主活动状态。必然是客观规律，不依赖人的愿望；它既是自由的根据，也是自由的限度。了解规律而有条件地运用，才能扩大自主行动；只有知识而无现实行动条件也不足。否认必然、把想做什么就能做什么叫自由，是唯意志论；只见必然而否认人的作用，是宿命论。意志自由是基于认识作决定的能力，不等于前一种错误。自由是历史形成、有认识与实践条件的，不能摆脱一切规律成为绝对自由；课程还要求不以牺牲他人自由为前提，这是规范边界。必然王国到自由王国指社会活动状态的历史进程，不是进入一个无规律空间。

<a id="c03-innovation"></a>

实践创新为理论创新提供动力与材料，理论创新立足实践又提供科学行动指南；良性互动是相互激发、共同促进；理论创新接受实践检验，并指导实践创新，不把两个“创新”写成无条件对等因果或互为真理标准。本章由此通向 C04：这些人在怎样的生产与社会关系中活动，何种社会结构制约目的、资源和行动？

### 主线：实践接触世界 → 实践产生认识 → 感性上升理性 → 认识返回实践 → 真理不断发展 → 实践检验真理 → 价值参与行动 → 认识与改造统一于实践

#### ① 实践：人不是在头脑里直接接触世界，而是通过现实活动进入对象

实践是人类能动改造客观世界的物质性活动。它不是纯思想活动：实践能实际改变对象并产生现实结果。乘风把实践的基本特征概括为**客观实在性（直接现实性）、自觉能动性、社会历史性**；基本结构是**主体、客体、中介**，主客体关系还表现为实践关系、认识关系和价值关系，其中实践关系最根本。基本类型为**物质生产实践、社会政治实践、科学文化实践**；虚拟实践是派生形式，不是第四种基本类型。

2027 腿姐 p23–25 同样用“实践的桥梁作用 + 实践333”集中组织这部分，并强调实践连接主观/客观、自然界/人类社会。

**主提示：`实践333｜桥梁作用｜主客体3关系/实践最根本`。**  
首次答案：3特征、3结构、3基本类型都在上段；桥梁是实践使主观/客观及自然界/人类社会发生分化又保持统一；三种主客体关系是实践、认识、价值，实践关系最根本。主体能力细分、客体化双向过程、虚拟实践具体特点留 Core，不为完整而强制枚举。

#### ② 实践决定认识：认识从现实接触中来，并被现实需要继续推动

实践对认识的决定作用不是一句“来源”就结束。它同时是**认识的来源、发展的动力、目的和检验标准**。直接经验是知识的源头，一个人的大量知识可以来自书本和传授等间接经验；间接经验不取消最终的实践来源。现实需要、技术条件和实践手段会推动认识发展；认识又能反过来指导实践，但这种反作用不改变实践的基础地位。

2027 腿姐 p22–24 明确强化“实践是认识来源/源头活水、认识世界和改造世界统一的基础、实践是检验真理唯一标准”，并在 p24 再列动力、目的和逻辑证明的边界。

**主提示：`实践→认识4作用｜直接经验=源/间接经验=流`。**  
四作用就是来源、动力、目的、检验；“源/流”用来防止把多数知识来自间接经验误判成认识不来自实践。乘风对动力三机制等细分保留 Core，做题时按材料调用，不另造长期清单。

#### ③ 感性 → 理性：认识先得到材料，再把握本质和规律

感性认识是在实践基础上由感官直接获得的关于现象、外部联系和各方面的认识，形式是**感觉、知觉、表象**；理性认识借助抽象思维把握事物的本质、全体、内部联系和规律，形式是**概念、判断、推理**。感性是理性的基础，理性依赖感性，感性有待深化为理性，二者还相互渗透。

从感性上升理性要满足两类条件：一是深入实践，获得丰富且合乎实际的感性材料；二是经过思考和科学抽象，对材料进行**去粗取精、去伪存真、由此及彼、由表及里**的加工。理性因素与非理性因素是另一分类：理性因素侧重指导、解释、预见，非理性因素如情感、意志、灵感、直觉起激活、驱动作用，不能把它们分别等同于理性/感性认识。

**主提示：`感性3↔理性3｜第一飞跃2条件/4加工｜理性vs非理性因素`。**  
2027 腿姐 p31–32 明确把这整组作为主动恢复对象。数字都来自 Source：感性三形式、理性三形式、上升两条件和四个加工方向；非理性因素不另拆卡，而与认识阶段区别一起恢复。

#### ④ 理性认识必须回到实践：认识的目的不是停在“知道”

具体一次认识包含两次飞跃：第一次从实践到认识，体现为感性材料上升为理性把握；第二次从认识到实践，把理论、方案和目的转为现实行动，**第二次飞跃更重要**，因为认识的目的在于改造世界。总的认识运动不是两步走完，而是在实践—认识—再实践—再认识中反复循环、不断发展。

乘风补充第二次飞跃实现要经过现实方案、方法、组织宣传等条件；这些是把认识变为行动的 Core，不要求为提示再背一串中介名称。

**主提示：`两次飞跃｜第二次更重要｜实践—认识循环`。**  
2027 腿姐 p32 直接以“两次飞跃 + 认识运动总过程”组织该内容。认识的反复性、无限性和具体历史统一继续由 Core 解释为什么循环不会机械重复，不强制另列三张概念卡。

#### ⑤ 真理：正确认识既有客观标准，又总处在发展过程中

真理是对客观事物及其规律的正确反映。**客观性**是真理的本质属性：真理所正确反映的客观内容不依赖人的意志，检验真理的实践标准也是客观的；仅说“来源于客观实际”不充分，错误认识也可能从客观材料出发。真理是认识，不是客观实物，其表达形式仍是主观的。客观性决定**一元性**：在同一条件下，对同一对象的同一方面、同一问题，就客观内容而言正确认识只有一个；不同方面的问题可以各有正确认识，同一内容也可有多种表达。

任何真理都同时具有绝对性和相对性。绝对性抓正确内容的确定性和人类认识发展的无限性；相对性抓具体认识在广度、深度和条件上的有限、不完善。二者是同一客观真理的两种属性，不是两种互不相干的真理。真理与谬误有原则界限，又会因对象、条件和认识发展发生边界变化，不能把“相对”理解为真假取消。

**主提示：`真理客观性/一元性｜绝对×相对`。**  
2027 腿姐 p28–29 明确把这两组作为专题十一的主体。乘风关于真误转化、认识反复性与无限性的更细辨析继续留 Core，用于防止“相对真理=谬误”“多数有用=真理”等错项。

#### ⑥ 实践检验真理：最终仍要让认识回到现实

实践之所以是检验真理的唯一标准，是因为真理要求主观认识与客观实际相符合，而实践具有把主观目的转成客观结果的直接现实性，能把二者真正联系起来。逻辑证明能够探索、论证真理并保证思维表达的必要严密性，但不能取代实践作为最终检验标准。

乘风还区分实践标准的确定性与不确定性：最终检验标准只有实践，这是确定的一面；具体实践总受历史条件限制，需要继续发展和反复检验，这是不确定的一面。2027 腿姐直接强化“唯一标准”和“逻辑证明不能取代实践”，未把“确定/不确定”单列成背诵专题，因此后者保留 Core。

**主提示：`实践=唯一标准｜逻辑证明≠最终检验`。**  
本节点只主动恢复决定性关系，不为术语完整性把实践标准两特点再拆成独立 Memory。

#### ⑦ 价值：行动不只问“对不对”，还问“对谁有什么意义”

价值是主体与客体之间意义关系的哲学范畴。它具有**主体性、客观性、多维性、社会历史性**：价值围绕现实主体需要形成，但不能由主观评价任意创造；客体属性与主体需要要通过实践形成现实价值；不同主体、不同关系和历史条件使价值表现多样。

价值评价是对客观价值关系的主观反映，不是随意表态。评价结果的正确性既依赖对客体状况的认识，也依赖对主体需要的把握。课程明确把“是否推动社会历史进步、是否符合社会发展趋势、是否维护和满足最广大人民的需要和根本利益”作为最高标准；正确评价要以真理为根据、与规律一致、以人民需要和利益为根本。

实践中的成功行动要求**真理尺度与价值尺度统一**：既合规律，也合目的。价值不能替真理决定事实，真理也不自动替主体完成价值选择。

**主提示：`价值4性｜价值评价最高标准｜真理尺度×价值尺度`。**  
2027 腿姐 p29–30 直接组织这三组，且 p24/p27 再强化“成功实践是真理尺度与价值尺度统一”。价值评价的逐条特点保留 Core；若以后真实错题只在某一句固定标准上反复串位，再复用原对象做最小加练。

#### ⑧ 认识世界和改造世界：整章最后回到实践

认识世界和改造世界不是两个彼此分离的任务：认识为改造提供指导，改造又继续产生新的认识条件，二者统一的基础仍是实践。主观世界和客观世界的矛盾推动认识和实践继续发展，所谓自由也不是任意选择，而要以认识并利用客观必然性为前提。

乘风还把实践创新与理论创新的良性互动放在这里：实践提出问题和条件，理论创新提供认识与行动指导；二者相互促进但不构成对等决定关系。2027 腿姐当前马原专题没有把“自由与必然定义/两条件”或“实践创新—理论创新配对”列为本章主动背诵组，因此它们留在 Core，而不是为了旧卡完整性强行背。

**主提示：`认识/改造统一基础=实践`。**  
腿姐 p22 明确把这一句列入“马哲第一梯队 K”。其余收束关系靠主模型理解，不再新增一组枚举。
