## 本轮首课、同模型编码与精记诊断

首课只围绕一个张力推进：**现实世界不由人的意识任意决定，但人的意识又确实能够改变现实，这两句话怎样同时成立？** 教师让每个新概念承担一次“跨过当前逻辑缺口”的工作：物质第一性解决现实独立性，客观实在性避免把哲学绑死在某一具体形态，运动/静止解释变化世界为何仍可辨认，实践把人放回物质世界内部，意识起源与本质守住派生关系，能动作用与规律条件解释“能改变但不能任意改变”，AI只做边界压力测试，最后回到物质统一性。

首课不要报“现在进入节点03/04”再逐段念定义；节点编号、K/NU和精记ID留在后台。讲完一个自然问题关口后，再用一句话指出它填实了固定十节点中的哪些位置。若隐藏所有标题和编号后，正文不能继续形成一个前问逼出后问的连续解释，就应回到主问题重组课堂表达，而不是继续按稿朗读。

每次只编码已经解释的一个范围。基本问题用“谁是本原／能否认识”分两轴，方法分野另问“怎样存在发展”。物质先抽共同规定，再保独立于意识与能被反映；其四意义分别解决本原、可知、辩证、自然历史统一。运动题以承担者与存在方式分主语；静止题以相对位置和根本性质两个稳定层次解释认识利用及衡量尺度；时空把具体对象/整体世界与客观存在/具体特性分两组，防止相对性取消客观性。

世界分化不能画成社会就是主观：实践使自然分化出社会、客观分化出主观，同时构成两组统一的关键。意识起源按自然反映形式发展和劳动社会实践两面展开；语言是物质外壳和现实形式，作用为促进，劳动在源中起决定作用。器官、源泉、本质、内容形式四问分开后，再用“目的计划—创造观念—经实践改造—调控身心”恢复四能动作用。认识世界与改变世界两个转化环节不可都缩成意识直接创造物质。

## 从导论进入本章

导论说明我们正在学习一套世界观、方法论及社会解放理论。现在先解决最底层问题：如果没有人的想法，这个世界还存在吗？如果存在，人脑中的思想、现实中的社会和我们制造的技术又处在什么位置？这不是问“思想重要还是物质重要”，而是问谁是本原，以及意识怎样产生和发生作用。

## 第一节哲学及其基本问题

<a id="c01-explain-01"></a>

先分清三种提问。哲学基本问题是思维和存在的关系，包含两个方面：物质和精神何者第一性，以及思维能否正确认识存在。第一个划分唯物主义与唯心主义；第二个划分可知论与不可知论。第一性说本原、派生关系，不是价值上的第一重要；“有同一性”说可认识，不是说思想与对象是同一种东西，也不是说人现在已经知道一切。教师若局部调用原分类表，先看末尾差异第1项：表中二元论与不可知论的概括不能讲成无例外定义。

承认物质第一性后，还要说明“物质”指什么。古代朴素唯物主义用水、火等具体实物解释本原；近代形而上学唯物主义把物质等同原子等某种形态；辩证唯物主义抽象出客观实在性。它们都承认物质第一性，但不能因此说观点全相同。旧唯物主义在自然观上唯物、历史观上唯心，不能说明社会生活的物质性，所以是不彻底的唯物主义。马克思的贡献不能写成首次创立所有唯物主义，应保留形成辩证唯物主义、创立唯物史观的区别。

唯心主义内部也要分：主观唯心把个人精神当本原，客观唯心把独立于个人的精神、绝对观念等当本原。“客观唯心”的客观修饰精神相对于个人的位置，不等于承认物质第一性。判断名言时要读它怎样回答本原，不凭人物名字或“有意识活动”认定唯心。

第三问是世界怎样存在和发展。辩证法用联系、全面、发展和矛盾的观点理解世界，认为内部矛盾是发展的根本原因；形而上学把对象孤立、片面、静止地看，否认内部矛盾的存在和作用。它不是哲学基本问题的第三个方面，而是另一组方法分野。唯物/唯心与辩证/形而上学可以交织，不可把唯物自动等于辩证、唯心自动等于形而上学。

这一节的局部对比只比较各自回答的问题：本原轴、认识可能轴、存在发展方式轴。这是马原考试框架下的分类工具，不是给整个哲学史的所有思想家机械贴标签。暂不把全章塞进二维矩阵。教师自然收口：我们的选择是物质第一性和辩证观点；下一节必须把“物质世界”展开，否则只是一个立场标签。

## 第二节世界的多样性与物质统一性

### 物质范畴怎样避开把具体当一般

<a id="c01-explain-02"></a>

石头、原子、场和社会生产关系形态不同，哲学不是把某一种列为永恒模型，而是抽象它们不依赖意识而存在的共同规定。物质概念是抽象，不是把各种物直接堆在一起；客观实在性是其唯一特性。列宁定义还同时保留不依赖感觉、能为感觉所反映两面，所以看不见摸不到不等于不存在，尚未认识不等于不可认识。“能被反映”也不要求每个人、每一时刻都直接感知。

这一物质观的意义可以逐项解释：客观实在性划清唯心一元论、二元论；可反映性保留可知论和能动反映；具体形态变化而共同规定稳定，统一唯物论和辩证法；自然和社会同属物质世界，统一自然观与历史观。近代形而上学唯物主义的缺陷在把特殊形态当一般，并割裂自然和社会，不只是“以前的人不知道新粒子”。“从个性见共性、相对见绝对、暂时见永恒”说的是这个抽象关系，不能推为每个事物都永恒。

### 一个物质世界如何既变化又保持可辨认

<a id="c01-explain-03"></a>

运动指一切变化及其过程，不仅是位置移动。物质是运动的承担者，运动是物质的存在方式和根本属性；物质与运动不可分割但不等同。设想无物质的运动丢掉承担者，滑向唯心；设想不运动的物质否认变化，滑向形而上学。唯一特性“客观实在性”回答何以是物质，根本属性“运动”回答物质怎样存在，不能互换。

<a id="c01-explain-04"></a>

一切运动并不取消稳定。相对静止是一定条件下相对位置或根本性质暂时不变，是运动的特殊状态。桌子可相对地面不动，内部仍有运动；一个对象在性质尚未跃迁时才可被持续辨认和利用。运动绝对、无条件，静止相对、有条件；二者相互依赖、渗透和包含。静止是认识利用事物的前提、衡量运动的尺度，也是过去运动的结果和未来运动的出发点。夸大静止否认运动是形而上学；夸大运动否认静止是诡辩论。河流例子检验的是这种边界，不能只记名言出处。

运动还具有时间和空间形式。时间是持续性、顺序性，特点一维性；空间是广延性、伸张性，特点三维性。时空是运动着物质的基本存在形式，不是另一个独立容器，更不是意识制造的框架。物质、运动、时空统一且不能直接等同。时空客观性说不以意志转移；具体事物的时空有限、整个物质世界的时空无限；客观存在的意义是绝对的、具体特性随运动特性变化是相对的。教师必须给出每个判断的主语，不能让“相对”误取消客观性。原材料高速运动例只用于识别具体时间特性变化，不把教材简化措辞扩为物理定律。

### 人的出现为何没有带来第二个本原

<a id="c01-explain-05"></a>

实践活动使世界发生二重分化：自然界中分化出人类社会，客观世界中分化出主观世界。两个划分不是同一条轴，不能把社会放进主观世界。客观世界包括自然界和人类社会；主观世界是人的意识观念和精神活动。社会通过有目的活动运行，但人的目的不能任意决定生产条件和社会关系，所以社会仍具有客观性。自然界的因果关系自发起作用，社会领域通过人的有目的活动实现；有目的不等于结果完全符合目的。

自然和社会交叉作用：人化自然有人的目的印记仍是自然物；社会生产利用自然物质和自然力，本身是人与自然的物质变换。主观世界从客观世界分化，具有相对独立性，能保留过去印象、构造不同于当前对象的观念，但不是孤立实体。实践既是分化的关键，也是统一的关键，统一是动态历史过程。元宇宙属于现实实践产物的延伸，不因虚拟性而成为独立本原的第三世界。人类社会是最高级物质存在形态属于来源固定判断，仍须以生产实践和社会结构解释其物质性。

### 意识怎样依赖物质又能发挥作用

<a id="c01-explain-06"></a>

意识的起源有自然史和社会史两面。物质反应特性、低等生物刺激感应、高等动物感觉心理直到人的意识，是逐步发展的反映形式；不能把一切反应都称为人的意识。社会实践特别是劳动起决定性作用，语言促进意识发展，是意识的物质外壳和现实形式。“劳动决定”不排除语言重要，“语言重要”也不等于决定。

本质上意识是人脑这种特殊物质的机能和属性，是客观世界的主观映象。人脑是器官和生理基础，客观世界是源泉；意识不是人脑本身、分泌物或一种特殊物质，也不能由人脑脱离客观世界自主产生。内容客观说内容来源于客观世界，形式主观说经主体加工，不保证每个认识正确。虚构鬼神也是对现实材料的加工，不是客观鬼神进入脑中；其是否正确指向认识与对象是否符合，教师见末尾差异第2项：源表“虚幻反映不能用对错形容”的范围未决，不把它当认识没有真假。

<a id="c01-explain-07"></a>

意识不是机械照相。它有目的和计划，选择反映对象；具有创造性，加工感性材料、把握本质、追溯过去和推测未来；指导实践改造世界；调控行为和生理活动。必须当场讲“通过实践”：规划房屋不等于房屋已经存在，实施规划才把观念转为现实。错误意识同样可指导实践，但指导作用不保证有效、正确或有益。能动性实现受时代实践水平、现实条件和物质手段制约，不能由想得到推出办得到。

物质与意识既区别又联系：物质本原、意识派生，不能互相代替或直接等同；意识依赖物质又相对独立，物质决定意识而意识反作用于物质。源文的“物质转化为意识”须解释为现实被认识反映，“意识转化为物质”须解释为通过实践对象化，不讲成两种实体自由互换。“同一性”保留可认识的意义，不能冲掉类别区别。

### 能动性怎样在规律中获得现实效力

<a id="c01-explain-08"></a>

规律是事物变化发展中本身固有的内在、本质、必然联系，不是人为命令或每次出现的表面现象。自然和社会规律均客观；自然规律自发作用，社会规律通过人的自觉活动实现，不能把后者解释为由意志创造规律或人人自觉掌握规律。

尊重客观规律是正确发挥能动性的前提；发挥能动性才能认识利用规律；实践是二者统一的基础。因此必须明确：从实际出发也是正确发挥主观能动性的前提，实践是基本或根本途径，物质条件和手段提供实现支撑。人不能创造、改变、消灭规律，却能认识利用规律、改变其作用条件和具体实现形式。重复性、稳定性不等于任何旧规律在任何新条件下都起同样作用。这里的双向联系不是相互决定：主观能动性不能决定客观规律。

用“有多少汤泡多少馍”先解释现实条件限制目标，再说明人在条件内可以设计利用方式。源题与改题强调不同，学生要按材料实际表达判断，不能看见“人做事”就把所有能动性选项打包。适度在第二章有更完整条件，本章只作桥接，不偷改题目答案。

### 技术扩展为什么仍回到统一的物质世界

<a id="c01-explain-09"></a>

人工智能在本章 Source 中是部分智能活动的机器化，是对人脑组织结构和思维运行机制的模仿及人类智能的物化。它可以在计算速度、准确度和程序化任务等方面超过人，却不能由局部优势推出全面替代人类意识。来源以知情意统一、人的社会性、自然语言意义、可数字化内容的限度说明区别；承担社会功能不等于具有人类社会属性，模拟智能活动不等于拥有人的意识。脑机接口例同样通过设备和物理运动实现对象化，不能删掉物质手段而说意识直接搬动物体。教师见末尾差异第3项：这里保留 Source 的考试判断，不外推成所有未来技术的无条件结论。

<a id="c01-explain-10"></a>

最后收束物质统一性，不是把所有东西都叫“物质”。自然先于人并不依赖意识；人化自然可变形态结构，不改客观实在性。社会的自然基础、生产活动是物质的，生产方式构成社会存在发展的基础；社会有精神现象不取消这一基础。意识从起源、本质、作用条件上统一于物质，但意识本身不等于物质。世界的统一性在物质性，不在一种具体物质形态。该原理是辩证唯物主义最基本最核心观点、马克思主义基石；一切从实际出发是方法论落点，不是先有愿望再把世界配成愿望。

## 骨架学懂后的补全讲解

<a id="c01-supplement-01"></a>

哲学名言不要按“有没有心字”猜。“存在就是被感知”“物是感觉的复合”“万物皆备于我”把个人感觉精神当本原，落在主观唯心；“世界是绝对观念的外化”“世界是上帝意志创造物”把超个人精神当本原，落在客观唯心。“穷则变，变则通，通则久”“祸兮福之所倚”强调变化和相互联系，体现辩证观点；“天不变，道亦不变”否认发展，体现形而上学。人物和短句归类保留原表的具体语境；不能由一个人的某句观点把该人的全部思想判成一种单一类型。“机械唯物主义”和“形而上学唯物主义”的命名也不能无条件当同义词，前者突出用机械运动解释一般世界，来源提示其范围较窄。

<a id="c01-supplement-03-04"></a>

静止的两个层次要分别举例：相对位置不变不能证明内部没有变化；根本性质暂时不变不能证明所有数量都不变。“人不能两次踏进同一条河流”强调河水变化仍有可辨认河流；“一次也不能”把一切稳定性取消，认识与命名本身也就无法进行。洲与阁相对稳定，使舟行、鸽飞成为可比较运动，故源题问静止时选衡量尺度，不选矛盾、普遍状态或时空。运动形式除机械位置变化外，还有物理、化学、生物和社会等过程；不以一种形式抹掉其他形式。

<a id="c01-supplement-04-space"></a>

时空原题描述高速粒子与外界时间的具体差异，直接强调相对性；不能因为它同时发生在客观世界便把所有正确性质都当成该题着重证明的性质。把时空叫绝对观念的表现、观念载体、先天直观形式或主观经验产物，均取消了本章所说的客观性。有限无限与绝对相对不是同一对概念；判题先问是在说具体对象、整体世界、客观存在还是具体特性。

<a id="c01-supplement-02-06-07"></a>

意识原表的错项可分三个失败机制。第一是把意识物质化：人脑、分泌物和特殊物质都不是意识本身；第二是取消来源或器官：脱离人脑、在人脑中自主产生、把人脑说成源泉都缺少必要关系；第三是缩小或夸大作用：只能反映现存对象忽略追溯推测，把意识说成联结主客体中介忽略实践，能动性超越时代实践水平忽略物质条件。“望梅止渴”显示心理活动能调节生理，不说明梅的观念等于梅果；“画饼不能充饥”显示区别，不否认意识所有作用。暗物质材料说明间接效应也能支持认识：不发光不等于不存在，不依赖意识且能反映符合物质观；把世界排除在人类理性可能认识的范围外，则滑向不可知。原题各选项与红色答案保留 Source，不在此产生新答案 owner。

<a id="c01-supplement-08"></a>

规律例要分两步读。“有多少汤泡多少馍”先以现实资源为限制，再按地区时间和条件决定发展；改成“汤固定，想办法尽量多泡”则强调在承认限制后创造具体利用条件。两者都不准凭愿望增加资源或改变规律，但材料重心不同。源图把只尊重规律解释为“办得到但没价值”属于提示语，不能当作普遍因果：教学只保留认识规律还须能动实践、主观努力须受规律制约。

<a id="c01-supplement-09"></a>

人工智能四项源原因也必须展开到它们回答的对象：知情意方面，Source认为AI只是人的理性智能模拟拓展，不具备情感、信念、意志等人的意识形式，用来区分人的意识整体与理性活动模拟；社会性方面，Source明确主张社会性是人的意识本质属性，AI不可能真正具有人类社会属性，不能以机器承担社会功能替换该命题；语言意义方面，Source以自然语言为思维物质外壳和意识现实形式，并认为AI难以完全具备理解自然语言真实意义的能力；可化约性区分可数字化内容与来源认为不可化约的内容。不能把机器有社会用途误判为具有人的社会属性，也不能把“不能全面替代”误读成所有任务均不能超过人。脑机接口把脑活动经过装置转换为物理控制，源题支持对象化现实化、延伸器官功能，不支持机器拥有情感意志或代替真情实感。四项来源判断的技术外推仍受未决差异限制。

## 同一模型压缩与下一章桥接

依次恢复原 `ch01.json` 的十节点，节点名称、顺序与最小意义保持一致：

- 01 哲学在问什么｜本原轴、可知轴、世界怎样存在发展的方法轴
- 02 物质是什么｜物质第一性；哲学物质抓客观实在性
- 03 物质怎样存在｜运动是物质的存在方式和根本属性，运动离不开物质承担者
- 04 运动怎样既变化又保持可辨认｜运动绝对、静止相对；时间空间是运动着物质的存在形式
- 05 人怎样进入物质世界｜实践使自然界/人类社会、客观世界/主观世界发生二重分化并保持统一
- 06 意识从哪里来、是什么｜人脑是物质器官，客观世界是内容来源，意识是客观世界的主观映象
- 07 意识怎样起现实作用｜物质决定意识；意识具有能动作用，并通过实践反作用于物质
- 08 人怎样正确行动｜尊重客观规律与发挥主观能动性统一于实践
- 09 人工智能检验什么边界｜技术可以模拟、延伸和物化部分智能活动，但不产生与物质并列的新本原
- 10 最后怎样收束｜世界的统一性在于物质性；方法论落到一切从实际出发

更薄的复习可以先遮住每条竖线后的解释、再恢复它，或只检索当次相关节点；01–10的固定问题与关系不合并、拆分或另换名字。完整答案需要更多条件时，按本稿节点表回到原段落或该ID的原精记对象。

这条线是教学依赖与重建线，不宣称每个后项都从前项演绎出来。下一章的问题自然是：这个运动的世界怎样联系，何种变化叫发展，变化动力、状态和方向怎样解释？C01 已给运动和规律的入口，C02 才完整展开联系、发展、三大规律和基本范畴。C03 再接实践的认识论循环；C04 接社会物质性和生产基础，避免讲第二章时假称已学完整唯物史观。
