# 2. Analysis capability chain

The durable capability chain is:

```text
IDENTIFY
→ SKELETON
→ MATERIAL_BINDING
→ FORMULATION
→ DELIVER
→ TRANSFER
```

This is a progression of cognitive tasks, not six mandatory screens.

## 2.1 IDENTIFY

Question:

> What is this subquestion actually asking, and which principle/theme owns the answer?

Learner output:

- owning subject / theme;
- 1–2 candidate principles when ambiguity is real;
- final selected owner plus a short reason.

No full answer required.

Typical target time:

- about 30–60 seconds once the task is familiar.

Primary failure:

- wrong owner;
- answering a related but different question;
- material-keyword matching without understanding the asked relation.

## 2.2 SKELETON

Question:

> If this were the exam, what distinct scoring moves would I make?

Learner output:

- normally 2–5 non-duplicative answer moves;
- ordered by the prompt's logic;
- no requirement for polished prose.

A move is not merely a memorized sentence. It must have a job, for example:

- define / identify;
- explain why;
- state relation;
- state significance;
- compare / distinguish;
- give requirement / method;
- connect historical process;
- draw implication.

Primary failure:

- template dumping;
- duplicate points;
- missing a major part of a two-part relation;
- listing facts without answering the verb in the prompt.

## 2.3 MATERIAL_BINDING

Question:

> What in the material makes each answer move relevant?

Learner output:

```text
answer move
↔
concrete material cue / fact / contrast / causal relation
```

The learner does not need to copy material wording.

Primary failure:

- a theoretically correct answer that could have been pasted under any material;
- one generic sentence such as “结合材料可知” with no real binding;
- using only material paraphrase without the owning theory.

## 2.4 FORMULATION

Question:

> Can the answer retrieve the source-grounded formulation at the precision this task actually requires?

This has three freshness classes.

### STABLE_CURRENT

Current stable source supports the formulation.

May be trained now.

### LEGACY_GEOMETRY_ONLY

Historical material supplies task shape but its exact annual formulation is not Current authority.

Train IDENTIFY / SKELETON / BINDING. Do not admit the wording to 2027 Memory merely because the legacy answer used it.

### CURRENT_YEAR_EXACT_REQUIRED

The point depends on current-year handbook/current affairs/annual sprint Source.

Before that source is BOUND:

- exact retrieval remains UNKNOWN / NOT YET TRAINABLE;
- no invented substitute;
- no penalty for a learner not reproducing unavailable 2027 wording in an early geometry drill.

After the source is BOUND:

- exact/source-grounded wording may become an explicit training target.

## 2.5 DELIVER

Question:

> Can Kian turn the skeleton into a complete, concise, time-feasible written answer?

Learner output:

- full prose;
- visible point separation;
- no unnecessary preamble;
- enough material binding to remain on-topic;
- feasible under handwriting / paper time.

Full prose is **selective**, not the default for every early task.

## 2.6 TRANSFER

Question:

> Can the same capability work on genuinely new material without answer leakage?

A TRANSFER task must use material not already rehearsed as the same question-answer pair.

Transfer may test:

- IDENTIFY only;
- SKELETON + BINDING;
- full DELIVER.

A repaired old answer is useful learning evidence, but it is not fresh transfer.

# 3. Task modes

Every Analysis task has one primary mode.

| Mode | Required learner output | Required rubric dimensions |
| --- | --- | --- |
| `IDENTIFY` | owner/principle + reason | I |
| `SKELETON` | owner + distinct answer moves | I, S |
| `BIND` | skeleton + material cue per major move | I, S, B |
| `FORMULATION` | bound skeleton + source-grounded formulation | I, S, B, F |
| `DELIVER` | complete timed prose | I, S, B, F when the task requires formulation, D |

`TRANSFER` is **not** a sixth task mode. It is an attempt role applied to any mode when the material is genuinely fresh.

Do not require DELIVER when the training purpose is only IDENTIFY or SKELETON.

That would spend handwriting/prose time without producing additional evidence for the current bottleneck.

# 4. Task-level rubric

The rubric is a **vector**, not an automatic exam score.

Default dimensions:

```text
I = Identify / ownership
S = Skeleton / coverage
B = Material binding
F = Formulation / source fidelity
D = Delivery / time-feasible prose
```

Each applicable dimension is:

- `0 = failed / absent`
- `1 = partial / usable but unstable`
- `2 = task-level secure`
- `NA = dimension not required by this task mode`

Do not sum the vector into a high-confidence Politics score.

## 4.1 I — Identify / ownership

### 0
- wrong principle/theme;
- answers a different relation;
- cannot resolve the core prompt.

### 1
- broad subject/theme is right;
- owner is vague, overbroad or competing principles are not cleanly resolved.

### 2
- owning principle/theme is correct;
- the asked verb/relation is correctly identified;
- irrelevant neighboring principles are excluded.

## 4.2 S — Skeleton / coverage

### 0
- no usable answer structure;
- mostly unrelated memorized material;
- misses the main requested dimension.

### 1
- contains useful moves;
- but one major dimension is missing, duplicated or poorly ordered.

### 2
- distinct, non-duplicative moves cover the actual question;
- usually 2–5 moves, but the number follows the task rather than a fixed template;
- each move has a clear function.

## 4.3 B — Material binding

### 0
- answer is detached from the material;
- or only paraphrases the material with no theory.

### 1
- some valid binding exists;
- but important moves remain generic or the link is weak.

### 2
- every major move is anchored to a concrete material cue / relation / fact;
- theory and material explain each other.

## 4.4 F — Formulation / source fidelity

### 0
- unsupported / fabricated formulation;
- materially wrong wording;
- stale annual content presented as Current.

### 1
- meaning is broadly correct;
- but exactness is incomplete, or current-year exact wording is not yet available;
- this may still be fully acceptable for an early geometry task when F is not required.

### 2
- formulation is supported by the responsible Current source;
- freshness is appropriate to the task;
- where exact wording matters, the exact source requirement is satisfied.

### NA
Use when the task intentionally does not test exact formulation.

## 4.5 D — Delivery

### 0
- incomplete;
- materially over time;
- structure is unusable on paper.

### 1
- basically complete;
- but verbose, repetitive, poorly separated, or timing is fragile.

### 2
- complete;
- concise enough for exam use;
- clear point structure;
- time / handwriting load is feasible.

# 5. Critical failure flags

A task may carry a critical flag independent of the 0–2 vector.

Allowed flags:

- `WRONG_OWNER`
- `PROMPT_MISREAD`
- `TEMPLATE_DUMP`
- `MATERIAL_UNBOUND`
- `UNSUPPORTED_FORMULATION`
- `STALE_CURRENT_YEAR_CONTENT`
- `ANSWER_LEAKAGE`
- `TIMEOUT`
- `INCOMPLETE`

These flags help Chat choose the smallest repair.

They are not a second mastery score.

# 6. Stable task identity

Durable evidence requires exact task identity.

Each task must bind at minimum:

- `task_id`;
- `task_revision`;
- subject lane;
- source family;
- exact source/material identity;
- subquestion identity;
- task mode;
- freshness class;
- rubric version.

Recommended identity basis:

```text
source identity
+ material/prompt identity
+ subquestion
+ task mode
+ target owner/principle set
+ rubric version
→ task_revision
```

Changing answer wording alone does not necessarily change the task.

Changing the prompt, source material, intended owner, freshness class, formulation requirement or assessment target does.

# 7. Attempt roles

Persist one of:

- `FIRST`
- `REPAIR`
- `TRANSFER`

## FIRST

First meaningful attempt on this exact task/revision.

Do not overwrite it.

## REPAIR

The learner has seen diagnosis/reference and attempts the task again.

Useful for learning evidence, not clean transfer.

## TRANSFER

Fresh material / different question context designed to test whether the capability generalizes.

TRANSFER evidence is required before calling a repaired pattern robust.

# 8. How Kian studies Analysis

## 8.1 Now — before 2027 later Source

Default is **short output training, not full-answer grinding**.

One drill may look like:

```text
30–60 s    IDENTIFY
60–120 s   SKELETON
1–3 min    BIND major moves to material
then       compare / diagnose / repair
```

The comparison step asks only:

1. Did I identify the right owner?
2. Which scoring move did I miss?
3. Which move was not actually bound to material?
4. Did I use unsupported or legacy-only wording?

Then repair the smallest failure.

Do **not** copy the full historical answer merely because it is longer.

### Best early uses

- **Marxism:** especially suitable now. Stable principles make IDENTIFY → SKELETON → BINDING trainable early.
- **History:** train event/process ownership, cause/significance/comparison skeletons and material linkage.
- **Xi / theory:** train prompt decomposition, answer architecture and stable Current concepts; annual exact wording stays source-gated.
- **Ethics/Law:** train concept/value ownership, normative move selection and material application.
- **Current affairs:** before 2027 current-affairs Source, use historical material only for question geometry / binding practice, not current-fact recall.

## 8.2 Full prose

Do not write every drill in full.

Use full DELIVER when:

- skeleton is already basically right and delivery itself needs evidence;
- timing / handwriting has not been tested;
- a transfer task needs complete-output proof;
- later Mock phase requires whole-paper execution.

This protects study time.

## 8.3 When 2027 handbook/current affairs arrives

Add FORMULATION training:

```text
existing stable structure
+ 2027 source delta
→ exact current-year formulations
→ selective Memory admission
→ bind wording back into Analysis tasks
```

Do not relearn the whole Analysis system.

## 8.4 Xiao8

2027 Xiao8 is primarily:

- clean current-year transfer;
- Objective calibration where appropriate;
- Analysis full-task evidence;
- timed/mock execution.

Do not pre-study its answer before the clean attempt when it is being used as calibration evidence.

## 8.5 Xiao4

2027 Xiao4 is primarily:

- final exact-output compression;
- high-yield current-year formulation;
- final delivery / whole-paper rehearsal.

It is not the first place to learn how to IDENTIFY or SKELETON.

# 9. Evidence aggregation

A single good answer does not prove Analysis maturity.

Fresh Chat may summarize:

- latest FIRST evidence by capability;
- open critical failure flags;
- latest REPAIR result;
- whether TRANSFER exists;
- whether timed DELIVER exists;
- which evidence depends on legacy-only vs Current-year Source.

Do not expose a fake global mastery number.

Capability interpretation stays phase-aware:

```text
UNKNOWN
→ IDENTIFY observed
→ SKELETON observed
→ MATERIAL_BINDING observed
→ FORMULATION source-ready
→ TIMED_OUTPUT observed
→ TRANSFER observed
```

“Observed” remains evidence, not a permanent badge.
