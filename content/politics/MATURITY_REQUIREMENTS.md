# Politics Highest-Bar Maturity Requirements

Status: **CANDIDATE ACCEPTANCE REQUIREMENTS**

Parent quality bar: `EXAM_SUBJECT_MATURITY_STANDARD.md`

This file does not replace Politics Source / Learning contracts. It defines what must be proven before the Politics subject system may be called mature for the current exam cycle.

## 1. Score closure

Fixed target:

- **Protect 70**
- **Push 75**

Planning decomposition remains reliability-first:

- 70 path: roughly Objective 40+ / 50 + Analysis 30+ / 50;
- 75 path: roughly Objective 42–44 / 50 + Analysis 31–34 / 50.

These are planning targets, not score guarantees.

The system must explicitly identify which work protects 70 and which work is only 75-upside.

Work that does neither should be compressed or removed.

## 2. Ability closure

### Objective capability

```text
understand relation
→ compress model
→ retrieve exact high-value facts
→ precision for hats/time/actor/scope/list
→ judge option propositions
→ multi-select boundary control
→ transfer to unfamiliar wording/material
→ normal exam speed
```

### Analysis-output capability

```text
read prompt/material
→ segment material
→ identify owning principle / political position
→ retrieve source-grounded formulation
→ choose 3–5 answer moves
→ bind each move back to material
→ complete usable timed prose
```

Objective strength may not imply analysis readiness.

## 3. Material closure

Current first-round core must remain fully usable:

- 160 Chengfeng Natural Units;
- 1148 Xiao1000 objective questions as **full learning assets, no holdout**;
- Suyi as framework/reference input, not second course;
- refined Xiao1000 backside content;
- Review/Repair;
- selective Memory.

Later-stage readiness must be prepared before arrival of:

- current-year memory/sprint handbook;
- current affairs / 形势与政策;
- Xiao8;
- Xiao4.

Historical LEG26 / prior Xiao8/Xiao4 may define baseline, task geometry, topic skeletons and delta scaffolds, but may never directly authorize 2027 exact wording/current-affairs recall.

If a required ability lacks a training asset, create source-grounded derived/synthetic material now where legitimate.

## 4. Method closure

First-round control:

```text
REACTIVATE
→ COMPRESS
→ VERIFY with all relevant Xiao1000
→ STABILIZE only justified Memory/Repair
→ MAINTAIN / ELASTIC
```

Most understanding may move quickly; the main cost may sit in compression, exact retrieval and option boundaries.

Rules:

- Xiao1000 is consumed for learning, not reserved for testing.
- Stable correct work stays cheap.
- W/U is raw pressure, not one-task-per-question debt.
- Chat compresses many W/U into the fewest real root causes.
- Memory candidates do not become review debt merely by existing.
- durable Memory requires source support plus justified learner need / output need.

Later analysis-output defaults to low-cost training:

```text
material cue
→ IDENTIFY
→ SKELETON
→ EXACT only when source/current-year wording matters
→ DELIVER selectively
```

Full prose is used when delivery skill itself needs evidence.

## 5. Evidence closure

Objective evidence distinguishes:

- first attempt;
- W/U cause;
- repair;
- later changed-context success;
- Memory FORGOT/FUZZY/STABLE;
- current-year fresh/mock performance.

Xiao1000 re-exposure may show repair but may not be converted mechanically into exam score. Because Xiao1000 is intentionally consumed as full learning material, formal Objective score calibration must come from a separate appropriate evidence source (for example low-contamination official/current-year mock evidence when available) rather than pretending Xiao1000 is a holdout.

Analysis evidence must distinguish:

- first IDENTIFY;
- first SKELETON;
- repaired output;
- new-material transfer;
- exact-formulation retrieval;
- timed full answer;
- whole-paper analysis execution.

A memorized template that fails to bind material is not Secure.

Analysis score evidence requires an accepted rubric / anchor set and explicit scoring uncertainty. One Chat/model score may guide repair, but it cannot by itself create high-confidence Protect-70 / Push-75 total-score evidence when strategy depends on that estimate.

## 6. Dynamic control

Politics does not use a fixed D1/D3/D7 scheduler or mastery score.

Control asks:

- which capability currently protects 70;
- which 75-upside action has best marginal value;
- whether Memory/Repair is growing faster than new learning;
- whether stable work can be reduced;
- whether later source has matured enough to activate new output work.

P20/P50/P80 estimates capacity only.

## 7. Forecast closure

Forecast is phase-dependent.

### Early / first-round
Higher confidence in:

- NU / Xiao1000 structural progress;
- objective W/U structure;
- Memory / Repair pressure;
- learning throughput.

Lower confidence in final total score.

### Later
As current-year handbook/current-affairs/Xiao8/Xiao4 arrive, uncertainty should narrow for:

- exact Memory;
- analysis-output readiness;
- current-year objective calibration;
- Mock execution;
- Protect-70 reliability / Push-75 upside.

Required inputs include:

- actual Politics minutes;
- weighted NU progress where valid evidence exists;
- 528 single-choice / 620 multiple-choice full learning load;
- single vs multiple W/U separately;
- W/U→Repair compression;
- Memory admission and retention;
- later-source assimilation;
- analysis-output evidence;
- Mock execution.

UNKNOWN is valid and preferred to fake precision.

## 8. Future-source closure

Prepare today:

- LEG26 historical baseline metadata / derived topic structures;
- analysis-output hooks / drill geometry;
- current-affairs overlay slots;
- handbook delta/admission rules;
- Xiao8 clean-attempt + review/mock rules;
- Xiao4 final-output + final-compression rules.

When 2027 source arrives:

```text
real source
→ provenance bind
→ compare with stable Current + legacy baseline
→ classify stable / updated / new / retired / current-year-only
→ update only responsible derived/current-year asset
→ validate freshness
→ Chat training
```

No learner should need to ask how a known annual source family is used.

Each future-source family must also define partial/late/low-quality/missing-source fallback, second-revision supersession, and invalidation of derived Memory/Analysis/current-affairs assets. The system must know when to stop waiting for a source and continue with a safe alternative rather than freezing the learner.

## 9. Analysis synthetic asset closure

Before later phase, maintain a ready bank of:

- Principle Retrieval drills;
- Material Binding drills;
- Skeleton drills;
- source-supported Formulation Retrieval drills;
- Complete Synthetic Analysis tasks;
- Stress variants with ambiguous-looking cues / competing principles.

Generated assets require independent self-attack for ambiguity, leakage, naturalness, source legitimacy and task validity.

## 10. Execution closure

Current loop must remain:

```text
Daily / subject evidence
→ Chat decides today’s Politics work
→ typed plan / instruction
→ Website executes Memory / Xiao1000 / Review / Continue
→ evidence
→ Chat
```

Later Analysis Output may remain Chat-primary unless real learner friction proves a Website helper is necessary.

No second Politics scheduler or second learner-state ledger is allowed.

## 11. Adversarial acceptance

Attack at least:

- NU pace 30% slower than forecast;
- Xiao1000 W/U far above forecast;
- multiple-choice much weaker than single-choice;
- Memory explosion;
- Memory relapse after apparent stability;
- many W/U sharing one root cause;
- cross-NU question ownership;
- missing Chengfeng locator;
- Chengfeng/Suyi disagreement;
- handbook/current-affairs delayed 7–10+ days;
- current-year source revision invalidating a derived object;
- Xiao8/Xiao4 late arrival;
- analysis first output far below expectation;
- memorized skeleton with poor material binding;
- objective stable but analysis timing fails;
- whole paper over-time;
- Daily Packet missing fields;
- stale/replayed Chat Plan;
- restart/corrupted checkpoint;
- missing timer;
- 30% capacity day / multi-day bad week;
- Chat false-Secure judgment;
- Chat remaining over-conservative and repeatedly assigning already-stable Politics work;
- lack of W/U being mistaken for objective stability despite incomplete representative sampling;
- Xiao1000 being reused as if it were unbiased score evidence after full learning exposure;
- one-model Analysis scoring narrowing the total-score band too aggressively;
- Chat selecting low-ROI Politics work;
- partial / low-quality / missing future source;
- second revision of future source after first ingestion.

Every case must judge learning-decision safety, not merely runtime survival.

## 12. Fresh-Chat / no-Website attack

Fresh Chat + Current + private evidence must make a defensible Politics next decision.

Removing Website must not break:

- Politics learning semantics;
- source priority;
- Memory admission;
- W/U repair meaning;
- analysis-output topic ownership;
- forecast interpretation.

## 13. Final acceptance question

A mature Politics system must be able to answer:

> What currently threatens Protect-70, what is merely Push-75 upside, what exact capability is weak, what material/method trains it, what evidence would prove improvement, how much capacity is likely required, and can tomorrow’s learner action be executed with near-zero manual system maintenance?
