# 1. What Politics is, specifically

Politics is not mainly a “deep-understanding” subject for this learner.

Current working learner prior:

- Kian has studied Politics before;
- prior understanding reduces first-round conceptual rebuild cost;
- large exact-memory burden may have decayed;
- first-round speed may therefore be fast;
- the main first-round cost is expected to sit in:
  - compression;
  - exact retrieval;
  - option-boundary discrimination;
  - selective Memory;
  - Wrong/Uncertain repair.

This is a **prior**, not learner truth. Real U may confirm or reject it.

Therefore Politics maturity must not optimize for:
- maximum lecture time;
- maximum explanation;
- full-course repeated rereading;
- fixed spaced-repetition rituals;
- one-task-per-error repair;
- a second Politics scheduler.


# 3. Objective capability model

The Objective channel must be modeled as:

```text
relation understanding
→ compression
→ exact retrieval where required
→ hat/time/actor/scope/list precision
→ proposition judgment
→ single-choice discrimination
→ multiple-choice boundary control
→ changed-context transfer
→ timed mixed execution
```

## 3.1 Relation understanding

Question:
> Can Kian reconstruct why a proposition is true/false without rereading a full section?

Primary material:
- Chengfeng Current Natural Unit;
- Current teaching bridge/compression;
- Suyi only as framework/reference input.

Failure:
- recognition without reusable model;
- repeated source reopening for near variants.

Repair:
- smallest owning relation;
- no full-lecture replay by default.

Evidence:
- changed wording/material judged correctly.

---

## 3.2 Compression

Question:
> Has a learned region been reduced to a smaller reusable structure that actually removes future operations?

Good compression reduces:
- rereading;
- reconstruction time;
- confusion among near-neighbor propositions;
- future memorization volume;
- analysis-answer generation cost.

Bad compression:
- shorter text but more learner operations;
- beautiful framework that becomes a second course.

---

## 3.3 Exact retrieval

Politics exactness is selective.

Typical exact targets:
- hats;
- actors;
- chronology;
- lists;
- identity;
- scope;
- policy/legal/current-year wording when source-backed.

Rule:

```text
source support
+ real Objective or Analysis need
→ candidate may become durable Memory
```

Candidate existence alone never creates review debt.

---

## 3.4 Single-choice discrimination

Current full learning asset:
- 528 Xiao1000 single-choice questions.

Role:
- learning/verification;
- W/U discovery;
- option-boundary evidence.

Not a holdout.

---

## 3.5 Multiple-choice boundary control

Current full learning asset:
- 620 Xiao1000 multiple-choice questions.

This is a high-leverage Objective capability because one unstable boundary can invalidate an otherwise understood item.

Evidence must track single and multiple separately.

A Politics model that reports only aggregate Xiao1000 accuracy is insufficient.

---

## 3.6 Changed-context transfer

Same-item correction is not enough.

After a meaningful Repair:

```text
repair
→ independent changed-context task
→ later delayed / current-year fresh evidence
```

Generated transfer is allowed for mechanism testing.

Generated success cannot by itself become final exam-score calibration.

---

## 3.7 Timed Objective execution

Later evidence must test:
- mixed-topic switching;
- normal pace;
- fatigue;
- uncertainty handling;
- paper-like execution when relevant.

Current-year Xiao8 / Mock are expected to become stronger calibration assets than repeated Xiao1000.

# 4. Analysis capability model

Analysis is a separate score channel.

The required chain is:

```text
read prompt
→ segment material
→ identify owning principle / political position
→ retrieve legitimate formulation
→ choose 3–5 answer moves
→ bind answer moves to material
→ complete usable timed prose
```

A strong first round does not automatically prove this chain.

---

## 4.1 Prompt interpretation

Must distinguish:
- what is being asked;
- what relation must be explained;
- whether the answer needs cause / meaning / relation / method / evaluation / measure.

Failure:
- topic dump;
- correct knowledge, wrong task.

---

## 4.2 Material segmentation

Must extract:
- events;
- claims;
- conflicts;
- causes;
- effects;
- evaluation cues;
- action cues.

Failure:
- copying material;
- missing the decisive clue.

---

## 4.3 Principle retrieval

Default low-cost drill:

```text
material cue
→ identify owning principle / political position
```

No full prose required.

This should be trained before current-year exact recitation material arrives.

---

## 4.4 Skeleton construction

Default:

```text
principle / theme
→ 3–5 answer moves
```

The skeleton must:
- contain only relevant logic;
- avoid “all-purpose” dumping;
- leave an explicit material-binding slot.

---

## 4.5 Exact formulation retrieval

Use only when exact wording materially improves score.

High-delta areas:
- current-year Xi wording;
- current affairs;
- legal/normative exactness;
- final current-year recitation.

No current-year source:
> no exact current-year claim.

Stable conceptual formulation may be trained earlier when source-supported.

---

## 4.6 Material binding

This is a first-class ability.

Failure mode:

> knows the right principle  
> + remembers a template  
> + still writes a generic answer that does not use the material.

Dedicated Material Binding drills are required.

A mature system may not infer this ability from Principle Retrieval alone.

---

## 4.7 Complete delivery

Full writing is selective.

Use complete answers when:
- a major family is first calibrated;
- identify/skeleton is stable but delivery is unknown;
- time-bounded production is itself the weakness;
- Mock/final practice requires complete output.

Stable topics should not owe endless full-answer writing.

---

## 4.8 Timed / whole-paper Analysis execution

Late-phase evidence must test:
- answer completion;
- time allocation;
- switching from Objective;
- fatigue;
- handwriting/paper cost where relevant.

This is required before high-confidence Protect-70 closure.

# 9. Protect-70 / Push-75 control

## Protect-70 work

Work is Protect-70 when failure to do it can materially threaten:
- Objective 40+ path;
- Analysis 30+ path;
- current-year source validity;
- exam-time completion.

Examples:
- major unlearned Objective scope;
- repeated multiple-choice boundary failures;
- high-value exact Memory holes;
- Analysis principle/skeleton/material-binding failure;
- severe timed/whole-paper execution defect;
- required current-year Source still not assimilated.

---

## Push-75 work

Once Protect-70 risk is bounded, extra Politics capacity may target:
- Objective 42–44;
- lower multiple-choice variance;
- stronger exact retrieval;
- denser/more precise Analysis answers;
- faster delivery;
- lower whole-paper variance.

Push-75 work is Elastic and competes with Xizong/English.

# 10. Dynamic control states

Politics uses subject-native states:

```text
REACTIVATE
→ BUILD
→ VERIFY
→ STABILIZE
→ MAINTAIN
→ ELASTIC
```

## Reduce practice when
- representative evidence exists;
- mechanism error no longer recurs;
- delayed evidence is stable when needed;
- changed-context transfer is stable;
- timed/whole-task performance is stable when relevant;
- new practice produces little actionable information.

## Increase/reopen when
- same mechanism recurs;
- multiple-choice is materially weaker than single;
- Memory relapses;
- current-year fresh transfer underperforms training;
- material binding fails;
- exact current-year wording changes;
- timed/whole-paper performance contradicts local stability.

No fixed D1/D3/D7 learner-facing cadence.

- Memory candidate explosion;

- first IDENTIFY far below expectation;
- good skeleton, poor material binding;
- memorized template, weak unseen transfer;
- exact wording used without current-year source;

- rubric systematically over/under-scores output.

- handbook 7–10+ days late;
- current affairs partial;
- Xiao8/Xiao4 late;
- future source low-value;
- source v2 corrects v1;
- OCR/answer-key/fidelity corruption;
- source never arrives.

### Transport / learner state
- Daily Packet missing fields;
- stale plan;
- plan replay;
- browser restart;
- checkpoint corruption;
- timer loss;
- partial learner state;
- two-state race / newer learner evidence after packet copy.

### Control error
- false Secure;
- false Unstable;
- low-ROI Politics task chosen while another subject has higher value;
- Push-75 work selected while Protect-70 blocker remains;

Every attack asks:
