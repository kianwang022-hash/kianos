# 0. Politics-specific adaptations that override generic defaults

The shared subject maturity standard is a quality bar, not a universal learning algorithm.

For Politics, the following subject-specific rules take precedence over generic interpretations.

## P0.1 Score control is asymmetric

Politics has two fundamentally different score channels:

```text
Objective
= early-cycle high-information channel

Analysis
= later-cycle output-conversion channel
```

Therefore:

- early Objective confidence may become relatively narrow;
- early final-total confidence must remain wider;
- Analysis UNKNOWN is legitimate before current-year output evidence exists;
- the system must never infer a 70/75 total-score claim from Objective evidence alone.

## P0.2 Xiao1000 is full-consumption learning material, not a calibration holdout

All 1148 Xiao1000 Objective questions are learning assets.

Do not reserve untouched Xiao1000 merely to create a fresh test set.

Use them to:

- learn boundaries;
- expose W/U;
- discover exact-memory needs;
- validate first-round knowledge;
- drive causal Repair.

Later fresh/current-year calibration comes from:

- changed-context generated transfer when legitimate;
- Xiao8;
- Xiao4;
- current-year accepted mocks / mixed sets.

## P0.3 Politics first-round cost is expected to be memory/compression-heavy, not understanding-heavy

Current learner prior:

- prior-cycle Politics score was about 60;
- Objective study was incomplete;
- Analysis/subjective preparation was essentially not systematically built;
- much of the conceptual framework has been understood before;
- exact memory may have decayed substantially.

This means the default first-round hypothesis is:

```text
reactivation is relatively cheap
compression / exact retrieval / option discrimination are the larger costs
```

This is a hypothesis to calibrate from real U, not a permanent truth.

## P0.4 Historical 60 is a sanity prior, not a floor

The prior 60 score must be used only to attack implausible models.

A Forecast that says:

> completing Objective coverage + building real Analysis capability still requires extremely large Politics workload merely to reach 70

must explain why the historical incomplete-preparation result was already ~60.

If it cannot, suspect workload/score-model overestimation.

The opposite attack is also required:

> prior 60 does not make current 70/75 automatic.

## P0.5 Politics Memory is selective admission, never automatic accumulation

Politics exactness can create large fake debt if every candidate becomes a card.

Therefore:

```text
candidate
≠ durable Memory
≠ review debt
```

Durable Memory requires:

```text
source support
+
real Objective/Analysis need
```

No fixed cadence is learner-facing truth.

## P0.6 Source freshness is domain-dependent

Politics later-stage material has unequal annual-delta risk.

Relatively stable structural use may begin earlier for:

- Marxist principles;
- stable historical causal structures;
- stable conceptual ethics/life-value themes.

Strong current-year source gates apply especially to:

- Xi/current policy wording;
- current affairs;
- recent-history additions;
- legal/normative exact wording;
- current-year recitation emphasis;
- Xiao8/Xiao4 final framing.

Historical structure may be reused.
Historical exact current-year wording may not.

## P0.7 Analysis training must start structurally before current-year recitation arrives

The system must not wait until November to discover that:

- prompt interpretation is weak;
- principle retrieval is weak;
- skeleton construction is weak;
- material binding is weak.

Stable structural drills may be prepared and used earlier.

However:

> current-year exact wording remains source-gated.

## P0.8 Protect-70 and Push-75 are different control modes

Before Protect-70 risks are bounded:

> Politics time is defensive / viability-preserving.

After Protect-70 is genuinely supported:

> additional Politics time becomes Elastic and competes with Xizong/English.

The system must not keep investing in Politics merely because further improvement is theoretically possible.

## P0.9 Analysis may remain Chat-primary

Politics maturity does not require a dedicated Analysis Website.

A Website helper is justified only if real learner use proves that Chat-primary execution creates material friction.

Do not build a new Analysis Runtime merely for symmetry.

## P0.10 Late annual sources should update content, not redesign the system

For handbook/current affairs/Xiao8/Xiao4:

```text
prior-year baseline
+ Current stable Politics knowledge
+ new 2027 source
→ delta
→ validate
→ update responsible derived/current-year assets
→ existing learning loop continues
```

Arrival of a known annual source is not permission to redesign Politics.

# 3. Objective capability model

The Objective channel must be modeled as:

```text
relation understanding
→ compression
→ exact retrieval where required
→ hat/time/actor/scope/list precision
→ proposition judgment
→ single-choice discrimination
→ multiple-choice boundary control
→ changed-context transfer
→ timed mixed execution
```

## 3.1 Relation understanding

Question:
> Can Kian reconstruct why a proposition is true/false without rereading a full section?

Primary material:
- Chengfeng Current Natural Unit;
- Current teaching bridge/compression;
- Suyi only as framework/reference input.

Failure:
- recognition without reusable model;
- repeated source reopening for near variants.

Repair:
- smallest owning relation;
- no full-lecture replay by default.

Evidence:
- changed wording/material judged correctly.

---

## 3.2 Compression

Question:
> Has a learned region been reduced to a smaller reusable structure that actually removes future operations?

Good compression reduces:
- rereading;
- reconstruction time;
- confusion among near-neighbor propositions;
- future memorization volume;
- analysis-answer generation cost.

Bad compression:
- shorter text but more learner operations;
- beautiful framework that becomes a second course.

---

## 3.3 Exact retrieval

Politics exactness is selective.

Typical exact targets:
- hats;
- actors;
- chronology;
- lists;
- identity;
- scope;
- policy/legal/current-year wording when source-backed.

Rule:

```text
source support
+ real Objective or Analysis need
→ candidate may become durable Memory
```

Candidate existence alone never creates review debt.

---

## 3.4 Single-choice discrimination

Current full learning asset:
- 528 Xiao1000 single-choice questions.

Role:
- learning/verification;
- W/U discovery;
- option-boundary evidence.

Not a holdout.

---

## 3.5 Multiple-choice boundary control

Current full learning asset:

This is a high-leverage Objective capability because one unstable boundary can invalidate an otherwise understood item.

Evidence must track single and multiple separately.

A Politics model that reports only aggregate Xiao1000 accuracy is insufficient.

Same-item correction is not enough.

After a meaningful Repair:

→ later delayed / current-year fresh evidence

Generated transfer is allowed for mechanism testing.

Generated success cannot by itself become final exam-score calibration.

## 3.7 Timed Objective execution

Later evidence must test:

- paper-like execution when relevant.

# 4. Analysis capability model

Analysis is a separate score channel.

The required chain is:

```text
read prompt
→ segment material
→ identify owning principle / political position
→ retrieve legitimate formulation
→ choose 3–5 answer moves
→ bind answer moves to material
→ complete usable timed prose
```

A strong first round does not automatically prove this chain.

---

## 4.1 Prompt interpretation

Must distinguish:
- what is being asked;
- what relation must be explained;
- whether the answer needs cause / meaning / relation / method / evaluation / measure.

Failure:
- topic dump;
- correct knowledge, wrong task.

---

## 4.2 Material segmentation

Must extract:
- events;
- claims;
- conflicts;
- causes;
- effects;
- evaluation cues;
- action cues.

Failure:
- copying material;
- missing the decisive clue.

---

## 4.3 Principle retrieval

Default low-cost drill:

```text
material cue
→ identify owning principle / political position
```

No full prose required.

This should be trained before current-year exact recitation material arrives.

---

## 4.4 Skeleton construction

Default:

```text
principle / theme
→ 3–5 answer moves
```

The skeleton must:
- contain only relevant logic;
- avoid “all-purpose” dumping;
- leave an explicit material-binding slot.

---

## 4.5 Exact formulation retrieval

Use only when exact wording materially improves score.

High-delta areas:
- current-year Xi wording;
- current affairs;
- legal/normative exactness;
- final current-year recitation.

No current-year source:
> no exact current-year claim.

Stable conceptual formulation may be trained earlier when source-supported.

---

## 4.6 Material binding

This is a first-class ability.

Failure mode:

> knows the right principle  
> + remembers a template  
> + still writes a generic answer that does not use the material.

Dedicated Material Binding drills are required.

A mature system may not infer this ability from Principle Retrieval alone.

---

## 4.7 Complete delivery

Full writing is selective.

Use complete answers when:
- a major family is first calibrated;
- identify/skeleton is stable but delivery is unknown;
- time-bounded production is itself the weakness;
- Mock/final practice requires complete output.

Stable topics should not owe endless full-answer writing.

---

## 4.8 Timed / whole-paper Analysis execution

Late-phase evidence must test:
- answer completion;
- time allocation;
- switching from Objective;
- fatigue;
- handwriting/paper cost where relevant.

This is required before high-confidence Protect-70 closure.

# 23. Value-of-Information rule

Politics must not consume learner time merely to make the model feel more certain.

Before collecting evidence mainly for uncertainty reduction, Chat should ask:

- what decision could this evidence change?
- how many learner minutes does it cost?
- does it consume valuable fresh material?
- does the task also have direct learning value?
- would a robust action be possible without resolving the uncertainty?

If no plausible decision changes enough to justify the cost:

> keep the uncertainty and continue with a robust learning action.

This is especially important for:
- unnecessary full mocks;
