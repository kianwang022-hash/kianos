# 1｜Score closure

English maturity begins from the score target, not from the existing material inventory.

Required durable interpretation:

- **Hard target:** 85+.
- **Objective capability target:** 60 / 60.
- **Productive capacity:** must provide enough Translation + Writing performance and buffer that a small exam-day Objective loss does not automatically destroy 85+.
- **Elastic upside:** once 85+ is secure, English may continue above it only when marginal value remains competitive cross-subject.

Important distinction:

> Objective 60 / 60 is a **capability-building requirement**, not a claim that every mock must literally score 60.

The system may not permanently accept a known recurring Objective loss merely because Writing/Translation could compensate.

Productive secure/elastic score bands may be used as planning priors only after scoring validity is established. Before that, they are targets, not evidence about Kian's current score.

A mature English score model must output:

```text
85+ target
→ section score needs / loss budget
→ capability needs
→ evidence required to believe the path is viable
→ residual variance / contamination / scoring uncertainty
```

Unknown stays UNKNOWN.

### Objective 60 proof boundary

Objective 60 / 60 does **not** require infinite proof or endless consumption of scarce fresh official material. Operationally, the target means:

> no known recurring predictable Objective loss mechanism remains unaddressed, and representative low-contamination / integrated evidence supports near-zero predictable loss under normal time pressure.

Residual exam randomness may remain explicit.

### Fresh-material capital

Low-contamination official material is scarce calibration capital. Its use must be budgeted by value of information and future Gate need.

- engineering tests do not consume protected learner material;
- do not spend the cleanest remaining material merely to satisfy a bookkeeping milestone;
- preserve enough integrated evidence for later formal Gates where feasible.

# 3｜Ability closure — Reading A

Reading A maturity requires at least the following abilities.

## 3.1 Demand resolution

Exam action:

> Identify the exact decision requested by the question before evaluating options.

Failure:

- answering a nearby but different question;
- confusing purpose / inference / detail / attitude / main idea demands.

Training:

- whole-passage clean attempts;
- targeted demand contrasts only when real evidence justifies them.

Evidence:

- independent first-attempt performance across representative demand types.

## 3.2 Relevant representation

Exam action:

> Recover the proposition / relation structure needed for the current question.

Includes when material:

- clause hierarchy;
- attachment;
- reference;
- negation;
- modality / degree / quantifier scope;
- causal / contrast / concession relation.

Failure:

- English sentence feels understood but decisive relation is wrong.

Training:

- smallest Representation repair, then return to whole passage.

Evidence:

- later changed-passage success without assistance.

## 3.3 Evidence localization

Exam action:

> Find the smallest decisive source evidence efficiently.

Failure:

- answering from memory / impression;
- rereading broadly;
- evidence boundary too wide or too narrow.

Evidence:

- unseen / low-contamination timed passage with correct evidence-based adjudication.

## 3.4 Option proposition control

Exam action:

> Reduce each serious candidate to what it actually claims.

Failure:

- lexical-overlap attraction;
- paraphrase fluency mistaken for truth;
- partial truth / true-but-irrelevant.

## 3.5 Scope / modality / attribution / relation

Failure families include:

- entity / object shift;
- scope shift;
- degree / quantity shift;
- modality shift;
- attribution shift;
- cause shift / reversal;
- example ↔ claim substitution;
- local ↔ global shift;
- over-inference.

## 3.6 Candidate competition

Exam action:

> Compare the strongest candidates against decisive evidence rather than accepting the first plausible option.

The maturity bar must specifically attack **two-strong-option** cases.

## 3.7 Stop / speed

Exam action:

> Leave once the evidence settles the competition.

Failure:

- endless checking;
- abandoning evidence when rushed;
- changing a correct answer without new decisive evidence.

## Reading A Secure cannot be inferred from

- high TOEFL Reading alone;
- repeated old English-I true questions;
- one synthetic passage;
- average module score while difficult inference / two-strong-option behavior remains untested.

# 6｜Ability closure — Translation

Translation maturity is not “understand English + write fluent Chinese.”

The chain is:

```text
Representation
→ Fidelity
→ Chinese Reconstruction
→ Timed Delivery
```

Required abilities:

## 6.1 Representation

- clause hierarchy;
- attachment;
- reference;
- scope;
- logical relation;
- degree/modality.

## 6.2 Fidelity

Preserve:

- propositions;
- relation;
- actor/object;
- degree;
- modality;
- omissions/additions.

A smooth Chinese sentence can still be wrong.

## 6.3 Chinese reconstruction

Produce natural Chinese without copying English surface structure.

## 6.4 Load control

Handle dense/nested source by safe restructuring without losing relation or information.

## 6.5 Timed delivery

Complete the entire section under realistic exam pressure.

## Translation evidence hierarchy

```text
same-section correction
< different-section independent output
< delayed independent output
< timed complete section
< paper/handwriting-calibrated execution
< whole-paper preservation
```

Reference translation is a comparison tool, not automatically a unique gold answer.

Translation scoring must explicitly tolerate multiple valid Chinese renderings when proposition/relation fidelity is preserved. Convergence toward one reference style is not itself evidence of higher score.

# 7｜Ability closure — Small Writing

Small Writing is a communicative task.

Required abilities:

1. identify role / audience / purpose;
2. satisfy all required communicative moves;
3. choose useful details;
4. maintain appropriate register;
5. realize intended propositions in stable English;
6. control high-value language errors;
7. complete the task efficiently.

Failure examples:

- polished English but missing one required move;
- generic politeness instead of useful information;
- wrong register;
- spending too much time on sophistication;
- memorized template that does not complete the communicative job.

A good rewrite of the same prompt is repair evidence, not transfer.

Writing transfer must also resist **topic-package overfit**. Different prompt IDs are not enough if they recycle the same semantic theme, visual relation and argument demand. Reusable language is allowed; memorized whole-content packages must not be mistaken for generative ability.

# 8｜Ability closure — Big Writing

Big Writing requires:

```text
Observation
→ Interpretation
→ Core Message
→ Content Generation
→ Development / Organization
→ English Realization
→ Error Control
→ Timed Delivery
```

## 8.1 Observation boundary

Describe only what the source/visual supports before importing a theme.

## 8.2 Core Message

The claim must be:

- grounded;
- specific;
- developable;
- not an empty slogan.

## 8.3 Content generation

Generate reusable information atoms:

- claim;
- why/how mechanism;
- consequence;
- example;
- contrast;
- practical implication / boundary.

## 8.4 Information gain

Each sentence/paragraph should materially advance the answer.

## 8.5 English realization

Stable relation/proposition expression beats ornamental complexity.

## 8.6 Timed delivery

A high-quality unfinished essay is not a secure exam capability.

# 10｜Whole Paper integration closure

Whole Paper is the final integrated validator.

It must test whether task-local capability survives:

- 180-minute resource competition;
- task switching;
- front/back-half fatigue;
- pacing;
- uncertainty;
- Translation/Writing time compression;
- end-of-paper Writing quality;
- answer-sheet / paper operation;
- handwriting;
- completion.

Whole Paper may reopen a locally stable module.

But one noisy Whole Paper does not automatically justify heavy rebuild. Reopen intensity must match the strength and recurrence of counterevidence.

The number of whole-paper runs is an evidence prior, not a sacred quota. Two strong representative runs may sometimes be more informative than three contaminated runs; five unstable runs still do not prove Secure.

Printed section order is Source truth. Execution order may remain a learner strategy variable when exam rules permit. Alternative order is adopted only after real execution evidence shows a benefit.

As Whole Paper becomes representative and stable, it should absorb part of single-module Maintenance.

# 12｜English-specific synthetic standard

Synthetic assets are necessary because old English-I material is exposure-limited.

But synthetic has strict boundaries.

Every synthetic asset must carry:

- target mechanism / ability;
- evidence role;
- version / identity;
- answer/reference separation;
- transfer independence from the Repair example;
- quality/self-attack result;
- calibration status;
- retire/dedupe rule.

Quality gates:

- task-native geometry;
- one defensible key where objective;
- natural English;
- explicit distractor/failure mechanism;
- no accidental option-position cue;
- no answer leakage;
- controlled difficulty;
- representative mechanism coverage;
- no overfitting to the learner's just-repaired wording.

Synthetic may prove:

- mechanism acquisition;
- changed-context transfer;
- stress behavior.

Synthetic may **not** automatically prove:

- English-I score equivalence;
- authentic difficulty equivalence;
- whole-paper performance.

Any asset counted as **ready inventory** must also be executable through an accepted learner path with valid identity, answer/reference gating, evidence capture and exposure semantics. Otherwise classify it as `PREPARED_NOT_EXECUTABLE`, not READY.

Difficulty must be empirically calibrated against appropriate low-contamination authentic evidence.

One-off targeted Repair material should usually remain ephemeral unless reuse is proven valuable.

# 15｜Evidence closure

English already has strong task-local evidence semantics. Highest maturity requires the following to remain explicit.

```text
opened ≠ attempted
attempted ≠ understood
correct ≠ justified
workflow-complete ≠ performance success
same-item repair ≠ transfer
module stability ≠ whole-paper stability
```

Evidence metadata must preserve, where material:

- task/material identity;
- source revision/hash;
- first attempt/output;
- prior exposure;
- assistance;
- explicit time budget / timing status;
- changed-context independence;
- later repair;
- whole-paper context.

## Assistance provenance

At minimum distinguish:

- unassisted;
- Chat/help-assisted;
- source/reference revealed before completion when applicable.

A helped correct answer cannot silently qualify as independent transfer.

## Missing evidence

No W/U record does not mean stable.

No timing budget means timing is uncalibrated, not fast.

Unknown exposure is not unseen.

Runtime assistance flags are necessary but not always sufficient. If prior Chat discussion materially cued the target prompt/mechanism before an attempt, Chat/learner may downgrade independence even when no on-page assistance event exists. Uncertain cognitive independence remains UNKNOWN rather than clean.

Track separately:

- Reading A;

- Small Writing;
- Big Writing;
- Lexical support;
- Whole Paper.

- representative evidence coverage;

# 18｜Forecast falsification / backtesting

Once Real Learner U exists, Forecast itself becomes testable.

Required backtest questions:

- Were prior P20/P50/P80 bands calibrated?
- Was actual productive learning consistently slower/faster?
- Was lexical retention systematically overestimated?
- Did whole-paper degradation repeatedly exceed prior assumptions?
- Did score ranges remain too narrow?
- Did the model repeatedly favor the wrong module?

Repeated miss must reduce confidence and update parameters.

The system must not preserve a forecast merely because its architecture is elegant.

Total-score synthesis must also account for shared execution risk. Do not mechanically add Objective / Translation / Writing midpoint estimates as if section errors, fatigue and time competition were independent. Whole Paper is the main reality check on those independence assumptions.

# 19｜Dynamic control closure

English uses subject-native modes conceptually similar to:

```text
UNCALIBRATED
→ BUILD
→ VERIFY
→ MAINTAIN
→ ELASTIC
```

These are Chat interpretations, not Website learner states.

## Reduce practice

Only when:

- representative evidence floor is satisfied;
- required form/mechanism negative space is covered;
- independent timed performance is stable;
- recurring errors are absent;
- Whole Paper does not contradict local performance;
- new ordinary practice yields little decision-relevant information.

## Increase practice

When:

- mechanism recurs;
- changed-context transfer fails;
- delayed retention drops;
- Whole Paper reveals task degradation;
- lexical work fails to reduce downstream lexical problems;
- new material/conditions alter the demand.

# 20｜Minimum Dose / evidence floor

Minimum Dose exists only to block tiny-sample false confidence.

It is not a quota.

English-specific rules:

- Kian's strong Reading prior may lower the new Reading calibration burden;
- Translation/Writing uncalibrated status may require more complete first-output evidence;
- Part B requires form coverage, not only aggregate count;
- Cloze requires complete-set evidence;
- Whole Paper requires repeated integrated evidence before stable execution claims;
- Lexical uses delayed retention + downstream transfer, not word-count completion.

After the evidence floor is met, additional work must justify itself by new evidence, maintenance hazard or Elastic ROI.

# 21｜Control hysteresis

English must not thrash between BUILD and MAINTAIN because of ordinary noise.

→ small Verify / observe

→ Verify

# 31｜Adversarial stress methodology

English maturity cannot be proven by a fixed script list alone.

Use where relevant:

- parameter grids;
- boundary values;
- reproducible randomized valid states;
- combinatorial cases;
- counterfactual policy comparisons;
- historical sanity/backcast;
- stale/duplicate/missing/corrupt transport;
- decision flip surfaces;
- metamorphic invariants.

Key stress dimensions:

- lexical retention;
- Objective residual error;
- task duration;
- Translation/Writing score level;
- scoring variance;
- handwriting penalty;
- whole-paper degradation;
- exposure contamination;
- daily capacity.

The report must identify:

- high-confidence conclusions;
- parameter-dependent conclusions;
- known flip points;
- highest-value next evidence.

# 32｜Fresh Chat attack

A completely fresh Chat receives only:

- Current English / Lexical durable owners;
- bounded Daily / Resume / English evidence packet;
- current exam facts.

It must be able to answer:

- what English capability currently matters;
- what is unknown;
- what exact task should run next;
- why;
- what evidence would change that decision.

Normal English planning should resolve through a bounded owner path.

If broad repository archaeology is repeatedly required, English ownership/routing is not mature.

---

# 33｜No-Website attack

Remove the Website.

The following must remain semantically correct:

- English score target;
- task cognition;
- Source ownership;
- material roles;
- evidence meaning;
- exposure meaning;
- Lexical boundary;
- repair logic;
- Forecast meaning;
- dynamic control rules.

Website is an executor, not the English brain.

---

# 34｜Evidence identity / revision

Material freshness follows semantic identity, not:

- filename;
- route;
- device;
- tab;
- session.

Duplicate / near-derivative official/synthetic/external objects require exposure classification before Calibration / Transfer / score use.

When Content changes, prior evidence becomes explicitly:

```text
PRESERVE
MIGRATE
STALE
INVALID
```

No old attempt is silently reinterpreted under a new prompt/rubric/material revision.

Representative coverage must be checked across obvious dimensions that matter to English: mechanism, task/form, difficulty/stress, source/evidence class, and timed/integrated context where relevant. A synthetic-only coverage claim cannot silently stand in for authentic difficulty calibration.

---

# 35｜Authentic modality

Formal English score/execution confidence must eventually include realistic paper cost.

Especially for:

- Translation handwriting;
- Small Writing handwriting;
- Big Writing handwriting;
- page switching;
- answer-sheet transfer;
- whole-paper fatigue.

Browser typing can train cognition and produce useful evidence.

It cannot automatically substitute for paper execution time.

# 37｜English-specific stop rule

Stop English system construction when:

- the 85+ Score → Ability → Material → Method → Evidence chain is closed;
- required materials are executable;
- subjective score calibration is adequate for current decisions;
- Forecast survives adversarial attack;
- Chat↔Website Day‑1/full-lifecycle proof is safe;
- fresh audit no longer finds material all-green failure;
- remaining uncertainty depends on Real Learner U or genuinely unavailable evidence.

Then:

```text
real English study
> more English architecture
```

Reopen only for:

- real learner-visible friction;
- evidence invalidity;
- material/source defect;
- Forecast miss;
- a new counterexample that materially changes score/control;
- a genuinely new high-value source need.

Do not reopen because a theoretically prettier framework exists.

# 39｜Final acceptance question

English is near mature only when a fresh Chat can reliably answer:

> For Kian's 85+ English target, which exact score-relevant capability is currently limiting the path; what evidence supports that judgment; what material and method are the smallest effective intervention; what task should happen next; what evidence would change the judgment; how much remaining English capacity is likely required; which stable work should now be reduced or stopped; whether an extra English hour is still worth more than competing Xizong/Politics work; and whether a sudden change in retention, score, capacity, exposure or whole-paper execution can be handled without making Kian maintain the system manually.

If any unanswered question would materially change learning behavior or the 85+ probability:

> continue closure.

If all are answered and further architecture would not improve learning/control:

> stop building and study.
