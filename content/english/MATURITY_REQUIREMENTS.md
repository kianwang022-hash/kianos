# English Highest-Bar Maturity Requirements

Status: **CANDIDATE ACCEPTANCE REQUIREMENTS**

Parent quality bar: `EXAM_SUBJECT_MATURITY_STANDARD.md`

This file does not replace English task contracts. It defines what must be proven before the English subject system may be called mature for the current exam cycle.

## 1. Score closure

Current hard target: **85+**, consistent with the Current English Learning Contract. Any lower number may be used only as an explicitly named recovery / downside reference, not as a competing target owner. Above Secure 85+, English retains elastic upside when marginal value remains competitive with Xizong / Politics.

The subject must treat these as distinct score channels:

- Cloze;
- Reading A;
- Part B;
- Translation;
- Small Writing;
- Big Writing;
- whole-paper execution;
- Lexical as a cross-cutting causal support layer rather than an exam section.

A strong Reading score alone may not imply English readiness.

## 2. Ability closure

Required ability families include:

### Reading A
- evidence localization;
- proposition / scope / attitude discrimination;
- distractor mechanism rejection;
- global vs local consistency;
- lexical meaning-in-context;
- speed without evidence abandonment.

### Cloze
- syntax/semantics/discourse joint fit;
- near-synonym discrimination;
- collocation and grammatical constraint;
- global coherence under local ambiguity.

### Part B
- form-specific discourse reconstruction;
- local reference;
- global fit;
- paragraph/function relationships;
- switching across all currently required forms.

### Translation
- clause/attachment parsing;
- scope and logical relation;
- reference resolution;
- accurate Chinese regeneration;
- complete timed section delivery.

### Writing
- task fulfillment;
- information selection;
- organization;
- language control;
- reusable but non-template-bound expression;
- prompt transfer;
- timed complete output.

### Whole Paper
- pacing;
- switching;
- fatigue resistance;
- end-of-paper writing quality;
- handwriting / paper-delivery cost and answer-transfer behavior where it differs from browser typing;
- stable completion.

### Lexical
- delayed retention;
- retrieval in real English tasks;
- reduction of lexical-caused objective/translation failure.

## 3. Material closure

Every capability must have a ready inventory before need.

Material classes:

- official / authentic task assets;
- low-contamination calibration tasks;
- teaching / repair assets;
- transfer assets;
- stress / edge assets;
- writing prompts;
- translation sets;
- whole-paper execution assets;
- lexical retention/transfer evidence;
- external reading only when it improves real exam capability.

Synthetic assets must pass:

- task-native geometry;
- answer uniqueness;
- explicit distractor/failure mechanism;
- natural language quality;
- controlled difficulty;
- coverage balance;
- anti-leakage;
- independent self-attack.

Synthetic transfer may prove mechanism transfer but cannot impersonate exam-score calibration without evidence.

## 4. Method closure

English uses adaptive control rather than finite completion.

A mature module moves through:

```text
UNCALIBRATED
→ BUILD
→ VERIFY
→ MAINTAIN
→ ELASTIC
```

Secure requires both:

1. a sufficient Minimum Dose / sample floor;
2. independent Performance Evidence.

Minimum Dose is a floor, never a completion quota.

When stable evidence is strong, practice frequency must fall.

A module-level MAINTAIN state may coexist with one open mechanism in BUILD/VERIFY. Broad status must never hide a recurring inference, scope, form-specific, lexical-production or delivery defect.

No-new-information may reduce practice only after representative mechanism/form/difficulty coverage. Repeating homogeneous easy tasks is not evidence that negative space is safe.

When mechanism error, timed collapse, transfer failure or whole-paper regression appears, the exact module/mechanism returns to Build/Verify.

## 5. Evidence closure

Evidence strength must distinguish:

- same-task correction;
- near-transfer;
- independent changed-prompt/task transfer;
- delayed transfer;
- timed complete section;
- whole-paper execution.

A polished rewrite of the same Writing prompt is not proof of transfer.

A correct answer produced by guessing or answer familiarity is weaker than a justified first attempt.

Whole-paper failure may reopen a module even when isolated practice is stable.

Translation and Writing score evidence require accepted scoring anchors and explicit rater/model uncertainty. One Chat score, however plausible, cannot alone create a narrow score Forecast when that judgment would materially change allocation. Use anchored re-score / independent review where feasible for high-impact calibration.

## 6. Maintenance and Elastic closure

Secure modules are not deleted; they enter adaptive Maintenance.

Maintenance frequency should decrease with repeated stability and may be naturally supplied by Whole Paper.

After protected English viability is met, an extra English hour enters Elastic only when marginal ROI remains competitive with Xizong/Politics.

ROI considers:

- expected score gain;
- variance reduction;
- speed / time release;
- cross-task transfer;
- compounding value;
- material/freshness cost;
- diminishing returns;
- cross-subject opportunity cost.

The question is never “can English still improve?” It is “is the next English hour currently worth more than competing actions?”

## 7. Forecast closure

P20/P50/P80 estimates capacity to Secure / next Gate.

It must not prescribe fixed passage/set counts.

Forecast inputs include:

- current module state;
- Minimum Dose remaining;
- observed task duration;
- mechanism-error recurrence;
- repair loops;
- transfer success;
- lexical support trajectory;
- whole-paper execution reserve.

Forecast must expose separate uncertainty for:

- Objective;
- Translation;
- Writing;
- Whole-paper execution.

Forecast/adversarial proof must sweep the learner parameters that can reverse the conclusion: lexical retention, Objective residual error, Translation/Writing output level, task duration, handwriting/paper delivery cost, whole-paper degradation and daily capacity.

## 8. Ready-inventory closure

Before study demand, maintain adequate ready inventory for:

- Reading mechanism probes;
- Cloze fresh task-native sets;
- all Part B forms;
- Translation complete sections;
- Small Writing prompts;
- Big Writing prompts;
- transfer/stress variants;
- selective whole-paper execution.

Do not generate the learner’s next task at the last second unless the task is intentionally adaptive and the generator itself is accepted.

Generated assets must also have a lifecycle: intended mechanism, evidence role, version/identity, transfer independence, calibration status, dedupe/retire rule. One-off Repair assets should remain ephemeral unless reuse is proven valuable.

## 9. Execution closure

Chat chooses:

- which module needs Build/Verify/Maintain/Elastic work;
- exact depth;
- when to stop.

Website executes existing task/workspace semantics and captures evidence.

A fresh Chat with Current + Daily Packet must be able to continue without undocumented prior-chat knowledge.

## 10. Adversarial acceptance

Attack at least:

- excellent Reading but weak Writing/Translation;
- Minimum Dose met but performance unstable;
- one perfect task with tiny sample;
- repeated mechanism error after apparent repair;
- lexical retention high but real-task lexical failure unchanged;
- same Writing prompt repaired but new prompt collapses;
- isolated sections stable but whole-paper fatigue breaks them;
- contaminated official material;
- synthetic ambiguity / answer leakage;
- Part B one form strong and another weak;
- objective stable but timing too slow;
- Whole Paper stable once but not repeatable;
- stale Chat plan / missing packet field / browser restart;
- learner capacity loss / bad week;
- Chat incorrectly keeps a low-ROI module in Build;
- Chat falsely declares a stable module weak because evidence is sparse/selective;
- homogeneous tasks producing a false No-new-information signal;
- one-model Writing/Translation scoring moving Forecast too confidently;
- same material appearing through another source/copy and being misclassified as fresh;
- adaptive synthetic generation overfitting the repaired mechanism;
- English Elastic work crowding out higher-ROI Xizong/Politics.

## 11. Final acceptance question

A mature English system must be able to answer:

> Which module is not yet Secure, what minimum evidence is still missing, what is the smallest task that can change the judgment, what maintenance is sufficient for already-stable modules, and is the next English hour still the best use of cross-subject capacity?
