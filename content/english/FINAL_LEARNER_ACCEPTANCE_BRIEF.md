## 4｜English learning model to pressure-test

The Current model is a **claim to attack**, not a guaranteed answer.

### English-wide direction

```text
clean real performance
→ fast triage
→ Stable: leave
→ cheap one-off correction: understand and leave
→ meaningful recurring / ambiguous / expensive failure:
     smallest useful repair
→ return to performance
```

First Learning is currently claimed to be a **complete-but-skippable repair reservoir**, not a prerequisite course.

Teacher/framework material is Source/Knowledge input, not automatically learner order.

### Objective

Objective is one scoring/runtime family but **not one cognition**.

Current claimed task models:

```text
Reading A
question demand
→ decisive passage evidence
→ option proposition
→ adjudication

Cloze
slot demand
→ syntactic / lexical / discourse constraints
→ candidate competition
→ best fit

Part B
discourse skeleton
→ target/position role
→ candidate role/cohesion
→ global reconciliation
```

The audit must reject either extreme:

- falsely collapsing all three into “定位 + 同义替换”;
- inventing three bloated courses when one shared primitive genuinely suffices.

Whole passage/set remains the claimed clean attempt and review context.

### Translation

Current claimed smallest model:

```text
represent English meaning / relations
→ reconstruct faithfully in natural Chinese
→ deliver under exam constraints
```

Fidelity is cross-cutting, not a compulsory fourth stage.

The whole Translation set is the learner-facing attempt/review context; diagnosis may narrow to sentence/clause.

First translation evidence must survive revision.

Reference stays protected during clean attempt.

Learner Reconstruction is the repair action; AI-written replacement is not.

### Writing

Current claimed six primitives:

```text
Task / genre fulfillment
Content generation
Organization / development
English realization
Register + high-value error control
Timed delivery
```

One complete essay is the learner-facing task/review unit.

Small/Big are task specializations, not extra base primitives.

Plan is optional; Direct mode is legitimate.

Chat may review/coaching the essay, but the learner must revise/re-generate.

Same-prompt rewrite is repair evidence, not mastery.

### Vocabulary / Lexical

Learner-facing Vocabulary belongs under English, while Lexical semantic truth remains independently owned.

Current intended boundary:

```text
English task exposes exact lexical failure
→ exact Word / sense / phrase / construction / relation
→ smallest Lexical repair
→ return to the originating English task
```

A read-only lookup must not manufacture Lexical learner state.

English must not create a second local vocabulary truth.

### External Reading

External Reading is a Reading data/source path, not automatically another UI family.

Unseen material is diagnostic capital.

Compatible question-bearing objects should reuse Reading task semantics.

Questionless periodical reading may use a simpler read → optional compression/repair path when that is the true task.

Do not build/consume a fresh corpus merely for completeness.

### Whole paper

English must eventually execute the integrated 180-minute paper:

```text
Cloze
+ Reading A ×4
+ Part B
+ Translation
+ Small Writing
+ Big Writing
```

Whole-paper execution is a later integrated performance phase, not a second permanent English course.

## 5｜Required acceptance attacks

### A. Learning Logic attack — mandatory first gate

Challenge at minimum:

- Is performance-first correct for the Current learner, or does some missing foundational ability require a real first-learning prerequisite?
- Are First Learning pages truly skippable reservoirs, or are important abilities hidden behind a path the learner will never enter?
- Does Stable exit too cheaply anywhere and lose high-value learning?
- Does Wrong/Uncertain trigger too much ceremony anywhere?
- Are review/context units correct for each task?
- Does fresh-evidence logic preserve transfer truth without creating a transfer curriculum?
- Does Chat enter too early, too late, or too often?
- Does any module confuse “framework exists” with “learner should study framework now”?

If the answer is wrong, reopen the earliest Rule/Content owner before testing more UI.

### B. Objective cognition attack

Use real representative Reading A / Cloze / all Part B forms.

Attack:

- answer leakage before Submit;
- one-question/one-blank wizard behavior replacing whole-task cognition;
- Reading A option adjudication being flattened into keyword matching;
- Cloze becoming 20 isolated vocabulary questions;
- Part B being flattened into independent item review despite coupled/global errors;
- Uncertain-correct being forced into deep repair;
- clean work creating Chat/review debt;
- Lexical failures being duplicated into Objective content;
- pending backend claims surfacing as learner obligations.

### C. Translation attack

Prove:

- whole source + whole set stay available;
- first attempts cannot be overwritten by revision;
- Reference cannot leak during clean attempt;
- Stable PASS is real;
- meaningful failure can narrow to the smallest useful scope;
- learner Reconstruction is preserved;
- Chat review is optional/secondary;
- deep reference material remains accessible without becoming compulsory course order;
- pending transfer evidence stays silent unless naturally relevant.

### D. Writing attack

Prove:

- complete prompt remains visible while writing;
- complete essay is the formal task context;
- Direct mode works without fake plan evidence;
- Planned mode works when chosen;
- first draft remains immutable evidence;
- no model answer/rewrite leaks into clean production;
- PASS exits cheaply;
- Chat identifies high-value failure instead of becoming ghostwriter;
- learner re-generates the affected scope;
- cosmetic polish cannot outrank task/content/organization failure;
- same prompt cannot close transfer/mastery;
- protected true-exam prompts are not consumed by engineering tests.

### E. Lexical integration attack

Test at least Reading/Cloze plus one productive task boundary where relevant.

Required:

- exact lexical identity, no fuzzy invented target;
- lookup does not create learner debt;
- a qualified real lexical failure can enter the exact Lexical repair target;
- replay is idempotent;
- qualified later evidence can update/dormant the exact target under Lexical rules;
- return to the originating English task is natural;
- English does not become a second lexical database.

Do not re-audit all 7,946 Lexical owners inside this English task unless a real integration defect points upstream.

### F. External Reading / freshness attack

Verify:

- held-out true exam / TPO / IELTS material remains protected before clean attempt;
- substantial memory residue is not mislabeled as fresh evidence;
- External Reading reuses Reading cognition only when interaction semantics truly match;
- questionless reading is not forced into fake exam questions;
- material is selected because it serves learner value, not quota/completeness.

### G. Chat control / Resume attack

Current Rule says **Chat owns cross-task strategy**.

Required round trip:

```text
factual English learner evidence
→ Chat
→ Chat chooses a useful next action only when needed
→ typed English Session Instruction
→ website validates exact Current object identity
→ exact Resume
```

Attack:

- website secretly ranking/recommending tasks;
- most recently opened page being mistaken for highest-value Resume;
- finished work resurfacing as debt;
- stale-day instruction being accepted;
- invented object IDs;
- evidence packet containing recommendations instead of facts;
- Chat instruction removing free navigation;
- malformed return partially mutating learner state.

### H. Whole-paper attack

Use real Current paper construction and isolated exam-session state.

Prove:

- exact 180-minute / 100-point structure;
- all task owners hydrate the correct same-year paper;
- custom task order is explicit and valid, never silently invented;
- exam work cannot pollute ordinary study attempt state;
- objective answers/results remain hidden until the intended exam release boundary;
- Seal is irreversible/idempotent as intended;
- objective score releases correctly out of 60;
- Translation/Writing remain productive outputs for semantic review rather than receiving fake automatic scoring;
- whole-paper evidence is exportable to Chat without losing task identity;
- restart/navigation preserves the exam session safely;
- whole-paper use does not silently consume protected material outside learner intent.

### I. Evidence / debt attack

Across modules verify:

```text
Wrong / Uncertain = observation
≠ automatic diagnosis
≠ automatic durable debt
≠ mastery state
```

Prove:

- first meaningful evidence survives;
- diagnosis ≠ repair;
- repair ≠ mastery;
- same-item correction is weaker than later fresh transfer;
- irrelevant later evidence cannot close a claim;
- genuinely independent downstream failures may remain separate;
- dependent/cascade failures are not multiplied into artificial debt;
- private learner evidence remains private.

### J. Visual / Mac Human Gate

Inspect real Mac-wide surfaces, not CI screenshots alone:

- English Home;
- Reading A;
- Cloze;
- all materially different Part B forms;
- Translation;
- Writing;

Check:

- typography comfortably readable;
- no duplicate navigation;
- no engineering/state-machine language dominating learner work;
- no generic card-wall/SaaS feel;
- family coherence without erasing task-specific cognition.

Any material visual repair requires real Mac evidence + Kian Human Gate.

### K. Recovery / durability / evolvability

Verify:

- refresh/restart cannot corrupt first-attempt evidence;

- GitHub → Mac Current sync cannot overwrite private learner evidence;

## 7｜Repair rule

When a defect is found:

```text
learner/evidence failure
→ earliest responsible owner
→ smallest repair
→ affected targeted evidence
→ bounded representative regression
→ reconciliation
```

Examples:

- wrong learner model → English Learning Contract / exact task learning owner;
- missing/incorrect capability content → exact canonical task Content;
- correct semantics shown badly → Visual owner;
- correct behavior not executable → Runtime owner;
- evidence corruption → Evidence/runtime owner;
- shared durability failure → Shared Platform owner.

Do not solve an Engineering problem by rewriting Learning Logic.

Do not solve a Visual problem by duplicating Content.
