# English Maturity Gap Matrix

Status: **CANDIDATE · E1 OUTPUT**
Date: 2026-09-20
Standard: `ENGLISH_HIGHEST_MATURITY_STANDARD.md`
Stage plan: `ENGLISH_HIGHEST_MATURITY_STAGE_PLAN.md`

Purpose:

> Identify real English maturity gaps from Current truth before implementation.

Priority meanings:

- **BLOCKER** — prevents a trustworthy 85+ control loop or Day-1 learning decision.
- **HIGH** — materially affects evidence/score/control and should close early.
- **MEDIUM** — useful but may wait for Real Learner U.
- **LOW / DEFER** — not currently limiting the 85+ path.

- rewriting Writing Guide;
- another English Home;
- another learner-state system;

- broad External Reading expansion before a real need.

The next implementation phase should therefore be narrow.

```text

→ evidence contamination / exposure integrity
→ Forecast
→ dynamic control proof
```
