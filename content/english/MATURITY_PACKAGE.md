
## Secure dual gate

A task family requires:

1. enough representative independent evidence to avoid tiny-sample false confidence;
2. performance evidence strong enough for the real task demand.

Minimum evidence is a prior/floor, not a quota.

## Add work only for a reason

Increase work when, for example:

- a reusable mechanism failure recurs;
- fresh work is materially worse than exposed work;
- correct answers remain uncertain/slow;
- changed-context transfer fails;
- Whole Paper degrades local capability;
- Lexical study fails to reduce downstream lexical loss/latency.

Decrease work when:

- representative evidence is stable;
- new tasks yield no actionable information;
- Whole Paper naturally supplies enough maintenance evidence.

## Hysteresis

```text
one anomaly
→ small Verify

repeated independent defect
→ Verify

clear reusable failure
→ Build

whole-paper / repeated fresh collapse
→ major reallocation candidate
```

False Secure and False Unstable are both defects.

After 85+ is protected, extra English work competes with other subjects using:

- expected score gain/protection;
- variance reduction;
- speed/time release;
- transfer value;
- latency;
- fresh-material cost;
- diminishing return;
