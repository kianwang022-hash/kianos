## Current learner shape

Xi Current freezes the first-round rule:

> 先分层级和身份，再做固定表述精确化。

Current teaching shape:

```text
HIERARCHY_ROLE_GOAL_PRINCIPLE_PATH_WITH_CONFUSABLE_FORMULATION_BOUNDARIES
```

The learner-facing risk is often not failure to understand a long causal argument, but mixing nearby labels that belong to different levels of the same theory structure.

Mac wide landscape should therefore use width for **role/hierarchy simultaneity**, not expose every backend list at once.

## Representative test — C02 Chinese Dream / Chinese Modernization

Current chapter-level identity chain:

```text
民族复兴
→ 中国梦：总目标的集中表达
→ 阶段性战略安排
→ 中国式现代化：实现强国建设和民族复兴的现实道路
→ 中国特色 / 本质要求 / 重大原则 / 重大关系
```

Accepted chapter-wide Mac rail:

```text
最终目标        目标表达        现实道路        道路是什么        根本上必须什么       推进时怎样把握       长期怎样平衡
民族复兴   →   中国梦   →   中国式现代化   →   中国特色   →   本质要求   →   重大原则   →   重大关系
```

This rail is an identity/orientation device, not a claim that all items are a strict causal sequence.

### Natural Unit focus rule

When entering a Current Unit, preserve the whole identity rail at low weight and enlarge the current role question.

Examples from Current C02:

```text
中国特色     = 道路特征 / 是什么样
本质要求     = 根本要求 / 必须做到什么
重大原则     = 推进原则 / 怎么坚持
重大关系     = 实践张力 / 如何平衡
文明新形态   = 文明意义 / 历史价值
```

The main learner task is to keep these hats stable before memorizing exact lists.

### Dense-list handling

Current `content_support` contains complete lists such as five characteristics, nine essential requirements, five principles and six major relationships. These do not all become equal-weight first-view cards merely because they exist.

Accepted projection:

```text
first view
→ role / identity / nearby contrast
→ only the currently owning list at readable density when useful
→ other neighboring lists remain visible by title/role, not fully expanded
```

This uses interaction only when switching the **current cognitive object** (e.g. from Characteristics to Essential Requirements), not to reveal a single object's baseline useful information.

## Xi Natural Unit grammar — ACCEPTED

A Xi Natural Unit may project:

```text
1. chapter role / WHY NOW
2. low-weight subject/chapter hierarchy rail
3. current role question
4. current identity / hierarchy object
5. nearest confusable role/boundary
6. Current-owned fixed formulation only at the priority appropriate to first round
7. Chengfeng handoff / look-for questions
8. optional lightweight closure
9. Xiao1000 through the preserved Politics Workbench
```

Rules:

- role/hierarchy precedes exact-list memorization;
- do not show all backend `content_support` lists simultaneously;
- do not flatten goal / road / characteristic / requirement / principle / relationship into equal cards;
- current list can be dense on Mac, but neighboring objects should remain contextual rather than compete for attention;
- fixed formulation must preserve Current wording/identity and cannot be silently rewritten;
- source-heavy detail remains on Chengfeng iPad/MarginNote;
- no new mandatory recall or diagnosis step is introduced;
- question verification uses the preserved historical Politics Workbench.
