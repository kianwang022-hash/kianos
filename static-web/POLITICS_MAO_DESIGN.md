## Current learner shape

Mao Current uses the teaching shape:

```text
HISTORICAL_PROBLEM_TO_THEORY_RESPONSE_WITH_POSITIONING_BOUNDARIES
```

The learner problem is therefore not primarily a chronology page and not primarily a Marxism-style abstract relation network. The recurring first-round task is:

```text
real historical / construction problem
→ theory response
→ identify each answer's role / position
→ keep nature / leadership / goal / road / method boundaries from crossing
→ return to Chengfeng for complete source study
```

Mac wide landscape remains the design origin.

## Representative test A — C02 New Democratic Revolution

Current chapter logic:

```text
国情
→ 主要矛盾
→ 革命任务 / 对象
→ 革命性质
→ 总路线：对象 / 动力 / 领导 / 性质 / 前途
→ 政治 / 经济 / 文化纲领
→ 道路
→ 三大法宝
```

### S01 accepted geometry

Use a horizontal decision chain rather than prose blocks:

```text
半殖民地半封建国情
→ 主要矛盾
→ 革命任务 / 对象
→ 革命性质
```

Keep the decisive boundary directly visible at lower weight:

```text
革命性质由任务和对象决定
≠ 单看谁来领导
```

### S02 accepted geometry

Use a role matrix because the Current problem is explicitly “怎样放在一张结构图里而不串帽子”:

```text
对象 | 动力 | 领导 | 性质 | 前途
```

Below that, project the three program layers only as their role:

```text
政治纲领 | 经济纲领 | 文化纲领
```

Do not duplicate the complete continuous Chengfeng detail. Current `content_support` explicitly keeps many exact lists/source details in Chengfeng.

Directly visible boundaries:

```text
性质 ≠ 领导 ≠ 前途
民族资产阶级 = 动力之一，同时有两面性
新民主主义共和国 = 过渡形式 ≠ 社会主义国家本身
```

### S03 accepted geometry

Separate “road” from “three magic weapons” rather than putting four equal cards beside each other:

```text
道路：农村积累力量 → 包围城市 → 武装夺取政权

支撑这条革命实践：
统一战线   武装斗争   党的建设
扩大同盟   斗争形式   保证领导/方向
```

Boundary:

```text
三大法宝 ≠ 革命道路本身
```

## Mao Natural Unit grammar — ACCEPTED

A Mao Natural Unit may project:

```text
1. historical / construction problem
2. current theory response or role matrix
3. sequence position when the answer belongs in a larger historical-theoretical chain
4. decisive identity/boundary distinctions
5. small Current-owned active precision only when needed to prevent hat-swapping
6. Chengfeng handoff / look-for questions
7. optional lightweight closure
8. Xiao1000 through the preserved Politics Workbench
```

Rules:

- do not convert Mao into a second History timeline course;
- do not convert Mao into a generic card grid of slogans;
- parallel theory answers remain parallel when Current says they answer one common problem;
- role/identity matrices are preferred when the real learner risk is label confusion;
- source-heavy detail remains on Chengfeng iPad/MarginNote;
- no new mandatory recall or diagnosis step is introduced;
- question verification uses the preserved historical Politics Workbench.
