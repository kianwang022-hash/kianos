This owner is intentionally narrow. It owns **System Recall and the handoff out of the learning surface**. It does not own formal question practice.

## 1｜Learner path

```text
whole System genuinely learned
→ System Framework releases one quiet “进入 System Recall” handoff
→ dedicated System Recall surface
→ System Recall Front
→ System Recall Reveal
→ complete this Recall
→ Practice(scope = current System) when an accepted question scope exists
```

System Recall is part of the learning/reconstruction chain and therefore **does not depend on exact official-question scope availability**. Question-scope availability controls only the Practice handoff.

Hard surface rule:

> **System Framework and System Recall are two different learner surfaces.** The System page may release the next-action handoff after every Block is genuinely complete, but it must not embed the Recall workspace inside the Framework page as an accordion, details region or bottom expansion. Recall owns its own full L3 route/workspace.

## 2｜Recall Front

Before Reveal, the workspace stays answer-safe.

Visible:
- the neutral Current recall prompt;
- reconstruction dimensions such as 系统主链 / 并行控制 / Failure 定位 / 病例判断顺序;
- the action to reveal.

Hidden:
- actual spine contents;
- parallel-control contents;
- Failure chains;
- reverse-case answers;
- other answer-bearing System model content.

Kian may reconstruct mentally, verbally or on paper.

**No web scratch textarea is needed.** Typed scratch is neither required evidence nor a completion gate.

Interaction:

```text
Space = reveal / hide model
Enter = after Reveal, complete Recall
```

## 3｜Recall Reveal

Reveal restores the System's own Current compressed cognition. It may include, only when Current owns them:

- System spine / mother model;
- parallel controls;
- Current free-reconstruction objects;
- Failure Modes;
- reverse-case / unfamiliar-case algorithm;
- other accepted System-level compressed relations.

Presentation should read as **one cognitive paper**, using typography, alignment and thin dividers before cards.

Different Systems keep their own cognition. A1 geometry must not invent A2/A3 relations or vice versa.

## 4｜Practice boundary

Formal questions are owned only by `XIZONG_PRACTICE_DESIGN.md`.

System Recall must not implement or style:

- Question Map;
- answer options;
- Fast Sweep;
- result visibility;
- Marked;
- explanation layout;
- W/U concentrated review;
- whole-paper behavior.

When the current System has an accepted exact question scope, completion exposes a quiet handoff:

```text
进入训练 · <System>
```

If no accepted exact question scope exists, Recall still completes normally and no broken/fake Practice scope is invented.

## 5｜Evidence

Recall completion remains browser-private learner evidence. New Content invalidates only the smallest affected evidence according to the existing Evidence guard.

System Recall completion is not:
- a mastery claim;
- a Question attempt;
- a substitute for later application.
