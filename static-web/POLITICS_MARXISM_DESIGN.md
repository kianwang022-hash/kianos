## Marxism cognitive shape — ACCEPTED BASELINE

Marxism is not projected as History chronology/stage geometry. Its primary learner object is:

```text
concept / relation network
+ reasoning chain
+ decisive boundary
+ small amount of first-round Exact when Current explicitly requires it
```

The learner-facing question is usually not “what happened next?” but:

```text
what is related to what?
why does A support / produce / constrain B?
which concepts look similar but answer different questions?
what total relation does a group of labels form?
```

Mac wide landscape remains the design origin. High density means more simultaneously useful relations, not more cards or chrome.

## C00-S02 — ACCEPTED REFERENCE

C00-S02 proves that one Natural Unit may contain multiple equally important framework maps.

Accepted Mac-wide rule:

> When two Current framework maps are both first-round useful and fit comfortably on the intended Mac viewport, show them simultaneously rather than hiding one behind Map tabs.

For C00-S02 this means side-by-side first-round visibility of:

```text
Map A — basic characteristics
people-oriented + practical + developmental → revolutionary
scientific → scientific basis of revolutionary
scientific + revolutionary → unity

Map B — contemporary value
                     ┌ recognition tool / understand contemporary world
contemporary value ──┼ action guide / guide contemporary China
                     └ scientific truth / human social progress
```

The practical-character relation chain is also first-round useful and should be directly visible at lower visual weight:

```text
from practice → back to practice → tested in practice → develops with practice
```

The three Current boundaries are first-round useful and may be shown simultaneously in a compact boundary row:

```text
people-orientation ≠ denying class character
scientificity ≠ opposition to revolutionary character
action guide ≠ ready-made concrete plan / road / model
```

Current `FIRST_ROUND_EXACT` may be attached locally to its owning node without creating a separate Exact card. Example: `人民性是马克思主义的本质属性，人民至上是马克思主义的政治立场。`

Items marked `PRECISION_NOT_ORIENTATION` remain downstream.

## Marxism Natural Unit composition grammar — PROVISIONAL FREEZE

A Marxism Natural Unit may project:

```text
1. current problem / why-now
2. one or more framework maps
3. relation-chain deepening only where it explains a decisive relation
4. decisive boundaries
5. local FIRST_ROUND_EXACT only when Current explicitly requires it
6. Chengfeng handoff / look-for questions
7. optional lightweight mental closure
8. Xiao1000 via the preserved Politics Workbench
```

Rules:

- maps preserve semantic topology; do not coerce hub/branch relations into a fake linear chain;
- when multiple maps are simultaneously useful on Mac, simultaneous visibility is preferred to reveal-only tabs;
- not every semantic layer receives equal visual weight;
- node prose may be shorter than source prose but must preserve Current meaning;
- boundaries are not decorative “易混卡”; they appear only when Current owns a decisive distinction needed for understanding;
- no separate Suyi course or continuous Astro lecture is created;
- Chengfeng remains continuous source learning on iPad/MarginNote;
- Xiao1000 uses the preserved historical Politics Workbench interaction/information architecture;
- no extra learner process is introduced merely because semantic structure is richer.
