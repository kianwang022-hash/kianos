## Marxism cognitive shape — ACCEPTED

Marxism is not projected as History chronology/stage geometry. Its primary learner object is:

```text
concept / relation network
+ reasoning chain
+ decisive boundary
+ small amount of first-round Exact when Current explicitly requires it
```

The learner-facing question is usually not “what happened next?” but:

```text
what is related to what?
why does A support / produce / constrain B?
which concepts look similar but answer different questions?
what total relation does a group of labels form?
```

Mac wide landscape remains the design origin. High density means more simultaneously useful relations, not more cards or chrome.

## C02-S01 dialectics generalization — PASS

Current `content/politics/learning/marxism/ch02.json` is a materially harder test than C00. One Natural Unit coordinates multiple concepts/laws that must not become six equal definition cards.

The Current teaching chain is:

```text
普遍联系   → relationship network / conditions
发展       → direction / new quality
对立统一   → root动力
矛盾分析   → universality + specificity + hierarchy
量变质变   → state transition
否定之否定 → forward + tortuous development form
```

Accepted Mac-wide projection principle:

```text
current question across the top
→ horizontal responsibility strip: each concept answers a different development question
→ one visible integrative chain tying them into one development model
→ compact decisive-boundary row
→ Chengfeng handoff
```

Representative structure:

```text
联系中的事物
→ 发生发展
→ 内部矛盾提供动力
→ 量变 / 质变解释跃迁
→ 否定之否定解释发展形式
```

The embedded fine-grained contradiction-analysis Natural Unit remains a switchable cognitive object rather than being flattened into the overview. This is an appropriate use of interaction: switching to a materially deeper cognitive object, not revealing baseline information that should already be visible.

Major Current boundaries remain directly available at lower weight, including:

```text
联系普遍 ≠ 联系任意
变化 ≠ 发展
矛盾普遍 ≠ 所有具体问题用同一办法处理
主要矛盾 ≠ 矛盾主要方面
辩证否定 ≠ 简单抛弃
```

No new learner workflow is required. The C00 grammar generalizes to a real dialectics chapter.

## Marxism Natural Unit composition grammar — FROZEN

A Marxism Natural Unit may project:

```text
1. current problem / why-now
2. one or more framework maps or relation-responsibility surfaces
3. relation-chain deepening only where it explains a decisive relation
4. decisive boundaries
5. local FIRST_ROUND_EXACT only when Current explicitly requires it
6. Chengfeng handoff / look-for questions
7. optional lightweight mental closure
8. Xiao1000 via the preserved Politics Workbench
```

Rules:

- maps preserve semantic topology; do not coerce hub/branch relations into a fake linear chain;
- when multiple maps are simultaneously useful on Mac, simultaneous visibility is preferred to reveal-only tabs;
- not every semantic layer receives equal visual weight;
- node prose may be shorter than source prose but must preserve Current meaning;
- boundaries appear only when Current owns a decisive distinction needed for understanding;
- complex embedded Natural Units may be switched as genuine cognitive objects;
- no separate Suyi course or continuous Astro lecture is created;
- Chengfeng remains continuous source learning on iPad/MarginNote;
- Xiao1000 uses the preserved historical Politics Workbench interaction/information architecture;
- no extra learner process is introduced merely because semantic structure is richer.

The Marxism grammar is now ready to enter the shared Politics implementation brief. Real browser implementation still requires Mac-wide screenshot acceptance before any mass rollout.
