## Current learner shape

Ethics-Law Current freezes the learner path:

> 先判断概念/规范处在哪一层，再分清最近边界，最后放回具体关系或情境做判断。

Current teaching shape:

```text
CONCEPT_BOUNDARY_NORMATIVE_JUDGMENT_IDENTITY_AND_SITUATIONAL_APPLICATION
```

The learner-facing object is therefore usually:

```text
concept / norm identity
→ nearest boundary
→ relation or evaluation scale
→ concrete scenario / application
```

Mac wide landscape should show these simultaneously when they belong to one first-round judgment object.

## Representative test A — C05 Socialist Morality

### S01 core / principle accepted geometry

Current gives a natural left-to-right structure:

```text
起源条件
劳动 / 社会关系 / 自我意识
→
本质与功能层
反映经济关系 / 调节利益关系
→
社会主义道德身份
→
核心：为人民服务   |   原则：集体主义
```

The decisive boundary is directly visible:

```text
核心 ≠ 原则
集体主义 ≠ 否定个人正当利益
道德 ≠ 调节社会一切行为的唯一规范
```

Application strip:

```text
固定表述题 → 先判断题目在问起源 / 本质 / 功能 / 属性 / 核心 / 原则
个人—集体冲突题 → 先判断个人利益是否正当，再看共同利益中的协调
```

Do not manufacture unsupported exact names when Current explicitly says the source shard is incomplete.

### S03 scene grammar

For public / professional / family / personal morality, use the wide viewport as a scene matrix rather than a vertical list:

```text
公共生活 | 职业生活 | 家庭生活 | 个人修养
责任对象 | 责任对象 | 责任对象 | 自我稳定德性
```

The Current application rule drives the learner action:

> first identify the relationship/scene, then match the norm identity.

### S04 fixed-hat distinction

Use a compact identity strip:

```text
志愿服务精神 = 奉献 / 友爱 / 互助 / 进步
精髓 = 奉献精神
重要载体 = 培育和弘扬社会主义核心价值观
```

These are nearby hats, not three separate courses.

## Representative test B — C06 Law / Rule of Law

### S02 governance hierarchy

Current directly supports a role matrix:

```text
根本遵循 / 行动指南  习近平法治思想
前进方向             中国特色社会主义法治道路
总抓手               中国特色社会主义法治体系
宏伟目标             法治中国
工作格局             科学立法 / 严格执法 / 公正司法 / 全民守法
```

Below this, keep the two related but distinct structures visible:

```text
共同推进：依法治国 / 依法执政 / 依法行政
一体建设：法治国家 / 法治政府 / 法治社会
```

Do not merge these into one generic list.

Application prompt remains first-round useful:

> identify whether the question asks for thought basis, road, general grasp, goal, co-advance/integrated construction, or four-part work pattern before matching the phrase.

### S04 legal-thinking application

The five Current legal-thinking contents can use horizontal columns:

```text
法律至上 | 权力制约 | 公平正义 | 权利保障 | 程序正当
```

Below, retain the rights/obligations relation and nearest boundaries. Scenario questions should ask the learner to classify the principle being tested before evaluating the action.

## Ethics-Law Natural Unit grammar — ACCEPTED

A Natural Unit may project:

```text
1. concept / normative question
2. concept or role identity
3. nearest Current-owned boundary
4. relation / evaluation scale when needed
5. scenario/application rule
6. only Current-supported active precision
7. Chengfeng handoff / look-for questions
8. optional lightweight closure
9. Xiao1000 through the preserved Politics Workbench
```

Rules:

- concept/boundary/application are one cognitive object when the Current Unit uses all three; do not hide each behind separate cards;
- use horizontal scene matrices or role matrices when Mac width makes comparison clearer;
- fixed expressions remain attached to their owning identity rather than becoming free-floating memorization cards;
- do not fill Current source gaps from model memory;
- dense full lists remain on Chengfeng unless Current marks them as first-round active/precision;
- no new mandatory recall or diagnosis step is introduced;
- question verification uses the preserved historical Politics Workbench.
