## Frozen product principles

Inherited authority:

1. `static-web/PRESENTATION_CONTRACT.md` — canonical shared Projection / interaction grammar;
2. `SYSTEM_CONTRACT.md` — surface ownership and shared learner-surface boundaries;
3. applicable domain Learning / Interaction contract — cognition, learner order and lane-specific semantic shape;
4. current canonical content/runtime owners — actual material to project.

Hard UI principles:

- **Dense Calm**: medium-high useful density, comfortable readable type, low noise, strong hierarchy;
- primary environment = Mac / wide landscape; narrow layout is responsive fallback, not design origin;
- cognition before components;
- `Content structure ≠ page structure`;
- do not default to `Markdown heading → equal card / panel`;
- horizontal space expresses simultaneous relationships; state transition expresses sequence;
- one dominant cognitive task at a time;
- cards / borders exist only for real semantic or interaction boundaries;
- avoid tiny-text + giant-whitespace pseudo-minimalism;
- preserve domain variation when cognition differs;
- visual polish may not change learning semantics, evidence/mastery meaning, repair admission, Resume priority, surface ownership or canonical truth.

Shared semantic presentation roles remain:

`Problem / Map / Chain / Compare / Boundary / Anchor / Exact / Handoff / Recall / Question / Repair / Closure / Reference`.
