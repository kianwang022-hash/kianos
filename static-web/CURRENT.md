## Kian preference baseline

- **Dense Calm** — medium/high useful density, comfortable readable type, low visual noise.
- draw the logic; do not require the learner to rebuild hierarchy/relations from prose.
- no tiny-text + giant-whitespace pseudo-minimalism.
- no default card/panel pile merely because components exist.
- obvious primary action; progressive disclosure for secondary capability.
- stable, predictable, low-friction interaction.
- work/content surfaces calm; entry/identity may be stronger.
- stable/correct paths should be extremely fast; Wrong/meaningful Uncertain gets heavier only when useful new information appears.

### Protected interaction baselines

```text

keyboard-first navigation / Reveal / local targeting / Challenge
```

These are interaction grammar, not universal evidence/mastery semantics.

## Domain product conclusions

### English = Digital Workbook + Adaptive Coach

Task / passage / prompt / learner output is foreground. First Learning is a complete-but-skippable coaching/repair reservoir. Stable work exits quickly.

- Writing: preserve whole-essay runtime, Prompt, optional Plan/Direct, Draft, PASS and smallest Repair; make six primitives on-demand Coach.
- Translation: preserve source/work split, immutable first attempt, delayed Reference, PASS and Reconstruction; reduce chaptered First Learning and engineering chrome.
- Reading A: preserve split passage/question workspace, readable passage, continuous practice and optional whole-passage deep review; add shared `1–4` grammar and reduce chrome.
- Cloze: preserve whole passage + active blank + unified submit; add keyboard-first blank traversal and larger reading type.
- Part B: **do not redesign IA**. Its material/candidate/map geometry and real task-form distinctions are already good.
- English Resume: include Cloze and Part B alongside Reading A / Translation / Writing without manufacturing debt; Continue should dominate architecture explanation.
