## 缺血、损伤、坏死的电观察

[内科物理P414 / 印刷P342：八种ST形态](p414-ST-forms-original-crop.png)

上排区分水平、上斜、下斜、鱼钩样压低；下排区分水平、弓背向上、弓背向下、墓碑样抬高。它们让“ST改变”有可见形态，不表示仅凭一幅形态就能给病因下结论。运动负荷的课程阳性是水平/下斜压低≥0.1 mV且持续2 min等；不把上斜图或鱼钩图自动代入这个标准。

[内科物理P415 / 印刷P343：四期表与A–E五幅波形](p415-four-stages-ABCDE-original-crop.png)

先看四期表：数小时内高耸T；数小时至2天ST抬高、可出现病理Q；数天至2周ST回基线、T平坦或倒置；数周至数月可有倒置T等残留。再沿下面五幅图看形态：B旁文是高耸T和/或ST抬高但无Q；C看病理Q、ST抬高与T倒置；D看ST回等电位线而Q/QS可仍在，T变化；E看T可恢复或仍倒置。A没有独立文字命名，不替它新增一期。四个时段与五幅示意不强行一一配对，每例也不必有完全相同的形态和时程。

## 导联从哪一面看心肌

[内科物理P415 / 印刷P343：胸导联位置与心壁空间](p415-lead-space-original-crop.png)

先从胸骨两侧的V1/V2、V2与V4之间的V3，走到左锁骨中线V4，再沿同水平的V5/V6，V7在左腋后线。图把前间壁、局限前壁/心尖、前侧壁、下壁画成不同空间面。这里只恢复已有空间关系，不把导联编号变成疾病的时间顺序。

[内科物理P416 / 印刷P344：肢体导联方向和空间汇总](p416-lead-space-and-polarity-original-crop.png)

Ⅰ/aVL朝高侧，Ⅱ/Ⅲ/aVF朝下；胸导联和肢体导联合起来看侧壁/前壁空间。三角形上的+、−是电极极性，和下一页表中“±=可能正面改变”不是同一种标记。

[同页广泛前壁括线](p416-extensive-anterior-bracket-original-crop.png)

课程红括线只合并V1–V3前间壁与V3–V5局限前壁/心尖，即V1–V5。它没有把右侧V5–V7整组一起圈入，不能为了熟悉的另一套口诀改括线。

[内科物理P417 / 印刷P345：冠脉供区](p417-coronary-territories-original-crop.png)

原页确实把LAD与左室前壁/心尖、前间壁、侧壁及前乳头肌相连，LCX与侧壁/左房相连，RCA与右房/右室及右优势型的下壁、后壁、结区相连。保留本课典型映射及优势型/个体差异，不据一组导联断言唯一责任血管或前乳头肌绝无其他供血。

[同页表3-4-4与脚注](p417-localization-table-and-footnotes-original-crop.png)

广泛前壁列V1–V5是+，Ⅰ/aVL为±，V6/V7空白。脚注“+”表示正面改变（典型ST抬高、Q及T变化），“−”表示反面改变，“±”表示可能有正面改变；空白不是−。前侧壁与高侧壁仍分列，不能合成一项。右室和正后壁等脚注可以原图回看，不因此自动多建一套文字卡。

回到主模型：以上都是症状、损伤、电活动或空间的观察窗，不把标志物曲线或ECG当作制造坏死的原因。机械并发症依旧先追血流去向；不能只凭ST或单个标志物跳过危险鉴别。
