- KP19：[AV与SA阻滞比较及SA条带](p462-sa-avb.png)，[SAⅠ/Ⅱ与左右束支阻滞](p463-sa-bbb.png)。SA脱落的是整组P-QRS；SP不能在常规体表直接测见。BBB先看导联和形态，再接时限。P463原页第②行也误印“右束支阻滞：V5、V6”，但下图明标完全性左束支阻滞；按正文的左右导联对应与图名读取，保留原字，不把误植转成新的左/右规则。

- KP21：[室扑与室颤波形](p465-ventricular-flutter-fibrillation.png)。这组图没有独立的R定位放电时序图。课程简写“R存在→同步”不能覆盖无脉VT或持续多形VT；按正文脉搏、稳定性、形态分流，骤停流程回B12。

### ICD / CRT 原脚注查阅

[物理P467、印刷P388脚注30](p467-device-source-note.png)确有如下课程接口，并非来源全无条件：

- ICD：抗心动过缓起搏、抗心动过速起搏、低能电转复、高能电除颤四功能。原文列MI 48小时后非可逆性室颤或血流动力学不稳定室速；MI经血运重建或药物治疗后，LVEF≤35%且NYHAⅡ–Ⅲ，或LVEF≤30%且NYHAⅠ；另列有猝死危险因素的肥厚型心肌病、致心律失常性右室心肌病、长QT和Brugada等接口。
- CRT：药物治疗后仍有心衰表现、窦性心律、完全LBBB、QRS>130ms、LVEF≤35%、NYHAⅡ–Ⅳ；或有心室起搏指征/高度AVB且LVEF<40%等课程支路。旁注另写心律失常章>120ms，这与正文用于BBB识别的≥120ms不能混用。

这些是原脚注的查阅落点，完整恢复与适用条件接B11 KP21、病种危险因素接B8；它们未列全等待期、预期生存及疾病特异条件，不是完整现实植入标准，也不新增一套B10主动精记。
