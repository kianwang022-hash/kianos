# B12 休克与心脏骤停原图

这些图回到原节点解释容量、泵、分布、通路与灌注反馈。原图保留课程旧写法；读图时同读正文的适用条件，不把简表当独立诊疗方案，也不由图像阅读推定操作已经掌握。

外科来源为《27外科精编版【带导图】.pdf》。这里的P指物理PDF页，印刷页另列；与旧跟课合集的顺序页分开。

## 四种故障入口与恶性反馈

[物理P276／印刷P223：图5-1与图5-2](p276-failure-feedback.png)

原课概述并列氧供不足和氧需求增加，应放在氧供与需求失配中理解，不把绝对血容量减少或需求必然增加当成每种休克都须满足的条件。

图5-1把微生物产物、创伤损伤、失血、心衰与神经源性等不同入口接到组织灌注减少。LPS等经模式识别受体（如Toll样）与细胞/炎症介质激活是感染支路的解释；创伤可以同时造成损伤炎症和出血。神经源性张力丧失、过敏性通透性增加可放回既有分布支路，不能把原图所有例子排成疾病发生顺序。

图5-2把低CO与低灌注接成反馈：回心减少、细胞缺氧后的酸中毒/液体分布异常、冠脉灌注下降可进一步损害输出；实质细胞损伤及内皮/微循环损伤、炎症聚集也是并行放大支路。图中“感染性最严重”仅为原课旁注，不构成四类休克的绝对严重度排名。

原图的人工胶体/羟乙基淀粉及“先晶后胶”不能覆盖正文已经保留的休克类型、制剂和活动性大出血边界。

## 微循环的入口 出口与三条通路

[物理P276／印刷P223：微循环与DIC旁注](p276-microcirculation-dic.png)

微动脉为总入口，毛细血管前括约肌控制真毛细血管迂回通路，通血毛细血管构成直捷通路，动静脉吻合支可绕开交换床；微静脉在出口侧。正常结构归B1，这里只把同一结构用于“只出不进”和“只进不出”的病理解释。

后期淤积、外渗、浓缩和微血栓会使有效回心与灌注更差。3P旁注解释FDP与纤维蛋白单体、鱼精蛋白的关系；B4 KP14已有凝血/单体背景和不能把所有FDP升高判阳性的接口，KP04承接它。标准化试验全流程仍未在本课展开。原“早期肝素”仍要服从正文的病因、血栓主导与出血风险条件。

## 分度与动脉压证据

[物理P277／印刷P224：分度与血压因素表](p277-shock-bp-tables.png)

先区分约4 L的休克分度示例与约5 L的输血表。分度表的“100–200／>200次/分”确实写在原图，仍待勘误，不能拿>200作为严重休克必备条件。

下表把充盈、SV、HR、阻力和弹性分别对应SBP、DBP、脉压。正常规律回B1；本块用它解释为什么代偿可暂保血压而脉压变窄，不能用血压单项代替组织灌注。

## 楔压的空间位置

[物理P277／印刷P224：右心至肺动脉导管示意](p277-pawp-location.png)

看导管从右侧进入，经右心到肺动脉远端的空间路线；PAWP/PCWP用于左侧上游/充盈接口，不能与右房/胸内大静脉的CVP混同。小图保留“mean 6–12 mmHg”和曲线示意，仅作该来源图注；它不提供完整置管步骤、校零条件或全部波形判读。

## CVP与BP共同读取

[物理P278／印刷P225：四格与补液试验](p278-cvp-bp.png)

CVP低时BP可能仍被代偿维持；本页失血场景的时序说明不使CVP变成通用血容量计。四格先看容量与泵/通路，再用病因、肺部、超声和输出校准；最后一行是CVP正常而BP低的试验入口，不是无条件补液。原图没有完整试验量和时程。

## 冷暖休克的同坐标比较

[物理P278／印刷P225：表5-3完整七行](p278-cold-warm-table.png)

沿神志、皮色、温湿、再充盈、脉搏、脉压、尿量逐行看两种典型表型。暖列1–2秒、脉压>30 mmHg、尿量>30 mL/h仍是课程比较，不是每例都要满足的诊断规则；“慢”不能推为必须心动过缓。冷暖受容量、心功能和病程影响，不按G+／G−互斥；温暖皮肤或清醒不独自排除低灌注。

## CAB原图与VF条带

内科来源为《27内科精编版合集【带导图】.pdf》，物理P476／印刷P394。

[按压、仰头抬颏、口对口人工呼吸原图](p476-cab-original.png)；[原VF条带](p476-vf-strip.png)。

按压图A显示肩部正对患者胸骨上方、肘部保持不动；B先定按压部位再摆手。仰头抬颏图分为头后仰、提起下颌两步，口对口图示捏鼻和口部密封。它们用于识别空间关系，不能从静态图测出动作频率，也不能绕过KP17保留的创伤气道和通气条件。固定距剑突和乳头连线仍是来源旧定位，正文用胸部中央胸骨下半部。

VF条带的振幅、间距和方向紊乱，没有稳定重复的正常P-QRS-T组合；这里只辨认该图标示的VF，不从缩放嵌图计算幅值或频率，不把文字提及的pVT当成本页另一张实测波形。

[P476右栏电除颤说明原文](p476-arrest-source-notes.png)原文写“心脏停搏和无脉电活动时电除颤均无用”；按同页与VF/pVT并列的语境，这里分别指心静止与PEA，不是说所有心脏骤停都不可电击。所以“不可电击”确有本课来源；该段没有展开两者全部复苏流程。原叙述以早期电击重要性为主，按压/通气不能替代可电击节律的除颤；其每延误1分钟成功率下降7%–10%的教学数字不作为所有场景统一预测公式。

## 室颤原流程的查阅边界

[内科物理P477／印刷P395：图3-11-3完整原流程](p477-vf-source-flow.png)

这是课程原室颤流程的查阅答案，保留原字和剂量，不能独立当成完整现代ACLS处方。既有精记只要求原准入的能量、CAB条件和肾上腺素途径，不因这张图自动增加剂量卡。

原流程全部分支依次为：
1. 持续心肺复苏直到连接除颤器。
2. 持续性室颤/无脉性室速需要除颤，原图列单相360 J、双相120–200 J；双相实际使用仍读KP18的厂家推荐/未知推荐条件。
3. 除颤失败，继续CPR 2分钟，监测是否需再次除颤，并建立静脉通路。
4. 再次除颤失败，原图列肾上腺素1 mg静脉推注，每3–5分钟重复，考虑气管插管；CPR 2分钟，再监测是否需除颤。
5. 继续失败时三条并行支路：治疗可逆原因；静脉抗心律失常药；持续CPR、监测复苏质量，并循环药物和除颤步骤。图中只写“可逆原因”，没有完整原因清单。
6. 原药物框：胺碘酮300 mg静推，必要时再150 mg；利多卡因1.0–1.5 mg/kg静推，5–10分钟后0.75 mg/kg，最大3 mg/kg；硫酸镁仅在尖端扭转型室速相关时列1–2 g、5% GS 10 mL稀释后静推，否则不推荐。

上述第6项是来源旧流程的完整转录，不据此替代不同节律、ROSC、有脉状态或具体给药安全条件；例如不能把所有持续心律失常都放进无脉室颤药物框。完整现代算法、药物配制与给药监测、可逆原因清单和非可电击分支仍需其专门来源与训练。
