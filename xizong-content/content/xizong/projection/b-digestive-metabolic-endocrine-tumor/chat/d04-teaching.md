<h2>跨过上皮才进入身体</h2>
<p>小肠兼有充分消化的小分子、接触时间、丰富血淋巴管和三级面积放大；上部承担多数吸收，回肠特别负责B12、胆盐并有储备作用。高位瘘和短肠可减少有效吸收，但不能据低位瘘就断言无需营养支持。 <span class="binding" data-kp="digestive-d4-kp01" data-candidate-conflict="false">为什么小肠是主要吸收部位：结构、时间和消化程度同时占优〔4优势｜三级放大｜主要部位｜回肠2特殊｜大肠水盐｜高位瘘/短肠〕</span></p>
<p>吸收需追到顶端进入、细胞内处理和基底侧输出，也存在细胞旁路径。水溶性小分子多经毛细血管入门静脉，长链脂质重装后入淋巴，不能把两路当先后必经。 <span class="binding" data-kp="digestive-d4-kp02" data-candidate-conflict="false">吸收路径：顶端进入只是半程，最终必须离开基底侧进入血或淋巴〔跨细胞4步｜细胞旁｜血管2字/淋巴3字｜门静脉首过｜长链特殊〕</span></p>

<h3>为什么小肠是主要吸收部位：结构、时间和消化程度同时占优</h3>
<h3>1｜四个基础优势</h3>
<ol>
<li>大多数食物已被胰酶等分解为可吸收小分子；</li>
<li>食物在小肠停留较长，约 3–8 h；</li>
<li>绒毛内毛细血管和毛细淋巴管丰富；</li>
<li>环状皱襞—绒毛—微绒毛形成三级放大，吸收面积巨大。</li>
</ol>
<p>Study 补充：正常小肠约 4–5 m，三级结构可把面积放大约 600 倍。</p>
<h3>2｜部位分工</h3>
<ul>
<li>口腔、食管：一般不承担明显营养吸收；</li>
<li>胃：吸收少量水和乙醇等；</li>
<li>十二指肠、空肠上段：糖、蛋白、脂肪等绝大多数吸收；</li>
<li>回肠：<strong>Vit B12 与胆盐</strong>的特殊吸收；同时是吸收储备段；</li>
<li>大肠：主要吸收水和盐类，讲义口径可吸收内容物中约 80% 水、90% Na⁺ / Cl⁻。</li>
</ul>
<h3>3｜临床接口</h3>
<pre><code class="language-text">高位小肠瘘
→ 主要吸收区被绕过 / 丢失
→ 营养吸收显著受损
→ 可需肠外营养

短肠综合征
→ 有效面积和接触时间下降
→ 广泛吸收不良
</code></pre>
<p>（边界：低位小肠瘘对吸收的影响相对较小，但不能机械理解为所有低位瘘均无需营养支持；当前只保留 Study 的考试方向。）</p>

<h3>吸收路径：顶端进入只是半程，最终必须离开基底侧进入血或淋巴</h3>
<h3>1｜跨细胞路径</h3>
<pre><code class="language-text">肠腔
→ 顶端膜 / 刷状缘进入上皮细胞
→ 细胞内加工或暂存
→ 基底侧膜输出
→ 毛细血管或毛细淋巴管
</code></pre>
<p>考试常把“从肠腔进入上皮细胞”称作吸收，但完整生理过程应追踪到血液或淋巴。</p>
<h3>2｜细胞旁路径</h3>
<p>部分水、离子等可经相邻上皮细胞间的紧密连接区域进入细胞间隙，再到循环。</p>
<h3>3｜血液 vs 淋巴</h3>
<ul>
<li><strong>中、短链脂肪酸</strong>：水溶性较好，可经毛细血管直接进入门静脉。</li>
<li><strong>长链脂肪酸及多数脂类消化产物</strong>：在上皮内重装成乳糜微粒，进入毛细淋巴管。</li>
<li>脂溶性维生素 A、D、E、K 随脂类以淋巴途径为主。</li>
</ul>
<h3>4｜为什么门静脉与淋巴不同</h3>
<pre><code class="language-text">门静脉路径
→ 先到肝脏
→ 进入首过加工、储存和代谢

淋巴路径
→ 经胸导管进入体循环
→ 长链脂质先绕开门静脉首过
</code></pre>
<p>这正是后续“吸收 → 物质代谢 M1–M10”的入口。</p>

<h2>腔内递送与上皮输出不能混为一颗粒</h2>
<p>混合微胶粒在腔内把脂质送到顶端；长链材料入胞后在内质网重合成TAG，与apoB48等组装乳糜微粒，经高尔基体、基底侧出胞进入淋巴和胸导管。中短链可直接入血/门静脉，胆盐则另循回肠—门静脉回收。 <span class="binding" data-kp="digestive-d4-kp04" data-candidate-conflict="false">脂类吸收：微胶粒只负责送到岸边，乳糜微粒才负责离开上皮〔腔内3角色Recall｜静水层｜顶端释放｜长链4步｜载脂蛋白｜中短链去向｜胆盐去向〕</span></p>
<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>脂类吸收：微胶粒只负责送到岸边，乳糜微粒才负责离开上皮</h3>
<h3>1｜到达顶端膜前｜Recall D3</h3>
<ul>
<li>胰脂肪酶水解脂肪；</li>
<li>辅脂酶将胰脂肪酶锚定在脂滴表面；</li>
<li>胆盐与脂肪消化产物形成混合微胶粒；</li>
<li>微胶粒穿过静水层，把脂质递送至上皮顶端膜。</li>
</ul>
<p>（易混：混合微胶粒是<strong>吸收前的腔内运输结构</strong>，不是入淋巴的颗粒。）</p>
<h3>2｜长链脂质进入上皮后</h3>
<pre><code class="language-text">长链脂肪酸 + 一酰甘油进入上皮
→ 在内质网重新合成三酰甘油TAG
→ 与胆固醇酯、磷脂、脂溶性维生素及apoB48组装
→ 形成乳糜微粒CM
→ 高尔基体包装
→ 基底侧出胞
→ 毛细淋巴管
→ 胸导管
→ 体循环
</code></pre>
<h3>3｜中、短链脂肪酸</h3>
<p>水溶性较好，在上皮内不必重装成乳糜微粒，可直接从基底侧进入毛细血管和门静脉。</p>
<h3>4｜胆盐的去向</h3>
<p>胆盐通常不随脂质进入上皮，而留在肠腔继续参与运输，最后主要在回肠重吸收并进入肠肝循环。</p>
<h3>5｜为什么总体脂肪以淋巴途径为主</h3>
<p>膳食脂肪中长链脂肪酸占多数，因此总体脂类吸收以乳糜微粒—淋巴途径为主。</p>

<h2>同到血侧，入口的驱动力仍不同</h2>
<p>葡萄糖/半乳糖顶端借Na⁺梯度继发主动进入，基底侧载体输出，能量间接来自Na⁺—K⁺泵；果糖走载体易化，仍有特异、饱和和竞争。 <span class="binding" data-kp="digestive-d4-kp05" data-candidate-conflict="false">单糖吸收：葡萄糖 / 半乳糖借 Na⁺梯度，果糖走易化扩散〔葡/半顶端｜果糖顶端｜基底侧共同｜Na/K泵供能｜速度顺序〕</span></p>
<p>多数氨基酸借Na⁺，二/三肽借H⁺入胞后水解为氨基酸，再输出入血；小肽吸收可更快，终点相同不能推出入口相同。 <span class="binding" data-kp="digestive-d4-kp06" data-candidate-conflict="false">氨基酸与小肽：小肽借 H⁺进入，吸收反而更快〔AA vs 小肽：顶端驱动力｜入胞后处理｜谁更快｜AA速度3类〕</span></p>
<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>单糖吸收：葡萄糖 / 半乳糖借 Na⁺梯度，果糖走易化扩散</h3>
<h3>1｜葡萄糖与半乳糖</h3>
<pre><code class="language-text">顶端膜：与Na⁺同向转运
→ 利用Na⁺电化学梯度
→ 继发性主动转运进入上皮

基底侧：载体易化扩散
→ 进入毛细血管
</code></pre>
<p>Na⁺梯度最终由基底侧 Na⁺—K⁺泵维持，因此能量间接来自 ATP。</p>
<h3>2｜果糖</h3>
<p>顶端膜和基底侧主要依赖载体易化扩散，不与 Na⁺同向转运。</p>
<h3>3｜速度比较</h3>
<pre><code class="language-text">己糖 &gt; 戊糖
半乳糖、葡萄糖 &gt; 果糖 &gt; 甘露糖 &gt; 戊糖（如核糖）
</code></pre>
<p>（易混：载体易化扩散不等于简单扩散；它仍具有特异性、可饱和和竞争等载体特征。）</p>

<p><a href="../../../knowledge/systems/b-digestive-metabolic-endocrine-tumor/d-d1-d23/D4_小肠吸收与营养运输_门静脉淋巴与关键营养素_学习阅读版_v1_最终执行版.md">当前完整知识与出处</a></p>
<h3>氨基酸与小肽：小肽借 H⁺进入，吸收反而更快</h3>
<h3>1｜氨基酸</h3>
<p>多数氨基酸在顶端膜通过与 Na⁺相关的继发性主动转运进入上皮；基底侧再经载体进入血液。</p>
<p>吸收速度：</p>
<pre><code class="language-text">中性氨基酸 &gt; 碱性氨基酸 &gt; 酸性氨基酸
</code></pre>
<h3>2｜二肽、三肽等寡肽</h3>
<pre><code class="language-text">顶端膜：H⁺同向转运
→ 继发性主动转运进入上皮
→ 细胞内被肽酶进一步水解为氨基酸
→ 基底侧输出入血
</code></pre>
<p>当前 Study 强调：寡肽吸收速度可快于游离氨基酸。</p>
<p>（易混：氨基酸与寡肽不是共用同一套顶端转运；前者主要挂 Na⁺梯度，后者挂 H⁺梯度。）</p>

<h2>特殊营养素有各自的门槛</h2>
<p>B12先由胃酸/胃蛋白酶从食物蛋白释放，交R蛋白护送；胰蛋白酶处理R后换给内因子，最终由回肠受体接收。胃酸缺乏、内因子缺乏、换手失败或回肠受损均可截断接力，胃酸减少并不等于达到缺乏。 <span class="binding" data-kp="digestive-d4-kp03" data-candidate-conflict="true">Vit B12：胃酸放人、R蛋白护送、胰蛋白酶换手、内因子带回肠〔食物结合态｜胃2步｜肠2步｜回肠受体｜缺陷3类｜巨幼贫〕</span></p>
<p>铁吸收受需求、溶解还原和黏膜暂存影响；慢性失血与吸收障碍须先分主次。FPN1跨膜价态和血中运输价态在两版中的表达冲突仍待审，不能用一句口诀替代该步决定。 <span class="binding" data-kp="digestive-d4-kp07" data-candidate-conflict="true">铁吸收：先把 Fe³⁺变成可进入的 Fe²⁺，再决定输出还是随黏膜脱落〔部位｜促3｜抑3｜价态4步｜2转运体｜铁蛋白门控｜主病因边界〕</span></p>
<p>钙吸收以需求量、Vit D和可溶性为主轴。肠腔钙皂促吸收的条件及其与胰腺炎钙皂的对照仍待原医学/Source owner判定，暂不把任一方向纳入精确答案。 <span class="binding" data-kp="digestive-d4-kp08" data-candidate-conflict="true">钙吸收：需求量与 Vit D 是主轴，能否保持可溶决定能否进入〔吸收率｜主因素2｜促进5｜抑制3｜酸度｜肠腔钙皂 vs 血中钙皂｜大多粪排〕</span></p>
<p class="hold" data-hold="D4-03">绑定/计数冲突：恢复Current“缺陷3类”而正文四个故障入口均保留；候选按环节去计数未采纳，不缩减完整接力。</p>

<p class="hold" data-hold="D4-07">Fe/FPN1 HOLD：Current“运输Fe³⁺→经FPN1输出”与候选“Fe²⁺跨膜后氧化为Fe³⁺血运”有实质差异；价态链及口诀依赖冻结，需求、溶解和黏膜暂存独立内容继续。</p>

<p class="hold" data-hold="D4-08">钙皂HOLD：Current肠腔钙皂促吸收及胰腺炎对照，与候选可溶性限制/外部研究校准未统一；形成位置、条件、净方向和Block Exit该项共同冻结，钙需求/VitD/可溶性主轴继续。</p>

<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>Vit B12：胃酸放人、R蛋白护送、胰蛋白酶换手、内因子带回肠</h3>
<h3>1｜胃内第一段接力</h3>
<p>食物中的 B12 多与蛋白质结合。</p>
<pre><code class="language-text">胃酸 + 胃蛋白酶
→ B12从食物蛋白中释放
→ 游离B12迅速与R蛋白结合
</code></pre>
<p>R 蛋白来自唾液和胃液，在胃内对 B12 的亲和力高于内因子，因此胃中主要形成 B12—R 蛋白复合物。</p>
<h3>2｜小肠换手</h3>
<pre><code class="language-text">B12—R蛋白复合物进入小肠
→ 胰蛋白酶降解R蛋白
→ B12再次游离
→ 与壁细胞分泌的内因子结合
</code></pre>
<p>内因子—B12 复合物可抵抗肠腔酶的破坏。</p>
<h3>3｜回肠吸收</h3>
<pre><code class="language-text">内因子—B12复合物到达回肠末端
→ 顶端膜受体识别
→ 受体介导入胞
→ B12进入上皮并转运
</code></pre>
<p>受体介导入胞的其他代表包括 LDL、运铁蛋白等。</p>
<h3>4｜三个故障入口</h3>
<ul>
<li>胃酸<strong>缺乏</strong>：B12 难从食物蛋白释放；</li>
<li>内因子缺乏：不能形成有效复合物；</li>
<li>胰蛋白酶缺乏：不能从 R 蛋白完成换手；</li>
<li>回肠病变 / 切除：最终受体吸收失败。</li>
</ul>
<p>结果可进入巨幼细胞性贫血模型。</p>
<p>（易混：胃酸“减少”不一定达到影响 B12 的缺乏程度；A 型胃炎常为明显缺乏，B 型胃炎可正常或减少。）</p>

<h3>铁吸收：先把 Fe³⁺变成可进入的 Fe²⁺，再决定输出还是随黏膜脱落</h3>
<h3>1｜部位与需求调节</h3>
<p>铁主要在小肠上部吸收。机体缺铁时，对相同摄入量的吸收比例可提高，体现需求量调节。</p>

<li>Vit C：将食物中较多的 Fe³⁺还原为更易吸收的 Fe²⁺。</li>
</ul>

<h3>5｜黏膜门控</h3>
<p>未输出入血的铁可在黏膜细胞内氧化为 Fe³⁺并结合铁蛋白暂存；若始终未被利用，可随上皮更新脱落排出，形成“黏膜阻滞”式调节。</p>
<h3>6｜贫血边界</h3>
<p>胃大部切除或 A 型胃炎造成 HCl 缺乏，可不利于铁吸收；但 Study 同时强调：</p>
<ul>
<li>体内铁大量来自衰老红细胞回收；</li>
<li>缺铁性贫血更常见、更重要的原因是慢性失血，而非单纯胃酸减少。</li>
</ul>
<p>完整贫血模型归血液系统。</p>

<h3>钙吸收：需求量与 Vit D 是主轴，能否保持可溶决定能否进入</h3>
<h3>1｜基本特点</h3>
<ul>
<li>食物钙只有约 **20%–30%**被吸收；</li>
<li>大部分随粪便排出；</li>
<li>必须以可溶的 Ca²⁺状态存在才能被吸收。</li>
</ul>
<h3>2｜两个主决定因素</h3>
<ol>
<li>机体对钙的需求量；</li>
<li><strong>Vit D</strong>，为最重要促进因素。</li>
</ol>
<h3>3｜促进因素｜Study 口径</h3>
<ul>
<li>HCl / 酸性环境：促进钙盐溶解；</li>
<li>Vit D；</li>
<li>乳酸；</li>
<li>葡萄糖；</li>
<li>脂肪酸、氨基酸等。</li>
</ul>
<p>肠腔 pH 较低、钙保持离子化时更利于吸收。</p>
<h3>4｜抑制因素</h3>
<ul>
<li>草酸；</li>
<li>磷酸；</li>
<li>植酸；</li>
</ul>
<p>它们与 Ca²⁺形成难溶复合物 / 沉淀，降低可吸收性。</p>
