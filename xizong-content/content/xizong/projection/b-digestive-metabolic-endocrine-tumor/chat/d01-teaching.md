<h2>节律与力量是两项任务</h2>
<p>消化管需要柔性容纳、持续张力、混合和推进；平滑肌舒缩慢、伸展性强，胃最能增容。机械消化、酶的化学消化和跨黏膜吸收各有任务。 <span class="binding" data-kp="digestive-d1-kp01" data-candidate-conflict="false">消化道平滑肌：为什么适合做“长期运行的柔性管道”〔6特性｜AP 3差异｜紧张2意义｜伸展最大1｜敏感/不敏感〕</span></p>
<p>环、纵肌交界的ICC以Ca²⁺—Cl⁻活动起搏，经缝隙连接扩布慢波；慢波安排节律、传播速度和方向。 <span class="binding" data-kp="digestive-d1-kp02" data-candidate-conflict="false">慢波：胃肠运动的“节拍器”，不是每次收缩本身〔定义｜局部电位6例｜ICC位置｜起搏离子链4步｜频率3处｜决定3项〕</span></p>
<p>慢波过机械阈可有轻收缩，不必已有动作电位；再过电阈，成簇动作电位增加Ca²⁺进入，主要强度取决于每慢波的锋电位数，而非单个锋电位幅度。 <span class="binding" data-kp="digestive-d1-kp03" data-candidate-conflict="false">慢波—机械阈—电阈—动作电位—收缩：两道门槛〔机械阈 vs 电阈｜有无AP｜机械阈段强度2因素｜节律由谁｜0期离子〕</span></p>

<h3>慢波：胃肠运动的“节拍器”，不是每次收缩本身</h3>
<h3>1｜身份</h3>
<p>慢波是在静息电位基础上，自发出现的节律性轻度去极化和复极化，也称<strong>基本电节律</strong>。</p>
<p>它属于<strong>局部电位</strong>，本身通常没有达到动作电位阈值。</p>
<p>当前 Study 列举的局部电位包括：</p>
<ul>
<li>慢波；</li>
<li>终板电位；</li>
<li>EPSP；</li>
<li>IPSP；</li>
<li>感受器电位；</li>
<li>发生器电位。</li>
</ul>
<h3>2｜起源与机制</h3>
<pre><code class="language-text">环形肌—纵行肌交界处的Cajal间质细胞 ICC
→ ICC内Ca²⁺↑
→ Ca²⁺激活Cl⁻通道
→ Cl⁻外流，负电荷外移
→ ICC膜去极化
→ 经缝隙连接向平滑肌扩布
→ 平滑肌L型Ca²⁺通道开放
→ 形成节律性膜电位波动
</code></pre>
<p>（易混：慢波<strong>不由平滑肌细胞本身起搏</strong>；ICC 是起搏细胞和两肌层间的电活动桥梁。）</p>
<h3>3｜三个代表频率</h3>
<ul>
<li>胃：约 <strong>3 次 / min</strong>；</li>
<li>十二指肠：约 <strong>12 次 / min</strong>；</li>
<li>回肠末端：约 <strong>8–9 次 / min</strong>。</li>
</ul>
<p>不能机械推成“越往下越快”：十二指肠快于回肠末端。</p>
<h3>4｜慢波真正决定什么</h3>
<p>慢波决定胃肠平滑肌收缩的：</p>
<ul>
<li><strong>频率 / 节律</strong>；</li>
<li><strong>传播速度</strong>；</li>
<li><strong>传播方向</strong>。</li>
</ul>
<p>它不直接决定主要收缩强度；强度主要看后续动作电位的数量。</p>

<h3>慢波—机械阈—电阈—动作电位—收缩：两道门槛</h3>
<h3>1｜第一道门：机械阈</h3>
<pre><code class="language-text">慢波去极化超过机械阈
→ L型Ca²⁺通道有一定开放
→ 少量Ca²⁺内流
→ 可出现轻度平滑肌收缩
</code></pre>
<p>此时不一定产生动作电位。</p>
<p>收缩幅度与：</p>
<ul>
<li>慢波幅度；</li>
<li>慢波在机械阈以上停留的时间；</li>
</ul>
<p>呈正相关。</p>
<h3>2｜第二道门：电阈 / 阈电位</h3>
<pre><code class="language-text">慢波进一步达到电阈
→ 在慢波顶端出现成簇动作电位
→ Ca²⁺内流显著增加
→ 收缩明显增强
</code></pre>
<p>每个慢波上出现的动作电位越多，收缩越强；这是收缩强度的主要决定因素。</p>
<p><a href="../../../../../assets/physiology-p208-threshold-AP-tension-original-crop.png">P208 原两阈—动作电位—张力图</a>：对照机械阈低于电阈、轻收缩与簇发 AP 后增强；图中没有固定张力数值，不从曲线补出新阈值。</p>

<th>主要回答</th>
</tr>
</thead>

<td>慢波</td>

<td>动作电位频率 / 每慢波锋电位数</td>

</tr>

<h3>4｜离子基础</h3>
<ul>
<li>消化道平滑肌动作电位 0 期：以 <strong>L 型 Ca²⁺电流</strong>为主。</li>
<li>神经、骨骼肌和心肌快反应细胞 0 期：以快 Na⁺电流为主。</li>
</ul>

<h2>局部控制与全身调节同时工作</h2>
<p>肌间神经丛调运动，黏膜下神经丛调分泌和转运；切断外在神经后ENS仍能局部工作。缺神经节段形成通行障碍、近端扩张，只在这里验证机制。 <span class="binding" data-kp="digestive-d1-kp04" data-candidate-conflict="false">ENS：消化道自带的“本地控制器”〔2神经丛｜各管谁｜递质3｜外神经切断后？｜巨结肠链〕</span></p>
<p>自主神经改变慢波幅度和跨阈概率，不承担ICC起搏。交感使管壁舒张、括约肌收缩、腺体分泌减少；副交感通常相反，使上游收缩与下游开门配合。唾液是交感、副交感都能促泌的例外。 <span class="binding" data-kp="digestive-d1-kp05" data-candidate-conflict="false">外在自主神经：先分“管壁、括约肌、腺体”，再判断方向〔交感4效应｜副交感4效应｜递质｜慢波是否依赖｜特殊：唾液〕</span></p>

<h3>3｜局部独立性</h3>
<p>外在自主神经主要是对 ENS <strong>调节和改档</strong>。去除外在神经后，ENS 仍可独立调节：</p>
<ul>
<li>胃肠运动；</li>
<li>分泌；</li>
<li>局部血流；</li>
<li>水和电解质转运。</li>

<p>因此：</p>
<pre><code class="language-text">外在神经切断
≠ 胃肠道完全失去运动与分泌
</code></pre>

<h3>外在自主神经：先分“管壁、括约肌、腺体”，再判断方向</h3>
<h3>1｜交感神经</h3>
<pre><code class="language-text">交感节后纤维释放 NA
├─ 慢波幅度↓
├─ 管壁平滑肌 β₂：舒张
├─ 括约肌 α₁：收缩
└─ 腺体分泌↓
</code></pre>
<p>整体结果：抑制胃肠推进和消化。</p>
<p>（特殊：唾液分泌不是这个总规律，交感和副交感都可促进唾液；D2 完整学习。）</p>
<h3>2｜副交感神经</h3>
<pre><code class="language-text">迷走 / 盆神经调节ENS（多数节后纤维释放ACh）
├─ 慢波幅度↑
├─ 管壁平滑肌M受体：收缩
├─ 括约肌经抑制性肽能通路：舒张
└─ 腺体分泌↑
</code></pre>
<p>副交感还可调用 VIP、NO、GRP 等非胆碱能递质。</p>
<h3>3｜为什么管壁与括约肌方向相反</h3>
<p>消化内容物要向前推进，必须同时发生：</p>
<pre><code class="language-text">上游管壁收缩
+
下游括约肌舒张
</code></pre>
<p>若把“副交感促进消化”机械理解为“所有平滑肌都收缩”，就会把门关死。</p>
<h3>4｜慢波边界</h3>
<p>自主神经可改变慢波<strong>幅度</strong>和跨阈概率，但慢波的产生依赖 ICC，<strong>不依赖自主神经作为起搏源</strong>。</p>

<h2>共同执行端把信号变成张力</h2>
<p>电活动经L型Ca²⁺通道、化学信号经Gq—PLC—IP₃，都可提高胞质Ca²⁺；Ca²⁺结合CaM，激活MLCK，使MLC磷酸化、横桥工作。Ca²⁺下降、MLCK失活和MLCP去磷酸化使肌肉舒张。平滑肌无T管，不能套用骨骼肌的肌钙蛋白开关。 <span class="binding" data-kp="digestive-d1-kp06" data-candidate-conflict="false">平滑肌收缩：Ca²⁺—CaM—MLCK 把电和化学信号变成张力〔无T管｜Ca来源2｜收缩调控链3步｜电-机械｜药物-机械｜舒张3出口〕</span></p>


<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>平滑肌收缩：Ca²⁺—CaM—MLCK 把电和化学信号变成张力</h3>
<h3>1｜联管结构与三类肌细胞的 Ca²⁺来源边界</h3>
<ul>
<li>骨骼肌：<strong>三联管</strong>；讲义口径近乎全部 Ca²⁺来自肌质网。</li>
<li>心肌：<strong>二联管</strong>；细胞外 Ca²⁺先进入，再触发肌质网 CICR。</li>
<li>平滑肌：<strong>无 T 管、无联管结构</strong>，肌质网相对不发达；胞质 Ca²⁺以细胞外进入为主，也可由肌质网释放。</li>
</ul>
<h3>2｜收缩主链</h3>
<pre><code class="language-text">胞质Ca²⁺↑
→ Ca²⁺结合钙调蛋白CaM
→ 激活肌球蛋白轻链激酶MLCK
→ 肌球蛋白轻链MLC磷酸化
→ 横桥ATP酶活性↑
→ 肌球蛋白与肌动蛋白结合
→ 平滑肌收缩
</code></pre>
<p>（易混：平滑肌不依靠肌钙蛋白启动横桥，而依靠 <strong>CaM—MLCK</strong>。）</p>
<h3>3｜电—机械耦联</h3>
<pre><code class="language-text">牵张 / 化学刺激
→ 动作电位
→ L型Ca²⁺通道开放
→ 细胞外Ca²⁺大量进入
→ 少量CICR
→ 收缩
</code></pre>
<p>因此 Ca²⁺通道阻滞剂可使平滑肌舒张。</p>
<h3>4｜药物—机械耦联</h3>
<p>不必先产生动作电位：</p>
<pre><code class="language-text">配体
→ GPCR—Gq
→ PLC
→ IP₃
→ 肌质网IP₃受体开放
→ Ca²⁺释放
→ 收缩
</code></pre>
<p>原 Source P209 另以 α₁受体阻断剂哌唑嗪说明：阻断 NA 相关的血管平滑肌收缩。这是生理靶点配对的查阅例子，不是个体用药建议。</p>
<h3>5｜舒张</h3>
<pre><code class="language-text">胞质Ca²⁺下降
+ MLCK失活
+ MLCP使MLC去磷酸化
→ 横桥ATP酶活性下降
→ 平滑肌舒张
</code></pre>
<p>Ca²⁺下降依赖肌质网 Ca²⁺泵、细胞膜 Ca²⁺泵和 Na⁺—Ca²⁺交换等；过程较慢，与平滑肌舒张缓慢相呼应。</p>
