<h2>从润滑到放行再关门</h2>
<p>入口先用唾液湿润、润滑、初步消化淀粉并清洁防御；胃酸会使唾液淀粉酶失活，不能靠它完成全程糖消化。 <span class="binding" data-kp="digestive-d2-kp01" data-candidate-conflict="false">唾液：低渗、近中性、先润滑再初步消化〔性质3｜成分5｜功能4｜淀粉酶pH｜排泄特殊〕</span></p>
<p>唾液主要受神经调节：副交感量多而稀，交感量少、固体多，两者均促分泌，血流和分泌物成分需一起看。 <span class="binding" data-kp="digestive-d2-kp02" data-candidate-conflict="false">唾液调节：交感、副交感都促分泌，但“量与质”相反〔调节类型｜副交感2递质+量/质｜交感2递质+量/质｜条件/非条件｜特殊1〕</span></p>
<p>食管下段LES是生理高压区；食团经过时VIP/NO松门，入胃后ACh恢复张力，重新建立抗反流屏障。 <span class="binding" data-kp="digestive-d2-kp03" data-candidate-conflict="false">LES：一扇没有明显解剖门的生理高压区〔性质｜压力差｜功能1｜食团到/入胃两阶段递质｜收缩/舒张因素〕</span></p>
<p>不能松门导致通过受阻，屏障不足导致反流；降低出口阻力也可能削弱抗反流，完整疾病在D9继续。 <span class="binding" data-kp="digestive-d2-kp04" data-candidate-conflict="false">贲门失弛缓：门打不开；GERD：门关不住〔损伤部位｜门效应｜症状｜钡餐｜术式后果｜vs GERD〕</span></p>


<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>唾液：低渗、近中性、先润滑再初步消化</h3>
<h3>1｜性质与成分</h3>
<ul>
<li>无色、无味；</li>
<li><strong>低渗</strong>；</li>
<li>pH 约 <strong>6.6–7.1</strong>，接近中性；</li>
<li>水约占 99%。</li>
</ul>
<p>主要成分：</p>
<ul>
<li>唾液淀粉酶；</li>
<li>黏蛋白；</li>
<li>溶菌酶；</li>
<li>IgA；</li>
<li>Na⁺、K⁺、Ca²⁺、Cl⁻、SCN⁻等。</li>
</ul>
<p>唾液淀粉酶的最适 pH：原 Source P215 的 2013N13A 选项采用 <strong>6–7</strong>；P213 正文写与唾液接近，约 <strong>6.6–7.1</strong>。保留各自题目 / 正文范围，不把两种精度混成同一原句。</p>
<p>原 Source P213：初分泌唾液等渗，经导管处理后终末唾液低渗；导管 Na⁺吸收、K⁺分泌还受醛固酮调节。这些是原查阅层细节。</p>
<h3>2｜四类功能</h3>
<ol>
<li><strong>湿润和溶解食物</strong>：便于吞咽，并帮助味觉形成。</li>
<li><strong>初步消化淀粉</strong>：将部分淀粉水解为麦芽糖等。</li>
<li><strong>清洁和防御</strong>：清除残渣、稀释和中和有害物；溶菌酶与 IgA 参与抗微生物。</li>
<li><strong>排泄接口</strong>：某些重金属、氰化物及狂犬病毒等可随唾液排出。</li>
</ol>
<p>（边界：胃酸很快使唾液淀粉酶失活，因此它不是全程糖消化的主力。）</p>

<h3>唾液调节：交感、副交感都促分泌，但“量与质”相反</h3>
<h3>1｜调节性质</h3>
<p>唾液分泌几乎主要受<strong>神经调节</strong>；胃泌素不影响唾液分泌。</p>
<ul>
<li>望梅止渴：条件反射；</li>
<li>食物入口刺激：非条件反射。</li>
</ul>
<h3>2｜副交感</h3>
<pre><code class="language-text">ACh → 腺细胞M受体 → IP₃ / Ca²⁺ → 分泌↑
VIP → 腺体血管舒张 → 局部血流↑
</code></pre>
<p>结果：<strong>量多、固体少、稀薄唾液</strong>。唾液分泌对副交感依赖更强。</p>
<h3>3｜交感</h3>
<pre><code class="language-text">NA → 腺细胞分泌 + 血管收缩
NPY → 血管收缩
</code></pre>
<p>结果：<strong>量少、固体多、黏稠唾液</strong>。</p>
<p>（易混：交感和副交感对多数器官常呈相反效应，但对唾液腺都可促进分泌；区别在分泌量、固体含量和血流。）</p>
<h3>4｜//串联：干燥综合征</h3>
<p>当前 Lecture 口径：SSA、SSB 等自身抗体相关损伤唾液腺，可出现：</p>
<ul>
<li>口干，严重者进固体食物需饮水送服；</li>
<li>猖獗性龋齿；</li>
<li>食管清除能力下降，GERD 风险增加。</li>
</ul>
<p>完整风湿免疫病模型后置。</p>

<h3>LES：一扇没有明显解剖门的生理高压区</h3>
<h3>1｜身份与功能</h3>
<p>LES 没有明显的环形平滑肌增厚，不是典型解剖括约肌，而是食管下段形成的<strong>生理性高压区</strong>。</p>
<ul>
<li>静息压力通常比胃内高约 <strong>5–10 mmHg</strong>；</li>
<li>核心功能：构成最重要的抗反流屏障。</li>
</ul>
<h3>2｜食团经过时的双相控制</h3>
<pre><code class="language-text">食团进入食管
→ 机械感受器
→ 迷走节前胆碱能传出接入肠壁抑制性神经元
→ VIP + NO
→ LES舒张，允许食团入胃

食团已进入胃
→ 迷走经肠壁兴奋性胆碱能神经元
→ ACh
→ LES收缩，恢复抗反流屏障
</code></pre>
<h3>3｜体液和药物因素</h3>
<p><strong>促 LES 收缩</strong>：</p>
<ul>
<li>胃泌素；</li>
<li>胃动素；</li>
<li>ACh。</li>
</ul>
<p><strong>促 LES 舒张</strong>：</p>
<ul>
<li>促胰液素；</li>
<li>CCK；</li>
<li>VIP；</li>
<li>前列腺素；</li>
<li>抗胆碱药、钙拮抗剂、地西泮等代表性药物接口。</li>
</ul>
<p>记忆原则：当前 Study 中，促进胃动力的一组更倾向使 LES 收缩；抑制胃运动的一组更倾向使 LES 舒张。</p>
<p>（边界：这是本讲义的考试组织法，不扩成所有药物和临床病因清单。）</p>

<h3>贲门失弛缓：门打不开；GERD：门关不住</h3>
<h3>1｜失弛缓的机制链</h3>
<pre><code class="language-text">食管下2/3肌间神经丛受损

</code></pre>

<h2>容纳、磨碎与限流构成同一个动力模型</h2>
<p>吞咽和胃肠刺激通过迷走长反射、壁内短反射及VIP/NO放松胃头区，容量明显增加而压力不明显升高；失败可早饱。 <span class="binding" data-kp="digestive-d2-kp06" data-candidate-conflict="false">容受性舒张：容量显著增加，胃内压却不明显上升〔胃特有｜刺激3处｜长/短反射｜2递质｜结果2｜失败表现〕</span></p>
<p>头区储存，尾区磨碎、混合、推进；紧张性收缩是基础，空腹MMC清扫残渣和细菌，与进食后磨碎分工。 <span class="binding" data-kp="digestive-d2-kp05" data-candidate-conflict="false">胃的功能分区与 4 种运动：头区收、尾区磨、空腹清扫〔头/尾功能｜4运动｜MMC 4期｜2调节因子｜蠕动始/主/方向/作用〕</span></p>
<p>胃—十二指肠压力差推动间断排空，下游酸、脂肪、高渗和扩张经反射及肠抑胃素限流。胃泌素虽促胃运动，却更强地收缩幽门，净效应可延缓排空。 <span class="binding" data-kp="digestive-d2-kp07" data-candidate-conflict="false">胃排空：胃推动，下游十二指肠按处理能力限流〔时间2｜三营养物速度序｜直接/原动力｜胃促2反射｜肠抑4刺激+激素｜胃泌素总效应〕</span></p>


<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>容受性舒张：容量显著增加，胃内压却不明显上升</h3>
<h3>1｜触发来源</h3>
<ul>
<li>食物刺激口、咽、食管感受器；</li>
<li>食物进入胃造成机械刺激；</li>
<li>食糜进入十二指肠造成机械、化学刺激。</li>
</ul>
<h3>2｜反射与递质</h3>
<pre><code class="language-text">迷走—迷走长反射（迷走节前胆碱能传出）
+
壁内神经丛短反射
→ 分别经相应肠壁抑制性神经元释放 VIP + NO
→ 胃底、胃体上部舒张
</code></pre>
<h3>3｜功能结果</h3>
<ul>
<li>胃容量明显增加；</li>
<li>胃内压不明显升高。</li>
</ul>
<p>因此同时：</p>
<ul>
<li>避免食物刚进入即迅速排入十二指肠；</li>
<li>减少胃内压骤升造成反流的倾向。</li>
</ul>
<p>容受性舒张受损可出现<strong>早饱</strong>。</p>
<p>（易混：迷走节前纤维的胆碱能传出，与肠壁节后抑制性神经元的 VIP / NO 不是同一层；局部短反射不必先经过迷走。这里只澄清原长 / 短反射与递质槽，不增加新名单。）</p>
<p>神经层级校准：<a href="https://pmc.ncbi.nlm.nih.gov/articles/PMC6850045/">Goyal 等，2019，胃排空生理</a>，摘要及 §8：迷走节前胆碱能纤维接入肌间丛抑制性神经元。该综述所引局部反射包含动物实验，不据此另加人体定量结论。</p>
<p><a href="../../../../../assets/physiology-p218-receptive-relaxation-neural-levels-original-crop.png">P218 原容受性舒张图</a>：用于定位长反射、胃头区和容量 / 压力结果。原页把传出路写成“迷走肽能”，并笼统断言传出递质绝不可能是 ACh；这不能作为迷走节前递质的结论，须按本节已校准的节前胆碱能→肠壁抑制性 VIP / NO 神经元分层理解。图中胃示意也不是定量压力—容积曲线。</p>

<h3>胃的功能分区与 4 种运动：头区收、尾区磨、空腹清扫</h3>
<h3>1｜头区与尾区</h3>
<ul>
<li><strong>头区</strong>：胃底 + 胃体上 1/3，主要负责储存。</li>
<li><strong>尾区</strong>：胃体下 2/3 + 胃窦，运动较强，负责磨碎、混合并向十二指肠推进。</li>
</ul>
<h3>2｜胃的 4 种运动</h3>
<ol>
<li>紧张性收缩；</li>
<li>消化间期移行性复合运动 MMC；</li>
<li>蠕动；</li>
<li>容受性舒张。</li>
</ol>
<h3>3｜MMC：空腹“清道夫”</h3>
<pre><code class="language-text">Ⅰ期：只有慢波、无收缩；与NO相关
Ⅱ期：不规则锋电位和收缩
Ⅲ期：每个慢波上成簇锋电位，规则高幅收缩；与胃动素相关
Ⅳ期：向下一Ⅰ期过渡
</code></pre>
<p>作用：清扫食物残渣、脱落细胞、细菌、吞入的唾液和黏液。</p>
<p>MMC 减弱可连接：</p>
<ul>
<li>功能性消化不良；</li>
<li>小肠细菌过度繁殖。</li>
</ul>
<h3>4｜胃蠕动</h3>
<ul>
<li>始于胃中部；</li>
<li>以尾区为主；</li>
<li>起搏源位于胃大弯上部；</li>
<li>沿纵行肌向幽门传播；</li>
<li>作用：磨碎、混合并推进食糜。</li>
</ul>
<p>（易混：胃没有把“分节运动”作为其特有主要运动；分节运动是小肠消化吸收的重要形式。）</p>

<h3>胃排空：胃推动，下游十二指肠按处理能力限流</h3>
<h3>1｜基本参数</h3>
<ul>
<li>进食后约 <strong>5 min</strong> 开始排空；</li>
<li>约 <strong>4–6 h</strong> 完全排空；</li>
<li>排空是间断进行，而非无控制连续倾倒。</li>
</ul>
<p>速度：</p>
<pre><code class="language-text">糖类 &gt; 蛋白质 &gt; 脂肪
</code></pre>
<h3>2｜动力</h3>
<ul>
<li><strong>直接动力</strong>：胃与十二指肠之间的压力差。</li>
<li><strong>原动力</strong>：胃平滑肌收缩。</li>
</ul>
<h3>3｜促进：胃内因素</h3>
<p>食物扩张胃：</p>
<ul>
<li>迷走—迷走长反射；</li>
<li>壁内神经丛短反射；</li>
</ul>
<p>促进胃运动和排空。</p>
<h3>4｜抑制：肠内因素</h3>
<p>酸、脂肪、高渗食糜、十二指肠扩张：</p>
<pre><code class="language-text">肠—胃反射
+
促胰液素 / CCK / GIP等肠抑胃素
├─ 胃运动↓、胃排空延缓
└─ 胃酸分泌↓
</code></pre>
<h3>5｜胃泌素的“看似矛盾”</h3>
<p>胃泌素：</p>
<ul>
<li>促进胃运动；</li>
<li>更明显增强幽门括约肌收缩；</li>
</ul>
<p>所以<strong>总效应是延缓胃排空</strong>。</p>
<p>（易混：胃泌素“促进胃运动”不能直接推出“促进胃排空”。必须把幽门这扇门一起算进去。）</p>

<h2>细胞分工与调节网共同决定胃液</h2>
<p>壁细胞提供HCl和内因子，主细胞提供胃蛋白酶原，黏液细胞保护表面；G/ECL/D细胞构成调酸网络。胃酸减少不等于内因子必然缺乏。 <span class="binding" data-kp="digestive-d2-kp09" data-candidate-conflict="false">胃液细胞地图：消化、保护、B12 三条功能线〔壁2｜主1｜黏液2来源｜G/ECL/D三角｜功能3线｜IF疾病链〕</span></p>
<p>壁细胞将H⁺泵向胃腔、HCO₃⁻送向血侧，形成胃内酸环境和餐后碱潮；酸帮助初消化、杀菌、钙铁溶解并触发下游中和。 <span class="binding" data-kp="digestive-d2-kp10" data-candidate-conflict="false">胃酸：既是消化工具，也是必须被约束的攻击因素〔最大分泌决定｜作用5｜泌酸链｜碱潮｜pH｜下游2激素〕</span></p>
<p>ACh、胃泌素、组胺汇向泌酸执行端；酸增加后直接抑G细胞，并经D细胞/SST刹车。CCK的课程净效应抑酸，不能把对某成分的促进扩成整个胃的促进。 <span class="binding" data-kp="digestive-d2-kp11" data-candidate-conflict="false">胃酸调节网：ACh—胃泌素—组胺三路放大，HCl—D细胞—SST负反馈刹车〔促酸3主轴｜迷走4靶点｜胃泌素直/间接｜抑酸6类｜CCK净效应｜HCl负反馈2路〕</span></p>
<p>按刺激位置分别看头期前馈、胃内扩张/蛋白产物和十二指肠输入；肠期仍有少量分泌，不改变肠对胃总体偏抑制的方向。原 Source P219 写“几乎同时开始，互相重叠”，按刺激位置区分三期，不把它们排成互斥时段。 <span class="binding" data-kp="digestive-d2-kp08" data-candidate-conflict="false">消化期胃液分泌：头期—胃期—肠期可重叠，主导方式不同〔三期比例｜消化力方向｜主导调节递变｜头2路｜胃3路｜肠期边界〕</span></p>
<p class="source-boundary">三期时间关系按原 Source P219 的近同时与可重叠范围解释。</p>

<p class="source-boundary">pH 0.9–1.5 只保留 P222 原页适宜酸性环境对象，不能当全胃液正常值或替换胃蛋白酶最适值；原页链接与代表药物配对见展开。</p>

<p class="source-boundary">P224 迷走四靶点均保留：壁、ECL、G、D，不为旧数字压缩成员。</p>

<h3>胃酸：既是消化工具，也是必须被约束的攻击因素</h3>
<h3>1｜最大分泌能力</h3>
<p><strong>壁细胞数量</strong>决定胃酸最大分泌量；质子泵活性影响当下分泌，但不替代“有多少壁细胞”这个容量上限。</p>
<h3>2｜胃酸五类作用</h3>
<ol>
<li>激活胃蛋白酶原，并提供酸性环境；</li>
<li>使蛋白质变性，更易被蛋白酶水解；</li>
<li>杀灭随食物进入的微生物；</li>
<li>入十二指肠后促进促胰液素、CCK 等释放，带动胰液、胆汁和肠液；</li>
<li>增加钙、铁等在肠腔内的溶解，有利于吸收。</li>
</ol>
<h3>3｜壁细胞泌酸机制</h3>
<pre><code class="language-text">CO₂ + H₂O
--碳酸酐酶→ H₂CO₃
→ H⁺ + HCO₃⁻

顶端膜：H⁺—K⁺—ATP酶把H⁺泵入分泌小管
K⁺经通道循环
Cl⁻经基底侧Cl⁻/HCO₃⁻交换进入细胞
再经顶端Cl⁻通道入腔
→ H⁺ + Cl⁻形成HCl

HCO₃⁻入血
→ 餐后碱潮
</code></pre>
<h3>4｜pH 的原页对象与代表药物</h3>
<p>原 Source P222（印刷 P196）写“为胃蛋白酶提供适宜酸性环境（pH 0.9–1.5）”。这个数值按原页修饰<strong>适宜酸性环境</strong>，不能转写为全胃液 / 胃腔的普遍正常 pH，也不替换 KP09 的胃蛋白酶最适 pH 1.8–3.5。原图只确定印字对象，不自动裁定不同医学范围相同。</p>

<p>原图支持的代表配对：奥美拉唑抑制 H⁺—K⁺泵；伏诺拉生与 K⁺竞争结合质子泵；西咪替丁、法莫替丁阻断 H₂受体。仅解释既有生理靶点，不扩成个人用药。</p>
<p>原 Source P224 已核原图：哌仑西平—M受体；丙谷胺—CCK_B受体。仍仅作原图代表药物与靶点配对，不引申个体用药。</p>

<h3>胃酸调节网：ACh—胃泌素—组胺三路放大，HCl—D细胞—SST负反馈刹车</h3>
<h3>1｜三条主促酸轴</h3>
<pre><code class="language-text">ACh → 壁细胞M受体
胃泌素 → 壁细胞 / ECL的CCKB受体

<p>胃泌素作用于 ECL 细胞促进组胺释放，这条间接放大可能比直接刺激壁细胞更重要。</p>
<h3>2｜迷走神经的四个靶点</h3>
<ul>
<li>ACh 直接刺激壁细胞；</li>
<li>ACh 刺激 ECL 释放组胺；</li>
<li>GRP 刺激 G 细胞释放胃泌素；</li>
<li>ACh 还抑制 D 细胞释放生长抑素，解除刹车。</li>
</ul>
<h3>3｜其他促酸因素｜MI-D集合</h3>

<li>Ca²⁺；</li>
<li>糖皮质激素 / 皮质醇；</li>

<li>乙醇、咖啡、牛奶、茶。</li>
</ul>

<h3>4｜抑酸因素</h3>
<ul>
<li>生长抑素；</li>
<li>HCl 负反馈；</li>
<li>VIP 总效应；</li>
<li>小肠脂肪及肠抑胃素：促胰液素、CCK、GIP、胰高血糖素、神经降压素等；</li>
<li>肠内高渗液及肠—胃反射；</li>
<li>前列腺素、EGF。</li>
</ul>
<h3>5｜HCl 两路负反馈</h3>
<pre><code class="language-text">HCl↑

→ 胃泌素和胃酸下降
</code></pre>
<h3>6｜CCK 的易混边界</h3>
<p>CCK 可经不同受体产生促酸和抑酸效应，但当前 Study 的<strong>总效应为抑制胃酸</strong>。同时，胃泌素、促胰液素、CCK 都可促进胃蛋白酶原分泌。</p>

<h2>有酸不等于一定损伤</h2>
<p>黏液—HCO₃⁻、上皮紧密连接、黏膜血流与修复共同防御；PG/EGF支持保护。NSAID削弱PG后，即使酸未增加，攻击—防御平衡也可能向损伤倾斜，完整HP/PUD及出血诊疗交D10。 <span class="binding" data-kp="digestive-d2-kp12" data-candidate-conflict="false">胃黏膜防御：屏障、血流和修复共同对抗 HCl—胃蛋白酶〔3层屏障｜PG/EGF 4作用｜直接保护6组物质｜适应性保护｜NSAID链｜溃疡天平〕</span></p>
<details class="explanation"><summary>展开这一段的机制、比较与完整细节</summary>

<h3>胃黏膜防御：屏障、血流和修复共同对抗 HCl—胃蛋白酶</h3>
<h3>1｜三层防御</h3>
<ol>
<li><strong>黏液-HCO₃⁻屏障</strong>：黏液减慢 H⁺向黏膜扩散，HCO₃⁻在近上皮侧中和 H⁺。</li>
<li><strong>上皮与紧密连接 / 胃黏膜屏障</strong>：限制 H⁺反向进入黏膜。</li>
<li><strong>黏膜血流和修复能力</strong>：带走反向扩散的酸，提供修复所需氧和底物。</li>
</ol>
<h3>2｜前列腺素与 EGF</h3>
<p>主要作用：</p>
<ul>
<li>抑制胃酸；</li>
<li>抑制胃蛋白酶原；</li>
<li>促进黏液和 HCO₃⁻；</li>
<li>舒张黏膜微血管、增加血流并促进修复。</li>
</ul>
<h3>3｜直接细胞保护物质</h3>
<p>当前 Study 列出：</p>
<ul>
<li>铃蟾素 / GRP 相关轴；</li>
<li>PGE₂、PGI₂；</li>
<li>EGF；</li>
<li>生长抑素；</li>
<li>神经降压素；</li>
<li>CGRP。</li>
</ul>
<h3>4｜适应性细胞保护</h3>
<p>食物、胃酸、胃蛋白酶或反流胆汁造成的经常性轻微刺激，可诱导黏膜持续少量释放前列腺素、生长抑素等，使防御系统处于准备状态。</p>
<h3>5｜//串联：NSAID 与消化性溃疡</h3>
<pre><code class="language-text">传统NSAID抑制COX
→ 生理性前列腺素↓
→ 黏液 / HCO₃⁻ / 黏膜血流与修复下降
→ 防御减弱
→ 在胃酸和胃蛋白酶存在时更易发生黏膜损伤 / 溃疡
</code></pre>
<p>当前只建立“攻击—防御天平”；HP、PUD 病理、出血和治疗归 D10。</p>
