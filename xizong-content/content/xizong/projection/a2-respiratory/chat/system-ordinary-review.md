# A2 呼吸系统：普通复习，同一模型压缩

任务：O₂由外界到组织，CO₂反向排出，维持PaO₂、PaCO₂与酸碱稳定。

## 1. 同一张整系统模型

```text
O₂去程：外界空气 → 传导气道 → 肺泡气 ──跨呼吸膜──→ 血液中的O₂ → Hb携氧 → 组织供氧
                                  ↑                 ↑
                            肺泡通气 VA         肺血流 Q
                                  └──并行匹配于同一交换面──┘

并行机械支：呼吸肌 / 胸廓 / 胸膜耦联
           → 肺扩张与肺泡压差 → 驱动空气经气道进出肺泡
           弹性负荷与气道流阻同时约束这次通气

CO₂回程：组织 → 血液 → 肺泡 → 传导气道 → 外界

反馈：血气 / H⁺ → 外周与中枢呼吸调节 → 呼吸频率、深度与时程
                → 有效肺泡通气 VA → 血气 / H⁺改变 → 返回调节输入
```

机械支驱动气流；VA和Q并行到达交换面；CO₂反向运输；控制器持续反馈。四者的关系不随复习压缩而改变。

## 2. 空气怎样进肺泡：动力、负荷与读数

呼吸肌→胸廓/胸膜耦联→肺扩张、肺泡压差→气流；平静呼气依系统净回缩，用力呼气另加肌肉参与。弹性负荷与气道阻力并行约束。

VE=VT×f；VA=(VT−VD)×f。FVC、FEV1、FEV1/FVC读取容量/流速；RV、FRC、TLC读取气量；顺应性、弹性回缩、气道阻力与呼吸功读取机械负担。读数不是原因。

## 3. 肺泡怎样把氧给血：两侧匹配、膜条件与携氧

VA与Q并行→同一交换面；分压差驱动扩散，膜厚/面积限制通量。VA/Q=肺泡通气量/肺血流量；高VA/Q为死腔样，低VA/Q为分流样；可在不同区域并存。DLCO读弥散，不能代替病因。

PaO₂/SaO₂ ≠ Hb/CaO₂ ≠ 组织供氧。PaO₂正常仍可能携氧不足。肺血流/右心、血液携氧与组织供氧接口保留各自所属系统。

## 4. CO₂反向回程与持续反馈

组织CO₂→血液→肺泡→外界。有效VA相对CO₂生成不足→PaCO₂可升高。

血气/H⁺→外周与中枢输入→频率、深度、时程→VA→血气/H⁺，闭合反馈。中枢主要读取脑脊液H⁺；外周与中枢输入并行；极端低氧/高CO₂可能抑制。pH、HCO₃⁻与PaCO₂共同读酸碱，完整肾性代偿另归泌尿。

## 5. 把失败放回同一位置

- 气道：阻塞→气流受限，严重时VA不足/CO₂潴留
- 机械/泵：肺、胸廓、胸膜或肌肉扩张失败→VA下降
- 肺泡：充填/塌陷，有血少气→低VA/Q/分流样低氧
- 呼吸膜：厚度↑或面积↓→弥散受限
- 气血配对：高VA/Q死腔样；低VA/Q分流样
- 肺血管：Q减少和/或PVR↑→交换受损、右室后负荷↑；PAP与后果按情境判断
- 控制器：驱动/调节失常→VA与PaCO₂控制失稳
- 携氧：Hb数量/结合或SaO₂异常→CaO₂与组织氧输送下降，PaO₂可正常

允许多处并存；限制≠必然高CO₂，低氧≠必然通气不足；ARDS≠所有呼衰。

## 7. 用什么证据判断，再压缩回来

稳定性→首个失败部件→通气/换气、阻塞/限制→ABG氧合/通气方向→针对性PFT、影像、病原/血管/胸膜/病理证据→主Block及所需接口。危重支持与必要取证并行。

同时保留：低氧血症/携氧失败；死腔样/分流样；气道、肺泡、膜、血管、机械支、控制器定位；急/慢；低氧为主/CO₂潴留；稳/不稳。
