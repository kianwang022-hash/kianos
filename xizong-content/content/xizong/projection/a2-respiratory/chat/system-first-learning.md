# A2 呼吸系统：先把整套关系接起来

呼吸系统要持续完成两件相反方向的工作：把外界O₂送到组织，把组织生成的CO₂排到外界，并维持PaO₂、PaCO₂与酸碱稳定。先把气体经过的位置、驱动气体的机械过程，以及持续调节通气的反馈分开，再看它们怎样协同。

## 1. 同一张整系统模型

```text
O₂去程：外界空气 → 传导气道 → 肺泡气 ──跨呼吸膜──→ 血液中的O₂ → Hb携氧 → 组织供氧
                                  ↑                 ↑
                            肺泡通气 VA         肺血流 Q
                                  └──并行匹配于同一交换面──┘

并行机械支：呼吸肌 / 胸廓 / 胸膜耦联
           → 肺扩张与肺泡压差 → 驱动空气经气道进出肺泡
           弹性负荷与气道流阻同时约束这次通气

CO₂回程：组织 → 血液 → 肺泡 → 传导气道 → 外界

反馈：血气 / H⁺ → 外周与中枢呼吸调节 → 呼吸频率、深度与时程
                → 有效肺泡通气 VA → 血气 / H⁺改变 → 返回调节输入
```

这里最重要的两个“同时”是：呼吸肌、胸廓、胸膜在气路旁驱动通气；肺血流和肺泡通气从两侧到达同一交换面。血液不必等空气经过呼吸膜后才来，呼吸控制器也不是组织之后的最后一站。

## 2. 空气怎样进肺泡：动力、负荷与读数

从呼吸肌开始，胸廓容积改变，密闭胸膜腔把运动传给肺。肺扩张后，肺泡压暂低于大气压，空气才沿传导气道流入。空气流入使压差缩小，到吸气末压差消失，气流暂止。平静呼气主要依赖肺—胸廓系统净弹性回缩；用力呼气另有呼气肌主动参与。这就是R1承担的机械模型。

同一次呼吸受两类负担约束：肺和胸廓能否容易扩张，空气能否顺利通过气道。顺应性反映压力变化能带来多大容积变化；气道阻力则限制气流。肺太硬和肺失去回缩力是不同故障，不能只用“肺功能不好”混在一起。

肺功能是这些过程的观察：FVC、FEV1及FEV1/FVC读取容量和呼气速度；RV、FRC、TLC读取剩余气量、呼气末状态及总容量。它们不是引起疾病或驱动空气的上游。

每分钟通气量VE=VT×f；真正更新肺泡气的VA=(VT−VD)×f。每口气要扣去无效腔，所以“呼得更快”或“VE看上去很大”并不保证有效肺泡通气足够。读PaCO₂时还要结合CO₂生成：生成相对稳定而有效肺泡通气不足，CO₂排出会减少。

## 3. 肺泡怎样把氧给血：两侧匹配、膜条件与携氧

肺泡内有气体，毛细血管内有血液，两侧分压差驱动O₂入血、CO₂出血；呼吸膜面积和厚度限制交换通量。膜增厚或有效面积减少可损害弥散，DLCO是相关功能读数。肺泡是否开放、是否被渗出物填充，则影响空气能否真正到达交换面。

同一肺泡还必须同时获得合适的VA与Q，VA/Q=肺泡通气量/肺血流量。气相对多、血相对少，出现死腔样改变；血相对多、气相对少，出现分流样改变。肺泡完全不通气而仍有灌注时，单纯提高吸入氧也难以让这部分血充分氧合。区域VA/Q与整体肺泡通气要分开：一个病人可以低氧，同时PaCO₂正常、下降或升高，取决于实际通气和代偿。

氧进入血液后，PaO₂、SaO₂、Hb和CaO₂仍回答不同问题。PaO₂是动脉血氧分压；SaO₂描述相应口径下的Hb氧饱和度；Hb提供载体；CaO₂表示实际氧含量。PaO₂正常不能证明携氧量正常，更不能单独证明组织供氧充足。Hb数量不足或结合异常可造成携氧失败，完整贫血/中毒病因回各自系统。

这几段共同归R2。它既解释“气进没进去、气血配没配上、膜能否交换”，也把血液运输接到组织，而不是把所有低氧都归于通气差。

## 4. CO₂反向回程与持续反馈

组织产生CO₂，经血液回肺，再随肺泡通气排出。它与O₂的方向相反，两条运输在肺与组织处互相配合。判断通气是否足以排出CO₂，PaCO₂比单看呼吸次数更直接。

与此同时，外周与中枢调节持续读取相应化学输入，再改变呼吸频率、深度和吸气时程。外周可读取PaO₂下降及血H⁺等输入；中枢主要读取脑脊液H⁺，CO₂越过血脑屏障后参与形成这一刺激。两路并行调节呼吸输出，VA改变后又改变血气，反馈闭合。严重低氧或过高CO₂可抑制中枢，不能把“异常越大，呼吸一定越强”无限外推。

完整神经肌肉疾病、肾性代偿和混合酸碱算法各有所属系统；在A2先守住控制器—有效通气—PaCO₂/pH这条真实接口。

## 5. 把失败放回同一位置

- 气道阻塞：空气进出受阻，严重时有效通气下降，可出现CO₂潴留。R3和R4分别展开持续与可变阻塞。
- 机械/泵扩张失败：肺、胸廓、胸膜或呼吸肌不能建立足够扩张。有效通气可下降，严重时低氧并伴CO₂潴留；定位看R1、R8、R10及相关接口。
- 肺泡充填或塌陷：血流仍在而局部通气显著减少，形成低VA/Q或分流样低氧。感染和ARDS等从不同病因到达此处。
- 呼吸膜增厚或面积减少：气体弥散受限。与肺变硬可以来自共同损伤，二者不构成必然先后。
- VA/Q失配：高比值偏死腔样，低比值偏分流样；同一疾病不同区域可以同时存在。
- 肺血管通路或阻力异常：影响Q，并可提高右室后负荷；急慢性后果在R9比较。
- 控制器/神经驱动异常：频率、深度或时程不能正确调节，VA与PaCO₂控制失稳。
- 血液携氧失败：PaO₂可以正常，但Hb数量、结合或SaO₂异常使CaO₂和组织氧输送下降。

这些是失效位置，允许并存，不是八个互斥病名。一种病可以跨多个位置；R12把上游疾病的后果重新归入氧合和通气两维，ARDS只占其中一条屏障损伤分支。

## 7. 用什么证据判断，再压缩回来

遇到病例先看是否不稳定，支持和必要取证按当前危险并行。随后定位首个失败部件，区分通气/换气、阻塞/限制、死腔样/分流样、急/慢，以及低氧为主还是CO₂潴留；同时别把PaO₂/SaO₂低氧血症与Hb/CaO₂携氧失败混同。

病史、症状和视触叩听提供入口；肺功能读取机械与气流，动脉血气读取氧合、CO₂和酸碱，X线/CT/HRCT定位空间，再按需要选病原、肺血管/右心、胸水/胸膜或病理/组织/分子证据。这是按问题选取的证据层次，不是危重者必须依次排完的检查清单。PVR、PAP与呼吸功读取肺血管和负担；pH、HCO₃⁻与PaCO₂一起读取酸碱接口。

最终回到同一张图：空气由机械支推动，VA与Q在交换面并行匹配，O₂经Hb送向组织，CO₂反向排出，控制器通过有效通气闭合反馈；疾病改变其中某些位置，检查读取改变，处理回作用于失效环节。
