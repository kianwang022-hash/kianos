# 0｜Why Biochemistry gets a scoped contract

Biochemistry has a learning geometry that is materially different from most organ / disease content:

- the current Lecture is a long continuous **pathway / information-flow source**;
- one canonical Block may be formed from multiple non-contiguous Source units;
- a concept encountered early may need only a tiny just-in-time explanation before its formal Block appears later;
- the most durable memory is often a **state variable, switch, conserved carrier, compartment or boundary**, not a paragraph or pathway name;
- understanding improves sharply when Source order and canonical Knowledge order are allowed to differ.

Therefore Biochemistry inherits the current Learning and Lecture Replacement Contracts and specializes **continuous accepted-model teaching, optional Source continuity, same-model reconstruction/review, Memory and question repair**.

Hard distinction:

```text
teacher Source order
≠ canonical M/G Knowledge order
≠ Logic Group order
≠ Recall order
≠ official-question order
```

## Content consistency｜Biochemistry is a learning/content specialization within the shared model

Biochemistry inherits the **same canonical hierarchy as every mature Xizong System**:

```text
System
→ Block
→ Logic Group
→ KP
```

This scoped contract may specialize **how Source is contacted when chosen or locally required, how optional retrieval and ordinary review use the accepted model, how state reconstruction works, and how cross-System connections are timed**. It may not create another canonical level such as:

```text
Block → Layer → Logic Group / KP
Block → pathway band → KP
Source unit → canonical layer
```

A biochemical “mother model”, pathway family, state model or submodel is a **Framework / compression object** owned by the existing System or Block. If it groups the same KPs as an existing Logic Group, the Logic Group remains the canonical local learning unit; do not duplicate it with a second topology.

Likewise, the following remain content jobs around the same Block/LG/KP owners:

```text
Framework
Core

Precision
Visual
Connection
Memory Routing
MI-G / MI-D
Recall / Closure
Compression
Question Probe / Repair
```

They may be presented at different levels of detail, but they are not new Knowledge hierarchy.

**Dedicated Biochemistry lane ≠ isolated Biochemistry Knowledge.**

The lane may be Source-continuous; the Knowledge must remain integrated with digestive, endocrine, hematology, hepatobiliary and tumor owners through reviewed Connection / Recall / Reconstruction semantics.

# 1｜Top-level learning decision

## 1.1 One continuous accepted Biochemistry model

Normal Biochemistry learning teaches the existing accepted model continuously in Chat/content:

- use natural title〔complete canonical Prompt〕 nodes to carry the causal model;
- keep each node’s full canonical Prompt and all relevant exact Memory/Precision answers available; expand explanatory Core only as needed to make the same model understandable;
- ordinarily review and compress the same model, with no compulsory KP-by-KP lessons or fixed quiz/stop cadence;
- hide answers only for an explicitly requested self-test;
- use state-based cross-Block reconstruction and smallest-sufficient repair without adding a competing teaching route;
- enter official questions when the relevant Knowledge and reviewed question scope are available.

When original Source study is chosen or a local Source requirement applies, preserve the current teacher-order continuity and map its segments to existing Block/LG/KP owners. A Source-contact completion claim still waits for its last required current-Source segment; this does not gate ordinary teaching of the accepted model.

During that chosen Source lane, Biochemistry is **not routinely interleaved** with digestive / endocrine / organ Source courses.

Cross-System material appears only as:

- a just-in-time explanation that materially improves the current biochemical model;
- a short Recall of already learned neighboring Knowledge;
- a deferred Connection to one formal Current owner.

A connection is not permission to leave the Biochemistry lane and learn the neighboring course in full.

## 1.2 Chosen Source study preserves Source continuity

Canonical Block identity remains stable, but Block numbering does not control Source reading order.

When studying the original Source, if it teaches metabolism before formal enzyme theory, continue that Source with the smallest sufficient language needed to understand the current page, without falsely declaring the later Block complete. Chat/content teaching may instead develop the same accepted model continuously under its real cognitive readiness.

Likewise, if one canonical Block is distributed across early and late Source units, the earlier segment may form partial Knowledge, while claimed Source-contact closure waits for the last required Source unit. Ordinary same-model explanation or compression does not claim that missing Source evidence.

# 2｜Source policy

## 2.1 One continuous current Source

For original-Source study and exact source verification, the current authoritative Source is resolved by the Source-map owner. Continuous Chat/content teaching remains grounded in the same accepted canonical model.

For the current 27-cycle rebase, the binding is in:

`biochemistry-27-source-map.json`.

The learner should not be asked to read two full Biochemistry courses in parallel.

## 2.2 Historical / refined material is reconstruction substrate

A previous refined Source may contribute explanation only after re-verification.

A historical explanation is admitted only when all are true:

1. it is compatible with current Source truth;
2. it materially clarifies a mechanism, direction, compartment, state variable or boundary;
3. it reduces future memorization load or prevents a high-value category error;
4. it can be routed to the existing canonical Block/KP or an explicit external owner.

Reject or demote it when it is:

- merely repetitive prose;
- a mnemonic with no durable cognitive value;
- contradicted by current Source;
- unsupported precision;
- a reason to create a competing medical model, a mandatory second Source course or a second medical owner.

The durable result is the **reconstructed meaning**, not preservation of the old paragraph.

## 2.3 Source ambiguity stays explicit

Decision-relevant ambiguity in:

- direction / negation / exception;
- enzyme / substrate / product / cofactor relation;
- numeric / threshold / timing;
- table row-column relation;
- handwritten symbol / image relation;
- answer / option identity;

stays `UNKNOWN / CONFLICT / SOURCE_BOUND` until verified.

Current-year novelty never authorizes guessing.

# 3｜Biochemistry Knowledge model

Biochemistry should compress into two durable mother models.

## 3.1 Metabolism = material–energy network

Default coordinates:

```text
carbon flow
+ ATP / high-energy transfer
+ NADH / FADH2 vs NADPH redox role
+ group carriers
+ compartment
+ tissue identity
+ physiologic state
```

High-reuse hubs include:

```text
G-6-P
pyruvate
acetyl-CoA
oxaloacetate / TCA
ATP / GTP
NADH / FADH2
NADPH
CoA
FH4
SAM
PRPP
```

The preferred learner question is not only “what is the pathway?” but:

> Where does the substrate come from, where can it go, what energy/redox currency changes, which control point determines direction, where does it occur, and what physiologic state changes the flow?

## 3.2 Molecular Biochemistry = information lifecycle

Default spine:

```text
DNA identity / packaging
→ replication
→ transcription
→ RNA processing
→ translation
→ expression control
→ damage / repair
→ oncogene / tumor-suppressor control failure
→ molecular tools
```

The learner should locate a defect or technique on this lifecycle before memorizing isolated labels.

# 5｜Content generation — inherit the shared standard, then optimize for Biochemistry

Produce Biochemistry content by checking the medical meaning and its teaching correspondence:

```text
reliable current Source, explicit scope and unresolved Source boundaries
→ supported mechanism / state / information-flow model in existing Knowledge owners
→ matching continuous teaching with natural title〔complete canonical Prompt〕 nodes
→ complete relevant exact Memory/Precision answers and necessary explanatory Core
→ correspondence checks across the affected model, teaching, Source references and support content
```

Use current Source for direction, negation, exceptions, exact values and visual relations. Use verified refined explanations to make the causal model clear without adding a competing model. Preserve unchanged valid content; revise only the affected explanation, Prompt, exact answer or support reference.

Content Realization must still satisfy the shared responsibility set:

```text
ORIENTATION
SOURCE_CONTACT
RETRIEVAL
CORE_CHECK
BOUNDARY
COMPRESSION
```

These are responsibilities, not mandatory headings or serial lesson stages. They all serve one accepted model, whose complete applicable answers remain available in ordinary learning and review.

## 5.1 ORIENTATION

Use the smallest map that makes the current accepted model or chosen Source segment navigable.

Prefer:

- flow / branch / state switch;
- conserved carrier;
- compartment / tissue coordinate;
- comparison axis;
- information-lifecycle position.

Teach the accepted model as fully as needed in one continuous explanation; do not create a competing model or a compulsory second course. Source-only uncertainty and visual requirements remain local.

## 5.2 SOURCE_CONTACT

For chosen or locally required Source contact, use natural continuous Source units from the current Source map.

A Source unit may:

- contribute to several canonical Blocks;
- complete only part of a Block;
- revisit a Block later.

Logic Group count must not manufacture Source-contact count.

## 5.3 RETRIEVAL

For an explicitly requested self-test, Recall fronts expose **coordinates** without revealing the answer. Ordinary review compresses the same accepted model, preserving every included node’s full canonical Prompt and all relevant exact Memory/Precision answers. Expand explanatory Core only where the current understanding, distinction or causal link needs it; do not dump every detailed expansion.

Good prompts ask the learner to reconstruct:

- direction;
- causal link;
- compartment;
- tissue;
- physiologic state;
- decisive boundary;
- exact item when Precision is actually required.

During that explicit self-test only, avoid leaking the accepted closure before the learner answers. Outside self-test, use natural title〔complete canonical Prompt〕 nodes and keep the answer available; Reveal is not a required learning stage.

## 5.4 CORE_CHECK

Canonical KP Core supplies the same medical model for continuous teaching, ordinary review, checking and repair. Expand its explanation to the depth needed for the current model or gap; compression retains the causal skeleton rather than printing every detailed Core paragraph. When explanation is needed, favor:

```text
causal order
→ direction / branch
→ compartment / tissue / state
→ decisive boundary
→ exact high-value precision
```

Valid 26 refined explanation may improve the Core only after current-Source re-verification.

## 5.5 BOUNDARY

Explicitly preserve:

- what this Block owns;
- what is only Recall / Connection;
- what is Source-visual only;
- what is conflict / uncertain;
- what belongs to another System.

Do not duplicate neighboring clinical or physiology Core merely because the biochemical mechanism connects to it.

## 5.6 COMPRESSION

The desired compression unit is usually a **reconstructable switch / state model**, not a shortened pathway paragraph.

A compressed view becomes thinner by retaining the model’s governing variables, causal connections and decisive boundaries. Preserve each included node’s full canonical Prompt and all relevant exact Memory/Precision answers; expand the corresponding explanatory Core only as needed. Compression neither changes the model nor deletes the underlying detailed content.

# 6｜Framework, Logic Group and KP roles

Biochemistry does not change the shared hierarchy. The roles below operate **inside**:

```text
System → Block → Logic Group → KP
```

## Framework

Framework = canonical System/Block-owned cognitive map that makes the Block or current Source segment navigable.

For Biochemistry it should usually expose:

- input / output;
- decisive branch or switch;
- energy / redox currency;
- compartment / tissue;
- physiologic-state control;
- one or two confusable boundaries.

A Framework can be rich and answer-bearing. It is still a **content job**, not a level between Block and Logic Group.

Explicit Block Framework content remains canonical Block content and must not be demoted to a disposable derived layer.

## Logic Group

Logic Group = the canonical local reconstruction / retrieval / closure grouping inside a Block; it preserves coverage and cognitive relationships without imposing a separate serial lesson or mandatory test stop.

A Biochemistry LG should group KPs that answer one causal job such as:

- carbon-entry branching;
- redox defense;
- storage-output decision;
- lipoprotein transport;
- nitrogen handling;
- DNA replication execution.

It does not automatically equal a continuous Source segment.

If a proposed “layer” has the same KP membership and cognitive job as an existing LG, **use the LG**. Do not create a parallel layer.

## KP

KP = stable canonical Knowledge identity.

A KP may own or receive:

- Prompt;
- canonical Core mechanism;
- current Source Precision;
- verified explanatory reconstruction;
- Boundary / Confusable;
- Visual;
- Connection / Extension.

It does not dictate first-pass Source order or learner order.

## Block-owned content jobs

When current canonical Block content explicitly contains them, preserve:

- center question / ownership boundary;
- first-pass route;
- Framework;
- high-density comparisons;
- Memory Routing;
- MI-G / MI-D;
- Visual / exactness gates;
- coverage / routing ledgers;
- Lecture-attached question checkpoint;
- Block Exit / Recall target.

These jobs are part of durable Content Realization and belong to the same accepted model; they are not disposable engineering metadata. Preserve their valid medical and content roles without carrying forward an obsolete Source-only route, fixed stopping cadence or hidden-answer requirement.

# 7｜Recall and reconstruction

## 7.1 Local Recall

Optional KP / LG Recall uses the same accepted model after that local model has been explained and the minimum prerequisite language is available. Ordinary review keeps the full applicable answers available; self-test hides them only when explicitly requested.

Claims of owning current-Source contact still require actual contact, and explicit Source/Visual/HOLD requirements remain local. Do not wait for unrelated formal Block closure when the local cognitive object is already valid.

## 7.2 Block Recall

Block Recall reconstructs the Block model, not all KP wording.

For distributed Blocks, a full Source-contact completion claim waits until the last required Source unit. Ordinary explanation and compression may use the already accepted model without claiming that Source evidence or forcing a Block-end test.

## 7.3 Cross-Block state reconstruction

Biochemistry must deliberately use state-based reconstruction because it compresses multiple pathways into one model.

High-value states include:

- fed vs fasting;
- mature RBC;
- hypoxia / respiratory-chain inhibition / uncoupling;
- diabetes / glucose-utilization failure;
- lipid storage vs mobilization;
- DNA expression / regulation / repair state.

Example form:

```text
state variable changes
→ control point changes
→ substrate flow changes
→ energy/redox consequence
→ expected metabolite / phenotype
```

Prefer this over reciting multiple isolated pathways.

# 8｜Memory policy

Precision-content selection emphasizes **high-reuse switches and decisive boundaries**, plus explicit canonical Precision. Selection does not restrict answer availability: all relevant exact canonical Memory/Precision answers stay available during ordinary teaching and review.

Examples:

- NADH vs NADPH;
- cytosol vs mitochondrion;
- liver vs muscle;
- mitochondria-present vs absent;
- fed vs fasting;
- malonyl-CoA ↔ CPT-I;
- LPL vs HSL;
- LCAT vs ACAT;
- HMG-CoA cholesterol vs ketone branch;
- reversible vs irreversible control;
- substrate-level vs oxidative phosphorylation.

Hard rule:

> Do not duplicate a whole pathway as separate Memory content when its meaning can be reconstructed from the existing model; retain its explicit canonical exact-answer items.

`MI-G / MI-D` remains governed by the Block Pre-entry Content Contract:

- only explicit Current Block ownership may assign membership;
- importance / frequency / exam yield alone cannot infer it;
- preserve existing admitted identities and exact answers; availability alone neither adds nor removes admission.

# 10｜Cross-System integration

Biochemistry should connect aggressively in **meaning**, but conservatively in **ownership and Source switching**.

The following are context-dependent integration modes of the same accepted model, not a compulsory serial teaching ladder:

```text
1. JIT Connection during current Biochemistry Source
   → only the minimum outside idea needed to understand the current biochemical mechanism
   → no course switch

2. Connection Hook / Recall at Block or Logic Group level
   → already learned target owner: Recall it
   → not-yet-learned target owner: mark the formal future owner
   → no duplicate external Core

3. Post-formation cross-Block / cross-System Reconstruction
   → combine biochemical mechanism with digestive / endocrine / clinical state
   → use shared state variables rather than rereading both courses
```

Therefore Biochemistry may keep a dedicated continuous Source lane **without becoming an isolated knowledge island**.

High-value integration examples include:

- M4 glucose output ↔ D7 fed/fasting and insulin/glucagon control;
- M7 storage/mobilization/ketogenesis ↔ D7/D8 fasting, diabetes and glucose-utilization failure;
- M5 lipoprotein transport ↔ D3/D4 intestinal lipid digestion/absorption;
- M6 bile-acid synthesis ↔ D3/D4 digestion/absorption ↔ D19 hepatobiliary disease;
- M8 ammonia/urea ↔ D17 hepatic failure / hyperammonemia;
- M10 bilirubin handling ↔ D17/D19 jaundice localization;
- RBC / folate / B12 / heme ↔ hematology;
- HIF / nuclear receptor ↔ physiology / endocrine;
- oncogene / repair ↔ tumor-general.

Rules:

- Connection may Recall or preview one external idea;
- external medical Core stays in its formal owner;
- a durable deferred hook requires one formal Current target owner;
- no full-course switching merely because a connection exists;
- after the relevant owners are learned, Reconstruction should actively **recombine** them rather than leaving the knowledge graph as isolated subjects.

A useful summary is:

> **Source continuity can be domain-specific; Knowledge integration must remain System-wide.**

# 12｜Affected-content correspondence checks

When current Source or biochemical meaning changes, inspect the affected content rather than rebuilding unchanged material for symmetry.

Check the following correspondences:

- **Source → mechanism:** current identity, exact locators and Source-supported direction, negation, enzyme/substrate/product/cofactor relations, numeric details and visual/table relations agree with the affected M1–M10 or G1–G5 content. Keep UNKNOWN / CONFLICT / SOURCE_BOUND and local visual requirements explicit.
- **Mechanism → model:** carbon flow, ATP/high-energy transfer, NADH/FADH2 versus NADPH, group carriers, compartment, tissue and physiologic state remain connected in the material–energy network. Molecular changes stay located in the DNA/information lifecycle rather than becoming detached facts.
- **Model → teaching node:** each natural title〔complete canonical Prompt〕 corresponds to the medical question actually explained. Keep the full Prompt, causal link, decisive boundary and relevant exact answer; do not substitute a label, serial testing checkpoint or separate summary model.
- **Model → ordinary review:** compress the same causal/state model. Keep full node Prompts and relevant exact Memory/Precision answers; reopen explanatory Core only for a relation or distinction that needs expansion.
- **Exactness → canonical answer:** preserve explicit Memory/Precision answers, units, conditions, exceptions and Source-version boundaries. Do not infer MI-G / MI-D membership from frequency, importance or exam yield, and do not alter existing admission identities merely because presentation changes.
- **Source map → existing content:** verify any affected Source-unit/page reference against its existing Block/LG/KP or explicit support/Connection target. Keep non-contiguous Source contributions and partial contact distinctions; a teacher-order segment must not manufacture learner completion. Preserve the existing System → Block → Logic Group → KP identities in changed content and its actual dependents; a Source unit, Framework or mother model must not become an extra hierarchy.
- **Core → Framework and support:** retain valid Frameworks, high-density comparisons, Memory Routing, MI-G / MI-D, visual/exactness references and Block Recall targets. Update only support whose medical meaning or teaching correspondence actually changed, without restoring obsolete Source-only routes or hidden-answer defaults.
- **Model → Guide/Orientation:** any affected guide explains the same two biochemical mother models, JIT Prelude, teacher-order versus canonical-order distinction, and current-Source versus verified historical-explanation boundary.
- **Knowledge → question material:** check only reviewed relations and learner-facing explanations affected by the changed meaning, terminology, exactness or owner boundary. Question membership changes require actual corpus/ownership evidence; missing fine-grained mapping remains legal.
- **Biochemistry → neighboring owners:** preserve digestive, endocrine, hematology, hepatobiliary and tumor connections through the existing state variables and reviewed ownership boundaries; do not duplicate the neighboring clinical Core or turn the connection into another course.

Unchanged medical content, valid Source references and existing admitted answer identities remain intact.
