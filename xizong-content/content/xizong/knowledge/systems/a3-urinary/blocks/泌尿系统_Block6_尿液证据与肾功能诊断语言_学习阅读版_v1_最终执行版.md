# 0｜尿液是一份“从肾单位到尿道”的系统日志

面对异常尿检，不能先猜疾病名。先问异常证据从哪一层产生：

```text
滤过屏障漏
→ 白蛋白 / 大分子蛋白 / 变形RBC / RBC管型

近端小管回收失败
→ 小分子蛋白、葡萄糖等回收障碍

血中小分子负荷过高
→ 溢出性蛋白尿

肾小管 / 集合管内有细胞与蛋白凝固
→ 管型

尿路下游出血或炎症
→ RBC / WBC可出现，但通常不形成肾内管型

单侧肾功能或上尿路通畅问题
→ 先问需要定量分肾功能，还是解剖 / 排泄侧别信息

出血发生在尿流的哪个时间段
→ 尿三杯定位
```

固定顺序：

> **先判断证据身份 → 再定位结构 → 再判断总肾功能 / 单侧功能 → 最后进入疾病模型。**

# 1A｜同一模型上的自然节点〔完整 Prompt〕

## 血液与管液分流，尿液留下各层处理的证据

血由入球进入肾小球，经过出球进入管周毛细血管/直小血管再回血；只有滤出的液体进入肾小囊，沿近端、髓袢、远端和集合管形成终尿。小管重吸收把管液中的物质送回血侧，分泌则把物质加入管液；终尿再经肾盂、输尿管、膀胱和尿道排出。不同位置的异常可同时留下证据，蛋白尿、血尿、脓尿和功能下降没有必经先后。
〈五类证据先定位：漏、吸不回、负荷过大、肾内凝固、尿路出血〔5证据机制｜各自第一结构｜总功能vs分侧功能｜先定位后命名。〕〉

## 蛋白进入终尿：滤入过多、回收不足或尿路加入

屏障蛋白限制能力下降，使原本受限的白蛋白乃至较大蛋白进入滤液；超过小管回收能力后进入终尿。选择性与非选择性反映尿蛋白谱及屏障损伤程度，不由一个尿量级直接命名疾病。
〈肾小球性蛋白尿：选择性以白蛋白为主，非选择性提示屏障更重〔选择/非选择2型｜蛋白谱3组｜严重程度｜大小/电荷/裂隙膜｜量级边界〕〉

自由滤过的小蛋白正常由近端回收。近端回收受损，即使血中负荷未升高也可尿中增多；若血中Hb、肌红蛋白或轻链大量增加，滤入负荷超过原本正常的回收能力，便是溢出入口。两条入口可并存，但第一故障不同。
〈肾小管性蛋白尿：小蛋白能滤，但近端吸不回来〔机制｜量级｜小蛋白5｜第一故障层｜vs 肾小球性。〕〉
〈溢出性蛋白尿：滤过的小蛋白负荷超过回收能力〔机制链｜肾小管功能｜3疾病—3蛋白｜vs 肾小管性｜清除负荷边界。〕〉

尿路分泌可加入IgA；小管产生尿调节素并可形成管型基质，不能当成滤过后等待回收的小蛋白。肾衰毒素名单是在血中蓄积的另一分类，不等同尿中蛋白分类。上述终尿蛋白用总量或白蛋白量测量；短暂功能性/体位性变化与持续升高须分开，泡沫外观只能提示检查。
〈分泌性、组织性 + 肾衰大分子毒素：三个名单不要串〔分泌性1｜组织性1｜肾衰毒素5｜与小管小蛋白差哪1项｜T-H来源边界。〕〉
〈蛋白尿定义 + 两类生理性 + 微量蛋白尿〔定量/定性/外观3｜生理2型及触发｜微量范围｜提示疾病｜一过性边界。〕〉

## 血细胞进入管液还是在下游加入，决定定位证据

受损滤过屏障可让RBC进入管液，机械应力与小管渗透环境可使其形态、容积不均；变形/棘形RBC、RBC管型及相符蛋白尿共同支持肾小球来源。没有典型变形不能绝对排除；某个疾病名也不能替代这些证据。
〈肾小球源性血尿：变形RBC + 小容积曲线 + RBC管型 / 蛋白〔首选检查｜RBC形态｜容积分布2点｜伴随证据2｜机制链｜非对称原因。〕〉
〈RBC形态不是单独金标准：证据组合决定“是否支持肾小球来源”〔RBC单轴边界｜严重屏障例外｜管型/蛋白组合｜疾病名≠来源〕〉

肾内炎症可使WBC进入小管；下尿路出血/炎症也可直接把RBC/WBC加入已形成的尿。血尿、脓尿的计数确认细胞增多，却不能单靠数量定位来源。尿三杯观察初始、终末、全程的出血分布，粗定位尿路空间；全程也可因大量出血出现，不能作为上尿路的唯一证明，肿瘤警报仍须疾病检查。
〈肉眼血尿、镜下血尿与脓尿：三组阈值〔肉眼阈值/单位+外观｜镜下RBC两阈｜脓尿WBC两阈｜常见病因4｜单位别混。〕〉
〈尿三杯：初始前尿道、终末膀胱出口、全程上尿路 / 大量出血接口〔初始/终末/全程3位置｜肾结核2阶段｜膀胱癌2型｜恶性血尿特征/间歇边界｜血块/疾病完整后置。〕〉

## 管型给出肾内形成条件，不把细胞数直接变成病名

细胞进入肾小管后，还须与蛋白基质在远端/集合管内聚集成圆柱，才形成细胞管型；只有尿中RBC或WBC不保证有管型，下尿路加入的细胞也没有经过这一步。WBC管型支持肾实质炎症，并非肾盂肾炎必有或独有。
〈脓尿 vs 白细胞管型：一个说明尿中有WBC，一个提示肾内形成圆柱〔脓尿vsWBC管型｜形成位置/基质｜疾病2组｜下尿路边界｜非必要/非充分〕〉
〈RBC / WBC 与管型的两条边界〔RBC/WBC与管型2区别｜入小管+基质2条件｜上/下尿路定位｜病因反推边界〕〉

管型材料保留形成时的肾内信息：RBC、WBC、上皮、脂肪或长期停滞相关蜡样管型分别提供出血、炎症、小管损伤、脂质尿、严重慢性病变接口。它们帮助定位，仍须组合其他证据确认病因。
〈五类管型地图：红、白、蜡、上皮、脂肪〔形成位置/材料｜管型5类→位置/病因｜预后/小管坏死/肾病接口〕〉

## 成分与功能是并行读数，再按问题反推结构

血Cr/BUN读总体清除，尿量/比重/渗透压读动态水与溶质处理；成分异常不必伴总功能下降，总功能正常也不能排除单侧损伤。需要定量左右功能时用核素肾图；CTU/IVU主要读侧别解剖及造影剂排泄，不与定量功能等价，逆行显影更不能证明肾脏自身排泄。
〈总肾功能与尿量：Cr / BUN看总体，尿量是动态输出〔总功能2项/侧别边界｜尿量3类｜尿渗/比重定位｜AKI-CKD接口〕〉
〈分侧肾功能证据：肾图定量功能；CTU / IVU提供排泄与解剖侧别〔Study检查3｜核素定量｜CTU/IVU解剖-排泄｜MRU/逆行边界｜总vs分侧〕〉

将突出证据与形成条件对应，再并行核对总/分侧功能和尿流时段，才能把搜索缩到肾小球、小管间质或尿路；按病例需要进入AKI/CKD、感染、免疫或梗阻/肿瘤/外伤。这个诊断读取顺序不是疾病的因果发生顺序。
〈最终病例算法：证据 → 位置 → 功能 → 病因分支〔证据→位置→功能8步｜蛋白/RBC/WBC/管型｜总功能/分侧｜尿三杯｜疾病4分支〕〉

**Residual 边界**：先保留模型与自然节点的完整 Prompt，再独立判断精确恢复的困难；分类、比较或名单不能仅因形式被移出 Prompt。已审 Prepared Memory / Precision 即使与 Prompt 重叠，仍保留原有答案、条件、身份与历史，不因本次模型校准撤销准入。

## KP01｜五类证据先定位：漏、吸不回、负荷过大、肾内凝固、尿路出血

> **讲义定位 →** 内科 Lecture P143–144；外科 P106。  
> **主提示**：5证据机制｜各自第一结构｜总功能vs分侧功能｜先定位后命名。

```text
肾小球屏障漏
→ 肾小球性蛋白尿 / 变形RBC / RBC管型

近端小管重吸收失败
→ 肾小管性蛋白尿

血中小分子蛋白负荷过高
→ 溢出性蛋白尿

远端小管 / 集合管内蛋白+细胞凝固
→ 管型

尿路局部炎症、结石、肿瘤、外伤
→ 血尿 / 脓尿，可无管型
```

同时区分：

- Cr / BUN：总肾功能；
- 放射性核素肾图：定量分肾功能 / 灌注—摄取—排泄功能主工具；
- CTU、IVU / IVP：上尿路解剖、排泄和侧别信息，可形成分侧功能接口，但不与核素肾图的定量功能能力等价；
- 尿三杯：出血时间—空间定位。

## KP02｜蛋白尿定义 + 两类生理性 + 微量蛋白尿

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：定量/定性/外观3｜生理2型及触发｜微量范围｜提示疾病｜一过性边界。

蛋白尿的 Study 定义：

- 尿蛋白定量 > **0.15 g/d**；
- 定性阳性；
- 泡沫尿可提示进一步检查，但不是蛋白尿的独立诊断标准，也不能用无泡沫排除。

### 生理性蛋白尿｜一过性

- 功能性：运动、发热时出现；
- 体位性：直立时出现。

### 微量蛋白尿

- 指尿白蛋白排泄约**30–300 mg/d**，不是尿总蛋白30–300 mg/d；现代常称中度增加白蛋白尿，须与总蛋白>0.15 g/d区分；
- Study主要提示糖尿病肾病早期。

（易混：区别不仅是g与mg，更是总蛋白与白蛋白的检测对象；单次升高还需排除暂时因素并复核。）

## KP03｜肾小球性蛋白尿：选择性以白蛋白为主，非选择性提示屏障更重

> **讲义定位 →** 内科 Lecture P143；Recall K2滤过屏障。  
> **主提示**：选择/非选择2型｜蛋白谱3组｜严重程度｜大小/电荷/裂隙膜｜量级边界

| 类型 | 终尿主要蛋白 | 屏障损伤程度 |
|---|---|---|
| 选择性肾小球性蛋白尿 | 白蛋白为主 | 相对较轻 |
| 非选择性肾小球性蛋白尿 | 白蛋白 + 免疫球蛋白 + C3等 | 更严重，较大蛋白也可通过 |

统一机制：

```text
滤过屏障蛋白限制能力下降
→ 原本被限制的蛋白进入原尿
→ 超过小管回收能力
→ 尿蛋白增多
```

这里 **Recall B2** 的考试模型：白蛋白受到大小 / 结构与经典电荷选择性的共同限制；nephrin 属于足细胞裂隙膜结构 / 通透选择性轴。B6 不再把“选择性蛋白尿”重新解释成一个独立的“电荷屏障疾病分类”，只学习尿中蛋白谱怎样反映屏障选择性严重度。

Study将肾小球性蛋白尿量级概括为常可 >2 g/d接口；完整肾炎 / 肾病综合征分支在K9–K11。

<!-- kianos:kp id="urinary-b06-kp04" -->

## KP04｜肾小管性蛋白尿：小蛋白能滤，但近端吸不回来

> **讲义定位 →** 内科 Lecture P143；Recall K3近端。  
> **主提示**：机制｜量级｜小蛋白5｜第一故障层｜vs 肾小球性。

正常情况下，一些小分子蛋白可经过滤过膜，再由近端小管回收。

```text
近端小管重吸收障碍
→ 小分子蛋白回收失败
→ 肾小管性蛋白尿
```

Study列举五类：

- VitA结合蛋白；
- 溶菌酶；
- 核糖核酸酶；
- 轻链蛋白；
- β₂-微球蛋白。

量级：多 <2 g/d。

（易混：这里的第一故障在小管，不是滤过屏障大量漏大蛋白。）

<!-- kianos:kp id="urinary-b06-kp05" -->

## KP05｜溢出性蛋白尿：滤过的小蛋白负荷超过回收能力

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：机制链｜肾小管功能｜3疾病—3蛋白｜vs 肾小管性｜清除负荷边界。

```text
血中某种小分子蛋白大量增加
→ 经肾小球滤过负荷↑
→ 超过正常近端小管重吸收上限
→ 溢出性蛋白尿
```

三组对应：

| 场景 | 尿中蛋白 |
|---|---|
| 血管内溶血 | 血红蛋白 |
| 横纹肌溶解 / 挤压综合征 | 肌红蛋白 |
| 多发性骨髓瘤 | Bence-Jones / 凝溶蛋白 / 游离轻链 |

| 比较轴 | 肾小管性 | 溢出性 |
|---|---|---|
| 血中小蛋白负荷 | 通常不必升高 | 明显升高 |
| 小管本身 | 回收障碍 | 初始可正常，只是超载 |

## KP06｜分泌性、组织性 + 肾衰大分子毒素：三个名单不要串

> **讲义定位 →** 内科 Lecture P143。  
> **主提示**：分泌性1｜组织性1｜肾衰毒素5｜与小管小蛋白差哪1项｜T-H来源边界。

### 分泌性蛋白尿

- 尿中 IgA增多。

### 组织性蛋白尿

- 尿中Tamm-Horsfall蛋白（尿调节素uromodulin）来源于肾小管，以髓袢升支粗段为主，早段远曲小管亦表达；它是糖蛋白并可聚合为尿管型基质，不能沿用“小分子T-H”将其归入滤过后重吸收的小蛋白组。

### 肾衰竭“大分子毒素”｜Study名单

- 核糖核酸酶；
- 溶菌酶；
- β₂-微球蛋白；
- VitA结合蛋白；
- 氨甲酰化蛋白。

（易混：与肾小管性蛋白尿五种小蛋白相比，肾衰毒素名单**没有轻链蛋白，增加氨甲酰化蛋白**。二者参考分类不同，不能因重叠就视为同一知识。）

# 4｜血尿：先确认来源，再看管型

<!-- kianos:kp id="urinary-b06-kp07" -->

## KP07｜肉眼血尿、镜下血尿与脓尿：三组阈值

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：肉眼阈值/单位+外观｜镜下RBC两阈｜脓尿WBC两阈｜常见病因4｜单位别混。

以下数量界值按本讲义及相应检测方法记忆，不将一次肉眼外观或旧计数法等同于所有情境的临床确诊。

### 肉眼血尿

- >1 mL血 / 1 L尿；
- 典型洗肉水样。

### 镜下血尿

- 尿沉渣 RBC >3个 / HP；
- 或12 h尿 RBC >5×10⁵。

### 脓尿

- 尿沉渣 WBC >5个 / HP；
- 或12 h尿 WBC >10⁶。

血尿常见于泌尿系统炎症、结石、肿瘤、外伤等。

（易混：血尿和脓尿是尿中细胞数量概念；红 / 白细胞管型还要求这些细胞在肾小管内与蛋白凝固。）

<!-- kianos:kp id="urinary-b06-kp08" -->

## KP08｜肾小球源性血尿：变形RBC + 小容积曲线 + RBC管型 / 蛋白

> **讲义定位 →** 内科 Lecture P144；Recall K2滤过膜。  
> **主提示**：首选检查｜RBC形态｜容积分布2点｜伴随证据2｜机制链｜非对称原因。

判断肾小球源性血尿，Study首选：**相差显微镜**。

证据层：

```text
大量变形RBC / acanthocytic pattern接口
+ 尿RBC非对称容积分布曲线
+ 曲线峰值小于静脉RBC容积
+ 可伴RBC管型
+ 可伴较明显蛋白尿
```

机制：

```text
RBC通过受损的肾小球滤过屏障
→ 机械应力与后续不同小管渗透环境等可影响细胞膜及体积
→ 受影响程度不一，形成形态/大小不均的群体，容积分布可不对称
→ 进入肾小管后可与蛋白基质形成RBC管型
```

> **肾小球来源由证据链支持，不由某个疾病名称直接决定。**

（边界：明显蛋白尿增加肾小球来源概率；没有大量蛋白尿不能单独排除。）

---

<!-- kianos:kp id="urinary-b06-kp09" -->

## KP09｜RBC形态不是单独金标准：证据组合决定“是否支持肾小球来源”

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：RBC单轴边界｜严重屏障例外｜管型/蛋白组合｜疾病名≠来源

Study强调：严重肾小球屏障损伤时，尿 RBC 不一定都呈典型变形，因此：

> **“RBC不变形”不能在所有情境下绝对排除肾小球来源。**

Current 判断顺序改为证据组合：

```text
变形 / 棘形RBC明显
或RBC管型
或与肾小球模式相符的蛋白尿 / 肾炎证据
→ 更支持肾小球来源

只有“有血尿”或只有某个疾病名
→ 不足以直接归类为肾小球源性血尿
```

历史 Study 在“肾小球源性血尿例子”中混入肾盂肾炎、肾结核。Current 不把该疾病名单继续作为分类规则：

- 肾盂肾炎可有血尿，但其主要疾病模型是**小管间质 / 上尿路感染**；
- 泌尿系结核也可有血尿，但其主要模型是**感染 + 尿路结构破坏 / 狭窄**；
- 只有另有变形 RBC、RBC 管型等独立肾小球证据时，才另行判断肾小球来源。

原题要求的正向疾病例子不能只靠排错替代：肾小球肾炎是主类，具体可回看K9–K11的急性肾炎、急进性肾炎、IgA肾病等。某些肾病综合征病理类型也可伴肾小球性血尿，但“肾病综合征”不等于每例都血尿。感染性疾病定位分别在K8/K13；本Block负责把证据与结构对应。

# 5｜WBC与管型：细胞出现 ≠ 管型形成

<!-- kianos:kp id="urinary-b06-kp10" -->

## KP10｜脓尿 vs 白细胞管型：一个说明尿中有WBC，一个提示肾内形成圆柱

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：脓尿vsWBC管型｜形成位置/基质｜疾病2组｜下尿路边界｜非必要/非充分

```text
脓尿
= 尿中WBC数量增多

白细胞管型
= WBC在远端小管 / 集合管内
  与蛋白等凝固成圆柱
```

Study关联：

- 白细胞管型：肾盂肾炎、肾脏免疫反应接口；
- 膀胱 / 下尿路炎症可有脓尿，但细胞没有在肾小管内凝固，因此可无白细胞管型。

> 白细胞管型不等于脓尿；脓尿也不保证一定有白细胞管型。白细胞管型是支持肾实质 / 小管间质受累的证据，不是“有肾盂肾炎就必须出现”的必要条件。

<!-- kianos:kp id="urinary-b06-kp11" -->

## KP11｜五类管型地图：红、白、蜡、上皮、脂肪

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：形成位置/材料｜管型5类→位置/病因｜预后/小管坏死/肾病接口

管型由蛋白质、细胞和细胞碎片等在**远端肾小管、集合管**中凝固，形成圆柱形蛋白聚体。

| 管型 | Study提示 |
|---|---|
| 红细胞管型 | 强支持肾小球性 / 肾实质性出血接口 |
| 白细胞管型 | 支持肾实质 / 小管间质炎症，如肾盂肾炎、肾脏免疫反应 |
| 蜡样管型 | 肾单位长期阻塞、肾衰竭、严重小管病变；预后差 |
| 上皮细胞管型 | 肾小管上皮损伤 / 坏死接口 |
| 脂肪管型 | 肾病综合征 / 脂质尿接口 |

这些是证据身份，不等于已完成病因诊断。

## KP12｜RBC / WBC 与管型的两条边界

> **讲义定位 →** 内科 Lecture P144。  
> **主提示**：RBC/WBC与管型2区别｜入小管+基质2条件｜上/下尿路定位｜病因反推边界

### 边界1

```text
尿中有RBC
≠
一定有RBC管型
```

RBC必须进入肾小管，并在蛋白基质中凝固，才形成管型。

### 边界2

```text
尿中有WBC
≠
一定有WBC管型
```

下尿路炎症可直接把WBC加入尿液，但没有经历肾小管内凝固。

定位价值：

- 细胞本身：可来自肾或尿路多个层级；
- 细胞管型：更支持肾实质 / 肾小管内形成。

（边界：管型提供位置证据，但仍需结合蛋白、Cr、培养、影像和病理。）

## KP13｜总肾功能与尿量：Cr / BUN看总体，尿量是动态输出

> **讲义定位 →** 内科 Lecture P144；Recall K1/K4。  
> **主提示**：总功能2项/侧别边界｜尿量3类｜尿渗/比重定位｜AKI-CKD接口

按本节 Study：

- 血肌酐 Cr；
- 血尿素氮 BUN；

主要反映**总肾功能**，不能告诉你哪一侧肾功能差。

尿量与尿渗透压是动态输出：

- 少尿 / 无尿：灌注、GFR、肾实质或梗阻接口；
- 多尿：渗透性利尿、水利尿或浓缩失败接口；

这些阈值已在K1 / K4进入MI-D；AKI / CKD完整定义与分期在K7。

## KP14｜分侧肾功能证据：肾图定量功能；CTU / IVU提供排泄与解剖侧别

> **讲义定位 →** 内科 Lecture P144；外科 P106。  
> **主提示**：Study检查3｜核素定量｜CTU/IVU解剖-排泄｜MRU/逆行边界｜总vs分侧

### 1｜当前 Study 的考试列表

Study列三项与“分肾功能 / 上尿路侧别”相关的检查：

1. 放射性核素肾显像 / 肾图；
2. CT尿路造影 CTU；
3. 静脉肾盂 / 尿路造影 IVP / IVU。

这个列表保留用于 306 考试识别，但三者能力不能压成完全等价。

### 2｜能力层级

**放射性核素肾显像 / 肾图**直接记录双侧肾的灌注、摄取 / 分泌和排泄曲线，可做相对 / 定量的分肾功能判断，并评估上尿路梗阻。

**CTU / IVP / IVU**主要提供：

- 左右侧肾与集合系统解剖；
- 造影剂排泄是否延迟 / 缺失；
- 上尿路通畅及侧别信息。

因此它们可以支持“哪一侧排泄 / 功能异常”的判断，但不与核素肾图的**定量分肾功能**能力等价。

### 3｜两个 Study 边界

- MRU不作为当前题纲所列的“分肾功能”标准答案；
- 逆行性肾盂 / 尿路造影可显示解剖通路，但造影剂不是由肾脏滤过 / 分泌进入尿路，因此不能据此评价肾脏自身分泌 / 排泄功能。

> 面对题目先问：是在考 Study 列表，还是在问“真正定量左右功能”的工具。前者记三项，后者优先核素肾图。

具体疾病检查层级后置 K12–K14。

## KP16｜最终病例算法：证据 → 位置 → 功能 → 病因分支

> **主提示**：证据→位置→功能8步｜蛋白/RBC/WBC/管型｜总功能/分侧｜尿三杯｜疾病4分支
