# K11｜肾病综合征分支
## 大量蛋白漏出以后，低白蛋白、水肿、高脂、高凝和感染怎样形成；传统病理索引怎样与病因层分开

> **中心问题**：当滤过屏障大量漏蛋白时，怎样从四联诊断进入并发症和治疗；又怎样用年龄、血尿、补体、LM / IF / EM把 MCD、膜性与 MsPGN / MPGN / FSGS 等传统 306 病理索引分开，同时避免把损伤模式误当成唯一病因？
>
> **Primary Study**：内科 Lecture P159、P163–165及 P167–175病例串联。
>
> **Primary Outline**：U067肾病综合征11题；U068全部19题；U070病例与继发病因3题，共 **33 / 33**。
>
> **Source boundary**：糖皮质激素、抗凝阈值、免疫抑制和饮食数字均保留当前 Study 口径作为 306 Source Precision，不把传统病理标签直接升级成现代病因或治疗 owner。继发性肿瘤、SLE、乙肝、紫癜、糖尿病等完整疾病模型仍归各自系统。

# 0｜先看屏障漏出怎样变成全身问题

B9把肾小球病分成临床综合征、三镜模式和病因三个坐标；这一块从其中“大量漏蛋白”的分支进入。可以先想同一股蛋白流：屏障留不住白蛋白，小管也收不回来，于是尿里蛋白多、血里白蛋白少。水分布、肾内潴钠、肝脂代谢和抗凝/免疫蛋白的变化，从这里向不同方向展开；水肿、高脂、血栓、感染和 AKI 不是患者必然依次经过的几个阶段。

接着把问题放回肾脏：同样是大量蛋白尿，MCD 的足突损伤和膜性的上皮下沉积并不同；系膜增生、双轨和局灶节段硬化也只先说明损伤模式。用 LM / IF / EM、临床和病因证据交叉，才能决定后续处理。共同支持治疗与当前并发症可同步考虑，不能等五型标签全部排完才处理危险。

沿下面 §1A 的同一模型展开，在对应位置恢复原完整标题和主提示；普通复习仍沿这些节点，可直接核对答案。剂量、疗程和病理细表按原 Core / 精记入口查看，当前需要的形态仍回原图。后面的覆盖、自测和完成条款各保留原用途，不作为每讲一段就暂停答题的脚本。

# 1｜Framework

本 Block 的唯一连续关系在 §1A：屏障损伤→蛋白漏出，胶体渗透/肾内钠潴留与肝代偿并行；高凝、感染和 AKI 从不同机制分叉；诊断和治疗需交叉临床综合征、LM/IF/EM 病理模式与最终病因。旧五型是考试识别索引，不是疾病发生顺序或自动处方表。

# 1A｜同一模型上的自然节点〔完整 Prompt〕


## 足细胞—基底膜屏障大量漏蛋白，肾内处理和全身代偿同时改变

肾小球滤过屏障，特别是足细胞裂孔膜/足突及相关结构失去对白蛋白的限制后，蛋白持续进入原尿，小管回收能力不能抵消大量漏出；这直接形成大量蛋白尿。血浆白蛋白因尿丢失而下降，肝脏可增加蛋白及脂蛋白合成，但通常不能完全抵消；**大量蛋白尿与低白蛋白是肾病综合征的两项诊断关键**，水肿、高脂是常见伴随的系统后果，不应把四联全部当互为必然的机械步骤。
〈蛋白漏出主链〔屏障→尿蛋白｜肝补偿/血白蛋白方向｜4后果〕〉
〈四联诊断：两项必备〔4联｜必备2/阈值｜定性边界〕〉

低血浆胶体渗透压有利于水从血管进入组织间隙，部分患者因有效循环容量下降激活 RAAS/交感而继发潴钠；另一些患者存在肾小管原发潴钠。两种水肿入口因个体和疾病状态不同可并存，不能把所有肾病性水肿都写成先低容量后 RAAS。肾炎性水肿的主要驱动则通常是 GFR 下降、钠水排出不足；两类水肿机制可以叠加，仍需看实际容量和肾功能。
〈肾病性水肿 vs 肾炎性水肿〔低胶渗→有效量/RAAS｜原发远端潴留接口｜肾炎性GFR轴〕〉

肝脂蛋白合成变化与脂蛋白代谢/清除受损，分别促进血浆胆固醇、甘油三酯异常；高脂并非“白蛋白低之后发生的下一期”，而是与低白蛋白共同受蛋白丢失和肝脏补偿影响。
〈高脂血症：TG分解少，胆固醇合成多且清除少〔TG机制1｜胆固醇机制2｜肝代偿接口〕〉

## 四种全身风险从不同失衡轴出现，不是患者必然经过的顺序

血液高凝倾向由尿中抗凝蛋白流失、凝血/纤溶系统改变、血液浓缩与血管内皮因素等共同推动；尤其膜性肾病可出现肾静脉血栓风险，但旧白蛋白数值不是不分患者的绝对抗凝开关。出现突发腰痛、血尿/蛋白变化或肾功能波动时需要按原证据检查，而不是只凭肾病名称作诊断。
〈四类并发症：感染、蛋白脂代谢、血栓、AKI〔4类｜机制/危险｜课程2误项｜对应KP〕〉
〈血栓为什么发生〔内皮｜浓缩/黏度｜凝抗纤溶｜血小板｜药物2〕〉
〈肾静脉血栓：膜性最易，肾静脉最常〔易栓病理/部位｜临床4组｜检查2角色｜Alb阈值/抗凝条件〕〉

免疫球蛋白/补体等抗感染防御丢失以及部分治疗带来的免疫抑制增加感染风险，预防与实际感染治疗不同，**不能所有肾病综合征患者常规预防性使用抗菌药**。另外有效循环不足、肾间质水肿、管型阻塞或相关肾实质损伤可造成 AKI；经典 MCD 可出现此类并发症，但肾病表现与 AKI 并非一一对应。蛋白与脂类代谢变化、血栓、感染和 AKI 需平行监测。
〈感染：不预防性用抗生素〔感染风险3｜预防性抗菌边界｜发生后处理｜激素调整〕〉
〈AKI：最常见于MCD〔最常病｜表现2｜扩容利尿反应｜机制2接口〕〉

## 先根据病因和危险程度选择共同支持，再按实体决定特异治疗

控制容量/水肿、血压与蛋白尿，识别血栓/感染等并发症，是跨病因支持性任务；如何使用激素、免疫抑制剂或其他药物，要回到原发实体、继发因素、当前肾功能与风险分层。MCD 的经典激素敏感倾向、部分原发 FSGS 对激素不敏感、膜性肾病的病程和抗体信息可以帮助识别，**绝不能由一张“形态五型→统一处方”直接推出治疗**。课程旧足量、缓减、维持、药名和限盐/限蛋白数字继续留在原 Core/Source/Precision，不替代当前处置边界。
〈激素原则：当前 Study 的考试 Precision〔起始剂量｜足量疗程｜减量原则｜维持｜疗效判断时点｜不当现代通用模板〕〉
〈传统初治配对：考试倾向 ≠ 从形态直接推出治疗〔初治5类配对｜MCD/FSGS反应｜病因边界〕〉
〈难治与支持治疗〔Source药物接口｜降蛋白｜盐/蛋白｜白蛋白条件｜病因优先〕〉

## LM/IF/EM 把共享足突损伤分为不同形态，再回病因

一种经典入口是微小病变性肾病（MCD）：儿童常见，光镜肾小球可基本正常，IF 没有特异免疫沉积，电镜显示弥漫足突融合；选择性蛋白尿是典型倾向，但课程的“电荷屏障”仅为帮助理解的经典描述，不排除多层足细胞机制。**足突融合是损伤反应，并非 MCD 独有的病因指纹。**
〈MCD三名字 + 三个最核心身份〔3名｜人群｜LM｜EM｜IF｜免疫类型〕〉
〈MCD选择性蛋白尿：保留经典电荷模型，但不把它当唯一机制〔经典电荷vs足细胞机制｜蛋白选择性｜典型NS｜老年例外〕〉

另一入口是膜性肾病：上皮下免疫沉积及足细胞损伤导致 GBM 反应性增厚和钉突，IF 常呈颗粒；原发性膜性常与 PLA2R 等足细胞抗原有关，而继发病因需要并行排查。两者可有足突融合、大量蛋白尿，却在 LM、IF、EM、抗体与血栓风险上不同，不能把“同有足突融合”当成同一种疾病。
〈膜性肾病：中老年 + PLA2R + GBM增厚〔人群｜复合物形成/抗原部位｜LM4词｜EM位置｜IF｜抗体｜并发症〕〉
〈MCD vs 膜性：都有足突融合，但不是同一病〔年龄｜LM｜IF/EM沉积｜蛋白选择性｜血栓〕〉

系膜增生是一种系膜细胞/基质变化的形态；膜增生样改变表现为毛细血管壁重塑及基底膜双轨，可由免疫复合物或补体调控异常等不同背景造成，传统 MPGN 三型仍用于考试辨识沉积的超微位置，却不天然代表三种互斥病因。FSGS 的“局灶”指部分肾小球，“节段”指同个肾小球一部分袢硬化；可由原发足细胞疾病、适应性继发或遗传等机制产生。系膜增生、双轨、局灶节段硬化都是要继续追查病因的**模式**，不是光镜一看即可自动决定激素敏感性。
〈MsPGN：先认系膜增生模式，再问病因〔LM模式｜传统人群/临床｜血尿方向｜pattern≠etiology｜易混MPGN〕〉
〈MPGN：双轨是形态模式，不是唯一病因〔双轨形成｜传统人群/临床｜C3方向｜pattern≠etiology｜三型后接KP19〕〉
〈MPGN传统三型：保留306沉积索引，现代病因层不在这里展开〔MPGN传统3型｜EM位置/形状｜最常型｜传统分型vs病因〕〉
〈FSGS：局灶+节段硬化先是损伤模式〔两个“部分”｜LM｜EM｜临床接口｜原发/遗传/继发背景〕〉
〈足突融合三类：共同证据，不是共同病因〔自己摸足3｜共同证据｜各自差异1｜不能反推病因〕〉

## 用传统五型当快速识别索引，而不让它取代临床—病理—病因交叉

病例先确定是否满足大量蛋白尿与低白蛋白、当前容量/GFR/血栓感染风险，再读年龄、血尿、补体与 LM/IF/EM；把 MCD、膜性、系膜增生、膜增生和 FSGS 的经典识别要点放到对应证据位置，而非五个同时并列的单病因节点。继发性免疫、肿瘤、感染、代谢和遗传背景应继续向各自疾病 owner 追索；年龄只改变先验概率，不代替确诊和风险分层。诊断、处理与后续监测反馈至蛋白尿、白蛋白、GFR和并发症，而不是令治疗决定疾病定义。
〈传统五类病理考试索引：识别形态，不直接等于病因〔传统病理5索引｜各自最强识别组｜模式vs病因｜三镜回查〕〉
〈继发性肾病综合征：年龄只用于加权，不替代病因证据〔儿童青年组｜中老年组｜肿瘤/感染/免疫接口｜病理+病因〕〉
〈K11病例算法：综合征→模式→病因→治疗〔四联→并发4类｜年龄/血尿/C3｜LM-IF-EM｜模式→病因→治疗〕〉

# 2｜Memory Routing

## MI-G

- 四联及两个必备阈值；
- 水肿与高脂形成机制；
- 四类并发症；
- 膜性最易血栓，肾静脉最常；
- 突发腰痛、血尿/蛋白尿加重、肾大；
- 首选B超、最佳肾静脉造影、白蛋白阈值按 Source；
- 不预防性用抗生素；
- AKI最常见于MCD；
- 当前 Study 的激素足量、缓减、维持原则作为考试 Precision；
- MCD典型激素敏感；传统“原发FSGS”相对更易激素抵抗，但 FSGS lesion 本身不自动规定治疗；
- MCD：儿童、LM基本正常、足突融合、无典型沉积、选择性蛋白尿方向；
- 膜性：中老年、GBM增厚、钉突、上皮下沉积、PLA2R、血栓；
- MsPGN：系膜增生是 LM 模式，不等于单一病因；
- MPGN：双轨是形态模式，需再结合 IF / EM 和病因；
- FSGS：局灶 + 节段 + 硬化是损伤模式，可有不同病因背景；
- 足突融合三类只是共同超微证据。

## MI-D

- 全部剂量、疗程和复治方案；
- 免疫抑制剂完整药名；
- 预防性抗凝和溶栓细节；
- MCD 60岁后小高峰；
- 膜性病理各阶段染色；
- MPGN I/II/III传统超微细节；
- FSGS五种亚型；
- 儿童青年和中老年继发病因完整口诀；
- 原发性肾病综合征传统病理总表。

# 3｜共同模型

<!-- kianos:kp id="urinary-b11-kp01" -->
## KP01｜四联诊断：两项必备

> **主提示：4联｜必备2/阈值｜定性边界**

### 快速核对

1. 大量蛋白尿：`>3.5 g/d`，定性常 `+++`及以上；
2. 低蛋白血症：白蛋白 `<30 g/L`；
3. 明显水肿；
4. 高脂血症。

大量蛋白尿和低白蛋白血症为当前 Study 必备。仅有“水肿”或“蛋白尿”不能自动确诊。

---

<!-- kianos:kp id="urinary-b11-kp02" -->
## KP02｜蛋白漏出主链

> **主提示：屏障→尿蛋白｜肝补偿/血白蛋白方向｜4后果**

### 快速核对

```text
滤过屏障受损
→ 大量蛋白进入尿
→ 肝脏增加合成仍赶不上丢失与分解
→ 低白蛋白血症
→ 胶体渗透压下降、水肿
+ 肝合成脂蛋白增加
+ 高凝
+ 感染风险
```

---

<!-- kianos:kp id="urinary-b11-kp03" -->
## KP03｜肾病性水肿 vs 肾炎性水肿

> **主提示：低胶渗→有效量/RAAS｜原发远端潴留接口｜肾炎性GFR轴**

### 快速核对

肾病综合征：

```text
大量蛋白尿
→ 低白蛋白
→ 血浆胶体渗透压下降
→ 液体进入组织
→ 有效循环量下降
→ RAAS / ADH激活
→ 水钠进一步潴留
```

上图是underfill机制。课程另保留原发远端肾单位水钠潴留；overfill时有效循环量可正常或增加，RAAS并不固定升高，不能把整类肾病综合征都画成低血容量。与K9 KP14同一条件，治疗扩容/利尿须先辨容量。

肾炎性水肿主要是 GFR下降导致水钠潴留。

---

<!-- kianos:kp id="urinary-b11-kp04" -->
## KP04｜高脂血症：TG分解少，胆固醇合成多且清除少

> **主提示：TG机制1｜胆固醇机制2｜肝代偿接口**

### 快速核对

- 高甘油三酯：主要与分解减少有关；
- 高胆固醇：肝合成 LDL-C 增加 + LDL 清除减少；
- 高脂不是独立偶发现象，而是蛋白丢失后肝脏代偿与脂代谢改变的一部分。

---

<!-- kianos:kp id="urinary-b11-kp05" -->
## KP05｜四类并发症：感染、蛋白脂代谢、血栓、AKI

> **主提示：4类｜机制/危险｜课程2误项｜对应KP**

### 快速核对

当前 Study固定：

1. 血栓及栓塞；
2. 蛋白质及脂代谢紊乱；
3. 感染；
4. 急性肾损伤。

## KP06｜血栓为什么发生

## KP07｜肾静脉血栓：膜性最易，肾静脉最常

膜性肾病最易发生血栓

# 5｜治疗

<!-- kianos:kp id="urinary-b11-kp10" -->
## KP10｜激素原则：当前 Study 的考试 Precision

> **主提示：起始剂量｜足量疗程｜减量原则｜维持｜疗效判断时点｜不当现代通用模板**

### 快速核对

当前 Study：

- 泼尼松 `1 mg/kg/d`；
- 起始足量 `8–12周`；
- 缓慢减量；
- 长期维持约半年；
- 4周尿蛋白仍+++：继续原剂量；
- 8周仍无效：进入加用环磷酰胺等分层。

这些数字继续作为 306 题源 Precision 保留，但**不把一个统一激素模板外推到所有现代肾病综合征病因 / 病理模式**。真正治疗 owner 必须先明确具体疾病实体和病因背景。

<!-- kianos:kp id="urinary-b11-kp11" -->
## KP11｜传统初治配对：考试倾向 ≠ 从形态直接推出治疗

> **主提示：初治5类配对｜MCD/FSGS反应｜病因边界**

### 快速核对

当前 Study 的传统考试配对继续保留：

**初治单用激素：**

- MCD；
- MsPGN；
- FSGS。

**初治激素 + 环磷酰胺：**

- 膜性肾病；
- MPGN。

复治：当前 Lecture统一进入激素 + 环磷酰胺方向。

但 learner-canonical 必须多加一层：

```text
先明确具体疾病实体 / 病因背景
→ 再谈免疫抑制
```

高价值稳定倾向：

- **MCD 典型激素敏感**，继续作为 306 核心识别；
- 传统“原发 FSGS”比 MCD 更易激素抵抗 / 反应较差；
- **FSGS lesion 本身只是局灶+节段硬化的损伤模式**，可有原发、遗传、继发 / 适应性等背景，不能写成“看到 FSGS 病理 = 一律按原发 FSGS 激素方案”；
- MsPGN / MPGN 也先是形态模式，具体治疗必须回病因层。

因此上面的五类配对属于 **Source-specific exam Precision**，不是通用 Current 治疗算法。

## KP12｜难治与支持治疗

> **主提示：Source药物接口｜降蛋白｜盐/蛋白｜白蛋白条件｜病因优先**

### 快速核对

当前 Study列：

- 常用免疫抑制剂：环磷酰胺；
- 难治性接口：环孢素、吗替麦考酚酯；

稳定边界：支持治疗可作为共同层；免疫抑制方案则必须回具体病因 / 疾病 owner，不能仅按一个 LM pattern 推出。

## KP13｜MCD三名字 + 三个最核心身份

<!-- kianos:kp id="urinary-b11-kp14" -->
## KP14｜MCD选择性蛋白尿：保留经典电荷模型，但不把它当唯一机制

> **主提示：经典电荷vs足细胞机制｜蛋白选择性｜典型NS｜老年例外**

### 快速核对

当前 Study 的经典考试模型：

```text
电荷选择性受损
+ 大小 / 机械屏障相对保留
→ 以白蛋白漏出为主
→ 选择性蛋白尿
→ 典型肾病综合征
→ 几乎无血尿和高血压
```

这条用于306识别继续保留；但机制边界回看本肾脏系统K2的滤过屏障：**MCD 的稳定结构/功能身份是足细胞与裂隙膜屏障功能异常、足突融合**，不能把疾病机制简化成“某一个电荷分子缺失”。经典大小 / 电荷选择性是学习模型，不是唯一现代分子解释。

60岁后可出现发病小高峰，并可更常伴高血压、肾功能损害；不能把“儿童病”绝对化。

## KP15｜膜性肾病：中老年 + PLA2R + GBM增厚

> **主提示：人群｜复合物形成/抗原部位｜LM4词｜EM位置｜IF｜抗体｜并发症**

### 快速核对

- 中老年最常见的肾病综合征；
- 原位免疫复合物方向；
- GBM明显增厚；
- 钉状突起、齿梳样、虫蚀样空隙；

- 最易并发肾静脉血栓。

（边界：经典形态身份稳定；原发 / 继发与具体抗原层仍需后续病因证据。）

# 7｜系膜、双轨与硬化

<!-- kianos:kp id="urinary-b11-kp17" -->
## KP17｜MsPGN：先认系膜增生模式，再问病因

> **主提示：LM模式｜传统人群/临床｜血尿方向｜pattern≠etiology｜易混MPGN**

### 快速核对

核心 LM 模式：

- 系膜细胞增生；
- 系膜基质增多。

当前306 Study的传统“原发性MsPGN”识别：课程列为青少年最常见的肾病综合征，主要呈肾病综合征并常伴血尿。这里是课程年龄/病理索引，不将不同地区或病因构成的流行病学一律套成同一排序。

但 learner-canonical 必须明确：

> **Mesangial proliferative pattern 是形态描述，不是一个单病因标签。**

同类系膜增生模式可出现在 IgA、狼疮等不同免疫性疾病背景。遇到该 LM 后要继续看 IF / EM、临床和系统性病因，不从“系膜增生”一步跳到唯一疾病。

---

<!-- kianos:kp id="urinary-b11-kp18" -->
## KP18｜MPGN：双轨是形态模式，不是唯一病因

> **主提示：双轨形成｜传统人群/临床｜C3方向｜pattern≠etiology｜三型后接KP19**

### 快速核对

传统又称膜增生性 / 系膜毛细血管性肾炎。

```text
系膜细胞和基质增生
+ 系膜插入 / 毛细血管壁重塑
→ 毛细血管壁双轨 / 双线 / 分层征
```

双轨的空间组成：外侧为原有GBM，内侧为新形成的基膜样物质，伴系膜细胞/基质插入及毛细血管壁重塑，不能只答“有两条线”而漏掉两侧是谁。

当前Study的传统考试组合：青少年方向，常呈肾病综合征并伴血尿，C3可持续下降；与急性肾炎典型8周内恢复、Ⅱ型RPGN可持续低的对照回K10 KP05/12。

但 **MPGN 首先是 LM 损伤模式**。不同免疫复合物、补体异常等机制都可以产生类似形态，因此：

```text
看到双轨
→ 先认MPGN pattern
→ 再看IF/EM与补体/病因背景
→ 才进入具体疾病实体
```

---

<!-- kianos:kp id="urinary-b11-kp19" -->
## KP19｜MPGN传统三型：保留306沉积索引，现代病因层不在这里展开

> **主提示：MPGN传统3型｜EM位置/形状｜最常型｜传统分型vs病因**

### 快速核对

当前 Study 传统形态分型：

- Ⅰ型：最常见；系膜区 + 内皮下电子致密物；
- Ⅱ型：致密沉积物病；GBM致密层带状沉积；
- Ⅲ型：内皮下 + 上皮下沉积。

这些作为 306 LM / EM 识别索引保留。完整现代免疫复合物性 MPGN、C3 glomerulopathy 等病因重组不在当前 Source 扩写；**传统 type ≠ 唯一现代病因。**

---

<!-- kianos:kp id="urinary-b11-kp20" -->
## KP20｜FSGS：局灶+节段硬化先是损伤模式

> **主提示：两个“部分”｜LM｜EM｜临床接口｜原发/遗传/继发背景**

### 快速核对

```text
局灶
→ 部分肾小球受累（讲义以<50%表达；需考虑采样及特定分类）

节段
→ 单个肾小球的部分血管丛受累；通用“节段”不限定一定<50%

硬化
→ 受累节段玻璃样变、硬化、毛细血管闭塞
```

可伴足突融合，临床可呈肾病综合征或蛋白尿。

**FSGS lesion 是损伤模式，不单独规定病因。**可有原发、遗传、继发 / 适应性等背景。当前 306 Source 中“原发 FSGS”的经典肾病综合征与激素反应倾向继续保留，但病理看到 FSGS 后仍要问病因背景。

---

<!-- kianos:kp id="urinary-b11-kp21" -->
## KP21｜足突融合三类：共同证据，不是共同病因

> **主提示：自己摸足3｜共同证据｜各自差异1｜不能反推病因**

### 快速核对

足突融合 / effacement 可见：

1. MCD；
2. 膜性肾病；
3. FSGS。

最小对照：MCD光镜肾小球近正常、无典型免疫复合物沉积（KP13–14）；膜性有上皮下沉积及基膜改变（KP15–16）；FSGS光镜部分肾小球出现节段硬化（KP20）。足突融合只是共同超微证据，不能反推出唯一病因。

# 8｜病理总表与病例

<!-- kianos:kp id="urinary-b11-kp22" -->
## KP22｜传统五类病理考试索引：识别形态，不直接等于病因

> **主提示：传统病理5索引｜各自最强识别组｜模式vs病因｜三镜回查**

### 快速核对

| 传统索引 | 最强识别 | ontology 边界 |
|---|---|---|
| MCD | 儿童、LM基本正常、IF阴性、足突融合 | 经典实体相对稳定；仍可有继发背景 |
| 膜性 | 中老年、GBM增厚/钉突、上皮下沉积、抗PLA2R抗体 | 经典形态稳定；原发/继发需病因层 |
| MsPGN | 系膜细胞/基质增生、传统青少年/血尿方向 | 首先是系膜增生 pattern |
| MPGN | 双轨、补体/沉积位置传统索引 | 首先是 MPGN pattern，需按机制/病因再分 |
| FSGS | 局灶+节段硬化、足突融合 | 首先是损伤 pattern，可多病因 |

> 这张表用于306快速识别，不是“五个形态＝五个单病因疾病”。

原题“抓规律、记特殊”还需要下面四组入口：

- 变性/坏死：课程P164写“均有玻璃样变性”，特殊为MCD可见小管脂肪变性，RPGN及重症急性肾炎可有纤维素样坏死。玻璃样变必须分部位和阶段，肾小管蛋白重吸收滴与肾小球玻璃样硬化不是一回事，不能把课程概括解读成所有类型早期都有肾小球硬化；MCD的肾小球光镜基本正常仍须保留。
- IF：多数免疫复合物型颗粒状；抗GBM/Ⅰ型RPGN线状；MCD与Ⅲ型RPGN无特异或极弱沉积，回K9 KP09。
- EM：MCD、抗GBM/Ⅰ型RPGN及Ⅲ型RPGN无典型免疫复合物电子致密沉积；其余类型仍按病因与沉积部位判断，回K9 KP06和本Block各型。
- 可呈多种LM病理模式的是IgA肾病，不能由此丢掉系膜IgA身份，回K10 KP17。

<!-- kianos:kp id="urinary-b11-kp23" -->
## KP23｜继发性肾病综合征：年龄只用于加权，不替代病因证据

> **主提示：儿童青年组｜中老年组｜肿瘤/感染/免疫接口｜病理+病因**

### 快速核对

按Source P172补齐年龄分组：

- 儿童/青年：乙肝病毒相关性肾炎、狼疮肾炎、IgA血管炎肾炎（旧称过敏性紫癜肾炎）；
- 中老年：骨髓瘤性肾病、淋巴瘤/实体肿瘤相关肾病、糖尿病肾病、肾淀粉样变性。

这是相对多见分组，不是年龄排除规则；保留必要入口，不在本Block重复完整系统病教材。

决策：

```text
年龄 + 病史
→ 提高某类继发病因权重
→ 尿证据、血液/免疫/感染证据
→ 必要时肾穿刺明确LM/IF/EM模式
→ 再把病理模式与具体病因合并成最终诊断
```

系统性病因完整模型回对应系统。

<!-- kianos:kp id="urinary-b11-kp24" -->
## KP24｜K11病例算法：综合征→模式→病因→治疗

> **主提示：四联→并发4类｜年龄/血尿/C3｜LM-IF-EM｜模式→病因→治疗**

### 快速核对

```text
1. 确认大量蛋白尿 + 低白蛋白
2. 查水肿、高脂与血栓/感染/AKI
3. 看年龄、血尿、高血压、C3
4. 肾穿刺：
   LM / IF / EM
5. 先识别病理模式：
   MCD / 膜性经典模式
   或 MsPGN / MPGN / FSGS pattern
6. 再搜病因：
   原发 / 继发 / 遗传 / 免疫复合物 / 补体等
7. 只有疾病实体 / 病因层明确后，才决定是否以及如何免疫抑制
8. 同时处理血栓、感染、AKI、容量与蛋白尿
```
