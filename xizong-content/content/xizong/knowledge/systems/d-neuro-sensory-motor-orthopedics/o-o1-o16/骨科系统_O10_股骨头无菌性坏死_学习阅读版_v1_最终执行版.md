# O10｜股骨头无菌性坏死
## 没有感染也会“坏死”：血供中断后，修复速度追不上承重，最终从骨梗死走向塌陷与继发关节退变

# 1｜Framework

```text
上游两条病因支路 → 血供受损（不需要病原感染）
├─ 创伤：股骨颈骨折/髋脱位 → 旋股内侧分支骺外侧动脉接口
  创伤性病因：股骨颈骨折/髋脱位共同伤到“骺外侧动脉”接口〔外伤2｜关键血供1｜来自哪条动脉｜串联O7〕
└─ 全身危险因素：激素、乙醇、减压、血红蛋白病，原课双侧倾向
  非创伤危险因素：激素、酒精、减压、血红蛋白病；多为双侧〔全身4类｜血液2例｜双侧倾向〕
“通常单侧”旁注指代不明的原冲突保留，不由此图裁决

中心病理链：缺血骨梗死 → 修复/重塑与承重矛盾 → 可塌陷 → 继发关节退变
  本质：无菌性坏死=缺血造成骨梗死，不需要病原〔定义2件｜上游1｜下游3步｜易混：感染？〕
这是解释病程的机制，不是检查造成塌陷，也不是所有病例必然到终末期

临床观察旁支：髋活动受限/腹股沟深压痛/4字试验，联系病因但不单独确诊
  临床入口：髋活动受限+腹股沟深压痛+4字试验〔症状3｜4字试验共4病｜不能单独确诊〕
原4字试验另3病与AVN合计4个背景，保留原名单

影像观察旁支：在同一病程上获取证据，不插作致病步骤
早期普通X线可不敏感；核素热区中冷区、MRI双线/新月原课识别
  早期诊断：普通X线可能晚；核素看热中冷，MRI看双线/新月〔早期2检查｜核素模式4字｜MRI2征〕
原X线四期：I软骨下溶解/新月，II硬化，III塌陷，IV三种关节退变影像
  X线四期：软骨下溶解→硬化→塌陷→脱位/继发OA〔I软｜II硬｜III塌｜IV脱｜IV三影像〕
分期照当前Source保存，不拿现代分期静默替换；形态仍依原像

治疗目标回到结构状态：未塌陷保髋方向 vs 终末关节匹配失败重建方向
  股骨头坏死进入不同分期后，治疗目标为什么会从保髋转向关节重建？〔塌陷前结构｜终末关节退变｜保髋入口｜置换入口｜分期怎样改变目标〕
原课I髓芯减压/IV全髋为条件分支，II/III具体策略当前未展开，不按序数插值

同图反查病因、血供、临床与早期影像、分期及功能目标
  O10出口：先问缺血，后问塌陷；不要把“髋痛”直接等于坏死〔病因→血供｜早期影像｜分期轴｜塌陷？｜继发OA〕
普通复习原Core与全部MI精确信息可见，不强制闭卷；专业诊断/术式不由髋痛或单一影像词决定
```

中心矛盾是：**坏死骨需要修复，但股骨头持续承重。** 是否已经塌陷，直接改变治疗目标。

# 3｜正式内容与完整 Prompt

<!-- kianos:kp id="orthopedics-o10-kp01" -->
## KP01｜本质：无菌性坏死=缺血造成骨梗死，不需要病原
> **主提示：定义2件｜上游1｜下游3步｜易混：感染？**

### Detailed Expansion

当前 Lecture 直接定义为：**缺血造成骨梗死**。因此核心链为血供受损 → 骨组织死亡 → 修复/重塑异常 → 承重下塌陷，而不是病原感染。

（易混：髋结核、化脓性关节病走感染/炎症模型；O10不使用抗感染逻辑解释坏死。）

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o10-kp02" -->
## KP02｜创伤性病因：股骨颈骨折/髋脱位共同伤到“骺外侧动脉”接口
> **主提示：外伤2｜关键血供1｜来自哪条动脉｜串联O7**

### Detailed Expansion

当前 Study 强调股骨头最重要血供为**旋股内侧动脉分支的骺外侧动脉**。股骨颈骨折、髋关节脱位可损伤这一供血，因此是重要外伤性病因。

**Routing**：CORE + CONNECTION + VISUAL_ONLY + MI-G

<!-- kianos:kp id="orthopedics-o10-kp03" -->
## KP03｜非创伤危险因素：激素、酒精、减压、血红蛋白病；多为双侧
> **主提示：全身4类｜血液2例｜双侧倾向**

### Detailed Expansion

当前 Source 列：

- 糖皮质激素；
- 乙醇；
- 减压/沉箱/潜水员病（氮气栓塞接口）；
- 镰状细胞贫血或地中海贫血。

非创伤性场景可多为双侧。这里只保存 Study 名单与接口，不自行补完整发病机制。

**Routing**：CORE + SPECIAL + BOUNDARY + MI-G/MI-D

<!-- kianos:kp id="orthopedics-o10-kp04" -->
## KP04｜临床入口：髋活动受限+腹股沟深压痛+4字试验
> **主提示：症状3｜4字试验共4病｜不能单独确诊**

### Detailed Expansion

当前 Lecture：髋关节活动受限、腹股沟区深压痛、4字试验可阳性。

4字试验阳性还可见：股内收肌损伤、髋关节结核、强直性脊柱炎，因此它只是**髋区结构异常入口**，不能单独确认AVN。

**Routing**：CORE + CONFUSABLE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o10-kp05" -->
## KP05｜X线四期：软骨下溶解→硬化→塌陷→脱位/继发OA
> **主提示：I软｜II硬｜III塌｜IV脱｜IV三影像**

### Detailed Expansion

当前 Study 的X线分期：

1. **I 软骨下溶解期**：新月征；
2. **II 修复期**：硬化带；
3. **III 塌陷期**：股骨头塌陷；
4. **IV 脱位期**：Shenton线不连续、关节间隙变窄、髋臼骨赘形成。

这些影像不是四个孤立名词，而是当前课程从“坏死—修复—承重失败—关节退变”描述的分期轴；并非所有病人必然依次进展，也不能把MRI/核素检查作为其中的致病步骤。

**Routing**：CORE + VISUAL_ONLY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o10-kp06" -->
## KP06｜早期诊断：普通X线可能晚；核素看热中冷，MRI看双线/新月
> **主提示：早期2检查｜核素模式4字｜MRI2征**

### Detailed Expansion

当前 Lecture：早期诊断使用核素与MRI。

- 核素：**热区中有冷区**——有血供/修复区域可浓聚，缺血坏死区相对不浓聚；
- MRI：双线征和新月征。

原图属于必须回看的视觉真相层。

**Routing**：CORE + RECOGNITION + VISUAL_ONLY + MI-G

<!-- kianos:kp id="orthopedics-o10-kp07" -->
## KP07｜股骨头坏死进入不同分期后，治疗目标为什么会从保髋转向关节重建？
> **主提示：塌陷前结构｜终末关节退变｜保髋入口｜置换入口｜分期怎样改变目标**

### Detailed Expansion

按当前 Study：

- I期软骨下溶解/新月征阶段 → 髓芯减压术等保髋方向；
- IV期脱位、关节间隙变窄、髋臼骨赘 → 全髋关节置换术。

根本差异：**是否仍能保存未塌陷的股骨头结构，还是关节已进入不可逆匹配失败。** 当前只给I/IV方向，II/III的具体术式或阈值未展开，不自行插值；现实治疗需完整专业评估，不能由一个影像征直接决定手术。

**Routing**：CORE + BOUNDARY + MI-G

<!-- kianos:kp id="orthopedics-o10-kp08" -->
## KP08｜O10出口：先问缺血，后问塌陷；不要把“髋痛”直接等于坏死
> **主提示：病因→血供｜早期影像｜分期轴｜塌陷？｜继发OA**

### Detailed Expansion

病例顺序：

```text
危险因素/外伤
→ 髋区症状与4字试验
→ 早期MRI/核素
→ X线分期
→ 是否塌陷/关节退变
→ 保髋 vs 置换目标
```

**Routing**：CORE + CONNECTION + MI-G
