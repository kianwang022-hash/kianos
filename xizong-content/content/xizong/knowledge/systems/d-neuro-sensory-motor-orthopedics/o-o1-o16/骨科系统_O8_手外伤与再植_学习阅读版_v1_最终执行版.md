# 1｜Framework

```text
手外伤入口：生命/血供、污染与缺损同步评估，目标是活组织与将来精细功能
  手外伤出口：活组织、覆盖、长度/稳定、神经肌腱、功能位五层同时保〔存活｜覆盖｜稳定｜神经肌腱｜功能〕
五层是同时核对的职责，不是等缝好再检查神经肌腱

血供/修复轴｜清创条件下问哪些组织需立即恢复连续性，哪些可分期
  清创后的组织优先级：血供不能等，其余按污染与时机分层〔清创后4类组织怎么处理｜时间窗｜超时后血管 vs 其他｜延期/二期时点〕
物理P152右栏明确一期修复按伤后6–8h、超过12h判断；原延期约3周/二期约12周照留，未列8–12h区间不插值
血管不能因过了课程时窗而等待，所有修复为专业方向

覆盖轴｜创面条件决定直接缝合、皮片、深部外露皮瓣
  覆盖阶梯：无缺损缝、缺损皮片、深部外露皮瓣〔3创面→3覆盖｜皮瓣为什么不同？〕
不是所有缺损依次走过三阶，具体覆盖需结合血供/污染等评估

功能轴｜握球状固定服务将来抓握，与髌骨伸直位形成部位对照
  手的功能位：固定不是越直越好，而是为后续抓握留下位置〔功能位1形状｜目的｜串联：髌骨功能位？〕

离断支路在入口即识别：断面损伤范围、时间与保存共同影响再植价值
切割/碾压/撕脱是相对组织损害，不单项决定可植性
  断肢 / 指再植：断面损伤方式怎样影响可植性与成功机会？〔切割 / 碾压 / 撕脱｜组织损害范围｜相对成功机会〕
原一般6–8h、断指12–24h与无药敷料/密封/干燥/冷藏条件保留
  断肢 / 指再植：时间与保存条件怎样共同决定组织耐受？〔一般时窗｜断指特殊时窗｜敷料｜密封 / 低温｜禁忌保存方式〕
时间不是等待许可；禁忌保存按KP05具名补充：不浸泡保存、不直接接触冰块/冰水、不冷冻；不冒充原讲义名单

血供证据旁支｜Allen压迫后松尺动脉，恢复红润看侧支；苍白/阳性按原口径
  Allen试验：不是“桡动脉通不通”，而是看尺桡侧支够不够〔松谁｜红不红｜阳性=侧支？｜桡穿刺？〕
该试验的用途不代表所有创伤都要先做桡穿刺；相关操作由专业人员判断
```

# 2｜正式内容与完整 Prompt

## KP01｜清创后的组织优先级：血供不能等，其余按污染与时机分层
> **主提示：清创后4类组织怎么处理｜时间窗｜超时后血管 vs 其他｜延期/二期时点**

### Detailed Expansion

当前 Study：先清创；原PDF物理P152右栏“理顺手外伤清创修复”明确争取在**伤后6–8小时内**一期修复血管、神经、肌腱、骨组织，时窗不是从清创完成重新起算。伤后超过12小时，**血管仍应立即修复**；其余可考虑延期约3周、二期约12周修复。

来源层次：左栏正文分别给“延期（3周）、二期（12周）”；右栏说明强调在创面稳定、感染得到控制前提下，于“伤后3周左右或更晚”行二期或延期修复。左右栏对延期/二期的时点与术语表述不完全相同，分别保留；左栏3周、12周未单列起算事件，不据右栏替它们补定起点或统一术语。

关键不是背时钟，而是理解：**缺血会立刻威胁组织存活；神经/肌腱/骨功能重建可在污染与软组织条件允许时分期。**

（边界：所有时程严格按当前 Study 口径，不扩写显微外科现实方案。6–8小时及超过12小时的起算，由右栏明确为伤后。该页仍未规定8–12小时段的完整处理规则，当前Prompt要求Source已有时窗与分层，不要求新增逐小时算法，不擅自插值；这些数字不能当等待许可或自行排手术的精确规则，受伤应及时专业评估。）

**Routing**：CORE + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o08-kp02" -->
## KP02｜覆盖阶梯：无缺损缝、缺损皮片、深部外露皮瓣
> **主提示：3创面→3覆盖｜皮瓣为什么不同？**

### Detailed Expansion

- 皮肤裂伤、无缺损 → 直接缝合；
- 皮肤缺损 → 皮片移植；
- 神经、肌腱、骨关节外露 → 皮瓣（含皮下脂肪的皮肤）覆盖。

这一表的底层问题是：创面是否仅需要“盖住”，还是需要带更厚软组织覆盖保护深部结构。

**Routing**：CORE + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o08-kp03" -->
## KP03｜手的功能位：固定不是越直越好，而是为后续抓握留下位置
> **主提示：功能位1形状｜目的｜串联：髌骨功能位？**

### Detailed Expansion

当前 Source 将手固定在**握球状功能位**。它与髌骨骨折的伸直位固定一起提示：

> “功能位”不是全身统一姿势，而是让该部位未来最重要功能尽可能容易恢复。

**Routing**：CORE + CONNECTION + MI-G

<!-- kianos:kp id="orthopedics-o08-kp04" -->
## KP04｜断肢 / 指再植：断面损伤方式怎样影响可植性与成功机会？
> **主提示：切割 / 碾压 / 撕脱｜组织损害范围｜相对成功机会**

### Detailed Expansion

当前 Study 再植成功率：

```text
切割伤 > 碾压伤 > 撕脱伤
```

底层变量是断面与组织损害是否整齐、局限。此处不扩写显微吻合细节。

**Routing**：CORE + MI-G

<!-- kianos:kp id="orthopedics-o08-kp05" -->
## KP05｜断肢 / 指再植：时间与保存条件怎样共同决定组织耐受？
> **主提示：一般时窗｜断指特殊时窗｜敷料｜密封 / 低温｜禁忌保存方式**

### Detailed Expansion

- 断肢/指一般6–8小时内；
- 断指当前 Source 可延长至12–24小时；
- 保存：**无药敷料、密封、干燥、冷藏**。

**原Prompt“禁忌保存方式”的具名补充答案**（原讲义P152只列上述正向条件，下列不是讲义原名单）：

- 不把离断肢体浸在盐水/生理盐水、自来水或消毒液中保存。[北京市卫生健康委《意外伤害断指（趾）的急救》，2020-07-29](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jzjj/202007/t20200729_1964787.html)
- 不让离断肢体直接接触冰块；消毒液浸泡禁忌包括酒精、碘伏。[淄博市卫生健康委发布的市第六人民医院提示，2024-06-27](https://ws.zibo.gov.cn/art/2024/6/27/art_815_2825726.html)
- 不冷冻保存，也不把离断肢体直接置于冰水中。[北京大学首钢医院提示，北京市卫生健康委发布，2023-06-05](https://wjw.beijing.gov.cn/xwzx_20031/jcdt/202306/t20230620_3140134.html)

这些禁忌针对**离断组织的保存方式**；密封袋外用冰/冰水降温不等于组织直接接触冰/冰水，液体浸泡保存也不等于湿纱布包裹或短暂冲洗。各来源的现场清洗与敷料细节不完全相同，本处不扩写“一律不得冲洗”等额外禁忌，也不声称列尽全部临床情境。

（边界：当前课程Source未展开不同离断平面/温度下缺血耐受差异，本文件不补。原课程四条件与时窗保留，保存禁忌槽由上列具名资料补答，不能反称原讲义已有完整名单。课程一般/断指时窗不允许等待，应尽快专业急救处理和转运评估。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

<!-- kianos:kp id="orthopedics-o08-kp06" -->
## KP06｜Allen试验：不是“桡动脉通不通”，而是看尺桡侧支够不够
> **主提示：松谁｜红不红｜阳性=侧支？｜桡穿刺？**

### Detailed Expansion

Current Study 的解释：压迫后松开尺动脉，若手掌恢复红润说明尺—桡侧支沟通；若仍苍白提示侧支循环不良。**Allen试验阳性 → 禁止桡动脉穿刺。**

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o08-kp07" -->
## KP07｜手外伤出口：活组织、覆盖、长度/稳定、神经肌腱、功能位五层同时保
> **主提示：存活｜覆盖｜稳定｜神经肌腱｜功能**

### Detailed Expansion

手外伤病例按五层检查：

```text
血供与组织存活
→ 污染与覆盖
→ 骨关节稳定
→ 神经/肌腱连续性
→ 固定与未来抓握功能
```

这也是为什么单纯“把伤口缝上”不能代表手外伤处理完成。

**Routing**：CORE + CONNECTION + MI-G
