# 1｜Framework｜慢性损伤先定位“哪种结构长期受错力”，神经卡压再问“哪条神经被哪个空间夹住”

这一 Block 不按病名平铺，而先建立两条并行链。

```text
原模型两条并行链：慢损组织的负荷问题，与固定空间中命名神经的卡压问题
  慢性损伤总入口：没有一次断裂，仍可因反复负荷把结构“磨坏”〔诱因3｜结构5类｜结果3｜治疗目标3｜急性创伤边界〕
关节囊/肌腱附着/腱鞘/软骨/骨骺为五类组织，神经属于另一路，不能用同一休息策略套全部
  O11整合：先分结构慢损还是神经卡压，再看“减负还是保持活动”〔结构2路｜肩特殊1｜药物2边界｜神经4配对｜报警2类〕

结构慢损链：反复负荷/牵拉/退变 → 微损伤、炎症/粘连 → 疼痛与功能受限
一般治疗：观察/理疗/NSAIDs/局部GC边界/必要手术，按条件不固定五步人人走完
  一般治疗：先减负和理疗，再药物；两类“药物滥用”是考试边界〔一般治疗层次｜NSAID 3原则｜COX-2 2例｜GC 1禁｜两NSAID？〕
├─ 关节囊：肩周炎粘连/僵硬，外旋外展与内旋后伸两组生活动作
  粘连性肩关节囊炎：两个方向都卡住，先想到“关节囊粘连/僵硬”〔人群｜侧别｜动作2组｜本质1｜无红热｜疼痛范围边界〕
│  MRI/6–24月原自限，主动活动而非长期悬吊，失败松解方向
  肩周炎为什么不能把“疼痛”简单处理成长期不动？〔影像｜病程自限性｜主动活动｜长期固定后果｜保守失败出口｜与肩脱位对照〕
├─ 肌腱附着：伸肌反复牵拉外上髁，Mills与局部定位，限制相关异常负荷
  网球肘：前臂伸肌反复牵拉，把肱骨外上髁变成疼痛定位点〔部位1｜动作机制｜Mills｜治疗抓1｜炎症性质〕
├─ 腱鞘：狭窄滑动受阻→弹响卡顿；Finkelstein限桡骨茎突部位不套所有扳机指
  狭窄性腱鞘炎：肌腱是“车”，腱鞘是“隧道”，狭窄后就弹响卡顿〔身份2名｜表现3｜Finkelstein边界｜治疗3级｜失败→？〕
├─ 软骨：髌骨软化，限制剧烈活动/原玻璃酸钠，GC慎用条件
  髌骨软骨软化：软骨已经是问题中心，激素封闭反而是重要禁区〔限制1｜关节内药1｜GC为什么慎｜与髌骨骨折分开〕
└─ 骨骺两支
   胫骨结节：X线增大/致密/碎裂，18岁后症状可退但隆起留，原不宜GC
  胫骨结节骨软骨病：儿童骨骺在牵拉中受伤，18岁后症状可退但隆起可留〔人群/骨骺｜X线3词｜18岁后2结局｜GC禁因〕
   儿童股骨头骨软骨病：髋痛/跛行/Thomas、ECT、血供重建期，不与O10全块合并
  股骨头骨软骨病：儿童髋痛+跛行+Thomas，早期ECT，关键看血供重建期〔症状3｜Thomas｜早诊1｜关键期1｜vs O10〕

神经卡压链：空间狭窄 → 特定神经功能受损 → 感觉/运动领地及电生理验证
  慢性神经卡压地图：四个空间先配四条神经〔腕→？｜肘→？｜旋后肌→？｜梨状肌→？｜急慢边界〕
腕正中/肘尺/旋后肌桡深/梨状肌坐骨；先感觉后运动是原腕管常见观察，不泛化运动深支
腕管细展开：Phalen、桡侧3指中指甚/抖腕、鱼际/对掌与电生理
  腕管综合征：正中神经的感觉线索先出现，晚期再看鱼际和对掌〔神经1｜Phalen｜感觉3+中指｜抖腕｜运动2｜检查1〕
根与神经鉴别：皮节肌节反射 vs 命名领地和固定空间，按需回N11不设全块门槛
  卡压 vs 神经根：命名神经领地对“皮节+肌节+反射”〔卡压3证据｜根3证据｜脊柱诱发｜局部空间｜肩/手/坐骨样痛〕

回原两路比较：减异常负荷或保持活动取决于结构；进行性萎缩/固定功能缺失需专业评估
全部药名/时程/条件仍在Core与精记，实际注射/康复不由模型生成个人处方
```

## KP01｜慢性损伤总入口：没有一次断裂，仍可因反复负荷把结构“磨坏”
> **主提示：诱因3｜结构5类｜结果3｜治疗目标3｜急性创伤边界**

### Detailed Expansion

当前 System 的慢性损伤主模型是：

```text
重复受力 / 牵拉 / 摩擦或软组织退变
→ 局部微损伤、无菌性炎症、粘连或狭窄
→ 疼痛 + 活动受限 / 神经功能异常
```

常见受累对象包括：

- 关节囊；
- 肌腱与附着点；
- 腱鞘；
- 关节软骨；
- 儿童骨骺；
- 狭窄空间内的周围神经。

第一轮不要先背病名，先问：**哪个结构在什么动作中持续受力？**

（边界：突然骨折、脱位、韧带断裂、神经断裂仍归 O2/O5/O6–O9 的急性创伤链。）

**Routing**：CORE + CONNECTION + MI-G

## KP02｜一般治疗：先减负和理疗，再药物；两类“药物滥用”是考试边界
> **主提示：一般治疗层次｜NSAID 3原则｜COX-2 2例｜GC 1禁｜两NSAID？**

### Detailed Expansion

当前 Lecture 的一般治疗次序：

1. 临床观察；
2. 理疗；
3. NSAIDs；
4. 糖皮质激素局部使用边界；
5. 必要时手术。

NSAIDs：

- 单独使用；
- 短期间断使用；
- 当前 Study 给出选择性 COX-2 抑制剂塞来昔布、美洛昔康，以减少胃黏膜损害；
- **不建议联合两种 NSAIDs**：意义不大而不良反应增加。

糖皮质激素：当前 Study 强调**不能多次反复使用**；不同慢性损伤还有更严格例外，见KP07–08。以上药物与注射配对为课程范围，不能直接用作个人自行用药/注射方案；原剂量与具体操作未展开不补猜。

## KP03｜粘连性肩关节囊炎：两个方向都卡住，先想到“关节囊粘连/僵硬”
> **主提示：人群｜侧别｜动作2组｜本质1｜无红热｜疼痛范围边界**

### Detailed Expansion

当前 Study 的稳定识别点：

- 女性多见；
- 左侧多见；
- 肩关节**外旋、外展**时疼痛和受限，典型场景是梳头；
- **内旋、后伸**也疼痛和受限，典型场景是挠背；
- 软组织退变、肩盂肱关节囊粘连和僵硬构成主体。

病例里要抓“**主动生活动作明显受限 + 慢性疼痛**”，而不是看到肩痛就叫肩周炎。原Prompt“无红热”当前展开未给对应明确答案，本轮无匹配原页，不将提示词自身当作已核医学结论。

当前 Lecture 还提示肩周炎疼痛可向周围放射，但典型情况下不应只凭远端手麻来下诊断；若出现明确命名神经或神经根分布，应回到 O4/N11/O11 卡压坐标重新定位。

**Routing**：CORE + RECOGNITION + CONFUSABLE + MI-G

<!-- kianos:kp id="orthopedics-o11-kp04" -->
## KP04｜肩周炎为什么不能把“疼痛”简单处理成长期不动？
> **主提示：影像｜病程自限性｜主动活动｜长期固定后果｜保守失败出口｜与肩脱位对照**

### Detailed Expansion

当前 Study：

- 软组织退变 → **MRI** 用于诊断和鉴别；
- 病程具有自限性，约 **6–24个月**；
- 每日进行肩关节**主动活动**；
- **不能用三角巾长期悬吊固定**；
- 无效时可行关节镜松解术。

为什么“疼就固定”在这里是错方向？

```text
关节囊本已粘连/僵硬
→ 再长期不活动
→ 肩部功能更难恢复
```

//若已学 O6，可用肩脱位复位后的固定场景做对照；未学 O6 不阻塞本机制形成。同样是肩痛，病变身份和功能目标不同。

（易混：X线出现明显关节间隙变窄、软骨下骨改变、边缘骨赘时，应优先考虑关节退变模型而不是把所有慢性肩痛归肩周炎。）

**Routing**：CORE + CONFUSABLE + CONNECTION + MI-G + MI-D

## KP05｜网球肘：前臂伸肌反复牵拉，把肱骨外上髁变成疼痛定位点
> **主提示：部位1｜动作机制｜Mills｜治疗抓1｜炎症性质**

### Detailed Expansion

当前 Lecture：

```text
击球等动作反复牵拉前臂伸肌肌腱
→ 肱骨外上髁附着处反复受力
→ 无菌性炎症
→ 肘外侧痛
```

识别体征：**Mills 征**。

治疗主轴不是记一长串药物，而是**限制腕关节相关活动**，降低持续牵拉。

**Routing**：CORE + RECOGNITION + MI-G

<!-- kianos:kp id="orthopedics-o11-kp06" -->
## KP06｜狭窄性腱鞘炎：肌腱是“车”，腱鞘是“隧道”，狭窄后就弹响卡顿
> **主提示：身份2名｜表现3｜Finkelstein边界｜治疗3级｜失败→？**

### Detailed Expansion

当前 Study 的识别：

- 弹响指 / 扳机指；
- 痛性结节；
- 活动时弹响、卡顿和疼痛；
- Finkelstein 征被放在本段，Lecture 特别提示主要对应桡骨茎突部位的狭窄性腱鞘炎。

处理顺序：

```text
限制活动
→ NSAIDs
→ 局部糖皮质激素注射（当前Source：腱鞘邻近骨膜）
→ 无效：腱鞘切开减压
```

第一轮记“狭窄导致滑动受阻”，再挂治疗层级，不需要把所有腱鞘解剖扩写成新章节。

**Routing**：CORE + SPECIAL + RECOGNITION + BOUNDARY + MI-G + MI-D

## KP08｜胫骨结节骨软骨病：儿童骨骺在牵拉中受伤，18岁后症状可退但隆起可留
> **主提示：人群/骨骺｜X线3词｜18岁后2结局｜GC禁因**

## KP12｜卡压 vs 神经根：命名神经领地对“皮节+肌节+反射”
> **主提示：卡压3证据｜根3证据｜脊柱诱发｜局部空间｜肩/手/坐骨样痛**

### Detailed Expansion

进入 O11-LG05 时，如 N11 已形成可直接 reactivation：

- 神经根病变：皮节 + 肌节 + 相应反射，常有颈肩或腰部向肢体放射，并可被脊柱动作/牵拉诱发；
- 单根周围神经病变：感觉和运动落在该命名神经领地，更容易与局部创伤或卡压空间对应。

若 N11 尚未形成，也只补这一鉴别所需的最小“根 vs 命名神经”语言；不得把 N11 变成 O11 whole-Block gate。

因此：

- 肩痛不能自动等于肩周炎；
- 手麻不能自动等于腕管；
- 坐骨神经样痛不能自动等于梨状肌综合征。

当前只做定位边界，不重新教学 O4/N11 的颈腰椎疾病正文。

**Routing**：CONFUSABLE + CONNECTION + BOUNDARY + MI-G

## KP13｜O11整合：先分结构慢损还是神经卡压，再看“减负还是保持活动”
> **主提示：结构2路｜肩特殊1｜药物2边界｜神经4配对｜报警2类**

### Detailed Expansion

普通复习与病例分析均按同一两路走，只有明确自测才隐藏答案：

```text
局部结构疼痛/活动受限
→ 关节囊 / 肌腱附着 / 腱鞘 / 软骨 / 骨骺
→ 找反复动作与定位体征

感觉异常/无力
→ 是否符合命名周围神经
→ 找固定卡压空间
→ 体征 + 电生理
```

治疗思想也不能一概“休息”：

- 重复牵拉/剧烈活动常需减负；
- 粘连性肩关节囊炎反而要求维持主动活动，不能长期三角巾悬吊；
- 神经卡压若出现进行性肌萎缩、固定性功能缺失，应进入更高层级评估，而不是只做对症止痛。

**Routing**：CORE + CONNECTION + MI-G
