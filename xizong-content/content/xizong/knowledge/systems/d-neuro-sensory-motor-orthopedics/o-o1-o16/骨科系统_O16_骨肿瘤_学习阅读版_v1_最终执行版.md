# 1｜Framework｜五步缩小候选，再用活检确认

面对骨痛、肿块或病理性骨折，不先问“是不是骨肉瘤”，而按：

```text
原五步候选模型：侵袭性 → 年龄 → 骨内位置 → 影像/基质 → 证据与范围
  O16整合：面对骨痛 / 肿块 / 病折，五步候选链怎样闭合到活检与危险门禁？〔侵袭性｜年龄｜骨内位置｜影像 / 基质｜全身范围｜最终证据｜Danger Gate｜所有权边界〕
这些是证据核对次序，病折/神经压迫危险从入口即查，不等所有命名或活检结束

Step 1｜侵袭性比较：速度/边界/破坏/皮温静脉/疼痛/皮质/骨膜/硬化/病折/扩散全部原轴
  良恶性入口：速度、边界、疼痛、皮质、骨膜、硬化、病折、扩散比较轴〔比较轴｜良性特殊痛1｜恶性最显著症状1｜骨膜反应边界〕
良性夜痛反例骨样骨瘤；骨膜反应非恶性专属，无反应亦不保证良性
  骨膜反应能告诉你什么，又为什么不能单独当病名？〔反应类型｜生长速度 / 刺激｜感染反例｜无反应反例｜与年龄、部位、基质合用〕

Step 2/3｜年龄—骨段构成候选地址，不是各肿瘤前后演变
  年龄—骨段矩阵：看到年龄和骨内位置后，候选集合怎样收窄？〔儿童｜青少年｜20–40岁｜中老年｜骨端 / 干骺 / 骨干｜手足 / 骨盆 / 颅骶特殊部位〕
每个候选同时挂Step4形态与Step5病理/处理条件，原医疗知识不另拆名单课
├─ 青少年干骺端外生：骨软骨瘤皮质连续/髓腔通，骨骺闭合后稳定自然史
  骨软骨瘤：怎样用年龄、骨内位置、皮质 / 髓腔关系和自然史确认身份？〔年龄｜骨段｜外生形态｜皮质 / 髓腔关系｜骨骺闭合后的自然史｜处理方向〕
│  成熟后再长/痛/软组织包块等违反自然史 → 证据升级
  骨软骨瘤何时不能再按稳定良性自然史观察？〔成熟后变化｜疼痛｜软组织变化｜骨质破坏｜钙化变化｜证据升级〕
├─ 20–40骨端：巨细胞瘤偏心肥皂泡、细胞组合、交界性
  骨巨细胞瘤：怎样从年龄、骨段、膨胀性影像和组织学建立候选？〔年龄｜骨段｜破坏形态｜骨膜反应｜局部体征｜细胞构成｜生物学行为〕
│  范围/可切除性决定原局部或根治/地舒单抗；化疗文字SC01仍冲突
  骨巨细胞瘤的治疗怎样随范围与可切除性变化，Source Conflict 在哪里？〔早期局部处理｜晚期处理｜脊柱困难场景｜放疗风险｜难治药物｜化疗角色冲突〕
├─ 青少年膝周干骺端成骨：骨肉瘤瘤骨/ALP、Codman/日光，原化疗—手术—化疗
  骨肉瘤：怎样由年龄—骨段—基质—骨膜反应与转移风险完成识别？〔年龄｜骨段｜成骨证据｜骨膜反应｜治疗顺序｜肺转移评估〕
│  肺转移评估属于范围轴，不能等治疗后才看
├─ 儿童骨干/骨盆/肩胛：尤文命名/葱皮及炎症样，回骨髓炎鉴别与病理
  尤文肉瘤：怎样与骨髓炎区分，并由年龄、部位、骨膜和全身表现建立候选？〔命名｜年龄｜骨段 / 特殊部位｜骨膜反应｜全身炎症样表现｜治疗组成｜敏感性〕
├─ 手足短骨/骨盆软骨基质 vs 颅表骨瘤：部位、钙化、敏感性原配对
  软骨瘤、软骨肉瘤与骨瘤：怎样用部位、基质和治疗敏感性区分？〔三类典型部位｜基质钙化｜手术角色｜放化敏感性｜表面生长接口〕
├─ 中老年融冰淋巴瘤 vs 颅底骶尾脊索：无骨膜也可恶性，二便风险回神经轴
  淋巴瘤与脊索瘤：哪些部位、影像 / 细胞线索和行为最有区分力？〔淋巴瘤人群 / 影像 / 治疗｜脊索部位｜神经功能接口｜骨膜反应边界｜细胞与基质〕
├─ 下肢长骨骨样骨瘤：夜痛/原阿司匹林反应、小瘤巢/硬化
  骨样骨瘤为什么是“良性肿瘤常少痛”规则的重要反例？〔疼痛节律｜药物反应｜常见部位｜瘤巢 / 周围硬化｜处理方向〕
└─ 囊性/发育性候选，与恶性破坏比较
   单纯骨囊肿：年龄/干骺端/清晰透亮与原观察刮植/年龄药物条件
  单纯性骨囊肿：怎样从年龄、骨段、透亮灶形态与病折风险确认模型？〔人群｜骨段｜影像边界 / 透亮特征｜观察或手术边界｜年龄特殊处理｜病折接口〕
   动脉瘤性囊肿：分隔泡沫/出血风险，原脊柱放疗条件与儿童风险均保留
  动脉瘤性骨囊肿：怎样从分隔形态、出血风险与治疗边界区别于单纯囊肿？〔人群｜骨段｜囊腔分隔形态｜手术方向｜出血危险｜脊柱放疗边界〕
   纤维发育不良：磨玻璃、近端股骨牧羊杖、矫形方向，肿瘤样不自动恶性
  骨纤维发育不良：哪些影像、部位和畸形线索把它从囊性 / 恶性病变中分开？〔影像基质｜常见部位｜特征畸形｜处理方向｜肿瘤样边界〕

Step 4｜影像与基质共同加权：成骨/溶骨化验支持，不取代病理
  化验方向：溶骨看血钙，成骨看ALP；前列腺成骨转移酸/碱性磷酸酶都可升〔溶骨1｜成骨1｜骨肉瘤1｜前列腺2酶｜只是支持证据〕
脊柱专门空间比较：转移椎弓根/间隙、腰结核冷脓肿、OA骨赘、AS骶髂/竹节
  脊柱破坏性病变：怎样用间隙、椎弓根、冷脓肿、骨赘与骶髂关系分流？〔转移｜结核｜OA｜AS｜椎间隙｜椎弓根｜软组织 / 骨赘 / 骶髂｜神经压迫检查〕

Step 5｜确诊与范围：影像先有限候选，活检确认，治疗按身份/范围而非单一征
  证据层：影像只能缩小候选，确诊金标准仍是活检〔金标准1｜影像3任务｜病理1任务｜活检前后边界｜不要凭单征〕
转移支路：原五器官及乳腺最常见口径、ECT敏感低特异、MRI神经范围/CT引导取材
  骨转移入口：乳腺最常见；ECT敏感但不特异，脊髓受累看MRI，最终仍需影像/活检闭环〔原发5｜最常见1｜ECT优缺2｜脊髓1｜CT引导1｜椎旁静脉接口〕
脊髓/马尾危险需及时专业评估，不能机械先等ECT再做神经评估
原统一病理关系：异常克隆/发育异常→基质/破成骨反应→皮质髓腔骨膜变化→症状；影像/活检是观察验证
全部Core/精记表答案可见，MM与器官原发各回owner，源冲突与未给现代方案不猜补
```

## KP01｜良恶性入口：速度、边界、疼痛、皮质、骨膜、硬化、病折、扩散比较轴
> **主提示：比较轴｜良性特殊痛1｜恶性最显著症状1｜骨膜反应边界**

### Detailed Expansion

当前 Study 的总坐标：

| 轴 | 良性 | 恶性 |
|---|---|---|
| 生长 | 慢 | 快 |
| 边界 | 较清 | 不清 |
| 骨破坏 | 膨胀/外生 | 浸润性 |
| 血管怒张/皮温 | 少 | 多 |

| 骨皮质 | 膨胀变薄 | 被侵犯 |

| 周围硬化 | 多 | 少 |
| 病理性骨折 | 少 | 多 |
| 扩散 | 无 | 以血道为主 |

## KP02｜证据层：影像只能缩小候选，确诊金标准仍是活检
> **主提示：金标准1｜影像3任务｜病理1任务｜活检前后边界｜不要凭单征**

### Detailed Expansion

当前 Source：

- 骨肿瘤确诊金标准：**活检**；
- X线/CT/MRI用于识别位置、基质、侵袭范围和软组织/神经受累；

- CT可用于引导活检。

正确顺序：

```text
年龄+部位+影像建立有限候选
→ 评估转移与手术范围
→ 活检确认病理身份
```

## KP03｜骨转移入口：乳腺最常见；ECT敏感但不特异，脊髓受累看MRI，最终仍需影像/活检闭环
> **主提示：原发5｜最常见1｜ECT优缺2｜脊髓1｜CT引导1｜椎旁静脉接口**

### Detailed Expansion

当前 Study 列出易骨转移的原发癌：

- 乳腺癌（最常见）；
- 前列腺癌；
- 甲状腺癌；
- 肺癌；
- 肾癌。

路径：

```text
怀疑骨转移
→ 放射性核素骨扫描/ECT（敏感高、特异低）
→ 其他影像
→ 脊髓受累用MRI
→ 必要时CT引导活检
```

不同原发肿瘤的完整诊疗仍归各器官系统。

原Prompt“椎旁静脉接口”在当前Core未展开具体传播路径；本轮未取回该项匹配Source答案，保持局部未答，不以Prompt出现或通用解剖知识代替已备答案。

有脊髓/马尾压迫或进行性神经缺失时，应及时专业评估，不能把上述证据链读成必须先等骨扫描再评估神经危险。

**Routing**：CORE + CONNECTION + EVIDENCE + MI-G

> **主提示：溶骨1｜成骨1｜骨肉瘤1｜前列腺2酶｜只是支持证据**

## KP05｜骨软骨瘤：怎样用年龄、骨内位置、皮质 / 髓腔关系和自然史确认身份？
> **主提示：年龄｜骨段｜外生形态｜皮质 / 髓腔关系｜骨骺闭合后的自然史｜处理方向**

### Detailed Expansion

当前 Study：

- 青少年；
- 长骨干骺端；
- 外生性杵/疣状骨性突起；
- 与正常骨皮质连续；
- 髓腔相通；
- 可见钙化；
