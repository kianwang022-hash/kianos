# Block 5｜高血压与动脉粥样硬化
## 长期压力与内皮损伤怎样建立慢性血管病底物｜学习阅读版 v2 · 最终执行版

> **中心问题**：慢性高压与慢性内皮损伤怎样分别造成阻力血管重构和中大动脉粥样斑块，并最终引出冠脉缺血、周围血管病和心力衰竭？

# 先看两条长期损伤轴

B1–B4 已经建立正常血压、调节、内皮和止血。

先把时间从一次心跳拉长到许多年。血压长期偏高时，左心室每次都要顶着更大压力射血，肌壁可以先变厚来承担负荷，却也更耗氧、更难舒张；与此同时，细小动脉的壁逐渐变厚、管腔变窄，肾、脑和眼底的灌注就会受影响。肾缺血还可启动保盐保水、缩血管的反应，反过来继续升压。另一条变化发生在中大动脉的内膜：脂质进入，细胞吞脂，炎症与修复一起形成带纤维帽和坏死核心的斑块。斑块可以长期限制供血，也可以因破裂或侵蚀突然触发血栓。这两条损伤轴会互相影响，观察时要分别看压力、器官和病因，干预时则回到负荷与灌注，不能只盯一个血压数字。

# 总 Framework

```text
压力轴
容量 / CO / TPR长期异常 → 血压持续升高
大动脉顺应性下降 → 尤其SBP / 脉压升高
    ├─ 左室后负荷↑ → 向心性肥厚 → 舒张障碍 / 缺血 → 可失代偿
    └─ 小动脉 / 细动脉壁增厚、腔变窄 → 肾 / 脑 / 视网膜损害
         └─ 肾缺血 → RAAS↑ → 缩血管、保钠水 → 反过来加重高压
急进 / 恶性路径：纤维素样坏死 + 洋葱皮样增生 → 肾功能可迅速恶化
    （与缓进型比较，不是所有缓进型的必经终点）

内膜轴
高压 / 吸烟 / 糖脂异常等 → 内皮损伤 + 脂质进入 / 炎症
→ 巨噬细胞与SMC吞脂 → 泡沫细胞 / 脂纹
    ├─ SMC合成ECM → 纤维帽
    └─ 细胞死亡 + 脂质碎屑 → 坏死核心
→ 稳定结构偏固定狭窄；易损结构可破裂 / 侵蚀 → 血栓事件
→ 后果由冠脉、脑、肾、四肢等受累管路决定

观察：测血压、看器官、查病因，分别验证压力、损伤与上游故障。
处置：按主导变量与危险程度选择干预，回作用于容量 / CO / TPR / RAAS；
      平稳减轻负荷并保住灌注，不能把“损伤→检查→治疗”当病程。
```

# Part A｜高血压：先从长期变量异常开始

## KP01｜高血压先放回 P/Q/R/V：血压升高是共同结果，不是单一病因

> **讲义回看 →** B1 MAP、B2调节；**讲义定位 →** 内科印刷P308–314 / PDF P377–383、病理P39–41。  
> **主提示**：MAP关系｜升压4路径｜判断3层

```text
MAP ≈ CO × TPR
```

长期升压的上位路径：

- `CO↑`：HR、收缩性、回心量 / 容量增加；
- `TPR↑`：阻力血管持续收缩或结构性狭窄；
- `ECF / 血容量↑`：肾保钠保水；
- `大动脉顺应性↓`：弹性储器下降，尤其SBP / PP升高。

三个判断层：

```text
测量层：血压达到当前Study阈值了吗？
风险层：危险因素 / 靶器官 / 临床疾病有多少？
病因层：原发还是继发，主故障在哪个调节环？
```

不能因为 RAAS 能升压，就把所有高血压解释成单一路径。

## KP02｜原发性 vs 继发性：不是“有没有原因”，而是能否定位单一主病因

> **讲义定位 →** 内科印刷P308–314 / PDF P377–383。  
> **主提示**：原发vs继发｜共同变量｜搜病因6组线索｜本Block范围

原发性高血压：多因素、长期调压网络整体偏移，通常不能定位一个唯一可逆主病因。

继发性高血压：存在可定位的基础疾病 / 结构异常，但其血压最终仍通过容量、CO、TPR、RAAS或大血管力学等共同变量升高。

提高继发性病因搜索优先级的线索包括：

- 年轻起病或突然恶化；
- 顽固 / 难治；
- 明显低钾、阵发症状；
- 腹部 / 血管杂音；
- 上下肢血压显著差；
- 肾功能、尿检或内分泌异常。

本 Block 只完整到当前 Study 的肾实质、肾血管与主动脉缩窄；原醛、嗜铬、库欣后置内分泌。

## KP03｜高血压心脏病：所有体征都能回到长期左室后负荷

> **讲义定位 →** 内科印刷P308 / PDF P377；**讲义回看 →** B1心音 / 后负荷。  
> **主提示**：长期负荷/LVH｜体征6项/机制｜相对MR｜早晚功能

```text
长期高血压
→ 左室后负荷↑
→ 向心性肥厚
```

| 体征 | Study机制 |
|---|---|
| LVH / 心界向左下扩大 | 压力负荷；晚期可扩张 |
| A2亢进 | 主动脉压力高，关闭动力强 |
| S2反常 / 逆分裂 | 在左室射血/激动延迟使A2晚于P2时出现；不是高血压必有体征 |
| S4 | 肥厚心室顺应性↓，房缩更用力 |
| 抬举样心尖 | 肥厚LV持续有力冲动 |
| 心尖收缩期吹风样杂音 | 腔 / 瓣环改变 → 相对性MR |

长期压力负荷先可表现舒张障碍 / HFpEF底物，晚期可扩张失代偿；完整心衰归 B11。

## KP08｜玻璃样变：高压怎样把血浆蛋白和ECM压进细小动脉壁

> **讲义定位 →** 病理P39。  
> **主提示**：特征病变｜形成2来源｜好发处｜vs纤维素样坏死

> **细小动脉玻璃样变 / 玻璃样小动脉硬化** 是缓进型高血压特征病变。

```text
长期高压 + 内皮通透异常
→ 血浆蛋白渗入壁
+ SMC合成ECM
→ 均质嗜伊红玻璃样物沉积
→ 管壁厚、管腔窄
```

这里的两类来源是血浆蛋白与局部生成的ECM。病理P39还说明，除存活SMC合成ECM外，SMC受损后的修复组织也可由成纤维细胞补入胶原；不能把修复性基质这一路丢掉，也不能说坏死细胞自身继续分泌。

当前 Study 强调肾入球小动脉、视网膜、脾等。玻璃样变 ≠ 急进型纤维素样坏死。

## KP09｜高血压肾：双侧对称细颗粒固缩

> **讲义定位 →** 病理P39–40。  
> **主提示**：原发颗粒肾形态｜细颗粒机制｜AS大瘢痕｜肾缺血/RAAS

> **原发性颗粒性固缩肾**：双肾、对称、缩小、质硬、表面弥漫细颗粒。

```text
大量细小动脉弥漫狭窄
→ 许多小范围肾单位慢性缺血 / 萎缩 / 纤维化
→ 保存区与萎缩区细小不均
→ 细颗粒表面
```

肾动脉AS较大分支 / 开口狭窄 → 较大范围缺血 → 大瘢痕肾 / AS性固缩肾。

肾缺血又可激活RAAS，形成“高压伤肾—肾再升压”。

## KP10｜高血压脑：出血、软化、脑病是三条不同路径

> **讲义定位 →** 病理P40。  
> **主提示**：脑损害3路｜出血部位/血管｜软化本质/修复｜脑病｜Study严重度/死因

**脑出血**：当前 Study 视为高血压最严重并发症、缓进型常见死因；最常见基底节，尤其豆状核 / 内囊区域，与豆纹动脉等深穿支高压损伤和微动脉瘤破裂相关。

**脑软化**：

```text
小动脉血栓 / 闭塞
→ 局部缺血
→ 脑液化性坏死
→ 软化灶 → 胶质瘢痕接口
```

**高血压脑病**：以急性脑损害、脑水肿 / 神经症状为入口。三者不是同一病理过程。

## KP11｜高血压心与视网膜：同一高压在泵和微血管产生不同重构

> **讲义定位 →** 病理P40–41。  
> **主提示**：代偿→失代偿：壁/腔/功能｜肥厚→缺血链｜视网膜改变

```text
长期左室后负荷↑
→ 向心性肥厚
→ 壁厚、腔正常 / 偏小
→ 顺应性↓、耗氧↑、毛细血管相对密度↓
→ 舒张障碍 / 缺血
→ 失代偿后扩张 / 离心性重构
```

视网膜：小动脉狭窄、硬化、交叉压迫；严重时出血、渗出、视盘水肿。眼底临床分级见 KP06。

## KP12｜急进 / 恶性高血压：坏死性细动脉炎 + 洋葱皮样增生

> **讲义定位 →** 病理P40–41；内科印刷P309 / PDF P378。  
> **主提示**：特征2｜肾血管/肾功能｜Study死因｜缓进vs急进4轴

```text
坏死性细动脉炎
→ 纤维素样坏死

增生性小动脉硬化
→ SMC / 基底膜同心层状增生
```

## KP06｜危险分层：同一血压数字，器官风险可以完全不同

```text
血压级别
```

| 130–139和/或85–89（原页行文字） | 原页空白，不补风险级别 | 低危 | 中/高危 | 高/很高危 |

| 3级 | 高危 | 很高危 | 很高危 | 很高危 |

- 危险因素：年龄、吸烟/被动吸烟、糖耐量或空腹血糖受损、血脂异常、早发心血管病家族史、腹型肥胖/肥胖、同型半胱氨酸升高等。
- 靶器官损害：左室肥厚、颈动脉内膜中层增厚/斑块、脉搏波传导速度增快、ABI降低、CKD3期、微量白蛋白尿等。

## KP13｜高血压危象：急症 vs 亚急症看急性靶器官损害

> **讲义定位 →** 内科印刷P309 / PDF P378。  
> **主提示**：危象入口｜急症vs亚急症｜血压数值vs急性器官损害｜脑病/恶性接口

当前 Study危象常以血压突然升高、`SBP>180 或 DBP>120 mmHg` 为入口，但：

```text
有急性进行性心 / 脑 / 肾等靶器官损害
→ 高血压急症

无急性靶器官损害
→ 高血压亚急症
```

血压绝对值与急性损害程度不成正比。脑损害 / 水肿突出 → 高血压脑病；Study另保留 DBP持续≥130且肾损害突出作为恶性 / 急进型临床入口。

## KP14｜急症降压：迅速，但不能把灌注一起打掉

> **讲义定位 →** 内科印刷P309 / PDF P378。  
> **主提示**：自身调节→灌注风险｜降压3时段｜缺血时调整

```text
若突然降到正常人水平
```

# Part D｜慢性治疗：围绕主导变量和器官风险

## KP16｜生活方式与慢性目标：治疗对象不是数字本身

> **讲义定位 →** 内科印刷P310 / PDF P379。  
> **主提示**：Study目标分层｜盐量｜生活方式→变量｜各风险层共同底座

课程目标分层：一般 `<140/90 mmHg`；合并糖尿病 / 肾病 / 心衰 / 冠心病 `<130/80 mmHg`。老年单纯收缩期强调SBP：无合并症（尤其>80岁）先 `<150/90`，耐受时 `<140/90`。

原题另要求与泌尿章节对照：课程慢性肾衰一般 `<130/80`，尿白蛋白/肌酐<30 mg/g或透析时列 `<140/90`；慢性肾炎列SBP<120 mmHg、尿蛋白<1 g/d。这里保留课程各章的不同口径，具体测量条件及现行指南范围由泌尿章节说明，不能合并成所有肾病患者的统一治疗目标。

生活方式：盐 `<6g/d`；补钾 / 叶酸接口；控重、戒烟、活动、改善糖脂代谢。

```text
限盐 → ECF / 容量负荷↓
控重 / 代谢 → 交感、胰岛素抵抗、内皮损伤与AS风险↓
```

所有风险层级都需要生活方式，不是“轻症专属”。

> **讲义定位 →** 内科印刷P310–313 / PDF P379–382。

## KP18｜ABCD：先记作用层级，再记药名和禁忌

> **讲义定位 →** 内科印刷P313–314 / PDF P382–383；**讲义回看 →** B2。  
> **主提示**：ABCD作用层｜亚类｜适用/禁忌｜肾功/血钾条件

### A｜ACEI / ARB / ARNI

```text
ACEI：AngⅡ生成↓ + 缓激肽降解↓
ARB：AT1阻断
ARNI：ARB + 脑啡肽酶抑制
```

课程代表药：ACEI为普利类，ARB为沙坦类，ARNI为沙库巴曲缬沙坦。ACEI约3–4周、ARB约6–8周达最大降压作用；为课程药类概括，具体药物起效和调量仍有差异。ARB治疗剂量窗较宽。

适用：糖尿病伴蛋白尿、高血压、冠心病、慢性心衰/DCM等对应场景。

- 妊娠、双侧肾动脉狭窄、明显低血压或高钾需避用/评估；课程列Cr>265 μmol/L、K>5.5 mmol/L为不用口径，不能把单一Cr或“任何肾功能不全”当作所有RAAS药的统一永久禁忌。
- ACEI/ARB应监测Cr、K及血压；KDIGO以开始/加量后4周内Cr升幅>30%等情形触发复评，不因eGFR降到30以下自动停药。
- ACEI干咳可考虑换ARB；血管性水肿须区别于咳嗽，不能同样直接替换。ARNI禁用于既往ACEI/ARB相关血管性水肿；与ACEI换用须间隔36 h。ACEI、ARB、ARNI不重复叠加。

### B｜β阻断

先回忆激动效应：心脏β1增强收缩、加快心率与传导并增加CO；球旁β1促肾素；血管/支气管β2促舒张。阻断β1则降低HR、收缩、CO及肾素/RAAS。

课程代表为美托洛尔、阿替洛尔、卡维地洛；适合交感 / 心率 / 肾素高的青年患者，以及冠心病、快速节律、甲亢、HCM等相应场景。稳定HFrEF有降低死亡率证据的具体药物是比索洛尔、琥珀酸美托洛尔缓释剂和卡维地洛，不能把效益套给全类。

病窦、二度Ⅱ型/三度AVB（无合适起搏保护）、预激房颤及急性血流动力学不稳定等是重要限制；哮喘、变异心绞痛、雷诺应结合药物选择性和具体适应证。课程把NYHAⅣ列入不用，但不能推出所有稳定Ⅳ级患者永久禁用；开始/加量看失代偿、灌注与容量状态。课程强调体重稳定，水肿本身不等于统一绝对禁忌。长期尤其高剂量勿骤停。

### C｜CCB

二氢吡啶如硝苯地平、氨氯地平偏血管；非二氢吡啶如维拉帕米、地尔硫卓兼负性频率 / 传导 / 肌力。降低TPR，对血脂、血糖、尿酸通常无明显不利影响；适合老年 / 盐敏感、哮喘、变异、雷诺、冠心病、痛风等相应场景。维拉帕米另有快速室上性心律失常、HCM接口。非DHP在HFrEF、病窦/严重AVB和预激房颤等场景受限，这些不能整包套给氨氯地平。课程另写BPH不用CCB；应保留为课程差异，不能据此宣称所有CCB遇BPH均属绝对禁忌，需看具体药物和排尿症状。

### D｜利尿剂

早期排Na水 → ECF / CO↓；后期血管平滑肌Na / Ca改变 → 舒张、TPR↓。容量依赖 / 老年盐敏感、心衰适用；容量依赖型先利尿消肿降压，GFR<30当前Study选袢。课程列排钾与保钾利尿剂合理合用，保钾代表为螺内酯、依普利酮、阿米洛利、氨苯蝶啶；必须监测K和肾功能，不能理解成人人均应合用。痛风尽可能避免氢氯噻嗪；急性右室MI避免使前负荷进一步不足；注意低K及糖脂/尿酸变化。课程低钠时托伐普坦、高脂时优选吲达帕胺，是带条件的选择：托伐普坦排游离水，不能用于低容量低钠，也不能把高钠患者列为其一般适用人群。

## KP20｜三类继发性高血压：肾实质、肾血管、主动脉缩窄

> **讲义定位 →** 内科印刷P311 / PDF P380。  
> **主提示**：继发3类：机制→证据｜最常见｜ACEI/ARB边界｜上下肢压差

**肾实质性**：当前 Study最常见，多见慢性GN。

```text
肾实质损伤 → 水钠潴留 + 肾缺血 / RAAS↑ → BP↑
```

病理类型需肾活检。

**肾血管性**：

```text
肾动脉主干 / 大分支狭窄
→ 灌注↓ → 肾素 / AngⅡ↑
→ 缩血管 + 保Na水
```

上腹 / 背部肋脊角血管杂音；课程列肾动脉造影确诊。双侧肾动脉显著狭窄或孤立功能肾的供血动脉狭窄时，ACEI/ARB解除出球动脉收缩可使GFR明显下降，须避免/专科评估。课程原句把“肾功能已受损”一概列禁用过宽：蛋白尿CKD也可有ACEI/ARB适应证，须结合Cr变化、K、容量与血压判断，不能与KP18的条件相矛盾。

**主动脉缩窄**：上肢高压、下肢低 / 不高；可有背部尤其肩胛间区血管杂音，侧支发达时可闻持续杂音并触及侧支搏动，伴桡/肱动脉至股动脉搏动延迟。原题询问杂音与侧支部位，讲义正文只列压差；此体征说明另据ESC先心病指南补足。课程以增强CT / 造影确诊。

# Part E｜动脉粥样硬化：内膜中的脂质—炎症—修复反应

## KP21｜危险因素与脂蛋白：先确定进入内膜的脂质负荷

> **讲义定位 →** 病理P42、内科印刷P329 / PDF P400；**讲义回看 →** 生化。  
> **主提示**：危险因素｜脂蛋白/apo方向｜LDL与ox-LDL｜继发高脂4项

危险因素：中老年男性 / 绝经后女性、高脂、高血压、DM / 胰岛素抵抗、吸烟、甲减、代谢综合征等。

```text
TC / TG / LDL-C / VLDL / CM / apoB ↑ → 风险↑
HDL / apoA ↓ → 风险↑
```

当前 Study最强调 LDL-C，尤其 ox-LDL。原题要求的继发高脂四项分别为：糖尿病、高胰岛素血症、甲状腺功能减退、肾病综合征。课程危险因素题列吸烟、不列饮酒；这只是该题的选项口径，不表示饮酒无害或应为预防AS而饮酒。

## KP22｜始动环节：内皮功能异常促进脂质沉积和白细胞进入内膜

> **讲义定位 →** 病理P42–43；**讲义回看 →** B2、B4。  
> **主提示**：正常内皮功能｜损伤/脂质/黏附/单核｜炎症证据｜始动/特征细胞/最早肉眼

正常内皮是主动屏障：抗栓、舒缩、调黏附 / 迁移 / 增殖。

课程以慢性反复内皮损伤概括始动环节；这里包括功能异常，并不要求内皮先脱落或出现缺口。LDL也可经内皮细胞主动跨胞运输进入动脉壁，故“损伤后才可进入”不是必要条件。补充依据：Huang等，Nature 2019，https://doi.org/10.1038/s41586-019-1140-4。

```text
高压 / 吸烟 / 糖脂异常
→ 内皮功能 / 屏障受损
→ LDL进入内膜并氧化
→ P-selectin、VCAM-1等黏附分子↑
→ 单核 / T细胞黏附、迁入
```

巨噬、T细胞、SMC、细胞因子和MMP持续参与，所以不是静态“脂肪堆积”。病理P43还以T淋巴细胞浸润、血中CRP升高说明炎症参与；这不是将CRP单独当作AS诊断。

始动环节＝内皮损伤；特征细胞＝泡沫细胞；最早肉眼病变＝脂纹，三个问题不能混。

## KP23｜泡沫细胞与脂纹：巨噬细胞和SMC都能吞脂

> **讲义定位 →** 病理P42–44。  
> **主提示**：2来源｜受体｜最早病变

巨噬源：单核→巨噬 → 清道夫受体 / CD36 / Fc → 摄取ox-LDL → 泡沫细胞。

SMC源：中膜SMC在PDGF / FGF等作用下迁入内膜 / 增殖 → 当前Study LDL受体接口 → 吞脂 → 肌源性泡沫细胞。

本句保留病理P42的课程表述；SMC摄脂受体仍有既有Source分歧，尚未裁定统一结论。模型使用“两类细胞均可吞脂”的稳定部分，不把巨噬细胞的受体清单直接套给SMC。

大量泡沫细胞聚集 → **脂质点 / 脂纹**，肉眼黄色点状 / 条纹。

> 两类都能成为泡沫细胞，但形成纤维帽 / ECM的主力是SMC。

## KP24｜从脂纹到纤维帽与粥样坏死核心

> **讲义定位 →** 病理P44–45。  
> **主提示**：纤维帽｜坏死核心｜成分5项｜稳定性｜SMC作用2

```text
脂纹
+ SMC迁移 / 增殖
+ SMC合成胶原、蛋白多糖、弹性蛋白
→ 纤维帽 / 纤维斑块
```

```text
ox-LDL毒性
+ 泡沫 / 炎症细胞凋亡坏死
→ 脂质、细胞碎屑、胆固醇结晶等
→ 粥样坏死核心
```

原题粥样斑块五项成分：针状胆固醇结晶、钙盐沉积、淋巴细胞、泡沫细胞、肉芽组织。这份课程清单包含沉积物、炎症细胞及修复组织，不应理解成坏死核心内五种同质物质；仍以“纤维帽 + 脂质坏死核心”理解结构。

炎症细胞释放MMP等降解胶原 → 帽变薄、机械强度下降、破裂风险↑。SMC既能形成泡沫细胞，也能合成保护性纤维帽，不是单向“促坏”。

## KP25｜稳定 vs 易损斑块：固定狭窄程度 ≠ 急性事件风险

> **讲义定位 →** 病理P45–46；**讲义跳转 →** B6接口。  
> **主提示**：稳定vs易损：帽/核心/炎症/后果｜继发改变｜狭窄≠急性风险

| 类型 | 结构 | 主后果 |
|---|---|---|
| 稳定 | 帽厚、核心小、炎症较少 | 固定狭窄 / 稳定缺血 |
| 易损 | 帽薄、核心大、炎症活跃 | 破裂 / 侵蚀 → 血栓 / ACS |

继发改变：斑块内出血、破裂 / 溃疡、血栓、胆固醇栓 / 血栓栓塞、梗死、营养不良性钙化、动脉瘤、狭窄。

```text
固定狭窄程度
→ 决定慢性血流储备

斑块稳定性
→ 决定突然血栓事件风险
```

狭窄不极重但高度易损也可引起 ACS。完整ACS归 B6。

## KP26｜AS器官地图：同一内膜病变落到不同管路

> **讲义定位 →** 病理P46–47。  
> **主提示**：血管类型/轻重｜器官8处：部位→后果｜高压轴vsAS轴出口

主要累及体循环大型弹力动脉和中型肌性动脉；肺循环少见。

| 部位 | Study高频后果 |
|---|---|
| 冠脉 | 最严重；LAD最常见 → CHD / MI |
| 主动脉 | 后壁 / 分支开口，腹主动脉较重 → 动脉瘤 / 分支缺血 |
| 颈动脉 | 颈内动脉起始部 |
| 脑动脉 | MCA、基底、Willis等 → 脑萎缩、脑梗死（脑软化）、脑出血 |
| 肾动脉 | 开口 / 近端 → AS性固缩肾 / 大瘢痕肾 |
| 四肢 | 下肢多 → 缺血 / 坏疽，完整B9 |
| 肠系膜 | 肠缺血坏死；课程归入绞窄性肠梗阻口径 |
| 升主动脉 / 瓣膜 | 瓣膜纤维化 / 钙化 → 主动脉瓣狭窄；瓣环扩张 → 主动脉瓣关闭不全 |
