# Block 11｜心力衰竭 · 学习阅读版 v2｜最终执行版
## 多种上游疾病为什么汇合成同一个综合征

> **中心问题**：心脏收缩或充盈异常怎样同时造成前向低灌注与后向淤血，并通过神经体液代偿形成恶性循环；又怎样根据表型、病因与诱因、湿冷状态和证据选择治疗目标？

# 先建立脑内模型：心衰不是“心脏停了”

初学先展开下方整体解释，再沿同一模型到自然节点；复习保留模型与完整Prompt，卡住时只打开对应解释。精记仍走原Memory / Precision入口，不改变真实学习记录。

<details>
<summary>初学展开：输出不足、充盈压升高与代偿反噬</summary>

心衰是各种原因导致心脏结构和 / 或功能异常，使心脏出现收缩和 / 或充盈功能障碍，在静息或运动时出现：

```text
心排血量不能满足组织需要（可为绝对减少，也可相对需求不足）
或
必须靠更高心腔充盈压才能维持输出
```

所以不要先从 EF 分类开始。先抓住共同电影：

```text
泵不出去 / 充不进去
→ 有效 SV、CO下降，或充盈压被迫升高
        ↓
前向：组织和肾灌注不足
后向：上游心房、静脉与毛细血管压力升高
        ↓
交感↑、RAAS↑、醛固酮↑、ADH↑
→ HR / 收缩性↑、血管收缩、水钠潴留
        ↓
短期：保压、保灌注、提高回心
长期：耗氧↑、后负荷↑、充盈压↑、淤血↑、肥大 / 纤维化 / 重构
        ↓
泵与充盈进一步恶化
```

这条链直接解释两个看似矛盾的现象：

```text
前向低灌注 + 后向淤血可以同时存在

全身总水量很多
≠ 有效循环量 / 器官灌注足够
```

因此患者可以**全身水肿，却仍让肾脏读到“有效循环量不足”并继续保钠保水**。

再把淤血方向放回串联泵：

```text
左心问题
→ 左房 / 肺静脉压力↑
→ 肺淤血

右心问题
→ 右房 / 体静脉压力↑
→ 体静脉淤血
```

> 后面的 HFrEF / HFpEF、左 / 右心衰、干湿冷暖和所有治疗，都是在这张图上定位，不是另一套知识。

</details>

# 总 Framework

<!-- kianos:framework id="circulation-b11-framework-main" -->

```text
心肌损害 / 压力、容量或充盈负荷异常 + 当前诱因
→ 收缩 / 充盈功能异常
   ├─ 有效前向输出不足 → 器官与肾灌注不足
   └─ 维持输出需更高充盈压 → 左侧肺淤血 / 右侧体静脉淤血
两种后果可单独突出，也可并存；高排量状态可CO不低而仍相对组织需要不足。EF是观察分型，不是机制起点。

灌注不足 → 交感、RAAS、醛固酮、ADH → 短期保压保回心
持续激活 → 耗氧、后负荷、水钠潴留、重构↑ → 收缩 / 充盈进一步恶化
室壁牵张 → ANP / BNP反向代偿，并提供标志物证据

从上述模型读取：左 / 右淤血、EF与阶段、结构、压力、输出、牵张及运动能力
→ 急性按淤血 × 低灌注分流，减负荷服从灌注
→ 稳定期按表型处理上游病因、重构、淤血及节律 / 同步问题
治疗与复评回到原来的故障和变量；完整自然节点见下一节同一模型。
```

# 同一模型上的自然节点〔完整 Prompt〕

沿正文已确立的医学关系展开与压缩同一模型。括注只绑定该位置的完整正式 Prompt；删去全部括注后，机制、分支、反馈、证据与干预关系仍完整保留。

```text
A1 循环系统 → B11 心力衰竭
上游多种心脏病在这里汇合：哪里先坏，怎样导致淤血 / 低灌注，怎样打断恶性循环？

① 上游故障 → 收缩 / 充盈异常
心肌损害，或长期压力 / 容量负荷、充盈入口异常
  〈病因两大类：“泵本体坏了”或“长期负荷不对”〔心肌损害2组｜负荷3入口｜压力vs容量重构｜超代偿→心衰〕〉
  ↓
收缩或充盈不能满足需要；感染、房颤、容量增加等可打破原有代偿
  〈诱因：本来能勉强维持的系统被一次额外负担推入失代偿〔诱因6组/最常见｜病因vs诱因｜旧MI＋新事件定位〕〉
  ├─ 排空能力下降 → ESV增加 → 有效SV / CO不足，或依靠代偿暂时维持
  └─ 顺应性下降 / 主动舒张异常 → 同一容积需更高舒张压
       → 左房 / 肺静脉压力升高；EDV可不大、EF仍可保留
       〈HFpEF：泵不一定弱，但“泵硬、充不进去、压力高”〔基础病｜充盈障碍2路｜压力/容积/肺淤血｜PV/EDV/EF｜超声指标〕〉
两类机械异常可并存；HFrEF / HFpEF不把收缩与舒张分成互斥疾病。
高排量状态从组织需要 / 循环负荷进入：CO可不低而仍相对不足；不必先假定收缩力下降。

② 沿同一串联泵看前向与后向
收缩 / 充盈异常
  ├─ 有效前向流量不足 → 组织、肾灌注不足
  └─ 上游充盈压升高 → 淤血
       ├─ 左房 / 肺静脉压↑ → 肺淤血、换气受损、呼吸困难
       │    〈左心衰：必须关注肺〔呼吸困难序列｜咯血/肺水肿｜心脏体征｜发绀2机制/来源〕〉
       └─ 右房 / 体静脉压↑ → 颈静脉、肝、胃肠及低垂部位淤血
            〈右心衰：必须关注体静脉〔最有价值征｜体静脉7组表现｜水肿3特征｜DVT/甲减对照｜奇脉低权重接口〕〉
前向低灌注与后向淤血可以并存，但并非每位患者都同时明显。
左衰后右室输出再下降 → 肺循环输入减少 → 肺淤血可相对减轻
  同时总体输出更低、体静脉淤血更重；这种变化不代表心衰好转
  〈左心衰发展到右心衰后，肺淤血为什么可减轻〔串联泵｜输入/肺淤血｜体淤/低输出｜变化判读〕〉

③ 同一故障的反馈：短期代偿 → 长期反噬
肾与组织有效灌注不足
  → 交感、RAAS、醛固酮、ADH激活
  → 心率 / 收缩性、血管张力与水钠保留增加 → 短期保压、保回心
  持续激活 → 耗氧、后负荷、充盈压及重构增加 → 回到①，故障进一步加重
室壁牵张 → ANP / BNP反向卸货信号；它们是代偿 / 标志物，不是病因
  〈心衰共同电影〔首故障｜前向/后向｜代偿系统｜短期→长期代价｜闭环｜ANP/BNP反向信号〕〉

④ 证据读取以上变量，分类描述同一综合征
排空量与舒张末容积 → EF = SV / EDV → HFrEF / HFmrEF / HFpEF / HFimpEF
  〈按 LVEF 分型：EF回答射血比例，不等于完整泵功能〔EF分型4｜HFrEFvsHFpEF机制｜EF公式｜保留EF≠完整功能正常〕〉
结构 / 功能改变及症状历史 → A–D阶段；症状缓解不自动倒退疾病阶段
  〈A–D 分期：描述疾病进展，治疗只能延缓，不轻易逆转阶段〔A–D4期｜有无症状边界｜无症状期ESV/EDV/SV/EF链〕〉
活动限制、急性MI背景和步行能力 → NYHA / Killip / 6MWT，各用其适用轴
  〈NYHA、Killip 与 6 分钟步行分别回答什么〔NYHA4级｜夜间vs持续不能平卧｜Killip适用/4级｜6MWT3档〕〉
压力与输出 → PAWP / CVP / CO / CI；左侧充盈与右侧回心分开解释
  〈血流动力学：Swan-Ganz 是 Study 金标准〔PAWP/CVP/CO/CI：参考值/方向｜Swan-Ganz地位｜HFpEF静息/负荷证据〕〉
腔、壁、瓣、收缩 / 充盈与肺淤血 → 超声、MRI、X线分别校准结构和后果
  〈心衰影像：超声、MRI与X线的证据职责〔影像3类：超声/MRI/X线→职责｜KerleyBvs蝴蝶征｜EF比例边界〕〉
牵张 → BNP / NT-proBNP；稳定慢性状态的运动能力 → CPET
  低BNP不能绝对排除HFpEF；急性不稳定者不做负荷试验
  〈BNP / NT-proBNP 与心肺运动试验〔BNP/NT-proBNP：来源/排除/严重度/预后/局限｜CPET用途/指标〕〉
这些是观察与分类关系，不把检查、EF标签画成心衰病因。

⑤ 急性失代偿：从②读取淤血 × 低灌注，再选当下目标
上游淤血＝湿；前向灌注不足＝冷
  → 干暖 / 湿暖 / 干冷 / 湿冷；血压与充盈状态共同限制处理
  〈急性心衰四象限：先判断“湿不湿、冷不冷”〔湿/冷2判断轴｜4象限｜最常见/最严重〕〉
  ├─ 湿暖 → 减淤血，按血压与病因决定能否扩管
  ├─ 干冷 → 先辨容量不足还是泵弱，再决定补充充盈或支持泵
  └─ 湿冷 → 同时有高充盈压与低输出；严重低血压 / 低灌注时先保灌注
       不能因肺湿就继续强扩管；持续严重低灌注接B12
氧合、减淤血、维持血压、恢复灌注并处理诱因相互校准
  〈急性处理的四个目标〔急性目标4｜湿暖/干冷/湿冷→处理｜血压与充盈前提｜扩管慎禁情境〕〉
利尿 / 扩管改变负荷，正性肌力支持泵，血管收缩支持压力，呼吸 / 循环支持渡过危险
  → 按改变的变量复评；增加耗氧的短期支持不充当慢性抗重构药
  〈急性药物与非药物按功能归类〔急性药物4功能→代表｜呼吸/循环支持｜耗氧代价与退出〕〉

⑥ 稳定后的长期干预回到①—③，不另换模型
上游病因 / 诱因、长期结局、淤血症状分别设目标
  〈治疗目标分三层：改善结局、改善症状、处理诱因 / 合并症〔治疗目标3层｜长期结局vs症状｜上游病因/诱因｜缓解≠降死亡〕〉
HFrEF：阻断持续神经体液激活及重构，基础治疗与特定加用药分开
  〈Study“降低死亡率五朵金花”与共同逻辑〔课程5类｜4基础+加用｜机制角色｜结局边界〕〉
  ├─ RAAS / 醛固酮、肾性水钠与NO–sGC–cGMP等靶点 → 药物按机制和条件选择
  │    〈ACEI / ARB / ARNI、MRA、SGLT2i、sGC〔4药组机制｜各自限制｜肾功/血钾｜启用vs维持〕〉
  ├─ 持续交感毒性 → 稳定期β阻断；休克 / 明显低灌注时不机械套用
  │    〈β受体拮抗剂：慢性稳定期抗重构，不是急性休克时强行压心率〔稳定期作用链｜代表3药｜慎禁情境｜急性失代偿继续/调整条件〕〉
  ├─ 体液潴留 → 适量利尿 → 减淤血；过量会损害充盈、血压与肾灌注
  │    〈利尿剂：改善液体潴留症状的基石〔用药前提｜不足vs过量｜利尿4组：作用/不良反应｜低钠/抵抗接口〕〉
  └─ 符合条件的心率、收缩、负荷或不同步 / 恶性节律问题 → 选对应药物或器械
       CRT改善同步，ICD防恶性节律，两者任务不同
       〈伊伐布雷定、强心苷、血管扩张剂、CRT 与 ICD〔药械5类→靶点/场景｜强心苷链｜用药边界｜CRTvsICD〕〉
HFpEF：回到①的充盈与压力问题，处理高压 / 缺血 / 房颤及淤血
  → 降率须有适应证，利尿避免充盈不足，盲目强心不能修复顺应性
  → SGLT2i等结局证据仍按原Core人群和终点条件读取
  〈HFpEF 治疗：控制上游病因、延长充盈、适量减淤血，避免盲目强心〔病因/心率/充盈3目标｜药物→目标｜利尿容量边界｜强心局限〕〉
治疗后回到④—⑤复评；症状改善、复合终点与单独死亡率获益分别判断。

病例反推：共同故障 → 左 / 右方向 → EF表型 → 急慢与诱因 → 湿冷及证据 → 对应靶点
  〈心衰六问〔病例6问｜机制/方向/EF/时程诱因/湿冷证据/治疗｜反事实3〕〉
```

## KP01｜按 LVEF 分型：EF回答射血比例，不等于完整泵功能

> **讲义定位 →** 内科 P355。  
> **主提示**：EF分型4｜HFrEFvsHFpEF机制｜EF公式｜保留EF≠完整功能正常

<details>
<summary>展开解释、条件与精记</summary>

| 类型 | LVEF | 当前 Study 身份 |
|---|---:|---|
| HFrEF | ≤40% | 射血分数降低；传统“收缩性心衰”主体 |
| HFmrEF | 41%–49% | 射血分数轻度降低 |
| HFpEF | ≥50% | 射血分数保留；通常有充盈压升高 / 舒张功能受损，既往常称“舒张性心衰” |
| HFimpEF | 既往≤40%，治疗后＞40% | 射血分数改善型 |

```text
HFrEF
→ 收缩性下降突出
→ ESV↑、EF↓

HFpEF
→ 常见顺应性下降 / 主动舒张异常
→ 心室不易充盈、充盈压↑
→ EF可保留但患者仍可明显淤血、呼吸困难
```

> **边界**：HFpEF 不能机械等同于“只有舒张异常”。当前 Study 自身也提示 HFrEF 常合并舒张功能不全，而 HFpEF 也可存在一定程度的收缩功能异常；EF 是分型轴，不是全部机械功能。

（易混：EF是 `SV/EDV`；EF正常不等于舒张功能、充盈压、CO储备均正常。）

</details>

## KP02｜A–D 分期：描述疾病进展，治疗只能延缓，不轻易逆转阶段

> **主提示**：A–D4期｜有无症状边界｜无症状期ESV/EDV/SV/EF链

<details>
<summary>展开解释、条件与精记</summary>

| 分期 | 状态 |
|---|---|
| A | 只有高危因素，如高血压、冠心病危险因素；无结构异常、无症状 |
| B | 前心衰：已有结构改变、充盈压 / 标志物异常，但无症状 |
| C | 症状性心衰：既往或目前有症状 / 体征 |
| D | 晚期心衰：优化治疗后仍明显症状、反复住院，可有心源性恶病质 |

无症状性收缩功能减退时：

```text
收缩性↓
→ ESV↑
→ EDV↑
→ Frank–Starling暂时维持SV
→ 但EF已下降，神经体液系统已激活
```

因此 LVEF 比单次 SV 更敏感地暴露早期射血功能减退。

## KP03｜NYHA、Killip 与 6 分钟步行分别回答什么

> **主提示**：NYHA4级｜夜间vs持续不能平卧｜Killip适用/4级｜6MWT3档

<details>
<summary>展开解释、条件与精记</summary>

### NYHA

- Ⅰ：日常活动不受限；
- Ⅱ：休息无症状，一般活动出现症状；
- Ⅲ：活动明显受限，较轻活动即出现症状，夜间憋醒坐起后缓解接口；
- Ⅳ：静息也有症状，不能平卧 / 任何活动均加重。

（易混：端坐呼吸不能机械等同于NYHAⅣ；Study 强调“夜间躺下后坐起可缓解”可在Ⅲ级，而持续半卧、完全躺不下更接近Ⅳ级。）

### Killip

急性心肌梗死并发心衰采用：

```text
I 无心衰
II 肺啰音＜50%肺野等
III 肺水肿 / 啰音＞50%
IV 心源性休克
```

陈旧性心梗导致慢性心衰仍按 NYHA。

### 6分钟步行

按 Study：

```text
＜150m 重度
150–450m 中度
＞450m 轻度
```

</details>

# ② 病因与诱因

<!-- kianos:kp id="circulation-b11-kp04" -->

## KP04｜病因两大类：“泵本体坏了”或“长期负荷不对”

> **讲义定位 →** P356。  
> **主提示**：心肌损害2组｜负荷3入口｜压力vs容量重构｜超代偿→心衰

<details>
<summary>展开解释、条件与精记</summary>

### 心肌损害

- 原发：缺血（冠心病最主要）、炎症 / 免疫（心肌炎、扩心病接口）、遗传（HCM、DCM等）；
- 继发：糖尿病、甲亢 / 甲减、浸润、心脏毒性药物等。

### 负荷异常

```text
后负荷 / 压力负荷过重
→ 高血压、主动脉瓣狭窄、肺动脉高压、肺动脉瓣狭窄

前负荷 / 容量负荷过重
→ 瓣膜关闭不全、动脉导管未闭、间隔缺损、高排量状态

充盈入口受限 / 前负荷不足接口
→ 二尖瓣狭窄等“左室没血可充”
```

压力负荷常先向心性肥厚；容量负荷常先扩张 / 离心性重构。超过代偿后均可进入心衰。

高排量状态用“**动—脚—贫—甲—妊**”收束课程名单：动静脉瘘、脚气病、贫血、甲亢、妊娠相关状态。它们提高回心 / 循环负荷或组织代谢需要，心排血量可不低却仍相对不足。讲义提醒：年轻、原心脏耐受较好的甲亢患者可表现为高排量；老年或有基础心脏病者也可因恶化原病表现为低排量，不能只凭“甲亢”选定类型。Source将妊娠与围生期心肌病并列作记忆接口，不代表所有围生期心肌病均为高排量。

二尖瓣狭窄是充盈入口受阻：左房压力升高可造成肺淤血，即使左室本身无明显收缩 / 舒张障碍。这里调用B7瓣口与负荷模型；不要把“肺淤血”一律翻译成左室收缩力下降。

</details>

<!-- kianos:kp id="circulation-b11-kp05" -->

## KP05｜诱因：本来能勉强维持的系统被一次额外负担推入失代偿

> **主提示**：诱因6组/最常见｜病因vs诱因｜旧MI＋新事件定位

<details>
<summary>展开解释、条件与精记</summary>

常见诱因：

- 呼吸道感染最常见；
- 心律失常，尤其房颤；
- 输液过多过快、血容量增加；
- 过度劳累、情绪激动、妊娠后期 / 分娩；
- 不恰当停药；
- 原有心脏病突然加重。

```text
病因
放在原本健康心脏上也足以造成长期结构 / 功能损害

诱因
使已有心脏病的代偿平衡突然被打破
```

急性心梗若直接造成心衰，是病因；既往心梗后长期稳定，后来因其他事件失代偿，旧心梗可作为基础病因，而感染 / 房颤等是当前诱因。

</details>

# ④ 左、右、全心衰

<!-- kianos:kp id="circulation-b11-kp07" -->

## KP07｜左心衰：必须关注肺

> **讲义定位 →** P357。  
> **主提示**：呼吸困难序列｜咯血/肺水肿｜心脏体征｜发绀2机制/来源

<details>
<summary>展开解释、条件与精记</summary>

### 肺淤血表现

- 咳嗽、白色泡沫痰、双肺湿啰音；
- 劳力性呼吸困难：最早但缺乏特异性；
- 夜间阵发性呼吸困难、端坐呼吸：更有特点；
- 急性肺水肿 / 心源性哮喘：粉红色泡沫痰、明显呼吸困难、湿啰音或干湿共存。

夜间 / 仰卧加重的 Study 链：

```text
回心血量↑
+ 膈肌上移、肺活量↓
+ 迷走张力↑、支气管收缩
+ 熟睡时呼吸中枢敏感性↓
→ 呼吸困难加重
```

咯血：痰中带血与肺毛细血管淤血相关；大咯血可与压力经侧支传至支气管静脉并破裂相关。

### 心脏体征

- 心尖向左下移；
- 相对性二尖瓣关闭不全 → 心尖部收缩期杂音；
- S1减弱；
- S3奔马律：快速充盈血流冲击顺应性较差、过度充盈的心室壁；
- 交替脉：心室收缩力与每搏输出量强弱交替；课程用Ca²⁺释放 / 回收交替帮助理解，不能把它误认成心率快慢交替。

急性左心衰的病例入口是高血压急症、急性MI、急性心肌炎或急性瓣膜关闭不全等背景，加上突发呼吸困难、端坐、湿啰音和粉红泡沫痰；找诱因时仍回相应上游病因。

### 发绀：保留来源差异

- 肺淤血/水肿 → 换气受损 → 中央性成分；
- 心排血量减少 → 周围灌注不足、组织摄氧比例增加 → 周围性成分；
- 本讲义并列两种教材口径：《诊断学》第10版P20归为混合性，《内科学》第10版P179归为中央型。回答指定教材题时按对应来源；解释病例时分清两条机制。

### 心源性哮喘 vs 支气管哮喘

| 维度 | 心源性哮喘 | 严重支气管哮喘 |
|---|---|---|
| 呼吸困难 | 混合性、常端坐 | 呼气性为主 |
| 痰 | 可粉红泡沫痰 | 一般无 |
| 啰音 | 湿啰音或干湿共存 | 干啰音，严重可沉默肺 |
| X线 | 左心扩大、肺淤血 / 蝴蝶征 | 可无明显异常或透亮度↑ |

</details>

<!-- kianos:kp id="circulation-b11-kp08" -->

## KP08｜右心衰：必须关注体静脉

> **讲义定位 →** P357。  
> **主提示**：最有价值征｜体静脉7组表现｜水肿3特征｜DVT/甲减对照｜奇脉低权重接口

<details>
<summary>展开解释、条件与精记</summary>

```text
右心射血能力下降
├─ 向肺循环前向射血减少 → 有效输出 / 氧输送不足
└─ 右房 / 体静脉压力升高 → 体循环淤血
```

主要表现：

- 颈静脉怒张；
- **肝颈静脉回流征阳性：诊断右心衰最有价值体征**；
- 肝大、压痛，长期可心源性肝硬化；
- 胃肠淤血：腹胀、食欲下降、恶心等；
- 双下肢对称性、凹陷性、低垂部位水肿；
- 胸水、腹水，多为漏出液；
- 心尖多向左移，胸骨左缘4–5肋间收缩期杂音、奔马律；当前 Study 另保留严重右心衰可见奇脉 / 吸停脉的精确接口。

单纯右心衰也可因低输出 / 缺氧而有劳力性呼吸困难，但未必出现左衰的肺淤血和不能平卧。按压淤血肿大的肝脏时颈静脉持续、明显怒张，即肝颈静脉回流征；消化道淤血症状是课程所列常见症状。

水肿按同一轴比较：心源性从低垂部位起、对称、凹陷，并找颈静脉怒张 / 肝颈回流征；肾炎性多从疏松颜面起，机制偏GFR下降后水钠潴留；肾病性与肝源性常有低白蛋白、血浆胶体渗透压下降，也可低垂水肿，但不能只凭部位当成心衰。甲减黏液性水肿多非凹陷；少数甲亢有局限胫前黏液性水肿。单侧或明显不对称肢体肿痛转向DVT鉴别。详细肾 / 肝病归原System。

（易混：肺气肿、膈下移可使肝界下移；淤血性肝大更支持伴压痛。奇脉不是右心衰的第一定位征；出现时仍要考虑B8心包压塞等背景，本处只保留课程低权重接口。）

</details>

## KP09｜左心衰发展到右心衰后，肺淤血为什么可减轻

> **主提示**：串联泵｜输入/肺淤血｜体淤/低输出｜变化判读

<details>
<summary>展开解释、条件与精记</summary>

```text
原先左心衰
→ 左房和肺静脉压力↑
→ 肺淤血

随后右心也衰
→ 右室向肺循环射血↓
→ 肺循环输入减少
→ 肺淤血症状可相对减轻
```

这不代表病情好转，而是前向输出进一步下降、体静脉淤血加重。

</details>

# ⑤ 辅助检查与证据职责

<!-- kianos:kp id="circulation-b11-kp10" -->

## KP10｜血流动力学：Swan-Ganz 是 Study 金标准

> **讲义定位 →** P358。  
> **主提示**：PAWP/CVP/CO/CI：参考值/方向｜Swan-Ganz地位｜HFpEF静息/负荷证据

<details>
<summary>展开解释、条件与精记</summary>

左心衰常见：

```text
PAWP / PCWP ↑
CVP 可↑（尤其全心衰）
CO ↓
CI ≤2.2 接口
```

Study 常用参考：PAWP / PCWP 正常＜12mmHg，左心衰可≥18mmHg；CVP正常约5–10cmH₂O；CO正常约＞5L/min；CI正常约＞2.5。

无创不能确诊HFpEF且存在劳力性呼吸困难者，课程侵入性支持证据为静息PCWP≥15 mmHg，或LVEDP≥16 mmHg，或负荷PCWP≥25 mmHg。右心漂浮导管测PCWP，LVEDP须左心侧测量，不能把两者当作同一处直接测值。

上面的CO/CI参考为本课简化值，受体表面积、负荷等影响；CI≤2.2是低输出严重度线索，不是所有左心衰必须满足的诊断条件。

## KP12｜BNP / NT-proBNP 与心肺运动试验

> **主提示**：BNP/NT-proBNP：来源/排除/严重度/预后/局限｜CPET用途/指标

<details>
<summary>展开解释、条件与精记</summary>

### BNP

- 主要来源于心室；
- 室壁张力 / 牵张增加时释放；
- 增高程度与心衰严重度正相关，可评估预后；
- 正常值有助排除急性 / 慢性心衰；
- Study 提醒约20% HFpEF患者可有正常脑钠肽。
- NT-proBNP较BNP半衰期长、较稳定；两者阈值不能互换，ng/L与pg/mL数值相等。

课程慢性/非急性排除参考：NT-proBNP<125 pg/mL或BNP<35 pg/mL；急性常用NT-proBNP<300 pg/mL或BNP<100 pg/mL（ESC急性心衰口径补充，讲义此处仅写“正常”）。低值使心衰可能性下降，不代表所有HFpEF均被绝对排除；高值亦非心衰独有，需结合临床和影像。

### 心肺运动试验

课程用于慢性稳定性心衰，评估运动能力、治疗、预后及心脏移植可行性；最大耗氧量下降、无氧阈提前/降低提示功能受损。不能把负荷试验安排给急性不稳定者。

</details>

## KP13｜急性心衰四象限：先判断“湿不湿、冷不冷”

> **讲义定位 →** P359–360。  
> **主提示**：湿/冷2判断轴｜4象限｜最常见/最严重

<details>
<summary>展开解释、条件与精记</summary>

| 类型 | 淤血 | 低灌注 | 感性身份 |
|---|---|---|---|

## KP14｜急性处理的四个目标

> **主提示**：急性目标4｜湿暖/干冷/湿冷→处理｜血压与充盈前提｜扩管慎禁情境

<details>
<summary>展开解释、条件与精记</summary>

```text
1. 改善氧合与呼吸困难
2. 降低过高充盈压和淤血
3. 维持足够血压
4. 恢复组织灌注并处理诱因
```

- 干暖：无明显淤血 / 低灌注，课程以调整口服药、继续复评为入口；
- 湿暖：利尿与扩管减负荷。高血压、液体再分布突出时课程先扩管；体液潴留、淤血突出时先利尿，始终看血压与病因；
- 干冷：先评估容量不足，适当补液后若仍低灌注，再考虑正性肌力；若并不缺容量，不能无限补液；
- 湿冷：课程以SBP 90 mmHg附近分流。表列＞90时扩管 / 利尿，效果不佳再正性肌力；＜90时先正性肌力，必要时血管收缩支持，低灌注纠正后再利尿。Source表格写＞90、说明文写≥90，恰等于90时不能只靠单点读数忽略灌注、容量与趋势；药物无反应的严重低灌注接机械循环支持与B12；
- 高血压急症伴急性肺水肿：硝普钠等扩张动静脉可降前后负荷；
- 低血压 / 休克、HCM、AS、急性右室梗死等禁忌 / 慎用扩血管。

> **核心边界**：急性心衰“减负荷”成立的前提是仍有足够灌注；已休克时继续扩血管可加重低灌注。

</details>

## KP15｜急性药物与非药物按功能归类

> **主提示**：急性药物4功能→代表｜呼吸/循环支持｜耗氧代价与退出

<details>
<summary>展开解释、条件与精记</summary>

| 目标 | Study代表 |
|---|---|
| 利尿降容量 | 袢利尿剂等 |
| 静脉 / 动脉扩张 | 硝酸酯、硝普钠、奈西立肽等按血压选择 |
| 正性肌力 | 多巴酚丁胺、多巴胺、米力农、左西孟旦、毛花苷丙等按场景 |
| 血管收缩保灌注 | 去甲肾上腺素等 |
| 其他 | 吸氧 / 通气、处理ACS / 节律 / 感染、机械循环支持接口 |

β受体激动剂、PDE抑制剂等增加心肌耗氧，低灌注纠正后应尽早停用；不是慢性抗重构药。

扩管药按靶点分组，保留课程“肖肖无奈”的完整答案：硝普钠（动静脉，降前后负荷）、硝酸酯（静脉作用突出，持续应用可耐药）、乌拉地尔（α受体拮抗，偏降外周阻力）、奈西立肽（重组人BNP，扩管兼利钠、抑制RAAS / 交感）。二狭导致左室充盈不足时，课程不选硝普钠；不能把所有肺水肿都当高后负荷。Source另列硝普钠氰化物风险及“使用不超过72小时”，保留为课程来源提醒，不构成可安全连续给药72小时的保证。

正性肌力按机制收束：β受体激动剂（多巴胺 / 多巴酚丁胺）；PDE抑制剂（米力农 / 氨力农，减少cAMP降解）；Ca²⁺增敏剂（左西孟旦，增强肌钙蛋白C对Ca²⁺反应并有血管KATP接口）；短效强心苷（毛花苷丙，钠泵链见下文）。血管收缩组为去甲肾上腺素 / 肾上腺素，保压有增加后负荷的代价。**Source HOLD**：讲义将“慢性心衰急性失代偿不用β激动剂”写成概括，后文解释与既用β阻断背景有关；当前仅保留歧义，不能把它改写为所有急性失代偿患者的统一禁忌。

## KP16｜治疗目标分三层：改善结局、改善症状、处理诱因 / 合并症

> **主提示**：治疗目标3层｜长期结局vs症状｜上游病因/诱因｜缓解≠降死亡

<details>
<summary>展开解释、条件与精记</summary>

```text

→ 抑制交感 / RAAS / 醛固酮、SGLT2、sGC、CRT / ICD等
```

## KP17｜Study“降低死亡率五朵金花”与共同逻辑

> **讲义定位 →** P360–361。  
> **主提示**：课程5类｜4基础+加用｜机制角色｜结局边界

<details>
<summary>展开解释、条件与精记</summary>

课程“五朵金花”列出以下5类；这是课程分类，不等于五类在任何人群都已分别证明降低死亡：

1. ACEI / ARB / ARNI；
2. β受体拮抗剂；
3. MRA；
4. SGLT2抑制剂；
5. sGC刺激剂。

现代HFrEF基础治疗以其中前4类为骨架；sGC刺激剂维立西呱是在特定患者中考虑的加用治疗。

结局要分开：VICTORIA在近期恶化HFrEF中改善“心血管死亡或心衰住院”复合终点，单独心血管死亡未达显著；2025 VICTOR在无近期恶化人群的主要复合终点未达显著。预设合并分析则观察到心血管死亡减少，说明不能反过来说“绝无死亡获益”。共同学习规则是：看具体人群、药物与终点，不能将所有复合获益都改写为单独死亡率结论。

共同逻辑：

```text
阻断长期交感 / RAAS / 醛固酮
+ 减少水钠和压力负担
+ 抑制肥厚、纤维化和重构
→ 延缓疾病进展、改善预后
```

</details>

## KP18｜ACEI / ARB / ARNI、MRA、SGLT2i、sGC

> **主提示**：4药组机制｜各自限制｜肾功/血钾｜启用vs维持

<details>
<summary>展开解释、条件与精记</summary>

- ACEI / ARB / ARNI：降低AngⅡ / AT₁效应，减少血管收缩、醛固酮、重构；ARNI同时增强利钠肽等；
- MRA：阻断醛固酮保钠排钾和重构，为保钾利尿 / 抗重构；
- SGLT2i：近端小管排糖排钠、减轻容量负担并有心肾保护接口；
- sGC刺激剂：增强NO–sGC–cGMP方向，扩血管 / 抗重构接口。

| 药组 | 主要限制与阈值 |
|---|---|
| ACEI/ARB/ARNI | 妊娠、双侧肾动脉狭窄、明显高钾/低血压需避用或评估；课程Cr>265 μmol/L、K>5.5 mmol/L不是全类通用永久界限。ACEI/ARB看启动后Cr变化及K；ARNI另有血管性水肿和ACEI间隔36 h限制，见B5 KP18 |
| MRA | HFrEF启动通常要求eGFR>30 mL/min/1.73m²且K<5.0 mmol/L；治疗中若无法维持K<5.5 mmol/L需停用/重新评估，不能与RAAS三类共用一条阈值 |
| SGLT2i | 注意容量不足、酮症风险及长期禁食/手术/危重病暂缓；按药物和适应证分启用与维持。课程达格列净表写GFR<30、正文写<25，存在差异；FDA心肾适应证口径eGFR<25不建议新启用，但既有治疗可有继续条件。恩格列净课程20界值不等于下降后必停；KDIGO允许符合条件者低于20继续至不耐受或肾替代治疗 |
| sGC刺激剂维立西呱 | 妊娠禁用；不可与其他sGC刺激剂合用，不推荐合用PDE5抑制剂；关注低血压。不要套用MRA的K/eGFR门槛 |

上表是机制学习中的风险核对，不替代具体制剂说明书及个体处方。

## KP19｜β受体拮抗剂：慢性稳定期抗重构，不是急性休克时强行压心率

> **主提示**：稳定期作用链｜代表3药｜慎禁情境｜急性失代偿继续/调整条件

<details>
<summary>展开解释、条件与精记</summary>

常用 Study 代表：美托洛尔缓释、比索洛尔、卡维地洛等。

```text
长期交感激活
→ 心率 / 耗氧↑、β受体脱敏、重构、心律失常风险↑

β阻断
→ 慢性稳定期降低交感毒性
→ 延缓进展、减少猝死
```

通常不用 / 慎用：

- 心源性休克、明显低灌注；
- 严重缓慢节律、SSS、二度Ⅱ型 / 三度AVB；
- 支气管哮喘、变异型心绞痛、雷诺等 Study 接口；
- 急性失代偿期若无休克，原已长期服用者常继续，避免反跳；具体调整结合灌注和容量。

一般药物安全回B5 KP18的既有边界：预激房颤也限制房室结抑制药；严重AVB要看有无合适起搏保护。课程虽列NYHAⅣ不用，不能推出所有稳定Ⅳ级永久禁用，开始 / 加量看当前失代偿、灌注与容量；哮喘 / 变异型心绞痛 / 雷诺须结合具体药物选择性及适应证。此处保留慢性稳定获益与急性负性肌力的区别，不重建第二套通用禁忌。

</details>

## KP20｜利尿剂：改善液体潴留症状的基石

> **主提示**：用药前提｜不足vs过量｜利尿4组：作用/不良反应｜低钠/抵抗接口

<details>
<summary>展开解释、条件与精记</summary>

只要存在明显体液潴留，利尿剂可改善淤血。剂量不足 → 淤血持续；剂量过大 → 容量不足、低血压、肾功能恶化。

| 组别 | 作用部位 / 靶点与代表 | 需要准确保留的限制 |
|---|---|---|
| 袢利尿剂 | 髓袢升支粗段Na⁺-K⁺-2Cl⁻同向转运体；呋塞米、托拉塞米、布美他尼 | 强效；低钾、耳毒性。该段本身不透水，抑制盐重吸收降低髓质高渗，最终减少集合管水重吸收；低GFR时课程偏用袢 |
| 噻嗪类 | 远曲小管NaCl重吸收；氢氯噻嗪 | 低钾、高尿酸；长期大剂量可影响糖脂代谢。课程GFR＜30 mL/min/1.73m²时作用明显受限，偏换袢；痛风尽量避免氢氯噻嗪 |
| 保钾类 | MRA螺内酯 / 依普利酮拮抗醛固酮；阿米洛利 / 氨苯蝶啶抑制集合管ENaC | 减少Na⁺重吸收和K⁺排泄；可按容量 / 电解质状态与排钾类合用，必须监测K和肾功能。MRA抗重构角色与单纯利尿分开；螺内酯可致男性乳腺增生，依普利酮该作用较弱 |
| V2拮抗剂 | 托伐普坦阻断集合管主细胞V2受体，减少AQP2参与的水重吸收 | 排游离水；课程低钠 / 利尿抵抗入口须连容量状态。依B5已采用边界，不能用于低容量低钠，也不能把高钠作为一般适应证 |

先按“排盐兼排钾 / 保钾 / 排游离水”分组，再记低GFR和低钠条件。排钾与保钾并非人人固定联合；急性右室MI等前负荷依赖场景另回B6 / B5。当前Source未给各药完整剂量，不生成处方剂量表。

</details>

## KP21｜伊伐布雷定、强心苷、血管扩张剂、CRT 与 ICD

> **讲义定位 →** P362。  
> **主提示**：药械5类→靶点/场景｜强心苷链｜用药边界｜CRTvsICD

<details>
<summary>展开解释、条件与精记</summary>

### 伊伐布雷定

选择性抑制窦房结If。课程条件：慢性HFrEF、LVEF≤35%、NYHAⅡ–Ⅳ、窦性心律、静息HR≥70次/min，且已用β受体拮抗剂；房颤、急性失代偿期不用。2022 AHA/ACC/HFSA推荐具体限定为稳定慢性、NYHAⅡ–Ⅲ且接受含最大耐受β阻滞剂的规范治疗，不能省去稳定状态与背景治疗。

### 强心苷

```text
抑制Na⁺-K⁺泵
→ 胞内Na⁺↑
→ 跨膜Na⁺梯度减小，NCX介导的Ca²⁺净外排减少
→ 胞内/SR可用Ca²⁺增加
→ 正性肌力
```

NCX净方向随膜电位和Na⁺/Ca²⁺梯度变化，可发生反向转运，但不是每个时相必然反向。

同时抑制房室结、增强迷走。适合收缩性心衰合并快房颤 / 房扑或AVNRT等特定场景；预激、SSS、二度Ⅱ / 三度AVB、急性MI早期（课程列24小时内）、重症心肌炎早期、HCM / AS、二狭窦性心律等属于课程避免使用的场景；具体应用需区分梗阻、传导障碍及控率需求。

“正在用强心苷”不等于所有电复律绝对禁止：药品说明书要求评估室性心律失常风险；疑中毒时延后择期复律，危急情况下由专业团队权衡，不能机械阻断救命电击。B10共用这一安全边界，不照搬Source“用苷禁止电复律”的绝对句。

把既有精记按问题分组，完整保留答案：

- **用在何处**：收缩性心衰伴适合控率的快房颤 / 房扑，或课程所列AV结折返性室上速；若有预激等禁忌不能只看“快”。二狭伴窦律的肺水肿不靠强心解决；合并房颤是否调用要单独查控率需求和禁忌。
- **避免 / 慎用四组**：旁路（预激）；慢与阻滞（SSS、二度Ⅱ型 / 三度AVB）；受损心肌（急性MI 24小时内、重症心肌炎早期）；充盈 / 出口障碍（二狭窦律、HCM / AS，按梗阻背景判断）。另把疑中毒与择期电复律作为条件核对，不能背成一律禁电击。
- **中毒识别三组**：胃肠道恶心呕吐；视觉黄视 / 绿视；心脏反应，课程列室性期前收缩最常见、三度AVB最具特征性。任何一条都不能单独替代综合判断。
- **易中毒因素三组**：心肌缺血 / 缺氧；电解质低K⁺、低Mg²⁺、高Ca²⁺；清除 / 敏感性及合用药背景（肾衰、甲减、利血平）。低K⁺减少与强心苷竞争钠泵、高Ca²⁺使钙负担更重；原讲义将利血平作迷走效应增强的历史药物接口。

这些是现有药物精记内容的补全，不新增强心苷中毒处置流程或现实给药指令。

### 血管扩张剂

用于不耐受ACEI / ARB或合并心绞痛 / 高血压等特定场景；SBP＜90、HCM、AS、急性右室MI等不用 / 慎用。

### CRT

改善房室、室间 / 室内收缩不同步，提高有效输出。Study典型组合：**最佳药物治疗3个月以上仍有心衰症状 + 窦性心律 + 完全性LBBB + QRS＞130 ms + LVEF≤35% + NYHAⅡ–Ⅳ**。另保留课程支路：有心室起搏指征或合并高度AVB且LVEF＜40%者。把“药物后、症状、节律 / 不同步、EF、功能级”作为恢复顺序；不要把B10在束支阻滞形态已成立时判断完全性的QRS≥120 ms与本课CRT组合的＞130 ms混用。本课Source旁注另写心律失常＞120 ms，保留其与B10原owner的等号差异。

这里保存课程组合；指南还按QRS宽度、形态和临床状态分层，单项超过130 ms不等于自动植入指征，旁支也不是无条件植入承诺。

### ICD

预防 / 终止室颤、持续性室速所致猝死。它不直接改善机械同步；CRT与ICD可组合，但任务不同。

课程功能四项：抗心动过缓起搏、抗心动过速起搏、低能电转复、高能电除颤。课程适用路径分组保留：

1. 已发生危险节律：非可逆原因所致、血流动力学不稳定的室颤 / 持续性室速；
2. 心梗后经血运重建 / 优化药物仍有低EF：LVEF≤35%并NYHAⅡ–Ⅲ，或LVEF≤30%并NYHAⅠ；
3. 有心源性猝死危险因素的心肌病（如HCM、DCM），以及有晕厥 / 室速记录、β阻断无效的遗传性心脏病（课程例长QT、Brugada）。

这些是Source列出的评估入口。各病种风险分层仍归B8 / B10；本段未完整给出所有植入等待期、预期生存及病种特异条件，不能把课程清单升级成完整现实植入标准。

</details>

# ⑧ HFpEF：以充盈压 / 舒张障碍为核心，但不等同于“只有舒张异常”

<!-- kianos:kp id="circulation-b11-kp22" -->

## KP22｜HFpEF：泵不一定弱，但“泵硬、充不进去、压力高”

> **主提示**：基础病｜充盈障碍2路｜压力/容积/肺淤血｜PV/EDV/EF｜超声指标

<details>
<summary>展开解释、条件与精记</summary>

常见背景：高血压导致左室肥厚、HCM、限制性心肌病、老龄等。

```text
顺应性下降
或
主动舒张耗能 / Ca²⁺回收异常
→ 心室舒张不充分
→ 同一容积需要更高舒张压
→ 左房 / 肺静脉压力↑
→ 呼吸困难、肺淤血
```

PV环感性：舒张期压力—容积关系上移 / 左移，EDV可不大，LVEF可保留。超声综合E/e′、E/A、组织多普勒、左房及其他充盈压证据。

课程用E/e′≥15、E/A<1.2作为记忆入口；E/A随松弛受损、假性正常化和限制性充盈可呈不同模式，不能把E/A<1.2当作所有HFpEF必备条件，也不能单靠一个比值确诊。

> [Source 原图 P430／印刷355：舒张/收缩不全PV环A/B](../../../../../../assets/source-visuals/a1-b11-full-use/p430-pv-original-crop.png)；横轴左室容积ml/m²、纵轴左室压力mmHg，正常点线与异常实线分开读。

</details>

## KP23｜HFpEF 治疗：控制上游病因、延长充盈、适量减淤血，避免盲目强心

> **主提示**：病因/心率/充盈3目标｜药物→目标｜利尿容量边界｜强心局限

<details>
<summary>展开解释、条件与精记</summary>

- 控制高血压、缺血、房颤和心动过速；
- 有相应适应证时β受体拮抗剂降低HR、延长舒张，梗阻性HCM尤其适用；不等于所有HFpEF均应无条件降低心率；
- ACEI / ARB / ARNI用于高血压、肥厚等背景；
- 非二氢吡啶CCB可改善舒张 / 控率接口；
- 利尿减淤血但避免过量导致前负荷和充盈不足；
- 强心苷等不能靠正性肌力改善顺应性，盲目强心可能增加耗氧/梗阻，因此不用于单纯纠正“泵硬”；另有房颤控率等适应证时须单独判断。

课程清单与现行证据须分开：2023 ESC更新已推荐达格列净或恩格列净用于HFpEF以减少心衰住院或心血管死亡的复合风险，不能从旧课程未列出就推出SGLT2i只适用于HFrEF。该复合终点也不等于已证明每一患者单独死亡率获益。

（易混：HFrEF和HFpEF都可淤血、都可用适量利尿；但“长期结局药”和“盲目强心”的适用边界不同。）

## 三个反事实

### EF正常但呼吸困难、左房压高

```text
不排除心衰
→ 考虑HFpEF / 舒张障碍
```

### 水肿明显但肾仍保钠保水

```text
总水量多
≠ 有效前向灌注足
→ 肾读取的是灌注 / 有效循环量
```

### 左心衰肺淤血后来减轻但全身水肿加重

```text
右心进一步衰竭
→ 肺循环输入减少
→ 肺淤血相对减轻
→ 体静脉淤血加重
```
