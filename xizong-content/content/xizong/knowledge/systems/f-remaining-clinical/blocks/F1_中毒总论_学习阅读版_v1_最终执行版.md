# F1｜中毒总论
## 先保命，再阻止继续吸收，最后才是“猜毒物”

> **中心问题**：急性中毒患者为什么不能从“这是什么毒”开始；怎样先识别生命危险和仍在继续的暴露，再把去污、促进清除、特异解毒和器官支持放进正确顺序？
>
> **Primary Study**：`内科学讲义_AI阅读版.md` 书页 P286–287。  
> **Primary Outline**：内科 U107《中毒》，元数据 **11题**。  
> **本 Block 身份**：F 系列真正的临床入口。它不是完整临床毒理学，而是建立所有毒物题通用的风险控制骨架。

```text

→ 停止暴露
→ 阻止继续吸收
→ 判断毒物性质与器官效应

→ 器官支持与持续监测
```

```text
闻到气味 / 看到瞳孔
→ 立刻猜一个毒物

```

中毒题真正的高价值能力是：**先判断患者正在因什么故障变危险，再判断毒物身份。**

# 1｜总 Framework

<!-- kianos:framework id="final-f01-framework-main" -->

```text
B｜生命危险层优先（处理优先级；不等待毒物命名）
气道｜呼吸｜循环｜意识｜惊厥 → 有威胁即支持生命功能
  中毒患者到来时，第一层优先级怎样确定？〔生命威胁｜暴露是否持续｜毒物身份何时进入｜后续控制层〕
生命支持与监测贯穿下列暴露、去污、清除、解毒判断，不是只在开头做一次。

A｜暴露入口与持续输入（病因定位，与生命支持并行核对）
口服 / 吸入 / 皮肤 / 黏膜 / 眼部 → 是否仍在继续暴露或吸收？
  暴露途径：口服不是唯一入口，皮肤和球结膜也能吸收〔入口4｜皮肤吸收↑2条件｜眼1｜仍吸收先做什么〕
停止继续暴露；按未吸收 / 已吸收分清不同处理对象
  去污：先区分“未吸收”与“已吸收”〔未吸收3路｜已吸收2路｜为什么不能混｜气道先行〕

C｜未吸收毒物：去污支路
脱离现场 / 去污染衣物；皮肤、毛发、眼部冲洗
胃肠去污先问操作是否安全、气道是否受保护
  洗胃：哪些情况会让操作本身制造更大伤害？〔禁忌类别｜各自伤害机制｜腐蚀性毒物边界｜意识/惊厥与气道〕
导泻另受毒物性质、器官状态与禁忌限制，不无条件加做
  导泻：不能把“让毒物快点出去”当成无条件正确〔不单用｜油脂禁因1｜常用4｜Mg禁5｜底层原因1〕

D｜吸收后的毒效应与证据（加权线索，不是等去污结束才识别）
呼吸快慢 / 瞳孔方向 → 受损生理层；单点不能确诊毒物
  呼吸 + 瞳孔：先识别方向，再结合其它证据〔呼快2组｜呼慢2组｜散瞳1组｜缩瞳5组｜M/α1逻辑〕
气味与颜色、器官表现作为并列线索组合
  气味：高密度 MI-D，不允许凌驾于生命层级〔蒜5｜烂苹果1｜苦杏仁1｜鞋油1｜臭蛋1｜鱼腥2｜胶水1〕
  皮肤颜色与腐蚀痂皮：颜色反映不同毒效应层〔绀3｜樱桃红1｜鲜红接口1｜黄3｜痂黄棕黑〕
  器官表现不是杂表：要先问“毒物打坏了哪一层”〔器官表现先定位受损层：CNS｜NMJ｜溶血/黄疸｜凝血/出血｜病理接口〕

E｜吸收后控制（性质、毒效应和器官状态决定；不替代支持）
├─ 促进清除：先审适用条件，再据理化性质选择
│    血液净化什么时候进入：不是“中毒=透析”〔进入条件5｜先看性质3｜方法3｜器官状态1〕
│    ├─ 小分子、非脂溶为主 → 透析
│    │   血液透析：哪些理化性质使毒物适合被“析”出？〔分子大小｜水溶/脂溶｜蛋白结合｜代表毒物｜不适合方向｜时间边界〕
│    ├─ 脂溶 / 蛋白结合且可吸附 → 灌流
│    │   血液灌流：什么时候应从“弥散”转向“吸附”思路？〔吸附原理｜脂溶性｜蛋白结合｜代表毒物｜吸附副损〕
│    └─ 血浆中游离 / 蛋白结合负荷及相应场景 → 血浆置换
│        血浆置换：什么样的毒物负荷更适合直接更换血浆？〔游离/蛋白结合负荷｜血浆载体｜代表场景｜与透析/灌流比较〕
└─ 特异解毒：毒效应—靶点—解毒方向；具体名单与考试边界保留
     常见解毒药：先记“毒效应—靶点—解毒方向”，名单放 MI-D〔铅1｜阿片1｜亚硝酸盐1｜苯二氮䓬1｜其余回表〕

F｜动态复评与病例收束
意识、呼吸、循环、酸碱、肝肾、血液
→ 识别持续吸收、反跳或迟发损伤 → 回到相应支持 / 控制层调整

病例整体收束（回看上面生命威胁、暴露/去污、证据、清除/解毒与监测的完整关系）
  最终病例算法：身份判断永远服从“生命危险 + 暴露层级”〔6步主链｜4线索｜3净化｜1出口F2〕
有机磷完整模型接口 → F2；本图是控制层关系，不能机械等待上一项完成才处理下一项。
```

## 1.1 四类操作必须分开

| 操作 | 在解决什么 | 典型入口 |
|---|---|---|
| **去污 Decontamination** | 还没吸收的毒物 | 脱衣、冲洗、胃肠去污 |
| **清除 Elimination** | 已经进入体内 / 血液的毒物 | 透析、灌流、血浆置换 |
| **解毒 Antidote** | 特定毒物的靶点或代谢后果 | 拮抗、复能、络合等 |
| **支持 Support** | 中毒造成的器官失败 | 气道、呼吸、循环、惊厥、酸碱 |

关键不是“哪个最高级”，而是**每一步处理不同层级的问题**。

# 2｜正式内容与完整 Prompt

<!-- kianos:kp id="final-f01-kp01" -->
## KP01｜中毒患者到来时，第一层优先级怎样确定？

> **主提示：** 生命威胁｜暴露是否持续｜毒物身份何时进入｜后续控制层

### Detailed Expansion

中毒题最危险的认知错误，是把“病因识别”放在“生命支持”之前。

当前 System Guide 冻结的顺序是：

```text
气道 / 呼吸 / 循环 / 意识等生命层级
→ 停止继续暴露
→ 清除尚未吸收的毒物
→ 判断吸收后的器官毒效应
→ 清除、解毒与支持
→ 动态监测
```

因此，**特异解毒药也不能替代生命支持**。即使已经知道毒物，患者如果正处于呼吸抑制、呼吸肌麻痹、休克或昏迷，首要危险仍然是器官功能失败。

**Routing**：CORE｜DECISION｜MI-G

<!-- kianos:kp id="final-f01-kp02" -->
## KP02｜暴露途径：口服不是唯一入口，皮肤和球结膜也能吸收

> **主提示：** 入口4｜皮肤吸收↑2条件｜眼1｜仍吸收先做什么

### Detailed Expansion

当前 Lecture 明确提示：

- 毒物可经消化道、呼吸道、皮肤和黏膜进入；
- 某些损伤皮肤的毒物可经皮肤吸收；
- **皮肤多汗或有损伤时，吸收可加快**；
- 有的毒物可经球结膜吸收。

这决定了问诊不是只问“吃了什么”，而要先问：

```text
接触了什么
→ 从哪条路进入
→ 现场暴露是否还在继续
→ 皮肤 / 眼 / 衣物是否仍带毒物
```

所以“脱离毒源”和“去除污染衣物”属于病因控制最前端，而不是事后护理。

**Routing**：CORE｜RECOGNITION｜MI-G

<!-- kianos:kp id="final-f01-kp03" -->
## KP03｜呼吸 + 瞳孔：先识别方向，再结合其它证据

> **主提示：** 呼快2组｜呼慢2组｜散瞳1组｜缩瞳5组｜M/α1逻辑

### Detailed Expansion

### 1｜呼吸方向

当前 Study：

- **呼吸加快**：水杨酸类、甲醇 / 酸性毒物；刺激性气体也可；
- **呼吸减慢**：吗啡、镇静催眠药等抑制呼吸中枢的毒物。

Lecture 的机制串联：

```text
酸 / 水杨酸等
→ 外周化学感受器刺激
→ 呼吸加深加快

吗啡 / 镇静催眠药
→ 呼吸中枢抑制
→ 呼吸减慢甚至呼吸麻痹
```

### 2｜瞳孔方向

- **散瞳**：阿托品、莨菪类等 M 受体阻断方向；
- **缩瞳**：毛果芸香碱、新斯的明、有机磷、氨基甲酸酯、吗啡等。

底层受体：

```text
瞳孔括约肌 M 受体激活 → 缩瞳
M 受体阻断 → 散瞳
```

α1—瞳孔开大肌只作为 Recall 接口，不在这里重建完整自主神经药理。

**边界**：呼吸或瞳孔单点只能缩小范围，不能独立确诊毒物。

**Routing**：CORE｜CONFUSABLE｜RECOGNITION｜MI-G

## KP05｜皮肤颜色与腐蚀痂皮：颜色反映不同毒效应层

> **主提示：** 绀3｜樱桃红1｜鲜红接口1｜黄3｜痂黄棕黑

### Detailed Expansion

### 1｜发绀：先想高铁血红蛋白方向

当前 Study：

- 亚硝酸盐；
- 苯胺；
- 硝基苯；

可形成高铁血红蛋白，出现发绀。

### 2｜红色

- CO 中毒：HbCO 相关，皮肤黏膜可呈樱桃红；
- 氰化物：当前 Lecture 作为“组织不能利用氧、静脉血氧仍高”的鲜红接口。

### 3｜黄染

Lecture列：

- 毒蕈；
- 四氯化碳；
- 鱼胆；

通过肝损伤 / 黄疸方向解释。

### 4｜腐蚀性痂皮颜色

- 硝酸：黄色；
- 盐酸：棕色；
- 硫酸：黑色。

颜色题是识别线索，不改变“先处理腐蚀损伤和生命危险”的优先级。

## KP07｜去污：先区分“未吸收”与“已吸收”

> **主提示：** 未吸收3路｜已吸收2路｜为什么不能混｜气道先行

### Detailed Expansion

```text
未吸收毒物
→ 脱离毒源
→ 去污染衣物
→ 皮肤 / 毛发 / 眼部冲洗
→ 必要时评估胃肠去污

已经吸收
→ 不能再靠洗皮肤解决
→ 进入器官支持、特异解毒或血液净化判断
```

这就是“去污”和“清除”的核心边界。

对意识障碍患者，胃肠去污前必须先考虑**误吸和气道保护**；所以“昏迷既提示中毒重，也可能让洗胃本身变危险”。

**Routing**：CORE｜DECISION｜MI-G

## KP08｜洗胃：哪些情况会让操作本身制造更大伤害？

> **主提示：** 禁忌类别｜各自伤害机制｜腐蚀性毒物边界｜意识/惊厥与气道

### Detailed Expansion

当前 Study 的洗胃禁忌：

| 情况 | 主要风险 |
|---|---|
| 强腐蚀性毒物 | 插管 / 操作可增加穿孔风险 |
| 食管静脉曲张 | 破裂出血 |
| 昏迷 | 吸入性肺炎 / 误吸风险 |
| 惊厥 | 操作诱发 / 加重惊厥风险 |

### 腐蚀性物质

当前 Source列：

- 酸：盐酸、硝酸、硫酸、石炭酸 / 苯酚、醋酸；
- 碱：氢氧化钠、氢氧化钾、氧化汞。

### 强酸强碱不能机械互相中和

当前 Study 的理由是：**强酸强碱中和可大量放热，反而加重组织损伤。**

Lecture同时保留考试口径：

- 强酸可用弱碱如氢氧化铝凝胶等；
- 强碱可用弱酸如果汁 / 食醋等；
- 对强酸不选 NaHCO₃，因为可产生大量 CO₂，增加胃肠膨胀与穿孔风险。

> **边界**：以上仅冻结当前西综 Study 的考试口径，不扩写现代临床毒理学去污指南。

**Routing**：CORE｜DECISION｜BOUNDARY｜MI-G

## KP09｜导泻：不能把“让毒物快点出去”当成无条件正确

> **主提示：** 不单用｜油脂禁因1｜常用4｜Mg禁5｜底层原因1

### Detailed Expansion

当前 Lecture：

- 不推荐单独使用导泻药清除急性中毒患者肠道毒物；
- 通常不用油脂类泻药，以免促进脂溶性毒物吸收；
- 列举甘露醇、硫酸镁、硫酸钠、乳果糖等。

## KP10｜血液净化什么时候进入：不是“中毒=透析”

> **主提示：** 进入条件5｜先看性质3｜方法3｜器官状态1

### Detailed Expansion

当前 Lecture 把血液净化放在以下场景：

- 血中毒物浓度明显升高；
- 中毒严重；
- 昏迷时间长；
- 有并发症；

- 血浆置换；

## KP13｜血浆置换：什么样的毒物负荷更适合直接更换血浆？

> **主提示：** 游离/蛋白结合负荷｜血浆载体｜代表场景｜与透析/灌流比较

### Detailed Expansion

当前 Lecture：血浆置换可用于清除**游离或与蛋白质结合**的毒物，尤其：

- 蛇毒；
- 蕈中毒；
- 砷化氢等溶血毒物。

三种方法一眼分：

| 方法 | 当前 Study 最值得抓的性质 | 典型例 |
|---|---|---|

## KP15｜最终病例算法：身份判断永远服从“生命危险 + 暴露层级”

> **主提示：** 6步主链｜4线索｜3净化｜1出口F2

### Detailed Expansion

以下六步是问题核对顺序，不要求前一步全部结束后才做下一步。生命支持与动态监测贯穿始终，停止暴露、按条件去污、毒效应识别和清除/解毒可按患者危险与处理对象并行推进；关系以§1同一模型为准。

```text
1. 生命危险？
   气道 / 呼吸 / 循环 / 意识 / 惊厥
        ↓
2. 暴露还在继续吗？
   现场、衣物、皮肤、眼、胃肠
        ↓
3. 去污安全吗？
   洗胃禁忌 / 腐蚀 / 昏迷 / 惊厥
        ↓
4. 毒物综合征定位
   呼吸 + 瞳孔 + 皮肤 + 气味 + 器官损伤
        ↓
5. 吸收后怎么办？
   解毒药 + 透析 / 灌流 / 置换 + 器官支持
        ↓
6. 动态复评
   意识、呼吸、循环、酸碱、肝肾、血液
```

看到**针尖样瞳孔 + 大汗流涎 + 肌纤维颤动 + 肺部表现**时，不再停留于“中毒总论”，而进入 **F2 有机磷与胆碱能危象**完整模型。

# 3｜高密度比较表

## 3.1 去污 / 清除 / 解毒 / 支持

| 轴 | 去污 | 促进清除 | 特异解毒 | 器官支持 |
|---|---|---|---|---|
| 处理对象 | 未吸收毒物 | 已吸收毒物 | 特定靶点 / 代谢后果 | 器官功能失败 |
| 时间 | 越早越靠前 | 吸收后按适应证 | 确认 / 高度怀疑后 | 任何生命危险时立即 |
| 例 | 脱衣、冲洗、胃肠去污 | 透析 / 灌流 / 置换 | 纳洛酮、亚甲蓝等 | 气道、呼吸、循环 |
| 主要陷阱 | 操作禁忌 | 不看理化性质 | 以为能替代复苏 | 只支持而不停止暴露 |

## 3.2 三种血液净化

```text
小分子 + 非脂溶

→ 血液灌流

血浆中游离 / 蛋白结合、生物毒 / 特定溶血毒
→ 血浆置换
```
