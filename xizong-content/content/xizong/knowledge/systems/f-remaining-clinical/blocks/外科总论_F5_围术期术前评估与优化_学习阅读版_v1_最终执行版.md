# 1｜Framework｜术前评估的第一问题不是“异常有多少”，而是“手术能等多久”

```text
A｜先定时间窗口，紧急威胁优先（风险评估与必要复苏可并行）
疾病是否立即威胁生命/器官？
├─ 急诊：不能等指标完美，边复苏边处理手术问题
├─ 限期：有短时准备空间，但不能无限拖延
└─ 择期：可先纠正可逆高风险
  急诊、限期、择期手术：区分依据是什么，各自为什么能或不能等？〔3类｜时间容忍度/进展风险｜急诊4例｜限期1类｜择期4例｜优化窗口〕

三条贯穿轴：紧急度 × 可逆性 × 器官储备
  术前总决策：紧急度×器官储备×可逆风险〔3轴｜急诊怎么做｜择期怎么做｜5高危层〕
下列B–D是并行风险检查，不能解释成必须依次走完才开始复苏/决策

B｜器官储备与可优化时间（结论必须返回A）
心 / 肺 / 肝 / 肾 / 神经储备能否承受麻醉、失血与应激？必要时调用各原owner
烟酒/卒中 → 呼吸、循环、神经风险；课程等待时间只在相应可等待情境理解
  戒烟酒与脑卒中：当前 Study 的等待/优化时间怎样重建？〔烟酒4周｜卒中≥2周/最好6周｜目的3｜急诊边界｜当前Study不扩指南〕
肝严重失代偿与肾严重损害不类推；肾可透析部分替代，肝过渡须按原病因/适应证
  肝肾储备：哪些失代偿会改变手术时机，透析又怎样改变耐受性？〔严重肝功能Child分级 vs 严重肾损害｜何时暂缓手术｜如何过渡/透析及耐受｜为何不能类推〕

C｜代谢、修复与出血风险（感染、营养、电解质、贫血/凝血同时评估，不另造疗程）
糖尿病控制方式 → 原课程药物/饮食准备 → 防低血糖与代谢失代偿
  糖尿病术前：饮食、口服药、长效药与胰岛素分别怎样处理？〔饮食型｜口服药｜长效2–3d｜胰岛素晨｜血糖5.6–11.2｜为什么不求正常〕
原Core区分围术期5.6–11.2与P267术前空腹<8.3、尿酮阴性条件，不合成一个阈值
血压稳定/原用药 → 防戒断；正文与附题数字冲突依原语境保留
  高血压术前：用药与精确阈值怎样处理，Source 冲突在哪里？〔药不停｜防1｜正文140/90｜题目160/100｜当前怎么答｜不得静默统一〕
NSAIDs / 抗血小板用药 → 出血风险；停药也有血栓风险，课程天数不是个人处方
  NSAIDs 与抗血小板：不同药物的停药时间怎样重建？〔NSAIDs/ASA/氯吡格雷术前停药多久｜各目标｜桥接边界〕
血小板门槛分一般围术期、再障、ITP三种场景；单位不完整，不可直接执行
  血小板门槛：一般术前与再障/ITP分别属于什么口径？〔一般50｜再障20｜ITP10｜为什么不能互换｜输血主体在哪〕

D｜误吸与局部准备（按手术类型、时间窗口选择）
摄入物类别 → 胃排空差异 → 课程最短禁食时间 → 降低反流/误吸风险
  最短禁食时间：怎样按摄入物类别重建当前 Study 时间？〔清2｜母4｜牛6｜淀粉6｜脂肉8｜目标1〕
胃肠一般准备 vs 大肠额外准备 → 抗生素、流食时间、灌肠与药物接口
  胃肠与大肠手术准备：两者的共同项和额外项是什么？〔胃肠2件+1–2d｜大肠3件+2–3d+两次灌肠｜药2〕
手术开始前备皮 → 切口准备/避免过早后再污染；消毒无菌边界回F3
  备皮最佳时间：手术开始前〔时间1｜目的2｜为什么不越早越好｜无菌接口〕

A–D｜Go / Delay：把所有风险放回允许等待的窗口
  术前 Go / Delay：怎样按紧急度与可逆风险走完决策？〔先3类｜5风险（失代偿/误吸/出血/感染/修复）｜急诊动作｜择期动作｜哪些可等｜最终确认〕
立即边复苏边手术 / 有限时间优化 / 暂缓择期；不把评估清单变成急救串行等待
精确药物/时间/阈值只保留课程口径；个体停药、择期和急诊决策由医疗团队评估
```

## KP01｜急诊、限期、择期手术：区分依据是什么，各自为什么能或不能等？

> **主提示：3类｜时间容忍度/进展风险｜急诊4例｜限期1类｜择期4例｜优化窗口**

### Detailed Expansion

| 类型 | 当前 Study 角色 | 例子 |
|---|---|---|
| 急诊手术 | 延误会迅速危及生命或器官 | 嵌顿/绞窄疝、急性消化道穿孔、急性完全性肠梗阻、大血管破裂 |

## KP02｜术前总决策：紧急度×器官储备×可逆风险

> **主提示：3轴｜急诊怎么做｜择期怎么做｜5高危层**

### Detailed Expansion

```text
手术是否紧急？
→ 器官是否处于失代偿？
→ 营养/感染/贫血/凝血/代谢风险能否快速纠正？
→ 药物和禁食是否已处理？
→ 决定立即、短时优化或暂缓
```

五个高价值风险层：

1. 气道、呼吸与循环不稳定；
2. 严重肝肾功能失代偿；
3. 活动性感染；
4. 贫血、血小板或凝血障碍；
5. 营养不良、高血糖及长期免疫抑制导致的修复失败。

（边界：风险存在不等于一律不能手术；必须放回紧急度。）

**Routing**：CORE + INTEGRATION + MI-G

## KP03｜戒烟酒与脑卒中：当前 Study 的等待/优化时间怎样重建？

> **主提示：烟酒4周｜卒中≥2周/最好6周｜目的3｜急诊边界｜当前Study不扩指南**

### Detailed Expansion

当前 Study：

- 术前戒烟戒酒 **4周**；
- 脑卒中后手术推迟至少 **2周**，最好 **6周**。

这些时间用于择期/限期风险优化，旨在降低呼吸、循环和神经并发症。若手术本身是急诊救命，不能机械套用等待窗口。

**适用边界**：4周及卒中2/6周仅保留当前课程特定口径，不可套用于所有患者，也不能直接据此决定个人手术时机；实际决定需医疗团队结合病情与手术紧急度评估。

**Routing**：SPECIAL + BOUNDARY + MI-D

## KP07｜糖尿病术前：饮食、口服药、长效药与胰岛素分别怎样处理？

> **主提示：饮食型｜口服药｜长效2–3d｜胰岛素晨｜血糖5.6–11.2｜为什么不求正常**

### Detailed Expansion

当前 Study：

- 仅饮食控制：不需特殊准备；
- 口服降糖药：继续至术前 1 天；
- 长效降糖药：术前 2–3 天停；
- 平时用胰岛素：手术日晨停用；
- 维持血糖约 5.6–11.2 mmol/L 的轻度升高状态。

**27 外科精编 Source Precision（PDF P267）**：术前血糖控制目标一般以**空腹血糖 <8.3 mmol/L**为宜；尿糖可以阳性，但**尿酮应阴性**；酮症酸中毒属于择期手术禁忌证。该条是术前考试 Precision，不替代围术期 5.6–11.2 mmol/L 的总体风险控制范围。

Lecture强调不要求强行降至完全正常，以免低血糖。

**适用边界**：上述“手术日晨停用胰岛素”等为课程特定口径，不能套用于所有患者，也不是个人停药指令；现实用药与手术决定需由医疗团队按具体治疗与病情制定。

（边界：具体药物半衰期、SGLT2i等现代分类和胰岛素输注方案不在当前 Source。）

**Routing**：CORE + BOUNDARY + MI-G + MI-D

### Detailed Expansion

稳定原则：

- 继续降压药；
- 避免停药后的戒断 / 反跳；
- 不要求仅因紧张导致的瞬时升高就机械停止手术。

数字冲突：

- 正文写 BP≤140/90 mmHg；
- 附题接受 160/100 mmHg 以下不予特殊处理，另一个病例约150–160/85–95也可手术。

因此：

```text
机制题：优先答继续用药、防戒断、综合稳定性
精确阈值题：按题目所在Source口径与原页核对
```

不得用外部指南静默选一个数字覆盖另一个。

**Routing**：CORE + SOURCE_CONFLICT + MI-G

## KP12｜术前 Go / Delay：怎样按紧急度与可逆风险走完决策？

> **主提示：先3类｜5风险（失代偿/误吸/出血/感染/修复）｜急诊动作｜择期动作｜哪些可等｜最终确认**

### Detailed Expansion

```text
A. 定急诊 / 限期 / 择期
B. 查气道、呼吸、循环及活动性失代偿
C. 查肝肾储备和透析/过渡需求
D. 查感染、营养、血糖、贫血、血小板/凝血
E. 查禁食、胃肠准备、降糖/降压/抗血小板药物
F. 决定：边复苏边手术 / 简短优化 / 暂缓择期
```

上述A–F是问题核对顺序，不要求复苏等到F才开始；威胁优先，评估、复苏与手术决策可按紧急度并行。

典型错误：

- 急诊病人等待所有化验“正常”；
- 择期病人带着可纠正的严重感染或失代偿进入手术；
- 为了“正常血糖”造成低血糖；
- 随意停降压药造成反跳；
- 忽视停药本身的血栓风险边界，而把数字当成现实通用处方。

**Routing**：CORE + INTEGRATION + MI-G
