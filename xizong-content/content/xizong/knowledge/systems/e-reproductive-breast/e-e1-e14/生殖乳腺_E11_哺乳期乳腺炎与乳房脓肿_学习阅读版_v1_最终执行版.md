# 1｜Framework｜从正常泌乳到封闭脓腔

<!-- kianos:framework id="reproductive-e11-framework-main" -->

```text
正常底座：PRL产乳 + OT/肌上皮射乳 + 导管/有效吸吮排空（SR6 Recall）
  正常乳腺如何走到感染：先有“排空失败”〔SR6三层｜淤积｜细菌｜炎症〕
排空不足→乳汁淤积，和细菌入侵共同进入课程感染模型；不是所有淤积必然化脓
  病原入口：乳汁淤积 + 金葡菌经淋巴管〔两前提｜最常菌｜途径1〕
原课金葡菌/淋巴入口保留，不另建抗菌药理课

急性乳腺炎候选：红肿热痛 + 寒战高热/WBC/痛性淋巴等组合
  急性乳腺炎典型像：局部炎症 + 全身感染同时成立〔人群｜局部4｜全身2｜淋巴｜WBC〕
这是典型像，不是必须凑齐全套才可评估
并列鉴别：红肿也可有炎性乳癌等来源，证据不符须进一步评估，癌主体回E12–E14
  急性乳腺炎 vs 炎性乳癌：红肿不等于感染〔年龄方向｜痛？｜寒战高热？｜WBC？｜淋巴结痛？〕

治疗功能与病原两轴并行
├─ 排空：解除淤积，不由“停止患侧直接哺乳”推成完全停止排出乳汁
  治疗第一原则之一：乳汁要排空〔为什么排｜停排的后果｜与抗生素并列〕
└─ 抗感染/哺乳条件：患侧/健侧、严重或乳瘘、药物和禁用名单回原精记
  哺乳与抗感染：按当前 Study 记，不自行现代化〔患侧｜健侧｜严重/乳瘘｜抗菌1｜禁4类〕
这是课程特定配对，不能用作个人停哺乳、回乳用药或抗菌处方，实际由专业评估决定

脓腔评估贯穿，不需等前两轴失败才查
波动/穿刺脓液支持封闭化脓空间 → 当前课程进入切开引流源控制
  什么时候从“乳腺炎”升级为“脓肿模型”〔波动｜穿刺｜封闭空间｜下一动作〕
没有浅表波动不证明不存在深部脓腔；操作与方式由专业人员结合证据处理
空间决定课程切口：表浅放射状，乳晕下边缘弧形，深部/后方下缘弧形
  不同位置的乳房脓肿如何决定切口方向？〔表浅｜乳晕下｜深部/乳房后｜切口方向与解剖关系〕
分隔需处理；大脓腔低位对口引流，使脓液真正排出
  脓肿引流怎样避免残腔与引流不畅？〔分隔｜大脓腔｜低位引流｜为什么只开一个口不够〕

同图回查淤积/感染证据/脓腔空间及处理，继续保留癌鉴别出口
  E11反向算法：淤积—感染—脓腔—源控制〔哺乳期｜炎症证据｜排空｜波动｜切口〕
原Core/表/药名答案可见；源控制、抗感染、局部功能不是依次替代的三阶段
```

一句话：

> **淤积是入口，感染是过程，脓腔是必须改变处理方式的空间门槛。**

## KP04｜治疗第一原则之一：乳汁要排空

> **主提示：为什么排｜停排的后果｜与抗生素并列**

### 快速核对

当前 Study明确强调：

> **排空乳汁。**

原因链：

```text
排空不足
→ 淤积持续
→ 局部感染环境不解除
```

### 详细展开

“抗感染”与“排空”不是二选一。前者处理病原，后者处理促使感染持续的局部功能问题。单纯停止排空会加重乳汁淤积。

**Routing**：CORE｜MECHANISM｜MI-G

## KP05｜哺乳与抗感染：按当前 Study 记，不自行现代化

> **主提示：患侧｜健侧｜严重/乳瘘｜抗菌1｜禁4类**

### 快速核对

当前 Study：

- 患侧停止哺乳；
- 健侧不停止；
- 若感染严重，或脓肿引流后并发乳瘘 → 停止哺乳 + 溴隐亭；
- 抗菌药举例：苯唑西林等；
- 当前 Study 列为禁用：
  1. 四环素类；
  2. 磺胺类；
  3. 喹诺酮类；
  4. 氨基糖苷类。

### 详细展开

这是高风险的 **Source-bound 考试口径**。本文件不使用外部临床指南纠正、替换或扩写，因为当前生产合同要求忠于 Study Source。这些是课程特定口径，不能直接用于个人停哺乳、选择回乳药或决定抗菌药；实际需结合母婴情况、感染与药物风险由专业人员评估。患侧直接哺乳与乳汁排出是两个问题，不将本条“停哺乳”读成自动停止一切排空。

## KP06｜什么时候从“乳腺炎”升级为“脓肿模型”

> **主提示：波动｜穿刺｜封闭空间｜下一动作**

### 快速核对

当前 Study：

```text
出现波动感
→ 穿刺抽脓
→ 仍需切开引流
```

### 详细展开

这一步的结构意义是：

```text
弥漫感染
→ 局部液化、形成封闭脓腔
→ 抗菌药不能替代机械排脓
```

P0 的共同语言：脓肿是器官或组织内局限性化脓性炎症；E11只把这条共同语言落到乳房空间。该链为课程处置方向，穿刺/切开/分隔处理是专业操作；无浅表波动不能单独排除深部脓肿，具体评估和处理方式不由本页自行决定。

**Routing**：CORE｜DECISION_GATE｜MI-G

## KP08｜脓肿引流怎样避免残腔与引流不畅？

## KP09｜急性乳腺炎 vs 炎性乳癌：红肿不等于感染

> **主提示：年龄方向｜痛？｜寒战高热？｜WBC？｜淋巴结痛？**

### 快速核对

按当前 Study 对比：

| 轴 | 急性乳腺炎 | 炎性乳癌 |
|---|---|---|
| 人群 | 初产妇 / 哺乳期方向 | 中老年方向 |
| 疼痛 | 痛 | 可不痛 |
| 寒战高热 | 常有 | 无典型寒战高热 |
| WBC | 升高 | 不以WBC升高为特征 |
| 淋巴结 | 痛性 | 可无痛性肿大 |
| 肿块 | 炎症区域 | 可无明显肿块 |

### 详细展开

这一 KP 只是**安全分流**：

```text
红肿乳房
≠
自动等于感染
```

证据不支持典型感染时，应进一步专业评估并保留炎性乳癌等鉴别，乳腺癌知识回 E12–E14；不在 E11 硬解释，也不将“不典型感染”直接诊断为癌。

**Routing**：CONFUSABLE｜SAFETY_GATE｜MI-G

## KP10｜E11反向算法：淤积—感染—脓腔—源控制

> **主提示：哺乳期｜炎症证据｜排空｜波动｜切口**

### 快速核对

```text
哺乳期红肿疼痛
→ 有无寒战高热 / WBC↑ / 痛性淋巴结？
   ↓
符合急性感染
→ 排空乳汁 + 抗感染
   ↓
有无波动感 / 穿刺脓液？
├─ 未见 → 不能只凭无波动排除深部脓腔，结合专业评估再分流
└─ 有 → 乳房脓肿
        → 按空间选切口
        → 打通分隔 / 充分引流

若红肿但不痛、无发热、WBC不高、淋巴结无痛
→ 转 E12–E14 排炎性乳癌
```

### 详细展开

这是 E11 的最终 Framework Reconstruction：病例必须先判断是否进入了“封闭感染空间”，因为这一结构变化会改变治疗方式。
