# 1｜Framework｜先问“睾丸在哪里”，再问“液体与腹腔通不通”

<!-- kianos:framework id="reproductive-e09-framework-main" -->

```text
共同发育底座：睾丸下降与鞘突延伸；未闭连接积液/斜疝两方向
  鞘突：只建一条最小桥〔下降时带下什么｜未闭→2方向｜疝去哪里〕
完整疝解剖与处理回D14；隐睾和积液是两条鉴别支路，不是必然前后阶段

A｜阴囊空虚：确认睾丸位置方向
  隐睾：先把它定义成“位置没完成”〔阴囊1征｜本质1｜年龄是主轴〕
隐睾当前Study年龄轴：1岁内等待、1岁后短期hCG、2岁前固定
  隐睾在不同年龄节点的处理如何变化？〔自然下降窗口｜何时尝试保守/激素处理｜何时固定｜按 Current Study〕
特殊条件分支另判断：萎缩且对侧正常/双侧均不能下降
  隐睾两个特殊分支〔萎缩+对侧正常｜双侧不能下降｜各1动作〕
上述数字和术式是课程配对，实际儿童不能据此自行等待、用药或决定手术

B｜阴囊/精索区包块：液体证据方向
  鞘膜积液的共同识别：液体，不是含气肠管〔透光｜气液声｜两问入口〕
透光阳性与无气液声支持当前液体模型，并非完整排除其他包块的诊断终点

C｜液体位置与交通双轴，同时问摸到睾丸/平卧变化
  三类鞘膜积液：摸睾丸 × 平卧变化〔睾丸/精索/交通｜摸到？｜平卧？〕
├─ 睾丸鞘膜：难摸睾丸；平卧不消失
├─ 精索鞘膜：能摸睾丸；平卧不消失
└─ 交通性：能摸睾丸；平卧可缩小/消失

D｜若有肠管/气液/咳嗽冲击等证据，回D14疝；不符合积液不等于必定是疝
  阴囊/腹股沟包块反向算法〔空虚｜透光｜摸睾丸｜平卧｜疝接口〕
普通复习沿A或B/C与D鉴别回同一图，原表与答案可见；来源外疾病不在本块重建
```

一句话：

> **隐睾是“位置问题”；鞘膜积液是“液体—交通问题”。**

## KP01｜隐睾：先把它定义成“位置没完成”

- **阴囊空虚感 / 阴囊内未触及正常睾丸**；

## KP03｜隐睾两个特殊分支

> **主提示：萎缩+对侧正常｜双侧不能下降｜各1动作**

### 快速核对

当前 Study：

- 未降睾丸萎缩，且对侧睾丸正常 → **切除未降睾丸**；
- 双侧睾丸均不能下降 → **睾丸自体移植术**。

### 详细展开

这两个分支是当前外科讲义的直接考试配对，不在本 Block用一般医学知识重写。看到课程病例先判断它是否已经进入“特殊分支”，再调用对应 Source 结论；真实手术选择需专业评估，不能仅凭这两句自行决定。

## KP04｜鞘突：只建一条最小桥

> **主提示：下降时带下什么｜未闭→2方向｜疝去哪里**

### 快速核对

```text
睾丸下降
→ 相应腹膜结构随之向阴囊方向延伸
→ 鞘突 / 鞘膜腔形成

若相关通道未闭
→ 可与腹股沟斜疝有关
→ 也可形成交通性鞘膜积液
```

### 详细展开

这里的目标只是解释为什么“腹股沟斜疝”和“交通性鞘膜积液”会共享一个发育接口。完整疝囊、腹股沟管、内环、嵌顿与修补全部留在 D14。

**Routing**：CONNECTION｜RECALL_APPLY｜BOUNDARY

<!-- kianos:kp id="reproductive-e09-kp05" -->
## KP05｜鞘膜积液的共同识别：液体，不是含气肠管

> **主提示：透光｜气液声｜两问入口**

### 快速核对

当前 Study：

- **透光试验阳性**；
- **无气液咕咕声**；
- 下一步只做两问：
  1. 能否摸到睾丸？
  2. 平卧后是否缩小/消失？

### 详细展开

这一步先把“液体性包块”与含气/肠内容物的疝方向分开。不要在第一步就强背三种积液名称；先用这些物理线索支持“液体模型”方向；本块两项线索不能独自确诊或排除全部其他阴囊包块。

**Routing**：RECOGNITION｜DISCRIMINATION｜MI-G

---

<!-- kianos:kp id="reproductive-e09-kp06" -->
## KP06｜三类鞘膜积液：摸睾丸 × 平卧变化

> **主提示：睾丸/精索/交通｜摸到？｜平卧？**

### 快速核对

| 类型 | 能否摸到睾丸 | 平卧后 |
|---|---|---|
| 睾丸鞘膜积液 | × | 不消失 |
| 精索鞘膜积液 | √ | 不消失 |
| 交通性鞘膜积液 | √ | 可缩小 / 消失 |

### 详细展开

```text
先看睾丸是否被积液包裹到难以触及
→ 再看液体是否能随体位与腹腔方向交通
```

因此最有辨别价值的并不是三个病名，而是两个结构问题。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G

---

<!-- kianos:kp id="reproductive-e09-kp07" -->
## KP07｜阴囊/腹股沟包块反向算法

> **主提示：空虚｜透光｜摸睾丸｜平卧｜疝接口**

### 快速核对

```text
阴囊空虚？
├─ 是 → 隐睾 → 按年龄 / 特殊分支
└─ 否 → 有包块
       ↓
透光阳性、无气液声？
├─ 是 → 鞘膜积液
│      ↓
│   摸睾丸 + 平卧变化
│   → 睾丸 / 精索 / 交通性
└─ 有肠管样等疝证据 → 回D14腹股沟疝
   仅不符合积液线索 → 保持其他病因待评估，不直接等同疝
```

### 详细展开

这是 E9 的最终 Framework Reconstruction。病例不先问“背到哪个口诀”，而先问“位置异常还是液体异常；液体是否交通”。

**Routing**：FRAMEWORK_RECONSTRUCTION｜MI-G
