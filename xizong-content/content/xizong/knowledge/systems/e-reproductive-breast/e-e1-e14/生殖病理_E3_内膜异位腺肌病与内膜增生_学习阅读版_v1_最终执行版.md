# E3｜子宫内膜异位、腺肌病与内膜增生
## 同一种激素敏感组织：一条“长错位置”，一条“长得过多”

> **中心问题**：正常子宫内膜为什么一旦出现在错误位置仍会随卵巢激素周期性出血；而宫腔内内膜长期受到雌激素刺激时，又怎样从增生进入异型增生，并最终以“是否有间质浸润”与内膜癌分界？
>
> **Primary ownership**：本 Block 首次完整建立两条彼此独立但共享雌激素接口的病理轴：①**位置轴**：内膜异位症—腺肌病—巧克力囊肿；②**生长轴**：内膜增生不伴不典型—异型增生—内膜腺癌门槛。

# 1｜Framework｜把“位置异常”和“生长异常”分成两条轴

```text
共同组织身份：子宫内膜 = 腺体 + 间质；位置与生长性质分开询问
  E3反向算法：先问位置，再问生长性质〔病灶在哪｜腺体+间质？｜周期出血？｜E持续？｜间质浸润？〕

A｜位置轴：正常身份的组织出现在内膜以外，并非必须子宫以外
  子宫内膜异位症定义：腺体 + 间质，位置在“内膜以外”〔定义2成分｜位置不是“子宫外”而是？｜最常/次常〕
├─ 子宫肌层，且按当前Study距内膜基底层>2mm → 腺肌病/腺肌瘤
  腺肌病：内膜组织进入肌层，名字带“瘤”也不等于肿瘤〔位置1｜距离>？mm｜仍属于哪大类｜“腺肌瘤”≠什么〕
└─ 卵巢等处 → 仍响应卵巢激素 → 随周期变化/反复出血
  异位内膜仍有“周期记忆”，所以会反复出血〔异位后还受谁影响｜周期动作1｜局部后果3｜为什么可反复〕
原Core的局部后果为积血、组织反应与组织损伤；不是三个必经病程阶段
卵巢反复出血 → 体积增大/囊腔 → 陈旧黏稠咖啡色血液 → 巧克力囊肿
  巧克力囊肿：卵巢反复周期性出血 → 陈旧血液〔最常部位1｜周期出血→3步｜咖啡色液体是什么〕
腺肌病和卵巢囊肿是位置条件分支，不是两种疾病顺次转化

B｜生长轴：在原位的增殖信号与组织性质
正常周期E促进增生；病理持续/过强E刺激可使内膜腺体或间质增生
  正常增生期和病理性内膜增生共享一个上游：雌激素〔上游激素1｜正常时做什么｜持续过强→什么｜不是哪个激素〕
按组织形态区分不伴不典型与异型增生，风险不同，不把分类画成人人必经的癌变链
  内膜增生两类：不伴不典型 vs 异型增生〔2类｜癌风险1–3% / 1/3｜背靠背轻/明显｜数字MI-D〕
原课程1–3% / 约1/3保留精记；背靠背/更拥挤不是单独癌证据
异型增生是癌前但无内膜间质浸润；出现间质浸润才越过当前Study癌的边界
  异型增生何时跨到子宫内膜癌？〔癌前 vs 癌｜决定性结构证据1｜不要用“更挤”替代〕
E2基底膜与本处间质是器官特异观察条件，不能只靠名字带“瘤”或组织挤就判断

A/B｜回到位置与性质双轴
共享E/P生理接口，不意味着异位症必然导致内膜增生或内膜癌；具体临床管理后置
```

关键：两条轴不要互相替代。

- 异位症的中心是**长错地方**；
- 增生症的中心是**在原位长得过多 / 过乱**。

## KP01｜子宫内膜异位症定义：腺体 + 间质，位置在“内膜以外”

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 子宫内膜异位症 Q1–Q2

## KP02｜腺肌病：内膜组织进入肌层，名字带“瘤”也不等于肿瘤

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 子宫内膜异位症 Q1  
> **主提示：位置1｜距离>？mm｜仍属于哪大类｜“腺肌瘤”≠什么**

### 快速核对

当前 Study：

- 子宫内膜腺体和间质异位于**子宫肌层**；
- 且距子宫内膜基底层 **> 2 mm**；

### Detailed Expansion

这里训练的是病理命名陷阱：

```text
名称含“瘤”
≠
一定是克隆性肿瘤
```

## KP03｜异位内膜仍有“周期记忆”，所以会反复出血

> **讲义定位 →** 病理 Lecture PDF P98；SR3 Recall  
> **主提示：异位后还受谁影响｜周期动作1｜局部后果3｜为什么可反复**

### 快速核对

```text
异位内膜仍受卵巢激素影响
→ 随周期发生变化
→ 周期性反复出血
→ 局部积血 / 组织反应
```

### Detailed Expansion

“异位”改变了位置，没有把内膜变成对激素完全失去反应的组织。因此正常周期的时间信号被带到了错误空间，结果不是月经血顺利排出，而是局部反复出血和组织损伤。

**Routing**：CORE｜CONNECTION｜MI-G

## KP04｜巧克力囊肿：卵巢反复周期性出血 → 陈旧血液

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 子宫内膜异位症 Q3  
> **主提示：最常部位1｜周期出血→3步｜咖啡色液体是什么**

### 快速核对

```text
卵巢内异位内膜
→ 周期性反复出血
→ 卵巢体积增大、形成囊腔
```

## KP05｜正常增生期和病理性内膜增生共享一个上游：雌激素

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 内膜增生 Q1；SR3 Recall

### 快速核对

- 正常周期：雌激素促进内膜**增生期**；

- 因此病理性增生不是一条完全陌生机制，而是正常“增生”信号失去合适时相 / 强度。

### Detailed Expansion

SR3已经完整建立 E 与 P 的正常靶组织方向，E3只调用其中一条：

```text
E → 内膜增生
```

不重新学习整个月经周期。

## KP06｜内膜增生两类：不伴不典型 vs 异型增生

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 内膜增生 Q2  
> **主提示：2类｜癌风险1–3% / 1/3｜背靠背轻/明显｜数字MI-D**

### 快速核对

当前 Study：

| 类型 | 腺体形态 | 进展为内膜腺癌风险 |
|---|---|---|
| 增生不伴不典型性 | 腺体增多，可出现背靠背 | 约 1–3% |
| 异型增生 | 明显背靠背 + 异型 | 约 1/3 |

### Detailed Expansion

不要把“背靠背”当成唯一癌证据。当前 Source 中增生不伴不典型也可有腺体拥挤 / 邻接；**异型**和最后的**间质浸润**才决定进一步身份。

比例属于 MI-D；第一轮先建立风险方向：

```text
不伴不典型 < 异型增生 < 已发生浸润癌
```

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-G / MI-D

## KP07｜异型增生何时跨到子宫内膜癌？

> **讲义定位 →** 病理 Lecture PDF P98｜Outline U011 内膜增生 Q3  
> **主提示：癌前 vs 癌｜决定性结构证据1｜不要用“更挤”替代**

### 快速核对

- 子宫内膜异型增生：癌前病变；
- **无子宫内膜间质浸润**；

```text
宫颈：看基底膜
内膜：看内膜间质浸润
```

不能把同一个词机械搬到所有器官；真正共同的是“有没有越过原本的组织边界”。

## KP08｜E3反向算法：先问位置，再问生长性质

> **主提示：病灶在哪｜腺体+间质？｜周期出血？｜E持续？｜间质浸润？**

### 快速核对

```text
腺体 + 间质出现在错误位置
→ 异位症支路
→ 若肌层 + >2mm → 腺肌病
→ 若卵巢反复出血 → 巧克力囊肿

病灶仍在宫腔内膜
+ E持续刺激
→ 增生支路
→ 不伴不典型 / 异型
→ 最后问有无间质浸润
```

### Detailed Expansion

E3最核心的抽象能力是把“组织身份”和“组织位置”拆开：正常组织出现在错误位置可以致病；同一位置上的组织也可以因为增殖秩序失控而致病。

**Routing**：CORE｜DECISION｜CONFUSABLE｜MI-G

# 5｜Memory Routing

## MI-G

- 内膜异位症 = 腺体 + 间质出现在内膜以外；
- 卵巢最常见；
- 异位组织仍响应激素 → 周期性出血；
- 巧克力囊肿 = 陈旧血液；
- E持续刺激 → 内膜增生；
- 两类增生；
- 异型增生是癌前；
- 内膜癌关键门槛 = 间质浸润。

## MI-D

- 腺肌病 >2 mm；
- 好发部位完整排序；
- 1–3% vs 1/3；
- 背靠背的完整组织学细节；
- 完整妇科症状、检查和治疗。

以下用于本块模型查漏与按需自测；普通复习可看答案，不作为完成或后续学习门槛：

1. 为什么子宫内膜异位症不是“内膜必须跑到子宫外”；
2. 腺肌病和异位症是什么包含关系；
3. 为什么异位内膜仍会周期性出血；
4. 巧克力囊肿里的咖啡色液体是什么；
5. 正常增生期与病理性内膜增生为什么都能连到雌激素；
6. 两类内膜增生的风险方向；
7. 异型增生和内膜癌最关键的门槛是什么。

> **并行下一 Block**：E4 子宫平滑肌瘤 / 肉瘤。E3处理“内膜”，E4切换到“平滑肌”，不要把腺肌病的“肌”字误当平滑肌肿瘤。
