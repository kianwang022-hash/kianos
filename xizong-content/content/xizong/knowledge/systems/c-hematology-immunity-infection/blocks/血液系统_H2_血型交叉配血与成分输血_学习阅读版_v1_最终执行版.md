# H2｜血型、交叉配血与成分输血
## 不是“什么血型能给谁”一张表，而是追踪抗原、抗体、方向、剂量和输入成分

> **中心问题**：供者的红细胞、血浆蛋白或免疫细胞进入受者后，为什么可能发生凝集、溶血、过敏、容量负荷或代谢紊乱；怎样用 ABO / Rh、主次侧交叉配血和成分选择，把风险限制在可接受范围？

> **文件性质**：血液系统第二个 canonical Block，也是输血的全局唯一 Primary。后续失血、再障、白血病、围术期、烧伤与移植只 Recall / Apply，不重新建立第二套输血模型。

# 1｜总 Framework

<!-- kianos:framework id="hematology-h02-framework-main" -->

```text
供者成分进入受者
        ↓
① 细胞抗原层
供者RBC上的ABO / Rh等抗原
        ↓
受者血浆抗体识别？
        ↓
凝集 → 补体 / 清除 → 溶血

② 血浆抗体层
供者血浆中的抗体
        ↓
是否攻击受者RBC？
        ↓
风险取决于抗体、血浆量、稀释与配血

③ 免疫蛋白 / 细胞层
血浆蛋白、白细胞、淋巴细胞
        ↓
发热 / 过敏 / GVHD等

④ 容量与代谢层
输入速度、总量、库存血成分
        ↓
肺水肿｜高K｜低Ca｜低温｜碱中毒｜凝血异常
```

所以输血前不是只问“ABO一样吗”，而是：

```text
需要什么成分
→ 血型 / 抗体是否相容
→ 主次侧交叉配血
→ 选择最小必要成分
→ 控制量和速度
→ 监测反应
```

# 1A｜同一输入风险模型上的自然节点〔完整 Prompt〕

原总Framework的四层风险与输血决策流程在这里合读；①–④是同一次输入可并存的风险层，不是病情依次经历的四阶段。各节点的解释与精确答案仍取本文件同标题Core；初学展开，复习缩短解释，主次方向和条件不变。

```text
供者成分进入受者
│
│  ①②共同的抗原—抗体关系：相应抗体桥联RBC→凝集；补体/清除→溶血
│  抗原—抗体方向：凝集和溶血先看谁攻击谁〔RBC带什么｜血浆带什么｜桥联凝集｜补体溶血｜方向2条〕
│  抗体性质同时约束两方向；IgM/IgG的“主要类型”与胎盘边界不能省略
│  天然IgM vs 免疫IgG：是否需致敏、能否过胎盘〔IgM冷/大/胎盘｜IgG温/小/胎盘｜天然vs免疫｜自身抗原无自身抗体〕
│
├─① 细胞抗原层：供者RBC上的ABO/Rh抗原 → 受者血浆抗体识别？
│    ├─ABO身份：前体→H→A/B；O保留H，孟买缺H
│    │  H抗原是ABO底座：O型有H，孟买型连H也没有〔前体→H→A/B｜O有什么｜孟买缺什么/有3抗体｜ABH还在哪〕
│    │  A1/A2是该抗原身份内的比较，不是先后阶段
│    │  A1与A2：A2不是“A2抗原”，而是缺少A1抗原〔A1抗原3｜A2抗原2｜各自抗体｜A2/A2B误判谁｜表格门禁〕
│    │  遗传只确定同一ABO身份的来源，不替代抗体检测
│    │  ABO遗传：IA与IB共显性，i隐性〔3等位｜A/B关系｜i关系｜4表型6基因型｜O唯一｜父母各给1〕
│    └─Rh暴露与致敏：无天然抗D；首次暴露主要建立致敏（当时未必立即明显反应）→免疫抗体→再次暴露风险
│       Rh / D致敏：第一次主要“建立记忆”，后续暴露才容易反应〔D位置/性质｜无天然抗体｜首次→2–4月｜再次｜Rh母胎时相｜抗D预防〕
│    → 受者抗体攻击供者RBC：主侧风险 → 凝集/清除/溶血
│
├─② 血浆抗体层：供者血浆抗体 → 是否攻击受者RBC？
│    → 次侧风险取决于实际抗体、血浆量、稀释与配血
│    ①②一起判断相容；O/AB标签不能替代成分与攻击方向
│
├─③ 免疫蛋白/细胞层：血浆蛋白、白细胞、活性淋巴细胞
│    → 过敏 / 发热 / GVHD等；GVHD为供者淋巴细胞攻击受者
│
└─④ 容量与代谢层：输入速度、总量、库存血成分
     ├─过快/过多 → 循环负荷 → 肺水肿
     └─库存血成分负担 → 碱 / K / Ca / 温 / 凝的并行改变
        大量输血：一袋袋库存血把五类负担同时带进来〔碱/K/Ca/温/凝5类｜各自机制｜谁最先危膜｜与K5 Recall〕
        “最先”需以实际生命危险为条件；不能从五项名单推出固定发生顺序

同一四层风险用于原有输血决策（决策先后，不是疾病因果链）：
需要什么成分：当前缺携氧、凝血因子还是容量？
  输血四原则：同型、成分、自体、交叉配血〔4原则｜为什么成分优先｜Rh重点人群｜全血不是默认｜缺什么补什么〕
  ↓
血型/抗体是否相容：回看①②的ABO身份、抗体性质及Rh致敏
  ↓
主次侧交叉配血：用两条攻击方向验证；主侧阳性不能输
  主侧vs次侧：主侧阳性绝不能输，次侧阳性只属旧应急接口〔主侧谁RBC+谁血清｜次侧反向｜相合/不合/基本相合｜应急3条件｜主侧为何优先〕
  次侧旧应急接口保留紧急、少量、缓慢及低效价条件，不常规化
  ↓
选择最小必要成分：按缺失功能与负担选；失血量、Hb是不同判断轴
  失血量决定补什么：先恢复循环，再恢复携氧〔失血4档｜晶/胶｜何时加浓红｜>30%比例｜先灌注后携氧〕
  成分血选择：缺什么功能，就尽量只补什么〔浓红3阈｜洗涤/去白/辐照区别｜FFP｜冷沉淀3成分｜心/肾/过敏/反复输血〕
  自体是输入来源的另一种选择，仍要检查血液来源/污染边界
  自体输血：同一个人供给自己，免疫风险低，但血液来源必须安全〔回输什么｜3方式｜脾裂/宫外孕｜肝裂为何否｜开放伤>4h｜预存4数字｜稀释顺序〕
  ↓
控制量和速度：回看④容量与代谢负担，不省掉免疫风险
  ↓
监测反应：把①②③④及污染线索按被伤害的对象分流
  输血反应第一分流：发热、溶血、过敏还是超负荷〔最常见/最严重｜高热+低压+腰痛｜无高热｜无低压｜急肺水肿｜污染/GVHD〕
  ├─溶血：免疫破坏 + 循环伤害 + 肾负担；保留有尿/无尿与延迟条件
  │  溶血反应：供受血不合后同时伤循环、红细胞和肾〔表现8｜Hb尿/黄疸｜肾损伤链｜Study处理5｜有尿/无尿分流｜延迟1–2周〕
  └─发热、过敏、容量超负荷与GVHD的共同辨别范围
     发热、过敏、超负荷与GVHD：病因对象不同，处理方向也不同〔发热人群2｜过敏表现5/重症2药｜超负荷因1果1｜GVHD谁打谁｜完整机制去哪〕
```

本图保留当前课程口径。H2-SC01/03不决定Rh阴性者必有抗D或AB可忽视配血；H2-SC02不冻结洗涤红残留细胞。A1/A2原表、主次侧原图及其余真正依赖图像的结论仍按§6核对。完整正常止血、容量/酸碱与GVHD回各自既有owner，不在这里扩成另一门课。

## KP01｜抗原—抗体方向：凝集和溶血先看谁攻击谁

> **主提示：RBC带什么｜血浆带什么｜桥联凝集｜补体溶血｜方向2条**

### 1｜ABO / Rh风险的共同本质

红细胞膜上的血型抗原可与相应抗体结合。抗体具有多个抗原结合位点，可在多个 RBC之间形成桥梁：

```text
抗体桥联多个RBC
→ 红细胞凝集

进一步激活补体或被单核—巨噬系统清除
→ 溶血
```

### 2｜输血有两个攻击方向

```text
受者血浆抗体
→ 攻击供者RBC
→ 主侧风险，优先级最高

供者血浆抗体
→ 攻击受者RBC
→ 次侧风险，受输入血浆量和稀释影响
```

这就是主侧 / 次侧交叉配血的逻辑基础。

### 3｜为什么成分输血能降低风险

只输入患者真正缺少的成分，可减少：

- 不必要的红细胞抗原；
- 不必要的供者血浆抗体和蛋白；
- 过多容量；
- 不必要的白细胞 / 淋巴细胞暴露。

**Routing**：CORE｜CONNECTION｜MI-G

## KP02｜H抗原是ABO底座：O型有H，孟买型连H也没有

> **主提示：前体→H→A/B｜O有什么｜孟买缺什么/有3抗体｜ABH还在哪**

### 1｜糖链逐层加成

ABO抗原特异性取决于红细胞膜糖链的组成和连接顺序。

```text
前体物质
→ 加工形成H抗原
→ 在H基础上加A或B决定簇
→ A / B / AB

只保留H
→ O型
```

所以：

- O型 RBC仍有 H抗原；
- 孟买型因 H基因相关缺陷，**没有H抗原**。

### 2｜孟买型为什么不能按普通O型理解

孟买型血清可有：

- 抗A；
- 抗B；
- 抗H。

因此除同型者外，可与常规 ABO各型 RBC不相容。

### 3｜ABH抗原不只在RBC

A、B、H抗原还可见于：

- 淋巴细胞；
- 血小板；
- 多数上皮和内皮细胞；
- 可溶性形式进入体液，唾液较丰富。

（易混：Rh / D抗原在当前 Study强调只位于 RBC膜，且其特异性主要由蛋白质氨基酸序列决定。）

**Routing**：CORE｜CONFUSABLE｜SPECIAL｜MI-G

## KP03｜A1与A2：A2不是“A2抗原”，而是缺少A1抗原

> **主提示：A1抗原3｜A2抗原2｜各自抗体｜A2/A2B误判谁｜表格门禁**

### 1｜核心差异

| 血型 | RBC抗原｜Study | 血清抗体｜Study |
|---|---|---|
| A1 | H、A、A1 | 抗B |
| A2 | H、A | 抗A1、抗B |
| B | H、B | 抗A1、抗A |
| A1B | H、A、A1、B | 无相应ABO抗体 |
| A2B | H、A、B | 抗A1 |
| O | H | 抗A1、抗A、抗B |

关键：

> A2型没有所谓“A2抗原”；它是有A抗原、但没有A1抗原。

### 2｜为什么会误判

A2 / A2B的A相关凝集反应可能较弱，又可带抗A1，当前 Study提示容易在血型鉴定中被误认为 B型或 O型方向。

这属于高风险视觉表格，必须回 P83原图核对，不靠一句口诀替代表格。

**Routing**：CORE｜CONFUSABLE｜VISUAL_ONLY｜MI-D

## KP04｜天然IgM vs 免疫IgG：是否需致敏、能否过胎盘

> **主提示：IgM冷/大/胎盘｜IgG温/小/胎盘｜天然vs免疫｜自身抗原无自身抗体**

| 轴 | 天然抗体 | 免疫抗体 |
|---|---|---|
| 主要类型 | IgM | IgG |
| 温度身份 | 冷抗体接口 | 温抗体接口 |
| 分子大小 | 大 | 小 |
| 胎盘 | 不能通过 | 可通过 |
| 形成 | 自然存在方向 | 接触外源性红细胞抗原后产生 |

ABO体系以天然 IgM为主要考试方向，但当前 Study也提示正常成人可存在一定 IgG型 ABO抗体；Rh系统则没有天然抗D，主要是接触D抗原后产生的 IgG。

共同规律：

> 正常情况下，血清中不会存在攻击自身 RBC血型抗原的相应抗体。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP05｜ABO遗传：IA与IB共显性，i隐性

> **主提示：3等位｜A/B关系｜i关系｜4表型6基因型｜O唯一｜父母各给1**

当前 Study按孟德尔遗传组织：

- `Iᴬ`与`Iᴮ`共显性；
- `i`为隐性；
- 每人从父母各获得一个等位基因。

| 表型 | 可能基因型 |
|---|---|
| A | IᴬIᴬ、Iᴬi |
| B | IᴮIᴮ、Iᴮi |
| AB | IᴬIᴮ |
| O | ii |

同一表型不一定同一基因型；O型只有 `ii`。血型可辅助亲子关系判断，但不单独作为最终身份鉴定工具。

**Routing**：CORE｜RECOGNITION｜MI-D

## KP06｜Rh / D致敏：第一次主要“建立记忆”，后续暴露才容易反应

> **主提示：D位置/性质｜无天然抗体｜首次→2–4月｜再次｜Rh母胎时相｜抗D预防**

### 1｜Rh抗原身份

- 主要考试抗原：D抗原；
- 位于 RBC膜；
- 特异性取决于膜蛋白氨基酸序列；
- Rh阳性：有D抗原；Rh阴性：无D抗原。

### 2｜输血致敏主链

```text
从未接触D抗原的Rh−者
→ 第一次暴露Rh+ RBC
→ 当时未必立即发生明显抗D反应
→ 产生免疫性IgG抗D
→ Study：2–4个月达高峰
→ 再次接触Rh+ RBC时风险增大
```

### 3｜母胎接口

```text
Rh−母亲 + Rh+胎儿
→ 妊娠晚期 / 分娩时胎儿RBC较多进入母体
→ 母体致敏
→ 后续Rh+妊娠时，IgG抗D可过胎盘
→ 新生儿溶血风险
```

当前 Study以“第二胎更典型”组织；生育第一胎后及时给予特异性抗D免疫球蛋白，可中和进入母体的D抗原并减少致敏。

### 4｜SOURCE_CONFLICT H2-SC01

生理 P85题旁存在一个“Rh+受者接受Rh−供者血、因供者可能有D抗体而发生次侧凝集”的历史例子，与同节“Rh系统无天然抗D、需外源刺激致敏”的主干不能自动等同。

本文件处理：

```text
不把“Rh−供者必有抗D”写成规则
→ 是否存在意外抗体，以真实抗体筛查 / 交叉配血为准
→ 原题旁例子保留为SOURCE_CONFLICT，回原页核对
```

## KP07｜输血四原则：同型、成分、自体、交叉配血

> **主提示：4原则｜为什么成分优先｜Rh重点人群｜全血不是默认｜缺什么补什么**

### 1｜四个原则

1. 尽量同型输血；
2. 优先成分输血；
3. 适合时采用自体输血；
4. 输血前必须完成血型鉴定和交叉配血。

对于育龄女性和需反复输血者，当前 Study特别强调 Rh相合与抗Rh抗体风险。

### 2｜“贫血”不等于“缺所有成分”

```text
主要缺携氧能力
→ 优先红细胞成分

主要缺凝血因子
→ 选择血浆 / 冷沉淀等相应成分

失血伴容量不足
→ 容量复苏 + 按失血程度补红细胞 / 全血接口
```

所以“全血”不是贫血默认答案；选择成分要与缺失功能对应。

## KP08｜主侧vs次侧：主侧阳性绝不能输，次侧阳性只属旧应急接口

> **主提示：主侧谁RBC+谁血清｜次侧反向｜相合/不合/基本相合｜应急3条件｜主侧为何优先**

### 1｜两侧配血

```text
主侧：
供者RBC + 受者血清
→ 检测受者是否会攻击供者RBC

次侧：
受者RBC + 供者血清
→ 检测供者血浆抗体是否会攻击受者RBC
```

### 2｜结果

| 结果 | 当前 Study身份 |
|---|---|
| 主、次侧均不凝集 | 配血相合 |
| 主侧凝集 | 配血不合，不能输 |
| 主侧不凝集、次侧凝集 | 配血基本相合 |

主侧优先，因为输血主要需要供者 RBC，不能允许它们被受者血浆直接攻击。

### 3｜“基本相合”的旧应急口径

当前 Study保留：

- 紧急；
- 少量 `<200 mL`；
- 缓慢；
- 低抗体效价 `<1:200`。

这是当前考试 Source的历史应急接口，不能扩写成日常跨型输血原则。现代临床实际执行以血库和当期规范为准。

### 4｜“万能供者 / 万能受者”只能拆成成分与方向判断

#### O型“万能供者”

O型 RBC不带A / B抗原，但 O型血浆含抗A、抗B。输入大量**全血**时，供者血浆抗体仍可攻击受者 RBC，因此不能把“O型万能”当常规规则。

#### AB型“万能受者”｜H2-SC03

在只讨论 ABO 的**红细胞成分**时，AB受者血浆缺少抗A / 抗B，兼容方向较宽；但 P85历史文字又把“AB受者自身RBC带A / B抗原”写成接受其他血型时“必然被溶”的理由，混淆了：

- 受者血浆攻击供者 RBC；
- 供者血浆攻击受者 RBC；
- 红细胞成分与全血。

本文件不接受该句的字面泛化，也不静默删除：

```text
H2-SC03
→ “万能”标签一律拆回成分 + 攻击方向
→ 最终以抗体筛查和交叉配血裁决
```

稳定主干只有：

> **不使用“万能供者 / 受者”替代成分、方向和交叉配血。**

**Routing**：CORE｜CONFUSABLE｜BOUNDARY｜MI-G｜MI-D

## KP09｜失血量决定补什么：先恢复循环，再恢复携氧

> **主提示：失血4档｜晶/胶｜何时加浓红｜>30%比例｜先灌注后携氧**

按当前外科 Study：

| 失血量 | 当前 Study补充方向 |
|---|---|
| `<10%`，约 `<500 mL` | 通常不输血，可代偿 |
| `10%–20%`，约 `500–1000 mL` | 晶体液、胶体液 |
| `20%–30%`，约 `1000–1500 mL` | 晶体 / 胶体 + 浓缩红细胞 |
| `>30%`，约 `>1500 mL` | 晶体 / 胶体 + 1/2浓缩红 + 1/2全血 |

判断逻辑：

```text
早期失血
→ 第一危险是有效循环量下降
→ 先恢复灌注

失血继续增加
→ RBC与Hb丢失达到需要补充的程度
→ 再恢复携氧能力
```

（边界：精确复苏液种类、速度、目标和大量失血协议不在当前 Source完整展开。）

## KP10｜成分血选择：缺什么功能，就尽量只补什么

> **主提示：浓红3阈｜洗涤/去白/辐照区别｜FFP｜冷沉淀3成分｜心/肾/过敏/反复输血**

### 1｜浓缩红细胞

- 当前 Study称最常用；
- 主要补充携氧能力；
- 心功能不全等需要减少不必要容量者更适合。

Study阈值接口：

```text
Hb >100 g/L：通常不输
Hb <70 g/L：输浓缩红
Hb 70–100 g/L：结合情况，心衰等可考虑
```

不扩写外部限制性输血策略。

### 2｜洗涤红细胞

当前主干：

- 减少血浆和血浆相关抗体 / 蛋白；
- 用于 IgA低下、既往严重过敏等方向；
- 血浆量少，肾功能不全等容量 / 血浆负担接口。

### 3｜少白 / 去白红细胞

当前 Study方向：

- 多次输血；
- 经产妇；
- 预计需反复输血者，如再障、地贫、白血病。

核心是减少白细胞抗原相关反应。

### 4｜辐照红细胞

```text
灭活供者淋巴细胞
→ 预防输血相关GVHD
```

用于移植准备、某些严重免疫缺陷 / 血液肿瘤接口；完整 GVHD机制在 H14。

### 5｜新鲜冰冻血浆与冷沉淀

- FFP：凝血障碍、肝病等凝血因子补充方向；
- 冷沉淀：纤维蛋白原缺乏、甲型血友病 / FⅧ接口；
- 当前原图提示冷沉淀含较高浓度 FⅠ、FⅧ与vWF。

### 6｜SOURCE_CONFLICT H2-SC02

27外科精编当前条目在洗涤红细胞制品相关文字出现“含无功能白细胞和血小板”的文字，结合相邻语境和制品身份存在“含 / 去除”转写歧义。

本文件不静默改字，只冻结安全主干：

```text
洗涤红
→ 主要减少血浆相关抗体 / 蛋白和血浆量

去白红
→ 主要减少白细胞相关抗原暴露
```

具体制备后残留成分回 P190原图核对。

**Routing**：CORE｜CONFUSABLE｜BOUNDARY｜VISUAL_ONLY｜MI-G｜MI-D

## KP11｜输血反应第一分流：发热、溶血、过敏还是超负荷

## KP13｜发热、过敏、超负荷与GVHD：病因对象不同，处理方向也不同

> **主提示：发热人群2｜过敏表现5/重症2药｜超负荷因1果1｜GVHD谁打谁｜完整机制去哪**

### 1｜发热反应

当前 Study提示多见于：

- 多次输血；
- 经产妇；

与针对白细胞等成分的免疫反应接口相关，血压多正常。

### 2｜过敏

表现：

- 瘙痒；
- 荨麻疹；
- 会厌 / 喉头水肿；
- 支气管痉挛；
- 严重时休克。

重症按 Study：肾上腺素 + 糖皮质激素。其典型边界是**多无发热**。

### 3｜循环超负荷

```text
输血过快 / 过多
→ 容量负荷急升
→ 急性肺水肿
```

与溶血的腰痛、Hb尿和黄疸方向不同。

### 4｜输血相关GVHD

```text
供者有活性的淋巴细胞
→ 在免疫缺陷受者内存活
→ 攻击受者组织
→ 可出现全血细胞减少
```

攻击方向与普通输血溶血不同：

- 溶血：受者抗体多攻击供者 RBC；
- GVHD：供者淋巴细胞攻击受者。

完整排斥 / GVHD在 H14。

## KP15｜自体输血：同一个人供给自己，免疫风险低，但血液来源必须安全

> **主提示：回输什么｜3方式｜脾裂/宫外孕｜肝裂为何否｜开放伤>4h｜预存4数字｜稀释顺序**

### 1｜共同身份

收集患者自身血液，经处理后回输浓缩红细胞，可减少同种异体免疫相关风险。

### 2｜三种方式

当前 Study例子：

- 外伤性脾破裂；
- 异位妊娠破裂。

先采的血浓度高

- Hct ≥30%；
- 择期手术前约1个月开始；
