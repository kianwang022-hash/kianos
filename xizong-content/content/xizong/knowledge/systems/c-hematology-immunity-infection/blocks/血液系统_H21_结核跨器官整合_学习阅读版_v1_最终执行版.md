# 0｜这不是“结核第二讲”，而是一张跨器官路由图

```text
结核杆菌进入
→ 巨噬细胞吞噬但不能彻底清除
→ 细胞免疫尝试局限病原
+ 迟发型变态反应造成干酪样坏死
→ 结核肉芽肿
        ↓
感染经历与宿主免疫背景共同影响表现
├─ 初次感染 / 尚无特异免疫：原发，淋巴 / 血道播散倾向
└─ 已有免疫 / 内源复发：继发，肺上部、支气管播散、空洞倾向
另叠加宿主条件：HIV等免疫缺陷可使病原多、播散多，但空洞 / 肉芽肿 / PPD可少
        ↓
器官落点
肺｜胸膜｜肾 / 泌尿｜肠 / 腹膜｜骨关节｜脑膜｜生殖｜淋巴结
        ↓
每个器官只调用其canonical诊疗模型
```

H21的任务是：看到某个器官结核时，能从共同机制解释“怎么来的、为什么是这种形态、下一步回哪个Block”，而不是重复所有药物、影像和术式。

# 1｜Framework｜结核有三张坐标图

## 1.1 免疫—损伤图

```text
巨噬细胞吞噬TB
→ 上皮样细胞聚集
→ Langhans巨细胞 + 淋巴细胞 + 少量成纤维细胞
→ 肉芽肿局限病原

与此同时
蜡质相关变态反应
→ 干酪样坏死
→ 排出后形成空洞
→ 可持续排菌与传播
```

## 1.2 宿主背景图

| 背景 | 主要播散方向 | 典型倾向 |
|---|---|---|
| 原发 / 初次感染 | 淋巴、血道 | 儿童、原发复合征、肺门结核、肺外播散 |
| 继发 / 已有免疫 | 支气管为主 | 成人、肺上部、上旧下新、空洞、局限肺内 |
| HIV免疫缺陷 | 血行与多部位 | 下肺、肺门 / 纵隔结节、肺外播散；空洞、肉芽肿、PPD可少 |

上述HIV行是可叠加的宿主条件，不是与原发/继发互斥的第三病型，也不是继发结核的下一阶段；原病理不带图P112即在继发性肺结核下列“若合并AIDS”。

## KP01｜结核的双重免疫逻辑：控制病原，也制造坏死

> **主提示：吞噬未清｜细免=控制｜迟发=损伤｜共同结果2**

### Detailed Expansion

结核杆菌进入后，单核—巨噬细胞吞噬却不能彻底清除。细胞免疫把病灶组织成肉芽肿，限制扩散；迟发型变态反应同时造成组织损伤和干酪样坏死。

因此：

```text
肉芽肿 = 控制结构
干酪坏死 = 免疫相关组织损伤
```

二者不是前后完全分离，而是在结核病中并存。完整免疫细节不扩写到当前Source之外。

**Routing**：CORE｜CONFUSABLE｜MI-G

## KP02｜菌体细胞壁3成分：多糖—蜡质—蛋白质

> **主提示：3成分｜免疫1｜坏死/空洞1｜皮肤试验1**

### Detailed Expansion

当前病理Study口径：

- 多糖 → 血清反应等免疫应答；
- 蜡质 → 干酪样坏死与空洞；
- 蛋白质 → 皮肤红斑与PPD阳性。

结核杆菌不以产生毒素作为当前致病主线；致病性主要挂在菌体细胞壁成分和宿主免疫反应上。

**Routing**：CORE｜MI-G｜MI-D

## KP03｜结核结节：4类细胞 + 中央干酪坏死

> **主提示：细胞4｜巨细胞核形｜中央1｜坏死大体｜镜下1**

### Detailed Expansion

典型结核结节：

- 上皮样 / 类上皮细胞：吞噬TB后的单核—巨噬细胞；
- Langhans巨细胞：多核，胞核呈U形或周边排列；
- 大量淋巴细胞；
- 少量反应性增生的成纤维细胞；
- 中央常有干酪样坏死。

干酪样坏死大体干燥、淡黄、细腻、质实；镜下为无结构嗜酸性颗粒物。当前Source称其为彻底的凝固性坏死。

**Routing**：CORE｜VISUAL_ONLY｜MI-G

## KP04｜原发性肺结核：无特异免疫，所以更会淋巴 / 血播

## KP05｜继发性肺结核：已有免疫，所以更局限、更空洞、更沿支气管

> **主提示：人群｜来源主｜部位3｜播散1｜上旧下新｜空洞**

### Detailed Expansion

继发性肺结核：

- 成人多见，以静止原发灶内源复发为主；
- 宿主已建立特异免疫；
- 好发上叶尖后段、下叶背段和后基底段；
- 主要沿支气管播散；
- 病变上重下轻、上旧下新；
- 多局限肺内，空洞常见。

具体六型、活动性、排菌证据和化疗全部回R7。

## KP06｜空洞、排菌与传播：空洞是病理形态，涂阳是传染性证据

> **主提示：坏死排出→？｜开放性证据1｜三空洞壁｜传染最强接口**

### Detailed Expansion

```text
干酪坏死物经支气管排出
→ 原位置重新充入空气
→ 形成空洞
```

空洞与外界相通可增加排菌机会；当前内科口径以痰涂片阳性 / 涂阳提示排菌量大、开放性与传染性强。

R7已区分：

- 浸润型：薄壁空洞；
- 干酪性肺炎：虫蚀样 / 无壁空洞；
- 慢性纤维空洞型：厚壁空洞。

H21只保存“坏死—空洞—排菌—传播”的共同链。

**Routing**：CORE｜CONNECTION｜MI-G

## KP07｜血源播散：短时间大量入血，怎样变成粟粒和肺外地图

> **主提示：入哪静脉｜经哪心｜全身落点4｜肺内三均匀｜原/继谁都可**

### Detailed Expansion

当前病理Study：结核杆菌短时间一次或反复多次大量进入肺静脉分支，经左心进入体循环，可播散至肺、肝、脾、脑膜等器官。

急性粟粒性肺结核影像：双肺弥漫约2 mm粟粒影，分布、大小、密度“三均匀”。原发、继发均可血播；原发因缺乏免疫更有播散基础，但临床粟粒性结核亦可来自继发病变。

**Routing**：CORE｜VISUAL_ONLY｜MI-G｜MI-D

## KP08｜HIV合并结核：病原更多，但空洞、肉芽肿和PPD可更少

> **主提示：部位偏｜淋巴结2｜播散2｜空洞/肉芽/PPD3方向｜为什么**

### Detailed Expansion

HIV免疫缺陷时，当前Study提示：

- 病灶可偏下肺；
- 肺门、纵隔淋巴结肿大更常见；
- 胸膜 / 心包渗出及粟粒、肺外播散增多；
- 空洞少、肉芽肿少；
- PPD可阴性或弱阳性。

原因在于宿主难以形成充分细胞免疫和变态反应。H13已建立这一宿主反应边界；H21把它放入结核地图。

**Routing**：CORE｜CONFUSABLE｜CONNECTION｜MI-G

## KP09｜肾与泌尿生殖结核：肺外播散落在肾，症状却常先出现在膀胱

> **主提示：肾/泌尿生殖结核：来源｜症状先落哪｜三症｜肾自截｜男性生殖播散方向**

### Detailed Expansion

病理地图：

- 肾结核约90%继发于肺结核；
- 含TB的尿液下行刺激膀胱，可出现慢性膀胱刺激征：尿频、尿急、尿痛（原病理不带图P115）；
- 严重钙化、输尿管闭塞后可形成“肾自截”；
- 其他泌尿与男性生殖结核多继发于肾结核。

完整血尿方式、培养、影像、疗程和手术归K13；H21只解释播散与上下游器官关系。

**Routing**：CORE｜CONNECTION｜BOUNDARY｜MI-G

## KP10｜肠与腹膜结核：一个多经吞咽，一个多由腹腔灶直接蔓延

> **主提示：肠结核 vs 腹膜结核｜来源路径｜好发部位｜溃疡方向｜并发症/体征**

### Detailed Expansion

- 肠结核多继发于空洞性肺结核：反复咽下含TB痰液；
- 好发回盲部；
- 肠黏膜淋巴管环形走向 → 环形 / 横形溃疡，长轴与肠长轴垂直 → 易狭窄和梗阻；
- 结核性腹膜炎多由肠结核、肠系膜淋巴结结核或输卵管结核等腹腔灶直接蔓延；
- 触诊可有揉面感 / 柔韧感。
