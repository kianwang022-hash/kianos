## 0｜这个 Block 到底解决什么

COPD 的临床身份要把暴露、症状和其他病因，与**支气管扩张剂后仍存在的持续气流受限**合起来判断。慢支描述气道炎症及临床综合征，肺气肿描述末梢肺组织的结构改变，二者与 COPD 不能简单画等号。

气道损伤与肺实质损伤提供两条可汇合的机制：清除下降、分泌增多和管壁重塑使小气道狭窄；弹性框架破坏使回缩动力和气道支撑下降。两支的贡献随表型而异。课程中的“慢支 → 腺泡中央型肺气肿”是有条件的连接，不要求每例 COPD 都按同一先后发展。

呼气流速受限使排空困难；若呼气时间又不足，动态未排空和内源性 PEEP 会增加下一次吸气的负担。同时，局部通气减少、局部血流减少和交换面积丢失可各自影响气体交换；只有整体有效肺泡通气不足时，才沿排出障碍解释 CO₂潴留。体征、肺功能和血气分别读取这些变化。

并发症各有自己的上游：严重气体交换或通气失败接呼衰，慢性低氧接肺血管与右心，胸膜下大疱破裂接气胸。临床处理由当下状态决定：稳定时评症状和加重风险；出现急性加重、意识改变或其他危险时，直接评当前气道、氧合与通气。

### 本 Block 的总任务

> **看到中老年吸烟、慢性咳痰喘或呼气性呼吸困难时，能从结构与功能的关系解释观察证据，判断当前危险和对应治疗目标。**

## 1｜总 Framework

```text
空间：传导气道到终末细支气管；远端肺腺泡承担气体交换，并提供回缩与气道支撑

两条结构支按表型汇合，贡献和进展可不同
├─ 纤毛损伤/清除↓ + 分泌↑ + 管壁炎症/纤维化 → 小气道狭窄、阻力↑
└─ 蛋白酶/抗蛋白酶失衡等 → 腺泡弹性框架破坏 → 回缩动力↓、气道支撑↓
慢支的小气道不完全阻塞伴蛋白酶失衡时，可连接腺泡中央型肺气肿；不是所有COPD固定先后

气道狭窄和/或回缩不足，遇上呼气时牵拉减弱 → 呼气流速受限、提前闭合、排空困难
若再有呼气时间不足 → 动态未排空 → 呼末肺泡压高于气道开口压 → PEEPi
→ 下一次吸气先克服阈值负荷 → 呼吸功↑、可致肌疲劳 → 有效通气进一步受损

结构与通气改变也作用于气体交换
├─ 局部气少、血相对多 → 低V̇A/Q̇ → 分流样低氧
├─ 毛细血管床受压/破坏、血流相对通气更少 → 高V̇A/Q̇ → 死腔样通气；面积丢失时弥散可↓
└─ 整体有效肺泡通气不足时 → CO₂排出↓ → PaCO₂↑
低氧与CO₂潴留分开判断，Ⅰ/Ⅱ型按实际血气和采样情境

各自的并发出口
严重氧合/通气失败 → 呼衰（R12）
慢性低氧 → 肺小动脉收缩/重构 → 肺血管阻力↑、肺动脉高压 → 右室后负荷↑ → 肺心病（R9）
胸膜下肺大疱破裂 → 胸膜腔进气 → 自发性气胸（R10）

观察与判断接回上述变量，不组成病程阶段
肺功能：支扩后持续受限证据、FEV1%pred严重度、容量与弥散各有条件
体征：含气/传声/气流/分泌物分别解释视触叩听；临床身份须合读暴露与其他病因
检查：稳定能配合时肺功能；意识改变先评血气、气道/通气；疑气胸看相应影像
稳定状态 → 症状与既往加重风险 → A/B/E与相应长期处理；慢性重度静息低氧按条件LTOT
急性触发/当下危险 → 同时评感染、痉挛、炎症、氧合、通气与气道保护 → 针对失效环节处理
```

### 四个最重要的判断轴

```text
支气管扩张剂后 FEV1/FVC
→ 是否仍有持续气流受限？临床身份还须结合暴露、症状与其他病因

FEV1%pred
→ 气流受限严重到什么程度？不能替代症状/既往加重构成的A/B/E

RV / FRC / TLC / RV:TLC
→ 最大呼气末、平静呼气末与总肺量各怎样改变？滞气/过充不等于已证明PEEPi

PaCO₂
→ CO₂排出是否提示有效肺泡通气不足？与PaO₂、pH和采样情境合读
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

气道与肺腺泡的两条结构支汇入呼气受限，观察和处理沿各自的变量展开。下列医学关系与条件独立于注释；完整标题〔Prompt〕固定在相应节点，用于在同一模型上恢复知识，细节沿原 Core 展开。

```text
结构底座：空气经传导气道到终末细支气管，再进入远端肺腺泡
肺腺泡包括呼吸性细支气管、肺泡管、肺泡囊、肺泡；间隔中的弹力与毛细血管分别参与力学支撑和交换
病变可偏重气道、偏重肺实质或两者并存；两支贡献和进展不要求一致
〈气道树与肺腺泡：COPD 同时损害“管”和“泡”〔传导区终点｜腺泡4段/肺小叶｜肺泡上皮2型｜病变定位4类〕〉

长期刺激与易感背景改变两类结构
├─ 气道支：纤毛损伤、清除↓ + 杯状细胞/腺体增生、分泌↑
│  → 分泌物潴留；叠加慢性炎症、壁损伤与纤维修复 → 小气道黏、窄、硬
│  → 管腔更窄、气道阻力↑，咳、痰、喘分别来自刺激、分泌失衡和气道负担
│  首先接触较大气道与主要病变集中小气道回答不同问题；慢支3+2不等于COPD诊断
│  〈慢性支气管炎完整人设：把气道变成“黏、窄、硬”〔病因2｜首先vs主要｜3+2｜管壁6层→咳痰喘｜化生2类｜增生≠异型〕〉
└─ 肺实质支：弹性蛋白酶/抗蛋白酶保护失衡等 → 腺泡间隔与弹性框架破坏
   → 回缩动力↓、对小气道的支撑↓，并可出现肺泡扩大融合、大疱与毛细血管床减少
   回缩↓使单纯吸气弹性负荷下降，却同时削弱呼气动力；总呼吸功还取决于气道阻力和过度充气
   〈肺气肿：弹性阻力下降，为什么不是“呼吸更省力”〔肺气肿：病因｜病变部位｜大体/镜下｜弹性变化｜吸气 vs 呼气力学｜呼吸困难〕〉
两支可相互连接：慢支的小气道不完全阻塞，伴蛋白酶失衡/α1-抗胰蛋白酶保护下降
→ 可发展为腺泡中央型肺气肿；这是课程中的条件性路径，不是全部COPD必经的时间轴
小气道阻力与通气不均可使动态顺应性↓；合并肺气肿时静态顺应性可↑，两者按结构和测量条件解释
〈慢支怎样发展为腺泡中央型肺气肿〔小气道｜蛋白酶失衡｜肺泡/血管｜顺应性条件〕〉
空间旁查：中央/近端、周围/间隔旁、全腺泡按受累位置分型
间质性是气体进入间质；代偿、老年、瘢痕旁保留各自结构身份，周围型不等于随瘢痕分布的不规则型
〈肺气肿分类：先按肺腺泡受累位置，再看特殊类型〔腺泡3型：位置/机制/别称｜间质性｜特殊3型｜周围vs瘢痕旁｜气胸接口〕〉

两类结构损伤可共同限制呼气流速
呼气时肺体积减小、对小气道牵拉减弱；原有气道狭窄和/或回缩动力不足
→ 呼气时更易提前闭合、空气难排出
缩唇缓呼维持气道内相对压力，可减慢提前闭合；活动时通气需求↑，更易暴露排气限速
〈为什么 COPD 是“越吸越容易，越呼越困难”〔呼气困难2机制｜缩唇呼气：气道内压/闭合｜活动负荷：通气需求/充气〕〉
若呼气受限又遇到呼气时间不足（时间常数延长/呼吸过快等）
→ 下一次吸气前尚未达到静态平衡 → 动态过度充气、呼末肺泡压仍高于气道开口压 → PEEPi
→ 新吸气先跨过阈值负荷 → 吸气做功↑、可致呼吸肌疲劳 → 有效通气进一步受损
RV/FRC增大只说明相应气量变化，不能单独证明动态未排空或PEEPi；“越吸越容易”只适用于前述弹性负荷
〈小气道先受累：动态顺应性下降、静态顺应性升高、内源性 PEEP〔小气道指标｜动静顺应性｜PEEPi形成/负担〕〉

同一损伤还改变区域气血匹配；整体CO₂排出另看有效肺泡通气
├─ 分泌物/狭窄使局部通气少、血相对多 → 低V̇A/Q̇ → 分流样低氧
├─ 膨胀、大疱和间隔破坏使局部血流相对通气更少 → 高V̇A/Q̇ → 死腔样通气
│  肺气肿/毛细床面积丢失还可降低弥散能力；这些改变不能推广到所有气道为主的COPD
└─ 呼气负担、呼吸肌疲劳等使整体有效肺泡通气不足时 → CO₂排出↓ → PaCO₂↑
低氧可出现而PaCO₂尚未升高；Ⅰ型或Ⅱ型依实际血气和采样情境判断，不由COPD病名预定
课程低氧机制的完整五组配对仍回R8的低氧机制坐标
〈COPD 低氧与 CO₂潴留：区域换气与整体肺泡通气分别判断〔低氧3机制｜CO₂潴留主轴｜V̇A/Q̇高低2支｜O₂vsCO₂弥散｜Ⅰ/Ⅱ型依血气〕〉

三个并发出口各接自己的上游，彼此没有固定发生顺序
├─ 严重氧合/通气失败 → 呼吸衰竭；持续通气不足可走向慢性Ⅱ型，完整诊疗交R12
├─ 慢性低氧 → 肺小动脉收缩/重构 → 肺血管阻力↑、肺动脉高压 → 右室后负荷↑ → 肺心病，交R9
└─ 胸膜下肺大疱破裂 → 气体进入胸膜腔 → 突发胸痛后气促等气胸线索，交R10
〈COPD 三个并发症：呼衰、肺心病、气胸〔COPD并发症3｜各上游机制｜典型证据｜气胸症状先后〕〉

由结构和功能读证据：这些是观察支，不是病变的下一阶段
├─ 气流受限由FEV1/FVC读取；FEV1%pred量受限程度
│  滞气时RV常↑，过度充气时FRC常↑；合并肺气肿时TLC可↑、DLCO常↓，各指标有自己的条件
│  〈COPD 肺功能全图：流速、残气、容积与弥散分别怎么看〔COPD肺功能：气流｜残气/容积｜弥散｜各指标问什么｜诊断 vs 严重度〕〉
├─ 过多含气改变胸廓、叩诊和传声，膨胀肺改变肺/肝/心界；气流少使呼吸音弱、呼气延长
│  液体分泌物与狭窄分别提供湿/干啰音；桶状胸和这些声音都不能独自定病
│  〈COPD 体征：肺内残气怎样改变视、触、叩、听〔视触叩听｜肺/肝/心界｜含气-传声-狭窄-分泌物｜语颤/叩诊/啰音坐标〕〉
│  体征比较旁查：空气、液体、实变的位置决定语颤/叩诊/啰音；积液上方与积液区不能混同
│  〈呼吸系统重要体征：先判断空气、液体还是实变〔语颤最强/最弱｜增强3类｜叩诊3组｜啰音3病对照〕〉
└─ 临床身份由暴露/症状、支扩后仍有持续受限及其他病因合读；慢支、肺气肿和COPD是不同层级
   〈COPD 的临床身份：慢支、肺气肿与 COPD 不能简单画等号〔本质/定性证据｜慢支-肺气肿-COPD3层｜标志症状｜稳定vs加重痰｜病例入口≠确诊〕〉
   阻塞/限制的比较旁查分别看流速与容量；支扩后比值是证据，不能单独替代病因判断
   〈阻塞性 vs 限制性：本 Block 只做诊断坐标复用〔阻塞vs限制6轴｜流速vs容积｜FEV1/FVC与RV/TLC｜支扩后证据/临床背景〕〉
   与哮喘比较看持续与可变的主轴；COPD可有舒张反应，哮喘可持续受限，两病可并存，完整比较交R4
   〈COPD 出口：先与哮喘建立“持续 vs 可变”的主鉴别轴〔共同表现7组｜持续vs可变｜共同体征≠定病｜后续接口3条〕〉
检查随当前问题选择：稳定且能配合时肺功能回答持续受限/程度；意识改变或疑肺性脑病时先看血气和气道/通气
疑气胸看胸膜线外无肺纹理等相应影像，COPD本身透亮度增加不能代替气胸证据
〈COPD 诊断、严重度与检查选择〔检查选择3场景｜支扩后FEV1/FVC｜FEV1%pred｜定性/定级配对｜X线2用途〕〉

处理直接回到当下状态和失效环节，急性加重可叠加于上述任一病程
稳定状态：症状负担 + 既往急性加重风险 → A/B/E评估；FEV1%pred不能替代这两个输入，课程与2026版边界分开
〈稳定期先评估：症状与急性加重风险组成 A / B / E〔稳定期｜风险/症状｜mMRC 5级｜ABE版本〕〉
├─ 戒烟干预持续损害的上游；支气管扩张剂减轻平滑肌痉挛等可变气道负担
│  ICS按加重史、嗜酸细胞、伴哮喘及肺炎等风险判断，初始与随访升级分开；单个嗜酸细胞阈值不是独立充分指征
│  〈稳定期治疗：戒烟是上游，支气管扩张剂处理可逆部分〔风险干预｜ABE方案｜药类/代表｜ICS条件〕〉
└─ 稳定期慢性重度静息低氧符合条件时 → LTOT并复评，改善氧合和相应预后
   LTOT与急性高碳酸风险的氧疗滴定是不同情境；氧合改善不能替代CO₂排出或必要通气支持
   氧后CO₂升高继承R2的V̇A/Q̇、霍尔丹效应与部分通气改变，不能只归因于低氧驱动
   〈长期家庭氧疗：改善预后，但不等于解决 CO₂潴留〔LTOT适应/时长｜目标｜设备｜CO₂机制〕〉
急性触发：感染等使气道炎症、分泌或痉挛加重 → 原有限速与通气负担进一步恶化
├─ 按当下问题处理感染、气道痉挛、炎症和低氧：必要抗菌、支扩、全身激素、氧疗各有对应目标
└─ 严重呼衰或意识改变 → 立即评估血气、气道保护和通气支持；意识改变是危险提示，不等于已经决定插管
   适合且无禁忌的急性高碳酸呼衰可先评估NIV；不能保护气道、持续循环不稳、呼吸停止或NIV失败等需升级有创支持
〈AECOPD：先识别严重度，再处理感染、气道、炎症和通气〔AECOPD诱因｜症状/严重度｜急性期3类药｜氧疗/通气｜有创门槛〕〉
若CO₂潴留形成呼吸性酸中毒 → 先改善通气和病因；课程pH接口不是自动补碱指令
通气衰竭或意识障碍时避免自行加镇静/抑呼吸药；专业气道管理是另一个监护情境
〈COPD 急救安全边界：先改善通气，不轻易“补碱和镇静”〔呼酸处理优先轴｜补碱条件｜镇静/抑呼吸风险〕〉
```

**Residual 边界**：模型节点及其完整 Prompt 先承载机制、分类、比较和可自然恢复的成员。精确数值、阈值、药名、例外或固定配对若仍有独立恢复价值，可同时由既有 Memory / Precision 复习；出现在 Prompt 中不撤销其准入，已有精记也不能替代完整 Prompt。模型校准不增删已准入身份、不改变历史或生成新复习债务。

## 2｜Memory Routing

### MI-G｜理解当前推理所需的即时支点

1. 传导区、终末细支气管与肺腺泡的空间边界；
2. 慢支“首先累及较大气道、主要病变集中于小气道”的双重口径；
3. 慢支病理从内向外：上皮—杯状细胞 / 腺体—炎症—管壁结构；
4. 肺气肿不是只累及肺泡，而是末梢肺组织 / 肺腺泡异常扩大与弹性减弱；
5. 肺弹性阻力下降为何使呼气更困难；
6. 慢支 → 腺泡中央型肺气肿的完整链；
7. 小气道阻力增加时动态顺应性可下降，合并肺气肿时静态顺应性可升高；两者不是所有 COPD 必经的先后阶段；
8. COPD 诊断必须强调支气管扩张剂后 `FEV1/FVC < 70%`；
9. `FEV1/FVC` 定性与 `FEV1%pred` 定量的职责边界；
10. COPD 可同时出现 VA/Q↓ 与 VA/Q↑；
11. 肺泡通气下降是 CO₂潴留和总体通气失败的主要机制；
12. COPD 多见慢性Ⅱ型呼衰，但血气给出时仍可表现为Ⅰ型；
13. COPD 三个并发症：呼衰、肺心病、自发性气胸；
14. 稳定期与急性加重期必须先分开；
15. A/B/E 分组的输入是症状与既往急性加重风险，不是 FEV1%pred；
16. 急性加重出现意识状态改变时，按课程进入Ⅲ级危险接口并立即评气道保护与通气，不能把所有意识变化自动等于插管。

### MI-D｜既有精确复习范围，保留原身份与完整答案

- 慢支“每年 3 个月、连续 2 年”；
- 各型肺气肿的完整位置、别称和低频病因；
- MEFV、闭合容积、各肺容量和 DLCO 的精确组合；
- GOLD 1–4 数字；
- mMRC 0–4 全部表述；
- A/B/E 全部药名与 ICS 指征；
- 长期家庭氧疗的 PaO₂、SaO₂、流量和浓度；
- AECOPD 分级、抗菌药类别、全身激素代表与机械通气场景；剂量、疗程和 NIV 数值准入未给出，不猜；
- 呼吸系统体征的完整疾病名单；
- pH 补碱课程接口，以及吗啡、地西泮的课程风险场景；不得扩写成无条件处方或“所有呼吸病永久禁用”。

# Unit A｜先看疾病发生在哪里

## KP01｜气道树与肺腺泡：COPD 同时损害“管”和“泡”

> **讲义定位 →** 病理 Lecture PDF P54–56｜呼吸道与肺腺泡概述  
> **Outline →** 病理 U001｜慢支炎 1–3  
> **主提示：** 传导区终点｜腺泡4段/肺小叶｜肺泡上皮2型｜病变定位4类

[气道到肺腺泡原图：病理物理 P55／印刷 P53](../../../../../../assets/source-visuals/a2-r03-lg01/p55.webp)。

### 1｜传导区

```text
气管
→ 主支气管
→ 叶支气管
→ 段支气管
→ 小支气管
→ 细支气管
→ 终末细支气管【传导区最后】
```

这些结构的主要任务是输送空气，不直接承担肺泡气体交换。

### 2｜末梢肺组织 / 肺腺泡

```text
呼吸性细支气管
→ 肺泡管
→ 肺泡囊
→ 肺泡
```

- 肺腺泡是肺的基本功能单位；
- 肺小叶由若干终末细支气管及其远端结构组成，内含多个肺腺泡；
- I 型肺泡上皮：薄，主要承担气体交换；
- II 型肺泡上皮：分泌肺表面活性物质，降低表面张力，并参与肺泡上皮修复接口；
- 肺泡间孔：让相邻肺泡相通；炎症可经此扩散，大叶性肺炎的完整应用归 R5；
- 肺泡间隔内含毛细血管、弹力纤维等。

病理 PDF P55 提醒：这里的组胚肺小叶与大叶性/小叶性肺炎所强调的病变范围不作一一对应。P56 的“3–5 个终末细支气管、15–25 个肺腺泡”及“Ⅱ型数量较Ⅰ型少”原字样与所在图示已核见；计数口径与数量命题的医学核证仍未完成，HOLD 仅限该非必需 Source 查阅命题，不把它们补成无条件精记答案或新增记忆任务。

### 3｜这张地图怎样服务后续疾病

```text
慢支
→ 从较大支气管向小气道发展，主要病变集中小气道

肺气肿
→ 末梢肺组织 / 肺腺泡扩大，弹性结构破坏

支扩
→ 主要是段、小支气管管壁支撑结构破坏

肺炎
→ 根据肺泡、细支气管周围或间质定位
```

（易混：慢支与肺气肿最终都可影响小气道，但肺气肿的形态主体不是“大支气管狭窄”，而是末梢肺组织异常扩张和弹性破坏。）

## KP02｜慢性支气管炎完整人设：把气道变成“黏、窄、硬”

> **讲义定位 →** 病理 Lecture PDF P58–60｜慢性支气管炎  
> **Outline →** 病理 U001｜慢支炎 4–8  
> **主提示：** 病因2｜首先vs主要｜3+2｜管壁6层→咳痰喘｜化生2类｜增生≠异型

[管壁层次与软骨边界：病理物理 P58／印刷 P56](../../../../../../assets/source-visuals/a2-r03-lg01/pathology-p058-source-page.png)；[慢支管壁病理变化：物理 P60／印刷 P58 原裁图](../../../../../../assets/source-visuals/a2-r03-lg01/p60.webp)。

### 1｜身份与病因

慢支是：

> **支气管黏膜及其周围组织的慢性炎症。**

主要病因按当前 Study：

- 吸烟；
- 病毒、细菌等感染。

### 2｜“首先”与“主要”不是同一问

```text
烟雾 / 病原从口鼻进入
→ 首先接触较大支气管
→ 逐渐向较小支气管和周围组织扩展

颗粒在细支气管停留更久
→ 主要病变集中于小气道 / 细支气管
```

### 3｜临床定义接口

```text
咳嗽、咳痰等症状
每年至少持续 3 个月
连续 2 年以上
```

该“3+2”是慢支的临床定义接口，不等于内科学 COPD 的持续气流受限诊断。

### 4｜从内向外看病理变化

| 层级 | 病理变化 | 功能结果 |
|---|---|---|
| 纤毛柱状上皮 | 纤毛倒伏 / 脱失，细胞变性、坏死、脱落 | 黏液清除下降 |
| 上皮适应 | 柱状上皮鳞状化生 | 更耐刺激，但失去正常纤毛功能 |
| 杯状细胞 | 数量增多 | 黏液增多 |
| 黏膜下腺体 | 增生肥大，浆液腺黏液腺化生 | 黏液进一步增多 |
| 管壁 | 充血、水肿，淋巴细胞和浆细胞等浸润 | 慢性炎症、管壁增厚 |
| 软骨 / 平滑肌 / 弹力纤维 | 破坏、萎缩或断裂；软骨可萎缩、变性、骨化，损伤后可纤维性修复 | 管壁僵硬、狭窄、回缩异常 |

**组织位置先分清**：较大支气管的 C 形软骨、平滑肌和弹力结构不能原样套到小气道；病理 PDF P58 明示终末细支气管及其远端无软骨支撑。

**平滑肌的课程例外**：一般可萎缩、断裂；喘息型慢支（常有过敏史）也可增生肥大。两种描述依表型，不把“平滑肌只会萎缩”记成绝对项（病理 PDF P60）。

### 5｜为什么出现咳、痰、喘

```text
黏膜受炎症刺激
+ 杯状细胞 / 腺体分泌↑
→ 咳嗽、咳痰

平滑肌痉挛 / 管壁增厚
+ 黏液、渗出物堵塞
→ 气道狭窄
→ 喘息
```

### 6｜两类化生

化生经具有分化潜能的干细胞等实现，不是成熟柱状细胞直接变为成熟鳞状细胞；这里只调用 P0 的共同病理语言。

- 鳞状上皮化生；
- 黏液腺化生。

（易混：慢支可有细胞增生与化生，但当前 Study 不把“软骨细胞不典型 / 异型增生”列为慢支病理。异型增生是肿瘤与部分癌前病变的语言。）

## KP03｜肺气肿：弹性阻力下降，为什么不是“呼吸更省力”

> **讲义定位 →** 病理 Lecture PDF P61｜肺气肿概述  
> **Outline →** 病理 U001｜肺气肿 1–4  
> **主提示：** 肺气肿：病因｜病变部位｜大体/镜下｜弹性变化｜吸气 vs 呼气力学｜呼吸困难

[肺气肿形态示意与镜下原图：病理物理 P61／印刷 P59](../../../../../../assets/source-visuals/a2-r03-lg01/pathology-p061-source-page.png)。

### 1｜病变身份

按当前 Study，肺气肿主要表现为：

- 末梢肺组织 / 肺腺泡过度充气、扩大；
- 大体：肺体积膨大、灰白、含气增多；
- 肺泡间隔和弹性结构破坏；
- 肺毛细血管床受压、减少；
- 肺弹性减弱。

当前病理 Study 将慢性支气管炎列为最常见病因；这是课程病因口径，不把两病等同。

（易混：肺气肿不是仅限“肺泡变大”，它涉及呼吸性细支气管、肺泡管、肺泡囊和肺泡等末梢肺组织。）

### 2｜机械悖论

```text
肺弹性阻力
吸气时 = 阻力
呼气时 = 回缩动力
```

肺气肿时：

```text
弹性结构破坏
→ 吸气时确实更容易被拉开
但
→ 呼气时回缩动力不足
→ 小气道更易提前关闭
→ 气体呼不出去
→ 残气增加
```

所以它的典型功能表现是：

> **呼气性呼吸困难。**

### 3｜结构—功能恶性循环

```text
肺泡过度充气
→ 压迫肺泡间隔毛细血管和弹力纤维
→ 毛细血管床减少、弹性进一步下降
→ 回缩更差
→ 残气更多
→ 肺泡继续扩大、融合为肺大疱
```

## KP04｜慢支怎样发展为腺泡中央型肺气肿

> **讲义定位 →** 病理 Lecture PDF P62｜慢支—肺气肿机制  
> **主提示：** 小气道｜蛋白酶失衡｜肺泡/血管｜顺应性条件

### 1｜小气道炎症与阻塞

```text
慢支小气道炎症
→ 终末细支气管及近端呼吸性细支气管管壁受损
→ 管壁纤维化、增厚、管腔狭窄

杯状细胞 / 腺体增生
+ 黏液腺化生
+ 纤毛清除下降
→ 黏液潴留
→ 小气道不完全阻塞
```

必须区分上游狭窄与远端扩张：课程具体为终末细支气管、一级呼吸性细支气管狭窄，其远端的二级呼吸性细支气管呈囊状扩张。慢支机制中的“狭窄”与腺泡中央型形态中的“扩张”说的是不同层级，不能互相抹掉（病理 PDF P62–63）。

### 2｜弹性框架破坏

```text
中性粒细胞活化
→ 弹性蛋白酶↑

氧自由基↑
→ α1-抗胰蛋白酶保护作用↓

弹性蛋白酶 / 抗蛋白酶失衡
→ 末梢肺组织弹力纤维破坏
→ 弹性回缩下降
```

### 3｜最后形成过度充气与换气障碍

```text
气体呼不出去
→ 末梢肺组织残气↑、扩大
→ 肺泡破裂、融合为肺大疱
→ 毛细血管受压、破坏（课程强调减少的是毛细血管床，不能替换成肺小动脉数量减少）
→ 弥散面积↓、VA/Q异常
```

### 4｜放回 R1 的阻力语言

```text
小气道狭窄、分泌物阻塞与通气不均
→ 非弹性阻力↑
→ 动态顺应性↓

合并肺气肿时肺弹性结构破坏
→ 弹性阻力↓
→ 静态顺应性↑
```

> **“动低静高”对应不同结构与测量条件；本页慢支→腺泡中央型是课程模型，不是所有COPD必然按同一先后顺序进展。**

## KP05｜肺气肿分类：先按肺腺泡受累位置，再看特殊类型

> **讲义定位 →** 病理 Lecture PDF P62–64｜肺气肿分类与原图  
> **Outline →** 病理 U001｜肺气肿 5–10  
> **主提示：** 腺泡3型：位置/机制/别称｜间质性｜特殊3型｜周围vs瘢痕旁｜气胸接口

### 1｜肺泡性 / 肺腺泡型

| 类型 | 主要受累位置 | 当前 Study 机制 / 特点 |
|---|---|---|
| 腺泡中央型 / 近端型 | 呼吸性细支气管及邻近肺泡明显扩张，远端肺泡管 / 囊相对较轻 | 最常见；常与慢支小气道阻塞相关 |
| 腺泡周围型 / 间隔旁型 / 远端型 | 肺泡管、肺泡囊等腺泡远端明显扩张，邻近胸膜和小叶间隔 | 当前 Study 以肺泡间隔胶原纤维收缩解释；多不合并慢支；胸膜下肺大疱可破裂 |
| 全腺泡型 | 呼吸性细支气管、肺泡管、肺泡囊、肺泡均扩张 | 遗传性 α1-抗胰蛋白酶缺乏接口；当前 Study 提示我国少见、主要见于北欧青壮年（课程流行病学描述） |

### 2｜间质性肺气肿

```text
肋骨骨折 / 胸部穿透伤 / 剧烈咳嗽等
→ 空气进入肺间质
→ 串珠状气泡、皮下气肿
```

（特殊：气胸通常不会造成阻塞性肺气肿，但张力性气胸可形成间质性肺气肿接口。）

### 3｜其他类型

- 代偿性肺气肿：肺病变或肺叶切除后残余肺组织代偿性充气；
- 老年性肺气肿：老年肺弹性回缩减弱、残气增多；
- 瘢痕旁 / 不规则肺气肿：瘢痕附近肺泡破裂融合，位置、大小、形态不规则。

> **原图回看：** 本轮27病理精编版【不带导图】印刷P61（PDF物理63）图10-10及CT，区分呼吸性细支气管为主的中央型、腺泡远端为主的周围型；印刷P62（物理64）全腺泡CT及瘢痕旁/间隔旁对照表。重排版页码另有差异，不能与本版物理页码互换。

### 4｜周围型 vs 瘢痕旁型

共同点：均可与胶原瘢痕牵拉有关。

```text
腺泡周围型
→ 受累位置稳定在腺泡远端

瘢痕旁型

```

## KP06｜COPD 的临床身份：慢支、肺气肿与 COPD 不能简单画等号

> **讲义定位 →** 内科 印刷 P1（PDF 物理 P2）｜COPD 临床入口  
> **Outline →** 内科 U001｜临床表现 1–3  
> **主提示：** 本质/定性证据｜慢支-肺气肿-COPD3层｜标志症状｜稳定vs加重痰｜病例入口≠确诊

### 1｜内科学的核心身份

> **COPD＝持续性气流受限。**

真正定性需要：

```text
吸入支气管扩张剂后
FEV1/FVC 仍 < 70%
```

### 2｜三层概念不要混

```text
慢支
→ 临床综合征和气道慢性炎症语言

肺气肿
→ 末梢肺组织异常扩大和弹性破坏语言

临床 COPD
→ 持续性、不完全可逆的气流受限语言
```

当前病理 Study 可把慢支、肺气肿放在 COPD 疾病组框架中；内科诊断则要求持续气流受限证据。两种表述层级不同，不强行改成一句完全相同定义。

### 3｜临床入口

- 标志性症状：气短，常在活动后出现；
- 慢支样表现：咳、痰、喘；
- 稳定期：白色泡沫痰为主；
- 急性加重期：黄脓痰为主；
- 典型病例入口：中老年、长期吸烟、反复咳痰喘、活动后呼吸困难。

（易混：症状和风险背景必须与肺功能合看。支扩剂后持续气流受限也可见于哮喘等疾病，既不能只凭症状，也不能只凭一个FEV1/FVC数值完成COPD病因诊断。）

## KP07｜为什么 COPD 是“越吸越容易，越呼越困难”

> **讲义回看 →** R1 气道阻力与弹性回缩；内科印刷 P1–2（PDF 物理 P2–3）  
> **主提示：** 呼气困难2机制｜缩唇呼气：气道内压/闭合｜活动负荷：通气需求/充气

### 1｜气道口径的呼吸周期效应

```text
吸气
→ 胸膜腔负压更负、肺体积增大
→ 肺组织对小气道牵拉增强
→ 气道口径增大、阻力下降

呼气
→ 肺体积减小、胸膜腔负压负值减小
→ 对小气道牵拉减弱
→ 狭窄小气道更易闭合
```

### 2｜弹性回缩下降

```text
肺气肿破坏弹力纤维
→ 呼气回缩动力不足
→ 气体更难排出
```

### 3｜缩唇呼吸

```text
缩唇、缓慢呼气
→ 呼气道内压相对维持
→ 小气道提前闭合减慢
→ 可帮助更多残气排出
```

### 4｜活动后加重

活动使氧耗和通气需求增加；而 COPD 已存在气流速度限制与动态过度充气，无法按需求显著增加有效肺泡通气，因此气短更明显。

## KP08｜COPD 体征：肺内残气怎样改变视、触、叩、听

> **讲义定位 →** 内科 印刷 P2（PDF 物理 P3）；印刷 P11（PDF 物理 P12）呼吸系统重要体征  
> **Outline →** 内科 U001 临床 4–7；U003 重要体征 1–4  
> **主提示：** 视触叩听｜肺/肝/心界｜含气-传声-狭窄-分泌物｜语颤/叩诊/啰音坐标

### 1｜COPD 视触叩听

| 检查 | 典型方向 | 机制 |
|---|---|---|
| 视诊 | 缩唇呼吸；桶状胸 | 残气与过度充气 |
| 触诊 | 语音震颤减弱 | 过多空气使声音传导下降 |
| 叩诊 | 过清音；Kronig峡增宽 | 肺组织含气增多 |
| 边界 | 肺下界、肝浊音界下移 | 过度充气、膈肌下移 |
| 心界 | 心浊音界缩小、心音遥远 | 膨胀肺组织遮挡心脏、增加传导距离 |
| 听诊 | 呼吸音减弱、呼气音延长 | 气流受限、过度充气 |
| 啰音 | 湿啰音或干湿啰音共存 | 分泌物 / 液体 + 气道狭窄 |

（易混：桶状胸并非 COPD 专属；课程四类为 COPD、严重支气管哮喘、老年人、矮胖者。必须结合病史和持续气流受限证据。）

Kronig 峡（肺尖叩诊清音带）在课程内科印刷 P2 标为正常宽约 4–6 cm；肺气肿可增宽，继发性肺结核可变窄。这是肺尖叩诊对照，不拿宽度独自确诊。

### 2｜呼吸系统体征坐标

```text
语音震颤增强
→ 肺实变、大空洞、胸腔积液上方

语音震颤减弱
→ COPD、哮喘、肺不张、肺水肿、胸膜增厚粘连、胸腔积液、气胸等
```

```text
鼓音 > 过清音 > 清音 > 浊音 / 实音
```

```text
湿啰音
→ 气道内有液体

干啰音 / 哮鸣音
→ 气道狭窄或痉挛
```

# Unit C｜持续气流受限怎样被肺功能和血气“看见”

## KP09｜小气道先受累：动态顺应性下降、静态顺应性升高、内源性 PEEP

> **讲义定位 →** 内科 印刷 P2–4（PDF 物理 P3–5）｜COPD 病理生理  
> **Outline →** 内科 U001｜病理生理 1  
> **主提示：** 小气道指标｜动静顺应性｜PEEPi形成/负担

### 1｜最早的小气道指标

COPD 首先累及小气道，可先表现为：

- 最大呼气流速 / 流量—容积曲线 MEFV 下降；
- 闭合容积升高；
- 动态肺顺应性下降。

### 2｜动态顺应性为何下降

```text
黏液 / 渗出物
+ 小气道壁纤维化、狭窄
→ 气道阻力↑
→ 有气流时测得的动态顺应性↓
```

### 3｜合并肺气肿时静态顺应性为何升高

```text
弹性蛋白酶—抗蛋白酶失衡
→ 末梢肺组织弹性结构破坏
→ 弹性阻力↓
→ 无气流时测得的静态顺应性↑
```

### 4｜内源性 PEEP

```text
呼气受限
+ 呼气时间不足以完成排空（时间常数延长/呼吸过快等）
→ 动态过度充气，下一次吸气前尚未达静态平衡
→ 呼气末肺泡压仍高于气道开口压
→ 内源性 PEEP
```

RV/FRC增大本身不能独自证明PEEPi：静态过度充气与动态未排空要分开。患者下一次吸气需先克服这一阈值负荷，才开始产生吸气流：

```text
吸气做功↑
→ 呼吸肌疲劳
→ 通气泵进一步下降
→ CO₂潴留加重
```

## KP10｜COPD 肺功能全图：流速、残气、容积与弥散分别怎么看

> **讲义定位 →** 内科 印刷 P3–4（PDF 物理 P4–5）｜肺功能  
> **Outline →** 内科 U001 病理生理 2–3；U002 辅助检查 1–2  
> **主提示：** COPD肺功能：气流｜残气/容积｜弥散｜各指标问什么｜诊断 vs 严重度

| 指标 | COPD 方向 | 主要反映 |
|---|---:|---|
| FEV1 | ↓ | 第一秒快速呼出量 |
| FEV1/FVC | ↓ | 气流速度 / 阻塞定性 |
| 支扩剂后 FEV1/FVC | 仍 <70% | 持续气流受限、COPD 诊断身份 |
| FEV1%pred | ↓ | 气流受限严重程度 |
| VA | 通气失败时可↓；并非所有COPD均↓ | 有效肺泡通气及CO₂排出 |
| RV | 气体潴留时常↑ | 最大呼气末余气；不是平静呼气末 |
| FRC | 过度充气时常↑ | 平静呼气末肺内气体 |
| TLC | 肺气肿等可↑，并非必然 | 最大肺容量 |
| RV/TLC | ↑；当前 Study 以 >40% 作为肺气肿接口 | 残气在总肺量中的比例 |
| DLCO | 肺气肿/毛细血管床破坏时常↓ | 不可把降低推广到全部气道为主的COPD |

### 两个诊断职责

```text
支气管扩张剂后 FEV1/FVC <70%
→ 定性：持续气流受限 / COPD

FEV1%pred
→ 定量：GOLD 严重程度
```

当前 Study 的 GOLD 肺功能分级：

- 1级：≥80%；
- 2级：50%–79%；
- 3级：30%–49%；
- 4级：<30%。

## KP11｜COPD 低氧与 CO₂潴留：区域换气与整体肺泡通气分别判断

> **讲义定位 →** 内科 印刷 P3（PDF 物理 P4）｜低氧与 CO₂潴留  
> **Outline →** 内科 U001 病理生理 4–5；U003 低氧机制 1  
> **主提示：** 低氧3机制｜CO₂潴留主轴｜V̇A/Q̇高低2支｜O₂vsCO₂弥散｜Ⅰ/Ⅱ型依血气

### 1｜CO₂潴留主轴：整体有效肺泡通气下降

```text
小气道阻塞
→ 有效肺泡通气 VA↓
→ CO₂排出下降
→ PaCO₂↑
```

这是COPD发生CO₂潴留、并常走向Ⅱ型呼衰的主要机制。原课程单选配对以肺泡通气下降解释COPD低氧/潴CO₂，但低氧本身常与区域V/Q失调密切相关，不能用高碳酸机制覆盖全部低氧。U003所问COPD/哮喘、肺栓塞/肺炎、ILD、肺泡蛋白沉着症、ARDS五组配对及课程/机制边界，明确回R8 KP03。

### 2｜VA/Q↓：气少、血相对多

```text
黏液 / 渗出物 / 管壁狭窄
→ 局部通气 VA↓
→ VA/Q↓
→ 功能性动静脉短路 / 分流样低氧
```

### 3｜VA/Q↑：气还在、血减少

```text
肺泡过度膨胀、肺大疱
→ 压迫 / 破坏毛细血管
→ 局部血流 Q↓
→ VA/Q↑
→ 死腔样通气 / 肺泡无效腔增加
```

### 4｜弥散障碍

```text
肺泡间隔与毛细血管床破坏
→ 弥散面积↓
→ DLCO↓
```

CO₂溶解度高、扩散快，因此单纯弥散障碍首先表现为低氧，不易单独造成 CO₂潴留。

### 5｜为何既可Ⅰ型，又常为Ⅱ型

```text
换气障碍占主导
→ PaO₂↓，PaCO₂正常
→ 可呈Ⅰ型呼衰

肺泡通气不足占主导
→ PaCO₂>50 mmHg，常伴低氧
→ 慢性Ⅱ型呼衰
```

> 有血气时必须以实际 PaO₂ / PaCO₂ 为准，不能仅凭“COPD通常Ⅱ型”覆盖题干。

# Unit D｜并发症、证据与诊断坐标

## KP12｜COPD 三个并发症：呼衰、肺心病、气胸

> **讲义定位 →** 内科 印刷 P4（PDF 物理 P5）｜并发症  
> **Outline →** 内科 U001｜并发症 1–4  
> **主提示：** COPD并发症3｜各上游机制｜典型证据｜气胸症状先后

### 1｜呼吸衰竭

- 多见慢性Ⅱ型：传统海平面、静息、室内空气判据为PaO₂＜60 mmHg且PaCO₂＞50 mmHg；给氧后PaO₂可被纠正，不能据此排除原有通气衰竭；
- 若以 VA/Q失调和弥散障碍为主，也可为Ⅰ型。

完整呼衰诊断与通气策略后置 R12。

### 2｜慢性肺心病

```text
慢性低氧
→ 肺小动脉痉挛、重构
→ 肺动脉高压
→ 右心后负荷↑
→ 右心功能不全
```

接口表现：P2亢进、颈静脉怒张、双下肢水肿等。完整肺高压 / 肺心病后置 R9。

### 3｜自发性气胸

```text
胸膜下肺大疱破裂
→ 气体进入胸膜腔
→ 先突发胸痛
→ 继之呼吸困难
```

可见：鼓音、患侧肋间隙增宽、纵隔向健侧移位、语音震颤和呼吸音减弱或消失。

（易混：肺栓塞也可突然胸痛和呼吸困难，但当前 Study 强调自发性气胸常有“胸痛先、继之呼吸困难”的顺序。）

## KP15｜呼吸系统重要体征：先判断空气、液体还是实变

> **主提示：** 语颤最强/最弱｜增强3类｜叩诊3组｜啰音3病对照

[物理 P12／印刷 P11：语颤、叩诊与啰音原图区域](../../../../../../assets/source-visuals/a2-r03-lg01/internal-p12-signs.png)。原页实际含语颤文字、人体叩诊分区与干湿啰音/气道示意，没有患者胸片；积液区与积液上方的部位条件仍按下文区分。

### 1｜正常语音震颤分布

- 最强：肩胛间区、左右胸骨旁 1–2 肋间；

### 2｜语颤增强三类

- 肺实变：课程例为大叶性肺炎、大片肺梗死；
- 肺内空洞：课程例为结核性空洞、脓性空洞；
- 胸腔积液上方。

**语颤减弱七类**：COPD、支气管哮喘、肺不张、肺水肿、胸膜增厚粘连、胸腔积液、气胸。积液区的减弱与其上方的增强分开；同病不同部位可不同，不能把名单当成不看部位和气道传声条件的绝对定律。

### 3｜叩诊音

原主提示的“叩诊3组”指过清、鼓、浊 / 实三组异常音；正常清音作为比较参照，不能因列出正常参照而另加一组默认检索要求。

- 清音：正常肺部；
- 过清音：COPD、哮喘等过度充气；
- 鼓音：气胸、含气空洞；
- 浊 / 实音：胸腔积液、含液空洞、实变、肺水肿、肺不张等。

### 4｜啰音主导

```text
COPD
→ 湿啰音或干湿啰音共存

支气管哮喘
→ 干啰音 / 哮鸣音为主

心源性哮喘
→ 湿啰音或干湿啰音共存
```

[物理 P6／印刷 P5：mMRC原表及 A/B/E 条目](../../../../../../assets/source-visuals/a2-r03-lg01/internal-p6-abe.png)。原页是症状表与风险/用药条目，不是另一套二维学习模型；同页“中度加重＝GOLD2”旁注的冲突处置见下文，核见原字样不等于采用。

### 1｜先确认是稳定期

急性加重期先救治，不进行稳定期 A/B/E 分组决策。

### 2｜急性加重风险

按当前 Study，风险回看去年；“住院”同样在这一回顾时间窗内：

```text
低风险
→ 去年中度急性加重≤1次，且无加重住院

高风险 / E
→ 去年中度急性加重 ≥2 次
或
→ 去年因急性加重住院
```

**Source 冲突 HOLD（原页已核见）**：内科印刷 P5“理顺15”把“中度急性加重”括注成 FEV1%pred 50%–79%。这与该页先按加重史、再按症状的 A/B/E 结构以及 KP13 的肺功能分级职责冲突；不采用这一括注，也不能凭 FEV1%pred 给急性加重事件定级。保留课程既有风险门槛，不在这里另造事件分级标准。

### 3｜症状多少

按 mMRC：

- 0–1级：症状少；
- 2–4级：症状多；
- 0级：仅剧烈活动时气短；1级：平地快走/爬缓坡时气短；
- 2级：平地走得比同龄人慢，或按自己速度行走仍需停下；
- 3级：约100m或数分钟后需停下喘气；4级：不能离家，或穿脱衣即气短。

课程仍用“≥2次中度或住院”的风险门槛；GOLD 2026已调整ABE并将一次中度加重作为升级治疗评估阈值。必须标清课程版与2026版，不能把旧风险分组称为最新GOLD。

### 4｜分组

```text
A
低风险 + 症状少

B
低风险 + 症状多

E
急性加重高风险
```

（易混：GOLD 1–4 用 FEV1%pred 评估肺功能严重程度；A/B/E 用症状与急性加重风险组织治疗。）

## KP17｜稳定期治疗：戒烟是上游，支气管扩张剂处理可逆部分

> **讲义定位 →** 内科 印刷 P5（PDF 物理 P6）｜稳定期治疗  
> **Outline →** 内科 U002｜治疗 1–5、9  
> **主提示：** 风险干预｜ABE方案｜药类/代表｜ICS条件

### 1｜上游措施

> **戒烟是预防 COPD 最重要的措施。**

稳定期还需降低感染诱发急性加重的风险。

### 2｜药物针对“可逆部分”

COPD 同时包含：

```text
不可逆
气道纤维化 / 狭窄
末梢肺组织弹性结构破坏

相对可逆
气道平滑肌痉挛
分泌物与炎症渗出
```

因此稳定期以吸入支气管扩张剂改善气道痉挛和流速。β₂受体激动剂提供舒张方向，抗胆碱药阻断 M 受体介导的收缩方向；课程以氨茶碱抑制磷酸二酯酶、减少 cAMP 水解解释茶碱支扩接口。具体用药仍回到适用场景，不把列举药物当成可互换处方。

### 3｜按当前 Study 的 A / B / E

- A组：一种支气管扩张剂；
- B组：LABA + LAMA；
- E组：LABA + LAMA，或在相应指征下 LABA + LAMA + ICS。

常见类别：

- SABA：沙丁胺醇、特布他林；
- SAMA：异丙托溴铵；
- LABA：沙美特罗、福莫特罗；
- LAMA：噻托溴铵；
- 茶碱类为课程列举，不能与常用吸入支扩药视为同等默认选择。

### 4｜ICS 加用指征

当前 Study 强调：

- 急性加重住院史；
- 每年 ≥2 次中度急性加重；
- 血嗜酸性粒细胞≥300个/μL；
- 哮喘史或伴哮喘特征。

课程ICS代表为布地奈德、氟替卡松、倍氯米松。加重史、血嗜酸性粒细胞与伴哮喘共同帮助判断获益，300个/μL是获益预测线索而非所有场景的独立充分指征；初始治疗与随访升级须分开，结合当前支扩方案、持续加重和肺炎等风险。

必要时可用祛痰药；课程原有三种代表为氨溴索、乙酰半胱氨酸、羧甲司坦（内科印刷 P6｜PDF 物理 P7）。药名精记可按“扩气道—抗炎—清痰”分组；祛痰不能替代支扩或必要通气支持。

（易混：ICS 是哮喘长期抗炎核心；COPD 并非所有稳定期患者都常规使用 ICS。）

## KP18｜长期家庭氧疗：改善预后，但不等于解决 CO₂潴留

> **讲义定位 →** 内科 印刷 P6（PDF 物理 P7）｜长期家庭氧疗  
> **Outline →** 内科 U002｜治疗 6  
> **主提示：** LTOT适应/时长｜目标｜设备｜CO₂机制

按当前 Study：

```text
长期家庭氧疗目标
PaO₂ ≥60 mmHg
SaO₂ ≥90%
```

采用低流量：

```text
课程鼻导管示例1–2 L/min
课程鼻导管粗估式 FiO₂(%) ≈ 21 + 4×氧流量(L/min)，1–2 L/min 算得约25%–29%
“约30%”是近似口径，实际 FiO₂随设备、呼吸模式与分钟通气变化
```

当前 Study 的解释链：

```text
长期 CO₂潴留
→ 中枢化学感受器逐渐适应
→ 对 CO₂敏感性下降
→ 低氧刺激外周化学感受器成为重要驱动
→ 高浓度氧可能削弱该驱动并加重 CO₂潴留
```

上述低氧驱动不是唯一机制，须与R2的V/Q恶化、霍尔丹效应及部分通气下降合看。长期氧疗的生存获益主要针对稳定期慢性重度静息低氧，不是所有COPD均获益。ATS条件示例：PaO₂≤55 mmHg或SpO₂≤88%；或PaO₂56–59/SpO₂89%伴水肿、红细胞增多或肺型P等，LTOT至少15h/d，并复评适应证。

> **LTOT目标与急性高碳酸风险的88%–92%滴定情境分开；吸氧改善低氧，不能替代必要通气支持。**

## KP19｜AECOPD：先识别严重度，再处理感染、气道、炎症和通气

> **讲义定位 →** 内科 印刷 P6（PDF 物理 P7）｜急性加重期  
> **Outline →** 内科 U002｜治疗 2、7–11；U003 治疗 12–13  
> **主提示：** AECOPD诱因｜症状/严重度｜急性期3类药｜氧疗/通气｜有创门槛

### 1｜识别急性加重

最常见原因：感染。课程列出的常见病原体为肺炎链球菌、流感嗜血杆菌、卡他莫拉菌、金黄色葡萄球菌（内科印刷 P6｜PDF 物理 P7）；这份已有Source名单供理解诱因与查阅，不新增逐项默认记忆要求，也不纳入lg05精记答案；它不穷尽所有加重病原体。

常见表现：

- 咳嗽、咳痰、喘息加重；
- 黄脓痰；
- 可伴发热；
- 气促和血气恶化。

### 2｜当前 Study 分级

| 分级 | 高碳酸血症 | 呼吸衰竭 | 意识状态 |
|---|---|---|---|
| Ⅰ级 | 无 | 无 | 无改变 |
| Ⅱ级 | 有 | 有 | 无改变 |
| Ⅲ级 | 有 | 有 | 有意识改变 / 肺性脑病 |

### 3｜治疗层级

```text
感染
→ 必要抗菌治疗

气道痉挛
→ 吸入支气管扩张剂

住院、炎症加重
→ 口服或静脉全身糖皮质激素

低氧
→ 鼻导管低流量氧疗

严重呼衰
→ 机械通气

意识障碍 / Ⅲ级
→ 立即评估通气和气道保护，进入有创机械通气评估接口
```

课程Ⅲ级是危险提示，不把所有意识变化机械等同已决定插管。适合且无禁忌的急性高碳酸呼衰常先评估NIV；不能保护气道、持续循环不稳、呼吸停止或NIV失败等需升级有创支持，不能因尝试NIV而延误。

稳定期和急性加重期都需要支气管扩张剂，但糖皮质激素的给药身份不同：稳定期按特定条件考虑 ICS；需要住院的急性加重可用全身激素。

### 4｜原课程已经给出的药物答案

- 抗菌药：课程只列“头孢、沙星等”两类，没有给出可直接执行的具体药物、剂量、疗程或个体选药算法。保留类别，不补造处方。
- 全身激素：泼尼松、氢化可的松、甲泼尼龙；课程给药途径为口服或静注，未逐药配给剂量。
- 祛痰药：氨溴索、乙酰半胱氨酸、羧甲司坦，和 KP17 同一组答案。
- 支扩药类别与代表复用 KP17；NIV 的数值准入、通气参数与完整机械通气路径仍归 R12，本 Source 未给的数字保持 HOLD。

记忆时先把药放回感染、痉挛、炎症、分泌物四个靶点，再恢复原有类别/名字，不能只背一串药。

## KP20｜COPD 急救安全边界：先改善通气，不轻易“补碱和镇静”

> **讲义定位 →** 内科 印刷 P6（PDF 物理 P7）｜其他治疗  
> **主提示：** 呼酸处理优先轴｜补碱条件｜镇静/抑呼吸风险

### 1｜酸中毒

```text
气道阻塞 / 肺泡通气不足
→ CO₂潴留
→ 呼吸性酸中毒
```

首要处理应是改善通气和病因，而不是直接用碱掩盖 CO₂问题。

按当前 Study：

- 一般不补碱；
- 课程pH<7.2列补碱接口，但不能单凭这一数值处理呼酸；应先看通气能否排出新增CO₂、是否合并代谢性酸中毒及循环不稳，避免补碱掩盖通气失败。

### 2｜药物安全

- 课程“呼吸系统疾病禁用吗啡”针对抑呼吸风险，不能扩成所有呼吸病、所有治疗目的和监护条件下的永久绝对禁忌；
- 课程另一具名例为地西泮：意识障碍者禁用这类镇静药；通气衰竭或意识障碍时不可自行加镇静/抑呼吸药。专业气道与机械通气管理的镇静方案是另一情境，不能用口诀代替。
- Source 旁注“无意识障碍者可用地西泮等减少氧耗”不等于无意识障碍即可常规安全使用；这一缺少监护/气道保护等前提的宽泛用药命题保持 HOLD，不从它生成自动给药建议。

（易混：这不是完整重症镇静方案；本 Block 只保留会加重呼吸中枢抑制的考试边界。）

## KP21｜COPD 出口：先与哮喘建立“持续 vs 可变”的主鉴别轴

### 1｜共同点

两者都可出现：

- 呼气性呼吸困难；
- 阻塞性通气障碍；
- FEV1/FVC下降；
- RV增多、过度充气；

- 严重时低氧、CO₂潴留。

```text
COPD
```
