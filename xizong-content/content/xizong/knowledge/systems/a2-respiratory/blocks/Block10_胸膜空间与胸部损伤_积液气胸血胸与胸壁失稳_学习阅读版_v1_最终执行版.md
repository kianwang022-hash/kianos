## 0｜这个 Block 到底解决什么

胸膜腔正常时只有少量润滑液，并维持负压，使肺随胸壁扩张。胸膜内容物增加、持续高压与胸壁失稳分别改变肺扩张和循环；危险可以同时出现。

```text
液体 / 血液 / 脓液占据胸膜空间
├─ 肺受压、扩张受限 → 通气负担增加、呼吸困难
├─ 积液区声音传导减弱 → 语颤 / 呼吸音减弱，叩浊或实
└─ 大量占位可将纵隔推向健侧
其中全血进入胸膜腔还伴循环血量丢失 → 可出现低血容量 / 休克

气体进入胸膜腔 → 负压减弱、肺回缩 → 通气受损
若形成单向活瓣、胸膜压力持续升高
├─ 肺进一步受压 → 呼吸受损
└─ 静脉回流受阻 → 心室前负荷、搏出量与CO下降 → 阻塞性休克

胸壁受伤
├─ 骨折疼痛 → 深呼吸 / 咳嗽受抑制 → 通气及排痰受影响
└─ 胸壁失稳并出现反常运动时，结合肺挫伤 / 疲劳判断呼吸支持需求
```

### 本 Block 的中心任务

> **先识别呼吸和循环威胁；张力性气胸等紧急情况即时处理。随后和处置同时，用内容物、压力、胸壁与失血的证据分别确定病因和下一步，不能等待叩诊或完整分类后才救治。**

## 1｜进入本章需要的模型

先把三件事接起来：

- 密闭胸膜腔把胸壁运动传给肺；积气破坏耦联，液体占位也会限制肺扩张。这接回 R1 的胸膜负压与 R2 的有效通气。
- 静水压推动液体滤出，血浆蛋白的胶体渗透压帮助保留血管内水分；通透性增加则让更多蛋白、细胞随液体进入胸膜腔。
- 循环不稳可来自血液丢失，也可来自高压阻碍静脉回流；这两条路都能使心室充盈和输出下降，处理对象却不同。

进入本章时只调用这三段所需模型；出现理解卡点再局部补讲，不以固定问答或显式确认作为继续讲解的门槛，也不据此记录已掌握。R7 的结核、R9 的肺栓塞与右心模型只在相应鉴别处调用。

## 2｜总 Framework

```text
入口：先看呼吸 / 循环是否不稳，危险处置与后续取证并行

胸膜内容物与压力支
├─ 炎症 / 损伤使通透性↑，或静水压 / 胶渗压 / 淋巴回流失衡
│  → 胸水形成；液体和病因证据决定渗出 / 漏出及后续处理
├─ 全血进入胸膜腔 → 胸内占位 + 循环容量丢失
│  持续引流血、循环不稳与血象趋势共同支持仍在出血 → 及时探查处理
├─ 感染形成脓液 → 抗感染 + 引流源控制
│  若形成慢性纤维收缩 → 胸廓收缩、纵隔牵向患侧
└─ 气体进入 → 负压减弱、肺回缩
   ├─ 破口闭合：压力与大小须结合症状、背景和循环判断
   ├─ 破口开放：与外界相通、可有纵隔摆动 → 封闭后仍观察是否转为张力
   └─ 单向活瓣使压力持续↑ → 肺受压，同时回心↓、CO↓ → 立即减压

共同空间后果与观察
液 / 气占位可压肺并隔音；叩诊、影像及取材分别读内容物、位置与性质
大量占位推向健侧；纤维收缩 / 肺不张拉向患侧，方向不是病名的固定顺序
穿刺 / 引流解除占位或压力，但须防骤然复张损伤与迷走反应

胸壁损伤支，与胸膜内容物支可并存
├─ 肋骨骨折疼痛 → 抑制深呼吸和排痰 → 镇痛与呼吸管理
├─ 胸壁失稳 / 反常运动 + 肺挫伤、疲劳程度 → 决定支持和固定层级
└─ 挤压 + 声门闭合 → 胸内压骤升 → SVC逆流 → 上半身瘀点

处理回到失效环节：减压、封闭、引流、通气、止血 / 探查各有对象
持续出血、重大胸腹 / 膈肌损伤、循环崩溃等沿原开胸指征立即判断
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

这张模型从呼吸和循环威胁进入，沿胸膜内容物 / 压力与胸壁损伤两支解释机制；检查读取这些改变，处理回到造成危险的环节。完整标题〔Prompt〕固定在相应关系或旁查位置，数值和操作版本沿原 Core、Memory 与 Source 回看。

```text
胸痛、气促、单侧呼吸音弱或胸部外伤
→ 先识别呼吸和循环不稳；紧急处置与判断内容物、压力、胸壁及失血原因并行

胸膜内容物从不同来源增加
├─ 局部炎症 / 损伤 → 通透性↑ → 蛋白、细胞与液体进入胸膜腔
│  静水压↑ / 胶渗压↓等动力失衡也可形成胸水；恶性胸水还可涉及浸润、淋巴回流受阻
│  药物 / 超敏相关胸膜炎属于已裁决的渗出支；旧表项只作Source provenance
│  〈胸水形成机制：炎症通透性 vs Starling动力失衡〔渗出vs漏出机制｜病因按机制归组｜药物炎症已裁决｜恶性多机制〕〉
├─ 全血进入胸膜腔 → 胸内占位压肺，同时循环血量丢失 → 气促与低容量表现可并存
│  血性胸水只是液体混血，不能凭一次抽到血就等同血胸或持续出血
│  〈血性胸水 vs 血胸：先分清“胸水带血”还是“全血进胸腔”〔身份2｜分度3｜表现2组｜血性胸水病因3〕〉
│  若持续引流血、循环不稳、血象下降和引流血特征共同支持仍在出血
│  → 进行性血胸 → 及时开胸探查；不能等单个数字满足后才评估危险
│  〈进行性血胸：不只看一次引流量，要看持续出血证据链〔4证据｜出血3阈值｜生命征｜血象3轴｜引流血2特征｜处理1〕〉
└─ 感染形成脓液 → 抗菌治疗同时引流源控制；已抽到脓不等待pH再决定是否为脓胸
   〈急性脓胸：抗生素不够，最基本是把脓液引出去〔起病｜纵隔｜ADA｜细胞/数｜pH/LDH｜金标病原｜治疗4〕〉
   若迁延形成纤维收缩 → 胸廓收缩、肺扩张受限、纵隔可牵向患侧
   → 按纤维化、病肺和病程判断剥脱等处理；急性到慢性是条件性演变
   〈慢性脓胸：从大容量推挤转为纤维收缩牵拉〔热型｜胸廓｜纵隔｜杵状指｜短/长病程术式〕〉

液体占位的两类后果同时发生
├─ 肺受压、扩张受限 → 呼吸困难；程度还看积液量、速度和原有肺病
└─ 积液区声音传导受阻 → 语颤 / 呼吸音减弱，叩浊或实
   积液上方可有支气管呼吸音；摩擦音取决于相应位置的两层胸膜是否仍接触
   〈胸腔积液体征：液体隔开了声音，也把肺和纵隔推走〔最常见1｜呼吸困难液量门槛｜抑制呼吸3病｜视触叩听5层｜纵隔方向〕〉
大量液 / 气占位可推纵隔向健侧；纤维收缩、肺不张等可牵向患侧，轻病变可不移位
大量积液使局部胸膜层分离，不能由任何纵隔移位反推必有大量液体或全胸无摩擦音
〈纵隔方向：大块占位推向健侧，慢性收缩拉向患侧〔纵隔移位2方向：2/5病组｜不移：轻病变+3病组｜摩擦音共存边界〕〉

对胸水的取证分别回答位置、性质和病因，证据不是病理的下一阶段
├─ 胸片显示液体分布；超声敏感并定位穿刺；CT补充病因 / 胸膜信息
│  取液检查性质，高疑恶性时进一步取胸膜证据；不要求每人按同一串检查全部走完
│  〈胸水检查顺序：看见液体、找到位置、取得液体、看清胸膜〔X线/液量/弧形/D字｜超声2用途｜CT病因｜胸穿性质｜疑恶性胸腔镜〕〉
├─ 蛋白 / LDH等读取形成机制，Light任一阳性支持渗出，不能凭其中一条阴性判漏出
│  糖低见于部分病因；利尿、白蛋白梯度及单位边界沿原表判读
│  〈渗出 vs 漏出：先抓“内容物丰富度”，再记 Light 三条〔外观/凝固｜比重/蛋白｜糖/细胞｜比值3｜蛋白梯度门槛｜Light3条/组合条件〕〉
└─ 病程、人群、ADA / CEA / LDH与细胞 / 组织证据共同加权结核或恶性来源
   单标志物不确诊；结核病因治疗与恶性胸水引流 / 胸膜处理分路，完整病种回R7 / R11
   〈结核性 vs 恶性胸水：ADA先分，CEA / LDH和年龄再加权〔起病/人群｜ADA/CEA阈值与比值｜LDH2阈值｜细胞共同｜血性3病｜处理2路〕〉

穿刺 / 引流减少占位和压力，但处理也可引起新损伤
分次、控制速度与量，并观察胸痛、咳嗽和气促；课程量限与现有指南条件分开，不追求一次抽空
〈胸腔穿刺基本量：分次抽，不追求一次抽空〔抽液频次｜首次/后续容量｜分次目的2｜操作边界〕〉
├─ 过快 / 过多排液，压力骤变与肺、血管复张 → 可出现复张后肺水肿
│  → 停止、给氧并评估支持；原药物说法和现代处理边界仍回Core
│  〈复张后肺水肿：抽得太快 / 太多，肺和血管同时骤然复张〔触发2｜机制链｜表现3｜处理4〕〉
└─ 穿刺刺激迷走反应 → 心率 / 血压下降及自主症状
   → 停止、体位和生命征评估，同时排除其他并发症；不由“心悸”直接推心动过速
   〈胸膜反应：迷走神经被刺激，不是抽液容量本身〔迷走/心率/血压｜自主症状｜即刻处置3轴｜用药条件｜复张水肿鉴别〕〉

气体进入胸膜腔 → 负压减弱、肺回缩 → 通气受损
突发胸痛后气促是常见入口，结合基础病与危险背景鉴别，不能仅凭症状排除PE
〈自发性气胸识别：先胸痛、继之呼吸困难〔基础病4｜胸痛→气促｜与PE共性/危险条件｜鉴别4轴〕〉
气体也隔音，但含气区常叩鼓音；影像的胸膜线及外侧肺纹理缺失等帮助识别
纵隔方向、气液并存和气体进入纵隔的体征按各自空间解释
〈气胸体征：像胸水一样“隔音”，但叩诊是鼓音〔视触叩听4层｜纵隔｜心尖｜振水音｜Hamman｜X线〕〉
├─ 破口已闭合：课程“压力低于大气压”不是所有时相的保证，也不能据此排除张力
│  观察或抽气须结合症状、低氧、循环、大小及背景；20%保留课程条件，不新造等号裁决
│  〈闭合性气胸：破口已经闭合，压力低于大气压〔别称｜破口｜压力｜纵隔｜大小2支/处理条件〕〉
├─ 破口与外界相通：呼吸时胸腔压力变化可使纵隔摆动
│  → 封闭开放通道并评估引流；封闭后若继续漏气、恶化，警惕张力，不能封闭后即停止观察
│  〈开放性气胸：吸吮样破口使纵隔随呼吸摆动〔别称｜破口｜压力｜吸气纵隔方向｜急救1｜恶化时1〕〉
└─ 单向活瓣使气体只进不出 → 胸膜压力持续升高
   ├─ 肺受压更重 → 呼吸受损
   └─ 静脉回流受阻 → 前负荷、搏出量、CO下降 → 阻塞性休克
   → 立即减压；呼吸和循环是同一高压的并行后果，不等影像才解除危急高压
   〈张力性气胸：气只进不出，先减压再谈后续〔别称｜活瓣｜压力｜呼吸/循环链｜体征3｜威胁最大｜立即1〕〉
需要持续排气 / 排液时接闭式引流；急救穿刺与胸管不是同一种操作
位置按目的、现有安全定位与影像条件选择；插拔时相带操作版本，拔管看完整组合，堵管不等于可拔
〈胸腔闭式引流：位置、插拔时相与拔管判断〔气/液置管位置2组｜置入/拔管呼吸时相｜拔管4组合｜适应6〕〉

胸壁损伤与上述胸膜支可同时发生
├─ 肋骨骨折疼痛 → 深呼吸和咳嗽受抑制 → 通气 / 排痰受影响
│  → 镇痛和呼吸管理；低位肋骨伤同时检查肝脾等并伤，不能把外固定写成常规紧束胸
│  〈肋骨骨折：最常第4–7肋，疼痛可让患者不敢通气和排痰〔好发肋4｜症状3｜抑制呼吸链｜低肋并伤｜治疗3层〕〉
├─ 多处骨折可形成游离胸壁节段；影像连枷段与临床反常运动分开
│  胸壁失稳、肺挫伤和呼吸肌疲劳共同影响有效通气 → 按呼吸状态选择支持 / 固定
│  临床吸气内陷、呼气外凸不同于开放性气胸纵隔摆动；不因影像骨折排列就自动插管
│  〈连枷胸：胸壁反常运动，不等于开放性气胸的纵隔摆动〔定义｜别称2｜反常运动｜小/大范围处理｜与开放气胸比较〕〉
└─ 胸部挤压时声门紧闭 → 胸内压骤升 → SVC系统逆流 → 上半身瘀点 / 瘀斑
   这是创伤性窒息的受力与静脉分布，不能将其当作持续张力性气胸
   〈创伤性窒息：胸内压瞬间升高，把静脉血反冲到上半身〔受伤机制2环｜胸内压/SVC链｜分布/出血形态｜处理/消退时程〕〉
持续出血、重大胸腹 / 膈肌损伤、压塞 / 休克或严重气管内出血等
→ 按原急诊开胸范围及时处理；减压、封闭、引流、通气与止血分别纠正具体威胁
```

## 3｜Memory Routing

### MI-G｜沿模型主动恢复的要点

1. 血性胸水 ≠ 血胸：前者是胸水中混有血，后者是全血积入胸膜腔；
2. 血胸分度：≤0.5 L、0.5–1 L、>1 L；
3. 进行性血胸四证据，尤其引流 >200 ml/h 持续3小时；
4. 渗出液主轴是炎症 / 通透性增加；漏出液主轴是静水压、胶渗压等动力失衡；药物 / 超敏相关胸膜炎症归渗出液；
5. Light 标准三条，符合任一即渗出液；
6. 胸腔积液：患侧胸廓饱满、肋间隙增宽、语颤 / 呼吸音↓、叩浊 / 实、肺下界移动↓，大量时纵隔向健侧；
7. 胸膜摩擦音可出现在仍接触的炎症胸膜区域；大量积液覆盖并分开两层的区域通常减弱 / 消失，不能推成任何纵隔移位或全胸均无摩擦音；
8. X线首选，超声最敏感且定位穿刺，胸穿是明确性质金标准，疑恶性胸水胸腔镜金标准；
9. 胸穿课程量：首次<800 ml、以后<1000 ml；量限带版本，胸痛、持续咳嗽或气促加重应提前停止；
10. 胸膜反应来自迷走神经刺激，与“抽太快太多”不同；
11. 结核性胸水：ADA>45、淋巴细胞为主；恶性胸水：CEA / LDH更高；
12. 急性脓胸：中性粒细胞、细胞数高、pH可<7、LDH>500；最基本治疗是引流；
13. 慢性脓胸：胸廓塌陷、纵隔向患侧、可杵状指；按纤维化程度决定剥脱 ± 病肺切除；
14. 气胸典型：突发胸痛后呼吸困难、患侧鼓音、语颤 / 呼吸音↓、多无啰音；
15. 闭合性指破口闭合；压力低于大气压和20%分支是课程概括，不能排除张力。观察 / 抽气还须结合症状、低氧、循环、大小和背景，详见KP16；
16. 开放性：吸吮样破口、胸膜压=大气压、纵隔摆动；呼气末封闭破口；
17. 张力性：活瓣、胸膜压>大气压、呼吸循环障碍、皮下 / 纵隔气肿；立即穿刺减压；
18. 课程气 / 液引流位置分别为锁骨中线第2肋间、腋中—腋后线第6–7肋间；须区分急救针刺与胸管，并结合安全三角 / 超声等定位，详见KP19；
19. 插管深呼气后屏气、拔管深吸气后屏气是课程配对；实际呼吸配合与Valsalva等按具体操作，拔管须看完整组合，堵管不等于可拔，详见KP19；
20. 肋骨最常骨折第4–7肋；低位肋骨需警惕肝脾；
21. 多根多处骨折可形成连枷段；影像连枷段与临床反常运动须分开，课程与现有定义带版本，支持取决于肺挫伤、疲劳和呼吸状态，详见KP21；
22. 开放性气胸“纵隔摆动”与连枷胸“胸壁反常运动”不是同一现象；
23. 创伤性窒息链：挤压 + 声门闭合 → 胸内压骤升 → 上腔静脉逆流 → 上半身瘀点；
24. 进行性血胸、重大胸腹 / 膈肌损伤、休克 / 压塞、严重气管内出血等需急诊开胸。

# Unit B｜胸腔积液：先判漏出 / 渗出，再判病因和是否必须引流

## KP03｜胸水形成机制：炎症通透性 vs Starling动力失衡

> **讲义定位 →** 内科 Lecture P67  
> **Outline →** 内科 U026｜胸水1–3  
> **主提示：** 渗出vs漏出机制｜病因按机制归组｜药物炎症已裁决｜恶性多机制

### 1｜渗出性胸水

主轴：

```text
炎症 / 损伤
→ 胸膜毛细血管通透性↑
→ 蛋白、细胞和液体进入胸膜腔
```

Study 例：

- 胸膜炎、结核和普通细菌感染；
- 膈下脓肿、肝脓肿、急性胰腺炎；
- 肿瘤 / 胸膜转移；
- 风湿病；
- 肺梗死、气胸；
- 胸膜淋巴引流受阻。

canonical 补充：**药物诱发 / 超敏相关胸膜炎症也按渗出性胸水处理**。

### 2｜漏出性胸水

主轴：

- 胸膜毛细血管静水压↑；
- 血浆胶体渗透压↓；
- 系统性动力失衡。

Study 例：

- 右心衰、心包积液、缩窄性心包炎、上腔 / 奇静脉受阻；
- 血容量增加；
- 营养不良、肝硬化、肾病、腹膜透析、黏液性水肿。

### 3｜Source Conflict 裁决｜R10-SC01

Lecture 表格把“药物过敏”列入漏出液，但同一处正文又以“通透性增加”解释该路径，内部已经形成机制冲突。canonical 不要求 learner 同时记两套互斥分类。

外部权威核验：

- **AAFP, Pleural Effusion: Diagnostic Approach in Adults (2023)**：药物导致胸膜表面炎症，归入 **exudative fluid accumulation**；其表格也把 medication-induced effusion 列在 exudative 一侧；
- **Merck Manual Professional, Pleural Effusion**：漏出液的核心是静水压升高 / 胶体渗透压下降，渗出液的核心是毛细血管通透性增加。

因此 learner canonical 固定为：

```text
药物 / 超敏导致胸膜炎症
→ 局部通透性↑
→ 渗出性胸水
```

旧 Lecture “药物过敏→漏出液”只保留为 source-conflict provenance，不作为 Recall target。

### 4｜恶性胸水边界

恶性肿瘤可通过局部胸膜炎症 / 浸润、淋巴回流障碍等不同机制形成胸水；病例分析通常先按渗出性胸水识别，再用细胞学 / 胸腔镜等证据确定恶性身份。

## KP04｜渗出 vs 漏出：先抓“内容物丰富度”，再记 Light 三条

> **讲义定位 →** 内科 Lecture P68  
> **Outline →** 内科 U026｜胸水4；U027｜5  
> **主提示：** 外观/凝固｜比重/蛋白｜糖/细胞｜比值3｜蛋白梯度门槛｜Light3条/组合条件

| 轴 | 渗出液 | 漏出液 |
|---|---:|---:|
| 比重 | >1.018 | <1.018 |
| 外观 | 混浊，可凝固 | 清亮，不凝固 |
| 蛋白 | >30 g/L；Rivalta+ | <30 g/L；Rivalta− |
| 葡萄糖 | 部分感染、恶性或类风湿等胸水可降低；并非所有渗出液均<3.3 mmol/L | 常与血糖相近 |
| 细胞 | >500×10⁶/L | 多<100×10⁶/L |
| 胸水 / 血清蛋白 | >0.5为Light一条 | 不超过0.5且其余Light亦阴性才按漏出判断 |
| 胸水 / 血清 LDH | >0.6为Light一条 | 不超过0.6且其余Light亦阴性才按漏出判断 |
| 血清−胸水白蛋白梯度 | 讲义<12 g/L | 讲义≥12 g/L；属辅助指标，不是Light必备条件 |
| 肿瘤细胞 / 细菌 | 可有 | 无 |

蛋白和细胞进入较多，解释了渗出液常较混浊、比重和蛋白较高；纤维蛋白等成分可使其凝固。葡萄糖下降则还要看消耗和病因，不能从“渗出”两个字直接推出低糖。检查是在读取形成机制留下的结果，不是蛋白或LDH比值升高先制造了胸水。

### Light 标准

符合任意 1 项即判渗出液：

1. 胸水 / 血清蛋白 >0.5；
2. 胸水 / 血清 LDH >0.6；
3. 胸水 LDH >血清 LDH 正常上限的 2/3。

上表为典型方向而非每项均须符合。Light任一阳性即归渗出，三条均不满足才归漏出；利尿后心衰胸水可能出现假性渗出分类，须结合病因及白蛋白梯度。外观、比重、Rivalta、细胞数及葡萄糖不能代替Light。

## KP05｜胸腔积液体征：液体隔开了声音，也把肺和纵隔推走

> **讲义定位 →** 内科 Lecture P68–69  
> **Outline →** 内科 U027｜6–8  
> **主提示：** 最常见1｜呼吸困难液量门槛｜抑制呼吸3病｜视触叩听5层｜纵隔方向

### 1｜症状

- 呼吸困难最常见；
- 一般积液 >500 ml 时症状明显；
- 急性胸膜炎可有抑制性呼吸。

抑制性呼吸常见：

- 急性胸膜炎；
- 胸膜恶性肿瘤；
- 肋骨骨折。

### 2｜患侧体征

| 检查 | 当前 Study |
|---|---|
| 视诊 | 胸廓饱满，肋间隙增宽 |
| 触诊 | 语音震颤 / 共振减弱或消失；左侧大量时心尖搏动↓ / 消失 |
| 叩诊 | 浊音或实音；肺下界移动度↓ / 消失；假性上移 |
| 听诊 | 呼吸音↓ / 消失，多无干湿啰音 |
| 积液上方 | 可闻异常支气管呼吸音或支气管肺泡呼吸音 |

少量炎性积液处两层仍接触时可有摩擦音；大量积液覆盖区域常听不到。体征取决于量、分布及合并肺病，不能推成“任何部位摩擦音与大量积液绝不共存”。大量游离积液常使纵隔向健侧，小量或合并肺不张/粘连时可不移位。

“肺下界假性上移”是叩诊界限的变化：由上向下叩到积液就提前出现浊音，不能据此认定整个肺下缘真的被向上牵拉。少量炎症胸膜仍接触时，呼吸带动两层摩擦；屏气后摩擦音可消失，这是与心包摩擦音区分的线索。合并肺炎等肺内病变仍可有啰音，不能以听到啰音排除同时存在胸水。

## KP06｜纵隔方向：大块占位推向健侧，慢性收缩拉向患侧

> **讲义定位 →** 内科 Lecture P69、P74  
> **Outline →** 内科 U027｜8  
> **主提示：** 纵隔移位2方向：2/5病组｜不移：轻病变+3病组｜摩擦音共存边界

### 1｜向健侧

- 大量胸腔积液；
- 大量气胸。

### 2｜向患侧

- 慢性纤维空洞型肺结核；
- 慢性肺脓肿；
- 慢性脓胸；
- 肺不张；
- 明显胸膜粘连 / 增厚。

### 3｜多不移位

- 病变较轻；
- COPD、哮喘；
- 大叶性肺炎实变；
- 肺泡性肺水肿。

## KP08｜胸腔穿刺基本量：分次抽，不追求一次抽空

> **讲义定位 →** 内科 Lecture P70  
> **Outline →** 内科 U028｜12  
> **主提示：** 抽液频次｜首次/后续容量｜分次目的2｜操作边界

当前 Study：

- 大量胸水每周抽液 2–3 次；
- 首次 <800 ml；
- 以后每次 <1000 ml。

目的：

- 减轻肺受压与呼吸困难；
- 避免胸膜腔压力和肺血流在短时间内变化过大。

这些是本讲义考试数值，不是所有病因固定每周抽液的处方。临床补充（BTS 2023）：缓慢引流，一般单次最多1.5 L；胸闷、胸痛、持续咳嗽或气促加重须提前停止。不能把上限当必须抽到的目标；完整操作需专业评估与超声定位。

## KP09｜复张后肺水肿：抽得太快 / 太多，肺和血管同时骤然复张

> **讲义定位 →** 内科 Lecture P70  
> **Outline →** 内科 U028｜13  
> **主提示：** 触发2｜机制链｜表现3｜处理4

```text
抽液过快 / 过多
→ 胸膜腔压力骤降
→ 肺组织骤然扩张
→ 肺内血管也快速复张、血流增加
→ 渗出动力和损伤增加
→ 复张后肺水肿
```

表现：

- 剧烈咳嗽；
- 大量泡沫痰；
- 可有湿啰音、低氧及新发肺泡浸润；讲义写双肺满布，不应当作每例必备，亦可主要累及复张侧。

处理：

1. 立即停止抽液；
2. 吸氧；
3. 立即评估生命体征、氧合并检查影像，按严重度升级呼吸支持；
4. 讲义列“控制入量，必要时利尿剂和糖皮质激素”，须标为课程口径。BTS 2023指出利尿剂缺乏证据支持，未将激素列为常规处理；不能仅因“肺水肿”一概利尿或限液，仍须评估循环与容量。

## KP10｜胸膜反应：迷走神经被刺激，不是抽液容量本身

> **讲义定位 →** 内科 Lecture P70  
> **Outline →** 内科 U028｜14  
> **主提示：** 迷走/心率/血压｜自主症状｜即刻处置3轴｜用药条件｜复张水肿鉴别

胸腔穿刺刺激迷走神经：

```text
迷走反射 / 血管迷走性反应
→ 心率可减慢并伴血压下降
→ 头晕、面色苍白、出汗，严重时晕厥
→ 心悸属于主观感受，不能据此认定心率一定增快
```

处理：

- 停止抽液；
- 平卧休息；
- 监测血压、防止休克；
- 讲义列“必要时肾上腺素”，不能变成普通血管迷走反应的默认用药。持续症状性心动过缓伴低灌注时按复苏流程评估阿托品；无效才考虑起搏或监护下血管活性药输注（AHA 2025）。同时排查出血、气胸、低氧等其他原因。

（易混：复张后肺水肿看“抽得快 / 多 + 泡沫痰湿啰音”；胸膜反应看“迷走症状 + 低血压苍白出汗”。）

## KP11｜结核性 vs 恶性胸水：ADA先分，CEA / LDH和年龄再加权

> **讲义定位 →** 内科 Lecture P70、P73–74；回看 R7、预览 R11  
> **Outline →** 内科 U028｜15  
> **主提示：** 起病/人群｜ADA/CEA阈值与比值｜LDH2阈值｜细胞共同｜血性3病｜处理2路

| 轴 | 结核性胸水 | 恶性胸水 |
|---|---|---|
| 起病 | 慢，多低热 | 慢，多不发热或低热，中老年 |
| ADA（U/L） | 讲义>45 | 讲义<45；两侧均有例外 |
| CEA | <10 μg/L | >10 μg/L 或胸水 / 血清>1 |
| LDH | >200 U/L | >500 U/L |
| 细胞 | >500×10⁶/L，淋巴细胞 / 单个核为主 | 同样可为淋巴细胞 / 单个核为主 |
| 血性 | 可有 | 可有 |
| 处理 | 全身抗结核为主，按症状与分隔情况安全引流；不常规胸腔注抗结核药 | 结合肿瘤治疗、症状及肺复张选择引流、留置导管或滑石粉固定等 |

血性胸水还可见于PE。CEA/LDH/ADA为辅助证据，不以单一数值确诊恶性或结核；需相应细胞学、组织学或病原证据。讲义“尽快抽净”不能解释为一次快速无量限抽净，出现胸痛、持续咳嗽或呼吸困难应停止并评估。胸膜固定需考虑肺能否复张，胸腔化疗也不是所有恶性胸水的通用方案。

（边界：ADA 阈值用于“最可能”加权，不是绝对排除；当前 Study 明确免疫低下结核可 ADA 不高，胸膜淋巴瘤也可 ADA 很高。）

## KP12｜急性脓胸：抗生素不够，最基本是把脓液引出去

> **讲义定位 →** 内科 Lecture P70、P73  
> **Outline →** 内科 U028｜16；U029承接  
> **主提示：** 起病｜纵隔｜ADA｜细胞/数｜pH/LDH｜金标病原｜治疗4

### 1｜识别

- 急性寒战高热；
- 纵隔可向健侧移位；
- ADA可升高，讲义列>45 U/L，但不是脓胸诊断必备；
- 中性粒细胞 / 多核细胞为主；
- 胸水细胞可 >10×10⁹/L；
- pH 可 <7；
- LDH >500 U/L。

类肺炎性胸腔积液明确病原体最可靠：

- 胸水细菌培养 + 药敏。

### 2｜治疗

- 及时全身抗菌并按培养/药敏调整；
- **有效引流——感染源控制的关键**；明确脓液不必等pH降至7以下再处理；
- 讲义另列胸腔抗菌药、2% NaHCO₃冲洗和链激酶，不将其保留为通用临床常规；
- BTS 2023：初始引流停止但仍有残留感染性积液时，可评估tPA＋DNase；不推荐链激酶。盐水冲洗只在合适情形评估，不自行套用碱液冲洗。

> 脓腔是感染源；只有抗生素而没有源控制，治疗不完整。

## KP15｜气胸体征：像胸水一样“隔音”，但叩诊是鼓音

> **讲义定位 →** 内科 Lecture P71  
> **Outline →** 内科 U029｜气胸3–5  
> **主提示：** 视触叩听4层｜纵隔｜心尖｜振水音｜Hamman｜X线

患侧：

- 胸廓饱满、肋间隙增宽；
- 语音震颤减弱或消失；

## KP16｜闭合性气胸：破口已经闭合，压力低于大气压

> **讲义定位 →** 内科 Lecture P71  
> **Outline →** 内科 U030｜6  
> **主提示：** 别称｜破口｜压力｜纵隔｜大小2支/处理条件

- 别称：单纯性气胸；
- 破口：已闭合；
- 胸膜腔内压：低于大气压；
- 纵隔可不移位；
- 肺压缩量 <20%：观察；
- 超过该范围：当前 Study 采用穿刺抽气。

## KP17｜开放性气胸：吸吮样破口使纵隔随呼吸摆动

> **讲义定位 →** 内科 Lecture P71；27外科精编 PDF P028  
> **Outline →** 内科 U030｜7；外科 U006接口  
> **主提示：** 别称｜破口｜压力｜吸气纵隔方向｜急救1｜恶化时1

- 别称：交通性气胸；
- 破口：吸吮样，气体可自由进出；
- 胸膜腔内压：等于大气压；
- 吸气时健侧胸腔负压更低，把纵隔拉向健侧；呼气时又摆回，形成纵隔扑动 / 摆动。

急救：

- **呼气末封闭破口，把开放性变成闭合性。**

若转运中呼吸困难加重或出现张力性表现，当前 Study 提示可在呼气时开放敷料排出高压气体，并在条件允许时行胸腔闭式引流。

## KP18｜张力性气胸：气只进不出，先减压再谈后续

> **讲义定位 →** 内科 Lecture P71、P75–76；回看 R1、R9  
> **Outline →** 内科 U030｜8；外科真题接口  
> **主提示：** 别称｜活瓣｜压力｜呼吸/循环链｜体征3｜威胁最大｜立即1

- 别称：高压性气胸；
- 破口：活瓣；
- 胸膜腔内压：高于大气压；
- 三类气胸中威胁最大。

```text
气体只进不出
→ 胸膜腔压力持续升高
├─ 患肺受压、通气下降
└─ 高压阻碍腔静脉回流
   → 回心血量、前负荷下降，SV、CO可下降
   → 可出现心动过速、低血压、休克
```

还可：

- 纵隔气肿；
- 皮下气肿；
- 呼吸循环障碍。

急救：

> **立即胸膜腔穿刺减压 / 抽气。**

（易混：张力性气胸是高压持续向一侧推移，不是开放性气胸的左右纵隔摆动。）

## KP19｜胸腔闭式引流：位置、插拔时相与拔管判断

> **讲义定位 →** 内科 Lecture P72  
> **Outline →** 内科 U030｜胸腔引流1–3  
> **主提示：** 气/液置管位置2组｜置入/拔管呼吸时相｜拔管4组合｜适应6

### 1｜位置

- 气胸：锁骨中线第2肋间；
- 胸水：腋中线与腋后线之间第6–7肋间。

以上为讲义传统定位，不能替代术前影像与安全定位。液体操作须超声定位；置管常在安全三角区选择合适位置，不能混淆应急针刺减压点和正式胸管置入点。

### 2｜呼吸配合

- 插管：深呼气后屏气；
- 拔管：讲义为深吸气后屏气；现代操作强调按流程配合屏气/Valsalva并立即密闭创口，吸气末或呼气末本身不是唯一成败因素。

### 3｜拔管逻辑

| 肺扩张与气液证据 | 引流管 | 处理 |
|---|---|---|
| 肺扩张好，且无气液排出 | — | 拔 |
| 肺不张，或仍有气液排出（任一成立） | — | 不拔 |
| 肺扩张好，少量残留 | 通畅 | 继续引流，不拔 |
| 肺扩张好，少量残留 | 堵塞 | 讲义列可拔；实际先明确堵塞、漏气/积液及肺复张状态，不能以“堵了”作为自动拔管依据 |

### 4｜Lecture-only 适应证路由

- 中、大量闭合性气胸；
- 开放性 / 张力性气胸；
- 穿刺后肺未复张；
- 机械通气相关气胸 / 血气胸；
- 拔管后复发；
- 开胸术后。

# Unit D｜胸壁与严重胸部创伤：风箱本身也可能失效

## KP20｜肋骨骨折：最常第4–7肋，疼痛可让患者不敢通气和排痰

> **讲义定位 →** 27外科精编 PDF P028  
> **Outline →** 外科 U006｜肋骨1、3–4  
> **主提示：** 好发肋4｜症状3｜抑制呼吸链｜低肋并伤｜治疗3层

### 1｜好发部位

- 第4–7肋最易骨折；
- 第1–3肋较粗且受锁骨、肩胛骨保护；
- 第8–10肋形成肋弓，可传递力量；
- 第11–12肋为浮肋，不易骨折。

### 2｜功能后果

先区分疼痛造成的呼吸受限与骨折的局部证据：胸痛使呼吸浅快、咳嗽受抑；断端活动可出现骨擦音或骨擦感，局部可见胸廓畸形、压痛及挤压试验阳性。出现这些表现后，还要看是否合并血气胸、肺不张或感染，而不是把所有气促都归给疼痛。

```text
骨折疼痛
→ 不敢深呼吸 / 咳嗽
→ 抑制性呼吸
→ 痰液潴留
→ 肺部并发症风险↑
```

低位肋骨骨折需警惕肝、脾损伤，腹部超声用于寻找这些腹腔并伤，并非用来替代骨折本身的影像判断。

### 3｜治疗原则

- 控制疼痛；
- 早期活动、物理治疗；
- 讲义列非多根多处胸带固定；现代一般不常规紧束胸廓，以免限制深呼吸和排痰。固定/手术策略须看稳定性、移位及呼吸功能。

## KP21｜连枷胸：胸壁反常运动，不等于开放性气胸的纵隔摆动

> **讲义定位 →** 外科 Lecture P22  
> **Outline →** 外科 U006｜肋骨2、4–5  
> **主提示：** 定义｜别称2｜反常运动｜小/大范围处理｜与开放气胸比较

### 1｜身份

- 讲义定义为≥2根相邻肋骨各≥2处骨折；现代WSES/CWIS影像连枷段常定义为≥3根连续肋骨各≥2处，须区分定义版本；
- 胸壁软化；
- 连枷胸；
- 临床连枷胸强调反常运动：吸气时软化段内陷，呼气时外凸；影像连枷段与明显临床反常运动不完全等同。

### 2｜处理

| 胸壁软化范围 | 表现 | 当前 Study |
|---|---|---|
| 小 | 无明显反常呼吸 | 胸带固定 |
| 大 | 明显反常呼吸、可纵隔扑动 | 气管插管、呼吸机正压通气、切开复位内固定 |

以上处理表为课程分支。实际优先镇痛、排痰与评估肺挫伤，依据呼吸衰竭/疲劳决定通气支持，而非看到连枷段就必须插管；对适合患者评估肋骨手术固定。不能把表中胸带理解为普遍紧束胸廓。

### 3｜两种“动”

```text
连枷胸
→ 胸壁软化段随吸呼气反常运动

开放性气胸
→ 两侧胸膜压力不平衡
→ 纵隔左右摆动
```

> 一个是胸壁结构失稳，一个是胸膜腔与外界交通；病例中必须先看受伤结构。

## 4｜高密度比较表

### A｜胸水、气胸、肺不张

| 轴 | 胸腔积液 | 气胸 | 肺不张 |
|---|---|---|---|
| 胸廓 | 患侧饱满 | 患侧饱满 | 患侧平坦 / 塌陷 |
| 纵隔 | 大量时向健侧 | 大量时向健侧 | 向患侧 |
| 语颤 | ↓ / 消失；积液上方可↑ | ↓ / 消失 | ↓ / 消失 |
| 叩诊 | 浊 / 实 | 鼓音 | 浊 / 实 |
| 呼吸音 | ↓ / 消失 | ↓ / 消失 | ↓ / 消失 |
| 啰音 | 多无 | 多无 | 多无 |
| 关键空间 | 液体 | 气体 | 肺组织容积收缩 |

### B｜三类气胸

| 轴 | 闭合性 | 开放性 | 张力性 |
|---|---|---|---|
| 别称 | 单纯性 | 交通性 | 高压性 |
| 破口 | 已闭 | 吸吮样开放 | 活瓣 |
| 胸膜压 | <大气压 | =大气压 | >大气压 |
| 纵隔 | 可不移 | 随呼吸摆动 | 持续推向健侧 |
| 课程处理入口 | 20%为课程分支；症状、基础病与稳定性条件见KP16 | 封闭后监测张力性恶化，见KP17 | 立即减压，见KP18 |

### C｜结核、恶性、急性脓胸

| 轴 | 结核性 | 恶性 | 急性脓胸 |
|---|---|---|---|
| 病程 / 发热 | 慢、低热 | 慢、不热 / 低热 | 急、高热 |
| 细胞 | 淋巴 / 单核 | 淋巴 / 单核 | 中性粒 / 多核 |
| ADA（课程方向，均非诊断必备） | 常>45，可例外 | 常<45，可例外 | 可升高，非必备 |
| LDH | >200 | >500 | >500 |
| pH | 常下降 | 常下降 | 可<7 |
| 核心处理 | 抽液 + 全身抗TB | 胸膜固定 / 抗肿瘤 | 抗感染 + 引流 |

### D｜病例最小算法

```text
Step 1｜先识别呼吸 / 循环威胁，处置与检查并行
高压气胸体征 + 呼吸 / 循环不稳 → 立即减压
持续引流血 + 循环不稳 / 血象下降 → 进行性血胸评估、及时探查处理
吸吮样开放伤口 → 封闭并观察是否恶化为张力；胸壁失稳则按呼吸状态支持

Step 2｜按内容物和胸壁寻找证据
浊 / 实提示液体、血、脓等候选，仍结合影像及肺内病变
鼓音结合单侧隔音与影像支持气胸；不凭叩诊单独定病
胸壁反常运动与开放伤口造成的纵隔摆动分别定位

Step 3｜确定病因、持续性与处理目标
按问题选择影像、超声、取液和动态出血证据；不等待完整分类后才处理危险

Step 4｜处理后复评
减压 / 封闭 / 引流 / 通气 / 开胸分别对应压力、通道、内容物、力学或出血来源
同时复查呼吸与循环，并防封闭后张力、复张后水肿、迷走反应等新问题
```
