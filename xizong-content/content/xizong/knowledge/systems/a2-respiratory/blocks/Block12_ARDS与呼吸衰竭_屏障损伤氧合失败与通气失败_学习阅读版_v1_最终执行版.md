## 0｜这个 Block 到底解决什么

上游疾病可损害氧合、通气或两者；ARDS是其中的屏障损伤模型，不能把所有呼吸衰竭都接成ARDS。

```text
换气 / 气血匹配受损 → 动脉氧合失败、PaO₂下降
有效肺泡通气相对CO₂生成不足 → CO₂排出不足、PaCO₂升高，也可伴低氧
两项可并存；Ⅰ / Ⅱ型按实际血气、采样条件和治疗背景判断，不由病名预定

ARDS的特定上游：严重肺部 / 全身损伤
├─ 肺毛细血管内皮受损 → 富蛋白液体渗漏、肺水肿
└─ 肺泡上皮尤其II型细胞受损 → 表活↓、张力↑、肺泡塌陷
充液 / 不张而血流仍过 → 肺内分流 → 给氧仍难完全纠正低氧
同时顺应性↓、有效通气肺量↓，肺血管 / 右心负荷可增加
```

### 本 Block 的总任务

> **先按意识、呼吸功、气道和循环识别危重状态，支持与取证并行；用血气分别读氧合与CO₂排出，用影像、病因和心脏证据确定故障，再把PEEP、有效通气、肺保护和液体策略接回对应环节。**

### 本章实际调用的先备模型

- 肺泡通气由真正参与交换的气量决定；呼吸快不等于有效通气一定增加，PaCO₂还要联系CO₂生成。
- 肺泡要同时有通气与血流：有血少气可形成低VA/Q或分流；PaO₂低与PaCO₂高不是同一件事。
- 表面活性物质降低张力、帮助肺泡稳定；屏障渗漏与左心压力升高是肺水肿的不同起点。
- 肺血管阻力决定右室后负荷；急性负荷后果还取决于右室储备。

先用这些旧模型进入§1A，再在对应节点展开本章知识。缺少哪一环，就在该处补讲；P54–60原文与§4所列必要原图仍各有自己的核对用途。

## 1｜总 Framework

```text
危重入口：先看意识、呼吸功、气道和循环；按需要立即支持并取得血气等证据

上游故障分两维，可以并存
├─ 弥散 / VA-Q / 分流 / 肺血流异常 → 氧合失败
└─ 气道 / 中枢 / 神经肌肉 / 胸壁或呼吸肌疲劳使有效通气不足 → CO₂排出失败
COPD、哮喘、ILD、PE等各按实际故障进入，不能沿一根箭头全变成ARDS

ARDS屏障损伤子支
严重肺部 / 全身事件
├─ 内皮受损、通透性↑ → 富蛋白液体渗漏 / 水肿，渗出和坏死成分可形成透明膜
└─ 肺泡上皮、尤其II型受损 → 表活↓、张力↑ → 不张与反复开闭损伤

两种损伤汇入的功能后果
├─ 充液 / 不张且仍有血流 → 分流↑、严重VA/Q失调 → 顽固低氧
├─ 顺应性↓、可通气肺量↓ → 吸气负担↑；支持时要保护剩余baby lung
└─ 低氧性血管收缩 + 内皮损伤相关微血栓 → PVR↑、肺高压 → 右室后负荷↑
低氧 / 肺水肿反射可增加呼吸；只有有效通气相对CO₂生成增加时PaCO₂才下降

证据读取模型，不能由一个数值直接确诊
血气分别读PaO₂、PaCO₂和pH；Ⅰ / Ⅱ型注明传统室内空气及已给氧条件
ARDS需合看时间、双肺影像、水肿来源与相应氧合 / 正压条件；P/F分级带Berlin版本
心超辅助区分压力性与屏障性水肿，二者可并存；影像呈现不均一和依赖区分布

支持与反馈
├─ 氧疗按反应滴定；低氧、呼吸功、意识与循环决定升级，不是ARDS即人人立即插管
├─ PEEP维持呼气末开放，俯卧改善依赖区分布 → 减少分流 / 反复开闭
├─ 小潮气量 + 平台压限制 → 减少残余肺过度扩张；CO₂代价须看耐受
├─ 相对干肺减少继续渗漏，但避免低容量、痰稠及低钾低氯碱中毒
└─ 通气失败处理气道 / 驱动 / 执行与疲劳，必要时提供有效通气排CO₂
   慢性COPD高碳酸风险控制给氧并复血气，不能套到所有Ⅱ型，也不能放任严重低氧

治疗伤害回接同一模型
过高压力可伤肺且降低回心 / CO；过度通气可使慢性高CO₂者出现酸碱失衡
CO₂与肾代偿按时间解释，不能把正常代偿当代碱；血K和混合紊乱须联合实测
```

### 六个组织问题

```text
是否危重，需要怎样的即时支持？
PaO₂低和PaCO₂高分别指向什么故障，能否并存？
低氧为何难被吸氧完全纠正，是否存在分流？
水肿来自屏障通透性还是左心压力，是否并存？
当前更需要维持肺泡开放、保护残余肺，还是提高有效通气？
支持是否又造成气压伤、低回心或酸碱紊乱？
```

## 1A｜同一模型上的自然节点〔完整 Prompt〕

氧合与通气是两项可同时失控的功能；ARDS只占其中的屏障损伤支。证据读取失效环节，支持和治疗伤害回接同一模型。完整标题〔Prompt〕附在对应机制、条件或旁查处，详细数值、版本和原图沿原owner保留。

```text
先看意识、呼吸功、气道和循环：危重者按当下需要支持，同时取得血气并寻找上游故障
上游疾病可使弥散 / VA-Q / 分流 / 肺血流受损，也可使整体有效肺泡通气不足，两维可以并存
传统海平面、静息、室内空气血气：Ⅰ型低氧且CO₂正常 / 低；Ⅱ型低氧且CO₂升高
已给氧须记装置 / FiO₂并结合治疗前血气；氧被纠正不能取消已确立的通气衰竭
ILD的限制性肺功能不自动等于Ⅱ型，COPD或哮喘也不能只凭病名预定类型
〈Ⅰ型 vs Ⅱ型：核心差别不是病名，而是PaCO₂是否因通气失败升高〔测量前提｜Ⅰ/Ⅱ血气｜换气/通气｜代表病〕〉

ARDS是严重肺部或全身事件触发的特定屏障损伤支
高危事件后的时间窗、进行性气促、双肺影与难纠正低氧共同提示ARDS候选，不是按顺序出现才成立
大量补液更直接提示容量 / 心源性水肿候选；这些上游不能仅凭“低氧”互相替换
〈ARDS高危入口：严重事件后1周内出现进行性顽固低氧〔病因8｜起病时间窗2口径｜进行性｜双肺影｜吸氧反应〕〉
├─ 肺毛细血管内皮受损 → 通透性↑ → 富蛋白液体和细胞成分渗入间质 / 肺泡
└─ 肺泡上皮尤其II型细胞受损 → 表活↓、表面张力↑ → 肺泡 / 小气道塌陷
两支共同改变肺容积、顺应性和气血交换；不是所有通气失败都会先经历这两种损伤
〈ARDS核心：内皮与肺泡上皮两种细胞同时失守〔2细胞｜通透性｜表活｜水肿/不张｜限制+分流〕〉
渗漏的起点是屏障通透性，而非左房 / 肺静脉压力先升；蛋白渗出与坏死成分可形成透明膜
交换距离增加与有效面积减少可同时存在；湿肺、白肺和baby lung分别描述大体、影像与功能肺量
baby lung指可参与通气的肺量少，不要求整只肺肉眼缩小
〈高通透性肺水肿与透明膜：厚度增加与有效面积减少〔内皮渗漏｜非心源性｜透明膜｜厚度/面积2轴｜湿肺〕〉
表活减少和不张使肺更难撑开 → 顺应性↓、吸气所需压力↑
反复开闭可再损伤肺泡 → 进一步恶化原有开放 / 塌陷问题，需要维持适当呼气末容量
〈II型肺泡上皮与表活：为什么肺泡会反复塌陷并越来越难撑开〔II型细胞/表活/张力｜不张链｜顺应性/吸气压｜反复开闭损伤｜呼气末容量〕〉

损伤的功能后果分支展开
├─ 充液 / 塌陷区域通气接近零，血流仍经过 → 血液未充分氧合便回左心
│  → 肺内分流↑ → 高浓度氧仍难完全纠正；膜厚、面积少和区域VA/Q失调可同时参与
│  〈ARDS低氧主链：分流为什么比单纯弥散障碍更顽固〔不张/充液｜局部气/血配对｜分流｜VA/Q｜吸氧反应〕〉
├─ 低PaO₂刺激外周化学感受器，充血 / 水肿刺激J感受器 → 快而费力、可浅快的呼吸
│  若有效肺泡通气相对CO₂生成增加 → PaCO₂下降、呼碱入口；早期低CO₂不代表肺交换正常
│  〈呼吸窘迫：早期过度通气为什么可使PaCO₂下降〔呼吸型式｜2感受器｜通气/CO₂｜5场景〕〉
└─ 低氧性肺血管收缩 + 内皮损伤相关微血栓 → PVR↑ → 肺动脉高压 → 右室后负荷增加
   若负荷急升超过右室储备，可形成急性肺心病；PE的机械阻塞是另一种上游，课程常见病因排序仍回原Core
   〈肺血管与右心：缺氧性收缩 + 微血栓怎样形成急性肺心病〔PVR上游2支｜肺高压/右室后负荷｜急性肺心病：ARDSvsPE〕〉

证据分别读取上述变量和病变分布
动脉血气读取氧、CO₂和pH；P/F将PaO₂与实际吸入氧浓度配对，FiO₂用小数
Berlin分级须结合相应正压、起病时间、双肺影和水肿来源；P/F低单独不能确诊
低流量鼻导管估算不能套到其他装置；定义、三档分度和估算数字留在原Core / Memory
〈氧合指数：FiO₂已经很高，PaO₂仍上不去〔首选｜P/F定义/诊断门槛｜分度3档｜FiO₂估算｜含义〕〉
├─ 心超看左心证据；PAWP是压力线索，不能把单一阈值当排除ARDS的充分条件
│  屏障性和心源性水肿可并存；各自起点不同，不因其中一项存在就取消另一项
│  〈ARDS vs 心源性肺水肿：先看起点，再看超声与PAWP〔屏障vs压力｜首选检查｜PAWP阈值/边界｜并存条件〕〉
└─ 胸片 / CT显示水肿、不张与可能的后期改变，损伤并不均一
   仰卧背侧依赖区更易受压、充液和不张，前侧相对保留 → 解释baby lung及复张 / 体位目标
   〈影像时相与重力依赖区：为什么背侧更容易水肿和塌陷〔X线/CT顺序｜背侧/基底｜早中晚3期｜不均一〕〉

支持直接回到缺氧、肺泡开放、通气和循环
氧疗按反应滴定；分流和低顺应性使单加氧可能不足
根据低氧、呼吸功、意识与循环及时升级支持，不把ARDS诊断等同于人人立即插管
压力控制 / 容量控制名称不能替代实际潮气量、压力与患者反应
〈氧疗与机械通气：ARDS不是只“多吸一点氧”〔氧合目标｜支持升级｜2模式｜保护目标〕〉
├─ PEEP维持呼气末肺容量、帮助开放塌陷区 → 减少分流与反复开闭损伤
│  但压力过高可致气压伤；胸内压↑可使回心↓、CO / 血压↓，低容量会放大循环代价
│  从低水平按反应调整，不能只追求更高PEEP和PaO₂；课程范围与容量门槛同时保留
│  〈PEEP：撑开塌陷肺泡，但胸内压与气压伤不能被忽略〔PEEP目的｜起始/调节范围｜肺泡4效｜风险2链｜容量门槛〕〉
├─ 可通气肺量少，过大潮气量更易进入剩余肺并使其过度扩张
│  → 采用按预测体重的小潮气量与平台压限制，减少机械损伤
│  减少通气可带来CO₂代价，但须看酸血症、颅内压、右心和循环耐受，不主动追求高CO₂
│  〈小潮气量与平台压：保护残余健康肺，而不是把所有肺泡“吹满”〔潮气量/体重基准｜平台压｜CO₂代价｜pH条件〕〉
├─ 俯卧减轻背侧大体积肺区受压、改善通气 / 压力 / 血流分布
│  → 可复张区域参与交换、功能性分流减少 → 氧合改善
│  〈俯卧位：把背侧大体积肺组织从“压在下面”变成可复张区〔仰卧vs俯卧｜背侧受压/复张｜通气-压力-血流分布｜分流→氧合〕〉
└─ 限制继续渗漏、保持相对干肺；同时看灌注与容量，避免过度利尿
   低容量叠加PEEP会进一步降低回心；痰稠、低钾低氯碱中毒也会增加负担
   严重哮喘可能缺液，不能机械套用同一液体方向
   〈相对干肺：减少继续渗漏，但不能把患者利到低容量、低钾和碱中毒〔液体方向/利尿｜哮喘对照｜PEEP+低容量｜过利尿3害〕〉

整体有效肺泡通气不足时，另回气道 / 中枢 / 神经肌肉 / 胸壁与呼吸肌疲劳寻找原因
→ 处理可纠正故障并按需要支持有效通气排CO₂，给氧不能代替排CO₂
慢性COPD高碳酸风险者控制给氧并复血气；过量氧可经部分驱动下降、VA/Q更失配和Haldane效应升CO₂
不能仅归为“靠缺氧呼吸”，也不能因担心CO₂放任严重低氧；急性哮喘不自动套慢COPD方案
〈吸氧浓度：慢性COPD型Ⅱ型需要低浓度，不能把规则套到所有Ⅱ型〔氧合目标｜CO₂潴留3因｜控制给氧｜血气复查〕〉
呼吸兴奋剂只有中枢可响应、传出 / 肌肉可执行且气道通畅时才可能有效；不能修复交换膜或失效执行器
机制分类不是具体药适应证；讲义药物 / 例子与多沙普仑禁忌的Source冲突沿KP18明确分层
不能由“脑干出血造成中枢抑制”推导该药可用，不能用兴奋剂拖延必要通气支持
〈呼吸兴奋剂：只有完整反射弧和可执行呼吸肌时才可能有效〔急/慢药｜中枢适应｜气道通畅｜禁2慎1｜COPD弱效边界〕〉

低氧与高CO₂还各自作用于其他器官，时间尺度不同
├─ 慢性低氧 → 肾HIF / EPO信号 → 红细胞增多代偿；成人肾HIF-2与旧讲义HIF-1差异保留
└─ 急性低氧 / CO₂潴留可影响意识、脑血管与颅压，也可有球结膜水肿线索；急性来不及增红系
〈呼衰全身表现：慢性低氧增红细胞，急性低氧 / CO₂影响脑和眼〔慢性低氧：HIF/EPO/RBC轴｜神经表现2｜球结膜｜急慢边界〕〉
CO₂潴留 → 呼酸；急性先缓冲，随时间肾排酸与保留 / 生成HCO₃⁻更充分
合适代偿的HCO₃⁻升高仍可为单纯呼酸，不直接等同合并代碱

这些是条件性分支，不是所有慢性Ⅱ型都必经“失代偿→代酸→高钾”
〈慢性Ⅱ型呼衰酸碱电影：呼酸→肾保HCO₃⁻→失代偿→缺氧性代酸〔急慢代偿｜CO₂/HCO₃/pH｜混合紊乱｜血K条件〕〉

治疗后的结果必须回读同一模型
补碱不当、过利尿、过度通气、KCl补不足可使pH升高

〈pH升高与机械通气并发症：治疗本身也会制造新的Failure Mode〔pH↑4因｜机械通气CO₂目标｜并发7类｜回心链〕〉
稳定性、血气、故障层、支持与防伤害贯穿全程；PaCO₂ / HCO₃⁻方向要区分原发改变与代偿
AB / SB沿原比较式作入口，未准入额外标准化定义仍排除；完整定量 / 混合紊乱交A3 B5 KP19–20
呼酸先改善气道、氧合和通气；原补碱考试阈值不自动成为输碱指令
〈酸碱快速入口与呼吸危重五步算法〔pH｜PaCO₂｜BE/HCO₃/CO₂CP｜K｜AB/SB｜补碱边界｜五步〕〉
```

## 2｜Memory Routing

### MI-G｜沿模型主动恢复的要点

1. 呼吸窘迫常快而费力，深浅不固定；ARDS早期过度通气可出现 PaCO₂下降和呼吸性碱中毒。
2. ARDS常在高危事件后1周内、尤其72小时内出现进行性呼吸困难与顽固低氧。
3. ARDS核心是**肺毛细血管内皮 + 肺泡上皮**两种细胞损伤。
4. 内皮损伤→高通透性非心源性肺水肿；II型肺泡上皮损伤→表活下降、肺泡塌陷。
5. ARDS是限制性通气入口 + 换气 / 分流失败；顺应性下降、肺内分流是低氧核心。
6. PaO₂ / FiO₂≤300是课程必要氧合条件，200 / 100分档；Berlin版本还须相应正压、时间、双肺影和水肿来源条件，不能凭比值单独确诊，详见KP08。
7. 鉴别心源性肺水肿首选心脏超声；PAWP<18支持ARDS，但>18不能排除并存。
8. PEEP的任务是复张肺泡、增加呼气末肺容量、减少分流和反复开闭。
9. 肺保护：按预测体重给小潮气量、限制平台压，结合耐受性允许一定高碳酸血症；数字与版本见KP13。
10. 俯卧位使背侧重力依赖区肺泡复张，减少功能性分流。
11. Ⅰ/Ⅱ型传统室内空气判据与给氧后血气须分开；Ⅱ型突出PaCO₂>50 mmHg，详见KP16。
12. 慢性COPD高碳酸风险控制给氧并复血气；严重急性哮喘发生通气衰竭时可为Ⅱ型，不能机械套用同一COPD氧疗方案，详见KP17。
13. 呼吸兴奋剂只适合“中枢可被兴奋、传出和呼吸肌仍能执行、气道通畅”的通气障碍。
14. 急性早期肾代偿尚不充分，慢性更充分；代偿性HCO₃⁻升高不等于合并代碱。
15. 慢性Ⅱ型呼衰pH升高常是医源性：补碱、过度利尿、过度通气、补KCl不足。
16. 机械通气升高胸内压可使回心、CO和血压下降；不能只盯血气。

## KP03｜ARDS核心：内皮与肺泡上皮两种细胞同时失守

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** 2细胞｜通透性｜表活｜水肿/不张｜限制+分流

### 1｜肺毛细血管内皮

损伤后：

```text
通透性↑
→ 液体、蛋白、纤维蛋白、细胞成分渗出
→ 肺间质和肺泡水肿
```

### 2｜肺泡上皮

尤其II型肺泡上皮损伤：

```text
表面活性物质↓
→ 表面张力↑
→ 肺泡 / 小气道萎陷、不张
```

### 3｜共同后果

- 肺容积下降；
- 顺应性下降；
- 限制性通气障碍入口；
- 弥散距离增加；
- 肺内分流与严重VA/Q失调；
- 顽固性低氧。

## KP04｜高通透性肺水肿与透明膜：厚度增加与有效面积减少

> **讲义定位 →** 内科 Lecture P54；回看R5病毒性肺炎  
> **Outline →** 内科 U021｜核心机制1；病理DAD只Recall  
> **主提示：** 内皮渗漏｜非心源性｜透明膜｜厚度/面积2轴｜湿肺

### 1｜非心源性肺水肿

ARDS的液体进入肺泡，起点是屏障通透性增加，而不是左房 / 肺静脉压力先升高。

```text
内皮损伤
→ 富含蛋白的液体渗出
→ 间质 / 肺泡水肿
→ 非心源性肺水肿
```

### 2｜透明膜

蛋白性渗出物和坏死成分贴附肺泡壁，可形成透明膜。

### 3｜厚度与面积两条作用轴

```text
渗出尚未充满肺泡
→ 扩散距离↑、呼吸膜“变厚”

渗出充满 + 肺泡塌陷
→ 有效交换面积↓、肺容积↓
```

上述为讲义便于理解的分解，实际水肿、塌陷与交换面积减少可并存，并非必须严格先后发生。

### 4｜肉眼与功能识别

- 湿肺：暗红、水肿、重量增加；
- 小 / 婴儿肺（baby lung）：可参与通气的功能性肺量减少，不等于整只肺肉眼必然缩小；
- 白肺：弥漫性渗出影像接口。

## KP05｜II型肺泡上皮与表活：为什么肺泡会反复塌陷并越来越难撑开

> **讲义定位 →** 内科 Lecture P54  
> **Outline →** 内科 U021｜核心机制1  
> **主提示：** II型细胞/表活/张力｜不张链｜顺应性/吸气压｜反复开闭损伤｜呼气末容量

```text
II型肺泡上皮损伤
→ 表面活性物质↓
→ 肺泡表面张力↑
→ 肺泡、小气道萎陷
→ 肺不张
→ 肺顺应性↓
→ 吸气所需压力↑
```

若肺泡在每个呼吸周期反复开放—闭合，会形成新的机械损伤；因此治疗不仅要“给氧”，还要维持适当呼气末肺容量。

表活原本还可减少液体向肺泡内的“抽吸”；减少后这项保护也变弱（回看R1 KP12）。这不替代本章内皮损伤→通透性升高的主渗漏链，两项可共同加重肺泡充液。

（易混：ARDS的“表面张力增加”不是肺气肿；肺气肿是弹性框架破坏、回缩动力下降。）

## KP06｜ARDS低氧主链：分流为什么比单纯弥散障碍更顽固

> **讲义定位 →** 内科 Lecture P54–55

> **主提示：** 不张/充液｜局部气/血配对｜分流｜VA/Q｜吸氧反应

肺泡充液或塌陷
→ 肺泡通气接近0

## KP08｜氧合指数：FiO₂已经很高，PaO₂仍上不去

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜检查1–2  
> **主提示：** 首选｜P/F定义/诊断门槛｜分度3档｜FiO₂估算｜含义

### 1｜首选检查

> 动脉血气分析。

### 2｜氧合指数

```text
PaO₂ / FiO₂ ≤ 300
→ 当前 Study的ARDS必要氧合条件
```

分度：

| 程度 | PaO₂ / FiO₂ |
|---|---|
| 轻度 | 200 < P/F ≤300 |
| 中度 | 100 < P/F ≤200 |
| 重度 | ≤100 |

P/F单位为mmHg，FiO₂代入小数。按Berlin定义使用上述分级时，还须满足相应正压条件（PEEP≥5 cmH₂O；轻度可为CPAP≥5），以及起病时间、双肺影像和水肿来源等条件；P/F降低单独不能确诊ARDS。此处标明定义版本，不把它说成全部现代定义的唯一入口。

### 3｜FiO₂估算

当前 Study：

```text
普通低流量鼻导管的粗略估算：
吸入氧浓度（%）≈ 21 + 4 × 氧流量（L/min）
```

该估算受呼吸型式、分钟通气量和装置影响，不能套用于面罩、高流量装置或呼吸机；分级优先采用可靠的实际设定/测定FiO₂。

例如40%氧、PaO₂ 80 mmHg：

```text
P/F = 80 / 0.40 = 200
```

> 比值低说明“增加吸入氧浓度后，动脉氧分压仍难升高”。

## KP11｜氧疗与机械通气：ARDS不是只“多吸一点氧”

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗1–2  
> **主提示：** 氧合目标｜支持升级｜2模式｜保护目标

### 1｜氧疗目标

当前 Study：

- 高浓度吸氧；
- PaO₂≥60 mmHg；
- SaO₂≥90%。

### 2｜为何需要尽早机械通气

ARDS存在分流、肺泡塌陷和顺应性下降，单纯提高FiO₂往往不足；讲义强调多数患者尽早机械通气。实际按低氧程度、呼吸功、意识及循环状况选择和及时升级支持，不能把ARDS诊断直接等同于人人立即插管；FiO₂随氧合反应滴定，避免不必要的持续高氧。

### 3｜通气模式边界

讲义的选项口径是“压力控制较容量控制更常用”。肺保护的关键则是实际潮气量、平台压及患者反应；压力控制和容量控制均可实施肺保护，压力控制本身不保证潮气量安全，容量控制也不等于不能限压。

不在此扩写现代呼吸机全部模式和参数。

## KP12｜PEEP：撑开塌陷肺泡，但胸内压与气压伤不能被忽略

> **讲义定位 →** 内科 Lecture P55  
> **Outline →** 内科 U021｜治疗3–4  
> **主提示：** PEEP目的｜起始/调节范围｜肺泡4效｜风险2链｜容量门槛

### 1｜当前 Study参数

```text
先从5 cmH₂O起
→ 逐步至8–18 cmH₂O适当范围
```

### 2｜四个目标

- 增加呼气末肺容量；
- 使萎陷肺泡 / 小气道再开放；
- 改善弥散与VA/Q，减少肺内分流；
- 防止肺泡在呼吸周期反复开闭。

### 3｜两类主要风险

```text
压力过高
→ 肺气压伤

胸内压↑
→ 静脉回心↓
→ CO↓、血压↓
```

因此：

- 从低水平开始；
- 血容量不足者需纠正容量不足；
- 不能只追求更高PEEP与更漂亮的PaO₂。

这里讨论的是支持时施加的外源性PEEP。COPD / 哮喘因呼气受限、气体来不及排空而形成的内源性PEEP，起点是气体潴留；不能把它当成同一项治疗效果。完整气体潴留模型回R3 / R4。

## KP13｜小潮气量与平台压：保护残余健康肺，而不是把所有肺泡“吹满”

> **讲义定位 →** 内科 Lecture P56  
> **Outline →** 内科 U022｜5  
> **主提示：** 潮气量/体重基准｜平台压｜CO₂代价｜pH条件

### 1｜肺保护参数

```text
潮气量 4–8 mL/kg 预测体重（PBW，不是实际体重）
平台压：讲义≤30 cmH₂O；ATS肺保护推荐表述为<30 cmH₂O
```

### 2｜为什么不是大潮气量

ARDS肺泡损伤不均：病变肺泡难打开，气体更易进入剩余健康肺泡。大潮气量会使“baby lung”过度扩张，增加机械损伤。

### 3｜允许性高碳酸血症

小潮气量可能使CO₂排出不足；当前 Study允许：

```text
一定程度CO₂潴留
pH约7.25–7.3
```

目标是用可接受的CO₂代价减少肺泡过度扩张，不要求把所有血气数字立即恢复正常。讲义的pH范围不是所有患者必须达到或均可安全耐受的固定目标；须同时评估酸血症、颅内压、右心负荷和循环状态，不能为追求高CO₂而主动降低通气。

→ 背侧肺受重力、心脏压迫

# Unit C｜呼吸衰竭：先判氧合失败还是通气失败

## KP16｜Ⅰ型 vs Ⅱ型：核心差别不是病名，而是PaCO₂是否因通气失败升高

> **讲义定位 →** 内科 Lecture P58；Recall R2  
> **Outline →** 内科 U023｜分类1–2  
> **主提示：** 测量前提｜Ⅰ/Ⅱ血气｜换气/通气｜代表病

| 轴 | Ⅰ型呼衰 | Ⅱ型呼衰 |
|---|---|---|
| 血气（mmHg） | PaO₂<60；PaCO₂正常或低 | 传统室内空气判据为PaO₂<60且PaCO₂>50；给氧后PaO₂可被纠正而高碳酸血症持续 |
| 主要故障 | 肺换气障碍 | 肺泡通气障碍 |
| O₂ | 进入动脉血失败 | 进入肺泡不足，同时CO₂排不出 |
| 急性代表 | ARDS、急性PE、急性肺水肿 / 左心衰、严重肺部感染 | 严重哮喘、脑干出血、膈肌麻痹 / MG、镇静催眠药中毒、气管异物 |
| 慢性 / 急性代表 | ILD | COPD、脊柱侧凸 / 胸廓畸形 |

上述传统数值按海平面、静息、呼吸室内空气理解；已给氧者须注明装置/FiO₂并结合治疗前血气，不以纠正后的PaO₂否定原有通气衰竭。

（边界：ILD也有“限制性通气”表现，但其呼衰主要矛盾可为换气 / 弥散；COPD也有换气障碍，但CO₂潴留体现通气失败。）

换气受损时为什么常先见低氧而没有CO₂潴留？CO₂较易扩散，仍能通气的肺区还可增加排CO₂；但这些肺区的Hb已接近饱和，难以再多带足够O₂去补偿病变区。因此低氧可与正常 / 降低的PaCO₂并存。动静脉分压差和两条气体解离曲线的完整比较回R2 KP04；一旦整体有效通气不足，仍可叠加高碳酸血症。

## KP17｜吸氧浓度：慢性COPD型Ⅱ型需要低浓度，不能把规则套到所有Ⅱ型

> **讲义定位 →** 内科 Lecture P58；Recall R2化学感受器  
> **Outline →** 内科 U023｜分类2  
> **主提示：** 氧合目标｜CO₂潴留3因｜控制给氧｜血气复查

### 1｜Ⅰ型

换气失败、低氧突出，当前 Study采用高浓度吸氧方向。

### 2｜慢性Ⅱ型COPD

```text
长期PaCO₂↑
→ 中枢化学感受器适应
→ 低氧对外周化学感受器的刺激更重要
→ 过量给氧可降低部分通气驱动
同时：低氧性肺血管收缩被解除→VA/Q失配加重；Haldane效应→血液释出CO₂
→ CO₂可升高，不能只归因于“靠缺氧呼吸”
```

讲义用 `<35%` 提示控制给氧；临床对有高碳酸血症风险者通常先以SpO₂ 88–92%为目标并复查血气，再按结果调整，不以固定氧浓度代替目标监测，也不能因担心CO₂而放任严重低氧。

### 3｜不能过度泛化

- 严重急性哮喘发生通气衰竭时可为Ⅱ型，氧疗同样按病情和目标滴定，不能机械套用COPD方案；
- Ⅱ型定义不再要求吸氧后PaO₂仍低：已确立通气衰竭时，即使PaO₂被给氧纠正而PaCO₂仍>50，也不能据此取消Ⅱ型判断；仍结合治疗前血气、酸碱状态和病因。

## KP19｜呼衰全身表现：慢性低氧增红细胞，急性低氧 / CO₂影响脑和眼

## KP20｜慢性Ⅱ型呼衰酸碱电影：呼酸→肾保HCO₃⁻→失代偿→缺氧性代酸

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理2–3  
> **主提示：** 急慢代偿｜CO₂/HCO₃/pH｜混合紊乱｜血K条件

### 1｜急性 vs 慢性

- 急性Ⅱ型：早期以非肾性缓冲为主，肾性适应尚不充分，不宜绝对写成“急性完全没有肾反应”；
- 慢性Ⅱ型：经时间积累，肾排酸、保留和生成HCO₃⁻的适应更充分。

### 2｜当前 Study连续过程

```text
CO₂长期潴留
→ 呼吸性酸中毒

肾HCO₃⁻重吸收↑
→ HCO₃⁻↑
→ pH接近正常：代偿性呼酸

病情继续恶化
→ 肾代偿不足
→ pH↓：失代偿性呼酸

严重缺氧
→ 无氧代谢、酸性产物↑
→ 合并代谢性酸中毒
→ 可出现血钾异常，须结合酸的类型、肾排钾、药物和组织损伤实测判断
→ 不能把缺氧性乳酸酸中毒机械等同于必然高钾
```

这些是可能相接的条件分支，不是所有慢性Ⅱ型都必经的固定阶段。讲义用“呼酸 + 代碱”描述HCO₃⁻升高，但合适范围内的肾性代偿仍是单纯呼酸；只有超出预期代偿并结合病因才判断合并代碱。完整代偿公式在泌尿K5统一。

## KP21｜pH升高与机械通气并发症：治疗本身也会制造新的Failure Mode

> **讲义定位 →** 内科 Lecture P59  
> **Outline →** 内科 U023｜病理生理4；机械通气1  
> **主提示：** pH↑4因｜机械通气CO₂目标｜并发7类｜回心链

### 1｜慢性Ⅱ型呼衰pH升高四因

1. 补碱不当；
2. 利尿过量；
3. 机械通气过度；
4. KCl补充不及时。

机械通气可使PaCO₂迅速下降，但肾脏保留的HCO₃⁻下降较慢：

```text
CO₂快速下降 + HCO₃⁻仍高
→ 代谢性碱中毒 / 混合紊乱
```

因此当前 Study强调：慢性Ⅱ型呼衰机械通气时，PaCO₂应降至患者原有水平，而不是骤然“正常化”。

### 2｜机械通气并发症七组

- 呼吸机所致肺损伤：肺水肿、高氧性肺损伤；
- 呼吸机所致膈肌功能障碍；
- 呼吸机相关肺炎；
- 代谢性碱中毒及混合酸碱紊乱；
- 气胸、纵隔 / 皮下气肿、间质性肺气肿；
- 气囊压迫：黏膜缺血、气道狭窄、气管软化、气管—食管瘘；
- 胸内压↑→回心↓→CO↓→血压↓。

> 机械通气不是“把血气调好”就结束，还必须同时监测肺、气道、感染、膈肌与循环。

## KP22｜酸碱快速入口与呼吸危重五步算法

> **讲义定位 →** 内科 Lecture P60  
> **Outline →** 内科 U023｜酸碱1–7；全部可见问句均路由  
> **主提示：** pH｜PaCO₂｜BE/HCO₃/CO₂CP｜K｜AB/SB｜补碱边界｜五步

### 1｜当前 Study快速阈值

| 指标 | 方向 |
|---|---|
| pH<7.35 | 酸血症；再判断原发过程与混合紊乱 |
| pH>7.45 | 碱血症；正常pH也不能排除混合紊乱 |
| PaCO₂<35 mmHg | 呼吸性碱中毒方向 |
| PaCO₂>45 mmHg | 呼吸性酸中毒方向 |
| BE<-2.3 mmol/L | 代谢性酸中毒方向 |
| BE>+2.3 mmol/L | 代谢性碱中毒方向 |
| HCO₃⁻<22 mmol/L | 代谢性酸中毒方向 |
| HCO₃⁻>27 mmol/L | 代谢性碱中毒方向 |
| CO₂结合力（CO₂CP）↑ | HCO₃⁻ / 碱储备升高方向；可见于代碱或呼酸代偿，不能脱离pH、PaCO₂单独定性 |
| K⁺<3.5 mmol/L | 多与代碱方向相伴 |
| K⁺>5.5 mmol/L | 多与代酸方向相伴 |

PaCO₂、HCO₃⁻的方向还可能属于代偿：低PaCO₂可为代酸的呼吸代偿，高HCO₃⁻可为呼酸的肾代偿。BE和血钾也不能单独确定混合紊乱；上述参考范围沿用讲义，须看实验室范围及完整血气。

### 2｜AB / SB当前 Study入口

```text
AB = SB <22
→ 代酸

AB = SB >27
→ 代碱

AB > SB
→ 呼酸方向

AB < SB
→ 呼碱方向
```

AB/SB的浓度单位为mmol/L；这组是讲义的快速线索，不能取代pH、PaCO₂与预期代偿的联合判断。

### 3｜补碱边界

当前 Study 强调：呼吸系统疾病导致的酸中毒，首先应改善气道、氧合与肺泡通气，不常规直接补碱；仅当 **pH<7.2** 时，才保留使用 **5% NaHCO₃** 的考试口径。这只是讲义考试阈值，不是pH一低于7.2就自动输碱的临床指令；纯呼吸性酸中毒首先改善通气，碳酸氢钠可增加CO₂负荷，须区别是否合并代酸并评估排CO₂能力。完整酸碱诊断回A3 B5 KP19–20；该接口不包含NaHCO₃治疗指征、剂量或ICU通气方案，本章也不扩写这些治疗内容。

### 4｜五步危重算法

```text
Step 1｜稳定性
意识、呼吸功、血压、沉默肺 / 气道、紫绀

Step 2｜血气
PaO₂低？PaCO₂高？pH是否失代偿？

Step 3｜故障层
氧合失败：弥散 / VA-Q / 分流 / 肺血管
通气失败：气道 / 中枢 / 胸壁 / 神经肌肉 / 呼吸肌疲劳

Step 4｜立即支持
高浓度氧、低浓度氧、PEEP、NIV / 有创通气按病因和危重度选择

Step 5｜防止治疗伤害
过度通气、PEEP低回心、过利尿、低K碱中毒、气压伤、VAP
```

（边界：完整代偿公式、混合性酸碱定量、阴离子间隙与肾性处理统一回看 A3 B5 KP19–KP20：`泌尿系统_Block5_水钠钾钙与酸碱整合_学习阅读版_v1_最终执行版.md`。这是原owner的精确回看入口，本轮不重审或改写A3。）

## 3｜高密度比较表

### 3.1 ARDS vs 心源性肺水肿

| 轴 | ARDS | 心源性肺水肿 |
|---|---|---|
| 上游 | 炎症 / 屏障损伤 | 左心压力负荷 / 泵衰 |
| 水肿机制 | 通透性↑，非心源性 | 肺静脉静水压↑ |
| 低氧 | 分流突出，常顽固 | 弥散 / 肺泡充液；纠正心衰后改善 |
| 心超 | 无必须的左心衰证据 | 可见左心结构 / 功能异常 |
| PAWP | 通常<18 | 通常>18 |
| 治疗主轴 | 肺保护通气、PEEP、相对干肺、处理原发病 | 强心 / 利尿 / 降前后负荷等循环主轴 |

### 3.2 氧合失败 vs 通气失败

| 轴 | 氧合失败 | 通气失败 |
|---|---|---|
| 核心字母 | PaO₂ | PaCO₂ |
| 主要机制 | 弥散、VA/Q、分流、肺血流 | 肺泡通气量下降 |
